第 1 題

社會個案工作、團體工作及社區工作正式納入社會工作三大方法之時間先後順序，下列何者正確？
  1. （A）社會個案工作、團體工作、社區工作
  2. （B）社區工作、社會個案工作、團體工作
  3. （C）社會個案工作、社區工作、團體工作
  4. （D）團體工作、社區工作、社會個案工作

答案：（C）

詳解與考點

正解：社會工作三大方法在專業發展史上並非同時被正式承認，一般整理其確立的先後順序為：社會個案工作最早確立為專業方法（以 Mary Richmond《社會診斷》一書所奠定的個案工作方法論為代表，時間最早）；社區工作其次，早期由睦鄰運動與慈善組織會社協調救濟資源的實務經驗發展而來，並經重要報告確立為社會工作方法之一，確立時間早於團體工作正式被專業協會承認的時間點；團體工作雖然在實務操作上歷史悠久，但正式被納為社會工作第三種基本方法、成立專業組織並獲承認，時間相對最晚。三者確立順序依序為個案工作、社區工作、團體工作，故選 C。

A：社會個案工作、團體工作、社區工作——順序將團體工作排在社區工作之前，是最容易誤植的排列，因團體工作在實務操作上歷史悠久容易讓人誤以為其正式確立時間也較早；但就正式納入社會工作方法的專業化時間點而言，社區工作的確立實際早於團體工作，此為本題最主要的誘答。

B：社區工作、社會個案工作、團體工作——將社區工作列為最早確立的方法，與個案工作最早被系統化確立為專業方法的史實不符，個案工作的確立時間應早於社區工作。

D：團體工作、社區工作、社會個案工作——將個案工作列為最晚確立的方法，與個案工作作為社會工作最早系統化、最早確立方法論的專業發展史實相反，順序完全顛倒。

本題考點：社會工作三大方法（個案工作、團體工作、社區工作）的專業化確立順序，是社會工作發展史的常考重點，須留意實務操作歷史與正式確立為專業方法的時間點未必一致，尤其團體工作與社區工作的確立先後常是混淆焦點。

第 38 題

以社區組織層面為核心的「社區培力」（empowerment），何者為優先的工作方針？①以弱勢個案需求為焦點 ②強調共同工作及學習 ③伴隨服務資源一同發展 ④重視平等及民主價值
  1. （A）①②③
  2. （B）①③④
  3. （C）②③④
  4. （D）①②④

答案：（C）

詳解與考點

正解：社區組織層面的社區培力（community empowerment）以社區整體的集體行動與能力建構為核心，優先方針在於強調共同工作及學習、伴隨服務資源一同發展、以及重視平等及民主價值，三者皆屬社區組織層次培力工作的核心方針，組合恰為②③④，故選 C。

A、B、D：三者同因而不得選——A（①②③）、B（①③④）、D（①②④）均含①「以弱勢個案需求為焦點」，而①屬個案工作層次關注個別案主需求評估與處遇的取向，並非社區組織層次培力工作的優先方針；社區培力著重社區整體成員的集體參與、共同行動與結構性改變，而非聚焦單一個案的需求，故凡納入①的組合選項皆應排除。

本題考點：社區培力（Community Empowerment），以社區集體行動、共同學習、資源發展與平等民主價值為核心的社區工作方法；培力工作的層次區分（個案、團體、社區），社區組織層次的培力方針有別於個案工作層次以個別需求為焦點的取向。

第 36 題

社區能力建構的重要手法中，下列敘述何者正確？①政府資源應該持續的提供，方能建立社區的服務永續能力 ②社區方案撰寫能力的培養有助於社區居民改善生活 ③與社區中利害關係人之政治協商未有其必要性 ④社區資源網絡的建立可幫助社區增進政治影響力
  1. （A）①②
  2. （B）③④
  3. （C）①③
  4. （D）②④

答案：（D）

詳解與考點

正解：本題採先判斷各命題正誤、再選正確組合的形式。命題②「社區方案撰寫能力的培養有助於社區居民改善生活」正確——社區方案撰寫能力是社區能力建構的重要環節，居民具備此能力才能爭取外部資源、規劃並執行改善生活的具體方案。命題④「社區資源網絡的建立可幫助社區增進政治影響力」正確——透過建立跨組織、跨部門的資源網絡，社區得以整合力量、擴大集體發聲的基礎，進而增進其在政治場域中的影響力與談判籌碼。②④皆正確，故選 D。

A：命題①「政府資源應該持續提供，方能建立社區的服務永續能力」有誤——社區能力建構的核心精神在於培養社區自主解決問題、動員自身及在地資源的能力，若持續仰賴政府資源挹注，反而容易養成社區對外部資源的依賴、削弱其自主發展與永續經營的能力，與能力建構培力（empowerment）的目標相悖，選項 A 因含①而不選。

B、C：命題③「與社區中利害關係人之政治協商未有其必要性」有誤——社區能力建構的過程中，社區內部及與外部行動者（如政府、企業、其他組織）之間的政治協商，是整合意見、化解衝突、爭取資源與正當性的必要手段，絕非無必要；選項 B、C 皆因含③而不選。

本題考點：社區能力建構（Community Capacity Building），強調培養社區自主解決問題、撰寫方案爭取資源、建立資源網絡以增進政治影響力等內在能力，而非單純仰賴外部資源持續挹注；社區能力建構亦重視與利害關係人（stakeholders）的政治協商，作為凝聚共識與爭取權益的必要過程。

第 4 題

在社區組織的資源整合中，實務上的關鍵在於那一個原則？
  1. （A）目標共識、策略共識
  2. （B）事工與資源現況
  3. （C）發現重疊與空隙
  4. （D）移動填補空隙

答案：（C）

詳解與考點

正解：社區組織進行資源整合時，實務程序通常包括先掌握目標共識、盤點既有事工與資源現況，再進一步「發現重疊與空隙」，最後才據以採取行動填補缺口；其中「發現重疊與空隙」是整個資源整合能否有效推展的關鍵所在——唯有先診斷出哪些服務彼此重疊（造成資源浪費）、哪些領域出現空白（造成需求未被滿足），後續的目標協調與行動填補才有明確依據，故本題選C。

A：「目標共識、策略共識」是資源整合過程中前置且重要的協調基礎，讓各方單位對整合方向有共同理解，但其本身屬於整合的起點與條件，而非診斷資源現況、找出問題所在的關鍵操作步驟。

B：「事工與資源現況」是資源整合的基礎資料蒐集工作，屬盤點階段，說明的是「有什麼」，尚未進到分析「哪裡重疊、哪裡欠缺」的診斷層次，因此是前置步驟而非題目所問的關鍵所在。

D：「移動填補空隙」是找出空隙之後才能進行的具體行動，屬整合流程的後續執行步驟，必須以「先發現重疊與空隙」為前提，若尚未診斷出問題所在便貿然行動，填補方向恐無所依據。

本題考點：社區資源整合（community resource integration），其實務流程強調先盤點現況、凝聚目標共識，再透過診斷「重疊與空隙」找出資源配置問題，最後才據以行動調整，其中「發現重疊與空隙」的診斷步驟是整合能否對症下藥的關鍵。

第 2 題

社會工作專業重視案主自決、充權、案主參與等概念，這些概念屬於何種模型的考量？
  1. （A）道德模型
  2. （B）商業模型
  3. （C）政治模型
  4. （D）成本效益模型

答案：（A）

詳解與考點

正解：案主自決（client self-determination）、充權（empowerment）與案主參與等概念，其核心精神在於尊重案主作為獨立個體的人性尊嚴、自主意志與主體地位，這是植基於倫理價值層次的考量，對應於道德模型（moral/ethical model），故選A。

B：商業模型（business model）以市場競爭、顧客滿意度、營收與效率作為核心考量，與案主自決等強調人性尊嚴與自主權利的價值取向不同，並非本題所指之考量模型。

C：政治模型（political model）著重權力分配、政治過程與各方利益角力，充權概念常涉及案主權力增能，容易讓人聯想到政治模型而誤選；但案主自決、案主參與的根本精神仍在於對人的倫理尊重，而非權力結構本身的運作，故不選C。

D：成本效益模型（cost-benefit model）以資源投入與產出效益的量化比較作為核心考量，關注的是效率與經濟性，與案主自決等強調價值與尊嚴的取向不同。

本題考點：社會工作實務中的道德模型（moral model），強調以尊重案主尊嚴、自主權利與案主參與為核心的倫理價值考量；與商業模型、政治模型、成本效益模型等以效率、權力或經濟性為核心考量的模型相區辨。
