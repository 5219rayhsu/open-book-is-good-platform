第 1 題

社會排除成為當代社會政策的核心概念之一，下列敘述何者不是社會排除概念所強調的重點？
  1. （A）社會排除是多面向的概念
  2. （B）社會排除所指涉的是一個靜態的結果
  3. （C）社會排除更多是來自於因為結構因素
  4. （D）社會排除涉及到社會心理層面的影響

答案：（B）

詳解與考點

正解：社會排除概念強調的重點包括：其為多面向（multi-dimensional）現象，同時涉及經濟、政治、社會、文化等層面的剝奪；其成因主要來自結構性因素（如勞動市場排除、制度性歧視），而非純粹個人歸因；且排除經驗會帶來社會心理層面的影響（如污名、自我認同受損、社會疏離）。但社會排除更被強調的是一個動態過程（dynamic process），即個人或群體被逐步推向社會邊緣的持續性歷程，而非固定不變的靜態結果；B將其描述為靜態結果，恰與此核心特徵相反，故本題選B。

A：社會排除確實是多面向概念，同時涵蓋經濟、社會、政治、文化等多重剝奪面向，此為社會排除概念的正確重點。

C：社會排除確實更強調來自結構性因素（如制度安排、勞動市場結構、社會資源分配），而非僅歸因於個人特質或選擇，此為正確重點。

D：社會排除確實涉及社會心理層面的影響，例如被排除者的自我認同、歸屬感與心理健康皆可能受衝擊，此為正確重點。

本題考點：社會排除（Social Exclusion），指個人或群體因結構性因素被逐步邊緣化、無法充分參與社會經濟政治生活的動態過程；社會排除與貧窮概念的差異，在於前者強調多面向、動態、關係性的排除歷程，而非僅止於所得不足的靜態狀態。

第 2 題

對於費邊社會主義的敘述，下列何者錯誤？
  1. （A）社會主義應該要透過一套中立的仲裁制度來加以統治
  2. （B）社會主義應該透過革命式的階級鬥爭來達成
  3. （C）相信專業文官可以透過社會行政來解決社會問題
  4. （D）強調國有化

答案：（B）

詳解與考點

正解：費邊社會主義主張透過漸進式改良、國家仲裁與專業文官體系逐步推動社會主義理想，反對以革命式階級鬥爭作為達成手段；B選項所述「透過革命式的階級鬥爭來達成」正是馬克思主義（Marxism）而非費邊社會主義的核心主張，此敘述錯誤，故選B。

A：費邊社會主義確實主張社會主義的實現應透過一套中立的仲裁制度（如國家）加以統治協調，而非階級對抗，此敘述正確，故不選。

C：費邊社會主義相信具備專業知識的文官可以透過理性的社會行政逐步解決社會問題，此為其漸進改良路線的具體體現，此敘述正確，故不選。

D：費邊社會主義強調透過國有化（nationalization）將關鍵產業收歸公有，作為推動社會主義經濟的重要手段，此敘述正確，故不選。

本題考點：費邊社會主義（Fabian Socialism），主張漸進改良、國家仲裁與專業文官行政，與馬克思主義主張的革命式階級鬥爭路線形成鮮明對比，是社政考科的重要理論對照題。

第 3 題

米爾頓．傅利曼（Milton Friedman）的觀點一般被歸類於那一種經濟與社會的意識形態？
  1. （A）自由主義
  2. （B）社會民主
  3. （C）新馬克思主義
  4. （D）綠色主義

答案：（A）

詳解與考點

正解：本題答案為A。米爾頓·傅利曼（Milton Friedman）是芝加哥學派經濟學代表人物，主張自由市場機制、貨幣政策穩定、政府角色極小化，反對國家過度干預經濟與福利供給，這正是（新）自由主義在經濟與社會政策上的核心立場，故本題選A。

B：社會民主主張透過國家積極介入市場與所得重分配、建立普及式福利制度以追求平等，與傅利曼主張縮小政府角色、仰賴市場機制的立場方向相反，不符題旨。

C：新馬克思主義從階級與資本主義結構性剝削的角度批判市場經濟，主張透過結構變革達成社會公平，與傅利曼捍衛自由市場、反對政府干預的立場截然不同。

D：綠色主義以生態永續與環境正義為核心關懷，並非傅利曼經濟思想的分類範疇，與題幹描述的經濟意識形態無關。

本題考點：新自由主義（Neo-liberalism），主張自由市場、極小化政府角色、反對福利國家過度擴張的經濟與社會意識形態；傅利曼與芝加哥學派，是二十世紀後半自由市場經濟理論的重要代表，常與凱因斯學派、社會民主路線對照出題。

第 4 題

John Rawls 正義理論所提出的差異原則，下列敘述何者正確？
  1. （A）人類之間天生有所差異，因此社會福利應該儘可能消彌這些差異
  2. （B）人類之間本來就會有階級上的差異，因此社會應該保持這樣的差異
  3. （C）任何不公平的重分配政策，都應該讓社會中最弱勢的人獲得最大的利益
  4. （D）人類之間即便有差異，也享有同等的自由權利

答案：（C）

詳解與考點

正解：本題問Rawls正義論差異原則之敘述何者正確。差異原則（difference principle）主張社會與經濟制度所造成的不平等安排，唯有在使社會中最弱勢者獲得最大利益時才具有正當性，即以「最弱勢者利益最大化」作為判斷資源分配是否公正的準則，故C正確。

A：消彌人類天生差異並非差異原則的內涵，差異原則承認不平等可以存在，只是要求其安排必須使最弱勢者受益最大，並非以消除差異為目標，此為混淆差異原則與齊頭式平等的誘答。

B：主張社會應保持階級差異、放任其存在，忽略了差異原則要求不平等安排必須有利於最弱勢者的限制條件，僅描述了不平等的存在事實，並非Rawls差異原則的規範性主張，故不選。

D：人類即便有差異仍享有同等自由權利，描述的是Rawls正義二原則中的第一原則——平等自由原則，而非本題所問的差異原則（屬第二原則的一部分），兩者層次不同，是常見的原則混淆誘答。

本題考點：Rawls正義論之正義二原則——第一原則為平等自由原則，第二原則含機會平等原則與差異原則；差異原則主張社會經濟不平等安排須使最弱勢者獲得最大利益，是社會政策課程的高頻考點。

第 5 題

關於福利多元主義的敘述，下列何者錯誤？
  1. （A）強調社會福利服務提供的分散化和多元參與
  2. （B）社會福利服務之提供單位在地理空間的分散
  3. （C）基於保障受服務者之權益，受服務之案主不宜參與福利服務之決策
  4. （D）可以矯治以往福利國家之弊端

答案：（C）

詳解與考點

正解：福利多元主義（welfare pluralism）主張福利提供不應僅限於國家單一部門，而應由政府、市場、志願部門與非正式部門等多元主體共同參與、分散提供，且特別重視服務使用者作為福利體系中的積極參與者，應能參與福利服務的規劃與決策過程，以保障其權益、提升服務對其需求的回應性。選項C卻主張「基於保障受服務者之權益，受服務之案主不宜參與福利服務之決策」，恰與福利多元主義強調案主參與、賦權的精神相反，故本題選C為錯誤敘述。

A：福利多元主義強調福利服務提供的分散化與多元參與，由不同部門共同承擔福利供給責任，此為其核心主張，敘述正確。

B：福利服務提供單位在地理空間上的分散，使服務更貼近在地需求、避免福利資源過度集中於單一機構或地區，同樣是福利多元主義分散化精神的具體展現，敘述正確。

D：福利多元主義的提出背景之一，正是為了矯治傳統福利國家由政府壟斷福利供給所產生的官僚僵化、資源浪費、忽視在地需求等弊端，透過多元部門參與提升服務效率與回應性，此敘述正確。

本題考點：福利多元主義（Welfare Pluralism），主張福利供給應由政府、市場、志願部門與非正式部門共同分擔、分散提供，並重視服務使用者參與決策的賦權精神；福利國家危機（Welfare State Crisis），指傳統國家壟斷福利供給模式所面臨的官僚化、財政負擔等問題，是福利多元主義興起的背景。

第 6 題

有關社會民主觀點下社會福利行政性質的敘述，下列何者錯誤？
  1. （A）「民主」代表政府的權威來自人民
  2. （B）「社會」代表出自互助或追求共同目標的集體行動
  3. （C）積極的國家作為會威脅個人自由
  4. （D）傾向採取普及式或制度式社會福利行政進行所得重分配

答案：（C）

詳解與考點

正解：本題問社會民主觀點下社會福利行政性質敘述何者錯誤，答案為 C。社會民主觀點肯認並倚重國家的積極作為，主張政府應透過普及式、制度式的社會福利政策介入市場分配結果、實現所得重分配與社會團結，視積極國家為促進平等與自由的必要條件；「積極的國家作為會威脅個人自由」是新自由主義對國家角色的疑慮，並非社會民主觀點的立場，故 C 為錯誤敘述，選 C。

A：社會民主觀點中的「民主」，強調政府權威源自人民授權與民主參與程序，此為正確敘述。

B：社會民主觀點中的「社會」，強調基於互助精神或追求共同目標而產生的集體行動，此為正確敘述。

D：社會民主觀點傾向採取普及式或制度式的社會福利行政，透過廣泛涵蓋全民的福利制度進行所得重分配，以縮小階級與貧富差距，此為正確敘述。

本題考點：社會民主（social democracy）觀點下的福利國家理念，主張積極國家作為與普及式、制度式福利制度以實現重分配；與新自由主義（neo-liberalism）視積極國家為個人自由威脅的立場形成對照，是本題設計的核心對比。

第 7 題

我國2013 年頒布之人口政策白皮書，有關少子女化社會的對策總目標之敘述，何者錯誤？
  1. （A）依原住民特性，將原住民地區納入全國醫療網
  2. （B）營造友善家庭之職場環境
  3. （C）強化兒童保護體系
  4. （D）提升婚姻機會與重建家庭價值

答案：（A）

詳解與考點

正解：2013年（民國102年）修正之人口政策白皮書，針對少子女化對策訂定的總目標主要包括提升婚姻機會、營造家庭友善之生育與養育環境（含友善職場）、健全婦幼衛生與兒童保護體系、以及建構平價優質之托育與教育體系等，核心聚焦於提升生育率、支持家庭育兒與婚姻的政策目標。A所述「依原住民特性，將原住民地區納入全國醫療網」屬於原住民醫療政策或健康不平等改善措施，其政策對象與訴求重點在於原住民族群之醫療可近性，與少子女化對策所欲處理的婚育、家庭支持、兒童保護等總目標無直接關聯，故本題選A為錯誤敘述。

B：營造友善家庭之職場環境是少子女化對策的核心措施之一，透過育嬰留職停薪、彈性工時等制度，降低家庭因就業而犧牲生養意願的障礙，屬於白皮書明列之對策方向，故非錯誤敘述。

C：強化兒童保護體系是少子女化對策中建構優質平價育兒環境的一環，透過完善兒童保護網絡，讓已生育家庭能安心養育子女，屬白皮書對策內容，故非錯誤敘述。

D：提升婚姻機會、重建家庭價值直接對應少子女化對策中因應晚婚不婚而降低生育率的問題核心，是白皮書總目標明訂的方向，故非錯誤敘述。

本題考點：2013年人口政策白皮書少子女化對策，總目標聚焦於提升婚姻機會、營造友善家庭職場環境、健全兒童保護與育兒體系；原住民醫療政策則屬另一政策範疇，常被用作跨政策領域的辨析誘答。

第 8 題

1980 年我國通過社會福利三項立法，有關其立法背景及內容之敘述，下列何者錯誤？
  1. （A）其目的在轉移1970 年代之政治民主化的抗爭
  2. （B）緩和1978 年美國與中共建交的震撼
  3. （C）回應聯合國老人綱領之主張
  4. （D）涵蓋老人福利法、殘障福利法與社會救助法

答案：（C）

詳解與考點

正解：本題問「何者錯誤」，答案為C。聯合國《老人綱領》（United Nations Principles for Older Persons）於1991年由聯合國大會通過，時間上晚於我國1980年制定的社會福利三法約11年，我國1980年立法當時並無可能「回應」一份尚未出現的國際文件，故C在時序上明顯錯誤，為本題答案。

A、B：兩者同屬1980年三法立法的政治背景因素，皆為正確敘述——A指出1970年代黨外及社會運動等政治民主化抗爭風潮，促使當局以社會福利立法轉移抗爭焦點；B指出1978年底美國宣布將與中共建交，並於1979年正式建交，對我國造成外交重大衝擊，執政當局藉推動社會福利立法安定民心、鞏固統治正當性。兩者性質相近，皆屬政治情勢對三法立法背景的直接影響，敘述正確、非本題答案。

D：1980年通過的社會福利三法，即為老人福利法、殘障福利法（今身心障礙者權益保障法之前身）與社會救助法，此為明確之歷史事實，敘述正確。

本題考點：1980年社會福利三法（老人福利法、殘障福利法、社會救助法），我國社會福利法制化的重要里程碑，立法背景兼具國內政治民主化抗爭與1978年底建交公告及1979年中美斷交所造成的外交衝擊等時代因素；聯合國老人綱領（1991），常與本題三法對照出題、藉時序辨誤的高頻考點。

第 9 題

各國於二次大戰之後所建立的諸多社會安全制度，主要以現金給付與實物給付形式提供服務對象所需的服務與給付，另發展諸多「保護性立法」而成為福利國家的第三大支柱。對於「保護性立法」之敘述，下列何者最為貼切？
  1. （A）藉由建立具有促進性與預防性之立法，保障人民的社會權、健康權、生存權等
  2. （B）透過諸多相關法規的建立，確保民眾能夠普遍獲得所需的現金給付與福利服務之權利
  3. （C）立法保障獲得給付者已經取得的福利服務與現金給付，以增進其運用服務與給付的選擇權
  4. （D）該等立法可簡化行政處理、審查與評估程序，以保障經濟弱勢者取得服務與給付的社會權

答案：（A）

詳解與考點

正解：本題問對保護性立法之敘述何者最為貼切，官方答案為A。二次大戰後各國福利國家的建立，除了現金給付與實物給付構成福利國家的前兩大支柱外，另發展出以促進性與預防性為導向的立法，作為福利國家的第三大支柱，藉由這類立法保障人民在社會權、健康權、生存權等基本權利面向獲得制度性的保護，而非僅限於個別給付請求，A藉由建立具有促進性與預防性之立法，保障人民的社會權、健康權、生存權等，正確掌握了保護性立法的性質與功能，故選A。

B：B著重確保民眾普遍獲得所需現金給付與福利服務之權利，這其實描述的是現金給付與實物給付本身的普及性保障，屬於福利國家給付制度的範疇，並未凸顯保護性立法促進性、預防性的特殊性質，故不若A貼切。

C：C著重保障已取得的福利服務與現金給付，增進其運用服務與給付的選擇權，這是聚焦在給付請求權與使用自主性上，同樣落在給付制度的範疇內，而非保護性立法作為預防性、促進性規範的核心意涵，故不合。

D：D著重簡化行政處理、審查與評估程序，以保障經濟弱勢者取得服務與給付的社會權，這偏重的是給付近用程序的簡化與可近性，而非保護性立法本身促進性、預防性的規範性質，故不合。

本題考點：福利國家的三大支柱，即現金給付、實物給付與保護性立法（protective legislation）；保護性立法，指以促進性與預防性為導向，保障人民社會權、健康權、生存權等基本權利的立法規範，是社會政策與社會立法考科常考的福利國家結構概念。

第 10 題

在福利混合經濟的論述中，納入透過稅賦形式所提供的福利服務與給付，以減輕家戶與個人的負擔。我國並未提供下列何種稅賦福利？
  1. （A）長期照顧服務費抵減
  2. （B）人身保險費抵減
  3. （C）工作所得租稅抵減（EITC）
  4. （D）依附者扶養抵減

答案：（C）

詳解與考點

正解：本題問我國「並未」提供的稅式福利（tax expenditure）措施。就現行所得稅法而言，長期照顧服務費抵減、人身保險費抵減、依附者（受扶養親屬）扶養抵減，皆已透過所得稅法第十七條所定的免稅額、列舉扣除額、特別扣除額等機制，實際減輕家戶負擔；而工作所得租稅抵減（Earned Income Tax Credit, EITC）是美國式的制度，針對低薪工作家庭依申報之工作所得計算，屬於可退稅（refundable）的負所得稅式（negative income tax）安排，即使應納稅額為零仍能獲得現金退還，我國現行所得稅制並未採行這種以工作所得為基準、可退稅的稅額抵減措施，故本題選C。

A：長期照顧服務費抵減在我國係透過所得稅法所定的長期照顧特別扣除額實現，符合規定之長期照顧身心失能者的家庭，得於申報綜合所得稅時列報此項特別扣除額，我國確已提供此項稅式福利，與題目所問「並未提供」不符。

B：人身保險費抵減係透過所得稅法所定的保險費列舉扣除額實現，納稅義務人為本人、配偶或受扶養直系親屬所繳納的人壽保險、健康保險等保險費，在一定金額內得列報扣除，我國同樣已提供此項稅式福利。

D：依附者（受扶養親屬）扶養抵減係透過所得稅法所定的扶養親屬免稅額實現，納稅義務人扶養符合規定的直系尊親屬、子女或其他親屬者，得按規定金額減除免稅額，我國亦已提供此項安排。

本題考點：稅式支出（tax expenditure），指政府透過免稅額、扣除額、稅額抵減等稅制設計，間接提供福利給付以減輕家戶負擔，是福利混合經濟（welfare mix）中「透過稅制提供的福利」這一環；工作所得租稅抵減（Earned Income Tax Credit, EITC），美國用以補貼低薪工作家庭、可退稅的負所得稅式制度，我國現行稅制尚未採行。

第 11 題

下列的福利服務或現金給付之中，何者屬於由民間提供財務負擔、政府提供服務或給付之性質？
  1. （A）非營利組織所提供的緊急安置服務
  2. （B）社會救助法所提供的急難救助
  3. （C）由社會局所提供的早期療育服務
  4. （D）地方政府愛心專戶所提供的福利服務

答案：（D）

詳解與考點

正解：社會福利服務供給的分析架構中，可依「財務負擔來源」（民間或政府）與「服務提供主體」（民間或政府）交叉區分不同的供給型態。地方政府設立的愛心專戶，其款項來自社會大眾與企業的自願捐款，屬於「民間財務」；而這筆款項的運用、核發與服務輸送，是由地方政府依其行政程序審核、執行，屬於「政府提供服務或給付」，兩者組合正符合「民間出資、政府提供服務或給付」的型態，故本題選D。

A：非營利組織所提供的緊急安置服務，其經費來源多為該組織自身的捐款或政府委外經費，而服務本身也是由該民間組織直接提供，屬於「民間財務、民間提供服務」的型態，並非本題所問的「政府提供服務」。

B：社會救助法所提供的急難救助，其經費來自政府編列之公務預算，服務也是由政府審核並核發，屬於「政府財務、政府提供服務」的型態，資金來源與D的「民間捐款」不同。

C：社會局所提供的早期療育服務，其經費同樣是由政府編列預算支應、並由政府部門提供服務，財務負擔是政府而非民間，與本題所問「民間出資」的條件不符。

本題考點：福利服務供給型態的分析架構，依「財務負擔主體」與「服務提供主體」是政府或民間，交叉區分出四種基本供給型態；愛心專戶，是政府接受民間捐款、再由政府執行運用的典型「民間出資、政府提供」案例；此類供給型態歸類仍可能因個案財源與執行細節而有不同判讀空間。

第 12 題

1980 年代之後，西方福利國家的福利供給開始從福利科層和專業主義轉向福利多元主義，下列敘述何者正確？
  1. （A）福利科層與專業主義著重競爭
  2. （B）福利科層與專業主義著重績效要求
  3. （C）福利多元主義注重服務提供的一致性
  4. （D）福利多元主義強調應該由不同部門提供服務

答案：（D）

詳解與考點

正解：福利多元主義（welfare pluralism）主張福利供給不應僅由國家壟斷，而應由政府部門、市場（營利組織）、志願部門（非營利組織）與非正式部門（家庭、鄰里）等多元行動者共同分擔提供，藉此增加服務選擇、貼近在地需求並分散國家財政負擔，這正是1980年代後對福利國家過度科層化、專業壟斷提出反省而興起的取向，因此本題選D。

A：福利科層與專業主義的特徵是由國家透過科層組織、專業人員統一提供服務，強調的是科層體制內部的規範與專業判斷的權威性，而非競爭，引入競爭機制其實是新右派與新管理主義改革（如準市場、民營化）之後才被強調的特徵，與福利科層、專業主義本身的定義相反，是容易混淆的誘答。

B：著重績效要求同樣是新管理主義（強調成本效益、目標管理、績效指標）的特徵，而非福利科層與專業主義的核心特質，科層與專業主義原本著重的是依循規章程序與專業自主判斷，而非以量化績效作為管理依據，這是把不同改革脈絡錯置到福利科層、專業主義身上的誘答。

C：福利多元主義強調服務由不同部門依其特性提供，本質上會帶來服務內容與品質的多樣性而非一致性，正因為政府、市場、志願、非正式部門各自的運作邏輯不同，服務才會呈現多元樣貌，這與題幹所述「注重一致性」恰好相反，是把多元主義的核心精神說反的誘答。

本題考點：福利多元主義（Welfare Pluralism），主張由政府、市場、志願與非正式部門共同分擔福利供給責任；新管理主義（New Managerialism），強調引入市場競爭機制與績效管理，常與福利多元主義同時作為1980年代後福利國家改革的兩條相關但不同的路徑被比較。

第 13 題

依我國國民年金法規定，國民年金保險的保險人，目前由下列那個機關負責辦理？
  1. （A）中央健康保險署
  2. （B）勞工保險局
  3. （C）社會保險司
  4. （D）銓敘部

答案：（B）

詳解與考點

正解：依國民年金法規定，國民年金保險以中央主管機關為主管機關，並委由勞工保險局辦理保險業務，即擔任國民年金保險的保險人，故本題選B。勞保局長期承辦勞工保險、就業保險等社會保險業務，國民年金保險開辦後亦委由其一併辦理，以整合承保與給付作業。

A：中央健康保險署承辦的是全民健康保險，屬另一獨立的社會保險制度，與國民年金保險的承保機關不同，是最常見的誘答——考生容易把「健保」與「年金」兩種社會保險的主管機關混淆。

C：社會保險司若存在，性質上偏向政策規劃與監督的行政單位，並非實際承辦保險業務、核發給付的保險人角色，與條文所定「保險人」身分不符。

D：銓敘部主管公教人員的銓敘、退休撫卹等人事業務，與一般國民之國民年金保險完全屬不同體系，並非國民年金保險的保險人。

本題考點：國民年金保險的承保機關，即國民年金法所定由勞工保險局擔任保險人，辦理保險費收繳、老年年金等各項給付的核發等業務；社會保險體系分工，指全民健保、勞保、國民年金等不同社會保險各有專責承辦機關，是常考的機關對應題型。

第 14 題

有關從「科層－專業主義守門人取向」到「新管理主義顧客取向」變化的敘述，下列何者正確？
  1. （A）從需求取向，往預算取向變化
  2. （B）從預算沒有彈性，往預算具有彈性變化
  3. （C）從量身打造服務，往有效率提高服務供給量變化
  4. （D）從基於個人選擇，往最佳利用納稅人稅賦變化

答案：（B）

詳解與考點

正解：新管理主義（new managerialism）相對於科層－專業主義守門人取向，其中一項核心轉變在於引入市場機制與管理彈性，包括將預算管理權下放給第一線管理者、以成本中心方式運作，讓資源分配得以依實際服務狀況彈性調整，取代過去由科層體系依固定預算額度、逐級核撥、缺乏彈性的資源控管方式。因此，從「預算沒有彈性」到「預算具有彈性」的變化方向正確，故本題選B。

A：「從需求取向，往預算取向變化」把兩個典範的資源分配邏輯方向對調——科層－專業主義守門人取向本身即帶有以有限預算為前提、由專業守門人依額度篩選服務對象的性質，而新管理主義引入消費者導向後，反而更強調回應個別顧客的需求與選擇，方向與題幹描述相反，敘述不成立。

C：「從量身打造服務，往有效率提高服務供給量變化」同樣把方向對調——科層－專業主義守門人取向偏向標準化、依規定程序處理個案，較不強調個別量身打造；新管理主義引入顧客導向後，才轉而強調回應個別顧客需求、講求服務彈性與客製化，敘述方向有誤。

D：「從基於個人選擇，往最佳利用納稅人稅賦變化」也是方向相反——科層－專業主義守門人取向以專業判斷與程序控制為主，個人選擇空間有限；轉向新管理主義顧客取向後，才開始強調服務對象的個人選擇權，而最佳利用納稅人稅賦則較貼近科層體系強調的成本控管邏輯，敘述方向與實際變化相反。

本題考點：科層－專業主義守門人取向（bureaucratic-professional gatekeeping）與新管理主義（new managerialism）顧客取向的比較，前者以專業判斷、固定預算與標準化程序控管資源，後者引入市場機制、預算彈性化與消費者選擇；本組對照的誘答選項常以方向對調方式設計，作答時先確認變化方向即可判別。

第 15 題

有關福利服務領域中最佳價值所倡導的5Cs 組合，下列何者正確？
  1. （A）合作績效、競爭績效、審慎、競爭、回應
  2. （B）規劃績效、比較績效、避險、標準、合作
  3. （C）溝通績效、加乘績效、回應、召喚、避險
  4. （D）挑戰績效、比較績效、徵詢、競爭、合作

答案：（D）

詳解與考點

正解：英國「最佳價值」（Best Value）政策框架源自 1999 年地方政府法（Local Government Act 1999），原以四個 C 為核心：挑戰（Challenge，檢視服務是否仍有存在必要與改善空間）、比較（Compare，與其他機構或標竿比較績效）、徵詢（Consult，徵詢服務使用者與利害關係人意見）、競爭（Compete，透過市場競爭機制確保效率與品質），後續再納入合作（Collaborate）作為第五個 C，強調跨部門、跨機構的協力。選項 D「挑戰績效、比較績效、徵詢、競爭、合作」完整對應這五個核心要素，故本題選 D。

A：「合作績效、競爭績效、審慎、競爭、回應」重複列出「競爭」二次，且加入「審慎」「回應」等非最佳價值 5Cs 核心用語的詞彙，並非該架構的正確組合。

B：「規劃績效、比較績效、避險、標準、合作」中的「規劃」「避險」「標準」皆非最佳價值框架的核心用詞，僅「比較」「合作」與 5Cs 相符，屬詞彙拼湊而成的誘答。

C：「溝通績效、加乘績效、回應、召喚、避險」全數用詞與最佳價值 5Cs（挑戰、比較、徵詢、競爭、合作）皆不相符，屬明顯的干擾組合。

本題考點：英國最佳價值政策（Best Value, Local Government Act 1999）的 5Cs 架構，即挑戰（Challenge）、比較（Compare）、徵詢（Consult）、競爭（Compete）、合作（Collaborate），是檢視地方公共服務績效與品質改善的核心原則。

第 16 題

有關社會福利政策中網絡治理（network governance）模式之所以出現的假設情境敘述，下列何者正確？
  1. （A）政府和準市場皆運作正常
  2. （B）政府失靈、準市場運作正常
  3. （C）政府運作正常、準市場失靈
  4. （D）政府失靈、準市場也失靈

答案：（D）

詳解與考點

正解：網絡治理（network governance）模式興起的背景假設，是政府失靈（government failure）與準市場失靈（quasi-market failure）同時發生——當政府由上而下的科層治理與市場機制的準市場競爭都無法有效提供公共服務時，才需要透過政府、市場、第三部門等多元行動者組成的協力網絡，以協調合作的方式彌補雙重失靈，故本題選D。

A：若政府與準市場皆運作正常，代表既有的科層治理或市場機制已能有效提供服務，並不存在需要另闢網絡治理途徑的失靈壓力，與網絡治理模式出現的前提相反，不成立。

B：若僅政府失靈、準市場運作正常，則透過強化市場競爭、擴大民營化或準市場機制即可彌補政府失靈，尚不必然需要發展出跨部門協力的網絡治理模式，與題目所問網絡治理模式出現的雙重失靈前提不符。

C：若政府運作正常、僅準市場失靈，則政府可以透過重新收回職能或加強管制準市場等傳統科層手段因應，同樣不需要仰賴網絡治理這種強調多元行動者協力的替代途徑，與網絡治理興起的前提不符。

本題考點：網絡治理（network governance），指在政府失靈與準市場失靈同時存在的情況下，透過政府、市場、第三部門等多元行動者組成協力網絡以彌補雙重失靈的治理模式；政府失靈與準市場失靈，是社會福利政策治理理論中，解釋治理典範由科層、市場轉向網絡的核心概念。

第 17 題

關於我國社會保險的敘述，下列何者錯誤？
  1. （A）社會保險保費常稱為薪資稅（payroll tax）
  2. （B）社會保險保費是公共財源的一種，具有強制性
  3. （C）雇主和受僱者都有維護社會保險體系的義務
  4. （D）國民年金不算是社會保險的一種

答案：（D）

詳解與考點

正解：我國的國民年金制度是依國民年金法建立的社會保險制度，正式名稱即為國民年金保險，屬於社會保險體系的一環，與勞保、農保、公教保等並列，共同建構我國社會保險的骨幹；D 選項稱其不算是社會保險的一種，與制度事實不符，敘述錯誤，故本題選 D。

A：社會保險保費因多以薪資或投保薪資為費基、由雇主與受僱者依比例分擔繳納，在財政學上常被稱為薪資稅（payroll tax），此為社會保險財源的通稱說法，敘述正確。

B：社會保險保費屬於公共財源的一種，且依法強制納保、強制繳費，不論個人是否願意皆須參加，這正是社會保險有別於商業保險（自願投保）的核心特徵，敘述正確。

C：社會保險採取雇主與受僱者共同分擔保費、共同維護體系運作的設計，部分險種另有政府補助，雙方均負有繳費與維護制度健全的義務，敘述正確。

本題考點：社會保險的強制性與薪資稅性質，指依法律強制納保、以薪資為費基的社會保障財源設計；國民年金保險，我國依國民年金法建立、涵蓋未參加其他社會保險國民的年金制度，性質上屬於社會保險而非社會救助或商業保險。

第 18 題

下列何者非屬社會津貼制度的特質？
  1. （A）對符合某種資格之人口群均可領取
  2. （B）財務規模大，行政成本也高
  3. （C）採取假定需求原則
  4. （D）給付採取定額均一給付

答案：（B）

詳解與考點

正解：社會津貼制度的核心特質包括：以特定人口群身分為請領資格，凡符合資格者均可領取（普及性）；不進行資產調查，而依「假定需求」推定該人口群有此需求即予給付；給付金額多為定額、對象內一致的均一給付。因不必逐案資產調查與審核，其行政作業相對單純、成本較低，這正是社會津貼相對於須逐案審查的社會救助最主要的制度優勢之一；B 稱其「行政成本也高」，恰與此特質相反，故本題選 B 為非屬其特質者。

A、C、D：三者皆為社會津貼制度公認的特質——A 的普及性（對符合資格之人口群均可領取，不設排富門檻）、C 的假定需求原則（以身分類別推定需求，免除逐案資產調查）、D 的定額均一給付（同一類別對象領取相同金額），三者環環相扣，共同構成社會津貼與社會保險、社會救助制度區隔的判準，因其確屬社會津貼特質，故均非本題答案。

本題考點：社會津貼（Social Allowance/Demogrant），以人口類別身分為請領資格、不經資產調查、採定額均一給付的福利給付方式；假定需求原則（Presumed Need），依身分類別推定其有需求而逕予給付，是社會津貼區別於社會救助的關鍵設計。

第 19 題

代券為福利給付型式之一，下列何者為其限制？
  1. （A）能平衡社會控制與消費者選擇的工具
  2. （B）代券具有實物給付的性質
  3. （C）仍有可能具有標籤效果
  4. （D）具有自由市場的特性，其消費與使用效用較高

答案：（C）

詳解與考點

正解：代券（voucher）雖介於現金給付與實物給付之間，兼具部分消費選擇彈性，但因其使用仍須在特定範圍或特定商店出示、兌換，容易讓使用者在使用過程中被標籤化（stigma），例如被辨識為社會救助或福利對象，這正是代券作為福利給付形式的重要限制，故本題選 C。

A：「能平衡社會控制與消費者選擇」描述的是代券制度設計上的優點，即透過限定使用範圍達成一定的社會控制目的、同時保有部分消費者選擇空間，屬對代券功能的正面評價，並非其限制，是易與「限制」混淆的誘答。

B：「具有實物給付的性質」是在描述代券的給付屬性，即兼具現金彈性與實物指定用途的中介性質，屬中性的制度特徵描述，而非缺點或限制。

D：「具有自由市場的特性，其消費與使用效用較高」同樣是在正面肯定代券相對於實物給付更具彈性、更貼近市場消費的優點，並非限制。

本題考點：代券式給付（voucher），福利給付型式之一，兼具現金與實物給付特性，其優點為兼顧社會控制與消費彈性，限制則在於可能產生標籤效應（stigma），是社會政策比較現金、實物、代券、機會等各類給付形式優劣時的常考重點。

第 20 題

依據老人福利法中，有關老人保護措施之敘述，下列何者錯誤？
  1. （A）為發揮老人保護功能，應以地方政府為單位，建立老人保護體系，並定期召開老人保護聯繫會報
  2. （B）老人因無人扶養、獨居、兩老同居者，地方主管機關應立即依家屬之需求，予以機構緊急安置
  3. （C）地方主管機關接獲老人保護通報時，應立即處理，必要時得進行訪視調查
  4. （D）老人之扶養人或其他實際照顧老人者，違反第51 條情節嚴重者，應施予4 小時以上20 小時以下之家庭教育及輔導

答案：（B）

詳解與考點

正解：老人福利法第41條處理照顧義務人疏忽、虐待、遺棄等情事，致老人生命、身體、健康或自由有危難時的保護與安置；老人福利法第42條則規定，老人無人扶養，生命、身體有危難或生活陷於困境時，得依老人申請或依職權予以適當安置。B把無人扶養、獨居、兩老同居逕行等同於地方主管機關必須立即機構緊急安置，並將判斷依據錯置為「依家屬之需求」，未符合上述法定情形，故B為錯誤選項。

A：為發揮老人保護功能，法規要求以地方政府（直轄市、縣市主管機關）為單位建立老人保護體系，並定期召開老人保護聯繫會報，以整合警政、衛生、社政等相關單位資源，此為老人福利法有關保護體系建置之正確敘述。

C：地方主管機關接獲老人保護通報後，應立即處理，必要時得進行訪視調查，以掌握老人實際處境並決定後續服務或安置措施，此為老人保護通報後應有的正確處理程序。

D：老人之扶養人或其他實際照顧老人者，若違反老人福利法第51條情節嚴重者，主管機關應課予其接受4小時以上20小時以下之家庭教育及輔導，此為法定裁罰性輔導措施之正確敘述。

本題考點：老人福利法第41條與第42條的安置情形不同；前者涉及照顧義務人疏忽、虐待、遺棄等造成危難，後者涵蓋無人扶養且生命、身體有危難或生活陷於困境。不能只憑獨居或兩老同居便推定必須立即安置，也不能以家屬需求取代法定判準。

第 21 題

有關社會保險財務特性之敘述，下列何者錯誤？
  1. （A）財務自給自足原則
  2. （B）財務管理面採完全提存準備制
  3. （C）保險成本估計較不易
  4. （D）面對弱勢及特殊的被保險人，政府以社會福利預算補助其保險費，而非免繳保費

答案：（B）

詳解與考點

正解：社會保險在財務管理制度上，通常採用隨收隨付制或部分提存準備制，以當期保費收入支應當期給付支出，並保留部分準備金因應風險波動；完全提存準備制則是每位被保險人依其未來可能請領的給付，逐年提存足額準備金，此制度屬於商業保險常見的財務精算方式，並非社會保險的普遍特性，故「財務管理面採完全提存準備制」的敘述有誤，本題選B。

A：財務自給自足原則是社會保險的重要財務特性之一，強調保險基金應以保費收入與投資收益支應給付支出，避免長期仰賴政府一般稅收挹注，此敘述正確。

C：社會保險涉及長期、跨世代的風險精算（如老年、失能、死亡等給付），影響因素眾多且難以精確預測，例如人口結構變遷、經濟景氣、醫療技術進步等，保險成本估計確實較商業保險更不容易，此敘述正確。

D：社會保險強調全民納保、危險共同分攤，為避免弱勢與特殊被保險人因無力繳費而被排除在保障之外，政府通常編列社會福利預算補助其保險費，而非直接免除其繳費義務，以維持其被保險人身分與權利義務對等性，此敘述正確。

本題考點：社會保險財務制度——隨收隨付制（Pay-As-You-Go）與完全提存準備制（Fully Funded System）的區分；社會保險的財務自給自足原則與保費補助（而非免繳）原則。

第 22 題

有關老人福利法之規定，下列敘述何者正確？①私立老人福利機構停辦、停業、歇業、解散、經撤銷或廢止許可時，對於其收容之服務對象應即予以適當之安置 ②無法安置時，由主管機關協助安置，機構應予配合 ③私立老人福利機構停辦原因消失後，應申請復業或歇業許可，其未依規定申請復業、歇業許可或申請復業原因不予許可者，主管機關應廢止其設立許可 ④老人福利機構經依前項規定廢止設立許可者，主管機關並應限期令該機構繳回設立許可書；屆期未繳回者，應移送法辦
  1. （A）①②③④
  2. （B）僅①②③
  3. （C）僅②③④
  4. （D）僅③④

答案：（B）

詳解與考點

正解：本題採「選出正確敘述」的組合題型，須先逐一判斷①至④是否正確，再對應到選項A至D的組合。①私立老人福利機構於停辦、停業、歇業、解散或經撤銷、廢止許可時，對其收容之服務對象應即予以適當之安置，符合老人福利法對機構退場之安置規定；②機構無法自行安置服務對象時，由主管機關協助安置，機構並應予配合，同屬正確；③私立老人福利機構停辦原因消失後，應依規定申請復業或歇業許可，若未依規定申請、或申請復業經不予許可者，主管機關應廢止其設立許可，亦屬正確；④則有誤，機構經廢止設立許可後，主管機關對其應限期令繳回設立許可證書，屆期未繳回者，法律效果是由主管機關逕予公告註銷，而非直接移送法辦。綜合判斷，正確者僅①②③，對應選項為B，故本題選B。

A：A將①②③④全數列為正確，但④所述「屆期未繳回者應移送法辦」之法律效果有誤，正確應為主管機關逕予註銷，A因納入有誤的④而不正確。

C：C為「僅②③④」，除同樣納入有誤的④（正確法律效果應為屆期未繳回逕予註銷，而非移送法辦）外，還遺漏了正確的①（機構應即予以適當安置服務對象之義務），故不正確。

D：D為「僅③④」，除同樣納入有誤的④外，還遺漏了正確的①（安置義務）與②（機構應配合安置、主管機關協助安置），故不正確。

本題考點：老人福利法對私立老人福利機構退場機制的規範，包括停業、歇業、解散、許可撤銷或廢止後之安置義務、機構配合義務、停辦原因消失後之復業或歇業申請、以及未繳回設立許可證書之註銷效果；行政管制手段（註銷、廢止）與司法追訴（移送法辦）的層級區辨，是本題辨析的核心細節。

第 23 題

依據老人福利法規定，下列何者不是協助失能老人之家庭照顧者所提供的服務？
  1. （A）提供有關輔具、輔助性之生活用品及生活設施設備之資訊
  2. （B）臨時或短期喘息的照顧服務
  3. （C）照顧者的訓練及研習
  4. （D）照顧者個人諮商及支援團體

答案：（A）

詳解與考點

正解：本題問依老人福利法規定，何者「不是」協助失能老人之家庭照顧者所提供的服務。老人福利法有關家庭照顧者支持服務之規定，明列臨時或短期喘息照顧服務、照顧者訓練及研習、照顧者個人諮商及支援團體等項目，服務對象是「照顧者本人」；而 A「提供有關輔具、輔助性之生活用品及生活設施設備之資訊」，其服務對象是失能老人本身（協助老人取得輔具與生活設施設備資訊），性質上屬於對失能老人的直接服務，而非對家庭照顧者的支持服務，故不屬於家庭照顧者支持服務項目，本題選 A。

B：臨時或短期喘息照顧服務讓照顧者能暫時卸下照顧責任、獲得休息，是家庭照顧者支持服務的典型項目，故不選。

C：照顧者的訓練及研習，協助照顧者習得照顧技巧、減輕照顧負荷，屬於家庭照顧者支持服務項目，故不選。

D：照顧者個人諮商及支援團體，協助照顧者抒發照顧壓力、獲得同儕支持，屬於家庭照顧者支持服務項目，故不選。

本題考點：老人福利法有關家庭照顧者支持服務之規定，服務項目鎖定「照顧者本人」（臨時或短期喘息照顧、照顧者訓練及研習、照顧者個人諮商及支援團體），須與服務失能老人本身的輔具、生活輔助設施設備資訊提供作區分；此類列舉條文屬社福立法中常隨修法調整的細節規範。

第 24 題

依兒童及少年福利與權益保障法之規定，主管機關應邀集兒童及少年福利相關學者或專家、民間相關機構、團體代表、目的事業主管機關代表、兒童及少年代表，協調、研究、審議、諮詢及推動兒童及少年福利政策。關於其組成比例之規定，下列敘述何者正確？
  1. （A）兒童及少年福利相關學者、專家、民間相關機構、團體代表、兒童及少年代表不得少於三分之一，單一性別不得少於三分之一
  2. （B）兒童及少年福利相關學者、專家、民間相關機構、團體代表、兒童及少年代表不得少於三分之一，單一性別不得少於四分之一
  3. （C）兒童及少年福利相關學者、專家、民間相關機構、團體代表、兒童及少年代表不得少於二分之一，單一性別不得少於二分之一
  4. （D）兒童及少年福利相關學者、專家、民間相關機構、團體代表、兒童及少年代表不得少於二分之一，單一性別不得少於三分之一

答案：（D）

詳解與考點

正解：依兒童及少年福利與權益保障法第十條規定，主管機關邀集之兒童及少年福利相關學者或專家、民間相關機構、團體代表及兒童及少年代表，合計不得少於全體成員二分之一，其中單一性別代表不得少於三分之一，故本題選 D。此一規定用意在確保民間、專家及兒少本人的聲音在政策審議中占有相當分量（至少半數），同時避免決策成員在性別組成上失衡。

A：以三分之一為代表合計下限、單一性別亦以三分之一為門檻，把「合計比例」與「性別比例」兩個門檻誤設為相同數字，未達法定二分之一的代表合計下限，屬記憶混淆。

B：同樣把代表合計下限誤記為三分之一，且單一性別門檻誤記為四分之一，比法定的三分之一更寬鬆，會使性別失衡的風險更高，不符法規原意。

C：代表合計下限二分之一正確，但把單一性別門檻誤記為二分之一，即要求任一性別都須達半數，此門檻高於法定的三分之一，屬比例數字的混淆誤植。

本題考點：兒童及少年福利與權益保障法第十條，兒少福利政策審議組織的代表比例規定；性別比例原則，政策諮詢審議組織中常見以特定比例確保單一性別不過度失衡的立法設計。

第 25 題

依兒童及少年福利與權益保障法，關於兒童及少年施用毒品的規定，下列敘述何者錯誤？
  1. （A）戶政人員或村（里）幹事知悉兒童及少年施用毒品時，具有通報義務
  2. （B）直轄市、縣（市）主管機關受理案件後，應提出調查報告
  3. （C）直轄市、縣（市）主管機關得對兒童及少年進行訪視。訪視顯有困難或兒童及少年行蹤不明，經警察機關處理、尋查未果，涉有犯罪嫌疑者，得經司法警察機關報請檢察機關處理
  4. （D）直轄市、縣（市）主管機關於接獲通報兒童及少年施用毒品時，應立即進行分級分類處理，至遲不得超過48 小時

答案：（D）

詳解與考點

正解：依兒童及少年福利與權益保障法第53條規定，醫事人員、社會工作人員、教育人員、保育人員、警察及司法人員、戶政人員及村（里）幹事等執行兒童及少年福利業務人員，知悉兒童及少年施用毒品等法定事由時，應立即向直轄市、縣（市）主管機關通報，而主管機關受理案件後，於接獲通報時應立即進行分級分類處理，法定至遲不得超過的時限是24小時，並非選項所述的48小時，故本題選出敘述錯誤的選項為D。這項時限規定的立法用意，在於要求主管機關對兒少施用毒品等高風險通報案件，必須在極短時間內完成初步分級分類、啟動後續調查與保護程序，避免延誤介入時機。

A：戶政人員或村（里）幹事屬兒童及少年福利與權益保障法第53條所列執行兒童及少年福利業務人員之一，知悉兒少有施用毒品等法定事由時確實負有通報義務，此敘述正確。

B：主管機關受理通報案件後，應依法進行調查並提出調查報告，作為後續分級分類、轉介處遇或保護安置的依據，此為通報後的標準法定程序，敘述正確。

C：主管機關對兒少負有訪視義務，若訪視顯有困難或兒少行蹤不明，經警察機關處理、尋查仍無結果，且涉有犯罪嫌疑者，可經司法警察機關報請檢察機關處理，這是法定的後續強制查訪與司法介入機制，敘述正確。

本題考點：兒童及少年福利與權益保障法第53條之責任通報制度，規定執行兒少福利業務人員知悉法定事由應立即通報、主管機關受理後應於24小時內進行分級分類處理，是兒少保護通報流程中常被考查的時限規定。

第 26 題

身心障礙者權益保障法中有關身心障礙者就業權益之規定，下列敘述何者錯誤？
  1. （A）身心障礙者之機關（構），對其所進用之身心障礙者，應本同工同酬之原則
  2. （B）各級政府機關、公立學校及公營事業機構員工總人數在34 人以上者，進用具有就業能力之身心障礙者人數，不得低於員工總人數2%
  3. （C）經職業輔導評量符合庇護性就業之身心障礙者，由辦理庇護性就業服務之單位提供工作，並由雙方簽訂書面契約
  4. （D）私立學校、團體及民營事業機構員工總人數在67 人以上者，進用具有就業能力之身心障礙者人數，不得低於員工總人數1%，且不得少於1 人

答案：（B）

詳解與考點

正解：依身心障礙者權益保障法第三十八條規定，各級政府機關、公立學校及公營事業機構員工總人數在三十四人以上者，進用具有工作能力之身心障礙者人數，不得低於員工總人數百分之三；本題選項B敘述為「不得低於員工總人數2%」，將法定比例由3%誤植為2%，與現行規定不符，故本題選B。

A：「身心障礙者之機關（構），對其所進用之身心障礙者，應本同工同酬之原則」符合身心障礙者權益保障法有關就業權益保障的規定，敘述正確，不選。

C：「經職業輔導評量符合庇護性就業之身心障礙者，由辦理庇護性就業服務之單位提供工作，並由雙方簽訂書面契約」符合該法有關庇護性就業安排方式之規定，敘述正確，不選。

D：「私立學校、團體及民營事業機構員工總人數在67人以上者，進用具有就業能力之身心障礙者人數，不得低於員工總人數1%，且不得少於1人」符合該法針對私部門所定較低之進用比例（1%）規定，與B所述公部門3%門檻不同，敘述正確，不選。

本題考點：身心障礙者權益保障法第三十八條定額進用制度（全國法規資料庫現行條文），公部門（政府機關、公立學校、公營事業，員工34人以上）法定進用比例為百分之三，私部門（民營事業，員工67人以上）法定進用比例為百分之一，兩者門檻與比例常互為出題對照重點。

  1. （A）45 日內
  2. （B）30 日內
  3. （C）15 日內
  4. （D）10 日內

答案：（D）

詳解與考點

正解：依身心障礙者權益保障法第六條規定，直轄市、縣（市）主管機關受理身心障礙者鑑定及需求評估申請後，應由專業團隊進行鑑定與評估，鑑定報告至遲應於完成後十日內送達申請人戶籍所在地之衛生主管機關，以利銜接後續之需求評估程序，故本題選D。

A：45日並非法規所定鑑定報告送達的期限，數字與實際規定不符。

第 28 題

依據兒童及少年福利與權益保障法規定，下列何者得申請警政機關建立指紋資料作為失蹤協尋用途？
  1. （A）遭遇家暴者
  2. （B）身心失能者
  3. （C）身心障礙兒童的監護人
  4. （D）遭遇性剝削的少年

答案：（C）

詳解與考點

正解：依兒童及少年福利與權益保障法第30條，疑似發展遲緩、發展遲緩或身心障礙兒童及少年之父母或監護人，得申請警政機關建立指紋資料，作為失蹤協尋用途。C「身心障礙兒童的監護人」屬於法定申請人及對象範圍，故選C。

A：遭遇家庭暴力者所涉及的是保護令聲請、緊急安置等家庭暴力防治法相關的人身安全保護措施，與「預先建立指紋資料以利走失協尋」這項針對高風險走失族群的規定並非同一保護體系。

B：身心失能者若為成年人，其指紋建檔協尋機制通常另依身心障礙者權益保障法或失智症協尋相關規定辦理，並非本題所問兒少權法下針對兒童及少年之條文適用對象。

D：遭遇性剝削之少年所適用者，是兒童及少年性剝削防制條例下的安置、輔導與加害人查緝規定，其保護重點在脫離性剝削情境與身心創傷復原，與走失協尋指紋建檔的立法目的不同。

本題考點：兒童及少年福利與權益保障法第30條的失蹤協尋指紋資料，法定範圍為疑似發展遲緩、發展遲緩或身心障礙兒童及少年之父母或監護人；C落在其中的身心障礙兒童範圍。

第 29 題

依據家庭暴力防治法規定，當被害人遭受家庭暴力之急迫危險時，可申請下列何種保護令？
  1. （A）通常保護令
  2. （B）暫時保護令
  3. （C）緊急保護令
  4. （D）急迫保護令

答案：（C）

詳解與考點

正解：依家庭暴力防治法規定，保護令分為通常保護令、暫時保護令與緊急保護令三種。其中，當被害人遭受家庭暴力之「急迫危險」時，警察機關或檢察官得依法向法院聲請緊急保護令，法院並應於受理後四小時內核發，以因應被害人立即的人身安全需求，故本題選C。

A：通常保護令須經法院審理程序（可能包含開庭調查）後始核發，處理時程較長，並非用於因應「急迫危險」的即時情況，適用於暴力情形已獲一定證據、需長期性保護措施的案件。

B：暫時保護令是在通常保護令審理終結前，法院為避免被害人續受侵害而先行核發的保護令，雖然核發速度快於通常保護令，但制度設計上仍以「審理中之暫時因應」為性質，與專門因應「急迫危險」、可不經審理程序迅速核發的緊急保護令仍有區別，容易因兩者都具有「快速」的特性而混淆。

D：家庭暴力防治法並無「急迫保護令」此一法定名稱，屬混淆選項。

本題考點：家庭暴力防治法保護令制度，法定僅有通常保護令、暫時保護令、緊急保護令三種，其中緊急保護令即為對應「被害人遭受家庭暴力之急迫危險」情形所設計的即時保護機制。

第 30 題

依據家庭暴力防治法規定，下列那一類人員並未被課以法定通報責任？
  1. （A）學校老師
  2. （B）里長
  3. （C）社會工作人員
  4. （D）保育人員

答案：（B）

詳解與考點

正解：依家庭暴力防治法第五十條規定，醫事人員、社會工作人員、教育人員、保育人員、警察人員、移民業務人員及其他執行家庭暴力防治人員，於執行職務時知悉有疑似家庭暴力情事者，應立即通報當地主管機關，此為法定責任通報人員名單；里長為地方自治選舉產生之基層民意代表／行政協助人員，並非上開條文所列執行家暴防治業務之專業人員，不在法定責任通報人員之列，故本題選B。

第 31 題

依社會救助法之規定，低收入戶成員符合特定情形者，主管機關得依其原領取現金給付之金額增加補助，上述特定情形不包含下列何者？
  1. （A）年滿65 歲
  2. （B）懷胎滿3 個月
  3. （C）罹患嚴重傷病
  4. （D）領有身心障礙手冊或身心障礙證明

答案：（C）

詳解與考點

正解：社會救助法就低收入戶現金給付設有加成規定，明定低收入戶成員如有年滿六十五歲、懷胎滿三個月、領有身心障礙手冊或身心障礙證明等情形之一者，主管機關得依其原領取現金給付之金額增加補助，用意在於這些身分別的家庭成員通常有更高的生活或醫療照顧需求。四個選項中，「罹患嚴重傷病」並未被列為現金給付加成的法定情形，重大傷病者的醫療需求另有醫療補助等其他管道處理，並非透過生活扶助現金給付加成因應，故本題選 C。

A、B、D：三者依社會救助法規定均屬得增加現金給付補助之法定情形，僅所指涉身分不同──A「年滿65歲」之老年給付對象，B「懷胎滿3個月」之孕婦給付對象，D「領有身心障礙手冊或身心障礙證明」之身心障礙給付對象。三者均屬法定加成之列，並非本題所問「不包含」之除外情形，故均不合本題要求。

本題考點：社會救助法有關低收入戶生活扶助現金給付加成規定，法定加成對象限於年滿65歲、懷胎滿3個月、領有身心障礙手冊或證明三類身分，罹患嚴重傷病者則循醫療補助等其他救助管道處理，是社會救助法給付項目與加成對象辨析的常考重點。

第 32 題

社會救助法內對社會救助機構之規定，下列何者錯誤？
  1. （A）社會救助機構，除利用各種社會福利機構外，地方主管機關得視需要自行設立或輔導民間設立
  2. （B）政府依規定設立之社會救助機構，不收任何費用
  3. （C）私立社會救助機構，經許可設立後，應於6 個月內辦理財團法人登記，有正當理由者得申請延長6 個月
  4. （D）接受政府委託安置之社會救助機構，非有正當理由者，不得拒絕依法之委任安置

答案：（C）

詳解與考點

正解：本題問社會救助法有關社會救助機構規定「何者錯誤」，官方答案為C。依社會救助法第二十九條，私立社會救助機構經許可設立後，應於三個月內辦理財團法人登記，有正當理由者，得申請主管機關核准延期三個月；C敘述「應於6個月內辦理財團法人登記，有正當理由者得申請延長6個月」，其登記期限與展延期限均應為三個月而非六個月，數字有誤，故為本題所要選出的錯誤敘述。

A：社會救助機構除由主管機關利用既有社會福利機構外，地方主管機關得視需要自行設立或輔導民間設立，此為社會救助法對社會救助機構設立方式的正確描述，敘述無誤。

B：政府依規定設立之社會救助機構提供服務不收任何費用，符合社會救助以政府資源保障弱勢基本生活、不得再向受助者收費的立法精神，敘述無誤。

D：接受政府委託安置之社會救助機構，非有正當理由不得拒絕依法之委任安置，是為確保政府委託安置業務得以順利執行、避免機構任意拒收個案的規定，敘述無誤。

本題考點：社會救助機構（social assistance institutions），社會救助法規範地方主管機關得自行設立、輔導民間設立或委託安置之福利服務設施；私立社會福利機構財團法人登記期限（社會救助法第二十九條：三個月內辦理、得展延三個月），是社福法規常考的條文數字項目，應與其他福利機構登記期限區辨、避免混淆記憶。

第 33 題

關於社會工作師法之敘述，下列何者錯誤？
  1. （A）我國於1997 年4 月2 日制定公布社會工作師法
  2. （B）社會工作師法明確規範社會工作師的基本職責，確保維護個案權益
  3. （C）定義社會工作師為協助個人、家庭、團體、社區，促進、發展或恢復其社會功能，謀求其福利之準專業工作者

答案：（C）

詳解與考點

正解：依社會工作師法第二條規定，本法所稱社會工作師，指依社會工作專業教育、訓練及實務工作經驗，具有社會工作專業知識與技術，協助個人、家庭、團體、社區，促進、發展或恢復其社會功能，謀求其福利之專業工作者；C 選項卻將其定義為準專業工作者，與法條所定專業工作者的定位不符，敘述錯誤，故本題選 C。

A：社會工作師法確於民國八十六年（1997年）四月二日制定公布，此為我國社會工作專業法制化的重要里程碑，敘述正確。

B：社會工作師法對社會工作師的執業範圍、專業倫理與相關義務均有明確規範，其立法目的即在確立專業職責、維護服務對象（個案）權益，敘述正確。

D：依社會工作師法有關專科社會工作師之規定，社會工作師須完成專科社會工作師訓練，並經中央主管機關甄審合格，始得請領專科社會工作師證書，此為專科社工師分科分級制度的設計，敘述正確。

本題考點：社會工作師法第二條之社會工作師定義，明定社會工作師之角色為運用專業知識與技術協助案主系統的專業工作者，而非準專業或半專業角色；專科社會工作師制度，指社會工作師完成專科訓練並經甄審合格後，得請領專科證書、於特定領域執業之分科分級設計。

第 34 題

依據兒童及少年性剝削防制條例所稱之「性剝削」，不包括下列何者？
  1. （A）使兒童或少年為有對價之性交或猥褻行為
  2. （B）對兒童或少年性心理之輔導
  3. （C）利用兒童或少年為性交、猥褻之行為，以供人觀覽
  4. （D）使兒童或少年坐檯陪酒或涉及色情之伴遊、伴唱、伴舞等行為

答案：（B）

詳解與考點

正解：本題問兒童及少年性剝削防制條例所稱「性剝削」不包括何者。依該條例第2條，性剝削係指下列行為之一：使兒童或少年為有對價之性交或猥褻行為（A所述）；利用兒童或少年為性交、猥褻之行為，以供人觀覽（C所述）；使兒童或少年坐檯陪酒或涉及色情之伴遊、伴唱、伴舞等行為（D所述）；以及拍攝、製造兒少為性交或猥褻行為之圖畫、語音等物品。B「對兒童或少年性心理之輔導」屬於發現、救援兒少性剝削被害人後所提供的保護扶助、輔導處遇措施，性質是協助被害人而非剝削行為本身，並非該條例定義性剝削的行為態樣，故選B。

A、C、D：三者同因而不得選——皆為該條例第2條明文列舉、構成「性剝削」定義的行為類型，僅具體行為態樣不同：A是使兒少從事有對價的性交或猥褻行為；C是利用兒少從事性交猥褻行為供人觀覽；D是使兒少坐檯陪酒或涉及色情之伴遊伴唱伴舞等行為，三者皆屬條文列舉的剝削樣態，題目問「不包括」者，這三項既屬其列舉範圍，即應排除。

本題考點：兒童及少年性剝削防制條例第2條「性剝削」定義，以列舉方式界定有對價性交猥褻、供人觀覽、色情伴遊伴唱伴舞、拍攝製造猥褻物品等行為態樣；性剝削行為與被害人保護輔導措施的區辨，是條文定義題的常見誘答設計，將保護性措施誤植為剝削行為之一。

第 35 題

依據特殊境遇家庭扶助條例，關於緊急生活扶助之申請資格，下列敘述何者正確？
  1. （A）符合特殊境遇家庭條件，於事實發生後6 個月內申請
  2. （B）按當年低收入戶每人每月最低生活費用1.5 倍核發
  3. （C）每人每次補助1 年為原則
  4. （D）同一個案同一事由補助2 次為限

答案：（A）

詳解與考點

正解：特殊境遇家庭扶助條例之緊急生活扶助，其申請資格設有時效限制，須於符合特殊境遇家庭要件之事實發生後一定期間內提出申請，逾期即不予受理；四個選項中，只有A所述「事實發生後6個月內申請」的申請時效架構，是本題官方認定為正確的敘述，其餘三個選項在核發金額計算基準、補助期程與補助次數上的具體數字均與法規不符，故選A。

B：依特殊境遇家庭扶助條例第6條，緊急生活扶助按當年度低收入戶每人每月最低生活費用標準1倍核發；選項誤寫為1.5倍，混淆了其他社會福利制度可能採用的資格門檻，故不選。

C：緊急生活扶助之補助期程另有法定原則，並非以選項所述「每人每次補助1年為原則」呈現，屬以看似合理的期間包裝而成的數字誘答，須以法條原文之期程為準。

D：緊急生活扶助之補助次數限制，法定次數與選項所述「同一事由補助2次為限」不同，屬另一種數字置換的誘答方式，考生須精確對照法條原文之次數規定。

本題考點：特殊境遇家庭扶助條例之緊急生活扶助，其申請時效、核發基準、補助期程與次數等具體規定，是社會政策法規考科常見的數字辨析型考點，作答時須精確對照法條原文數字，避免被結構相似但數字不同的選項混淆。

第 36 題

下列何者為性侵害犯罪防治法中，直轄市、縣（市）主管機關應協調相關機關辦理之事項？①提供被害人24 小時緊急救援 ②訂定性侵害防治政策及相關法規 ③協助被害人就醫診療、驗傷及採證 ④推廣性侵害防治教育、訓練及宣導 ⑤提供加害人身心治療、輔導或教育
  1. （A）①②③④
  2. （B）①②③⑤
  3. （C）①②④⑤
  4. （D）①③④⑤

答案：（D）

詳解與考點

正解：性侵害犯罪防治法將中央與地方主管機關的職責做了分工：訂定全國性的性侵害防治政策及相關法規，屬中央主管機關的職權；直轄市、縣（市）主管機關則負責協調各相關機關，落實各項第一線保護與防治工作，包括提供被害人24小時緊急救援（①）、協助被害人就醫診療、驗傷及採證（③）、推廣性侵害防治教育、訓練及宣導（④），以及提供加害人身心治療、輔導或教育（⑤），這四項都屬於地方主管機關應協調辦理之事項，故選 D（①③④⑤）。

A、B、C：三個選項都包含②「訂定性侵害防治政策及相關法規」，但訂定全國性政策與法規屬於中央主管機關的職權，並非直轄市、縣（市）主管機關「協調相關機關辦理」的事項；A、B、C 都因誤將中央職權併入地方協調事項的組合中而不成立。

本題考點：性侵害犯罪防治法之中央與地方主管機關職責分工，中央負責政策與法規之訂定，地方負責緊急救援、驗傷採證、教育宣導、加害人身心治療輔導等第一線協調辦理事項，是本題辨析各選項組合是否成立的關鍵依據。

第 37 題

依據國民年金法規定，有關不予保險給付之敘述，下列何者錯誤？
  1. （A）被保險人故意造成保險事故，包括喪葬給付在內，保險人不予保險給付
  2. （B）被保險人故意犯罪行為，導致保險事故，除未涉案之當序受益人外，不予保險給付
  3. （C）被保險人配偶故意犯罪行為，導致保險事故，除未涉案之當序受益人外，不予保險給付
  4. （D）由於戰爭變亂而發生保險事故

答案：（A）

詳解與考點

正解：依國民年金法有關不予保險給付之規定，被保險人故意造成保險事故者，原則上保險人不予保險給付，但喪葬給付性質上是用以協助支付被保險人身故後之喪葬費用、保障其遺屬，並非給付予被保險人本人，故法規對此設有除外規定，喪葬給付不因被保險人故意造成保險事故而一律排除；選項A稱「故意造成保險事故，包括喪葬給付在內，保險人不予保險給付」，將喪葬給付一併排除，與法規除外規定不符，敘述有誤，故本題選A。

B：被保險人故意犯罪行為導致保險事故者，除未涉案之當序受益人外，保險人不予保險給付，此一規定係為避免被保險人因自身犯罪行為獲得保險給付之不當利益，同時保障未參與犯罪之其他受益人權益，敘述正確。

C：被保險人配偶故意犯罪行為導致保險事故者，除未涉案之當序受益人外，同樣不予保險給付，其立法意旨與B同理，係為防止配偶之犯罪行為使家庭其他成員之保險給付權益受牽連，同時保障未涉案受益人，敘述正確。

D：由於戰爭變亂而發生保險事故者，屬於不可歸責於被保險人個人行為之特殊風險事由，國民年金保險制度將此類事故列為不予給付事由之一，敘述正確。

本題考點：國民年金法之不予保險給付事由，包括故意造成保險事故（但喪葬給付除外）、故意犯罪行為導致保險事故（未涉案當序受益人除外）、戰爭變亂等情形；喪葬給付因保障遺屬治喪需要而設有除外規定，是本題辨析故意造成事故不予給付範圍的關鍵考點。

第 38 題

依據志願服務法規定，下列何者屬於各目的事業主管機關可提供給志願服務運用單位的措施？
  1. （A）發給服務績效證明書
  2. （B）將汰舊之器材及設備無償撥交
  3. （C）定期考核志工個人及團隊之服務績效
  4. （D）提供意外事故保險及經費補助

答案：（B）

詳解與考點

正解：依志願服務法規定，各目的事業主管機關對志願服務運用單位得提供之協助措施之一，即為將政府機關汰舊之器材及設備無償撥交運用單位使用，以減輕運用單位在物力資源上的負擔，故本題選B。

A：發給服務績效證明書，性質上是運用單位對其所屬志工服務時數與表現的認證，屬「運用單位對志工」的措施，並非目的事業主管機關對運用單位的協助措施。

C：定期考核志工個人及團隊之服務績效，屬運用單位對其志工人力進行內部管理與考核的職責，並非目的事業主管機關提供給運用單位之措施。

D：提供意外事故保險及經費補助，性質上多屬運用單位為所屬志工投保，或由主管機關對志工個人（而非對運用單位本身）提供之保障措施，與本題所問「目的事業主管機關可提供給運用單位」之措施性質不同。

本題考點：志願服務法中「目的事業主管機關對運用單位」與「運用單位對志工」兩種不同權責主體之協助與管理措施的區分，是本法考題常見的角色錯置誘答設計。

第 39 題

關於我國現行長期照顧服務法之敘述，下列何者錯誤？
  1. （A）長期照顧係指身心失能持續已達或預期達3 個月以上者，依其個人或其照顧者之需要，所提供之生活支持、協助、社會參與、照顧及相關之醫護服務
  2. （B）機構住宿式指以受照顧者入住之方式，提供全時照顧或夜間住宿等之服務
  3. （C）長期照顧服務法所稱主管機關，在中央為衛生福利部，在直轄市為直轄市政府
  4. （D）遺產稅及贈與稅稅率由10%調增至20%以內所增加之稅課收入，為特種基金來源之一

答案：（A）

詳解與考點

正解：依長期照顧服務法第三條，長期照顧的法定定義為身心失能持續「已達或預期達六個月以上」者，依其個人或其照顧者之需要，提供生活支持、協助、社會參與、照顧及相關醫護服務。A將期間寫成「3個月以上」，與法定期間不符，故A為錯誤敘述，本題選A。

B：機構住宿式服務指以受照顧者入住之方式，提供全時照顧或夜間住宿等服務，與長期照顧服務法對此類服務型態的定義相符，敘述正確。

C：長期照顧服務法所稱主管機關，在中央為衛生福利部，在直轄市為直轄市政府，在縣（市）為縣（市）政府，敘述正確。

D：長期照顧服務法所定長照服務發展基金之財源，包括遺產稅及贈與稅稅率由百分之十調增至百分之二十以內所增加之稅課收入，敘述正確。

本題考點：長期照顧服務法「長期照顧」法定定義中的失能期間門檻（六個月以上），是與其他社福法規期間（如三個月、其他鑑定期間）混淆的高頻誘答點；長照服務發展基金之法定財源來源。
