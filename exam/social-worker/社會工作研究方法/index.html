第 1 題

在規劃研究問題時，下列那個選項不會作為考慮的面向？
  1. （A）執行的可行性
  2. （B）研究者個人利益
  3. （C）對社會的重要性
  4. （D）與過去研究的關聯性

答案：（B）

詳解與考點

正解：規劃研究問題時，應考量的面向包括研究執行的可行性（時間、經費、方法是否可行）、研究對社會或學術的重要性、以及與既有文獻或過去研究的關聯性，這些都是評估一個研究問題是否值得投入的正當依據；「研究者個人利益」並非合宜的考量面向，因為研究問題的選定應服務於知識累積與社會需要，而非圖利研究者個人，故選B。

A：執行的可行性是規劃研究問題的必要考量，包括時間、經費、人力、資料取得等條件是否足以支持研究完成，屬正當考量面向。

C：對社會的重要性是評估研究問題價值的核心指標之一，研究議題若能回應重要的社會需求或學術缺口，更值得投入資源進行。

D：與過去研究的關聯性可協助研究者釐清該問題是否已被充分探討、有無延續或補充既有研究的空間，是規劃研究問題時的合宜考量。

本題考點：研究問題評估準則（criteria for selecting a research question），包括可行性、重要性、與既有研究之關聯性，並強調研究應服務公共知識與社會需要而非研究者私利。

第 33 題

承上題，若研究者想要瞭解各個需求程度的數量時，下列何者為最適當的統計分析方法？
  1. （A）次數分配
  2. （B）平均數
  3. （C）相關係數
  4. （D）標準差

答案：（A）

詳解與考點

正解：研究者若想了解各個需求程度有多少人、即各類別出現的次數多寡，應使用次數分配，將資料按類別加總計算各類別出現的次數與百分比，直接呈現各需求程度的數量分布，故選 A。

B：平均數是描述一組數值資料集中趨勢的統計量，適用於呈現整體資料的平均水準，並非用來呈現各個需求程度個別的數量分布，與題目所問不符。

C：相關係數是用來檢定兩個連續變項之間線性關聯強弱的統計量，本題僅涉及單一變項各類別數量的呈現，並未涉及兩變項間關係的檢定，不適用。

D：標準差是描述一組數值資料離散程度的統計量，用於呈現資料分布的離散情形，並非用來呈現各類別的數量多寡，與題目所問不符。

本題考點：次數分配（Frequency Distribution），將資料依類別歸類並計算各類別出現次數或百分比，是呈現類別變項數量分布最基本的統計方法；集中量數（平均數）與離散量數（標準差）用於描述數值資料的分布特性，相關係數用於檢定變項間關聯，三者皆非用於呈現單一類別變項的數量分布。

第 25 題

研究者為加強質性研究的研究設計，常借助於三角檢定（triangulation），若以多種方法去研究一個問題或方案，屬於下列何種類型？
  1. （A）理論三角檢定（theory triangulation）
  2. （B）方法論三角檢定（methodological triangulation）
  3. （C）資料三角檢定（data triangulation）
  4. （D）研究者三角檢定（investigator triangulation）

答案：（B）

詳解與考點

正解：三角檢定（triangulation）依所整合的對象不同，可分為多種類型；當研究者以多種方法（例如同時採用訪談、觀察、文件分析等不同資料蒐集方法）來研究同一個問題或方案時，屬於方法論三角檢定（methodological triangulation），故本題選B。

A：理論三角檢定（theory triangulation）指研究者運用多種不同的理論觀點或架構來詮釋、解釋同一組資料或現象，重點在理論的多元並置，而非本題所述方法的多元運用，故不選。

C：資料三角檢定（data triangulation）指從不同的來源（例如不同時間點、不同地點、不同對象）蒐集資料以相互驗證，重點在資料來源的多元，而非蒐集資料所使用的方法本身是否多元，與題意不符，故不選。

D：研究者三角檢定（investigator triangulation）指由多位研究者分別對同一現象進行觀察、分析或編碼，藉由比對不同研究者的結果來提升研究的信實度，重點在研究者人數的多元，而非方法的多元，故不選。

本題考點：三角檢定（Triangulation），質性研究常用以提升研究可信賴度（trustworthiness）的策略，依整合對象不同分為方法論三角檢定（多種方法）、資料三角檢定（多元資料來源）、研究者三角檢定（多位研究者）與理論三角檢定（多種理論觀點）四種類型。

第 17 題

在進行推論統計時，研究人員無可避免地必須承擔錯誤的風險，名為第一型錯誤（type I error）與第二型錯誤（type II error）。今當顯著水準由0.05 變更為0.01 時，犯上述錯誤的風險會如何改變？
  1. （A）犯第一型錯誤的風險降低，犯第二型錯誤的風險提高
  2. （B）犯第一型錯誤的風險提高，犯第二型錯誤的風險降低
  3. （C）犯第一型錯誤的風險降低，犯第二型錯誤的風險不變
  4. （D）犯第一型錯誤的風險不變，犯第二型錯誤的風險降低

答案：（A）

詳解與考點

正解：顯著水準（α）就是研究者容許犯第一型錯誤（誤將為真的虛無假設拒絕）的機率上限，α由0.05降為0.01，代表研究者要求更嚴格的證據才願意拒絕虛無假設，因此犯第一型錯誤的風險直接降低；但在樣本數與效果量不變的情況下，拒絕虛無假設的門檻提高，會使原本足以拒絕虛無假設的證據變得不足，導致本應拒絕卻未拒絕虛無假設（即犯第二型錯誤）的風險相對提高，兩者呈現此消彼長的關係，故選A。

B：本選項把兩種錯誤的變化方向完全說反——α調低是使第一型錯誤風險降低而非提高，第二型錯誤風險則是提高而非降低，故B錯誤，是最容易與正解混淆的方向誤植選項。

C：本選項正確掌握第一型錯誤風險降低的方向，但誤認第二型錯誤風險不變；事實上第一型與第二型錯誤在其他條件不變下具有消長關係，α降低必然使第二型錯誤風險上升而非維持不變，故C錯誤。

D：本選項誤認第一型錯誤風險不變，但α本身的定義就是第一型錯誤的機率上限，調整α必然直接改變第一型錯誤的風險，不可能不變，故D錯誤。

本題考點：第一型錯誤與第二型錯誤（Type I Error / Type II Error），分別指誤拒真的虛無假設、與未能拒絕假的虛無假設；顯著水準（Significance Level, α）與檢定力（Statistical Power）的消長關係，指在樣本數與效果量固定下，調低α會降低第一型錯誤風險但同時提高第二型錯誤風險。

第 9 題

抽樣調查時，下列那一項措施比較無法確保增加樣本的代表性？
  1. （A）增大樣本數與回收率
  2. （B）利用能反映群體特性的抽樣架構進行抽樣
  3. （C）利用分層的技巧減少抽樣誤差
  4. （D）利用電腦網路調查

答案：（D）

詳解與考點

正解：電腦網路調查僅能觸及具備上網能力與意願的族群，容易將不熟悉網路操作、無網路設備或不上網者（如部分年長者、低社經地位者）排除在樣本之外，形成涵蓋誤差（coverage error），使樣本結構偏離母體特性，故電腦網路調查較無法確保增加樣本的代表性，選D。

A：增大樣本數並提高回收率，能降低抽樣誤差並減少因無反應（non-response）而產生的偏誤，使樣本更貼近母體，有助於提升代表性。

B：能反映母體特性的抽樣架構（sampling frame）可降低涵蓋不足；再配合適當的機率抽樣設計，才能使抽樣單位具有已知且非零的入選機率，兩者有助於提升樣本代表性。

C：分層抽樣（stratified sampling）依母體特性事先分層再行抽樣，能降低抽樣誤差、確保各層樣本比例貼近母體結構，有助於提升代表性。

本題考點：樣本代表性（representativeness）之影響因素；網路調查所產生的涵蓋誤差（coverage error）；分層抽樣（stratified sampling）提升抽樣精確度的原理。
