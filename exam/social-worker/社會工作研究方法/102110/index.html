第 1 題

進行推論檢定時，如果有不只一種方法適用，原則上應優先選擇：
  1. （A）考驗力大的檢定
  2. （B）顯著性高的檢定
  3. （C）自由度大的檢定
  4. （D）強韌性大的檢定

答案：（A）

詳解與考點

正解：進行統計推論檢定時，若同一資料型態下有多種檢定方法皆可適用，統計學上原則建議優先選擇考驗力較大的檢定方法，因為考驗力愈大，愈能在母群體確實存在效果時偵測出該效果，降低犯第二類型錯誤的風險，故本題選 A。

B：顯著性高若指設定較嚴格的顯著水準，並不是選擇檢定方法的優先準則，顯著水準是研究者依研究性質事先設定的容許誤判機率，而非比較不同檢定方法孰優孰劣的依據；若誤解為檢定結果數值愈小愈好，則更是倒果為因，與方法選擇原則無關。

C：自由度是計算檢定統計量與判斷臨界值時的參數，通常由樣本數與估計參數個數決定，並非用來比較不同檢定方法優劣的選擇準則；自由度大小是檢定過程的結果之一，而非事先選擇方法的依據。

D：強韌性即對於違反統計假設時仍能維持正確性的穩健程度，雖然也是選擇檢定方法時的重要考量之一，但題目所問的原則上優先準則，統計學界公認以考驗力為首要比較基準，強韌性通常是在無法滿足母數檢定假設時，才轉而考慮以無母數等強韌性較高的方法替代。

本題考點：統計檢定力，即正確偵測出母群體中真實存在效果的機率，是比較與選擇檢定方法的核心準則之一；第一類型與第二類型錯誤，檢定力與第二類型錯誤機率互為餘數關係，是研究方法科目的重要基礎概念。

第 2 題

某人想知道夫妻情緒智商（EQ）是否相似，他隨機選取12 對夫妻測量其EQ 分數，並進行平均數t 考驗。結果，夫、妻EQ 平均數分別是29.33、35.67，樣本相關係數 .037，p=.909，t 值(-1.998)，p=.071。下列敘述，何者正確？
  1. （A）它採用的是單一樣本t 檢定
  2. （B）t 值考驗結果達到顯著性，夫妻情緒智商有顯著差異
  3. （C）t 值考驗結果沒有達到顯著性，夫妻情緒智商沒有顯著差異
  4. （D）它需要再進行多元共線性（multicollinearnality）分析

答案：（C）

詳解與考點

正解：本題12對夫妻的EQ分數，是同一對夫妻各自測得的兩筆數值，屬於配對（相依）樣本，故應採用相依樣本t檢定而非獨立樣本t檢定；相關係數 r=.037、p=.909，顯示這兩組配對分數之間的線性關聯不顯著，但此結果只描述配對相關程度，不直接等於平均數差異的檢定結果。判斷平均數是否有差異，需看t值考驗：以慣用顯著水準α=.05為準，t=−1.998時對應p=.071，大於.05，故不能拒絕「夫妻EQ平均數相等」的虛無假設，也就是統計上無法說夫妻EQ有顯著差異，故選 C。

A：單一樣本t檢定是將「一組樣本平均數」與「一個已知母體平均數」做比較，本題是比較「丈夫」與「妻子」兩組配對分數的平均數差異，並未涉及已知母體參數，不屬單一樣本t檢定的情境。

B：t值考驗的p=.071大於顯著水準.05，應判定為未達顯著，敘述卻說「達到顯著性、有顯著差異」，方向恰好相反，是常見的p值判讀錯誤。

D：多元共線性是複迴歸分析中，多個自變項彼此高度相關而扭曲迴歸係數估計的問題，與本題單純比較兩組配對平均數的t檢定無關，無須進行此項分析。

本題考點：相依樣本（配對樣本）t檢定，用於比較同一組受試者（或配對受試者）前後或兩種情境下平均數的差異；p值判讀，指以p值是否小於事先設定的顯著水準（通常α=.05）決定是否拒絕虛無假設。

第 3 題

下列對研究設計中「分析單位（unit of analysis）」的敘述，何者正確？
  1. （A）幫派整體特質比較性研究的分析單位是「個人」
  2. （B）報紙社論中自由主義傾向比較性研究的分析單位是「個別的社論」
  3. （C）社會科學的分析單位禁止包含諸如繪畫在內的「社會人造事實（social artifact）」
  4. （D）把團體作為分析單位的結論概推到團體中的個人身上，稱為「個體的謬誤（individualistic fallacy）」

答案：（B）

詳解與考點

正解：分析單位（unit of analysis）是研究者蒐集資料、進行描述與分析時所鎖定的對象或層次。當研究比較的是「報紙社論中的自由主義傾向」時，研究者實際蒐集與編碼的對象是一篇篇個別的社論內容，因此其分析單位即為「個別的社論」，選項 B 敘述正確，本題選 B。

A：幫派整體特質的比較性研究，關切的是幫派這個「團體」層次的特質（如組織型態、活動模式），而非個別成員的特質，故其分析單位應是「幫派（團體）」而非「個人」，選項 A 將分析單位誤植為個人，與研究性質不符。

C：社會科學的分析單位並不限於人或團體，舉凡繪畫、書信、新聞報導、建築物等由人類創造、承載社會意義的「社會人造事實（social artifact）」，同樣可以作為內容分析等研究方法的分析單位，選項 C 主張「禁止」以社會人造事實為分析單位，與研究方法上的實際做法相反，敘述錯誤。

D：以團體為分析單位所得出的結論，若不當地概推到組成該團體的個人身上，正確名稱應為「區位謬誤（ecological fallacy）」，而非選項所稱的「個體的謬誤（individualistic fallacy）」；區位謬誤指的正是由團體層次資料推論到個人層次時可能產生的推論錯置，選項 D 誤用了名詞，敘述錯誤。

本題考點：分析單位（Unit of Analysis），指研究蒐集與分析資料時鎖定的對象層次（如個人、團體、社會人造事實等）；區位謬誤（Ecological Fallacy），指誤將團體層次分析所得的結論，直接套用到團體中個別成員身上所產生的推論錯誤。

第 4 題

下列有關「按數量成比例的機率抽樣（ Probability Proportionate to Size Sampling，簡稱PPS）」敘述，何者正確？
  1. （A）它是種透過獎勵機制來提高樣本數，並且擴充代表性的一種抽樣方法
  2. （B）它是種讓母群體中含量大的部分被抽中的機率也大，可以提高樣本代表性方法
  3. （C）它適用於不容易取得完整的母體名冊，缺乏相關輔助變項的研究之中
  4. （D）為了要降低樣本蒐集成本及抽樣誤差，這種方法對輔助變項資訊的要求程度低

答案：（B）

詳解與考點

正解：按數量成比例的機率抽樣（Probability Proportionate to Size Sampling, PPS）是一種多階段抽樣中常用的方法，其原理是讓母體中規模較大的抽樣單位，被抽中的機率也相對較高，藉此使樣本更能反映母體中不同規模單位的實際分布，提高樣本的代表性，故 B 敘述正確，為本題答案。

A：PPS 抽樣的原理是依據抽樣單位的規模大小調整其入選機率，並非透過提供獎勵誘因來提高樣本數或擴充代表性；PPS 是機率抽樣設計上的技術，與獎勵機制無關，A 敘述有誤。

C：PPS 抽樣需要事先掌握各抽樣單位的規模資訊（輔助變項，如各單位的人口數、機構規模等）以計算入選機率，因此恰好適用於已具備完整母體名冊與規模等輔助變項資訊的情況，而非不容易取得完整母體名冊、缺乏輔助變項的研究情境，C 敘述方向相反，有誤。

D：PPS 抽樣的實施仰賴精確的輔助變項資訊來計算各單位的抽樣機率，對輔助變項資訊的要求程度其實較高、而非較低；若輔助變項資訊不足或不準確，會直接影響抽樣機率的正確性與樣本代表性，D 敘述有誤。

本題考點：按規模成比例之機率抽樣（PPS Sampling），依抽樣單位規模大小調整入選機率以提升樣本代表性的機率抽樣方法，常見於多階段集群抽樣中作為第一階段抽樣的技術；輔助變項（auxiliary variable）之角色，指抽樣設計中用以估計單位規模、進而決定抽樣機率的既有資訊。

第 5 題

某研究者從選取用以形成所探究概念的類似樣本著手，但是當他發現再也無法產生新的見地之後，就換另個類型的樣本繼續研究。這種抽樣方法是：
  1. （A）機率抽樣（probability sampling）
  2. （B）限額抽樣（quota sampling ）
  3. （C）理論抽樣（theoretical sampling）
  4. （D）滾雪球抽樣（snowball sampling）

答案：（C）

詳解與考點

正解：研究者依理論發展的需要，持續選取性質相似的樣本進行資料蒐集與分析，直到不再產生新的概念或見解（即達到理論飽和，theoretical saturation）後，才轉換抽取另一類型的樣本繼續探究，此種依分析結果不斷調整下一步取樣方向、以發展與驗證理論為目的的抽樣方式，稱為理論抽樣（theoretical sampling），常見於紮根理論（grounded theory）研究，故本題選C。

A：機率抽樣（probability sampling）是依隨機原則、讓母群體中每個個體都有已知且非零的被抽中機率的抽樣方式（如簡單隨機抽樣、分層抽樣），目的通常是為了推論母群體，與本題描述「依概念飽和程度決定何時換樣本」的邏輯完全不同，不適用。

B：限額抽樣（quota sampling）是先依母群體特徵（如性別、年齡）設定各類別應抽取的樣本配額，再依配額抽取樣本，抽樣過程是預先設定好比例，並非依「資料是否產生新見解」動態調整，與題目描述不符。

D：滾雪球抽樣（snowball sampling）是透過已知樣本介紹或推薦其他具相同特徵的潛在受訪者，逐步擴大樣本，其抽樣依據是人際網絡的轉介，而非依「概念是否飽和」決定樣本類型的轉換，雖然同屬非機率抽樣，但抽樣邏輯與本題描述的理論驅動取樣不同。

本題考點：理論抽樣（Theoretical Sampling），依理論建構與資料飽和程度動態決定下一步抽樣對象與類型的質性研究抽樣方式；理論飽和（Theoretical Saturation），指持續蒐集資料已不再產生新概念或關係的狀態，兩者是紮根理論方法論的核心概念，也是本題與機率抽樣、限額抽樣、滾雪球抽樣區辨的關鍵。

第 6 題

下列對福利服務滿意度中測量誤差的敘述，何者正確？
  1. （A）受訪者故意用低服務滿意度分數，破壞福利機構良好形象，稱為社會期望的偏誤（social desirability bias）
  2. （B）受訪者隨著時間和服務的改變，回答出不同的滿意度分數，稱為隨機性的誤差（random error）
  3. （C）受訪者滿意所提供的福利服務，卻給了低滿意度分數，稱為月暈效應（halo effect）
  4. （D）受訪者填寫服務滿意度問卷時，無論正負向題都答非常滿意，稱為順勢反應（acquiescent response set）

答案：（D）

詳解與考點

正解：受訪者不論題目正向或負向敘述、一律勾選「非常滿意」等一致傾向的作答方式，稱為順勢反應組（acquiescent response set），即不論題意內容為何、傾向一律同意或給予正向反應的反應心向，這是測量誤差中常見的反應心向偏誤之一，題幹描述的正是此現象，故選 D。

A：社會期望偏誤是指受訪者為求符合社會認可的形象、避免被評價負面，傾向給出較正向、討喜的回答，而非「故意壓低分數以破壞機構形象」；題幹描述的是帶有惡意動機的刻意扭曲，與社會期望偏誤趨向正向、社會期許的方向相反，故敘述有誤。

B：受訪者的滿意度分數若因服務內容真的隨時間改變而不同，那是反映真實狀況變化的真實分數變動，並非測量誤差；隨機誤差指的是與真實狀態無關、由情緒、疲勞、誤讀題意等偶發因素造成的不一致波動，題幹描述的情境屬於真實改變而非隨機誤差，混淆了真實變化與測量誤差兩個概念，故敘述有誤。

C：月暈效應是指評分者因對受評對象的整體印象而連帶影響對其個別、不相關面向的評分，使各項評分呈現不當一致的正向或負向傾向；題幹描述「明明滿意卻給低分」屬於答案與真實態度不一致的作答矛盾，並非月暈效應所指整體印象牽動個別評分的機制，故敘述有誤。

本題考點：反應心向（Response Set）中的順勢反應組（Acquiescent Response Set），指受訪者不論題目內容一律同意或給予正向反應的作答傾向；社會期望偏誤（Social Desirability Bias）與月暈效應（Halo Effect）則是測量誤差中常與其對照辨析的相關概念。

第 7 題

下列因素中，那一個不會影響抽樣誤差的大小？
  1. （A）母群體大小
  2. （B）樣本大小
  3. （C）信心水準高低
  4. （D）標準誤大小

答案：（A）

詳解與考點

正解：依本題採用的大母體近似，抽樣誤差（sampling error，常以信賴區間的誤差界限表示）＝z值（依信心水準決定）×標準誤（standard error，SE＝σ／√n）。在抽樣比例很小或忽略有限母體校正的前提下，抽樣誤差受樣本大小n、信心水準與標準誤影響，而近似不受母群體大小影響，故選A。若為有限母體且抽樣比例較高，母群體大小會透過有限母體校正影響標準誤，不能把A理解為無條件成立。

B：樣本大小n是標準誤公式（SE＝σ／√n）的分母核心，n越大則SE越小、抽樣誤差越小，故會影響抽樣誤差。

C：信心水準決定誤差界限公式中的z值，例如95%信心水準對應z約1.96，99%對應z約2.58；信心水準越高，誤差界限越大。

D：標準誤是誤差界限＝z×標準誤的直接組成部分，會影響抽樣誤差大小。

本題考點：抽樣誤差（Sampling Error）、標準誤（Standard Error）與有限母體校正；母群體大小不影響抽樣誤差是有前提的近似判斷。

第 8 題

女性平均教育程度較高的國家，離婚率較高。由此可以推論：
  1. （A）教育程度較高的女性，離婚率較高
  2. （B）一國的女性平均教育程度與其離婚率正相關
  3. （C）女性的教育程度與她的離婚機率正相關
  4. （D）教育程度較高的女性，較能經濟獨立，因此較有能力選擇離婚

答案：（B）

詳解與考點

正解：題目所給資料是以「國家」為分析單位（一國女性平均教育程度、一國離婚率），兩者皆為國家層級的加總變項，因此唯一能安全推論的是「一國的女性平均教育程度與其離婚率正相關」，即總體層次對總體層次的關聯，故選B。

A：「教育程度較高的女性，離婚率較高」把國家層級的加總關聯，直接套用到個人層級（個別女性）身上，犯了區位謬誤（ecological fallacy）——一國平均教育程度高，不代表該國內教育程度較高的個別女性離婚率也較高，因為總體相關可能是由完全不同的個人層級機制造成，故A不能由題目資料推論。

C：「女性的教育程度與她的離婚機率正相關」同樣是把總體層次的相關直接轉換成個人層次的相關陳述，屬於區位謬誤，資料並未提供個人層級的教育程度與離婚機率配對資料，故C不能推論。

D：「教育程度較高的女性，較能經濟獨立，因此較有能力選擇離婚」不僅犯了與A、C相同的區位謬誤，還進一步推論了資料中完全未觸及的因果機制（經濟獨立→選擇離婚），屬於過度推論，故D不能由題目資料推論。

本題考點：區位謬誤（ecological fallacy），指誤將總體層次的分析結果，直接套用到個體層次上做推論；分析單位（unit of analysis）與推論層次的一致性，是研究方法中判斷推論是否合理的基本原則。

第 9 題

某大學抽樣調查畢業生流向，首先按各學院的人數比例，分配樣本數；接著各學院內再按性別比例，決定男女學生的樣本數，然後以學號為抽樣架構，將總人數除以所需樣本數，算出抽樣間距（interval），據以抽出樣本。此調查應用了那些抽樣技術？①配額抽樣 ②分層抽樣 ③等比例抽樣 ④系統抽樣⑤立意抽樣
  1. （A）①②③
  2. （B）②③④
  3. （C）③④⑤
  4. （D）①②③④

答案：（B）

詳解與考點

正解：本題描述的抽樣過程可拆解為三個步驟：第一步「按各學院的人數比例分配樣本數」是依學院這個類別變項分層、且依各層人數比例決定樣本配置，兼具分層抽樣（②，先將母體依特徵分為若干層）與等比例抽樣（③，各層樣本數依其占母體比例分配）的性質；第二步「各學院內再按性別比例決定男女學生的樣本數」是在學院這一層之內，再依性別做第二層的比例分層，仍屬分層抽樣與等比例抽樣的延伸應用；第三步「以學號為抽樣架構，將總人數除以所需樣本數算出抽樣間距，據以抽出樣本」則是典型的系統抽樣（④，依固定間距從抽樣架構中抽取樣本）。整個調查依序運用了分層抽樣、等比例抽樣與系統抽樣，也就是②③④，因此本題選 B。

A、D：A（①②③）與 D（①②③④）都納入了配額抽樣（①），但配額抽樣屬於非機率抽樣，是研究者依主觀配額指標自行選取樣本、而非透過機率方法抽出，本題描述的抽樣架構與抽樣間距計算，是明確的機率抽樣程序，並不存在研究者主觀選取的配額抽樣成分，因此含①的選項都不成立。

C：C（③④⑤）納入了立意抽樣（⑤），立意抽樣同樣屬於非機率抽樣，是研究者依研究目的主觀選取具代表性或特定特徵的樣本，本題全程都是依人數比例與固定抽樣間距的機率抽樣程序，並未出現研究者主觀選取樣本的立意抽樣成分，因此 C 也不成立；此外 C 未納入②分層抽樣，也與題目先按學院、再按性別分層的描述不符。

本題考點：分層抽樣（stratified sampling）與比例分配（proportionate allocation），依母體特徵分層並依各層占比決定樣本數；系統抽樣（systematic sampling），依固定抽樣間距從抽樣架構中抽取樣本；配額抽樣（quota sampling）與立意抽樣（purposive sampling），皆屬非機率抽樣方法，常在混合式抽樣設計題目中作為誘答項，用以測驗考生能否正確區辨機率與非機率抽樣的本質差異。

第 10 題

青少年安置機構以個案紀錄分析青少年離院原因，由兩位資深社工分別進行編碼，再核對兩人編碼的一致性。這樣的目的是為了檢驗：
  1. （A）內容效度（content validity）
  2. （B）分數信度（score reliability）
  3. （C）鑑別度（discriminatory power）
  4. （D）同時效度（concurrent validity）

答案：（B）

詳解與考點

正解：由兩位資深社工各自獨立對同一批個案紀錄進行編碼，再核對兩人編碼結果的一致程度，這種做法檢驗的是不同評分者對同一資料進行判斷是否一致，也就是評分者間一致性，對應本題選項所稱之「分數信度（score reliability）」，用以確認編碼結果不會因評分者不同而產生落差，確保資料的穩定性與可信賴程度，故選 B。

A：內容效度（content validity）檢驗的是測量工具的內容是否能完整涵蓋所欲測量構念的各個面向，通常透過專家審查題目內容是否周延、有無遺漏來判斷，與兩位編碼者對同一批資料的判斷是否一致這種一致性檢驗性質不同，屬於效度而非信度的範疇。

C：鑑別度（discriminatory power）是測驗編製與試題分析中的概念，指某一題目能否有效區分出高分組與低分組受測者的能力，與本題編碼者間一致性的檢驗目的無關。

D：同時效度（concurrent validity）檢驗的是新工具的測量結果，與同一時間點另一個已具公認效標的既有工具測量結果之間的相關程度，用以驗證新工具能否有效反映相同構念；本題並未涉及與其他效標工具的比較，而是同一份紀錄由兩人各自編碼後核對彼此一致性，性質上是信度而非效度的檢驗，是本題最容易誤選的效度類選項。

本題考點：評分者間信度／分數信度（inter-rater reliability），指不同評分者對同一資料進行判斷或編碼時結果一致的程度，是質性資料分析確保資料可信賴度的重要程序；並與內容效度、同時效度、鑑別度等效度或試題分析概念做出區分。

第 11 題

某人想研究父母積極履行親職的行為，正著手列出諸如稱讚、鼓勵、以身作則…等觀察清單。請問他所進行的這項程序是：
  1. （A）概念化
  2. （B）操作化
  3. （C）測量化
  4. （D）標準化

答案：（B）

詳解與考點

正解：將抽象概念（積極履行親職）轉化為可具體觀察、可記錄的行為指標（如稱讚、鼓勵、以身作則等），這種把抽象概念轉換為具體可觀察測量指標的程序稱為操作化（operationalization），故選 B。

A：概念化是操作化之前的步驟，指的是先釐清、界定某一抽象概念（如「積極履行親職」）的意涵與構成面向，屬於「這個概念是什麼」的定義工作，尚未具體列出可觀察的行為清單，與題幹已進入「列出稱讚、鼓勵等觀察項目」的階段不符，是操作化與概念化先後順序混淆的典型誘答。

C：「測量化」並非研究方法學中的標準通用術語，字面容易讓人誤以為與操作化同義而誤選，但操作化強調的是「把抽象概念轉為具體可觀察指標」的定義過程，與泛稱的測量行為不同，此選項屬名詞混淆型誘答。

D：標準化通常指測量工具或程序經過統一規範，使不同施測者、不同時間或不同對象間的結果具有一致性與可比較性（如標準化量表），關注的是測量的一致性，而非把抽象概念轉為具體觀察指標的過程，與題幹描述的階段不符。

本題考點：概念化（conceptualization），指界定抽象概念意涵的過程；操作化（operationalization），指將抽象概念轉化為具體可觀察、可測量指標的過程，兩者在量化研究流程中依序而不可混淆。

第 12 題

透過加總平均壽命、教育水準、收入三項積分來表示男性和女性的地位，這是那種測量編製方法？
  1. （A）評鑑（evaluation）
  2. （B）評量（assessment）
  3. （C）量表（scale）
  4. （D）指數（index）

答案：（D）

詳解與考點

正解：本題將平均壽命、教育水準、收入三項積分依規則加總，以單一分數表示男性與女性的地位。這是指數（index）的典型建構方式：把多個個別指標（indicator）加總或加權，合成代表某一構念的分數，故選D。

A：評鑑（evaluation）是對方案、政策或服務成效進行系統性價值判斷，並非多指標加總的測量編製方法。

B：評量（assessment）通常指系統性蒐集資料以了解或判斷個案、群體或現象，並非題述的多指標合成技術。

C：量表（scale）可由多個題項形成總分，但重點在依題項反應間的經驗或邏輯關係測量構念；Likert量表與Guttman量表只是不同形式，Guttman量表的累積型態並非所有量表的必要條件。本題明示把不同指標積分加總，故以指數辨識較適切。

本題考點：指數（Index）將多個指標依規則加總或加權成單一分數；量表（Scale）依一組題項反應測量構念，不能以特定量表形式概括全部量表。

下列對「線上調查（online survey）」敘述組合，何者正確？①窮人及老人的代表性低 ②無法使用資料校對及改正工具 ③具有自動輸入資料的功能 ④敏感問題的回答具有匿名效果 ⑤它的完訪率低於面訪
  1. （A）①②③④
  2. （B）②③④⑤
  3. （C）①③④⑤
  4. （D）①②④⑤

答案：（C）

詳解與考點

正解：題目要判斷五個敘述①至⑤何者正確描述線上調查（online survey）的特性。①窮人及老人使用網路的比例較低，以線上調查作為抽樣管道，這兩類人的代表性確實偏低；③受訪者直接在系統上填答，資料會自動存入資料庫，具有自動輸入資料的功能，省去人工謄打的步驟；④線上填答不必面對訪員，對敏感問題的回答較不易因人際壓力而失真，具有一定的匿名效果；⑤線上調查缺乏訪員親自邀請與追蹤，受訪者中途放棄的比例較高，完訪率通常低於面訪。①③④⑤四項敘述皆正確，故本題選C。

本題考點：線上調查（online survey）方法的特性比較，包括樣本代表性偏誤（數位落差）、資料校對機制、敏感問題的匿名效果、以及完訪率（response rate）與傳統面訪的差異。

第 14 題

  1. （A）①③
  2. （B）②④
  3. （C）①②③
  4. （D）①②③④

詳解與考點

正解：官方答案為C，將①②③視為成立，故選C；惟題目只顯示自願參加者的前測平均65分、標準差9分，後測平均76分、標準差20分，且前後平均數有顯著差異。這些資料可支持參與兒童後測平均分數較高及③後測分數離散程度變大，但無控制組與隨機分派，不能排除成熟、測驗等解釋，故不能據此證明①的因果主張；兩次標準差也不能顯示每名兒童的改變量，故不足以證明②的效果異質性。官方答案與可由題幹推出的統計結論並不完全一致。

A：A包含①③。③可由標準差由9增至20支持，但①把前後差異歸因於方案，超出單組前後測設計可支持的範圍。

B：B包含②④。僅有兩次平均數與標準差不足以判定②；④亦錯，變異數不同仍可使用不假設變異數同質的方法比較平均數。

D：D納入①②③④，除①與②的推論不足外，④也不成立。

本題考點：單組前後測設計不能單憑顯著前後差異推論因果；標準差反映各次測量的離散程度，個別效果差異須檢視配對改變分數或其他效果異質性資料。

第 15 題

承上題，此方案評估設計，屬於：
  1. （A）前實驗（或稱非實驗）設計（pre-experimental design）
  2. （B）準實驗設計（quasi-experimental design）
  3. （C）半實驗設計（half-experimental design）
  4. （D）實驗設計（experimental design）

答案：（A）

詳解與考點

正解：由承接上一題的方案設計可知，此方案評估僅有單一組個案（無對照組或控制組），採自願報名、非隨機分派，且僅進行處遇前後測比較個案改變。此種設計即為前實驗（或稱非實驗）設計中的「單組前後測設計」，因缺乏控制組可排除歷史、成熟等其他干擾因素，內部效度最弱，屬前實驗設計等級，故本題選A。

B：準實驗設計雖然同樣缺乏隨機分派，但通常仍會設置比較組（如未接受處遇的對照組）以增進因果推論的內部效度；本題設計僅有單一組、沒有任何比較組，未達準實驗設計「有比較組」的門檻，故不選B。

C：「半實驗設計」並非研究方法學上常用的正式分類名稱，是易與「準實驗設計」混淆而誤植的選項，本題不採此非正式用語作答。

D：實驗設計的必要條件是隨機分派受試者至實驗組與控制組，並設有控制組以進行比較；本題方案僅單一組自願報名，既無隨機分派也無控制組，內部效度不足以稱為實驗設計，故不選D。

本題考點：實驗設計的效度層級（前實驗設計、準實驗設計、實驗設計），關鍵判準在於有無控制組與是否隨機分派；單組前後測設計是前實驗設計中最典型、也最常考的低效度設計範例。

承第14 題，此方案評估設計，可能會有那些效度的問題？①成熟因素（maturation） ②測驗（testing）③選擇性偏誤（selection bias） ④迴歸因素（regression）
  1. （A）①②
  2. （B）③④
  3. （C）①②③
  4. （D）①②③④

答案：（C）

詳解與考點

正解：官方答案為C，將①成熟因素、②測驗效應及③選擇性偏誤列為可能問題，故選C。本題是自願報名者的單組前後測前實驗設計，缺乏對照組，半年間的自然成長可能形成①；重複接受相同測驗可能形成②。至於③，自願報名會使樣本代表性受限，若教材廣義稱為選擇性偏誤，可依官方分類納入；但非隨機抽樣不等於非隨機分派，也不能單憑自選樣本解釋同一組的前後改變。題幹未顯示依極端前測分數選入，④迴歸因素證據不足。

A：A納入①②，兩者確是單組前後測可能面臨的威脅，但依官方分類遺漏③。

B：B納入③④，遺漏①②，且題幹沒有依極端分數選樣的資訊，不能納入④。

D：D把①②③④全數納入，但④欠缺極端分數選樣的前提。

本題考點：單組前後測（one-group pretest-posttest design）屬前實驗設計；成熟與測驗效應會威脅前後差異的因果解釋，隨機抽樣與隨機分派須分別辨識。

第 17 題

下列對「參與式行動研究（participatory action research）」敘述，何者正確﹖
  1. （A）它是種基於菁英主義模型下的研究傳統
  2. （B）它反對把研究主體化約成客體，認為研究者與被研究者之間的區隔應該要消除
  3. （C）它認為研究的功能主要在生產有效的科學知識
  4. （D）它倡議掌握資訊與權力的研究者要更有意識的引導研究進行

答案：（B）

詳解與考點

正解：參與式行動研究（participatory action research, PAR）主張研究不應是研究者單方面對「被研究對象」進行觀察、分析的過程，而應讓被研究者也成為研究的共同參與者、共同決定研究問題與行動方向，藉此消弭傳統研究中「研究者（主體）／被研究者（客體）」的位階區隔，達到賦權（empowerment）與社會改變的目的，故B正確。

A：PAR的知識論立場恰與菁英主義相反——它批判傳統研究由少數專家（菁英）主導、決定研究議程與詮釋權的模式，主張讓在地、基層的被研究者也擁有參與研究、共同建構知識的權力，故A所述「基於菁英主義模型」與PAR精神相反，是誘答。

C：PAR固然也產出知識，但其核心目的並非單純為了生產「有效的科學知識」本身，而是透過研究過程本身促成參與者的覺醒、增能與集體行動、進而改變不公平的處境；若僅以「生產科學知識」界定其功能，會忽略PAR強調行動與社會改變的實踐取向，故C不夠精準，為誘答。

D：D所述「掌握資訊與權力的研究者更有意識地引導研究進行」，仍然預設研究者居於主導、掌控地位，這與PAR強調研究者和被研究者權力共享、共同決定研究方向的精神相違背，是把傳統專家主導模式誤植為PAR特徵的誘答。

本題考點：參與式行動研究（Participatory Action Research, PAR），強調研究者與被研究者共同參與研究設計、執行與行動的研究取向，目的在消弭研究者與被研究者間的權力位階、促成賦權與社會改變；與傳統菁英式、專家主導研究典範的對照，是本題辨析的核心。

第 18 題

調查研究中，當面訪問、電話訪問、郵寄問卷與線上調查（網路填答）的優缺點，下列敘述何者錯誤？
  1. （A）當面訪問，受訪者會比較配合，回收率高，也比較不會出現社會期望性的答案
  2. （B）電話訪問問卷完成速度快，但受詐騙電話肆虐的影響，拒訪率高
  3. （C）郵寄問卷成本低，但回收率低，也無法確定是否由他人代填問卷
  4. （D）線上調查的缺點是較難確保樣本的代表性

答案：（A）

詳解與考點

正解：當面訪問（面對面訪談）確實因訪員在場督促、建立關係而使受訪者較為配合、回收率較高，但正因為是面對面互動，受訪者反而「較容易」因顧慮訪員觀感、想表現出符合社會期待的形象，而出現社會期望性偏誤（social desirability bias），並非「比較不會出現」；A把面對面訪談與社會期望效應的關係說反了，故A錯誤，為本題答案。

B：電話訪問確實具有完成速度快的優點，但近年受詐騙電話氾濫影響，民眾對不明來電戒心提高，導致電話訪問的拒訪率明顯上升，敘述正確。

C：郵寄問卷免除訪員人事成本，成本較低，但因缺乏訪員督促與提醒，回收率通常偏低，且問卷可能經由填答者以外的人（如家人）代為填寫，難以掌握實際填答者身分，敘述正確。

D：線上調查（網路填答）受限於受訪者是否具備網路使用能力與意願，容易產生自我選擇偏誤，導致樣本結構偏向特定族群（如較年輕、較常使用網路者），難以確保樣本對母群體的代表性，敘述正確。

本題考點：調查研究方法的優缺點比較，社會期望性偏誤（social desirability bias）在面對面訪談中反而較容易出現而非較不易出現；四種調查方式（面訪、電訪、郵寄、網路）在回收率、成本、代填風險、樣本代表性等面向的取捨，是研究方法選擇的常見考點。

第 19 題

下列對「內容分析（content analysis）」的敘述，何者正確﹖
  1. （A）它並不適用於誰向誰說了什麼、為何說、如何說、產生什麼效果的傳播研究
  2. （B）為了編碼具有信度，它重視溝通中隱性的內容（latent content）
  3. （C）內容分析可以是計量的，也可以是計質的研究
  4. （D）為了編碼具有效度，內容分析的缺點在不易重複再做一次

答案：（C）

詳解與考點

正解：內容分析（content analysis）是一種對文本、影像或傳播內容進行系統性分析的研究方法，其分析取向可以是計量的（如統計特定詞彙、主題出現的次數），也可以是計質的（如詮釋文本的深層意涵與脈絡），兩種取向並不互斥，故本題選C。

A：內容分析正是傳播研究的重要工具，可用以分析「誰向誰說了什麼、為何說、如何說、產生什麼效果」等議題，此敘述稱其不適用是錯誤的。

B：內容分析為求編碼具有信度（不同編碼者對同一文本的判讀結果一致），通常著重可觀察、可明確辨識的顯性內容（manifest content），而非需要高度主觀推論的隱性內容（latent content），隱性內容的編碼較難達到一致性，此敘述方向相反，是錯誤的。

D：內容分析的優點之一正是「可重複性」——只要編碼規則明確，不同研究者或同一研究者在不同時間都能依循相同的編碼類目重新分析同一批文本，以檢驗信度；此選項卻把「可重複」說成缺點且「不易重複再做一次」，與內容分析的實際特性相反，是錯誤的。

本題考點：內容分析（content analysis）的計量與計質雙重取向；顯性內容（manifest content）與隱性內容（latent content）的區分；編碼信度與方法可重複性的關係。

第 20 題

下列對焦點團體（focus group）的敘述，何者正確﹖
  1. （A）參與焦點團體的成員，可以依據討論主題的關聯性，以立意抽樣方式選出
  2. （B）考量資料信度，焦點團體蒐集資料的次數以一次為佳
  3. （C）焦點團體所蒐集的資料，因為人多而具有系統性，不易受到參與者偏誤影響
  4. （D）考量資料效度，焦點團體蒐集資料的次數以一次為佳

答案：（A）

詳解與考點

正解：焦點團體法之成員招募，通常依研究主題選取具相關經驗或背景之成員，屬立意抽樣的一種，以確保參與者的意見與討論主題具高度關聯性、能產出有意義的資料，故本題選 A。

B、D：兩者皆主張焦點團體蒐集資料以「一次為佳」，只是分別掛上信度（B）與效度（D）的說法，但無論從何種角度，焦點團體法通常需要進行多場次，才能觀察意見是否重複出現、達到資料飽和，並藉由跨場次比對降低單一團體動力或特定成員意見過度主導的影響；只做一次容易讓結果受該場特定成員互動影響而失去代表性，B、D皆錯誤。

C：焦點團體人數雖較個別訪談多，但也正因為是團體互動情境，容易產生從眾效應、意見領袖主導討論、社會期許等團體動力偏誤，參與者彼此互相影響、未必能各自獨立表達意見，因此焦點團體資料反而較容易受參與者偏誤與團體動力影響，並非「因為人多而具系統性、不受偏誤影響」，C 的敘述倒果為因，故錯誤。

本題考點：焦點團體法（Focus Group），質性研究蒐集資料方法之一，成員多以立意抽樣依主題相關性選取；資料飽和（Data Saturation），指持續蒐集資料直到不再出現新的重要訊息，通常需要多場次焦點團體或訪談方能達成；團體動力偏誤，指焦點團體因成員互動可能產生從眾、意見領袖主導等影響資料品質的效應。

第 21 題

某位採用質性觀察的研究者，坐在校園操場邊，觀察學生下課時的互動。此時，他採取的研究角色是﹕
  1. （A）完全參與者
  2. （B）觀察參與者
  3. （C）參與觀察者
  4. （D）完全觀察者

答案：（D）

詳解與考點

正解：本題描述研究者「坐在操場邊觀察」學生下課互動，未涉入學生的互動歷程，也未表明身分與學生產生互動關係，這種只做觀察、完全不參與研究情境的角色，即為完全觀察者（complete observer），故選D。完全觀察者的特徵在於研究者僅以旁觀者身分蒐集資料，盡量不影響或介入被觀察者的自然行為。

A：完全參與者（complete participant）是指研究者隱藏其研究者身分，實際融入並參與觀察對象的生活或互動之中，讓對方誤以為其僅是普通成員；本題研究者僅在操場邊觀察、並未真正參與學生互動，不符合此一角色。

B：觀察參與者（observer-as-participant）是研究者公開表明研究者身分、以參與者角色出現在情境中，但參與程度較低、以觀察蒐集資料為主要目的；本題研究者並未進入學生的活動或表明參與身分，僅止於旁觀，更接近完全觀察，而非此一角色。

C：參與觀察者（participant-as-observer）是研究者實質參與研究對象的日常生活或活動、同時公開研究者身分並蒐集資料，參與程度高於觀察參與者；本題研究者完全未參與學生的下課互動，不符合此一角色的參與特徵。

本題考點：Gold（1958）觀察者角色連續體（complete participant、participant-as-observer、observer-as-participant、complete observer），依研究者「參與程度」與「身分公開與否」區分四種質性觀察角色。

第 22 題

下列「需求評估（needs assessment）」方法的組合，何者正確？①調查關鍵資訊提供者 ②舉行社區論壇  ③檢視接受處遇者比例 ④分析社會指標 ⑤進行社區或目標團體調查
  1. （A）①②③
  2. （B）①②④
  3. （C）①②③④
  4. （D）①②③④⑤

答案：（D）

詳解與考點

正解：本題①～⑤分別對應需求評估（needs assessment）的五種常見取向。①關鍵資訊提供者法（key informant approach），以熟悉社區的人士（如專業人員、機構主管）提供意見評估需求；②社區論壇法（community forum approach），透過公開會議廣泛蒐集居民意見；③檢視接受處遇者比例（rates-under-treatment approach），分析既有服務使用者占率以推估潛在未滿足需求；④社會指標分析（social indicators approach），運用人口、經濟、健康等次級統計資料推估需求；⑤社區或目標團體調查（community survey approach），直接對居民或目標對象進行問卷或訪談調查。這五種方法在需求評估文獻中並列且性質互補，皆屬正當合理的評估途徑，並無互斥或錯誤之處，故五項全部正確，選 D。

A：①②③僅列出關鍵資訊提供者、社區論壇與接受處遇者比例三種，漏列了④社會指標分析與⑤社區或目標團體調查，這兩者同樣是正當的需求評估方法，不應被排除，故 A 不完整。

B：①②④僅列出關鍵資訊提供者、社區論壇與社會指標分析，漏列了③檢視接受處遇者比例與⑤社區或目標團體調查，同樣是可用的需求評估方法，不應被排除，故 B 不完整。

C：①②③④僅漏列⑤社區或目標團體調查，這是需求評估中最直接蒐集第一手意見的方法之一，同樣應納入，故 C 仍不完整。

本題考點：需求評估五種取向（Five Approaches to Needs Assessment），涵蓋關鍵資訊提供者法、社區論壇法、接受處遇率法、社會指標法與社區調查法，是社會工作規劃方案前評估社區需求的常用架構。

第 23 題

下列對「演繹法（deduction）」的敘述，何者正確？
  1. （A）它是種從普遍性推論到特殊結論的邏輯模型
  2. （B）它是種從個別觀察衍生到普遍結論的過程
  3. （C）多數質化研究偏向採用它
  4. （D）紮根理論（grounded theory）就是這種方法的應用

答案：（A）

詳解與考點

正解：本題問對演繹法（deduction）敘述何者正確，答案為 A。演繹法是一種從普遍性原理或既有理論出發，推導出特殊、具體結論的邏輯推理模型，研究者通常先建立理論假設，再蒐集資料加以檢驗，此即「由一般到特殊」的推論方向，A 正確描述此邏輯過程，故選 A。

B：從個別觀察衍生到普遍結論的過程，描述的是歸納法（induction）而非演繹法，兩者推論方向相反，是本題最容易與正解混淆的誘答。

C：多數質化研究偏向採用歸納法而非演繹法，質化研究常從個案或現象的深入觀察中逐步發展概念與理論，此敘述誤將歸納法取向的特徵套用於演繹法之上。

D：紮根理論（grounded theory）是一種由資料出發、逐步發展並驗證理論的歸納取向研究方法，而非演繹法的應用；此選項延續 C 的誤解，將典型歸納法的代表方法錯置為演繹法的例子。

本題考點：演繹法（deduction）與歸納法（induction）的區分，演繹是由普遍理論推導特殊結論，歸納是由個別觀察歸結普遍原則；紮根理論（grounded theory）作為歸納取向質化研究方法的代表，是本題對照演繹法的重要參照概念。

第 24 題

某位慣用家庭溝通動態分析並解釋問題的社工，容易留意家庭中潛在的溝通問題，並放大其對整體事件的影響力。請問他犯了下列何種錯誤？
  1. （A）稻草人論證（straw person）
  2. （B）選擇性觀察（selective observation）
  3. （C）人身攻擊（ad hominem attack）
  4. （D）事後假設（ex post facto hypothesizing）

答案：（B）

詳解與考點

正解：題幹描述社工因習慣以家庭溝通動態的框架分析問題，導致其特別容易注意到、也特別放大符合此框架的線索（即家庭中的溝通問題），而忽略或低估其他可能同樣重要的因素，這正是「選擇性觀察」（selective observation）的典型表現——研究者或實務工作者傾向注意、記住並強調與自己既有理論或期待相符的訊息，而對不一致的訊息視而不見，故選B。

A：稻草人論證是指刻意曲解或簡化對方的論點、再針對這個被扭曲的版本加以攻擊反駁的謬誤，題幹並未涉及對他人論點的曲解與反駁，與此不符，故不選。

C：人身攻擊是指以攻擊對方的人格、身分等與論點本身無關的因素來反駁其主張，題幹情境並非針對特定人物的攻擊性論辯，與此無關，故不選。

D：事後假設是指在觀察到結果之後，才回過頭去建構一個看似合理的解釋或假設，藉此「事後」為已發生的結果找理由，題幹描述的是社工在分析過程中持續、系統性地放大特定類型線索的偏誤，重點在於觀察的選擇性而非事後編造假設，兩者性質不同，故不選。

本題考點：選擇性觀察（selective observation），指因既有理論框架或預期心理，使觀察者偏好注意、記憶並放大與其框架相符的資訊而忽略不符資訊的推理謬誤；此為社會工作研究方法中常考的科學推理謬誤類型之一，需與稻草人論證、人身攻擊、事後假設等其他謬誤類型區辨。

第 25 題

某社會工作研究者想了解安置兒童返家後的適應，包括安置經驗對他的影響、親子關係的重建、對生活環境變化的適應等，以對兒童安置處遇提出建議。此研究較適合採用的典範是：
  1. （A）實證主義（positivism）
  2. （B）解析主義（interpretivism）
  3. （C）批判主義（criticism）
  4. （D）絕對主義（absolutism）

答案：（B）

詳解與考點

正解：本題研究目的是深入理解安置兒童返家後的主觀經驗，包括安置經驗對其自身的意義、親子關係如何重新建立、如何適應生活環境的變化，這些都是重視當事人主觀詮釋、脈絡意義與歷程理解的探究取向，符合解釋主義（interpretivism，又譯詮釋主義）強調「理解行動者賦予其經驗的意義」的典範精神，故本題選 B。

A：實證主義（positivism）強調以客觀、可量化的方式測量變項間的因果關係，並追求可複製、可通則化的規律，較適合驗證假設或比較群體差異，而非深入理解單一個案返家適應的主觀歷程與意義，與題目探究目的不符。

C：批判主義（criticism，即批判理論取向）關注的是社會結構中的權力、壓迫與不平等，研究目的通常是揭露宰制關係並促成解放與社會變革，題幹雖涉及安置兒童的處境，但其研究焦點在個人適應與關係重建的意義理解，而非批判社會結構或權力壓迫，故不符合。

D：「絕對主義」（absolutism）並非社會科學研究方法中常見的典範分類，題目所列四個典範中，除實證主義、解釋主義、批判主義為公認的三大研究典範外，此選項屬非標準分類的誘答。

本題考點：研究典範（Research Paradigm）的選擇，依研究目的（測量因果 vs. 理解意義 vs. 揭露權力關係）決定採用實證主義、解釋主義或批判主義；解釋主義（Interpretivism）強調透過質性方法理解行動者主觀賦予經驗的意義，適用於探究個人生命歷程與適應經驗的研究設計。

第 26 題

下列關於質化研究與量化研究的敘述，何者正確？
  1. （A）質化是演繹的邏輯；量化是歸納的邏輯
  2. （B）質化方法常用於解釋性研究；量化方法則較常用於探索性研究
  3. （C）兩種研究方法都是有系統和可驗證的
  4. （D）兩種研究方法都強調儘可能的隨機抽樣

答案：（C）

詳解與考點

正解：質化研究與量化研究雖然在資料蒐集方式、邏輯取向與適用情境上有所不同，但兩者都是講求方法系統性、且研究過程與結論都能被檢驗的科學研究方法，質化研究同樣要求嚴謹的資料蒐集程序（如三角檢證、厚實描述）以確保可信賴度，量化研究則以統計方法檢驗假設，兩者在系統性與可驗證性這兩個科學方法的基本要求上是一致的，因此本題選C。

A：邏輯取向的敘述剛好說反了，量化研究通常採取演繹邏輯，先由理論建立假設，再蒐集資料加以檢驗；質化研究則多採取歸納邏輯，先蒐集資料，再從資料中歸納、發展概念與理論，與A選項所述方向恰好相反。

B：適用情境的敘述也剛好說反了，質化方法因能深入探索現象的意義與脈絡，常用於理論尚未成熟、需要先行摸索方向的探索性研究；量化方法則需要在變項與假設已相對明確的情況下，透過統計檢驗因果或相關關係，較常用於驗證既有理論的解釋性研究，與B選項所述方向恰好相反。

D：隨機抽樣主要是量化研究為求樣本代表性、以便將結果推論至母體所強調的抽樣原則；質化研究著重的通常是能提供豐富資訊的立意抽樣或理論抽樣，目的在深入了解特定現象或個案，而非追求樣本代表性與推論母體，因此並非兩種研究方法都強調隨機抽樣。

本題考點：質化研究與量化研究的邏輯取向（量化偏演繹、質化偏歸納）與適用情境（量化偏解釋性、質化偏探索性）之對比；抽樣方法的差異，量化研究重隨機抽樣以求代表性，質化研究則多採立意或理論抽樣以求資訊深度；兩者共通點在於都要求方法的系統性與可驗證性，是本題判斷正確敘述的關鍵。

第 27 題

某研究發現，新住民子女發展遲緩的比例較非新住民子女高，但是加入另一個變項「家庭社經地位」之後，差異就不顯著了。下列關於三個變項的敘述，何者錯誤？
  1. （A）「新住民子女」與「發展遲緩」兩個變項是虛假關係
  2. （B）「家庭社經地位」是中介變項，透過它的作用，「新住民子女」才會對「發展遲緩」產生作用
  3. （C）新住民子女之所以呈現較高比例發展遲緩，是因為他們有較高比例家庭社經地位較低
  4. （D）「家庭社經地位」變項與「新住民子女」、「發展遲緩」兩個變項相關

答案：（B）

詳解與考點

正解：本題問何者錯誤。依題目欲考的第三變項判準，加入「家庭社經地位」後，「新住民子女」與「發展遲緩」的差異不再顯著，原關聯被解讀為由第三變項造成的虛假關係；B卻把家庭社經地位標示為中介變項，與題設分類不符，故選B。僅憑控制後不顯著，尚不能證明三變項的時間順序或因果方向，不能斷言新住民身分不會影響家庭社經地位，或已證實特定因果模型。

A：依題設的第三變項解讀，原關聯屬虛假關係，故此敘述正確，非答案。

C：依題設解讀，新住民子女呈現較高比例發展遲緩，是因其家庭社經地位分布不同；此敘述符合題目預設，但相關資料本身不等於因果證明。

D：依題設模型，家庭社經地位與「新住民子女」及「發展遲緩」皆有關聯，故非答案。

本題考點：虛假關係（spurious relationship）與中介變項的分類；控制第三變項後關聯消失是模型線索，但不能單靠此結果確定因果方向。

第 28 題

女性有沒有比男性更熱心從事志願服務？一位研究者以戶籍資料抽樣，調查18 歲以上人口，發現女性每週擔任志工的平均時數顯著高於男性。本研究的自變項與依變項為何？
  1. （A）自變項為每週擔任志工時數；依變項為性別
  2. （B）自變項為女性；依變項為每週擔任志工時數
  3. （C）自變項為性別是否有影響；依變項為每週擔任志工時數
  4. （D）自變項為性別；依變項為每週擔任志工時數

答案：（D）

詳解與考點

正解：本題研究問「性別是否影響志工時數」，依戶籍抽樣調查18歲以上人口的每週志工時數。自變項（independent variable）是研究者認為可能造成差異的「原因」變項，此處為分類變項「性別」（男／女）；依變項（dependent variable）則是被預測、被解釋的「結果」變項，此處為連續變項「每週擔任志工的時數」。故正確敘述為：自變項為性別、依變項為每週擔任志工時數，選 D。

A：把自變項與依變項的角色顛倒——A 敘述將「每週擔任志工時數」設為自變項、「性別」設為依變項，等於倒果為因，與研究「性別是否造成時數差異」的邏輯方向相反，故錯誤。

B：把自變項寫成「女性」而非「性別」——性別是一個具有「男性／女性」兩個類別的變項，自變項應是整個分類變項本身，「女性」只是該變項底下的一個類別（組別），並非變項名稱，用詞不精確，故不能選。

C：把自變項寫成「性別是否有影響」——這是把研究假設（性別對志工時數是否有影響）誤當成自變項的名稱，自變項本身應是「性別」這個變項，而不是描述其效果有無的敘述句，混淆了「變項」與「研究問題」兩個層次，故不能選。

本題考點：自變項與依變項（independent variable versus dependent variable）的判定，指研究設計中「推測的原因」與「觀察的結果」兩類變項的區分；變項與類別的區分，即變項本身（如性別）與其下的類別值（如女性、男性）不可混為一談。

第 29 題

承上題，該研究最適合採用下列那個統計方法？
  1. （A）卡方檢定
  2. （B）獨立樣本t 檢定
  3. （C）雙因子變異數分析
  4. （D）邏輯斯迴歸分析

答案：（B）

詳解與考點

正解：承上題設計，自變項為性別（僅分兩組之類別變項），依變項為志工服務時數（連續變項），研究目的是比較男性與女性兩組在志工時數上的平均數是否有顯著差異；當自變項僅有兩組、依變項為連續變項時，比較兩組平均數差異的正確統計方法是獨立樣本t檢定（independent-samples t-test），故選B。

A：卡方檢定用於檢定兩個類別變項之間是否具有關聯，本題依變項志工時數是連續變項而非類別次數資料，不適用卡方檢定。

C：雙因子變異數分析適用於兩個以上類別自變項共同對一個連續依變項的效果分析（含主效果與交互作用），本題自變項僅有性別一個變項，並非兩個自變項的設計，若僅有一個兩組類別自變項，應以t檢定而非變異數分析（更非雙因子）處理。

D：邏輯斯迴歸分析適用於依變項是類別（尤其是二分類別）的情形，用以估計自變項對依變項發生機率的影響；本題依變項志工時數是連續變項，並非二分類別結果，不適用邏輯斯迴歸。

本題考點：獨立樣本t檢定（Independent-Samples t-test），用於檢定兩組（類別自變項僅兩組）在同一連續依變項上的平均數是否有顯著差異；統計方法選擇判準，須依自變項組數與尺度及依變項測量尺度，決定應採t檢定、卡方檢定、變異數分析或迴歸分析。

第 30 題

承第28 題，研究者之後又加入一個變數：年齡，分為老（65 歲以上）、中（36-64 歲）、青（35 歲以下）三組，發現在老年組裡女性每週擔任志工時數顯著高於男性，但是中年組和青年組裡男、女每週擔任志工時數並沒有顯著差異。這表示：
  1. （A）性別和志工服務有交互作用
  2. （B）年齡和志工服務有交互作用
  3. （C）性別和年齡有交互作用
  4. （D）性別、年齡和志工服務有交互作用

答案：（C）

詳解與考點

正解：官方答案為C。題述老年組中女性每週擔任志工時數顯著高於男性，而中年組與青年組沒有顯著性別差異，依題意呈現性別效果隨年齡組別而異的型態，因此選性別與年齡有交互作用的C。惟「一組顯著、其他組不顯著」不等於各組性別效果已有顯著差異；正式判定仍須檢驗性別×年齡交互作用項或相應的簡單效果差異。

A：交互作用描述兩個自變項如何共同影響依變項；A把性別與志工服務時數並列，混淆自變項與依變項。

B：B同樣把年齡與志工服務時數並列，未指出題意所要比較的性別與年齡兩個自變項。

D：D把依變項志工服務時數也列為交互作用的一方，不符合本題二因子關係的標準表述。

本題考點：交互作用（interaction effect）指一個自變項對依變項的效果隨另一自變項的水準而改變；分組內顯著性不同只是線索，不能取代交互作用項的正式檢定。

第 31 題

某研究者和小兒神經科醫生合作，想長年追蹤同一群亞斯伯格症患者在接受馬術訓練後社交技巧成效，他們適用：
  1. （A）橫斷性研究（cross sectional study）
  2. （B）世代研究（cohort study）
  3. （C）小樣本覆訪研究（panel study）
  4. （D）區位研究（ecological study）

答案：（C）

詳解與考點

正解：題幹強調研究者要「長年追蹤同一群」亞斯伯格症患者接受馬術訓練後的社交技巧成效，重點在於針對「同一批固定個案」進行多次、重複的測量與觀察，這正是小樣本覆訪研究（panel study）的定義特徵——固定樣本、長期反覆追蹤同一批受試者的變化，故本題選C。

A：橫斷性研究只在單一時間點對樣本蒐集一次資料，用以描繪某一時刻的現況，無法呈現同一群個案隨時間推移的變化，與題幹「長年追蹤」的設計要求不符。

B：世代研究是以具有共同出生年代、共同重大事件經驗或共同特徵的「世代群體」作為追蹤或比較對象，每次調查的樣本不必然是完全相同的個人，而題幹明確要求追蹤「同一群」患者、重複測量同一批個案，此與世代研究著重世代群體、樣本可替換的設計精神不完全相符，是本題最容易與正解混淆的誘答，因為兩者同屬縱貫性研究、都涉及長期追蹤。

D：區位研究是以群體、地區等聚合層次的單位作為分析對象，探討的是群體層次變項間的關係，而非針對個別患者進行追蹤，與題幹以個別患者為追蹤對象的設計不符。

本題考點：縱貫性研究設計（longitudinal design）中小樣本覆訪研究（panel study）與世代研究（cohort study）的區辨，前者固定追蹤同一批個案、後者追蹤具共同特徵的世代群體但樣本可能更替；橫斷性研究（cross-sectional study）與區位研究（ecological study）則分別以單一時間點與群體聚合層次為特徵，皆與長期追蹤同一批個案的設計不同。

第 32 題

研究新台灣之子的族群認同與其自我概念的關係，族群認同分成「父系認同」、「母系認同」、「雙族群認同」三種，自我概念為量表分數，分數越高代表自我概念越正向。此研究最適合採用：
  1. （A）卡方檢定
  2. （B）t 檢定
  3. （C）變異數分析
  4. （D）迴歸分析

答案：（C）

詳解與考點

正解：本題自變項為「族群認同」，分成父系認同、母系認同、雙族群認同三組，屬三組以上的類別（名義）變項；依變項是自我概念量表分數，屬連續變項。當自變項為三組以上類別變項、依變項為連續變項，且要檢定三組平均數是否有顯著差異時，應採用單因子變異數分析（one-way ANOVA），故選C。變異數分析藉由比較組間變異與組內變異計算F值，判斷三種族群認同型態的自我概念平均分數是否真的不同。

A：卡方檢定用於檢定兩個類別變項間是否獨立或有關聯，適用對象是次數（人數）資料；本題依變項是連續的量表分數，不是類別次數，不適用卡方檢定。

B：t檢定同樣是比較平均數的方法，但只能處理兩組比較；本題自變項有三組，若硬要兩兩進行三次t檢定，會使犯第一類型錯誤的機率隨比較次數累加、超出原訂顯著水準，統計上並不恰當，是本題最容易誤選的選項。

D：迴歸分析把三組族群認同轉換成虛擬變項（dummy variable）後，數學上與單因子變異數分析等價，但本題自變項只是單純三組類別變項、研究目的是直接比較三組平均數，並未涉及多個連續預測變項或需控制其他變項的情境，用變異數分析最直接對應題意，是四個選項中最適切的答案。

本題考點：單因子變異數分析（One-way ANOVA），比較三組以上類別自變項在同一連續依變項上平均數是否有顯著差異的統計方法；統計方法選擇判準，依「依變項測量尺度」與「自變項組數」決定該用卡方檢定、t檢定或變異數分析。

第 33 題

下列敘述何者正確？
  1. （A）要知道兩個變項是不是線性關係，最簡單方式是求其迴歸線
  2. （B）一般說來，我們可以使用同一個的迴歸方程式來以X 預測Y 或以Y 預測X
  3. （C）若兩變項間完全相關，則估計（以一個變項預測另一個變項）的標準誤為0
  4. （D）如果迴歸線平行於X 軸，則迴歸線的斜率等於1

答案：（C）

詳解與考點

正解：本題考相關與迴歸分析的基本性質。當兩變項間為完全相關（相關係數為正負1）時，所有觀察點都精確落在迴歸線上，以一個變項預測另一個變項完全沒有誤差，估計標準誤（standard error of estimate）因此等於0，故C正確。

A：判斷兩變項是否為線性關係，最簡單直接的方式是繪製散布圖觀察點的分布形態，而不是先求迴歸線；求迴歸線本身就預設了以直線模型配適資料，若資料實際上並非線性關係，強行配適迴歸線反而會誤導判斷，因此求迴歸線並非檢視線性關係最簡單的方式。

B：以X預測Y的迴歸方程式與以Y預測X的迴歸方程式一般而言並不相同——除非兩變項完全相關，否則兩條迴歸線的斜率與截距通常互異，因為兩者是分別以最小平方法個別針對不同依變項最小化誤差平方和所得，不能混用同一方程式，此為常見的混淆點。

D：迴歸線平行於X軸，代表依變項Y不隨自變項X改變而改變，也就是斜率為0，而非斜率等於1；斜率等於1的迴歸線是與X軸成45度角的直線，並非平行於X軸，此為數值記憶型誘答，須留意平行與斜率的正確對應關係。

本題考點：估計標準誤（Standard Error of Estimate），衡量以迴歸線預測依變項時的誤差程度，完全相關時降為0；迴歸方向性（regression of Y on X vs. X on Y），提醒兩變項互為預測時迴歸方程式一般不同；斜率與線形的幾何對應，是判讀迴歸線圖形常見的細節誘答。

第 34 題

下列有關眾數（mode）的敘述，何者正確﹖
  1. （A）它只適用於分析順序尺度的資料
  2. （B）它適用於分析類別、順序、等距、等比尺度的資料
  3. （C）它容易受到極端值（extreme value）影響
  4. （D）它屬於離散趨勢量數的一種

答案：（B）

詳解與考點

正解：眾數（mode）是資料中出現次數最多的數值，四種測量尺度（類別、順序、等距、等比）皆可計算眾數，因為眾數只需要能判斷「相同或不同」的類別劃分即可求得，不要求資料具有大小順序或等距特性，故眾數是適用範圍最廣的集中趨勢量數，B 敘述正確，應選 B。

A：眾數並非「只」適用於順序尺度，而是四種尺度皆可用，A 把適用範圍限縮在順序尺度，過於狹隘，錯誤。

C：眾數是依出現次數判定，不受數值大小影響，因此不會受極端值牽動而改變（易受極端值影響的是平均數），C 敘述錯誤。

D：眾數與平均數、中位數同屬集中趨勢量數（measure of central tendency），用以描述資料的集中位置，而非描述資料分散程度的離散趨勢量數（如全距、變異數、標準差），D 敘述錯誤。

本題考點：集中趨勢量數（measure of central tendency），眾數、中位數、平均數為其三大類型，各自適用不同測量尺度；眾數（mode）因不受尺度限制、不受極端值影響，是四種測量尺度皆可使用的集中趨勢指標。

第 35 題

下列對於實驗與準實驗設計中，內、外在效度的敘述，何者正確﹖
  1. （A）某依變項觀察到的作用的確是由自變項而非由其他因素所造成的程度，稱為內部效度
  2. （B）一項研究所描繪的因果關係在研究條件下可概化的程度，稱為內部效度
  3. （C）某依變項觀察到的作用的確是由自變項而非由其他因素所造成的程度，稱為外部效度
  4. （D）一項研究所描繪的因果關係在研究條件下不可概化的程度，稱為外部效度

答案：（A）

詳解與考點

正解：本題問實驗與準實驗設計中，內、外在效度的敘述何者正確。內在效度（internal validity）指的是，研究者能夠確認依變項觀察到的變化，的確是由自變項（處遇或介入）所造成，而非受到其他競爭因素（如成熟、歷史事件、選樣偏誤等）干擾所致的程度；A正是此一定義的正確敘述，故選 A。

B：B把「因果關係在研究條件下可概化的程度」稱為內部效度，但「可概化（推論到其他母體、情境、時間）的程度」其實是外在效度的定義，B把外在效度的定義誤植為內在效度。

C：C的敘述內容本身（依變項變化確為自變項所致的程度）正是內在效度的定義，卻標示為外部效度，同樣是把內在效度的定義誤植給外在效度，是與A內容相同、標籤相反的誘答。

D：外在效度應指因果關係「可以」概化到其他情境的程度，效度愈高、愈能推論到其他情境；D卻敘述成「不可概化的程度」，把外在效度的方向敘述反了。

本題考點：內在效度（Internal Validity），指依變項的變化確實由自變項造成、排除其他競爭解釋的程度；外在效度（External Validity），指研究所得因果關係能夠推論、概化至其他母體或情境的程度；兩者常以定義對調或方向顛倒的方式互為誘答。

第 36 題

類屬與其特質 ③撰寫理論 ④比較各事件在各類屬中的適合性
  1. （A）①②④③
  2. （B）④②①③
  3. （C）③①②④
  4. （D）②①④③

答案：（B）

詳解與考點

正解：紮根理論（grounded theory）持續比較法（constant comparative method）的分析歷程，依 Glaser 與 Strauss 提出的經典架構，其邏輯依序為：先比較各事件在各類屬中的適合性（④，透過反覆比較新出現的資料事件與既有類屬是否相符，逐步建立類屬）；接著整合類屬與其特質（②，將相關類屬加以整併並釐清各類屬的屬性內涵）；再限定（界定）理論（①，將分析範圍與理論架構收斂聚焦，減少不必要的類屬與細節）；最後才撰寫理論（③，將前述分析結果轉化為完整的理論陳述）。對應本題編號，正確順序即為④②①③，故本題選 B。此流程的核心精神是由資料出發、透過持續比較逐步建構理論，理論是分析末端的產物，而非分析的起點。

A：①②④③將「限定（界定）理論」排在最前面，等於尚未從資料中比較歸納出類屬與特質，就先收斂界定理論範圍，違反紮根理論由資料歸納而非由理論演繹出發的基本精神。

C：③①②④把「撰寫理論」排在最前面，等於分析尚未展開就先寫出理論陳述，完全顛倒了紮根理論先分析資料、後產出理論的邏輯順序。

D：②①④③先整合類屬與特質、再限定理論，卻把「比較各事件在各類屬中的適合性」排到第三步，等於類屬與其特質尚未經逐一比較各事件確立之前就先整合，違反持續比較法必須先比較事件、才能整合類屬的先後關係。

本題考點：紮根理論持續比較法（Constant Comparative Method, Glaser 與 Strauss）的分析步驟，依序為比較事件適合性、整合類屬與特質、限定（界定）理論、撰寫理論，強調理論是由資料持續比較歸納而來，而非預先設定後再套用資料。

第 37 題

某媒體對縣市長施政滿意度調查結果，甲縣長得76.3 分、乙縣長得73.9 分、丙縣長得70.7 分。若95%的信心水準下，抽樣誤差皆為正負2.5 分，則甲、乙、丙縣長的支持度為：
  1. （A）甲縣長＞乙縣長＞丙縣長
  2. （B）甲縣長、乙縣長＞丙縣長；甲、乙縣長沒有差異
  3. （C）甲縣長＞丙縣長；甲、乙縣長沒有差異，乙、丙縣長沒有差異
  4. （D）甲縣長、乙縣長、丙縣長都沒有差異

答案：（C）

詳解與考點

正解：官方答案為C。各估計值依抽樣誤差±2.5分形成的95%信賴區間為：甲76.3±2.5=73.8至78.8；乙73.9±2.5=71.4至76.4；丙70.7±2.5=68.2至73.2。依本題採用的區間重疊簡化判讀，甲與乙、乙與丙重疊，甲與丙不重疊，因此選C。惟兩個各自的95%信賴區間重疊時，估計值之差仍可能顯著；正式判定須知道估計值間的共變異，檢驗差值的標準誤或信賴區間，不能把區間重疊當成一般顯著性規則。

A：依題目簡化判讀，甲與乙的區間重疊，不能僅憑點估計排序成甲＞乙＞丙。

B：依同一簡化判讀，乙與丙的區間重疊，不會得到甲、乙皆高於丙。

D：依同一簡化判讀，甲與丙的區間不重疊，不會把三者全數判為沒有差異。

本題考點：95%信賴區間（confidence interval）呈現估計不確定性；兩估計值的正式比較應直接檢驗差值，而非只看個別信賴區間是否重疊。

第 38 題

當檢定統計量的P 值為小於預定的α值（α＝.05 2tail）時，下列關於此假設檢定的敘述，何者正確？①得以拒絕虛無假設 ②可能犯了第二類型錯誤 ③研究結論預定承擔至多5%的第一類型錯誤風險④統計考驗力為95%
  1. （A）①②
  2. （B）①③
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：p 值小於預定的 α 值（.05，雙尾），依統計假設檢定的判斷準則，即得以拒絕虛無假設（①正確）；而 α＝.05 本身即代表研究者事先設定「最多」承擔 5% 的機率犯下第一類型錯誤（Type I error，虛無假設為真卻錯誤地拒絕它），此為顯著水準的定義（③正確）。①③同時成立，故選 B。

A：組合為①②，②（可能犯了第二類型錯誤）有誤——第二類型錯誤是指虛無假設為假卻未能拒絕它，僅發生在「未拒絕虛無假設」的情境下；本題已因 p<α 而拒絕虛無假設，此時可能面對的是第一類型錯誤而非第二類型錯誤，故此組合不正確。

C：組合為②③，③為真，但②（可能犯了第二類型錯誤）有誤，理由同上——本題情境是拒絕虛無假設，第二類型錯誤在此不適用，故此組合不正確。

D：組合為③④，③為真，但④（統計考驗力為 95%）有誤——統計考驗力（1－β）取決於效果量、樣本數與 β 風險等因素，並非顯著水準 α 的互補值（1－α），不能僅因 α＝.05 就推論考驗力為 95%，故此組合不正確。

本題考點：假設檢定的兩類錯誤（Type I / Type II Error），第一類型錯誤是虛無假設為真卻拒絕它、其上限即顯著水準 α；統計考驗力（Statistical Power, 1－β），指虛無假設為假時正確拒絕它的機率，與 α 是彼此獨立的兩個統計量。

第 39 題

當社會工作研究者面臨接受服務的權利與評估服務效果義務的研究倫理兩難時，比較適切的作法是：
  1. （A）當遇到接受服務權利和評估服務效果義務的兩難時暫不處理
  2. （B）考量服務使用者接受服務的權利，拒絕進行新處遇方案評估工作
  3. （C）把接受新處遇案主的評估結果，和另組未接受新處遇案主的結果相比較
  4. （D）把接受新處遇案主的評估結果，和在新處遇出現前使用一般處遇案主的評估結果相比較

答案：（D）

詳解與考點

正解：本題的倫理兩難是兼顧案主接受服務的權利與評估服務效果的義務。D採歷史對照，將接受新處遇案主的結果與新處遇出現前接受一般處遇者的結果比較，既提供比較基準，也不必在研究期間為建立對照組而安排案主不接受新處遇，故選D。

A：「暫不處理」沒有解決兩難，也放棄評估方案效果的專業義務，故不適切。

B：直接拒絕評估新處遇，使方案成效無法檢驗，未兼顧評估義務。

C：以同時期未接受新處遇者作比較，若其未接受是研究安排所致，可能引發服務可近性與權利疑慮；但選項沒有交代該組是否符合資格、是否可取得服務或未接受原因，不能直接斷定研究者刻意剝奪服務。相較之下，D較能避開此潛在兩難。

本題考點：研究倫理兩難與歷史對照組；判斷同時期未處遇組的倫理性，須確認資格、服務可近性及未接受處遇的原因。

第 40 題

下列有關「效度（validity）」的敘述，何者正確﹖
  1. （A）研究者或其他專家對效度所作的客觀評估，稱為預測效度（predictive validity），它具有相當的說服力
  2. （B）內容效度（content validity）指在某個概念下所包含的諸多意義，其測量工具所能夠加以涵蓋的程度
  3. （C）研究法模擬考成績可以恰當反映日後社會工作師高等考試該科成績，表示其表面效度（face validity）好
  4. （D）在李克特量表（Likert scale）中Cronbach’s α值高表示量表中的校標關聯效度（criterion-related validity）高

答案：（B）

詳解與考點

正解：內容效度（content validity）係指測量工具能否涵蓋某一概念底下所包含的各項意義與面向的程度，也就是題項是否足以代表該概念的完整內容範疇，此為效度的正確定義，故選B。

A：研究者或專家對測量工具之判斷屬於內容效度或表面效度的評估方式（透過專家審查題項內容是否合宜），並非「預測效度」；預測效度是以測量分數與未來某一效標表現的相關程度來檢驗，本選項將專家主觀評估錯置為預測效度，是概念混淆的誘答。

C：研究法模擬考成績若能恰當反映日後高考該科成績，指的是模擬考分數與未來實際表現（效標）之間具有預測力，這屬於效標關聯效度中的預測效度，而非表面效度；表面效度僅指測量工具「看起來」是否像在測量該概念，與其能否實際預測未來表現無關，本選項屬效度類型錯置的誘答。

D：Cronbach's α係數是用來檢驗量表題項間內部一致性的信度指標，數值高代表題項測量結果穩定一致，屬於信度（reliability）而非效度；本選項將信度指標誤植為「校標關聯效度」，是信度與效度混淆的常見誘答。

本題考點：效度（validity）類型辨析，包括內容效度、表面效度、效標關聯效度（含預測效度、同時效度）之定義與差異；信度與效度之區分，Cronbach's α為內部一致性信度指標，不可與效標關聯效度混淆。
