第 1 題

Fiedler是領導理論中權變模式的先驅，下列何者不是Fiedler所認為的情境因素？
  1. （A）領導者的領導行為
  2. （B）領導者與成員間的關係
  3. （C）任務工作結構
  4. （D）職位的權力

答案：（A）

詳解與考點

正解：Fiedler權變領導理論主張，領導的有效性取決於「領導風格」與「情境有利程度」的配合，而情境有利程度由三項情境因素決定：領導者與部屬（成員）間的關係、任務結構、以及領導者的職位權力。「領導者的領導行為（領導風格，如任務取向或關係取向）」在此理論中是被評估、需與情境配合的「領導者變項」本身，並非用來描述情境好壞的情境因素，故A不屬於Fiedler所稱的情境因素，選A。

B：領導者與成員間的關係是Fiedler三項情境因素之一，指部屬對領導者的信任、尊重與支持程度，關係越好，情境越有利。

C：任務工作結構是Fiedler三項情境因素之一，指任務目標、程序與標準的明確程度，結構越清楚，情境越有利。

D：職位的權力是Fiedler三項情境因素之一，指領導者依職位所擁有的獎懲與指揮權力，權力越大，情境越有利。

本題考點：費德勒權變領導理論（Fiedler's Contingency Model），主張領導效能取決於領導風格與情境有利程度的配合，情境有利程度由領導者與成員關係、任務結構、職位權力三項情境因素構成。

第 2 題

彼得‧聖吉（Peter M. Senge）提出之學習型組織的五項要素，不包括下列何者？
  1. （A）建立知識分享
  2. （B）改進心智模式
  3. （C）建立共同願景
  4. （D）系統思考

答案：（A）

詳解與考點

正解：彼得‧聖吉（Peter M. Senge）提出學習型組織的五項修練分別為：自我超越（personal mastery）、改善心智模式（improving mental models）、建立共同願景（building shared vision）、團隊學習（team learning）、系統思考（systems thinking）。選項中的「建立知識分享」並非這五項修練之一，故本題選A（不包括）。

B、C、D：三者依序對應五項修練中的「改善心智模式」「建立共同願景」與「系統思考」，皆確實屬於聖吉所提出的五項修練，因此不是本題應選的答案；題目要找的是「不包括」的一項，只有A（建立知識分享）不在五項修練之列。

本題考點：彼得‧聖吉學習型組織理論（Learning Organization）的五項修練，即自我超越、改善心智模式、建立共同願景、團隊學習、系統思考，是組織管理考科的高頻經典考點。

第 3 題

隨著新管理主義的興起，社會服務已逐漸以「準市場（quasi-market）模式」取代傳統的供給模式，下列對於「準市場模式」的敘述，何者錯誤？
  1. （A）準市場模式之所以為「市場」，乃是因為較具競爭、獨立的服務，取代政府部門的直接供給
  2. （B）準市場模式之所以為「準」，乃是因為在許多面向並不同於傳統市場
  3. （C）準市場模式在供給面與傳統市場一樣，服務供給者之間存在著競爭，且為了獲取最大的利益
  4. （D）準市場模式在需求面向上往往不是直接表達，而是由第三者代理之

答案：（C）

詳解與考點

正解：本題要選出對準市場模式敘述「錯誤」者。準市場之所以稱為「準」而非純粹市場，正是因為它在供給面刻意保留了與傳統市場不同的特質：政府仍負責財源籌措與規範管制，服務供給者雖彼此競爭，但競爭的誘因未必是追求利潤最大化——許多供給者是非營利組織，其目的在提供優質服務、維持組織使命，而非單純逐利；C 敘述「服務供給者之間存在著競爭，且為了獲取最大的利益」，等於把準市場等同於追求利潤最大化的傳統市場，抹去了準市場與傳統市場的關鍵差異，故敘述錯誤，選 C。

A：準市場之所以為「市場」，確實是因為政府引入具競爭性、產權相對獨立的多元供給者，取代政府部門獨占式的直接供給，敘述正確。

B：準市場之所以稱「準」，正是因為它在多個面向不同於傳統市場，敘述正確，且與 C 的推理邏輯一致。

D：準市場在需求面的特色是使用者本身通常不直接以現金購買服務，而是由政府或專業人員代為評估需求、分配預算或購買服務，即需求由第三者代理表達，敘述正確。

本題考點：準市場（Quasi-market）理論，由 Le Grand 等學者提出，指政府在維持財源與管制角色下，於供給面引入競爭性多元供給者、需求面由第三者代理消費決策的社會服務供給模式；其與傳統市場的核心差異在供給者未必以利潤最大化為目的、需求端無法直接以價格機制表達偏好。

第 4 題

共享利益、公民參與促使最佳價值體制的興起，有關最佳價值的敘述，下列何者正確？①在合理的價格下有更佳的服務 ②給予地方政府更多的決定權 ③地方政府官員和員工有責任與義務傾聽地方的聲音 ④徵詢服務提供者的意見 ⑤重視績效指標的使用 ⑥新公共管理與地方和社區治理的折衷模式
  1. （A）①③⑤⑥
  2. （B）②③④⑤
  3. （C）①②③⑥
  4. （D）③④⑤⑥

答案：（A）

詳解與考點

正解：最佳價值（Best Value）是英國新工黨政府於 1999 年地方政府法（Local Government Act 1999）中，取代強制競爭性招標（CCT）後推動的地方治理改革，核心精神是共享利益與公民參與，並以「四 C」——挑戰、比較、諮詢、競爭——作為具體操作原則。①在合理的價格下有更佳的服務，正是最佳價值的核心定義：以整體生命週期成本與服務品質的最適組合來滿足使用者需求；③地方政府官員和員工有責任與義務傾聽地方的聲音，對應「諮詢」原則，要求地方政府向納稅人、服務使用者與社區廣泛徵詢意見；⑤重視績效指標的使用，對應最佳價值績效指標（Best Value Performance Indicators）制度，用以衡量與比較服務表現；⑥新公共管理與地方和社區治理的折衷模式，點出最佳價值一方面延續新公共管理重視效率與競爭的精神，一方面又強調地方與社區治理的參與色彩，是兩者的折衷體制。四者皆正確描述最佳價值的特性，故本題選 A（①③⑤⑥）。

B：B（②③④⑤）除③⑤正確外，另納入②④。最佳價值制度雖賦予地方政府一定的施政彈性，但同時搭配中央訂定的績效指標與稽核督導、必要時介入的機制，並非單純給予地方政府更多的決定權；而「諮詢」原則所徵詢的對象是納稅人、服務使用者與社區居民，而非④所述的服務提供者，故②④皆不成立，B 不能選。

C：C（①②③⑥）除①③⑥正確外，另納入②，同樣誤將最佳價值制度描述為單純擴大地方政府決定權，忽略中央績效監督的一面，故不能選。

D：D（③④⑤⑥）除③⑤⑥正確外，另納入④，將「諮詢」原則的對象誤植為服務提供者而非地方居民與服務使用者，故不能選。

本題考點：最佳價值制度（Best Value, 1999 年英國地方政府法），以挑戰、比較、諮詢、競爭四 C 為操作原則、取代強制競爭性招標的地方公共服務治理改革；最佳價值績效指標（Best Value Performance Indicators），用以衡量與比較地方公共服務表現的績效管理工具。

第 5 題

「70%的中輟生透過甲機構所提供之一系列體驗教育課程的學習，其自我效能感能提升40%，此將由一般性自我效能量表測量得知。」若以成效（effectiveness）導向撰寫構成要素來檢視，該方案目標（objective）缺乏下列那個要素？
  1. （A）欲達成的成果
  2. （B）時間架構
  3. （C）改變的標的
  4. （D）用以測量結果之判準

答案：（B）

詳解與考點

正解：撰寫成效導向（effectiveness-oriented）方案目標時，完整的敘述通常須包含改變的標的（誰、多少比例的對象）、欲達成的成果（產生何種具體改變及其幅度）、測量結果之判準（用什麼工具驗證改變），以及時間架構（在多久期限內達成）四大要素。題幹敘述「70%的中輟生……自我效能感能提升40%……由一般性自我效能量表測量得知」，已明確交代了標的對象、成果幅度與測量工具，卻完全沒有說明這樣的改變要在多長的方案期程或多久時間內達成，缺乏時間架構這項要素，故選B。

A：題幹「自我效能感能提升40%」即為欲達成的具體成果，已包含在敘述中，並非本題目標所缺乏的要素。

C：題幹「70%的中輟生」即已界定改變的標的對象與比例，並非本題目標所缺乏的要素。

D：題幹明確指出「將由一般性自我效能量表測量得知」，已說明用以測量結果的判準工具，並非本題目標所缺乏的要素。

本題考點：方案目標（Program Objective）之成效導向撰寫要素，須同時包含改變的標的、欲達成的成果、測量判準與時間架構四項，是方案評估（program evaluation）與方案設計中常考的目標撰寫規範。

第 6 題

在邏輯模式的方案規劃架構中，「服務對象的生活是否因提供服務而獲得改善？」此為下列那一個階段必須回答的問題？
  1. （A）輸入
  2. （B）過程
  3. （C）輸出
  4. （D）成果

答案：（D）

詳解與考點

正解：本題問的是邏輯模式（logic model）方案規劃架構中，「服務對象生活是否因提供服務而獲得改善」屬於哪一階段。邏輯模式將方案分為輸入（投入的資源，如人力、經費）、過程（將輸入轉化為服務的執行活動）、輸出（服務量化的產出，如服務人次、辦理場次）與成果（指服務對象因介入而產生的實際改變與生活品質提升）四個階段。「服務對象生活是否因服務而改善」問的正是介入所帶來的改變與效益，這正是成果階段要回答的核心問題，故選D。

A：輸入階段回答的是投入了哪些資源，例如經費、人力、設備等，並非詢問服務對象生活是否改善，故不選。

B：過程階段關注的是如何執行服務，即服務輸送的活動與程序本身是否落實，並非詢問服務對象最終的生活改變，故不選。

C：輸出階段回答的是做了多少，即服務的量化產出，例如服務人次、辦理場次等，僅反映服務的執行量，不涉及服務對象生活品質是否真正改善，是最容易與成果混淆的誘答——輸出常被誤以為就是績效，但輸出只是產出量而非改變本身，故不選。

本題考點：方案邏輯模式（Program Logic Model），將方案要素分為輸入、過程、輸出、成果四階段；輸出與成果的區辨（Output vs. Outcome），輸出是服務量化產出，成果則是服務對象實質改變與生活改善，是方案評估中最常考的核心概念。

第 7 題

由於方案評估所處理的議題可能影響到各種利害關係人，因此倫理議題的考量即顯得重要。下列對於方案評估倫理的敘述，何者錯誤？
  1. （A）方案評估應保障基本人權，因此一項完整的評估進行應更加重視同意、隱私及保密，以及與利害相關的風險等倫理議題
  2. （B）方案評估者常遇到的倫理困境之一是如何把評估的發現表達得清楚、完整與公正，因此需要了解不同方案關係人的需求，以避免做出過度窄化的評估結論
  3. （C）論及評估的效度倫理議題，只要方案評估者能選擇有效的標準化工具，即能避免倫理違悖議題
  4. （D）對於方案評估的倫理考量，除了需注意方案規劃的過程，亦需重視方案的執行過程是否可能發生負面作用

答案：（C）

詳解與考點

正解：本題為選錯誤的敘述。C稱「只要方案評估者能選擇有效的標準化工具，即能避免倫理違悖議題」，此敘述錯誤，因為評估工具的效度只是測量技術層次的問題，而方案評估倫理涉及的是同意、隱私、保密、公正報告、對利害關係人的影響等多重面向，即使工具再有效，若取得資料方式、資訊揭露、結論詮釋等環節處理不當，仍可能違反倫理；「工具有效即能避免倫理違悖」的推論過度簡化，故本題選C。

A：方案評估應保障基本人權、重視同意、隱私及保密與利害相關風險等，是評估倫理的核心要求，敘述正確，不當選。

B：評估者需正確、公正、完整呈現評估結果，並了解不同關係人需求以避免結論窄化，此為評估倫理常見困境之一，敘述正確，不當選。

D：評估倫理考量不僅止於方案規劃階段，也需注意執行過程可能產生的負面作用，敘述正確，不當選。

本題考點：方案評估倫理（Program Evaluation Ethics），指評估者於研究設計、資料蒐集、結果報告全程中對受評對象與利害關係人應盡的倫理責任，涵蓋知情同意、隱私保密、公正呈現與傷害風險評估等面向；效度與倫理的區別，指測量工具是否準確反映概念與整個評估過程是否符合倫理規範，是兩個不同層次的問題，不能互相取代。

第 8 題

透過有經驗的同仁或直屬主管進行工作的教導與指示，員工一邊聆聽，一邊從實務的操作中觀察與模仿，使受訓者逐漸能夠獨立執行工作，是屬於在職訓練中何種方法？
  1. （A）工作輪調
  2. （B）師徒制
  3. （C）教練法
  4. （D）行為示範

答案：（D）

詳解與考點

正解：D。題幹描述的訓練方式，核心機制是由資深同仁或直屬主管一邊教導、一邊示範操作，受訓者透過在旁聆聽、觀察與模仿，逐步累積技能到能獨立作業，這正是行為示範法（behavior modeling）的定義：讓受訓者觀看正確行為的具體示範，再透過模仿與反覆練習內化該行為模式，強調示範、觀察、模仿的學習歷程，故本題選D。

A：工作輪調是讓員工在不同職務或部門間定期輪換，目的在拓展員工對組織不同職能的認識、培養多職能人才，重點在「更換工作內容」，而非透過示範與模仿學習特定技能，與題幹描述的教導模式不同。

B：師徒制強調的是資深員工（師傅）與新進員工（徒弟）之間建立較長期、全面性的引導關係，內容除了工作技能，還常涵蓋組織文化認同、職涯發展建議等面向，關係的持續性與廣度是其特徵；題幹僅描述特定工作技能的教導與模仿，範圍較窄，且未提及長期關係配對，故不是最貼切的答案。

C：教練法通常指主管或教練針對員工實際工作表現，持續提供個別化的觀察、回饋與績效改善建議，重點在事後回饋、逐步調整的循環歷程，而非題幹所強調教導者示範動作、受訓者當場觀察模仿的即時學習模式。

本題考點：行為示範法（Behavior Modeling），一種透過觀看正確行為示範、再由受訓者模仿練習以習得工作技能的在職訓練方法；在職訓練（On-the-Job Training, OJT）方法的分類，需依教導者角色、學習機制、關係長短判斷屬於工作輪調、師徒制、教練法或行為示範何者。

第 9 題

志工人力資源的管理應把握相關的實施原則，其中「使每位志工都有發表意見及提出建議的機會和權利」，符合下列那種管理原則？
  1. （A）建立人事制度
  2. （B）建立回饋制度
  3. （C）鼓勵情感交流
  4. （D）重視訓練發展

答案：（B）

詳解與考點

正解：題幹描述「使每位志工都有發表意見及提出建議的機會和權利」，核心在於為志工建立一個由下而上表達心聲、意見得以被組織聽見並回應的管道，這正是志工人力資源管理中「建立回饋制度」的定義與功能，故選B。

A：建立人事制度指的是志工的招募、甄選、任用、考核、獎懲、離職等制度化措施，關注的是志工「進出與管理」的規則，而非讓志工發聲的管道，與題意不符。

C：鼓勵情感交流著重在增進志工彼此之間、以及志工與機構間的人際情感聯繫與歸屬感（如聯誼、慶生等活動），偏向社會性、情感面的連結，並非讓志工提出建議的正式溝通機制，容易因「交流」一詞被誤認為包含意見表達而誤選。

D：重視訓練發展指的是為志工規劃教育訓練課程、能力提升與生涯發展的安排，目的在提升志工的專業知能，與「發表意見及建議」的溝通管道無關。

本題考點：志工人力資源管理原則，其中回饋制度（feedback mechanism）指建立讓志工意見得以上達、組織給予回應的雙向溝通管道，是志工留任與士氣經營的重要一環。

第 10 題

社會工作者的工作充滿壓力，督導者必須協助工作者保持工作動力，這是屬於下列那種督導角色？
  1. （A）行政性督導
  2. （B）支持性督導
  3. （C）教育性督導
  4. （D）調解性督導

答案：（B）

詳解與考點

正解：Kadushin提出的督導三大功能中，支持性督導（supportive supervision）的核心任務在於協助社工紓解工作壓力、處理情緒耗竭與工作倦怠，並維持其工作動力與士氣；題幹「社會工作者的工作充滿壓力，督導者必須協助工作者保持工作動力」正對應此功能，故選B。

A：行政性督導（administrative supervision）著重的是工作分派、政策與程序的執行、服務品質的監督與管控，確保工作者依機構規定與流程完成任務，與題幹所述「處理壓力、維持工作動力」的情緒層面功能不同。

C：教育性督導（educational supervision）著重提升工作者的專業知識、技巧與能力，透過個案討論、案例教學等方式協助工作者成長，聚焦在「能力養成」而非「情緒支持與動力維持」，是常見的督導功能混淆選項。

D：調解性督導並非Kadushin督導三大功能（行政、教育、支持）中的標準分類，屬於本題的混淆選項，不對應題幹所述功能。

本題考點：Kadushin督導三大功能（Administrative, Educational, Supportive Supervision），行政性督導管理工作品質與流程、教育性督導提升專業知能、支持性督導處理情緒壓力並維繫工作動力，是社會工作督導理論的基礎架構。

第 11 題

管理是組織資源以完成工作的過程，若是強調「把事情做對（do the thing right）」係屬於管理概念中那項重要的要素？
  1. （A）資源
  2. （B）活動或過程
  3. （C）效率
  4. （D）效能

答案：（C）

詳解與考點

正解：「把事情做對（do the thing right）」講的是用既定方法、資源正確且不浪費地完成工作，這正是管理學中「效率（efficiency）」的定義——強調投入與產出的比率，以最少的資源、時間、成本達成既定的工作方式，故本題選 C。與之相對的「做對的事（do the right thing）」則是選擇正確的目標與方向，屬於效能（effectiveness）的範疇，兩者常被拿來對照命題。

A：資源（resources）指管理過程中被組織、運用的人力、經費、物力、資訊等投入項目，是管理的材料而非「做對」這個判準本身，敘述重點不在資源多寡，而在使用方式是否正確。

B：活動或過程（activity/process）泛指管理當中規劃、組織、領導、控制等一系列運作步驟，是管理的動作框架本身；題幹強調的是這些動作執行得對不對，而非活動或過程這個概念本身。

D：效能（effectiveness）指的是做對的事，也就是目標或方向的正確性；本題題幹強調的是把事情做對，即執行層面的正確與否，屬效率而非效能，兩者容易因中文語感相近而混淆，是本題最主要的誘答。

本題考點：效率（efficiency）與效能（effectiveness）的區辨，前者指以正確方式做事（do the thing right），著重投入產出比；後者指做正確的事（do the right thing），著重目標方向的正確性，是管理學基礎且常互相對照出題的概念。

第 12 題

衝突管理思想有不同的觀點，若認為衝突是無法避免，對團體是有助益且是必要的，最有效的方式是將衝突納入制度規範，建立完整的管理制度。係屬於下列那種觀點？
  1. （A）衝突的行為觀點
  2. （B）衝突的功能觀點
  3. （C）衝突的失能性觀點
  4. （D）衝突的人際觀點

答案：（B）

詳解與考點

正解：題幹描述的觀點認為衝突無法避免、對團體具有助益且是必要的，因此應將衝突納入制度規範、建立完整管理制度加以妥善運用，而非設法完全消除衝突；這正是衝突管理中的「功能觀點」（又稱互動觀點，interactionist view）的主張——適度衝突能刺激創新、促進團體活力與變革，管理者的任務不是消滅衝突，而是透過制度化的規範將衝突導向建設性結果，故本題選B。

A：「行為觀點」並非本題衝突理論分類中用以描述「衝突有益且應制度化管理」此一立場的標準用語，其強調重點與題幹「納入制度規範、視衝突為必要」的論述不符，屬混淆概念的誘答。

C：「失能性觀點」（傳統觀點）視衝突為組織運作不良、溝通失敗所產生的負面結果，主張應盡量避免或消除衝突，與題幹「衝突有助益且必要」的立場恰好相反，故不選。

D：「人際關係觀點」承認衝突是自然且難以避免的現象，傾向接受其存在；題幹所述功能觀點則進一步強調衝突的正面功能及制度化運用，故依題旨不選 D。

本題考點：衝突管理的三大理論觀點——傳統（失能性）觀點視衝突為有害、應消除；人際關係觀點視衝突為自然現象、應予接受；功能（互動）觀點則進一步主張適度衝突對團體具正面助益，應透過制度化管理善加運用，是本題辨析的核心架構。

第 13 題

定期檢討預算，在過程中進行修正與調整，以確保組織能達成年度目標。下列何者不是定期檢討預算之目的？
  1. （A）審慎預估未來可能的經費收入
  2. （B）檢討各項活動達成的進度
  3. （C）掌握支出的重點項目，並加強管理
  4. （D）比較實際數與預算數，評估績效表現

答案：（A）

詳解與考點

正解：本題選「非」定期檢討預算之目的者。「審慎預估未來可能的經費收入」屬於預算編製（budgeting）階段的工作——在年度開始前，依過去經驗與未來預期估算收入與支出，形成年度預算；而定期檢討預算則是在預算執行「過程中」，回頭檢視實際執行狀況並據以修正調整，兩者發生的時間點與功能不同，故A不屬於定期檢討預算之目的，選A。

B：檢討各項活動達成的進度，是定期檢討預算的核心目的之一——透過比對執行進度與預算期程，掌握方案是否如期推展，屬於定期檢討之目的。

C：掌握支出的重點項目並加強管理，是定期檢討預算藉由分析各項支出結構、辨識重大或異常支出項目、進而強化財務控管的目的，屬於定期檢討之目的。

D：比較實際數與預算數、評估績效表現，是預算執行控制中最基本的檢討方式，透過差異分析了解執行是否符合預期，屬於定期檢討之目的。

本題考點：預算管理（budget management）中「預算編製」（事前估算收支）與「預算執行控制／定期檢討」（事中監測、比較差異、調整修正）兩階段之區辨，是社會工作管理常考的財務管理概念。

第 14 題

在社工職場中管理者時常面臨倫理兩難問題，下列何者不是常見恪守倫理的原則？
  1. （A）對專業負責：對實務工作者及專業發展有所貢獻
  2. （B）對個案和重要他人負責：為案主系統與其利害關係人之長期福祉服務
  3. （C）對自己負責：包括真誠的舉止、追求知識與個人的成長
  4. （D）對社工人員之家庭負責：為社工人員家庭系統之關係負責

答案：（D）

詳解與考點

正解：社工管理者／督導所需恪守的倫理責任，常見架構包括對專業（貢獻於實務發展與同儕專業成長）、對個案與重要他人（服務對象系統及其利害關係人之長期福祉）、對自己（真誠舉止、持續追求知識與個人成長）三大面向，選項 A、B、C 分別對應這三類標準內容；「對社工人員之家庭負責」並非此一倫理責任架構中的既定類別，管理倫理處理的是管理者對專業社群、對服務對象、對自身操守的責任，並不涵蓋社工人員家庭系統的關係經營，因此本題選 D。

A：「對專業負責：對實務工作者及專業發展有所貢獻」是管理倫理責任架構中明確列出的一項，指管理者應致力於促進同仁專業成長與整體專業發展，屬於既有類別。

B：「對個案和重要他人負責：為案主系統與其利害關係人之長期福祉服務」同樣是既有類別，強調管理決策應以服務對象及其相關利害關係人的長期福祉為依歸。

C：「對自己負責：包括真誠的舉止、追求知識與個人的成長」也是既有類別，強調管理者本身的專業操守與持續學習，是自我要求的一環。

本題考點：社工管理／督導倫理責任架構，通常區分為對專業、對個案與重要他人、對自己（有時再加上對雇用機構、對社會）等面向；本題透過新增一個非既定類別（對社工人員家庭負責）的方式，測驗考生是否熟悉這套標準架構的既有範圍。

第 15 題

關於組織員工層級之工作內容及分類，下列敘述何者錯誤？
  1. （A）社工員與組員為基層員工，直接負責某項工作或任務
  2. （B）督導與組長為基層管理者，工作任務包含確保績效能達所定目標
  3. （C）主任與處長為中階管理者，領導與監督基層員工為工作內容之一
  4. （D）秘書長與執行長為高階管理者，工作任務含規劃組織長期方向

答案：（C）

詳解與考點

正解：組織管理層級一般分為基層員工（operatives）、基層管理者（first-line managers）、中階管理者（middle managers）與高階管理者（top managers）四層。中階管理者（如主任、處長）的核心工作在於承接高階管理者所訂定的政策與長期方向，將其轉化為具體的部門目標與計畫，並協調、督導基層管理者以確保各單位運作順暢，而主要不是直接領導與監督基層員工——直接督導基層員工、確保其工作績效達成所定目標，是基層管理者（督導、組長）的職責，而非中階管理者的主要工作內容。C將中階管理者的職責描述成偏向基層管理者的直接督導角色，配對不當，故本題選C為錯誤敘述。

A：社工員與組員屬直接執行第一線服務工作、不負督導管理職責的基層員工（operatives），直接負責某項具體工作或任務，此敘述正確，故不選。

B：督導與組長屬基層管理者（first-line managers），其工作任務正是直接督導基層員工的日常工作、確保績效達到組織所定目標，此敘述正確，故不選。

D：秘書長與執行長屬組織最高層級的高階管理者（top managers），其工作任務著重擬訂組織的使命、願景與長期發展方向，此敘述正確，故不選。

本題考點：組織管理層級架構——基層員工（operatives）、基層管理者（first-line managers）、中階管理者（middle managers）、高階管理者（top managers）四層分工；中階管理者的核心職能在承上啟下、督導基層管理者，依本題採用的標準分類，主要不是直接督導基層員工，是本題辨析重點。

第 16 題

增強理論認為人們的行為會因管理者使用的獎懲，使員工改變或調整自己的行為，下列關於增強理論的敘述何者錯誤？
  1. （A）當員工出現組織期望的行為時，管理者則給予加薪獎勵，為正向增強
  2. （B）當員工出現組織期望的行為時，管理者消除員工不渴望的報償，為負向增強
  3. （C）當員工出現組織不期望的行為，管理者給予員工渴望的報償，為消除
  4. （D）當員工出現組織不期望的行為，管理者給予員工不渴望的報償，為懲罰

答案：（C）

詳解與考點

正解：增強理論中的「消除」是指當員工出現組織不期望的行為時，管理者「停止給予」原本可能強化該行為的報償（即不再提供員工渴望的報償），使該不當行為因不再被強化而逐漸減少或消失。C敘述卻說「員工出現不期望行為時，管理者給予員工渴望的報償」，這等於在不當行為出現時反而給予獎勵，只會意外強化（正向增強）該不當行為，而非使其消除，此敘述與「消除」的定義相反，故本題選C為錯誤敘述。

A：員工出現組織期望行為時給予加薪獎勵，即透過給予渴望的報償以增加該期望行為再次出現的機率，正是正向增強的定義，此敘述正確。

B：員工出現組織期望行為時，管理者移除員工不渴望的報償（例如免除額外加班、解除某項限制），同樣是透過消除嫌惡刺激以增加期望行為出現的機率，屬於負向增強，此敘述正確。

D：員工出現組織不期望行為時，管理者給予員工不渴望的報償（如扣薪、申誡），是透過施加嫌惡後果以減少該不當行為再度發生，正是懲罰的定義，此敘述正確。

本題考點：增強理論四種行為改變類型——正向增強、負向增強、懲罰、消除，核心差異在於「增加或減少行為」與「給予或移除報償、嫌惡刺激」的組合，消除的關鍵是「停止給予」原有報償，而非「給予」渴望報償。

第 17 題

對機構而言，決策不僅會影響目標之達成、所採取之方案或策略，也會影響到組織員工之士氣，關於理性決策之限制，下列敘述何者錯誤？
  1. （A）此種決策方式不適用於較複雜問題的解決
  2. （B）管理者能力與時間有限
  3. （C）組織所面對之環境往往是多變的且不確定性高，組織難以掌握環境，因此不利最佳決策的產出
  4. （D）參與決策之管理者的偏好與價值觀不一，影響其決策之共識

答案：（A）

詳解與考點

正解：理性決策模式作為一種規範性（normative）決策理論，理論上並不預設「只適用於簡單問題、不適用於複雜問題」——它原則上企圖對所有問題窮盡蒐集資訊、比較所有可能方案、選出最適解；真正的限制在於「執行面」的落差：管理者能力與時間有限、環境多變不確定、參與者價值偏好不一，這些因素使複雜問題下更難達成理想理性，而非模式本身「不適用」複雜問題。A把「面對複雜問題時難以落實」誤述成「不適用於較複雜問題」，混淆了模式的適用範圍與其實踐困難，故A敘述錯誤，為本題答案。

B：管理者本身的認知能力與可運用時間有限，無法窮盡蒐集與分析所有資訊及方案，是理性決策模式常被批評的核心限制（即Herbert Simon所稱的有限理性 bounded rationality），敘述正確。

C：組織所處環境的多變與不確定性，使決策者難以掌握完整、準確的環境資訊，不利於達成理性決策模式所預設的最佳化結果，敘述正確。

D：參與決策的管理者彼此價值觀與偏好不一，會影響對「何謂最佳方案」的判斷共識，是理性決策模式在多人決策情境下的實際限制，敘述正確。

本題考點：理性決策模式（Rational Decision-Making Model）與有限理性（Bounded Rationality, Herbert Simon）——理性模式為追求最適解的規範性理想型，實務上受限於決策者能力與時間、環境不確定性、價值偏好分歧等因素，難以完全落實，而非模式本身排除複雜問題的適用。

第 18 題

關於策略性規劃與長期規劃之比較，下列敘述何者正確？
  1. （A）策略性規劃視未來為不可預期的
  2. （B）策略性規劃視規劃為週期性過程
  3. （C）策略性規劃假設目前的趨勢會持續下去
  4. （D）長期規劃對於未來，係考慮一連串的可能性，並強調評估現階段組織環境之後所制定的策略

答案：（A）

詳解與考點

正解：策略性規劃（strategic planning）與長期規劃（long-range planning）的根本差異在於對「未來可預測性」抱持不同假設。長期規劃假設環境穩定、目前趨勢會持續下去，故可依現有趨勢外推、訂定固定期程的目標與計畫；策略性規劃則假設環境快速變動、未來充滿不確定性與不可預期性，因此組織必須持續掃描外部環境、隨時評估情勢並彈性調整策略，而非僅依過去趨勢推估未來。A敘述「策略性規劃視未來為不可預期的」正符合策略性規劃對環境不確定性的基本假設，故為正解。

B：策略性規劃強調的是「持續性」的環境掃描與策略調整過程，而非固定週期（如每年一次）才進行的規劃活動；「規劃為週期性過程」恰是長期規劃的特徵——長期規劃通常按固定期程產出一份長程計畫書，此後直到下一週期才重新檢視，B將長期規劃的特徵誤植於策略性規劃，屬選項互換型的常見誘答。

C：「假設目前的趨勢會持續下去」正是長期規劃的核心假設——長期規劃立基於環境穩定、可用現有數據外推未來，才會依現有趨勢設定長程目標；策略性規劃則正相反，強調環境多變、不可只依現有趨勢推估，C同樣是把長期規劃的特徵誤植給策略性規劃。

D：「考慮一連串的可能性，並強調評估現階段組織環境之後所制定的策略」，描述的其實是策略性規劃的做法——策略性規劃因視未來不可預期，才需要持續評估組織所處環境、考量多種情境可能性以制定因應策略；長期規劃則傾向依單一趨勢外推，並不強調多重可能情境的評估，D把策略性規劃的特徵誤植給長期規劃，是本題四個選項中最容易與正解混淆之處，因其描述內容本身無誤、只是主詞對調。

本題考點：策略性規劃（Strategic Planning）與長期規劃（Long-Range Planning）之比較，前者假設環境不確定、需持續掃描評估並彈性調整策略；後者假設趨勢穩定延續、規劃多屬固定週期產出的計畫文件，此組概念常以「未來可預期性」與「規劃是否持續」為主要辨異軸線。

第 19 題

雙因子（激勵－保健）理論認為，若缺乏保健因子，員工會感到「有」不滿足，下列何者為保健因子？
  1. （A）工作條件
  2. （B）成就感
  3. （C）賞識
  4. （D）個人成長

答案：（A）

詳解與考點

正解：依赫茲伯格（Herzberg）雙因子理論，保健因子（hygiene factor）指工作外在環境相關的因素，其缺乏會使員工感到不滿足，但即使具備也不必然帶來滿足感，例如薪資、公司政策、工作條件、人際關係、督導方式等；選項中的「工作條件」正屬於工作外在環境因素，缺乏時會引發員工不滿足，故為保健因子，選A。

B：成就感是員工完成任務、克服挑戰後所獲得的內在心理滿足，屬於能帶來正向滿足感的激勵因子（motivator），並非保健因子。

C：賞識指他人對員工工作表現給予的肯定與讚賞，同屬工作內在的激勵因子，能提升工作滿足感，而非避免不滿足的保健因子。

D：個人成長涉及員工在職涯或能力上的發展機會，屬於能激發工作動機、帶來正向滿足的激勵因子，並非保健因子。

本題考點：雙因子理論／激勵保健理論（Herzberg's Two-Factor Theory），保健因子（如薪資、工作條件、政策、人際關係）缺乏會導致不滿足但無法帶來滿足，激勵因子（如成就感、賞識、成長、責任）才能真正提升工作滿足與動機，兩者性質與作用機轉不同，是本理論的核心辨析重點。

第 20 題

以成效（effectiveness）為導向的方案規劃與評估應包含一系列經過設計的步驟如下：①清楚了解所欲處理的問題 ②檢視選定的指標進行追蹤研究 ③評量服務對象接受服務時的問題類型與嚴重程度 ④評量服務對象離開服務時的問題類型與嚴重程度 ⑤提供相關的服務處置。其正確步驟順序為何？
  1. （A）①②③④⑤
  2. （B）③①②④⑤
  3. （C）①③⑤④②
  4. （D）②⑤④③①

答案：（C）

詳解與考點

正解：以成效為導向的方案規劃與評估，邏輯上須先界定問題、再測量起點狀態、接著提供服務處遇、然後測量終點狀態，最後才能檢視長期指標並追蹤成效，正確順序為：①清楚了解所欲處理的問題（界定問題）→③評量服務對象接受服務時的問題類型與嚴重程度（建立基準線）→⑤提供相關的服務處置（介入）→④評量服務對象離開服務時的問題類型與嚴重程度（評估介入後改變）→②檢視選定的指標進行追蹤研究（後續追蹤成效），即①③⑤④②，故本題選 C。

A：①②③④⑤將「檢視指標追蹤研究」（②）排在提供服務處置與離開時評量之前，等於尚未提供服務、也未評量介入後改變，就先做追蹤研究，因果順序顛倒。

B：③①②④⑤把①了解問題排在③評量問題狀況之後，且把②追蹤研究安排在④離開時評量、⑤提供服務之前，同樣是服務尚未提供、離開時狀況未評量前就先做追蹤研究，程序倒置。

D：②⑤④③①把②追蹤研究放在最前面、①了解問題放在最後，完全顛倒「先界定問題、後追蹤成效」的方案規劃邏輯。

本題考點：成效導向方案評估（outcome-oriented program evaluation）的核心流程——問題界定、基準線測量（pre-test）、介入處遇、成果測量（post-test）、後續追蹤（follow-up）——是方案評估設計由前而後的基本邏輯順序。

第 21 題

下列關於行政管理學派的敘述何者錯誤？
  1. （A）創始者為費堯
  2. （B）事權集中原則是該學派的管理原則之一
  3. （C）對於人性的假設為Y理論
  4. （D）組織需具備由最高到最低階層的鏈鎖關係

答案：（C）

詳解與考點

正解：行政管理學派（以費堯Fayol為代表）對人性的假設較接近X理論——認為人需要受到管理與監督控制才能有效工作，而非Y理論所主張「員工可自主自律、追求自我實現」。Y理論是後來人群關係／行為學派（如麥克葛瑞格McGregor）才提出的觀點，並非行政管理學派的立場，故C敘述有誤，本題選C。

本題考點：行政管理學派（Administrative Management School, Fayol）的十四點管理原則，包括事權集中、層級節制（鏈鎖原則）等；X理論與Y理論（McGregor）則是對人性的兩種管理假設，前者視人被動需受控管，後者視人主動可自我實現，用以對照不同管理學派對人性預設的差異。

第 22 題

有關新管理主義的崛起與發展，下列敘述何者正確？
  1. （A）傳統科學管理依舊盛行不衰
  2. （B）管理的議題著重於組織系統與個人目標的一致
  3. （C）人群關係模式仍處於盛行階段
  4. （D）管理的焦點在於責信與顧客滿意

答案：（D）

詳解與考點

正解：新管理主義（new managerialism）興起於對傳統科層／科學管理過度僵化、以及人群關係模式過度強調員工心理需求卻忽略組織績效與服務對象權益的反思，其核心精神在於引進企業化管理理念，強調責信（accountability）、績效衡量與顧客導向，要求組織對出資者、服務對象與社會大眾負起明確可課責的績效責任，故本題選D。

A：新管理主義正是對傳統科學管理（重視標準化流程、忽略人性與彈性）的反動與超越，若科學管理依舊盛行不衰，就不會有新管理主義興起的必要，此敘述與新管理主義興起的脈絡矛盾，錯誤。

B：新管理主義強調的是組織對外部利害關係人的責信與績效，而非單純著重組織系統與個人目標一致，此較接近傳統人群關係或組織行為理論的關切重點，與新管理主義的核心精神不符，錯誤。

C：人群關係模式盛行於科學管理之後、新管理主義興起之前的階段，新管理主義的出現正代表管理典範已轉移至責信與顧客導向，若人群關係模式仍處於盛行階段，即與新管理主義已經崛起的題幹前提矛盾，錯誤。

本題考點：新管理主義（New Managerialism）強調責信（accountability）與顧客滿意（customer satisfaction）的管理典範轉移，是相對於傳統科層／科學管理與人群關係模式的新興組織管理理論，常見於非營利組織與公部門管理的比較考題。

第 23 題

方案執行前所進行的評估方式，下列何者錯誤？
  1. （A）需求評量
  2. （B）投入評估
  3. （C）形成評估
  4. （D）可行性評估

答案：（C）

詳解與考點

正解：方案評估依實施時間點可分為執行前、執行中、執行後三階段。執行「前」的評估目的在確認方案有無必要、資源是否足夠、能否推行，包括需求評量（needs assessment，確認標的人口的問題與需求是否存在）、投入評估（input evaluation，檢視人力、經費、設備等資源是否到位）、可行性評估（feasibility evaluation，評估方案在現有條件下能否順利執行）。形成評估（formative evaluation）則是在方案「執行過程中」進行，目的是即時檢視執行狀況、提供回饋以改善方案運作，並非執行前的評估，故本題選 C。

A：需求評量在方案規劃前進行，用以確認標的族群是否確實存在該項需求，屬執行前評估，非本題答案。

B：投入評估檢視方案所需的人力、經費、設備等資源在執行前是否備妥，屬執行前評估，非本題答案。

D：可行性評估評估方案構想在現實條件（法規、資源、環境）下是否可行，屬執行前評估，非本題答案。

本題考點：方案評估依時間點分為執行前評估（需求評量、投入評估、可行性評估）、形成評估（過程評估，執行中進行）與總結評估（執行後，含效果評估、效率評估），是方案評估分類的基本架構。

第 24 題

方案係指不同於平日所執行工作的活動，但其又與日常作業有相似之處，下列有關方案管理與作業管理的敘述，何者正確？
  1. （A）兩者皆須規劃、執行與控制
  2. （B）兩者皆是達到目標即須停止
  3. （C）兩者皆是持續性的服務
  4. （D）兩者皆是由符合組織結構的功能性團體執行

答案：（A）

詳解與考點

正解：方案（program）與作業（operation）雖然性質不同——方案通常是為達成特定目標而設、有明確起訖時間的暫時性活動，作業則是機構日常持續運作的例行工作——但兩者在管理歷程上，都必須經過規劃（設定目標與執行方式）、執行（落實計畫內容）與控制（監督進度、檢核成效並適時修正）三個階段，這是方案管理與作業管理共同具備的管理循環，故本題選A。

B：「達到目標即須停止」是方案（有起訖點的暫時性活動）的特性，並非作業管理的特性——作業管理是機構為維持組織正常運作而持續進行的工作，並不會因某次目標達成就停止運作，故此敘述僅適用於方案、不適用於作業，兩者並非皆然。

C：「持續性的服務」恰好是作業管理的特性，而非方案的特性——方案本質上具有明確的起訖時間與階段性目標，達成後即結束，並非持續不斷進行，故此敘述僅適用於作業、不適用於方案，兩者並非皆然。

D：作業管理通常由機構既有、符合組織結構的功能性部門（如依專業分工設置的常設單位）執行；方案則常為特定目的而跨部門組成任務團隊或另設專案小組來推動，不一定符合既有的組織結構配置，故此敘述並非兩者皆然。

本題考點：方案管理（program management）與作業管理（operations management）的異同，共同點在於皆須經過規劃、執行、控制的管理歷程；差異則在於方案具暫時性、達標即停止，作業則具持續性、依常設組織結構運作。

第 25 題

影響評估是指方案結束後其所產生成效的延續性，若以失業者職業訓練方案為例，下列那種敘述較符合「影響評估」的概念？
  1. （A）預計招收50位學員
  2. （B）90%的學員可以透過訓練學到該職業所需的知識與技能
  3. （C）80%的學員完成訓練
  4. （D）70%找到工作的學員可以在6個月內仍被僱用

答案：（D）

詳解與考點

正解：影響評估（impact evaluation）關注方案結束後，其成效是否能延續、維持一段時間，而非僅止於方案進行中或結束當下的立即產出。以失業者職業訓練方案為例，「70% 找到工作的學員可以在 6 個月內仍被僱用」正是在追蹤方案結束後一段期間（6 個月）成效是否持續存在，符合影響評估關注「延續性」的定義，故本題選 D。

A：預計招收 50 位學員屬於方案規劃階段的投入（input）指標，僅設定招生目標，尚未涉及任何成效，與影響評估無關。

B：90% 學員透過訓練學到職業所需知識與技能，衡量的是訓練「當下」是否達成學習目標，屬方案的立即成果，並未涉及方案結束後成效是否持續，故非影響評估。

C：80% 學員完成訓練屬於方案執行的產出（output）指標，僅反映參與完成率，同樣未涉及成效的延續性。

本題考點：方案評估中投入、產出、成果、影響（input/output/outcome/impact）層次的區分；影響評估（impact evaluation），特指方案結束後一段期間，其效果是否仍維持或延續的評估層次，是方案評鑑常考的核心概念。

第 26 題

變化工作形式是常見的員工激勵方法之一，下列何者並非變化工作形式的方式？
  1. （A）工作擴大化
  2. （B）工作豐富化
  3. （C）參與決策
  4. （D）彈性工時制度

答案：（C）

詳解與考點

正解：本題問哪一項「並非」屬於「變化工作形式」這類員工激勵方法。工作擴大化（job enlargement）、工作豐富化（job enrichment）與彈性工時制度（flextime）三者，都是直接調整「工作本身的內容、範圍或時間安排」，屬於變化工作形式的具體作法；而C「參與決策」談的是讓員工在管理決策過程中擁有發言權與影響力，這是激勵理論中另一類「員工參與／授權」的激勵策略，並非透過改變工作內容或形式本身來達成激勵效果，兩者層次不同，故C並非變化工作形式的方式，選C。

A：工作擴大化——指增加員工工作的任務種類與範圍（水平擴展工作內容），屬直接改變工作內容形式的做法，非本題答案。

B：工作豐富化——指賦予員工更多工作自主性、責任與成就感（垂直深化工作內容），同樣屬於改變工作本身設計的做法，非本題答案。

D：彈性工時制度——指調整員工上下班時間的安排方式，讓員工在一定範圍內自主安排工作時間，屬改變工作「形式」（時間安排）的做法，非本題答案。

本題考點：員工激勵方法中的「變化工作形式」（Work Redesign），涵蓋工作擴大化（Job Enlargement）、工作豐富化（Job Enrichment）、彈性工時（Flextime）等直接調整工作內容與時間安排的做法；參與式決策（Participative Decision Making）則屬於另一類強調員工參與授權的激勵途徑，兩者常在題目中並列以測試考生的分類能力。

第 27 題

社會工作是一項高工作負荷與高壓力的行業，但是有些職業基本上就比其他職業更容易產生壓力，也就是說，這種壓力源與工作本身有關，這是屬於下列何種壓力源？
  1. （A）任務需求
  2. （B）角色需求
  3. （C）人際需求
  4. （D）物理環境需求

答案：（A）

詳解與考點

正解：本題所述「有些職業本質上就比其他職業更容易產生壓力」，其壓力來源是工作本身、職業性質所致，這正是組織行為壓力來源分類中的任務需求（task demands）：任務需求指與個人所擔任的工作本身有關的壓力因素，包括工作自主性、工作設計、工作條件，乃至職業種類本身固有的高壓性質（如社會工作因高負荷、高情緒勞動而屬於任務需求偏高的職業），故本題選 A。

B：角色需求指的是個人在組織中所擔任角色所產生的壓力，通常源於角色衝突（角色間要求互相矛盾）或角色模糊（角色期待不清楚），是角色層次的壓力，而非工作性質本身，與題幹「壓力源與工作本身有關」不同，屬易混淆之誘答。

C：人際需求指的是同事、主管、部屬等人際互動與人際關係所帶來的壓力，著眼於人的互動關係，而非工作或職業本身的性質，故不符題意。

D：物理環境需求指工作場所的物理條件（如噪音、擁擠、照明、溫度等環境因素）所形成的壓力，關注的是環境層面而非職業或工作本質，與題幹描述不符。

本題考點：組織行為學中的工作壓力來源分類（Job Stressors），常見區分為任務需求、角色需求、人際需求與物理環境需求四類；其中任務需求特指壓力源自工作或職業本身的性質，是本題辨識的核心概念。

第 28 題

有關危機管理的敘述，下列何者錯誤？
  1. （A）危機管理是對危機情境維持一種持續性、動態性之監控與管理過程
  2. （B）危機管理的目的在於第一時間點發揮緊急救難的功能
  3. （C）危機的預防階段首重於控制處理、轉危為安，立即啟動已建立的應變機制
  4. （D）危機具有複雜性、威脅性、緊迫性、衝突性與雙面效果性

答案：（C）

詳解與考點

正解：本題找出危機管理敘述中錯誤的一項。危機管理通常區分為預防（減緩）、準備、回應（處理）、復原等階段，其中「預防階段」的重點在於危機發生前的風險辨識、減少危機發生的可能性與建立應變機制、演練及訓練；而「控制處理、轉危為安、立即啟動已建立的應變機制」，指的是危機已經發生後、實際啟動先前建立好的應變計畫來處理危機的階段，屬於危機「回應／處理階段」的工作內容，而非「預防階段」。C敘述把回應階段的工作誤植為預防階段的首要重點，階段歸屬錯誤，故本題選C。

A：危機管理強調對危機情境進行持續性、動態性的監控與管理，而非危機發生當下才臨時介入，此為危機管理的基本特質，敘述正確。

B：危機管理的核心目的之一，正是在危機發生的第一時間，發揮緊急救難、控制危害擴大的功能，敘述正確。

D：危機同時具有複雜性（成因與影響因素交錯）、威脅性（對個人或組織造成損害）、緊迫性（須快速決策）、衝突性（利害關係人立場不一）與雙面效果性（危機中亦可能蘊含轉機），是危機管理教科書對「危機」特性的常見界定，敘述正確。

本題考點：危機管理（Crisis Management）的階段劃分，包括預防（準備）階段與回應（處理）階段的工作內容區辨；危機的特性（複雜性、威脅性、緊迫性、衝突性、雙面效果性），是社工管理考科常見的概念架構。

第 29 題

總結評估常常採取外部評估進行，下列何者為外部評估的優點？
  1. （A）與執行者接觸密切，易於掌握方案實施的內容
  2. （B）對方案易有全面性的掌握與了解
  3. （C）可減少方案執行者的心理防衛
  4. （D）有助於提升評估的可信度

答案：（D）

詳解與考點

正解：外部評估（external evaluation）由獨立於方案執行團隊之外的評估者進行，因評估者與方案執行者沒有利害關係、立場相對客觀中立，評估過程與結果較不易受人情、利益或組織內部壓力所干擾，因此最主要的優點是有助於提升評估的客觀性與可信度（credibility），故本題選 D。

A：「與執行者接觸密切、易於掌握方案實施內容」恰恰是內部評估（由方案內部人員自行評估）的優點——內部評估者因長期參與方案執行，對細節與脈絡掌握度高；外部評估者由於介入時間短、獨立於方案運作之外，反而在這方面不如內部評估者深入，此描述與外部評估的特性相反，是誘答。

B：「對方案易有全面性掌握與了解」同樣較貼近內部評估的優勢，因為內部人員長期身處方案脈絡中，對方案整體運作、歷史脈絡與細微環節的掌握通常優於短期介入的外部評估者；外部評估者反而需要額外投入時間才能建立對方案的全面理解，此項並非外部評估相對於內部評估的優勢。

C：「減少方案執行者的心理防衛」也偏向內部評估的優點——由於評估者是自己人、彼此熟悉信任，執行者較不易因評估而產生被檢視、被究責的防衛心理；外部評估者身分獨立、甚至可能帶有監督究責的意味，執行者面對外部評估者時心理防衛通常較高而非降低，此描述與外部評估的實際效果相反。

本題考點：外部評估（External Evaluation）與內部評估（Internal Evaluation）的優缺點對比——外部評估的核心優勢在客觀中立、提升評估可信度；內部評估的核心優勢在對方案脈絡與細節的熟悉度高、較不引發執行者防衛心理，是方案評估設計時的重要權衡考量。

第 30 題

全面品質管理動員組織內的員工，將服務朝向零缺點目標的理念，下列何者不是全面品質管理的實務策略？
  1. （A）為鼓勵變革、創新、以工作為榮，組織的高層主管需率先積極投入
  2. （B）建立開放性管道，讓民眾獲取所需資訊
  3. （C）品質保證即是注重錯誤發生後進行的控制與檢查
  4. （D）將每位員工的智慧、創意與活力，導引並投入組織目標和品質追求

答案：（C）

詳解與考點

正解：本題問何者不是全面品質管理（Total Quality Management, TQM）的實務策略，即要找出與TQM理念相違的敘述。TQM的核心精神是事前預防、持續改善、全員參與，追求零缺點，強調品質是在服務或產品產出的每一個環節就內建進去、而非事後才檢驗出來；C將品質保證定義為注重錯誤發生後進行的控制與檢查，把品質管理窄化成事後補救式的檢驗，恰與TQM預防勝於檢查、把品質內建於流程的理念相反，故本題選C。

A：TQM強調組織文化與領導承諾是變革成功的關鍵，高層主管須以身作則、率先投入變革與創新、營造以工作為榮的組織氛圍，這是TQM推動的重要實務策略，敘述正確。

B：TQM重視顧客導向與資訊透明，建立開放性管道讓服務對象取得所需資訊，有助於掌握顧客需求、即時回饋改善品質，是TQM強調顧客滿意與透明溝通的具體實踐，敘述正確。

D：TQM主張全員參與（employee involvement），將每位員工的智慧、創意與工作熱忱導引投入組織的品質目標，使品質改善成為全體成員共同的責任而非少數品管部門的工作，這是TQM的核心實務策略，敘述正確。

本題考點：全面品質管理（Total Quality Management, TQM），強調事前預防、全員參與、持續改善以追求零缺點；品質保證的預防取向，指TQM主張品質應內建於流程之中、而非仰賴事後檢驗補救，是與傳統品管觀念對照的重要辨析點。

第 31 題

平衡計分卡是一種包括顧客、內部作業流程、財務表現、學習與成長等四個構面組成的績效衡量系統，下列有關平衡計分卡的敘述何者錯誤？
  1. （A）將組織的使命轉換成一致的績效量度，平衡地去整合、建構與管理組織的績效指標工具
  2. （B）平衡計分卡強調策略性的思維與策略性的因果關係連結
  3. （C）平衡「原始指標」與「領先指標」
  4. （D）平衡「主觀衡量」與「客觀衡量」

答案：（C）

詳解與考點

正解：平衡計分卡（Balanced Scorecard, BSC）強調同時掌握「落後指標」（lagging indicators，即結果性、事後才能得知的財務或成果指標）與「領先指標」（leading indicators，即能預先反映未來績效趨勢的驅動性指標），透過兩者搭配呈現組織績效全貌；C選項將其中一項指標寫成「原始指標」，並非BSC理論中用以與領先指標相對的標準概念，敘述錯誤，故選C。

A：BSC的設計目的正是將組織抽象的使命與願景轉換為具體、一致的績效衡量指標體系，透過財務、顧客、內部作業流程、學習與成長四個構面平衡地整合、建構與管理組織績效，敘述正確。

B：BSC的核心特色之一即是透過策略性思維，將各項績效指標連結成一套具因果關係的策略地圖，使各構面指標環環相扣、共同支持組織策略目標的達成，敘述正確。

D：BSC強調兼顧客觀衡量（如財務數字等可量化、可稽核的指標）與主觀衡量（如顧客滿意度、員工士氣等需仰賴評估判斷的指標），以避免單一衡量方式的偏誤，敘述正確。

本題考點：平衡計分卡（Balanced Scorecard, BSC），由Kaplan與Norton提出，透過財務、顧客、內部作業流程、學習與成長四構面，平衡落後指標與領先指標、主觀與客觀衡量、財務與非財務指標，將組織策略轉化為具體績效衡量系統的管理工具。

第 32 題

相較於一般組織，有關社會服務組織的品質文化，下列敘述何者錯誤？
  1. （A）重視服務使用者的選擇權與決定權
  2. （B）公民導向，重視發現問題
  3. （C）品質組織會重視員工投資與教育訓練支出
  4. （D）重視品質和效率是集體努力的結果

答案：（B）

詳解與考點

正解：本題要選出社會服務組織品質文化「錯誤」的敘述，正解為B。社會服務組織的品質文化，其精神源自全面品質管理（TQM），強調品質是透過事前預防、內建於服務流程之中而不斷精進，而非仰賴事後檢查、發現問題再補救。B前半「公民導向」與社會服務組織強調公共性、以服務使用者的福祉為核心的特質相符，並無錯誤；但後半「重視發現問題」把品質文化的核心精神講成事後查核瑕疵的被動邏輯，與其強調預防勝於矯正的取向相反，故此敘述錯誤，為本題答案。

A：服務使用者的選擇權與決定權，是社會服務組織有別於一般營利組織之處——一般組織以顧客滿意、市場競爭為核心，社會服務組織則須同時尊重案主的自主性與選擇權，此敘述正確，故不選。

C：品質組織重視對員工的投資與教育訓練支出，因為服務品質高度仰賴第一線工作者的專業知能與態度，訓練投資是維持與提升品質的必要條件，此敘述正確，故不選。

D：品質與效率是組織全體成員集體努力的結果，強調品質不是單一部門的責任，而是全員參與、共同承擔的組織文化，此敘述正確，故不選。

本題考點：全面品質管理（Total Quality Management, TQM）在社會服務組織的應用，核心精神是預防勝於檢查、品質內建於流程、全員參與；社會服務組織品質文化的特殊性，在於須兼顧服務使用者的自主決定權與公共課責。

第 33 題

社會服務夥伴關係（partnership）不是一種單純的主從或附屬關係，或是一種純粹市場型態的契約。下列有關夥伴關係的敘述何者錯誤？
  1. （A）服務主要由服務提供者的規劃與組織而成
  2. （B）服務認知彼此相互依賴
  3. （C）機構發展共同的願景、目標和行動
  4. （D）使用者感受到的服務是無縫隙的

答案：（A）

詳解與考點

正解：社會服務夥伴關係（partnership）強調的是各方在平等基礎上共同參與、共同承擔，而非由單一方主導規劃。選項 A 敘述「服務主要由服務提供者的規劃與組織而成」，意味著服務內容與流程仍是由服務提供者單方面主導決定，使用者或其他協力機構僅是被動接受安排，這種單方主導的關係模式仍屬主從或附屬性質，違背夥伴關係「不是一種單純的主從或附屬關係」的核心精神，故 A 為錯誤敘述，選 A。

B：夥伴關係要求雙方或多方認知彼此在資源、專業或功能上相互依賴，任一方都無法單獨完成服務目標，這正是夥伴關係有別於單方主導或純粹市場契約關係的核心特徵，描述正確，故不選。

C：夥伴關係下，各參與機構會共同發展願景、目標與行動方案，透過協商凝聚共識而非由一方片面訂定，描述正確，故不選。

D：當各夥伴機構之間的服務銜接良好、資訊與資源整合順暢時，服務使用者所感受到的會是連續、不中斷的無縫隙服務，這正是良好夥伴關係運作下應有的成果，描述正確，故不選。

本題考點：社會服務夥伴關係（Partnership）的本質，強調相互依賴（Interdependence）、共同願景（Shared Vision）與無縫隙服務（Seamless Service），有別於單方主導的主從關係或單純市場契約關係。

第 34 題

有關社會工作使用網際網路的敘述，下列何者錯誤？
  1. （A）決策者可能受到網路上未經證實的訊息所影響
  2. （B）網際網路對於社會工作的保密原則，具有潛在威脅
  3. （C）服務的案主為社會上的弱勢者，限制到資訊科技的推廣
  4. （D）網際網路對每位社會服務的使用者而言，皆可方便使用

答案：（D）

詳解與考點

正解：本題問社會工作使用網際網路的敘述何者錯誤。網際網路雖為社會工作實務帶來資訊蒐集、宣導與服務輸送上的便利，但社會服務使用者中有相當比例屬於身心障礙者、高齡者、低收入戶等資訊近用能力較弱的弱勢族群，受限於設備取得、網路資費、數位素養等因素，並非人人皆能方便使用網路服務，D 稱「每位使用者皆可方便使用」過於樂觀、忽略數位落差（digital divide）的現實，與實務觀察不符，故本題選 D。

A：網路上流通大量未經查證的訊息，決策者（無論是實務工作者或政策制定者）確實可能因接觸這類資訊而受到誤導，此為網路使用於社會工作領域中真實存在的風險，敘述正確。

B：網際網路資訊傳播快速、留存不易刪除，對社會工作重視的保密原則（confidentiality）確實構成潛在威脅，例如案主資料外洩或不當轉傳，敘述正確。

C：社會工作服務對象多為社會弱勢者，其原本在經濟、教育資源上已相對不足，資訊科技的取得與使用能力往往更受限制，此一數位落差現象確實限制了資訊科技在此一群體中的推廣，敘述正確。

本題考點：數位落差（digital divide），指不同群體在資訊科技近用與使用能力上的差距；網際網路使用於社會工作實務時，須同時考量其帶來的便利性與伴隨而來的保密風險、資訊真偽風險、弱勢族群近用限制等挑戰。

第 35 題

有關社會服務機構預算編列步驟，下列順序組合何者較為適當？①設定與機構需要相關的特定目標 ②確定有關機構運作的事實 ③探討機構運作可能的替代方案 ④決定機構的優先次序⑤確定有關預算的決策 ⑥提供充分的解釋和公共關係
  1. （A）①②⑤③④⑥
  2. （B）①②③④⑥⑤
  3. （C）①③④⑥⑤②
  4. （D）①②③④⑤⑥

答案：（D）

詳解與考點

正解：本題問社會服務機構預算編列步驟的合理排序。依規劃邏輯，機構預算編列應先設定與機構需要相關的特定目標（①），接著確定機構運作的相關事實（②），再據以探討機構運作的替代方案（③），並決定機構的優先次序（④），最後才能確定預算的決策（⑤），並在決策後對外提供充分的解釋與公共關係（⑥）。這是「目標設定→事實確認→方案探討→優先排序→預算決策→對外溝通」的自然邏輯順序，即①②③④⑤⑥，故本題選 D。

A：①②⑤③④⑥將「確定預算決策（⑤）」提前到「探討替代方案（③）」與「決定優先次序（④）」之前，在尚未比較各項替代方案、排定優先順序前就做出預算決策，違反先評估、後決策的規劃邏輯。

B：①②③④⑥⑤將「提供解釋與公共關係（⑥）」排在「確定預算決策（⑤）」之前，但對外說明與公關的對象是已經確定的預算內容，理應在預算決策拍板之後才進行，順序顛倒。

C：①③④⑥⑤②將「確定有關機構運作的事實（②）」延後到接近最後，只在最末段落才確認事實，但探討替代方案（③）與決定優先次序（④）都需要以正確的機構運作事實為基礎，事實確認理應緊接在目標設定之後儘早進行，不宜延後。

本題考點：方案預算編列流程（program budgeting process），指機構從目標設定、事實蒐集、替代方案分析、優先順序決定、預算決策到對外溝通的一系列規劃步驟；規劃邏輯順序，強調「先評估、後決策、再溝通」的先後原則。

第 36 題

當一項服務方案進入衰退期，此時對於「產品」的行銷策略，下列何者較為恰當？
  1. （A）去除相對弱勢的服務
  2. （B）提供單一或少量的服務
  3. （C）多品牌策略
  4. （D）提供垂直模式的服務

答案：（A）

詳解與考點

正解：本題問服務方案進入衰退期時，關於產品的行銷策略何者較恰當。在方案生命週期中，衰退期代表服務的需求或效益已明顯下降，此時行銷策略應轉為精簡與收斂，去除相對弱勢、效益較低或已不合時宜的服務項目，將有限資源集中在仍具需求或效益的核心服務上，故選 A。

B：提供單一或少量的服務較貼近方案剛推出、資源與定位尚未擴展的導入期做法，而非衰退期該有的精簡淘汰策略，時機不對，故不選。

C：多品牌策略是透過同時經營多種品牌或服務線以擴大市場覆蓋，通常用於成長期或成熟期欲開拓新客群、鞏固市場地位時，並非衰退期應採取的收斂做法，故不選。

D：提供垂直模式的服務，即延伸服務的深度或整合上下游服務鏈，屬於擴張性的產品策略，常見於成長期欲強化服務完整性時採用，與衰退期應精簡、去除弱勢服務項目的方向相反，故不選。

本題考點：服務生命週期（Product Life Cycle）行銷策略，依導入期、成長期、成熟期、衰退期各階段特性擬定不同的產品策略；衰退期的精簡策略，主張淘汰效益低、需求萎縮的服務項目，集中資源於核心服務。

第 37 題

有效的勸募策略必須考量的要件，下列何者較不適當？
  1. （A）以簡短易理解的故事為議題
  2. （B）讓捐物者看到所捐贈的實際用途
  3. （C）極大化的人際網絡
  4. （D）強調同業結盟，避免異業合作被邊緣化

答案：（D）

詳解與考點

正解：有效的勸募策略強調運用簡短易懂的故事觸動捐款人情感、讓捐款人清楚看到捐款或捐物的實際用途以建立信任、並極大化人際網絡以擴大潛在捐款來源，這些都是募款實務公認的有效要件。D 主張「強調同業結盟、避免異業合作」，等於主動限縮跨領域合作的資源網絡，與募款講求盡可能擴大、多元化人際與組織網絡的原則相反，屬較不適當的做法，故本題選 D。

A：以簡短易懂的故事作為訴求議題，能讓捐款人在短時間內理解受助對象的處境並產生情感連結，是勸募文案與說帖設計的基本原則，屬適當要件，故不選。

B：讓捐贈者看到所捐款項或物資的實際運用情形，能提高捐款人對機構的信任與再次捐款的意願，屬課責與透明度的具體實踐，屬適當要件，故不選。

C：勸募成效高度仰賴人際網絡的廣度，人際網絡越大，能觸及的潛在捐款人越多，屬適當要件，故不選。

本題考點：勸募策略（fundraising strategy）的有效要件，包括故事行銷、資源透明化、人脈網絡極大化；異業合作、跨界結盟在非營利組織募款中被視為擴大資源基礎的正向策略，而非應避免的作法。

第 38 題

資訊系統對社會服務機構帶來的效益，下列敘述何者錯誤？
  1. （A）員工可以隨時調閱組織內的任何資訊
  2. （B）可增進填寫文件的正確性
  3. （C）工作的提醒
  4. （D）資料查詢速度提升

答案：（A）

詳解與考點

正解：本題問資訊系統為社會服務機構帶來效益的敘述何者錯誤，官方答案為A。資訊系統的建置通常伴隨權限分級與保密機制的設計，依人員職務與業務需要開放對應的資料存取權限，而非讓員工可以隨時調閱組織內的任何資訊；若真如A所述不分權限、任意調閱一切資訊，將嚴重違反案主資料保密與個資保護原則，這並非資訊系統的正確效益，而是誤解了資訊系統管理應有的存取控制設計，故A為錯誤敘述，選A。

B：資訊系統可透過欄位檢核、必填提示、格式驗證等機制，減少人工填寫時的疏漏與錯誤，確實有助於增進填寫文件的正確性，敘述正確。

C：資訊系統可設定待辦、到期或追蹤提醒等功能，協助工作者掌握案件進度與應辦事項，確實具備工作提醒的效益，敘述正確。

D：相較人工翻閱紙本檔案，資訊系統以資料庫化管理資料，能大幅縮短檢索與調閱所需時間，確實能提升資料查詢速度，敘述正確。

本題考點：機構資訊系統（management information system）的效益，包括提升資料正確性、提供工作提醒、加快查詢速度等；資訊安全與存取權限管理（access control），強調系統應依職務需要分級授權，而非讓任何人員均可任意調閱全部資訊，是社工管理考科常考的資安觀念。

第 39 題

Kurt Lewin提出的組織變革之解凍、改變、再結凍三階段模式，其中有關改變（changing）的敘述，下列何者正確？
  1. （A）將新的管理實務變成例行性活動的一部分
  2. （B）以新資訊為基礎發展新回應
  3. （C）排除員工對變革的抗拒
  4. （D）需要穩住和統整變革

答案：（B）

詳解與考點

正解：Kurt Lewin 提出的組織變革三階段模式為解凍（unfreezing）、改變（changing）、再結凍（refreezing）。改變階段的核心，是組織成員在打破舊有平衡狀態後，開始蒐集、學習新資訊，並以此為基礎嘗試發展新的認知、態度與行為回應，即題幹選項所述「以新資訊為基礎發展新回應」，故選 B。

A：將新的管理實務變成例行性活動的一部分，是再結凍階段的任務——把改變階段已嘗試成功的新做法予以制度化、常規化，並非改變階段本身的工作，是易與「改變」混淆的誘答。

C：排除員工對變革的抗拒屬於解凍階段的任務——須先鬆動組織成員對現狀的心理防衛與抗拒、營造變革的必要性認知，才能進入改變階段，故發生的時間點在改變之前。

D：需要穩住和統整變革同樣是再結凍階段的任務——透過穩固化、系統化的機制將變革成果統整固定下來，避免成員故態復萌，屬於三階段中的最後一環。

本題考點：Lewin 組織變革三階段模式（Unfreezing-Changing-Refreezing Model），解凍階段鬆動抗拒與現狀認知、改變階段以新資訊發展新回應、再結凍階段將新做法制度化並穩固下來。

第 40 題

社區發展協會現任理監事會預期社區將面對內、外部環境重大變化，未雨綢繆著手準備相關資料並擬定因應對策，屬於何種類型的變革？
  1. （A）計畫性變革
  2. （B）動態變革
  3. （C）漸進式變革
  4. （D）革命式變革

答案：（A）

詳解與考點

正解：社區發展協會理監事會「預期」內外部環境將出現重大變化、並「事先」著手準備資料、擬定因應對策，屬於組織主動預見未來、有意識地規劃行動方案的變革型態，即計畫性變革（planned change），故選A。

B：動態變革一般用以描述組織持續、多面向且非特別強調事先規劃的變動狀態，較著重變革「正在發生」的性質，而非題述「未雨綢繆、預先準備」這種有意識規劃的作為。

C：漸進式變革是依變革的「速度與幅度」所做的分類，指組織以緩慢、逐步的方式進行調整，題幹重點在於理監事會是否「預先規劃」因應對策，並未描述變革推動的速度快慢，二者分屬不同的分類軸線，故不切題。

D：革命式變革同樣是速度與幅度軸線上的分類，指短時間內大幅度、劇烈的變革，通常伴隨較高的衝突與抗拒；題述情境是組織主動預先準備、從容因應，性質上與革命式變革的急遽、劇烈恰恰相反。

本題考點：組織變革類型的分類判準，一是依「是否經事前規劃」區分計畫性變革與非計畫性（自然演進）變革，二是依「變革速度與幅度」區分漸進式變革與革命式（激進式）變革，本題屬於前一種分類軸線。
