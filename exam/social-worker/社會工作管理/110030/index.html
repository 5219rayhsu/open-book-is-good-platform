第 1 題

Frederick Herzberg 所提出的雙因子理論（motivation-hygiene theory）是激勵的重要理論，下列有關雙因子理論之敘述，何者錯誤？
  1. （A）管理者在激勵員工時，要先區隔保健因子跟激勵因子的不同
  2. （B）工作滿足的反面是工作不滿足
  3. （C）保健因子主要是跟工作環境有關，激勵因子主要是跟工作成就感有關
  4. （D）提供保健因子主要是滿足員工的基本需求，提供激勵因子才可以滿足員工的高層次需求

答案：（B）

詳解與考點

正解：Herzberg雙因子理論（motivation-hygiene theory）主張工作滿足與工作不滿足並非同一條連續量尺的兩端，而是分屬兩個各自獨立的向度：工作滿足的相反狀態是「沒有滿足」，而非「工作不滿足」；工作不滿足的相反狀態則是「沒有不滿足」，而非「工作滿足」。選項B宣稱「工作滿足的反面是工作不滿足」，正是把兩個獨立向度誤合併為單一連續量尺的傳統觀點，恰與Herzberg理論的核心主張相反，故為錯誤敘述，本題選B。

A：Herzberg理論主張保健因子（hygiene factors）與激勵因子（motivators）作用機制不同，管理者若欲有效激勵員工，須先區分兩者、分別對症下藥，此為理論的正確應用原則，故非本題答案。

C：保健因子主要對應薪資、工作環境、公司政策、人際關係等外在條件，激勵因子則主要對應工作本身帶來的成就感、認可、責任感等內在動力，此為雙因子理論對兩類因子內涵的正確劃分，故非本題答案。

D：保健因子的作用在於消除員工的不滿、滿足其基本需求，未提供則導致不滿，但提供了也僅止於沒有不滿，不會產生積極的激勵效果；激勵因子才能真正激發員工的高層次心理需求、帶來積極的工作滿足感，此為正確敘述，故非本題答案。

本題考點：Herzberg雙因子理論（Motivation-Hygiene Theory），主張工作滿足與不滿足分屬兩個獨立向度，保健因子消除不滿但不激勵、激勵因子才能帶來積極滿足；此「滿足與不滿足非同一量尺兩端」的主張，是本理論最常被考出、也最容易與傳統直覺混淆的核心論點。

第 2 題

新管理主義（new managerialism）是一種對專業權力的挑戰，著重管理、績效評鑑及效能，下列對於新管理主義的敘述何者錯誤？
  1. （A）強調公共服務的集體化與去分散化，以提升公共服務供給者間的競爭
  2. （B）強調服務使用者對服務供給者的選擇權與發言權
  3. （C）強調買方與賣方分離之契約化服務供給模式
  4. （D）降低政治決策對公共服務管理的直接干預

答案：（A）

詳解與考點

正解：新管理主義（new managerialism）源於新公共管理（New Public Management）思潮，主張引入市場機制與企業化管理手法改造公共服務，其核心作法是打破公共服務的集體壟斷、推動去集體化與分散化（decentralization），讓多元供給者（公、私、非營利部門）相互競爭，以競爭機制提升服務效率與品質。A 選項卻說「強調公共服務的集體化與去分散化」，方向恰與新管理主義主張相反——新管理主義要的是去集體化而非集體化，要的是分散化而非去分散化，故本題選 A。

B：新管理主義透過準市場（quasi-market）機制引入消費者選擇的邏輯，賦予服務使用者對供給者的選擇權與發言權（voice and choice），敘述正確，非本題答案。

C：新管理主義的重要特徵是購買者與供給者分離（purchaser-provider split），以契約委外方式取代公部門直接供給，敘述正確，非本題答案。

D：新管理主義主張以專業管理權威取代科層與政治直接干預，降低政治力對公共服務日常管理的直接介入，改由管理者依績效指標自主決策，敘述正確，非本題答案。

本題考點：新管理主義（New Managerialism）與新公共管理（New Public Management），核心主張為去集體化、市場化競爭、購買者與供給者分離之契約委外、賦予服務使用者選擇權、降低政治對管理的直接干預。

第 3 題

J. Bradshaw 的需求理論提供方案規劃者多種需求評量的方法，下列敘述何者正確？
  1. （A）運用資源盤點資料法所收集的資料可以有助於全面了解方案目標人口群的需求
  2. （B）全國性調查可以在時間成本耗用最少的情況下確認民眾對需求的感受
  3. （C）舉辦公聽會可以測得感受性需求，但卻存在著代表性是否足夠的爭議
  4. （D）以現有研究資料進行差補外推法來進行需求評量，不需考量相關名詞操作性定義的不一致

答案：（C）

詳解與考點

正解：舉辦公聽會（社區論壇）是蒐集感受性需求（felt need）常用的方法之一，藉由邀請民眾出席發表意見，直接了解其主觀感受到的需求；然而公聽會出席者往往是較積極、較有意願或較有時間參與的特定民眾，未必能代表全體目標人口群，因此存在代表性是否足夠的爭議，C 敘述正確，故本題選 C。

A：資源盤點資料法蒐集的是「現有服務資源與方案的分布、使用狀況」等既有供給面資訊，反映的是既有資源的樣貌，而非目標人口群「尚未被滿足」的實際需求全貌，若僅依賴既有資源盤點資料，容易遺漏未被現有服務觸及的潛在需求，故無法「全面」了解目標人口群的需求，A 敘述有誤。

B：全國性調查雖能取得具代表性的普遍性資料，但需要大規模抽樣、問卷設計、資料蒐集與統計分析等作業，所需人力、經費與時間成本通常相當可觀，並非「耗用時間成本最少」的方式；相對而言，公聽會、焦點團體等方法才屬於時間成本較低廉的需求評量方式，B 敘述有誤。

D：以現有研究資料進行差補外推（如將他地研究資料套用推估本地需求）時，必須留意各研究對相關名詞（如「貧窮」「失能」等）操作性定義是否一致，若定義不一致卻逕行套用外推，將導致推估結果失真，因此仍須審慎考量操作性定義的一致性問題，D 敘述有誤。

本題考點：Bradshaw 需求類型理論下的需求評量方法比較，包括資源盤點法、社會調查法（全國性調查）、公聽會（社區論壇）法、次級資料差補外推法等，各有其資料性質、代表性與成本上的優缺點，是社會工作管理方案規劃的基礎工具。

第 4 題

下列何者最能說明人群服務方案之「成效（effectiveness）」的意涵？
  1. （A）方案輸入與輸出之間的比例
  2. （B）相對於方案的各項成本所能提供之服務的多寡
  3. （C）服務對象在接受方案的服務過程或服務後所產生的改變
  4. （D）為達成預定之目標或目的所事先安排好的一套活動

答案：（C）

詳解與考點

正解：本題問人群服務方案「成效（effectiveness）」的意涵。方案評估中，成效指服務對象在接受方案服務過程中或服務後，其行為、狀態或問題所產生的實質改變或結果，是評估方案是否達成預期效果的核心指標，故選C。

A：方案輸入與輸出之間的比例，指投入資源（人力、經費、時間）與產出服務量之間的轉換關係，這是「效率（efficiency）」的定義，而非成效；效率關心的是「用多少資源做出多少服務」，不涉及服務對象是否真的因此改變。

B：相對於方案的各項成本所能提供之服務的多寡，同樣以成本為基準衡量產出量，屬效率概念的另一種表述，容易與成效混淆，但衡量的仍是「產出量」而非「服務對象的改變」。

D：為達成預定之目標或目的所事先安排好的一套活動，描述的是方案的「過程」或方案設計本身，即方案如何被規劃執行，屬方案的輸入與活動安排，而非方案執行後產生的結果。

本題考點：方案評估（Program Evaluation）中成效（effectiveness）與效率（efficiency）之辨，成效聚焦服務對象的改變結果，效率聚焦投入產出比；方案邏輯模式（Logic Model）中輸入、過程、產出、成果的區分是評估方案的基本架構。

第 5 題

在社會服務組織中薪酬是激勵與維繫員工的重要因素，對於在薪酬制度上的設計，下列敘述何者錯誤？
  1. （A）薪酬內容應儘量單一性，比較明確可衡量
  2. （B）薪酬制度要強化組織的社會形象
  3. （C）薪酬制度應具公平性和適法性
  4. （D）薪酬制度應可提高員工的組織承諾

答案：（A）

詳解與考點

正解：本題問薪酬制度設計「何者錯誤」。A 主張薪酬內容「應儘量單一性」，但完善的薪酬制度設計原則上應具多元性——涵蓋本薪、加給、獎金、福利等不同組成部分，以同時滿足員工基本生活保障、績效誘因與福利需求，並非愈單一愈好；雖然單一結構較明確易於衡量，但這犧牲了薪酬制度應兼顧的彈性與激勵功能，與薪酬管理強調的多元化原則相悖，故A描述錯誤，為本題答案。

B：薪酬制度對外代表組織願意投入的人力成本與待遇水準，良好的薪酬設計確實有助於強化組織在勞動市場與社會大眾心中的形象，此描述正確。

C：薪酬制度必須符合勞動基準法等相關法令的最低標準（適法性），且在組織內部對相同職務、績效與資歷的員工應一致對待（公平性），此為薪酬制度設計的基本原則，描述正確。

D：具吸引力且公平合理的薪酬制度，能提高員工對組織的認同與留任意願，即提升組織承諾，此描述正確。

本題考點：薪酬制度設計原則（Compensation System Design），涵蓋公平性、適法性、多元化（本薪、獎金、福利並重）、強化組織形象與提升員工組織承諾等面向，是社會服務組織人力資源管理的核心考點。

第 6 題

危機管理對機構而言是重要的，對於危機特性的敘述，下列何者錯誤？
  1. （A）不確定性
  2. （B）緊迫性
  3. （C）複雜性
  4. （D）單一負面性

答案：（D）

詳解與考點

正解：危機（crisis）具有不確定性（發展方向與結果難以預料）、緊迫性（須在有限時間內決策與回應）、複雜性（成因、影響層面交織糾結）等特徵，同時危機往往兼具威脅與轉機的雙重性質，也就是同一危機事件可能帶來負面衝擊，也可能成為組織調整、成長或改革的契機，並非單純只有負面性質；D「單一負面性」與危機兼具危險與機會的雙重本質相反，故為錯誤敘述，本題選 D。

A：不確定性是危機的核心特徵之一，危機發生時往往資訊不完整、發展方向難以預測，敘述正確，非本題答案。

B：緊迫性是危機的核心特徵之一，危機通常要求在極短時間內做出回應與決策，拖延往往使情勢惡化，敘述正確，非本題答案。

C：複雜性是危機的核心特徵之一，危機成因、影響範圍與利害關係人往往相互糾結、牽一髮動全身，難以用單一原因或單一對策簡單處理，敘述正確，非本題答案。

本題考點：危機的特性（Characteristics of Crisis），包括不確定性、緊迫性、複雜性，以及危機兼具威脅與轉機的雙重性質；危機管理（Crisis Management）即以此雙重性質為前提，設計兼顧風險控制與轉機掌握的應變策略。

第 7 題

組織若決定要引進績效管理以提升效能時，需具備的認知和態度，何者錯誤？
  1. （A）認知績效管理就是一種選擇，量力而為選取項目的行動
  2. （B）應該承認和接受任何績效是需要改善的
  3. （C）沒有終點的旅程，持續的改善
  4. （D）一定必須完成的行動

答案：（A）

詳解與考點

正解：本題問「引進績效管理以提升效能時，需具備的認知和態度，何者錯誤」。正確態度應認知績效管理是一項組織必須落實、無法回避的持續性行動——B「應承認並接受任何績效都有改善空間」、C「沒有終點、持續改善的旅程」、D「一定必須完成的行動」，三者均傳達出嚴肅、承諾、持續投入的態度。反觀A將績效管理定位為「一種選擇、量力而為挑選項目的行動」，把它當成可彈性放棄、依組織餘力挑著做的自由裁量事項，弱化了其必要性與全面性，與正確認知相違，故A為錯誤選項，選A。

B、C、D：三者皆正確描述績效管理應有的認知態度——B強調應正視任何績效都有改善空間；C強調這是一段沒有終點、持續精進的歷程；D強調這是組織一定必須落實、不可回避的行動；三者共同點在於都傳達「嚴肅看待、持續投入」的立場，與A把績效管理當成可選、量力而為的態度形成對比，故三者皆非本題所問的錯誤選項。

本題考點：績效管理（Performance Management）應具備的組織承諾態度，強調其強制性、持續性而非可選擇性；持續改善（Continuous Improvement）概念，指績效管理是沒有終點的動態歷程。

第 8 題

社會服務方案的績效管理，有關於成果目標的具體（specific）是重要的，撰寫目標時應採用能使情境產生可觀察變化的敘述，以下用詞何者較不適當？
  1. （A）改善
  2. （B）減輕
  3. （C）感受
  4. （D）促進

答案：（C）

詳解與考點

正解：本題要找「較不適當」作為成果目標具體化用詞的選項。撰寫績效目標時，用詞必須能使情境產生「可觀察」的變化，也就是要指向外顯、可衡量的行為或狀態改變。C「感受」屬於服務對象的內在主觀心理狀態，除非另外操作化為量表分數，否則無法被直接觀察或客觀測量，與「可觀察變化」的要求不符，是四個選項中最不適當者，故選C。

A、B、D：三者同因不得選——「改善」「減輕」「促進」皆屬描述某種可觀察、可衡量之外顯狀態朝特定方向變化的動詞（例如改善適應能力、減輕壓力症狀、促進親子互動），只要搭配具體測量工具或指標，即可呈現情境的可觀察變化，均符合目標具體化（specific）的要求，故不屬於「較不適當」的用詞。

本題考點：績效目標具體化（Specific，SMART原則之一），要求目標敘述指向可觀察、可衡量的外顯變化；方案評估中「內在感受」與「外顯可觀察行為」的區分，是目標撰寫的常見誘答判準。

第 9 題

有關社會服務「品質要素」的敘述，下列何者錯誤？
  1. （A）工作人員對服務對象有禮貌，抱著尊重體貼態度是保證性（assurance）
  2. （B）服務易於被取得，距離近便是可近性（accessibility）
  3. （C）工作人員領會服務對象需求，提供個別化關懷服務是同理心（empathy）
  4. （D）以簡單語言告知服務使用者有關服務的訊息是可靠性（reliability）

答案：（D）

詳解與考點

正解：本題問社會服務「品質要素」（服務品質模型 SERVQUAL 相關構面）的敘述何者錯誤。以簡單易懂的語言告知服務使用者關於服務的相關訊息，其核心在於「溝通性」（communication）——清楚地把資訊傳達給服務使用者，讓對方聽得懂、能理解；而可靠性（reliability）指的是服務提供者能否正確、一致、值得信賴地履行所承諾的服務內容（說到做到、結果穩定），兩者性質不同。D 把「以簡單語言告知服務訊息」歸類為可靠性，配對錯誤，故選 D。

A：工作人員對服務對象有禮貌、抱持尊重體貼的態度，能讓服務對象感受到專業與可信賴，屬於保證性（assurance）——服務人員的知識、禮貌及使人信任的能力，敘述正確。

B：服務易於被取得、地理距離近便，屬於可近性（accessibility）——服務對象能否方便、及時地取得所需服務，是服務品質評估中常見的延伸構面，敘述正確。

C：工作人員能領會服務對象的個別需求，並提供個別化的關懷服務，屬於同理心（empathy）——設身處地理解案主需求、提供個別化關注的能力，敘述正確。

本題考點：服務品質模型（SERVQUAL）之五大構面——有形性（tangibles）、可靠性（reliability）、回應性（responsiveness）、保證性（assurance）、同理心（empathy），其中可靠性強調「說到做到、結果一致」，須與強調「清楚傳達資訊」的溝通性（communication）加以區辨，是本題辨析的核心。

第 10 題

為某一特定任務而組成的團隊，其成員係建立在個人的專門技能和經驗，係屬於下列那一類的工作團隊？
  1. （A）問題解決團隊
  2. （B）專案團隊
  3. （C）跨功能團隊
  4. （D）自我管理團隊

答案：（B）

詳解與考點

正解：專案團隊（project team）是為完成某一特定、有明確終止點的任務而臨時組成的工作團隊，其成員通常是依據任務所需的專門技能與經驗個別選調而來，任務完成後即解散，題幹「為某一特定任務而組成」「成員建立在個人的專門技能和經驗」正是專案團隊的典型定義，故本題選 B。

A：問題解決團隊（problem-solving team）通常由同一部門或工作領域的員工定期聚會，針對如何改善品質、效率或工作環境等議題提出建議，重點在持續性的討論改善，而非為單一特定任務而臨時組成，與題幹不符。

C：跨功能團隊（cross-functional team）是由組織內不同部門、不同工作領域但層級相近的成員所組成，重點在整合不同功能或部門的觀點以協調複雜任務，強調的是成員來源部門的多元性，而非題幹所強調「依個人專門技能與經驗」選任成員，是與專案團隊定義相近、容易混淆的誘答選項。

D：自我管理團隊（self-managed team）成員從事高度相關或相互依賴的工作，團隊自主承擔原本主管的規劃、排程、督導等責任，強調的是團隊自主管理而非因特定任務而臨時組成，與題幹不符。

本題考點：工作團隊類型（types of work teams）中的專案團隊（Project Team），因特定任務組成、依成員專門技能經驗選任、任務結束即解散；並與問題解決團隊、跨功能團隊、自我管理團隊等其他類型作區辨。

第 11 題

契約委外之經費的取得已成為社福機構重要的財源之一，相較於非社會服務，有關社會服務契約的特性，下列敘述何者錯誤？
  1. （A）服務對象經常為弱勢的民眾
  2. （B）服務內容相對不具體且較複雜
  3. （C）任務通常較為標準化
  4. （D）績效監督難以進行

答案：（C）

詳解與考點

正解：C「任務通常較為標準化」錯誤，為本題答案。社會服務的服務對象需求高度個別化、服務內容複雜多元，因此契約委外之任務內容通常不易標準化，難以像一般財物或工程採購那樣明確界定規格與產出，這也正是社會服務契約監督與績效評量困難的根源之一，故「較為標準化」的敘述與社會服務契約的實際特性相反，選C。

A：社會服務的對象確實經常是經濟弱勢、身心障礙、兒少或老人等弱勢族群，這是社會服務契約有別於一般採購契約的重要特性，敘述正確。

B：社會服務內容涉及人的處遇與需求評估，服務歷程因人而異、難以事先窮盡規範，故服務內容相對不具體且較複雜，敘述正確。

D：正因社會服務任務不易標準化、成效難以量化，使得政府或委託單位對受託機構的績效監督相對困難，敘述正確。

本題考點：社會服務契約委外的特性（purchase of service contracting），相較一般財物採購，具服務對象弱勢化、服務內容不具體複雜、任務難以標準化、績效監督困難等特質，是社福機構契約管理與政府監督機制設計須特別因應的課題。

第 12 題

有關社會服務行銷的特徵，下列敘述何者錯誤？
  1. （A）關心的是人、理念、價值和服務
  2. （B）目標是追求公益使命的實現，超越財務的考量
  3. （C）社會服務的利益往往與服務對象或捐贈者的支付有直接關聯
  4. （D）成效很難標準化，品質難保證且不易衡量

答案：（C）

詳解與考點

正解：社會服務行銷的特徵之一，是服務利益的受益對象與付費者經常是分離的——例如低收入戶接受救助服務的受益者是案主本身，但費用來源可能是政府預算或社會大眾捐款；又如非營利組織的服務可能由捐贈者出資、卻由第三方（服務使用者）獲得實際利益。這種受益人不等於付費者的特性，使社會服務的利益往往與服務對象或捐贈者的支付沒有直接關聯，而C選項卻敘述兩者往往有直接關聯，與社會服務行銷的實際特徵相反，故本題選C。

A：「關心的是人、理念、價值和服務」正確描述了社會服務行銷不同於一般商業行銷（聚焦有形產品），更著重人本、理念與價值傳遞的特性。

B：「目標是追求公益使命的實現，超越財務的考量」正確描述了社會服務行銷以達成組織使命為優先目標，財務僅是達成使命的手段而非目的本身。

D：「成效很難標準化，品質難保證且不易衡量」正確描述了社會服務因服務內容因人而異、難以像實體商品般標準化生產，其品質與成效的評量本就存在高度困難。

本題考點：社會服務行銷（Social Service Marketing）的特徵，強調以人、理念、價值為核心，追求公益使命優於財務考量，且服務利益的受益者與付費者經常分離、成效難以標準化與衡量，是社會服務行銷區別於商業行銷的重要辨析點。

第 13 題

社會工作組織在從事各種助人服務時，須有效率及效能，因此「領導」與「管理」是十分重要的。Warren Bennis 針對領導者與管理者之差異，下列敘述何者錯誤？
  1. （A）管理者即為執行者，關注系統與結構、控制流程
  2. （B）管理者總是問怎麼做及何時做
  3. （C）領導者即為改革者，展望未來、創造並挑戰現實
  4. （D）領導者重視把事做對，管理者強調做對的事

答案：（D）

詳解與考點

正解：Warren Bennis 對領導者與管理者差異最著名的區辨之一，即「管理者把事情做對，領導者做對的事」——管理者著重效率、依既定目標與流程正確執行；領導者則著重方向與願景，確保組織所做的事本身是正確、值得做的。D 選項將兩者互換，說成「領導者重視把事做對，管理者強調做對的事」，恰與 Bennis 原意相反，故為錯誤敘述，選 D。

A：管理者即為執行者，關注既有系統與結構的維持、掌控作業流程，確保組織依既定軌道運作，此為 Bennis 對管理者角色的典型描述，敘述正確。

B：管理者所關注的問題面向是怎麼做及何時做，即聚焦於執行的方法與時程安排，此為管理者導向執行細節之特徵，敘述正確。

C：領導者即為改革者，著重展望未來願景、勇於創造新局並挑戰既有現實，此為 Bennis 對領導者角色的典型描述，敘述正確。

本題考點：Warren Bennis 領導者與管理者之區辨，核心命題為「管理者把事做對，領導者做對的事」（Managers do things right; leaders do the right things），是社會工作管理科目中領導與管理理論的高頻考點。

第 14 題

在管理能力方面，成功的管理者必須具備一些基本技巧，「以領導、激勵與溝通來達成組織或部門的目標」屬於下列何種管理技巧？
  1. （A）概念能力
  2. （B）人際關係能力
  3. （C）技術能力
  4. （D）政治能力

答案：（B）

詳解與考點

正解：管理者需具備的三大基本技巧為概念能力（conceptual skill）、人際關係能力（human／interpersonal skill）與技術能力（technical skill）。「以領導、激勵與溝通來達成組織或部門的目標」，其核心是透過與人互動、帶動他人共同行動來完成任務，正屬於人際關係能力的展現，故本題選B。

A：概念能力指管理者對組織整體情勢的洞察與策略思考能力，例如分析環境、規劃願景、統合各部門關係，重點在於見樹又見林的宏觀判斷，與題幹強調領導、激勵、溝通等與人互動的具體行為不同，故不選A。

C：技術能力指執行特定專業工作所需的方法、技術與知識，例如財務作業、方案設計等具體操作能力，屬於做事的能力而非帶人的能力，與題幹描述不符，故不選C。

D：政治能力並非管理者三大基本技巧中的傳統項目，而是部分管理理論補充的能力構面，指建立權力基礎與適當人脈網絡的能力，與題幹所述以領導、激勵與溝通達成目標的人際互動核心並不吻合，是容易讓人聯想到組織政治手腕而誤選的選項，故不選D。

本題考點：管理者三大基本技巧（Katz's Three-Skill Approach：概念能力、人際關係能力、技術能力），區分管理者洞察全局、與人互動及專業執行三種不同層面的能力；人際關係能力（human skill）特別強調領導、激勵與溝通等帶動他人共同達成目標的能力。

第 15 題

「目標–路徑」理論著重於領導者如何影響部屬對於工作目標與如何達成此目標之路徑的知覺，將領導行為區分為四類，下列何者是「指導型領導」的特徵？
  1. （A）管理者積極尋求部屬意見，並將其意見納入決策
  2. （B）管理者是任務取向領導
  3. （C）管理者引領部屬發揮最大潛能，獎勵達標之部屬
  4. （D）領導者關心部屬福祉並公平對待每位員工

答案：（B）

詳解與考點

正解：House的路徑—目標理論（Path-Goal Theory）將領導行為區分為指導型、支持型、參與型、成就導向型四類。指導型領導（directive leadership）的特徵是領導者明確告知部屬工作任務、標準、規則與時程，重視任務的完成與達成方式的具體指引，屬於任務取向（task-oriented）的領導風格，故本題選B。

A：管理者積極尋求部屬意見、並將其意見納入決策，描述的是參與型領導（participative leadership）的特徵，重點在領導者與部屬共同決策、廣納部屬觀點，與指導型領導由上而下明確交代任務的方式不同。

C：管理者引領部屬發揮最大潛能、並獎勵達標之部屬，描述的是成就導向型領導（achievement-oriented leadership）的特徵，重點在為部屬設定具挑戰性的目標、展現對部屬能力的信任並依績效給予獎勵，與指導型領導著重任務指示的性質不同。

D：領導者關心部屬福祉並公平對待每位員工，描述的是支持型領導（supportive leadership）的特徵，重點在關懷部屬需求與人際關係，屬於員工取向而非任務取向，與指導型領導的性質相對。

本題考點：路徑—目標理論（Path-Goal Theory, House），主張領導者應依部屬特質與工作環境調整領導風格以協助部屬達成目標；其下指導型（任務取向）、支持型（員工關懷）、參與型（共同決策）、成就導向型（設定挑戰性目標）四類領導風格的特徵區辨，是本題的核心考點。

第 16 題

組織結構界定了組織成員間的分工架構與合作關係，可由複雜性、正式化以及集中化三構面描述，下列敘述何者錯誤？
  1. （A）複雜性指組織分化的情形，可分為水平分化與垂直分化
  2. （B）正式化指組織仰賴規則、正式訓練的標準化程度
  3. （C）集中化係指決策權之所在
  4. （D）正式化程度越高，給員工的自由裁量權就愈多

答案：（D）

詳解與考點

正解：組織結構的正式化（formalization）係指組織仰賴明文規則、標準作業程序、正式訓練等方式規範成員行為的程度；正式化程度愈高，代表組織對成員行為的規範與約束愈嚴密、愈仰賴既定規則行事，成員能夠自主判斷、彈性應變的自由裁量權反而愈小，故選項 D「正式化程度越高，給員工的自由裁量權就愈多」方向恰好相反，敘述錯誤，即為本題答案。

A：複雜性指組織內部分化的程度，可分為水平分化（部門、單位、專業分工的橫向劃分）與垂直分化（組織層級節制的縱向劃分），此為標準定義，敘述正確。

B：正式化指組織仰賴規則、標準作業程序、正式訓練等方式使成員行為標準化的程度，此為標準定義，敘述正確。

C：集中化係指組織決策權集中或分散之所在，決策權愈集中於高層，集中化程度愈高，此為標準定義，敘述正確。

本題考點：組織結構三構面（複雜性、正式化、集中化），是組織理論分析組織結構的基本架構；正式化與自由裁量權呈反向關係——正式化程度愈高，成員依循既定規則行事、自由裁量空間愈小，是本題辨析的關鍵。

第 17 題

轉換型領導者除展現領導者對追隨者的關心外，更以發展體恤面的方式來影響追隨者，具有「4Is」的作為，下列關於「4Is」的敘述何者錯誤？
  1. （A）個人的魅力（Individual charisma）
  2. （B）知識的啟發（Intellectual stimulation）
  3. （C）鼓舞的動機（Inspirational motivation）
  4. （D）理想化的影響（Idealized influence）

答案：（A）

詳解與考點

正解：轉換型領導理論（transformational leadership）中，Bass 所提出的「4Is」標準內涵為理想化的影響（Idealized influence）、鼓舞的動機（Inspirational motivation）、知識的啟發（Intellectual stimulation），以及個別的關懷（Individualized consideration）——最後一項強調領導者針對每位追隨者的個別需求給予關懷與指導，而非題目 A 所寫的「個人的魅力（Individual charisma）」；魅力（charisma）在理論中其實已被涵蓋進「理想化的影響」之中，並非獨立於四項之外自成一個「I」，故 A 的用詞與 4Is 正式內涵不符，本題選 A。

B：知識的啟發（Intellectual stimulation）指領導者鼓勵追隨者以創新、批判性的角度重新檢視問題與既有做法，屬 4Is 正式項目之一，敘述正確。

C：鼓舞的動機（Inspirational motivation）指領導者透過願景與意義感激勵追隨者投入、提升士氣，屬 4Is 正式項目之一，敘述正確。

D：理想化的影響（Idealized influence）指領導者以個人操守、遠見與魅力成為追隨者認同、效法的典範，屬 4Is 正式項目之一，敘述正確；也因此魅力已內含於此項，不需另立「個人魅力」一項。

本題考點：轉換型領導 4Is（Bass's Four I's of Transformational Leadership）——理想化的影響、鼓舞的動機、知識的啟發、個別的關懷，是評估轉換型領導風格的四個核心構面；常見誘答是把「魅力」誤設為獨立的一項，實則魅力已內含於理想化的影響之中。

第 18 題

「卡內基決策模式」是一種滿意模式，也是一種有限理性的決策模式，下列何者為卡內基決策模式之假設？
  1. （A）資訊是完全的
  2. （B）決策不受決策者的偏好和價值觀影響
  3. （C）由組織中結盟間的相互妥協及協商所選出有限範圍的方案
  4. （D）管理者具備充分的知識、才智及充裕的時間

答案：（C）

詳解與考點

正解：卡內基決策模式（Carnegie Model）由Cyert與March等學者提出，屬於「有限理性」與滿意取向的決策模式，其核心假設是：組織並非鐵板一塊的單一決策者，而是由具有不同利益與偏好的次團體（結盟）所組成；決策方案是這些結盟之間透過討價還價、妥協與協商後，選出彼此都能接受的有限範圍方案，而非窮盡所有可能方案後選出最理想的一個，故選C。

A：「資訊是完全的」是古典理性決策模式的假設，該模式假定決策者能取得與問題相關的所有資訊；卡內基模式正是為了反駁這種不切實際的完全理性假設而提出，主張組織決策時面對的其實是資訊不完整、有限理性的情境，A與卡內基模式的立場相反。

B：「決策不受決策者的偏好和價值觀影響」同樣是古典理性模式對「客觀理性決策者」的理想化假設；卡內基模式恰恰強調決策深受組織內部不同結盟的偏好、利益與價值觀角力所左右，B與卡內基模式主張相反。

D：「管理者具備充分的知識、才智及充裕的時間」也是古典理性模式對決策者能力與資源的理想化假設；卡內基模式主張管理者的認知能力、時間與資訊皆屬有限，無法做到窮盡分析，D同樣與卡內基模式的基本立場相反。

本題考點：卡內基決策模式（Carnegie Model），主張組織決策是不同結盟間妥協協商後選出滿意方案的有限理性歷程；有限理性（Bounded Rationality）與滿意模式，皆用以對照古典理性決策模式「資訊完全、追求最適解」的理想化假設。

第 19 題

關於理性系統模式之敘述，下列何者錯誤？
  1. （A）1900 年代理性系統模式興起，又可稱為科學管理學派
  2. （B）理性系統模式之核心主張是：確立目標、正式化、階層化、法制化
  3. （C）行政管理與科層管理屬於理性系統模式
  4. （D）權變理論屬於理性系統模式

答案：（D）

詳解與考點

正解：理性系統模式（rational system model）興起於1900年代前後，又稱科學管理學派，核心主張是透過確立明確目標、正式化、階層化、法制化等手段追求組織效率，代表理論包括科學管理、行政管理與科層管理（官僚體制）等，皆假設組織是相對封閉、可用理性設計達成既定目標的系統。權變理論（contingency theory）則主張組織的最佳結構與管理方式須視所處環境與情境條件而定、沒有放諸四海皆準的單一最佳解，強調組織與外部環境的互動與調適，屬於開放系統模式（open system model）的代表理論，而非理性系統模式，D把權變理論歸入理性系統模式，敘述錯誤，故選D。

A：理性系統模式確實興起於1900年代前後，以科學管理為代表，又稱科學管理學派，敘述正確。

B：理性系統模式的核心主張正是透過確立目標、正式化、階層化、法制化等機制追求組織效率與可預測性，敘述正確。

C：行政管理理論與科層管理（官僚體制理論），均強調正式結構、層級節制與依法行政，屬於理性系統模式的代表理論，敘述正確。

本題考點：組織理論的系統模式分類（理性系統、自然系統、開放系統），理性系統模式（含科學管理、行政管理、科層理論）強調封閉、正式化、依理性設計達成既定目標；權變理論（Contingency Theory）主張組織結構應隨環境與情境調整、無單一最佳解，屬開放系統模式，是常見與理性系統模式對照混淆的考點。

第 20 題

下列何種管理學派將組織視為有機體，把各項管理業務看成是相互聯繫的網絡，並重視組織結構和模式的分析？
  1. （A）經驗主義學派
  2. （B）系統學派
  3. （C）管理過程學派
  4. （D）計量理論學派

答案：（B）

詳解與考點

正解：系統學派（systems approach）將組織視為一個與外部環境互動的有機體（open system），組織內部各項管理業務（如人事、生產、財務等子系統）彼此相互聯繫、相互依存，構成一個整體網絡；此學派特別重視分析組織的結構與運作模式，以及各部分之間的交互關係，完全符合題幹描述，故選B。

A：經驗主義學派主張透過分析成功或失敗的管理案例與實務經驗，歸納出可供後人參考的管理原則，重點在案例經驗的整理與傳承，並非將組織視為有機體、分析其整體結構網絡，故不選。

C：管理過程學派聚焦於規劃、組織、用人、指揮、控制等管理功能的執行過程，將管理視為一連串可拆解的普遍性職能，重點在「管理者做什麼」的功能分析，而非組織作為整體有機體的結構與網絡分析，是容易與系統學派混淆的誘答，因兩者都具有整體性、程序性的思考方式，但管理過程學派著重的是管理職能步驟，而非組織與環境互動的有機體觀。

D：計量理論學派運用數學模式、統計方法與作業研究等量化工具，協助管理者在決策時進行最適化分析，重點在數量化的決策輔助工具，並非以有機體觀點分析組織結構與各部門的網絡關係，故不選。

本題考點：系統理論／系統學派（Systems Approach），將組織視為與環境互動的開放系統，強調各子系統間相互依存的整體網絡關係；管理理論學派比較，經驗學派、管理過程學派、計量學派與系統學派各自的核心關注焦點不同，是管理學基礎考科的常見辨析題型。

第 21 題

知識管理係指在組織中建構一個知識系統，而知識可以分為外顯知識與內隱知識，下列敘述何者正確？
  1. （A）公司內部的操作手冊、訓練手冊等書面資料屬於內隱知識
  2. （B）「融合」係指將內隱知識轉換為外顯知識，亦即把內隱知識表達出來的過程
  3. （C）員工個人的見解、直覺、預感屬於外顯知識
  4. （D）「社會化」係指將內隱知識轉換為內隱知識，藉由共同經驗來產生新的內隱知識

答案：（D）

詳解與考點

正解：本題考 Nonaka 知識轉換模式（SECI model）。「社會化（Socialization）」是指將個人的內隱知識，透過共同經驗、觀察、模仿等方式傳遞給他人，轉換為另一個人的內隱知識，屬於內隱知識到內隱知識的轉換過程，故 D 敘述正確，選 D。

A：公司內部的操作手冊、訓練手冊等書面資料是已經用文字、圖表明確記錄下來、可傳遞的知識，屬於外顯知識（explicit knowledge），並非內隱知識，A 敘述有誤。

B：SECI 模式中，把內隱知識轉換為外顯知識、使其表達出來的過程稱為「外化（Externalization）」；「融合（Combination）」則是指將不同的外顯知識加以系統化、組合成更複雜的外顯知識體系，並非把內隱轉換為外顯，B 混淆了外化與融合兩個階段，敘述有誤。

C：員工個人的見解、直覺、預感屬於難以用語言文字完整表達、深植於個人經驗與心智模式中的內隱知識（tacit knowledge），而非外顯知識，C 敘述有誤。

本題考點：SECI 知識轉換模式（Nonaka & Takeuchi, SECI Model），指組織知識透過社會化、外化、融合、內化四個階段，在內隱知識與外顯知識之間循環轉換並創造新知識的歷程；外顯知識與內隱知識（Explicit / Tacit Knowledge）的區辨，是知識管理的基礎概念。

第 22 題

有關1990 年代以前，公共部門管理新模式已出現於多數先進國家，且以多種不同的名詞出現，下列名詞何者是不一致的？
  1. （A）管理主義
  2. （B）新公共管理
  3. （C）影子政府
  4. （D）企業型政府

答案：（C）

詳解與考點

正解：1990年代以前，公共部門管理新模式在多數先進國家已出現，但用語各異，其中「管理主義」（managerialism）、「新公共管理」（New Public Management）與「企業型政府」（entrepreneurial government）三者名異實同，皆指涉同一波強調效率、績效與企業化經營手法引入政府部門的行政改革浪潮；「影子政府」（shadow state）則是指政府大量透過契約委託非營利組織或民間單位執行公共服務、使後者實質承擔起原本由政府執行之職能的現象，探討的是政府與第三部門之間的治理關係，而非政府內部管理方式的改造，概念範疇與另外三者不同，故本題選C。

A：管理主義是這波改革浪潮的統稱之一，強調將企業管理原則（如效率、成本控制、績效導向）引入公部門運作，與新公共管理、企業型政府同屬一組指涉相同現象的用語，非本題答案。

B：新公共管理是描述此波改革最常見的學術用語，核心同樣是引入市場機制、績效指標與顧客導向的管理方式，與管理主義、企業型政府所指涉的改革內容一致，非本題答案。

D：企業型政府是這波改革的另一種常見稱法，強調政府應以企業家精神經營，追求效能與創新，與管理主義、新公共管理指涉相同的改革內容，非本題答案。

本題考點：新公共管理（New Public Management），1980年代起引入企業管理原則、績效導向與市場機制的政府再造浪潮，又稱管理主義、企業型政府；影子政府（Shadow State），指政府透過契約委託將公共服務執行權移轉予民間或非營利組織、使其實質承擔政府職能的現象，探討政府與第三部門間的治理關係而非政府內部管理改造。

第 23 題

假使某地方政府社會福利行政業務的執行，被視為「科層–專業」主義的取向，下列關於該取向的敘述何者錯誤？
  1. （A）外部取向
  2. （B）規則限制
  3. （C）標準取向
  4. （D）自我管制

答案：（A）

詳解與考點

正解：本題問屬於科層－專業主義取向的敘述何者錯誤，官方答案為A。科層－專業主義取向強調機構依循既定的規則與程序運作、以標準化流程處理業務，並仰賴專業人員依專業倫理與規範進行自我管制，其運作邏輯是向內看，依循組織內部的規則、標準與專業規範，而非依市場競爭、顧客導向或外部評鑑結果來決定運作方式的外部取向；A稱外部取向，與科層－專業主義依循內部規則、標準運作的本質相反，故A為錯誤敘述，選A。

B：規則限制，指組織成員的行為與業務處理均須依循既定的規章制度進行，是科層體制強調依法行政、照章辦事的核心特徵之一，敘述正確。

C：標準取向，指業務處理依循一套標準化的作業程序執行，以確保服務品質具一致性與可預期性，同樣是科層－專業主義取向強調規範化運作的特徵，敘述正確。

D：自我管制，指專業人員依其專業倫理、專業判斷自主約束執行行為的品質與界線，是專業主義強調專業自主與自律的核心特徵，敘述正確。

本題考點：科層－專業主義（bureaucratic-professional orientation），指組織運作同時依循科層體制的規則、標準作業程序，並仰賴專業人員依專業倫理自我管制的內部取向；與依市場、顧客需求決定運作方式的外部取向相對，是社工管理考科常見的組織取向辨析概念。

第 24 題

一個方案往往涉及到許多利害關係人，為達到評估的目的，需要確認利害關係人，「確認利害關係人」係屬於方案管理過程中那個階段重要的評估工作？
  1. （A）開始階段
  2. （B）準備階段
  3. （C）執行階段
  4. （D）結束階段

答案：（A）

詳解與考點

正解：方案評估的歷程通常區分為開始、準備、執行、結束等階段。在最初的開始階段，評估者須先釐清為何評估、為誰評估等根本問題，其中確認利害關係人（stakeholders）——即釐清誰對此方案及其評估結果具有利害關係、關注哪些議題——是啟動整個評估工作最先且最基礎的步驟，唯有先確認利害關係人及其關切焦點，後續的評估目的界定、指標設計與資料蒐集方能有明確依循，故選A。

B：準備階段著重於評估工具與設計的具體規劃，例如確立評估問題、選擇評估設計、發展測量工具等，這些工作須以已確認的利害關係人及其關切焦點為前提才能展開，故確認利害關係人須先於準備階段完成。

C：執行階段是實際進行資料蒐集、分析等評估工作的階段，此時利害關係人應已於開始階段確認完畢，執行階段的重點在於評估活動本身的落實，而非確認利害關係人。

D：結束階段著重於評估結果的整理、報告撰寫與應用推廣，是整個評估歷程的收尾工作，與最初辨識利害關係人的工作性質及時序皆不相同。

本題考點：方案評估歷程（Program Evaluation Process）的階段劃分，包括開始、準備、執行、結束等階段；利害關係人分析（Stakeholder Analysis），指評估之初辨識對方案及評估結果具利害關係之個人或團體，是奠定評估目的與設計方向的基礎工作。

第 25 題

王先生得知很多老人安養中心都有很長的等待名單，他認為這代表社會上需要更多的安養中心，而想要開辦一間老人安養中心。這種進行需求評量的作為是基於何種需求概念？
  1. （A）規範性需求
  2. （B）感覺性需求
  3. （C）表達性需求
  4. （D）比較性需求

答案：（C）

詳解與考點

正解：Bradshaw需求分類中的表達性需求（expressed need），是指民眾將感受性需求進一步化為具體求助或使用服務的行動，而「等候名單」（waiting list）正是這種已表達之求助行動被記錄下來的具體證據；王先生依安養中心等待名單很長，推論社會需要更多安養中心，正是以「已表達出來的求助行為數量」作為需求判斷依據，故選C。

A：規範性需求是由專家或專業機構依既定標準（例如評估工具、法定門檻）界定應有的服務量，判斷依據來自外部專業規範，而非民眾實際排隊等候的行為紀錄，與題幹不符。

B：感覺性需求（選項用字為「感覺性」，即感受性需求）是民眾主觀認為自己需要某服務的心理狀態，尚停留在認知層次、未必化為具體求助行動；題幹的等候名單已是具體行動的紀錄，超出單純感受的層次，故非答案。

D：比較性需求（相對性需求）是藉由比較不同地區或群體間服務資源與涵蓋率的落差來推估需求，題幹並未進行跨地區或跨群體的資源比較，而是直接以單一現象（等候名單長）推論需求存在，判斷依據不同，故非答案。

本題考點：Bradshaw需求分類（Bradshaw's Taxonomy of Need）中的表達性需求（expressed need），指民眾已將主觀感受化為具體求助行動（如申請、排隊等候）而被記錄下來的需求型態，與規範性、感受性、比較性需求相對照，是需求評估的重要判準。

第 26 題

在社會服務的方案評估中，包括對服務對象及服務的評估，下列何種方式主要是針對「服務對象」所進行的評估？
  1. （A）投入評估
  2. （B）形成評估
  3. （C）產出評估
  4. （D）效果評估

答案：（D）

詳解與考點

正解：方案評估依評估焦點可分為投入、過程（形成）、產出與效果（成果）等類型，其中效果評估（outcome evaluation）聚焦於服務對象接受服務後在知識、態度、行為或生活狀況上的實際改變與受益情形，直接回應「服務對象」是否因方案而獲益，因此是四者中主要針對「服務對象」所進行的評估，故本題選 D。

A：投入評估關注方案投入的資源，例如人力、經費、設備等是否充足與妥適運用，評估焦點在「資源投入面」，而非服務對象本身的改變。

B：形成評估（過程評估）關注方案執行過程中的實施狀況，用以即時發現問題、調整方案內容與執行方式，評估焦點在「方案運作過程」，而非服務對象所獲得的改變。

C：產出評估關注方案實際提供的服務量，例如服務人次、服務時數等產出指標，評估焦點在「方案的服務數量」，同樣不是針對服務對象本身狀態的改變。

本題考點：方案評估類型（Program Evaluation Types），依評估焦點區分為投入評估、過程（形成）評估、產出評估與效果（成果）評估，其中效果評估以服務對象的改變與受益作為核心評估對象，是方案評估架構的常考分類。

第 27 題

依據美國標準共同委員會所出版的《方案評估標準》，「確保該評估可提供預定使用者的訊息」是屬於方案評估時的那個標準？
  1. （A）適當性標準
  2. （B）精確性標準
  3. （C）實用性標準
  4. （D）可行性標準

答案：（C）

詳解與考點

正解：美國教育評鑑標準聯合委員會（Joint Committee on Standards for Educational Evaluation）所訂的方案評估四大標準中，實用性標準（utility standards）的核心宗旨即在確保該評估能提供預定使用者（intended users）所需的資訊，使評估結果具有實際參考與應用價值，故本題選C。

A：適當性標準（propriety standards）關注評估過程是否合乎法律、倫理，並保障受評估者及利害關係人的權益，重點在評估行為本身的正當性，而非確保資訊符合使用者需求，故不適用。

B：精確性標準（accuracy standards）關注評估所蒐集與呈現的資訊是否正確、可靠、有效，重點在資料本身的正確程度，而非資訊是否切合使用者需要，故不適用。

D：可行性標準（feasibility standards）關注評估設計是否務實、可操作，能在有限資源、時間與政治現實條件下順利執行，重點在評估執行的可操作性，而非確保資訊符合使用者需求，故不適用。

本題考點：美國教育評鑑標準聯合委員會方案評估四大標準：實用性標準（確保滿足使用者資訊需求）、可行性標準（確保務實可操作）、適當性標準（確保合乎倫理法律）、精確性標準（確保資訊正確可靠），是社會工作方案評估的重要判準架構。

第 28 題

員工訓練是人力資源管理的重要活動，一般而言，在職訓練可以區分為職場內訓練與職場外訓練，下列何者非屬於職場內訓練？
  1. （A）工作輪調
  2. （B）師徒制
  3. （C）體驗式學習
  4. （D）行為示範

答案：（C）

詳解與考點

正解：本題問「何者非屬於職場內訓練」。體驗式學習（experiential learning）通常以模擬情境、戶外活動、工作坊等方式，讓學習者在脫離實際工作崗位的安排情境中透過體驗、反思來學習，屬職場外訓練（off-the-job training），故不屬於職場內訓練，選C。

A：工作輪調讓員工在不同實際職務、崗位間輪替歷練，訓練場域就是實際工作崗位，屬職場內訓練，故不選。

B：師徒制由資深同仁在實際工作現場帶領新進人員邊做邊學，訓練場域同樣是實際工作崗位，屬職場內訓練，故不選。

D：行為示範由主管或資深同仁在工作現場示範正確行為、讓學習者模仿並獲得回饋，訓練場域仍在實際工作崗位進行，屬職場內訓練，故不選。

本題考點：職場內訓練（on-the-job training）與職場外訓練（off-the-job training）之區分，判準在於訓練是否於實際工作崗位上進行；工作輪調、師徒制、行為示範多在崗位現場進行，體驗式學習、數位學習、課堂講授等脫離崗位者屬職場外訓練。

第 29 題

社會工作者需要具備自我管理的概念來因應忙碌且複雜的社會工作實務，若是「為了避免層出不窮之收爛攤子現象的發生」，社會工作者應具備下列那項自我管理的技巧？
  1. （A）管理期待
  2. （B）管理界線
  3. （C）管理壓力與時間
  4. （D）管理工作量

答案：（B）

詳解與考點

正解：本題所述「避免層出不窮之收爛攤子現象」，其根源在於社工未能清楚界定自己與案主、同事之間的責任範圍，因而一再被動承接他人未完成或處理不當的事務、疲於奔命善後。要防止此現象反覆發生，社工需具備的自我管理技巧是「管理界線」——清楚界定自己在專業關係中能做、該做的範圍，適時說「不」、將不屬於自己責任的事務歸還給當事人或適當單位處理，才能從根本上減少被迫收拾爛攤子的情形，故本題選B。

A：管理期待指社工需與案主、機構、同事等各方溝通、調節彼此對服務結果與角色的期望落差，避免因期待不合理而引發衝突或耗竭，處理的是「認知落差」問題，而非本題所述因界線不清而反覆善後他人事務的情形。

C：管理壓力與時間著重的是社工如何調節自身情緒負荷、安排工作排程以提升效率，屬於身心調適與時間分配層面；雖然頻繁收爛攤子確實會帶來壓力與時間壓迫，但那只是「界線不清」造成的後果之一，並非問題的根本技巧，容易因題目提到「忙碌」而誤選。

D：管理工作量指合理評估、分配自己所承接的案件與任務數量，確保負荷量在可負荷範圍內；本題強調的是「層出不窮」——反覆被動接收他人未妥善處理之事，而非單純案量過多的問題，兩者性質不同，故不選。

本題考點：社工自我管理技巧的分類，包括管理界線、管理期待、管理工作量、管理壓力與時間；其中管理界線（managing boundaries）指清楚劃定專業角色與責任範圍，是避免因界線模糊而被迫反覆承接他人責任、收拾爛攤子的核心技巧。

第 30 題

Vroom 提出的期望理論，認為人在追求報酬的過程中會考慮變項間的關係，下列何者正確？
  1. （A）個人努力→工作績效→組織報酬→個人需求
  2. （B）個人需求→個人努力→工作績效→組織報酬
  3. （C）個人努力→組織報酬→工作績效→個人需求
  4. （D）個人努力→工作績效→個人需求→組織報酬

答案：（A）

詳解與考點

正解：Vroom 的期望理論（Expectancy Theory）認為，員工是否願意付出努力，取決於三項知覺連結：努力是否能帶來績效（期望，expectancy）、績效是否能換得組織報酬（工具性，instrumentality）、以及該報酬是否真正符合個人所看重的需求（價值，valence）。因此整個歷程依序為：個人努力→工作績效→組織報酬→個人需求，也就是先付出努力、努力產生績效、績效換取組織給予的報酬，最終這份報酬滿足個人的需求，故本題選 A。

B：把個人需求放在最前面，等於把整個歷程的起點誤設為需求本身，但期望理論真正探討的是努力如何一路轉化為報酬與需求滿足的因果鏈，個人需求是驅動努力的背景動機、而非歷程中努力之後才出現的一個環節，順序錯置。

C：把組織報酬錯置在工作績效之前，變成先有報酬才產生績效，這違反了期望理論工具性（instrumentality）的邏輯——報酬必須是績效表現之後所換得的結果，而非績效產生的前提，順序顛倒。

D：把個人需求錯置在組織報酬之前，變成績效直接滿足個人需求、之後才產生組織報酬，跳過了報酬作為績效與需求滿足之間中介環節的角色，順序錯置。

本題考點：Vroom 期望理論（Expectancy Theory），核心公式為努力（effort）依期望（expectancy）產生績效、績效依工具性（instrumentality）換得報酬、報酬依價值（valence）滿足個人需求，三項知覺環環相扣、缺一不可。

第 31 題

管理者若善用績效管理機制，可讓有限資源充分發揮其效能，有關績效管理的敘述，下列何者錯誤？
  1. （A）績效管理過程主要有：員工、品質、標的、監測等四項要素
  2. （B）績效管理是一種「控制」的過程，必須承認績效是需要改善的
  3. （C）績效管理即是績效評估，要讓員工績效獲得改善，使組織朝正確方向發展
  4. （D）績效管理的推動必須是沒有終點，持續且漸進的變革

答案：（C）

詳解與考點

正解：績效評估僅是績效管理循環中的一個環節，用以衡量、檢視員工當下的績效表現；績效管理則是涵蓋目標設定、持續監測、回饋輔導、改善行動等在內的完整、持續性歷程，兩者不能劃上等號。選項C將「績效管理」直接等同於「績效評估」，過度簡化了績效管理的完整內涵，故本題選C為錯誤敘述。

A：績效管理過程涉及員工、品質、標的（目標）、監測等要素的整合運作，此敘述正確。

B：績效管理本質上是一種「控制」歷程，其前提正是承認組織與員工的績效存在持續需要改善之處，此敘述正確。

D：績效管理並非一次性活動，而是沒有終點、持續且漸進推動的變革歷程，此敘述正確。

本題考點：績效管理（Performance Management）與績效評估（Performance Appraisal）的區分——前者是涵蓋目標設定、監測、回饋與改善行動的持續循環過程，後者僅是其中的衡量環節。

第 32 題

對社會工作而言，透過網絡建構以提供整合性的服務，是網絡治理的重要工作。下列有關網絡功能之敘述，何者錯誤？
  1. （A）促進組織、社區或社會的凝聚力
  2. （B）提供分享訊息、學習和創新的機會
  3. （C）可增進參與者的自主性
  4. （D）提供對話與溝通的管道，增進了解與信任

答案：（C）

詳解與考點

正解：本題問網絡功能敘述中「何者錯誤」。網絡治理（network governance）強調透過多元行動者間的協力、互賴與資源交換，共同提供整合性服務；其功能包括促進凝聚力、促成資訊分享與學習創新、以及透過溝通對話增進彼此了解與信任，這些都是網絡運作帶來的正向效果。然而參與網絡意味著行動者必須與其他成員協調行動、遵守共同規範、甚至讓渡部分決策自主權以換取資源整合與協力效益，其本質是相互依賴而非各自獨立自主，因此網絡並不會單純增進參與者的自主性，反而常是以降低單方自主換取整體協調效果，故C敘述錯誤，為本題答案。

A：促進組織、社區或社會的凝聚力是網絡治理的正確功能——透過網絡連結多元行動者，可建立共同認同與合作關係，強化彼此間的凝聚力。

B：提供分享訊息、學習和創新的機會是網絡治理的正確功能——網絡使不同組織與專業間得以交流資訊、彼此學習，進而激發服務創新。

D：提供對話與溝通的管道、增進了解與信任是網絡治理的正確功能——網絡提供行動者間持續互動的平台，透過對話溝通累積合作經驗，逐步建立信任關係。

本題考點：網絡治理（network governance），強調透過多元行動者間的互賴、協力與資源交換以達成整合性服務目標，其核心特徵是相互依賴與協調而非個別自主，此為辨識本題錯誤選項的關鍵。

第 33 題

工作團隊（work team）是一個協力的團體，強調個別或共同責任，讓團隊成員能夠朝特定目標邁進。下列何者不屬於工作團隊的特色？
  1. （A）工作由全體共同決定，再由團隊合力完成
  2. （B）團隊有特定的目標，透過成員互補的技能來完成
  3. （C）績效的評估取決於個人的工作表現
  4. （D）無效的工作團隊會讓組織各面向陷入負向迴圈

答案：（C）

詳解與考點

正解：本題問「不屬於」工作團隊（work team）特色者。工作團隊與工作群體（work group）的關鍵差別在於績效歸屬與課責方式：團隊講求共同目標、成員技能互補，以及對「共同工作成果」負起集體責任，績效評估也以團隊整體產出為準；反之，只看「個人的工作表現」來評估績效，是工作群體的特徵，而非團隊的特徵。故選項C「績效的評估取決於個人的工作表現」不屬於工作團隊的特色，為本題答案。

A：「工作由全體共同決定，再由團隊合力完成」正是工作團隊強調共同決策與合力產出的特色，屬於團隊特徵，故非本題答案。

B：「團隊有特定的目標，透過成員互補的技能來完成」也是團隊定義的核心要素——共同目標與技能互補，屬於團隊特徵，故非本題答案。

D：「無效的工作團隊會讓組織各面向陷入負向迴圈」描述團隊運作失能對組織的連動影響，反映團隊成員彼此高度相依、牽一髮動全身的特性，仍屬在描述團隊而非群體的動態特徵，故非本題答案。

本題考點：工作團隊（work team）與工作群體（work group）之辨，團隊強調共同目標、技能互補、集體課責與團隊整體績效，群體則以個人課責與個人績效為主；此區分常見於社會工作管理科目中團隊建立（team building）相關考題。

第 34 題

目標管理可實現組織的願景，但可能因組織內外因素的變異，使目標管理過程中出現阻力而難以達到預期效益。下列何者不是目標管理的限制？
  1. （A）目標管理有時易於陷入本位主義或形式主義
  2. （B）鼓勵參與會增加員工的工作壓力、倦怠感與流失率
  3. （C）獎懲不公易削弱目標管理的效果
  4. （D）資源的不穩定致使目標不易實現

答案：（B）

詳解與考點

正解：目標管理（Management by Objectives, MBO）強調由主管與員工共同參與設定具體、可衡量的目標，此一鼓勵參與的機制在管理學文獻中普遍被視為MBO的核心優點——透過參與設定目標可提升員工的承諾感、工作動機與對目標的認同，而非導致工作壓力、倦怠感與流失率上升；B把MBO賴以成立的參與式優點，錯置為其限制，故本題選B。

A：目標管理若執行不當，容易流於為訂目標而訂目標的形式主義，或各部門僅顧本身目標達成、忽略組織整體目標的本位主義，此為文獻中常見列舉的MBO限制，敘述正確。

C：目標管理的成效高度仰賴獎懲制度的公平性，若考核與獎懲不公，將削弱員工對目標管理制度的信任與投入意願，進而使整體效果打折，此為常見列舉的限制，敘述正確。

D：目標管理假設組織能在穩定的資源條件下依計畫逐步達成設定目標，若外部環境變動或資源供給不穩定，將使原訂目標難以如期實現，此亦為常見列舉的限制，敘述正確。

本題考點：目標管理（Management by Objectives, MBO），由主管與部屬共同參與設定具體目標、據以考核績效的管理方法，參與式目標設定被視為其核心優點而非限制；目標管理的常見限制，包括本位主義／形式主義、獎懲公平性不足與外部資源環境不穩定等因素。

第 35 題

財務管理是社會服務機構實踐組織願景和目標的工具與過程，下列有關財務管理內涵的敘述，何者錯誤？
  1. （A）財務管理係指發展預算、監督支出及資金的調度和移轉
  2. （B）財務管理必須考慮組織內外部環境的變化
  3. （C）財務管理只是少數主管與特定人員的責任
  4. （D）社工人員也必須負起爭取經費的責任

答案：（C）

詳解與考點

正解：本題問財務管理內涵敘述何者錯誤，答案為 C。社會服務機構的財務管理雖由主管與財務人員負主要規劃執行之責，但機構整體的財源穩定與資源運用，仰賴包括第一線社工在內全體成員的共同投入（例如協助爭取經費、掌握服務成本效益），並非僅侷限於少數主管與特定人員；C 將財務管理窄化為「只是少數主管與特定人員的責任」，與機構財務管理需全員參與、社工亦負爭取經費之責的理念相違，故為錯誤敘述，選 C。

A：財務管理本即涵蓋發展預算、監督支出，以及資金的調度和移轉等具體工作內容，此為正確敘述。

B：機構財務管理必須因應組織內部資源條件與外部環境（如政策、經濟景氣、捐助來源）的變化而調整，此為正確敘述。

D：社工人員身為服務提供者與資源使用者，也必須負起爭取經費（如撰寫方案計畫書、募款）的責任，而非置身財務管理事務之外，此為正確敘述。

本題考點：社會服務機構財務管理（financial management）的內涵與全員參與原則，涵蓋預算編列、支出監督、資金調度，並強調財務責任不限於少數主管，第一線社工亦應共同承擔爭取經費之責。

第 36 題

有關社會服務的策略性行銷，下列敘述何者錯誤？
  1. （A）社會機構為避免陷入「營利的偽裝」，最先確立的是使命
  2. （B）社會服務的典型顧客包括案主、志工和捐贈者
  3. （C）行銷組合的5P 中，「價格」（price）是主要要素
  4. （D）「市場定位」是指在競爭市場中尋找一個獨特的位置

答案：（C）

詳解與考點

正解：社會服務組織多屬非營利性質，其服務對象往往因社會福利或補助而免費或低價使用服務，價格在行銷組合中並非決定顧客選擇與否的主要要素；相對地，機構的使命、服務品質、人員互動與宣傳溝通等要素，才是非營利組織策略性行銷中更受重視的部分，C選項稱價格是主要要素與此不符，故為錯誤敘述，本題選C。

A：非營利組織若一味追求營收而忽略核心任務，容易陷入營利的偽裝，因此在規劃策略性行銷之前，最先必須確立的是機構使命，以使命引導行銷策略的方向，A敘述正確，並非答案。

B：社會服務的顧客並不侷限於直接接受服務的案主，還包括提供人力的志工，以及提供資源的捐贈者等多元利害關係人，B敘述正確，並非答案。

D：市場定位是指組織在眾多同類服務提供者中，找出並凸顯自身獨特、能與其他機構區隔的位置，以利吸引資源與案主，D敘述正確，並非答案。

本題考點：非營利組織策略性行銷（strategic marketing），核心在於以使命引導行銷、辨識多元顧客（案主、志工、捐贈者），並在行銷組合（marketing mix）中，因服務多為免費或補助而使價格的重要性相對低於其他要素。

第 37 題

組織面對抗拒創新的應對策略，下列敘述何者較不適當？
  1. （A）召開員工說明會議
  2. （B）邀請員工參與規劃
  3. （C）鼓勵資深員工表達接受學習之意願
  4. （D）讓抗拒者成為組織中的活躍份子

答案：（D）

詳解與考點

正解：本題問因應組織抗拒創新的策略中，何者較不適當。因應抗拒創新一般採取教育溝通、參與、支持等正向且透明的方式，讓員工真正理解變革、實質參與規劃過程；而 D「讓抗拒者成為組織中的活躍份子」若非透過真誠的參與機制達成，而是刻意將抗拒者拉攏、收編為代言人以化解其抗拒（即操縱收編策略），一旦員工察覺其操縱性質，反而會損害管理者的信任，甚至讓抗拒者取得更大的組織影響力、使抗拒立場被進一步強化，故較不適當，選 D。

A：召開員工說明會議屬於「教育溝通」策略，藉由清楚說明變革的原因與內容，降低員工因資訊不足或誤解而產生的抗拒，是因應抗拒創新常見且適當的做法。

B：邀請員工參與規劃屬於「參與」策略，讓員工在變革設計過程中有實質參與和發言權，能提升員工對變革的認同感與掌控感，是化解抗拒最有效的正向做法之一。

C：鼓勵資深員工表達接受學習之意願，屬於「支持與催化」策略，透過資深員工的正向示範與帶頭學習，降低同儕間對創新的疑慮與抗拒，是適當且具引導效果的做法。

本題考點：組織變革抗拒因應策略，包括教育溝通、參與、支持催化、協商、操縱收編、強制等方式；其中操縱收編（manipulation and co-optation）雖能短期化解抗拒，但因帶有欺瞞性質、且可能助長抗拒者影響力，長期而言風險較高、較不適當。

第 38 題

有關社會服務機構決策時的資訊蒐集特性，下列敘述何者錯誤？
  1. （A）好的決策必須建立在即時的資訊上
  2. （B）過於瑣細資訊會成為決策上的障礙
  3. （C）片面訊息比沒有訊息好
  4. （D）保密是一項難以完全避免的潛在威脅

答案：（C）

詳解與考點

正解：本題描述社會服務機構決策時的資訊蒐集特性，問「何者錯誤」。C「片面訊息比沒有訊息好」的敘述並不成立——片面、片段或偏頗的資訊容易讓決策者產生「以為已充分掌握狀況」的錯覺，反而可能因資訊不完整或偏誤而做出比完全沒有資訊時更差的判斷，片面訊息未必優於沒有訊息，甚至可能更具誤導性與風險，故本題選C。

A：「好的決策必須建立在即時的資訊上」是正確的資訊蒐集原則——決策所依據的資訊若已過時，將無法反映案主或機構當下的真實狀況，即時性是有效決策的基本要求，此敘述正確，不選A。

B：「過於瑣細資訊會成為決策上的障礙」同樣正確——資訊並非愈多愈好，過度瑣碎、缺乏篩選的細節會增加決策者的認知負荷、模糊焦點，反而阻礙有效判斷，此敘述正確，不選B。

D：「保密是一項難以完全避免的潛在威脅」亦屬正確描述——在蒐集與運用案主相關資訊的過程中，資訊外洩或保密疏漏的風險始終存在，難以百分之百杜絕，這是機構決策資訊管理必須正視的潛在威脅，此敘述正確，不選D。

本題考點：社會服務機構決策資訊管理，強調資訊的即時性、適量性（避免過細）與保密風險管理；片面資訊的決策風險，指不完整或偏頗資訊可能比毫無資訊更容易誤導判斷的管理學觀點。

第 39 題

具有相當悠久歷史的心智障礙教養院，該機構的員工教育程度、年資差異大，早晚班的交接不確實，甚至夜班的值班員工還經常喝點小酒；工作上很少被要求，工作紀錄凌亂不全，組織並沒有訂定工作規則、員工福利制度混亂，內部小團體彼此不太互動，老員工自恃有經驗會輕視年輕員工，新進員工常常待不久就離職。新到任的教養院主任，想要有所作為，準備六個月內建立制度與組織文化，其運用方式下列敘述何者錯誤？
  1. （A）邀機構內最資深與孚眾望的員工，表達對於組織制度缺失的批判
  2. （B）分別召開座談會，與各種班別、科室的員工開會聽取意見
  3. （C）對於違反制度值班時間喝酒員工，只能以溝通勸說方式，不宜以懲罰方式
  4. （D）已循規定作業的新進菜鳥員工，給予支持，提供與示範分享經驗

答案：（C）

詳解與考點

正解：本題問建立制度與組織文化的作為中，何者錯誤。題幹明示機構尚未訂定工作規則，因此不能把值班喝酒說成已違反既有工作規則；但 C 以「只能」溝通勸說並預先排除其他適當處置，同樣不利於制度建立。主任可在規則明確、程序正當且符合比例的前提下，依行為風險採取適當管理措施，故 C 為錯誤做法，選 C。

A：邀請機構內最資深與孚眾望的員工表達對組織制度缺失的批判，是借重意見領袖影響力、凝聚組織共識以推動變革的合理做法，有助於降低變革阻力。

B：分別召開座談會，與各種班別、科室的員工開會聽取意見，能全面掌握不同班別、單位的問題與需求，是建立制度前廣納意見、確保制度可行性的合理步驟。

D：對已循規定作業的新進員工給予支持、提供並示範分享經驗，有助於降低新人流動率、強化其對組織規範的認同，是穩定人力與建立正向文化的合理做法。

本題考點：組織變革與制度建立中「獎懲並行」原則——建立紀律文化須同時運用支持引導（如聽取意見、示範分享）與明確究責（如依明確規則、正當程序與比例採取適當處置）兩種手段，僅靠溝通勸說無法確立制度的約束力。

第 40 題

組織內的變革需要有觸媒，負有觸媒功能與控制變革過程者，下列何者比較不會是變革媒介角色？
  1. （A）組織管理者
  2. （B）內部專業人員
  3. （C）外聘顧問督導
  4. （D）服務對象

答案：（D）

詳解與考點

正解：組織變革理論中，變革媒介（change agent）指負有觸媒功能、主動推動並掌控變革過程的角色，通常由組織管理者、內部專業人員或外聘顧問督導擔任，因為他們具備推動變革所需的職權、專業知識或外部客觀視角；服務對象（案主）通常是變革的受影響對象或回饋來源，而非主導、控制變革過程的一方，故本題選 D。

A：組織管理者掌握組織內的正式職權與資源分配權力，能夠由上而下發動並主導變革歷程，是最典型的變革媒介角色之一，不應選。

B：內部專業人員（如資深社工或方案負責人）熟悉組織內部運作與實務問題，常被賦予規劃與推動變革方案的角色，屬於內部變革媒介，不應選。

C：外聘顧問督導以其專業知識與組織外部客觀立場，協助組織診斷問題、設計並引導變革過程，是常見的外部變革媒介角色，不應選。

本題考點：變革媒介（Change Agent），指在組織變革歷程中負責觸發、規劃並掌控變革過程的角色，可能來自組織內部（管理者、專業人員）或外部（顧問／督導）；服務對象在組織變革理論中通常被定位為受變革影響或提供回饋的一方，而非主導變革者，是社會工作管理組織變革理論的常考辨析點。
