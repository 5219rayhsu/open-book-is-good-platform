下列有關嬰兒安全睡眠環境安排的敘述，何者最為適當？

第 32 題

12歲男童因發燒全身紅疹到急診室，看診醫師沒有得過水痘也沒有接種過水痘疫苗，診察時也沒有穿戴適合的個人防護裝備。3天後病童確診水痘感染。此醫師應接受下列何種處置最為適當？
  1. （A）有水痘症狀再服用抗病毒藥物
  2. （B）立即預防性服用抗病毒藥物
  3. （C）馬上到門診接種水痘疫苗
  4. （D）即刻開始在家隔離一週觀察症狀

答案：（C）

第 64 題

李姓男性國民，20歲（簡稱李男）須服義務兵役，李男為了逃避兵役，故意裝病。李男最有可能的診斷為何？
  1. （A）factitious disorder
  2. （B）malingering
  3. （C）conversion disorder
  4. （D）panic disorder

答案：（B）

第 17 題

罹患頭痛的小孩，出現以下何種情形時，最需要做神經影像檢查？
  1. （A）頭痛持續一個小時以上
  2. （B）出現發燒
  3. （C）有局部不正常神經學徵兆（Focal neurological sign）
  4. （D）有偏頭痛（Migraine）家族史

答案：（C）

第 48 題

A先生，65歲男性，有高血壓病史多年，早上吃完早飯後，突然頭暈，步態不穩，被送至急診室，身體神經功能檢查，發現講話口語不清，吞嚥困難，右側gag reflex消失，左側疼痛感覺遲鈍，其病灶最可能與下列那條血管堵塞有關？
  1. （A）右側後下小腦動脈
  2. （B）左側後下小腦動脈
  3. （C）右側前下小腦動脈
  4. （D）左側前下小腦動脈

答案：（A）
