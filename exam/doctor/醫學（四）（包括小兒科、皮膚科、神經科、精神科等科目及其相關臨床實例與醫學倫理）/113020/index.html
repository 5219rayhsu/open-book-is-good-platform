  3. （C）在病人身邊擺放家人照片和時鐘，幫助建立定向感
  4. （D）可長時間約束，以避免病人暴力和預防跌倒

答案：（D）

第 69 題

有關臺灣採用美沙冬（methadone）替代療法治療海洛因（heroin）成癮，下列敘述何者最適當？
  1. （A）長期使用多數患者會導致憂鬱或嗜睡（drowsiness）
  2. （B）主要使用途徑為靜脈注射
  3. （C）不會導致依賴（dependence）
  4. （D）長期使用美沙冬後，藥效持續24小時以上，每天給與一次治療即可

答案：（D）

第 70 題

苯二氮平類（benzodiazepines, BZDs）在臨床上廣泛被使用，下列敘述何者最適當？
  1. （A）BZDs戒斷症狀和酒精很相似，都有焦慮、不悅、失眠，甚至抽搐的可能性
  2. （B）BZDs戒斷誘發的抽搐多半在停用後的10天左右最易發生
  3. （C）半衰期較長之BZDs，成癮性較高
  4. （D）男性濫用者較女性多

答案：（A）

第 71 題

有關自閉症類群障礙症（autism spectrum disorder）的症狀，下列敘述何者最適當？
  1. （A）患者社交發展的主要特徵是完全缺乏依附行為（absent attachment behavior）
  2. （B）與同年齡孩童相比，患者面對陌生人時的反應會更為顯著不安
  3. （C）認知功能上，患者的視覺空間（visual-spatial）能力會優於口語理解（verbal reasoning）能力
  4. （D）患者雖然有社交功能障礙，但與同年齡孩童相比，其心智理論（theory of mind）功能並無缺損

答案：（C）

第 72 題

有關中樞神經刺激劑（CNS stimulant）用來治療注意力不足／過動症，下列何者最不適當？
  1. （A）常用的中樞神經刺激劑為methylphenidate，其作用機轉為血清素回收抑制劑（serotonin reuptakeinhibitor）
  2. （B）可提升社交互動和衝動控制
  3. （C）對於大多數的注意力不足／過動症三大核心症狀有效
  4. （D）副作用主要是食慾降低或影響睡眠

答案：（A）

第 73 題

詐病（malingering）與佯病（factitious disorder）之最大區別為何？
  1. （A）佯病為個案有意圖的（intentionally）裝病
  2. （B）佯病找不到真正的身體疾病或其他精神疾病
  3. （C）詐病為個案主要的意圖在維持病人的角色（sick role）
  4. （D）詐病有明確的外在的因素。如避免法律事件、逃避兵役等

答案：（D）

第 74 題

84歲女性，有高血壓病史，突然頭痛噁心而至急診求診。頭部電腦斷層檢查發現有廣泛蜘蛛網膜下腔出血（subarachnoid hemorrhage, SAH）併腦室內出血；進一步做頭部血管攝影檢查，影像如附圖（右側及左側頸動脈造影），造成她SAH的原因最可能為下列何者？
  1. （A）右側內頸動脈（ICA）和後交通動脈（PCommA）交界腦動脈瘤
  2. （B）左側內頸動脈（ICA）和後交通動脈（PCommA）交界腦動脈瘤
  3. （C）右側前大腦動脈瘤
  4. （D）左側前大腦動脈瘤

第 75 題

關於腦梗塞（cerebral infarction）的影像，下列敘述何者錯誤？
  1. （A）通常12小時之內的頭部電腦斷層（CT）掃描看不到明顯變化
  2. （B）兩週左右的頭部電腦斷層（CT）或磁振造影（MRI）靜脈注射顯影劑後，可能會有顯影加強現象
  3. （C）頭部電腦斷層（CT）比磁振造影（MRI）更容易偵測腦梗塞之後的出血性轉化（hemorrhagictransformation）
  4. （D）擴散加權影像（diffusion-weighted-imaging）上偵測到的異常可以持續兩週左右

第 76 題

  3. （C）常發生於未滿三歲嬰幼兒
