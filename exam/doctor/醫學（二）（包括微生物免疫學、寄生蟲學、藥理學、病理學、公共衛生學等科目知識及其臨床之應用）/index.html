有關胺基醣苷類（aminoglycosides）抗生素之敘述，下列何者最不適當？
  1. （A）此類抗生素可抑制細菌蛋白質生合成，進而達到殺菌或抑制細菌生長之作用
  2. （B）降低抗生素進入細菌內可能會導致細菌對此類抗生素出現抗藥性
  3. （C）此類抗生素需在厭氧環境下，方可穿過細胞膜，因此厭氧菌對此類抗生素具有感受性（susceptible）
  4. （D）卡納黴素（kanamycin）與阿米卡星（amikacin）為此類常見抗生素

答案：（C）

第 53 題

下列有關抗癌藥oxaliplatin之敘述，何者錯誤？
  1. （A）病人對carboplatin產生抗藥性時，對oxaliplatin也會產生交叉抗藥性（cross-resistance）
  2. （B）為FOLFOX合併用藥之一，可治療轉移性大腸直腸癌
  3. （C）主要的劑量限制毒性（dose-limiting toxicity）為產生神經毒性
  4. （D）可用於治療實質固態瘤（solid tumor）

答案：（A）

  3. （C）細胞壁上含有短鏈分枝菌酸（short-chain mycolic acids）
  4. （D）主要造成呼吸道或皮膚的疾病

  2. （B）使⽤斜率因⼦進⾏風險計算

  4. （D）不適合進⾏不確定性分析
