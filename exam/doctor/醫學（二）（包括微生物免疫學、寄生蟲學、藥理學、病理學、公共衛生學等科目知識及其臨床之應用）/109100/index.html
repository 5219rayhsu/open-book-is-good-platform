第 1 題

在12月中旬，一位5歲男童出現發燒、頭痛、喉嚨痛、流鼻水、打噴嚏、無痰性乾咳、肌肉痛不舒服等症狀，病情持續4天沒有好轉，卻進一步發展為細菌性肺炎（pneumonia）及肌炎（myositis），與該男童同住之家人一星期後亦出現類似症狀，此男童最可能受下列何種病原感染？
  1. （A）麻疹病毒（Measles virus）
  2. （B）呼吸道細胞融合病毒（Respiratory syncytial virus）
  3. （C）流行性感冒病毒（Influenza virus）
  4. （D）腸病毒71型（Enterovirus 71）

答案：（C）

詳解與考點

正解：題幹的冬季群聚性發燒、頭痛、肌肉痛、乾咳與上呼吸道症狀，且後續併發細菌性肺炎及肌炎，最符合流行性感冒病毒（influenza virus）感染，故選 C。家人一週後出現相似症狀也支持具人傳人能力的流感。

A：麻疹通常有發燒、咳嗽、鼻炎、結膜炎及後續特徵性皮疹，題幹缺乏皮疹線索，併發肌炎也不如流感典型。

B：呼吸道細胞融合病毒較常在嬰幼兒造成細支氣管炎與喘鳴；5 歲兒童的明顯肌痛、冬季流感樣全身症狀及肌炎較指向流感。

D：腸病毒 71 型可造成手足口病、疱疹性咽峽炎及少數嚴重神經系統併發症，但不符合此題的季節性流感樣群聚與細菌性肺炎脈絡。

本題考點：流行性感冒（influenza）——突發發燒、頭痛、肌痛與乾咳是典型流感樣症候群；兒童可併發肌炎，流感亦可因病毒性或繼發細菌性感染導致肺炎。

第 2 題

診斷結核分枝桿菌（Mycobacterium tuberculosis）感染症時，DNA技術（DNA technologies）與傳統培養法比較，其優點不包括下列何者？
  1. （A）增加鑑定菌種之專一性
  2. （B）敏感度較高
  3. （C）可快速診斷
  4. （D）可以精確且完整判讀對抗生素的抗藥性

答案：（D）

詳解與考點

正解：DNA 技術相對於傳統培養法的「優點不包括」。核酸檢測可直接偵測結核分枝桿菌的特異性序列，因此有助於快速且專一地鑑定病原，也常可提高檢出效能；但抗藥性判讀只能偵測已知基因變異，無法取代完整的表型藥物感受性試驗，故選 D。

A：DNA 序列可設計為針對結核分枝桿菌複合群的特異性標的，能提升菌種鑑定的專一性，屬其優點。

B：分子法相較塗片通常較敏感，但不能概括為必然比培養敏感；其敏感度依檢體、菌量與方法而異。

C：核酸檢測不必等待分枝桿菌緩慢培養生長，可縮短診斷所需時間，屬其核心優點。

本題考點：分子診斷（molecular diagnostics）可快速、特異性偵測結核分枝桿菌；藥物感受性試驗（drug susceptibility testing）仍須區分基因型抗藥性標記與表型抗藥性全貌。

第 3 題

有關B級β-內酰胺酶（class B β-lactamase）之敘述，下列何者錯誤？
  1. （A）同屬於蛋白酶（protease）家族
  2. （B）作用時需金屬離子
  3. （C）無法分解carbapenems
  4. （D）基因多位於質體上

答案：（C）

詳解與考點

正解：B 級 β-內酰胺酶為金屬 β-內酰胺酶（metallo-β-lactamase），其臨床重要性正是可水解 carbapenems；因此稱其「無法分解 carbapenems」與其定義相反，故選 C。

A：B 級酶的催化核心屬金屬依賴性水解酶，其催化機轉與部分 metalloprotease 類似，但水解的是 β-內酰胺環，不能直接稱為蛋白酶；本題的辨識重點是其以金屬參與水解，而非 serine β-lactamase 的機轉。

B：B 級 β-內酰胺酶需要金屬離子，典型為鋅離子，協助活化水分子以水解 β-內酰胺環，敘述正確。

D：具臨床意義的金屬 β-內酰胺酶基因可由可移動遺傳元件攜帶並在質體上傳播，因而容易造成抗藥性擴散，敘述正確。

本題考點：B 級 β-內酰胺酶（class B β-lactamase）即金屬 β-內酰胺酶；carbapenemase 可水解 carbapenems；抗藥性基因的質體傳播（plasmid-mediated dissemination）是重要流行病學機制。

第 4 題

針對治療非多重抗藥性結核分枝桿菌（Mycobacterium tuberculosis）所引起的結核病，下列那些藥物是屬於世界衛生組織（WHO）建議的第一線藥物？ ①異菸鹼醯（isoniazid） ② 硫胂密胺（melarsporol） ③ 兩性黴素B（amphotericin B） ④ 乙胺丁醇（ethambutol）
  1. （A）①③
  2. （B）②③
  3. （C）①④
  4. （D）②④

答案：（C）

詳解與考點

正解：非多重抗藥性結核病的 WHO 第一線藥物。① isoniazid 與④ ethambutol 都是標準第一線抗結核藥；② melarsoprol 是治療非洲錐蟲病的藥物，③ amphotericin B 是抗黴菌藥，故正確組合為①④，選 C。

A：① isoniazid 正確，但③ amphotericin B 的作用標的是黴菌細胞膜成分，不是非多重抗藥性結核病第一線治療，組合不完整且含錯項。

有關傷寒沙門氏桿菌（Salmonella Typhi）的敘述，下列何者錯誤？
  1. （A）主要的傳染途徑為糞口傳染（fecal-oral spread）
  2. （B）大多由帶菌的家禽或家畜直接傳染給人
  3. （C）細菌會感染腸道，也會感染肝臟與脾臟
  4. （D）少數病人為無症狀帶原者，細菌通常潛伏在膽囊（gall bladder）

答案：（B）

詳解與考點

正解：傷寒沙門氏桿菌的傳播型態。Salmonella Typhi 的主要宿主是人，經受人類糞便污染的水或食物作糞口傳染，並非通常由帶菌家禽或家畜直接傳給人；後者較符合非傷寒型沙門氏菌的常見來源，故選 B。

本題考點：傷寒（typhoid fever）由 Salmonella Typhi 引起且以人為主要宿主；糞口傳染（fecal-oral transmission）與慢性膽囊帶原（chronic gallbladder carriage）是其流行病學重點。

第 6 題

下列何者無法將金黃色葡萄球菌（Staphylococcus aureus）與表皮葡萄球菌（Staphylococcus epidermidis）區分出來？
  1. （A）產生凝固酶（coagulase）的能力
  2. （B）醱酵甘露醇（mannitol）的能力
  3. （C）溶血（hemolysis）型態
  4. （D）觸酶（catalase）試驗

答案：（D）

詳解與考點

正解：「無法區分」金黃色葡萄球菌與表皮葡萄球菌。兩者同為葡萄球菌屬，皆具有觸酶（catalase），所以觸酶試驗只能區分葡萄球菌與鏈球菌，不能區分這兩種葡萄球菌，故選 D。

A：金黃色葡萄球菌通常 coagulase 陽性，表皮葡萄球菌為陰性，可作重要鑑別。

B：金黃色葡萄球菌常可在甘露醇鹽培養基醱酵甘露醇，表皮葡萄球菌通常不能，具有鑑別價值。

C：兩者的溶血表現可不同，金黃色葡萄球菌常見 β 溶血而表皮葡萄球菌多不溶血，因此可提供區分線索；看似都是革蘭氏陽性球菌，但溶血型態並非完全相同。

本題考點：觸酶試驗（catalase test）區分葡萄球菌與鏈球菌；凝固酶試驗（coagulase test）可鑑別 Staphylococcus aureus 與 coagulase-negative staphylococci；甘露醇醱酵（mannitol fermentation）是輔助鑑定。

  1. （A）一條mRNA可以轉譯出多種蛋白質
  2. （B）基因進行轉錄時，可同時進行轉譯工作
  3. （C）lac操縱子基因表現主要受到定額感應系統（quorum-sensing system）的直接調控
  4. （D）在色胺酸（tryptophan）操縱子（trp operon）的調控機制中，色胺酸是共同抑制子（co-repressor）

答案：（C）

詳解與考點

A：細菌常有多順反子 mRNA（polycistronic mRNA），同一轉錄本可帶有多個開放閱讀框並轉譯成不同蛋白質，敘述正確。

B：細菌沒有核膜將轉錄與轉譯隔開，核糖體可在 mRNA 尚在轉錄時開始轉譯，稱轉錄—轉譯偶聯（transcription-translation coupling），敘述正確。

D：trp operon 中，色胺酸作為共同抑制子與抑制蛋白結合，使其能結合操縱區抑制轉錄，敘述正確。

本題考點：lac 操縱子（lac operon）受 LacI 與 cAMP-CRP 調節；多順反子 mRNA（polycistronic mRNA）是原核基因表現特色；共同抑制子（co-repressor）可啟動抑制蛋白功能。

第 9 題

下列何者不是炭疽桿菌（Bacillus anthracis）常引起的疾病？

  2. （B）小朋友如果感染小DNA病毒（Parvovirus）B19， 會在兩側臉頰產生整片發紅的現象，俗稱巴掌臉（slapped-cheek）
  3. （C）在免疫缺乏的病人身上，B19會造成慢性貧血
  4. （D）病毒本身不帶有DNA聚合酶（polymerase）， 因此只能在生長中的細胞裏複製

第 13 題

有關流感病毒減毒疫苗（live attenuated influenza vaccine）的敘述，下列何者錯誤？
  1. （A）適當生長溫度是攝氏25度
  2. （B）大部分在鼻咽部感染
  3. （C）容易刺激IgA抗體的產生
  4. （D）適用於60歲以上之成人

答案：（D）

  2. （B）體細胞超突變（somatic hypermutation）需要AID（activation-induced cytidine deaminase）一種脫胺酵素的參與，主要是作用在胞嘧啶（cytosine, C）上使之轉變為尿嘧啶（uridine, U），再經過DNA修復作用引起突變

  3. （C）患者自體的血小板凝集蛋白（thrombospondin）受到抑制，造成受到瘧原蟲寄生的紅血球集結成團，進而影響血流

  1. （A）世代研究
  2. （B）病例對照研究
  3. （C）生態研究
  4. （D）橫斷式研究

答案：（A）

詳解與考點

正解：先依暴露狀態分組，再向後追蹤疾病發生。研究一開始納入 1400 名無肺癌者，分為 700 名抽菸者與 700 名不抽菸者，追蹤 5 年後比較各組肺癌新發個案數，這是世代研究（cohort study），故選 A。

B：病例對照研究是先依疾病狀態選病例與對照，再回溯比較過去暴露；本題的起點是無病者與抽菸暴露，方向相反。

C：生態研究以地區、國家等群體的彙整資料為分析單位，本題追蹤的是個別受試者。

D：橫斷式研究在單一時間點同時評估暴露與疾病，不能呈現本題 5 年追蹤的新發疾病時間順序。

本題考點：世代研究（cohort study）的暴露先行與追蹤設計；發生率（incidence）比較；病例對照研究（case-control study）與橫斷式研究（cross-sectional study）的區分。

第 39 題

假設有一個疾病為顯性遺傳病，得病者父母親中，其中有一位有病，另一位則無。這種疾病每位子女遺傳的機率 1/2，一個有 2 個小孩的家庭，兩個小孩皆得病的機率為何？
  1. （A）0
  2. （B）1/2
  3. （C）1/4
  4. （D）1/8

答案：（C）

詳解與考點

正解：每一位子女得病機率為 1/2，且兩位子女的遺傳結果分開計算。第一位小孩得病機率為 1/2，第二位小孩得病機率也為 1/2；兩人皆得病須同時發生，故機率為 1/2 × 1/2 = 1/4。因此選 C。

A：機率不是 0，因為題目已明示每位子女都有 1/2 的遺傳機率。

B：1/2 是單一子女得病的機率，沒有乘入另一位子女也必須得病的條件。

D：1/8 會低估一次，常見於把兩個獨立的 1/2 事件錯誤地多乘一次 1/2。

本題考點：常染色體顯性遺傳（autosomal dominant inheritance）；獨立事件（independent events）的乘法法則；機率計算（probability calculation）。

  1. （A）組織型胞漿素原活化因子（tissue-type plasminogen activator）
  2. （B）組織因子（tissue factor）
  3. （C）凝血酵素（thrombin）
  4. （D）內皮素（endothelin）

答案：（D）

詳解與考點

正解：小動脈受損後要加強「短暫收縮」的物質。內皮素（endothelin）由受損或活化的內皮細胞釋放，是強力血管收縮胜肽，可協助初期止血時縮小血管腔、降低出血，故選 D。

A：組織型胞漿素原活化因子（tissue-type plasminogen activator）促進纖維蛋白溶解，作用是分解血栓，不是增強血管收縮。

B：組織因子（tissue factor）啟動外因性凝血途徑，主要促進凝血酶與纖維蛋白形成，並非直接造成血管收縮。

C：凝血酶（thrombin）將纖維蛋白原轉為纖維蛋白，也會活化血小板；它看似參與止血，但題目問的是直接加強小動脈收縮的介質，最符合的是（D）內皮素。

A：腦膜炎雙球菌（Neisseria meningitidis）敗血症是Waterhouse-Friderichsen症候群的典型相關感染，敘述正確，故非答案。

B：急性腎上腺功能不全、敗血性休克及血管塌陷可造成嚴重低血壓，敘述正確，故非答案。

C：重度敗血症可併發瀰漫性血管內凝血（disseminated intravascular coagulation, DIC），並加重出血，敘述正確，故非答案。

本題考點：Waterhouse-Friderichsen症候群（Waterhouse-Friderichsen syndrome）是敗血症造成的雙側腎上腺出血；腦膜炎雙球菌敗血症（meningococcemia）是典型病因；瀰漫性血管內凝血（DIC）與休克共同加重器官損傷。

第 93 題

在藥物或毒物所引起的腎小管間質性腎炎，在間質中浸潤的炎症細胞主要為：
  1. （A）淋巴球及巨噬細胞
  2. （B）嗜酸性白血球
  3. （C）漿細胞
  4. （D）肥大細胞

答案：（A）

詳解與考點

正解：藥物或毒物引起的腎小管間質性腎炎（tubulointerstitial nephritis）屬間質性免疫發炎，主要浸潤細胞是淋巴球及巨噬細胞；嗜酸性白血球可以出現且具提示性，但通常不是主要成分，故選 A。

B：嗜酸性白血球與藥物誘發性腎間質性腎炎常有關，是很強的誘答；但它是伴隨性特徵，主要間質浸潤仍以（A）淋巴球及巨噬細胞為主。

C：漿細胞大量浸潤較提示其他慢性發炎或特定免疫疾病，並非此病最典型的主要浸潤細胞。

D：肥大細胞可參與過敏反應，但不是藥物或毒物性腎小管間質性腎炎的主要組織浸潤細胞。

本題考點：急性腎小管間質性腎炎（acute tubulointerstitial nephritis）常由藥物引起；主要間質浸潤為淋巴球與巨噬細胞（lymphocytes and macrophages）；嗜酸性白血球（eosinophils）是常見但非必要的提示線索。

下列何者不是甲狀腺乳突狀癌（papillary carcinoma）之典型細胞核變化？
  1. （A）Ground-glass nuclei

  4. （D）Intranuclear grooves

  1. （A）是50歲以上男性最常見良性前列腺疾病
  2. （B）組織學上可見前列腺上皮與間質的結節性增生（nodular hyperplasia）
  3. （C）其致病機轉，主要是上皮細胞的大量增生

A：BPH是中老年男性常見的良性前列腺疾病，盛行率隨年齡增加，敘述正確，故非答案。

第 97 題

下列有關隱睪症（cryptorchidism）的敘述，何者較不正確？
  1. （A）睪丸的下移可以分為兩個時期，在第一時期，腹部位移時期（transabdominal phase），主要是受穆勒氏管抑制素（müllerian-inhibiting substance）的控制
  2. （B）睪丸的下移可以分為兩個時期，在第二時期，腹股溝陰囊時期（inguinoscrotal phase），主要是受雄性素（androgen）的控制
  3. （C）未下降的睪丸，如未及時治療，比正常下降的睪丸有更高發生睪丸癌的危險性
  4. （D）腹腔是睪丸未能按照正常發育程序從腰部腹膜後下降至陰囊而停留（arrest）的最常見位置

答案：（D）

詳解與考點

正解：題目問隱睪症（cryptorchidism）何者較不正確。未下降睪丸最常停留在腹股溝管，而不是腹腔；腹腔內睪丸是較高位但較不常見的位置，故選 D。

A：睪丸下降可分腹部位移期與腹股溝陰囊期，第一期受穆勒氏管抑制素（müllerian-inhibiting substance）等發育訊號影響，敘述方向正確，故非答案。

B：腹股溝陰囊期的睪丸下降需要雄性素（androgen）訊號參與，敘述正確，故非答案。

C：未下降睪丸有較高的生殖細胞腫瘤風險；及時治療有助於追蹤與生育功能處理，但不能把原有風險完全歸零，敘述正確，故非答案。

本題考點：隱睪症（cryptorchidism）是睪丸下降異常；睪丸下降（testicular descent）分腹部位移期與腹股溝陰囊期；最常見停留處是腹股溝管（inguinal canal），並與不孕及睪丸癌風險增加相關。
