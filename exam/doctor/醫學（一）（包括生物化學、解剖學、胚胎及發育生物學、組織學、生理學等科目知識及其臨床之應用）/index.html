第 1 題

顏面神經的感覺根（sensory root of facial nerve）主要將接收到的感覺訊息直接傳入下列腦幹內的那兩個神經核？
  1. （A）三叉神經脊髓核（spinal trigeminal nucleus）與孤立核（solitary nucleus）
  2. （B）三叉神經脊髓核（spinal trigeminal nucleus）與顏面運動神經核（facial motor nucleus）
  3. （C）疑核（nucleus ambiguus）與孤立核（solitary nucleus）
  4. （D）疑核（nucleus ambiguus）與涎核（salivatory nucleus）

答案：（A）

第 62 題

在整個呼吸循環（respiratory cycle）中，肺泡內壓（alveolar pressure, Palv）於何時達到最高點？
  1. （A）開始吸氣時
  2. （B）吸氣階段中途
  3. （C）吸氣結束，開始呼氣之前
  4. （D）呼氣階段中途

答案：（D）

第 22 題

關於女性外陰（vulva），下列敘述何者正確？
  1. （A）尿道旁腺（paraurethral glands）又稱為巴多林氏腺（Bartholin's glands），其導管（ducts）開口於尿道口附近
  2. （B）大前庭腺（greater vestibular gland）位於前庭球（bulb of vestibule）的前方
  3. （C）男性陰莖（penis）有懸韌帶（suspensory ligament），但女性陰蒂（clitoris）沒有
  4. （D）前庭球（bulb of vestibule）是由勃起組織（erectile tissue）構成

答案：（D）

第 82 題

大腸桿菌DNA複製過程中，DnaB解螺旋酶（DnaB helicase）會結合於A上，朝B方向行進，解開雙股DNA。前述A與B分別代表下列何者？
  1. （A）A：前進股（leading strand）；B：5’→ 3’
  2. （B）A：前進股（leading strand）；B：3’→ 5’
  3. （C）A：延遲股（lagging strand）；B：5’→ 3’
  4. （D）A：延遲股（lagging strand）；B：3’→ 5’

答案：（C）

第 42 題

在肛⾨直腸連接處（anorectal junction）的位置，會觀察到下列何項構造？
  1. （A）直腸（rectum）上⽪有許多杯狀細胞（goblet cells）
  2. （B）直腸（rectum）上⽪為複層扁平上⽪（stratified squamous epithelium）
  3. （C）肛⾨（anus）有Peyer's patch
  4. （D）肛⾨（anus）肌外層的縱⾛肌⾁（longitudinal layer of muscularis externa）有顯著加厚作為內括約肌（internal sphincter）

答案：（A）
