第 1 題

有關多發性硬化症之診斷檢查，下列何者錯誤？
  1. （A）腦脊髓液分析可發現IgG抗體上升
  2. （B）視覺誘發電位可觀察到受損的神經在傳導過程出現延遲和中斷
  3. （C）超音波檢查可發現中樞神經系統髓鞘脫失
  4. （D）核磁共振影像可用來確認多發性硬化症之斑塊

答案：（C）

詳解與考點

多發性硬化症（MS）的診斷工具：腦脊髓液分析可見 IgG 上升（A 正確），視覺誘發電位可測出傳導延遲（B 正確），MRI 可確認白質斑塊（D 正確）。C 選項「超音波可發現髓鞘脫失」錯誤——超音波無法穿透顱骨檢視中樞神經髓鞘，髓鞘脫失需靠 MRI 才能顯影，故 C 為錯誤診斷工具。

第 2 題

下列何者不是腦幹中風的常見之表徵？
  1. （A）眼球活動不協調
  2. （B）運動功能障礙
  3. （C）手顫抖
  4. （D）嘔吐反射減弱

答案：（C）

詳解與考點

腦幹負責眼球運動（CN III、IV、VI）、嘔吐反射（CN IX、X）、運動協調傳導等功能，腦幹中風會出現複視、眼球活動不協調（A）、對側運動障礙（B）及嘔吐反射減弱（D）。C「手顫抖（tremor）」主要與基底核（Parkinson's）或小腦病變相關，並非腦幹中風的典型表徵，故 C 為不常見之表徵。

第 3 題

有關頭部外傷病人顱內壓升高的處置，下列何者錯誤？
  1. （A）急性期可裝置顱內壓監測器，依醫囑引流腦脊髓液降低顱內壓
  2. （B）病人的格拉斯哥昏迷量表（GCS）總分為5分，表示病人處於昏迷狀態
  3. （C）使用Mannitol 降腦壓時，使用前後要注意血糖的變化
  4. （D）若病人的瞳孔突然放大、對光沒有反應或是固定、肌力及意識下降，有可能是顱內壓升高

答案：（C）

詳解與考點

本題問「錯誤」者，正解為（C）。（C）「使用 Mannitol 降腦壓時，使用前後要注意血糖的變化」為錯誤：Mannitol 為高滲透性利尿劑，藉滲透作用將組織間液拉入血管再經腎臟排出以降低顱內壓，使用前後主要應監測的是血清滲透壓、血鈉等電解質、腎功能、尿量及體液容積狀態（避免脫水、電解質失衡或腎損傷），其主要副作用並非血糖升高，故以「注意血糖變化」作為重點屬學理錯誤。（A）急性期可置放顱內壓監測器並依醫囑引流腦脊髓液以降腦壓，正確。（B）GCS 總分 5 分屬重度意識障礙、可判定為昏迷狀態（一般 GCS ≤ 8 即視為昏迷），敘述正確。（D）瞳孔突然放大、對光反射消失或固定、合併肌力與意識下降，可能是顱內壓升高、腦疝形成的警訊，正確。故錯誤者為（C）。

第 4 題

有關阿茲海默氏症之敘述，下列何者錯誤？
  1. （A）是一慢性、進展性、退化性腦部疾病
  2. （B）可能病因為年紀、基因遺傳
  3. （C）典型的症狀為長期記憶喪失
  4. （D）腦部典型變化為神經纖維糾結與老年性斑塊

答案：（C）

詳解與考點

阿茲海默症的典型早期症狀是「短期記憶（近期記憶）」喪失，而非長期記憶喪失——患者對遠期往事仍可保留相當記憶，卻無法記住剛發生的事。長期記憶通常在病程晚期才受損，故C「典型症狀為長期記憶喪失」為錯誤敘述。其餘選項（慢性退化性、年齡與基因遺傳為危險因子、神經纖維糾結與老年斑）均正確。

第 5 題

有關癲癇藥物Dilantin的敘述，下列何者正確？
  1. （A）靜脈輸注時須採用5%葡萄糖稀釋
  2. （B）口服常見的副作用為血液惡病質、心律不整等
  3. （C）指導病人須維持良好的口腔衛生，使用軟毛牙刷按摩牙齦
  4. （D）應維持血清治療濃度於80～100 mcg/dL

答案：（C）

詳解與考點

Dilantin（phenytoin）靜脈注射須以0.9% N/S稀釋，不可用葡萄糖液（會沉澱）。口服常見副作用為牙齦增生（gingival hyperplasia），而非心律不整（靜脈快速推注才有心律不整風險）。有效血清濃度為10～20 mcg/mL（非 mcg/dL、更非80～100）。因此C正確：牙齦增生是Dilantin著名副作用，指導病人以軟毛牙刷按摩牙齦可減輕症狀。

第 6 題

陳先生因肝硬化、嚴重腹水，出現呼吸急促、意識混亂的情形，由家人送往醫院接受治療，於實驗室檢查 中，可能出現下列何種結果？①ALT：80 U/L、AST：55 U/L ②albumin 4.0 gm/dL ③prothrombin time 5 sec ④ammonia 120 mg/dL
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

肝硬化嚴重腹水患者的預期實驗室結果：ALT/AST升高（肝細胞損傷，選①正確）；albumin應低（肝合成下降，選②的4.0 g/dL為正常值，不符）；prothrombin time應延長（肝合成凝血因子下降，正常約11–13秒，選③的5秒過短，不符）；ammonia應升高（肝解毒功能下降，120 mg/dL偏高，選④正確）。故答案①④為B。

第 7 題

承上題，關於陳先生的護理措施，下列何者正確？①限制水分與蛋白質的攝取 ②每天測量體重與腹圍，記 錄輸出入量 ③給與利尿劑後，儘快補充Albumin ④使用Lactulose以減少細菌分解蛋白質所產生大量氨
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（A）

詳解與考點

正解為（A），即「①②」。此為肝硬化併腹水／肝性腦病的護理。①於急性期或依醫囑限制水分與蛋白質攝取：腹水合併低血鈉時需限水，肝性腦病急性期須暫時限制蛋白質以減少氨的產生，故在此情境下①成立（屬視病況／依醫囑調整，非永久絕對禁食蛋白質）。②每天測量體重與腹圍、記錄輸出入量，以監測腹水及體液變化、評估利尿成效，為標準護理，正確。③敘述「給利尿劑後儘快補充 Albumin」順序與臨床常規不符：臨床多為先（或同時）補充白蛋白以提升血漿膠體滲透壓、再配合利尿，並非利尿後才『儘快』補白蛋白，故③不選。④「Lactulose 用以減少『細菌分解蛋白質』所產生的氨」對機轉的描述不夠精確：Lactulose 主要藉酸化腸道、促進氨轉為不易吸收的銨並經腸道排出，而「抑制腸道細菌、減少細菌產氨」較屬抗生素（如 rifaximin、neomycin）的作用，故此敘述易混淆而不選。綜合正確項為①②，選（A）。

第 8 題

有關不同部位腸造瘻特性之敘述，下列何者正確？
  1. （A）升結腸造瘻的排便沒有規則性
  2. （B）迴腸造瘻的大便性狀是半成形狀
  3. （C）乙狀結腸造瘻的液體需要量需增加
  4. （D）橫結腸造瘻不需要使用人工造口袋

答案：（A）

詳解與考點

升結腸造瘻（ascending colostomy）位於近端大腸，腸道水分尚未充分吸收，排便為液態且不規則，無法如乙狀結腸造瘻般訓練定時排便，故A「升結腸造瘻排便沒有規則性」正確。迴腸造瘻排便為液態（非半成形）；乙狀結腸造瘻無須額外增加液體需要量；橫結腸造瘻仍需人工造口袋。

第 9 題

有關膽道疾病的敘述，下列何者錯誤？
  1. （A）膽囊炎大部分是結石造成
  2. （B）膽道結石男性比女性發生機率高
  3. （C）可用meperidine HCL（Demerol®）肌肉注射止痛
  4. （D）急性膽囊炎病人會出現右上腹部疼痛

答案：（B）

詳解與考點

膽道結石（膽石症）的流行病學顯示女性發生率高於男性，尤其好發於40歲以上、肥胖、多次妊娠的女性（5F口訣：Female, Fat, Forty, Fertile, Fair），故B「男性比女性發生機率高」為錯誤敘述。其他選項（大部分為結石所致、Demerol止痛、右上腹疼痛）均正確。

第 10 題

有關預防傾倒症候群（dumping syndrome）的飲食建議，下列何者不適宜？
  1. （A）高醣食物
  2. （B）適量脂肪
  3. （C）高蛋白飲食
  4. （D）乾性食物

答案：（A）

詳解與考點

傾倒症候群（dumping syndrome）係胃切除術後食物過快進入小腸所致，預防原則為：高蛋白、適量脂肪、低醣（避免高醣）、乾性飲食（進食時減少液體，飯前後30分鐘再飲水）。高醣食物會加速滲透壓改變、加重傾倒症候群症狀，故A「高醣食物」為不適宜的飲食建議。

第 11 題

有關骨折癒合階段照護之敘述，下列何者正確？
  1. （A）血腫形成期，應鼓勵病人進行患肢等張運動
  2. （B）細胞增生期，應鼓勵病人進行患肢等張運動
  3. （C）骨痂形成期，應鼓勵病人補充足夠的營養
  4. （D）鞏固化與再塑造期，告知病人骨折癒合不需再運動

答案：（C）

詳解與考點

骨折癒合分四階段：血腫形成期→細胞增生期→骨痂形成期→鞏固化再塑造期。骨痂形成期骨組織正在礦化，此時補充足夠鈣質、蛋白質、維生素C/D等營養素有助骨痂鈣化，C正確。血腫形成期及細胞增生期不宜做患肢等張運動（會破壞血腫及新生組織）；鞏固化期仍需適當運動促進骨骼再塑造。

第 12 題

有關關節炎的敘述，下列何者正確？
  1. （A）骨性關節炎典型的疼痛在活動後加劇，休息後緩減
  2. （B）類風濕性關節炎晨間關節僵硬會在不活動後又出現
  3. （C）骨性關節炎是慢性、全身性、炎症性關節病變
  4. （D）骨性關節炎最先侵犯周邊小關節，包括指、腕、肘、踝、趾

答案：（A）

詳解與考點

本題問「正確」者，正解為（A）。（A）骨性關節炎（退化性關節炎，OA）的典型疼痛在「活動／負重後加劇、休息後緩解」，反映關節軟骨磨損與機械性負荷的特徵，敘述正確。（B）錯誤：類風濕性關節炎（RA）的特徵是「晨間僵硬」且僵硬感在久不活動後可再出現、活動後逐漸緩解，故說 RA 僵硬「不會在不活動後出現」與學理不符。（C）錯誤：OA 是局部、退化性、非全身性的關節病變；屬「慢性、全身性、炎症性」者為 RA，敘述張冠李戴。（D）錯誤：最先侵犯指、腕等周邊小關節並呈對稱性者是 RA；OA 好發於負重大關節（如膝、髖）及遠端指間關節等，故（D）將 OA 與小關節侵犯連結並不正確。綜合四項，唯（A）正確。

第 13 題

有關下背痛病人使用骨盆牽引治療之敘述，下列何者正確？
  1. （A）骨盆牽引是一種骨骼牽引，有助於緩解疼痛
  2. （B）牽引時床尾抬高可增加牽引的效果
  3. （C）保持臥於床之正中位置，膝、第二腳趾與滑輪在一直線位置
  4. （D）牽引使用之拉力可達體重的1/2

答案：（B）

詳解與考點

本題問「正確」者，正解為（B）。（B）「牽引時將床尾（腳端）抬高可增加牽引效果」正確：藉抬高床尾使病人體重產生反向拉力（反牽引），可維持並提升骨盆牽引的牽引效能，故正確。（A）錯誤：骨盆牽引屬「皮膚牽引」（經骨盆帶施力於皮膚與軟組織），並非穿過骨骼的「骨骼牽引」。（C）錯誤：題目情境為骨盆牽引，「膝、第二腳趾與滑輪成一直線」的對線描述是下肢牽引的評估重點，並非本題骨盆牽引的正確要點，敘述過於武斷而不切題。（D）「牽引拉力可達體重的 1/2」對皮膚牽引而言過大：皮膚牽引重量受限（過重會傷及皮膚），不宜達體重的一半，故錯誤。綜合判斷正確者為（B）。

第 14 題

下列何者為白內障最有效的治療方式？
  1. （A）手術置換水晶體
  2. （B）點散瞳劑
  3. （C）眼睛熱敷
  4. （D）配戴老花眼鏡

答案：（A）

詳解與考點

白內障係水晶體混濁導致視力模糊，目前唯一有效治療方法是手術摘除混濁水晶體並植入人工水晶體（IOL），A正確。點散瞳劑、熱敷、老花眼鏡均無法逆轉水晶體混濁，僅為症狀管理或非白內障之適應症。

第 15 題

有關鼻竇炎病人的護理指導，下列何者錯誤？
  1. （A）鼻竇炎是因鼻竇內黏膜發炎所造成
  2. （B）慢性鼻竇炎症狀消退後，即可停用抗生素
  3. （C）使用鼻滴劑時，可採用坐姿，頭向後仰
  4. （D）使用鼻滴劑時，避免過量，以防引起反彈效果

答案：（B）

詳解與考點

慢性鼻竇炎（細菌性）抗生素療程通常需持續3～6週，不可因症狀消退即自行停藥，以防感染復發或產生抗藥性，故B「症狀消退後即可停用抗生素」為錯誤護理指導。其餘（黏膜發炎、坐姿頭後仰使用鼻滴劑、避免過量防反彈效果）均正確。

第 16 題

有關心肌炎病人的護理指導，下列何者不適宜？
  1. （A）教導阻力運動，提升活動耐力
  2. （B）教導服用類固醇藥物，需觀察大便顏色
  3. （C）教導減少水分攝取，減少心臟前負荷
  4. （D）教導服用毛地黃，需監測脈搏

答案：（A）

詳解與考點

心肌炎急性期心肌受損、心功能下降，阻力運動（resistance exercise）會大幅增加心臟後負荷、加重心肌耗氧，為禁忌，故A「教導阻力運動提升活動耐力」不適宜。急性期應以臥床休息為主，漸進式活動須待病情穩定後才進行。其餘（類固醇監測大便顏色偵測消化道出血、限水減少前負荷、毛地黃監測脈搏）均正確。

第 17 題

有關心肌梗塞後性生活的建議事項，下列敘述何者正確？①應該儘量避免以免再次發作 ②能量消耗大約與 上下兩層樓相當 ③飽餐後或酒後比較適合性行為 ④性行為事後應預防性服用NTG ⑤應在熟悉的環境與 伴侶進行以避免過度緊張與刺激 ⑥環境的室溫勿太冷或太熱
  1. （A）①②③
  2. （B）①④⑥
  3. （C）②⑤⑥
  4. （D）③④⑤

答案：（C）

詳解與考點

正解為（C），即「②⑤⑥」。②性行為的能量消耗大致與爬上下兩層樓相當，屬中等強度活動，可作為評估心臟負荷能否承受的參考，敘述正確。⑤宜在熟悉的環境、與固定／熟悉伴侶進行，以減少緊張、刺激與額外的心臟負擔，正確。⑥環境室溫不宜過冷或過熱，避免極端溫度增加心血管負荷，正確。錯誤項：①「應儘量避免性行為以免再發作」過度消極，心肌梗塞病情穩定後在醫療評估下多可恢復性生活，故①錯。③「飽餐後或酒後較適合」錯誤，飽餐或飲酒後血流重新分配、心臟負荷增加，反而應避免。④「事後預防性服用 NTG」錯誤，NTG 應用於發作時緩解或依醫囑於活動『前』預防，而非事後常規服用。綜合正確組合為②⑤⑥，選（C）。

  2. （B）體液容積缺失

  2. （B）胸部X光出現肺浸潤
  3. （C）白血球上升
  4. （D）呼吸離軌度增加

答案：（D）

本題問「最不適當」者，正解為（D）。肺炎鏈球菌肺炎常造成肺實變，典型臨床表徵包括：痰量增多（常為鐵鏽色痰）、胸部 X 光呈現肺浸潤／實變、白血球上升等發炎反應，故（A）（B）（C）皆為合理且常見的表徵。（D）「呼吸離軌度增加」最不適當：肺實變側因肺組織充填、肺擴張受限，患側的胸廓擴張（呼吸運動度／呼吸離軌度）通常是『減少』而非增加；至於觸覺震顫（tactile fremitus）在實變時可能增強，但題目所述為胸廓擴張度，方向應為減少。因此將其描述為「增加」與肺實變的理學表現不符，故（D）為最不適當，選（D）。

  1. （A）①②
  2. （B）①③
  3. （C）②④
  4. （D）③④

答案：（A）

詳解與考點

COPD 病人進食時呼吸做功增加，建議①將氧氣面罩換為鼻套管以便進食時持續供氧，②選易咀嚼食物減少消耗；不增加碳水化合物（代謝產生更多 CO2，對已有 CO2 滯留者不利）；不限水分（COPD 通常需足夠水分稀化痰液）。故①②正確，答案為 A（①②）。

第 37 題

有關腎臟移植過程之敘述，下列何者錯誤？
  1. （A）病人術前需再進行血液透析移除體液與毒素
  2. （B）交叉試驗陰性才可以進行腎臟移植
  3. （C）移植腎多是植入於下腹部腔膜外的腸骨窩處
  4. （D）必須先移除原來腎臟再將新的腎臟做尿道接合

答案：（D）

詳解與考點

腎臟移植時，受贈者原有的病腎通常「不需移除」，新腎植入腹膜外腸骨窩（iliac fossa），並與腸骨動靜脈及膀胱吻合，輸尿管直接接膀胱而非尿道。選項 D 描述「先移除原腎再做尿道接合」為錯誤——尿道無須接合，且原腎不強制移除。其他三項均正確。

第 38 題

下列那些檢查前需要確認病人腎功能？①腎動脈攝影術 ②腎臟、輸尿管、膀胱X光檢查 ③腎臟超音波 ④逆行性腎盂攝影術 ⑤靜脈注射腎盂攝影術
  1. （A）①②
  2. （B）①⑤
  3. （C）②③
  4. （D）④⑤

答案：（B）

詳解與考點

需確認腎功能的檢查是使用含碘顯影劑者：①腎動脈攝影術（造影劑）及⑤靜脈注射腎盂攝影術（IV urography，需注射顯影劑）均需事先確認 eGFR，以防顯影劑腎病變。②KUB X 光和③腎臟超音波不使用顯影劑；④逆行性腎盂攝影由尿道逆向注射顯影劑，不經靜脈，腎功能影響小。故答案①⑤，選 B。

第 39 題

有關透析治療比較之敘述，下列何者正確？
  1. （A）血液透析的飲食限制，較腹膜透析嚴格
  2. （B）血液透析的蛋白質流失量，較腹膜透析多
  3. （C）血液透析發生高血脂比例，較腹膜透析高
  4. （D）血液透析對於心血管負荷，較腹膜透析少

答案：（A）

詳解與考點

本題問「正確」者，正解為（A）。（A）血液透析（HD）的飲食限制較腹膜透析（PD）嚴格，正確：HD 為間歇性治療，兩次透析間易蓄積水分、鉀、磷，故對水分、鉀、磷的限制較嚴；PD 為持續性清除，飲食限制相對較寬鬆。（B）錯誤：蛋白質流失方向相反，PD 因蛋白質會隨透析液持續流失（每日可達數克至十餘克），其蛋白質流失量通常較 HD 多，故說「HD 蛋白質流失較 PD 多」不正確。（C）錯誤：PD 因透析液中含葡萄糖、長期吸收易致血脂異常，發生高血脂的比例通常較 HD 高，敘述相反。（D）錯誤：HD 在短時間內大量移除水分、造成血流動力快速變化，對心血管系統的負荷通常較大而非較少。綜合判斷，唯（A）正確。

第 40 題

韓小姐的動脈血液氣體分析結果為pH 7.44、PaCO2 30 mmHg、HCO3 - 20 mmHg、PaO2 82 mmHg，根據以上數 值，判讀結果下列何者正確？
  1. （A）部分代償性呼吸性酸中毒
  2. （B）未代償性代謝性酸中毒
  3. （C）未代償性代謝性鹼中毒
  4. （D）完全代償性呼吸性鹼中毒

答案：（D）

詳解與考點

pH 7.44（正常偏鹼）、PaCO2 30 mmHg（偏低，呼吸過度）、HCO3- 20 mEq/L（偏低）。PaCO2 低→呼吸性鹼中毒為原發；HCO3- 代償性下降至 20（正常 24）→腎臟已代償排出 HCO3-；pH 回到正常範圍（7.44），代表完全代償性呼吸性鹼中毒，選 D。

第 41 題

有關良性前列腺肥大（BPH）之敘述，下列何者錯誤？
  1. （A）是男性常見的老年疾病，是前列腺體的細胞本身肥大所致
  2. （B）尿路動力學檢查時發現病人的最大尿流速會減低
  3. （C）病人常主訴頻尿或餘尿感（解不乾淨）
  4. （D）肛門觸診可以評估前列腺肥大的程度

答案：（A）

詳解與考點

良性前列腺肥大（BPH）的病理機轉是前列腺「基質細胞與上皮細胞增生（hyperplasia）」，而非細胞本身「肥大（hypertrophy）」，故選項 A「細胞本身肥大」敘述有誤為答案。BPH 確為老年男性常見，且會使最大尿流速下降，症狀有頻尿、餘尿感，肛診（DRE）可評估前列腺大小。

第 42 題

有關原發性醛固酮過多症之護理措施，下列何者錯誤？
  1. （A）需觀察病人有無肌肉軟弱無力、疲倦、麻痹、心律不整等臨床表徵
  2. （B）需觀察病人有無強直性痙攣和呼吸抑制情形
  3. （C）教導病人飲食中應多補充高鈉食物，例如火腿、香腸、起司等
  4. （D）需注意病人血壓的變化，有無血壓過高情形

答案：（C）

詳解與考點

原發性醛固酮過多症（Conn's syndrome）因醛固酮過多導致鈉滯留、鉀流失，引發高血壓、低血鉀。選項 C「多補充高鈉食物」明顯錯誤——病人已鈉滯留且高血壓，應限鈉飲食。低血鉀引發的肌肉軟弱、抽搐及呼吸抑制須注意，血壓監測也必要，故 A、B、D 均正確。

第 43 題

有關抗利尿激素分泌不當症候群（SIADH）病人的臨床照護，下列何者錯誤？
  1. （A）依醫囑補充3%生理食鹽水的靜脈輸液及注射furosemide（Lasix®）
  2. （B）鼓勵病人多攝取低纖食物
  3. （C）監測有無出現肌肉抽搐與昏迷的徵象
  4. （D）依醫囑限制水分攝取每日在1,000 c.c.以下

答案：（B）

詳解與考點

本題問「錯誤」的照護措施，答案為（B）。SIADH 因 ADH 分泌過多，造成水分滯留、稀釋性低血鈉與水中毒，照護重點是限制水分（每日約 800～1,000 c.c. 以下，故 D 正確），嚴重低血鈉（< 120 mmol/L 或出現抽搐、昏迷）時依醫囑緩慢輸注 3% 高張食鹽水並可合併 furosemide（Lasix®）以促進排水（A 正確）。furosemide 屬亨利氏環利尿劑（loop diuretic），會抑制鈉、氯與水的再吸收，造成水分與鈉一起排出、且常伴隨鉀流失，並非「促鈉保鉀」；使用高張食鹽水加 loop diuretic 時須嚴密監測血鈉、血鉀並控制矯正速度（避免過快引發橋腦中心髓鞘溶解）。低血鈉會引起神經肌肉症狀，故監測肌肉抽搐與昏迷徵象正確（C 正確）。（B）錯在「鼓勵多攝取低纖食物」與 SIADH 的水鈉失衡照護無關，亦非適當指導，故為錯誤選項即本題正解。

第 44 題

有關雙胍類降血糖藥物metformin（Glucophage®）之敘述，下列何者錯誤？
  1. （A）減少肝臟葡萄糖的輸出，以降低空腹血糖
  2. （B）最好與食物一起服用，或飯後馬上服用
  3. （C）易出現胃腸道刺激及引發維生素B6缺乏
  4. （D）腎功能不良的病人需要小心使用

答案：（C）

詳解與考點

metformin 常見胃腸道副作用（噁心、腹瀉）及長期使用引起維生素 B12 缺乏（因干擾迴腸末端 B12 吸收），非維生素 B6 缺乏，故選項 C 錯誤。metformin 確實減少肝葡萄糖輸出、建議隨餐服用，腎功能不良（eGFR<30 mL/min）禁用（防乳酸酸中毒）。

第 45 題

張太太，罹患糖尿病2年，平日使用口服抗血糖藥物控制血糖，今日在家昏倒被送至急診，醫師初步診斷為 高滲透壓高血糖狀態（HHS），病人會呈現的徵象，下列何者正確？①呼吸速率26次／分 ②血壓166/84 mmHg ③尿酮呈陽性反應，明顯升高 ④血糖為750 mg/dL。
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

答案為（B），即敘述①與④正確。HHS（高滲透壓高血糖狀態）多見於第 2 型糖尿病、口服降血糖藥控制者，特徵是極度高血糖（常 > 600 mg/dL，本題 750 mg/dL，故④正確）、嚴重高血漿滲透壓與明顯脫水，但因仍有少量胰島素可抑制脂肪分解，故「無顯著酮體堆積、無明顯代謝性酸中毒」，尿酮陰性或僅微量（故③錯誤）。嚴重脫水與高滲透壓可造成代償性呼吸稍快，呼吸 26 次／分屬可見表徵（①可成立）；而嚴重脫水會使血容量不足、血壓偏低甚至休克，並不會出現血壓升高至 166/84 mmHg（故②錯誤）。綜合①④正確、②③錯誤，正解為（B）。註：明顯酮酸與酸中毒型深快呼吸（Kussmaul）是 DKA 的特徵，而非 HHS。

第 46 題

有關甲狀腺機能亢進病人服用飽和碘化鉀溶液之敘述，下列何者正確？
  1. （A）絕不可與牛奶一起服用
  2. （B）主要功能是抑制T4轉變為T3
  3. （C）可以降低甲狀腺素的釋放及合成
  4. （D）要長期服用超過一個月才能評估臨床效果

答案：（C）

詳解與考點

飽和碘化鉀溶液（SSKI）用於甲亢術前準備，機轉是抑制甲狀腺素的「釋放」及「合成」（Wolff-Chaikoff effect），故選項 C 正確。SSKI 可與果汁或牛奶混合服用以減少胃刺激（A 錯）；抑制 T4 轉 T3 是 PTU 的特性（B 錯）；SSKI 短期（10–14 天）即可見效，不需長期超過一個月（D 錯）。

第 47 題

有關休克病人體溫下降之護理措施，下列何者正確？
  1. （A）當身體顫抖產熱及代謝增加，應調低室溫以減少發燒程度
  2. （B）靜脈注射的液體或血液，應加溫至接近正常體溫
  3. （C）使用熱水袋或電毯包裹四肢
  4. （D）給予熱水浴，以增加病人舒適感

答案：（B）

詳解與考點

休克病人體溫下降（低體溫）的護理：靜脈輸液或血液製品應加溫至接近正常體溫（37°C），避免加重低體溫，故 B 正確。不應調低室溫（A 錯，應維持溫暖）；熱水袋包裹四肢會造成外周血管擴張、血液重新分配離心，加重循環衰竭（C 錯）；熱水浴禁用於休克病人（D 錯，風險過高）。

第 48 題

有關食物中毒之敘述，下列何者正確？
  1. （A）河豚中毒主要是處理河豚過程被細菌污染造成
  2. （B）金黃色葡萄球菌中毒症狀主要是視力模糊、吞嚥困難
  3. （C）沙門氏桿菌中毒症狀主要是腹瀉、噁心、嘔吐及發燒
  4. （D）食物中毒之嚴重度與食入污染物的量與內毒素含量呈負相關

答案：（C）

詳解與考點

沙門氏桿菌（Salmonella）食物中毒典型症狀為腹瀉、噁心、嘔吐及發燒，潛伏期 12–48 小時，C 正確。河豚中毒為河豚毒素（tetrodotoxin）導致，非細菌污染（A 錯）；金黃色葡萄球菌中毒主要症狀為嘔吐、腹痛，視力模糊、吞嚥困難是肉毒桿菌的特徵（B 錯）；嚴重度與毒素量呈正相關而非負相關（D 錯）。

第 49 題

有關自動體外電擊去顫器（AED）操作，下列敘述何者錯誤？
  1. （A）可由非醫護人員操作使用
  2. （B）若病人體內裝有人工心臟節律器就不能使用AED
  3. （C）操作步驟口訣：開、貼、插、按
  4. （D）按電擊鈕前先清場，確認無人接觸病人

答案：（B）

詳解與考點

體內裝有人工心臟節律器（pacemaker）並非 AED 的絕對禁忌症；若病人有節律器，貼片應避開裝置位置（距至少 8 cm），仍可使用 AED，故 B「就不能使用 AED」的說法錯誤。AED 可由非醫護人員操作、步驟口訣「開、貼、插、按」、電擊前須清場確保無人接觸病人，以上均正確。

第 50 題

有關漢生病（Hansen's disease）俗稱痲瘋（leprosy）的照護措施，下列何者正確？
  1. （A）最常侵犯腸胃系統，應加強評估消化功能與營養狀態
  2. （B）照護時採接觸及呼吸道隔離
  3. （C）目前無治療藥物，採支持療法
  4. （D）皮膚病變僅出現在臉部

答案：（B）

詳解與考點

答案為（B）。漢生病由痲瘋分枝桿菌（Mycobacterium leprae）引起，主要侵犯周邊神經與皮膚，造成皮膚斑塊、感覺喪失與肢端變形，並不是侵犯腸胃系統（故 A 錯），皮膚病變也分布全身而非僅限臉部（故 D 錯）。本病有有效藥物，採世界衛生組織建議之多重藥物治療（MDT，如 dapsone、rifampicin、clofazimine），並非僅支持療法（故 C 錯）。就本題作答而言，相對於 A、C、D 三項明顯違反學理，（B）為單選題中唯一可選的答案。需提醒：依現行感染管制建議，漢生病傳染力低、潛伏期長，一般採標準防護（standard precautions）即可，治療開始後傳染性更迅速下降；本題以「接觸及呼吸道隔離」作為標準答案屬考題用法，臨床上不必對所有個案常規執行接觸加呼吸道隔離。
