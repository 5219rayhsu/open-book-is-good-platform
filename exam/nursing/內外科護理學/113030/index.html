第 1 題

有關多發性硬化症之診斷檢查，下列何者錯誤？
  1. （A）腦脊髓液分析可發現IgG抗體上升
  2. （B）視覺誘發電位可觀察到受損的神經在傳導過程出現延遲和中斷
  3. （C）超音波檢查可發現中樞神經系統髓鞘脫失
  4. （D）核磁共振影像可用來確認多發性硬化症之斑塊

答案：（C）

詳解與考點

正解：判準是超音波的穿透力與解析度能否呈現中樞神經髓鞘脫失病灶。多發性硬化症（MS）為中樞神經去髓鞘疾病，診斷需仰賴能穿透顱骨並解析軟組織細節的影像工具；超音波因穿透力與解析度有限，無法呈現腦部與脊髓的髓鞘脫失病灶，故C為錯誤的診斷方式。

A：腦脊髓液分析可發現IgG抗體上升，是MS常見的腦脊髓液異常，屬正確診斷工具。 B：視覺誘發電位可測出受損神經傳導延遲與中斷，反映視神經去髓鞘後傳導速度下降，屬正確診斷工具。 D：核磁共振影像（MRI）可清楚顯示腦室周圍與脊髓的白質斑塊，是確診MS最主要的影像工具，屬正確診斷工具。

本題考點：MS診斷工具的判準——腦脊髓液IgG抗體異常、視覺誘發電位傳導延遲、核磁共振影像（MRI）白質斑塊三者皆為有效工具；超音波受限於穿透力與解析度，無法用於中樞神經髓鞘的影像判讀。

第 2 題

下列何者不是腦幹中風的常見之表徵？
  1. （A）眼球活動不協調
  2. （B）運動功能障礙
  3. （C）手顫抖
  4. （D）嘔吐反射減弱

答案：（C）

詳解與考點

正解：關鍵在「手顫抖」與腦幹解剖功能之間的落差。腦幹中風的表徵源自其所含的顱神經核與運動傳導徑；手顫抖（tremor）屬錐體外系症狀，主要與基底核病變（如Parkinson's disease）或小腦病變相關，並非腦幹中風的典型表徵，故C為正確答案（即不常見之表徵）。

A：眼球活動不協調反映第三、四、六對顱神經（CN III、IV、VI）受損，屬腦幹中風常見表徵。 B：運動功能障礙（如對側肢體無力）反映腦幹內運動傳導徑受損，屬常見表徵。 D：嘔吐反射減弱反映第九、十對顱神經（CN IX、X）核受損，屬常見表徵。

本題考點：腦幹中風表徵的判準——涉及顱神經核（CN III、IV、VI主眼球運動；CN IX、X主嘔吐反射）與運動傳導徑者屬腦幹病變；手顫抖等錐體外系症狀應歸類基底核或小腦病變，不屬腦幹中風表徵。

第 3 題

有關頭部外傷病人顱內壓升高的處置，下列何者錯誤？
  1. （A）急性期可裝置顱內壓監測器，依醫囑引流腦脊髓液降低顱內壓
  2. （B）病人的格拉斯哥昏迷量表（GCS）總分為5分，表示病人處於昏迷狀態
  3. （C）使用Mannitol 降腦壓時，使用前後要注意血糖的變化
  4. （D）若病人的瞳孔突然放大、對光沒有反應或是固定、肌力及意識下降，有可能是顱內壓升高

答案：（C）

詳解與考點

正解：判準在Mannitol降腦壓時使用前後應監測的項目。Mannitol屬高滲透性利尿劑，作用機轉是將組織間液滲透至血管內再經腎臟排出以降低顱內壓，使用前後應監測的重點是血清滲透壓、血鈉等電解質、腎功能與尿量，以避免脫水、電解質失衡或腎損傷；血糖並非其主要監測項目，故C「使用前後要注意血糖的變化」為學理錯誤的敘述。

A：急性期可裝置顱內壓監測器，並依醫囑引流腦脊髓液以降低顱內壓，屬正確處置。 B：格拉斯哥昏迷量表（GCS）總分5分屬重度意識障礙，臨床上GCS≤8即可判定為昏迷狀態，敘述正確。 D：瞳孔突然放大、對光反射消失或固定，合併肌力與意識下降，屬顱內壓升高、腦疝形成的典型警訊，敘述正確。

本題考點：顱內壓升高處置的判準——顱內壓監測器搭配腦脊髓液引流為標準急性期處置；Mannitol的監測重點是滲透壓、電解質與腎功能而非血糖；GCS≤8為昏迷判定門檻；瞳孔變化合併意識與肌力下降是腦疝警訊。

第 4 題

有關阿茲海默氏症之敘述，下列何者錯誤？
  1. （A）是一慢性、進展性、退化性腦部疾病
  2. （B）可能病因為年紀、基因遺傳
  3. （C）典型的症狀為長期記憶喪失
  4. （D）腦部典型變化為神經纖維糾結與老年性斑塊

答案：（C）

詳解與考點

正解：阿茲海默氏症（Alzheimer's disease）早期典型記憶喪失的類型，是本題判準所在——其早期典型症狀是短期（近期）記憶喪失，患者對遠期往事往往仍保留相當記憶，卻無法記住剛發生的事；長期記憶通常要到病程晚期才受損，故C「典型的症狀為長期記憶喪失」為錯誤敘述。

A：阿茲海默氏症屬慢性、進展性、退化性的腦部疾病，敘述正確。 B：年紀增長與基因遺傳皆為阿茲海默氏症的可能病因，敘述正確。 D：神經纖維糾結與老年性斑塊為阿茲海默氏症的典型腦部病理變化，敘述正確。

本題考點：阿茲海默氏症的判準——早期記憶喪失以短期（近期）記憶為主、長期記憶留待晚期才受損；疾病本質為慢性進展性退化；年齡與基因為危險因子；神經纖維糾結與老年性斑塊為病理標誌。

第 5 題

有關癲癇藥物Dilantin的敘述，下列何者正確？
  1. （A）靜脈輸注時須採用5%葡萄糖稀釋
  2. （B）口服常見的副作用為血液惡病質、心律不整等
  3. （C）指導病人須維持良好的口腔衛生，使用軟毛牙刷按摩牙齦
  4. （D）應維持血清治療濃度於80～100 mcg/dL

答案：（C）

詳解與考點

正解：Dilantin（phenytoin）口服最著名的副作用是牙齦增生（gingival hyperplasia），這是本題的判準。此藥物會刺激牙齦結締組織增生，指導病人使用軟毛牙刷按摩牙齦、維持良好口腔衛生可減輕此副作用，故C為正確敘述。

A：Dilantin靜脈輸注須以0.9%生理食鹽水（N/S）稀釋，若以5%葡萄糖液稀釋會產生沉澱，故A錯誤。 B：口服Dilantin常見副作用為牙齦增生、嗜睡、共濟失調等，心律不整多見於靜脈快速推注過快時而非口服常見副作用，血液惡病質亦非其典型口服副作用，故B錯誤。 D：Dilantin的有效血清治療濃度為10～20 mcg/mL，單位與數值皆與題述「80～100 mcg/dL」不符，故D錯誤。

本題考點：Dilantin（phenytoin）用藥判準——靜脈輸注限用0.9%生理食鹽水（N/S）稀釋（葡萄糖液會致沉澱）；口服典型副作用為牙齦增生、需搭配軟毛牙刷口腔照護；治療血清濃度為10～20 mcg/mL，注意單位（mcg/mL非mcg/dL）與數值範圍。

第 6 題

陳先生因肝硬化、嚴重腹水，出現呼吸急促、意識混亂的情形，由家人送往醫院接受治療，於實驗室檢查 中，可能出現下列何種結果？①ALT：80 U/L、AST：55 U/L ②albumin 4.0 gm/dL ③prothrombin time 5 sec ④ammonia 120 mg/dL
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：判準在於肝硬化併嚴重腹水、意識混亂病人的實驗室數值組合是否符合肝功能衰竭合併肝性腦病的病理生理。①ALT 80 U/L、AST 55 U/L顯示肝細胞損傷、轉胺酶上升，符合肝硬化活動期表現；④ammonia 120 mg/dL偏高，反映肝臟解毒（尿素循環）功能下降、氨無法有效代謝，與病人出現意識混亂（肝性腦病）相符；①④皆成立，故選B。

A（①②）：②albumin 4.0 gm/dL屬正常範圍，但肝硬化因肝合成功能下降，血清白蛋白應偏低，此數值與病情不符，故A不選。 C（②③）：②同上偏離預期；③prothrombin time 5秒過短——凝血酶原時間正常約11～13秒，肝臟合成凝血因子功能下降時應延長而非縮短，故③亦不符，C不選。 D（③④）：③prothrombin time 5秒同樣過短、不符肝功能下降應延長之預期，雖④成立，D仍因③錯誤而不選。

本題考點：肝硬化併肝衰竭的實驗室判準——轉胺酶（ALT/AST）上升反映肝細胞損傷；albumin應下降而非正常；prothrombin time應延長而非縮短；ammonia上升與肝性腦病相符。四項數值需逐一核對是否符合「肝功能下降」的方向，而非只看數字本身是否偏高。

第 7 題

承上題，關於陳先生的護理措施，下列何者正確？①限制水分與蛋白質的攝取 ②每天測量體重與腹圍，記 錄輸出入量 ③給與利尿劑後，儘快補充Albumin ④使用Lactulose以減少細菌分解蛋白質所產生大量氨
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（A）

詳解與考點

正解為（A），即「①②」。此為肝硬化併腹水／肝性腦病的護理。①於急性期或依醫囑限制水分與蛋白質攝取：腹水合併低血鈉時需限水，肝性腦病急性期須暫時限制蛋白質以減少氨的產生，故在此情境下①成立（屬視病況／依醫囑調整，非永久絕對禁食蛋白質）。②每天測量體重與腹圍、記錄輸出入量，以監測腹水及體液變化、評估利尿成效，為標準護理，正確。③敘述「給利尿劑後儘快補充 Albumin」順序與臨床常規不符：臨床多為先（或同時）補充白蛋白以提升血漿膠體滲透壓、再配合利尿，並非利尿後才『儘快』補白蛋白，故③不選。④「Lactulose 用以減少『細菌分解蛋白質』所產生的氨」對機轉的描述不夠精確：Lactulose 主要藉酸化腸道、促進氨轉為不易吸收的銨並經腸道排出，而「抑制腸道細菌、減少細菌產氨」較屬抗生素（如 rifaximin、neomycin）的作用，故此敘述易混淆而不選。綜合正確項為①②，選（A）。

第 8 題

有關不同部位腸造瘻特性之敘述，下列何者正確？
  1. （A）升結腸造瘻的排便沒有規則性
  2. （B）迴腸造瘻的大便性狀是半成形狀
  3. （C）乙狀結腸造瘻的液體需要量需增加
  4. （D）橫結腸造瘻不需要使用人工造口袋

答案：（A）

詳解與考點

正解：不同部位腸造瘻的排便特性，取決於腸道對水分的吸收程度隨造瘻位置而異，這是本題判準。升結腸位於近端大腸，腸內容物尚未經大腸充分吸收水分，故升結腸造瘻（ascending colostomy）排出的糞便呈液態且不規則，無法像乙狀結腸造瘻般訓練定時排便，故A為正確敘述。

B：迴腸造瘻的排泄物尚未進入大腸吸收水分，糞便性狀為液態，並非半成形，故B錯誤。 C：乙狀結腸造瘻位於大腸末端，糞便已接近成形，並不需要額外增加液體攝取量，故C錯誤。 D：橫結腸造瘻仍需使用人工造口袋收集排泄物，故D錯誤。

本題考點：腸造瘻排便特性的判準——造瘻位置愈接近近端（迴腸、升結腸），大腸尚未吸收水分，糞便愈液態、愈不規則；愈接近遠端（乙狀結腸），糞便愈成形、愈可訓練定時排便；各部位造瘻皆需使用人工造口袋收集排泄物。

第 9 題

有關膽道疾病的敘述，下列何者錯誤？
  1. （A）膽囊炎大部分是結石造成
  2. （B）膽道結石男性比女性發生機率高
  3. （C）可用meperidine HCL（Demerol®）肌肉注射止痛
  4. （D）急性膽囊炎病人會出現右上腹部疼痛

答案：（B）

詳解與考點

正解：關鍵在膽道結石的性別好發差異。膽石症好發於女性，尤以40歲以上、肥胖、多次妊娠的女性為典型族群（5F口訣：Female, Fat, Forty, Fertile, Fair），女性發生率高於男性，故B「膽道結石男性比女性發生機率高」與流行病學相反，為錯誤敘述。

A：膽囊炎大部分是膽結石造成，屬正確敘述。 C：可用meperidine HCL（Demerol®）肌肉注射止痛以緩解膽絞痛，屬正確敘述。 D：急性膽囊炎病人典型會出現右上腹部疼痛，屬正確敘述。

本題考點：膽道疾病判準——膽石症的性別好發以女性為主（5F：Female、Fat、Forty、Fertile、Fair）；膽囊炎多由結石所致；急性膽囊炎典型表現為右上腹痛；meperidine（Demerol®）可用於止痛。

第 10 題

有關預防傾倒症候群（dumping syndrome）的飲食建議，下列何者不適宜？
  1. （A）高醣食物
  2. （B）適量脂肪
  3. （C）高蛋白飲食
  4. （D）乾性食物

答案：（A）

詳解與考點

正解：判準在哪一項飲食會加速滲透壓改變、誘發傾倒症候群（dumping syndrome）。傾倒症候群是胃切除術後食物過快進入小腸所致，飲食原則為高蛋白、適量脂肪、低醣、乾性食物；高醣食物會使腸腔滲透壓迅速升高、拉入大量水分而加重症狀，故A「高醣食物」為不適宜的飲食建議。

B：適量脂肪攝取符合傾倒症候群的飲食原則，屬適宜建議。 C：高蛋白飲食有助組織修復且不易造成滲透壓劇烈變化，屬適宜建議。 D：乾性食物（進食時減少液體攝取，於飯前後30分鐘再補充水分）可延緩食物進入小腸的速度，屬適宜建議。

本題考點：傾倒症候群（dumping syndrome）飲食判準——高蛋白、適量脂肪、低醣（避免高醣）、乾性食物（進食與飲水分開）四項原則，核心在避免腸腔滲透壓快速上升。

第 11 題

有關骨折癒合階段照護之敘述，下列何者正確？
  1. （A）血腫形成期，應鼓勵病人進行患肢等張運動
  2. （B）細胞增生期，應鼓勵病人進行患肢等張運動
  3. （C）骨痂形成期，應鼓勵病人補充足夠的營養
  4. （D）鞏固化與再塑造期，告知病人骨折癒合不需再運動

答案：（C）

詳解與考點

正解：骨折癒合分四階段，各階段組織狀態決定護理措施，這是本題判準——骨折癒合依序經歷血腫形成期、細胞增生期、骨痂形成期、鞏固化與再塑造期。骨痂形成期骨組織正在礦化，此時補充足夠的鈣質、蛋白質與維生素C/D等營養素有助骨痂鈣化與強化，故C為正確敘述。

本題考點：骨折癒合四階段的照護判準——血腫形成期與細胞增生期應避免患肢等張運動以保護新生組織；骨痂形成期著重營養補充以助礦化；鞏固化與再塑造期仍需適當運動促進骨骼重塑。

  2. （B）教導服用類固醇藥物，需觀察大便顏色
  3. （C）教導減少水分攝取，減少心臟前負荷
  4. （D）教導服用毛地黃，需監測脈搏

詳解與考點

正解：關鍵在阻力運動（resistance exercise）對心臟負荷的影響。心肌炎急性期心肌受損、心功能下降，阻力運動會大幅增加心臟後負荷與心肌耗氧量，屬禁忌，急性期應以臥床休息為主，待病情穩定後才漸進式活動，故A「教導阻力運動，提升活動耐力」為不適宜的指導。

D：教導服用毛地黃需監測脈搏，以早期發現毛地黃中毒引起的心搏過緩，屬適宜指導。

本題考點：心肌炎護理判準——急性期以臥床休息、避免增加心臟後負荷的阻力運動為原則；類固醇需監測消化道出血徵象（大便顏色）；限水以減前負荷；毛地黃用藥須監測脈搏以防中毒。

  4. （D）③④

答案：（B）

詳解與考點

本題問「錯誤」的照護措施，答案為（B）。SIADH 因 ADH 分泌過多，造成水分滯留、稀釋性低血鈉與水中毒，照護重點是限制水分（每日約 800～1,000 c.c. 以下，故 D 正確），嚴重低血鈉（< 120 mmol/L 或出現抽搐、昏迷）時依醫囑緩慢輸注 3% 高張食鹽水並可合併 furosemide（Lasix®）以促進排水（A 正確）。furosemide 屬亨利氏環利尿劑（loop diuretic），會抑制鈉、氯與水的再吸收，造成水分與鈉一起排出、且常伴隨鉀流失，並非「促鈉保鉀」；使用高張食鹽水加 loop diuretic 時須嚴密監測血鈉、血鉀並控制矯正速度（避免過快引發橋腦中心髓鞘溶解）。低血鈉會引起神經肌肉症狀，故監測肌肉抽搐與昏迷徵象正確（C 正確）。（B）錯在「鼓勵多攝取低纖食物」與 SIADH 的水鈉失衡照護無關，亦非適當指導，故為錯誤選項即本題正解。

第 44 題

有關雙胍類降血糖藥物metformin（Glucophage®）之敘述，下列何者錯誤？
  1. （A）減少肝臟葡萄糖的輸出，以降低空腹血糖
  2. （B）最好與食物一起服用，或飯後馬上服用
  3. （C）易出現胃腸道刺激及引發維生素B6缺乏
  4. （D）腎功能不良的病人需要小心使用

答案：（C）

詳解與考點

正解：判準是 metformin 長期使用干擾迴腸末端維生素吸收所造成的缺乏種類——metformin 會干擾迴腸末端對維生素 B12 的吸收，造成的是維生素 B12 缺乏而非維生素 B6 缺乏，故 C「引發維生素 B6 缺乏」的敘述用詞有誤，為應選項。

A：metformin 主要機轉是減少肝臟葡萄糖的輸出，以降低空腹血糖，此為正確敘述。

B：metformin 易造成胃腸道刺激（噁心、腹瀉），建議與食物一起服用或飯後馬上服用以減少不適，此為正確敘述。

D：metformin 經腎臟排除，腎功能不良（如 eGFR 低於 30 mL/min）病人使用可能蓄積、增加乳酸酸中毒風險，須小心使用甚至禁用，此為正確敘述。

本題考點：metformin 的機轉與安全性判準——藥理機轉為減少肝糖輸出；常見胃腸道副作用建議隨餐服用以減緩不適；長期使用需留意維生素 B12（非 B6）缺乏；腎功能不良病人蓄積風險高，須小心使用以防乳酸酸中毒。

第 45 題

張太太，罹患糖尿病2年，平日使用口服抗血糖藥物控制血糖，今日在家昏倒被送至急診，醫師初步診斷為 高滲透壓高血糖狀態（HHS），病人會呈現的徵象，下列何者正確？①呼吸速率26次／分 ②血壓166/84 mmHg ③尿酮呈陽性反應，明顯升高 ④血糖為750 mg/dL。
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：本題要核對的是①②③④四項子敘述是否成立。高滲透壓高血糖狀態（HHS）好發於第 2 型糖尿病、口服降血糖藥控制者，特徵是極度高血糖（常大於 600 mg/dL，本題 750 mg/dL 符合），故④成立；體內仍有少量胰島素可抑制脂肪分解，因此無顯著酮體堆積、無明顯代謝性酸中毒，尿酮多呈陰性或僅微量，故③不成立；嚴重脫水與高滲透壓可造成代償性呼吸稍快，呼吸 26 次／分屬可見表徵，故①成立；嚴重脫水會使血容量不足，血壓應偏低甚至休克，不會出現 166/84 mmHg 這種偏高的血壓，故②不成立。綜合①④成立、②③不成立，選項 B（①④）為應選項。

A：①②之組合含②，②描述血壓 166/84 mmHg 偏向正常或稍高，與 HHS 嚴重脫水造成的低血壓不符，此組合含錯誤子敘述。

C：②③之組合同時含②與③兩項不成立的敘述，②血壓偏高與脫水機轉不符，③尿酮明顯升高則是糖尿病酮酸血症（DKA）的特徵而非 HHS，此組合含錯誤子敘述。

D：③④之組合含③，尿酮明顯升高與酸中毒型深快呼吸（Kussmaul respiration）是 DKA 的特徵，並非 HHS 的表現，此組合含錯誤子敘述。

本題考點：HHS 與 DKA 的鑑別判準——HHS 血糖極高（常大於 600 mg/dL）但因殘存胰島素抑制脂肪分解而酮體與酸中毒不顯著，尿酮陰性或微量；嚴重脫水造成代償性呼吸稍快但血壓偏低而非偏高；明顯酮酸與 Kussmaul 深快呼吸才是 DKA 的特徵。

第 46 題

有關甲狀腺機能亢進病人服用飽和碘化鉀溶液之敘述，下列何者正確？
  1. （A）絕不可與牛奶一起服用
  2. （B）主要功能是抑制T4轉變為T3
  3. （C）可以降低甲狀腺素的釋放及合成
  4. （D）要長期服用超過一個月才能評估臨床效果

答案：（C）

詳解與考點

正解：飽和碘化鉀溶液（SSKI）用於甲狀腺機能亢進術前準備的機轉，是抑制甲狀腺素的釋放及合成（Wolff-Chaikoff effect），可降低甲狀腺素的釋放及合成，故 C 為應選項。

A：SSKI 可與果汁或牛奶混合服用以減少胃部刺激，並非絕不可與牛奶一起服用，此敘述錯誤。

B：抑制 T4 轉變為 T3（周邊轉換）是 propylthiouracil（PTU）的特性，並非 SSKI 的主要功能，此敘述錯誤。

D：SSKI 屬短期用藥，通常服用 10 至 14 天即可見臨床效果，用於術前準備，並非需長期服用超過一個月才能評估，此敘述錯誤。

本題考點：甲狀腺相關藥物的機轉判準——SSKI（Wolff-Chaikoff effect）作用在甲狀腺素的合成與釋放、短期（10 至 14 天）可見效、可與牛奶或果汁併服；PTU 則另外具有抑制周邊 T4 轉 T3 的作用，兩者機轉不可混淆。

第 47 題

有關休克病人體溫下降之護理措施，下列何者正確？
  1. （A）當身體顫抖產熱及代謝增加，應調低室溫以減少發燒程度
  2. （B）靜脈注射的液體或血液，應加溫至接近正常體溫
  3. （C）使用熱水袋或電毯包裹四肢
  4. （D）給予熱水浴，以增加病人舒適感

答案：（B）

詳解與考點

正解：休克病人出現低體溫時，護理處置的判準在於避免造成周邊血管擴張——靜脈輸液或血液製品應加溫至接近正常體溫（37°C）後再輸注，以避免輸入低溫液體加重病人低體溫，故 B 為應選項。

A：休克病人身體顫抖產熱、代謝增加時應維持溫暖環境，不應調低室溫以「減少發燒程度」，此措施方向錯誤。

C：熱水袋或電毯直接包裹四肢會造成周邊血管擴張，使血液重新分配至體表而離心，反而加重循環衰竭，此措施方向錯誤。

D：熱水浴會造成周邊血管擴張、加重循環負擔，風險過高，禁用於休克病人，此措施方向錯誤。

本題考點：休克病人溫度調控的判準——目標是避免周邊血管擴張造成的血液重新分配（熱水袋、電毯、熱水浴皆屬禁忌），輸液與血品加溫至接近體溫（37°C）則是為避免外加低溫負荷，兩者作用方向不同不可混淆。

第 48 題

有關食物中毒之敘述，下列何者正確？
  1. （A）河豚中毒主要是處理河豚過程被細菌污染造成
  2. （B）金黃色葡萄球菌中毒症狀主要是視力模糊、吞嚥困難
  3. （C）沙門氏桿菌中毒症狀主要是腹瀉、噁心、嘔吐及發燒
  4. （D）食物中毒之嚴重度與食入污染物的量與內毒素含量呈負相關

答案：（C）

詳解與考點

正解：本題要配對的是各類食物中毒致病原與其典型症狀。沙門氏桿菌（Salmonella）食物中毒的典型症狀為腹瀉、噁心、嘔吐及發燒，潛伏期約 12 至 48 小時，故 C 為應選項。

A：河豚中毒是河豚毒素（tetrodotoxin）所致，並非處理過程遭細菌污染造成，此敘述錯誤。

B：金黃色葡萄球菌中毒的主要症狀是嘔吐與腹痛；視力模糊、吞嚥困難是肉毒桿菌中毒的特徵，此敘述將兩種致病原的症狀混淆。

D：食物中毒之嚴重度與食入污染物的量及毒素（內毒素）含量呈正相關，並非負相關，此敘述方向錯誤。

本題考點：食物中毒致病原的鑑別判準——沙門氏桿菌以腹瀉、噁心、嘔吐、發燒為典型表現（潛伏期約 12 至 48 小時）；金黃色葡萄球菌以嘔吐、腹痛為主；視力模糊與吞嚥困難屬肉毒桿菌中毒的神經症狀；河豚毒素（tetrodotoxin）是化學性毒素而非細菌污染；嚴重度與污染物及毒素量呈正相關。

第 49 題

有關自動體外電擊去顫器（AED）操作，下列敘述何者錯誤？
  1. （A）可由非醫護人員操作使用
  2. （B）若病人體內裝有人工心臟節律器就不能使用AED
  3. （C）操作步驟口訣：開、貼、插、按
  4. （D）按電擊鈕前先清場，確認無人接觸病人

答案：（B）

詳解與考點

正解：關鍵在體內裝有心臟節律器是否為 AED 使用的絕對禁忌。體內裝有人工心臟節律器（pacemaker）並非 AED 的絕對禁忌症，只需將電擊貼片避開節律器裝置位置（建議距離至少 8 cm）即可使用，並非「就不能使用 AED」，故 B 為應選項。

A：AED 設計為簡易操作，可由非醫護人員操作使用，此敘述正確。

C：AED 操作步驟口訣為「開、貼、插、按」，此敘述正確。

D：按下電擊鈕前須先清場、確認無人接觸病人，以避免旁人遭電擊波及，此敘述正確。

本題考點：AED 操作的適應與安全判準——裝有心臟節律器並非絕對禁忌，貼片避開裝置位置（至少 8 cm）即可使用；操作口訣「開、貼、插、按」可由非醫護人員執行；電擊前清場確保無人接觸病人是安全底線。

第 50 題

有關漢生病（Hansen's disease）俗稱痲瘋（leprosy）的照護措施，下列何者正確？
  1. （A）最常侵犯腸胃系統，應加強評估消化功能與營養狀態
  2. （B）照護時採接觸及呼吸道隔離
  3. （C）目前無治療藥物，採支持療法
  4. （D）皮膚病變僅出現在臉部

答案：（B）

詳解與考點

答案為（B）。漢生病由痲瘋分枝桿菌（Mycobacterium leprae）引起，主要侵犯周邊神經與皮膚，造成皮膚斑塊、感覺喪失與肢端變形，並不是侵犯腸胃系統（故 A 錯），皮膚病變也分布全身而非僅限臉部（故 D 錯）。本病有有效藥物，採世界衛生組織建議之多重藥物治療（MDT，如 dapsone、rifampicin、clofazimine），並非僅支持療法（故 C 錯）。就本題作答而言，相對於 A、C、D 三項明顯違反學理，（B）為單選題中唯一可選的答案。需提醒：依現行感染管制建議，漢生病傳染力低、潛伏期長，一般採標準防護（standard precautions）即可，治療開始後傳染性更迅速下降；本題以「接觸及呼吸道隔離」作為標準答案屬考題用法，臨床上不必對所有個案常規執行接觸加呼吸道隔離。
