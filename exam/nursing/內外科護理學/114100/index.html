第 1 題

有關巴金森氏症（Parkinson’sdisease）的主要典型症狀，下列敘述何者正確？①震顫 ②吞嚥困難 ③僵硬 ④運動遲緩 ⑤腹瀉
  1. （A）①②③
  2. （B）①③④
  3. （C）①③⑤
  4. （D）①②⑤

答案：（B）

詳解與考點

正解：題眼在「巴金森氏症的主要典型症狀」——判準是辨識其核心運動症狀：震顫、僵硬與運動遲緩。①、③、④均成立，故選 B。

A：①②③包含（②）吞嚥困難；吞嚥困難可隨病程出現，但不是題目所問的主要典型核心症狀。

C：①③⑤含有（⑤）腹瀉，腹瀉不是巴金森氏症的典型表現，故非答案。

D：①②⑤同時遺漏（③）僵硬與（④）運動遲緩，且包含腹瀉，故非答案。

本題考點：巴金森氏症（Parkinson’s disease）核心為靜止性震顫、肌肉僵硬與運動遲緩；吞嚥障礙（dysphagia）可為後續功能問題；症狀鑑別應抓主要運動表現。

第 2 題

有關顱內腫瘤病人顱內壓 ICP=18 mmHg，其照護之敘述，下列何者正確？
  1. （A）出現複視時，應鼓勵多下床活動
  2. （B）採高劑量類固醇治療時，應該要監測其血糖值
  3. （C）出現腦組織灌流失效時，應鼓勵液體攝取
  4. （D）出現腦疝是病情惡化之早期臨床表徵

答案：（B）

詳解與考點

正解：題眼在「顱內腫瘤」與「高劑量類固醇」——判準是類固醇可影響血糖代謝，照護時應監測血糖。（B）符合藥物副作用的護理監測重點，故選 B。

A：複視可能增加跌倒風險，應維護安全與評估神經狀態，不應鼓勵多下床活動。

C：腦組織灌流失效時須避免增加顱內壓的因素；鼓勵液體攝取不是首要處置。

D：腦疝是顱內壓嚴重惡化的危急表現，不是早期徵象。這是最強誘答——它看似是「警覺惡化」，但腦疝出現時已是緊急狀態。

本題考點：顱內壓（intracranial pressure, ICP）升高照護重視神經觀察與安全；類固醇（corticosteroids）治療須監測高血糖；腦疝（brain herniation）代表嚴重惡化。

第 3 題

下列何者不是肝硬化病人發生肝性腦病變的主要誘發因子？
  1. （A）感染
  2. （B）便秘
  3. （C）腸胃道出血
  4. （D）高血鉀

答案：（D）

詳解與考點

正解：題眼在「肝性腦病變的主要誘發因子」與「不是」——判準是會增加腸道含氮負荷、感染壓力或代謝失衡的因素容易促發腦病變；（D）高血鉀不是典型主要誘因，故選 D。

A：感染會增加分解代謝並使肝功能失代償，為常見誘發因素，故非答案。

B：便秘使腸道含氮物質停留與吸收增加，可能加重腦病變，故非答案。

C：腸胃道出血使血液進入腸道後被分解，增加含氮物質負荷，故非答案。

本題考點：肝性腦病變（hepatic encephalopathy）與含氮物質累積有關；感染（infection）、便秘（constipation）與腸胃道出血（gastrointestinal bleeding）是常見促發因素；電解質異常須依型態判讀。

第 4 題

有關癲癇藥物處置的敘述，下列何者正確？
  1. （A）多種抗癲癇藥物同時使用效果最佳
  2. （B）考慮停藥時可先行選擇半衰期較長的藥物逐漸減量
  3. （C）服用抗癲癇藥物 phenytoin 類（如 Dilantin） ，一旦懷孕須立即停藥，避免胎兒畸形
  4. （D）病人於服藥期間 2～3 年內無任何癲癇發作，且神經學及腦波檢查正常，可考慮慢慢停藥

答案：（D）

詳解與考點

正解：題眼在「長期無癲癇發作」且「神經學及腦波檢查正常」——判準是停用抗癲癇藥須在病況穩定、經專業評估後逐步減量。（D）符合可考慮慢慢停藥的原則，故選 D。

A：抗癲癇藥通常以能有效控制發作的最少藥物為原則，非多種同時使用效果最佳。

B：停藥策略須個別評估，不能只依半衰期長短先行選藥減量，故非答案。

C：懷孕時若自行立即停藥，可能引發發作而危及孕婦與胎兒；應由醫療團隊評估治療風險，故非答案。這是最強誘答——它看似在避免藥物致畸，但錯在以「立即停藥」取代個別化風險評估。

本題考點：抗癲癇藥物治療（antiseizure medication therapy）以控制發作與不良反應平衡；停藥（drug withdrawal）應漸進且依臨床評估；孕期癲癇（epilepsy in pregnancy）不可自行驟停用藥。

第 5 題

有關病人因頸椎脊髓損傷處於脊髓休克期的敘述，下列何者錯誤？
  1. （A）心跳 50 次／分、呼吸 15 次／分、血壓 160/100 mmHg
  2. （B）主要是因喪失自主神經的控制
  3. （C）受傷部位以下的所有運動、感覺、反射可能減弱或消失
  4. （D）出現尿滯留及腸蠕動下降

答案：（A）

詳解與考點

正解：題眼在「頸椎脊髓損傷」與「脊髓休克期」——判準是受傷後暫時失去脊髓反射與自主神經調節，常見低血壓與心搏過緩。（A）所列高血壓與心搏過緩的組合不符脊髓休克期，故為應選項。

B：脊髓休克與損傷以下自主神經控制暫時喪失有關，是正確敘述。

C：損傷部位以下的運動、感覺與反射減弱或消失，是脊髓休克期表現，故非答案。

D：膀胱張力與腸蠕動下降可造成尿滯留及腸蠕動減少，故非答案。

本題考點：脊髓休克（spinal shock）表現為損傷以下反射、感覺與運動暫失；自主神經失調（autonomic dysfunction）可致心搏過緩與低血壓；神經性休克（neurogenic shock）須與其他休克型態辨別。

第 6 題

有關膽囊炎病人的護理評估及照護，下列何者正確？
  1. （A）急性期症狀為右上腹疼痛可能輻射至右下腹部
  2. （B）膽囊手術後須監測腹脹、腹部僵硬、嘔吐等腹膜受感染的徵象
  3. （C）用 morphine 緩解疼痛與痙攣
  4. （D）術後引流液為墨綠色時需立刻通知醫師

答案：（B）

詳解與考點

正解：題眼在「膽囊手術後」與腹脹、腹部僵硬、嘔吐——判準是這些可能提示腹膜刺激或術後併發症，須持續監測。（B）符合術後腹部評估原則，故選 B。

A：急性膽囊炎常見右上腹痛，疼痛可放射至右肩或背部，不是右下腹部，故非答案。

C：嗎啡類藥物可能影響膽道平滑肌張力；疼痛處置應依醫囑與病況選擇，不以題述方式作為正確通則。

D：膽道引流液呈墨綠色可反映膽汁顏色，應評估量與變化，非單憑顏色就立即判為異常，故非答案。

本題考點：膽囊炎（cholecystitis）常見右上腹疼痛；術後腹膜炎（peritonitis）警訊包括腹脹、僵硬與嘔吐；膽道引流（biliary drainage）須綜合顏色、量與病人狀態判讀。

第 7 題

有關食道癌之敘述，下列何者錯誤？
  1. （A）食道下端之癌症可採行胃造口術維持身體營養需要
  2. （B）食道重建手術適用於中段的食道癌
  3. （C）光動力治療後需避光約 1 個月
  4. （D）鼓勵病人採低蛋白及高醣高渣飲食，維持適當的營養

答案：（D）

詳解與考點

正解：題眼在「食道癌」與「維持適當營養」——判準是吞嚥困難與腫瘤消耗均增加營養不足風險，飲食應重視足夠熱量與蛋白質。（D）低蛋白且高渣飲食不利於營養補充，也可能增加吞嚥不適，故為應選項。

A：下段食道病灶無法經口充分進食時，可用胃造口建立腸道營養途徑，故非答案。

B：中段食道癌是否適合重建須依病灶與手術評估，但食道重建是其治療選項之一，故非答案。

C：光動力治療後有光敏感風險，須依治療指示避光，故非答案。

本題考點：食道癌（esophageal cancer）常造成吞嚥障礙與營養不良；營養支持（nutritional support）以高熱量、高蛋白及易吞嚥為原則；胃造口（gastrostomy）可作為腸道營養途徑。

第 8 題

有關上腸胃道出血的照護，下列何者錯誤？
  1. （A）監測嘔吐物性質和大便的顏色
  2. （B）監測是否有肢端冰冷、指甲床蒼白等現象
  3. （C）出血停止後立刻停止血管加壓素的使用
  4. （D）評估腹部是否有腹脹僵硬情形

答案：（C）

詳解與考點

正解：題眼在「上腸胃道出血」與「出血停止後立刻停止血管加壓素」——判準是止血後仍須依病況與醫囑監測、調整治療，不能自行立即停藥。（C）跳過持續評估與處方調整，故為應選項。

A：嘔吐物與糞便顏色可反映出血部位與持續情形，應監測，故非答案。

B：肢端冰冷與指甲床蒼白可能提示周邊灌流不足，符合失血性循環評估，故非答案。

D：腹脹或腹部僵硬可能提示腹部問題或併發症，應納入評估，故非答案。

本題考點：上腸胃道出血（upper gastrointestinal bleeding）照護優先監測出血與循環灌流；血管加壓素（vasopressin）治療須依醫囑與病況調整；護理過程（nursing process）在非緊急變更時不可跳過評估。

第 9 題

有關食道靜脈曲張出血病人的護理指導，下列何者不適當？
  1. （A）避免用力咳嗽及提重物
  2. （B）採用軟質飲食，避免粗糙食物
  3. （C）須注意食物的溫度，避免過熱與過冷
  4. （D）須服用鎮靜劑以減輕焦慮

答案：（D）

詳解與考點

正解：題眼在「食道靜脈曲張出血」與「不適當」——判準是避免增加腹內壓、避免食道黏膜受傷，且用藥須有明確適應症。（D）不應為減輕焦慮而常規要求服用鎮靜劑；鎮靜可能掩蓋意識改變，且肝功能不全者更須審慎評估，故選 D。

A：用力咳嗽與提重物會增加胸腹壓力，應避免以降低再出血風險，故非答案。

B：軟質飲食可減少粗糙食物摩擦食道靜脈曲張，故非答案。

C：避免過熱或過冷食物可減少食道刺激，故非答案。

本題考點：食道靜脈曲張（esophageal varices）照護重點是預防再出血；出血預防（bleeding precautions）包括避免腹壓上升與黏膜刺激；鎮靜劑（sedatives）使用須考量意識與肝功能。

第 10 題

王先生，170cm，88Kg，從事搬運工，因腹股溝疝氣接受手術治療，有關疝氣手術後護理指導，下列何者 正確？①傷口處熱敷，以減輕疼痛與腫脹 ②不需要特別減重以免營養不良 ③陰囊應給與支托後再下床 ④平時應多吃蔬果以預防便秘 ⑤出院後可立即上班從事搬運工作
  1. （A）①②
  2. （B）②③
  3. （C）③④
  4. （D）④⑤

答案：（C）

詳解與考點

正解：題眼在「腹股溝疝氣術後」——判準是減少傷口張力、支持陰囊並預防便秘；③、④符合，故選 C。

A：①②中，（①）術後初期熱敷可能增加腫脹或出血風險；（②）體重管理可降低腹壓，不能因擔心營養不良而完全忽略，故非答案。

B：②③含有（②）不需減重的錯誤敘述，故非答案。

D：④⑤含有（⑤）出院後立即搬運重物；這會增加腹內壓與傷口負荷，故非答案。

本題考點：腹股溝疝氣（inguinal hernia）術後須避免腹內壓上升；陰囊支托（scrotal support）可減少不適與牽拉；便秘預防（constipation prevention）有助於保護傷口。

第 11 題

下列何者為骨質疏鬆的危險因子？①停經前之婦女 ②攝取大量咖啡茶飲 ③規律的運動 ④靜態生活 或長期臥床 ⑤日曬時間不足
  1. （A）①②③
  2. （B）①③④
  3. （C）②④⑤
  4. （D）③④⑤

答案：（C）

詳解與考點

正解：題眼在「骨質疏鬆的危險因子」——判準是骨量流失與骨生成刺激不足；②大量咖啡茶飲、④久坐或長期臥床、⑤日曬不足均會增加風險，故選 C。

A：①②③含有（①）停經前婦女與（③）規律運動，兩者不屬題意所列典型危險因子，故非答案。

B：①③④同樣含有停經前與規律運動，故非答案。

D：③④⑤含有（③）規律運動；負重與規律活動有助維持骨骼刺激，故非答案。

本題考點：骨質疏鬆症（osteoporosis）危險因子包括缺乏負重活動；日照不足（insufficient sun exposure）影響維生素 D 相關骨代謝；長期臥床（prolonged bed rest）會加速骨質流失。

第 12 題

有關病人因左膝關節退化性關節炎接受全膝關節置換術之術後照護，下列何者最不適當？
  1. （A）術後可用枕頭抬高左側下肢，以促進血液循環
  2. （B）術後 1～2 天可使用持續被動運動機（CPM）進行運動
  3. （C）助行器手把高度要與病人腰同高且手肘可彎曲≦30 度
  4. （D）教導病人返家後，多上下樓梯、走遠路，以促進膝關節血液循環

答案：（D）

詳解與考點

正解：題眼在「全膝關節置換術術後」與「最不適當」——判準是活動要漸進、兼顧人工關節保護與跌倒安全。（D）返家後多上下樓梯、走遠路會造成過度負荷，違反循序復健原則，故選 D。

A：適當抬高患肢可協助減輕腫脹並促進靜脈回流，故非答案。

B：依術後狀況使用持續被動運動機，可協助關節活動度訓練，故非答案。

C：助行器高度需讓病人握把時姿勢穩定、手肘保有適度彎曲，符合安全步行原則，故非答案。

本題考點：全膝關節置換術（total knee arthroplasty）術後重視漸進活動；持續被動運動（continuous passive motion, CPM）可用於關節活動訓練；輔具調整（assistive device fitting）以穩定與防跌為先。

第 13 題

有關移除下肢石膏後病人護理指導之敘述，下列何者不適當？
  1. （A）鼓勵病人立即下床行走，增加患肢平衡感
  2. （B）避免過度曝曬皮膚
  3. （C）行走時患肢可使用彈性繃帶包紮
  4. （D）患肢皮膚上布滿黃棕色鱗片是正常的現象

本題考點：輸血相關循環過度負荷（transfusion-associated circulatory overload）可有呼吸困難、咳嗽與血壓上升；輸血不良反應（transfusion reaction）辨別須合看呼吸、血壓、體液負荷與發燒等線索。

第 26 題

  3. （C）持續輸血
  4. （D）協助做放血術

詳解與考點

正解：題眼承接前題的「輸血中乾咳、血壓上升、嚴重呼吸困難」——已判定為循環過度負荷，處置優先是停止輸血、維持呼吸與減少循環容量；（D）協助放血術可在醫囑下減少血容量，故選 D。

本題考點：輸血相關循環過度負荷（transfusion-associated circulatory overload）須立即停止輸血並評估呼吸循環；容量管理（volume management）以減少過多循環血量為原則；呼吸困難（dyspnea）時的擺位應以改善換氣為先。

正解：題眼在「疥瘡」與「錯誤」——人類疥蟲主要藉密切皮膚接觸與受污染織物傳播；官方答案為 B，題目以「不會藉由寵物攜帶疥蟲而傳染」作為錯誤敘述，故選 B。惟不同動物疥蟎對人類的感染性與持續性不同，這一選項措辭過度絕對，須以現行感染管制指引確認。

B：按壓速率不是越快越好；過快會縮短胸部回彈與充盈時間，降低有效灌流。

本題考點：高品質心肺復甦（high-quality cardiopulmonary resuscitation, CPR）包含正確胸骨按壓位置、足夠深度、適當速率與完全胸部回彈（full chest recoil）；完整回彈是維持靜脈回流與冠狀動脈灌流的重要條件。

第 50 題

有關困難梭狀桿菌相關腹瀉（Clostridium difficile associated diarrhea）之敘述，下列何者錯誤？
  1. （A）困難梭狀桿菌為厭氧性革蘭陽性桿菌，容易在醫療環境中形成孢子體
  2. （B）易感染年長者或住院病人在長期使用抗生素者
  3. （C）首選治療藥物為靜脈注射 Vancomycin
  4. （D）腹瀉期間採接觸隔離

答案：（C）

詳解與考點

正解：題眼在「困難梭狀桿菌相關腹瀉」與「何者錯誤」——治療藥物必須在腸道腔內發揮作用；（C）靜脈注射 Vancomycin 無法提供治療此腸道感染所需的腸腔藥物濃度，故為應選項。

A：困難梭狀桿菌是厭氧性革蘭陽性桿菌，孢子可在醫療環境存留，故正確。

B：高齡、住院及長期使用抗生素會破壞正常腸道菌叢，增加感染風險，故非答案。

D：腹瀉期間採接觸隔離可降低孢子經手部或環境傳播，故正確。最強誘答是（C）——Vancomycin 名稱正確，但錯在給藥途徑。

本題考點：困難梭狀桿菌相關腹瀉（Clostridioides difficile associated diarrhea）與抗生素造成腸道菌叢失衡有關；治療須使藥物到達腸腔；接觸隔離（contact precautions）與環境清潔是感染管制重點。
