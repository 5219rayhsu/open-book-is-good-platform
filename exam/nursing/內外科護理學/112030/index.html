第 1 題

罹患腦下垂體腫瘤病人，醫師建議使用伽馬刀療法，下列何者顯示病人已了解本項治療？
  1. （A）治療時我的頭部會有一個切開傷口
  2. （B）治療時我不會疼痛也不會流血
  3. （C）治療後我的頭部會有留一條小型引流管
  4. （D）治療後我的腦瘤會立即消失

答案：（B）

詳解與考點

正解：題眼在「伽馬刀療法」——判準是其以精準聚焦放射線治療病灶，並非開顱手術。治療本身不需切開頭部組織，因此病人不會因治療切口而疼痛或流血，故選 B。

A：伽馬刀不是以手術刀切開頭部，頭部固定或定位程序不等於切開傷口。

C：小型引流管是開顱術後可能使用的裝置，伽馬刀治療不會因其本身留下頭部引流管。

D：放射線造成的治療效果需經時間觀察病灶控制或縮小，不會在治療後立即使腦瘤消失。這是最強誘答——它把「精準治療」誤解成「立即清除腫瘤」。

本題考點：伽馬刀（Gamma Knife radiosurgery）是立體定位放射手術；非侵入性治療（noninvasive treatment）不涉及切開組織；治療成效（treatment response）須後續追蹤評估。

第 2 題

與阿茲海默症病人的溝通技巧，下列何者不適宜？
  1. （A）若病人只能說出單字或短句，照顧者也要用簡單、易了解的字彙或圖片與其溝通
  2. （B）當病人出現眼神避開時，表示不了解溝通內容
  3. （C）溝通時，應該使用低音量、高音調及緩慢的速度
  4. （D）可以善用拍打和擁抱的觸覺刺激，協助病人表達

答案：（C）

詳解與考點

正解：題眼在「阿茲海默症病人」與「不適宜」——判準是認知功能受損時須降低理解負荷，並以聽得清楚、溫和的方式溝通。（C）錯在「高音調」：高頻聽力隨年齡先退化，音調拉高反而更聽不清；正確作法是適當音量、低音調、放慢語速並一次只給一個訊息，故 C 為應選項。

A：使用簡單字彙、短句、圖片或實物可減少抽象理解負荷，是適當作法。

B：病人避開眼神是需要進一步評估的非語言線索，可能反映不理解、焦慮、疲累或環境刺激過多；護理人員據此調整訊息與環境並無不當。相較之下（C）直接違反失智症溝通的音調原則，是本題要選的應選項，故 B 非答案。

D：在病人接受且不造成不適時，適當觸碰、拍打或擁抱可傳達支持並協助非語言表達。這是最強誘答——觸覺介入須先尊重個人界線，但選項的重點是善用而非強迫。

本題考點：失智症溝通（dementia communication）宜簡短具體、低音調慢速；非語言溝通（nonverbal communication）須結合情境評估；以人為中心照護（person-centered care）應尊重舒適度與界線。

第 3 題

有關多發性硬化症病人的自我照顧之護理指導，下列敘述何者錯誤？
  1. （A）鼓勵病人多攝取水分和高纖食物，預防便秘
  2. （B）依排定如廁時間表，提醒病人如廁
  3. （C）減少社交參與，避免造成身體心像紊亂
  4. （D）若出現複視，可以使用眼罩遮住一眼，緩解複視

答案：（C）

詳解與考點

正解：題眼在「多發性硬化症」與「自我照顧」——判準是症狀管理應在安全範圍內維持功能、支持生活參與。減少社交參與會加重孤立感與身體心像困擾，並非適當指導，故 C 為應選項。

A：充足水分與高纖飲食有助維持排便規律、預防便秘，是適當措施。

B：依排定時間提醒如廁可協助處理膀胱功能障礙並建立排尿規律，是適當措施。

D：複視時暫以眼罩遮住一眼可減少兩眼影像重疊，緩解視覺不適。這是最強誘答——它沒有治療病因，但題目問的是自我照顧下的症狀緩解。

本題考點：多發性硬化症（multiple sclerosis）可有視覺、排尿與疲倦等症狀；症狀管理（symptom management）著重安全與功能；社會參與（social participation）有助維持心理社會適應。

第 4 題

有關腦腫瘤病人術後發生尿崩症，下列敘述何者正確？
  1. （A）尿比重會比正常人高
  2. （B）會有尿量多、血漿滲透壓下降
  3. （C）因抗利尿素（ADH）分泌不足所致
  4. （D）可能有低血鈉導致抽搐症狀

答案：（C）

詳解與考點

正解：題眼在「腦腫瘤術後」與「尿崩症」——判準是抗利尿素不足使腎臟無法適當濃縮尿液。腦下垂體後葉或相關路徑受影響時，ADH 分泌不足造成大量稀釋尿，故選 C。

A：尿液無法濃縮時，尿比重會偏低，不會比正常人高。

B：大量排出自由水會使血漿濃縮，血漿滲透壓上升，而非下降。

D：自由水流失會提高血鈉濃度，主要風險是高血鈉與脫水，不是低血鈉。這是最強誘答——它把水分失衡的方向顛倒，應從「排出大量稀尿」推回血液濃縮。

本題考點：中樞性尿崩症（central diabetes insipidus）與 ADH 不足相關；尿液濃縮（urine concentration）下降會使尿比重偏低；高血鈉（hypernatremia）可由自由水流失造成。

第 5 題

有關顱內壓升高的藥物治療，下列敘述何者錯誤？
  1. （A）類固醇治療可用於腦瘤引起的血管性腦水腫
  2. （B）Mannitol 滲透性利尿劑若出現反彈現象會使腦水腫更嚴重
  3. （C）巴比妥酸鹽可降低腦組織代謝及使得血流均勻供應腦部
  4. （D）顱內壓升高病人皆須給與抗痙攣藥物以預防抽搐發作

答案：（D）

詳解與考點

正解：題眼在「顱內壓升高」與「何者錯誤」——判準是藥物治療須依病因與個別風險選擇，不能將特定藥物套用於所有病人。抗痙攣藥是否使用應依病灶、既往發作與醫囑評估，並非每一位顱內壓升高病人都必須預防性給藥，故 D 為應選項。

A：類固醇可減少腦瘤相關血管性腦水腫，屬常用的病因導向治療之一。

B：Mannitol 為滲透性利尿劑；若治療後出現反彈性水腫，腦水腫可能惡化，需密切觀察。

C：巴比妥酸鹽可降低腦部代謝需求，在特定難治情境下用以協助控制顱內壓。這是最強誘答——它不是所有病人的常規處置，但選項未說「所有」，其機轉敘述仍正確。

本題考點：顱內壓（intracranial pressure）治療須針對病因；血管性腦水腫（vasogenic cerebral edema）可考慮類固醇；抗痙攣治療（antiseizure therapy）應依個別風險評估。

第 6 題

有關巴金森氏症病人的日常活動指導，下列敘述何者錯誤？
  1. （A）行走時使用底面積較寬的助行器維持平衡
  2. （B）漸進式運動計畫以增加病人肌肉力量，鼓勵全關節運動
  3. （C）鼓勵病人以寬步伐行走，行走時身體直立，提醒腳跟先著地
  4. （D）因身體僵硬，鼓勵坐深且柔軟的椅子

答案：（D）

詳解與考點

正解：題眼在「巴金森氏症」與「日常活動指導」——判準是僵硬、姿勢不穩與動作遲緩時，環境應協助安全起身與轉位。深且柔軟的椅子會使病人身體下陷、增加起身困難與跌倒風險，故 D 為應選項。

A：底面積較寬的助行器可增加支撐面，有助維持行走平衡。

B：漸進式運動與全關節運動可協助維持肌力、關節活動度與功能。

C：以寬步伐、直立姿勢及腳跟先著地，可協助改善小碎步與前傾行走的風險。這是最強誘答——動作需要反覆練習與個別化評估，但其方向符合維持步態安全的原則。

本題考點：巴金森氏症（Parkinson disease）常見動作遲緩、僵硬與姿勢不穩；跌倒預防（fall prevention）重視安全轉位與環境設計；關節活動運動（range-of-motion exercise）有助維持功能。

第 8 題

有關中風病人臥床姿勢擺位之護理措施，下列何者錯誤？
  1. （A）避免採高坐臥姿，防髖關節屈曲畸形
  2. （B）大腿外側使用粗隆捲軸，防止髖關節外旋
  3. （C）膝關節下墊枕頭，防止膝關節屈曲畸形
  4. （D）患側腋下墊枕頭，防止肩關節內收

答案：（C）

詳解與考點

正解：題眼在「中風病人臥床姿勢擺位」與「何者錯誤」——擺位須維持關節功能位置、避免攣縮。膝關節下墊枕會使膝持續屈曲，反而增加屈曲攣縮風險，故 C 為應選項。

A：避免長時間高坐臥可減少髖關節持續屈曲，符合預防攣縮原則，故非答案。

B：大腿外側使用粗隆捲軸可限制髖關節外旋，故非答案。

D：患側腋下墊枕能支托上肢並減少肩關節內收，故非答案。最強誘答在於它看似只為舒適，實際是在維持肩部功能位置。

本題考點：關節功能位置（functional position）以預防攣縮為目標；中風偏癱擺位應防髖外旋、肩內收與膝持續屈曲。

第 9 題

B 型肝炎病毒帶原者且 HBeAg（+），下列敘述何者正確？
  1. （A）目前是急性 B 型肝炎病毒的恢復期
  2. （B）對於 B 型肝炎病毒已經有免疫力
  3. （C）目前具有 B 型肝炎病毒高傳染力
  4. （D）可能會併發 C 型肝炎病毒感染

答案：（C）

詳解與考點

正解：題眼在「B 型肝炎病毒帶原者」與 HBeAg（+）——HBeAg 表示病毒複製活躍，血液及體液傳染力較高，故選 C。

A：帶原不等於急性感染恢復期，故非答案。

B：是否具免疫力須依保護性抗體等血清標記判讀；HBeAg 陽性反而指向活躍複製，故非答案。

D：C 型肝炎感染需另以其病毒標記判定。最強誘答在於兩者皆可經血液傳播，但途徑相近不代表必然合併感染。

本題考點：B 型肝炎 e 抗原（hepatitis B e antigen, HBeAg）陽性代表病毒複製與較高傳染力；血清學標記不可跨病毒推論。

第 10 題

進行內視鏡逆行性膽胰攝影檢查，若導管不易進入總膽管，可使用下列何種藥物讓歐迪氏括約肌 （sphincter of Oddi）鬆弛？
  1. （A）Atropine
  2. （B）Buscopan
  3. （C）MgSO4
  4. （D）Xylocaine

答案：（C）

詳解與考點

正解：題眼在「導管不易進入總膽管」與「歐迪氏括約肌鬆弛」——MgSO4 可使平滑肌鬆弛，有助於膽管插管，故選 C。

A：Atropine 主要減少分泌及抑制副交感作用，非本題所問的特定括約肌鬆弛藥物，故非答案。

B：Buscopan 可減少腸胃道痙攣，但本題依歐迪氏括約肌的鬆弛作用應選 MgSO4。這是最強誘答——兩者都像解痙藥，關鍵是題幹指定的括約肌。

D：Xylocaine 是局部麻醉藥，不用於鬆弛膽道括約肌，故非答案。

本題考點：歐迪氏括約肌（sphincter of Oddi）調節膽汁與胰液排出；硫酸鎂（magnesium sulfate）具有平滑肌鬆弛作用。

第 11 題

有關升結腸造瘻的敘述，下列何者正確？
  1. （A）水分需求增加
  2. （B）糞便呈半成形狀
  3. （C）須定期做結腸灌洗
  4. （D）經訓練後排便可具規律性

答案：（A）

詳解與考點

正解：題眼在「升結腸造瘻」——造瘻位置近端時結腸吸收水分的路徑短，排出物較稀，水分與電解質流失風險較高，須注意增加水分攝取，故選 A。

B：半成形糞便較符合遠端結腸造瘻；升結腸造瘻排出物較液狀，故非答案。

C：規律結腸灌洗適用於遠端、糞便較成形的結腸造瘻，故非答案。

D：經訓練規律排便也需較成形的糞便與遠端結腸功能。最強誘答在於「訓練」看似合理，但造瘻位置決定是否具規律控制條件。

本題考點：升結腸造瘻（ascending colostomy）排出物較液狀；近端結腸造瘻重點為水分與電解質平衡；結腸灌洗較適用於遠端造瘻。

第 12 題

有關肝活體組織切片檢查，下列敘述何者正確？
  1. （A）檢查中，教導個案深呼吸，於吸氣後閉氣 5～10 秒進行穿刺
  2. （B）檢查後，立即協助個案正躺，傷口以彈繃加壓
  3. （C）檢查後，若病人主訴右肩疼痛，應懷疑橫膈下積血
  4. （D）檢查後，除短暫下床如廁外，需臥床 4～6 小時

答案：（C）

詳解與考點

正解：題眼在「肝活體組織切片檢查後」與「右肩疼痛」——最須警覺出血。肝臟出血形成橫膈下積血可刺激橫膈神經，造成右肩轉移痛，故選 C。

A：穿刺時應在呼氣末暫停呼吸以減少肝臟移動；吸氣後閉氣不適當，故非答案。

B：檢查後通常採右側臥壓迫穿刺處，非立即正躺，故非答案。

D：早期應嚴密臥床觀察，不能把短暫下床如廁列為常規。最強誘答在於「短暫」看似安全，但會減少傷口壓迫並增加出血風險。

本題考點：肝臟切片（liver biopsy）後優先監測出血；右肩轉移痛（referred pain）可提示橫膈受刺激；右側臥有助壓迫穿刺傷口。

第 13 題

有關迴腸造瘻口的護理指導，下列何者正確？
  1. （A）多吃蛋、乳酪等食物
  2. （B）多攝食高纖維的食物
  3. （C）記錄迴腸造瘻的引流量
  4. （D）每天攝取不超過 1,500 c.c.的液體

答案：（C）

詳解與考點

正解：題眼在「迴腸造瘻口」——迴腸內容物未經結腸充分吸收水分與電解質，引流量變化會影響體液平衡，應記錄引流量，故選 C。

A：蛋與乳酪不是迴腸造瘻最核心的固定指導；飲食應依耐受度調整，故非答案。

B：高纖維食物可能增加阻塞或脹氣風險，不宜一概鼓勵，故非答案。

D：迴腸造瘻易有水分流失，限制液體會加重脫水風險。最強誘答在於看似可減少引流量，但減少飲水不能取代監測與補充。

本題考點：迴腸造瘻（ileostomy）排出物較液狀；護理重點是監測引流量及體液平衡；飲食纖維依耐受度漸進調整。

第 14 題

有關慢性胃炎之敘述，下列何者錯誤？
  1. （A）A 型慢性胃炎主要與幽門桿菌的感染有關
  2. （B）B 型慢性胃炎常發生在胃竇處
  3. （C）B 型慢性胃炎的胃泌素值正常
  4. （D）A 型慢性胃炎可能形成惡性貧血

答案：（A）

詳解與考點

第 26 題

  2. （B）心肌旋轉蛋白（Troponin I）對心肌受損具有特異性及敏感性
  3. （C）心電圖出現 Q 波表示心肌受損在表層
  4. （D）心電圖 ST 間段及 T 波的改變可以協助判斷心肌是缺氧、缺血或壞死

答案：（C）

詳解與考點

正解：題眼在「急性心肌梗塞」與心電圖「Q 波」——病理性 Q 波通常反映較深層、全層性心肌壞死的電向量改變，不是表層心肌受損，因此 C 為應選項。

本題考點：急性心肌梗塞（acute myocardial infarction）診斷整合心電圖與心肌生物標記；心肌鈣蛋白 I（troponin I）具心肌特異性；病理性 Q 波提示較深層心肌壞死。

A：治療前依身體檢查、影像與檢驗所作的臨床分期可用 cTNM 表示，故非答案。

C：復發或再次治療時的分期可加 r 前綴，故非答案。

D：接受治療後再作臨床分期可用 ycTNM 表示，故非答案。這是最強誘答——y 代表曾接受治療後評估，與手術病理檢體的 p 前綴不可混用。

本題考點：TNM 分期系統（TNM staging system）；臨床分期（cTNM）；病理分期（pTNM）。

第 40 題

有關癌症病人血小板減少症之處置，下列何者正確？
  1. （A）可給與非類固醇抗發炎藥物緩解疼痛
  2. （B）必要時輸注凝血因子避免自發性出血
  3. （C）給與 Bisacodyl supp 避免便秘而閉氣用力
  4. （D）天冷時鼻黏膜塗擦凡士林保濕

詳解與考點

正解：題眼在癌症病人的「血小板減少症」——判準是避免黏膜破損與抑制血小板功能，以預防出血。天冷時鼻黏膜容易乾裂，塗擦凡士林保濕可減少鼻出血，故選 D。

A：NSAID 會影響血小板功能，會增加出血風險，故非答案。

B：血小板減少的補充處置以血小板製劑為主要考量；凝血因子不能直接矯正血小板數量不足，故非答案。

  2. （B）不管良性或惡性腫瘤，細胞排列皆不規則
  3. （C）良性腫瘤以浸潤方式侵入周圍組織

正解：題眼在「良性腫瘤」與「密閉空間」——良性不代表沒有臨床危害；若生長於顱腔、管腔等有限空間，壓迫或阻塞仍可造成症狀，故選 D。

  2. （B）B 細胞型急性淋巴性

  1. （A）維持呼吸道通暢並由面罩給 100%的氧氣吸入
  2. （B）發生呼吸窘迫時不適合進行插管
  3. （C）安排病人採平躺側臥
  4. （D）建立由口鼻腔進入的液體輸液通道

答案：（A）

詳解與考點

正解：題眼在火災後「吸入性灼傷」——依三層優先序的第一層，呼吸道與呼吸優先於姿勢或其他處置。應維持呼吸道通暢並給予高濃度氧氣，且密切觀察上呼吸道水腫，故選 A。

B：吸入性灼傷的水腫可能快速惡化，出現呼吸窘迫時反而應及早評估插管以確保氣道，故非答案。

D：液體復甦需建立靜脈輸液通道，不是由口鼻腔建立。這是最強誘答——它抓到燒傷需要輸液的方向，但途徑錯誤且忽略氣道優先。

  1. （A）①③④
  2. （B）①④⑤
  3. （C）②③⑤
  4. （D）②④⑤

答案：（D）

詳解與考點

正解：題眼在「深二度燒傷」——深二度屬部分厚度燒傷且傷及真皮深層：②創面呈灰白或紅白相間並有水泡、⑤表皮及真皮層受損，都是典型表現；④毛囊與汗腺等皮膚附屬構造尚有殘留，正是深二度仍能自行上皮化（惟癒合較慢、易留疤）的依據，故選 D。

A：①皮膚變紅無水泡較符合一度燒傷，且④與①的組合不能代表深二度燒傷，故非答案。

B：①同樣不符合深二度的灰白、水泡表現，故非答案。

C：②⑤可支持部分厚度燒傷，但③劇烈疼痛屬淺二度的表現；深二度因真皮層神經末梢受損，痛覺反而較淺二度減弱。這是最強誘答——它抓到水泡與真皮受損，卻把疼痛程度當成所有二度燒傷皆相同。

本題考點：深二度燒傷（deep partial-thickness burn）；部分厚度燒傷（partial-thickness burn）；皮膚附屬構造殘留與痛覺減弱的關係。

有關皮膚癌的預防或處置，下列敘述何者錯誤？
  1. （A）長時間暴露陽光下，無需重複塗抹 SPF15 以上的防曬乳液
  2. （B）陰天也要採取防曬措施
  3. （C）皮膚病灶變大或發生色素沉著現象應立即就醫

第 46 題

有關膠帶等黏性產品使用之敘述，下列何者正確？
  1. （A）移除膠帶時，應垂直、快速才不會痛太久
  2. （B）膠帶造成皮膚的損傷好發在嬰幼兒和水腫病人
  3. （C）移除膠帶時需支撐邊緣皮膚，以 180 度逆毛方向移除
  4. （D）使用膠帶前，可以在皮膚上塗抹優碘以增加黏性

答案：（B）

詳解與考點

正解：題眼在「膠帶造成皮膚損傷」——嬰幼兒皮膚屏障尚未成熟，水腫病人皮膚受牽拉且脆弱，兩者皆為醫療黏著劑相關皮膚損傷的高風險群，故選 B。

A：移除膠帶應低角度、緩慢進行並支撐皮膚；垂直快速撕除會增加表皮剝離與疼痛，故非答案。

C：移除時支撐邊緣皮膚正確，撕除也確實應把膠帶反折貼近皮膚（即 180 度低角度）緩慢移除；（C）錯在方向——應順毛而非逆毛，逆毛撕除會拉扯毛囊、增加表皮剝離與疼痛。這是最強誘答——它含有「支撐皮膚」與反折撕除兩個正確動作，錯在毛髮方向。

D：使用膠帶前不應以優碘增加黏性；應使皮膚清潔、乾燥，並依需要使用皮膚保護產品，故非答案。

本題考點：醫療黏著劑相關皮膚損傷（medical adhesive-related skin injury, MARSI）；脆弱皮膚；膠帶移除應反折貼近皮膚低角度、順毛方向緩慢進行。

第 47 題

有關細胞毒殺過敏反應之敘述，下列何者錯誤？
  1. （A）參與此類過敏反應的抗體是 IgG 或 IgM
  2. （B）Rh 血型不合屬此類過敏反應
  3. （C）參與此類過敏反應的細胞是吞噬細胞及殺手細胞
  4. （D）紅血球、白血球、血小板的作用不受此類過敏反應影響

答案：（D）

詳解與考點

正解：題眼在「細胞毒殺過敏反應」與「何者錯誤」——此為第Ⅱ型過敏反應，抗體結合細胞表面抗原後造成靶細胞損傷。紅血球、白血球與血小板正可能成為受影響的靶細胞；說它們不受影響違反此型反應的核心機轉，故選 D。

A：第Ⅱ型反應主要由 IgG 或 IgM 介導，抗體與細胞表面抗原結合後可活化補體或促進細胞清除，故非答案。

B：Rh 血型不合時，母體或受血者的抗體會針對帶有相對應抗原的紅血球反應，屬細胞毒殺反應，故非答案。

C：吞噬細胞可清除被抗體或補體標記的細胞，殺手細胞也可參與抗體依賴性細胞毒殺，故非答案。這是最強誘答——它把「參與反應的效應細胞」與「被傷害的血球」混在一起；兩者都可出現在同一反應中。

本題考點：第Ⅱ型過敏反應（type II hypersensitivity）以 IgG/IgM 對細胞表面抗原的反應為主；靶細胞損傷可經補體活化、吞噬或抗體依賴性細胞毒殺（antibody-dependent cellular cytotoxicity）造成；Rh 血型不合是代表情境。

第 48 題

有關器官移植前的組織配對，降低排斥反應之檢驗項目，不包含下列何者？
  1. （A）ABO 及 Rh 血型
  2. （B）人類白血球抗原
  3. （C）交叉配對試驗
  4. （D）梅毒血清檢查

答案：（D）

詳解與考點

正解：題眼在「器官移植前的組織配對」與「降低排斥反應」——判準是檢查是否用來確認供、受者的免疫相容性。梅毒血清檢查是感染篩檢，雖屬移植前重要安全評估，卻不能判定組織相容性或降低排斥反應，故選 D。

A：ABO 血型相容性會影響移植後立即發生的抗體介導排斥風險，因此須納入配對評估，故非答案。

B：人類白血球抗原是供、受者組織相容性的重要標記，配對越適合通常越有利於降低免疫排斥，故非答案。

C：交叉配對試驗可檢視受者血清是否含有會攻擊供者細胞的抗體，是移植前排除高風險免疫反應的重要檢驗，故非答案。這是最強誘答——它不像「血型」或「抗原」直接寫出配對，但其目的正是找出既存抗體造成的不相容。

本題考點：器官移植相容性（transplant compatibility）包括 ABO 血型、HLA 配對與交叉配對試驗（crossmatch）；感染篩檢是移植安全評估，與降低免疫排斥的配對目的不同。

第 49 題

有關全身性紅斑性狼瘡病人之護理指導，下列何者錯誤？
  1. （A）外出時，應戴太陽眼鏡及帽子，著長袖上衣及長褲，以避免日曬
  2. （B）女性病人可使用保險套或避孕藥來避孕
  3. （C）當處於壓力、生病或有感染時，應告知醫師以調整藥物劑量
  4. （D）關節疼痛時，可應用冷熱敷來緩解

答案：（B）

詳解與考點

正解：題眼在「全身性紅斑性狼瘡」與「護理指導何者錯誤」——此病可受日光與荷爾蒙因素影響，避孕須避免自行選用可能增加疾病活動風險的荷爾蒙製劑。把保險套與避孕藥並列為都可使用，忽略避孕藥種類及個別病況的評估，故選 B。

D：關節疼痛可依疼痛性質與病程採適當冷、熱敷來緩解不適，並配合休息與治療，故非答案。這是最強誘答——冷熱敷不能取代疾病治療，但作為症狀緩解措施本身並不錯。

本題考點：全身性紅斑性狼瘡（systemic lupus erythematosus）應避免紫外線暴露；感染與壓力是疾病活動的警訊；避孕應依疾病活動度、血栓風險及藥物由醫療團隊個別評估。

第 50 題

有關後天免疫缺乏症候群（AIDS）病人出現伺機性感染之敘述，下列何者正確？
  1. （A）CD4 細胞數值在 350 cells/μL 以下容易發生
  2. （B）以口腔念珠球菌感染最為常見
  3. （C）巨細胞病毒（CMV）感染的治療可服用 Zovirax
  4. （D）肺囊蟲肺炎感染會造成病人乾咳、用力咳嗽症狀

答案：（D）

詳解與考點

正解：題眼在「AIDS」與「伺機性感染」——肺囊蟲肺炎常見非生產性乾咳與活動時呼吸困難，符合（D）的症狀組合，故選 D。

A：伺機性感染的好發門檻是 CD4 細胞低於 200 cells/μL；350 cells/μL 屬須密切監測與啟動抗病毒治療的層級，尚非伺機性感染的常見界線，故非答案。

B：口腔念珠菌感染在免疫低下者雖常見，但 AIDS 最具代表性的伺機性感染是肺囊蟲肺炎；本選項把「常見」寫成「最常見」，故非答案。

C：Zovirax 為 acyclovir，主要用於疱疹病毒感染；巨細胞病毒感染的治療藥物選擇不同，故非答案。這是最強誘答——兩者都屬疱疹病毒群，不能因此把對單純疱疹病毒有效的藥物直接套用到 CMV。

本題考點：後天免疫缺乏症候群（acquired immunodeficiency syndrome）因細胞免疫缺損而易有伺機性感染；肺囊蟲肺炎（Pneumocystis pneumonia）常見乾咳與活動性呼吸困難；抗病毒藥須依病原選擇。

協助醫師拔除胸管時，應指導病人採取下列何種呼吸方式？
  1. （A）緩慢吸吐氣
  2. （B）哈氣
  3. （C）快速吸吐氣
  4. （D）深吸氣後閉氣

答案：（D）

詳解與考點

正解：題眼在「拔除胸管」——移除管路的瞬間須避免空氣被吸入胸腔，因此指導病人深吸氣後閉氣，以提高胸腔內壓、減少空氣進入的機會，故選 D。

A：緩慢吸吐氣無法在拔管瞬間有效提高胸腔內壓，仍可能隨吸氣造成空氣進入，故非答案。

B：哈氣常用於某些呼吸訓練，但不是拔除胸管時建立短暫正壓的標準指令，故非答案。

C：快速吸吐氣會增加胸腔壓力變動，無法穩定地配合拔管時機，故非答案。這是最強誘答——看似能「加強呼吸」，卻與拔管時要短暫阻斷吸氣、減少進氣的目的相反。

本題考點：胸管移除（chest tube removal）的核心是防止空氣進入胸腔；可採深吸氣後閉氣或依指示完成瓦爾薩爾瓦動作（Valsalva maneuver）；拔管後須立即以密封敷料覆蓋傷口並觀察呼吸狀態。

  2. （B）禁食直到作嘔反射恢復
  3. （C）臥床休息至少 4 小時
  4. （D）咳出微量血絲痰應立即通知醫師

答案：（B）

詳解與考點

正解：題眼在「支氣管鏡檢查後」——檢查與局部麻醉會暫時抑制作嘔反射，反射未恢復前進食或飲水容易嗆咳、吸入，故應禁食至作嘔反射恢復，選 B。

A：床頭可適度抬高以利呼吸與分泌物引流，但固定抬高至 80～90 度不是此檢查後最優先的通用措施，故非答案。

C：是否需臥床及時間應依鎮靜程度、生命徵象與檢查後狀況評估，不能一概規定至少 4 小時，故非答案。

本題考點：支氣管鏡檢查（bronchoscopy）後先確認作嘔反射（gag reflex）恢復再進食；護理評估包括呼吸狀態、出血量與鎮靜恢復；少量血絲痰與進行性出血的處置優先序不同。

  1. （A）肺餘容積（RV）
  2. （B）第一秒用力呼氣容積（FEV1）
  3. （C）血氧濃度（SaO2）
  4. （D）急性惡化的次數

正解：題眼在「GOLD 1～4 級」——此分級問的是 COPD 氣流受限的肺功能嚴重度，主要依支氣管擴張劑後第一秒用力呼氣容積（FEV1）判定，故選 B。

A：肺餘容積可反映氣體滯留與過度充氣，卻不是 GOLD 1～4 氣流受限分級的主要依據，故非答案。

  2. （B）肺部基底部出現反響音

詳解與考點

正解：題眼在「下肺區」與「支氣管呼吸音」——正常支氣管呼吸音應在氣管及大支氣管附近聽到；下肺野聽到它表示肺實質傳音異常或其他病變可能，故（C）為異常結果。

有關接受肺葉切除手術病人之護理，下列敘述何者正確？
  1. （A）術前接受肺功能檢查，可作為評估術後咳嗽能力的指標
  2. （B）術後教導避免肩部與手臂運動，以利傷口癒合
  3. （C）採肺葉切除手術，術後應臥向患側，以利健側肺部氣體交換
  4. （D）術後使用誘發性肺量計（incentive spirometry），可預防肺塌陷

答案：（D）

詳解與考點

正解：題眼在「肺葉切除術後」與「誘發性肺量計」——術後疼痛、淺呼吸與分泌物滯留會使肺泡擴張不足；規律使用誘發性肺量計可促進深吸氣與肺泡復張，降低肺塌陷風險，故選 D。

本題考點：肺切除術後照護（post-lobectomy care）重點為有效止痛、深呼吸、咳嗽與早期活動；誘發性肺量計（incentive spirometry）可促進肺泡擴張；擺位應配合術式與醫囑。

  1. （A）給與止痛藥，避免肺擴張不全，降低通氣量
  2. （B）給與氧氣，FiO2 60%
  3. （C）給與全血，避免血色素低下，影響攜氧量

正解：題眼是「心衰竭病史」加上「急性呼吸衰竭」——處置除了改善氧合，也必須避免不必要的容量負荷。全血容量大，對已有心衰竭且全血需求未經明確證實者，容易加重循環負荷與肺水腫，故（C）最不適宜。

本題考點：急性呼吸衰竭（acute respiratory failure）先處理氧合與通氣；肋骨骨折須兼顧止痛與肺擴張；心衰竭病人輸液或輸血須警覺容量負荷（volume overload）。

  2. （B）急性肺水腫
  3. （C）急性腎衰竭利尿期
  4. （D）急性巴比妥類中毒

詳解與考點

正解：題眼在「透析治療之適應症」與「不適宜」——透析用於無法以保守治療控制的嚴重電解質失衡、體液過多、特定可透析毒物或腎衰竭併發症；急性腎衰竭的利尿期代表尿量回升，通常不是單憑此期別就要透析，故選 C。

  4. （D）指導病人每天攝取至少 3,000 c.c.以上液體

正解：題眼在「膀胱炎」與「最適宜」——在無禁忌的情況下，增加水分攝取可增加尿量、促進排尿與沖洗泌尿道；題幹所示每日 3,000 c.c. 以上液體攝取符合此衛教方向，故選 D。

正解：題眼在「副甲狀腺功能低下」——副甲狀腺素不足會使血鈣降低、血磷升高，長期可有神經肌肉與眼部表現。①嗜睡、④白內障、⑤高血磷皆符合，故選 B。

A：此組合含③。副甲狀腺功能低下時骨質再吸收減少，並非骨質耗損加劇，故③錯誤。

C：此組合含②與③。病人應為低血鈣而非高血鈣，且骨質耗損加劇亦不符，故非答案。

D：此組合含②與③，將副甲狀腺素不足的鈣、磷與骨代謝方向反置，故非答案。

本題考點：副甲狀腺功能低下症（hypoparathyroidism）造成低血鈣與高血磷；副甲狀腺素（parathyroid hormone）促進血鈣維持；慢性低血鈣可有神經肌肉興奮及白內障。

第 74 題

下列何種情況可能會導致特魯索氏（Trousseau）與沃斯德克氏（Chvostek）徵象皆呈陽性反應？①低 血鈣 ②低血鉀 ③低血糖 ④副甲狀腺功能低下症
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：題眼在 Trousseau 與 Chvostek 徵象同時陽性——兩者都反映低血鈣造成的神經肌肉興奮性增加。①低血鈣可直接引起這兩種徵象；④副甲狀腺功能低下會造成低血鈣，故①④成立，選 B。

A：此組合含②。低血鉀主要影響肌肉與心臟電氣活動，並非這兩項典型徵象的共同原因。

C：②低血鉀與③低血糖都不是 Trousseau 與 Chvostek 徵象的典型共同機轉，故非答案。

D：此組合含③。低血糖可出現冒汗、顫抖或意識改變，但不能取代低血鈣作為兩徵象的判準。

本題考點：特魯索氏徵象（Trousseau sign）與沃斯德克氏徵象（Chvostek sign）提示低血鈣；低血鈣（hypocalcemia）使神經肌肉興奮性上升；副甲狀腺功能低下症（hypoparathyroidism）是其常見病因。

第 75 題

有關急救使用手壓式甦醒球面罩（Ambu Bag mask）給與人工呼吸的敘述，下列何者正確？
  1. （A）當病人 SPO2 95%時應該使用
  2. （B）面罩較尖的部位應對準病人下巴
  3. （C）氧氣流速調整至 12～15 公升／分鐘
  4. （D）一手使面罩密合病人口鼻，另一手應儘量完全壓扁球囊

答案：（C）

詳解與考點

正解：題眼在「Ambu Bag mask」急救人工呼吸——判準是須讓球囊連接足夠氧氣流量與儲氧裝置，才可提供高濃度氧氣。氧氣流速調整至 12～15 L/min 符合此急救操作，故選 C。

A：SpO2 95%本身不構成使用手壓式甦醒球面罩的適應情境；應依病人的呼吸、意識與氧合狀態整體評估。

B：面罩尖端應對準鼻樑，較寬部位覆蓋口鼻周圍；尖端對準下巴會使面罩難以密合。

D：應以適當潮氣量、可見胸廓起伏為原則，完全壓扁球囊容易過度通氣。這是最強誘答——一手密合面罩的方向正確，錯在把「儘量完全壓扁」當成有效通氣。

本題考點：手壓式甦醒球面罩（bag-valve-mask）須建立面罩密合；過度通氣（hyperventilation）會增加胸腔壓力並影響循環；人工呼吸以可見胸廓起伏為適當通氣判準。

第 76 題

有關施行心肺復甦術（CPR）成功徵象的敘述，下列何者正確？①四肢有動作反應 ②有自發性呼吸 ③刺激眼瞼會眨眼 ④瞳孔對光反射固定
  1. （A）①②③
  2. （B）①②④
  3. （C）①③④
  4. （D）②③④

答案：（A）

詳解與考點

正解：題眼在 CPR「成功徵象」——判準是自主循環恢復後，腦部與呼吸功能重新出現反應。①四肢動作、②自發性呼吸、③刺激眼瞼會眨眼皆表示神經與呼吸反應恢復；④瞳孔對光反射固定反而是嚴重神經功能受損警訊，故①②③成立，選 A。

B：此組合含④。瞳孔固定而缺乏對光反射不是復甦成功表現，故非答案。

C：此組合含④，即使有動作反應，固定瞳孔仍不能列為成功徵象。

D：此組合含④。自發呼吸及眨眼為正向反應，但固定瞳孔與成功判準相牴觸，故非答案。

本題考點：自主循環恢復（return of spontaneous circulation）可伴隨自發呼吸與動作反應；瞳孔對光反射（pupillary light reflex）反映腦幹功能；心肺復甦術（cardiopulmonary resuscitation）後須持續評估生命徵象與神經狀態。

第 77 題

下列何類休克有皮膚潮紅、溫暖的臨床徵象？①低血容性 ②敗血性 ③心因性 ④神經性
  1. （A）①②
  2. （B）①③
  3. （C）②④
  4. （D）③④

答案：（C）

詳解與考點

正解：題眼在休克合併「皮膚潮紅、溫暖」——判準是周邊血管擴張造成的分布異常性休克。②敗血性休克早期因發炎介質造成血管擴張，④神經性休克因交感神經張力喪失而血管擴張，皆可見溫暖潮紅皮膚，故選 C。

A：①低血容性休克因血容量減少而周邊血管收縮，皮膚多冰冷濕黏，故非答案。

B：此組合含①與③。①低血容性休克因血容量不足而周邊血管收縮、③心因性休克因心輸出量下降並代償性收縮，兩者皮膚皆冰冷濕黏，與題幹的潮紅溫暖相反，故非答案。

D：此組合含③。心因性休克因心輸出量下降且周邊代償性收縮，皮膚多冰冷；它是最強誘答，因同屬循環失調，但血管張力方向不同。

本題考點：敗血性休克（septic shock）早期可因血管擴張呈溫暖皮膚；神經性休克（neurogenic shock）因交感神經失調而血管擴張；低血容性與心因性休克常呈冰冷濕黏皮膚。

第 78 題

有關敗血症生理病理機轉之敘述，下列何者正確？①細菌感染引發腫瘤壞死因子活化產生微小血栓 ②微生物侵入人體造成微血管通透性增加、全身循環血量增加 ③全身代謝狀態升高造成細胞耗氧量 增加，但組織血流灌注降低，產生代謝性酸中毒 ④因心臟受刺激出現血壓上升，可能引發尿量增加
  1. （A）①②
  2. （B）①③
  3. （C）②④
  4. （D）③④

答案：（B）

詳解與考點

正解：題眼在敗血症的全身發炎、微循環與代謝變化——判準是發炎反應造成微血栓、血管滲漏與組織低灌流。①細菌感染可經發炎介質活化凝血並形成微小血栓；③高代謝使耗氧量增加而灌流下降，導致代謝性酸中毒，故①③成立，選 B。

A：此組合含②。微血管通透性增加會使液體外滲、有效循環血量下降，而不是增加。

C：②與④皆錯誤。敗血症可低血壓與腎灌流下降，不能以血壓上升、尿量增加解釋。

D：此組合含④。心血管失代償常造成低血壓及少尿，與④相反；②亦因有效循環血量方向寫反而錯誤。

本題考點：敗血症（sepsis）可引發全身發炎反應；微血管通透性增加（capillary leak）造成有效循環血量下降；組織低灌流（tissue hypoperfusion）與高代謝可導致代謝性酸中毒。

第 79 題

下列何者不需採取腸道隔離？
  1. （A）痢疾
  2. （B）傷寒
  3. （C）腮腺炎
  4. （D）霍亂

答案：（C）

詳解與考點

正解：題眼在「不需採取腸道隔離」——判準是病原是否主要經糞口途徑傳播。腮腺炎主要經飛沫與呼吸道分泌物傳播，並非腸道傳播，故選 C。

A：痢疾可經糞口途徑傳播，排泄物處置與手部衛生是防護重點，故非答案。

B：傷寒可由受污染食物或飲水經糞口傳播，需採腸道傳播防護原則。

D：霍亂亦以糞口途徑傳播，應重視排泄物、食物與飲水的污染控制。

本題考點：腸道傳播（enteric transmission）以糞口途徑為主；腮腺炎（mumps）主要為飛沫傳播；感染管制（infection control）須依傳播途徑選擇防護措施。

第 80 題

有關登革熱病人的隔離防護措施，下列何者正確？
  1. （A）接觸隔離
  2. （B）呼吸道隔離
  3. （C）腸道隔離
  4. （D）血液和體液的防護

答案：（D）

詳解與考點

正解：題眼在「登革熱」的傳播方式——登革病毒主要藉病媒蚊叮咬傳播，並非病人間的接觸、飛沫或腸道傳播；臨床照護仍須依標準防護處理可能接觸的血液與體液，故選 D。

A：接觸隔離用於主要由直接或間接接觸傳播的病原，非登革熱的一般傳播途徑。

B：呼吸道隔離針對飛沫或空氣傳播疾病；登革熱不經呼吸道分泌物作為主要傳播媒介。

C：腸道隔離用於糞口傳播疾病，與登革熱的病媒蚊傳播不符。

本題考點：登革熱（dengue fever）屬病媒傳播疾病（vector-borne disease）；標準防護（standard precautions）包含血液與體液暴露防護；病媒蚊控制是阻斷登革熱傳播的重要環節。
