第 1 題

有機磷殺蟲劑中毒患者，出現縮瞳、多汗、流涎等臨床表徵是屬於何種作用？
  1. （A）消化道刺激
  2. （B）菸鹼性作用
  3. （C）蕈毒鹼性作用
  4. （D）神經性反射作用

答案：（C）

詳解與考點

正解：題眼在「縮瞳、多汗、流涎」——有機磷抑制乙醯膽鹼酯酶，使乙醯膽鹼累積；腺體分泌增加與瞳孔收縮是副交感神經蕈毒鹼性受體刺激的典型表現，故選 C。

A：消化道刺激可造成噁心、嘔吐或腹瀉，但無法完整解釋縮瞳、多汗與流涎這組膽鹼性表徵，故非答案。

B：菸鹼性作用主要表現在骨骼肌顫動、無力或癱瘓及自主神經節症狀，與題幹的腺體分泌、縮瞳主軸不同，故非答案。

D：神經性反射不是有機磷中毒分類時用來解釋此組症狀的機轉。這是最強誘答——症狀發生於神經調控下，但判斷應看乙醯膽鹼作用的受體類型，故非答案。

本題考點：有機磷中毒（organophosphate poisoning）——乙醯膽鹼酯酶抑制使乙醯膽鹼累積；蕈毒鹼性作用（muscarinic effects）常見縮瞳、分泌增加與支氣管收縮；菸鹼性作用（nicotinic effects）偏向肌束顫動與肌無力。

第 2 題

急性呼吸窘迫症候群（ARDS）患者出現廣泛性肺擴張不全，主因肺泡內水腫影響那一種肺泡細胞的 生理功能？
  1. （A）第一類細胞的氣體交換
  2. （B）第二類細胞分泌表面張力素
  3. （C）第三類巨噬細胞吞噬外來物
  4. （D）柯恩氏孔（pores of Kohn）的氣體流通

答案：（B）

詳解與考點

正解：題眼在「ARDS」「肺泡內水腫」與「廣泛性肺擴張不全」——肺泡水腫會干擾第二型肺泡細胞製造或維持表面張力素的功能，表面張力升高後肺泡較易塌陷，故選 B。

A：第一型肺泡細胞主要構成氣體交換屏障；其受損會造成氧合障礙，但題幹特別問廣泛肺泡擴張不全的機轉，重點是表面張力素不足，故非答案。

C：肺泡巨噬細胞的主要功能是吞噬病原與異物，並非維持肺泡張開的關鍵，故非答案。

D：柯恩氏孔可提供相鄰肺泡間的側枝通氣，但不能取代表面張力素防止肺泡塌陷。這是最強誘答——它也與肺泡通氣有關，然而題幹所指的瀰漫性擴張不全是表面張力失衡所致，故非答案。

本題考點：急性呼吸窘迫症候群（acute respiratory distress syndrome, ARDS）——肺泡─微血管屏障受損造成非心因性肺水腫；第二型肺泡細胞（type II pneumocyte）分泌表面張力素（surfactant），有助維持肺泡張開。

第 3 題

有關口服降血糖藥物的護理指導，下列何者正確？
  1. （A）α配糖酵素抑制劑需餐後服用，由小劑量開始，以免發生低血糖
  2. （B）磺基尿素類（sulfonylureas）藥物常伴隨飲食不足，產生高血糖反應
  3. （C）服用雙胍類（biguanides）藥物，應注意乳酸中毒和腎毒性的副作用
  4. （D）糖皮質類固醇與磺基尿素類藥物交互作用，會使血糖降低

答案：（C）

詳解與考點

正解：題眼在「雙胍類」——此類藥物主要經腎排除，腎功能不全時藥物蓄積、乳酸中毒風險升高，因此護理指導須追蹤腎功能並衛教乳酸中毒的徵象（如噁心、肌肉痠痛、呼吸急促、意識改變），故選 C。要澄清的是，臨床重點在於腎功能受損者禁用或減量，而非藥物直接損傷腎臟。

A：α 配糖酵素抑制劑應在進食開始時隨第一口飯服用，以延緩醣類分解吸收，餐後服用不符其作用時機；且單獨使用此類藥物不易造成低血糖，其自小劑量起始是為減少腸胃脹氣與腹瀉，選項把理由歸為低血糖亦誤，故非答案。

B：磺基尿素類會促進胰島素分泌，飲食不足時主要風險是低血糖而非高血糖，故非答案。

D：糖皮質類固醇會使血糖上升，可能削弱降血糖藥效。這是最強誘答——兩者確有交互影響，但方向是高血糖風險增加，故非答案。

本題考點：口服降血糖藥（oral antidiabetic drugs）——雙胍類（biguanides）須留意乳酸中毒與腎功能；磺基尿素類（sulfonylureas）在進食不足時易低血糖；α 配糖酵素抑制劑（alpha-glucosidase inhibitors）須隨餐服用且單用不易低血糖。

第 4 題

有關尿失禁的處置，下列何者錯誤？
  1. （A）予抗乙醯膽鹼藥物，以減少膀胱頸的阻力
  2. （B）予女性激素，以改善尿流阻塞的情況
  3. （C）予陰道前方修補術，以壓迫尿道，增加尿流阻力
  4. （D）教導凱格爾氏運動（Kegel’s exercise），以增進尿道阻力

答案：（A）

詳解與考點

正解：題眼在「何者錯誤」及「抗乙醯膽鹼藥物」——抗乙醯膽鹼藥可降低逼尿肌收縮、增加膀胱儲尿能力，可能用於急迫性尿失禁；它不是用來減少膀胱頸阻力，題述機轉錯誤，故 A 為應選項。

B：女性荷爾蒙不足造成泌尿生殖道萎縮時，局部雌激素治療可改善相關組織狀態；其適用性仍須依病人型態評估，故非答案。

C：陰道前壁修補術可處理膀胱膨出等解剖支撐問題，藉重建骨盆底支持以改善壓力性尿失禁，故非答案。

D：凱格爾氏運動強化骨盆底肌群與尿道支持，可增加尿道閉合阻力。這是最強誘答——它看似只是一般運動指導，但其作用正對應壓力性尿失禁的病理機轉，故非答案。

本題考點：尿失禁（urinary incontinence）——急迫性尿失禁可用抗膽鹼作用降低逼尿肌過度活動；壓力性尿失禁著重骨盆底肌訓練（Kegel's exercise）與結構支持；治療須依失禁類型選擇。

第 5 題

有關末期腎疾病（ESRD）引起的腎性貧血，下列敘述何者錯誤？
  1. （A）與紅血球存活期縮短有關
  2. （B）主要因缺乏紅血球生成素
  3. （C）因凝血時間延長，易造成腸胃道出血
  4. （D）主要以鐵劑和葉酸來刺激血液生成

答案：（D）

詳解與考點

正解：題眼在「末期腎疾病引起的腎性貧血」與「何者錯誤」——腎性貧血的核心是腎臟產生紅血球生成素不足，治療主軸是補足紅血球生成素並依檢驗情形補鐵；（D）把鐵劑和葉酸說成主要用來刺激血液生成，遺漏核心機轉，故為應選項。

A：尿毒環境可使紅血球存活期縮短，會加重腎性貧血，故非答案。

B：腎臟紅血球生成素不足使骨髓紅血球生成受限，是腎性貧血的主要原因，故非答案。

C：末期腎疾病可因尿毒相關血小板功能異常增加出血傾向，腸胃道出血會使貧血惡化，故非答案。

本題考點：腎性貧血（renal anemia）——主要機轉是紅血球生成素（erythropoietin）不足，亦受紅血球壽命縮短與鐵利用狀態影響；尿毒症（uremia）可伴血小板功能異常與出血風險。

第 6 題

有關氣喘病人尖峰呼氣流速（Peak Expiratory Flow Rate, PEFR）的護理指導，下列何者正確？
  1. （A）氣喘治療期間所測得的 PEFR 值達最佳預期值，即可減少藥量
  2. （B）取二次吹氣數值之平均值記錄於氣喘日誌內
  3. （C）若 PEFR＜60％表示氣喘屬於紅燈區，須立即就醫
  4. （D）PEFR 值與病人之身高及年齡有關，與性別無關

答案：（C）

詳解與考點

正解：題眼在「PEFR<60％」——尖峰呼氣流速低於個人最佳值的 60％屬紅燈區，表示氣流受限嚴重，應依氣喘行動計畫立即處置並就醫，故選 C。

A：PEFR 達到最佳預期值不代表可自行減少藥量；控制藥物調整應依整體症狀與醫囑評估，故非答案。

B：測量時通常重複吹氣並記錄最高值，以反映可達到的尖峰呼氣流速，不是取二次平均值，故非答案。

D：個人預測或最佳 PEFR 的判讀會考量身高、年齡及性別。這是最強誘答——身高與年齡確實重要，但漏掉性別便使敘述不完整而錯誤，故非答案。

本題考點：尖峰呼氣流速（peak expiratory flow rate, PEFR）——以個人最佳值作比較；紅燈區（red zone）為低於 60％，代表嚴重氣流阻塞；居家監測取多次測量中的最高值。

第 7 題

注射 mitomycin 化學藥物發生外滲現象之處置，下列何者錯誤？
  1. （A）檢查靜脈導管有無回血及注射部位之腫脹情形
  2. （B）應停止注射藥物，並立刻拔出針頭套管
  3. （C）在外滲部位注射解毒劑，減少組織傷害
  4. （D）屬於發泡類藥物，外滲後應冷敷注射部位

答案：（B）

詳解與考點

正解：題眼在「mitomycin 化學藥物外滲」與「何者錯誤」——外滲時應立刻停止注射，但不可立刻拔除針頭或套管，須先保留管路嘗試回抽殘餘藥物，並供必要處置使用；（B）跳過保留通路的步驟，故為應選項。

A：觀察有無回血及局部腫脹，可協助及早辨識外滲並評估導管狀況，是正確處置，故非答案。

C：依藥物特性經既有管路或局部使用適當解毒處置，可降低組織傷害；重點是不可先拔除管路，故非答案。

D：mitomycin 屬發泡性藥物，冷敷可協助限制局部擴散，故非答案。這是最強誘答——冷、熱敷取決於藥物性質，不能套用所有化療藥，但本題指定 mitomycin，方向正確。

本題考點：化學治療外滲（chemotherapy extravasation）——立即停止輸注、保留導管並回抽殘餘藥物、依藥物採適當解毒與冷熱敷；發泡性藥物（vesicant）外滲可造成嚴重組織傷害。

第 8 題

接受高劑量化學治療，發生急性腫瘤溶解症候群的病人，會出現下列何種檢驗值的變化？
  1. （A）［ _ 2 4 PO ］下降
  2. （B）［K＋ ］上升
  3. （C）［Ca2＋ ］上升
  4. （D）［Uric acid］下降

答案：（B）

詳解與考點

正解：題眼在「高劑量化學治療」與「急性腫瘤溶解症候群」——大量腫瘤細胞快速破裂會釋出細胞內鉀離子，使血鉀上升，故選 B。

A：細胞內核酸分解後會增加磷酸鹽，腫瘤溶解症候群常見高磷血症，而非磷酸鹽下降，故非答案。

C：升高的磷酸鹽會與鈣結合，常造成血鈣下降而非上升，故非答案。

D：細胞核酸大量分解會形成尿酸，尿酸上升可造成腎損傷。這是最強誘答——尿酸確是檢驗重點，但變化方向若寫成下降即與細胞溶解機轉相反，故非答案。

本題考點：腫瘤溶解症候群（tumor lysis syndrome）——細胞快速破裂造成高血鉀（hyperkalemia）、高磷血症（hyperphosphatemia）、低血鈣（hypocalcemia）與高尿酸血症（hyperuricemia）；須警覺心律不整與急性腎損傷。

第 9 題

前壁與心尖之心肌梗塞，其阻塞之冠狀動脈血管最可能為下列何者？
  1. （A）左前降枝冠狀動脈
  2. （B）右冠狀動脈
  3. （C）左總冠狀動脈
  4. （D）左迴旋枝冠狀動脈

答案：（A）

詳解與考點

正解：題眼在「前壁與心尖」心肌梗塞——左前降枝供應左心室前壁、心尖及部分心室中隔，其阻塞最能對應這一組受損部位，故選 A。

B：右冠狀動脈較常供應右心與左心室下壁，阻塞時較易出現下壁相關梗塞，不符前壁與心尖的定位，故非答案。

C：左總冠狀動脈阻塞會影響其分支供應的大範圍心肌，臨床後果通常更廣泛；題幹指向特定前壁與心尖區域，故非答案。

D：左迴旋枝主要供應左心室側壁與後外側區域。這是最強誘答——它同屬左冠狀動脈系統，卻因供應區不同，不能解釋前壁加心尖的典型定位，故非答案。

本題考點：冠狀動脈供應（coronary circulation）——左前降枝（left anterior descending artery）供應前壁與心尖；右冠狀動脈（right coronary artery）常與下壁相關；左迴旋枝（left circumflex artery）多供應側壁。

第 10 題

下列何項檢驗可確立痛風診斷？
  1. （A）antinuclear antibodies
  2. （B）alkaline phosphatase
  3. （C）calcium and phosphorus
  4. （D）uric acid

答案：（D）

詳解與考點

正解：題眼在「確立痛風診斷」——官方答案為 D；血清尿酸可作為痛風的支持性檢驗，尿酸代謝異常也與痛風病理相關。惟單獨血清尿酸升高不能確立診斷，急性發作時也可能不高；臨床上以關節液檢出單鈉尿酸鹽結晶較具確診性。本題選項未列此檢查，故依官方答案選 D。

A：抗核抗體主要用於評估特定自體免疫疾病，不是痛風的確診檢驗，故非答案。

B：鹼性磷酸酶多用於肝膽或骨代謝相關評估，不能確認尿酸鹽結晶性關節炎，故非答案。

C：鈣與磷可協助評估其他代謝或骨骼問題，無法作為痛風的特異性診斷依據，故非答案。

本題考點：痛風（gout）——病理基礎為單鈉尿酸鹽結晶（monosodium urate crystals）沉積；血清尿酸（serum uric acid）可支持風險評估但非單獨確診；關節液結晶檢查（synovial fluid crystal analysis）較具診斷性。

第 11 題

有關肺結核病之敘述，下列何者正確？
  1. （A）原發性感染 2～6 個月後，結核菌素皮膚試驗才會呈現陽性反應
  2. （B）原發性感染後，常見病人咳嗽、發燒，不易診斷
  3. （C）結核桿菌會經由無生命的物品傳染，急性期病人需要接觸性隔離
  4. （D）結核菌感染治癒後，會產生終生免疫

答案：（B）

詳解與考點

正解：題眼在「原發性感染後」——初次感染肺結核常見症狀不明顯或非特異，也可能出現咳嗽、發燒而難以立刻辨識，故選 B。

A：結核菌素皮膚試驗在感染後需一段時間才可能轉為陽性，但題述的時間範圍不符合常用判讀，故非答案。

C：肺結核主要經含菌飛沫核的空氣傳播，應採空氣隔離，而不是經無生命物品傳染並採接觸隔離，故非答案。

D：感染或治癒後不代表產生終生免疫，仍可能再感染或復發。這是最強誘答——免疫反應會使檢驗轉陽，但檢驗陽性不等於具完全且永久的保護力，故非答案。

本題考點：肺結核（tuberculosis）——主要為空氣傳播（airborne transmission），照護採空氣隔離；原發性結核感染（primary tuberculosis infection）可症狀不典型；感染後的免疫反應不等於終生免疫。

第 12 題

正解：題眼在「眼前庭試驗」與「測試時眼球不偏向」——判準是冷熱刺激誘發的眼前庭反射。試驗刺激前庭系統後，腦幹功能完整者會出現可預期的眼球偏移與眼震；眼球不偏向反而提示反射缺失或腦幹功能受損，故 D 為應選項。

本題考點：眼前庭試驗（oculovestibular test/caloric test）評估腦幹反射；第 8 對腦神經提供前庭傳入，第 3、6 對腦神經參與眼球運動；反射消失應警覺腦幹功能異常。

  2. （B）戴手套處理體液和排泄物
  3. （C）更換的床單應留在病室內，等檢查不具放射性後才處理
  4. （D）皮膚接觸到病人體液時，應用肥皂及大量清水清洗

正解：題眼在「靜脈注射放射性同位素」與「保護措施錯誤」——判準是依放射性污染物的管制流程處理病人、體液與物品，而非把一般放射性物質操作設備直接放入病室。長鑷與鉛製容器主要用於處理放射性物質來源或廢棄物，並非每位接受靜脈同位素治療病人都須在室內配置，故 A 為應選項。

答案：（B）

正解：題眼在「長期缺氧」——慢性低氧會使末梢組織增生，典型指甲外觀為杵狀指（clubbing），指端膨大、指甲弧度增加，故選 B。

A：灰指甲主要是黴菌感染造成的甲板增厚、變色或碎裂，判準是局部感染，非慢性缺氧。

C：匙狀指是指甲中央凹陷、邊緣上翹的外觀，常與缺鐵等狀態相關；它看似也是指甲變形，但變形方向與杵狀指的末端膨大不同。

D：指甲凹陷可見於局部甲床受損或某些皮膚疾病，不能作為長期缺氧的代表徵象。

本題考點：杵狀指（clubbing）是慢性低氧的末梢身體評估徵象；匙狀指（koilonychia）重點在甲板中央凹陷；身體評估（physical assessment）須以外觀特徵連回病理機轉。

第 73 題

辜女士即將接受骨髓移植治療，以下何者代表其對骨髓移植有正確認識？
  1. （A）有治療希望的疾病，才可以接受這種治療
  2. （B）由於醫療科技的進步，接受移植已經沒有風險
  3. （C）捐髓者與受髓者在移植前都需要經過周延的檢查與評估
  4. （D）骨髓損贈者都來自親人

答案：（C）

詳解與考點

正解：題眼在「骨髓移植」與「正確認識」——移植前必須同時評估受髓者的適應性、感染與器官功能，以及捐髓者的健康與配對情形，故選 C。

A：是否可接受移植須依疾病狀態、治療目標、配對與整體風險綜合判定，不是只要「有治療希望」即可決定。

B：移植仍有感染、移植物相關併發症與排斥等風險。這是最強誘答——醫療科技進步確能改善結果，但不能把風險降低誤解為沒有風險。

D：捐髓者可為符合配對條件的親屬或非親屬捐贈者，並非都來自親人。

本題考點：造血幹細胞移植（hematopoietic stem cell transplantation）前需完成捐、受者評估與組織相容性配對；知情同意（informed consent）須包含效益與風險；感染預防（infection prevention）是移植照護重點。

第 74 題

下列何者是骨質疏鬆症患者易發生骨折的部位？
  1. （A）脊椎、腕部、髖部
  2. （B）腳踝、腕部、頸部
  3. （C）髖部、膝蓋、腳踝
  4. （D）肩部、髖部、鎖骨

答案：（A）

詳解與考點

正解：題眼在「骨質疏鬆症」——骨量降低時最常見的脆弱性骨折部位是脊椎、遠端橈骨所在的腕部與髖部，故選 A。

B：腳踝與頸部不是骨質疏鬆症最具代表性的三個脆弱性骨折部位；腕部雖正確，但整組不符。

C：髖部正確，但膝蓋與腳踝較常需考量外傷機轉，不能取代脊椎與腕部的典型組合。

D：髖部雖常見，肩部與鎖骨並非此病的標準高風險組合。這是最強誘答，因為肩部也可能骨折，但題目問的是骨質疏鬆最典型的部位。

本題考點：骨質疏鬆症（osteoporosis）造成脆弱性骨折（fragility fracture）；典型部位為脊椎、腕部與髖部；跌倒預防（fall prevention）是護理安全措施。

第 75 題

下列何者不是腸憩室炎的潛在合併症？
  1. （A）腹膜炎
  2. （B）腸麻痺
  3. （C）膿瘍
  4. （D）出血

答案：（B）

詳解與考點

正解：題眼在「不是」與「腸憩室炎」——憩室發炎可穿孔而引發腹膜炎，也可形成膿瘍或出血；腸麻痺不是其典型直接潛在合併症，故選 B。

A：發炎若穿孔使腸內容物流入腹腔，可造成腹膜炎，故為可能合併症。

C：局部感染受限時可形成膿瘍，故非答案。

D：憩室疾病可合併腸道出血；它看似較像單純憩室症的表現，但仍屬憩室相關的臨床併發問題，非本題所問的排除項。

本題考點：腸憩室炎（diverticulitis）可出現穿孔、腹膜炎與膿瘍；腸道出血（intestinal bleeding）可見於憩室疾病；併發症鑑別（complication differentiation）須連結發炎與穿孔機轉。

第 76 題

二氧化碳過高型急性呼吸衰竭病患，下列生理反應何者錯誤？
  1. （A）PaCO2 升高
  2. （B）PaO2 正常
  3. （C）腦部血管擴張
  4. （D）呼吸性酸中毒

答案：（B）

詳解與考點

正解：題眼在「二氧化碳過高型急性呼吸衰竭」與「錯誤」——肺泡通氣不足會使 PaCO2 升高，且常伴隨低氧血症，不應判為 PaO2 正常，故 B 為應選項。

A：肺泡通氣不足無法有效排出二氧化碳，PaCO2 升高是此型呼吸衰竭的核心改變，故非答案。

C：二氧化碳上升可造成腦部血管擴張，嚴重時可能伴隨頭痛、意識改變，故非答案。

D：急性二氧化碳滯留使碳酸增加，會形成呼吸性酸中毒，故非答案。這是最強誘答，因為慢性代償可使酸鹼值接近正常，但「急性」階段仍以呼吸性酸中毒判讀。

本題考點：第二型呼吸衰竭（type II respiratory failure）以高碳酸血症為主並常合併低氧血症；呼吸性酸中毒（respiratory acidosis）源於二氧化碳滯留；神經學評估（neurological assessment）須留意高碳酸血症的意識變化。

第 77 題

有關消化性潰瘍的診斷性檢查，下列何者正確？
  1. （A）胃鏡檢查可以直接確立幽門螺旋桿菌感染
  2. （B）上腸胃道攝影是最有效的診斷方法
  3. （C）經由胃液分析測量胃液量及游離酸量
  4. （D）血清抗體檢測 IgE，可確立幽門螺旋桿菌感染

答案：（C）

詳解與考點

正解：題眼在「消化性潰瘍的診斷性檢查」——胃液分析可測得胃液量及游離酸量，所述檢查內容正確，故選 C。

A：胃鏡可直接看見黏膜病灶並取得檢體，但要確立幽門螺旋桿菌感染仍須以活檢後的檢驗等方式確認，不能只憑胃鏡視覺判定。

B：上腸胃道攝影可協助觀察結構異常，但胃鏡能直接觀察與取樣，不能稱為最有效的診斷方法。

D：幽門螺旋桿菌的血清學檢測以相關抗體為主，IgE 不是確立此感染的檢測指標。這是最強誘答，因為「抗體檢測」方向看似合理，關鍵在抗體種類不能任意替換。

本題考點：胃液分析（gastric analysis）可評估胃液量與酸分泌；上消化道內視鏡（upper gastrointestinal endoscopy）可觀察病灶並取樣；幽門螺旋桿菌檢測（Helicobacter pylori testing）須以適當檢驗確認。

第 78 題

膽結石患者服用 cholestyramine（questran）之目的，下列何者正確？
  1. （A）結合膽道中的膽鹽
  2. （B）消除膽道平滑肌痙攣
  3. （C）分解膽固醇性膽結石
  4. （D）促進脂溶性維生素的吸收

答案：（A）

詳解與考點

正解：題眼在 cholestyramine 與「目的」——此藥為膽酸結合樹脂，於腸道與膽酸鹽結合成不被吸收的複合物，阻斷腸肝循環的再吸收，使膽鹽隨糞便排出；膽結石病人藉此減少膽鹽在血中蓄積所引起的搔癢，故選 A。臨床上實際結合部位在腸道，而非在膽道內直接作用。

B：解除膽道平滑肌痙攣屬解痙止痛方向，並非膽酸結合樹脂的作用。

C：此藥不會直接分解膽固醇性膽結石。這是最強誘答——它同樣提到膽結石，但「減少膽酸再吸收」不等於「溶解既有結石」。

D：膽酸被結合後，脂肪及脂溶性維生素的吸收反而可能受影響，不是促進吸收。

本題考點：cholestyramine 是膽酸結合樹脂（bile acid sequestrant）；腸肝循環（enterohepatic circulation）受阻可影響膽酸再吸收；脂溶性維生素吸收（fat-soluble vitamin absorption）是用藥監測重點。

第 79 題

α 干擾素與下列何種藥物合併治療慢性 C 型肝炎，效果較好？
  1. （A）adefovir dipivoxil
  2. （B）lamivudine（zeffix）
  3. （C）ribavirin
  4. （D）steroids

答案：（C）

詳解與考點

正解：題眼在「α 干擾素」與「慢性 C 型肝炎」——α 干擾素合併 ribavirin 為傳統的合併治療組合，可提升病毒清除率，故選 C。現行慢性 C 型肝炎治療已以直接作用抗病毒藥物為主。

A：adefovir dipivoxil 主要用於 B 型肝炎病毒相關治療，非此題的 C 型肝炎合併用藥。

B：lamivudine 亦主要針對 B 型肝炎病毒；它看似同為抗病毒藥物，但病毒種類與治療策略不能互換。

D：steroids 會抑制免疫反應，並非用來與 α 干擾素常規合併治療慢性 C 型肝炎的藥物。

本題考點：ribavirin 是核苷類似物（nucleoside analogue）；慢性 C 型肝炎（chronic hepatitis C）治療策略已演進；直接作用抗病毒藥物（direct-acting antivirals）為現行治療概念。

第 80 題

有關闌尾炎的護理措施，下列何者錯誤？
  1. （A）禁食
  2. （B）採半坐臥式
  3. （C）予灌腸，以緩解腹部脹痛
  4. （D）予冰敷，以緩解疼痛

答案：（C）

詳解與考點

正解：題眼在「闌尾炎」與「錯誤」——急性發炎時灌腸會增加腸蠕動與腸腔壓力，可能提高闌尾穿孔與腹膜炎風險，故 C 為應選項。

A：禁食可避免手術或處置前誤吸，亦便於病況惡化時立即處置，是正確措施。

B：半坐臥式可減輕腹部張力，並有助使感染性滲出液局限於骨盆腔，故非答案。

D：冰敷可在急性期協助減輕疼痛與局部發炎反應，故非答案。這是最強誘答，因為腹痛常讓人聯想到熱敷，但疑似急性闌尾炎不宜以熱敷促進局部充血。

本題考點：急性闌尾炎（acute appendicitis）有穿孔與腹膜炎風險；腹部急症（acute abdomen）避免灌腸與促蠕動處置；術前禁食（NPO）是安全準備。
