第 1 題

陳先生T3～T5脊髓損傷，目前血壓250/140 mmHg，心跳50～55次／分，有大量出汗情形，主訴頭部 嚴重疼痛、看東西模糊，超過6小時以上未解尿，陳先生可能發生何種現象？
  1. （A）神經性休克
  2. （B）自主神經過度反射
  3. （C）脊髓自動症
  4. （D）脊髓休克

答案：（B）

詳解與考點

自主神經過度反射（autonomic dysreflexia）發生於 T6 以上脊髓損傷，刺激物（此案例為膀胱脹尿超過 6 小時）引發橫隔膜以下血管劇烈收縮，導致血壓驟升（250/140 mmHg）、代償性心跳徐緩（50～55 次/分）、損傷平面以上出汗潮紅、嚴重頭痛及視覺模糊，符合 B 選項。神經性休克（A）為低血壓；脊髓休克（D）反射消失；脊髓自動症（C）為脊髓損傷後自發性無目的運動。

第 2 題

有關重症肌無力之敘述，下列何者正確？①屬於自體免疫疾病，體內產生攻擊Ach接受器的抗體 ② 第一型僅侵犯眼肌，造成複視和眼瞼下垂 ③四肢肌肉的無力發生在遠端和下肢且為不對稱 ④當 侵犯肋間肌，通氣容積會減少，嚴重呼吸困難致死
  1. （A）①②③
  2. （B）①②④
  3. （C）①③④
  4. （D）②③④

答案：（B）

詳解與考點

重症肌無力：①為自體免疫疾病，產生抗 AchR 抗體（正確）；② I 型僅侵犯眼肌（正確）；③四肢無力好發於「近端」（非遠端）且為對稱性（③錯誤）；④侵犯肋間肌造成通氣容積減少（正確）。故正確項目為①②④，答案為 B。最易誤選的是③，混淆了近端對稱性（重症肌無力）與 ALS 等遠端非對稱特徵。

第 3 題

有關腦膜炎病人接受腰椎穿刺檢查，下列敘述何者錯誤？
  1. （A）懷疑顱內壓升高時不宜執行腰椎穿刺
  2. （B）腰椎穿刺是將穿刺針由第三與第四腰椎椎間垂直穿入
  3. （C）腦脊髓液分析會出現總蛋白質減少及葡萄糖增加
  4. （D）正常之腦脊髓液壓力為70～180 mmH2O

答案：（C）

詳解與考點

細菌性腦膜炎腦脊髓液（CSF）分析特徵為：總蛋白質「升高」、葡萄糖「降低」（細菌大量消耗），選項 C 所述「蛋白質減少、葡萄糖增加」完全相反，故為錯誤。腰椎穿刺禁忌為顱壓升高（A 正確）；穿刺位置 L3～L4 椎間（B 正確）；正常 CSF 壓力 70～180 mmH₂O（D 正確）。

第 4 題

有關不同類型腦中風發作之比較，下列敘述何者錯誤？
  1. （A）暫時性缺血發作是血栓型腦中風之警訊
  2. （B）栓塞型腦中風的臨床症狀會突然發生
  3. （C）出血性腦中風會有劇烈頭痛前驅症狀
  4. （D）缺血性腦中風通常發作於活動時

答案：（D）

詳解與考點

缺血性腦中風（血栓型）通常在靜息或睡眠中發作（血流減慢易形成栓子），選項 D「發作於活動時」為錯誤，故為答案。出血性腦中風才常於活動、用力時因血壓驟升而發作。暫時性缺血發作（TIA）為血栓型警訊（A 正確）；栓塞型症狀突發（B 正確）；出血型有劇烈頭痛（C 正確）。

第 5 題

病人跌倒造成腦部枕葉受損時出現的症狀，下列何者正確？
  1. （A）無法控制情緒
  2. （B）無法辨識本體感受
  3. （C）無法解析所看見的東西
  4. （D）近、遠期記憶受損

答案：（C）

詳解與考點

枕葉（occipital lobe）為視覺皮質所在，負責解析視覺訊息。枕葉受損造成視覺失認症（visual agnosia）——眼睛能看但大腦無法辨識所見物體，即選項 C。情緒控制屬額葉（A）；本體感受屬頂葉（B）；記憶主要為顳葉（D）。

第 6 題

有關急性胰臟炎的敘述，下列何者正確？
  1. （A）因膽道疾病導致膽汁與胰液逆流而引起
  2. （B）穆菲氏徵象（Murphy's sign）是常見表徵
  3. （C）康復期應採高脂飲食
  4. （D）血清中鈣濃度通常會升高

答案：（A）

詳解與考點

急性胰臟炎最常見病因為膽道疾病（膽石阻塞壺腹）與酒精，兩者均可導致胰液與膽汁逆流，活化胰酶自我消化，選項 A 正確。Murphy's sign 為膽囊炎徵象（B 錯）；康復期應採低脂飲食（C 錯）；血鈣因脂肪壞死皂化通常「降低」（D 錯）。

第 7 題

有關口服膽囊攝影檢查（oral cholecystography）的敘述，下列何者正確？
  1. （A）檢查前需採低脂飲食
  2. （B）急性膽囊炎為適應症之一
  3. （C）檢查前30分鐘服下含碘顯影劑
  4. （D）檢查後若排尿有燒灼感代表出現泌尿道感染

答案：（A）

詳解與考點

口服膽囊攝影（OCG）依賴膽囊功能吸收顯影劑並濃縮，需前一天採「低脂飲食」讓膽囊充分儲膽汁，以利顯影（A 正確）。急性膽囊炎為禁忌症（B 錯，因膽囊功能障礙無法吸收顯影劑）；含碘顯影劑需前一晚（10～12 小時前）服用，非前 30 分鐘（C 錯）；排尿燒灼感非典型反應，顯影劑主由腸道吸收膽汁路徑（D 錯）。

第 8 題

有關口腔癌的敘述，下列何者正確？
  1. （A）發生部位以上顎黏膜最多
  2. （B）以鱗狀上皮細胞癌最常見
  3. （C）咀嚼不順為常見早期徵象
  4. （D）口腔有無痛且不易癒合的潰瘍為常見晚期徵象

答案：（B）

詳解與考點

口腔癌以「舌頭」為最常見發生部位（而非上顎黏膜，A 錯）；組織學上以「鱗狀上皮細胞癌」最為常見（B 正確）；早期徵象為口腔不癒合潰瘍、白斑或紅斑，非咀嚼不順（C 錯，咀嚼不順已屬進展期）；無痛不癒合潰瘍為早期警訊而非晚期（D 敘述誤）。

第 9 題

肝性腦病變可能出現的臨床表徵，下列何者錯誤？
  1. （A）深腱反射消失
  2. （B）肌肉僵直、抽搐發作
  3. （C）巴賓斯基反射（Babinski's sign）陽性
  4. （D）非昏迷期會出現手掌撲翼樣震顫（asterixis）

答案：（A）

詳解與考點

肝性腦病變（hepatic encephalopathy）由氨等毒素蓄積造成神經毒性，臨床上深腱反射「亢進」（hyperreflexia）而非消失，並常見 Babinski 陽性、肌肉僵直抽搐及非昏迷期的撲翼樣震顫（asterixis）。選項 A「深腱反射消失」錯誤，為本題答案。

第 10 題

因闌尾炎破裂而懷疑有腹膜炎病人之臨床表徵，下列何者正確？①觸診腹部僵硬 ②強烈的反彈痛 ③腸蠕動音增加 ④腹部叩診為實音
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（A）

詳解與考點

答案為（A），即①與②正確。闌尾炎破裂引發腹膜炎時，腹膜受炎症刺激會出現腹肌僵硬（板狀腹，肌肉緊張防衛，①正確）與明顯反彈痛（rebound tenderness，②正確）。同時腸道因發炎而麻痺，腸蠕動音會「減弱或消失」（麻痺性腸阻塞），而非增加，故③錯誤。腹膜炎合併腸麻痺與腸脹氣時，腹部叩診多呈「鼓音（脹氣）」，「實音／濁音」不是腹膜炎的典型叩診表徵（實音多見於腹水或實質腫塊），故④錯誤。綜合①②正確，正解為（A）。

第 11 題

病人因左側股骨骨折而接受石膏制動之治療，下列敘述何者錯誤？
  1. （A）上石膏前，部位皮膚要用石膏襪套及棉墊包覆
  2. （B）石膏乾燥過程中，左側上石膏處不要覆蓋衣物
  3. （C）左側肢體如果出現6P，表示可能有腔隙症候群
  4. （D）皮膚如果出現瘀斑，表示可能有低血容性休克

答案：（D）

詳解與考點

石膏固定處皮膚出現「瘀斑」，通常提示石膏下方壓力過高造成皮膚受壓壞死，而非低血容性休克的表現；低血容性休克表現為皮膚蒼白冷濕、心跳加速、血壓下降等全身性症狀。選項 D 描述不當，為本題錯誤選項。石膏前包棉墊（A）、乾燥過程勿覆蓋（B）、6P 徵象提示腔隙症候群（C）均正確。

第 12 題

有關不同關節炎之比較，下列何者正確？
  1. （A）類風濕性關節炎是一種與老化有關的疾病
  2. （B）退化性關節炎是一種嘌呤代謝異常的疾病
  3. （C）痛風性關節炎好發於男性四肢遠端關節
  4. （D）退化性關節炎好發於55歲以上女性周邊小關節

答案：（C）

詳解與考點

痛風性關節炎由尿酸（嘌呤代謝異常）堆積引起，好發於男性，最典型為第一蹠趾關節（四肢遠端關節），選項 C 正確。類風濕性關節炎為自體免疫疾病，非老化相關（A 錯）；退化性關節炎（骨關節炎）為磨損退化（B 錯，嘌呤代謝異常為痛風）；退化性關節炎好發部位以膝、髖等承重關節為主（D 錯，周邊小關節為 RA 特徵）。

第 13 題

有關急性中耳炎的醫療處置，下列何者錯誤？
  1. （A）抗生素的使用要持續3～5天
  2. （B）疼痛發燒可使用解熱鎮痛劑
  3. （C）鼓膜腫脹時可行鼓膜切開術（myringotomy）
  4. （D）使用減輕鼻充血藥物，幫助耳咽管功能恢復

答案：（A）

詳解與考點

急性中耳炎抗生素療程標準為 7～10 天（5～7 天亦有指引支持，但 3～5 天過短、易復發），選項 A「3～5 天」為錯誤，是本題答案。解熱鎮痛劑緩解疼痛發燒（B 正確）；鼓膜切開術引流膿液（C 正確）；鼻充血劑幫助耳咽管暢通（D 正確）。

第 14 題

下列何種病毒與罹患鼻咽癌有關？
  1. （A）EB病毒（Epstein-Barr virus）
  2. （B）COVID-19病毒（Coronavirus Disease-2019）
  3. （C）A型流感病毒（Influenza A virus）
  4. （D）B型流感病毒（Influenza B virus）

答案：（A）

詳解與考點

鼻咽癌與 EB 病毒（Epstein-Barr virus）感染高度相關，在台灣及東南亞族群尤為明顯，為標準護理、腫瘤學教材共識（A 正確）。COVID-19（B）、流感病毒 A、B 型（C、D）均與鼻咽癌無確立因果關聯。

第 15 題

有關病人使用青光眼用藥Timolol的護理指導，下列何者錯誤？
  1. （A）是一種縮瞳劑
  2. （B）可減少眼球內房水量
  3. （C）氣喘病人禁止使用
  4. （D）給藥前需評估是否有心搏徐緩

答案：（A）

詳解與考點

Timolol 屬 β-腎上腺素阻斷劑（β-blocker），抑制睫狀體產生房水，降低眼內壓；它並非縮瞳劑（縮瞳劑如 Pilocarpine 為膽鹼素作用劑），選項 A「縮瞳劑」為錯誤，是本題答案。β-blocker 減少房水（B 正確）、氣喘禁用（C 正確，因支氣管收縮）、心搏徐緩需評估（D 正確）。

第 16 題

有關心包膜炎照護之敘述，下列何者不適宜？
  1. （A）鼓勵病人採平躺及深呼吸，以減緩胸痛
  2. （B）發燒時應臥床休息，以減少心肌耗氧量
  3. （C）退燒藥可使用阿斯匹靈（Aspirin）
  4. （D）提供高蛋白、高醣飲食

答案：（A）

詳解與考點

心包膜炎病人採「前傾坐姿」可減輕胸痛，因此姿勢可使心包膜兩層分開；平躺會加重疼痛。選項 A「鼓勵平躺及深呼吸以減緩胸痛」不適宜，為本題答案。臥床減少耗氧（B 正確）；Aspirin 抗炎適用於非特定原因心包炎（C 正確）；高蛋白高醣飲食補充體力（D 正確）。

第 17 題

有關血栓性靜脈炎之評估與照護原則，下列敘述何者錯誤？
  1. （A）病人足背屈曲時，腓腸肌會產生疼痛
  2. （B）口服Coumadin可預防及治療靜脈血栓
  3. （C）應定期按摩病人患肢，以促進靜脈循環
  4. （D）協助病人抬高患肢，可減輕炎症及疼痛

答案：（C）

詳解與考點

深部靜脈血栓（DVT）／血栓性靜脈炎急性期禁止按摩患肢，因為按摩可能使血栓脫落形成肺栓塞。選項 C「定期按摩以促進靜脈循環」為錯誤護理措施，是本題答案。Homan's sign（A 正確）；Coumadin 口服抗凝（B 正確）；抬高患肢減輕炎症水腫（D 正確）。

第 18 題

有關慢性靜脈功能不全引起的鬱滯性潰瘍（stasis ulcer）的肢體評估，下列敘述何者正確？①潰 瘍部位多發生於足踝內側 ②皮膚出現色素沉著 ③肢體呈現凹陷性水腫 ④趾甲變厚 ⑤腳趾潰 瘍
  1. （A）①②③
  2. （B）①④⑤
  3. （C）②③⑤
  4. （D）③④⑤

答案：（A）

詳解與考點

鬱滯性潰瘍（靜脈性潰瘍）特徵：①潰瘍好發足踝內側（大隱靜脈回流區），②皮膚色素沉著（含鐵血黃素沉積），③凹陷性水腫（靜脈壓升高），三者均為靜脈功能不全典型表現，答案 A（①②③）。④趾甲變厚及⑤腳趾潰瘍為動脈阻塞性（周邊動脈疾病）特徵，不屬靜脈性潰瘍。

第 19 題

有關心因性休克護理重點之敘述，下列何者錯誤？
  1. （A）依醫囑使用促進心臟幫浦之藥物
  2. （B）使用溫熱療法（如電毯）提高全身周邊循環血量
  3. （C）為提高心輸出量，必要時協助放置主動脈內氣球幫浦（IABP）
  4. （D）給予氧氣使用

答案：（B）

詳解與考點

心因性休克（cardiogenic shock）由心臟幫浦功能衰竭引起，表現為低心輸出量、周邊灌流不足、四肢冰冷。使用「溫熱療法」擴張周邊血管，會進一步降低回心血量與心臟前負荷，加重休克。選項 B 為不適當護理措施，是本題答案。強心藥（A）、IABP（C）、氧氣（D）均為標準處置。

第 20 題

下列何者為右心衰竭的臨床表徵？
  1. （A）呼吸困難
  2. （B）粉紅色泡沫痰
  3. （C）下肢水腫
  4. （D）少尿或無尿

答案：（C）

詳解與考點

右心衰竭因右心輸出不足，靜脈回流受阻，造成體循環靜脈壓升高，表現為下肢凹陷性水腫、頸靜脈怒張、肝腫大、腹水，選項 C 正確。呼吸困難（A）、粉紅色泡沫痰（B）為左心衰竭（肺水腫）表現；少尿或無尿（D）見於嚴重低心輸出量或腎前性因素，非右心衰竭最具特異性表現。

第 21 題

惡性腫瘤細胞與正常細胞的不同特性之比較，下列何者正確？①細胞缺乏接觸抑制 ②細胞可快速 增殖 ③細胞未分化狀態 ④當需要更多細胞時會發生增殖 ⑤黏著性低而活動力高
  1. （A）①②③
  2. （B）①③④
  3. （C）①③⑤
  4. （D）②④⑤

答案：（C）

詳解與考點

答案為（C），即①③⑤正確。惡性腫瘤細胞相較正常細胞的特性包括：①缺乏接觸抑制（失去 contact inhibition，可堆疊增生）正確；③呈未分化（anaplasia）或分化不良狀態正確；⑤細胞間黏著性降低、活動力增高，易侵犯與轉移，正確。至於②「可快速增殖」與④「當需要更多細胞時才增殖」，惡性腫瘤的核心特性是「失控、不受正常生理調控的持續增殖」，而不是單純『快速』，更不是『依身體需求』才增殖（④描述的是正常細胞的調控性增生），故②、④皆不選。綜合①③⑤，正解為（C）。

第 22 題

王老太太背部骨骼疼痛就醫，醫生懷疑是多發性骨髓瘤，請依序回答下列3題。 下列何者為確定診斷的主要標準？

  2. （B）血清IgG 為2 gm/dL
  3. （C）X光檢查發現有骨頭侵蝕現象
  4. （D）IgA＜0.1 gm/dL

答案：（A）

詳解與考點

答案為（A）。多發性骨髓瘤的診斷以骨髓中異常漿細胞（plasma cell）增生為核心依據；傳統「主要標準（major criteria）」之一即為骨髓漿細胞比例明顯增高（達 30% 以上），選項（A）「骨髓內漿細胞比例 40%」符合此主要標準，故為正解。其餘為次要表現或未達門檻：（C）X 光顯示溶骨性病灶（骨頭侵蝕）屬支持診斷的次要標準，非單獨之主要標準；（B）血清 IgG 2 gm/dL（即 2 g/dL）僅輕度，未達單株免疫球蛋白大量增高（如 IgG ≥ 3.5 g/dL）的主要標準門檻；（D）IgA < 0.1 gm/dL 反映正常免疫球蛋白受抑制，屬伴隨現象而非確診主要標準。故正解為（A）。

第 23 題

  2. （B）高血鈣
  3. （C）高血鉀
  4. （D）高尿酸

答案：（B）

便秘、意識不清合併心律不整，高度提示高血鈣（hypercalcemia）。高血鈣的典型三聯症為「bones、stones、groans、psychic moans」，包括便秘（腸蠕動受抑）、意識混亂及心律不整（QT 縮短）。高血鉀雖也引起心律不整，但不典型呈現便秘與意識不清組合。

第 24 題

王老太太意識恢復後，針對其目前的問題，下列護理措施何者正確？
  1. （A）鼓勵多喝牛奶
  2. （B）限制水份補充
  3. （C）給與Allopurinol藥物治療
  4. （D）給與Zometa藥物治療

答案：（D）

詳解與考點

答案為（D）。多發性骨髓瘤常合併「高血鈣」，處置原則為積極補充水分（生理食鹽水水化以促進鈣排出）、使用雙磷酸鹽類抑制蝕骨細胞活性。Zometa（zoledronic acid）即雙磷酸鹽，可降低血鈣並保護骨骼、減少骨骼相關事件，故（D）為正解。其餘錯誤：（A）牛奶含高鈣，高血鈣病人應避免，不可鼓勵多喝；（B）「限制水分」會加重脫水、使血鈣更高並增加腎損傷風險，高血鈣照護恰恰需要『補充足量水分』，故為錯誤處置；（C）Allopurinol 是抑制尿酸生成藥物，用於高尿酸血症／預防腫瘤溶解症候群，並非針對高血鈣的首要處置。故正解為（D）。

第 25 題

答案：（D）

化療藥物外滲（extravasation）的正確處置：停止輸注但保留針頭（先用注射器回抽殘餘藥物），再視藥物性質注射解毒劑（antidote）於滲漏部位四周，故選 D。選項 A 立即拔針會失去回抽機會；選項 B 抬高（非放低）肢體以減少腫脹；選項 C 加壓包紮可能使藥物擴散。

第 26 題

第 33 題

第 36 題

  1. （A）肺泡與血管間的隔膜增厚，使得氧氣無法擴散進入血流中
  2. （B）細小氣管內有大量濃稠的痰液，阻礙肺泡的通氣
  3. （C）大部分的肺中有充分的血流灌注，但肺泡中未能有足夠的氣體可進行交換
  4. （D）肺泡中有足夠的通氣，但肺中有部分區域血流灌注受阻下降

答案：（D）

肺栓塞導致肺動脈阻塞，受影響肺區有通氣（V）但無血流灌注（Q），形成死腔效應（dead space），即 V/Q 比值升高。D 正確描述此機轉。選項 A 描述的是瀰漫性障礙（diffusion barrier）；選項 B 為阻塞性分流；選項 C（有血流無通氣）為肺內分流（shunt），與肺栓塞相反。

答案：（B）

詳解與考點

腎動脈攝影術（renal angiography）使用含碘顯影劑，具腎毒性，檢查後須多喝水以利顯影劑排出、保護腎功能，B 正確。選項 A 尿流速檢查僅需充盈膀胱，無須禁食；選項 C 靜脈腎盂攝影為仰臥姿，非俯臥；選項 D 腎臟切片採俯臥姿（非截石臥）。

第 40 題

預防腎功能不全病人血鉀過高之飲食護理指導，下列何者正確？
  1. （A）避免熱量攝取不足或長期饑餓
  2. （B）建議多攝取雞精用來補充營養
  3. （C）需要多使用低鈉鹽或薄鹽醬油
  4. （D）建議多吃水果乾減少水分攝取

答案：（A）

詳解與考點

腎功能不全病人易蓄積高血鉀，熱量攝取不足或長期饑餓會導致蛋白質分解（異化代謝），釋出細胞內鉀離子，進一步升高血鉀，故應避免熱量不足，A 正確。選項 B 雞精富含鉀及嘌呤，不適合；選項 C 低鈉鹽含高鉀，應避免；選項 D 水果乾含鉀量高，不建議。

第 41 題

趙小姐，45歲，無特殊疾病，近來健檢時發現有輸尿管結石約1.8公分，醫師建議行輸尿管鏡碎石 術，下列敘述何者錯誤？
  1. （A）沒有傷口但術後要放置導尿管 24～72小時
  2. （B）此為門診手術，但必須接受全身麻醉
  3. （C）若無特殊限制，術後鼓勵多喝水以利碎石排出
  4. （D）術後有嚴重發燒或是嚴重血尿的病人應速回診

答案：（B）

詳解與考點

輸尿管鏡碎石術（URS）一般可在脊椎麻醉或全身麻醉下進行，但並非「必須」全身麻醉，脊椎麻醉亦為常用選擇，故 B「必須接受全身麻醉」為錯誤敘述。術後放置 double-J stent 或導尿管、多喝水、注意發燒及嚴重血尿均為正確護理措施。

第 42 題

有關副甲狀腺功能低下之敘述，下列何者正確？
  1. （A）因高血鈣出現沃斯特克氏（Chvostek's）徵象，導致肌肉痙攣
  2. （B）因低血磷導致手指顫抖
  3. （C）可能會有急性抽搐，導致咬傷舌頭及呼吸道阻塞
  4. （D）因身體出現酸中毒，導致手足抽搐症狀惡化

答案：（C）

詳解與考點

答案為（C）。副甲狀腺功能低下因副甲狀腺素（PTH）不足，造成「低血鈣、高血磷」，低血鈣會提高神經肌肉興奮性，引發手足搐搦、Chvostek's 與 Trousseau's 徵象，嚴重時可發生急性抽搐、喉頭痙攣，導致咬傷舌頭與呼吸道阻塞，故（C）正確。其餘錯誤：（A）Chvostek's 徵象是『低血鈣』而非高血鈣所致，且本症為低血鈣，敘述前提錯誤；（B）本症為『高血磷』而非低血磷，且手指顫抖之機轉描述不當；（D）酸鹼方面，「鹼中毒」會使游離鈣（離子化鈣）下降，反而誘發或加重搐搦，「酸中毒」則使游離鈣上升、較不會惡化症狀，故「因酸中毒導致手足抽搐惡化」的敘述與生理機轉相反，為錯誤。綜上，正解為（C）。

第 43 題

有關嗜鉻細胞瘤切除手術後之護理措施，下列何者錯誤？
  1. （A）注意有無腎上腺功能不全的徵象，必要時由靜脈輸注皮質醇
  2. （B）監測每小時尿量，維持尿量在20～25 c.c./小時
  3. （C）觀察術後出血情況與腸蠕動狀態
  4. （D）依醫囑給與靜脈輸液，以維持體液容積

答案：（B）

詳解與考點

嗜鉻細胞瘤切除後，正常尿量應維持 ≥30 mL/hr（成人），選項 B 述及維持尿量 20～25 mL/hr 偏低，低於正常腎臟灌流標準，屬錯誤護理目標，故 B 為錯誤選項。其餘選項（皮質醇補充、觀察出血腸蠕動、補液）均為正確術後護理措施。

第 44 題

有關腦下垂體前葉功能低下之敘述，下列何者錯誤？
  1. （A）席漢氏症候群（Sheehan's syndrome）發生於腦下垂體切除的病人
  2. （B）以生長素（growth hormone）缺乏最常見
  3. （C）病人可能會有軟弱無力、血糖偏低等臨床表徵
  4. （D）病人可能會有黏液水腫症狀

答案：（A）

詳解與考點

席漢氏症候群（Sheehan's syndrome）是因產後大出血導致腦下垂體缺血壞死，發生於產後出血的產婦，並非腦下垂體切除的病人，故 A 為錯誤敘述。其餘選項：生長素缺乏最常見、軟弱無力與低血糖、黏液水腫（甲狀腺功能低下）均為正確描述。

第 45 題

劉女士因血糖控制不佳入院，下列病人平日之飲食攝取比例，何者不適宜？①碳水化合物類的食物 約占每日總熱量的50～60％ ②脂肪類的食物約占每日總熱量的5～10％ ③飽和脂肪類的食物小 於7％ ④蛋白質類的食物約占每日總熱量的30～35％
  1. （A）①②
  2. （B）①③
  3. （C）②④
  4. （D）③④

答案：（C）

詳解與考點

糖尿病飲食建議：碳水化合物占 50～60%（正確）；脂肪占 25～35%（非 5～10%，②錯誤）；飽和脂肪 <7%（正確）；蛋白質占 15～20%（非 30～35%，④錯誤）。②與④均不適宜，故選 C「②④」。

第 46 題

格雷氏病（Grave's disease）會出現下列何種臨床表徵？①神經質 ②眼球突出 ③怕冷 ④手 指顫抖 ⑤脛前凹陷性水腫
  1. （A）①②④
  2. （B）①③⑤
  3. （C）②③⑤
  4. （D）③④⑤

答案：（A）

詳解與考點

格雷氏病（Graves' disease）為甲狀腺功能亢進，典型表現：①神經質（交感神經亢奮）、②眼球突出（Graves'眼病）、④手指顫抖（甲亢神經肌肉症狀）。③怕冷為甲狀腺功能低下的表徵；⑤脛前「非凹陷性」黏液水腫雖見於 Graves'，但與怕冷同列的⑤選項組合在此題不構成正確答案，故選①②④即 A。

第 47 題

有關過敏性休克之敘述，下列何者正確？①接觸的過敏原可能來自藥物、食物、昆蟲叮咬等 ②發 生嚴重支氣管擴張及呼吸困難 ③脈搏次數增快、血壓可能正常或降低 ④通常可立即注射 epinephrine改善情況
  1. （A）①②③
  2. （B）①②④
  3. （C）①③④
  4. （D）②③④

答案：（C）

詳解與考點

過敏性休克（anaphylactic shock）特徵：①過敏原來源多元（正確）；②正確表現為嚴重支氣管「收縮」（bronchospasm）而非擴張，②錯誤；③脈搏加快、血壓下降（正確）；④立即注射 epinephrine 為首選急救（正確）。去除②，正確組合為①③④，即選 C。

第 48 題

有關有機磷中毒臨床處置之敘述，下列何者錯誤？
  1. （A）給予Apomorphine是因此藥為有機磷中毒的拮抗劑
  2. （B）進行胃灌洗、應維持呼吸道通暢必要時給與插管
  3. （C）其可從皮膚吸收，照護者須戴口罩、手套及穿隔離衣
  4. （D）對於沾有嘔吐物的衣物應除去並協助沐浴

答案：（A）

詳解與考點

有機磷中毒的特異性拮抗劑為 Atropine（阻斷毒蕈鹼受體效應）及 Pralidoxime（2-PAM，重活化膽鹼酯酶）。Apomorphine 為多巴胺受體促進劑，用於催吐，並非有機磷拮抗劑，故 A 為錯誤敘述。

第 49 題

有關病人誤食強鹼溶液之處置，下列何者錯誤？
  1. （A）立即給與胃灌洗
  2. （B）不可給與中和劑
  3. （C）疑似胃潰瘍應先採取禁食
  4. （D）注意口腔與食道之灼傷

答案：（A）

詳解與考點

誤食強鹼溶液（腐蝕性物質）絕對禁忌為胃灌洗，因為強鹼已灼傷食道與胃壁，插管灌洗可能造成穿孔；此外，催吐亦為禁忌，故 A 立即給與胃灌洗為錯誤處置。應立即用清水漱口、不給中和劑（反應產熱可加重傷害）、維持氣道、評估灼傷程度。

第 50 題

有關H1N1流感之敘述，下列何者錯誤？
  1. （A）病原菌屬於H型流感病毒
  2. （B）大部分病人症狀輕微，一週內可痊癒
  3. （C）主要經由飛沫與接觸傳染
  4. （D）治療藥物為Tamiflu及Relenza

答案：（A）

詳解與考點

H1N1 流感（2009 豬流感）屬 A 型流感病毒（Influenza A）中的 H1N1 亞型，並非「H 型」流感病毒，此分類方式在病毒學中不存在，故 A 為錯誤敘述。B（症狀輕微一週可痊癒）、C（飛沫與接觸傳染）、D（Tamiflu/Relenza 為治療藥物）均正確。
