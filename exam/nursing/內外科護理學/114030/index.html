第 1 題

有關巴金森氏症病人服用抗膽鹼激性製劑trihexyphenudyl（Artane®）之敘述，下列何者正確？
  1. （A）長期服用會出現姿位型低血壓
  2. （B）副作用少見，偶有情緒改變和頭痛情形
  3. （C）常與抗病毒製劑合併使用，可有效控制失眠和頭痛
  4. （D）需要監測眼壓變化，預防青光眼

答案：（D）

詳解與考點

trihexyphenidyl（Artane®）為抗膽鹼劑（anticholinergic），用於巴金森氏症。因瞳孔散大、睫狀肌麻痺可升高眼內壓，故有青光眼（尤其閉角型）的禁忌，需監測眼壓，D 正確。姿位性低血壓是左旋多巴或 dopamine agonist 的副作用（A 錯）；抗膽鹼副作用包括口乾、便秘、尿滯留、視力模糊，並非罕見（B 錯）；常與左旋多巴合用，不是抗病毒製劑（C 錯）。

第 2 題

多發性硬化症病人之日常活動護理指導，下列敘述何者正確？
  1. （A）運動前給予溫熱敷會增加肌肉強直和關節攣縮
  2. （B）避免在運動後洗熱水澡以免疾病惡化
  3. （C）可以增加多次且密集的運動，防止肌肉無力和強直
  4. （D）若疾病加重導致長期臥床，應避免執行全關節運動

答案：（B）

詳解與考點

多發性硬化症（MS）對熱敏感，高溫會加重神經傳導失調，因此運動後應避免洗熱水澡，B 正確。運動前溫熱敷反而可能加重症狀（A 錯）；應避免過度密集運動以防疲勞惡化（C 錯）；長期臥床者仍需執行全關節活動（ROM）預防攣縮（D 錯）。

第 3 題

有關頭部外傷相關合併症的敘述，下列何者正確？
  1. （A）封閉性比開放性頭部外傷更易產生癲癇後遺症
  2. （B）創傷後症候群症狀可持續數個月到數年
  3. （C）腦脊髓液瘻管是因腦脊髓液循環路徑阻塞或吸收有問題
  4. （D）當頭部外傷損及視丘時，會引起抗利尿激素（ADH）分泌失調

答案：（B）

詳解與考點

頭部外傷的創傷後症候群（post-traumatic syndrome）症狀包括頭痛、記憶力下降、情緒改變等，可持續數個月至數年，B 正確。開放性頭部外傷較封閉性更易發生癲癇（A 錯）；腦脊髓液瘻管是因頭骨骨折使硬腦膜撕裂，非循環阻塞問題（C 錯）；ADH 分泌失調主要與下視丘（hypothalamus）或腦下垂體損傷相關，而非視丘（thalamus）（D 錯）。

第 4 題

有關癲癇（epilepsy）發作處置，下列敘述何者錯誤？
  1. （A）電腦斷層檢查可確定異常放電位置
  2. （B）發作時，可將頭偏向一側以利唾液流出
  3. （C）發作時，若病人意識不清，不須試圖喚醒病人
  4. （D）驟然停藥為重積性癲癇常見的原因

答案：（A）

詳解與考點

電腦斷層（CT）可顯示結構性病灶（腫瘤、出血、梗塞），但確認「異常放電位置」需要腦電圖（EEG），故 A 錯誤為本題答案。發作時頭偏向一側可防止唾液嗆入（B 正確）；意識不清時不必喚醒病人（C 正確）；驟然停藥是重積性癲癇（status epilepticus）常見誘因（D 正確）。

第 5 題

有關左側大腦損傷可能引起的功能缺失症狀，下列敘述何者正確？①計算能力降低 ②空間缺損 ③半側忽略 ④語言障礙
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

左側大腦半球為語言優勢側（多數人），損傷會引起①計算能力降低（頂葉語言區相關）及④語言障礙（Broca 區或 Wernicke 區）。空間缺損與半側忽略（neglect）則多見於右側大腦損傷。故①④正確，答案選 B。

第 6 題

有關胃食道逆流症的護理指導，下列敘述何者錯誤？
  1. （A）進食後應立即平躺
  2. （B）避免在睡前2～3小時進食
  3. （C）少量多餐細嚼慢嚥
  4. （D）肥胖的病人應減重

答案：（A）

詳解與考點

胃食道逆流症（GERD）護理指導中，進食後應保持直立至少 2–3 小時，避免立即平躺，否則食物與胃酸易逆流至食道，A 描述「進食後立即平躺」為錯誤指導。睡前 2–3 小時不進食、少量多餐細嚼慢嚥及肥胖者減重，均可降低胃內壓力與逆流頻率，為正確措施。

第 7 題

有關大腸癌的高危險因子，下列敘述何者正確？
  1. （A）常攝取蔬菜及高纖維質
  2. （B）幽門螺旋桿菌感染
  3. （C）有家族型腺瘤性息肉症病史
  4. （D）胃酸分泌過多症

答案：（C）

詳解與考點

大腸癌高危險因子包括：高脂低纖飲食、家族型腺瘤性息肉症（FAP）、潰瘍性結腸炎、克隆氏病等。C 選項「家族型腺瘤性息肉症病史」確為最強高危因子之一。蔬菜高纖飲食是保護因子（A 錯）；幽門螺旋桿菌與胃癌相關（B 錯）；胃酸過多與消化性潰瘍相關（D 錯）。

第 8 題

肝性腦病變的病人給與Lactulose的目的，下列何者正確？
  1. （A）酸化糞便以減少氨在腸道吸收
  2. （B）抑制腸內細菌以減少氨的分解
  3. （C）預防發生肝腎症候群
  4. （D）減輕腹水的產生

答案：（A）

詳解與考點

Lactulose 為合成雙醣，口服後在腸道被菌分解為有機酸，降低腸道 pH 值（酸化），使氨（NH3）轉為無法被吸收的銨根（NH4+），同時加速腸道蠕動排出含氨糞便，減少氨的腸道吸收，A 正確。並非抑制細菌（B 錯）；不直接預防肝腎症候群或腹水（C、D 錯）。

第 9 題

有關胰臟炎急性發作及其治療的敘述，下列何者錯誤？
  1. （A）上腹部中央疼痛或輻射到背部，疼痛為突發、持續且劇烈
  2. （B）血清澱粉酶（amylase）升高、脂肪酶（lipase）上升、血鈣下降
  3. （C）放置鼻胃管的目的為抽出胰澱粉酶，以避免發炎加劇
  4. （D）當病情穩定可開始進食時，應採低脂肪、低蛋白、高醣飲食

答案：（C）

詳解與考點

鼻胃管在急性胰臟炎的目的是胃減壓（gastric decompression），緩解腹脹與嘔吐，並非抽出胰澱粉酶（amylase 在胰管中，鼻胃管無法抽出），故 C 錯誤。胰臟炎疼痛向背部放射、amylase/lipase 升高、血鈣下降均為典型表徵（A、B 正確）；病情穩定後飲食應低脂、低蛋白（D 所述正確）。

第 10 題

有關食道憩室的敘述，下列何者正確？
  1. （A）常見胸口灼熱感症狀
  2. （B）可做鋇劑食道攝影確定位置
  3. （C）餐後平躺可減緩不適
  4. （D）一旦發生須儘速以手術治療

答案：（B）

詳解與考點

食道憩室（esophageal diverticulum）診斷最常用「鋇劑食道攝影（barium swallow）」，可確定憩室位置與大小，B 正確。主要症狀為吞嚥困難、食物逆流（未消化食物），胸口灼熱感為 GERD 特徵而非典型症狀（A 錯）；餐後平躺會促進逆流加重（C 錯）；輕症可採保守治療，非一律立即手術（D 錯）。

第 11 題

有關痛風性關節炎護理指導之敘述，下列何者正確？
  1. （A）避免服用Aspirin，以預防血中尿酸升高
  2. （B）採取高脂飲食，以促進尿酸鹽排出
  3. （C）多喝小紅莓汁，以預防尿酸結石產生
  4. （D）多攝取肉汁、海鮮，以促進嘌呤代謝

答案：（A）

詳解與考點

痛風護理中，Aspirin（低劑量）會抑制腎臟排泄尿酸、升高血中尿酸，應避免使用，A 正確。應採低脂飲食（高脂影響尿酸排除，B 錯）；飲用大量水（每天 2000–3000 mL）以稀釋尿酸、預防結石，小紅莓汁可酸化尿液反而促進尿酸沉積（C 需查證，但不積極建議）；肉汁、海鮮含高普林，應避免（D 錯）。

第 12 題

有關肌肉骨骼系統身體檢查評估結果之敘述，下列何者正確？
  1. （A）湯瑪斯試驗（Thomas test）陽性反應表示病人對側髖關節攣縮
  2. （B）浮動試驗（Ballottement test）陽性表示病人膝半月板有損傷
  3. （C）抽拉試驗（Drawer test）若能將小腿向後牽引6mm表示副韌帶鬆弛
  4. （D）廷內爾氏徵象（Tinel's sign）陽性反應表示後十字韌帶鬆弛

答案：（A）

詳解與考點

答案為（A）。湯瑪斯試驗（Thomas test）用於評估髖屈曲攣縮：病人平躺，將一側髖、膝盡量屈曲貼近胸前以拉平腰椎前凸、固定骨盆，若對側下肢被動抬離檢查檯、無法平貼，即為陽性，表示該（對側）髖關節有屈曲攣縮，故 A 敘述正確。（B）浮動髕骨試驗（ballottement / patellar tap）陽性代表膝關節有積液，而非半月板損傷（半月板損傷常用 McMurray test），故錯。（C）抽拉試驗（drawer test）評估的是十字韌帶（前抽拉測前十字、後抽拉測後十字）的穩定度，並非「副韌帶（側副韌帶）鬆弛」，故錯。（D）廷內爾氏徵象（Tinel's sign）是輕敲神經（如正中神經）誘發麻刺感，用於評估周邊神經壓迫（如腕隧道症候群），與後十字韌帶無關，故錯。本題 A 可直接判定正確。

第 13 題

有關骨質疏鬆症處置之敘述，下列何者正確？
  1. （A）每日飯前服用碳酸鈣（calcium carbonate），以增加鈣吸收
  2. （B）鼓勵日曬及攝取維生素D，以促進鈣吸收
  3. （C）每日飯後服用雙磷酸鹽類（bisphosphonates），以減少骨流失
  4. （D）每天使用副甲狀腺素（teriparatide）鼻噴劑，以增加骨質量

答案：（B）

詳解與考點

骨質疏鬆症治療中，日曬可促進皮膚合成維生素 D3，維生素 D 再於肝腎活化為骨化三醇，進而促進腸道鈣吸收，是最具生理基礎的非藥物措施，故 B 正確。碳酸鈣（calcium carbonate）應飯後服用，因胃酸有助溶解；雙磷酸鹽類（bisphosphonates）需飯前空腹服用並維持直立姿勢至少 30 分鐘；teriparatide 為注射劑，不是鼻噴劑。

第 14 題

下列何者為充滿血管可以供應眼球及視網膜血液及營養的構造？
  1. （A）鞏膜
  2. （B）角膜
  3. （C）脈絡膜
  4. （D）睫狀體

答案：（C）

詳解與考點

脈絡膜（choroid）位於鞏膜與視網膜之間，富含血管，負責供應視網膜外層血液與養分，是眼球最主要的血管層。鞏膜為纖維保護層，角膜為透明折光結構，睫狀體負責懸韌帶調節水晶體曲率及分泌房水，三者均非主要供血結構。

第 15 題

有關扁桃腺炎（tonsilitis）病人接受扁桃腺切除術之敘述，下列何者錯誤？
  1. （A）急性發炎期時應儘快安排手術
  2. （B）術前可用溫食鹽水漱口，減輕咽喉不適
  3. （C）疑似扁桃腺腫瘤是手術適應症
  4. （D）術後有持續吞嚥動作時，可能為傷口出血的現象

答案：（A）

詳解與考點

扁桃腺炎急性發炎期禁止立即手術，因急性期組織充血水腫、感染活躍，手術風險極高（出血、感染擴散），須待急性期緩解後再評估手術。術前溫鹽水漱口可緩解咽喉不適（B 正確）；疑似腫瘤是手術適應症（C 正確）；術後持續吞嚥動作常為傷口滲血徵象（D 正確）。故 A「急性發炎期儘快手術」為錯誤敘述。

第 16 題

進行心臟復健時如出現活動耐力不足時應停止，下列何者不是其判斷依據？
  1. （A）心律不整或心跳上升或下降超過20次／分鐘以上
  2. （B）血壓上升或下降超過20 mmHg以上
  3. （C）體溫大於37℃
  4. （D）出現胸悶、胸痛、眩暈、盜汗、虛弱、疲倦

答案：（C）

詳解與考點

心臟復健停止活動的標準指標包括：心律不整或心跳變化超過 20 次/分鐘、血壓變化超過 20 mmHg、以及胸悶／胸痛／眩暈／盜汗／疲倦等症狀（A、B、D 均為停止依據）。體溫大於 37℃ 僅屬低度發燒，並非心臟復健的停止判斷標準；正式停止門檻為發燒（通常 ≥38℃）。故 C 不是判斷依據。

第 17 題

有關裝置永久性心臟節律器病人居家護理指導之敘述，下列何者錯誤？
  1. （A）每天需測量橈動脈1分鐘
  2. （B）住家頂樓避免裝設手機基地台
  3. （C）可使用微波爐，但應保持安全距離
  4. （D）持續打嗝時，可做伐式操作法（Valsalva）緩解

答案：（D）

詳解與考點

Valsalva 操作法（閉氣用力）會刺激迷走神經、減慢心跳，對已裝置永久性節律器的病人，若節律器在固定頻率模式（fixed-rate）下，Valsalva 可能導致競爭性心律失常，且「持續打嗝」並非 Valsalva 的適應症。此法用於終止陣發性上心室頻脈，並不適用打嗝，故 D 為錯誤指導。A（每天測脈搏）、B（避免基地台電磁干擾）、C（微波爐保持安全距離）均為正確護理指導。

第 18 題

有關心衰竭之敘述，下列何者正確？
  1. （A）右心衰竭會出現心搏過速、心室肥大、第三心音
  2. （B）右心衰竭常出現乾咳或帶有泡沫及血絲痰
  3. （C）左心衰竭早期徵象是下肢水腫、頸靜脈怒張、腹水
  4. （D）左心衰竭常見症狀為呼吸困難、端坐呼吸

答案：（D）

詳解與考點

左心衰竭因左心輸出減少、肺靜脈回流受阻，導致肺淤血，典型症狀為呼吸困難（dyspnea）及端坐呼吸（orthopnea），此為最常見且最具代表性的症狀組合，故 D 正確。選項 A（心搏過速、心室肥大、第三心音）描述的是左心衰竭的特徵而非右心；選項 B（乾咳或血絲痰）屬左心衰竭；選項 C（下肢水腫、頸靜脈怒張、腹水）為右心衰竭，並非左心衰竭早期徵象。

第 19 題

有關急性心肌梗塞引起的心因性休克給予的藥物處置，下列敘述何者錯誤？
  1. （A）Dobutamine滴注可以增加心肌收縮力及心輸出量
  2. （B）利尿劑主要目的為降低心臟前負荷
  3. （C）嗎啡主要是緩解疼痛，對心臟前、後負荷沒有影響
  4. （D）血管擴張劑nitroglycerin（NTG）滴注可以擴張周邊血管而減輕心臟負荷

答案：（C）

詳解與考點

嗎啡（morphine）在心因性休克及急性心肌梗塞的使用中，不只緩解疼痛，還能擴張靜脈（降低前負荷）及輕度擴張動脈（降低後負荷），具有降低心臟前、後負荷的效果。選項 C 稱「對前後負荷沒有影響」明顯錯誤。Dobutamine 增加心肌收縮力（A 正確）、利尿劑降低前負荷（B 正確）、NTG 擴張血管減輕心臟負荷（D 正確）。

第 20 題

有關靜脈剝除結紮手術（stripping and ligation）術後照護之敘述，下列何者錯誤？
  1. （A）術後臥床期間避免於床上進行全範圍關節運動
  2. （B）抬高床尾15度，膝部不彎曲
  3. （C）術後下床時均應穿彈性襪
  4. （D）應監測末梢血循變化及是否有感覺異常

答案：（A）

詳解與考點

靜脈剝除結紮術後，臥床期間應積極進行床上腳部踝關節運動（如踝幫浦運動），以促進靜脈回流、預防深層靜脈栓塞（DVT），故「避免進行全範圍關節運動」為錯誤敘述（A 為錯）。其餘正確措施：抬高床尾促靜脈回流（B）、下床穿彈性襪（C）、監測末梢血循（D）均為術後標準照護。

第 21 題

正在接受體外放射線治療的癌症病人表示：「臉和頸部的皮膚發紅刺痛、脫屑，甚至有些部位會濕 濕的，很不舒服」，下列處置何者正確？
  1. （A）清水洗淨後塗擦凡士林保濕
  2. （B）可局部溫濕敷以緩解不適症狀
  3. （C）0.9% N/S沖洗後以親水敷料（DuoDerm）覆蓋
  4. （D）刮鬍子時用刮鬍膏潤滑刮鬍刀以免刮傷

答案：（C）

詳解與考點

放射線治療引起的皮膚反應分為乾性脫屑及濕性脫屑（moist desquamation）。濕性脫屑屬於急性放射皮膚炎的進階期，應以 0.9% N/S（生理食鹽水）溫和清洗並以親水敷料如 DuoDerm 覆蓋，維持濕性癒合環境（C 正確）。凡士林可能阻塞毛孔加重反應（A 錯）；溫濕敷會刺激已損傷皮膚（B 錯）；放療部位禁止刮鬍及使用刮鬍膏（D 錯）。

第 22 題

顆粒性白血球低下的癌症病人之食物選擇，下列何者最適切？
  1. （A）溏心蛋：補充單白質
  2. （B）泡菜：補充纖維質防便秘
  3. （C）柑橘：補充維生素C
  4. （D）優格：補充鈣質、維生素

答案：（C）

詳解與考點

顆粒性白血球低下（granulocytopenia）病人免疫功能嚴重受損，飲食需避免生食或可能含活菌的食物。溏心蛋（未全熟）有沙門氏菌風險（A 錯）、泡菜含乳酸菌等活菌（B 錯）、優格含活菌益生菌（D 錯）。柑橘（新鮮水果，去皮食用）可補充維生素 C，且相對安全，為最適切選擇（C 正確）。

第 23 題

中樞神經系統癌症病人，若選用難以通過血腦障壁之化學治療時，下列何者為最適切之給藥途徑？ ①Port-A ②Ommaya reservoir ③Hickman catheter ④intrathecal injection
  1. （A）①③
  2. （B）①④
  3. （C）②③
  4. （D）②④

答案：（D）

詳解與考點

難以通過血腦障壁（blood-brain barrier）的化療藥物，需透過直接進入腦脊液的途徑給藥。Ommaya reservoir（②）是植入顱內的儲液囊，可直達腦室；intrathecal injection（④）即脊髓腔內注射，可直接進入蛛網膜下腔。兩者均可繞過血腦障壁，故答案選②④，即選項 D。Port-A（①）與 Hickman catheter（③）為全身性靜脈給藥，無法克服血腦障壁問題。

第 24 題

為一位乳癌骨轉移合併脊髓壓迫的病人進行身體評估時，下列症狀或徵象何者最不常出現？
  1. （A）背部疼痛指數7分（滿分10分）
  2. （B）布魯辛斯基氏徵象（Brudzinski's sign）陽性
  3. （C）大小便失禁情形
  4. （D）巴賓斯基氏徵象（Babinski's sign）陽性

答案：（B）

詳解與考點

布魯辛斯基氏徵象（Brudzinski's sign）是腦膜刺激的評估指標，陽性表現為被動屈頸時雙膝自動屈曲，常見於腦膜炎。脊髓壓迫的症狀為背痛、運動/感覺功能缺損、大小便失禁及 Babinski sign 陽性（反映上運動神經元損傷），並不產生腦膜刺激徵象，故 Brudzinski's sign 最不常出現於此情境（B 為最不常見）。

第 25 題

下列何者接受自體移植治療後的5年存活率最高？
  1. （A）急性骨髓性白血病第一次完全緩解後接受自體骨髓移植
  2. （B）急性骨髓性白血病第一次完全緩解後接受自體周邊血液幹細胞移植
  3. （C）急性淋巴性白血病第一次完全緩解後接受自體骨髓移植
  4. （D）急性淋巴性白血病第一次完全緩解後接受自體周邊血液幹細胞移植

答案：（A）

詳解與考點

急性骨髓性白血病（AML）在第一次完全緩解後接受自體骨髓移植（autologous BMT），其 5 年存活率在臨床試驗中表現相對較優於急性淋巴性白血病（ALL）相應治療。ALL 對同種異體移植反應較好，自體移植效果相對不理想。選項 A（AML 第一次完全緩解後自體骨髓移植）為 5 年存活率最高。（官方答案，建議查證）

第 26 題

有關致癌因子及其相關癌症的敘述，下列何者需進一步提供護理指導以澄清誤解？
  1. （A）「我看你還是少吃點檳榔吧，不然口腔癌可能會找上你喔」
  2. （B）「平時喝酒適量即可，過量可能會導致肝癌、乳癌、食道癌的發生」
  3. （C）「我老公平時是油漆工，聽說長時間接觸那些苯胺染料，可能和膀胱癌的發生有關」
  4. （D）「上次我去看醫師，他跟我說我有幽門螺旋桿菌，可能和食道癌的發生有關」

答案：（D）

詳解與考點

本題問「需進一步護理指導以澄清誤解」者，即內容有錯需更正的敘述，答案為（D）。（D）幽門螺旋桿菌（H. pylori）感染主要與胃部疾病相關，是慢性胃炎、消化性潰瘍及「胃癌」、胃黏膜相關淋巴組織（MALT）淋巴瘤的重要危險因子，並非與「食道癌」相關，故此敘述有誤，需澄清。其餘三項皆正確、不需更正：（A）嚼食檳榔是口腔癌的明確致癌因子；（B）飲酒過量與肝癌、乳癌、食道癌等多種癌症相關；（C）長期接觸芳香胺／苯胺類染料（如染料、橡膠業）與膀胱癌有關。故正解為（D）。

第 27 題

有關帶狀疱疹臨床症狀之敘述，下列何者正確？
  1. （A）帶狀小水疱群聚常會環繞軀幹一圈
  2. （B）最常發生在頭頸部
  3. （C）口腔有乳白色的斑塊
  4. （D）淋巴腺腫與水疱同時發生、同時消失

答案：（D）

詳解與考點

帶狀疱疹由水痘帶狀疱疹病毒（VZV）再活化引起，沿單側皮節分布，淋巴腺腫大與皮膚水疱幾乎同時出現，並隨水疱結痂而消退，故 D 正確。帶狀疱疹水疱不會環繞軀幹一整圈（A 錯，因單側神經節分布）；最常發生在胸部軀幹（B 錯）；口腔乳白色斑塊為鵝口瘡（念珠菌感染）的表現（C 錯）。

第 28 題

有關皮膚腫瘤之敘述，下列何者正確？
  1. （A）表皮囊腫（epidermal cysts）是一種惡性腫瘤，通常包裹著乳白色的粉狀物質
  2. （B）脂漏性角化症（seborrheic keratoses）是一種良性的表皮角質過度增生
  3. （C）纖維瘤（fibroma）是一種脂肪細胞常見的腫瘤
  4. （D）蜘蛛狀血管瘤（spider hemangioma）與血液中黃體激素升高有關

答案：（B）

詳解與考點

脂漏性角化症（seborrheic keratoses）是最常見的良性表皮腫瘤，表現為黑褐色蠟質「貼上去」感的角化病灶，屬表皮角質細胞過度增生，故 B 正確。表皮囊腫（epidermal cysts）為良性非惡性（A 錯）；纖維瘤是纖維組織腫瘤，脂肪細胞腫瘤為脂肪瘤（C 錯）；蜘蛛狀血管瘤與雌激素（非黃體激素）升高有關，常見於肝病及妊娠（D 錯）。

第 29 題

林先生因熱燒傷接受植皮手術，有關術後注意事項之敘述，下列何者正確？
  1. （A）供皮區應使用石膏夾板固定至少3～7天
  2. （B）術後應鼓勵病人移植部位多接受日照
  3. （C）肩部燒傷應使病人採俯臥，手臂位置遠離身體
  4. （D）膝蓋受傷部位應採屈曲姿位，膝下墊一枕頭

答案：（C）

詳解與考點

肩部燒傷植皮術後，為預防疤痕攣縮造成關節功能受限，應保持患肢外展位（手臂遠離身體），俯臥姿勢亦有助肩部伸展，故 C 正確。供皮區以非黏著性敷料覆蓋保濕即可，不需石膏固定（A 錯）；移植部位應避免日照以防色素沉著及組織損傷（B 錯）；膝蓋植皮後應保持伸直位，避免屈曲造成攣縮（D 錯）。

第 30 題

有關後天免疫缺乏症候群（AIDS）臨床表徵之敘述，下列何者錯誤？
  1. （A）急性HIV感染可能出現類感冒症狀如淋巴腺腫大、發燒、肌肉關節疼痛
  2. （B）臨床潛伏期可能持續10年或更長時間
  3. （C）卡波西氏肉瘤是愛滋病人最常見的惡性腫瘤
  4. （D）愛滋病人可能出現口腔紅斑症

答案：（D）

詳解與考點

AIDS 病人口腔常見病變為口腔念珠菌感染（鵝口瘡，白色偽膜）與口腔毛狀白斑（hairy leukoplakia），並非口腔紅斑症（oral erythema/erythroplakia 通常指癌前病變，與 AIDS 免疫缺陷的典型機會性感染不符）。急性 HIV 感染有類流感症狀（A 正確）；潛伏期可達 10 年以上（B 正確）；卡波西氏肉瘤為最常見惡性腫瘤（C 正確）。故 D 錯誤。

第 31 題

為降低排斥反應，下列何者為器官移植前進行組織配對的常見檢驗？①C型肝炎檢驗 ②人類白血 球抗原（HLA） ③混和性淋巴細胞反應 ④交叉配對試驗 ⑤人類免疫缺乏病毒（HIV）篩檢
  1. （A）①②③
  2. （B）①④⑤
  3. （C）②③④
  4. （D）③④⑤

答案：（C）

詳解與考點

器官移植前為降低排斥，需進行免疫相容性配對，常見檢驗包括：人類白血球抗原 HLA 配對（②）、混和性淋巴細胞反應 MLC（③）、交叉配對試驗（④，即 crossmatch，確認受者血清中是否存在抗捐贈者抗體）。C 型肝炎（①）及 HIV（⑤）篩檢是感染性疾病篩檢，目的是保護受者安全，而非「組織配對以降低排斥」，故答案為②③④，即選項 C。

第 32 題

病人因車禍送到急診，身體評估出現下列何者時，應懷疑可能有氣胸？
  1. （A）一側聽不到呼吸音或呼吸音減弱
  2. （B）二側肺葉有喘鳴音
  3. （C）二側肺葉於吸氣時聽到囉音
  4. （D）一側肺葉叩診出現濁音

答案：（A）

詳解與考點

氣胸（pneumothorax）時，患側胸腔充氣導致同側肺塌陷，聽診呈呼吸音消失或明顯減弱，叩診呈過度反響音（hyperresonance），而非濁音；對側呼吸音正常。兩側肺喘鳴音（B）及囉音（C）提示氣道疾病；一側濁音（D）提示血胸或大量肺炎實變。故 A（一側聽不到呼吸音或呼吸音減弱）是最應懷疑氣胸的徵象。

第 33 題

有關急性呼吸窘迫症候群（ARDS）之敘述，下列何者正確？
  1. （A）因為外分泌腺分泌異常，而導致黏液聚集在肺泡中
  2. （B）因為肺部疾病，而引起右心肥大與肥厚
  3. （C）因為肋膜腔內積聚空氣，而導致肺部塌陷
  4. （D）因為肺泡微血管膜的通透性受損，而產生肺水腫

答案：（D）

詳解與考點

ARDS 的核心病理機轉是肺泡微血管膜通透性增加（非心因性），大量蛋白質滲液積聚於肺泡及間質，形成非心因性肺水腫，嚴重影響氧合（D 正確）。A 描述的是囊性纖維化的外分泌腺問題；B 描述的是肺心病（cor pulmonale）；C 描述的是氣胸。

第 34 題

下列何者不屬於動脈血液氣體分析（arterial blood gas analysis）可以直接偵測之項目？
  1. （A）呼吸困難
  2. （B）酸鹼度
  3. （C）重碳酸鹽含量
  4. （D）血氧飽和度

答案：（A）

詳解與考點

動脈血液氣體分析（ABG）可直接量測的項目包括：pH 值（酸鹼度）、PaO2（血氧分壓）、PaCO2（二氧化碳分壓）、HCO3⁻（重碳酸鹽，由公式推算）及血氧飽和度（SaO2）。「呼吸困難」是症狀（subjective），ABG 無法直接測量主觀症狀，故 A 不屬直接偵測項目。

第 35 題

下列何種給氧方式能提供最高的氧氣吸入濃度（FiO2）？
  1. （A）卞德里面罩
  2. （B）單純型面罩
  3. （C）氧氣鼻套管
  4. （D）非再吸入面罩

答案：（D）

詳解與考點

非再吸入面罩（non-rebreather mask, NRM）附有儲氣袋及單向閥，可防止呼出氣體與新鮮氧氣混合，在流量 10-15 L/min 下可提供 FiO2 約 80-100%，為非侵入性給氧方式中最高濃度氧氣輸送系統（D 正確）。文氏面罩可精確控制 FiO2 但上限約 50%；單純型面罩約 40-60%；鼻套管約 24-44%。

第 36 題

有關肺膿瘍病人的護理評估，下列何者最可能出現？
  1. （A）呼吸音減弱有時會出現肋膜摩擦音
  2. （B）叩診出現鼓音
  3. （C）上肺葉吸氣期出現喘鳴音
  4. （D）叩診出現過度反響音

答案：（A）

詳解與考點

肺膿瘍（lung abscess）為肺實質的局限性化膿性感染，病灶處肺組織實變，聽診呈呼吸音減弱；若病灶鄰近肋膜，可出現肋膜摩擦音（pleural friction rub），故 A 正確。叩診應呈濁音（非鼓音，B 錯）；喘鳴音為氣道狹窄的表現（C 錯）；過度反響音為含氣過多如肺氣腫或氣胸（D 錯）。

第 37 題

有關高血鉀導因之敘述，下列何者正確？①使用血管收縮素轉換酶抑制劑 ②使用醛固酮拮抗劑 ③使用噻嗪類利尿劑（thiazide diuretics） ④代謝性鹼中毒
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（A）

詳解與考點

血管收縮素轉換酶抑制劑（ACEI，①）會減少醛固酮分泌、抑制腎臟排鉀，導致高血鉀。醛固酮拮抗劑（②，如 spironolactone）直接阻斷醛固酮作用、留鉀排鈉，亦導致高血鉀。噻嗪類利尿劑（③）促排鉀，造成低血鉀。代謝性鹼中毒（④）使 K⁺ 移入細胞，導致低血鉀。故高血鉀的藥物/病因為①②，即選項 A。

第 38 題

尿液分析中出現紅血球的病因，下列何者錯誤？
  1. （A）輸尿管結石
  2. （B）前列腺肥大
  3. （C）子癲前症
  4. （D）尿路感染

答案：（C）

詳解與考點

子癲前症（preeclampsia）的尿液病變以蛋白尿為最主要特徵，尿液中出現大量蛋白質，而非紅血球（血尿）。血尿（尿中紅血球）的常見原因為輸尿管結石（A）、前列腺肥大（B，因尿道阻塞引起微血管損傷）及尿路感染（D）。故 C 子癲前症不是血尿（尿中紅血球）的正確病因。

第 39 題

陳先生，88歲，因全身水腫，呼吸喘至急診求治，診斷為急性腎衰竭，下列敘述何者正確？
  1. （A）血鉀7.5 mg/dL，心電圖T波低而寬長
  2. （B）可能因前列腺肥大，導致腎性急性腎衰竭
  3. （C）24小時尿量約300 c.c.，正處於腎衰竭少尿期
  4. （D）腎臟超音波檢查，顯示雙側腎臟大小為7.5 cm

答案：（C）

詳解與考點

急性腎衰竭少尿期（oliguric phase）定義為 24 小時尿量 < 400 mL（或 < 0.5 mL/kg/hr），選項 C 的 300 mL/24h 符合少尿期標準，故 C 正確。血鉀 7.5 mg/dL 時心電圖應呈 T 波高尖而非低而寬長（A 錯，低而寬為低血鉀或洋地黃中毒表現）；前列腺肥大引起尿路阻塞屬腎後性（非腎性）急性腎衰竭（B 錯）；成人正常腎臟大小約 10-12 cm，7.5 cm 偏小，提示慢性腎臟病（D 錯）。

第 40 題

有關腎臟功能檢測血清肌酸酐（creatinine）之敘述，下列何者錯誤？
  1. （A）易受飲食影響可用以估算排泄能力
  2. （B）是用來估算腎臟功能最佳指標
  3. （C）升高時代表腎功能已損傷50%以上
  4. （D）升高時代表腎絲球過濾率功能已降低

答案：（A）

詳解與考點

血清肌酸酐（creatinine）是肌肉代謝的終產物，主要由腎絲球過濾、腎小管幾乎不再吸收，可反映腎絲球過濾率（GFR），是評估腎功能的重要指標，但受肌肉量影響，並非受飲食影響明顯（不像 BUN 受蛋白攝取影響）。選項 A 稱「易受飲食影響」，此敘述錯誤，creatinine 受飲食影響小，BUN 才易受飲食（蛋白質攝取量）影響，故 A 錯誤。

第 41 題

有關預防泌尿道感染復發的護理指導，下列何者錯誤？
  1. （A）減少不必要的導尿管留置
  2. （B）排便後，應由前往後擦拭
  3. （C）洗澡避免盆浴，儘量採淋浴
  4. （D）症狀減輕沒發燒就可以停藥

答案：（D）

詳解與考點

泌尿道感染（UTI）抗生素療程應完整服完，不可症狀改善即自行停藥，否則細菌未完全清除，容易復發並產生抗藥性，故 D（症狀減輕沒發燒就停藥）為錯誤護理指導。其餘正確措施：減少不必要導尿管（A）、排便後由前往後擦拭（B，預防腸道菌逆行感染）、採淋浴取代盆浴（C）均正確。

第 42 題

有關糖尿病酮酸中毒（DKA）之處置，下列何者正確？①建立靜脈輸液，由低劑量胰島素開始給與 ②最初2小時，給與0.45％生理食鹽水維持電解質平衡 ③等尿液排出量恢復正常，應補充鉀離子 ④血液pH值>7.1時，則與以重碳酸鈉（NaHCO3）
  1. （A）①②
  2. （B）①③
  3. （C）②④
  4. （D）③④

答案：（B）

詳解與考點

DKA 處置關鍵：① 建立靜脈輸液，以低劑量胰島素（如 0.1 U/kg/hr regular insulin 靜滴）開始，避免血糖下降過快（①正確）。③ 等尿量恢復後再補充鉀離子，因 DKA 初期血鉀可能正常或偏高（胰島素給予後鉀會移入細胞），但胰島素治療後血鉀會降低，需在尿量確認後補充（③正確）。最初 2 小時通常給 0.9% 等張生理食鹽水（非 0.45%）以快速恢復血量（②錯）；pH > 7.1 時不需要給予 NaHCO3（④錯，pH < 7.0-6.9 才考慮）。

第 43 題

有關服用治療甲狀腺機能亢進之放射性碘（131I）的敘述，下列何者正確？
  1. （A）食物會延遲放射性碘（131I）吸收，服用前一天午夜後及服用後2小時應禁食，以利吸收
  2. （B）服用治療劑量於8～30 μ Ci 的病人應限制訪客，第一週最好單獨睡，避免接觸孕婦
  3. （C）服用一個星期後會經由尿液、糞便排出，這段時間在使用馬桶後，宜沖水2～3次
  4. （D）服用高劑量者10年後易出現甲狀腺功能亢進，故需定期追蹤血清T3是否上升

答案：（B）

詳解與考點

答案為（B）。放射性碘 131I 治療甲狀腺機能亢進後，病人體內帶有放射性，應採輻射防護措施：限制訪客（尤其避免接觸孕婦與孩童）、初期最好單獨睡覺、保持適當距離，故（B）方向正確為本題標準答案。其餘選項錯誤：（A）服用 131I 並非須午夜後禁食以「促進吸收」這類描述，臨床主要重點在治療後的輻射防護與排泄物處理，故不適當。（C）131I 主要經尿液排出（也有部分經糞便、唾液、汗液），如廁後多次沖水、加強手部清潔屬合理衛教，但本題單選以（B）為正解；其敘述方向雖部分合理，仍以官方答案（B）為準。（D）放射性碘治療常見的長期後果是「甲狀腺功能低下（hypothyroidism）」而非機能亢進，需定期追蹤甲狀腺功能（含 TSH、T4）以早期發現低下，故 D 錯誤。註：選項（B）所列「8～30 μCi」與一般治療劑量（多以 mCi 計）不符，研判為題面或單位繕打問題，作答重點仍在治療後輻射防護。

第 44 題

有關肢端肥大症之症狀，下列何者錯誤？
  1. （A）泌尿系統：低血鈣症、腎結石
  2. （B）骨骼系統：關節痛、肌肉無力
  3. （C）神經系統：腕隧道症候群、嗜睡
  4. （D）皮膚系統：皮膚增厚、油脂增多

答案：（A）

詳解與考點

本題問「錯誤」者，答案為（A）。肢端肥大症（acromegaly）因生長激素（GH）過度分泌，典型表現包括：骨骼與軟組織增生造成肢端及顏面骨骼增大、關節痛與肌肉無力（B 正確）；周邊軟組織增生壓迫正中神經造成腕隧道症候群，並可因腦下垂體腫瘤、睡眠呼吸中止等出現嗜睡（C 正確）；皮膚增厚、皮脂腺與汗腺活性增加導致皮膚油膩、多汗（D 正確）。至於泌尿與鈣磷代謝方面，GH/IGF-1 過多會增加腸道鈣吸收與腎小管磷再吸收，臨床上較常見「高尿鈣」與腎結石傾向，血鈣多為正常或僅輕度偏高，「低血鈣症」並非肢端肥大症的表現，故（A）的「低血鈣症」敘述錯誤，為本題正解。（避免一概斷言必為高血鈣；重點是會有高尿鈣、腎結石風險，而非低血鈣。）

第 45 題

有關尿崩症病人之護理處置，下列何者錯誤？
  1. （A）應鼓勵病人多喝開水，以維持水分和體液電解質的平衡
  2. （B）噴灑鼻噴劑型desmopressin時，教導病人應吸氣以增加藥效
  3. （C）腎因性尿崩症應給與Thiazide利尿劑及限鹽攝取，以緩解症狀
  4. （D）Vassopressin Tannate是油性懸浮液，抽藥前需先溫熱與搖勻

答案：（B）

詳解與考點

中樞性尿崩症噴鼻型 desmopressin（DDAVP）給藥時，應教導病人「吸氣時停止、閉住氣」讓藥物停留在鼻黏膜，而非吸氣將藥液吸入肺部，選項 B 「吸氣以增加藥效」為錯誤操作，是本題答案。鼓勵多喝水（A）、腎因性尿崩症用 Thiazide 加限鹽（C）、Vasopressin Tannate 油性懸浮液須溫熱搖勻（D）均正確。

第 46 題

有關糖尿病足病人運動時鞋襪選擇之建議，下列何者錯誤？
  1. （A）楦頭要寬，可讓腳趾自由伸展
  2. （B）穿鞋前要先檢查鞋內有無異物
  3. （C）襪子選擇棉質易吸汗為佳
  4. （D）運動時需穿鞋保護雙足，偶爾不穿襪沒關係

答案：（D）

詳解與考點

糖尿病足護理強調全程保護：運動時必須同時穿鞋與棉質吸汗襪，任何時候不穿襪都可能造成摩擦傷口與感染。選項 D「偶爾不穿襪沒關係」違反糖尿病足保護原則，故為錯誤答案。楦頭寬（A）、穿鞋前檢查異物（B）、棉質吸汗襪（C）均為正確建議。

第 47 題

有關2020年美國心臟醫學會（American Heart Association, AHA）公告準則，啟動院內心臟停止 （IHCA）生命之鏈（chain of survival）的次序，下列何者正確？①提供高品質心肺復甦 ②去 顫 ③早期監測與預防 ④心臟驟停後照護 ⑤復原 ⑥啟動緊急應變系統
  1. （A）①→②→③→⑥→⑤→④
  2. （B）③→⑥→①→②→④→⑤
  3. （C）⑥→①→③→②→④→⑤
  4. （D）⑥→②→③→①→⑤→④

答案：（B）

詳解與考點

2020 AHA 院內心臟停止（IHCA）生命之鏈共 6 環，順序為：③早期監測與預防 → ⑥啟動緊急應變系統 → ①高品質 CPR → ②去顫 → ④心臟驟停後照護 → ⑤復原，即選項 B。院內鏈與院外鏈最大差異在於以「早期監測預防」為首，以減少心臟停止發生，而非等待停止後才啟動。

第 48 題

72歲男性，有心臟病病史，夏天逛露天賣場時不明原因昏倒，臉色潮紅，皮膚乾熱，呼吸24次／ 分，脈搏強而快，體溫41.5℃，下列何者為其最可能診斷？
  1. （A）熱中暑（heat stroke）
  2. （B）熱性痙攣（heat cramp）
  3. （C）熱衰竭（heat exhaustion）
  4. （D）熱暈厥（heat syncope）

答案：（A）

詳解與考點

熱中暑（heat stroke）為最嚴重熱傷害，典型表現為高體溫（>40℃）、皮膚乾熱潮紅（汗腺功能喪失）、意識改變或昏迷、心跳快而強。本案 41.5℃、皮膚乾熱、脈搏強快，符合熱中暑。熱衰竭（C）皮膚冷濕、體溫正常偏高；熱痙攣（B）主為肌肉痙攣；熱暈厥（D）短暫昏厥後迅速恢復。

第 49 題

有關輸血品項與適應症之敘述，下列何者錯誤？
  1. （A）血小板濃厚液適用於治療血小板減少症
  2. （B）2單位紅血球濃厚液適用於提高成年人血色素約1～1.2 gm/dL
  3. （C）全血適用於過敏性休克病人
  4. （D）新鮮冷凍血漿適用於發生瀰漫性血管內凝血之病人

答案：（C）

詳解與考點

全血適應症為急性大量出血合併低血容積，不適用於過敏性休克。過敏性休克屬分布性休克，第一線處置為注射 Epinephrine，而非輸全血。選項 C「全血適用於過敏性休克」為錯誤，故為本題答案。血小板濃厚液（A）、紅血球濃厚液提升 Hb 約 1～1.2 gm/dL（B）、新鮮冷凍血漿治 DIC（D）均正確。

第 50 題

有關登革熱的敘述，下列何者正確？
  1. （A）臉部出現不痛不癢的紅斑
  2. （B）病毒從呼吸道檢體分離是確診的主要依據
  3. （C）為第三類法定傳染病
  4. （D）馬鞍狀發燒，發燒3天後體溫下降1～2天後，又再度發燒

答案：（D）

詳解與考點

答案為（D）。登革熱典型可呈「馬鞍狀（雙峰）發燒」：發燒數日後體溫一度下降，間隔 1～2 天又再度升高，故（D）正確。其餘選項錯誤：（A）登革熱皮疹常為瀰漫性紅斑、可有出血點或瘀斑，多分布於軀幹與四肢，且常伴搔癢感，並非「臉部、不痛不癢」的特定描述，故錯。（B）確診主要依血液檢體（病毒分離、NS1 抗原、RT-PCR 或血清抗體），而非呼吸道檢體，故錯。（C）登革熱在台灣屬「第二類」法定傳染病，而非第三類，故錯。綜上，正解為（D）。
