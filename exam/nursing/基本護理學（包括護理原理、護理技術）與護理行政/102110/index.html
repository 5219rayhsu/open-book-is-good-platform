第 1 題

情況：許奶奶 82 歲，糖尿病多年，右下肢第二、三腳趾有潰瘍性傷口，傷口狀況不佳，門診醫師建議住院行截肢手術，住院第一天許奶奶面有愁容，不肯吃飯。 您評估個案對壓力的調適狀態中，下列敘述何者錯誤？
  1. （A）腎上腺素分泌減少
  2. （B）壓力越大則認知功能就越差
  3. （C）情緒可能有害怕、焦慮及悲傷反應
  4. （D）可能出現退縮、失眠及易怒攻擊行為

答案：（A）

詳解與考點

正解：題眼在「壓力的調適狀態」與「何者錯誤」——壓力反應會啟動交感神經與腎上腺相關反應，使身體準備因應威脅；腎上腺素不會減少，因此 A 是錯誤敘述，故選 A。

B：壓力過度或持續時，注意力、記憶與判斷可能受影響，認知功能可能下降，是正確的。

C、D：害怕、焦慮、悲傷是常見情緒反應；退縮、失眠、易怒或攻擊也可見於壓力調適失衡，兩者均非答案。這是最強誘答——易怒與攻擊看似只是人格問題，但在壓力反應的行為層面確可出現。

本題考點：壓力反應（stress response）涉及交感－腎上腺髓質系統（sympathetic-adrenal-medullary system）；壓力可表現在生理、認知、情緒與行為層面；適應（adaptation）失衡時常見睡眠與情緒改變。

情況：許奶奶 82 歲，糖尿病多年，右下肢第二、三腳趾有潰瘍性傷口，傷口狀況不佳，門診醫師建議住院行截肢手術，住院第一天許奶奶面有愁容，不肯吃飯。 許奶奶術後第二天，主訴傷口疼痛，護理師評估後依據醫囑給與 panadol 500 mg P.O. st.，此種給藥措 施為下列何種護理功能？
  1. （A）獨立性功能
  2. （B）依賴性功能
  3. （C）合作性功能
  4. （D）診斷性功能

答案：（B）

詳解與考點

正解：題眼在「依據醫囑」給予 panadol——是否給藥及其藥名、劑量與途徑均由醫囑決定，護理師是在授權範圍內執行處方，屬依賴性功能，故選 B。

A：獨立性功能是護理師依專業判斷可自行執行的護理措施，例如評估、衛教或舒適照護；本題給藥以醫囑為前提，故非答案。

C：合作性功能通常需與其他專業人員共同規劃並分工執行，與單純依醫囑執行處方不同，故非答案。

情況：夏小姐 32 歲，今日執行子宮切除術，目前已由恢復室返回病房，主訴傷口好痛。 有關護理記錄的書寫，下列敘述何者錯誤？
  1. （A）「傷口好痛」屬於問題為導向記錄中的「S」
  2. （B）「疼痛/因手術傷口造成」屬於問題為導向記錄中的「A」
  3. （C）「教導個案早期下床活動」屬於焦點式記錄法中的「R」
  4. （D）「注意傷口之變化」屬於焦點式記錄法中的「A」

答案：（C）

詳解與考點

正解：題眼在「護理記錄」與「何者錯誤」——焦點式記錄的 R 是病人對照護的反應，教導個案早期下床活動是護理人員實際採取的處置，應記於 A，不能記為 R，故 C 為錯誤敘述，故選 C。

A：問題導向記錄中的 S 是主觀資料，「傷口好痛」是個案自述，分類正確。

B、D：問題導向記錄的 A 為評估，將疼痛與手術傷口關聯是護理判斷；焦點式記錄的 A 為行動，「注意傷口之變化」屬後續觀察處置，故非答案。這是最強誘答——「教導」看似產生病人反應，但記錄的是護理師做了什麼，尚未記載病人的接受或表現。

本題考點：問題導向記錄（SOAP note）的 S 為主觀資料、A 為評估；焦點式記錄（focus charting）的 DAR 中 A 為行動、R 為反應；記錄分類要區分護理措施與病人結果。

第 7 題

情況：夏小姐 32 歲，今日執行子宮切除術，目前已由恢復室返回病房，主訴傷口好痛。 夏小姐的護理計畫中出現「每班監測病患疼痛部位強度與性質」的敘述，此為：
  1. （A）護理問題
  2. （B）護理目標
  3. （C）護理措施
  4. （D）護理評值

答案：（C）

詳解與考點

正解：題眼在「每班監測病患疼痛部位、強度與性質」——這句話具體指定護理人員要執行的觀察與頻率，是為達成目標所採取的行動，因此屬護理措施，故選 C。

A：護理問題應描述個案的健康反應或需求，例如急性疼痛，並非「每班監測」這項行動，故非答案。

B、D：護理目標應描述預期病人結果；護理評值是比較實際結果與目標的判斷。兩者均不等同於例行監測的執行內容。

本題考點：護理計畫（nursing care plan）包含問題、目標、措施與評值；護理措施（nursing intervention）是護理人員可執行的具體行動；評估資料（assessment data）可由監測疼痛部位、強度與性質取得。

第 8 題

護理師執行下列何項處置，所使用過的空針最具有傳染性？
  1. （A）IV bag 加藥
  2. （B）penicillin 藥物稀釋
  3. （C）驗 CBC/DC
  4. （D）打水球固定存留導尿管

答案：（C）

詳解與考點

正解：題眼在「使用過的空針」與「最具有傳染性」——傳染風險以是否接觸病人血液或體液判斷。抽血驗 CBC/DC 的空針直接接觸血液，具有血液傳染性風險，故選 C。

A：IV bag 加藥的空針通常接觸的是輸液或藥液，而非病人血液，故非答案。

B：penicillin 藥物稀釋所用空針同樣主要接觸藥液，未直接接觸血液，故非答案。

D：打水球固定存留導尿管的空針接觸的是無菌水與導尿管的氣囊腔，不應接觸病人血液。這是最強誘答——它與侵入性導尿操作有關，但傳染性判準仍是空針實際是否被血液或體液污染。

本題考點：標準防護（standard precautions）假設血液與特定體液可能具傳染性；針具安全（sharps safety）依實際污染來源評估風險；使用後針具應立即投入防穿刺容器，不可回套針帽。

第 9 題

下列何者不是外科無菌技術的應用對象？
  1. （A）導尿技術
  2. （B）鼻胃灌食
  3. （C）靜脈注射
  4. （D）手術傷口換藥

答案：（B）

詳解與考點

正解：題眼在「不是外科無菌技術的應用對象」——外科無菌技術用於進入無菌部位或需維持無菌操作的侵入性處置；鼻胃灌食是經既有鼻胃管進行腸道灌注，通常採清潔技術，不屬外科無菌技術，故選 B。

A：導尿須避免將微生物帶入泌尿道，須採無菌技術，故非答案。

C、D：靜脈注射須維持穿刺部位與器材的無菌性；手術傷口換藥須防止病原進入傷口，兩者均為外科無菌技術的重要應用。這是最強誘答——鼻胃管也進入體內，但「進入體內」不必然等於外科無菌；判準是操作是否涉及無菌組織或需建立無菌區。

本題考點：外科無菌技術（surgical asepsis）用於侵入性操作與無菌傷口；清潔技術（medical asepsis）著重降低微生物數量與傳播；鼻胃灌食（nasogastric feeding）一般採清潔操作。

第 10 題

有關觸診的敘述，下列何者正確？
  1. （A）觸診前必須先經過病患同意
  2. （B）避免誤會，檢查時一律戴手套
  3. （C）顧及隱私，檢查時不可掀開衣物
  4. （D）觸診時動作應該越輕越快越好

答案：（A）

詳解與考點

正解：題眼在「觸診」——觸診直接接觸病人身體，應先說明目的、方式與可能不適，取得病人同意並尊重其自主權，故選 A。

B：手套用於可能接觸血液、體液、黏膜、破損皮膚或依隔離需求時，並非為避免誤會而一律使用；過度使用也不能取代手部衛生，故非答案。

C：為正確評估需在尊重隱私與適當遮蔽下暴露必要部位，不能因隱私而完全不掀衣物，故非答案。

D：觸診應依部位與目的採適當力道、順序與速度，不是越輕越快越好，故非答案。

本題考點：知情同意（informed consent）與病人自主（patient autonomy）是身體評估的前提；觸診（palpation）應兼顧說明、隱私與適當暴露；標準防護（standard precautions）的手套使用依暴露風險決定。

第 11 題

皮下注射時的注射角度會受下列那一項因素的影響？
  1. （A）男性或女性
  2. （B）使用之注射針頭
  3. （C）藥物之注射劑量
  4. （D）藥物為油性或水性

答案：（B）

詳解與考點

正解：題眼在「皮下注射角度」——角度的目的在讓藥液進入皮下組織而非肌肉或真皮，因此須依針頭長度與病人的皮下組織厚度調整；四個選項中直接影響角度選擇的是使用之注射針頭，故選 B。

A：性別本身不是決定注射角度的判準，應看個別皮下脂肪與體型，而非以男性或女性概括，故非答案。

C：藥物劑量影響注射量與部位選擇，但不直接決定針頭進入皮下的角度，故非答案。

D：油性或水性影響藥物特性與給藥考量，也不是角度的主要判準。這是最強誘答——劑量與藥物性質確實牽涉注射技術，但本題問的是角度，關鍵在針頭長度與組織深度。

本題考點：皮下注射（subcutaneous injection）目標為皮下組織；注射角度（injection angle）依針頭長度與皮下組織厚度調整；安全給藥（medication safety）需同時確認途徑、部位與病人個別狀況。

第 12 題

有關盤尼西林皮膚試驗（penicillin skin test, PST）的敘述，下列何者正確？①注射時針頭斜面朝上， 以 5～15 度角插入真皮內 ②注射後 48～72 小時檢查反應結果 ③由醫師檢查反應 ④反應結果為 陽性反應，方可注射此藥 ⑤過敏反應常用之急救藥物為 1/1000 腎上腺素（epinephrine）

  2. （B）①③⑤
  3. （C）②③④

  2. （B）有臨床症狀顯現的患者，才算是感染鏈中的帶菌者
  3. （C）有效切斷感染鏈其中任一環節，則感染源的傳播即會停止
  4. （D）病人單位使用清潔劑擦拭，就可以達到滅菌的效果

詳解與考點

正解：題眼在「院內感染」與「感染鏈」——感染的傳播須由感染源、傳染途徑與易感宿主等環節相連；只要有效切斷其中一環，傳播鏈便無法延續，故選 C。

C：當報酬高於能力、能力又高於生產力時，具能力者未能在工作中發揮，可出現焦慮與不安；重點在能力與工作產出的失配，故非答案。

D：當生產力高於能力、能力又高於報酬時，員工承受的工作要求與報酬不相稱，易感受被剝削或處罰而不滿，故非答案。

本題考點：工作報償與滿意（work reward and satisfaction）——比較能力（capacity）、生產力（work productivity）與報酬（pay level）的相對關係；報酬高於投入時可能有不公平或罪惡感，報酬低於投入時易有不滿與疏離。

第 78 題

資深護理師在單位表現優異，具危機處理的能力，且能營造單位同仁向心力，並達到全人照護的目 標與精神。請問其扮演下列何種角色？
  1. （A）策劃者
  2. （B）追隨者
  3. （C）工作者
  4. （D）領導者

答案：（D）

詳解與考點

正解：題眼在「危機處理」「營造向心力」與「達到全人照護目標」——這些描述的是影響團隊方向、凝聚成員並帶領達成共同目標的角色，故選 D。

A：策劃者著重規畫目標、步驟與資源配置；題幹不只說規畫，更強調危機中的帶領與團隊凝聚，故非答案。

B：追隨者是支持並配合團隊方向的角色，不能解釋主動營造向心力及引導照護目標，故非答案。

C：工作者可完成分派的臨床工作，但不必然承擔凝聚成員與危機決策的影響力。這是最強誘答——資深護理師當然也是工作者，然而題幹問的是其展現的核心功能，故非答案。

本題考點：護理領導（nursing leadership）——領導者（leader）影響團隊、處理問題並導向共同目標；策劃（planning）是管理功能之一，追隨（followership）則是支持團隊目標的角色。

第 79 題

確認護理長之薪資層次最重要的工作表現因子為何？
  1. （A）技術需求
  2. （B）工作情況
  3. （C）責任
  4. （D）身體需求

答案：（C）

詳解與考點

正解：題眼在「護理長之薪資層次」——護理長須對單位人員、照護品質、資源運用與管理結果承擔責任；在工作評價中，責任範圍最能區分其與一般職務的薪資層次，故選 C。

A：技術需求會影響職務價值，但護理長的薪資差異不僅來自技術，更來自管理與決策責任，故非答案。

B：工作情況如環境風險、輪班或壓力是評價因素之一，卻不足以最具體反映護理長的職位層級，故非答案。

D：身體需求描述搬運、站立等體力負荷；護理長的職務價值主要不以此決定。這是最強誘答——臨床工作確有身體負荷，但題幹鎖定管理職薪資，其關鍵在責任幅度，故非答案。

本題考點：工作評價（job evaluation）——常以技術需求、責任、工作情況與身體需求比較職務相對價值；管理職的薪資層次尤其反映責任（responsibility）與決策範圍。

第 80 題

醫院主管事先訂定預算的最高金額，再交由護理部擬訂預算時提出申請是屬於：
  1. （A）固定限額預算（fixed ceiling budget）
  2. （B）彈性預算（flexible budget）
  3. （C）開放式預算（open-ended budget）
  4. （D）零基預算（zero-base budget）

答案：（A）

詳解與考點

正解：題眼在「事先訂定預算的最高金額」——主管先設定不可逾越的經費上限，護理部只能在該額度內編列與申請，正是固定限額預算，故選 A。

B：彈性預算會隨服務量或工作量改變而調整經費，不是先固定一個最高限額，故非答案。

C：開放式預算不以預先設定的固定上限為核心，與題幹的限制條件相反，故非答案。

D：零基預算要求各項支出自零開始重新論證必要性。這是最強誘答——兩者都要求審慎編列，但零基預算的辨識點是逐項重新審查，不是主管先定總額上限，故非答案。

本題考點：護理預算（nursing budget）——固定限額預算（fixed ceiling budget）先定支出上限；彈性預算（flexible budget）隨業務量調整；零基預算（zero-base budget）逐項重新證明支出必要性。
