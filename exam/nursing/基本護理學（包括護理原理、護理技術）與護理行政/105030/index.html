第 1 題

有關 SARS 的隔離措施，下列敘述何者錯誤？
  1. （A）SARS 屬於飛沫傳染，故需給予負壓單獨病房
  2. （B）只有在接觸 SARS 病患的體液時，才需要穿戴防護用具
  3. （C）SARS 病人使用的醫療用品，最好是拋棄式或單獨一套使用
  4. （D）SARS 病人的床單需要先行高壓滅菌消毒後才可進行清洗

答案：（B）

詳解與考點

正解：題眼在 SARS 隔離與「錯誤」——感染管制的判準是所有進入病人照護區、可能接觸呼吸道分泌物或受污染環境的工作，都須依傳播途徑採取適當個人防護；不能只在接觸體液時才穿戴防護用具，故（B）為錯誤敘述，應選 B。

A：SARS 除飛沫外，抽痰、插管等產生氣膠的處置具空氣傳播風險，故照護時提升至空氣傳播防護、安置於負壓單獨病房以降低含病原氣膠外逸，是正確的隔離措施。

C：病人專用醫療用品採拋棄式或單獨使用，可避免設備成為交叉感染媒介，是正確的。

D：依 SARS 期間所採規範，病人使用過的床單視為高感染性織品，先經高壓滅菌處理再送洗，以降低洗滌過程的環境傳播風險，是正確的。這是最強誘答——它的處理強度高於一般感染性織品，正因當時對此病原採取更嚴格的規範。

本題考點：傳染途徑隔離（transmission-based precautions）依病原傳播方式加強防護；個人防護裝備（personal protective equipment）依暴露風險全程使用；負壓隔離（negative-pressure isolation）用於空氣傳播風險控制。

第 2 題

有關護理倫理的原則，下列敘述何者錯誤？
  1. （A）醫師將愛滋病病人的資料向當地衛生局報告，違反保密原則
  2. （B）施行人體實驗時，事前告知相關注意事項，並取得受試者的書面同意，符合自主原則
  3. （C）告知 40 歲的婦女子宮頸抹片檢查的重要性，此為行善原則
  4. （D）醫師應末期病人的要求不予維生的治療，此種行為並不違反不傷害原則

答案：（A）

詳解與考點

正解：題眼在「愛滋病資料向衛生局報告」與「錯誤」——保密原則保障病人隱私，但依法定傳染病通報所為的必要通報屬保密義務的正當例外，不能說成違反保密，故（A）為錯誤敘述，應選 A。

B：人體研究須先充分告知、取得受試者書面同意，讓受試者能依自身價值作決定，符合自主原則。

C：主動告知子宮頸抹片檢查的重要性，目的在促進健康與預防疾病，符合行善原則。

D：末期病人拒絕無效或不符合其意願的維生治療時，尊重其決定並避免無益傷害，可與不傷害原則相容。這是最強誘答——停止治療不等於放棄照護，仍應提供舒適照護與症狀緩解。

本題考點：保密原則（confidentiality）有法定通報例外；自主原則（autonomy）以知情同意為核心；不傷害原則（nonmaleficence）要求避免無益醫療傷害。

第 3 題

尿液檢體收集後，應將用過的小兒集尿袋依下列那一種廢棄物規定處理？
  1. （A）一般性可燃
  2. （B）一般性不可燃
  3. （C）感染性可燃
  4. （D）感染性不可燃

答案：（C）

詳解與考點

正解：題眼在「用過的小兒集尿袋」——集尿袋直接盛裝尿液，屬受病人檢體污染的醫療廢棄物；依題目分類，應以感染性可燃廢棄物處理，故選 C。

A：一般性可燃廢棄物未受檢體污染；把（C）集尿袋當成一般垃圾會違反感染管制的污染物分流原則。

B：一般性不可燃廢棄物同樣不適用於盛裝過尿液的集尿袋，錯在忽略其感染性。

D：此選項雖辨識出感染性，卻錯在材質處理分類；集尿袋為可燃材質，故不選 D。這是最強誘答——它只差在可燃與不可燃，判斷時須同時確認污染性與材質。

本題考點：感染性廢棄物（infectious waste）含受檢體污染物；醫療廢棄物分類（medical waste segregation）須同時辨識污染性與材質；標準防護（standard precautions）包含污染物安全處理。

第 5 題

有關護理專業特性之敘述，下列何者錯誤？
  1. （A）運用護理過程解決病人的健康問題是屬於「相互依賴功能」
  2. （B）「人、環境、健康、護理」是護理專業的核心構面
  3. （C）重視人為「身、心、靈、社會」的複合體
  4. （D）護理所強調的理念是「care」，而不是「cure」

答案：（A）

詳解與考點

正解：題眼在「運用護理過程解決病人的健康問題」——這是護理人員依專業判斷可獨立執行的護理功能（independent nursing function），不是須與其他專業合作的相互依賴功能，故 A 為錯誤應選項。

B：人、環境、健康與護理是護理學關注的核心構面，說明護理不只處理疾病本身，故非答案。

C：將人視為身、心、靈、社會的整體，是全人護理（holistic nursing）的基本觀點，故非答案。

D：護理著重照護、支持與促進健康的 care，雖也配合治療，但 cure 主要指疾病治癒，故非答案。

本題考點：護理功能（nursing functions）可分獨立、依賴與相互依賴功能；護理過程（nursing process）是獨立專業判斷的工具；全人護理（holistic nursing）以人、環境、健康、護理四構面整合照護。

第 6 題

辦理社區子宮頸抹片檢查及胸部 X 光篩檢，依據三段五級健康學說，此活動是屬於那一層級的預防？
  1. （A）第一段第一級
  2. （B）第二段第二級
  3. （C）第一段第三級
  4. （D）第二段第三級

答案：（D）

詳解與考點

正解：題眼是「子宮頸抹片檢查及胸部 X 光篩檢」——兩者都是在尚未出現明顯症狀時及早發現疾病，屬第二段預防中的第三級，即次級預防（secondary prevention），故選 D。

A：第一段第一級預防是在疾病尚未形成前促進健康，如健康教育與生活型態促進；篩檢已有找出早期病變的目的，故非答案。

B：第二段第二級的標示並非本題三段五級理論中早期診斷與早期治療的位置，故非答案。

C：第一段第三級的編碼不符三段五級預防的分層；且篩檢的重點是早期發現，不是疾病後的復健，故非答案。

本題考點：三段五級預防（three levels and five stages of prevention）中，健康促進屬第一段第一級；特異性保護屬第一段第二級；篩檢與早期診斷治療屬第二段第三級，即次級預防（secondary prevention）。

第 7 題

依據護理人員法第 24 條規範，下列何者不是護理人員的業務範圍？
  1. （A）健康問題之護理評估
  2. （B）預防保健之護理措施
  3. （C）護理指導及諮詢
  4. （D）醫療處置行為

答案：（D）

詳解與考點

正解：題眼在「不是護理人員的業務範圍」——本題涉及法定業務，條文內容具時效敏感性；依題幹所指規範，護理人員可做護理評估、預防保健護理措施及護理指導諮詢，但一般性「醫療處置行為」不能概括視為其獨立業務，故選 D。

A：健康問題之護理評估是護理過程的起點，也是護理人員的核心專業工作，故非答案。

B：預防保健之護理措施屬護理人員依法執行的專業範圍，故非答案。

C：護理指導及諮詢用以協助病人理解與處理健康問題，屬護理專業工作，故非答案。

本題考點：護理人員法（Nurses Act）的業務範圍應以現行法規為準；護理評估（nursing assessment）、預防保健護理與護理指導諮詢屬護理核心工作；醫療處置須依授權、醫囑與執業範圍判定。

第 8 題

當頭部外傷傷口有許多新鮮血漬沾污頭髮時，使用下列何種清洗劑較合適？
  1. （A）過氧化氫溶液
  2. （B）丙酮
  3. （C）乙醚
  4. （D）冷水

答案：（D）

詳解與考點

正解：題眼在「新鮮血漬沾污頭髮」——血液中的蛋白質遇熱會凝固而更不易去除，因此先以（D）冷水清洗最合適，可避免血漬固定於毛髮與傷口周邊，故選 D。

A：過氧化氫可能有刺激性，也可能影響組織；清潔頭髮上的新鮮血漬不以此作為首選，故非答案。

B：丙酮是有機溶劑，可能刺激皮膚與傷口，不適合用於傷口附近頭髮清潔，故非答案。

C：乙醚具揮發性與安全風險，也會刺激皮膚，不應作為此情境的清洗劑，故非答案。

本題考點：傷口周邊清潔（wound-adjacent cleansing）先兼顧組織安全；血漬清潔（bloodstain removal）避免先用熱水以免蛋白質凝固；非傷口適用的有機溶劑不可任意接觸皮膚或傷口。

第 10 題

承上題，依醫囑為張小姐留取常規尿液檢體，下列敘述何者錯誤？
  1. （A）教導張小姐留取中段尿
  2. （B）儘量將尿液檢體於 30 分鐘內送檢
  3. （C）常規尿液檢體的檢驗值，可作為使用抗生素的依據
  4. （D）留取尿液前，須先評估張小姐目前月經是否來潮

答案：（C）

詳解與考點

正解：題眼在張小姐高燒住院後的「常規尿液檢體」與「何者錯誤」——常規尿液檢查可提供尿液性質與感染線索，但不能單獨作為選用抗生素的依據；若需判定致病菌與藥物敏感性，應依尿液培養及藥敏結果，故 C 為應選項。

A：留取中段尿可減少尿道口與周邊污染物混入檢體，是常規尿檢的正確採檢原則，故非答案。

B：尿液宜盡快送檢，題示 30 分鐘內送達可減少細胞、管型與細菌變化造成的檢驗誤差，故非答案。

D：月經血會污染尿液並影響結果判讀，採檢前先評估是否月經來潮是正確的，故非答案。

本題考點：常規尿液檢查（urinalysis）用於初步評估；尿液培養與藥物敏感性試驗（urine culture and susceptibility testing）才可支持抗生素選擇；中段尿（midstream urine）與迅速送檢可降低污染與檢體變質。

第 11 題

有關 S.O.A.P.I.E.R.紀錄法的敘述，下列何者正確？
  1. （A）病人「常有呻吟聲，對呼叫無反應、疼痛刺激會睜眼」，屬於主觀資料
  2. （B）「家屬表示早上吃飯時病人手上的碗突然掉到地上」，屬於客觀資料
  3. （C）病人「無法自行翻身下床」，屬於「活動功能障礙」問題的導因
  4. （D）病人「有吞嚥反射，但易有嗆食現象，需持續注意餵食情形」，屬於評值

答案：（D）

詳解與考點

正解：題眼在 S.O.A.P.I.E.R. 紀錄法與「屬於評值」——「有吞嚥反射，但易有嗆食現象，需持續注意餵食情形」是在記載措施後病人的反應及仍須追蹤的結果，屬評值（Evaluation），故選 D。

A：呻吟、對呼叫與疼痛刺激的反應是護理人員可觀察或測得的資料，屬客觀資料，不是主觀資料，故非答案。

B：家屬對事件的轉述屬他人陳述的主觀資料，不能因內容可想像為外在事件就改列客觀資料，故非答案。

C：無法自行翻身下床是活動功能障礙的表現或佐證資料，不是造成問題的導因，故非答案。這是最強誘答——它看似在說明活動受限，分辨關鍵在於護理診斷的導因須是造成該問題的因素，而非問題本身的表現。

本題考點：SOAPIE(R) 紀錄（SOAPIE(R) charting）以主觀資料、客觀資料、評估、計畫、執行與評值組成；主觀資料（subjective data）來自病人或他人陳述；客觀資料（objective data）可由觀察或測量取得。

第 12 題

病人表達「我吃不下飯，一點胃口也沒有！」在建立專業性護病關係時，護理師如何回應較恰當？
  1. （A）「你不餓嗎？我可是餓死了！」
  2. （B）「怎麼可能？你已經兩餐沒吃了？這樣可能有問題喔！」
  3. （C）「我認為你這樣做對你的病一點好處都沒有！」
  4. （D）「你那裡不舒服？我幫你檢查看看！」

答案：（D）

詳解與考點

正解：題眼在病人主訴「吃不下飯、沒有胃口」——建立專業性護病關係時，先用開放式問題探索不適原因並表達願意協助，最符合治療性溝通（therapeutic communication），故選 D。

A：將焦點轉到護理師自己的飢餓感，是不適當的自我揭露，無助於理解病人的困擾，故非答案。

B：以質疑與警告式語氣回應，容易使病人防衛，未先探索其食慾下降的原因，故非答案。

C：直接評價病人的作法並說教，會阻斷表達與合作關係，故非答案。

本題考點：治療性溝通（therapeutic communication）以傾聽、同理與開放式探索為原則；開放式問題（open-ended question）可協助釐清症狀與需求；非治療性溝通（nontherapeutic communication）包括說教、責備、轉移焦點與否定感受。

第 13 題

陳先生剛由醫師口中得知自己罹患末期癌症，護理師此時應如何表示最適當？
  1. （A）輕握病人的手或是輕拍其肩膀表示支持與關懷
  2. （B）鼓勵病人面對現實，儘量協助個案完成未完成之願望
  3. （C）告訴病人目前醫療進步非常快，應抱持希望接受持續醫療照顧
  4. （D）主動詳細告訴病人其後續所應做的準備

答案：（A）

詳解與考點

正解：題眼在「剛得知末期癌症」——病人處於突發且高度衝擊的訊息後，優先需要的是在場陪伴與支持；若病人接受觸碰，輕握其手或輕拍肩膀可傳達關懷，故選 A。

B：協助完成未竟心願可在病人表達其目標、情緒較能整理後共同規劃；此刻先要求面對現實，時機太早，故非答案。

C：以「醫療進步」要求抱持希望，可能淡化病人的震驚與悲傷，屬不恰當的安慰，故非答案。

  3. （C）資料
  4. （D）專技

答案：（B）

詳解與考點

正解：題眼在「工作完成後」的「慶功歡唱」——護理長提供令人愉快的回饋作為完成工作的結果，是以獎酬影響成員行為，故選 B。其效果來自成員期待或重視該正向結果。

A：法統影響力來自職位所授與的正式權力，例如依職責分派工作，非來自慶祝活動。

C：資料影響力來自掌握他人需要的資訊或運用資訊說服，題幹沒有以資訊交換為手段。

D：專技影響力來自專業知識、技術與經驗受人信賴；題幹提供的是完成後的正向報酬。這是最強誘答——護理長可能具有專業，但本題應依實際使用的影響手段判定。

本題考點：獎酬權力（reward power）透過正向報酬影響行為；法統權力（legitimate power）源於正式職位；專家權力（expert power）源於專業能力與可信度。

第 79 題

護理師使用醫療資訊系統資料時， 下列何者不適宜？
  1. （A）讀取後要登出
  2. （B）忙碌時請他人讀取後代為記錄
  3. （C）用自己身分進入系統
  4. （D）不隨意列印病人資料

答案：（B）

詳解與考點

正解：題眼在「醫療資訊系統」與「忙碌時請他人讀取後代為記錄」——系統的存取與記錄必須能追溯到實際執行照護的人；請他人代為讀取病人資料並代為記錄，會使紀錄與實際執行者脫節，破壞責任歸屬與資料正確性，也讓無照護關係者接觸到病人資料，故選 B。

A：使用完系統後登出可防止未授權者接續使用帳號，是基本資訊安全措施。

C：以自己的身分登入，才能使存取與登錄內容保有可追溯性，是正確作法。

D：不隨意列印病人資料可減少紙本外流與不必要揭露，符合隱私保護原則。這是最強誘答——忙碌時請人代勞看似提高效率，卻以犧牲個人責任與紀錄正確性為代價。

本題考點：身分驗證（authentication）要求帳號由本人使用；可追溯性（accountability）使紀錄能對應實際操作者；病人資訊保密（confidentiality）涵蓋電子與紙本資料。

第 80 題

下列何者屬於「過程」品質指標？
  1. （A）滿意度
  2. （B）護理師人數
  3. （C）手術流程
  4. （D）跌倒率

答案：（C）

詳解與考點

正解：題眼在「過程品質指標」——過程指標衡量照護服務如何被執行，例如手術是否依既定流程完成；手術流程直接描述服務提供的活動，故選 C。

A：滿意度反映病人對照護結果或經驗的感受，通常歸於結果面向，而非服務執行步驟。

B：護理師人數描述可投入的資源與人力配置，屬結構品質指標。

D：跌倒率是照護後發生的不良結果，用以反映病人安全成效，屬結果品質指標。這是最強誘答——跌倒預防涉及許多過程，但「跌倒率」量到的是最後發生的結果。

本題考點：結構—過程—結果模式（structure-process-outcome model）以資源條件、照護活動與服務成效評估品質；過程指標（process indicator）衡量實際執行流程；結果指標（outcome indicator）衡量病人或服務的最終狀態。
