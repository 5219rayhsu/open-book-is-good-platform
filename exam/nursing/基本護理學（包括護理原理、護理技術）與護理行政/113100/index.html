第 1 題

有關護理教育在促進護理專業持續發展的現況敘述，下列何者錯誤？
  1. （A）護理教育需要因應社會政策和醫療照護型態的轉變而調整
  2. （B）護理科系學生也需要學習新科技以便勝任未來的社會需求
  3. （C）現今護理教育應逐漸走向師徒制，以提供教學內容為導向的學習
  4. （D）護理教育不但重視知識和技術，專業倫理與社會正義的培養同等重要

答案：（C）

詳解與考點

正解：題眼在「護理專業持續發展」與「錯誤」——判準是現代護理教育強調能力導向、終身學習與回應照護情境變遷。C 將教育描述為逐漸走向師徒制且以教學內容為導向，忽略學生主動學習與能力培養，不符合專業持續發展方向，故 C 為應選項。

A：社會政策與醫療照護型態改變會影響護理所需能力，教育需隨之調整，故非答案。

B：數位科技已進入照護與健康資訊應用，學生學習新科技有助於回應未來需求，故非答案。

D：護理專業除知識與技術外，也重視倫理及社會正義，故非答案。這是最強誘答——它不談操作能力，卻是專業決策與公平照護不可分的一環。

本題考點：能力導向教育（competency-based education）重視可實踐的能力；終身學習（lifelong learning）因應照護變遷；專業倫理（professional ethics）與社會正義（social justice）同為護理教育核心。

第 2 題

孕婦懷孕 6 個月，近日感覺會陰部極癢，且陰道有黃色分泌物流出，自我沖洗外陰部後，仍舊感到難以忍 受，因此決定尋求婦產科醫師診治，依馬斯洛（Maslow）的五大需求階層理論，此時孕婦最需滿足的需求是：
  1. （A）生理需求
  2. （B）安全需求
  3. （C）愛及歸屬需求
  4. （D）自尊需求

答案：（A）

詳解與考點

正解：題眼在「會陰部極癢、陰道有黃色分泌物」與「難以忍受」——目前最直接受損的是身體舒適與生理功能。依 Maslow 五大需求階層，搔癢、不適及分泌物問題首先屬生理需求，故選 A。

B：安全需求涉及免於傷害、威脅與危險。這是最強誘答——孕期確實需要安全照護，但題幹沒有出血、胎動異常等危急安全訊號，優先序由當下難忍的身體不適決定，故非答案。

C：愛及歸屬需求著重人際連結與被接納，層次高於生理需求，不能優先於未緩解的身體不適，故非答案。

D：自尊需求指成就、受尊重與自我價值，層次更高，題幹無相關線索，故非答案。

本題考點：馬斯洛需求階層（Maslow's hierarchy of needs）以生理需求為基礎；安全需求（safety needs）在出現明確危害訊號時才躍升；護理優先序（nursing priority）依病人當下未滿足的最底層需求判斷。

第 3 題

手術室刷手的操作，應符合那些標準？①內科無菌 ②外科無菌 ③手應高舉至肩上 ④掌部應高於肘部
  1. （A）①③
  2. （B）①④
  3. （C）②③
  4. （D）②④

答案：（D）

詳解與考點

正解：題眼在「手術室刷手」——判準是外科無菌技術與由指尖向肘部的流水方向。②手術刷手必須符合外科無菌；④沖洗時掌部應高於肘部，使水由較清潔的手部流向肘部，故 ②④成立，選 D。

A：①③包含內科無菌；手術刷手要求的是外科無菌，且手不可高舉至肩上，故非答案。

B：①④雖包含掌部高於肘部，卻把無菌層級誤列為內科無菌，故非答案。

C：②③雖有外科無菌，卻誤稱手應高舉至肩上；正確重點是手高於肘部並維持在適當位置，故非答案。這是最強誘答——②正確，但組合題只要含一個錯誤子敘述即不能選。

本題考點：外科無菌技術（surgical asepsis）要求避免污染；手術刷手（surgical hand scrub）以手高於肘部維持水流方向；組合題判斷（combination item）須逐一檢核各子敘述。

第 4 題

醫院出現火災時，緊急應變守則可遵循 RACE 原則，下列措施何者錯誤？
  1. （A）將病人撤離疏散
  2. （B）通報以及啟動警報器
  3. （C）關閉氧氣與電器設備並打開門窗
  4. （D）油類及電氣火災，可先使用乾粉滅火器滅火

答案：（C）

詳解與考點

正解：題眼在「火災」與「RACE 原則」——判準是救援、警報、侷限火勢、滅火／疏散的順序。（C）關閉氧氣與電器設備確實可減少助燃與電氣危害，方向沒錯，錯在「打開門窗」：門窗應關閉以侷限煙火，打開反而助長通風、加速火勢與煙霧擴散，違反 Contain，故 C 為應選項。

A：先將立即危險中的病人撤離或疏散，符合 RACE 的 Rescue，故非答案。

B：通報並啟動警報器符合 Alarm，使院內人員及早啟動應變，故非答案。

D：油類與電氣火災適用乾粉滅火器，屬 RACE 的 Extinguish。這是最強誘答——它看似與「先救人再滅火」的順序衝突而易被當成錯項，但選項只陳述滅火器選用是否正確，並未主張其優先於疏散，故非答案。

本題考點：RACE（Rescue、Alarm、Contain、Extinguish/Evacuate）是火災應變順序；侷限火勢（containment）須關閉門窗與防火區劃；滅火器選擇（fire extinguisher selection）須符合火災類型。

第 5 題

劉先生對護理人員抱怨說： 「我受夠了每天做那麼多復健，醫生來看我的次數又那麼少，我很不滿」 ，下列 何者為最合宜的回應？
  1. （A）「我會請醫生把復健次數減少些，這樣好嗎？」
  2. （B）「聽起來您很生氣，可以再具體多講一點嗎？」
  3. （C）「我會再請醫生每天多來看您幾次！」
  4. （D）「醫生是照您的疾病需要，才會安排復健啊！」

答案：（B）

詳解與考點

正解：題眼在病人表達「很不滿」與「受夠了」——此刻首要是以治療性溝通接住情緒並探索具體困擾。B 回應病人的憤怒，再以開放式問題邀請說明，可促進病人表達並蒐集評估資料，故選 B。

A：未先了解問題便承諾減少復健次數，可能逾越護理人員角色且忽略復健需求，故非答案。

C：承諾要求醫師增加探視次數並未探索病人的真正期待，也做出無法保證的承諾，故非答案。

D：以疾病需要替醫師辯護，容易否定病人的感受並中斷表達。這是最強誘答——內容可能有部分事實，但時機錯在先說教而非先同理與評估。

本題考點：治療性溝通（therapeutic communication）先回應感受；開放式提問（open-ended question）促進敘說與評估；不當保證（false reassurance）會損害信任。

第 6 題

護理師首次照護王先生，先查閱其病歷資料，進入病室後向王先生自我介紹，隨後運用會談方式了解其昨 天晚上睡不好的原因，並提供情緒的安撫。王先生感謝地說： 「謝謝您這麼關心我，我現在感覺好多了。」 有關治療性人際關係過程的敘述，下列何者錯誤？
  1. （A）先查閱病歷資料以了解王先生健康狀況，為介紹前期（互動前期）階段
  2. （B）向王先生自我介紹，為認識期（介紹期）階段
  3. （C）運用會談方式了解睡不好的原因並提供情緒安撫，為工作期階段
  4. （D）王先生對護理師的感謝，為結束期階段

答案：（D）

詳解與考點

正解：題眼在護理師與王先生仍在了解睡眠原因、提供安撫的互動中——判準是治療性人際關係的階段功能，而非病人的一句感謝。D 將感謝直接判為結束期錯誤；結束期須有關係目標已完成、準備分離及評估成果等脈絡，故 D 為應選項。

A：接觸病人前查閱病歷以準備會談與了解健康狀況，屬介紹前期（互動前期），故非答案。

B：進入病室後自我介紹、建立初步信任與確認角色，屬認識期（介紹期），故非答案。

C：運用會談探究失眠原因並安撫情緒，是共同處理問題的工作期活動，故非答案。這是最強誘答——安撫後感覺好轉看似任務完成，但單次感謝不等同治療關係的正式結束。

本題考點：介紹前期（preinteraction phase）重在準備；認識期（orientation phase）建立角色與信任；工作期（working phase）探索問題並執行護理；結束期（termination phase）處理分離與評值。

第 7 題

有關病歷保存與管理的敘述，下列何者錯誤？
  1. （A）病歷內容未經病人、主治醫師許可，不得將病情洩漏
  2. （B）病人想要了解病情及預後，需由主治醫師說明
  3. （C）住院期間，方便醫師查房可先將病歷放在病人單位
  4. （D）依據醫療法及護理人員法，成年人病歷至少保存 7 年

答案：（C）

詳解與考點

正解：題眼在「住院期間」與「病歷放在病人單位」——判準是病歷的機密性與受控存取。C 為方便查房而將病歷隨意放在病人單位，會使未獲授權者可能閱覽，違反病歷保管與隱私保護原則，故 C 為應選項。涉及病歷保存年限的制度細節具時效敏感，本題依各選項的保密與保管概念判斷。

A：病歷資訊原則上應受保密保護，非因照護或依法授權不得洩漏，故非答案。

B：病情與預後的醫療說明應由負責診療的醫師依其專業責任進行，故非答案。

D：病歷保存年限屬法規規範的制度內容，並非本題所指的保管錯誤；實務上仍應依現行規定辦理，故非答案。這是最強誘答——選項含具體年限容易引發記憶疑慮，但本題真正違反保密原則的是 C。

本題考點：病歷機密性（medical record confidentiality）限制未授權閱覽；受控存取（controlled access）保障隱私；病歷保存（medical record retention）應依現行法規與機構規範辦理。

第 8 題

有關護理目標的訂定，下列何者最具體？
  1. （A）3/15 協助病人下床活動
  2. （B）3/15 病人使用止痛藥後疼痛緩解
  3. （C）3/15 病人能增加纖維質的攝取量
  4. （D）3/15 病人能說出三種以上富含鐵質的食物

答案：（D）

詳解與考點

正解：題眼在「最具體」——判準是護理目標是否同時具備明確時間、病人行為與可測量的結果。D 指定 3/15，主體是病人，並以「說出三種以上」呈現可觀察、可計數的學習成果，故選 D。

A：只有護理人員的協助行動，未說明病人要達成何種結果，屬護理措施而非目標，故非答案。

B：雖提及疼痛緩解，但未界定疼痛下降至何種可評值程度，故具體性不足。

C：增加纖維質攝取量有方向，卻沒有可測量的增加標準，故非答案。這是最強誘答——它以病人為主體且有正確方向，但缺少可評值的行為或數量。

本題考點：護理目標（nursing goal）應以病人結果為中心；SMART 原則（Specific, Measurable, Achievable, Relevant, Time-bound）強調可測量與期限；可評值結果（measurable outcome）須能觀察或計數。

第 9 題

下列護理評估資料的型態，何者屬於客觀資料（objective data）？
  1. （A）病人主訴： 「肚子痛的時間約持續 5 分鐘」
  2. （B）病人肌力檢查：右側下肢肌肉力量 3 分
  3. （C）病人抱怨昨天夜裡醒來 3 次
  4. （D）個案母親說病人昨天傷口滲出許多血水

答案：（B）

詳解與考點

正解：題眼在「客觀資料」——判準是資料是否可由護理人員直接測量、觀察或以標準工具驗證。B 右側下肢肌力 3 分是檢查者依肌力檢查所得的可驗證測量結果，屬客觀資料，故選 B。

A：腹痛持續時間由病人主訴，屬病人對症狀的個人經驗，故為主觀資料。

C：夜裡醒來的次數雖可計數，但本題來源是病人抱怨，未經直接觀察或紀錄驗證，仍屬主觀資料。這是最強誘答——數字不必然等於客觀，關鍵在資料來源是否為可驗證的觀察或測量。

D：母親轉述傷口滲出物是他人提供的病史，護理人員尚未直接觀察傷口，故非客觀資料。

本題考點：客觀資料（objective data）可測量、觀察或驗證；主觀資料（subjective data）來自病人感受或敘述；資料來源（source of data）決定同一現象在當下的資料型態。

第 10 題

有關給藥後的敘述，下列何者正確？①親自給藥親自記錄，不可在給藥前記錄 ②若病人拒服藥物，應記 錄之，待醫師查房再報告 ③p.r.n.藥物給予後，待觀察病人反應後再完成給藥記錄 ④給藥後，若病人出 現不適，應立即停藥並觀察生命徵象
  1. （A）①②
  2. （B）③④
  3. （C）①④
  4. （D）②③

答案：（C）

詳解與考點

正解：題眼在「給藥後」及四項敘述的組合——判準是給藥紀錄的即時性與不良反應處置。①給藥必須由執行者於實際給藥後立即記錄，不能預先記錄；④病人給藥後出現不適時，應先停止正在進行的給藥、評估生命徵象並依情況通報，因此①④成立，故選 C。

A：②病人拒服時，除記錄拒藥情形外，應及時評估原因並通知醫師或依單位流程處理，不能只等查房才報告；③PRN 藥物給予後仍應先完成給藥紀錄，再持續觀察療效與不良反應，故①②不成立。

B：③把紀錄延至觀察反應後，會使實際給藥時間與病歷不符；④是出現不適時的安全處置，故③④不成立。

D：②延後報告拒藥會延誤醫囑調整或病人安全評估；①④才是正確組合，故②③不成立。

本題考點：給藥紀錄（medication administration record）須於實際給藥後即時完成；拒藥（medication refusal）需記錄、評估並適時通報；必要時給藥（PRN medication）先記錄給藥事實，再評值反應。

第 11 題

有關給藥的禁忌，下列敘述何者錯誤？
  1. （A）鐵劑應避免與茶葉水併服，因茶葉中的鞣酸遇鐵會形成沉澱物
  2. （B）服藥時不可與酒精類飲料併服，因酒精會影響藥物的代謝過程
  3. （C）抗組織胺類藥物配合葡萄柚汁服用，不會影響藥物在肝臟之代謝
  4. （D）含鈣及鐵離子的藥物若與牛奶併服，容易抑制藥物的吸收

答案：（C）

詳解與考點

本題考點：護理過程（nursing process）先評估後處置；導尿系統通暢性（catheter patency）；少尿與無尿（oliguria and anuria）的初步評估。

  4. （D）護理人員移動病人時應多利用拖、拉的方式，少用滾動的方式

  2. （B）呼吸暫停（apnea）
  3. （C）呼吸過慢（bradypnea）
  4. （D）喟嘆式呼吸（sighing respiration）

  2. （B）灌食空針的高度與胃部距離為 60～90 cm

正解：題眼在「批次灌食」及「何者錯誤」——判準是利用重力緩慢灌入，避免空針高度過高造成流速太快與胃部不適。（B）空針與胃部距離 60～90 cm 過高，會使灌食速度難以安全控制，故為應選項。

  2. （B）①③
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：題眼在「長期臥床不動」——判準是失去肌肉張力與肌肉幫浦後的關節、循環變化。①髖部肌力與姿勢控制下降，容易外旋；③靜脈回流變差、血液鬱滯使血液黏稠度增加，因此①③成立，故選 B。

  4. （D）受到壓迫的部位較容易形成屍斑

B：資訊影響力來自掌握重要資訊並據以影響他人，並非本題調派的主要依據。

C：專家影響力來自專業知識與技能。這是最強誘答——護理長可能具備專業，但本題可要求支援的直接來源是其正式職位權限。

本題考點：法統影響力（legitimate power）來自正式職位與職權；專家影響力（expert power）來自專業能力；強制影響力（coercive power）來自懲罰或威脅。

第 49 題

有關品質管理，下列敘述何者正確？
  1. （A）醫院品質管理是追求主管滿意的過程
  2. （B）品質保證（quality assurance）是依照標準做評核，並找出不良品
  3. （C）石川馨（Ishikawa）的全面品質管理（total quality management）是以數據目標管理為主
  4. （D）戴明（Deming）提出全員參與之品質保證（company-wide quality assurance）

答案：（B）

詳解與考點

正解：題眼在品質保證的核心工作——品質保證是依既定標準評核照護結果或流程，辨識未達標準之處並促成改善；（B）正確，故選 B。

A：醫院品質管理以病人照護品質與組織持續改善為目標，不是追求主管個人滿意。

C：全面品質管理強調全員參與、顧客導向與持續改善，不能窄化為僅以數據目標管理為主。

D：戴明主張品質改善與管理哲學，題述的全員參與品質保證歸屬不正確。這是最強誘答——兩者都與品質管理相關，分辨要看理論主張與名稱是否相符。

本題考點：品質保證（quality assurance）依標準評核品質；全面品質管理（total quality management, TQM）強調全員參與與持續改善；品質改善（quality improvement）以發現缺口後修正系統為目的。

第 50 題

有關醫院護理主管預防護理業務糾紛的發生，下列敘述何者最適宜？
  1. （A）建立護理技術及常規的標準作業程序
  2. （B）為避免醫療糾紛，護理師不要相互支援
  3. （C）為避免說錯話，儘量不要回答病人問題
  4. （D）年資增長自然能了解如何預防醫療糾紛

答案：（A）

詳解與考點

正解：題眼在「預防護理業務糾紛」與「護理主管」——判準是以可遵循、可查核的制度降低照護差異。（A）建立護理技術及常規的標準作業程序，可使護理人員依一致流程執行、交班與紀錄，並作為教育訓練及品質改善的基礎，故選 A。

B：相互支援有助於在工作量大、病情變化或人力不足時維持照護安全；刻意不支援反而增加遺漏與風險，故非答案。

C：病人提出問題時，護理人員應在職責範圍內提供清楚說明，或協助轉介適當人員。因害怕說錯而不回應，會損害知情與治療性關係。這是最強誘答——減少不當承諾的方向雖對，錯在把「正確溝通」誤作「完全不溝通」。

D：年資可累積經驗，但不能取代標準流程、持續教育與風險管理；只依個人經驗會造成做法不一，故非答案。

本題考點：標準作業程序（standard operating procedure, SOP）可降低照護變異；護理風險管理（nursing risk management）重視溝通、紀錄與團隊支援；病人安全（patient safety）須靠制度而非個人年資。
