第 1 題

當發生醫療糾紛時，護理人員可能會面臨的法律責任，下列敘述何者錯誤？
  1. （A）須對「侵權行為」負民事責任，一般多以金錢賠償損害
  2. （B）執業時，應注意而未注意造成病人傷害可能會面臨「過失傷害罪」
  3. （C）護理人員法保障護理人員在涉及刑法上的責任時，可免於刑罰
  4. （D）地方衛生機關的懲戒委員會，就事件決定護理師執照是否撤銷或停權

答案：（C）

詳解與考點

正解：判準是護理人員法有沒有讓護理人員免除刑事責任——護理人員若因執業過失致病人傷亡，仍須依《刑法》負相應刑事責任，護理人員法並未賦予刑事豁免權，故C「護理人員法保障護理人員在涉及刑法上的責任時可免於刑罰」為錯誤敘述。

A：侵權行為造成他人損害須負民事賠償責任，且多以金錢賠償，敘述正確。 B：執業時應注意而未注意致病人受傷害，可能構成過失傷害罪（《刑法》第284條現行已整併為過失傷害罪，不再區分業務過失），敘述正確。 D：護理人員若有違失，由地方衛生機關的懲戒委員會就個案決定執照撤銷或停權等懲戒，敘述方向正確。

本題考點：護理糾紛的法律責任判準——民事責任（侵權行為、金錢賠償）與刑事責任（過失傷害罪，《刑法》第284條）分屬不同體系、互不排除，護理人員法規範的是執業與懲戒事項，並不能使刑事責任免除；懲戒（執照撤銷或停權）則由地方衛生機關的懲戒委員會依法審議。

第 2 題

醫療人員面對傳染病防疫壓力的反應與相關處置，下列敘述何者錯誤？
  1. （A）面對傳染病防疫，壓力愈大時認知功能和彈性思考通常也愈差
  2. （B）疫情帶來的壓力持續時間愈長、愈嚴重，適應的機會也就愈大
  3. （C）提供住所，降低醫護人員擔心回家可能使家人染病的心理負擔
  4. （D）充分的職前訓練，做好面對照護傳染性疾病病人的準備

答案：（B）

詳解與考點

正解：疫情壓力持續時間愈長、強度愈高，身心資源通常愈耗竭、適應能力愈差，而非題幹所稱「適應機會愈大」——B的因果方向與實證相反，為錯誤敘述。

A：面對防疫壓力時，壓力愈大通常認知功能與彈性思考愈差，敘述正確。 C：提供住所可降低醫護人員擔心返家使家人染病的心理負擔，屬於有效的壓力緩解措施，敘述正確。 D：充分的職前訓練能提升醫護人員照護傳染病病人的準備度，敘述正確。

本題考點：醫療人員防疫壓力管理判準——壓力愈大認知彈性愈差；壓力持續時間愈長、強度愈高，適應能力通常愈差而非愈好；降低心理負擔（提供住所）與提升準備度（職前訓練）是有效的因應措施。

第 3 題

護理師為了實踐個人護理理念，不計金錢報酬前往有大量傷患的醫院支援，以獲得個人精神與靈性 的昇華。此行為符合那一種護理理念？
  1. （A）苦行僧主義
  2. （B）浪漫主義
  3. （C）實用主義
  4. （D）具人文色彩的存在主義

答案：（A）

詳解與考點

正解：不計金錢報酬前往支援、以自我犧牲換取個人精神與靈性昇華，正是苦行僧主義（asceticism）強調克制物質欲望、藉自我犧牲追求精神成長的核心特徵，故選A。

B：浪漫主義偏重情感理想與浪漫化的護理形象，不以「自我犧牲換取靈性昇華」為核心，與題幹描述不符。 C：實用主義強調行動的實際效益與結果，與題幹不計報酬、追求精神層面的動機方向不同。 D：具人文色彩的存在主義同樣重視個人意義的追尋，但其核心在於自我實現與存在的意義，並不特別強調苦行式的自我犧牲，與題幹「苦行」特質的貼合度不如A。

本題考點：護理理念類型的判準——苦行僧主義（asceticism）以自我犧牲、克己與精神昇華為核心；辨別時先看行為是否伴隨「不計報酬」「自願犧牲」的特徵，再與浪漫主義（情感理想）、實用主義（效益導向）、存在主義（自我意義）逐一比對區隔。

第 4 題

有關外科無菌之敘述，下列何者正確？
  1. （A）是指一系列清潔的技術
  2. （B）是將非無菌的物件侷限在清潔區域內
  3. （C）避免微生物由一處傳播到另一處
  4. （D）應用於術後第一天傷口換藥時

答案：（D）

詳解與考點

正解：本題辨識的是外科無菌技術（surgical asepsis）的適用時機——凡需穿透皮膚或進入原本無菌腔室的操作皆須採外科無菌，術後第一天傷口換藥屬於傷口照護，須維持無菌環境以防感染，故選D。

A：「一系列清潔的技術」描述的是醫療無菌（medical asepsis），而非外科無菌，敘述不符外科無菌的定義。 B：外科無菌要求的是嚴格建立並維持無菌區域，而非僅將「非無菌物件侷限在清潔區域內」，此描述混淆了外科無菌與一般清潔隔離的概念。 C：「避免微生物由一處傳播到另一處」較接近感染管制的一般原則，並非外科無菌（著重建立與維持無菌狀態）的定義核心。

本題考點：無菌技術判準——外科無菌（surgical asepsis）用於穿透皮膚或進入無菌腔室的操作（如傷口換藥、侵入性處置），目標是建立並維持無菌區域；醫療無菌（medical asepsis）則以清潔技術降低微生物數量與傳播為目標，兩者層級不同，不可互換描述。

第 5 題

病人因退化性關節炎，對於是否接受全膝關節置換術徵詢護理人員的意見，下列護理人員的回應何 者最適當？
  1. （A）「開完刀加強復健，一定就會好的。」
  2. （B）「我們現在先去做心電圖檢查。」
  3. （C）「如果我是你，我會接受醫師的建議。」
  4. （D）「可以告訴我，你的擔心是什麼呢？」

答案：（D）

詳解與考點

正解：本題問的是最適當的治療性溝通回應——病人徵詢護理人員對手術的意見時，應以開放性問句探詢病人真正的擔憂，尊重其自主權並促進其自行做出知情決策，「可以告訴我，你的擔心是什麼呢？」正是這類開放性問句，故選D。

A：「開完刀加強復健，一定就會好的」是不切實際的保證，可能誤導病人對手術結果的期待，屬於治療性溝通應避免的作法。 B：「我們現在先去做心電圖檢查」轉移了病人提出的問題，未回應其徵詢意見的需求，屬於阻斷溝通的回應。 C：「如果我是你，我會接受醫師的建議」是以護理人員個人立場代替病人做決定，違反尊重病人自主權的原則。

本題考點：治療性溝通判準——面對病人徵詢意見時應以開放性問句探詢其真實想法與擔憂，而非給予不實保證、轉移話題或以自身立場代替病人決策；核心是尊重自主原則並促進知情決策。

第 6 題

有關紀錄書寫的原則，下列敘述何者錯誤？
  1. （A）記錄病人的抱怨內容時應標註「病人主述」，以便能區辨非家屬所言
  2. （B）病人的治療和反應皆應正確完整記錄，必要時其可作為法律證明文件
  3. （C）針對病人的護理目標和護理措施的擬定應具體可行、避免過於理想化
  4. （D）對執行護理措施後仍無法緩解的症狀，除了紀錄之外還需要報告醫師

答案：（A）

詳解與考點

正解：標註「病人主述」（P.S. 或 per patient）的目的，是要區辨這是病人本人的主觀陳述，而不是用來區辨「是否為家屬所言」；家屬陳述同樣須個別標示為「家屬主述」，A把標註目的窄化成區辨家屬，敘述邏輯錯誤，故選A。

B：病人的治療與反應皆應正確完整記錄，必要時可作為法律證明文件，敘述正確。 C：護理目標與措施的擬定應具體可行、避免過於理想化，敘述正確。 D：對執行護理措施後仍無法緩解的症狀，除了紀錄之外還需報告醫師，敘述正確。

本題考點：護理紀錄書寫判準——標註「病人主述」（P.S. 或 per patient）是區辨主觀資料的來源本人，同一原則適用於家屬陳述；記錄須正確完整、必要時具法律證明力；護理目標措施具體可行；異常症狀除紀錄外須報告醫師。

第 7 題

急性膽囊炎開腹手術後、生命徵象穩定的病人，擬定其護理計畫（nursing plan）階段內容，不包 括下列何者？
  1. （A）收集病人的主觀及客觀資料，以確立疼痛問題
  2. （B）將急性疼痛列為必須優先處理的護理問題
  3. （C）擬定給止痛藥後，病人疼痛降至2分的護理目標
  4. （D）計畫協助病人採取半坐臥式的護理活動

答案：（A）

詳解與考點

正解：「收集病人的主觀及客觀資料，以確立疼痛問題」屬於護理過程第一步驟「評估」的工作內容，並非計畫（nursing plan）階段所做的事，故選A。

B：將急性疼痛列為必須優先處理的護理問題，屬於計畫階段中排定護理問題優先順序的工作。 C：擬定給止痛藥後病人疼痛降至2分的護理目標，屬於計畫階段訂定護理目標的工作。 D：計畫協助病人採取半坐臥式的護理活動，屬於計畫階段擬定護理措施的工作。

本題考點：護理過程階段判準——評估負責收集主客觀資料以確立問題；計畫（nursing plan）階段則涵蓋排定護理問題優先序、訂定護理目標、擬定具體護理活動三項工作；凡題幹描述「收集資料」都應歸類到評估而非計畫。

第 8 題

王先生訴呼吸喘，聽診雙肺呈濕囉音，叩診肺呈濁音，觸診下肢水腫2＋。上述資料何者屬於症狀 （symptoms）？
  1. （A）個案主訴呼吸喘
  2. （B）聽診雙肺呈濕囉音
  3. （C）叩診肺呈濁音
  4. （D）觸診下肢水腫2＋

答案：（A）

詳解與考點

正解：本題辨別的是症狀（symptom）與體徵（sign）的差異——症狀是病人自身的主觀感受，只有病人本人能察覺，個案主訴「呼吸喘」正是這類主觀陳述，故選A。

B：聽診雙肺呈濕囉音是護理人員以聽診器客觀測量得到的發現，屬於體徵（sign），並非症狀。 C：叩診肺呈濁音同樣是他人可客觀觀察與測量的發現，屬於體徵。 D：觸診下肢水腫2＋也是可由他人客觀觸診測得的發現，屬於體徵。

本題考點：症狀（symptom）與體徵（sign）判準——症狀是病人主觀感受、僅病人本人可察覺（如主訴呼吸喘）；體徵是他人可透過聽診、叩診、觸診等方式客觀測量或觀察到的發現（如濕囉音、濁音、水腫），區分關鍵在於「誰能察覺到」。

第 9 題

護理目標設定的原則，下列何者錯誤？
  1. （A）主要以護理師的專業經驗來設定
  2. （B）設定目標應符合病人的能力與狀況
  3. （C）護理師有能力執行並可達到預期效果
  4. （D）醫療照護小組成員可認同與支持

答案：（A）

詳解與考點

正解：護理目標應以病人為中心設定，反映病人本身的能力、意願與狀況，而非「主要以護理師的專業經驗」為依據——護理師的專業判斷僅是參考，並非設定目標的主要基準，故A為錯誤敘述。

B：設定目標應符合病人的能力與狀況，敘述正確。 C：護理師須有能力執行該措施並可達到預期效果，敘述正確。 D：醫療照護小組成員可認同與支持該目標，敘述正確。

本題考點：護理目標設定判準——目標須以病人為中心（符合其能力與狀況），同時具備可執行性（護理師能執行並達效果）與團隊共識（照護小組認同支持），護理師的專業經驗是輔助判斷，不是設定目標的主要依據。

第 10 題

有關給藥醫囑縮寫的意義，下列何者正確？①A.U.是指雙眼 ②A.S.是指左耳 ③S.C.是指「皮下 注射」 ④Q4H表示每天四次
  1. （A）①②
  2. （B）②③
  3. （C）③④
  4. （D）①④

答案：（B）

詳解與考點

正解：本題核對的是給藥醫囑縮寫的正確定義——②A.S.（auris sinistra）指左耳，③S.C.（subcutaneous）指皮下注射，兩者定義皆正確；①A.U.（auris uterque）正確定義是雙耳，而非雙眼（雙眼是O.U.）；④Q4H表示每4小時給藥一次，而非每天四次（每天四次應為QID）。正確的組合是②③，故選B。

A：①②組合中，①A.U.的正確定義是雙耳而非雙眼，故此組合不成立。 C：③④組合中，④Q4H的正確定義是每4小時一次而非每天四次，故此組合不成立。 D：①④組合同時含①與④兩項錯誤定義，故不成立。

本題考點：給藥醫囑縮寫判準——部位類縮寫需分辨「耳／眼」與「左右／雙側」：A.S.（auris sinistra）指左耳，A.U.（auris uterque）指雙耳而非雙眼（雙眼另有專用縮寫O.U.）；時間類縮寫需分辨「間隔小時」與「每日次數」：Q4H是每4小時一次，QID才是每天四次；S.C.（subcutaneous）固定指皮下注射。

第 11 題

Gentamycin®每1 mL含40 mg，若醫囑需要100 mg，則應抽取該藥多少c.c.？
  1. （A）1.0
  2. （B）1.5
  3. （C）2.0
  4. （D）2.5

答案：（D）

詳解與考點

正解：本題是藥物濃度換算計算題——判準是先確認藥物濃度、再以「需要量÷濃度＝抽取量」公式代入。Gentamycin®的濃度為每1 mL含40 mg，醫囑需要100 mg，代入公式：100 mg ÷ 40 mg/mL = 2.5 mL，即抽取2.5 c.c.，故選D。

A：1.0 c.c.對不上任何一種常見的單一計算失誤路徑，屬純數字誘答。 B：1.5 c.c.同樣對不上正解公式的代入結果，屬純數字誘答。 C：2.0 c.c.最接近正解，最可能是把100 mg誤讀成80 mg、或把40 mg/mL的濃度做了估算捨入所致，代入時應逐一核對題幹給定的數字（100 mg、40 mg/mL）以避開此類接近值。

本題考點：藥物抽取量計算判準——公式為「需要量（mg）÷濃度（mg/mL）＝抽取量（mL）」，代入時逐一核對題幹給定的兩個數字（需要量100 mg、濃度每1 mL含40 mg），算出結果後換算為臨床慣用的c.c.單位並核對合理性，可避開因誤讀數字產生的鄰近誘答。

第 12 題

下列何者為適用於鼻胃管灌食的藥物劑型？
  1. （A）舌下錠
  2. （B）口含錠
  3. （C）軟膠囊
  4. （D）口服懸浮劑

答案：（D）

  2. （B）①④
  3. （C）②③
  4. （D）②④

第 21 題

病人中風後左側肢體無力多年，活動量少、無法自己解便，家屬常以甘油球灌腸幫助排便。下列護 理措施何者最適當？

  2. （B）糞便嵌塞時以肥皂水灌腸最有效
  3. （C）每日攝取2,500～3,000 mL的橘子汁
  4. （D）協助以手由左至右順著結腸按摩

詳解與考點

正解：本題問的是排便不規律中風病人的最佳護理策略，判準是能否運用胃結腸反射（gastrocolic reflex）——早餐後結腸蠕動最旺盛，此時協助病人坐在馬桶上，配合重力與自然反射促進排便，是最貼近生理機轉、風險最低的作法，故選 A。

本題考點：排便障礙病人的照護判準——利用胃結腸反射（gastrocolic reflex）安排如廁時機（早餐後）；灌腸非首選且濃度與頻率須節制；腹部按摩方向須順結腸走向（右下→右上→左上→左下）。

答案：（C）

詳解與考點

正解：判準是導尿管管徑選擇需依用途與病人族群調整。泌尿道手術病人執行膀胱灌洗（如三腔 Foley 導管的持續灌洗）需要足夠管徑讓灌洗液暢通流入流出，故通常使用18 Fr.以上的導尿管，故選 C。

A：男性成人一般使用20～22 Fr.導尿管，數值與正確範圍相近容易被誤認為合理，但男性成人常用管徑實為16～18 Fr.，管徑過粗（20～22 Fr.）易造成尿道損傷與不適。

B：兒童使用12～14 Fr.導尿管，錯誤——兒童尿道較細短，導尿管應選用8～10 Fr.，12～14 Fr.對兒童而言偏大。

D：男、女性成人使用相同大小管徑的導尿管，錯誤——女性尿道較男性短且無攝護腺阻力，通常選用較男性細1～2 Fr.的導尿管，兩者管徑並不相同。

本題考點：導尿管管徑選擇的判準——依用途（一般導尿 vs 膀胱灌洗18 Fr.以上）與族群（男性成人16～18 Fr.、女性成人較男性細1～2 Fr.、兒童8～10 Fr.）分別調整，管徑越粗越適合灌洗但也越易造成尿道損傷。

第 23 題

有關協助病人採坐臥姿之敘述，下列何者錯誤？
  1. （A）適用於腹水的病人
  2. （B）適用於腹部大出血病人
  3. （C）需預防病人發生姿位性低血壓
  4. （D）需預防薦骨處受壓

答案：（B）

詳解與考點

正解：判準是坐臥姿（Fowler's position）適應症與禁忌症的對照。坐臥姿使頭部抬高、腹腔壓力下移，適用於腹水病人（可減輕橫膈膜受壓）、心肺疾病病人（促進肺擴張）及術後病人；但腹部大出血病人應採平臥或 Trendelenburg 姿勢以維持腦部灌流，坐臥姿反而使血液滯留下肢、加重休克，故 B「適用於腹部大出血病人」與實際照護原則相反，為應選項。

A：坐臥姿適用於腹水的病人，看似與「腹腔有積液不宜抬高頭部」的直覺相反而容易被懷疑，但正確方向是抬高頭部可減輕橫膈膜受腹水壓迫的程度、改善呼吸，此敘述正確。

C：需預防病人發生姿位性低血壓，正確——坐臥姿使身體由平臥轉為半坐臥或坐姿，血壓易隨姿位改變而下降，須留意監測。

D：需預防薦骨處受壓，正確——坐臥姿時身體重心下移集中於薦骨與坐骨處，是壓瘡好發部位，須加強翻身與減壓。

本題考點：坐臥姿（Fowler's position）的適應症與禁忌症判準——適用腹水、心肺疾病與術後病人以減輕橫膈壓迫、促進肺擴張；腹部大出血或休克病人應採平臥或 Trendelenburg 姿勢維持腦部灌流；照護時須同時預防姿位性低血壓與薦骨受壓。

第 24 題

病人接受心導管檢查後，下列何處是評估下肢血液循環的最佳部位？
  1. （A）膝膕動脈
  2. （B）股動脈
  3. （C）足背動脈
  4. （D）脛後動脈

答案：（C）

詳解與考點

正解：本題問的是心導管檢查後評估下肢血液循環的最佳部位。心導管檢查通常經股動脈（femoral artery）穿刺，術後壓迫止血後，須評估穿刺肢體遠端的血流狀況；足背動脈（dorsalis pedis artery）位置表淺、易於觸及，可直接反映該側下肢末梢的脈搏強度、皮膚溫度與顏色，是臨床評估的標準部位，故選 C。

A：膝膕動脈（popliteal artery）因位置較接近穿刺點所在的大腿，容易被誤認為評估首選，但其位置較深，觸診不若足背動脈方便快速，雖也可用於評估但非臨床首選。

B：股動脈（femoral artery）本身即為心導管穿刺的部位，評估的是穿刺處止血狀況而非遠端末梢循環，兩者評估目的不同。

D：脛後動脈（posterior tibial artery）同樣可作為輔助評估，但不如足背動脈表淺易觸，非臨床首選的標準部位。

本題考點：心導管術後下肢循環評估的判準——穿刺部位在股動脈（femoral artery），評估遠端灌流的標準部位是位置表淺、易觸及的足背動脈（dorsalis pedis artery），膝膕動脈（popliteal artery）與脛後動脈可作輔助但非首選。

第 25 題

關於發燒的類型，下列敘述何者錯誤？
  1. （A）一段時間體溫反覆發燒又回復正常，常見於術後傷口感染
  2. （B）高熱期和退熱期交替出現，常見於肺結核
  3. （C）體溫24小時的波動相差2℃以上，常見於傷寒
  4. （D）24小時的體溫波動範圍，相差不超過1℃，常見於大葉性肺炎

答案：（B）

詳解與考點

正解：本題問的是發燒類型與典型疾病的對應是否正確，判準是各熱型的體溫波動特徵。B「高熱期和退熱期交替出現，常見於肺結核」對應錯誤——高熱期與退熱期交替出現、體溫可降回正常，屬於間歇熱（intermittent fever）的特徵，臨床常見於瘧疾，而肺結核典型呈現的是馳張熱（remittent fever），體溫在24小時內波動超過1℃但不降至正常，故 B 為應選項。

A：一段時間體溫反覆發燒又回復正常，常見於術後傷口感染，正確——此為間歇熱（intermittent fever）的特徵，體溫可回復至正常值，常見於局部感染反覆發炎的情況。

C：體溫24小時的波動相差2℃以上，常見於傷寒，正確——此為馳張熱（remittent fever）中波動幅度更大的表現，符合傷寒等疾病的發燒型態。

D：24小時的體溫波動範圍相差不超過1℃，常見於大葉性肺炎，正確——此為稽留熱（continuous fever）的特徵，體溫持續維持在高檔、波動幅度小，是大葉性肺炎等疾病的典型熱型。

本題考點：發燒熱型判準——間歇熱（intermittent fever，體溫可回復正常）常見於瘧疾與傷口感染等反覆發炎狀況；稽留熱（continuous fever，24小時波動≤1℃）常見於大葉性肺炎；馳張熱（remittent fever，波動>1℃但不降至正常）常見於傷寒（波動可達2℃以上）與肺結核；「高熱期與退熱期交替出現、體溫可降回正常」是間歇熱的特徵，而非肺結核的熱型。

第 26 題

病人雙側手臂因骨折以石膏固定，有關血壓測量的敘述，下列何者正確？
  1. （A）雖然打上石膏，仍可以測量橈動脈血壓
  2. （B）欲測量膝膕動脈時，壓脈帶氣囊應置於大腿中段前側
  3. （C）一般測得的膝膕動脈收縮壓數值較肱動脈數值為低
  4. （D）病人採俯臥姿勢，進行膝膕動脈血壓的測量

答案：（D）

詳解與考點

正解：本題問的是雙側上肢石膏固定病人如何測量血壓，判準是選擇未受石膏遮蓋的部位並採正確姿勢與擺位。雙側上肢石膏固定時橈動脈（radial artery）已遭遮蓋，須改測下肢的膝膕動脈（popliteal artery），病人應採俯臥姿勢（prone position），將壓脈帶置於大腿下段、聽診器置於膝膕窩，即可測得膝膕動脈血壓，故選 D。

A：雖然打上石膏仍可測量橈動脈血壓，錯誤——石膏已遮蓋橈動脈部位，聽診器與壓脈帶均無法貼合該處操作，無法測量。

B：欲測量膝膕動脈時，壓脈帶氣囊應置於大腿中段前側，錯誤——氣囊應置於大腿下段的後側（貼近膝膕窩），而非前側，方向錯誤。

C：一般測得的膝膕動脈收縮壓數值較肱動脈數值為低，「下肢血壓較低」的直覺容易讓人誤判方向而覺得此句合理，但實際上膝膕動脈收縮壓通常較肱動脈高約10～40 mmHg，因下肢肌肉量較多、血管阻力較高，數值應為較高而非較低，分辨關鍵在於血管阻力與肌肉量的差異。

本題考點：肢體受限時血壓測量部位選擇的判準——上肢被石膏遮蓋（橈動脈 radial artery 無法測量）時改測膝膕動脈（popliteal artery），需採俯臥姿勢（prone position）、氣囊置於大腿下段後側；膝膕動脈收縮壓較肱動脈高10～40 mmHg，而非較低。

第 27 題

關於肢體繃帶包紮原則與注意事項，下列何者錯誤？
  1. （A）包紮時應將肢體放低
  2. （B）由遠心端往近心端開始包紮
  3. （C）評估皮膚與循環狀況
  4. （D）骨突處可放置紗布或棉墊

答案：（A）

詳解與考點

正解：本題問的是肢體繃帶包紮的原則何者錯誤，判準是包紮時肢體擺位是否有利於靜脈回流。繃帶包紮時肢體應抬高（而非放低），以促進靜脈回流、減少組織水腫，A敘述「包紮時應將肢體放低」與此原則相反，故為應選項。

B：由遠心端往近心端開始包紮，正確——依循靜脈回流方向由遠端往近端纏繞，有助於推動血液回流，避免遠端腫脹。

C：評估皮膚與循環狀況，正確——包紮前後均須評估皮膚顏色、溫度與末梢脈搏，以確認繃帶鬆緊適當、未壓迫循環。

D：骨突處可放置紗布或棉墊，正確——骨突處直接受壓風險較高，墊上紗布或棉墊可分散壓力、預防皮膚破損。

本題考點：肢體繃帶包紮的判準——肢體須抬高而非放低以利靜脈回流；纏繞方向由遠心端往近心端；包紮前後評估皮膚與循環狀況；骨突處加墊以防壓傷。

第 28 題

  2. （B）正常範圍
  3. （C）體重過重
  4. （D）輕度肥胖

  2. （B）50～70
  3. （C）75～100
  4. （D）110～120

正解：本題是高蛋白飲食蛋白質攝取量的計算題，判準是依體重換算每公斤所需公克數。高蛋白飲食適用於感染、術後、組織修復等高代謝狀態，一般成人蛋白質需求為每公斤體重0.8 g/day，高蛋白飲食則提升至1.5～2 g/kg/day。代入本題體重50公斤：50 kg × 1.5 g/kg = 75 g，50 kg × 2 g/kg = 100 g，故一天應攝取75～100 g，選 C。

第 30 題

剛接受完手術病人，促進蛋白質合成及組織修復對病人特別重要，此作用發生於睡眠週期的那一 期？
  1. （A）NREM第四期
  2. （B）NREM第三期
  3. （C）NREM第二期
  4. （D）NREM第一期

答案：（A）

詳解與考點

正解：本題問的是術後病人促進蛋白質合成與組織修復的作用發生於睡眠週期哪一期，判準是各期睡眠對應的生理功能。NREM第四期（深睡期，現稱N3期）是睡眠最深沉的階段，此期生長激素（GH）大量分泌，促進蛋白質合成、組織修復與細胞再生，對術後病人的恢復最為關鍵，故選 A。

B：NREM第三期同屬慢波睡眠、與第四期相鄰而容易被混淆，但其深度不及第四期，生長激素分泌與組織修復效果不如第四期顯著。

C：NREM第二期為較淺層的睡眠階段，主要與睡眠紡錘波、記憶鞏固等功能相關，非促進組織修復的關鍵期。

D：NREM第一期是入睡初期最淺層的過渡階段，僅為由清醒進入睡眠的短暫過渡，與組織修復無直接關聯。

本題考點：睡眠分期與生理功能的判準——NREM第四期（深睡期／N3期）生長激素（GH）大量分泌、促進蛋白質合成與組織修復，是術後恢復的關鍵期；愈淺層的NREM分期（第一、二、三期）愈偏向入睡過渡或記憶鞏固等其他功能；REM期則主要與作夢及記憶處理相關，同樣非組織修復的關鍵期。

第 31 題

協助病人移位時，為能省時省力及避免護理人員受到傷害，下列何者最不適當？
  1. （A）搬運病人時，雙腳分開站立、髖部與膝關節微彎
  2. （B）移動病人時，護理人員應面對將移動的部位
  3. （C）儘量不要使用腰背部肌肉施力
  4. （D）身體重心應遠離病人，以防跌倒

答案：（D）

詳解與考點

正解：本題問的是協助病人移位時何者最不適當，判準是省時省力的人體力學原則。身體重心應靠近病人而非遠離，才能縮短力臂、減少施力並維持平衡；D「身體重心應遠離病人，以防跌倒」違反此力學原則，重心遠離病人反而增加施力負擔並提高護理人員自身跌倒或受傷的風險，故為應選項。

本題考點：協助病人移位的省力力學判準——擴大站立支撐面、髖膝微彎；面對移動方向避免脊椎扭轉；以下肢而非腰背肌肉施力；身體重心應靠近病人以縮短力臂，而非遠離病人。

面臨末期病人即將離世，有關家屬哀傷支持之敘述，下列何者最適當？
  1. （A）家屬減少探視，有助於漸進去除依附，減低分離焦慮
  2. （B）家屬在病人逝世後，開始進入哀傷歷程
  3. （C）家庭關係動態評估，有助於辨識需哀傷支持者
  4. （D）家屬與病人宜避免互表感受，以免加深哀傷情緒

答案：（C）

詳解與考點

正解：本題問的是末期病人家屬哀傷支持何者最適當，判準是能否及早辨識高風險哀傷者並提供個別化支持。家庭關係動態評估能協助辨識情感依附強、家庭衝突未解等哀傷風險較高的家屬，進而提供針對性的支持，是最適當的哀傷支持措施，故選 C。

A：家屬減少探視有助於漸進去除依附、減低分離焦慮，錯誤——減少探視反而阻斷家屬與病人間的情感連結與道別機會，不利於健康的哀傷歷程。

B：家屬在病人逝世後才開始進入哀傷歷程，看似合乎時序直覺，但預期性哀傷（anticipatory grief）在末期病人逝世前即已開始，並非逝世後才啟動，此敘述與哀傷歷程的實際進程不符。

D：家屬與病人宜避免互表感受以免加深哀傷情緒，錯誤——鼓勵家屬與病人適度表達彼此感受，有助於完成未竟事務、促進健康的哀傷調適，避免表達反而可能造成日後未解的遺憾與病態性哀傷。

本題考點：末期病人家屬哀傷支持的判準——預期性哀傷（anticipatory grief）於逝世前即已開始；家庭關係動態評估可辨識高風險哀傷者；鼓勵維持探視與情感表達，而非阻斷依附或迴避互表感受。

第 34 題

食道癌末期病人，僅能進食少量液體食物，不願意採用鼻胃管灌食或者腸道外營養治療，兒子認為 這樣下去病人會因飢餓死亡，心理無法接受，期待以更積極方式協助進食，下列措施何者最適當？
  1. （A）提供高熱量流質食物並鼓勵少量多餐
  2. （B）鼓勵病人使用胃造口進行灌食，以免兒子擔心
  3. （C）與醫師討論建議病人執行腸道外營養治療
  4. （D）請兒子與病人溝通以確認要採用何種方式進食

答案：（A）

詳解與考點

正解：本題問的是病人已表達拒絕鼻胃管灌食與腸道外營養、家屬期待更積極介入時的最適當措施，判準是在尊重病人自主意願（《安寧緩和醫療條例》所揭示的自主原則）的前提下，同時兼顧基本營養支持與家屬心理需求。提供高熱量流質食物並鼓勵少量多餐，既未違反病人已表達的意願，又能在病人能耐受的範圍內盡量維持營養攝取，協助兒子理解已盡力維持營養，故選 A。

B：鼓勵病人使用胃造口進行灌食以免兒子擔心，錯誤——胃造口屬侵入性介入方式，違反病人已表達拒絕鼻胃管灌食等積極營養介入的意願，不應為緩解家屬擔憂而執行違反病人自主意願的措施。

D：請兒子與病人溝通以確認要採用何種方式進食，看似顧及家庭溝通與共識，但病人的進食意願已在題幹中明確表達，此選項並未直接回應「如何在尊重病人意願下提供最適當進食協助」這個護理問題，不是最適當的措施。

本題考點：末期病人自主意願的照護判準——依《安寧緩和醫療條例》尊重病人已明確表達的拒絕（鼻胃管灌食、腸道外營養、胃造口等積極介入）；在病人可接受的範圍內提供高熱量流質、少量多餐等舒適取向的營養支持；照護措施須同時回應病人自主權與家屬心理需求，而非僅以家屬期待為依歸。

  2. （B）375

  4. （D）500

正解：本題問的是把月薪換算成每分鐘（或每小時）人力成本、再乘以活動所耗時間——判準是先求單位時間成本，逐步演算：每小時成本 = 45,000 元 ÷ 180 小時 = 250 元/小時；90 分鐘 = 1.5 小時；1.5 小時 × 250 元/小時 = 375 元，故選 B。

第 38 題

  2. （B）護理管理業務電腦化，如排班、庫存管理、考核等，強調數字會說話
  3. （C）推行護理工作標準化，參照時間與動作的研究結果，進行業務的改善
  4. （D）為維持單位正常運作，可依護理人力狀況，彈性調整護理管理模式

答案：（C）

詳解與考點

正解：判準是辨識「科學管理理論（scientific management）」的核心方法——泰勒（Taylor）主張以工時動作研究（time and motion study）分析標準化作業流程來提升效率。C 選項「推行護理工作標準化，參照時間與動作的研究結果進行業務改善」直接對應此核心方法，故選 C。

A：層級分明、每位員工有一位直屬主管、權責對等分工明確，描述的是官僚式（bureaucratic）行政管理理論的組織特徵，而非科學管理理論的核心。 B：護理管理業務電腦化、強調數字化管理，屬於資訊管理的範疇，與科學管理理論的時間動作研究方法不同。 D：依人力狀況彈性調整管理模式，對應的是情境領導（situational leadership）的概念，強調因應情境調整而非標準化流程。

本題考點：管理理論的辨識判準——科學管理理論（Taylor）以工時動作研究為核心、追求標準化流程；須與官僚式（層級分工）、資訊管理（電腦化）、情境領導（彈性調整）等相近但本質不同的理論區辨。

第 39 題

決策者預測不利後果情況下，從眾多方案中選擇危害最小的方案，此種決策策略是屬於下列何者？
  1. （A）滿意性策略
  2. （B）最少缺憾性策略
  3. （C）最小極限性策略
  4. （D）樂觀性策略

答案：（C）

詳解與考點

正解：判準是題幹描述的決策情境——「預測會出現不利後果」加上「從眾多方案中挑選危害最小者」，這是一種保守、避免最壞結果的決策取向，對應「最小極限性策略」（在悲觀預期下追求損害極小化、即小中取小或最壞情況最佳化的思維），故選 C。

A：滿意性策略指選取第一個達到可接受標準的方案即停止搜尋，未必追求危害最小化，與題幹「從眾多方案中挑選危害最小」的描述不同。 B：最少缺憾性策略著重於事後「後悔／缺憾」的極小化，即比較各方案結果與最佳結果的落差、選後悔最小者，是與正解最接近的策略，分辨關鍵在於題幹講的是「直接挑危害最小的方案」，而不是「事後比較後悔程度」。 D：樂觀性策略假設會出現有利結果、傾向追求最大利益，與題幹「預測不利後果」的前提相反。

本題考點：決策策略的辨識判準——先看決策者對後果的預期是樂觀或悲觀，悲觀預期下若直接挑危害最小的方案為最小極限性策略，若著重事後後悔程度的比較則為最少缺憾性策略，兩者判準不同不可混淆。

正解為（D）。哺乳中的受僱者於工作時間內應另給予哺（集）乳時間：依現行法令，子女未滿 2 歲須親自哺乳者，雇主除規定之休息時間外，每日應另給哺（集）乳時間，且每日 60 分鐘、可分次使用、並視為工作時間。（D）「每日上班時間另給與擠乳 2 次、每次 30 分鐘」合計 60 分鐘、且於上班時間內另行給予，最符合此規定，故選（D）。（A）僅利用午餐休息時間擠乳、（B）僅讓其自行安排休息時間、（C）以「多補 1 小時時數」方式處理，均未正確落實「於工作時間內另給予且視為工作時間的哺乳時間」之要求，故不適當。補充：哺（集）乳時間（子女未滿 2 歲、每日 60 分鐘並視為工時）規定於《性別平等工作法》；《勞動基準法》第 52 條規範的是子女未滿 1 歲的「哺乳時間」（每日 2 次、每次 30 分鐘），兩者法源與適用年齡不同，作答時以「每日另給 60 分鐘且視為工作時間」之精神判斷，選（D）。

  2. （B）要傳達的訊息是必須的
