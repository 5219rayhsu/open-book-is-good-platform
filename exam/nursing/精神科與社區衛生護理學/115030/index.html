第 1 題

吳小姐，24歲，碩士生，單親家庭，因應疫情返家遠距學習，在家期間與母親朝夕相處備感壓力。返診時對護理師說:「我坐在房間窗邊會想，如果跳下去會怎樣？」，根據同理心的原則，下列何項護理師的回應最適切？
  1. （A）「請問你住幾樓？」
  2. （B）「你有不想再活下去的念頭嗎？」
  3. （C）「你還很年輕，人生才要開始。」
  4. （D）「等疫情降級跟媽媽分開來住，這種情況就會改善。」

答案：（B）

詳解與考點

本題問依同理心原則最適切的回應，答案為 B。當個案透露「如果跳下去會怎樣」這類疑似自殺意念的訊息時，最適切的做法是以同理、直接而不迴避的方式確認其自殺意念，「你有不想再活下去的念頭嗎？」正是直接澄清自殺想法、開啟後續風險評估的回應，並能讓個案感到被理解，故 B 正確。A 錯誤：「請問你住幾樓？」聚焦於方法／工具，顯得冷漠且未回應其情緒，缺乏同理。C 錯誤：「你還很年輕，人生才要開始」屬說教與否定其感受，會讓個案覺得不被理解。D 錯誤：「等疫情降級分開住就會改善」是提早給保證與建議，忽略當下的自殺風險與情緒。需澄清：B 為直接確認自殺意念的封閉式探問；確認意念後，再依評估自殺計畫的明確性、致命性、工具可近性與獲救可能等面向進行風險分級。

第 2 題

向精神病人和家屬說明電痙攣療法對憂鬱症的療效和治療過程，讓他們可以充分了解後再決定簽署同意書，此時醫療人員是秉持下列那一項倫理原則？
  1. （A）自主原則
  2. （B）不傷害原則
  3. （C）誠實原則
  4. （D）公平原則

答案：（A）

詳解與考點

在進行電痙攣療法（ECT）前，向病人與家屬充分說明療效與過程，讓他們在知情狀態下自主決定是否簽署同意書，此即尊重病人自主選擇的自主原則（autonomy principle）。此過程並非誠實原則（C，誠實著重不欺騙），而是以知情同意為核心，強調賦予決策權，故答案為A。

第 3 題

黃小姐，診斷為思覺失調症，擔心一星期後即將出院返家。下列何項護理措施最適切？
  1. （A）加強黃小姐服用情緒穩定劑的劑量
  2. （B）要黃小姐安心等待出院
  3. （C）陪伴安撫黃小姐不安的情緒
  4. （D）建議延後黃小姐出院日期

答案：（C）

詳解與考點

思覺失調症病人出院前出現焦慮不安，是常見的預期性焦慮反應。最適切護理措施為陪伴與情緒支持（C），讓病人感受到安全感。加重情緒穩定劑劑量（A）無臨床依據；要病人「安心等待」（B）忽略情緒；延後出院（D）非立即處置且可能強化依賴，均不如直接情緒支持適當。

第 4 題

病人是20歲大學重考生，從小備受呵護寵愛長大，個性內向順從，成績中等。指考失利後，出現心情低落、胃口差、失眠等症狀，醫師診斷為鬱症，住院治療 2 週後，父母認為病人需要重回補習班接受鞭策，因此辦理自動出院，病人出院後出現自殺企圖。下列敘述何者最適宜？
  1. （A）大學考試失敗是生病的潛在因素（predisposing factor）
  2. （B）從小個性內向順從是生病的促發因素（precipitating factor）
  3. （C）父母的照護能力是生病的續存因素（perpetuating factor）
  4. （D）成長過程受寵愛呵護是生病的促發因素（precipitating factor）

答案：（C）

詳解與考點

促發因素（precipitating factor）指直接觸發疾病的近端事件，潛在因素（predisposing factor）指遠端背景脆弱性，續存因素（perpetuating factor）指維持疾病持續的現存條件。父母認為需回補習班「鞭策」而提前辦理出院，使病人在治療未完整時返回壓力環境，此為使憂鬱症與自殺風險持續存在的條件，故屬續存因素（C）。指考失敗是促發因素，個性內向是潛在因素。

第 5 題

有關老人憂鬱症的敘述，下列何者錯誤？
  1. （A）是老年人口中罕見的疾病
  2. （B）自殺是憂鬱症最具潛在性致命因素
  3. （C）會抱怨認知障礙
  4. （D）常訴說身體症狀而忽略情緒症狀

答案：（A）

詳解與考點

老年憂鬱症實為老年族群中相當常見的心理健康問題，並非罕見疾病，因此A「罕見」為錯誤敘述。老年憂鬱常以身體抱怨表現、認知障礙感、失眠等為主訴，情緒低落反而較不突顯；自殺風險確實高（B）；認知抱怨（C）及身體症狀掩蓋情緒症狀（D）均為老年憂鬱特點。

第 6 題

有關第一代抗精神病藥物之敘述，下列何者正確？
  1. （A）主要作用機轉是來自於多巴胺受體的促進作用
  2. （B）抗精神病作用越強的藥物，其鎮靜作用較低
  3. （C）抗精神病作用越強的藥物，其錐體外徑副作用越低
  4. （D）相較於haloperidol，chlorpromazine較會靜坐不能

答案：（B）

詳解與考點

第一代（典型）抗精神病藥物以多巴胺D2受體阻斷為主要機轉，並非促進（A錯）。效價（potency）越高的藥物（如haloperidol），鎮靜效果越低（B正確）、錐體外徑副作用（EPS）越高（C錯）。Chlorpromazine效價低、鎮靜強、EPS較少，靜坐不能（akathisia）在高效價如haloperidol更常見（D錯）。

第 7 題

根據團體治療型態的定義及目標，鼓勵成員在團體中用言語表達，並探討個人現在與過去情境中，情緒或心理上的問題，以增進成員的人格重建或行為型態之修正與調適。屬於下列何種團體治療？
  1. （A）健康指導團體
  2. （B）會心團體
  3. （C）娛樂治療團體
  4. （D）生物回饋團體

答案：（B）

詳解與考點

題目描述的治療型態重點是：言語表達、探討個人情緒與心理問題、目標為人格重建或行為修正，此為心理治療性團體的核心，即「會心團體（encounter group）」（B）。健康指導團體以衛教為主；娛樂治療著重活動參與；生物回饋以生理訊號訓練為主，均與描述不符。

第 8 題

有關家庭結構評估，下列何者屬於內在結構？
  1. （A）文化
  2. （B）次系統
  3. （C）社經地位
  4. （D）宗教

答案：（B）

詳解與考點

Wright與Leahey的家庭評估模式將家庭結構分為內在結構（次系統、界限、排列、權力階級）與外在結構（大家庭、社區）及情境脈絡（文化、宗教、社經地位）。次系統（B，如夫妻、親子）屬內在結構；文化（A）、社經地位（C）、宗教（D）屬情境脈絡，非內在結構。

第 9 題

有關思覺失調症病因之描述，下列何項正確？①負性症狀主要與多巴胺活動量過高有關 ②父母為高情緒表達且互動僵化 ③其發病與遺傳因素有相關 ④病人的自我（ego）功能異常
  1. （A）①②③
  2. （B）①②④
  3. （C）①③④
  4. （D）②③④

答案：（D）

詳解與考點

思覺失調症病因中：①負性症狀主要與多巴胺活動量「不足」（前額葉）有關，非過高（過高與正性症狀有關），故①錯誤。②高情緒表達（high EE）家庭與復發有關為正確；③遺傳因素有相關為正確；④自我（ego）功能異常（如現實測試、整合能力）為精神分析觀點，亦正確。故②③④均正確，答案為D。

第 10 題

有關病人保護約束隔離期間的護理措施，下列何者正確？
  1. （A）每30分鐘觀察病人狀況
  2. （B）滿足基本生理需求
  3. （C）不需要醫囑
  4. （D）打開監視器觀察，不須現場探視

答案：（B）

詳解與考點

保護約束隔離期間，最重要的護理原則是持續滿足病人基本生理需求（B），如飲水、如廁、體位變換，確保安全與尊嚴。觀察頻率應至少每15分鐘一次（非30分鐘，A錯）；需要醫囑（C錯）；需現場直接探視而非只看監視器（D錯）。

第 11 題

謝先生，診斷為雙相情緒障礙症，因要求外出抽菸未獲同意，在病室內摔東西。下列何項護理措施最適宜？
  1. （A）以嚴厲語氣制止病人
  2. （B）引導病人用言語表達憤怒
  3. （C）立即告知會延後病人出院的日期
  4. （D）直接將病人約束

答案：（B）

詳解與考點

雙相情緒障礙症病人因需求未被滿足而出現摔東西的憤怒行為，最適切處置是引導以語言表達憤怒（B），有助情緒疏洩且建立溝通模式。嚴厲制止（A）可能升高衝突；以延後出院威脅（C）帶有懲罰性質且不符倫理；立即約束（D）應為最後手段，尚無傷人行為時不宜優先採用。

第 12 題

有關被害妄想的護理措施，下列何者最適切？
  1. （A）積極與病人互動
  2. （B）頻繁評估其妄想內容
  3. （C）採被動友善方式接近病人
  4. （D）做任何護理技術時不需要額外解釋

答案：（C）

詳解與考點

有被害妄想的病人對接近者高度警覺，積極互動（A）易引發防衛；頻繁評估妄想內容（B）可能強化妄想系統；執行護理技術不解釋（D）更會引發恐懼。最適切做法是採被動友善方式接近（C）：保持非侵入性、穩定且可預期的態度，讓病人逐步建立安全感。

第 13 題

林先生，躁症發作（manic episode）住院，在病房客廳對著病友們滔滔不絕的批判醫護人員、醫院設施，並表示要投訴媒體。下列何項最適宜此時護理處置？
  1. （A）將林先生帶開，陪伴參加病房歌唱活動
  2. （B）轉知被批判的醫護人員，改善對林先生的態度
  3. （C）持續傾聽林先生的抱怨，並給予肯定
  4. （D）提供事實，澄清林先生所批判內容

答案：（A）

詳解與考點

躁症發作病人在公共場所大聲批評、影響他人，最優先處置是轉移環境（A）：將其帶離公共區域、提供結構化活動（歌唱），可降低刺激、減少衝突擴大。持續傾聽肯定（C）會強化躁症行為；澄清批判內容（D）可能引發辯論；轉知被批判的醫護改善態度（B）無治療依據。

第 14 題

吳先生，診斷為思覺失調症，近期被害妄想嚴重，拒絕服藥，因擔心鄰居窺看，將所有窗戶都貼上牛皮紙。下列何項居家護理處置最適切？
  1. （A）通知警察強制送醫
  2. （B）與居家治療團隊討論處置
  3. （C）建議病人搬家
  4. （D）教導鄰居自我安全防護

答案：（B）

詳解與考點

思覺失調症居家個案出現被害妄想加重、拒絕服藥，屬病情不穩需多專業介入，最適切做法是與居家治療團隊（精神科醫師、社工、護理師）討論整合性處置（B）。直接通知警察強制送醫（A）應在有立即危險時才採用；建議搬家（C）無助病情；教導鄰居自我防護（D）完全偏離護理重點。

第 15 題

恐慌症（panic disorder）的病人在至少一次恐慌發作後，最有可能會出現下列何種情況？
  1. （A）更加減少對自己身體感受的關注程度
  2. （B）試圖忽略對下一次發作的擔憂
  3. （C）時常出現解離症狀，以減少現實情境中的恐慌發作
  4. （D）避免現身不熟悉的情境，以免恐慌發作

答案：（D）

詳解與考點

DSM-5 恐慌症的核心特徵除恐慌發作本身外，還包括「預期性焦慮」與「適應不良的行為改變」，尤其是逃避不熟悉或被認為可能無法逃脫的情境（D），以防止恐慌再發作。病人通常會「增加」對身體感受的關注（A錯）、無法忽略下次發作的擔憂（B錯）；解離症狀（C）不是恐慌症的典型應對機制。

第 16 題

有關人格障礙症的敘述，下列何者最適切？
  1. （A）妄想型人格障礙症病人總是選擇孤單的活動
  2. （B）邊緣型人格障礙症病人常見有不穩定的人際關係及明顯的衝動性
  3. （C）孤僻型人格障礙症病人常見具有強烈的自大，對他人缺乏同理心
  4. （D）依賴型人格障礙症病人常見漠視且侵犯他人權益的行為

答案：（B）

詳解與考點

邊緣型人格障礙症（BPD）的核心特徵即不穩定的人際關係、衝動性、情緒不穩定及自我傷害行為（B正確）。妄想型人格障礙症偏好孤獨活動的是「孤僻型（schizoid）」而非妄想型（A錯）；自大與缺乏同理心屬自戀型（C錯）；漠視侵犯他人權益屬反社會型，非依賴型（D錯）。

第 17 題

林先生經歷暴雨過後家園遭遇土石流，目睹父親死亡，倖存後被診斷為創傷後壓力症（posttraumatic stress disorder），每當下起大雨或看到土石流的新聞，林先生最不可能出現下列何種反應？
  1. （A）過度的悲痛與罪惡感
  2. （B）人際疏離，無法感受到快樂
  3. （C）失眠、反覆的噩夢
  4. （D）經常重返事故地點

答案：（D）

詳解與考點

PTSD 的核心症狀包括：重複體驗（噩夢、閃回）、逃避（人際疏離、迴避相關刺激）、負向認知/情感（罪惡感、無法感受快樂）、過度警覺（失眠）。「經常重返事故地點」（D）與PTSD的逃避症狀相反，PTSD患者會主動迴避觸發刺激的地點，故D最不可能出現。

第 18 題

有關愷他命（ketamine）的敘述，下列何者錯誤？
  1. （A）在醫學上是用於手術麻醉
  2. （B）容易罹患急性膀胱間質炎
  3. （C）常見中毒症狀是心搏過速、震顫、噁心嘔吐
  4. （D）ketamine屬於第三級毒品

答案：（B）

詳解與考點

愷他命（ketamine）長期濫用最典型的泌尿道傷害為「間質性膀胱炎（interstitial cystitis）」，常稱為「K他命膀胱」，並非急性膀胱間質炎，且通常是慢性破壞性病變而非「急性」（B錯誤）。醫學上用於麻醉（A正確）；心搏過速、震顫、噁心嘔吐為常見中毒症狀（C正確）；台灣法規列為第三級毒品（D正確）。

第 19 題

小華的媽媽抱怨，小華很聰明、人緣好，但就是認字很差，文章表達不清楚。下列何項是小華最可能出現的診斷？
  1. （A）抽搐症
  2. （B）行為規範障礙症
  3. （C）閱讀障礙症
  4. （D）自閉症

答案：（C）

詳解與考點

第 30 題

有關篩檢工具信度（reliability）與效度（validity）的敘述，下列何者最不適當？
  1. （A）信度是指測量結果的一致性、穩定性及可靠性
  2. （B）信度很高的工具，其效度一定高
  3. （C）陽性預測值與陰性預測值會受到疾病盛行率的影響
  4. （D）效度是視工具的特異度（specificity）及敏感度（sensitivity）來決定

答案：（B）

詳解與考點

「信度高效度一定高」此敘述最不適當。信度（reliability）衡量一致性；效度（validity）衡量準確性。工具可以非常穩定地測出錯誤結果（高信度、低效度）；反之效度高者信度必高。陽性/陰性預測值受盛行率影響，效度由敏感度與特異度決定，兩者均正確，故最不適當為 B。

有關家庭的成長性和情境性危機敘述，下列何者正確？①成長性危機通常是可預測的 ②情境性危機是專指負向事件 ③中頭彩可能造成家庭的情境性危機 ④外派進修屬成長性危機
  1. （A）①②
  2. （B）①③
  3. （C）②③
  4. （D）②④

答案：（B）

詳解與考點

本題問正確敘述的組合，答案為 B（①③）。①正確：成長性（發展性）危機與家庭生命週期、發展任務相連結（如結婚、生子、子女離家、退休等），多為「可預測」的人生轉換。③正確：中頭彩屬非預期的突發事件，即使是正向事件，也可能打破家庭原本的平衡而造成「情境性危機」，故③正確。②錯誤：情境性危機是指非預期、突發的事件所引發，並「不專指負向事件」，正向重大事件（如中獎、升遷）同樣可能造成情境性危機。④錯誤：外派進修屬於非預期、與特定情境相關的壓力事件，較偏向「情境性危機」，而非與家庭發展任務相連結的成長性危機。綜合①③正確，選 B。

第 41 題

有關提升原住民慢性病健康照護政策之敘述，下列何者最不適當？
  1. （A）運用三段五級概念避免及延緩慢性病患者失能發生、壓縮失能的期間
  2. （B）運用部落社區特性進行社區健康營造
  3. （C）提供兼具文化傳承的健康飲食課程
  4. （D）成立原住民族文化健康站，服務45歲以上健康、亞健康、衰弱、輕度失能原住民

答案：（D）

第 42 題

護理師家訪就讀國小二年級被判定體重肥胖的大明，發現全家皆有體位異常問題，目前大明母親懷孕8個月，護理師與大明及其父母一起討論如何協助家庭成員維持正常體位。下列敘述何者最不適當？
  1. （A）鼓勵大明的父母修正全家的生活型態，以體重控制為主要目標
  2. （B）鼓勵大明由目前的體位漸進式減重，每個月0.5公斤為限
  3. （C）建議大明母親在產後三個月起停止母乳哺餵，以免導致嬰兒體重過重
  4. （D）衛教大明父母親須留意大明的身體心像

答案：（C）

詳解與考點

哺餵母乳可降低嬰兒日後肥胖風險，且 WHO/國健署建議純母乳哺餵至少六個月，不應為「避免嬰兒體重過重」而建議停止母乳。選項 C「產後三個月停止母乳」既違反哺育建議，也無科學根據，為最不適當敘述。答案為 C。

第 43 題

有關葡萄糖-6-磷酸鹽去氫酶（G-6-PD）的護理指導，下列何者錯誤？

  2. （B）避免使用萘丸
  3. （C）避免食用蠶豆及其製品
  4. （D）感染時以磺胺類藥物治療為首選

答案：（D）

G-6-PD 缺乏症（蠶豆症）患者使用磺胺類（sulfonamides）藥物會誘發溶血性貧血，屬禁忌用藥，非「首選」。應避免磺胺類、解熱鎮痛劑（如阿斯匹靈）、萘丸及蠶豆製品。感染治療需選擇對 G-6-PD 缺乏者安全之抗生素。答案 D 為錯誤敘述。

  2. （B）提供個案共餐等長照預防服務
  3. （C）提供失智個案申請外籍照顧服務員

第 47 題

有關出院準備服務的特性，下列何者最不適當？
  1. （A）是持續照護體系中重要的轉銜機制
  2. （B）是以機構為中心的照護模式
  3. （C）需要各醫療照顧等專業團隊共同參與
  4. （D）入院即為出院準備的開始

答案：（B）

詳解與考點

出院準備服務（discharge planning）是以「病人/個案為中心」的跨團隊轉銜機制，並非以機構為中心。其特性包含：入院即啟動、多專業參與、連接院內外持續照護。「以機構為中心」違背出院準備以病人需求為核心之精神，為最不適當，答案為 B。

第 48 題

依據老人福利機構設立標準，有關長期照顧機構類型及照護對象，下列敘述何者最適當？
  1. （A）失智照顧型機構是提供中度失智以上具行動能力且需受照顧者
  2. （B）安養機構僅提供自我照顧缺失老人照護
  3. （C）日間照顧是提供全天候的照顧服務
  4. （D）養護型機構提供具足夠生活自理能力之老人照護

答案：（A）

詳解與考點

本題問最適當的敘述，答案為 A。依老人福利機構設立標準，失智照顧型機構（長照機構中的失智照顧型）係收容「中度以上失智、具行動能力且需照顧」之長者，提供以家庭化、單元照顧為原則的服務，故 A 正確。B 錯誤：安養機構並非「僅」提供自我照顧缺失者，其主要收容對象為生活可自理、不需特別照護而需安養之長者，敘述與其定位不符。C 錯誤：日間照顧是「日間」（白天）提供照顧、晚上返家，並非「全天候」的照顧服務。D 錯誤：養護型機構收容的是生活自理能力「缺損、需他人照顧但無技術性護理需求」之長者，並非「具足夠生活自理能力」者，敘述相反。綜上以 A 最適當。

第 49 題

有關糖尿病的足部護理，衛生護理師應建議個案避免下列那些習慣？①穿拖鞋外出 ②每日用溫水泡腳10分鐘 ③睡覺時用電毯或熱水袋保暖足部 ④使用中性肥皂清洗足部
  1. （A）①②
  2. （B）②③
  3. （C）①③
  4. （D）②④

答案：（C）

詳解與考點

本題問糖尿病足部護理應「避免」的習慣，答案為 C（①③）。①應避免：糖尿病患者末梢感覺神經病變，赤足或穿拖鞋外出易因看不見的碰撞、異物刺傷而受傷又不自覺，增加足部潰瘍與感染風險，故應避免。③應避免：因感覺遲鈍，使用電毯或熱水袋保暖足部極易造成低溫燙傷而不自知，應嚴格避免任何直接熱源；保暖宜改穿襪子。②④為正確的足部護理：②以溫水（須先以手肘或溫度計測試水溫、避免過熱）短時間清潔足部、洗後徹底擦乾（尤其趾縫）是適當的；④使用中性肥皂清洗足部、避免刺激性清潔劑，亦為正確做法。故應避免者為①③，選 C。

第 50 題

有關代謝症候群及其健康照護的敘述，下列何者最適當？
  1. （A）最主要的原因是遺傳因素
  2. （B）是一群容易導致心血管代謝疾病的危險因子之總稱
  3. （C）三低健康飲食是指低油、低糖、低纖
  4. （D）罹患糖尿病者經藥物控制良好，即不屬之

答案：（B）

詳解與考點

代謝症候群是一群同時存在的心血管代謝危險因子（腹部肥胖、血脂異常、高血壓、高血糖）之總稱（B 正確）。主因為後天生活型態（飲食、運動），非主要遺傳因素（A 錯）；健康飲食為低油、低糖、高纖（非低纖，C 錯）；糖尿病用藥控制良好仍屬代謝症候群範疇（D 錯）。答案為 B。
