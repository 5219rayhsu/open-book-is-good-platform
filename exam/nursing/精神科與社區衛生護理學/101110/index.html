第 1 題

精神分裂症的 5 種主要症候群，除正性症狀、負性症狀外，尚包括那 3 種？①認知缺損 ②人格違常 ③情緒障礙 ④社會和職業功能障礙
  1. （A）①②③
  2. （B）②③④
  3. （C）①②④
  4. （D）①③④

答案：（D）

詳解與考點

正解：題眼在思覺失調症的主要症候群，題目已給正性與負性症狀，另三類應是認知缺損、情緒障礙、社會與職業功能障礙。故①③④成立，組合為（D）①③④，故選 D。

A：②人格違常不是本題分類中的主要症候群，故含②即錯。

B：同樣含②，且漏掉①認知缺損，故非答案。

C：含②而漏掉③情緒障礙，故錯誤。

本題考點：思覺失調症（schizophrenia）可呈正性症狀、負性症狀、認知缺損、情緒症狀及功能障礙；認知缺損（cognitive impairment）影響注意、記憶與執行功能；社會職業功能（social and occupational functioning）是疾病評估的重要面向。

第 2 題

護理師詢問病患：「兩全其美的意義」，是在評估病患那一方面的能力？
  1. （A）判斷力
  2. （B）定向力
  3. （C）記憶力
  4. （D）抽象思考

答案：（D）

詳解與考點

正解：題眼在要求病人說明「兩全其美」的意義。成語含義不是記憶原句或確認時地人物，而是把具體語句轉化為抽象概念的能力，故評估的是（D）抽象思考，故選 D。

A：判斷力是評估人在情境中能否作出合宜決定，例如遇到危險時如何處置，與解釋成語不同。

B：定向力評估人、時、地等現實辨識，非本題能力。

C：記憶力評估立即、近程或遠程資訊保留，並非成語意義的概念化。

本題考點：精神狀態檢查（mental status examination）包含認知功能評估；抽象思考（abstract thinking）可用成語解釋測試；定向力（orientation）與記憶力（memory）為不同認知面向。

第 3 題

對於躁症發作（manic episode）之症狀，下列何者最為正確？
  1. （A）感覺無助
  2. （B）睡眠需求增加
  3. （C）比平時多話或被迫一直說不停（pressured speech）
  4. （D）思考停頓（thought blocking）

答案：（C）

詳解與考點

正解：題眼在躁症發作的核心活化症狀。躁症常見情緒高昂或易怒、活動增加、睡眠需求減少、意念飛躍與語量增加；（C）比平時多話或被迫一直說不停正是壓迫性言語，故選 C。

A：感覺無助較常見於憂鬱狀態，與躁症的擴張或易怒情緒不符。

B：躁症通常是睡眠需求減少而非增加。

D：思考停頓較常見於思覺失調症的思考障礙；這是最強誘答，因它同樣是精神症狀，卻非躁症典型的「思考加速」方向。

本題考點：躁症發作（manic episode）表現為活動與語言增加、睡眠需求減少；壓迫性言語（pressured speech）是持續且難以打斷的多話；思考停頓（thought blocking）須與躁症的意念飛躍區辨。

第 4 題

下列關於護理師對服用抗憂鬱劑的衛教，何者正確？①服用 Moclobemide（Aurorix），不可吃含有 酪胺酸（Tyramine）的食物，例如乳酪 ②避免空腹服用 Fluoxetine（Prozac） ③服用 Imipramine （Tofranil）出現口乾時，可少量多次喝水 ④因為 Trazodone（Mesyrel）同時有助眠的效果，不宜 白天服用
  1. （A）②③④
  2. （B）①②③
  3. （C）①②④
  4. （D）①③④

答案：（A）

詳解與考點

正解：題眼在抗憂鬱劑衛教的四個子敘述，需逐一核對藥理特性與服用時機。②避免 Fluoxetine 空腹服用可減少腸胃不適；③Imipramine 的抗膽鹼作用致口乾，可少量多次飲水；④Trazodone 具鎮靜助眠效果，通常安排於夜間服用。②③④成立，組合為（A）②③④，故選 A。

B、C、D：三組都含①，故均錯。①錯在 Moclobemide 屬可逆性單胺氧化酶 A 抑制劑（RIMA），酪胺可與之競爭而使酵素抑制解除，因此不像傳統不可逆型 MAOI 需嚴格禁食乳酪等高酪胺食物；這是最強誘答——考生一看到 MAO 抑制劑就直接套用高酪胺飲食禁忌，分辨關鍵在於可逆與不可逆的差別。

本題考點：可逆性單胺氧化酶 A 抑制劑（RIMA）與不可逆型 MAOI 的飲食限制不同；Fluoxetine 服用時須留意腸胃耐受性；Imipramine 的抗膽鹼副作用可致口乾；Trazodone 具鎮靜性，服用時間應配合日常安全。

第 5 題

病患服用下列何種藥物時，護理師需衛教病患規律返診抽血，以確認顆粒性白血球之數目？
  1. （A）Clozapine（Clozaril）
  2. （B）Risperidone（Risperdal）
  3. （C）Alprazolam（Xanax）
  4. （D）Quetiapine（Seroquel）

答案：（A）

詳解與考點

正解：題眼在「規律返診抽血」及「顆粒性白血球」。Clozapine 可能造成嚴重嗜中性白血球減少或顆粒性白血球缺乏，需依規範持續監測血球數，因此（A）正確，故選 A。

B：Risperidone 的常見監測重點不以顆粒性白血球數為其特有的規律抽血要求。

C：Alprazolam 為抗焦慮藥，主要須注意鎮靜、依賴與停藥風險，非此血球監測。

D：Quetiapine 亦須評估代謝與鎮靜等問題，但不是題幹所指因顆粒性白血球風險而規律抽血的代表藥物。

本題考點：Clozapine（clozapine）可造成嗜中性白血球減少（neutropenia）與顆粒性白血球缺乏（agranulocytosis）；全血球計數（complete blood count）是重要用藥安全監測；護理衛教（nursing education）須強調規律追蹤與感染警訊通報。

第 6 題

非理性信念與負面情緒產生之相關，是依據下列那一理論？
  1. （A）認知理論
  2. （B）行為學習理論
  3. （C）精神分析理論
  4. （D）社會互動理論

答案：（A）

詳解與考點

正解：題眼在「非理性信念」與「負面情緒產生之相關」——這正是認知理論認為事件本身不必然直接造成情緒，而是個人對事件的解釋與信念影響情緒反應。當信念僵化、絕對化或不合現實時，較易引發焦慮、憂鬱或憤怒；調整非理性信念便可改變情緒與行為，故選 A。

B：行為學習理論著重行為如何經由古典制約、操作制約與模仿而習得，主要用於分析可觀察行為及其增強後果，非以非理性信念為核心。

C：精神分析理論重視潛意識衝突、早期經驗與防衛機轉，雖可解釋情緒困擾，題幹所指的「非理性信念」並非其判準。

D：社會互動理論著重人際關係、角色與環境互動對行為的影響，未直接說明信念評價如何引發負面情緒。

本題考點：認知理論（cognitive theory）——情緒受事件的認知評價與信念影響；非理性信念（irrational beliefs）——僵化或失真的信念可維持負向情緒；認知重建（cognitive restructuring）——辨識並修正不合現實的想法。

第 7 題

根據環境治療的概念，病房生活討論會的目的為何？
  1. （A）病患可以留下彼此的連絡電話和地址以方便出院後保持聯繫
  2. （B）病患可以修訂病房重要的住院常規
  3. （C）病患可以澄清個人的疾病及治療相關問題
  4. （D）病患之間可以討論最近病房所發生的衝突事件

答案：（D）

詳解與考點

正解：題眼在「環境治療」與「病房生活討論會」——環境治療把病房日常互動視為治療媒介，會議的重點是讓病人檢視共同生活中實際發生的事件、表達感受並練習問題解決。討論最近病房衝突可在安全架構下澄清事實、練習溝通與共同訂定處理方式，故選 D。

A：交換聯絡電話與地址涉及個人隱私與界限，並非病房生活討論會的治療目的。

B：住院常規由專業與病房管理原則建立；病人可表達意見，但會議的主要功能不是由病人修訂重要常規。

C：個別疾病與治療問題應優先於個別晤談、衛教或治療團隊會談中處理，不能取代團體對病房共同事件的討論。這是最強誘答——澄清治療問題看似有助病人，但它把團體焦點從共同生活議題移到個別醫療問題。

本題考點：環境治療（milieu therapy）——運用治療性環境與日常活動促進復元；病房生活討論會（community meeting）——處理病房共同事件與人際互動；治療性界限（therapeutic boundaries）——保障隱私與安全。

第 8 題

進行團體治療時，護理師擔任團體領導者（group leader）的角色，在下列何種情況時正確？
  1. （A）甲病友表達想要出院，護理師向團體宣布，該病友症狀尚不穩定，目前不宜出院
  2. （B）乙病友表達服藥後容易頭暈，護理師把握機會，立刻對團體提出有關該藥物的護理指導
  3. （C）丙病友表達夜眠睡不好，護理師詢問團體成員，是否有類似的經驗，要請其分享心得
  4. （D）丁病友表達自己是家暴受害者，護理師主動透露另外某病友也有類似經驗

答案：（C）

詳解與考點

正解：題眼在「團體領導者」與成員提出「夜眠睡不好」——團體領導者應促進成員間的互動與支持，而非代替團體宣告決定或揭露他人隱私。詢問其他成員是否有相似經驗，並邀請分享可促進普同感、互助與可行因應策略，故選 C。

A：是否適合出院須由治療團隊依評估決定；在團體中直接宣布個別病人的病情判斷，容易破壞其尊嚴與參與感。

B：藥物衛教本身可在適當時機進行，但立刻將一名成員的頭暈轉成對全體的衛教，會中斷其經驗探索；應先評估個別不適與安全。

D：未經當事人同意揭露另一名病人的家暴經驗，違反保密與團體界限。這是最強誘答——連結相似經驗的方向看似支持團體，但分享權應由本人自行決定。

本題考點：團體領導（group leadership）——促進成員互動而非主導答案；普同感（universality）——發現他人有相似經驗可減少孤立感；保密原則（confidentiality）——不得代替成員揭露個人經驗。

第 9 題

「藥物成癮」的原因與下列那 3 項因素交互影響的結果最有關？①藥物本身 ②生物遺傳 ③法律 因素 ④社會因素
  1. （A）①②③
  2. （B）①②④
  3. （C）①③④
  4. （D）②③④

答案：（B）

詳解與考點

正解：題眼在「藥物成癮」與「交互影響」——成癮通常以生物心理社會模式理解：藥物本身的作用與可得性、個人的生物遺傳脆弱性，以及家庭、同儕與社會環境共同影響使用與依賴風險。①、②、④均屬核心面向，故選 B。

A：①②③把法律因素列為三項核心因素，卻漏掉社會因素。法律與政策會影響取得與處遇環境，但不能取代家庭、同儕與社會支持等社會面向。

C：①③④漏掉生物遺傳脆弱性，無法完整解釋不同個體在相同暴露下的差異。

護理師教導焦慮的個案學習有效的放鬆技巧以緩解焦慮情緒及解決衝突，此護理措施係根據下列 何種理論所設計？

  2. （B）學習理論
  3. （C）認知理論
  4. （D）遊戲理論

答案：（B）

詳解與考點

正解：題眼在「學習有效的放鬆技巧」——放鬆屬可經由示範、練習、回饋與增強而習得的因應行為；將此反應用來降低焦慮、改善衝突處理，符合學習理論的行為改變觀點，故選 B。

  4. （D）疾病盛行率高的社區其個案數一定多於盛行率低的社區

第 48 題

強調以「預防注射」來預防傳染病，是應用下列何項遏止傳染病流行的原則？

  2. （B）控制傳染源
  3. （C）增強人體的抵抗力
  4. （D）控制傳染途徑

答案：（C）

詳解與考點

正解：題眼在「預防注射」——接種後由受種者自身產生免疫反應，直接提高宿主對病原的防禦能力；它不是消滅環境中的病原，也不是隔斷傳播環節，故選 C。

A：撲滅病原體是以消毒、滅菌等方式直接降低病原本身；疫苗不會殺滅外界病原，故非答案。

B：控制傳染源是針對病人、帶原者或動物宿主採取隔離、治療等處置；接種者未必是傳染源，故非答案。

  2. （B）正確時序

  4. （D）相關特定性

第 80 題

80 歲諸奶奶因罹患失智症（dementia）住院，病情好轉後出院，返家後的居住環境敘述，下列何者 錯誤？
  1. （A）原本熟悉的房間、空間應儘量保持原樣
  2. （B）牆壁和地面加裝各種飾物，增加環境刺激
  3. （C）浴室、走道設扶手
  4. （D）在其經常活動的空間，應有提供人、時、地定向感的指示

答案：（B）

詳解與考點

正解：題眼在「失智症返家」與居住環境——判準先取安全與定向感；熟悉、簡明且可預測的環境可減少混亂與跌倒。（B）牆壁和地面加裝各種飾物會增加視覺刺激與辨識困難，反而可能造成困惑或跌倒，故為應選項。

A：盡量維持熟悉的房間與空間，有助降低環境改變造成的不安，故非答案。

C：浴室及走道設扶手可增加移動安全、降低跌倒風險，故非答案。

D：在人、時、地常活動處提供定向提示，有助維持現實定向，故非答案。

本題考點：失智症照護（dementia care）；環境定向（environmental orientation）；跌倒預防（fall prevention）。
