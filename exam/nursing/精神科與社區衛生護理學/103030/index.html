第 1 題

96 年版精神衛生法為保護嚴重病人權益，其中強制住院的方式為下列何者？
  1. （A）嚴重病人仍執行強制住院，不需經當事人或保護人同意
  2. （B）需由一位主管機關指定之專科醫師鑑定後，認為有強制住院之治療必要，即可執行
  3. （C）以審查會鑑定機制，執行審查會議得通知當事人或利害關係人到場證明，或主動派員查訪
  4. （D）經強制鑑定結果，嚴重病人仍有全日住院治療之必要，不需詢問嚴重病人之意見，即執行強制 住院

答案：（C）

詳解與考點

正解：題眼是「96 年版精神衛生法」與「保護嚴重病人權益」——本題判準在該版本採取由審查機制檢視強制住院必要性的程序保障。審查會得通知當事人或利害關係人到場陳述，亦得主動查訪，能使處遇接受外部檢驗，故選 C。

A：強制住院不能只憑嚴重病人身分逕行處理，仍須符合必要性及程序保障，故非答案。

B：僅由一名指定專科醫師認定即執行，缺少本題所問版本的審查會鑑定機制，故非答案。

D：強制鑑定後仍須依法定程序判斷住院必要性與權益保障，不能以不詢問意見概括取代程序。這是最強誘答——緊急精神醫療確可能限制自主，但限制必須有必要性與正當程序。

本題考點：強制住院（involuntary hospitalization）的程序保障；精神病人權益（patients’ rights）；審查機制（review mechanism）。本題援引舊版制度；現行要件與程序可能已修正，應依現行精神衛生法及機構流程查核。

第 2 題

當護生告訴病人，今天是他實習的最後一天時，病人掩面低聲哭泣。此時護生最佳的反應為何？
  1. （A）「沒關係，你不要難過，我還會再來看你的。」
  2. （B）「人生無不散之宴席，你要學習適應分離。」
  3. （C）「你不要哭好不好？你一哭，我就不知道該怎麼辦？」
  4. （D）沉默，手輕按病人肩膀

答案：（D）

詳解與考點

正解：題眼在「最後一天」與病人掩面哭泣——這是治療關係結束引發的分離情緒，判準是先以在場與非語言支持接納感受。沉默並輕按肩膀，在尊重病人界限下傳達陪伴，讓病人有空間表達哀傷，故選 D。

A：承諾還會再來看病人容易造成不切實際期待，也模糊治療關係的結束界限，故非答案。

B：以人生道理要求病人適應，是過早勸告，未回應其當下感受，故非答案。

C：把焦點轉向護生自己的無措，會增加病人的負擔，違反治療性溝通以病人為中心的原則。這是最強誘答——真誠說出困難看似坦白，卻使原本需要支持的病人反過來照顧護生。

本題考點：治療性沉默（therapeutic silence）；分離議題（separation）；治療性關係結束期（termination phase）。

第 3 題

王先生向護理師表示：「昨日在開車路途中，突然心跳加快、發抖、呼吸困難、感到很焦慮和極度 的害怕，並擔心自己快死掉。」請問上述為何種症狀？
  1. （A）欣快感（euphoria）
  2. （B）激動（agitation）
  3. （C）恐慌（panic）
  4. （D）易怒心情（irritable mood）

答案：（C）

詳解與考點

正解：題眼在「突然」出現心跳加快、發抖、呼吸困難、極度害怕及瀕死感——這組急遽達高峰的自主神經與認知症狀符合恐慌發作，故選 C。

A：欣快感是異常高昂、愉悅或自我感覺良好的情緒狀態，與強烈害怕不同，故非答案。

B：激動可見坐立不安、易怒或動作增加，但不能完整解釋突發瀕死感與明顯自律神經症狀，故非答案。

D：易怒心情以容易生氣與挫折容忍度低為主，非本題的核心表現。這是最強誘答——恐慌者可能表現不安，但題幹的突發身體症狀與災難感才是辨識關鍵。

本題考點：恐慌（panic）；恐慌發作（panic attack）；自主神經亢進（autonomic arousal）。

第 4 題

關於護理師與病人之間建立的治療性護病關係，下列那一項敘述最適切？
  1. （A）互動中需維持非批判性的態度接受病人的價值觀
  2. （B）互動中並不需要專業理念與技巧面對病人
  3. （C）互動關係的結束少有計畫，通常不與病人討論
  4. （D）互動的目的是滿足雙方的需求

答案：（A）

詳解與考點

正解：題眼在「治療性護病關係」——判準是護理人員以專業、尊重及不批判態度理解病人的主觀經驗，而非評斷其價值觀。維持非批判性接納有助於建立信任與溝通，故選 A。

B：治療性關係需要專業知識、溝通技巧與自我覺察，不能只憑一般社交互動，故非答案。

C：關係結束應預先計畫並與病人討論，以處理分離感受與轉介需求，故非答案。

D：關係目的是促進病人的健康需求，不是滿足護理人員與病人雙方的私人需求。這是最強誘答——互動確有雙方參與，但治療關係的權力與目的並不對等。

本題考點：治療性護病關係（therapeutic nurse-patient relationship）；非批判性接納（nonjudgmental acceptance）；專業界限（professional boundaries）。

第 5 題

下列關於服用鋰鹽（lithium）的注意事項，何者正確？①初次服用鋰鹽 12 小時後需抽血檢驗鋰 鹽濃度 ②病情穩定後每隔半年抽血檢驗鋰鹽濃度 1 次 ③使用鋰鹽之前需檢驗病人的腎臟功能 ④鋰鹽濃度 > 2.0 mEq/L 出現中毒症狀時需立刻停藥
  1. （A）①②③
  2. （B）①③④
  3. （C）②③④
  4. （D）①②④

答案：（B）

詳解與考點

正解：題眼在「鋰鹽濃度」與四項組合——判準是鋰鹽安全使用須在開始治療前評估腎功能，並依規定時點監測血中濃度；出現中毒症狀時應立即停藥並緊急評估。依本題組合，①、③、④成立，故選 B。

A：①③成立，但納入錯誤的②，且未含④；鋰鹽中毒症狀出現時不可延後處置，故非答案。

C：②把病情穩定後的濃度追蹤固定為半年一次，未符合本題監測判準，且遺漏①，故非答案。

D：①④成立，但納入錯誤的②，且未含開始治療前腎功能評估的③，故非答案。這是最強誘答——它保留了抽血與停藥兩個安全動作，卻漏掉腎臟排除鋰鹽所必需的基線評估。

本題考點：鋰鹽（lithium）治療藥物監測（therapeutic drug monitoring）；腎功能評估（renal function assessment）；鋰鹽中毒（lithium toxicity）。血中濃度須配合與服藥時間相對的固定時序採檢才具判讀意義。

第 6 題

護理師參與自殺者成長團體中，某位成員分享自己如何從強烈自殺意念到能運用圖畫成功表達自己 的經驗時，其他成員感受到自己也會有朝向正向力量的感覺。上述現象為何種團體治療的有效因素？
  1. （A）普遍性（universality）
  2. （B）人際學習（interpersonal learning）
  3. （C）灌注希望（instillation of hope）
  4. （D）存在性因子（existential factors）

答案：（C）

詳解與考點

正解：題眼在成員分享自己從強烈自殺意念走向能表達自己，讓其他人感到也能朝正向力量前進——判準是從他人改善經驗獲得對改變的期待，這是灌注希望，故選 C。

A：普遍性是發現自己的困擾並不孤單；本題重點不是共同具有問題，而是看見復原可能，故非答案。

B：人際學習著重在團體互動中認識自己與修正關係模式，題幹未描述人際回饋，故非答案。

D：存在性因子涉及面對生命限制、責任與存在意義，非此處由成功經驗帶來的正向期待。這是最強誘答——自殺議題確會觸及存在意義，但本題關鍵是「我也做得到」的希望感。

本題考點：灌注希望（instillation of hope）；團體治療有效因素（therapeutic factors）；復原經驗（recovery experience）。

第 7 題

朱先生，患精神分裂症且服用抗精神病藥物多年，某日突然發高燒，意識變得呆僵，全身肌肉僵直， 心跳每分鐘 136 次，白血球 20,000/mm3 ，並有肌球蛋白尿（myoglobulinuria），下列敘述何項正確？
  1. （A）錐體外徑症候群
  2. （B）血清張力素症候群
  3. （C）代謝和內分泌的副作用
  4. （D）抗精神病藥惡性症候群

答案：（D）

詳解與考點

正解：題眼在長期服用抗精神病藥後突發高燒、意識呆僵、全身肌肉僵直、自律神經亢進、白血球上升與肌球蛋白尿——這組危及生命的症候群符合抗精神病藥惡性症候群，故選 D。

A：錐體外徑症候群可有肌張力異常、顫抖或靜坐不能，但通常不以高燒、嚴重自主神經不穩與肌球蛋白尿為主，故非答案。

B：血清張力素症候群常與血清素藥物相關，可見反射亢進與陣攣；本題的抗精神病藥暴露及鉛管樣僵直更符合 D，故非答案。

C：代謝和內分泌副作用多見體重、血糖或泌乳等變化，不會突然形成這種急症。這是最強誘答——兩者都與精神科藥物相關，分辨關鍵在於高燒、嚴重僵直與肌肉分解警訊。

本題考點：抗精神病藥惡性症候群（neuroleptic malignant syndrome, NMS）；橫紋肌溶解（rhabdomyolysis）；精神科藥物急症辨識。

第 8 題

蔡小姐面臨更年期憂鬱，她到門診就醫，目前已服用百憂解（prozac）憂鬱症藥物 1 週，卻自覺狀況 未改善。她向護理師詢問，下列何種回應最正確？
  1. （A）「若無效，需要換另一種藥物。」
  2. （B）「您需要轉介心理諮商。」
  3. （C）「您是不是沒有按時吃藥？」
  4. （D）「此藥物改善症狀一般至少需要 2 週。」

答案：（D）

詳解與考點

正解：題眼在服用百憂解僅 1 週且尚未改善——判準是選擇性血清素再吸收抑制劑的抗憂鬱療效通常需要一段持續服藥時間才會逐漸顯現，不能僅憑 1 週判定無效。依本題選項，應先說明改善一般至少需 2 週，故選 D。

A：尚未達可評估療效的時間便直接主張換藥，跳過治療反應與服藥狀況的評估，故非答案。

B：心理諮商可作為重要的整合照護，但不能取代對藥物起效時間的直接回答，故非答案。

C：確認規律服藥很重要，但此問的已知關鍵是開始治療時間短；先以質疑式問法回應也不具治療性。這是最強誘答——服藥遵從性確需評估，但它沒有回答「為何剛開始一週尚未改善」。

本題考點：氟西汀（fluoxetine）；選擇性血清素再吸收抑制劑（selective serotonin reuptake inhibitor, SSRI）；抗憂鬱藥療效延遲（delayed therapeutic onset）。起效所需時間會受個體與療程影響，應依現行醫囑追蹤療效與不良反應。

B：治療團體並非人數越多越好；過大的團體會降低每位成員參與及治療者觀察品質，故非答案。

本題考點：團體治療（group therapy）；同質性團體（homogeneous group）；團體發展階段（group development stages）。

情況：吳小姐，診斷為憂鬱症（major depression），整天待在病室中沉默少語，不與任何人互動。護理師探視吳小姐時面帶微笑，身體微微的前傾，經常陪伴、表達關心。 護理師主要是運用下列何項治療性態度？
  1. （A）友善、接納態度
  2. （B）就事論事態度
  3. （C）放縱、無關緊要態度
  4. （D）被動友善態度

答案：（A）

詳解與考點

正解：關鍵在護理師面帶微笑、身體前傾、經常陪伴並表達關心，這些非語言與陪伴行為傳達的是主動的友善與接納。面對沉默少語的憂鬱症病人，先建立可被接納的互動氛圍最合宜；（A）最符合描述，故選 A。

B：就事論事著重客觀處理事件，題幹的重點則是關懷、陪伴與接納的態度，故非答案。

C：放縱或無關緊要會削弱專業界線與關懷，和護理師持續探視的行為相反。

D：被動友善僅停留在表面禮貌，題幹所示的是主動靠近、持續陪伴與接納；這是最強誘答，兩者都有「友善」字樣，但差別在是否實際投入治療性關係。

正解：題眼在「精神疾病發生原因」——判準是精神疾病多屬生物、心理與社會因素交互作用，並非單一、短時間即可辨識的原因。人格特質會影響壓力因應、人際模式與脆弱性，可能是發病的潛在因素之一，故選 C。

D：個案研究只描述少數個案，不能穩健比較社區推動措施對整體民眾的影響，故非答案。這是最強誘答——橫斷調查可快速看到相關性，但「影響」需要時間順序作為判準。

本題考點：前瞻性世代研究（prospective cohort study）由暴露追蹤至結果；橫斷研究（cross-sectional study）評估單一時間點的分布；因果推論（causal inference）需重視暴露先於結果。

  2. （B）發生率乃指調查期間易感人口中新發生個案所占的比率
  3. （C）疾病盛行率以舊個案為分子計算
  4. （D）疾病盛行率以新個案為分子計算

答案：（B）

詳解與考點

正解：題眼是「發生率」——它關心在觀察期間原本有風險、尚未患病的人之中新出現多少病例。發生率的分子是新發生個案，分母是易感人口，因此（B）正確，故選 B。

A：調查期間所有個案所占比率描述的是盛行率的概念，不能稱為發生率，故非答案。

本題考點：發生率（incidence）以新個案／易感人口衡量新發生風險；盛行率（prevalence）以現存全部個案／總人口或相應人口衡量疾病負擔。

  4. （D）有暴力傾向的家庭

答案：（C）

詳解與考點

正解：題眼在「高風險家庭」與「何者錯誤」——判準是家庭是否因發展危機、經濟與照顧負荷、疾病或暴力而需要優先支持。未成年未婚懷孕、主要家計者重病及暴力傾向都會增加家庭功能受損風險；（C）僅有學齡期子女是常見家庭發展階段，本身不足以界定高風險，故為應選項。

A：未成年且未婚懷孕可能同時面臨支持不足、就學與經濟壓力，屬需評估與連結資源的高風險情境。

B：主要家計者罹患重大疾病會影響收入、照顧分工與家庭適應，故屬高風險因素。

D：暴力傾向牽涉家庭成員安全，須優先進行安全評估與適當通報、轉介，故非答案。

本題考點：高風險家庭（high-risk family）指因多重壓力或功能危機而需支持的家庭；家庭發展階段（family developmental stage）本身不等於風險。
