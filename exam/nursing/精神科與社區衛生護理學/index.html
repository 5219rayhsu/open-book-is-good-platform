第 1 題

吳小姐，24歲，碩士生，單親家庭，因應疫情返家遠距學習，在家期間與母親朝夕相處備感壓力。返診時對護理師說:「我坐在房間窗邊會想，如果跳下去會怎樣？」，根據同理心的原則，下列何項護理師的回應最適切？
  1. （A）「請問你住幾樓？」
  2. （B）「你有不想再活下去的念頭嗎？」
  3. （C）「你還很年輕，人生才要開始。」
  4. （D）「等疫情降級跟媽媽分開來住，這種情況就會改善。」

答案：（B）

詳解與考點

本題問依同理心原則最適切的回應，答案為 B。當個案透露「如果跳下去會怎樣」這類疑似自殺意念的訊息時，最適切的做法是以同理、直接而不迴避的方式確認其自殺意念，「你有不想再活下去的念頭嗎？」正是直接澄清自殺想法、開啟後續風險評估的回應，並能讓個案感到被理解，故 B 正確。A 錯誤：「請問你住幾樓？」聚焦於方法／工具，顯得冷漠且未回應其情緒，缺乏同理。C 錯誤：「你還很年輕，人生才要開始」屬說教與否定其感受，會讓個案覺得不被理解。D 錯誤：「等疫情降級分開住就會改善」是提早給保證與建議，忽略當下的自殺風險與情緒。需澄清：B 為直接確認自殺意念的封閉式探問；確認意念後，再依評估自殺計畫的明確性、致命性、工具可近性與獲救可能等面向進行風險分級。

第 71 題

下列何者為學生健康體能四大要素中最重要的一項？
  1. （A）心肺耐力
  2. （B）肌力與肌耐力
  3. （C）柔軟度
  4. （D）身體組成

答案：（A）

詳解與考點

正解：題眼在「健康體能四大要素中最重要」——心肺耐力反映心臟、肺臟與循環系統在持續活動時供應氧氣的能力，也是多數日常身體活動與健康風險的重要基礎，故選 A。

B：肌力與肌耐力關係到姿勢、活動與功能表現，固然重要，但不能取代心肺系統對長時間活動的基本支持，故非答案。

C：柔軟度可維持關節活動度並協助動作表現，卻不是整體有氧代謝能力的主要指標，故非答案。

D：身體組成用來描述脂肪與非脂肪組織的比例，適合健康風險評估；它不是運動時心肺輸氧與利用氧氣的能力。這是最強誘答——身體組成也與健康密切相關，但「健康相關體能」的核心耐力指標仍是心肺耐力。

本題考點：健康相關體能（health-related fitness）；心肺耐力（cardiorespiratory endurance）；身體組成（body composition）。

第 71 題

長期暴露於何種物質的工作環境中，最容易導致罹患帕金森氏症候群？
  1. （A）錳
  2. （B）鉛
  3. （C）鎘
  4. （D）砷

答案：（A）

詳解與考點

正解：題眼在「長期暴露」與「帕金森氏症候群」——錳的職業暴露可造成以動作遲緩、僵硬等為主的錐體外路徑症候群，稱為錳中毒相關帕金森氏症候群，故選 A。

B：鉛主要影響造血、神經與腎臟系統，其典型職業危害不是本題所問的帕金森氏症候群。

C：鎘常與腎小管損傷及骨骼影響相關，非本題的典型神經症候群，故非答案。

D：砷暴露可造成皮膚病變、周邊神經病變與其他全身毒性，但不以帕金森氏症候群為典型表現。這是最強誘答——砷也會影響神經系統，分辨關鍵在於周邊神經病變不同於錳造成的錐體外路徑表現。

本題考點：錳中毒（manganese poisoning）可造成帕金森氏症候群（parkinsonism）；職業暴露（occupational exposure）須連結物質與靶器官；錐體外路徑症候群（extrapyramidal syndrome）以動作控制異常為主。

第 71 題

某生參加大隊接力後，突冒冷汗、手發抖，護理師接獲通知，前往現場處理時，應該攜帶下列那些 設備至現場？①冰敷袋 ②血壓計 ③彈性繃帶 ④血糖機 ⑤葡萄糖片
  1. （A）①②③
  2. （B）①③④
  3. （C）②③④
  4. （D）②④⑤

答案：（D）

詳解與考點

正解：關鍵在症狀組合——大隊接力這類劇烈運動之後突然冒冷汗、手發抖，是交感神經代償的表現，最先要排除的是低血糖。到場前須帶齊評估生命徵象、確認血糖、立即處理三件事的器材：②血壓計評估血壓與脈搏，④血糖機提供判定低血糖的客觀依據，⑤葡萄糖片在學生意識清楚、能吞嚥時立即口服補糖。故選 D。

A、B：兩者都含①冰敷袋與③彈性繃帶，這兩項是急性軟組織損傷的用物——冰敷用於受傷初期減少出血與腫脹、彈性繃帶用於加壓固定，與冷汗、手抖這組全身性症狀無關。

C：含③，理由同上；它雖備有②血壓計與④血糖機，卻少了⑤葡萄糖片。這是最強誘答——評估器材備得最齊，分辨關鍵在於低血糖是評估與處置必須同時到位的狀況，只帶診斷器材而沒有可立即給予的糖分，到場後仍解決不了問題。

本題考點：低血糖（hypoglycemia）的現場辨識與處置——交感神經症狀（冒冷汗、心悸、手抖、飢餓感）與中樞症狀（意識改變、抽搐）並存時先想低血糖，運動後與空腹時風險最高；處置原則是意識清楚且能吞嚥者立即給予可快速吸收的糖分並於數分鐘後複測，意識不清者不可由口給予，改為維持呼吸道通暢並緊急轉送。

情況題：張護理師受僱於「愛愛幼稚園」，園長請她規劃這學期給家長的健康講座主題，若依據衛生福 利部（原行政院衛生署）兒童健康統計資料

第 71 題

下列何項主題應優先選擇？
  1. （A）兒童癌症的議題
  2. （B）如何預防事故傷害的產生
  3. （C）如何預防家庭暴力
  4. （D）兒童性別認同的議題

答案：（B）

詳解與考點

正解：題眼在「應優先選擇」——健康教育主題的排序判準是發生頻率、嚴重度，以及聽講對象能否據以立即行動而降低風險。幼兒事故傷害發生頻繁、後果嚴重，且照顧者可透過環境安全布置與看顧行為直接預防，因此（B）如何預防事故傷害的產生最適合優先選擇，故選 B。

A：兒童癌症雖嚴重，但發生率相對低、且難以靠衛教直接預防，不符合優先序判準，故非答案。

C：家庭暴力防治十分重要，惟其介入以通報與跨專業處遇為主，就一般兒童健康教育的頻率與可行動性排序而言仍次於事故傷害，故非答案。

D：性別認同的理解與支持有其價值，但不屬於以發生頻率與可預防性排序的首要健康威脅，故非答案。

本題考點：健康需求評估（health needs assessment）依頻率、嚴重性與可預防性排序；事故傷害預防（injury prevention）適合對照顧者衛教；健康教育優先序（priority setting）須連結目標族群能執行的行動。
