第 1 題

林小姐常責怪自己，認為凡事過錯都是自己造成的。下列何項心理防衛機轉最適合說明林小姐的行為？
  1. （A）合理化（rationalization）
  2. （B）潛抑（repression）
  3. （C）內射（introjection）
  4. （D）退化（regression）

答案：（C）

詳解與考點

「內射」（introjection）是將外部他人的態度、價值觀或批評內化為自我的一部分。林小姐將外界的責備內化，認為所有過錯都是自己造成的，典型為內射。合理化（rationalization）是事後找理由為行為辯解；潛抑（repression）是將不可接受的念頭壓入潛意識；退化（regression）是壓力下退回早期行為模式。

第 2 題

精神醫學史上，主張不以鐵鍊限制病人行動，奠定人道主義精神照護的代表性人物，下列何者正確？
  1. （A）克雷佩林（Emil Kraepelin）
  2. （B）畢乃爾（Phillipe Pinel）
  3. （C）佛洛伊德（Sigmund Freud）
  4. （D）瓊斯（Maxwell Jones）

答案：（B）

詳解與考點

法國精神科醫師畢乃爾（Philippe Pinel）於 18 世紀末主張以人道方式對待精神病患，移除鐵鍊約束，確立精神醫療人道主義基礎。克雷佩林（Kraepelin）以現代精神疾病分類著稱；佛洛伊德（Freud）建立精神分析學；瓊斯（Maxwell Jones）則以治療性社區（therapeutic community）聞名，皆非人道解鎖的代表人物。

第 3 題

根據DSM-5診斷準則，有關精神疾病的診斷及臨床表徵，下列敘述何者正確？
  1. （A）妄想症（delusional disorder）病人經常會出現明顯奇特怪異的行為
  2. （B）重鬱症（major depressive disorder）病人最常出現思緒飛躍的症狀
  3. （C）思覺失調症（schizophrenia）病人最常出現罪惡妄想的症狀
  4. （D）強迫症（obessive-compulsive disorder）病人會出現強迫思考、強迫行為的症狀

答案：（D）

詳解與考點

DSM-5 中，強迫症（OCD）的診斷核心特徵即為「強迫思考」（obsessions）和／或「強迫行為」（compulsions），選項 D 正確。選項 A 錯：妄想症（delusional disorder）患者的妄想通常「非奇特」（non-bizarre），行為外觀相對正常。選項 B 錯：思緒飛躍（flight of ideas）是躁症特徵，重鬱症主要表現為思考遲緩。選項 C 錯：思覺失調症最常見為被害妄想，而非罪惡妄想。

第 4 題

有關抗精神病藥物的敘述，下列何者正確？
  1. （A）躁症急性發作期，若已使用情緒穩定劑，則不建議併用抗精神病藥物
  2. （B）clozapine（Clozaril®）和fluvoxamine（Luvox®）產生交互作用，會誘發非預期癲癇痙攣
  3. （C）長效針劑risperidone（Risperdal Consta®）本質水性，多採淺層肌肉注射
  4. （D）鋰鹽為治療譫妄症的首選藥物

答案：（B）

詳解與考點

本題問「正確」者，答案為 B。clozapine（Clozaril®）主要經肝臟 CYP1A2 代謝，而 fluvoxamine（Luvox®）是強力 CYP1A2 抑制劑，併用會抑制 clozapine 代謝、使其血中濃度升高，clozapine 本身會降低癲癇閾值，濃度過高更易誘發非預期的癲癇痙攣，故 B 正確。A 錯誤：躁症急性發作期常於情緒穩定劑之外「併用」抗精神病藥物以快速控制症狀，並非不建議併用。C 錯誤：長效針劑 risperidone（Risperdal Consta®）為「水性」微球懸浮製劑，應採「深部」肌肉注射（臀部或三角肌），而非淺層肌肉注射，故敘述錯誤。D 錯誤：譫妄症的處置首重找出並矯正病因，藥物多以低劑量抗精神病藥（如 haloperidol）控制躁動，鋰鹽並非譫妄症的首選用藥。

第 5 題

護理師詢問病人「您幾歲？」，病人回答「38歲」，再繼續問病人「之前的工作服務多久？」，病人仍回答「38歲」，病人對之後的問題皆回答「38歲」。此現象屬於下列何種症狀？
  1. （A）音韻連結（clang association）
  2. （B）言語持續（perseveration）
  3. （C）重複言語（verbigeration）
  4. （D）回音性言語（echolalia）

答案：（B）

詳解與考點

「言語持續」（perseveration）是指對不同問題持續重複同一回應，無法轉換至新刺激。病人對不同問題均答「38 歲」，符合此定義。音韻連結（clang association）是依音韻而非意義聯想詞語；重複言語（verbigeration）是無意義重複詞或句；回音性言語（echolalia）是立即重複他人說話。三者均與「無法因問題改變而切換回應」不同。

第 6 題

有關「以整個事件中的單一細節下結論，而沒有考慮整個事件中還有其他相關的訊息」，是屬於下列何項「負向認知思考模式」？
  1. （A）二極化的思考
  2. （B）完美主義
  3. （C）選擇性的偏差推論
  4. （D）武斷推論

答案：（C）

詳解與考點

「選擇性的偏差推論」（selective abstraction）是 Beck 認知治療理論中的認知扭曲：從事件中只抽取某一細節下結論，忽略其他相關資訊，即「見樹不見林」。二極化思考（all-or-nothing）是非黑即白；武斷推論（arbitrary inference）是無充分證據就下結論；完美主義（perfectionism）是設立不切實際高標準。題幹強調「單一細節＋忽略其他訊息」，與選擇性偏差推論定義吻合。

第 7 題

下列何者不是動機式晤談法（motivational interview）的基本原則？
  1. （A）創造不一致的想法
  2. （B）應用夢的解析分析問題
  3. （C）支持自我效能感
  4. （D）避免發生爭辯

答案：（B）

詳解與考點

動機式晤談法（MI）的四大核心原則為：表達同理（express empathy）、創造不一致的想法（develop discrepancy）、面對阻抗（roll with resistance）、支持自我效能感（support self-efficacy）。「應用夢的解析分析問題」（B）屬精神分析技術，不是 MI 的基本原則。避免爭辯（D）對應 roll with resistance，支持自我效能感（C）是直接原則之一，創造不一致（A）亦是 MI 原則。

第 8 題

有關代幣制度的敘述，下列何項不適宜？
  1. （A）是行為治療中的一項技術
  2. （B）最適合在病人精神症狀混亂時使用
  3. （C）以具有交換價值的象徵物代替金錢
  4. （D）屬於操作制約作用的學習原理

答案：（B）

詳解與考點

代幣制度（token economy）屬行為治療（操作制約），以象徵性獎勵強化正向行為，需個案能理解與配合。選項 B「最適合在病人精神症狀混亂時使用」最不適宜：精神症狀混亂（如急性精神病發）的個案無法理解代幣規則與交換關係，使用時機應在症狀穩定後。代幣制度適用於慢性精神病房或長期照護環境，個案需具備一定認知功能。

第 9 題

胡先生，診斷為思覺失調症，因不停將家中東西丟到大街上，哥哥予以制止，胡先生即要攻擊哥哥。剛入住急性病房治療，下列何者為最優先的護理處置？
  1. （A）確認胡先生身邊環境與物品的安全性，進行暴力行為之評估與預防發生
  2. （B）直接先至保護室並給予預防性約束，以免發生自傷傷人行為
  3. （C）警告胡先生在醫院裡面不容許有攻擊行為發生，否則就無法出院
  4. （D）為表達護理師的關懷與建立信任，可先單獨與病人會談了解他為何要攻擊哥哥

答案：（A）

詳解與考點

急性精神科病房最優先護理原則為「安全」。選項 A 正確：入院時首先評估環境與物品安全性，執行暴力風險評估，以預防自傷或傷人。選項 B（預防性約束）屬最後手段，需有明確立即危險才使用，不應未評估即直接約束。選項 C（威脅性語言）會增加對立，無治療意義。選項 D（單獨會談）在尚未確認安全性前具風險。

第 10 題

根據DSM-5診斷準則，有關情感思覺失調症（schizoaffective disorder）的敘述，下列何者正確？
  1. （A）臨床症狀以情感障礙為主
  2. （B）在無情緒障礙症發作時，有二週以上的妄想或幻覺
  3. （C）思考障礙和情緒障礙不會同時發作
  4. （D）不會出現妄想、幻覺

答案：（B）

詳解與考點

DSM-5 情感思覺失調症（schizoaffective disorder）的核心診斷準則：在疾病病程中，「在無明顯情緒發作的期間，至少有連續 2 週的妄想或幻覺」，選項 B 正確。選項 A 錯：臨床症狀是精神病症狀與情感症狀混合，非單純以情感障礙為主。選項 C 錯：思考障礙與情緒障礙可同時發作。選項 D 錯：妄想、幻覺正是其診斷所必需。

第 11 題

宋小姐因情緒低落且有自殺行為，入院治療已兩週，常一個人臥床獨處，少與其他病友互動。下列何項護理措施最適宜？
  1. （A）配合病人低落心情，環境宜減少光線刺激
  2. （B）提供安靜的單人房，減少打擾病人
  3. （C）播放低沉的音樂，避免刺激病人
  4. （D）設計簡單的活動，增加病人活動

答案：（D）

詳解與考點

憂鬱症病人護理的核心原則之一是鼓勵活動、打破退縮循環。選項 D「設計簡單的活動，增加活動」最適宜——增加活動有助改善情緒及減少獨處沉溺。選項 A、C（減少光線、播放低沉音樂）會加重憂鬱情境，不利康復。選項 B（提供單人房、減少干擾）可能增加自殺風險，憂鬱症有自殺傾向者反需加強觀察與互動。

第 12 題

陳同學19歲，出現怪異行為，診斷為思覺失調症。因為干擾鄰居被送至精神科急性病房住院。入院時，說自己沒有生病，吵著要出院回家。以下何項護理措施最適切？
  1. （A）請他保證不再干擾鄰居就可以回家
  2. （B）跟他說必須住滿三個月才可考慮出院
  3. （C）引導他表達自己會住院的過程
  4. （D）跟他說只要配合吃藥就可以出院

答案：（C）

詳解與考點

思覺失調症急性期病人常缺乏病識感（anosognosia），強辯或威脅無效。最適切護理是引導病人表達自身的感受與住院經歷（C），建立同理關係，避免直接對質妄想內容。選項 A（承諾出院）不切實際且易破壞信任；選項 B（說明三個月）可能是錯誤資訊且威脅性；選項 D（以配藥換出院）屬條件交換，不符治療同盟精神。

第 13 題

承上題，住院第二天，陳同學表示我的父母一定是假的，否則不會將自己的小孩抓來住院。下列護理師的回答何者最適當？
  1. （A）「你的父母是不得已的」
  2. （B）「你的父母是為你好」
  3. （C）「父母的想法很難瞭解」
  4. （D）「這個想法很困擾你」

答案：（D）

詳解與考點

面對病人的妄想內容（「父母是假的」），正確護理回應應「聚焦於病人的情緒感受而非妄想內容本身」，避免辯駁或強化。選項 D「這個想法很困擾你」反映病人的情緒體驗，屬同理感受性回應，最適當。選項 A、B（為父母辯護）等於否定病人感受，可能引起對立。選項 C（父母難以了解）隱含認同妄想，不妥。

第 14 題

林先生總是表現出自己很優越，看不起醫護人員，認為自己是群體中最重要的人，且擁有特權。護理師針對此自戀行為（narcissistic）之應對方式，下列何者最適切？
  1. （A）持續的讚美病人，滿足其自誇的需求
  2. （B）利用幽默，與病人開玩笑，營造輕鬆的氣氛
  3. （C）為維持病人的自尊，接受病人對醫護人員的貶低
  4. （D）了解病人的自誇行為並持續提供包容，但避免過度讚美

答案：（D）

詳解與考點

對自戀型人格特質病人的護理，原則是「包容而不強化」：了解其自誇行為背後的脆弱自我，持續給予包容，但不過度讚美或滿足其貶低他人的需求（D 正確）。選項 A（持續讚美）會強化自戀行為。選項 B（開玩笑）可能傷害其脆弱自尊，引發強烈反應。選項 C（接受病人貶低醫護）則設定界限不當，有損護理關係及自我尊重。

第 15 題

有關創傷後壓力症（posttraumatic stress disorder）的敘述，下列何者最適切？
  1. （A）會出現解離反應，感到創傷事件重演
  2. （B）不包含目擊創傷發生於他人身上的經驗
  3. （C）創傷事件不會產生明顯生理反應
  4. （D）負面情緒不包含易怒或無預兆的發怒

答案：（A）

詳解與考點

DSM-5 PTSD 診斷準則包含「再體驗症狀」，如閃回（flashback）——感到創傷事件重演，以及解離性反應，選項 A 正確。選項 B 錯：PTSD 的創傷暴露準則（Criterion A）包含「目擊創傷發生於他人身上」。選項 C 錯：對創傷相關刺激的明顯生理反應是 PTSD 診斷準則之一（Criterion B5）。選項 D 錯：易怒或無預兆的暴怒是 PTSD 的過度激醒症狀（Criterion E2）。

第 16 題

辛小姐診斷為強迫症，會反覆出現希望妹妹死掉的念頭，且對此感到非常焦慮。所以每當看到妹妹時，就開始在心中默念圓周率的數字以減輕焦慮。下列何項敘述最能說明辛小姐的行為？
  1. （A）以抵消對妹妹的負面想法
  2. （B）以投射的作用逃避念頭
  3. （C）自我肯定，證明自己的數學好
  4. （D）一種解離性的狀態

答案：（A）

詳解與考點

強迫症中，「抵消」（undoing）是指以特定行為或思想中和令自己焦慮的強迫念頭。辛小姐以默念圓周率來抵銷「希望妹妹死掉」的侵入性念頭，正是抵消機制的典型表現。B「投射」是將自身感受歸咎他人；C「自我肯定」與症狀無關；D「解離」是意識/記憶/認同的分裂，三者均不符。

第 17 題

有關使用嗎啡之敘述，下列何者正確？
  1. （A）嗎啡能有效止痛且提神
  2. （B）嗎啡使用後會產生欣快感
  3. （C）嗎啡只能口服使用
  4. （D）護理師可自行斟酌使用

答案：（B）

詳解與考點

本題問「正確」者，答案為 B。嗎啡（morphine）作用於類鴉片受體，止痛之外常伴隨欣快感（euphoria），這也是其成癮性的來源之一，故 B 正確。A 錯誤：嗎啡會產生鎮靜、嗜睡，並非「提神」。C 錯誤：嗎啡給藥途徑多元，可口服、皮下、肌肉、靜脈注射，甚至硬脊膜外給藥，並非「只能口服」。D 錯誤：嗎啡屬管制藥品，使用須有醫師處方並依管制藥品管理規定，護理師不可自行斟酌使用。補充：依我國管制藥品分級，嗎啡列為「第一級」管制藥品（非第二級），管理最為嚴格。

第 18 題

根據DSM-5診斷準則，有關智能不足適應功能的評估，下列何者最不適切？
  1. （A）適應功能評估包含概念、社會以及實務三個領域
  2. （B）個人在獨立與擔當社會責任方面無法達到適齡的發展及文化準則，稱為適應功能缺損
  3. （C）評估個人的閱讀、書寫、問題解決能力以及對陌生情境的判斷力等，是屬實務領域
  4. （D）適應功能缺損會使個人在多重環境中的一項或多項日常活動功能受限

答案：（C）

詳解與考點

DSM-5 將適應功能分為「概念」「社會」「實務」三領域。閱讀、書寫、問題解決等學業技能屬「概念領域」（conceptual domain），而非實務領域（practical domain）。實務領域涵蓋個人照顧、家事管理、金錢管理、工作技能等。C敘述將學業技能劃入實務領域，故為最不適切。

第 19 題

陳小弟，上課時容易分心、坐不住、喜歡往外跑，不受控制的行為讓老師很困擾。陳小弟最可能出現以下何項問題？
  1. （A）智能不足（intellectural disabilities）
  2. （B）雙相情緒障礙症（bipolar disorder）
  3. （C）妥瑞氏症（Tourette's disorder）
  4. （D）注意力不足／過動症（ADHD）

答案：（D）

詳解與考點

陳小弟的核心表現為「注意力不集中、衝動、過動」三症狀組合，且在學校環境造成困擾，高度符合 ADHD（注意力不足/過動症）的 DSM-5 診斷特徵。A智能不足主要呈現學習能力缺損；B雙相情緒障礙以躁鬱發作為主；C妥瑞氏症以不自主的動作或聲音型抽動為核心，三者均不符合題幹描述。

第 20 題

有關老年憂鬱症的敘述，下列何者最不適切？
  1. （A）以身體症狀反應情緒
  2. （B）常談論自殺想法
  3. （C）記憶力變差
  4. （D）合併日落症候群

答案：（D）

詳解與考點

日落症候群（sundowning）是失智症的特徵性表現（傍晚後混亂加劇），並非老年憂鬱症的典型症狀。老年憂鬱症反而常以身體化症狀表現（A）、談論死亡或自殺（B）、假性失智造成記憶力下降（C）。D與憂鬱症的關聯最弱，故為最不適切。

第 21 題

有關社區精神衛生護理評估的敘述，下列何者正確？
  1. （A）不需了解個案的生活習慣及社交狀態，以免涉及病人私領域
  2. （B）不需評估照顧者對病人疾病的瞭解，以免涉及照顧者私領域
  3. （C）不需評估社區的資源，因與精神衛生護理無關
  4. （D）需評估個案、家屬及社區三方面的狀況，以提供多元的社區照護

答案：（D）

社區精神衛生護理需以個案、家屬（照顧者）及社區資源三個面向全面評估，才能提供連續性整合照護，D最正確。A、B、C分別主張「不評估生活習慣」「不評估照顧者」「不評估社區資源」，均違反整體性評估原則，為錯誤敘述。

第 22 題

對於安置在精神護理之家的病人，下列服務內容何者最適宜？
  1. （A）病人的精神症狀呈現慢性化，宜提供生活的照顧
  2. （B）照顧目標應優先讓病人能返回家庭
  3. （C）病人的精神症狀屬活躍期，宜嚴格監控行動
  4. （D）需積極安排病人就業規劃

答案：（A）

詳解與考點

精神護理之家（psychiatric nursing home）收治的是慢性精神病患，症狀已呈慢性化、趨於穩定，照護重點在維持日常生活功能與提升生活品質，A最適宜。B「優先返家」並非慢性安置的首要目標；C「活躍期嚴格監控」描述不符（護理之家收活躍期不適當）；D「積極安排就業」對病情慢性化者優先順序過高。

第 23 題

楊太太擔心自己罹患大腸癌，經多次檢查皆正常，但她仍深信自己不久人世，變得無食慾、失眠，有輕生念頭。下列何項為最優先的護理措施？
  1. （A）教導紓解壓力的方法
  2. （B）再做詳盡健康檢查，降低憂鬱
  3. （C）評估自殺的風險程度
  4. （D）鼓勵寫遺囑，降低焦慮

答案：（C）

詳解與考點

楊太太有「輕生念頭」（自殺意念），依護理優先原則，「安全」是首要考量，應立即評估自殺風險程度（C），才能決定後續介入層級。A教導壓力紓解、B再做檢查、D鼓勵寫遺囑，均在未評估安全風險之前超前部署或反而強化輕生念頭，皆為次要或不適當措施。

第 24 題

有關社區精神衛生護理的角色功能，下列何者最適切？

  2. （B）個案管理者是唯一的角色功能

第 25 題

有關解除肢體的約束，下列何者最不適宜？

  2. （B）瞭解病人在約束中的感受及需要
  3. （C）與其他工作人員共同解除病人的約束
  4. （D）觀察約束部位的膚色狀況

第 26 題

  2. （B）提供具實證基礎、非商業目的且攸關社區健康議題的健康資訊

第 27 題

第 28 題

有關流行病學的敘述，下列何者最不適當？

  2. （B）流行病指一個疾病的發生超過正常期望值
  3. （C）疾病的探討不限於地點或時間
  4. （D）可探討暴露源和疾病的因果關係

流行病學（epidemiology）的研究範疇不限於傳染病，還涵蓋慢性病、職業病、心理健康、意外傷害等非傳染性疾病的分布與決定因素。A「專為探討傳染病」為錯誤敘述，故最不適當。B、C、D均符合現代流行病學的定義與研究特性。

第 29 題

提供工廠作業員安全防護器具以減少傷害發生，是屬於三段五級預防工作的那一級？

  3. （C）第三級
  4. （D）第四級

三段五級預防中，第二級為「特殊保護」，目的是針對高危險族群採取具體防護措施以阻止疾病或傷害發生。提供安全防護器具（如護目鏡、耳塞、安全帶）屬於針對特定工作環境的特殊保護，對應第二級。第一級為健康促進；第三級以後為早期診斷與失能限制。

第 30 題

在疫情期間維持適當社交距離，是針對三角致病模式（epidemiological triangle）中那一因素的處理策略？
  1. （A）壓力
  2. （B）環境
  3. （C）病原體
  4. （D）宿主

答案：（B）

詳解與考點

流行病學三角（epidemiological triangle）包含「病原體（agent）」「宿主（host）」「環境（environment）」三要素。維持社交距離的目的是改變人與人之間的空間關係，屬於「環境」因素的干預策略（切斷傳播路徑），而非直接作用於病原體或宿主本身，答案為 B。

第 31 題

某社區為降低老人跌倒率，增設無障礙設施，此屬渥太華健康促進憲章行動綱領的那一項？

  4. （D）發展個人技巧

第 32 題

有關社區健康評估之敘述，下列何者最不適當？
  1. （A）使照護計畫能真正反應社區的需求
  2. （B）提升社區健康照護計畫之品質
  3. （C）隨機抽樣最常用來選擇重要人物進行訪談
  4. （D）民意團體過程法可以用來形成排定社區健康問題優先順序的共識

答案：（C）

社區健康評估選取關鍵人物（key informants）時，應採「立意抽樣」（purposive sampling）挑選對社區具代表性或深度了解的人，而非「隨機抽樣」（random sampling）。C敘述錯誤，故最不適當。A、B符合社區評估目的；D民意團體過程法（nominal group process）確為形成優先順序共識的常用方法。

第 33 題

  1. （A）男女的性比
  2. （B）婚姻狀況
  3. （C）對村／里長的滿意度
  4. （D）社會增加率

答案：（C）

詳解與考點

Anderson 與 McFarlane 以社區為夥伴模式（Community-as-Partner Model）的「人口群體特性」評估，涵蓋年齡、性別（性比）、婚姻狀況、種族、社會增加率（移入移出）、教育程度等人口學指標。「對村/里長的滿意度」屬政治感受或社區感知面向，不屬於人口群體特性範疇，C最不適當。

第 34 題

有關自我效能（self-efficacy）之敘述，下列何者最不適當？
  1. （A）是指個人評估在特定環境下，能完成特定行為的能力
  2. （B）自我效能低者容易因為失敗經驗而導致自我效能再度降低
  3. （C）外在資源越多者，自我效能越高
  4. （D）包括程度、類化和強度等三個層面

答案：（C）

詳解與考點

Bandura 的自我效能（self-efficacy）理論指出，自我效能受四大來源影響：成功經驗、替代學習、口語說服、生理/情緒狀態，「外在資源多寡」並非自我效能的構成因素。外在資源充足不代表個人對自身能力的判斷（自我效能）就高，C敘述不適當。自我效能三向度為程度（magnitude）、類化（generality）、強度（strength）。

第 35 題

依據加拿大衛生福利部於1974年提出的影響健康的四大要素，下列那一項對健康的影響最大？
  1. （A）提供基因檢測
  2. （B）控制環境中PM2.5濃度
  3. （C）廣推在宅醫療
  4. （D）鼓勵民眾實踐健康生活

答案：（D）

詳解與考點

加拿大衛生部 Lalonde Report（1974）提出健康四大決定因素：生活型態（約50%影響最大）、環境、生物遺傳、醫療體系。其中「生活型態」影響最大。選項D「鼓勵民眾實踐健康生活」對應生活型態，故影響健康最大。A基因檢測屬生物；B PM2.5 屬環境；C在宅醫療屬醫療體系，三者影響均次於生活型態。

第 36 題

王先生參加口腔癌篩檢，表示嘴破未癒合長達一個月，且最近有位同事因口腔癌治療飽受身心之苦，很害怕自己也得了口腔癌，妻子鼓勵他參與篩檢。依據健康信念模式，下列何者是影響王先生採取預防行為的因素？①罹患性認知 ②嚴重性認知 ③行動線索 ④利益性認知 ⑤自我效能

第 37 題

有關水媒疾病之敘述，下列何者最不適當？
  1. （A）志賀氏桿菌是細菌性痢疾的致病原之一
  2. （B）阿米巴原蟲是副傷寒的致病原之一
  3. （C）小兒麻痺病毒是小兒麻痺症的致病原
  4. （D）鞭毛蟲是寄生蟲病的致病原之一

答案：（B）

詳解與考點

副傷寒（paratyphoid fever）的致病原為沙門氏桿菌屬（Salmonella Paratyphi），屬細菌，而非阿米巴原蟲（Entamoeba histolytica）；阿米巴原蟲引起的是阿米巴痢疾（amoebiasis）。B敘述錯誤，為最不適當。A志賀氏桿菌→細菌性痢疾、C小兒麻痺病毒→小兒麻痺、D鞭毛蟲→梨形鞭毛蟲病均正確。

第 38 題

臺灣淨水廠的供水系統目前廣泛使用何種消毒法？

  2. （B）臭氧消毒法
  3. （C）紫外線照射消毒法
  4. （D）銀離子消毒法

答案：（A）

台灣自來水廠目前最廣泛使用「氯氣消毒法」（chlorination），因其成本低、持續性消毒效果好、操作管理成熟。臭氧消毒效果強但無持續性且成本高；紫外線消毒無殘留消毒力；銀離子消毒費用昂貴且效果有限。因此 A 為正確答案。

第 39 題

有關紫外線防護之護理指導，下列何者最不適當？

  3. （C）紫外線指數6以上代表紫外線指數過高
  4. （D）太陽眼鏡鏡片顏色越深，防紫外線效果越佳

答案：（D）

詳解與考點

防紫外線效果取決於鏡片的「UV 過濾塗層」，而非鏡片顏色深淺。深色鏡片若無 UV 塗層，反而因瞳孔在暗環境下擴張，使更多 UV 進入眼睛，加重傷害。D「鏡片顏色越深，防紫外線越佳」為錯誤觀念，故最不適當。A高海拔紫外線強、B紫外線可致白內障、C指數6（高度危險）以上須防護，均為正確。

第 40 題

護理師進行家訪時發現，李奶奶因患有退化性骨關節炎而行動不便，李爺爺則患有高血壓和糖尿病，已定期回診並規律服藥控制。下列何者為此家庭最優先的個案管理目標？
  1. （A）鼓勵李奶奶進行關節置換術，提高自主生活能力
  2. （B）監測並管理李爺爺的服藥遵從性
  3. （C）提供居家安全評估，減少跌倒和其他意外事件的發生
  4. （D）安排社交活動，促進心理健康和社交互動

答案：（C）

詳解與考點

李奶奶行動不便、李爺爺雖有高血壓糖尿病但已規律服藥控制良好，此家庭最大風險為「跌倒與居家意外」。C「提供居家安全評估，減少跌倒」直接針對現存且最優先的安全風險，應列首位。A關節置換屬侵入性選擇、B李爺爺服藥已規律無需優先監管、D社交活動非緊急需求，均次於居家安全。

第 41 題

下列何者不屬於衛生福利部107年度原鄉健康不平等之改善策略行動計畫？
  1. （A）骨骼肌肉傷害
  2. （B）結核病
  3. （C）消化系癌症
  4. （D）三高防治

答案：（A）

詳解與考點

衛生福利部107年「原鄉健康不平等改善策略行動計畫」針對原住民族常見健康問題，涵蓋結核病防治、消化系癌症（含肝癌、胃癌）、三高（高血壓、高血糖、高血脂）防治等。「骨骼肌肉傷害」並未列入該計畫的主要改善項目，A為答案。

第 42 題

42歲王太太的姐姐被診斷乳癌，為此王太太感到煩惱和擔憂。下列護理指導何者最適當？①乳癌的危險因子，包括初經較晚、停經較早、高脂肪飲食等 ②40歲以上至未滿45歲具有乳癌家族史的女性每年一次免費乳房X光攝影檢查 ③建議王太太多運動、少進食高脂肪食物、心情放鬆和減低壓力等
  1. （A）僅③
  2. （B）①②③
  3. （C）僅①③
  4. （D）僅②③

答案：（A）

詳解與考點

本題問最適當的護理指導，答案為 A（僅③）。③正確：規律運動、減少高脂肪飲食、放鬆心情與紓解壓力，屬乳癌的一般健康促進與風險調整建議，內容正確。①錯誤：乳癌的危險因子應為「初經較早、停經較晚」（雌激素暴露時間延長）、高脂肪飲食、肥胖等；題目寫成「初經較晚、停經較早」方向相反，故①敘述錯誤。②錯誤：現行國健署提供「45～69 歲」婦女、以及「40～44 歲具乳癌家族史」者每 2 年 1 次免費乳房 X 光攝影；題目敘述的年齡與頻率（40 歲以上至未滿 45 歲具家族史者每年 1 次）與現行規定不符，故②不正確。綜合僅③正確，選 A。

第 43 題

下列那些是骨質疏鬆的危險因子？①體重過重 ②飲食含鹽量過少 ③缺乏運動 ④飲酒過量 ⑤甲狀腺機能亢進
  1. （A）①④⑤
  2. （B）②③④
  3. （C）②③⑤
  4. （D）③④⑤

答案：（D）

詳解與考點

骨質疏鬆危險因子包括：缺乏運動（③）、飲酒過量（④）、甲狀腺機能亢進（⑤，促進骨質流失）、低體重（非體重過重①）、高鹽飲食（非低鹽②）、吸菸、鈣質/維生素 D 不足、女性停經後等。①體重過重反而是骨密度保護因子；②飲食低鹽不是危險因子（高鹽才是）。故答案為③④⑤（D）。

第 44 題

有關校園霸凌之敘述，下列何者最適當？①個人或集體持續以語言、肢體動作或網路等直接對他人故意欺負或戲弄之行為 ②成績優秀者最不容易成為被霸凌的對象 ③長期遭受霸凌者可能出現反擊行為再去霸凌比自己弱勢的人 ④網路霸凌須有重複性，至少要有二次才算
  1. （A）①②③
  2. （B）僅①③
  3. （C）①③④
  4. （D）僅③④

答案：（B）

詳解與考點

①「持續以語言、肢體或網路欺負/戲弄」為霸凌的正確定義；③「受凌者反擊去霸凌弱者」（霸凌循環）為正確敘述。②「成績優秀者最不容易被霸凌」錯誤，優秀或特殊者反而常成為目標；④網路霸凌不限「至少二次」，單次廣泛散布即可構成。故正確項為①③，選 B（僅①③）。

第 45 題

健康促進醫院為提升醫護人員的身體活動量而推動院內運動計畫，護理人員反應：「下班太累，無法參加」，此反應為潘德（Pender）健康促進模式中的何項行為認知？
  1. （A）自覺自我效能
  2. （B）個人因素
  3. （C）自覺行動障礙
  4. （D）情境的影響

答案：（C）

詳解與考點

Pender 健康促進模式中，「自覺行動障礙」（perceived barriers to action）是指個人認為執行健康行為時所遭遇的困難或代價。護理人員以「下班太累，無法參加」回應，正是感受到行為障礙（疲勞＝障礙），故為 C。A「自覺自我效能」是對自身能否完成行為的信心；B「個人因素」是生理/心理/社會背景特質；D「情境影響」是外在環境對行為的影響。

第 46 題

根據全民健康保險規定，可接受安寧緩和醫療照護之末期病人的主要支付診斷條件，下列何者最不適當？
  1. （A）老年期及初老期器質性精神病態
  2. （B）慢性肝病及肝硬化
  3. （C）急性腎衰竭，未明示者
  4. （D）思覺失調症

答案：（D）

詳解與考點

本題問「最不適當」者，答案為 D。依全民健康保險安寧療護的主要支付診斷條件，除末期癌症與漸凍症外，尚納入多項慢性末期疾病。A（老年期及初老期器質性精神病態，含失智末期）、B（慢性肝病及肝硬化末期）、C（急性腎衰竭，未明示者）均屬健保安寧緩和醫療可列入的主要支付診斷範疇。D「思覺失調症」屬慢性精神疾病，並非健保安寧療護的末期支付診斷條件，故為最不適當者，選 D。本題重點在於辨識 A、B、C 三者皆為健保安寧療護收案診斷，唯獨 D 不屬此範疇。

第 47 題

85歲方奶奶獨居，巴氏量表評估為65分，目前無法自行洗澡和備餐，需有社區志工陪同就醫。若要申請長期照顧服務項目，何項最合適？
  1. （A）居家護理
  2. （B）居家服務
  3. （C）家庭托顧
  4. （D）居家喘息

答案：（B）

詳解與考點

本題問最合適的長照服務項目，答案為 B（居家服務）。方奶奶巴氏量表 65 分、無法自行洗澡與備餐，主要需要協助日常生活活動（如沐浴、備餐、陪同就醫等）的居家照顧，最適合「居家服務」（由照顧服務員到宅提供身體與日常生活照顧），故選 B。A 居家護理：提供的是護理專業服務（如管路更換、傷口護理、注射等），需有護理需求才適用，方奶奶主要為生活照顧需求，不以此為主。C 家庭托顧：是由合格照顧服務員在「其自家住所」提供類似家庭式的日間照顧，並非機構式日托，且需將個案帶往照顧服務員家中，與本題就近居家協助的需求不符。D 居家喘息：屬喘息服務，目的是讓「主要照顧者」獲得休息，方奶奶為獨居、無固定家庭照顧者，故不適用。

第 48 題

林女士76歲獨居，有多重慢性病史，不慎跌倒導致下肢嚴重骨折，經住院治療後病情穩定出院回家休養。有關個案管理師的職責，下列何者最不適當？
  1. （A）與林女士共同訂定計畫，使其能恢復獨立自主的生活
  2. （B）聯繫藥師提供藥物整合服務，指導林女士正確用藥
  3. （C）親自到府執行復健，並提供日常生活功能服務
  4. （D）定期電話訪視，替林女士安排就醫回診的交通接送

答案：（C）

詳解與考點

個案管理師的職責在評估、協調、連結及監督照護服務，而非直接執行臨床技術或治療。「親自到府執行復健」（C）屬物理治療師或職能治療師的職責，不應由個案管理師親自操作，故為最不適當。共同訂定計畫（A）、連繫藥師整合用藥（B）、安排就醫交通（D）均屬個管師正當協調職責。

第 49 題

林先生56歲，身高167公分，體重82公斤，喜歡吃滷五花肉，經常便秘，初次檢查結果顯示血中總膽固醇（total cholesterol）數值為245 mg/dL，三酸甘油酯（triglyceride）的數值為230 mg/dL。護理師提供的衛教重點下列那一項最適當？
  1. （A）建議優先服用藥物控制膽固醇及三酸甘油酯
  2. （B）衛教烹飪以快炒或油煎方式取代滷五花肉
  3. （C）衛教選擇高纖維飲食並減少高油脂的食物攝取
  4. （D）身體質量指數為體重過重，建議一天至少運動30分鐘

答案：（C）

詳解與考點

本題問最適當的衛教重點，答案為 C。林先生總膽固醇 245 mg/dL（偏高）、三酸甘油酯 230 mg/dL（偏高），且飲食偏好高油脂的滷五花肉，最優先且適當的非藥物衛教是「選擇高纖維飲食並減少高油脂食物攝取」，符合生活型態先行的處置原則，故 C 正確。A 不適當：初次發現血脂異常應先以飲食與運動等生活型態調整為主，不宜一開始就建議優先服藥。B 錯誤：以快炒或油煎取代滷五花肉並未減少油脂攝取，反而可能增加用油量，與降血脂目標相違。D 敘述不正確：林先生 BMI＝82÷(1.67²)≈29.4，依台灣成人肥胖標準（BMI≧27 為肥胖），應屬「肥胖」而非「過重」（過重為 24≦BMI<27），故 D 對 BMI 分類的描述錯誤；規律運動的建議雖正確，但分類錯誤使該選項不適當。綜上以 C 最適當。

第 50 題

有關氣喘之護理指導，下列何項最不適當？
  1. （A）以百葉窗替代布窗簾
  2. （B）避免情緒起伏太大
  3. （C）進行高強度運動，以增加肺活量
  4. （D）遵從醫囑按時用藥，不可自行停藥

答案：（C）

詳解與考點

氣喘護理原則在避免誘發因素、維持氣道通暢、遵循藥物治療。高強度運動（C）會促使過度換氣與支氣管收縮，易誘發運動誘發性氣喘，故為最不適當。應建議低至中強度有氧運動。百葉窗取代布窗簾（A）可減少積塵；避免情緒起伏（B）可降低自律神經誘發；按時用藥（D）為基本原則。
