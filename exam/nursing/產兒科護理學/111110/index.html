  3. （C）餵食時抬高頭部，餵食後應採左側臥或半坐臥位
  4. （D）手術後，易造成腸阻塞宜補充脂溶性維生素

答案：（B）

第 76 題

小明，14 歲，最近常抱怨大腿肌肉疼痛，經檢查後確認是生長痛（growingpain） ，下列護理措施何者 不適當？
  1. （A）建議小明應維持日常活動
  2. （B）減少參與太多不同種類的運動，適時休息以減緩疼痛
  3. （C）必要時，可依醫囑給予止痛藥，如 Acetaminophen
  4. （D）若每晚都持續嚴重疼痛，建議尋求醫療診治

答案：（B）

第 77 題

有關兒童罹患妥瑞氏症（Tourette’s disorder）的疾病特徵，下列敘述何者正確？

  2. （B）屬於精神心理疾病，會影響未來智能發展
  3. （C）不自主的聲語型抽動相當罕見
  4. （D）動作型抽動最常出現的是聳肩

第 78 題

小強，7 歲，罹患癲癇，有長期服用抗癲癇藥，包括 Phenytoin(Dilantin)及 Valproicacid(Depakine)，有 關藥物護理指導，下列敘述何者錯誤？

  3. （C）Dilantin 易造成牙齦增生，須執行良好的口腔護理
  4. （D）雖有定時服用藥物，仍鼓勵維持正常生活習慣，以預防發作

第 79 題

  4. （D）非進行性的神經病變

第 80 題

張小弟，5 個月大，因不慎跌落床下，診斷為顱內出血，有顱內壓增高（increase intracranial pressure, IICP）現象，有關其護理措施，下列敘述何者較不適當？

  3. （C）給予多喝水，增加體液容積以及腦組織灌流
  4. （D）保持床頭抬高約 30～45 度，維持頭部於中線位置，並避免壓迫頸靜脈
