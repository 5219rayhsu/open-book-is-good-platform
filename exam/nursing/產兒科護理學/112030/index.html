  2. （B）通常執行膽道切開術後，病童一般預後良好
  3. （C）若未治療，易出現肝硬化、脾腫大現象
  4. （D）糞便內經常含有血絲及暗紅色大便

答案：（C）

第 77 題

有關使用格拉斯哥氏昏迷量表（GlasgowComaScale,GCS）評估兒童意識程度，下列敘述何者正確？
  1. （A）評估嬰幼兒時，不需要父母陪同，避免干擾評估正確性
  2. （B）評估兒童對於環境刺激的瞳孔、語言和運動反應
  3. （C）少於或等於 7 分定義為昏迷狀態
  4. （D）最高分 13 分表示正常

答案：（C）

第 78 題

有關雷氏症候群（Reye’s syndrome）的臨床表徵，下列敘述何者錯誤？
  1. （A）肝臟酵素-胺基轉胺酶（AST、ALT）皆升高
  2. （B）高血糖
  3. （C）腦水腫
  4. （D）凝血酶原時間（PT）及部分凝血酶原時間（PTT）延長

答案：（B）

第 79 題

有關早產兒腦室內出血，下列護理處置之敘述，何者最適當？
  1. （A）抬高床頭 45 度以減少顱內壓
  2. （B）採取集中照護，減少不必要的打擾
  3. （C）提供具聲光刺激的環境，以增加大腦血流
  4. （D）提供高張藥物及溶液，以減低大腦血流量

答案：（B）

第 80 題

李小妹，診斷為痙攣型腦性麻痺（spastic type of cerebral palsy），有關其臨床表徵，下列敘述何者 正確？

  2. （B）伸展反射增加
  3. （C）肌腱反射降低
  4. （D）跨大步伐行走

答案：（B）
