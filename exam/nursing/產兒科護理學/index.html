第 1 題

有關我國母嬰親善醫院之認證基準，下列敘述何者錯誤？
  1. （A）提供孕婦哺餵母乳相關衛教及指導
  2. （B）在醫療需求下，可提供母乳以外的食物或飲料
  3. （C）施行親子同室，依嬰兒需求哺餵母乳
  4. （D）嬰兒哭泣時可提供安撫奶嘴

答案：（D）

詳解與考點

正解：本題問的是何者錯誤——判準是母嬰親善醫院十大措施明確規定不得提供安撫奶嘴給哺乳中的嬰兒，以免造成乳頭混淆、影響母乳哺餵成功率，D 選項「嬰兒哭泣時可提供安撫奶嘴」違反此規定，故為錯誤敘述。

A：提供孕婦哺餵母乳相關衛教及指導，符合母嬰親善醫院認證基準。 B：在醫療需求下可提供母乳以外的食物或飲料，符合認證基準中例外情形的規範。 C：施行親子同室、依嬰兒需求哺餵母乳，符合認證基準的核心措施。

本題考點：母嬰親善醫院認證基準的判準——十大措施強調哺乳衛教、親子同室、依需求哺乳，並禁止提供安撫奶嘴以避免乳頭混淆，僅在醫療需求下才例外提供母乳以外的食物或飲料。

第 71 題

罹患癌症之嬰幼兒，需要接受骨髓穿刺檢查，最常選擇的部位為何？
  1. （A）胸骨
  2. （B）股骨
  3. （C）脛骨
  4. （D）腰椎

答案：（C）

詳解與考點

正解：題眼在「嬰幼兒」與「骨髓穿刺部位」——判準是依年齡選擇骨髓腔足夠且避開胸骨等高風險部位的穿刺點。嬰幼兒常選脛骨近端進行骨髓穿刺，故選 C。

A：胸骨鄰近重要胸腔器官，且不作為嬰幼兒常用的骨髓穿刺部位，故非答案。

B：股骨不是本題所問嬰幼兒最常選擇的標準部位，故非答案。

D：腰椎穿刺是取得腦脊髓液的常用部位，並非骨髓穿刺位置。這是最強誘答——兩者都屬侵入性檢查，但檢體來源分別是骨髓與腦脊髓液。

本題考點：骨髓穿刺（bone marrow aspiration）須依年齡選擇安全骨性部位；嬰幼兒常用脛骨近端；腰椎穿刺（lumbar puncture）採集的是腦脊髓液，不能與骨髓穿刺混淆。

第 71 題

癌症病童接受治療期間，有關疫苗接種之敘述，下列何者最不適當？
  1. （A）可以接種流行性感冒疫苗
  2. （B）可以口服小兒沙賓疫苗
  3. （C）不可以接觸水痘病人
  4. （D）不可以接觸麻疹病人

答案：（B）

詳解與考點

正解：題眼在「癌症病童接受治療期間」——化學治療可能抑制免疫功能，疫苗判準是避免使用可在體內複製的活性疫苗。（B）口服小兒沙賓疫苗屬活性疫苗，最不適當，故選 B。接種時機受治療與免疫恢復狀態影響，須依現行指引及醫囑評估。

A：流行性感冒疫苗是否接種需依當時治療與免疫狀態評估；非活性疫苗通常較可能納入保護策略，故非答案。

C：水痘可造成免疫低下病童嚴重感染，應避免接觸病人，故非答案。

D：麻疹傳染力高，免疫低下病童應避免接觸病人，故非答案。這是最強誘答——避免暴露是正確感染防護，不等於以活性疫苗替代防護措施。

本題考點：免疫抑制（immunosuppression）會提高感染風險；活性疫苗（live vaccine）須依免疫狀態審慎評估；暴露預防（exposure prevention）是癌症治療期間的重要護理措施。

第 71 題

有關胎血循環的血流方向，下列敘述何者正確？
  1. （A）臍動脈血液流入靜脈導管
  2. （B）動脈導管血液流入主動脈
  3. （C）肺靜脈血液流入肺臟
  4. （D）左心室的血液經卵圓孔流入右心室

答案：（B）

詳解與考點

正解：題眼在「胎血循環」——胎兒肺尚未擔負氣體交換，因此血流會經三條分流通道繞過部分肝臟與肺臟。右心室流出的肺動脈血多經動脈導管進入降主動脈，再流向下半身與臍動脈，故選 B。

A：臍動脈是把胎兒血液送往胎盤的血管；由胎盤回流的含氧血是經臍靜脈，並可經靜脈導管進入下腔靜脈，故非答案。

C：肺靜脈的方向是由肺臟回流至左心房，不是流入肺臟；胎兒肺血流量雖少，血管方向仍不改變，故非答案。

D：卵圓孔的分流方向是右心房流向左心房，使較高氧合的下腔靜脈血優先進入左心系統；左心室既不經卵圓孔，也不流入右心室，故非答案。

本題考點：胎兒循環（fetal circulation）的三個分流為靜脈導管（ductus venosus）、卵圓孔（foramen ovale）與動脈導管（ductus arteriosus）；動脈導管方向是肺動脈至主動脈；臍靜脈回胎兒、臍動脈往胎盤。

第 71 題

白血病患童於誘導期階段的化學治療後，特別容易有那些問題？①感染 ②卡氏肺囊蟲肺炎 ③聽力 障礙 ④自發性出血
  1. （A）①②
  2. （B）①④
  3. （C）②③
  4. （D）③④

答案：（B）

詳解與考點

正解：題眼在「白血病誘導期化學治療後」——此期骨髓抑制會同時降低白血球與血小板，判準是感染與出血風險。①感染成立，因嗜中性白血球低下使防禦力下降；④自發性出血成立，因血小板低下使止血能力受損，故選 B。

A：①②含感染雖正確，但②卡氏肺囊蟲肺炎不是誘導期後所有病童必然特別容易出現的問題，仍須視免疫抑制情形與預防措施判斷。

C：②③把非必然的卡氏肺囊蟲肺炎與聽力障礙併列，未抓到骨髓抑制的主要結果。

D：③④中的④正確，但③聽力障礙通常不屬誘導期骨髓抑制的典型表現。最強誘答是（D）自發性出血正確卻搭配聽力障礙；組合題必須每一子敘述都成立。

本題考點：誘導期化學治療（induction chemotherapy）可造成骨髓抑制；嗜中性白血球低下（neutropenia）優先防感染；血小板低下（thrombocytopenia）須防自發性出血。
