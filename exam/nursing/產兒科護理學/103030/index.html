  2. （B）平躺時，雙手將大腿托高，再快速伸展小腿，檢查者感到阻力，病童感到疼痛
  3. （C）用手指沿著病童腳跟由外側往上向內劃線，會出現大拇指向上翹，其餘四趾張開成扇形
  4. （D）將病童的頭部從一邊轉至另一邊，眼球活動能成對比共軛朝向與頭部旋轉相反方向移動

答案：（A）

第 78 題

有關罹患腦性麻痺的兒童及其家庭之護理指導，下列敘述何者錯誤？
  1. （A）為預防下肢攣縮，可以雙手控制膝關節，將雙腿內轉合併
  2. （B）教導三指下顎控制法，協助病童閉嘴咀嚼及吞嚥
  3. （C）鼓勵病童獨立完成自我照顧工作，並適時給予肯定
  4. （D）鼓勵病童就學與其他兒童互動，積極擴展社交聯繫

答案：（A）

第 79 題

有關罹患成骨不全（osteogenesis imperfecta）兒童的醫療及護理指導，下列敘述何者錯誤？
  1. （A）通常以骨內固定物做骨髓內固定，以加強長骨
  2. （B）以脊椎固定桿合併骨水泥矯正部分脊椎變形
  3. （C）因骨骼脆弱易發生骨折，應儘量完全固定不動
  4. （D）在活動限制下執行主動運動，防止肌肉萎縮

答案：（C）
