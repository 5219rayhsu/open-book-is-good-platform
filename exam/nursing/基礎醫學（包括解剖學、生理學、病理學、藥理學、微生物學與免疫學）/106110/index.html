第 1 題

皮膚上所見到的雞皮疙瘩現象，與下列何者較無關係？
  1. （A）豎毛肌收縮
  2. （B）交感神經興奮
  3. （C）副交感神經興奮
  4. （D）天氣寒冷

答案：（C）

詳解與考點

正解：題眼在「雞皮疙瘩」與「較無關係」——豎毛反射由交感神經使豎毛肌收縮，常見於寒冷或情緒刺激。（C）副交感神經興奮不主導豎毛肌收縮，故為應選項。

A：豎毛肌收縮會使毛髮豎立，正是雞皮疙瘩的直接機制，故非答案。

B：交感神經興奮可啟動豎毛反應，故非答案。

D：天氣寒冷是常見誘發刺激，能經交感反應造成雞皮疙瘩，故非答案。

本題考點：豎毛反射（Piloerection Reflex）——豎毛肌收縮使毛髮豎立；交感神經（Sympathetic Nervous System）——主導此類寒冷或警覺相關反應，非副交感神經。

第 2 題

下列那一個腺體之組織學特徵具有膠體（colloid）的構造？
  1. （A）松果腺
  2. （B）腎上腺
  3. （C）甲狀腺
  4. （D）副甲狀腺

答案：（C）

詳解與考點

正解：題眼是組織學的「膠體（colloid）」——濾泡腔內儲存含甲狀腺球蛋白膠體，是甲狀腺的辨識特徵。（C）甲狀腺由許多充滿膠體的濾泡構成，故選 C。

A：松果腺可見鈣化的松果體砂，並非膠體濾泡，故非答案。

B：腎上腺有皮質分帶與髓質構造，沒有儲膠體的濾泡，故非答案。

D：副甲狀腺以主細胞等細胞群為主，沒有典型膠體濾泡。這是最強誘答——名稱同樣含「甲狀腺」，但判別要看是否有濾泡與膠體，故非答案。

本題考點：甲狀腺濾泡（Thyroid Follicle）——濾泡腔內含膠體；甲狀腺球蛋白（Thyroglobulin）——為甲狀腺激素合成與儲存相關物質。

第 3 題

下列何者可使眼球向下內側看及向內旋轉？
  1. （A）上直肌（superior rectus）
  2. （B）下直肌（inferior rectus）
  3. （C）上斜肌（superior oblique）
  4. （D）下斜肌（inferior oblique）

答案：（C）

詳解與考點

正解：題眼在「向下內側看及向內旋轉」——判準是各條眼外肌的下轉與旋轉方向。（C）上斜肌可使眼球內旋、下轉並外展，其中內旋與下轉正對應題幹所述動作，故選 C。

A：上直肌主要使眼球上轉，雖可內收與內旋，方向不是向下，故非答案。

B：下直肌可使眼球下轉與內收，但伴隨的是外旋，故非答案。

D：下斜肌的作用為外旋、上轉並外展，與題幹的向下及內旋相反。這是最強誘答——名稱含「下」容易被誤認為向下看，但肌名不是眼球運動方向，故非答案。

本題考點：上斜肌（Superior Oblique）——內旋、下轉、外展；下直肌（Inferior Rectus）——下轉、內收、外旋，須以旋轉方向鑑別。

第 4 題

下列頭顱骨骼，何者負責與頸椎形成關節？
  1. （A）枕骨
  2. （B）顳骨
  3. （C）蝶骨
  4. （D）篩骨

答案：（A）

詳解與考點

正解：題眼是「與頸椎形成關節」——顱骨與第一頸椎的寰枕關節由枕骨髁參與形成。（A）枕骨位於顱底，其枕骨髁與寰椎關節面相接，故選 A。

B：顳骨主要與下頜骨形成顳顎關節，並不與頸椎直接構成此關節，故非答案。

C：蝶骨位於顱底中央，參與顱骨多處連結，非寰枕關節組成，故非答案。

D：篩骨位於鼻腔與眼眶間，與頸椎沒有直接關節關係，故非答案。

本題考點：寰枕關節（Atlanto-occipital Joint）——由枕骨髁與寰椎形成，主要參與點頭動作；枕骨（Occipital Bone）——構成後顱窩與顱椎交界。

第 5 題

有關兩性骨盆的比較，下列何者男性大於女性？
  1. （A）骨盆入口的寬度
  2. （B）恥骨弓的夾角
  3. （C）骨盆出口的寬度
  4. （D）真骨盆的深度

答案：（D）

詳解與考點

正解：題眼在「男性大於女性」——女性骨盆需適應分娩，因此入口與出口較寬、恥骨弓角度較大；相對地男性真骨盆較深。（D）真骨盆的深度男性大於女性，故選 D。

A：女性骨盆入口較寬，以利胎兒通過，故（A）不是男性較大。

B：女性恥骨弓夾角通常較寬，故非答案。

C：女性骨盆出口較寬，故非答案。

本題考點：性別骨盆差異（Sexual Dimorphism of Pelvis）——女性骨盆入口、出口與恥骨弓較寬；真骨盆（True Pelvis）——男性較深且較窄，是骨盆型態辨識重點。

第 6 題

正常情形下，白血球中數量最多與直徑最大的分別是：
  1. （A）嗜中性球與嗜酸性球
  2. （B）嗜中性球與單核球
  3. （C）淋巴球與嗜酸性球
  4. （D）淋巴球與單核球

答案：（B）

詳解與考點

正解：題眼是「白血球中數量最多與直徑最大」——須分別判斷常態血液分類中的數量及細胞大小。（B）嗜中性球是周邊血中最常見的白血球；單核球為直徑最大的白血球，故選 B。

A：嗜中性球數量最多正確，但嗜酸性球不是直徑最大的白血球，故非答案。

C：淋巴球不是數量最多的白血球，嗜酸性球也非最大，故非答案。

D：單核球最大正確，但淋巴球不是數量最多。這是最強誘答——它正確保留了「最大」的一半，分辨關鍵在於兩個空格必須各自成立，故非答案。

本題考點：嗜中性球（Neutrophil）——周邊血最常見的白血球，主要參與急性發炎與吞噬；單核球（Monocyte）——白血球中體積最大，可分化為巨噬細胞。

第 7 題

下列何者直接由升主動脈分支出？
  1. （A）冠狀動脈
  2. （B）支氣管動脈
  3. （C）食道動脈
  4. （D）前肋間動脈

答案：（A）

詳解與考點

正解：題眼在「直接由升主動脈分支」——升主動脈起始處的主分支是供應心肌的左右冠狀動脈。（A）冠狀動脈自升主動脈的主動脈竇發出，故選 A。

B：支氣管動脈通常源自胸主動脈或其相關分支，不是升主動脈直接分支，故非答案。

C：食道動脈多由胸主動脈分出，故非答案。

D：前肋間動脈與胸壁血管系統相關，不是升主動脈直接分支。這是最強誘答——都屬胸腔器官供血，卻必須依血管起源判斷，故非答案。

本題考點：升主動脈（Ascending Aorta）——起始處發出冠狀動脈；冠狀循環（Coronary Circulation）——直接供應心肌血流。

第 8 題

下列有關男性生殖器官的敘述，何者錯誤？
  1. （A）曲細精管可以產生精子
  2. （B）精囊儲存並促使精子成熟
  3. （C）輸精管穿過腹股溝管進入骨盆腔
  4. （D）前列腺位在恥骨聯合的後面，膀胱的下方

答案：（B）

詳解與考點

正解：題眼在「男性生殖器官」與「何者錯誤」——精子在曲細精管生成，主要於副睪成熟與儲存；精囊則分泌精液成分。（B）精囊儲存並促使精子成熟錯把副睪的功能移到精囊，故為應選項。

A：曲細精管是精子生成的位置，故非答案。

C：輸精管自陰囊經腹股溝管進入骨盆腔，故非答案。

D：前列腺位於膀胱下方、恥骨聯合後方，符合其解剖位置，故非答案。

本題考點：曲細精管（Seminiferous Tubules）——精子發生部位；副睪（Epididymis）——精子成熟與儲存；精囊（Seminal Vesicle）——分泌精液成分，不負責精子成熟。

第 9 題

用力吸氣增大胸腔容積時，與下列何者的收縮無關？
  1. （A）腹肌
  2. （B）橫膈
  3. （C）外肋間肌
  4. （D）斜角肌

答案：（A）

詳解與考點

正解：題眼在「用力吸氣增大胸腔容積」與「無關」——用力吸氣需使胸廓上提或橫膈下降；腹肌收縮則主要協助用力呼氣。（A）腹肌收縮會增加腹壓並推動橫膈上升，不會增大胸腔容積，故為應選項。

B：橫膈收縮下降，能增加胸腔垂直徑，是吸氣主力，故非答案。

C：外肋間肌收縮可上提肋骨、增大胸腔容積，故非答案。

D：斜角肌可上提上肋骨，於用力吸氣時作為輔助肌，故非答案。

本題考點：用力吸氣（Forced Inspiration）——橫膈、外肋間肌及輔助吸氣肌使胸腔擴張；用力呼氣（Forced Expiration）——腹肌收縮增加腹壓，促使橫膈上升。

第 10 題

關於子宮的敘述，下列何者正確？
  1. （A）子宮肌層是由骨骼肌形成
  2. （B）子宮血液供應主要來自髂外動脈的分枝
  3. （C）子宮圓韌帶幫助子宮維持前傾
  4. （D）子宮內膜之基底層會於月經期剝落而排出

答案：（C）

詳解與考點

正解：題眼在「子宮的敘述何者正確」——要以肌層種類、血流來源、韌帶作用及月經時剝落層次交叉判斷。（C）子宮圓韌帶有助維持子宮前傾位置，故選 C。

A：子宮肌層主要為平滑肌，不是骨骼肌，故非答案。

B：子宮主要接受髂內動脈分支的供血，非髂外動脈分枝，故非答案。

D：月經期主要剝落的是子宮內膜功能層，基底層保留以利再生。這是最強誘答——「內膜剝落」方向正確，但錯在把功能層與基底層混淆，故非答案。

本題考點：子宮圓韌帶（Round Ligament of Uterus）——協助維持子宮前傾；子宮內膜（Endometrium）——功能層隨月經週期剝落，基底層保留並再生。

第 11 題

下列何者的內襯上皮不是單層柱狀？
  1. （A）胃
  2. （B）十二指腸
  3. （C）食道
  4. （D）降結腸

答案：（C）

詳解與考點

正解：題眼是「內襯上皮不是單層柱狀」——消化道從胃到大腸大多以單層柱狀上皮利於分泌與吸收；食道需承受食團摩擦。（C）食道內襯為複層鱗狀上皮，不是單層柱狀上皮，故選 C。

A：胃黏膜內襯為單層柱狀上皮，利於黏液分泌，故非答案。

B：十二指腸為單層柱狀上皮，具吸收與分泌功能，故非答案。

D：降結腸內襯亦為單層柱狀上皮，含較多杯狀細胞。這是最強誘答——大腸的皺褶與功能不同於小腸，但上皮類型仍屬單層柱狀，故非答案。

本題考點：複層鱗狀上皮（Stratified Squamous Epithelium）——適於抵抗摩擦，見於食道；單層柱狀上皮（Simple Columnar Epithelium）——常見於胃腸道，負責分泌與吸收。

第 12 題

下列何者分別與食道及十二指腸相接？
  1. （A）胃體部與胃底部
  2. （B）胃底部與幽門部
  3. （C）賁門部與幽門部
  4. （D）胃體部與賁門部

答案：（C）

詳解與考點

正解：題眼在「食道」與「十二指腸」分別銜接胃的哪一部位——判準是胃的入口與出口解剖。食道經胃食道交界進入（C）賁門部，胃內容物再經幽門部進入十二指腸，故選 C。

A、B、D：胃體部與胃底部主要構成胃的儲存與分泌區，並非食道或十二指腸的直接交界；把胃內部區域誤當成進出口，便無法同時對應兩個器官，故非答案。

本題考點：胃的分區與鄰接（gastric regions and connections）——賁門部接食道、幽門部接十二指腸；胃體部與胃底部不是消化道兩端的直接接口。

第 13 題

下列那兩種皆屬於腹膜後器官？
  1. （A）脾臟與肝臟
  2. （B）胰臟與升結腸
  3. （C）橫結腸與降結腸
  4. （D）盲腸與乙狀結腸

答案：（B）

詳解與考點

正解：題眼是辨認「腹膜後器官」——判準為器官是否位於腹膜腔後方、僅部分表面受腹膜覆蓋。（B）胰臟與升結腸都屬腹膜後位置，故選 B。

A：脾臟與肝臟均為腹膜內器官，表面大部分有臟腹膜覆蓋，故非答案。

C：降結腸雖為腹膜後器官，但橫結腸有腸繫膜、屬腹膜內器官；這是最強誘答，關鍵在結腸不同分段的腹膜關係不能一概而論。

D：盲腸與乙狀結腸均屬腹膜內器官，乙狀結腸尤有明顯腸繫膜，故非答案。

本題考點：腹膜關係（peritoneal relations）——胰臟、升結腸與降結腸為常見腹膜後器官；脾臟、肝臟、橫結腸、盲腸與乙狀結腸屬腹膜內位置。

第 14 題

支配骨骼肌的運動神經元細胞體是位於脊髓的何處？
  1. （A）白質外側柱
  2. （B）白質前柱
  3. （C）灰質外側角
  4. （D）灰質前角

答案：（D）

詳解與考點

正解：題眼是「支配骨骼肌的運動神經元細胞體」——判準是脊髓灰質的功能分區。下運動神經元細胞體位於（D）灰質前角，其軸突經前根離開脊髓並支配骨骼肌，故選 D。

A、B：白質外側柱與前柱以傳導上、下行神經纖維為主，並非骨骼肌運動神經元的細胞體所在地，故非答案。

C：灰質外側角主要與自律神經節前神經元相關，不是支配骨骼肌的體運動神經元位置；這是最強誘答，兩者同屬灰質，但功能系統不同。

本題考點：脊髓灰質分區（spinal cord gray matter）——前角為體運動神經元細胞體；外側角與自律神經功能相關；白質以神經傳導束為主。

第 15 題

負責調節眼球晶狀體曲度的神經是：
  1. （A）視神經
  2. （B）眼神經
  3. （C）動眼神經
  4. （D）滑車神經

答案：（C）

詳解與考點

正解：題眼在「調節晶狀體曲度」——判準是副交感神經使睫狀肌收縮、完成調節反應。動眼神經的副交感纖維經睫狀神經節支配睫狀肌，改變晶狀體曲度以利近距離聚焦，故選 C。

A：視神經負責將視網膜的感覺訊息傳入中樞，並不直接驅動睫狀肌收縮，故非答案。

B：眼神經是三叉神經的感覺分支，主要負責眼周感覺，沒有調節晶狀體的副交感運動功能，故非答案。

D：滑車神經支配上斜肌以控制眼球運動，不調節晶狀體；這是最強誘答，眼球運動肌與睫狀肌的調節功能須分開判斷。

  3. （C）血管張力素（angiotensin）
  4. （D）腎上腺皮質素（corticosteroid）

  1. （A）二氧化碳濃度升高、pH 值降低
  2. （B）二氧化碳濃度降低、pH 值降低
  3. （C）二氧化碳濃度升高、pH 值增大
  4. （D）二氧化碳濃度降低、pH 值增大

答案：（D）

詳解與考點

正解：題眼在玉山的「氧分壓不足」與「呼吸加快」——判準是過度換氣對二氧化碳與酸鹼的立即影響。通氣增加使二氧化碳排出增加，血中二氧化碳濃度降低；碳酸減少使 pH 值增大，形成呼吸性鹼化趨勢，故選 D。

A：二氧化碳升高、pH 值降低是通氣不足造成的呼吸性酸化方向，與呼吸加快相反，故非答案。

B：二氧化碳降低雖正確，但 pH 值應隨碳酸減少而增大，不會降低，故非答案。

本題考點：呼吸性酸鹼調節（respiratory acid-base regulation）——過度換氣使 PaCO2 降低、pH 上升；通氣不足使 PaCO2 升高、pH 下降。

  2. （B）乳糜蛋白酶（chymotrypsin）
  3. （C）肌凝蛋白輕鏈激酶（myosin-light chain kinase）
  4. （D）阿爾發澱粉酶（alpha amylase）

正解：題眼在紅血球內催化「二氧化碳與水形成碳酸」的酵素——判準是二氧化碳運輸反應的專一催化者。碳酸酐酶可快速催化 CO2 與 H2O 可逆形成 H2CO3，促進二氧化碳以碳酸氫根形式運輸，故選 A。

  3. （C）遠端食道鱗狀上皮發生腸化生（intestinal metaplasia）
  4. （D）遠端食道鱗狀上皮過度增生（hyperplasia）

答案：（C）

詳解與考點

正解：題眼在「波雷特氏食道」——此名詞定義的是長期胃食道逆流造成的上皮化生，而不是單純潰瘍或狹窄。遠端食道原本的鱗狀上皮被具有腸道特徵的柱狀上皮取代，稱為腸化生，故選 C。

本題考點：波雷特氏食道（Barrett esophagus）是遠端食道的腸化生（intestinal metaplasia）；化生（metaplasia）是成熟細胞型態的可逆性替換；其背景常為慢性胃食道逆流（gastroesophageal reflux）。

  3. （C）是治療第一型過敏反應（type I hypersensitivity reaction）的首選用藥
  4. （D）會活化肝臟的 α2 腎上腺素受體（α2 adrenergic receptor）而減少肝醣分解

詳解與考點

正解：題眼在「第一型過敏反應」——此為速發型過敏，可能迅速造成呼吸道水腫、支氣管收縮與循環衰竭。腎上腺素同時具有 α 與 β 受體作用，可改善血管通透性、支氣管收縮與低血壓，是全身性第一型過敏反應的首選用藥，故選 C。

本題考點：腎上腺素（epinephrine）是兒茶酚胺（catecholamine）；第一型過敏反應（type I hypersensitivity reaction）可引發過敏性反應；α 受體作用可提升血管張力，β2 受體作用可支氣管擴張。

第 51 題

吸入性全身麻醉劑的 MAC（minimal alveolar concentration）數值越小，其所代表的意義為何？
  1. （A）麻醉劑強度越大
  2. （B）麻醉劑強度越小
  3. （C）麻醉劑溶解度越低
  4. （D）腦部的吸收率越差

答案：（A）

詳解與考點

正解：題眼在「MAC 數值越小」——MAC 是使一定比例個體對手術刺激不產生動作反應所需的肺泡麻醉劑濃度。所需濃度越低，代表在較少濃度下就能達到相同麻醉效果，因此麻醉劑強度越大，故選 A。

B：麻醉劑強度越小反而需要較高濃度才能達效，會對應較大的 MAC。

C：MAC 描述的是效價或強度，不直接等同於吸入麻醉劑的血氣溶解度。

D：MAC 也不直接表示腦部吸收率；腦部濃度上升速度較受血氣分配係數等因素影響。這是最強誘答——MAC 與吸入麻醉劑的性質都相關，但「需要多少濃度才有效」與「濃度上升多快」是兩個不同判準。

本題考點：最小肺泡濃度（minimal alveolar concentration，MAC）用以比較吸入性麻醉劑強度；MAC 與麻醉效價（anesthetic potency）呈反比；血氣分配係數（blood-gas partition coefficient）主要影響誘導與恢復速度。

第 53 題

  1. （A）乙醯膽鹼酶（acetylcholine esterase）
  2. （B）多巴脫羧酶（DOPA decarboxylase）
  3. （C）多巴胺羧化酶（dopamine beta-hydroxylase）
  4. （D）單胺氧化酶（monoamine oxidase）

答案：（B）

詳解與考點

正解：題眼在 carbidopa 與 levodopa 併用——判準是阻止 levodopa 在周邊轉成多巴胺，讓更多藥物通過血腦障壁。carbidopa 抑制周邊的多巴脫羧酶（DOPA decarboxylase），減少 levodopa 的周邊代謝與相關不良反應，故選 B。

A：乙醯膽鹼酯酶負責分解乙醯膽鹼；抑制它會增加膽鹼性傳遞，與 carbidopa 的作用不符。

第 73 題

關於病毒逃避免疫攻擊的機制，下列敘述何者錯誤？

  2. （B）單純疱疹病毒以潛伏的方式，躲藏在神經細胞，以避免免疫系統的辨認
  3. （C）人類免疫不全病毒（Human immunodeficiency virus）是一種超級抗原（super antigen），可有效活 化 T 細胞免疫反應
  4. （D）有些病毒可抑制 MHC（major histocompatibility complex）第一類分子表達

答案：（C）

詳解與考點

正解：題眼在「病毒逃避免疫攻擊」與「何者錯誤」——要辨認病毒是藉改變抗原、潛伏或抑制抗原呈現來躲避免疫，而不是把自身誤稱為超級抗原。人類免疫不全病毒會感染並耗損 CD4 T 細胞，並非超級抗原；超級抗原是能非特異性大量活化 T 細胞的一類抗原，故選 C。

A：流行性感冒病毒可因基因片段重組產生抗原轉移，使表面抗原大幅改變，既有抗體可能難以辨識，故非答案。

B：單純疱疹病毒可潛伏於神經節細胞，在病毒基因表現很少的狀態下降低被免疫系統清除的機會，故非答案。

本題考點：抗原轉移（antigenic shift）；病毒潛伏（viral latency）；主要組織相容性複合體第一類（major histocompatibility complex class I, MHC I）抗原呈現。

A：許多抗菌藥物可源於微生物代謝產物；抗病毒藥物則多依病毒複製步驟設計，不能概括說多來自其他微生物代謝產物。

C：抗病毒藥物的研發受到病毒仰賴宿主細胞與選擇性困難的限制，不能說其發展遠快於抗菌藥物，故非答案。

D：病毒突變與選擇壓力可造成抗藥性，尤其在長期治療或複製快速的病毒感染中更須注意，故非答案。這是最強誘答——藥物可抑制病毒不代表病毒不會適應，抗藥性正是抗病毒治療的重要限制。

本題考點：選擇性毒性（selective toxicity）；抗病毒治療（antiviral therapy）的宿主毒性；抗藥性（drug resistance）。

第 80 題

下列有關犬蛔蟲（Toxocara canis）之敘述，何者正確？
  1. （A）人吃入它的蟲卵後，蟲卵會在小腸孵化為成蟲而造成病害
  2. （B）蟲卵進入人體會孵化成幼蟲，可移行到肝臟、肺臟造成病害
  3. （C）可以檢查糞便中蟲卵，作為診斷依據
  4. （D）蟲卵進入人體後，很快就會被排出體外

答案：（B）

詳解與考點

正解：題眼在「犬蛔蟲」與「人體內的蟲卵」——判準是人類為偶然宿主，幼蟲可移行但通常不發育成腸道成蟲。蟲卵進入人體後孵化為幼蟲，可移行至肝臟、肺臟等組織造成病害，故選 B。

A：人在犬蛔蟲生活史中不是適合完成成蟲發育的終宿主，幼蟲不會在人體小腸發育成成蟲，故非答案。

C：人體內通常沒有成蟲產卵，因此糞便蟲卵檢查不是診斷人類犬蛔蟲症的主要依據，故非答案。這是最強誘答——糞便找蟲卵適用於不少腸道蠕蟲，但須先確認人類是否為會排卵的終宿主。

D：幼蟲可在組織中移行而非迅速排出，正是其造成內臟幼蟲移行症的原因，故非答案。

本題考點：犬蛔蟲（Toxocara canis）；偶然宿主（accidental host）；內臟幼蟲移行症（visceral larva migrans）。
