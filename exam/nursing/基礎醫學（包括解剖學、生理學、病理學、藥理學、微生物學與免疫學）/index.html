第 1 題

下列何種蛋白質屬於初級主動運輸子（active transporter）？
  1. （A）鈣通道
  2. （B）鈣依賴性鉀通道
  3. （C）鈉鈣交換子
  4. （D）鈣幫浦

答案：（D）

詳解與考點

正解：本題要分的是運輸蛋白的能量來源。初級主動運輸子直接水解 ATP 取得能量，將離子逆濃度梯度推送；（D）鈣幫浦（細胞膜的 PMCA 與肌漿網的 SERCA）正是以本身的 ATP 酶活性驅動鈣離子外送或回收肌漿網，故選 D。

A：鈣通道是通道蛋白，開啟時離子順電化學梯度流動，屬被動運輸，不耗能。

B：鈣依賴性鉀通道以細胞內鈣濃度作為開關訊號，本質仍是讓鉀離子順梯度流出的通道。這是最強誘答——名稱中的「鈣依賴性」讀來像是有耗能的調控，分辨關鍵在於鈣在此擔任的是開關訊號，不是能量來源。

C：鈉鈣交換子屬次級主動運輸，借用鈉鉀幫浦事先建立的鈉離子梯度所儲存的位能來搬運鈣，並不直接水解 ATP。它與正解同樣逆梯度運鈣，兩者差在能量是直接來自 ATP 或間接來自既有的離子梯度。

本題考點：膜運輸的三分判準——通道（channel）為順梯度被動運輸；初級主動運輸（primary active transport）直接水解 ATP，如鈣幫浦（Ca-ATPase）與鈉鉀幫浦；次級主動運輸（secondary active transport）如鈉鈣交換子（Na/Ca exchanger），借用既有離子梯度的位能。

第 45 題

法蘭西氏土倫桿菌（Francisella tularensis）主要感染何種人體細胞？
  1. （A）巨噬細胞
  2. （B）上皮細胞
  3. （C）基底細胞
  4. （D）自然殺手細胞

答案：（A）

詳解與考點

正解：題眼在「法蘭西氏土倫桿菌主要感染」——考其在宿主內存活的細胞嗜性。法蘭西氏土倫桿菌是兼性細胞內菌，主要侵入並在巨噬細胞內存活與複製，藉此逃避部分宿主防禦，故選 A。

B：上皮細胞是許多病原體的入侵或附著位置，但不是本菌最具代表性的細胞內寄生目標。

C：基底細胞屬上皮組織的再生細胞，並非土倫病感染的典型主要宿主細胞。

D：自然殺手細胞是先天免疫效應細胞，負責殺傷受感染細胞；它看似同樣涉及感染免疫，實際上是宿主防禦者而非本菌主要感染靶細胞。

本題考點：法蘭西氏土倫桿菌（Francisella tularensis）為兼性細胞內菌（facultative intracellular bacterium）；巨噬細胞（macrophage）是其重要宿主細胞；自然殺手細胞（natural killer cell）屬先天免疫效應細胞。

第 79 題

下列何種酵素與麴菌屬（Aspergillus）之毒性無關？
  1. （A）彈性蛋白酶
  2. （B）葉酸酶
  3. （C）磷脂酶
  4. （D）過氧化氫酶

答案：（B）

詳解與考點

正解：題眼在「與麴菌屬毒性無關」——麴菌侵入組織時可藉彈性蛋白酶、磷脂酶等破壞宿主結構，並以過氧化氫酶抵抗氧化殺菌；葉酸酶不是此類毒力機轉，故 B 為應選項。

A：彈性蛋白酶可分解彈性纖維，有助麴菌穿透組織與血管。

C：磷脂酶可破壞細胞膜磷脂，與組織侵襲及損傷有關。

D：過氧化氫酶可分解過氧化氫，幫助真菌抵抗宿主吞噬細胞的氧化壓力。這是最強誘答——它不是直接分解組織的酶，卻是抵禦宿主殺菌的重要防禦因子。

本題考點：麴菌屬（Aspergillus）的彈性蛋白酶（elastase）與磷脂酶（phospholipase）促進組織損傷；過氧化氫酶（catalase）協助抵抗氧化壓力；毒力因子須以其是否有助侵入或免疫逃避判定。

第 53 題

下列何者不是治療骨質疏鬆症的藥物？
  1. （A）Betamethasone
  2. （B）Calcitonin
  3. （C）Bisphosphonates
  4. （D）Teriparatide

答案：（A）

詳解與考點

正解：題眼在「不是治療骨質疏鬆症」——（A）Betamethasone 是糖皮質類固醇，長期使用反而可增加骨質流失與骨折風險，並非骨質疏鬆症的治療藥物，故選 A。

B：Calcitonin 可抑制蝕骨細胞活性，為骨代謝相關治療選項之一。

C：Bisphosphonates 可抑制蝕骨細胞介導的骨吸收，是骨質疏鬆症常用藥物類別。

D：Teriparatide 為副甲狀腺素相關的骨形成促進治療，可用於特定骨質疏鬆症病人。

本題考點：骨質疏鬆症（osteoporosis）藥物可分為抑制骨吸收與促進骨形成；Bisphosphonates 抑制骨吸收；Teriparatide 促進骨形成；糖皮質類固醇（glucocorticoids）會增加骨質流失風險。

第 27 題

下列有關血壓的敘述，何者錯誤？
  1. （A）小動脈血壓與主動脈血壓相似
  2. （B）平均動脈壓較接近舒張壓而非收縮壓
  3. （C）通常血壓指的是動脈壓
  4. （D）脈壓（Pulse pressure）通常比舒張壓小

答案：（A）

詳解與考點

正解：題眼在「何者錯誤」與「小動脈血壓」——小動脈管徑小、是循環系統中阻力最高的節段，血液流經時壓力顯著下降，因此小動脈血壓不會與主動脈血壓相似，故 A 為應選項。

B：心臟舒張期較收縮期長，平均動脈壓在一般心率下較接近舒張壓，是正確敘述，故非答案。

C：臨床未特別註明時，血壓通常指動脈壓，是正確敘述，故非答案。

D：脈壓是收縮壓與舒張壓之差，在一般狀態通常小於舒張壓，是正確敘述，故非答案。

本題考點：小動脈（arteriole）是體循環主要阻力血管，壓力在此下降最明顯；平均動脈壓（mean arterial pressure）較接近舒張壓；脈壓（pulse pressure）為收縮壓與舒張壓之差。
