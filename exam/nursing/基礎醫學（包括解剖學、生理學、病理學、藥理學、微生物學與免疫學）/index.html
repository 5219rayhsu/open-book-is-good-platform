第 1 題

下列何種蛋白質屬於初級主動運輸子（active transporter）？
  1. （A）鈣通道
  2. （B）鈣依賴性鉀通道
  3. （C）鈉鈣交換子
  4. （D）鈣幫浦

本題送分，無標準答案

第 40 題

下列何種成癮性物質是透過血清素受體來產生幻覺？
  1. （A）古柯鹼
  2. （B）安非他命
  3. （C）麥角酸二乙胺（LSD）
  4. （D）大麻

答案：（C）

詳解與考點

正解：題眼在「透過血清素受體產生幻覺」——這是典型迷幻劑的作用機轉。麥角酸二乙胺（LSD）主要作用於血清素受體，特別與 5-HT2A 受體相關，改變知覺與認知而產生幻覺，故選 C。

A：古柯鹼主要阻斷單胺類神經傳導物質再回收，增強多巴胺訊號，屬中樞刺激劑，非以血清素受體致幻為主。

B：安非他命促進兒茶酚胺釋放，主要影響多巴胺與正腎上腺素系統，並非本題所問的血清素受體機轉。

D：大麻的主要活性成分作用於大麻素受體（cannabinoid receptors）。它也可能改變知覺而像是致幻物質，錯在受體種類不同，故非答案。

本題考點：麥角酸二乙胺（LSD）為迷幻劑（hallucinogen）；5-HT2A receptor 與迷幻作用相關；古柯鹼與安非他命屬中樞刺激劑（central nervous system stimulants）。

第 69 題

包氏螺旋體（Borrelia）感染除了萊姆病（Lyme disease）外，主要造成何種人類疾病？
  1. （A）梅毒
  2. （B）腦膜炎
  3. （C）回歸熱
  4. （D）食物中毒

答案：（C）

詳解與考點

正解：題眼在 Borrelia——此屬螺旋體除可引起萊姆病外，另一個重要疾病是反覆出現發燒發作的回歸熱，故選 C。

A：梅毒由 Treponema pallidum 引起，雖同為螺旋體，但不是 Borrelia 造成，故非答案。

B：腦膜炎可由多種細菌或病毒引起，並非 Borrelia 除萊姆病外的主要代表性疾病，故非答案。

D：食物中毒通常與食入病原體或毒素有關，非 Borrelia 的典型傳播與疾病型態，故非答案。

本題考點：Borrelia 為螺旋體（spirochete），可造成萊姆病（Lyme disease）與回歸熱（relapsing fever）；螺旋體疾病鑑別須連結病原體與代表性疾病，例如 Treponema pallidum 對應梅毒。

第 39 題

下列那條血管與硬腦膜外血腫（epidural hematoma）關聯性最大？
  1. （A）上矢狀靜脈（superior sagittal vein）
  2. （B）中腦膜動脈（middle meningeal artery）
  3. （C）腦膜橋靜脈（bridging vein）
  4. （D）前大腦動脈（anterior cerebral artery）

答案：（B）

詳解與考點

正解：題眼在「硬腦膜外血腫」——顳側頭部外傷可撕裂位於硬腦膜與顱骨間的（B）中腦膜動脈，動脈出血迅速累積形成雙凸透鏡狀血腫，故選 B。

A：上矢狀靜脈竇是硬腦膜靜脈竇，並非硬腦膜外血腫最典型的受傷血管。

C：腦膜橋靜脈撕裂較典型地造成硬腦膜下血腫。這是最強誘答——兩者都可在頭部外傷後出血，分辨關鍵在於橋靜脈對應硬腦膜下血腫，中腦膜動脈對應硬腦膜外血腫。

D：前大腦動脈病變可造成特定腦區缺血或出血，但不是此類外傷性血腫的典型來源。

本題考點：硬腦膜外血腫（epidural hematoma）常與中腦膜動脈（middle meningeal artery）破裂相關；硬腦膜下血腫（subdural hematoma）常與橋靜脈（bridging vein）撕裂相關。

第 11 題

大腸的那一構造，是由縱走的平滑肌束構成？
  1. （A）結腸袋
  2. （B）結腸帶
  3. （C）腸脂垂
  4. （D）肛柱

答案：（B）

詳解與考點

正解：題眼在「由縱走的平滑肌束構成」——大腸外肌層的縱走肌並非均勻分布，而是集中成三條明顯的縱行帶，稱為結腸帶，故選 B。

A：結腸袋是結腸壁受結腸帶牽拉形成的囊狀膨出，不是平滑肌束本身，故非答案。這是最強誘答——它與結腸帶密切相關，但題目問的是構成它的肌束。

C：腸脂垂是附著於結腸表面的腹膜脂肪組織，非肌肉構造，故非答案。

D：肛柱位於肛管黏膜，是縱向黏膜皺襞，非大腸外層的平滑肌束，故非答案。

本題考點：結腸帶（taeniae coli）；結腸袋（haustra）的形成；大腸外肌層（muscularis externa）的特殊排列。
