包氏螺旋體（Borrelia）感染除了萊姆病（Lyme disease）外，主要造成何種人類疾病？

  2. （B）腦膜炎
  3. （C）回歸熱
  4. （D）食物中毒

  2. （B）中腦膜動脈（middle meningeal artery）
  3. （C）腦膜橋靜脈（bridging vein）
  4. （D）前大腦動脈（anterior cerebral artery）

答案：（B）
