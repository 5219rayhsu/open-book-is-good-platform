第 1 題

蘭氏細胞（Langerhans’cell）主要功能為何？
  1. （A）免疫及吞噬
  2. （B）吸收紫外線
  3. （C）接受感覺
  4. （D）儲存能量

答案：（A）

詳解與考點

正解：題眼在「蘭氏細胞」——表皮的蘭氏細胞是抗原呈現細胞，負責攝取、處理抗原並啟動局部免疫反應，故選 A。

B：吸收紫外線主要與黑色素及黑色素細胞相關，不是蘭氏細胞的主要功能。

C：接受感覺主要由感覺神經末梢與梅克爾細胞等構造參與，並非蘭氏細胞。這是最強誘答——兩者都位於皮膚，分辨關鍵在蘭氏細胞處理的是抗原，不是觸覺訊號。

D：儲存能量主要是皮下脂肪組織的功能，與表皮免疫細胞無關。

本題考點：蘭氏細胞（Langerhans cell）是表皮抗原呈現細胞；抗原呈現（antigen presentation）連結先天與適應性免疫；皮膚感覺（cutaneous sensation）由感覺受器與神經末梢負責。

第 2 題

關於腦下垂體前葉的分泌物，下列何者錯誤？
  1. （A）促甲狀腺素（thyroid-stimulating hormone）
  2. （B）促腎上腺皮質素（adrenocorticortropic hormone）
  3. （C）生長激素（growth hormone）
  4. （D）催產素（oxytocin）

答案：（D）

詳解與考點

正解：題眼在「腦下垂體前葉」與「錯誤」——須分辨前葉與後葉釋放的激素。催產素由下視丘合成、經腦下垂體後葉釋放，不是前葉分泌物，故 D 為應選項。

A：促甲狀腺素由腦下垂體前葉分泌，可刺激甲狀腺，故正確。

B：促腎上腺皮質素是前葉激素，可作用於腎上腺皮質，故非答案。

C：生長激素由前葉分泌，與生長及代謝調節有關。這是最強誘答——它與催產素同樣是常見內分泌激素，但分泌部位不同，不能因都受下視丘調控而混為一談。

本題考點：腦下垂體前葉（anterior pituitary）分泌促甲狀腺素、促腎上腺皮質素與生長激素；腦下垂體後葉（posterior pituitary）釋放催產素；下視丘（hypothalamus）負責合成催產素。

第 3 題

下列何者具有產生大量熱的功能？
  1. （A）骨骼
  2. （B）肌肉
  3. （C）循環
  4. （D）神經

答案：（B）

詳解與考點

正解：題眼在「產生大量熱」——骨骼肌收縮時代謝率大幅上升，顫抖產熱更可迅速增加熱生成，故選 B。

A：骨骼主要提供支持、保護與礦物質儲存，並非主要的快速產熱器官。

C：循環系統負責把熱量運送至全身並參與散熱調節，不是大量製造熱的來源。

D：神經系統可調節體溫反應，但不直接藉收縮形成大量熱。這是最強誘答——神經系統會啟動顫抖反應，真正產熱的效應器仍是肌肉。

本題考點：骨骼肌（skeletal muscle）收縮是重要產熱來源；顫抖產熱（shivering thermogenesis）透過不自主肌肉活動增加熱生成；體溫調節（thermoregulation）由神經調控與效應器共同完成。

第 4 題

下列何者的收縮與在髖關節處屈曲大腿最有關係？
  1. （A）股直肌
  2. （B）閉孔外肌
  3. （C）股內側肌
  4. （D）股外側肌

答案：（A）

詳解與考點

正解：題眼在「髖關節處屈曲大腿」——股直肌跨越髖、膝兩關節，除伸膝外也能協助屈髖，故選 A。

B：閉孔外肌主要使大腿在髖關節外旋，並非屈髖的主要肌肉。

C：股內側肌屬股四頭肌，主要作用為伸展膝關節，因未跨髖關節而不負責屈髖。

D：股外側肌同樣主要伸膝。這是最強誘答——它與股直肌同屬股四頭肌，分辨關鍵是股直肌跨過髖關節，股外側肌則否。

本題考點：股直肌（rectus femoris）可屈髖並伸膝；雙關節肌（biarticular muscle）可作用於兩個關節；股四頭肌（quadriceps femoris）多數成員以伸膝為主。

第 5 題

下列何者是尺骨的表面標記？
  1. （A）鷹嘴（olecranon）
  2. （B）滑車（trochlea）
  3. （C）小頭（capitulum）
  4. （D）結節（tubercle）

答案：（A）

詳解與考點

正解：題眼在「尺骨的表面標記」——鷹嘴位於尺骨近端、形成肘部後方可觸及的突出，故選 A。

B：滑車是肱骨遠端與尺骨關節面的構造名稱，並非尺骨本身的表面標記。

C：小頭位於肱骨遠端外側，與橈骨頭關節，故非尺骨構造。

D：結節是泛用的骨表面描述，未特定指向尺骨；本題所問的明確尺骨標記為鷹嘴。這是最強誘答——骨頭都可能有結節，但解剖辨識要選具特異性的名稱。

本題考點：尺骨（ulna）近端有鷹嘴；肱骨滑車（trochlea）與尺骨相接；肱骨小頭（capitulum）與橈骨頭相接。

第 6 題

心臟的電位傳導系統中，何構造位於冠狀竇開口處？
  1. （A）竇房結
  2. （B）房室結
  3. （C）希氏束
  4. （D）蒲金氏纖維

答案：（B）

詳解與考點

正解：題眼在「冠狀竇開口處」——房室結位於右心房下部、鄰近冠狀竇開口與房室間隔，是心房傳導延遲後通往心室的樞紐，故選 B。

A：竇房結位於右心房上部、接近上腔靜脈開口，並非冠狀竇開口處。

C：希氏束由房室結向下延續，穿過纖維骨架進入室間隔，位置較下方。

D：蒲金氏纖維分布於心室內膜下，負責快速傳至心室肌。這是最強誘答——它也屬傳導系統，但定位在心室，不能與右心房的房室結混淆。

本題考點：房室結（atrioventricular node）鄰近冠狀竇開口；竇房結（sinoatrial node）是主要節律點；心臟傳導系統（cardiac conduction system）依序將興奮傳至心室。

第 7 題

下列器官何者接受腸繫膜下動脈的血液供應？
  1. （A）迴腸
  2. （B）盲腸
  3. （C）升結腸
  4. （D）乙狀結腸

答案：（D）

詳解與考點

正解：題眼在「腸繫膜下動脈」——此動脈供應後腸，範圍包括遠端大腸與乙狀結腸，故選 D。

A：迴腸屬中腸，主要接受腸繫膜上動脈供應。

B：盲腸屬中腸，血流主要來自腸繫膜上動脈分支。

C：升結腸亦屬中腸供應範圍。這是最強誘答——它與乙狀結腸同為大腸，分辨關鍵不在器官名稱，而在中腸與後腸的胚胎分區。

本題考點：腸繫膜下動脈（inferior mesenteric artery）供應後腸；腸繫膜上動脈（superior mesenteric artery）供應中腸；乙狀結腸（sigmoid colon）屬後腸範圍。

第 8 題

當細菌侵入體內，何種血球細胞會轉變成巨噬細胞以吞噬細菌？
  1. （A）巨核細胞
  2. （B）肥胖細胞
  3. （C）B 淋巴球
  4. （D）單核球

答案：（D）

詳解與考點

正解：題眼在「轉變成巨噬細胞」——血液中的單核球進入組織後會分化為巨噬細胞，執行吞噬與抗原呈現，故選 D。

A：巨核細胞位於骨髓，主要產生血小板，並不分化為巨噬細胞。

B：肥胖細胞參與過敏與發炎介質釋放，不是巨噬細胞的前驅細胞。

C：B 淋巴球主要參與體液性免疫，可分化為漿細胞製造抗體。這是最強誘答——B 淋巴球也能作為抗原呈現細胞，但不會轉變成吞噬細菌的巨噬細胞。

本題考點：單核球（monocyte）進入組織後分化為巨噬細胞；巨噬細胞（macrophage）執行吞噬作用；體液性免疫（humoral immunity）主要由 B 淋巴球參與。

第 9 題

男性睪丸中，何種細胞主要負責分泌雄性激素（androgen）？
  1. （A）精原母細胞（spermatogonia）
  2. （B）支持細胞（sustentocyte；Sertoli cell）
  3. （C）間質細胞（interstitial cell；Leydig cell）
  4. （D）精細胞（spermatid）

答案：（C）

詳解與考點

正解：題眼在「分泌雄性激素」——睪丸間質中的 Leydig 細胞受促性腺激素刺激後分泌雄性激素，故選 C。

A：精原母細胞是精子發生的生殖細胞，主要功能為分裂與分化，不分泌雄性激素。

B：支持細胞支持精子發育、形成血睪障壁並分泌調節性物質，但不是雄性激素主要來源。

D：精細胞是精子成熟過程的細胞階段，並無內分泌功能。這是最強誘答——支持細胞與間質細胞都在睪丸，分辨關鍵是前者支持生精，後者分泌雄性激素。

本題考點：間質細胞（Leydig cell）分泌雄性激素；支持細胞（Sertoli cell）支持精子發生；精子發生（spermatogenesis）發生於曲細精管。

第 10 題

關於氣管（trachea）的敘述，下列何者正確？
  1. （A）上皮是具有纖毛的單層柱狀上皮（ciliated simple columnar epithelium）
  2. （B）軟骨組織是外型呈 C 型的彈性軟骨（elastic cartilage）
  3. （C）氣管軟骨的後方有屬於骨骼肌的氣管肌（trachealis）連結
  4. （D）氣管的血液供應部分來自支氣管動脈（bronchial arteries）

答案：（D）

詳解與考點

正解：題眼在「氣管的血液供應」——氣管的營養血流部分來自支氣管動脈，故選 D。

A：氣管黏膜為假複層纖毛柱狀上皮，不是單層柱狀上皮。

B：氣管軟骨呈 C 型，但屬透明軟骨，不是彈性軟骨。

C：氣管肌位於軟骨環後方，但為平滑肌，不是骨骼肌。這是最強誘答——它正確指出後方有氣管肌，錯在肌肉組織類型；位置正確不代表整句正確。

本題考點：氣管（trachea）覆蓋假複層纖毛柱狀上皮；氣管軟骨（tracheal cartilage）為 C 型透明軟骨；氣管肌（trachealis）為平滑肌。

第 11 題

腎臟（kidney）的何部位具有腎絲球（glomerulus）的構造？
  1. （A）腎皮質（renal cortex）
  2. （B）小腎盞（minor calyx）
  3. （C）腎錐體（renal pyramid）
  4. （D）腎乳頭（renal papilla）

答案：（A）

詳解與考點

正解：題眼在「腎絲球」——腎絲球與鮑氏囊共同構成腎小體，腎小體位於腎皮質，故選 A。

B：小腎盞收集腎乳頭流出的尿液，並沒有腎絲球。

C：腎錐體屬腎髓質，主要可見腎小管與集合管的走行，而非腎小體。

D：腎乳頭是腎錐體尖端、尿液流入小腎盞之處。這是最強誘答——它同樣屬腎內構造，但功能是排出已形成的尿液，不是濾過血液。

本題考點：腎皮質（renal cortex）含腎小體；腎絲球（glomerulus）是濾過血液的毛細血管叢；腎髓質（renal medulla）以腎錐體與集合管為主。

第 12 題

有關小腸絨毛的敘述，下列何者錯誤？
  1. （A）由小腸上皮細胞形成之指狀突起
  2. （B）絨毛中心僅有一條乳糜管，吸收所有的營養物質並送入血液中
  3. （C）其功能為增加消化吸收之面積
  4. （D）在十二指腸中可見到

答案：（B）

詳解與考點

正解：題眼在「小腸絨毛」與「錯誤」——絨毛中央雖有乳糜管，但脂質與多數水溶性營養素的吸收、運輸途徑不同。乳糜管主要吸收脂質，經淋巴系統運送，不會吸收所有營養物質後都送入血液，故 B 為應選項。

A：小腸絨毛是黏膜向腸腔形成的指狀突起，表面覆以單層柱狀上皮，中央含固有層、微血管與乳糜管，敘述方向成立，故非答案。

C：絨毛能增加小腸黏膜表面積，提升消化後營養物的吸收效率，故非答案。

D：十二指腸的小腸黏膜可見絨毛。這是最強誘答——十二指腸亦有特徵性腺體，但不影響其具有絨毛這項正確敘述。

本題考點：小腸絨毛（intestinal villi）為黏膜層的指狀突起，與上皮細胞頂端的微絨毛（microvilli）分屬不同層級；乳糜管（lacteal）主要運輸吸收後脂質；門靜脈循環（portal circulation）承接多數水溶性營養物。

第 13 題

舌頭表面的何種乳頭會角質化，嚴重時會出現舌苔的現象？
  1. （A）絲狀乳頭
  2. （B）蕈狀乳頭
  3. （C）輪廓狀乳頭
  4. （D）葉狀乳頭

答案：（A）

詳解與考點

正解：題眼在「會角質化」與「舌苔」——絲狀乳頭數量多、表面角化，角質堆積時可呈現舌苔，故選 A。

B：蕈狀乳頭散布於舌前部，含味蕾，外形較圓鈍，並非舌苔的主要來源。

C：輪廓狀乳頭位於舌根附近、呈排列成列的大乳頭，主要與味覺相關。

D：葉狀乳頭位於舌側後方。這是最強誘答——各種乳頭都在舌表面，分辨關鍵是會明顯角化並形成舌苔的是絲狀乳頭。

本題考點：絲狀乳頭（filiform papillae）具有角化特性；舌苔（tongue coating）與角質及附著物堆積相關；味蕾（taste buds）主要分布於非絲狀乳頭。

第 14 題

有關牙齒之敘述，下列何者錯誤？
  1. （A）一般而言，乳齒為 20 顆，恆齒 32 顆
  2. （B）乳齒中沒有犬齒
  3. （C）第二前臼齒為恆齒
  4. （D）牙齒固定於上下頷骨

答案：（B）

詳解與考點

正解：題眼在「乳齒」與「錯誤」——乳齒的齒列包含門齒、犬齒與臼齒，因此「乳齒中沒有犬齒」錯誤，故 B 為應選項。

A：一般乳齒共 20 顆、恆齒通常為 32 顆，敘述正確。

C：第二前臼齒出現在恆齒列，乳齒列沒有前臼齒，故非答案。

D：牙齒藉牙周組織固定於上下頷骨的齒槽內，敘述正確。這是最強誘答——牙齒雖與頷骨相連，但不是直接骨性融合，而是透過牙周組織固定。

本題考點：乳齒（deciduous teeth）包含犬齒；恆齒（permanent teeth）包含前臼齒；牙周組織（periodontium）將牙齒固定於齒槽骨。

第 15 題

下列何者參與形成血腦障壁？
  1. （A）星形膠細胞
  2. （B）寡突膠細胞
  3. （C）許旺氏細胞
  4. （D）室管膜細胞

答案：（A）

詳解與考點

正解：題眼在「血腦障壁」——星形膠細胞的終足包覆腦微血管，與緊密連結的內皮細胞共同維持血腦障壁，故選 A。

第 18 題

下列何種毒素會抑制乙醯膽鹼酯酶（acetylcholinesterase, AChE）？
  1. （A）河豚毒（tetrodotoxin）
  2. （B）沙林神經毒氣
  3. （C）南美箭毒（curare）
  4. （D）殺蟲劑裡的有機磷

詳解與考點

正解：本題經考選部公告一律給分，作答任一選項皆得分。原因是題目要找會抑制乙醯膽鹼酯酶（acetylcholinesterase, AChE）的毒素，而選項中屬於有機磷類膽鹼酯酶抑制劑的不只一個：神經性毒氣本身即是有機磷化合物，與農用殺蟲劑中的有機磷同樣以磷酸根和酵素活性部位的絲胺酸共價結合，使其失去水解乙醯膽鹼的能力。兩個選項指向同一個機轉，故送分。

A：河豚毒（tetrodotoxin）阻斷神經與肌肉細胞膜上的電位依賴型鈉離子通道，使動作電位無法產生而造成麻痺，屬鈉通道阻斷劑，作用位置與乙醯膽鹼酯酶無關。

B：沙林屬神經性毒氣，化學結構為有機磷化合物，與乙醯膽鹼酯酶形成共價鍵並可老化為不可逆結合，造成乙醯膽鹼在突觸堆積、蕈毒鹼與菸鹼受體同時過度刺激，本項成立。

C：南美箭毒（curare）是神經肌肉接合處的競爭性菸鹼受體拮抗劑，佔據受體而阻斷乙醯膽鹼的作用，作用位置在受體而不在酵素，屬另一種機轉。

D：殺蟲劑裡的有機磷與沙林同屬有機磷類膽鹼酯酶抑制劑，中毒表現同為流涎、流淚、排尿、腹瀉、腸胃不適與嘔吐等蕈毒鹼症狀，合併肌肉顫動與無力，本項同樣成立。

本題考點：乙醯膽鹼酯酶抑制劑（acetylcholinesterase inhibitor）的共同機轉與中毒表現；鈉離子通道阻斷與受體拮抗在作用位置上的區別；有機磷中毒的神經肌肉症狀辨識與解毒方向。

B：2X-Y+Z 無法對應腎小管物質處理流程，且把應扣除的重吸收改為相加。

C：X/Y+X/Z 是比值相加，單位不再是體積，不能表示排除體積。

D：X/Y-X/Z 同樣把體積運算誤作比值；最強誘答在於都使用 X、Y、Z，但排除量必須維持體積的加減關係。

本題考點：腎排除（renal excretion）＝過濾（filtration）＋分泌（secretion）－重吸收（reabsorption）；分泌增加尿中量；重吸收減少尿中量。

  2. （B）3,600
  3. （C）5,400
  4. （D）7,200

正解：題眼在「肺泡通氣量」，必須先從潮氣容積扣除不參與氣體交換的解剖性死腔。公式為肺泡通氣量（mL/min）＝〔潮氣容積（mL）－死腔容積（mL）〕× 呼吸頻率（次/min）。代入：450 mL-150 mL=300 mL/次；300 mL/次×12 次/min=3,600 mL/min，故選 B。

  1. （A）肥大細胞（mast cell）
  2. （B）嗜鹼性球（basophil）
  3. （C）T 細胞
  4. （D）活化的嗜酸性球（activated eosinophil）

答案：（C）

詳解與考點

正解：題眼在「FcεRI 高親和力受體不表現」——判準是 IgE 所致立即型過敏反應的效應細胞。FcεRI 典型表現於肥大細胞與嗜鹼性球，活化的嗜酸性球亦可表現；T 細胞不是其典型表現細胞，故選 C。

A：肥大細胞表面的 FcεRI 結合 IgE 後，抗原交聯可引起脫顆粒與介質釋放。

B：嗜鹼性球也表現 FcεRI，是血液中參與 IgE 反應的效應細胞。

D：活化的嗜酸性球可表現 FcεRI 並參與過敏性發炎。這是最強誘答——嗜酸性球不像肥大細胞是最經典的 IgE 效應細胞，但題幹限定的是「不表現」，不能因此誤選。

本題考點：FcεRI（high-affinity IgE receptor）可結合 IgE；肥大細胞（mast cell）與嗜鹼性球（basophil）是立即型過敏反應的主要效應細胞；T 細胞主要參與細胞媒介性免疫。

第 70 題

臘腸桿菌毒素（Botulinum toxin）可以用於美容除皺之機制為何？
  1. （A）阻止乙醯膽鹼的釋放
  2. （B）使施打處之肌肉壞死
  3. （C）造成神經傳遞物質 GABA 無法釋放
  4. （D）使神經末稍接受器被破壞

答案：（A）

詳解與考點

正解：題眼在「肉毒桿菌毒素」用於「除皺」——判準是神經肌肉接合處的乙醯膽鹼釋放。Botulinum toxin 阻斷突觸前末梢釋放乙醯膽鹼，使局部肌肉暫時放鬆，因而減少動態皺紋，故選 A。

B：其效果是可逆性神經傳遞抑制，不是使肌肉壞死。

C：GABA 是中樞神經系統重要抑制性神經傳遞物質，非美容除皺的主要作用標的。

D：毒素不會破壞神經末梢接受器，而是干擾突觸前囊泡融合與乙醯膽鹼釋放。這是最強誘答——兩者都會使神經肌肉傳遞減弱，但作用位置在「釋放端」而非「接受器」。

本題考點：肉毒桿菌毒素（botulinum toxin）抑制乙醯膽鹼（acetylcholine）釋放；神經肌肉接合處（neuromuscular junction）傳遞受阻會造成局部肌肉放鬆；動態皺紋與表情肌收縮相關。

第 71 題

Bordetella pertussis 造成百日咳的病程中，那一時期菌量最高，也最具傳染力？
  1. （A）潛伏期（incubation period）
  2. （B）黏膜期（catarrhal phase）
  3. （C）陣發期（paroxysmal phase）
  4. （D）恢復期（convalescent phase）

答案：（B）

詳解與考點

正解：題眼在百日咳病程中「菌量最高」且「最具傳染力」——判準是各期的細菌排出量。百日咳的黏膜期常呈類感冒表現，此期呼吸道菌量高、傳染力最強，故選 B。

A：潛伏期尚未出現典型臨床症狀，並非教材所強調的最高傳染期。

C：陣發期以劇烈陣發性咳嗽為特徵，但隨病程進展，細菌量與傳染力通常已較黏膜期下降。這是最強誘答——咳嗽最劇烈不代表排菌量最高，須區分症狀嚴重度與傳染力。

D：恢復期症狀逐漸改善，傳染性更低。

本題考點：百日咳（pertussis）的黏膜期（catarrhal phase）傳染力最強；陣發期（paroxysmal phase）以劇烈咳嗽為主；傳染力與臨床症狀嚴重度不必然平行。

第 72 題

針對淋病雙球菌（Neisseria gonorrhoeae）造成的疾病，下列何者錯誤？
  1. （A）主要造成生殖泌尿道感染
  2. （B）臨床上透過疫苗已可以有效預防疾病發生
  3. （C）是革蘭氏陰性菌，具有內毒素，可造成發燒
  4. （D）可能會造成皮疹及關節炎

答案：（B）

詳解與考點

正解：題眼在「淋病雙球菌」與「何者錯誤」——判準是目前可用的預防方式。淋病雙球菌感染尚無可供臨床常規使用、能有效預防疾病的疫苗；預防重點是安全性行為、篩檢與伴侶處置，故 B 為應選項。

A：淋病雙球菌主要感染生殖泌尿道黏膜，可造成尿道炎、子宮頸炎等表現，故正確。

C：淋病雙球菌為革蘭氏陰性雙球菌，具有脂寡醣等內毒素樣成分，可引發發炎與發燒，故正確。

D：散播性淋病感染可出現皮疹與關節炎。這是最強誘答——題目容易被「主要是泌尿生殖道感染」限制思考，但感染擴散時確可有全身表現。

本題考點：淋病雙球菌（Neisseria gonorrhoeae）主要感染泌尿生殖道；散播性淋病感染（disseminated gonococcal infection）可有皮疹與關節炎；預防以安全性行為、篩檢與伴侶處置為主。

第 73 題

下列何種細菌較容易引起抗生素相關腹瀉（antibiotic-associated diarrhea）？
  1. （A）空腸曲狀桿菌（Campylobacter jejuni）
  2. （B）困難梭孢桿菌（Clostridium difficile）
  3. （C）產氣梭孢桿菌（Clostridium perfringens）
  4. （D）仙人掌桿菌（Bacillus cereus）

答案：（B）

詳解與考點

正解：題眼在「抗生素相關腹瀉」——判準是廣效抗生素破壞腸道菌相後容易增生的病原體。困難梭孢桿菌可在腸道菌相失衡時過度生長並產生毒素，造成抗生素相關腹瀉與偽膜性腸炎，故選 B。

A：空腸曲狀桿菌常造成食源性腸胃炎，但不是抗生素使用後菌相失衡最典型的病原體。

C：產氣梭孢桿菌可與食物中毒及組織感染有關，非本題典型關聯。

D：仙人掌桿菌常因預成毒素或食物污染引起急性嘔吐或腹瀉，與抗生素相關腹瀉的典型機轉不同。這是最強誘答——兩者都可腹瀉，分辨關鍵在於是否由抗生素破壞正常菌相所誘發。

本題考點：困難梭孢桿菌（Clostridioides difficile）與抗生素相關腹瀉（antibiotic-associated diarrhea）密切相關；腸道菌相失衡（dysbiosis）是重要機轉；偽膜性腸炎（pseudomembranous colitis）是其代表性疾病。

第 74 題

下列何種細菌感染症較少經由節肢動物（arthropod）傳播？
  1. （A）回歸熱（relapsing fever）
  2. （B）立克次痘（rickettsialpox）
  3. （C）遊走性紅斑（erythema migrans）
  4. （D）砂眼（trachoma）

答案：（D）

詳解與考點

正解：題眼在「較少經由節肢動物傳播」——判準是各疾病的主要傳染途徑。砂眼可經直接或間接接觸感染性眼部分泌物傳播，也可由蒼蠅機械性攜帶分泌物而散播；相較 A、B、C 所列典型病媒傳播疾病，砂眼並不以特定節肢動物媒介為傳播的必要條件，故選 D。

A：回歸熱可由蝨或蜱等節肢動物媒介傳播。

B：立克次痘由蟎類媒介，其名稱即反映與節肢動物媒介的關聯。

C：遊走性紅斑是萊姆病的典型皮膚表現，萊姆病主要經蜱叮咬傳播。這是最強誘答——選項寫的是皮疹名稱而非病名，但仍應連結到蜱媒介的萊姆病。

本題考點：病媒傳播（vector-borne transmission）以節肢動物為必要媒介；回歸熱（relapsing fever）與蝨或蜱相關；砂眼（trachoma）以接觸傳播為主，蒼蠅僅屬機械性攜帶。

第 75 題

白色念珠菌（C. albicans）的結構及生理特性，下列何者錯誤？
  1. （A）菌絲型（mold form）
  2. （B）會出芽
  3. （C）有假菌絲（pseudohypha）
  4. （D）真核生物

本題送分，無標準答案

詳解與考點

正解：本題經考選部公告一律給分，作答任一選項皆得分。原因是題目要找白色念珠菌（C. albicans）結構與生理特性敘述中錯誤的一項，但四個敘述在通行的讀法下都能成立。白色念珠菌屬雙型性真菌，在一般培養條件下以酵母型出芽繁殖，在組織侵襲或特定培養條件下則長出假菌絲與真菌絲；因此連最可能被當成答案的菌絲型，也可被理解為它確實具有的型態之一，題目找不到唯一錯誤的敘述，故送分。

A：若把菌絲型（mold form）讀成分類上的黴菌型態，白色念珠菌以酵母型為基本型態，此讀法下本項為錯誤；若讀成它在特定條件下可轉換出的菌絲型態，本項即成立。同一敘述因讀法而結論相反，是本題的爭點所在。

B：出芽是酵母型的繁殖方式，白色念珠菌以出芽產生芽生孢子，鏡檢可見出芽的酵母細胞，敘述正確。

C：假菌絲（pseudohypha）由連續出芽而細胞未完全分離所形成，接合處有縊縮，是念珠菌鏡檢的重要辨識特徵，敘述正確。

D：真菌屬真核生物，具細胞核與胞器、細胞膜含麥角固醇，與細菌的原核構造不同；抗黴菌藥物以麥角固醇合成路徑為作用標的即源於此，敘述正確。

本題考點：白色念珠菌（Candida albicans）的雙型性（dimorphism）與型態轉換；出芽與假菌絲的形成方式及其鏡檢特徵；真菌作為真核生物的構造特徵與抗黴菌藥物的作用標的。

第 76 題

下列何者不屬於表淺性黴菌病（superficial mycosis）？
  1. （A）花斑癬（pityriasis versicolor）
  2. （B）黑癬（tinea nigra）
  3. （C）足癬（tinea pedis）
  4. （D）毛幹黑節病（black piedra）

答案：（C）

詳解與考點

正解：題眼在「不屬於表淺性黴菌病」——判準是病原菌侵犯的角質部位與傳統分類。足癬是皮癬菌造成的皮膚黴菌病，侵犯角質層，歸於皮膚黴菌病而非表淺性黴菌病，故 C 為應選項。

A：花斑癬由皮屑芽孢菌相關菌種造成，屬表淺性黴菌病。

B：黑癬主要侵犯皮膚最表層角質，屬表淺性黴菌病。

D：毛幹黑節病侵犯毛幹，亦歸在表淺性黴菌病。這是最強誘答——它與足癬都涉及角蛋白結構，但毛幹黑節病的傳統分類是表淺性。

本題考點：表淺性黴菌病（superficial mycosis）侵犯皮膚或毛髮最表層；皮膚黴菌病（cutaneous mycosis）常由皮癬菌引起；足癬（tinea pedis）屬皮膚黴菌病。

第 77 題

下列何種肝炎病毒，主要經由飲食傳染？
  1. （A）B 型肝炎病毒
  2. （B）C 型肝炎病毒
  3. （C）D 型肝炎病毒
  4. （D）E 型肝炎病毒

答案：（D）

詳解與考點

正解：題眼在「主要經由飲食傳染」——判準是肝炎病毒的傳播途徑。E 型肝炎病毒主要經糞口途徑傳播，可與受污染的食物或飲水有關，故選 D。

A：B 型肝炎病毒主要經血液、性接觸與周產期傳播。

B：C 型肝炎病毒主要經血液暴露傳播，飲食不是主要途徑。

C：D 型肝炎病毒須依附 B 型肝炎病毒，傳播途徑與 B 型肝炎相近。這是最強誘答——D 型肝炎同為肝炎病毒，但其複製依賴 HBV，不能依字母順序或疾病名稱推定為腸道傳播。

第 78 題

依波拉病毒（Ebola virus）是經由下列何者傳播？
  1. （A）飲用水
  2. （B）病媒蚊
  3. （C）空氣
  4. （D）病患的體液、血液

答案：（D）

詳解與考點

正解：題眼在「依波拉病毒」的傳播方式——判準是人與人之間的主要暴露媒介。依波拉病毒可經感染者的血液與其他體液接觸傳播，照護時須以標準防護及適當的接觸防護避免暴露，故選 D。

A：飲用水不是依波拉病毒主要傳播途徑。

B：依波拉病毒不以病媒蚊傳播。

C：它不是典型經由空氣長距離傳播的呼吸道病毒。這是最強誘答——臨床照護會強化個人防護裝備，但防護嚴格不代表其主要傳播途徑是空氣。

本題考點：依波拉病毒（Ebola virus）主要經血液與體液接觸傳播；體液暴露（body fluid exposure）是感染管制重點；標準防護（standard precautions）可降低血液與體液接觸風險。

第 79 題

下列病毒何者在複製過程中，並未經過反轉錄（reverse transcription）的階段？
  1. （A）人類免疫缺乏病毒（HIV）
  2. （B）B 型肝炎病毒（HBV）
  3. （C）人類噬 T 淋巴球病毒（HTLV）
  4. （D）依波拉病毒（Ebola virus）

答案：（D）

詳解與考點

正解：題眼在「並未經過反轉錄」——判準是各病毒複製時是否需要 reverse transcriptase。依波拉病毒是負股 RNA 病毒，以 RNA 依賴 RNA 聚合酶複製，不經反轉錄階段，故選 D。

A：HIV 是反轉錄病毒，必須將 RNA 反轉錄為 DNA。

B：HBV 雖為 DNA 病毒，但其複製過程包含 RNA 中間體與反轉錄步驟。

C：HTLV 同屬反轉錄病毒，複製需經反轉錄。這是最強誘答——HBV 看似是 DNA 病毒，但其特殊複製策略仍有反轉錄，不能只依基因體類型判斷。

本題考點：反轉錄（reverse transcription）是 RNA 轉為 DNA 的過程；反轉錄病毒（retrovirus）包括 HIV 與 HTLV；B 型肝炎病毒（HBV）複製亦使用反轉錄步驟。

第 80 題

有關有鉤絛蟲（Taenia solium）之敘述，下列何者錯誤？
  1. （A）成蟲寄生於人體小腸，引起腸病變
  2. （B）在臺灣曾經發現過病例
  3. （C）它的幼蟲不會在人體生存而造成病害
  4. （D）蟲體頭節有吸盤及二圈小鉤

答案：（C）

詳解與考點

正解：題眼在「有鉤絛蟲」與「何者錯誤」——判準是其幼蟲在人體內的致病性。有鉤絛蟲幼蟲可在人體組織存活並形成囊蟲，侵犯中樞神經系統時可造成囊蟲病，因此「不會在人體生存而造成病害」錯誤，故 C 為應選項。

A：成蟲可寄生於人體小腸，造成腸道寄生蟲感染，故正確。

B：有鉤絛蟲在臺灣曾有病例報告，故正確。

D：有鉤絛蟲頭節具有吸盤及小鉤，是其與無鉤絛蟲的重要形態鑑別。這是最強誘答——兩者同為絛蟲且皆可寄生腸道，但有無小鉤決定名稱與形態辨識。

本題考點：有鉤絛蟲（Taenia solium）成蟲寄生小腸；囊蟲病（cysticercosis）由幼蟲在組織內存活造成；頭節鉤（hooks）是與無鉤絛蟲的形態鑑別。
