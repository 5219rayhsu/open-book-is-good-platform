全部 40 題

第 1 題

DSM-5英文版由下列何者所出版？
  1. （A）英國精神醫學會
  2. （B）世界衛生組織
  3. （C）美國精神醫學會
  4. （D）國際精神醫學會

答案：（C）

詳解與考點

考點為 DSM-5 的出版單位。正解 C：DSM 系列由美國精神醫學會（APA）編纂出版。世界衛生組織出版的是 ICD 系列，並非 DSM。易誤選 B 世界衛生組織，因其確為國際診斷系統 ICD 的主管機構，但 DSM 屬美國 APA。把握度高。

第 2 題

DSM-5中之拔毛症（trichotillomania, hair-pulling disorder）屬於下列何者？
  1. （A）他處未分類之衝動控制疾患
  2. （B）強迫症與其相關障礙症
  3. （C）焦慮症
  4. （D）性偏好症

答案：（B）

詳解與考點

考點為 DSM-5 對拔毛症的歸類。正解 B：DSM-5 將拔毛症歸入「強迫症及相關障礙症」類別，與摳皮症同列。DSM-IV 時期曾列於衝動控制疾患，但 DSM-5 已重新分類。易誤選 A 衝動控制疾患，那是舊版歸類，新版已改。把握度高。

第 3 題

下列何者不是DSM-5對精神疾病的定義？
  1. （A）造成認知上的顯著困擾
  2. （B）造成情緒調節障礙
  3. （C）嚴重影響社交活動
  4. （D）導致個人與社會的衝突

答案：（D）

詳解與考點

考點為 DSM-5 對精神疾病的定義要素。DSM-5 定義強調認知、情緒調節或行為上的顯著困擾，並影響社交職業功能。正解 D「導致個人與社會的衝突」並非定義要件，DSM-5 明確排除純粹社會偏差或與社會衝突者。易誤選 C 影響社交，但功能損害確為定義一環。

第 4 題

有些臨床症狀被認為是比較具有跨文化的、無明顯文化差異的，但不包括下列何者？
  1. （A）焦慮症狀
  2. （B）憂鬱症狀
  3. （C）幻覺
  4. （D）妄想

答案：（A）

詳解與考點

考點為臨床症狀的跨文化一致性。較具跨文化、文化差異小者多為較生物性的症狀，如幻覺、妄想。正解 A 焦慮症狀的表現與詮釋受文化影響較大，較不屬無明顯文化差異者。易誤選 B 憂鬱，雖也具文化變異，但題意設定焦慮為最受文化形塑者。把握度中等。

第 5 題

下列何者不是最常使用的行為遺傳研究法？
  1. （A）家族法（family method）
  2. （B）雙胞胎研究法（twin method）
  3. （C）領養研究法（adoptees method）
  4. （D）個案研究法（case study method）

答案：（D）

詳解與考點

考點為行為遺傳學的主要研究方法。最常用三法為家族法、雙胞胎研究法、領養研究法，用以分離遺傳與環境貢獻。正解 D「個案研究法」屬質性深入描述，非行為遺傳研究法。易誤選 A 家族法，但它正是核心遺傳研究法之一。把握度高。

第 6 題

最能夠強調未經操弄前的兩變項關係之研究方法是：
  1. （A）使用控制組
  2. （B）縱貫性研究設計
  3. （C）相關法
  4. （D）個案研究法

答案：（C）

詳解與考點

考點為研究方法與變項關係的探討。正解 C 相關法在不操弄變項的前提下，檢視兩變項自然存在的關聯，最能呈現未經操弄前的關係。實驗用控制組需操弄自變項；縱貫設計著重時間變化；個案研究為深入描述。易誤選 B 縱貫設計，但其重點在追蹤變化而非未操弄的變項關係。

第 7 題

下列有關科學的敘述，何者錯誤？
  1. （A）科學取向要求清楚且準確的陳述
  2. （B）無論理論多麼合理，檢驗的結果也可能否定科學家的預期
  3. （C）科學的可重複性與可驗證性，必須藉由使用高效度與高信度的評估工具
  4. （D）心理病理學的研究較難達到可重複性與可驗證性

答案：（D）

詳解與考點

考點為科學方法的特性。正解 D 為錯誤：心理病理學研究透過操作型定義與標準化工具，仍可達到相當的可重複性與可驗證性，並非較難達成。要求精確陳述、結果可否定預期、需高信效度工具皆為科學特徵。易誤選 C，但使用高信效度工具確為達成可驗證性的必要條件。

第 8 題

探討每天寫日記是否可幫助人們抒發情緒，60位疑似有憂鬱症狀的大學生隨機分派至兩組，一組每日針對生活中令其困擾之事，撰寫一篇深入描述自己想法及感覺的日記，需連續寫7天。另一組則針對當日所知道的社會事件，撰寫一篇文章，亦是需連續寫7天。研究結果發現被分派至日記組，其在貝克憂鬱量表的分數，在研究前後有明顯改變，另一組則無。此效果，在臨床心理學研究方法中，可稱為：
  1. （A）類化效果（generalized effect）
  2. （B）實驗效果（experimental effect）
  3. （C）安慰劑效果（placebo effect）
  4. （D）練習效果（practice effect）

答案：（B）

詳解與考點

考點為實驗研究中效果的命名。本題隨機分派、有對照組且日記組量表分數出現顯著改變，此因實驗操弄（撰寫情緒日記）而生的效果稱實驗效果，故正解 B。安慰劑效果指因期待而非介入本身產生改變，此處有控制組對照已排除；練習效果指重複測驗本身的進步。易誤選 C 安慰劑效果。

第 9 題

下列對雙盲設計（double-blind design）的描述何者錯誤？
  1. （A）實驗者（experimenter）需要完全掌握有關該實驗的所有訊息
  2. （B）可減少研究結果受到研究參與者偏誤（participant bias）所影響
  3. （C）可防止研究結果受到安慰劑效果（placebo effect）所影響
  4. （D）可提升該實驗結果的效度（validity）

答案：（A）

詳解與考點

考點為雙盲設計的特性。正解 A 為錯誤：雙盲設計恰恰要求施測者與受試者皆不知分組，以避免實驗者偏誤，而非讓實驗者完全掌握所有訊息。雙盲可減少參與者偏誤、防止安慰劑效果、提升效度皆正確。易誤選 C，但防止安慰劑效果正是雙盲的目的之一。

第 10 題

下列何者研究概念，通常發生在學術場域中，並以隨機臨床試驗研究來進行。主要是要確定治療在理想情況下或是純淨的條件下，是否能夠達到預期的療效？
  1. （A）治療效能（treatment efficacy）
  2. （B）治療效果（treatment effectiveness）
  3. （C）治療效率（treatment efficiency）
  4. （D）治療影響（treatment impact）

答案：（A）

詳解與考點

考點為治療研究中效能與效果的區辨。正解 A 治療效能（efficacy）指在學術場域、隨機臨床試驗等理想或純淨控制條件下能否達到預期療效。治療效果（effectiveness）則指真實臨床情境的成效。易誤選 B 治療效果，但其強調的是日常實務的外部效度，非理想條件。把握度高。

第 11 題

下列關於個案研究法（case study method）的敘述何者錯誤？
  1. （A）可以用來評估新穎的治療方式
  2. （B）可以用來分析臨床上極少見的個案
  3. （C）可以用來否證某些臨床現象與關聯性
  4. （D）可以作為流行病學最常使用的研究方法

答案：（D）

詳解與考點

考點為個案研究法的適用與限制。正解 D 為錯誤：流行病學最常用的是調查與相關等大樣本方法，個案研究因樣本單一無法作為流行病學主力。個案研究可評估新療法、分析罕見個案、以反例否證關聯皆正確。易誤選 C 否證，但單一反例確可推翻全稱命題，屬個案研究功能。

第 12 題

某甲罹患了恐慌症，但是引起症狀發作的原因不明。欲採用「個案研究（case study）」的方式深入了解在他身上造成恐慌症的機制。下列何者不是採用個案研究的優點？
  1. （A）能夠形成多種不同的假設
  2. （B）能夠對現象或機制有豐富的描述
  3. （C）能夠驗證因果關係
  4. （D）能夠探索特殊性或新奇的影響因子

答案：（C）

詳解與考點

考點為個案研究法的優缺點。正解 C 為非優點：個案研究無法操弄變項與控制干擾，故不能驗證因果關係，這是其主要限制。形成多種假設、豐富描述現象機制、探索特殊或新奇因子皆為其優點。易誤選 A 形成假設，但那正是個案研究的長處而非限制。

第 13 題

依據DSM-5，下列有關流行病學盛行率研究結果之敘述，何者正確？
  1. （A）異食症（pica）可能發生在懷孕期的女性
  2. （B）勃起障礙症（erectile disorder）的盛行率與年齡無關
  3. （C）病態偷竊症（kleptomania）的比例男性顯著高於女性
  4. （D）夜間遺尿（nocturnal enuresis）在男性和女性身上一樣普遍

答案：（A）

詳解與考點

考點為 DSM-5 各障礙症的流行病學描述。正解 A 正確：異食症可能發生於懷孕期女性。B 錯在勃起障礙盛行率隨年齡上升；C 錯在病態偷竊症女性多於男性；D 錯在夜間遺尿男性多於女性。易誤選 D，但遺尿在性別上並非一樣普遍，男童較多。把握度中等。

第 14 題

延長暴露法（prolonged exposure）被廣泛應用於治療害怕或畏懼症，此技術基本上是依據何項學習原則？
  1. （A）負向增強（negative reinforcement）
  2. （B）正向處罰（positive punishment）
  3. （C）觀察學習（observational learning）
  4. （D）消弱（extinction）

答案：（D）

詳解與考點

考點為延長暴露法的學習理論基礎。正解 D 消弱（extinction）：持續暴露於恐懼刺激而不出現預期災難後果，使制約恐懼反應逐漸消退，正是消弱原理。負向增強反而是逃避維持畏懼的機轉。易誤選 A 負向增強，但那解釋的是迴避行為的維持，而非暴露治療的療效原理。

第 15 題

下列何者不是世界衛生組織失能評估量表第二版（The World Health Organization Disability Assessment Schedule 2.0, WHODAS 2.0）評估的個案功能領域？
  1. （A）自我照顧
  2. （B）家事活動
  3. （C）運動習慣
  4. （D）站立和行走

答案：（C）

詳解與考點

考點為 WHODAS 2.0 評估的功能領域。WHODAS 2.0 涵蓋認知、活動移動（站立行走）、自我照顧、與人相處、生活活動（家事）、社會參與六領域。正解 C「運動習慣」並非其評估領域。易誤選 D 站立和行走，但移動性確為其六大領域之一。把握度中等。

第 16 題

素質－壓力模型（Diathesis-stress model）是解釋心理疾病的整合模型。其中，Caspi等人（2003）探討血清素轉運子基因（serotonin transporter gene）與兒童受虐經驗對憂鬱症發生機率的預測力，被認為是互動模式（interactive model）的經典例子。下列關於互動模式的敘述，何者最不恰當？
  1. （A）素質（diathesis）一定要在壓力之前就出現，才會產生效果
  2. （B）不論壓力多大，若無某種特定的素質，個體發病的機率即大為降低
  3. （C）無論是否有特定素質，發病機率與壓力程度之間都呈現正相關，只是相關程度不同
  4. （D）即使具有特定素質，在沒有壓力的狀況下，發病機率也很低

答案：（C）

詳解與考點

考點為素質壓力模型的互動模式。正解 C 為最不恰當：互動模式的特點是有無特定素質會改變壓力與發病的關係斜率，並非「無論是否有素質都呈正相關只差程度」。A、B、D 描述素質的必要性與閾值效果皆符合互動模式。易誤選 A，但素質先於壓力的條件設定可成立。

第 17 題

在DSM-5中，針對創傷後壓力症（posttraumatic stress disorder）所涵蓋的診斷準則，下列何者不是「文化相關診斷議題」上所須考慮的症狀性質？
  1. （A）痛苦的夢（distressing dreams）
  2. （B）身體症狀（somatic symptoms）
  3. （C）認知症狀（cognitive symptoms）
  4. （D）逃避和麻木症狀（avoidance and numbing symptoms）

答案：（C）

詳解與考點

考點為 DSM-5 創傷後壓力症的文化相關診斷議題。文化相關議題常考量痛苦的夢、身體症狀、逃避麻木等在不同文化的表現差異。正解 C「認知症狀」相對非文化相關議題特別標註的症狀性質。易誤選 B 身體症狀，但身體化表現確因文化而異，屬須考慮者。把握度低。

第 18 題

下列何者最符合描述焦慮疾患患者的問題解決之脆弱性歷程？
  1. （A）其問題解決歷程包括那些步驟
  2. （B）影響其問題解決品質的機制有那些
  3. （C）成功與失敗的問題解決經驗各是什麼
  4. （D）從小到大所採用的問題解決方式

答案：（B）

詳解與考點

考點為焦慮疾患的問題解決脆弱性歷程。正解 B：脆弱性歷程關注的是「影響問題解決品質的機制有哪些」，即探討哪些內在歷程使焦慮者問題解決受損。A 問步驟、C 問成敗經驗、D 問慣用方式皆偏描述而非脆弱機制。把握度中等。

第 19 題

張同學的室友最近時常自笑自語、疑似有聽幻覺，張同學這學期剛學過DSM-5，他認為同學的行為很像是思覺失調症的典型病徵，張同學的判斷，最可能運用了下列何種策略？
  1. （A）可得性經驗法則（the availability heuristic）
  2. （B）解釋性推論（interpretation reasoning）
  3. （C）代表性經驗法則（the representativeness heuristic）
  4. （D）情緒性推論（emotion reasoning）

答案：（C）

詳解與考點

考點為臨床判斷的捷思法。張同學依少數典型病徵就把行為歸入思覺失調症的代表性類別，屬代表性經驗法則（以相似度配對原型），故正解 C。可得性捷思指依容易想起的例子判斷頻率；情緒性與解釋性推論非此。易誤選 A 可得性，但本題重點在以典型樣板比對而非記憶易得性。

第 20 題

下列何種神經傳導素的增加在自閉症類群障礙兒童患者最常被發現？
  1. （A）多巴胺
  2. （B）正腎上腺素
  3. （C）血清素（5-HT）
  4. （D）氟苯丙胺（fenfluramine）

答案：（C）

詳解與考點

考點為自閉症類群兒童的神經傳導物質異常。正解 C 血清素（5-HT）增加是自閉症患者最常被發現的神經化學異常（高血清素血症）。多巴胺、正腎上腺素並非最常見。氟苯丙胺是藥物而非內生神經傳導物質。易誤選 A 多巴胺，但最具一致證據者為血清素升高。

第 21 題

讓害怕髒污的強迫症病患接觸髒東西時，該病患腦部何區域血流量會明顯增加？
  1. （A）頂葉（parietal lobe）
  2. （B）前扣帶迴（anterior cingulate）
  3. （C）背外側前額葉（dorsolater prefrontal cortex）
  4. （D）藍斑核（locus coeruleus）

答案：（B）

詳解與考點

考點為強迫症暴露時的腦區活化。正解 B 前扣帶迴：強迫症患者接觸污染刺激誘發焦慮時，前扣帶迴血流量明顯增加，與眼眶額葉、尾核同屬強迫症過度活化迴路。易誤選 C 背外側前額葉，但該區較與工作記憶相關，非強迫症焦慮誘發的核心活化區。把握度中等。

第 22 題

如果在腦中發現類澱粉蛋白沉積（beta-amyloid protein deposits），則足以診斷個案為下列何者？
  1. （A）阿茲海默病（Alzheimer's disease）
  2. （B）思覺失調症
  3. （C）智能缺損
  4. （D）此資料不足以診斷任何心智疾病

答案：（D）

詳解與考點

考點為類澱粉蛋白沉積的診斷意義。正解 D：腦中發現 beta-amyloid 沉積不足以單獨確診任何疾病，因正常老化者也可能出現，須結合臨床症狀與其他證據。易誤選 A 阿茲海默病，雖類澱粉斑塊是其病理標記，但僅此一項生物標記不足以做出臨床診斷。把握度中等。

第 23 題

下列關於思覺失調症（Schizophrenia）的神經生理特徵之敘述，何者錯誤？
  1. （A）思覺失調症患者之腦結構，在頂葉（parietal lobe）體積較健康腦來的小
  2. （B）思覺失調症患者之腦結構，海馬迴（hippocampus）的體積較健康腦來的小
  3. （C）思覺失調症患者的腦室常較健康對照組之腦部來的大
  4. （D）在扣帶迴皮質區（cingulate cortex）有明顯增加的GABA結合位置（GABA-binding sites）

答案：（A）

詳解與考點

考點為思覺失調症的神經生理特徵正誤。正解 A 為錯誤：思覺失調症較典型的結構變化是顳葉（含海馬迴）體積縮小與腦室擴大，頂葉縮小並非其代表性特徵。海馬迴縮小、腦室擴大、扣帶迴皮質 GABA 結合位置改變等敘述較符文獻。易誤選 D，但 GABA 系統異常確有相關證據。把握度低。

第 24 題

腦中的灰質（gray matter）主要是由下列何者組成？
  1. （A）神經元（neurons）
  2. （B）腦溝（sulci）
  3. （C）腦裂（fissures）
  4. （D）腦膜（meninges）

答案：（A）

詳解與考點

考點為神經解剖基礎。灰質（gray matter）主要由神經元的細胞本體與無髓鞘部分構成，故 A 正確；白質才以有髓鞘軸突為主。陷阱在 D 腦膜，腦膜是包覆腦與脊髓的結締組織保護層，與灰質組成無關；B 腦溝、C 腦裂是皮質表面的構造形態，並非組織成分，易因「腦」字混淆。

第 25 題

從基因的典範來看，魏氏智力測驗的結果，由下列何種概念來解釋最為恰當？
  1. （A）基因型（genotype）
  2. （B）表現型（phenotype）
  3. （C）共享環境（shared environment）
  4. （D）非共享環境（nonshared environment）

答案：（B）

詳解與考點

考點為行為遺傳學的基因型與表現型。魏氏智力測驗測得的是個體實際展現出來的智力表現，是基因與環境交互作用後的可觀察結果，屬表現型（phenotype），故 B 正確。陷阱為 A 基因型，基因型指底層的遺傳組成本身，無法由測驗分數直接讀出；C、D 環境成分只是表現型變異的來源之一，非智測結果的整體定位。

第 26 題

行為主義（Behaviorism）對心理病理的看法，下列敘述何者錯誤？
  1. （A）問題行為的持續，主要是因為它們被增強（reinforced）
  2. （B）「獲取注意力（getting attention）」是問題行為持續常見的增強物
  3. （C）行為治療的方式是相當個人化（tailored），因為每個人的「行為－增強物」間的聯結不同
  4. （D）暫時隔離法（Time out）是利用「負性增強（negative reinforcement）」的方式來減少問題行為

答案：（D）

詳解與考點

考點為行為主義對心理病理的解釋與操作制約原理。題目要選錯誤者。暫時隔離法（Time out）是移除個體可接觸的正增強物（如注意力），屬負懲罰（negative punishment），而非負增強，故 D 錯誤為答案。負增強是移除嫌惡刺激以增加行為，方向相反，最易誤判。A、B、C 對增強維持問題行為的描述皆正確。

第 27 題

Lorber（2004）針對心理病態（psychopathy）的病人，進行威脅刺激的研究並測量膚電反應，下列結果何者正確？
  1. （A）在休息狀態下，病人之膚電反應較一般人高
  2. （B）在威脅刺激下，病人之膚電反應較一般人高
  3. （C）在休息狀態下，病人之膚電反應較一般人的變異大
  4. （D）在威脅刺激下，病人之膚電反應較一般人低

答案：（D）

詳解與考點

考點為心理病態（psychopathy）的低喚起與恐懼缺損生理特徵。Lorber（2004）後設分析顯示心理病態者面對威脅刺激時膚電反應較一般人低，反映情緒喚起與恐懼制約不足，故 D 正確。陷阱為 B，方向相反；一般人遇威脅膚電會升高，心理病態者反而鈍化，易直覺誤選反應較高者。

第 28 題

關於強迫型人格障礙症的敘述，下列何者最不適宜？
  1. （A）堅持自己做事方式，並拒絕與他人共事
  2. （B）過度謹慎、反覆檢查細節
  3. （C）強迫型人格障礙症與強迫症本質上類似
  4. （D）對道德、倫理或價值觀過度嚴苛

答案：（C）

詳解與考點

考點為強迫型人格障礙症（OCPD）與強迫症（OCD）的區辨。要選最不適宜者。OCPD 是缺乏病識感、自我和諧（egosyntonic）的固著人格型態，缺乏 OCD 的強迫思考與強迫行為，兩者本質不同，故 C 敘述錯誤為答案。A、B、D 描述完美主義、過度謹慎、道德嚴苛，皆為 OCPD 典型特徵；最易誤以為名稱相近即本質類似。

第 29 題

研究發現，把大量飲酒視為正常行為的文化或社會氛圍下，下列何種狀況最可能發生？
  1. （A）酒癮患者的盛行率會下降
  2. （B）飲酒率會增加
  3. （C）有酒癮的女性比例會降低
  4. （D）低社經地位的男性更有可能變成酒癮患者

答案：（B）

詳解與考點

考點為文化社會因素對物質使用的影響。當文化把大量飲酒視為常態、社會規範對飲酒寬容時，整體飲酒率會上升，故 B 正確。陷阱為 A，盛行率下降與寬容氛圍方向相反；C、D 針對特定性別或社經次群體做過細推論，題幹未提供此類條件，屬過度推論的誘答。

第 30 題

具有對立反抗症（oppositional defiant disorder）診斷的孩童，比起患有注意力不足及過動症（ADHD）的孩童，下列敘述何者正確？
  1. （A）比較衝動
  2. （B）男性所占比例更高
  3. （C）對於不守規矩的行為故意的成分較高
  4. （D）注意力損傷程度更大

答案：（C）

詳解與考點

考點為對立反抗症（ODD）與 ADHD 的鑑別。ODD 核心是故意、敵意、違抗權威的行為模式，其不守規矩帶有較高的「故意」成分，故 C 正確。ADHD 的破壞行為多源自衝動與注意力缺損而非蓄意。陷阱為 A 衝動與 D 注意力損傷，這兩者其實是 ADHD 較突出的特徵，方向放錯易誤選。

第 31 題

有關厭食症的性格特徵，不包括下列何者？
  1. （A）自我導向的完美主義
  2. （B）他人導向的完美主義
  3. （C）高強迫性
  4. （D）高開放性

答案：（D）

詳解與考點

考點為厭食症（anorexia nervosa）的人格特質。要選不包括者。厭食症患者典型具高完美主義（自我與他人導向）與高強迫性，但人格上偏向僵化、控制，並非高開放性（openness），故 D 不屬於其特徵為答案。陷阱在誤把臨床上常見的「拘謹控制」直覺連到開放，但開放性高反而與其僵化特質相反。

第 32 題

針對鬱症病人的認知實驗之相關研究結果，下列敘述何者較不適當？
  1. （A）觀看負向情緒臉孔的時間比正向情緒臉孔短
  2. （B）記得負向生活事件多於正向生活事件
  3. （C）記得研究中的負向字詞比正向字詞多約10%
  4. （D）會將注意焦點集中在自我相關的負向訊息

答案：（A）

詳解與考點

考點為鬱症的認知偏誤與負向訊息處理。要選較不適當者。鬱症患者對負向情緒臉孔通常注意停留時間較長（負向注意偏誤），而非較短，故 A 敘述不當為答案。B、C、D 描述負向記憶偏誤與自我相關負向訊息聚焦，皆為憂鬱認知理論一致發現。陷阱在 A 把注意偏誤方向寫反，易因「短」字忽略。

第 33 題

心理病理學中以行為主義的觀點來解釋時，下列敘述何者正確？
  1. （A）偏差行為可能與神經系統功能失調有關
  2. （B）病態性格特徵是造成行為病理的主因
  3. （C）可以用內在心理衝突來解釋症狀
  4. （D）大部分的偏差行為是習得的

答案：（D）

詳解與考點

考點為行為主義對心理病理的核心主張。行為主義認為大部分偏差行為是經由制約學習而習得的，故 D 正確。陷阱為 A 神經系統失調（生物醫學模式）、B 病態性格特徵（特質取向）、C 內在心理衝突（精神分析），三者分屬其他典範而非行為主義觀點，易因敘述本身看似合理而誤選。

第 34 題

對於大部分被診斷為性格疾患的病人而言，下列描述何者最貼切？
  1. （A）其實病人更適合用第一軸的診斷來描述之
  2. （B）病人往往也具有廣泛性發展上的疾患（pervasive developmental disorder）
  3. （C）病人只會有一種性格疾患的診斷
  4. （D）病人具有一個以上的性格疾患診斷

答案：（D）

詳解與考點

考點為人格疾患的共病現象。臨床上大多數被診斷為性格疾患的病人常同時符合一個以上的人格疾患診斷，共病率高，故 D 正確。陷阱為 C，誤以為一人只會有單一性格疾患診斷，與實證相反；A、B 把人格疾患誤導向第一軸或廣泛性發展疾患，皆非主流描述。

第 35 題

依據Ingram & Price（2010）一書，下列何者為兒童及青少年憂鬱在認知層面的脆弱性因子？
  1. （A）失功能的認知評估（dysfunctional cognitive appraisals）
  2. （B）執行功能缺陷（executive functioning deficits）
  3. （C）工作記憶力差（poor working memory）
  4. （D）病前言語和語言障礙（premorbid speech and language impairments）

答案：（A）

詳解與考點

考點依 Ingram & Price（2010）兒童青少年憂鬱的認知脆弱性因子。失功能的認知評估（dysfunctional cognitive appraisals）屬認知層面的脆弱性，故 A 正確。陷阱為 B 執行功能缺陷、C 工作記憶差、D 言語語言障礙，這些偏向神經認知或語言發展面向，並非該書歸類的「認知脆弱性」因子。標 med，依特定教材。

第 36 題

依據Ingram & Price（2010）一書，有關物質使用障礙症的基因遺傳，下列敘述何者錯誤？
  1. （A）在各種物質使用中，酒精的遺傳率高於菸草和大麻
  2. （B）宗教信仰和家庭功能可調節基因對物質使用障礙症的影響
  3. （C）MAO-A基因與物質使用障礙症有關
  4. （D）物質使用障礙症與多個基因有關

答案：（A）

詳解與考點

考點依 Ingram & Price（2010）物質使用障礙的基因遺傳。要選錯誤者。一般文獻指出酒精的遺傳率並非高於菸草（尼古丁依賴遺傳率常被報導偏高），此比較敘述與該書不符，故 A 為答案。B 宗教家庭功能可調節基因效果、C MAO-A 相關、D 多基因影響，皆屬正確敘述。標 med，依特定教材數據。

第 37 題

研究數據指出「老年人罹患心理疾病的盛行率比其他年齡層都低」，下列何者最不適合用來探討此結果的方法學議題？
  1. （A）反應偏誤
  2. （B）世代效應
  3. （C）選擇性死亡率
  4. （D）雙盲設計缺失

答案：（D）

詳解與考點

考點為老年盛行率偏低的方法學議題。要選最不適合者。反應偏誤、世代效應、選擇性死亡率都能解釋此現象（如世代差異、體弱者較早死亡），而雙盲設計是介入性實驗的控制手段，與盛行率調查的方法學無關，故 D 為答案。陷阱在 D 是熟悉名詞，易因「研究方法」字面而誤選。

第 38 題

依據精神疾病診斷及統計手冊第五版（DSM-5），下列有關疾患之敘述何者正確？
  1. （A）平均而言，思覺失調症患者的整體功能高於妄想疾患患者
  2. （B）有一定比例的妄想疾患患者，後來會發展成符合思覺失調症的診斷
  3. （C）妄想疾患常與思覺失調症、類思覺失調症相共病
  4. （D）妄想疾患與思覺失調症的亞型皆包括有被害妄想型（persecutory type）

答案：（B）

詳解與考點

考點依 DSM-5 妄想疾患的特徵與病程。有一定比例的妄想疾患患者後續會發展成符合思覺失調症診斷，故 B 正確。陷阱為 A，妄想疾患整體功能通常優於思覺失調症（敘述方向寫反）；C 妄想疾患與思覺失調症共病的描述不符；D DSM-5 已取消思覺失調症亞型，故「皆包括被害妄想型」不成立。

第 39 題

Linehan（1987）認為邊緣型人格障礙症可能是個體具有生物易感性、在不被認可的家庭環境中成長，以及長期被父母忽略或處罰等因素有關，此看法符合下列何種理論？
  1. （A）認知行為理論
  2. （B）素質－壓力模式
  3. （C）基因脆弱性模式
  4. （D）客體關係理論

答案：（B）

詳解與考點

考點為素質－壓力模式（diathesis-stress model）。Linehan 對邊緣型人格的觀點結合生物易感性（素質）與不被認可的家庭環境（壓力），正是素質與壓力交互作用，故 B 正確。陷阱為 A 認知行為理論與 D 客體關係理論：Linehan 雖為 DBT 創始者，但本題描述的成因架構是素質－壓力，而非單純認知行為或客體關係。

第 40 題

李同學與王同學是高三學生，兩人對於即將到來的大學學測都嚴陣以待。李同學的母親為重鬱症患者，家族中也有多位親人有情感疾患病史，下列何者最可能是臨床心理師對兩位學生目前心理健康狀態的預測？
  1. （A）李同學比王同學較可能出現心理健康問題
  2. （B）李同學與王同學出現心理健康問題的可能性是相同的
  3. （C）李同學比王同學更具有因應心理健康問題的技巧
  4. （D）李同學比王同學擁有更良好的社會支持

答案：（A）

詳解與考點

考點為情感疾患的家族遺傳風險。李同學母親為重鬱症且家族多人有情感疾患史，遺傳與家族風險升高，較王同學更可能出現心理健康問題，故 A 正確。陷阱為 B（風險相同，忽略家族史）、C、D（推論其因應技巧或社會支持更佳，題幹無此依據且方向相反），皆屬無根據的樂觀推論。
