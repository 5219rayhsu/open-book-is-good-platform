第 1 題

現今對心理疾病的概念中，下列何者並非定義偏差行為的方式？
  1. （A）形成污名反應
  2. （B）個人主觀苦惱
  3. （C）功能障礙缺損
  4. （D）偏離社會常模

答案：（A）

第 2 題

有關使用失能（disability）作為偏差行為的定義原則，下列何者正確？
  1. （A）強調個人感受
  2. （B）強調生理功能
  3. （C）強調社會功能
  4. （D）強調內在機制

答案：（C）

第 3 題

若某項研究結果顯示：「社會經濟地位（SES）與精神疾病的罹患率，兩者間並無關係（no relationship）」，下列何種類型的研究，會獲致如此結果？
  1. （A）流行病學與單一個案實驗法
  2. （B）流行病學與相關研究法
  3. （C）相關研究法與混合設計
  4. （D）個案研究法與實驗設計

答案：（B）

第 4 題

  1. （A）安非他命
  2. （B）吸入劑
  3. （C）苯環利定
  4. （D）菸草

第 5 題

  1. （A）侵擾行為、衝動控制及行為規範障礙症
  2. （B）身體症狀及相關障礙症
  3. （C）焦慮症
  4. （D）強迫症及相關障礙症

答案：（D）

第 6 題

多重認知功能缺陷是阿茲海默型失智症的臨床特徵，下列何者是核心障礙？
  1. （A）記憶障礙
  2. （B）語言障礙
  3. （C）執行功能障礙
  4. （D）動作技能障礙

答案：（A）

第 7 題

「臺灣大約有 2%的成人患有強迫症」，這句話是在說明有關強迫症的什麼？
  1. （A）發生率
  2. （B）盛行率
  3. （C）風險因子
  4. （D）相關係數

答案：（B）

第 8 題

下列何者不是相關法（correlational method）的特徵？
  1. （A）研究兩個以上變項間的關係
  2. （B）能提供特殊案例的訊息
  3. （C）因果關係較難由此研究方法確定
  4. （D）流行病學家常用此研究方法研究疾病的發生率或危險因子

答案：（B）

第 9 題

相關法（correlational method）與實驗性研究（experimental research）最主要的差異為何？
  1. （A）實驗性研究的樣本通常較大
  2. （B）相關法的樣本通常較大
  3. （C）相關法通常需要操弄特定變項
  4. （D）實驗性研究通常需要操弄特定變項

答案：（D）

第 10 題

有關個案研究法的敘述，下列何者正確？
  1. （A）有利於驗證造成個案改變的假設
  2. （B）可以提供因果關係上的直接證據
  3. （C）可以用來產生新假設
  4. （D）有利於治療效果的推廣應用

答案：（C）

第 11 題

關於橫斷研究（cross-sectional）的敘述，下列何者錯誤？
  1. （A）相較於縱貫性研究，較容易執行
  2. （B）可以解決世代效應的問題
  3. （C）難以確認變項間的因果關係
  4. （D）缺乏個人的發展性資訊

答案：（B）

第 12 題待校

下列研究作法中，何者不屬於類擬實驗法（analogue experiment）？
  1. （A）以白鼠為對象，透過動物實驗來了解人類行為
  2. （B）透過注射乳酸（lactate）來誘發參與者恐慌發作，以了解身體敏感度對恐慌症狀的影響效果
  3. （C）在雙胞胎被不同家庭收養十年之後，再評估兩者的情緒與智力功能
  4. （D）以貝克憂鬱量表對大學生進行施測，根據總分區分高分組與低分組，比較兩組在面對情緒刺激時的注
  5. （E）意力表現

答案：（C）

第 13 題

下列何者不屬於在單一受試者設計（single-subject designs）中，用重複測量（repeated measurement）分析各階段的目標行為表現要項？
  1. （A）趨向（trend）的變化
  2. （B）敏感度（sensitivity）
  3. （C）目標行為改變的程度（level/degree of behavior change）
  4. （D）變化度（variability）

答案：（B）

第 14 題

有關類擬實驗法（analogue experiment）之敘述，下列何者錯誤？
  1. （A）可提高研究倫理的考量
  2. （B）可考慮研究對象的相似性
  3. （C）可考慮由實驗操弄誘發相似的症狀
  4. （D）可具有較好的外效度

答案：（D）

第 15 題

關於評估外傷性腦傷（traumatic brain injury, TBI）的嚴重度，下列敘述何者錯誤？
  1. （A）意識喪失（loss of consciousness）大於 24 小時屬於重度損傷
  2. （B）創傷後失憶（posttraumatic amnesia）小於 24 小時屬於輕度損傷
  3. （C）Glasgow 昏迷量表分數（Glasgow Coma Scale Score）為 9-12 分屬於中度損傷
  4. （D）若 TBI 為神經認知疾患（NCD）的原因，診斷 NCD 時需評估個案 TBI 的嚴重程度

答案：（D）

第 16 題

下列何者是一非自主性的行動，雖然該行動本身看起來相當複雜，個體的動作協調性也佳，看似具有目的性（purposeful），但個體當時的意識狀態明顯不佳，事後也常無法回憶起當時的情況？
  1. （A）automatism
  2. （B）mannerism
  3. （C）stereotype
  4. （D）echopraxia

答案：（A）

第 24 題

  2. （B）必須在引發焦慮的情境下進行
  3. （C）進行暴露（exposure）階段時，若使用真實事物或情境，效果會比以想像的方式來得好
  4. （D）雖然放鬆技術可以降低個案的生理激發，但並沒有證據顯示放鬆是產生療效的必要因素

第 29 題

依據 Kring 等人（2013）談及臨床工作者對於 DSM-IV-TR 中人格疾患診斷分類的疑義，下列那個不是主要原因？
  1. （A）約一半的病人會同時符合兩種或兩種以上的人格疾患診斷
  2. （B）人格疾患不論是在社區或是門診都太常見了，因此與正常人之間缺乏區辨力
  3. （C）有些人雖然有嚴重的人格方面問題，但卻無法符合人格疾患中的任一診斷
  4. （D）高比例的病人可能在某時期符合診斷，但另一時期卻又不符合診斷

王小明常過度關注規則和瑣碎的細節，他平常沒有特別的休閒娛樂，很難放鬆或從事念書以外的活動，同學常說他有完美主義。王小明最有可能是下列那一種人格障礙症？

  3. （C）dependent personality disorder
  4. （D）paranoid personality disorder

第 31 題

依據 Ingram 與 Price（2010）之觀點，有關情緒調節（emotion regulation）在形成個體強烈、不穩定、不恰當之情緒（intense, unstable, and inappropriate emotion）上的角色，下列敘述何者正確？
  1. （A）情緒強烈、不穩定的個體的情緒調節較差，其情緒之受激發閾值也較情緒穩定者高
  2. （B）由於個體在青春期常展現強烈的情緒起伏，情緒調節是個體自青春期開始萌生的心智能力
  3. （C）情緒調節與個體先天的氣質特徵有關，因此不穩定、不恰當的情緒難以因環境因素而改變
  4. （D）在嬰兒期由照顧者主導的情緒調節，是兒童能自我調節強烈情緒的基礎

答案：（D）
