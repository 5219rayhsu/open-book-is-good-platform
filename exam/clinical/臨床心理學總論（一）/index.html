第 1 題

DSM-5將許多診斷重新分類，例如新增「強迫症和相關障礙症」章節，下列敘述何者錯誤？
  1. （A）基於診斷經常共病
  2. （B）基於具有相同的風險因子
  3. （C）基於具有共同的病因
  4. （D）基於症狀表現較為類似

答案：（D）

詳解與考點

本題問DSM-5新增「強迫症及相關障礙症」章節重新分類的依據何者錯誤。考點為DSM-5以效度為基礎的分類原則。重新歸類主要依共病、共同風險因子與共同病因，而非僅因「症狀表現類似」，故(D)錯誤為答案。陷阱在症狀相似看似合理，但DSM-5強調的是潛在病因與危險因子的共通性，而非表面症狀相似。

第 33 題

認為「種族」 （ethnicity）在心理疾患的表現及原因上占有重要份量的是什麼觀點？
  1. （A）學習理論
  2. （B）現象學派
  3. （C）人本論
  4. （D）社會文化因素

答案：（D）

詳解與考點

正解：題眼在「種族」與「心理疾患的表現及原因」——判準是理論是否把文化、族群處境、社會結構與歧視經驗視為心理健康的重要脈絡。社會文化因素直接處理族群與文化如何影響症狀表達、求助與風險，故選 D。

A：學習理論主要以制約、模仿與增強解釋行為形成，並不以種族或文化脈絡為核心分析單位。

B：現象學派重視個人的主觀經驗與意義世界，但題目問的是種族在疾患表現與成因中的系統性重要性，較符合社會文化觀點。

C：人本論著重自我實現、主觀選擇與成長潛能，並非以族群社會脈絡為主要解釋架構。

本題考點：社會文化觀點（sociocultural perspective）——以文化、族群與社會結構理解心理疾患；文化脈絡（cultural context）——影響症狀意義、表現與求助途徑。

第 25 題

某研究者想藉由研究來檢驗以下假設： 「焦慮患者的注意力會選擇性地偏向環境中的負向訊息」 ， 下列何者是最適合該研究者選擇的研究作業？
  1. （A）Recognition task
  2. （B）Random number generation task
  3. （C）Dot-probe task
  4. （D）Trail making task

答案：（C）

詳解與考點

正解：題眼在「注意力會選擇性地偏向環境中的負向訊息」——判準是研究作業必須直接測得注意力朝威脅線索配置的快慢。Dot-probe task 同時或短暫呈現威脅與中性刺激，再以探測點反應時間推估注意偏向；對威脅位置探測點反應較快，即支持注意偏向，故選 C。

A：Recognition task 主要測量辨識或記憶表現，不能直接區分最初的注意定向。

B：Random number generation task 常用來檢視執行控制或認知負荷；它不呈現威脅與中性線索的空間競爭。

D：Trail making task 主要測量視覺掃描、處理速度與轉換能力。最強誘答在於它也含注意成分，錯在未針對負向訊息的選擇性定向。

本題考點：點探測作業（dot-probe task）——以探測點反應時間推估注意偏向；注意偏向（attentional bias）——焦慮者較易優先處理威脅線索。

第 17 題

基因中的 DNA 序列生產出蛋白質的過程，步驟從 DNA 轉錄成 mRNA 開始，一直到對於蛋白質進行後轉譯修飾為止，是基因被開啟與關閉（turned on and off）的歷程，此過程稱為：
  1. （A）基因表現（gene expression）
  2. （B）多基因（polygenic）
  3. （C）轉錄（transcription）
  4. （D）多態性（polymorphism）

答案：（A）

詳解與考點

正解：題眼在「從 DNA 轉錄成 mRNA」到「蛋白質後轉譯修飾」——題幹描述的是基因資訊由 DNA 經 RNA 到蛋白質產物的整體運作與調控歷程，稱為基因表現，故選 A。

B：多基因是指一項特徵受多個基因共同影響，不是 DNA 到蛋白質的歷程，故非答案。

C：轉錄只是 DNA 產生 mRNA 的其中一步，題幹還包括後續轉譯與修飾，故非答案。

D：多態性指族群中同一基因座存在不同變異型態，不是基因被開啟或關閉的過程，故非答案。

本題考點：基因表現（gene expression）涵蓋轉錄、轉譯與蛋白質調控；轉錄（transcription）是 DNA 生成 mRNA 的步驟；多態性（polymorphism）描述遺傳變異而非表現歷程。

第 9 題

過去 DSM 診斷系統被批評欠缺考量種族文化之差異，從那一個版本開始增加文化敏感度？
  1. （A）DSM-III
  2. （B）DSM-III-R
  3. （C）DSM-IV
  4. （D）DSM-IV-TR

答案：（D）

詳解與考點

正解：本題問的是 DSM 版本沿革中，文化因素是從哪一版起被正式納入診斷系統——判準不是哪一版提到文化，而是哪一版把文化考量制度化為診斷程序的一部分（文化形構綱要 Outline for Cultural Formulation、文化相關症候群詞彙表、各疾患條目下的文化說明）。官方答案為 D；惟主流臨床心理學教科書多把這套文化附錄的建置記在 DSM-IV，DSM-IV-TR 屬文字修訂版，作用在更新與擴充各疾患的描述性說明而非首創該架構，此處認定基準有爭議，作答仍照官方答案，故選 D。

A、B：DSM-III 與 DSM-III-R 的變革主軸在操作型診斷準則與多軸診斷系統的建立，把診斷從病因理論的推論轉為描述性、以信度為導向的判準；文化差異在這兩版尚未成為診斷程序中的獨立考量，正是「欠缺種族文化考量」這項批評所指的時期。

C：DSM-IV 是最強誘答——文化形構綱要與文化相關症候群的詞彙表確實出現在這一版，若以「首度把文化寫進系統」為判準，答案會落在 C。分辨關鍵在兩種不同的認定基準：以附錄架構首度出現為準會選 DSM-IV，以各疾患內文的文化說明全面擴充為準才會選 DSM-IV-TR。

本題考點：DSM 的版本沿革與各版的變革主軸——DSM-III/III-R 建立操作型準則與多軸系統（operational criteria, multiaxial system）；文化敏感度（cultural sensitivity）的制度化以文化形構綱要（Outline for Cultural Formulation）與文化相關症候群（culture-bound syndromes）詞彙表為標誌，其歸屬版本在 DSM-IV 與 DSM-IV-TR 之間存在認定差異，此類「哪一版開始」的題目須先確認採計的是架構首創還是內文擴充。
