第 1 題

下列何者不是個案研究法的缺點？
  1. （A）可能導致無系統性的觀察
  2. （B）容易鼓勵對資料的主觀詮釋
  3. （C）變項間關係容易糾葛不清
  4. （D）無法否定所欲驗證的假設

答案：（D）

第 2 題

在現今精神疾病的概念中，何者與偏差行為的定義無關？
  1. （A）偏離社會常規
  2. （B）個人主觀的苦惱
  3. （C）羞恥的行為
  4. （D）功能障礙

答案：（C）

第 3 題

目前的研究大都支持「注意力缺陷/過動症」的患者，是大腦的那一個部分出問題？
  1. （A）額葉
  2. （B）枕葉
  3. （C）顳葉
  4. （D）頂葉

答案：（A）

第 4 題

以下何者為 Paul Meehl（1962）所提的精神分裂症之心理病理模式？
  1. （A）雙重束縛（double bind）模式
  2. （B）素質-壓力（diathesis-stress）模式
  3. （C）辯證-行為（dialectical-behavior）模式
  4. （D）認知基模（cognitive schema）模式

答案：（B）

第 5 題

下列何者不是自閉症（autistic disorder）患者的症狀表現？
  1. （A）大部分的患者會伴隨智能不足
  2. （B）語言認知技巧通常較非語言認知技巧優秀
  3. （C）特別在青春期多達 25%的個案會發生癲癇
  4. （D）患者的行為症狀範圍很廣，例如：過動、飲食及睡眠異常等

答案：（B）

第 6 題

下列何者不是精神分裂症（schizophrenia）的診斷準則 A5 中的三項負性症狀之一？
  1. （A）情感平板（affect flattening）
  2. （B）貧語症（alogia）
  3. （C）無動機（avolition）
  4. （D）喜樂不能（anhedonia）

答案：（D）

第 7 題

DSM-IV-TR 的物質依賴（substance dependence）診斷準則中「伴隨生理依賴」的特性說明，是指患者需 出現那種證據？
  1. （A）強迫性使用模式（compulsive use）與渴求現象（craving）
  2. （B）強迫性使用模式（compulsive use）與耐受性（tolerance）
  3. （C）耐受性（tolerance）與戒斷（withdrawal）
  4. （D）渴求現象（craving）與戒斷（withdrawal）

答案：（C）

第 8 題

當因為研究倫理的限制，或者在研究執行上的困難，而無法進行真實生活情境（real-life conditions）的研 究，研究者必須考慮的替代方案為何？
  1. （A）類擬研究法（analogue study）
  2. （B）混合設計（mixed design）
  3. （C）受試者間設計（between-group design）
  4. （D）受試者內設計（within-group design）

第 9 題

  2. （B）輻合效度（convergent validity）

第 14 題

假若有一個理論顯示，神經性厭食症和個案早期的性創傷經驗有關。許博士現在提出她的病人罹患神經 性厭食症，但早期並未受到性創傷，以否認該理論。許博士是採取什麼方法？

第 15 題

雙盲（double-blind）設計的優點在於同時排除那兩種干擾因素？

  2. （B）疾病病程的自然恢復與實驗者的正向預期
  3. （C）實驗者的正向預期與研究參與者的正向預期

第 16 題

第 20 題

有關大腦灰質（grey matter）與行為間的敘述，下列何者較為適當？

  2. （B）不同區域的大腦灰質扮演不同的功能，損傷時可能造成空間辨別或抽象能力之異常
  3. （C）灰質間緊密聯繫，因此語言區的皮質受損，常伴隨視知覺和體觸覺功能異常的問題
  4. （D）枕葉的灰質主掌視覺，所以，自幼眼睛受傷失去視覺的患者不會有此區域

第 30 題

有關妄想性人格疾患（paranoid personality disorder）的敘述，下列何者錯誤？
  1. （A）與妄想型精神分裂症（paranoid schizophrenia）之區別，在於妄想性人格疾患患者通常未出現幻覺和認 知功能混亂失序之症狀
  2. （B）與妄想型精神分裂症（paranoid schizophrenia）之區別，在於妄想性人格疾患患者職業功能較少受損
  3. （C）與分裂病性人格疾患（schizotypal personality disorder）某些症狀相似，都有多疑、人際疏離及妄想意念 等症狀
  4. （D）反社會性人格疾患（antisocial personality disorder）及做作性人格疾患（histrionic personality disorder）， 為其最常共病的疾患

答案：（D）

第 31 題

有關精神分析理論中之「本我」、「自我」、「超我」的敘述，下列何者正確？
  1. （A）「本我」的運作乃依循「現實原則」
  2. （B）「超我」運作的目的，在於降低因驅力未獲滿足而來的緊張感
  3. （C）「自我」的運作乃在協調「現實要求」與「慾望滿足」
  4. （D）「力比多」（libido）乃指「超我」所蘊含的能量

答案：（C）

第 32 題

有關 Beck 之認知療法（cognitive therapy）與 Ellis 之理性情緒行為療法（rational-emotive behavior therapy） 之敘述，下列何者正確？
  1. （A）認知療法認為情緒問題來自於認知偏誤，治療方向在於找出負向認知的證據
  2. （B）理性情緒行為療法不認為情緒問題來自於案主對自己、對關係抱持著求完美的心態
  3. （C）理性情緒行為療法為了維繫治療關係，會避免以指導性的方式進行介入
  4. （D）在治療過程中，認知療法並不反對使用非理性想法這個名稱

答案：（A）
