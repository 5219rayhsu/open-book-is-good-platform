第 1 題

以統計上的少數或偏離社會常模來定義偏差行為，其優點是？①診斷信度較高 ②有客觀的切截點 ③ 個案本身有較強的治療動機 ④不考慮文化的影響
  1. （A）①③
  2. （B）②④
  3. （C）①②
  4. （D）③④

答案：（C）

詳解與考點

正解：題眼在「統計上的少數或偏離社會常模」與「優點」——此一定義以常模分布為判準，因此可設定相對客觀的切截點，並提高分類在不同評定者間的一致性；①、②成立，故選 C。

A：③個案治療動機不是統計偏差定義所能保證的結果；被歸為少數或偏離常模，不代表個案主觀上願意接受處遇。

B：④「不考慮文化影響」是限制而非優點。常模本身會受文化與時代脈絡影響，忽略它可能造成錯誤分類。

D：③不成立，且④是缺點，故非答案。

本題考點：統計偏差（statistical deviance）以常模與切截點界定異常，優點是相對客觀及分類一致；文化脈絡（cultural context）與個人痛苦、功能受損仍須另行評估。

第 2 題

以功能失調來定義偏差行為時，最大的問題為何？
  1. （A）會給病患貼標籤
  2. （B）對於功能的判斷沒有絕對性的標準
  3. （C）過於強調負性的面向
  4. （D）利用維度（dimension）的概念有問題

答案：（B）

詳解與考點

正解：題眼在「功能失調」與「最大的問題」——判準是誰定義何謂良好功能、又以何種生活目標衡量；不同文化、角色與個人價值可能有不同答案，沒有絕對標準，故選 B。

A：貼標籤可能是診斷的倫理風險，但不是功能失調定義最根本的概念難題。

C：功能失調確實聚焦困擾或受損，但其主要困難不是「負性」本身，而是功能標準的相對性。

D：以維度概念描述功能好壞並非問題來源，反而可呈現功能受損的程度差異。

本題考點：功能失調（dysfunction）著重個體是否因心理狀態而無法有效生活；偏差行為的界定（definition of abnormality）必須兼顧文化、情境與價值判準，沒有單一絕對門檻。

第 3 題

下列關於 prosopagnosia 的描述，何者錯誤？
  1. （A）prosopagnosia 意指個體無法辨識熟悉的人臉
  2. （B）prosopagnosia 意指個體無法辨識所有人臉和其個別特徵
  3. （C）prosopagnosia 時常伴隨 visual object agnosia 出現
  4. （D）許多研究發現 prosopagnosia 與雙側枕葉損傷有關

答案：（B）

詳解與考點

正解：題眼在 prosopagnosia 與「錯誤」——臉孔失認症的核心是辨識熟悉臉孔或以臉辨認身分的困難，並不等於無法辨認所有人臉及其每一項個別特徵；B 將障礙範圍擴大為全面臉孔知覺不能，故為應選項。

A：無法辨識熟悉者的臉是臉孔失認症的典型表現，故非答案。

C：臉孔處理困難可與視覺物體失認（visual object agnosia）共同出現，尤其在較廣泛的視覺辨識系統受損時，故非答案。

D：臉孔失認症與雙側後部視覺處理區域的損傷有關，常涉及枕顳區網絡；選項以雙側枕葉概括其相關性，故非答案。

本題考點：臉孔失認症（prosopagnosia）是臉孔身分辨識障礙，不等同失明或所有視覺物體皆無法辨識；視覺物體失認（visual object agnosia）與臉孔處理障礙可共現，但兩者概念不可畫上等號。

第 4 題

某研究發現，臺灣某個社區內的犯罪人數與其學校數量呈現正相關，下列對於該現象的解釋，何者最為 可能？
  1. （A）純屬巧合
  2. （B）學校教育導致犯罪
  3. （C）該社區的警察單位執法較嚴所導致的
  4. （D）存在同時影響犯罪人數和學校數量的因素

答案：（D）

詳解與考點

正解：題眼在「犯罪人數與學校數量呈正相關」——相關不能直接推出因果；最合理的判準是是否存在同時影響兩變項的第三變項，例如社區人口或都市化程度，故選 D。

A：單靠相關資料不能排除巧合，但在四個解釋中，第三變項是處理穩定正相關時較有力的科學假設。

B：由學校數量與犯罪人數同時上升，不能推論學校教育導致犯罪，這是把相關誤作因果。

C：執法較嚴可能提高已登錄的犯罪數，但它未能自然解釋為何同一社區的學校數量也較多；除非另有證據連結兩者，不能作為最可能解釋。

本題考點：相關研究（correlational research）只能呈現變項共變；第三變項（third-variable problem）可同時造成兩變項的表面關聯；因果推論（causal inference）需要更能控制混淆因素的設計。

第 5 題

在某一段時間內，所產生的某種疾病新案例（new cases）的比率，稱為：
  1. （A）發生率（incidence）
  2. （B）分配性（distribution）
  3. （C）流行率（prevalence）
  4. （D）風險性（risk）

答案：（A）

詳解與考點

正解：題眼在「某一段時間內」與「新案例」——發生率的判準是計算指定期間新出現的病例比率；題幹明確限定 new cases，故選 A。

B：分配性是描述疾病按人、地、時分布的概念，不是新病例的比例名稱。

C：流行率計入某一時點或期間內所有現有病例，包含舊病例與新病例；它與只算新案例的發生率不同。這是最強誘答，因為兩者都描述疾病頻率，關鍵在題幹的「新」。

D：風險泛指未來發生某事件的可能性，並非此題所問的流行病學頻率指標。

本題考點：發生率（incidence）計算期間內的新病例；流行率（prevalence）計算特定時點或期間的全部現有病例；流行病學（epidemiology）需先辨認題目問的是新發生或既存疾病負荷。

第 6 題

下列何種狀況的發生，是多重基準線設計（multiple baseline designs）所希望獲得的結果？
  1. （A）目標行為改變發生在導入預操弄的獨變項之前
  2. （B）目標行為改變發生在導入預操弄的獨變項之後
  3. （C）目標行為改變發生在一開始進行基準線測量時
  4. （D）目標行為改變發生在最後基準線測量結束前

答案：（B）

詳解與考點

正解：題眼在「多重基準線設計」——判準是不同目標行為、情境或個體的介入時間被錯開，且每一條基準線都在各自導入自變項後才改變；這種時間上的依序改變支持介入效果，故選 B。

A：若尚未導入自變項就先改變，便無法將改變歸因於介入。

C：一開始量測基準線就改變，同樣沒有顯示介入與改變的時間關聯。

D：最後一條基準線結束前自行改變，會削弱不同基準線依序隨介入改變的證據。

本題考點：多重基準線設計（multiple baseline design）以錯開介入時間建立實驗控制；基準線（baseline）應在未介入時維持相對穩定；自變項（independent variable）導入後才出現目標行為改變，才支持因果解釋。

第 7 題

有關「類擬實驗法」（analogue experiment）之敘述，下列何者正確？
  1. （A）該法具有良好的外部效度（external validity）
  2. （B）該法欠缺內部效度（internal validity）
  3. （C）該法的優點多於縱貫研究法（longitudinal study）
  4. （D）該法也可透過動物實驗來了解人類行為

答案：（D）

詳解與考點

正解：題眼在「類擬實驗法」——此法以受控制的實驗情境模擬臨床現象，亦可利用動物模型檢驗與人類行為相關的基本機制；因此 D 正確。

A：類擬情境為了控制變項，往往與真實臨床生活有差距，外部效度通常是其限制，並非良好之處。

B：可操弄變項與控制條件正是類擬實驗的優點之一，通常有助於內部效度，而非欠缺它。

C：類擬實驗與縱貫研究回答的問題不同：前者偏重受控機制，後者偏重隨時間追蹤發展，不能籠統說前者優點較多。

本題考點：類擬實驗（analogue experiment）以可控制的模型研究心理病理機制；內部效度（internal validity）指能否支持操弄造成結果；外部效度（external validity）指結果能否推廣至真實世界。

第 8 題

為了解不同年齡青少年參與同人誌（Cosplay）的發展差異與發展變化，最好採取下列那種研究設計？
  1. （A）橫斷設計（cross-sectional design）
  2. （B）縱貫設計（longitudinal design）
  3. （C）系列設計（sequential design）
  4. （D）回溯法（retrospective method）

答案：（C）

詳解與考點

正解：題眼在同時了解「不同年齡」的差異與「發展變化」——系列設計結合橫斷與縱貫的隊列比較，可同時觀察不同年齡群，並追蹤各群隨時間的改變，最符合題意，故選 C。

A：橫斷設計可比較不同年齡者在同一時間點的差異，卻無法直接觀察同一群人的發展變化。

B：縱貫設計能追蹤同一群人的改變，但單一隊列難以清楚拆分年齡、世代與測量時間的影響；題幹同時要求年齡差異，資訊較不足。

D：回溯法依受試者對過去的報告重建發展歷程，容易受記憶偏誤影響，不能取代直接追蹤。

本題考點：橫斷設計（cross-sectional design）比較不同年齡的群體；縱貫設計（longitudinal design）追蹤同一群體；系列設計（sequential design）整合兩者以檢視年齡、世代與時間變化。

第 9 題

若確認某種治療介入確實有其治療效果，顯示此類療效研究具有下列何者特性？
  1. （A）內部效度
  2. （B）外部效度
  3. （C）假藥效果
  4. （D）模擬效果

答案：（A）

詳解與考點

正解：題眼在「確認治療介入確實有其治療效果」——要能把結果歸因於介入本身，須排除自然改善、期待、其他同時發生事件等替代解釋；這正是內部效度，故選 A。

B：外部效度問的是研究結果能否推廣至其他個案、情境或時間，並不直接保證此研究中的效果由介入造成。

C：假藥效果是受期待影響而改善的替代解釋，研究者應控制它，而非把它當作療效研究的品質特性。

D：模擬效果不是確認療效因果關係的效度概念。

本題考點：內部效度（internal validity）是介入是否造成觀察結果的可信度；外部效度（external validity）是結果的可推廣性；療效研究（treatment outcome research）必須優先處理替代解釋。

第 10 題

根據 S. Freud 的理論，超我（superego）是由什麼發展而來？
  1. （A）本我（id）
  2. （B）自我（ego）
  3. （C）防衛機制（defense mechanism）
  4. （D）伊底帕斯衝突（Oedipus conflict）

答案：（B）

詳解與考點

正解：題眼在 Freud 理論的「超我由何發展而來」——在結構模型中，自我是在本我與現實之間運作的組織；超我由自我內化父母與社會規範而逐步分化，故選 B。

A：本我是本能衝動的來源；自我由本我分化，但超我不是直接由本我發展而來。

C：防衛機制是自我用以處理衝突與焦慮的運作方式，不是超我的發展來源。

D：伊底帕斯衝突的解決與超我形成有關，但它是促成認同與內化的發展情境，不是題目所問的結構來源。這是最強誘答，因為它抓到相關發展階段，卻把相關情境誤當成直接來源。

本題考點：精神分析結構模型（structural model）包含本我（id）、自我（ego）與超我（superego）；超我（superego）由自我（ego）透過認同與規範內化分化；伊底帕斯衝突（Oedipus conflict）與其形成歷程相關。

第 11 題

研究參與者的權益與研究成果何者較重要？
  1. （A）研究參與者的權益比研究成果重要
  2. （B）研究成果比研究參與者的權益重要
  3. （C）兩者同樣重要
  4. （D）看情形，決定於研究成果的貢獻性

答案：（A）

詳解與考點

正解：題眼在研究倫理中「何者較重要」——研究參與者的尊嚴、安全、知後同意與可退出權不能為追求研究成果而犧牲；研究成果的價值必須建立在保障參與者權益的前提上，故選 A。

B：研究成果再具貢獻性，也不能凌駕參與者權益；把研究目的置於人之上違反研究倫理的基本原則。

C：兩者不構成可互相折抵的同等目標；當兩者衝突時，應優先保護參與者。

D：研究貢獻性可影響風險與效益的審查，但不能用來正當化侵犯基本權益。

本題考點：研究倫理（research ethics）以研究參與者保護為優先；知後同意（informed consent）與退出權是基本保障；風險效益評估（risk–benefit assessment）不能取代權益保護。

第 12 題

可能會影響實驗內部效度（internal validity）的因素有很多，當實驗結果因實驗情境過於新奇（novel）而 影響了參與者的表現時，此現象通常稱為：
  1. （A）痕跡效應（carryover effect）
  2. （B）實驗者的預期（experimenter expectancies）
  3. （C）反應性（reactivity）
  4. （D）抽樣偏誤（sampling bias）

答案：（C）

詳解與考點

正解：題眼在「實驗情境過於新奇」而改變參與者表現——參與者因察覺自己身在特殊研究情境，對情境或被觀察本身作出反應，稱為反應性，故選 C。

A：痕跡效應指先前處理或測量殘留的影響延續到後續條件，重點是順序殘留，不是新奇情境。

B：實驗者預期是研究者的信念透過互動或評量影響參與者與結果；題幹沒有描述實驗者傳遞期待。

D：抽樣偏誤關乎樣本是否能代表目標群體，主要威脅外部效度，與受試者在實驗內因新奇而改變表現不同。

本題考點：反應性（reactivity）指研究情境、被觀察或測量本身改變參與者行為；痕跡效應（carryover effect）源自先前處理殘留；抽樣偏誤（sampling bias）主要影響可推廣性。

第 13 題

有關自我精神分析家（ego analyst）的敘述，下列何者正確？
  1. （A）強調幻想的重要性
  2. （B）重視當下情境因素甚於早期的創傷經驗
  3. （C）運用古典制約方法建立治療策略
  4. （D）使用暴露法作為治療策略之一

答案：（B）

詳解與考點

正解：題眼在「自我精神分析家」——自我心理學取向重視自我的適應功能、因應能力及個體與當下環境的互動，不只將病理全然回溯到早期衝突；因此較重視當下情境因素的 B 正確。

A：強調幻想的重要性較接近其他精神分析取向的關注焦點，並非自我精神分析家最具區辨性的主張。

C：古典制約是行為治療的學習理論基礎，不是自我精神分析的治療策略。

D：暴露法是認知行為治療常用的行為介入技術，不屬自我精神分析的典型技術。

本題考點：自我心理學／自我精神分析（ego psychology）強調自我的適應與現實功能；精神分析治療（psychoanalytic therapy）與行為治療（behavior therapy）的理論基礎及技術應分辨；暴露法（exposure therapy）屬行為取向。

第 14 題

有關非系統式觀察法（unsystematic observation）的敘述，下列何者錯誤？
  1. （A）所觀察到的資料較難提供強而有力的知識基礎
  2. （B）所觀察到的資料可以協助研究人員形成研究假設，並嘗試加以驗證
  3. （C）是以隨意或無事先計畫方式進行觀察
  4. （D）屬於自然情境觀察法（naturalistic observation）中的一種

答案：（D）

詳解與考點

正解：題眼在「非系統式觀察法」與「錯誤」——判準是此法雖在自然場域中隨意、未預先規劃地觀察，卻不等同於自然情境觀察法這個較大的研究場域分類。非系統式觀察可啟發研究問題，但本身不是一種自然情境觀察法的固定子類型，故選 D。

B：研究人員可由初步、開放的觀察發現現象並形成可供後續研究驗證的假設，故非答案。

C：隨意或未先規劃的觀察正是非系統式觀察的定義特徵，故非答案。

本題考點：非系統式觀察（unsystematic observation）——重點是缺乏預先設定的觀察架構，適合產生假設但證據力較低；自然情境觀察（naturalistic observation）——指在真實場域蒐集資料，不能與前者直接畫上等號。

  2. （B）有助於不同精神疾病的理論與治療進展相互移轉
  3. （C）有助於解釋對精神疾病臨床治療的結果
  4. （D）有助於解釋不同精神疾病的正確病因

正解：題眼在 Harvey 等人所稱以認知與行為歷程「描述不同精神疾病」的優點，且問「並非」——跨診斷取向可處理共同維持機制，卻不能因此確定每一疾患的正確病因，故選 D。本題是特定文獻的概念整理，其分類範圍具文獻脈絡，故依題幹所指的跨診斷原理作答。

第 24 題

依據 A. Harvey 等人之理論，在跨診斷取向的確定歷程（definite transdiagnostic processes）中，下列何種 推理歷程尚未被證實？
  1. （A）解釋偏誤（interpretational bias）
  2. （B）期待偏誤（expectancy bias）
  3. （C）歸因（attributions）
  4. （D）情緒推理（emotional reasoning）

答案：（C）

詳解與考點

正解：題眼在「確定歷程」與「尚未被證實」——題目要辨認 Harvey 等人整理中尚缺跨診斷實徵支持的推理歷程；官方答案為 C，歸因在該整理中未被列為已確定的跨診斷歷程，故選 C。此題涉及特定研究者的分類與證據狀態，具查證敏感性，以下依題幹指定文獻作答。

A：解釋偏誤是將模糊資訊偏向威脅或負向意義解讀的歷程，已有跨多種情緒疾患的研究支持，故非答案。

B：期待偏誤涉及對未來結果的系統性預期，屬題目所列已獲跨診斷關注的歷程，故非答案。

D：情緒推理是把「我感到如此」當成「事實必然如此」，可見於多種情緒困擾，故非答案。

第 25 題

根據 Harvey 等人（2004）對推理功能的心理病理學實徵研究整理，認為慮病疾患的何種推理歷程較少被 關注？
  1. （A）共變偏誤（Covariation bias）
  2. （B）詮釋偏誤（Interpretational bias）
  3. （C）歸因偏誤（Attribution bias）
  4. （D）期望偏誤（Expectancy bias）

答案：（A）

詳解與考點

正解：題眼在慮病疾患的推理歷程「較少被關注」——本題問的是 Harvey 等人對實徵文獻的整理結果，而非哪一歷程理論上不可能存在；官方答案為 A，共變偏誤在該疾患的研究整理中較少受關注，故選 A。此為特定文獻的研究覆蓋度判斷，分類細節具查證敏感性，故依題幹指定結論作答。

本題考點：慮病疾患（illness anxiety disorder）——以健康焦慮及疾病擔憂為核心；共變偏誤（covariation bias）——錯估事件或線索共同出現的關聯；研究覆蓋度——須與理論關聯性分開判讀。

  2. （B）思考壓抑的矛盾效果（Paradoxical effect of thought suppression）
  3. （C）後設認知的信念（Metacognitive belief）
  4. （D）現實／來源的監控（Reality/source monitoring）

答案：（D）

詳解與考點

正解：題眼在 PTSD 的「思考歷程較少被關注」——本題依 Harvey 等人對實徵研究的整理，官方答案為 D，現實／來源監控在 PTSD 的思考歷程研究中相對較少被關注，故選 D。此為特定文獻的研究分類，具查證敏感性，以下依題幹指定的整理作答。

A：重複思考可與創傷記憶的反覆反芻或擔憂相連，並非題目所指較少關注的項目，故非答案。

B：思考壓抑的矛盾效果指越試圖壓下某念頭，該念頭反而更容易再現；這與侵入性創傷記憶高度相關，故非答案。

C：後設認知信念會影響個體如何評價與控制侵入性思考，是 PTSD 認知歷程中受到討論的面向，故非答案。

本題考點：現實／來源監控（reality/source monitoring）——辨別訊息來自外在事件、記憶或想像的能力；思考壓抑的矛盾效果（paradoxical effect of thought suppression）——壓抑嘗試可能增加目標思考的可近性；創傷後壓力疾患（PTSD）——常涉及侵入性記憶與其控制困難。

第 27 題

「social selectivity」在進行老年人的心理病理研究中，指的是下列何者？
  1. （A）年紀大了，選擇的朋友圈不再是新鮮，而是深交、常在身邊的朋友
  2. （B）年紀大了，選擇的朋友圈還是喜歡新鮮，不是深交的朋友
  3. （C）年紀大了，體力不夠了，選擇的社會活動變小了
  4. （D）年紀大了，體力雖然不夠了，選擇的社會活動仍不至於變小

答案：（A）

詳解與考點

正解：題眼在老年研究的「social selectivity」——此概念指隨時間感被知覺為有限，個體傾向優先選擇具情感意義、熟悉且親近的關係，而非擴張新奇的社交圈，故選 A。

B：偏好新鮮、非深交朋友與社會情緒選擇性理論的預測方向相反，故非答案。

C：體力下降可能限制社會活動，但這是在說活動量的被動縮小，沒有說明關係選擇轉向情感意義，故非答案。

D：即使體力不足仍不縮小活動量，也不是此概念的定義。C 是最強誘答，因為老年人確可能減少活動；關鍵在 social selectivity 講的是關係品質與目標的選擇，而非活動規模，故非答案。

本題考點：社會情緒選擇性（socioemotional selectivity）——隨時間觀改變而優先投資情感意義高的關係；老年心理病理研究（geropsychopathology）——須區分正常的社交目標調整與社會退縮或功能受損。

第 28 題

特殊恐懼症與社交恐懼症對於患者關注（concern-related）刺激均出現較差的記憶能力，根據 Mogg 等人 （1987）的警覺逃避假說（vigilance-avoidance hypothesis），可解釋為：
  1. （A）過度類化記憶的結果
  2. （B）對威脅刺激記憶的提取困難
  3. （C）對威脅刺激感到不舒服的逃避結果
  4. （D）記憶歷程的儲存失敗

答案：（C）

詳解與考點

正解：題眼在「警覺逃避假說」——恐懼症個體可能先對威脅線索警覺，隨後因不舒服而把注意力與處理資源轉離該線索；後段逃避使相關刺激的記憶表現較差，故選 C。

A：過度類化記憶是自傳式記憶提取過於概括的現象，不能直接說明對特定關注刺激的較差記憶，故非答案。

B：提取困難只描述測驗結果，未指出警覺後逃避的情緒與注意力機制，故非答案。

D：若是儲存失敗，表示資訊未被編碼保存；警覺逃避假說強調的是因不舒服而避開持續處理，不能直接等同儲存失敗。B 是最強誘答，因為記憶較差表面上像提取困難；但題幹指定的理論核心是對威脅刺激的逃避，故非答案。

本題考點：警覺逃避假說（vigilance-avoidance hypothesis）——先注意威脅、後轉移或逃避；特殊恐懼症（specific phobia）與社交焦慮症（social anxiety disorder）——可呈現對關注刺激的注意力與記憶處理偏差。

第 29 題

有關「妄想性人格疾患」的敘述，下列何者正確？
  1. （A）對於他人的讚美、批評、意見皆漠不關心
  2. （B）往往會出現怪異的想法
  3. （C）與「妄想型精神分裂症」的不同，在於「妄想性人格疾患」患者並未出現幻覺經驗
  4. （D）與「妄想型精神分裂症」的不同，在於「妄想性人格疾患」患者出現有認知能力的下降

答案：（C）

詳解與考點

正解：題眼在「妄想性人格疾患」與「正確」——判準是人格疾患雖有長期猜疑與不信任，通常不具思覺失調症的持續精神病性症狀；依題幹舊版用語，未出現幻覺經驗可作為與妄想型精神分裂症的區辨線索，故選 C。此題沿用命題當時分類；現行 DSM-5 中文版使用思覺失調症，且實務鑑別不能只憑單一症狀。

A：對讚美、批評與意見漠不關心較像分裂型人格的疏離特質；妄想性人格疾患者反而容易把他人意圖解讀為有害，故非答案。

B：怪異想法較符合思覺失調型人格的認知或知覺扭曲，不是妄想性人格疾患的主要特徵，故非答案。

D：認知能力下降不是妄想性人格疾患與妄想型精神分裂症的典型區辨。這是最強誘答，因為疾患嚴重度似乎可讓人想到功能下降；但鑑別重點是精神病性症狀與整體病程，故非答案。

本題考點：妄想性人格疾患（paranoid personality disorder）——以廣泛不信任與猜疑為核心；思覺失調症（schizophrenia）——可有妄想、幻覺及思考或行為失序，鑑別須整體心理衡鑑。

第 30 題

下列何種類型的人格疾患患者在 30 歲之後，症狀會逐漸改善?
  1. （A）反社會型人格疾患（Antisocial personality disorder）
  2. （B）邊緣型人格疾患（Borderline personality disorder）
  3. （C）自戀型人格疾患（Narcissistic personality disorder）
  4. （D）類分裂型人格疾患（Schizoid personality disorder）

本題送分，無標準答案

詳解與考點

正解：本題經考選部公告一律給分，作答任一選項皆得分。原因是題目要找 30 歲之後症狀會逐漸改善的人格疾患，但符合這個描述的不只一個：（A）反社會型人格疾患的違法與衝動行為隨年齡增長而趨緩，是教科書明載的病程特徵；（B）邊緣型人格疾患的不穩定在成年早期最為劇烈，之後多數個案的衝動與自傷行為逐步減輕。兩者都能對應題幹的年齡描述，差別只在緩解時點的估計，故送分。

A：反社會行為隨年齡下降是公認的病程走向，方向與題幹吻合；只是一般教材把明顯緩解的時點放得比 30 歲更晚一些，且缺乏同理與剝削性的核心特質未必隨之消失。

B：邊緣型的情緒不穩、衝動與自傷在成年早期達到高峰，之後多數個案趨於穩定，追蹤研究顯示相當比例可達症狀緩解，與題幹的年齡描述最為貼近。

C：自戀型人格的核心特質相當穩定，中年以後反而可能因老化與失落而使脆弱面浮現，並無隨年齡改善的通則。

D：類分裂型人格的人際疏離與情感侷限是長期穩定的特質，沒有隨年齡改善的病程描述。

本題考點：人格疾患的病程與年齡效應（course and age effects in personality disorders）——反社會型與邊緣型的外顯行為隨年齡趨緩，自戀型與類分裂型則相對穩定；行為層次的緩解不等於人格結構的改變，緩解率高也不表示核心特質已經消失。

第 31 題

在 Linehan（2006）的觀點中，下列何者是發展出邊緣性人格疾患的原因？
  1. （A）個體具有情緒調節不良的氣質（emotional dysregulation）
  2. （B）家庭環境無法有效的確認（invalidate）個體的情緒
  3. （C）個體具有情緒調節不良的氣質，再加上家庭環境無法有效的確認個體的情緒
  4. （D）個體具有情緒調節不良的氣質，再加上在童年早期遭受到虐待

答案：（C）

詳解與考點

正解：題眼在 Linehan 對邊緣性人格疾患發展的觀點——生物社會理論認為情緒調節不良的氣質與使情緒經驗被否定或不被確認的環境交互作用，故選 C。

A：情緒調節不良的氣質是重要易感因子，但單獨不足以呈現 Linehan 強調的個體與環境交互作用，故非答案。

B：無效化環境是重要環境因素，但若略去個體的情緒脆弱性，仍不是該理論完整的發展模型，故非答案。

D：童年虐待可增加風險，但不是此理論用來取代無效化環境的必要核心條件。這是最強誘答，因為虐待確與許多臨床風險相關；題目問的是 Linehan 的理論組合，故非答案。

本題考點：生物社會理論（biosocial theory）——情緒脆弱性與無效化環境交互形成持續的情緒調節困難；邊緣型人格疾患（borderline personality disorder）——需從情緒、關係與行為調節的長期模式理解。

第 33 題

  2. （B）個人中心治療
  3. （C）行為治療
  4. （D）完形治療

答案：（D）

詳解與考點

正解：題眼在「空椅法」——請個案對空椅上的想像他人、自己的一部分或未竟事務直接表達，著重此時此刻的覺察與經驗整合，是完形治療的代表技巧，故選 D。

A：認知治療主要辨識與檢驗自動化思考、核心信念及行為實驗；雖可使用角色扮演，空椅法不是其典型標誌，故非答案。

B：個人中心治療以同理、真誠與無條件積極關懷促進成長，不以空椅對話作為代表技術，故非答案。

C：行為治療重視可觀察行為、學習原理與暴露或增強程序，與空椅法的經驗性對話不同，故非答案。

本題考點：空椅法（empty-chair technique）——促進未竟事務、內在衝突或關係經驗的表達；完形治療（Gestalt therapy）——強調此時此刻覺察、接觸與經驗整合。

第 34 題

精神分析師對病人「指出其行為的意涵」，此種技巧為：
  1. （A）自由聯想
  2. （B）投射
  3. （C）詮釋
  4. （D）修通

答案：（C）

詳解與考點

正解：題眼在精神分析師「指出其行為的意涵」——治療師把個案的言談、行為、防衛或移情連結到可能的無意識衝突，協助個案理解其意義，稱為詮釋，故選 C。

A：自由聯想是邀請病人盡量說出腦中浮現內容的技術，不是分析師指出內容意涵的行動，故非答案。

B：投射是個體把自己難以承認的感受或衝動歸於他人的防衛機轉，不是治療師的技巧名稱，故非答案。

第 35 題

下列何者被視為自我分析師（ego analyst）？
  1. （A）Sigmund Freud
  2. （B）Anna Freud
  3. （C）Melanie Klein
  4. （D）Aaron Beck

答案：（B）

詳解與考點

正解：題眼在「自我分析師（ego analyst）」——判準是自我心理學把注意力放在自我功能、防衛機制與適應；Anna Freud 系統化整理防衛機制並將精神分析觀點延伸到兒童工作，故選 B。

A：Sigmund Freud 創立精神分析，提出本我、自我與超我的結構觀點；但題目所稱的自我分析師通常不是泛指提出自我概念的 Freud，而是後來以自我功能與防衛為中心發展理論的學者。

C：Melanie Klein 屬客體關係理論的重要代表，核心在早期內在客體、焦慮與偏執—分裂及憂鬱位置，不以自我心理學作為主要標記。

D：Aaron Beck 是認知治療的代表，強調自動思考、核心信念與認知扭曲，和精神分析脈絡的自我分析不同。

第 36 題

依附理論是嬰幼兒發展中重要的心理學概念，有關不安全依附阻抗型之敘述，下列何者正確？
  1. （A）後來可能會發展出品行疾患
  2. （B）後來可能會發展出焦慮疾患
  3. （C）後來可能會發展出心身症
  4. （D）與後來發展特定疾患的關連尚難定論

答案：（D）

詳解與考點

正解：題眼在「不安全依附阻抗型」與「發展特定疾患」——判準是依附型態可作為後續情緒與人際適應的風險線索，卻不能直接推定必然發展為某一特定心理疾患。阻抗型兒童常在分離後難安撫、重逢時既尋求接近又抗拒安撫；這與日後內化問題可能有關，但特定診斷仍受氣質、照顧環境與後續壓力共同影響，故選 D。

A：品行疾患屬外化問題，不能由阻抗型依附單獨推論。依附型態不是把兒童直接分配到某一疾患的診斷工具。

B：焦慮問題與不安全依附可有關聯，因而是最強誘答；錯在把群體層次的風險關聯說成阻抗型必然會發展的特定疾患。

C：心身症同樣不能由此依附型態直接預測；身心症狀的形成還涉及生理、家庭互動與壓力因應等因素。

本題考點：依附理論（attachment theory）描述早期照顧關係與情緒調節；不安全依附是適應風險因子而非特定疾患的充分條件；風險關聯（risk association）不可誤作診斷因果。

第 37 題

鑑別失智症與譫妄症狀，下列何者正確？①失智症是近期記憶退化，譫妄是遠期記憶退化 ②失智症是 逐漸退化，譫妄是急速認知改變 ③失智症通常與憂鬱情緒有關，譫妄則無情緒困擾 ④失智症較少伴 隨急性醫學狀況，譫妄通常伴隨其他醫學狀況產生
  1. （A）①②
  2. （B）②④
  3. （C）①④
  4. （D）③④

答案：（B）

詳解與考點

正解：題眼在「鑑別失智症與譫妄」——判準是起病與波動速度，以及是否有急性生理病因。失智症通常是逐漸退化的認知障礙；譫妄則急性發作、注意力與意識常波動，且常伴隨感染、藥物或其他醫學狀況。因此②與④成立，故選 B。

A：①錯在記憶方向的二分法。兩者都可能有記憶問題；譫妄的核心鑑別線索是急性且波動的注意力、覺醒與認知改變，不是單用近期或遠期記憶切開。

C：①仍錯，故此組合不成立。

D：③錯在把情緒困擾當成鑑別標準。失智症與譫妄都可能呈現焦慮、易怒、憂鬱或情緒不穩，不能據此判定。

本題考點：譫妄（delirium）以急性、波動性注意力與認知改變為核心；失智症／現行常稱重度神經認知障礙症（major neurocognitive disorder）多為漸進退化；鑑別診斷（differential diagnosis）須優先找急性醫學原因。

第 38 題

反應模式誤差（response biases）是許多研究老年人的學者所指出在研究法上的限制。此限制可能影響那 些研究結果？
  1. （A）發現選樣死亡率（selective mortality）過高
  2. （B）反映出其社會預期與價值觀系統（social prediction and value systems）的偏差
  3. （C）重複討論代間因素（cohort effects）的重要性
  4. （D）發現老年人的精神疾病（如焦慮、情緒疾患等）之流行率低於中年人

答案：（D）

詳解與考點

正解：題眼在「反應模式誤差」與老年研究——判準是受試者因社會期待、污名、回憶方式或作答傾向而系統性低報或高報症狀。老年人若較少承認焦慮或情緒困擾，流行病學研究便可能低估其精神疾病盛行率，故選 D。

A：選樣死亡率是追蹤研究中較脆弱或疾病較重者較可能退出或死亡造成的偏差，屬樣本留存問題，不是受試者作答偏差。

B：反映社會期待與價值觀的偏差是反應模式誤差的可能來源或機制，卻不是題目所問最直接受影響的研究結果。

C：世代效應是不同出生世代的歷史經驗差異，需由研究設計辨析，不能等同於個別受試者的反應偏誤。

本題考點：反應偏誤（response bias）會扭曲自陳資料與盛行率估計；選樣死亡率（selective mortality）屬樣本流失偏差；世代效應（cohort effect）是年齡研究中須另行控制的歷史世代差異。

第 39 題

某研究者發現「在第一與第二孕程感冒的母親，孩子在未來罹患思覺失調症的比例高於一般人群」。此 研究結果支持下列何種致病因素？
  1. （A）素質
  2. （B）環境
  3. （C）壓力
  4. （D）心理

答案：（A）

詳解與考點

正解：題眼在「第一與第二孕程感冒」與孩子日後罹患思覺失調症的比例較高——判準是素質指個體既有或長期形成的易感性。母親孕期的病毒感染會干擾胎兒中樞神經系統的發育，在出生之前就留下持久的生物性脆弱度，這正是素質－壓力模式中生物性素質的標準範例（與生產缺氧、孕期營養不良同類），故選 A。

B：若只看暴露來源，孕期感染確實來自個體之外，這是本題最強誘答；但在素質－壓力模式中，環境指的是出生後作用於個體的外在條件與生活情境，而非胎兒期即內化為體質的長期易感性，故非答案。

C：壓力指促發症狀或使個體失代償的急性、近端負荷；題幹描述的是胎兒期的風險因子，並未指出發病前的壓力事件，故非答案。

D：心理因素指認知、情緒、家庭互動或因應方式等層次的致病或維持機制；母親孕期感冒屬生物性事件，不屬此類，故非答案。

本題考點：素質－壓力模式（diathesis-stress paradigm）——區分長期易感性與促發壓力；產前感染（prenatal infection）——與生產併發症、孕期營養不良同列為生物性素質；歸類題須看該因子是形成體質，還是在發病前後施加負荷。

第 40 題

有關素質－壓力模式（diathesis-stress paradigm）之敘述，下列何者正確？
  1. （A）先天遺傳屬於「素質」因素
  2. （B）先天遺傳屬於「壓力」因素
  3. （C）後天教養屬於「壓力」因素
  4. （D）天災、車禍等創傷事件屬於「素質」因素

答案：（A）

詳解與考點

正解：題眼在「素質－壓力模式」——判準是素質指個體原有或較持久的易感性，壓力指後續環境負荷或生活事件。先天遺傳是生物性易感來源，故選 A。惟 C 所說後天教養在通常定義下也可構成環境壓力或風險因素；題目採單選而未限定教養的性質與時間點，選項間有歧義，依官方答案作答。

B：先天遺傳的方向講反了；它不是事件性負荷，而是可能提高易感性的素質來源。

C：後天教養可能是壓力或保護因素，因此看似也對；但本題最直接、無條件符合典型定義的是 A，官方答案亦選 A。

D：天災、車禍等創傷事件是外在壓力源，不是個體原有的素質，方向相反。

本題考點：素質（diathesis）是遺傳、氣質或既有脆弱性；壓力（stress）是環境負荷與創傷事件；風險因素的分類須區分來源、時間點與其是否構成個體的易感性。
