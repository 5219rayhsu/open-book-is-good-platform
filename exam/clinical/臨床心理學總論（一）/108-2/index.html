108 年第 2 次臨床心理師臨床心理學總論（一）試題與答案

這一頁是民國 108 年第 2 次臨床心理師臨床心理學總論（一）的整份歷屆試題，共 40 題，題目與標準答案出自考選部「國家考試試題及測驗式試題答案」開放資料。以下逐題列出題幹、選項與答案；要計時作答或記錄成績，請用線上練習。

全部 40 題

第 1 題

關於 DSM-5 的重大改變，下列敘述何者錯誤？
  1. （A）增加對發展議題的描述
  2. （B）加入遺傳學和神經影像學的發現
  3. （C）整合對人格障礙症的診斷
  4. （D）加入網路補充訊息

答案：（C）

第 2 題

DSM-5 的修訂包括回顧在精神疾病的表現中，男女間的潛在差異，其中性別差異（gender differences）意指：
  1. （A）源自於個人生殖器官和 XX 或 XY 染色體組的差異
  2. （B）源自於生物性別及個人的自我表現的差異
  3. （C）源自於個人自我表現的差異
  4. （D）源自於 XX 或 XY 染色體組的差異

答案：（B）

第 3 題

有關精神疾病的定義，下列何者正確？
  1. （A）可供跨國使用的良好定義不應受文化風俗的影響
  2. （B）包含多個精神疾病特徵的定義會造成診斷上的混亂
  3. （C）沒有一個單一要件可以定義所有精神疾病
  4. （D）所有的精神疾病都會導致個人痛苦

答案：（C）

第 4 題

有關單一個案設計法（single-case designs）之敘述，下列何者錯誤？
  1. （A）較常使用於研究治療方法的療效
  2. （B）可以讓研究者建立因果關係
  3. （C）具有良好的外效度
  4. （D）多重基期設計法（multiple baseline designs）屬於單一個案設計法

答案：（C）

第 5 題

相關研究法（correlational method）中，下列何者最可能會出現負相關？
  1. （A）智力與學業成績
  2. （B）受教育年數與罹患阿茲海默症的可能性
  3. （C）年齡與皺紋數量
  4. （D）頭圍大小與腦容量

答案：（B）

第 6 題

關於理論的敘述，下列何者正確？
  1. （A）科學的進步來自於證實理論為真
  2. （B）研究者總是透過檢視資料、提出假設，然後進行檢驗，依此提出理論，不會透過直覺或靈感而 提出理論
  3. （C）以科學的觀點來說，假設必須接受系統化的檢驗，並且可能被推翻
  4. （D）心理病理學的研究通常不需被重複驗證

答案：（C）

第 7 題

研究者在臨床上遇到一位從小在山林長大的個案，此個案與世隔絕許久，發展出其獨有之特殊語 言，研究者對其語言發展感興趣，想進一步進行研究，下列何種研究法較適合用於此情況？
  1. （A）個案研究法（case study）
  2. （B）相關研究法（correlational method）
  3. （C）類擬實驗法（analogue experiment）
  4. （D）整合分析法（meta-analysis）

答案：（A）

第 8 題

在一個設計良好的隨機分派臨床試驗（randomized clinical trial）的實驗中，下列敘述何者正確？
  1. （A）受試者可以自己自由地選擇要分派到實驗組或控制組
  2. （B）除了研究者欲操弄的獨變項外，控制組在樣本特徵或其他變項上，要盡可能與實驗組 （experimental group）類似
  3. （C）控制組是不可以接受安慰劑（placebo）之安排，以免產生對實驗組造成影響
  4. （D）為最不適合用來評估治療療效之方法

答案：（B）

第 9 題

依據 Kring et al. （2016） ，療效研究法 （treatment outcome study） 中，被視為有實證療效 （empirically supported treatments）所需的評估標準，不包括下列何者？
  1. （A）需將研究參與者隨機分配到治療組、或與治療組做比較的控制組或對照組（a control or comparison group）
  2. （B）需有足夠大的樣本用於統計分析
  3. （C）需要使用具有信效度的評估工具來對療效進行評估
  4. （D）實驗結果一定要能被類化（generalized）到自然情境（natural settings）

答案：（D）

第 10 題

關於類擬實驗法（analogue experiment）之敘述，下列何者錯誤？
  1. （A）透過動物實驗來了解人類行為
  2. （B）其中一種類型是透過操弄讓被研究的個體產生暫時性症狀
  3. （C）此研究法能夠提供資訊來判定因果關係
  4. （D）具有良好的外在效度

答案：（D）

第 11 題

在「行為基因學（behavior genetics）」，下列何者不是該領域常用的研究方法？
  1. （A）family method
  2. （B）twin method
  3. （C）experiments
  4. （D）cross-fostering

答案：（C）

第 12 題

單一受試者設計（single-case designs）中使用重複測量（repeated measurement）來評估受試者目 標行為，下列敘述何者正確？
  1. （A）在導入獨變項前，某一目標行為是被重複測量多次
  2. （B）在導入依變項前，某一目標行為是被重複測量多次
  3. （C）在導入依變項後，此目標行為仍繼續重覆被測量
  4. （D）在導入獨變項後，此目標行為則停止被重覆測量

答案：（A）

第 13 題

依據 DSM-5，關於思覺失調類群及其他精神病症（schizophrenia spectrum and other psychotic disorders）盛行率的敘述，下列何者正確？
  1. （A）情感思覺失調症（schizoaffective disorder）的終身盛行率約為 0.7%
  2. （B）短暫精神病症（brief psychotic disorder）在男性群體中比女性群體中更常見
  3. （C）類思覺失調症（schizophreniform disorder）在低社經地位群體中的盛行率較高
  4. （D）40 歲以後才第一次發病的思覺失調症（schizophrenia）病患中，女性顯著多於男性

答案：（D）

第 14 題

迷幻藥（hallucinogens）主要影響的神經傳導物質系統為下列何者？
  1. （A）多巴胺
  2. （B）GABA
  3. （C）正腎上腺素
  4. （D）血清素

答案：（D）

第 15 題

家庭內的「高情緒表露（high expressed emotion）」為許多心理疾病之復發的危險因子，下列何 者不屬於該概念的內涵？
  1. （A）權威教養
  2. （B）敵意
  3. （C）情緒過度涉入
  4. （D）批評性言論

答案：（A）

第 16 題

下列何項因子可以顯著預測雙相情感障礙症中，躁症症狀的發病與嚴重度？
  1. （A）高酬償敏感度
  2. （B）低社會支持
  3. （C）完美主義傾向
  4. （D）高情緒表露

答案：（A）

第 17 題

臨床心理師面對大學外籍學生的求助問題，想利用世界衛生組織失能評估量表第二版 （The World Health Organization Disability Assessment Schedule 2.0, WHODAS 2.0）和文化架構晤談（Cultural Formulation Interview, CFI） 評估該學生的社會支持情況，下列何項評估方式不適合該臨床心理師 採用？
  1. （A）由該學生自行填答 WHODAS 2.0
  2. （B）由臨床心理師親自填答 WHODAS 2.0
  3. （C）由該學生參考 CFI 晤談問題將回答填答於空白紙上
  4. （D）由臨床心理師以 CFI 晤談該學生同寢室的室友或導師

答案：（C）

第 18 題

過度且長期的飲酒容易帶來不良的後果，但不包括下列何者？

  2. （B）中風
  3. （C）記憶問題
  4. （D）提升高密度膽固醇

第 19 題

當我們陳述女性較容易學習到對蛇及蜘蛛的迴避，且比男性早發展出來，來自何種概念？

  2. （B）內隱記憶（implicit memory）
  3. （C）男性腦（male brain）
  4. （D）先備學習（prepared learning）

第 20 題

關於創傷後壓力症候群 （post-traumatic stress disorder, PTSD） 之神經生物研究結果 ， 下列何者正確？
  1. （A）患者的海馬迴體積天生就比一般人來的大，所以對創傷事件的記憶特別好
  2. （B）患者的記憶力有受損
  3. （C）突觸後接受器對於皮質醇（cortisol）的敏感度增加
  4. （D）患者會增加憂慮

第 21 題

思覺失調症患者有明顯的神經生理異常，下列關於此異常的敘述何者錯誤？

  2. （B）腦脊髓液中的多巴胺代謝物（dompamine metabolites）明顯增加
  3. （C）腦皮質麩胺酸（glutamate）明顯減少
  4. （D）扣帶迴皮質（cingulate cortex）中的麩胺酸（glutamate）回收位置（uptake sites）明顯減少

探討恐慌症（panic disorder）成因，下列敘述何者最為適當？

第 26 題

下列何種偏差行為與腦中血清素（serotonin）含量過低之關係最密切？
  1. （A）攻擊及自殺行為
  2. （B）思覺失調症
  3. （C）身體化疾患
  4. （D）躁症

第 27 題

下列關於行為主義對於心理病理的敘述，何者錯誤？
  1. （A）無論何種行為的產生或持續，皆依循學習法則（learning principle）
  2. （B）問題行為的持續，可能與「間隔式的增強（intermittent reinforcement）」有關
  3. （C）系統性減敏法（systematic desensitization）主要運用古典制約的概念
  4. （D）行為主義的缺點在於它沒有考慮到想法與情緒（thinking and feeling）

答案：（C）

第 28 題

有關反社會型人格障礙症與邊緣型人格障礙症之鑑別，下列敘述何者錯誤？
  1. （A）兩者都容易有衝動行為
  2. （B）反社會型人格障礙症患者的操弄行為是為了獲取照顧者（或他人）的關注
  3. （C）反社會型人格障礙症患者的情緒雖相對穩定，但較具侵略性
  4. （D）反社會型人格障礙症患者較無自殺或自殘行為

答案：（B）

第 29 題

關於依賴型人格障礙特質，下列敘述何者錯誤？
  1. （A）當一段親密關係結束時，患者可能因此出現社交退縮、逃避傷害
  2. （B）因為缺乏自信而難以獨自執行新計畫
  3. （C）若無他人的建議或保證，難以做出決定
  4. （D）患者過度專注在不被他人照顧的害怕

答案：（A）

第 30 題

從人格的因素來考量物質濫用的發生，下列何項人格特質與物質濫用的發生關連性最低？
  1. （A）高負向情緒性
  2. （B）尋求正向情緒性高
  3. （C）自我約束性低
  4. （D）神經質傾向高

答案：（D）

第 31 題

關於注意力不足／過動症，下列敘述何者錯誤？
  1. （A）症狀會在進入青春期後消失
  2. （B）同時併有注意力不足與過動兩項症狀的患童，較易有反社會行為

  4. （D）與缺乏行為抑制、約束力及負面情緒等氣質有關

第 32 題

根據 Abramson 等人的絕望理論（hopelessness theory），下列何項特質容易促發憂鬱症？
  1. （A）對負向生活事件做出不穩定且全面歸因型態者

  4. （D）對負向生活事件做出不穩定且特定歸因型態者

關於轉化症的特質及其可能成因，下列敘述何者錯誤？

第 34 題

人本心理學（Humanistic psychology）的發展，乃基於不同學者的理論脈絡而成型，下列那位學 者較不屬於此取向？

第 35 題

有關成人物質濫用的心理脆弱因子的研究發現，下列敘述何者錯誤？
  1. （A）根據人格五大因子（Big-5），較低的神經質（neuroticism）及較高的外向性（extraversion）與 酒精使用障礙症有關
  2. （B）對抽菸的後果期待（outcome expectancy），例如抽菸可以減緩緊張的情緒、或菸抽越多罹患 肺癌的比例越高，會影響戒菸成功與否
  3. （C）對後果期待，同樣也可應用於是否可成功戒斷物質使用
  4. （D）高度的焦慮敏感（anxiety sensitivity）與抽菸有關
