全部 40 題

第 1 題

為考量臨床的實用性，在定義精神疾患時，現今DSM-5對於文化議題所採取的概念，下列何者已被取代？
  1. （A）文化依存症候群（cultural-bound syndrome）
  2. （B）文化症候群（cultural syndrome）
  3. （C）有關苦惱的文化用語（cultural idiom of distress）
  4. （D）文化的解釋或被認定的原因（cultural explanation or perceived cause）

答案：（A）

詳解與考點

考點為 DSM-5 文化議題概念的更替。DSM-5 以「文化症候群」「苦惱的文化用語」「文化解釋／被認定原因」三概念，取代 DSM-IV 較僵化的「文化依存症候群」（cultural-bound syndrome），故答案 A 為被取代者。陷阱在後三項皆為 DSM-5 現行採用的新架構，易誤選，須記得被淘汰的是 bound 一詞。

第 2 題

有關DSM-5，下列敘述何者最不適當？
  1. （A）診斷數量增加
  2. （B）分類診斷的重新組織
  3. （C）仍缺乏向度取向
  4. （D）對症狀嚴重度的描述增加

答案：（C）

詳解與考點

考點為 DSM-5 相較前版的改變。DSM-5 確實診斷數量增加、重新組織分類、增加對症狀嚴重度的描述，並開始引入向度取向（dimensional approach）。故 C「仍缺乏向度取向」最不適當，因 DSM-5 正是朝向度化邁進。陷阱在誤以為 DSM-5 仍純為類別取向，實際已加入向度評估元素。

第 3 題

有關性別（gender）影響罹患精神疾病之敘述，下列何者錯誤？
  1. （A）個體罹病的風險
  2. （B）罹病的總體風險
  3. （C）於疾病中的症狀表現
  4. （D）性別是常見的診斷準則

答案：（D）

詳解與考點

考點為性別對精神疾病的影響。性別會影響個體罹病風險、總體罹病風險、以及疾病中的症狀表現，這些都有實證。但性別本身並非診斷準則（診斷不以性別為標準），故答案 D 錯誤。陷阱在性別雖影響盛行率與表現，卻不等於是構成診斷的條件，兩者須分清。

第 4 題

關於診斷效度的要件，下列敘述何者錯誤？
  1. （A）可以暗示背後的病因
  2. （B）可以預測治療效果
  3. （C）可以預測病程
  4. （D）可以維持診斷的穩定性

答案：（D）

詳解與考點

考點為診斷效度的要件。良好的診斷效度應能暗示病因、預測治療反應、預測病程結果。維持診斷的穩定性屬於信度（reliability）的概念而非效度，故答案 D 錯誤。陷阱在信效度混淆，穩定一致是信度指標，效度關注的是診斷與外部效標的關聯。

第 5 題

研究人員挨家挨戶進行結構化診斷訪談，蒐集並探討特定精神病診斷資料來進行研究，上述為何種類型的研究？
  1. （A）個案研究法（case studies）
  2. （B）流行病學研究法（epidemiological research）
  3. （C）高危險群研究法（high-risk method）
  4. （D）實驗法（experimental method）

答案：（B）

詳解與考點

考點為研究法辨識。挨家挨戶以結構化診斷訪談蒐集特定疾病在母群中的分布資料，是流行病學研究法的典型作法，目的在估計盛行率與發生率，故答案 B。陷阱在 C 高危險群研究，後者是先鎖定高風險者追蹤，而非普查全社區；本題的社區普查特徵指向流行病學。

第 6 題

可以提供罕見或新奇案例的詳細資訊，以利後續產生假說，或更進一步經過控制性研究來驗證此假說。上述指何種研究法？
  1. （A）個案研究法（case study method）
  2. （B）相關研究法（correlational method）
  3. （C）類擬實驗法（analogue experiment）
  4. （D）整合分析法（meta-analysis）

答案：（A）

詳解與考點

考點為研究法辨識。提供罕見或新奇案例的詳細描述，用以產生假說供後續控制性研究驗證，是個案研究法的特性，故答案 A。陷阱在 C 類比實驗，類比實驗是以可操弄的近似情境做控制比較，而非單一個案的深描；個案研究的價值在於假說生成而非假說檢驗。

第 7 題

關於多重基線設計（multiple baseline design）之敘述，下列何者最適當？
  1. （A）可以在同一時間點收集一組人的大量訊息
  2. （B）是一種有系統性的資料蒐集與研究方式
  3. （C）具良好之外在效度
  4. （D）在實驗過程中針對同一目標行為反覆安排基線測量

答案：（B）

詳解與考點

考點為多重基線設計。它屬於單一受試者實驗中有系統性的資料蒐集與研究方式，故答案 B 最適當。陷阱：A 描述的是橫斷大樣本，非多重基線；C 單一受試設計外在效度通常較弱而非良好；D「反覆對同一目標行為安排基線」描述的是 ABAB 撤回設計，多重基線是跨不同行為／情境錯開導入。

第 8 題

在某一實驗中，其實驗者決定選擇使用等候控制組（wait-list control group）而非無治療控制組（a no- treatment control group）來與實驗組進行比較，主要可能的好處是：
  1. （A）可以較快完成實驗程序
  2. （B）可讓所有受試者皆可獲得治療
  3. （C）不需進行隨機分派（random assignment）
  4. （D）可以減少練習效果（practice effect）的影響

答案：（B）

詳解與考點

考點為等候控制組的倫理優勢。採等候名單控制組而非完全不治療控制組，主要好處是研究結束後所有受試者最終皆能獲得治療，兼顧倫理，故答案 B。陷阱在 A 較快完成或 C 不需隨機分派，皆為誤解；等候控制組仍需隨機分派，且不會加快流程，核心優點在倫理上的治療可及性。

第 9 題

受試者不知道他們所屬的研究組別（實驗組或是對照／控制組）或是他們是被給予何種的治療，研究執行人員或提供治療的治療師也是如此，此研究設計為下列何者？
  1. （A）單盲設計（single-blind design）
  2. （B）雙盲設計（double blind design）
  3. （C）交叉設計（crossover design）
  4. （D）同步設計（concurrent design）

答案：（B）

詳解與考點

考點為盲性設計。受試者與研究執行者／治療師雙方皆不知分組或所施治療，屬雙盲設計，可同時控制受試者期望與實驗者偏誤，故答案 B。陷阱在 A 單盲，單盲僅受試者不知分組，研究者仍知情；本題明確指出雙方皆不知，故為雙盲。

第 10 題

流行病學的研究普遍存在下列何種問題？
  1. （A）都是實驗法的研究
  2. （B）只能測到發生率，無法測到盛行率
  3. （C）取到的樣本可能不具代表性
  4. （D）不使用大學生做樣本

答案：（C）

詳解與考點

考點為流行病學研究的限制。其普遍問題是抽樣難以完全具代表性，影響結果外推，故答案 C。陷阱：A 流行病學多為觀察而非實驗法；B 流行病學可同時測發生率與盛行率，並非只能測發生率；D 是否用大學生與此無關。核心限制在樣本代表性。

第 11 題

在ABAB研究設計中，若獎勵方式可增加受試兒童專心做家庭作業的行為，下列敘述何者正確？
  1. （A）該行為在各個A階段出現不穩定的行為模式
  2. （B）該行為在所有B階段明顯較A階段提升
  3. （C）該行為在所有A階段明顯較B階段提升
  4. （D）該行為在各個B階段出現不穩定的行為模式

答案：（B）

詳解與考點

考點為 ABAB 撤回設計的判讀。若獎勵（介入）有效，則所有 B（介入）階段的目標行為應明顯高於 A（基線）階段，呈現導入則升、撤回則降的對照，故答案 B。陷阱在 C 反向敘述（A 高於 B），與有效介入的預期相反；行為應在 B 階段提升而非 A 階段。

第 12 題

下列何者為單一受試者實驗設計（single-subject experimental designs）的優點？①可控制內在效度（internal validity）②可控制外在效度（external validity）③個人特殊面向（a unique aspect）可以被深入探討④實驗結果可幫助研究人員決定是否需要進行團體實驗
  1. （A）①②③
  2. （B）①②④
  3. （C）②③④
  4. （D）①③④

答案：（D）

詳解與考點

考點為單一受試者實驗設計的優缺點。其優點為可控制內在效度（①）、深入探討個人特殊面向（③）、結果可協助決定是否進行團體實驗（④）。外在效度（②）因樣本單一而較弱，非其優點，故答案為 D（①③④）。陷阱在誤選含②的組合，單一受試設計的外在效度正是其弱點。

第 13 題

依據DSM-5，關於神經認知障礙症（neurocognitive disorders, NCD）的敘述，下列何者正確？
  1. （A）額顳葉NCD病患中，語言不流暢症狀（nonfluent language-variant）的盛行率男性比女性高
  2. （B）男性和女性在路易氏體NCD的盛行率比為3比1
  3. （C）約有27%的巴金森氏症病患有輕度的NCD
  4. （D）女性的血管型NCD盛行率高於男性

答案：（C）

詳解與考點

考點為 DSM-5 神經認知障礙症的流行病學細節。正解 C：約 27% 巴金森氏症病患有輕度 NCD（與題組數據相符）。陷阱在其他選項的性別比與盛行率方向皆遭竄改（如路易氏體性別比、額顳葉語言不流暢型性別差異、血管型性別方向），數字與方向的細節是本題易錯處。把握度標 low。

第 14 題

下列那一位個案對於「沒考上研究所」的歸因方式，最有可能促成他在考試失利後產生絕望型憂鬱（hopeless depression）？
  1. （A）我的頭腦不好
  2. （B）考試範圍對我來說實在太多，來不及準備
  3. （C）紙筆測驗讓我焦慮度太高，所以失常
  4. （D）我可能不適合這個領域

答案：（A）

詳解與考點

考點為絕望理論（hopelessness depression）的歸因型態。最易促成絕望型憂鬱的是內在、穩定、整體的歸因，「我的頭腦不好」屬穩定且整體的內在歸因，最具絕望性，故答案 A。陷阱在 B、C 屬不穩定或特定情境歸因（範圍太多、焦慮失常），D 雖內在但較特定，絕望性皆低於 A。

第 15 題

下列何項因子是飲食疾患關鍵的危險因子？
  1. （A）高酬償敏感度（reward sensitivity）
  2. （B）高內在體感覺察（interoceptive awareness）
  3. （C）高完美主義傾向（perfectionism）
  4. （D）高情緒表露（expressed emotion）

答案：（C）

詳解與考點

考點為飲食疾患的關鍵危險因子。高完美主義傾向是飲食疾患（尤其神經性厭食）公認的重要危險因子，故答案 C。陷阱在 B 高內在體感覺察，飲食疾患患者其實常是內感覺察「低落或扭曲」而非高；高情緒表露多與其他疾患復發相關，非飲食疾患的關鍵起始危險因子。

第 16 題

文化概念對於精神疾病的診斷具有重要性，下列原因何者錯誤？
  1. （A）可以避免做出錯誤診斷
  2. （B）可以改善臨床投契關係
  3. （C）可以澄清文化流行病學
  4. （D）文化概念不隨時間改變

答案：（D）

詳解與考點

考點為文化概念對診斷的重要性。重視文化可避免誤診、改善臨床投契關係、澄清文化流行病學。文化概念會隨時間演變，並非固定不變，故 D「不隨時間改變」錯誤。陷阱在誤以為文化症候群是恆定的，實際上文化表現具動態性，DSM-5 也強調此點。

第 17 題

欲研究「焦慮症患者是否更容易將注意力投注在負向線索中？」的議題，下列何項是最適合選用的研究工具？
  1. （A）空間廣度測驗（Spatial Span task）
  2. （B）情緒史處普叫色作業（emotional Stroop task）
  3. （C）記憶廣度測驗（Digit Span task）
  4. （D）台大3-8注意力測驗

答案：（B）

詳解與考點

考點為注意力偏誤的研究工具。要測焦慮患者是否對負向線索有注意力偏向，情緒史楚普作業（emotional Stroop）以情緒字詞干擾命名反應，最能捕捉對威脅訊息的注意力捕獲，故答案 B。陷阱在 A、C、D 多為一般注意力或工作記憶廣度測驗，無情緒效價操弄，無法測情緒性注意偏誤。

第 18 題

下列那一個研究方式不屬於「類擬實驗（analogue experiment）」？
  1. （A）研究暴露在電擊下而無法逃脫的狗之行為反應
  2. （B）將參與者分派到接受某種藥物或安慰劑，比較其情緒症狀的改變程度
  3. （C）選擇在自陳式憂鬱程度問卷中得分偏高的大學生為參與者，比較他們與一般健康人的認知功能差異
  4. （D）讓參與者大量運動而引發與恐慌發作相似的生理反應

答案：（B）

詳解與考點

考點為類比實驗（analogue experiment）的辨識。類比實驗是以動物或近似情境模擬真實病理（如習得無助的電擊狗、誘發類恐慌生理反應、高憂鬱分大學生比較）。選項 B 是真正的隨機分派藥物對安慰劑的臨床實驗，屬正規實驗而非類比，故答案 B 不屬類比實驗。陷阱在誤把標準對照實驗當成類比設計。

第 19 題

關於A. Harvey等人（2004）的跨診斷取向觀點與DSM診斷系統的比較，下列何者最適當？
  1. （A）兩者都強調以連續向度來分析偏差行為
  2. （B）兩者都強調偏差行為的文化與社會背景
  3. （C）相較之下，跨診斷取向比較重視實徵證據，特別是訊息處理歷程中的認知特徵
  4. （D）相較之下，DSM診斷系統比較強調功能分析（functional analysis）的結果

答案：（C）

詳解與考點

考點為跨診斷取向（Harvey 等人， 2004）與 DSM 的比較。跨診斷取向更重視實徵證據，特別是訊息處理歷程中的認知共同特徵（如注意、記憶偏誤），故答案 C 最適當。陷阱在 D，功能分析（functional analysis）是行為取向概念，DSM 為描述性類別診斷，並不以功能分析為核心，方向相反。

第 20 題

在焦慮性疾患的討論中，許多研究指出這類病患有長期的肌肉緊張（muscle tension）反應，係指何類焦慮疾患？
  1. （A）恐慌疾患（panic disorder）
  2. （B）創傷後壓力疾患（PTSD）
  3. （C）社交畏懼症（social phobia）
  4. （D）廣泛性焦慮疾患（GAD）

答案：（D）

詳解與考點

考點為焦慮疾患的生理特徵對應。長期持續的肌肉緊張是廣泛性焦慮疾患（GAD）的核心身體症狀，反映其慢性、瀰漫性的擔憂與緊繃，故答案 D。陷阱在 A 恐慌症，恐慌以陣發性自律神經激發（心悸、呼吸困難）為主，而非長期肌肉緊張；GAD 才是持續性肌張力升高的代表。

第 21 題

下列何者不屬於阿茲海默病（Alzheimer's disease）造成的神經認知疾患（neurocognitive disorder）所呈現的神經病理變化（neuropathological changes）？
  1. （A）腦皮質萎縮（cortical atrophy）
  2. （B）腦血管發炎（vasculitis）
  3. （C）澱粉樣蛋白為主的神經炎斑塊（neuritic plaques）
  4. （D）Tau蛋白為主的神經纖維糾結（neurofibrillary tangles）

答案：（B）

詳解與考點

考點為阿茲海默病的神經病理變化。AD 的典型病變為腦皮質萎縮、β 類澱粉斑塊（neuritic plaques）與 Tau 蛋白神經纖維糾結。腦血管發炎（vasculitis）屬血管／發炎性病變，非 AD 的特徵病理，故答案 B 不屬於。陷阱在誤把血管病變歸入 AD，血管病變應對應血管型失智而非阿茲海默。

第 22 題

下列何項疾患之遺傳性（heritability）的估計為最高？
  1. （A）恐慌症
  2. （B）廣泛性焦慮性疾患
  3. （C）創傷後壓力症候群
  4. （D）蜘蛛恐懼症

答案：（A）

詳解與考點

考點為焦慮相關疾患的遺傳率比較。選項中恐慌症的遺傳性估計相對最高，反映其體質性生物基礎較強，故答案 A。陷阱在 D 蜘蛛恐懼症等特定畏懼，雖部分遺傳但常受特定學習經驗影響，遺傳率不及恐慌症；GAD 與 PTSD 的遺傳估計亦低於恐慌症。把握度標 med。

第 23 題

有關創傷後壓力症候群（post-traumatic stress disorder, PTSD）患者之腦造影的研究發現，下列何者正確？
  1. （A）海馬迴體積萎縮極可能在PTSD診斷前即已發生
  2. （B）嚴重的創傷事件是導致海馬迴體積萎縮的最直接原因
  3. （C）女性患者的海馬迴體積萎縮情況，往往比男性患者嚴重
  4. （D）女性同卵雙胞胎患者海馬迴萎縮情況，較女性異卵雙胞胎患者嚴重

答案：（A）

詳解與考點

考點為 PTSD 海馬迴的腦造影研究。雙胞胎研究（如 Gilbertson 等）發現較小的海馬迴體積可能是創傷前即存在的「易感體質標記」，而非創傷後果，故答案 A：萎縮極可能在診斷前即已發生。陷阱在 B，把嚴重創傷當成海馬迴萎縮的直接原因，正是該研究欲推翻的因果方向。

第 24 題

正子發射掃描（PET）顯示思覺失調症病人：
  1. （A）額葉較活躍
  2. （B）前額葉較不活躍
  3. （C）腦部比較大
  4. （D）腦室比較小

答案：（B）

詳解與考點

考點為思覺失調症的功能性腦造影發現。PET 研究顯示患者前額葉活性降低（hypofrontality），與執行功能、負性症狀缺損相關，故答案 B。陷阱在 A 額葉較活躍，與實際發現相反；腦部結構上患者腦室擴大（非縮小）、腦組織減少，與 C、D 描述皆不符。

第 25 題

與正常兒童相比較，注意力不足過動症的腦部影像研究顯示，下列何者為主要異常腦區？①amygdala ②globus pallidus ③frontal lobe ④hippocampus
  1. （A）①②
  2. （B）②④
  3. （C）②③
  4. （D）③④

答案：（C）

詳解與考點

正解 C（③frontal lobe 與②globus pallidus）。注意力不足過動症（ADHD）的腦影像研究一致指向「額葉—基底核（前額葉皮質與紋狀體／蒼白球等基底核結構）迴路」及其與小腦的連結出現體積縮小或活化異常；額葉（尤其前額葉）負責執行功能、抑制控制，蒼白球（globus pallidus）屬基底核，是該迴路的重要節點，故②③為主要異常腦區，選 C。 說明：蒼白球屬「基底核」，與尾核、殼核合稱時的「紋狀體」並不等同蒼白球（紋狀體一般指尾核＋殼核），辨識時不宜混為一談。 ①杏仁核（amygdala）與④海馬迴（hippocampus）主要與情緒處理、記憶有關，並非 ADHD 腦影像研究最主要、最一致的異常區域，故不選。

第 26 題

下列何者與腦中多巴胺（dopamine）含量過低關係最密切？
  1. （A）肌肉僵硬與顫抖
  2. （B）思覺失調症
  3. （C）追求愉悅感
  4. （D）探索行為

答案：（A）

詳解與考點

考點為多巴胺與帕金森氏症的關係。黑質紋狀體多巴胺神經元退化、含量過低，會導致動作障礙，表現為肌肉僵硬與顫抖，故正解 A。主要陷阱是選「追求愉悅感」或「探索行為」：這兩者反而與多巴胺活性提升（獎賞系統活化）相關，方向相反；思覺失調症傳統多巴胺假說則強調多巴胺過高而非過低，皆與本題「過低」不符。

第 27 題

有關反社會型人格障礙症的診斷與相關研究發現，下列敘述何者錯誤？
  1. （A）患者在十五歲前即有行為規範障礙症（conduct disorder）的證據
  2. （B）診斷上，患者須至少年滿十八歲
  3. （C）症狀表現可能隨年齡增長變得不明顯或緩解
  4. （D）與遺傳（基因）因素間的關係不明顯

答案：（D）

詳解與考點

考點為反社會型人格障礙症的診斷準則與成因。DSM 規定須年滿 18 歲、15 歲前有行為規範障礙證據，症狀常隨年齡緩解，皆正確。正解 D 為錯誤敘述：雙生子與領養研究顯示反社會行為與遺傳因素有明顯關聯，故「關係不明顯」說法錯誤。主要陷阱是誤選 C，但症狀隨年齡減弱確為文獻常見描述，並非錯誤。

第 28 題

根據DSM-5，下列何種類群人格障礙症患者通常顯得焦慮或害怕？
  1. （A）A群
  2. （B）B群
  3. （C）C群
  4. （D）D群

答案：（C）

詳解與考點

考點為 DSM-5 人格障礙症的三大群集分類。A 群（妄想、孤僻、思覺失調型）顯得古怪疏離；B 群（反社會、邊緣、戲劇、自戀）顯得戲劇化、情緒化；C 群（畏避、依賴、強迫）顯得焦慮或害怕，故正解 C。主要陷阱是誤選 B 群，B 群核心是情緒不穩與外顯衝動，而非以焦慮害怕為主軸；且 DSM 並無「D 群」。

第 29 題

下列何者不是自閉症類群障礙症兒童的特徵？
  1. （A）持續的社交溝通與社會互動障礙
  2. （B）侷限的重複行為、興趣或活動模式
  3. （C）症狀多始於小學學齡階段
  4. （D）症狀會限制及干擾目前功能

答案：（C）

詳解與考點

考點為自閉症類群障礙症（ASD）的診斷特徵。社交溝通障礙、侷限重複行為、症狀干擾功能皆為核心準則，正確。正解 C 為非特徵：DSM-5 強調症狀須在發展早期（幼兒期）即出現，而非「多始於小學學齡階段」，故 C 錯誤。主要陷阱是把後來才被察覺的時點誤當成發病起點，但準則看的是早期發展期的徵象。

第 30 題

關於抽搐症，下列敘述何者錯誤？
  1. （A）症狀會隨焦慮或疲憊因素惡化
  2. （B）症狀在平靜和集中精神的狀態會減緩
  3. （C）症狀在激動或壓力事件中會惡化
  4. （D）患者的日常生活功能會受到嚴重影響

答案：（D）

詳解與考點

考點為抽搐症（tic disorder）的症狀波動特性。抽搐會因焦慮、疲憊、激動或壓力而惡化，在平靜專注時減緩，三者皆正確。正解 D 為錯誤敘述：多數抽搐症（如暫時性抽搐）對日常功能影響有限，並非「嚴重影響」，故 D 過度誇大。主要陷阱是把妥瑞症少數重症個案的印象套用到一般抽搐症，誇大其功能損害。

第 31 題

關於創傷後壓力症的成因與認知特徵，下列敘述何者錯誤？
  1. （A）創傷嚴重度與症狀的發展明顯相關
  2. （B）人為的創傷比自然災害更可能促發症狀
  3. （C）患者主動搜尋與回憶創傷事件
  4. （D）患者可能因解離性失憶而無法記得創傷事件的重要情節

答案：（C）

詳解與考點

考點為創傷後壓力症（PTSD）的成因與認知特徵。創傷嚴重度與症狀相關、人為創傷比天災更易促發、可因解離性失憶遺忘關鍵情節，皆正確。正解 C 為錯誤：PTSD 患者典型是逃避而非「主動搜尋與回憶」創傷，逃避是核心症狀群。主要陷阱是把侵入性的非自願再體驗誤解為患者主動回憶，兩者性質相反。

第 32 題

下列何者不是憂鬱症的人際素質？
  1. （A）高度尋求再保證
  2. （B）缺乏社交能力
  3. （C）社會支持網絡貧乏
  4. （D）缺乏情緒表露

答案：（D）

詳解與考點

考點為憂鬱症的人際素質（脆弱因子）。高度尋求再保證、缺乏社交能力、社會支持貧乏，皆為文獻指出與憂鬱相關的人際特徵。正解 D「缺乏情緒表露」不是憂鬱症的人際素質。主要陷阱在於混淆：憂鬱者人際上常過度尋求再保證、表達負向情緒，而非情緒壓抑不表露，故 D 方向不符。此題以概念方向判斷為主。

第 33 題

目前研究指出，當出現童年心理創傷，包括性虐待或身體虐待等，較少見的心理疾患是：
  1. （A）邊緣型人格疾患（borderline personality disorder）
  2. （B）身體型疾患（somatoform disorder）
  3. （C）恐慌疾患（panic disorder）
  4. （D）思覺失調症（schizophrenia）

答案：（D）

詳解與考點

正解 D。本題問「童年創傷（含性虐待或身體虐待）較『少見』關連的心理疾患」。在四個選項中，邊緣型人格疾患、身體型疾患、恐慌疾患與童年受虐的關連在傳統臨床文獻中被討論得相當密切，特別是邊緣型人格疾患與早年創傷的連結最被強調；相對而言，思覺失調症在傳統教材脈絡中被視為以神經發展與遺傳因素為主，與童年受虐的「直接、特異性」關連相對較弱，故四選項中相對「較少見」者選 D。 須持平說明：近代大型研究顯示童年逆境（含受虐）確實會提高日後精神病性症狀（psychosis）的風險，此關連並非可忽略；本題答案 D 應理解為「在這四個選項的相對比較與傳統教材脈絡下」童年受虐的特異性關連相對最弱，而非否定創傷與精神病風險的關係。 A、B、C 與童年創傷的關連相對較明確，故不選。

第 34 題

有關診斷性格疾患具有低信度（reliability）之敘述，下列何者正確？
  1. （A）被診斷有性格疾患的人往往在日常生活功能上與常人無異
  2. （B）不同臨床工作者對於病人是否符合診斷難達成共識
  3. （C）大多數目前符合診斷的病人在日後追蹤時已經痊癒
  4. （D）某一類群性格疾患的人往往也具有其他類群性格疾患

答案：（B）

詳解與考點

考點為診斷信度（reliability）的定義。低信度指不同評定者對同一病人是否符合診斷難以達成一致，故正解 B 正確描述了評分者間信度不足。主要陷阱是選 D：不同類群人格障礙共病雖是事實，但那反映的是診斷區辨效度問題，不是信度問題；A、C 描述的是效度或預後，均與信度概念混淆。

第 35 題

為何心理病理學要特別探討成人的脆弱性，下列敘述何者錯誤？
  1. （A）有些成年期心理疾病的脆弱因子並非只源自於童年期，而是成年期才經歷的
  2. （B）有些成年期心理疾病的脆弱因子源自於潛在基因，但是於成年期才被誘發
  3. （C）某些疾病反覆發作的點燃現象（kindling phenomenon）在成年期更加顯著
  4. （D）成年期的脆弱因子通常難以改變，因此更須留意

答案：（D）

詳解與考點

考點為探討成人脆弱性的理由。脆弱因子可能源於成年期經歷、潛在基因於成年才誘發、點燃現象在成年更顯著，皆為合理理由。正解 D 為錯誤：探討成人脆弱性正是因為它有可介入、可改變的空間，而非「通常難以改變」。主要陷阱是把脆弱因子當成固定不變的宿命，與心理病理學重視可介入性的立場相違。

第 36 題

下列何者不是飲食障礙症較常共病的人格障礙症？
  1. （A）戲劇型人格障礙症
  2. （B）邊緣型人格障礙症
  3. （C）逃避型人格障礙症
  4. （D）依賴型人格障礙症

答案：（D）

詳解與考點

考點為飲食障礙症常共病的人格障礙症。戲劇型、邊緣型常與暴食型共病，畏避型常與限制型共病，皆屬常見。正解 D 依賴型人格障礙症較不是其常見共病。主要陷阱是依賴型表面上與飲食障礙者的人際依附需求相似，易被誤選為共病，但實證上飲食障礙最常見共病為 B 群（戲劇、邊緣）與畏避型，依賴型相對較少。

第 37 題

為了讓兒童出現的新行為可以持續更久，可採取那種策略？
  1. （A）連續增強
  2. （B）間歇增強
  3. （C）物質性增強
  4. （D）區辨性增強

答案：（B）

詳解與考點

考點為操作制約中增強時制對行為持久性的影響。間歇增強（部分增強效應）使行為更抗拒消弱、維持更久，故正解 B。連續增強雖能快速建立新行為，但一旦停止增強行為消退也快。主要陷阱是誤選連續增強，以為「每次都增強」最有效；事實上要讓新行為持續，應在建立後轉為間歇增強。

第 38 題

依據精神疾病診斷及統計手冊第五版（DSM-5），有關智能障礙（intellectual disability）的敘述，下列何者正確？
  1. （A）是患者在生命週期任一時間點出現的智能或適應功能之缺損
  2. （B）患者的功能缺損可分為概念、社會與實務等向度
  3. （C）患者在智能上的缺損包括無法承擔社會責任
  4. （D）患者在概念上的缺損包括進行自我照顧

答案：（B）

詳解與考點

考點為 DSM-5 智能障礙的診斷向度。功能缺損分為概念（學業、推理）、社會（人際、判斷）、實務（自我照顧、生活自理）三向度，故正解 B。主要陷阱：A 錯在缺損須起於發展期而非「任一時間點」；C 把承擔社會責任歸到智能缺損，實屬社會向度；D 把自我照顧歸到概念向度，實屬實務向度，向度歸類錯置是常見誤區。

第 39 題

小美在罹患思覺失調症的母親養育下成長，國中又遭受嚴重霸凌，可能因壓力分泌過量的多巴胺，使其在高二開始出現正性症狀。有關小美的心理病理機制，下列何種理論最能完整解釋前述情況？
  1. （A）精神分析學派
  2. （B）素質－壓力模式
  3. （C）認知行為理論
  4. （D）客體關係理論

答案：（B）

詳解與考點

考點為素質－壓力模式對思覺失調症的解釋。小美有遺傳素質（母親患病）加上後天壓力（霸凌）共同誘發正性症狀，正是素質與壓力交互作用的典型，故正解 B 最完整。主要陷阱是選認知行為理論或客體關係：這些取向各自只能解釋部分機制，無法同時整合先天素質與後天壓力誘發的完整路徑。

第 40 題

存在主義主張：「只要抱持一個存在的理由，便能忍受無數惡劣環境。」以心理病理學素質－壓力模式（diathesis-stress paradigm）觀之，抱持「存在的理由」是防止個體崩潰之何種因素？
  1. （A）心理素質
  2. （B）心理壓力
  3. （C）生理素質
  4. （D）生理壓力

答案：（A）

詳解與考點

考點為素質－壓力模式中素質與壓力的角色辨識。「存在的理由」是個體內在的保護性心理特質，屬於心理素質（diathesis）面向，能緩衝壓力、防止崩潰，故正解 A。主要陷阱是誤選心理壓力：壓力是外在誘發崩潰的負向因素，而「存在理由」是防止崩潰的正向內在資源，兩者角色相反，方向須分清。
