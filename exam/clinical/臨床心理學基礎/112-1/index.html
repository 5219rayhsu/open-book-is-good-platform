第 1 題

有關心理物理學的韋伯律（Weber's law），下列何項敘述最適當？
  1. （A）可以用內省法進行演繹來推導
  2. （B）可視為科學研究歸納法之一例
  3. （C）為科學研究化約主義之代表
  4. （D）不具科學研究可否證性

答案：（B）

詳解與考點

考點為韋伯律與科學研究方法論。韋伯律由大量心理物理觀察資料歸納出刺激差異閾與標準刺激成定比的通則，屬歸納法之一例，故選 B。易誤選 A 內省演繹，但韋伯律是經實證資料歸納而得，並非由內省演繹推導出來。

第 2 題

下列何者為反應偏誤（response bias）？
  1. （A）參與者傾向以特定的反應作答
  2. （B）實驗者對於特定參與者採取特定互動模式
  3. （C）研究者取樣時忽略樣本間差異
  4. （D）研究者對於參與者研究風險的判斷偏誤

答案：（A）

詳解與考點

考點為反應偏誤的定義。反應偏誤指受試者傾向以某種固定方式作答（如總選同意、極端或中庸），與題目實質內容無關，故選 A。其餘選項描述的是實驗者偏誤、抽樣偏誤或風險判斷偏誤，皆非「反應偏誤」的定義。

第 3 題

下列何者不是自主神經系統（autonomic nervous system）的主要功能？
  1. （A）能依照個人主觀意志來控制手和腳的移動
  2. （B）能控制消化系統的蠕動程度，影響消化效率
  3. （C）能調控個人心跳的加快或者減慢
  4. （D）能調控眼球中瞳孔的大小

答案：（A）

詳解與考點

考點為自主神經系統（ANS）的功能範疇。ANS 屬不隨意控制，調節內臟、平滑肌與腺體，故消化蠕動、心跳快慢、瞳孔大小皆其管轄，正解 A 描述「依主觀意志控制手腳移動」屬骨骼肌隨意運動，由體神經系統（軀體神經）負責，並非 ANS 功能，因此為「不是」的答案。陷阱在 C，心跳快慢確由交感／副交感調控，易因「心跳似可受意志影響」而誤選。

第 4 題

下列關於神經系統發育與基因影響的敘述，何者錯誤？
  1. （A）胚胎早期時許多細胞具有相當大的潛能，如果用人為方式移植到另外一個區域，常常可以成功地發育成為新的細胞種類
  2. （B）學者Caspi發現MAOA（monoamine oxidase A）酵素的基因型與暴力行為有關。低-MAOA基因型的男生若童年時期經歷嚴重的家暴事件，長大之後較容易出現反社會或暴力傾向
  3. （C）異卵雙胞胎的研究可以幫助我們了解環境對於行為的影響，因為他們的基因構造完全一樣，又由同樣的父母在同一個時間中撫養長大，可以互為對照組
  4. （D）在小鼠身上學者已經成功地建立起各種基因改造技術，可以將某個特定基因完全拿掉，或者改造使其喪失功能，然後我們可以觀察動物產生的行為變化，藉此推論該基因與行為之間的關係

答案：（C）

詳解與考點

考點為遺傳與行為的研究設計。錯誤在 C：異卵雙胞胎基因「並非完全一樣」，僅約共享一半，唯有同卵雙胞胎才基因相同；敘述把同卵特性誤套到異卵，故錯。A 的胚胎細胞潛能、B 的 Caspi MAOA × 童年受虐交互作用、D 的基因剔除小鼠皆為正確概念。陷阱在 B，內容專有名詞多易令人懷疑，但其交互作用結論正確，不應誤選為錯誤敘述。

第 5 題

關於大腦初級運動皮質（primary motor cortex）的敘述，何者錯誤？
  1. （A）大腦初級運動皮質位置在中央溝前方的帶狀區域
  2. （B）左手左腳的運動，主要由右半腦的運動皮質來控制
  3. （C）臉部肌肉的控制，主要由位於左右半腦中線的初級運動皮質來負責
  4. （D）身體上比較靠近的兩處肌肉，在大腦初級運動皮質上相對應的腦區也會比較靠近

答案：（C）

詳解與考點

考點為初級運動皮質的功能定位。錯誤在 C：臉部肌肉對應的是運動皮質「外側下方」區域（運動小人腳在內側、臉在外側），而非左右半腦中線；中線負責的是腳與下肢。A 中央溝前方帶狀、B 對側控制、D 體感對應拓樸鄰近性皆正確。陷阱在 B，對側支配為基本原則，正確不應誤選。

第 6 題

外在的刺激會引發大腦相對應的神經活動，若實驗者想要研究精神病患在極短時間內做決策時所引發的神經活動與相關歷程，下列那一種神經科學研究技術最合適？
  1. （A）功能性核磁共振造影（functional magnetic resonance imaging）
  2. （B）正子放射造影（positron emission tomography）
  3. （C）穿顱磁刺激（transcranial magnetic stimulation）
  4. （D）事件關連電位（event-related potential）

答案：（D）

詳解與考點

考點為神經科學技術的時間解析度。研究「極短時間內」的決策歷程需高時間解析度，正解 D 事件關連電位（ERP）以毫秒級捕捉腦電變化，最適合追蹤快速認知歷程。陷阱在 A fMRI，雖空間解析度佳且常見，但受血氧反應限制時間解析度差（秒級），無法捕捉極短歷程，最易誤選。

第 7 題

哈洛（H. Harlow）發現小猴子會花較多時間親近裹著絨布的替代媽媽勝過提供奶瓶的鐵絲媽媽。下列何者與此發現有關？
  1. （A）氣質（temperament）
  2. （B）分離焦慮（separation anxiety）
  3. （C）心智理論（theory of mind）
  4. （D）依附／依戀（attachment）

答案：（D）

詳解與考點

考點為 Harlow 恆河猴絨布媽媽實驗。小猴偏好提供溫暖接觸的絨布媽媽勝過供食的鐵絲媽媽，顯示「接觸安慰」是依附形成的關鍵，而非單純餵食，正解 D 依附／依戀。陷阱在 B 分離焦慮，雖屬依附研究相關現象，但本實驗核心是接觸偏好與依附形成，非分離情境的焦慮反應。

第 8 題

小佩在植物園指著蝙蝠說：「鳥！鳥！」，旁邊的媽媽跟小佩說：「這是蝙蝠不是鳥喔！」。於是小佩下次看到蝙蝠時就大叫：「蝙蝠！蝙蝠！」。根據皮亞傑（J. Piaget）的理論，下列何者最適合描述小佩習得了蝙蝠基模的過程？
  1. （A）調適（accommodation）
  2. （B）去中心性（decentration）
  3. （C）同化（assimilation）
  4. （D）再建構（reconstruction）

答案：（A）

詳解與考點

考點為 Piaget 同化與調適。小佩原以「鳥」基模套用蝙蝠（同化），經媽媽糾正後修改既有基模、新建「蝙蝠」類別以符合現實，這是調適（accommodation），正解 A。陷阱在 C 同化，指以既有基模解釋新事物（最初叫「鳥」即同化），但題目問的是「習得蝙蝠基模」的過程，重點在基模的改變而非套用，故選調適。

第 9 題

青少年友誼關係的性別差異為：
  1. （A）女生比男生更強調工具性合作
  2. （B）在出現友誼問題時，男生比女生出現更多關係攻擊
  3. （C）男生比女生傾向在遇到心理問題時，詢問朋友的意見
  4. （D）和友伴相處時，女生比較多自我揭露，男生比較多競爭

答案：（D）

詳解與考點

考點為青少年友誼的性別差異。研究指出女生友誼重情感親密與自我揭露，男生較多競爭與活動取向，正解 D。陷阱在 B：關係攻擊（relational aggression）研究上較常見於女生，題述稱男生較多，方向相反故錯；A 工具性合作非女生特徵、C 遇心理問題求助朋友偏女生而非男生，方向皆與題述顛倒。

第 10 題

小美剛開始學英語時，學會在動詞後加上「ed」代表過去式，因此將「go」說成「goed」，「do」說成「doed」。下列何者最適合描述小美的錯誤？
  1. （A）再造（recast）
  2. （B）過度延伸（over-extension）
  3. （C）延伸不足（under-extension）
  4. （D）過度規則化（over-regularization）

答案：（D）

詳解與考點

考點為語言發展的構詞錯誤。小美將不規則動詞 go、do 一律加 ed 變 goed、doed，是把規則過度套用到例外上，稱過度規則化（over-regularization），正解 D。陷阱在 B 過度延伸，那是詞彙語意層次（如把所有四腳動物都叫狗）的錯誤，與此處構詞規則套用不同，易混淆。

第 11 題

下列何者是物體辨識（object recognition）的理論？
  1. （A）反轉歷程模式（Reversed Process Model）
  2. （B）成分辨識理論（Recognition by Component Theory）
  3. （C）特徵整合論（Feature Integration Theory）
  4. （D）賽局理論（Game Theory）

答案：（B）

詳解與考點

考點為物體辨識理論。正解 B 成分辨識理論（Recognition by Component，Biederman），主張物體由基本幾何元件 geons 組合而被辨識。陷阱在 C 特徵整合論（Treisman），那是注意力與特徵綁定的理論，處理特徵如何整合為知覺，並非物體辨識的核心理論，易因「特徵」字眼誤選。A、D 為杜撰或無關理論。

第 12 題

下列何種現象比較能夠反映出由下而上（bottom-up）的處理歷程？
  1. （A）字優效應（word superiority effect）
  2. （B）語意觸發（semantic priming）
  3. （C）史促普叫色效應（Stroop color naming effect）
  4. （D）色彩後像（color afterimages）

答案：（D）

詳解與考點

考點為由下而上對上而下處理。Bottom-up 由感官刺激本身驅動、不依賴知識經驗，正解 D 色彩後像源於視網膜受器疲勞，純由生理刺激決定。陷阱在 A 字優效應，它反映既有詞彙知識促進字母辨識，屬由上而下；B 語意觸發、C Stroop 亦涉及知識與自動化歷程，皆為上而下。

第 13 題

下列有關視覺通道（visual pathway）的描述，何者正確？
  1. （A）在中央小窩附近的柱狀細胞（rods）密度比周邊高
  2. （B）右眼的訊息先傳到左半腦，然後再經由胼胝體傳送到右半腦
  3. （C）訊息傳遞的先後順序為視網膜、視丘的側膝核、基礎視覺皮質區
  4. （D）偵測物體位置以及移動的路徑為腹側路徑（ventral pathway）

答案：（C）

詳解與考點

考點為視覺通道解剖與傳遞順序。正解 C：訊息依序經視網膜→視丘外側膝狀核（LGN）→初級視覺皮質，順序正確。陷阱在 A，中央小窩密集的是錐細胞（cones）非桿細胞（rods），桿細胞分布於周邊，敘述顛倒故錯。D 偵測位置與移動是背側路徑（dorsal）非腹側，亦錯。

第 14 題

下列的物理向度和心理向度，那一個選項的配對是正確的？
  1. （A）頻率、音高
  2. （B）振幅、音色
  3. （C）頻寬、音量
  4. （D）波長、音質

答案：（A）

詳解與考點

考點為聲音物理向度與心理向度的對應。正解 A 頻率對應音高（pitch），頻率高則音高高。陷阱在 B 振幅，振幅對應的是音量（loudness）而非音色；音色（timbre）對應的是波形或泛音結構。C 頻寬、D 波長之配對亦不正確，易因名詞相近而誤配。

第 15 題

人類的聽覺受器位於：
  1. （A）鼓膜
  2. （B）耳蝸
  3. （C）半規管
  4. （D）鎚骨

答案：（B）

詳解與考點

考點為聽覺受器位置。正解 B 耳蝸，內含柯蒂氏器（毛細胞）為真正的聽覺受器，將機械振動轉為神經訊號。陷阱在 A 鼓膜與 D 鎚骨，它們屬傳音構造（外耳／中耳），負責傳遞與放大振動而非感受；C 半規管屬前庭系統管平衡，非聽覺。

第 16 題

下列何者不是失眠的症狀？
  1. （A）無法入眠
  2. （B）持續醒來
  3. （C）會立即進入REM sleep
  4. （D）很早醒來

答案：（C）

詳解與考點

考點為失眠的症狀表現。失眠包含入睡困難、夜間易醒（睡眠維持困難）與過早清醒，正解 C「會立即進入 REM sleep」並非失眠症狀，反而是猝睡症（narcolepsy）的特徵（睡眠起始即 REM）。陷阱在 B 持續醒來，這確屬失眠的睡眠維持障礙，易被誤判為非典型而誤選。

第 17 題

老鼠在穿梭箱裡面燈光亮了就被電擊，後來一陣子燈光亮了電擊卻沒出現，於是牠的警覺、害怕反應開始下降。但一旦過了一段時間再度看到燈亮時，又會對燈光有很大的反應，此現象稱為：
  1. （A）操作制約（operant conditioning）
  2. （B）二級制約（secondary conditioning）
  3. （C）行為塑造（shaping）
  4. （D）自然回復（spontaneous recovery）

答案：（D）

詳解與考點

考點為古典制約的消弱與自然回復。電擊撤除後恐懼反應消弱（extinction），但休息一段時間後再見燈光又重新出現反應，稱自然回復（spontaneous recovery），正解 D。陷阱在 B 二級制約，那是以已制約刺激建立新制約的歷程，與此處消弱後反應自行回復的現象不同。

第 18 題

下列有關學習的敘述，何者正確？
  1. （A）由於疾病或腦傷所導致的行為改變，這是一種學習
  2. （B）學習會完全反映在外顯行為的改變上
  3. （C）習慣化（habituation）是一種本能，不能稱為學習
  4. （D）重複刺激同一部位會覺得越來越痛，這是一種學習

答案：（D）

詳解與考點

考點為學習的定義界線。正解 D：重複刺激同處愈來愈痛屬敏感化（sensitization），是經驗造成的行為改變，屬學習。陷阱在 C，習慣化（habituation）是最基本的非聯結式學習，題目稱其為本能不算學習故錯。A 疾病腦傷導致的改變非經驗所致不算學習；B 學習未必反映於外顯行為（潛在學習）皆錯。

第 19 題

先天在個體的學習上扮演重要的角色，例如在條件化學習中，必須配合個體對於刺激間的特定屬性有先天上的傾向，會較有利或不利後續的學習，這樣的特性稱為：
  1. （A）古典制約（classical conditioning）
  2. （B）操作制約（operant conditioning）
  3. （C）生物傾向（biological predisposition）
  4. （D）生物變通性（biological flexibility）

答案：（C）

詳解與考點

考點為制約學習中的先天傾向。個體對刺激間特定屬性的先天傾向會使某些聯結較易或難建立（如味覺嫌惡學習、預備性），稱生物傾向（biological predisposition），正解 C。陷阱在 A 古典制約與 B 操作制約，它們是學習的「形式」而非描述先天傾向的特性，題幹問的是這種先天屬性的名稱。

第 20 題

有關操作制約（operant conditioning）學習理論中的固定時距（fixed interval）強化策略之敘述，下列何者正確？
  1. （A）個體想要有效率地調控操作制約反應（operant response），必須能夠提升反應速度
  2. （B）兩次操作制約反應之間必須至少間隔一定的次數，才會得到一次強化物
  3. （C）經過長久訓練之後，個體的反應速率在時距剛開始的時候會比較低，在時距快要結束時反應速率會升高
  4. （D）動物因為沒有時間觀念，所以無法學習這個強化策略

答案：（C）

詳解與考點

考點為固定時距（FI）強化的反應型態。FI 下個體經訓練會呈現「扇形（scallop）」反應：時距剛開始反應率低，接近發放時間時反應率升高，正解 C。陷阱在 B，那是固定比率（fixed ratio）的描述（需累積一定反應次數），與「時距」按時間計算混淆；A、D 敘述亦不符 FI 特性。

第 21 題

Peterson和Peterson（1959）讓參與者進行記憶作業，先聽到三子音，接著進行倒數作業3至18秒，最後要求報告出之前的三子音。關於此研究的發現與意涵，下列敘述何者錯誤？
  1. （A）研究發現隨著倒數時間的增長，參與者的回憶表現越差。若倒數了18秒，正確率幾乎趨近為零
  2. （B）研究發現若僅僅倒數3秒，回憶率並不會受到顯著影響
  3. （C）此研究顯示了複誦（rehearsal）對短期記憶（short-term memory）的重要性
  4. （D）此研究的發現可由干擾（interference）會影響短期記憶的觀點來做解釋

答案：（B）

詳解與考點

考點為 Peterson & Peterson 短期記憶遺忘實驗（Brown-Peterson 派典）。錯誤在 B：僅倒數 3 秒回憶率「確實會」顯著下降（約 80% 上下而非不受影響），題述稱不受影響故錯。A 18 秒趨近於零、C 阻止複誦致遺忘、D 干擾觀點解釋皆正確。陷阱在 D，干擾與消退之爭中此實驗常被引為消退證據，但亦可由干擾解釋故 D 仍正確。

第 22 題

有關短期記憶（short-term memory）與工作記憶（working memory）的比較，下列敘述何者正確？
  1. （A）工作記憶中子系統的功能與短期記憶的功能完全不重疊
  2. （B）工作記憶的容量有個別差異，短期記憶的容量則無
  3. （C）傳統的短期記憶是指訊息的暫存處，工作記憶則擴充至訊息處理的歷程
  4. （D）工作記憶模型的發展是因為研究發現透過組集（chunking）可增加記憶的容量，而短期記憶則與組集無關

答案：（C）

詳解與考點

考點為短期記憶與工作記憶之別。正解 C：傳統短期記憶強調訊息「暫存」，工作記憶（Baddeley）則擴充至訊息的主動「處理」歷程。陷阱在 A，工作記憶子系統與短期記憶功能並非「完全不重疊」（語音迴路本就涵蓋短期儲存），敘述過絕對故錯；B、D 對容量與組集的論述亦不正確。

第 23 題

學者A. Luchins著名的「水瓶問題（the water jar problem）」主要涉及下列那個效應？
  1. （A）育成效應（incubation effect）
  2. （B）頓悟效應（insight effect）
  3. （C）框架效應（framing effect）
  4. （D）心向效應（mental set effect）

答案：（D）

詳解與考點

考點為 Luchins 水瓶問題。受試者習得固定解法後，面對可用更簡單方法的新題仍沿用舊解法，反映心向（思維定勢）效應（mental set），正解 D。陷阱在 B 頓悟效應，那是突然領悟解法的歷程，與水瓶問題凸顯的「僵化沿用舊策略」恰好相反，易混淆。

第 24 題

有關Saul Sternberg（1966）的記憶掃描（memory scanning）實驗，下列何者正確？
  1. （A）參與者正確回答"YES"的反應時間比正確回答"NO"的反應時間快
  2. （B）實驗結果顯示了記憶掃描序列搜尋歷程的特性
  3. （C）結果顯示在記憶中掃描的項目數量與反應時間的關係是非線性的
  4. （D）實驗主要探討導致記憶偏誤的心理歷程

答案：（B）

詳解與考點

考點為 Sternberg 記憶掃描實驗。結果顯示反應時間隨記憶集大小「線性」增加，且 YES／NO 反應時間相近，支持序列、徹底（serial exhaustive）搜尋歷程，正解 B。陷阱在 A 與 C：YES 不比 NO 快（徹底搜尋之故）、關係是線性而非非線性，這兩項與實驗結論相反故錯。

第 25 題

會引發飽食感的荷爾蒙和能調節飽食感的下視丘部位分別為：
  1. （A）類生長素（ghrelin）；下視丘腹內側核
  2. （B）類生長素（ghrelin）；外側下視丘
  3. （C）瘦素（leptin）；下視丘腹內側核
  4. （D）瘦素（leptin）；外側下視丘

答案：（C）

詳解與考點

考點為飽食的荷爾蒙與下視丘調節。正解 C：瘦素（leptin）由脂肪分泌引發飽足感，下視丘腹內側核（VMH）為飽食中樞（受損致過食肥胖）。陷阱在外側下視丘（LH），那是攝食／飢餓中樞（受損致拒食），與飽食中樞相反；類生長素 ghrelin 則促進食慾而非飽足，方向皆相反。

第 26 題

驅力與生理恆定（homeostasis）和下列那個大腦部位的關係最為密切？
  1. （A）杏仁核
  2. （B）海馬迴
  3. （C）下視丘
  4. （D）腦島

答案：（C）

詳解與考點

考點為驅力與生理恆定的腦區。正解 C 下視丘，是維持體溫、攝食、飲水、內分泌等恆定（homeostasis）與驅力調節的核心。陷阱在 A 杏仁核，它主司情緒尤其恐懼處理；B 海馬迴主記憶、D 腦島涉內感受與厭惡，皆非恆定調節的主要中樞。

第 27 題

達爾文認為情緒是與生具有的特性；Ekman從表情照片辨認的一致性，主張人們具共同的基本表情。而根據後續研究，有關後天學習對情緒知覺的影響，下列敘述何者最適當？
  1. （A）不同種族的人，基本表情的表現方式不一致
  2. （B）對同種族者的表情辨識，優於對不同種族者
  3. （C）對不同種族者的臉孔辨識，優於對同種族者
  4. （D）在多族群的同一社會中，弱勢族群的個體在辨識強勢族群個體之情緒時，較易出錯

答案：（B）

詳解與考點

考點為後天經驗對情緒臉孔知覺的影響。研究顯示存在「同族偏誤」，對同種族者的表情辨識優於異種族者（接觸經驗多故），正解 B。陷阱在 C，方向相反（對同族而非異族辨識較佳）故錯；A 把基本表情表現方式說成不一致，違背 Ekman 跨文化一致性的核心發現亦錯。

第 28 題

有關情緒（emotion）與心情（mood）的比較，下列何者錯誤？
  1. （A）情緒可區分為較明確的類別，心情則多以向度來區分
  2. （B）情緒持續的時間較短，心情則持續較久
  3. （C）引發情緒的原因較不明確，引發心情的原因則較為明確
  4. （D）情緒包含完整的認知評估、生理變化、主觀經驗、表情、反應傾向等成分，心情則否

答案：（C）

詳解與考點

考點為情緒與心情之區辨。錯誤在 C：實際上情緒的引發原因「較明確」（有特定對象事件），心情的原因則「較模糊瀰漫」，題述把兩者顛倒故錯。A 情緒分類別、心情分向度、B 情緒短心情長、D 情緒成分較完整皆為正確比較。

第 29 題待校

受測者分別在三種不同情境中進行數學測驗，情境甲：受測者被告知將評估其數學能力；情境乙：以遊戲的形式呈現問題；情境丙：告知刻板印象威脅會導致的負向效應。下圖是實驗結果，請找出最適合的甲、乙、丙情境與長條圖1、2、3的配對：
  1. （A）甲：1；乙：2
  2. （B）乙：1；丙：2
  3. （C）丙：1；甲：3
  4. （D）甲：2；丙：3

第 30 題

測驗理論中的何種特性反映了隨機誤差之大小？
  1. （A）常模
  2. （B）信度
  3. （C）效標關聯效度
  4. （D）後果效度

答案：（B）

詳解與考點

考點為測驗理論中的隨機誤差。信度（reliability）反映測量結果的一致與穩定，隨機誤差愈大信度愈低，故反映隨機誤差大小的特性即信度，正解 B。陷阱在效標關聯效度，效度關乎測量是否「測到該測的構念」（系統性問題），而隨機誤差屬信度範疇，兩者概念須分清。

第 31 題

關於智力測驗評估研究的發現，下列何者錯誤？
  1. （A）幼兒時的智力分數與成年後的智力分數有高度相關
  2. （B）青少年智力測驗和成人智力測驗之間的相關係數介於.85-.95之間
  3. （C）在學期間的智力分數穩定
  4. （D）個體的智力測驗分數與其達成的教育程度之間的相關係數介於.60-.80之間

答案：（A）

詳解與考點

考點為智力的穩定性研究。錯誤在 A：「幼兒時」智力分數與成年智力相關「並不高」（嬰幼兒測量預測力低，需待學齡後才趨穩定），題述稱高度相關故錯。B、C、D 對青少年成人相關、在學穩定、與教育程度相關的數值描述大致符合研究發現。

第 32 題

有關遺傳率（heritability）的描述，下列何者錯誤？
  1. （A）遺傳率是指一群個體的特質變異中可由基因差異來解釋的比例
  2. （B）遺傳率是指涉到個人的測量，而非指涉到母群的測量
  3. （C）遺傳率無法告訴我們團體間平均數差異的來源
  4. （D）遺傳率無法告訴我們環境的改變將對有關特質造成多大的影響力

答案：（B）

詳解與考點

考點為遺傳率（heritability）的概念性質。錯誤在 B：遺傳率是「群體（母群）」層次的統計，描述群體特質變異中可歸因於基因差異的比例，「無法」指涉個人，題述說指涉個人而非母群故錯。A、C、D 對群體變異、團體間差異與環境影響的限制皆為遺傳率的正確理解。

第 33 題

下列何者為Walter Mischel提出的認知情感處理系統（cognitive-affective processing system）的核心想法？
  1. （A）行為的變動性（variability）是性格重要的特性之一
  2. （B）行為的重要決定因子是評價制約（evaluative conditioning）
  3. （C）大多數的行為都是透過觀察學習（observational learning）而來的
  4. （D）個人的特質具有跨情境的穩定性（cross-situational stability）

答案：（A）

詳解與考點

考點為 Mischel 認知情感處理系統（CAPS）。核心主張是行為具情境特定性，跨情境的「變動性」本身即為人格的穩定特徵（行為特徵剖面穩定），正解 A。陷阱在 D，傳統特質論才強調跨情境穩定性，恰是 Mischel 所挑戰的對象，方向相反故不選。

第 34 題

下列何種研究方法或取向強調收集詳細的個人資料與描述？
  1. （A）實驗法（experimental method）
  2. （B）相關法（correlational method）
  3. （C）特則取向（idiosyncratic approach）
  4. （D）通則取向（nomothetic approach）

答案：（C）

詳解與考點

考點為人格研究取向。強調蒐集個別、詳盡個人資料與描述的是特則取向（idiographic／idiosyncratic approach），聚焦個體獨特性，正解 C。陷阱在 D 通則取向（nomothetic），那是追求適用於眾人的普遍法則與群體比較，與重視個別深描恰相反。

第 35 題

關於五大性格特質的文化普同性（cultural universality）研究，下列何者最能說明目前的研究結果？
  1. （A）沒有任何的性格特質具有文化普同性
  2. （B）五項性格特質都具有文化普同性
  3. （C）僅部分性格特質具有文化普同性
  4. （D）僅有一個性格特質具有文化普同性

答案：（C）

詳解與考點

考點為五大人格的文化普同性。跨文化研究大致支持五大特質具相當程度的普遍性，但並非每一項在所有文化都同等清楚地浮現，目前結論為「僅部分具文化普同性」較貼切，正解 C。陷阱在 B 全部具普同性，過於絕對；研究顯示部分特質（如開放性）跨文化結構較不穩定故不選。

第 36 題

如果大華的本我（id）對其性格有相當大的支配力量，他很可能會：
  1. （A）一旦做錯事，會覺得很侷促不安
  2. （B）很容易處在羞怯的狀態
  3. （C）一旦有購物的慾望，就會趕緊衝去買
  4. （D）用很溫和、理性的方式處理衝突

答案：（C）

詳解與考點

考點為 Freud 人格結構之本我。本我遵循享樂原則、追求慾望即時滿足，若主導性格會衝動行事，故「有購物慾望就衝去買」最符，正解 C。陷阱在 A 與 B，做錯事侷促不安、處於羞怯，皆反映超我（道德良心）或自我的作用，與本我的即時滿足相反。

第 37 題

根據演化心理學（Evolutionary Psychology）的論述，男性會喜歡年輕貌美的女性，而女性會喜歡有權勢地位的男性。這是因為：
  1. （A）自尊提升的考量
  2. （B）能力與角色的考量
  3. （C）繁衍後代的考量
  4. （D）男女職業分工的考量

答案：（C）

詳解與考點

考點為演化心理學的擇偶偏好。從性擇與親代投資角度，男性偏好年輕貌美（生育力指標）、女性偏好權勢地位（資源供給能力），核心皆為提升後代繁衍成功，正解 C 繁衍後代的考量。陷阱在 B 能力與角色，較偏社會角色論的解釋，非演化心理學以繁殖適應為本的論述取向。

第 38 題

目前研究發現，會發生社會助長（social facilitation）或社會抑制（social inhibition）還需視「工作性質」而定。若小張所從事的工作是陌生而不熟練的作業，當老闆帶客人來參觀其作業時，小張的工作表現應該最可能出現：
  1. （A）社會助長（工作表現變好）
  2. （B）社會抑制（工作表現變差）
  3. （C）社會助長與社會抑制都會出現
  4. （D）社會助長與社會抑制僅在面對熟練作業時才會出現

答案：（B）

詳解與考點

考點為社會助長與社會抑制取決於作業熟悉度。Zajonc 觀點：他人在場提升優勢反應；面對「陌生不熟練」作業時，優勢反應多為錯誤，故表現變差，出現社會抑制，正解 B。陷阱在 A 社會助長，那適用於熟練／簡單作業；本題作業不熟練故方向相反。

第 39 題

在「思考可能性模式」（elaboration likelihood model）的說服論述中，影響個人是否會運用中央途徑（central route）來處理訊息的主要因素為：
  1. （A）動機與能力
  2. （B）動機與情緒
  3. （C）氣質與能力
  4. （D）動機、氣質、與能力

答案：（A）

詳解與考點

考點為推敲可能性模式（ELM）的中央途徑。是否採用中央途徑（深入處理訊息論點）取決於個人的「動機」與「能力」兩大條件，正解 A。陷阱在含「情緒」「氣質」的選項，ELM 並未將情緒或氣質列為決定中央／邊緣途徑的核心因素，易因加入似合理的變項而誤選。

第 40 題

下列何種情況，個體最不可能經歷認知失調（cognitive dissonance）？
  1. （A）當個體明明不贊成某事，但還是被強迫去做時
  2. （B）當個體花了很大的努力爭取到某事物，但其價值可能不如預期時
  3. （C）當個體之前的態度和之後的行為不一致時
  4. （D）當個體做了違背自己心意的事，但又無合理的解釋時

答案：（A）

詳解與考點

考點為認知失調的引發條件。失調來自態度與行為不一致且「缺乏充分外在理由」。正解 A：被「強迫」去做時，外在壓力提供了充分理由，反而較不會產生失調。陷阱在 D，做違心事且「無合理解釋」正是低外在誘因情境，最易引發失調，與 A 形成對比，須抓住有無外在正當理由的關鍵。
