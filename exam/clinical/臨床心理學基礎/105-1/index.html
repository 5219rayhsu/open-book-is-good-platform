第 1 題

有一名學者認為，只有在知道大腦那些部位的運作和「思考」有關之後，才能了解人類「思考」的心理歷程。這樣的敘述接近那一類心理學觀點？
  1. （A）生物優先論
  2. （B）先天論
  3. （C）化約論
  4. （D）社會生物論

答案：（C）

第 2 題

第 3 題

  2. （B）Gustav Theodor Fechner
  3. （C）Edward Titchener
  4. （D）Kurt Koffka

答案：（C）

第 4 題

利用反應時間（reaction time）來研究心理歷程，此研究法最早可以追溯到：
  1. （A）F. C. Donders
  2. （B）Max Wertheimer
  3. （C）Wilhelm Wundt
  4. （D）Hermann Ebbinghaus

答案：（A）

第 5 題

神經細胞在接受刺激時，會依據刺激大小是否超過閾限來決定是否引發動作電位（action potential），這個現象屬於下列何者？
  1. （A）靜止電位（resting potential）
  2. （B）不反應期（refractory period）
  3. （C）全有或全無定律（all-or-none law）
  4. （D）跳躍傳導（saltatory conduction）

答案：（C）

第 6 題

在動作電位初期神經元的細胞膜電位由負轉為正，這個去極化（depolarization）現象是由下列何種機制造成？
  1. （A）鉀離子通道打開，使得鉀離子由內往外流出
  2. （B）鈉離子通道打開，使得鈉離子由內往外流出
  3. （C）鈉離子通道打開，使得鈉離子由外往內流入
  4. （D）鉀離子通道打開，使得鉀離子由外往內流入

答案：（C）

第 7 題

下列何學門特別著重於探討行為與心智運作的天賦基礎？
  1. （A）行為遺傳學
  2. （B）分子遺傳學
  3. （C）健康心理學
  4. （D）行為神經科學

答案：（A）

第 8 題

荷爾蒙（hormones）與神經傳導素（neurotransmitters）的功能相似之處為：
  1. （A）均在體內細胞間傳遞特定的訊息
  2. （B）被分泌後，均作用於突觸處
  3. （C）傳遞訊息的距離均相同
  4. （D）均透過血液傳輸至受體，以產生作用

答案：（A）

第 9 題

在依附關係發展上，那種照顧者和嬰兒互動的方式有利於發展安全依附？
  1. （A）照顧者只在固定時間提供嬰兒食物，而且每次提供的份量遠超過嬰兒的食量
  2. （B）照顧者鼓勵嬰兒獨立處理自己的情緒，即使嬰兒哭鬧也不回應
  3. （C）照顧者在嬰兒哭鬧時很快回應，而且能按照嬰兒哭鬧原因（如心理或生理）提供回應
  4. （D）在遊戲時，照顧者主導遊戲進行的方式

答案：（C）

第 10 題

以兒童「行走（walking）」發展來探索先天後天的議題，研究發現：
  1. （A）茂密森林裡成長的巴拉圭嬰兒，開始走路的年齡比歐美小孩開始行走的平均年紀晚 6 個月
  2. （B）肯亞父母把嬰兒直立置放於堅硬的表面，這群小孩開始行走的年紀比歐美小孩早 1 個月
  3. （C）剛開始會爬行的嬰兒，因為具有天生的深度知覺，不敢爬過「視覺懸崖」
  4. （D）如果父母親利用操作制約的原則訓練嬰兒行走，會讓嬰兒可以提早到 6 個月大就會行走

答案：（B）

第 11 題

研究顯示，嬰兒有下列那種特徵？
  1. （A）新生兒無法區分在出生前 4 週就聽過的熟悉故事和陌生故事
  2. （B）6 個月大嬰兒能區分成人不易分辨的外語語音
  3. （C）新生兒還不能區分母語和外語的差異
  4. （D）和成人間的說話方式相比，嬰兒對於嬰兒導向式（infant-directed speech）並沒有任何聽覺上的偏好

答案：（B）

第 12 題

任教職的父母希望雅惠投入公職考試，大學畢業後才能擁有一份穩定、有保障的工作；雅惠聽從父母的建議，上大三後就開始補習，努力朝公職目標前進，從未懷疑父母的看法，也不曾為前途感到迷惘。根
  1. （A）據馬西亞（J. Marcia）的自我認同（self identity）理論，雅惠目前的認同狀態，最可能是下列何者？
  2. （B）定向型認同（identity achievement）
  3. （C）迷失型認同（identity diffusion）
  4. （D）早閉型認同（identity foreclosure）

答案：（C）

第 13 題

「何物」路徑（what pathway）與「何處」路徑（where pathway），分別由那個腦葉（lobe）處理？
  1. （A）顳葉（temporal lobe），枕葉（occipital lobe）
  2. （B）頂葉（parietal lobe），顳葉（temporal lobe）
  3. （C）顳葉（temporal lobe），頂葉（parietal lobe）
  4. （D）枕葉（occipital lobe），頂葉（parietal lobe）

答案：（C）

第 14 題

下列何項敘述支持色彩對比理論（opponent-process theory）？
  1. （A）一個藍色的方形會產生黃色的後像（afterimage）
  2. （B）人們可以看到最基本的三種顏色：紅、綠、藍
  3. （C）人們可以看到紅綠色，而非藍綠色
  4. （D）有些人無法區別紅色、綠色或藍色

第 15 題

小明被要求偵測快速呈現數字串中的兩個英文字母，在何種情形下，小明無法偵測到第二個字母？
  1. （A）當第二個字母出現於第一個字母消失後的 300～500 毫秒區間
  2. （B）當第二個字母立即出現於第一個字母消失後
  3. （C）當第二個字母與第一個字母具有不同的顏色
  4. （D）當第一個字母遠大於其他數字

  4. （D）第四階段

第 17 題

下列敘述何者為工具制約（instrumental conditioning）學習的範例？

  2. （B）超商舉辦購物集點的贈獎活動

  4. （D）日本的獼猴學會先用海水洗馬鈴薯，之後才食用

答案：（B）

第 18 題

大型量販店常常舉辦部分物品打折的活動，然而購物的顧客往往除了原先想購買的打折貨品之外，還會買其它打折的東西。從學習理論來看，這種現象符合下列何種概念？

  2. （B）正增強（positive reinforcement）
  3. （C）刺激類化（stimulus generalization）
  4. （D）趨避學習（avoidance learning）

第 19 題

有過車禍經驗的司機，聽到汽車喇叭的聲音就會心跳加快血壓上升。這樣的恐懼制約（fear conditioning）反應與下列那個腦區有關？

  2. （B）胼胝體（corpus callosum）
  3. （C）杏仁核（amygdala）
  4. （D）大腦皮質 Broca 區（Broca's area）

第 20 題

心理學家 Tolman 發現白鼠在迷津中尋找食物所在位置的學習歷程，並非機械式地對環境刺激作直接反應，而是在學習歷程中對於走過的迷津通路有一個整體的概念，進而形成一個：

第 23 題

第 27 題

甄先生是一個公司的主管，他對公司的同仁經常表現出敵意及攻擊的言行，此外，他也很缺乏耐心並且過度強調競爭對公司帶來的益處。有關這位主管的敘述，下列何者錯誤？

  4. （D）他的行為可以經由適度的介入或訓練而改變

第 28 題

第 37 題

第 38 題

第 39 題
