104 年第 2 次臨床心理師臨床心理學基礎試題與答案

這一頁是民國 104 年第 2 次臨床心理師臨床心理學基礎的整份歷屆試題，共 40 題，題目與標準答案出自考選部「國家考試試題及測驗式試題答案」開放資料。以下逐題列出題幹、選項與答案；要計時作答或記錄成績，請用線上練習。

全部 40 題

第 1 題

從研究觀點角度來看，下列何者與其他三者不同？
  1. （A）Edward C. Tolman
  2. （B）Edward L. Thorndike
  3. （C）John B. Watson
  4. （D）Burrhus F. Skinner

答案：（A）

第 2 題

實驗者預期（experimenter expectancy）有可能會導致符合理論預期的效果，而混淆了真相。下列何種實 驗操作最有可能排除該等混淆？
  1. （A）受試者間設計（between-subjects design）
  2. （B）受試者內設計（within-subjects design）
  3. （C）單盲控制（single-blind control）
  4. （D）雙盲控制（double-blind control）

答案：（D）

第 3 題

一個研究發現，離婚的夫妻有 75%回答他們曾為金錢問題而吵架，這是否意謂為金錢而吵架是離婚的主 因？
  1. （A）是，可以用機率的角度（高發生可能性）來作此判斷
  2. （B）是，這是屬於觀察研究法
  3. （C）否，研究中所有參與者都作答，而未進行隨機分配（random assignment）
  4. （D）否，缺乏一般夫妻的對照組資料

答案：（D）

第 4 題

霍桑效應（Hawthorne effect）是指下列何者？
  1. （A）研究參與者因為知道自己正被觀察而改變行為來博得好印象
  2. （B）研究參與者產生符合預期的結果，但是效果其實來自混淆（confounding）變項的影響
  3. （C）研究參與者未能隨機分配至不同情境，實驗結果可能來自於其他變項的干擾
  4. （D）以符合社會期許（socially desirable）方式作答的研究參與者有較高的自尊

答案：（A）

第 5 題

下列何種藥物其作用之神經傳導素機轉與其他三種藥物不同？
  1. （A）安非他命（amphetamine）
  2. （B）利他能（Ritalin, methylphenidate）
  3. （C）麥角酸二乙胺（LSD）
  4. （D）古柯鹼（cocaine）

答案：（C）

第 6 題

與壓力因應息息相關的 HPA 軸線，不包含：
  1. （A）松果體（pineal body）
  2. （B）下視丘（hypothalamus）
  3. （C）腦下垂腺（pituitary gland）
  4. （D）腎上腺（adrenal gland）

答案：（A）

第 7 題

發展過程常會受到不同的先天（基因）與後天（環境）因子的影響。下列何種疾患比較屬於後天因子所 造成？
  1. （A）唐氏症（Down syndrome）
  2. （B）阿茲海默症（Alzheimer’s disease）
  3. （C）苯尿酮症（phenylketonuria, PKU）
  4. （D）胎兒酒精症候群（Fetal Alcohol Syndrome）

答案：（D）

第 8 題

在神經細胞的訊號傳遞過程中，兩個神經細胞間突觸的傳導，不包含下列何種現象？
  1. （A）神經傳導物質的回收（reuptake）
  2. （B）神經傳導物質作用於受體（receptor）上
  3. （C）神經訊息以電流訊號通過突觸溝（synaptic cleft）
  4. （D）神經訊號引發神經傳導物質從突觸前被釋放出來

答案：（C）

第 9 題

設若你在 6 個月的嬰兒面前呈現一個玩具，當嬰兒伸手向前時，你用一塊布將玩具遮住，嬰兒的尋找動 作隨即停止。從 Piaget 學派的觀點，下列何者是上述行為的最佳解釋？
  1. （A）嬰兒不了解被遮住的玩具仍然存在
  2. （B）在尋找過程中，嬰兒可能已經將那個玩具忘記
  3. （C）嬰兒的手眼協調及進行意圖性活動的能力尚未發展成熟
  4. （D）嬰兒很少有機會觀察大人在布的下方尋找被遮住的物體

答案：（A）

第 10 題

阿明看到小美在公園餵流浪狗，指著路旁所貼出的公告勸導她：「明文禁止在公共區域餵飼流浪動物！ 身為社區一份子，你應該守法！」根據柯爾堡（L. Kohlberg）的道德發展理論，下列何者最可能是阿明的 道德推理階段？
  1. （A）道德成規前期（preconventional morality）
  2. （B）道德原則期（principled morality）
  3. （C）道德成規期（conventional morality）
  4. （D）道德成規後期（postconventional morality）

答案：（C）

第 11 題

凱根（J. Kagan）依據嬰兒對新事物的反應不同，將氣質分為抑制型（inhibited）和非抑制型（uninhibited）。 有關凱根的研究，下列敘述何者正確？
  1. （A）抑制型的孩子較大膽，面對新事物較不易害怕，表現較多正向情緒
  2. （B）非抑制型的孩子較害羞，面對新事物較謹慎，容易表現出退縮和害怕
  3. （C）抑制型的人數比例高於非抑制型，但大多數孩子的抑制型氣質介於兩個極端之間
  4. （D）環境可能使抑制型氣質變得較不極端，但最初的氣質類型並不容易改變

答案：（D）

第 12 題

有關發展階段（stages of development）的概念，下列敘述何者錯誤？
  1. （A）所有孩子皆以相同次序經歷相同的階段
  2. （B）每一階段與前後階段的行為有本質上的差異
  3. （C）社會文化因素會影響發展速率和階段次序
  4. （D）如果沒有經歷早先的階段，無法進入後來的階段

答案：（C）

第 13 題

下列何種神經傳導素與痛覺的關係最大？
  1. （A）腦內啡（endorphin）
  2. （B）多巴胺（dopamine）
  3. （C）血清素（serotonin）
  4. （D）正腎上腺素（norepinephrine）

答案：（A）

第 14 題

視覺懸崖（visual cliff）實驗典範是用來偵測嬰兒何種知覺能力？
  1. （A）形狀知覺
  2. （B）知覺恆常性
  3. （C）顏色知覺
  4. （D）深度知覺

答案：（D）

第 15 題

有關訊號偵測理論（signal detection theory）之敘述，下列何者正確？
  1. （A）當有刺激呈現時受試者回答有，稱為命中（hit）
  2. （B）當有刺激呈現時受試者回答無，稱為正確拒絕（correct rejection）
  3. （C）當有刺激呈現時受試者回答無，稱為假警報（false alarm）
  4. （D）當無刺激呈現時受試者回答無，稱為漏失（miss）

答案：（A）

第 16 題

裂腦（split brain）病人是下列那一個腦的部位受到切除而造成的？
  1. （A）胼胝體
  2. （B）前額葉
  3. （C）後頂葉
  4. （D）顳葉

答案：（A）

第 17 題

下列何者為心理學家 Skinner 之主張？
  1. （A）不應只觀察外顯行為，而應考慮內在歷程
  2. （B）應關注大腦生理狀態如何影響動物與人類的外在行為
  3. （C）分析動物或人類的行為，必須有一套完整的理論作為基礎
  4. （D）強調從實驗數據中，找出環境條件如何影響動物或人類之行為

答案：（D）

第 18 題

下列何者可以用古典制約（classical conditioning）來解釋？
  1. （A）人類使用金錢作為交易媒介
  2. （B）觀看含有暴力情節的電視節目，會增加孩童出現暴力行為的頻率
  3. （C）從越南戰爭中退伍的美國軍人，聽到汽車引擎聲會產生害怕情緒
  4. （D）強迫症患者以重覆性洗手消除不安

答案：（C）

第 19 題

下列何者可以用操作制約（operant conditioning）解釋？
  1. （A）媽媽每次聽到垃圾車的音樂遠遠傳來，就會開始打噴嚏
  2. （B）便利商店本月推出買五杯冰咖啡送一個小玩偶的活動後，銷售量增加了百分之三十
  3. （C）小狗一看到我打開狗食的盒子，就流口水
  4. （D）剛進入電影院的時候，什麼都看不見，過了五分鐘才漸漸能看到座位在那裡

答案：（B）

第 20 題

關在籠中的黑猩猩會先用較短的棍子取得較長的棍子，然後再用長棍子取得食物。有關這個實驗之敘述， 下列何者正確？
  1. （A）古典制約（classical conditioning）
  2. （B）操作制約（operant conditioning）
  3. （C）社會學習（social learning）
  4. （D）頓悟（insight）

答案：（D）

第 21 題

布洛卡皮質區（Broca’s area）位於：
  1. （A）頂葉（parietal lobe）
  2. （B）額葉（frontal lobe）
  3. （C）顳葉（temporal lobe）
  4. （D）枕葉（occipital lobe）

答案：（B）

第 22 題

請研究參與者猜測，在一段文字中，k 開頭的字比較多，還是 k 位於第三個字母的字比較多；結果大多數 人會誤以為 k 開頭的字較多。這些人可能受到下列何者影響？
  1. （A）定錨捷思法（anchoring heuristic）
  2. （B）易得性捷思法（availability heuristic）
  3. （C）代表性捷思法（representativeness heuristic）
  4. （D）歸納捷思法（inductive heuristic）

答案：（B）

第 23 題

當我們要回憶一連串的刺激時，在序列中最後呈現的幾個刺激會記得比較好，這個效果稱為：
  1. （A）衰退效果（decay effect）
  2. （B）初始效果（primacy effect）
  3. （C）干擾效果（interference effect）
  4. （D）新近效果（recency effect）

答案：（D）

第 24 題

病人在中風以後，沒有辦法記得中風以後發生的所有事情，這種失憶症屬於：
  1. （A）順向失憶（Anterograde amnesia）
  2. （B）逆向失憶（Retrograde amnesia）
  3. （C）全面性失憶（Global amnesia）
  4. （D）童年失憶（Infantile amnesia）

答案：（A）

第 25 題

有關性行為之敘述，下列何者正確？
  1. （A）睪丸酮（testosterone）愈高的女性愈不會有性的想法與欲望
  2. （B）與女性相比，男性觀看色情片時杏仁核有較高的活化
  3. （C）大腦皮質的多巴胺受體（dopamine receptor）與性的身體愉快有關
  4. （D）在西方的性腳本（sexual script）中，男性決定性行為的發生與否

答案：（B）

第 26 題

以減食來減肥，常出現體重下降後又復胖的情形。對於此現象較佳的解釋為：
  1. （A）葡萄糖狀態假說（glucostatic hypothesis）
  2. （B）脂質狀態假說（lipostatic hypothesis）
  3. （C）設定點理論（set-point theory）
  4. （D）固定點理論（fixed-point theory）

答案：（C）

第 27 題

Ekman & Friesen（1984）研究發現，不同種族間對那種基本情緒表情之辨識一致性最高？
  1. （A）悲傷
  2. （B）快樂
  3. （C）害怕
  4. （D）驚訝

答案：（B）

第 28 題

下列情緒理論的敘述，何者錯誤？
  1. （A）James-Lange 的理論強調生理反應先於情緒感受
  2. （B）Cannon-Bard 的理論主張自主神經反應與情緒感受同時被激發
  3. （C）LeDoux 認為不同情緒對應不同的自主神經反應型態
  4. （D）Cacioppo 主張不同情緒聯結不同的荷爾蒙，而其濃度則與情緒類別無關

答案：（D）

第 29 題

下列有關信度的說明，何者正確？
  1. （A）信度代表一個測量工具的穩定程度
  2. （B）信度代表一個測驗是否能測量到它想要測量的東西
  3. （C）信度關注的是是否皆在相同條件下施測
  4. （D）信度代表一個測驗是否難度適中

第 30 題

下列何者不是 Gardner 多元智力理論（Theory of multiple intelligences）中認為的智能？
  1. （A）邏輯數學智能（Logical-mathematical intelligence）
  2. （B）音樂智能（Musical intelligence）
  3. （C）情緒智能（Emotional intelligence）
  4. （D）人際智能（Interpersonal intelligence）

第 31 題

歌唱比賽中，要求參賽者演唱四首不同歌曲，並由五個評審計分，則無法得到何種信度係數？
  1. （A）評分者間
  2. （B）折半
  3. （C）內部一致性
  4. （D）再測

第 32 題

下列何種作法合乎測驗標準化的要求？
  1. （A）給予動作慢的受測者，較多的作答時間，以測出其真正能力
  2. （B）仔細解答受測者對測試題目的疑問
  3. （C）當受測者有好的表現，告訴他，他很棒，以維持他做測驗的動機
  4. （D）依照測驗手冊的指示施測

第 33 題

下列何特質不屬於五大人格向度（the Big Five）？
  1. （A）神經質（neuroticism）
  2. （B）嚴謹性（conscientiousness）
  3. （C）精神病性（psychoticism）
  4. （D）友善性（agreeableness）

第 34 題

根據氣質（temperament）研究的結果，「抑制型兒童（inhibited children）」對下列何者特別容易感到焦 慮？
  1. （A）親子關係（parent-child relations）
  2. （B）受管束的環境（restricted environment）
  3. （C）兄弟姊妹的競爭（sibling rivalry）
  4. （D）不熟悉的人物、刺激或環境（novel environment）

第 35 題

有關投射測驗的敘述，下列何者錯誤？
  1. （A）可由個體面對模糊刺激所做出的反應中，了解其內在狀態或性格特徵
  2. （B）羅夏克墨漬測驗及主題統覺測驗均為投射測驗
  3. （C）就投射測驗而言，刺激本身無特定意義，但是個體的反應是具有意義的
  4. （D）投射測驗均具有良好的信度及效度

答案：（D）

第 36 題

有關明尼蘇達多向人格測驗（MMPI）的陳述，下列何者正確？
  1. （A）是以效標關鍵法（criterion-keying method）來進行編製
  2. （B）是基於心理動力理論來發展各相關分量表
  3. （C）可以測得個體的種種動機狀態，常用於人事甄選與生涯發展規劃
  4. （D）該量表為半結構式（semi-structured）訪談測驗

第 37 題

購物頻道主持人正在告訴消費者，所推銷的商品品質極佳，本來應該賣多貴，但是剛巧現在週年慶特惠 價，還加送其他配件，所以絕對是物超所值，不買將來一定會後悔。在這樣的推銷之下，消費者常常就 被打動了。上述所使用的是何種引發順從策略（technique for eliciting compliance）？

  3. （C）變化球（the low-ball）
  4. （D）難以得到（hard-to-get）

第 38 題

百貨公司大促銷時，常打出廣告「全館六折」。等我們採買之後，才發現所選購的物品最多只能打八折， 此時常因為我們心理已經準備購買，所以還是咬咬牙掏出了錢。百貨公司可能採用了下列何種策略？
  1. （A）不僅如此（That’s not all）

  3. （C）變化球（the low-ball）
  4. （D）腳在門檻裡（foot-in-the-door）

第 39 題

當自己發怒罵人時，多半會認為是因為他人言行不當、激怒了自己；而看到他人發怒罵人時，卻傾向認 為他人所以罵人是因為個性暴躁。此種情形為下列何者？
  1. （A）公平世界的信念（belief in a just world）

  4. （D）行為者－觀察者的差異（actor-observer difference）

第 40 題

凱利（H. Kelley）強調個體對他人行為進行歸因時，會同時考慮區辨性（distinctiveness）、共識性（consensus） 及下列何者？
