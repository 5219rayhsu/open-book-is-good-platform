第 1 題

根據近年來的流行病學調查結果，下列何種飲食疾患（eating disorder）之好發年齡最大？
  1. （A）嗜食症（binge eating disorder）
  2. （B）暴食症（bulimia nervosa）
  3. （C）厭食症（anorexia nervosa）
  4. （D）反芻疾患（rumination disorder）

答案：（A）

詳解與考點

考點為各飲食疾患的好發年齡比較。厭食症與暴食症多起於青春期至成年早期，反芻疾患更早。嗜食症（binge eating disorder）相較之下好發年齡最大，常見於成年期，故選 A。陷阱在於把暴食症與嗜食症混淆，兩者皆有暴食但嗜食症發病較晚、年齡層較廣。

第 2 題

厭食症（anorexia nervosa）患者的死亡率高過正常健康族群數倍，有關罹患厭食症之直接致死原因，下列何者的比例最高？
  1. （A）月經不規律或停經
  2. （B）濫用瀉劑（laxative）
  3. （C）自發性的挨餓或拒絕進食
  4. （D）營養不良造成一般性醫療狀況

答案：（D）

詳解與考點

考點為厭食症的直接致死原因比例。厭食症死亡主要來自長期飢餓造成的營養不良與一般性醫療併發症（如電解質失衡、心律問題），故比例最高者為 D 營養不良造成的一般性醫療狀況。陷阱在於另一大死因是自殺，而選項中的停經、瀉劑濫用、自發挨餓雖為特徵，卻非直接致死的最高比例。

第 3 題

根據Polivy等人的系列研究顯示，在給予體重較重的評價等實驗操弄後，並讓受試者進食少許高熱量的食物（如奶昔），再讓受試者自由食用冰淇淋，以測量其食用的量，會得到什麼結果？
  1. （A）克制量表（Restraint Scale）得分高的受試者比得分低的受試者吃得更多
  2. （B）克制量表得分高的受試者大部分拒絕再吃，但得分低者仍然食用顯著的分量
  3. （C）克制量表的分數沒有影響，都拒絕再吃
  4. （D）克制量表的分數沒有影響，兩組都吃得很多

答案：（A）

詳解與考點

考點為 Polivy 等人的克制飲食（restraint）與反調節（counterregulation）研究。高克制者在被給予高熱量前負荷（奶昔）後反而「破戒」吃得更多，低克制者則維持節制，故選 A。此即抑制解除效應。陷阱在直覺以為節食者會更節制，與實驗結果相反，方向不可顛倒。

第 4 題

請問in vivo暴露療法是指：
  1. （A）先訓練個案產生心像的能力，然後進行想像暴露療法
  2. （B）先讓個案觀看害怕情境的影片畫面，然後再進行想像暴露療法
  3. （C）在真實生活情境中進行暴露療法
  4. （D）在虛擬實境（VR）的模擬情境中進行暴露療法

答案：（C）

詳解與考點

考點為暴露療法的類型辨識。in vivo（現場／實境）暴露指在真實生活情境中直接面對害怕刺激，故選 C。A、B 為想像暴露，D 為虛擬實境暴露。陷阱在於把 in vivo 與 VR 混淆，VR 屬模擬而非真實情境，in vivo 強調的正是現實生活中的實地暴露。

第 5 題

下列那一類焦慮症患者在進行暴露相關療法時不宜施作肌肉放鬆訓練？
  1. （A）恐慌症（panic disorder）
  2. （B）血液恐懼症（blood phobia）
  3. （C）動物恐懼症（animal phobia）
  4. （D）社交焦慮症（social anxiety disorder）

答案：（B）

詳解與考點

考點為血液恐懼症的特殊生理反應與治療禁忌。血液恐懼症患者面對刺激常出現血管迷走反應造成血壓驟降而暈厥，治療採「應用緊張法（applied tension）」升高血壓，而非肌肉放鬆，故選 B 不宜放鬆。陷阱在於放鬆訓練對多數焦慮症有益，易誤以為對血液恐懼症亦適用。

第 6 題

有關恐慌症的PCT（panic control therapy）治療，下列敘述何者錯誤？
  1. （A）治療中會設法引發個案產生類似恐慌發作的身體感覺
  2. （B）PCT的主要原理是暴露療法
  3. （C）在治療過程中個案被告知要充分覺察這些身體感覺，但不要去評價它
  4. （D）治療目標在增加個案對於恐慌發作與相關身體感覺的控制感

答案：（C）

詳解與考點

考點為恐慌控制治療（PCT）的原理。PCT 以暴露為主（含內感受暴露引發身體感覺）、目標在增加對恐慌與身體感覺的控制感，A、B、D 正確。C 描述「覺察但不評價」屬正念取向，非 PCT 認知重建的核心做法，故選 C 為錯誤。陷阱在於正念語句聽似合理而易被當成正確。

第 7 題

MacLeod和Mathews（2012）採用點偵測作業（dot probe task）進行研究，他們要參與者將其注意力放在電腦螢幕的光點，其中，實驗組參與者的光點可能出現在負向字詞的位置，而控制組參與者的光點則是隨機出現在左側或右側，結果被要求注意負向字詞的參與者自陳報告有較高的焦慮感。依據上述研究結果，可知焦慮症患者可能是受到下列那一個認知因子影響而產生焦慮？
  1. （A）持續的未來負向信念
  2. （B）知覺到缺乏控制感
  3. （C）對威脅信號的注意力
  4. （D）僵化的思考方式

答案：（C）

詳解與考點

考點為 MacLeod 與 Mathews 的注意力偏誤研究（點偵測作業）。被訓練將注意力導向負向字詞者焦慮上升，顯示焦慮與「對威脅信號的注意力偏誤」有關，故選 C。陷阱在於缺乏控制感、未來負向信念、僵化思考雖皆為焦慮認知因子，但與此實驗操弄（注意力導向）直接對應的是注意力偏誤。

第 8 題

「孫先生是一個35歲的男性個案，他向精神科醫師抱怨他長期睡眠品質不佳，日常生活也時常感覺浮躁與不耐煩，在工作上也容易覺得疲累或是不能專心，除此之外，孫先生似乎也對任何生活中的大小事情感到擔憂，尤其面對未來可能發生的事情，他也時常會設想最壞的情況。他覺得自己無法停止自己的擔心，因而嚴重影響生活的品質。」孫先生可能具有什麼樣的診斷？
  1. （A）恐慌症
  2. （B）雙相情緒障礙症
  3. （C）廣泛性焦慮症
  4. （D）鬱症

答案：（C）

詳解與考點

考點為廣泛性焦慮症（GAD）的臨床辨識。個案長期失眠、煩躁、易疲累、難專注、對大小事過度且難控制的擔憂並影響生活，符合 GAD 核心特徵，故選 C。陷阱在於失眠與疲累也見於鬱症，但本例核心是「無法停止的廣泛性擔憂」而非情緒低落或恐慌發作，故非鬱症或恐慌症。

第 9 題

有關社交焦慮症（social anxiety disorder）患者的認知特徵敘述，下列何者錯誤？
  1. （A）患者對於他們在社會情境下的表現結果時常具有負向預期
  2. （B）患者時常認為他人正負面地評價自己的表現
  3. （C）患者的焦慮升高時，將無暇專注在自己的內在感受上
  4. （D）患者時常相信自己很有可能受到他人的拒絕或批評

答案：（C）

詳解與考點

考點為社交焦慮症的認知特徵。患者對社交表現有負向預期、認為他人負面評價自己、相信易被拒絕批評，A、B、D 正確。C 錯在描述焦慮升高時「無暇專注內在感受」，事實上社交焦慮者焦慮時會過度自我聚焦、強化內在監控，故選 C。陷阱在於混淆自我聚焦增加與注意力轉移的方向。

第 10 題

儲物症（hoarding disorder）患者難以丟棄其持有物的理由，最有可能是下列何者？
  1. （A）相信這些持有物未來會增值
  2. （B）對於這些持有物有強烈的情緒依戀
  3. （C）害怕丟棄持有物會帶來厄運
  4. （D）相信這些持有物能帶來超能力

答案：（B）

詳解與考點

考點為儲物症患者難以丟棄物品的核心理由。最常見因素是對持有物有強烈情緒依戀，以及認為物品具實用或資訊價值，故選 B。增值、厄運、超能力等屬迷信或妄想式信念，並非儲物症典型動機。陷阱在於把儲物與強迫式迷信混淆，儲物核心是情感連結與決策困難。

第 11 題

有關強迫症之敘述，下列何者錯誤？
  1. （A）疾病的初發時期多在35歲以後的成年晚期，兒童與青少年期患者只是少數的比率
  2. （B）成人女性的診斷率略高於男性，而男性的初發年齡比女性來得早
  3. （C）兒童與青少年患者的症狀表現型態不如成人來得穩定，且強迫行為比起強迫思考較容易被診斷出來
  4. （D）雖然成人強迫症患者未接受治療的緩解率低，但是約40%的早發患者在成年早期可能經驗到症狀的緩解

答案：（A）

詳解與考點

考點為強迫症的流行病學特徵。A 錯在初發年齡：強迫症多在兒童青少年期至成年早期發病，而非 35 歲以後的成年晚期，故選 A 為錯誤。B、C、D 對性別、症狀穩定度與早發緩解率的描述大致正確。陷阱在於把好發年齡記成中晚年，與強迫症常早發的事實相反。

第 12 題

下列何者是強迫症（obsessive-compulsive disorder）與身體臆形症（body dysmorphic disorder）的共同特徵？
  1. （A）自我感喪失
  2. （B）重複擔憂自己罹患嚴重疾病
  3. （C）重複性思考與行為
  4. （D）非預期性的恐慌發作

答案：（C）

詳解與考點

考點為強迫症與身體臆形症的共同特徵。兩者同屬強迫及相關障礙症類別，皆有重複性的思考與行為（如檢查、照鏡），故選 C。A 失自我感、B 重複擔憂患病（屬罹病焦慮）、D 非預期恐慌發作皆非兩者共同核心。陷阱在於 B 像疑病而易誤選，但重複思考與行為才是兩者共通點。

第 13 題

有關創傷後壓力症（posttraumatic stress disorder）的治療與預防方式，下列敘述何者正確？
  1. （A）在心理分析中，治療者主要運用自由聯想的方式來緩解個體經驗創傷後的受苦情緒
  2. （B）治療的目標在於協助個體有效地阻斷對創傷記憶的提取
  3. （C）選擇性血清素回收抑制劑（SSRIs）是治療創傷後壓力症症狀有療效的藥物之一
  4. （D）想像暴露療法的目的是為了讓個體未來再遇到相似的創傷事件時，不再有恐懼或是逃避的行為

答案：（C）

詳解與考點

考點為創傷後壓力症的治療與預防。SSRI 是 PTSD 有實證療效的藥物之一，故選 C 正確。A 把心理分析自由聯想當主要治法、B 主張阻斷創傷記憶提取、D 說暴露目的是面對未來真實創傷，皆有誤；暴露治療目的在處理既有創傷記憶與減敏，而非保證未來不再恐懼。陷阱是 D 對暴露目標的錯誤詮釋。

第 14 題

有關急性壓力症（acute stress disorder）與創傷後壓力症（posttraumatic stress disorder）的敘述，下列何者正確？
  1. （A）假如個體在創傷事件六個月之後才出現嚴重的壓力症狀，較適合被診斷為急性壓力症
  2. （B）創傷事件是診斷兩類疾病的唯一必要因子，因為所有經驗過創傷事件的個體皆會發展出創傷後壓力症或是急性壓力症
  3. （C）大部分被診斷為急性壓力症的個體最終不會發展出創傷後壓力症，因為兩者的病程與病因皆不相同
  4. （D）急性壓力症與創傷後壓力症主要差異在於個體暴露於創傷事件後到出現壓力症狀的時間

答案：（D）

詳解與考點

考點為急性壓力症（ASD）與 PTSD 的區別。兩者主要差異在於症狀出現與持續的「時間」：ASD 在創傷後 3 天至 1 個月內，超過 1 個月才符合 PTSD，故選 D。A 把六個月後說成 ASD、B 說人人皆會發病、C 說病因病程完全不同皆錯。陷阱在於誤以為差異在症狀種類，實則關鍵在時間軸。

第 15 題

依據DSM-5創傷及壓力相關障礙症，診斷為反應性依附障礙症（reactive attachment disorder）的兒童，其發展年齡至少達到幾個月？
  1. （A）1個月
  2. （B）3個月
  3. （C）6個月
  4. （D）9個月

答案：（D）

詳解與考點

考點為 DSM-5 反應性依附障礙症的最低發展年齡標準。診斷要求兒童發展年齡至少達 9 個月，確保已具備形成選擇性依附的能力，故選 D。陷阱在於 1、3、6 個月皆為干擾項，需記住此症需個體已能發展依附（約 9 個月）才適用。

第 16 題

根據DSM-5，關於轉化症之敘述，下列何者正確？
  1. （A）女性患者多於男性
  2. （B）終生盛行率約3%
  3. （C）通常在中年時發病
  4. （D）最常與飲食疾患共病

答案：（A）

詳解與考點

考點為 DSM-5 轉化症（功能性神經症狀障礙症）的特徵。女性患者多於男性，故選 A 正確。終生盛行率遠低於 3%、發病常在青少年至成年早期（非中年）、最常與其他身體症狀及焦慮憂鬱共病而非飲食疾患，故 B、C、D 皆錯。陷阱在於盛行率 3% 與中年發病的數字易被誤記為正確。

第 17 題

近一年來張先生深受頭痛所苦，看了許多醫師也做了多項檢查皆未發現問題，很擔心頭痛是嚴重腦病變的徵兆；為了減少壓力，甚至辭去工作專心在家休養。依據前述，最不可能符合DSM-5的何項診斷？
  1. （A）罹病焦慮症（illness anxiety disorder）
  2. （B）身體症狀障礙症（somatic symptom disorder）
  3. （C）人為障礙症（factitious disorder）
  4. （D）廣泛性焦慮症（generalized anxiety disorder）

答案：（C）

詳解與考點

題目問「最不可能」符合的診斷。張先生長期頭痛、檢查無器質異常、強烈擔心是嚴重腦病變、甚至因而辭職休養，呈現對健康的過度焦慮與對身體症狀的持續擔憂。最不符合的是 C 人為障礙症（factitious disorder），因該診斷的核心是「刻意偽造、誇大或製造身體／心理症狀以扮演病人角色」，且無明顯外在誘因（不同於詐病）；題幹完全沒有偽造或欺瞞的線索，個案是真實受苦並真心擔憂，故選 C。A 罹病焦慮症：身體症狀輕微或不存在，焦慮集中在「罹患或將罹患重病」，與本案高度相符。B 身體症狀障礙症：有實際且困擾的身體症狀（頭痛）加上過度的健康相關想法、感受與行為，亦相符。D 廣泛性焦慮症：本案以健康焦慮為主，題幹未明確呈現對多項生活事件的廣泛、難以控制的擔憂，故 D 未必完全符合，但相較之下 C 才是最不可能成立者；不宜過度肯定地說本案「就是」GAD。

第 18 題

有關解離性身份障礙症（dissociative identity disorder, DID）與創傷後壓力症（posttraumatic stress disorder, PTSD）的鑑別診斷，下列何者錯誤？
  1. （A）DID的失憶包含每天生活的許多經驗；PTSD的失憶僅侷限於創傷事件相關的內容
  2. （B）DID可能不記得解離性再現（dissociative flashback）的內容，PTSD通常記得
  3. （C）DID的闖入記憶（intrusion）與轉換人格有關；PTSD的闖入記憶跟創傷事件有關
  4. （D）DID對解離症狀表現得漠不關心；PTSD對解離症狀有強烈的羞恥感

答案：（D）

詳解與考點

考點為解離性身份障礙症（DID）與 PTSD 的鑑別。A、B、C 對失憶範圍、再現記憶與闖入記憶來源的對比皆正確。D 錯在情緒反應描述：DID 與 PTSD 患者對解離症狀並非如此截然「漠不關心 vs 強烈羞恥」的對立，此配對不成立，故選 D。陷阱在於以情緒態度作為鑑別點並不可靠。

第 19 題

下列何項最不可能發生在失自我感／失現實感障礙症（depersonalization/derealization disorder）的患者身上？
  1. （A）感覺記憶出現斷層（gap）
  2. （B）感覺自己從遠處看著自己
  3. （C）感覺周遭的場景很不真實
  4. （D）感覺自己的身體像機器人

答案：（A）

詳解與考點

考點為失自我感／失現實感障礙症的症狀。典型為感覺從遠處看自己、周遭不真實、身體像機器人（B、C、D）。A「記憶出現斷層（gap）」屬解離性失憶的特徵，非本症核心，故選 A 最不可能。陷阱在於同屬解離類別，易把失憶與失自我感／失現實感的症狀混為一談。

第 20 題

行為活化治療（behavioral activation treatment）為治療憂鬱的有效策略之一，其主要作用是在透過下列何者來降低憂鬱者的逃避、缺少活力等症狀？
  1. （A）增加正向增強
  2. （B）降低負向增強
  3. （C）增加正向懲罰
  4. （D）降低負向懲罰

答案：（A）

詳解與考點

考點為行為活化治療的作用機轉。其透過安排活動、增加與環境的正向增強接觸，來對抗憂鬱者的逃避與活力不足，故選 A 增加正向增強。陷阱在於憂鬱的逃避雖涉及負向增強，但行為活化的核心策略是提升正向增強來源，而非單純降低負向增強。

第 21 題

根據Coyne與Joiner的理論，下列何者常見於憂鬱患者，其結果可能會使得周遭其他人感到厭煩而拒絕他？
  1. （A）高情緒表露（expressed emotion）
  2. （B）過度尋求再保證（reassurance seeking）
  3. （C）悲觀的歸因型態（attributional style）
  4. （D）童年受虐經驗

答案：（B）

詳解與考點

考點為 Coyne 與 Joiner 的人際憂鬱理論。憂鬱者常「過度尋求再保證（reassurance seeking）」，反覆要求他人確認自己被接納，最終使周遭厭煩而疏遠，故選 B。陷阱在於高情緒表露、悲觀歸因、童年受虐雖與憂鬱相關，但 Coyne 理論特別強調的人際機制是過度尋求再保證。

第 22 題

根據DSM-5，有關鬱症（major depressive disorder）的病程發展與特徵，下列敘述何者正確？
  1. （A）中年與老年的鬱症患者有較高的自殺企圖
  2. （B）嗜食與嗜睡較常見於老年患者身上，精神動作障礙（psychomotor disturbances）則較常見於年輕患者身上
  3. （C）越早發病的鬱症患者越有可能伴隨人格障礙
  4. （D）男性的鬱症患者對治療的反應較差

答案：（C）

詳解與考點

考點為 DSM-5 鬱症的病程特徵。越早發病越可能伴隨人格障礙，故選 C 正確。A 自殺企圖較高其實見於年輕族群、B 嗜食嗜睡與精神動作障礙的年齡歸屬被對調、D 性別與治療反應的描述亦無實證支持。陷阱在於 A、B 的年齡配對方向易被誤判為合理。

第 23 題

有關憂鬱症認知理論的實徵證據，下列敘述何者正確？
  1. （A）憂鬱組比非憂鬱組有更多負向思考
  2. （B）憂鬱組認知三角是對他人、世界、事務感到毫無價值
  3. （C）憂鬱認知與自動化的認知訊息處理無關
  4. （D）憂鬱組比非憂鬱組記不起正向記憶，但兩組負向記憶量沒差

答案：（A）

詳解與考點

考點為憂鬱認知理論的實證證據。憂鬱組確實比非憂鬱組有更多負向自動化思考，故選 A 正確。B 錯在認知三角應為對自我、世界、未來的負向看法（非僅他人事務）、C 否定自動化處理的關聯有誤、D 對記憶偏誤的描述不準確。陷阱在於 B 把認知三角內容說錯而看似熟悉。

第 24 題

根據DSM-5，持續性憂鬱症（persistent depressive disorder）的診斷標準，下列敘述何者最恰當？
  1. （A）一週中大部分時間心情憂鬱，維持至少2年
  2. （B）在出現困擾的期間內，無症狀時期從未超過3個月
  3. （C）反覆有死亡的想法或自殺意念亦可診斷為持續性憂鬱症
  4. （D）在18歲前初發者，屬早期初發（early onset）

答案：（C）

詳解與考點

考點為 DSM-5 持續性憂鬱症（輕鬱症）的診斷標準。其中反覆死亡想法或自殺意念也可作為症狀之一，故選 C 較恰當。A 應為「大部分日子」憂鬱至少 2 年（成人）、B 無症狀期不超過 2 個月（非 3 個月）、D 早發界定為 21 歲前（非 18 歲），故其餘選項數字有誤。陷阱在於各項門檻數字易記錯。

第 25 題

史小姐表示自己本來就容易認床、怕吵，生產完後睡眠品質有變差，但尚可應付白天工作，去年12月因被診斷為乳癌開始持續出現失眠問題，由醫師開立助眠藥物緩解化療療程中常見的失眠症狀，但化療療程已經結束，自陳還是無法順利停用藥物，因為一旦停藥就整晚都睡不著，很擔心沒有睡會影響免疫力，造成癌症復發。根據前述情形，下列配對何者錯誤？
  1. （A）前置因子─認床、怕吵的睡眠脆弱特質
  2. （B）促發因子─乳癌
  3. （C）促發因子─擔心睡不好癌症容易復發
  4. （D）持續因子─助眠藥物的依賴

答案：（C）

詳解與考點

考點為失眠的 3P 模式（前置、促發、持續因子）。認床怕吵屬前置因子、乳癌診斷屬促發因子、助眠藥依賴屬持續因子，配對皆對。C 把「擔心睡不好導致癌症復發」歸為促發因子有誤，這種不適應認知屬「持續因子」，故選 C。陷阱在於把維持失眠的認知誤分到促發因子。

第 26 題

小強就讀小學二年級，由父母帶來就診，表示他晚上經常會起來走動，對外界的刺激沒有反應，且早上通常不記得夜裡發生的事，依據DSM-5，小強的狀況最可能是下列何者？
  1. （A）非快速動眼睡醒障礙症─夢遊型
  2. （B）夢魘症
  3. （C）非快速動眼睡醒障礙症─睡驚型
  4. （D）快速動眼睡眠行為障礙症

答案：（A）

詳解與考點

考點為 DSM-5 非快速動眼睡醒障礙症的辨識。小強夜間起身走動、對外界無反應、醒後不記得，符合夢遊型（睡行型），故選 A。睡驚型以驚恐尖叫為主、夢魘症會記得夢境、REM 行為障礙多見於年長者並會演出夢境。陷阱在於夢遊與睡驚同屬 NREM 異睡症，需以「走動且失憶」辨為夢遊。

第 27 題

承上題，小強的狀況最佳的處置方式為何？
  1. （A）請父母儘量將小強喚醒，以中止此一行為
  2. （B）給予父母相關衛教，並持續觀察小強的狀況
  3. （C）給予藥物治療，避免此一現象出現
  4. （D）延後上床時間，以矯正晝夜節律的偏差

答案：（B）

詳解與考點

考點為兒童夢遊（NREM 異睡症）的處置。兒童夢遊多為良性且隨年齡改善，最佳處置是給予父母衛教（確保安全、避免強行喚醒）並持續觀察，故選 B。強行喚醒可能造成混亂、藥物非首選、延後上床無針對性。陷阱在於 A 直覺想喚醒，反而不當；多數情況以衛教與安全防護為主。

第 28 題

張三有連續超過六個月的時間，在與伴侶進行性活動時，有明顯的勃起困難；伴侶於是鼓勵他來尋求臨床協助。張三必須符合下列那兩種狀況，才有可能被診斷為勃起障礙症（erectile disorder）？
  1. （A）勃起困難需導致張三產生臨床上顯著的苦惱，且並非導因於伴侶關係上的嚴重困擾
  2. （B）勃起困難需導致伴侶具有臨床上顯著的苦惱，且並非導因於伴侶關係上的嚴重困擾
  3. （C）勃起困難需導致張三產生臨床上顯著的苦惱，再加上導因於伴侶關係上的嚴重困擾
  4. （D）勃起困難需導致伴侶具有臨床上顯著的苦惱，且同時有嚴重的伴侶關係問題

答案：（A）

詳解與考點

考點為 DSM-5 勃起障礙症的診斷要件。需症狀造成「個案本人」臨床顯著苦惱，且非僅由嚴重伴侶關係困擾或其他因素所能解釋，故選 A。其餘選項把苦惱主體放在伴侶、或把嚴重關係問題當成共存條件皆不符。陷阱在於苦惱的主體應是患者本人，且嚴重關係困擾是「排除」而非並存條件。

第 29 題

王先生一直覺得女性內衣對他很具有吸引力。在下列何種條件下，王先生最有可能被診斷為戀物症（fetishistic disorder）？
  1. （A）王先生同時有偷女性內衣的行為
  2. （B）王先生會用望遠鏡觀看鄰居女性穿／脫內衣
  3. （C）王先生會透過撫摸女性內衣來達到性興奮
  4. （D）王先生在房間中堆滿了他所買來的女性內衣

答案：（C）

詳解與考點

考點為 DSM-5 戀物症的診斷核心。戀物症指對非生命物體（如內衣）或非生殖部位產生反覆強烈的性興奮，並造成苦惱或損害；透過撫摸內衣達到性興奮最符合，故選 C。偷竊（竊盜）、窺視、囤積屬其他偏差行為而非戀物症本質。陷阱在於把偷或囤積內衣誤當戀物症，關鍵在以該物為性興奮來源。

第 30 題

交感神經腎上腺髓質軸所分泌的物質主要為：
  1. （A）corticosteroids
  2. （B）catecholamines
  3. （C）cytokines
  4. （D）dopamine

答案：（B）

詳解與考點

考點為壓力的生理途徑。交感神經－腎上腺髓質軸（SAM）受刺激時主要分泌兒茶酚胺（catecholamines，即腎上腺素與正腎上腺素），故選 B。corticosteroids（含 cortisol）屬 HPA 軸產物、cytokines 為免疫物質、dopamine 雖屬兒茶酚胺但非此軸主要分泌物。陷阱在於把 HPA 軸的可體松誤配給 SAM 軸。

第 31 題

具有負向情緒（negative affectivity）性格特性的人，容易經驗各種負向情緒，包括焦慮、憂鬱、生氣等，下列何者不是具有此一性格個體容易出現的情形？
  1. （A）易有情緒痛苦
  2. （B）易罹患疾病
  3. （C）常有身體抱怨
  4. （D）常不願就醫

答案：（D）

詳解與考點

考點為負向情緒性（negative affectivity）人格與健康。此類人易有情緒痛苦、較多身體抱怨，也較易感到罹病，A、B、C 為其特徵。D「常不願就醫」與事實相反，負向情緒高者反而較常抱怨並較常就醫，故選 D 為錯誤。陷阱在於誤以為負向情緒者逃避就醫，實則多為頻繁求醫。

第 32 題

根據Sarafino和Smith（2017）的整理，改變階段模式（stages of change model）應用在提升健康行為上，那一項的研究相較起來，支持度較不顯著？
  1. （A）戒菸
  2. （B）乳癌篩檢
  3. （C）減重
  4. （D）運動

答案：（C）

詳解與考點

考點為跨理論改變階段模式（stages of change）在健康行為的應用支持度。依 Sarafino 與 Smith 整理，戒菸、篩檢、運動等應用支持較佳，而在「減重」上的支持相對較不顯著，故選 C。陷阱在於減重直覺像最常用階段模式的領域，但實證上其效果支持反而較弱。

第 33 題

信念與意圖是影響人們實踐健康行為與否的重要因素，下列相關的理論敘述何者正確？
  1. （A）計畫行為理論（the theory of planned behavior）主要是評估個體採取預防行動機率的模式
  2. （B）健康信念模式（health belief model）主要是描述意圖行為改變的階段與過程
  3. （C）動機性推理（motivated reasoning）主要是探索人類的理性對健康行為的影響，人需要理性與合乎邏輯的動機促進健康
  4. （D）衝突理論（conflict theory）主要是探討選擇合適因應行為的影響因素：風險性、希望感及是否有合適的時間

答案：（D）

詳解與考點

考點為健康行為理論辨識。官方答案為 D，將「風險、希望感、是否有合適時間」歸於衝突理論（conflict theory，Janis & Mann 決策衝突模式），故 D 視為正解。A 計畫行為理論、B 健康信念模式、C 動機性推理的描述皆被對調或扭曲而錯。陷阱在於各理論定義易張冠李戴，須記每個模式的核心定位。

第 34 題

某位個案因身體不適而到診所就醫。醫師告訴他：「我開藥給你，每餐飯後吃。你的工時太長，應該要減少工作量。另外，你完全沒有運動，又常熬夜，也不利於身體健康，一定要規律運動，早點睡覺。」依照醫囑遵從的特性，醫師的醫囑當中，個案最有可能做到的是下列何者？
  1. （A）服藥
  2. （B）減少工作量
  3. （C）規律運動
  4. （D）不熬夜

答案：（A）

詳解與考點

考點為醫囑遵從性（adherence）的特性。一般而言，簡單、明確、短期、被動的醫囑（如按時服藥）遵從性最高，而需改變生活型態（減工時、運動、作息）的長期行為遵從性較低，故個案最可能做到的是 A 服藥。陷阱在於誤以為個案會配合所有醫囑，實則生活型態改變最難落實。

第 35 題

並非每個人都能夠有效的因應壓力，因此有許多協助增進因應能力的處遇方式（interventions for coping）。下列何者不是常見的因應處遇方式？
  1. （A）正念冥想／減壓（mindfulness-based meditation / stress reduction）
  2. （B）自我肯定（self-affirmation）
  3. （C）放鬆訓練（relaxation training）
  4. （D）壓力預防模式（stress prevention model）

答案：（D）

詳解與考點

考點為增進壓力因應能力的常見處遇方式。正念減壓、自我肯定、放鬆訓練皆為公認的因應介入。D「壓力預防模式（stress prevention model）」並非標準的因應處遇名稱（常見的是 Meichenbaum 的壓力免疫訓練 stress inoculation），故選 D。陷阱在於名稱相近，易把預防模式誤當成既有處遇。

第 36 題

有關「預先因應（proactive coping）」的敘述，下列何者最為正確？
  1. （A）個人針對已知未來必然發生（例如：三個月後要國考）而非有可能不會發生（例如：可能無法結婚）的壓力先行進行因應
  2. （B）個人主動極積的去面對已發生的壓力情境，以減低壓力的衝擊（impact）
  3. （C）需要個人有「自我調節（self-regulatory）」的技巧，像是個人控制、導引及修正其因應行動（actions）的方式
  4. （D）和個人預期（anticipate）或偵測（detect）壓力的能力無關，而是和壓力管理（stress management）的能力有關

答案：（C）

詳解與考點

考點為「預先因應（proactive coping）」的概念。其核心是運用自我調節技巧（個人控制、導引並修正因應行動）來面對尚未發生的潛在壓力，故選 C。A 把對象限定在必然發生的事過窄、B 描述的是面對已發生壓力、D 否定其與預期偵測能力的關聯皆誤。陷阱在於混淆預先因應與一般壓力管理。

第 37 題

根據Yerkes-Dodson Law，壓力與表現間呈現何種關係？
  1. （A）正相關的線性關係
  2. （B）倒U型曲線相關
  3. （C）U型曲線相關
  4. （D）負相關的線性關係

答案：（B）

詳解與考點

考點為 Yerkes-Dodson 法則。壓力（喚起）與表現呈倒 U 型關係：適度喚起表現最佳，過低或過高皆使表現下降，故選 B。陷阱在於誤以為壓力與表現是單純的正相關或負相關線性關係，而忽略其為非線性的倒 U 曲線。

第 38 題

下列與糖尿病（diabetes）照護相關的心理社會因素之敘述，何者錯誤？
  1. （A）壓力可經由影響個人自我照護（如飲食控制等）來影響糖尿病患者的血糖控制
  2. （B）壓力可經由促使正腎上腺素（norepinephrine）分泌，增加胰島素（insulin）的生成，而影響糖尿病患者的血糖控制
  3. （C）壓力可經由促使可體松（cortisol）分泌，增加肝臟葡萄糖（glucose）生成，而影響糖尿病患者的血糖控制
  4. （D）糖尿病患者完全依醫囑進行飲食控制後，仍有可能因為壓力等因素造成血糖控制不理想，因而感到挫折

答案：（B）

詳解與考點

考點為壓力影響糖尿病血糖控制的心理生理機轉。B 錯在生理方向：壓力使正腎上腺素等分泌會「抑制」胰島素並升高血糖，而非「增加胰島素生成」，故選 B 為錯誤。A、C、D 對自我照護、可體松升糖與依醫囑仍受壓力影響的描述皆正確。陷阱在於把壓力對胰島素的方向搞反。

第 39 題

有關安寧療護（hospice care）概念的敘述，下列何者最不恰當？
  1. （A）安寧療護之主要目標是經由生理、心理、社會與靈性上的照顧，以增進病人與家屬之生活品質
  2. （B）讓末期病人與其家人能好好討論想要「在那裡往生（例如在家或在機構）」，是安寧療護很重要的主題之一
  3. （C）安寧療護重視個人心靈上的平靜，可鼓勵病人參與和自己有關的醫療討論，而減少參與家庭相關事務
  4. （D）安寧療護在病人往生後，仍提供家屬相關後續服務（follow-up care）

答案：（C）

詳解與考點

考點為安寧療護（hospice care）的核心理念。安寧強調生理、心理、社會與靈性的全人照顧、尊重善終地點選擇、提供遺族後續服務（A、B、D 正確）。C 說鼓勵病人「減少參與家庭相關事務」與安寧重視家庭參與的精神相違，故選 C 最不恰當。陷阱在於 C 前半談心靈平靜為真，後半結論卻偏離。

第 40 題

對於緊張型頭痛（tension type headache）患者的頭痛症狀，生理回饋（biofeedback）與止痛藥的療效比較，下列敘述何者正確？
  1. （A）生理回饋較快產生療效但較不持久，止痛藥較慢產生療效但較持久
  2. （B）生理回饋較快產生療效且較持久，止痛藥較慢產生療效且較不持久
  3. （C）生理回饋較慢產生療效且較不持久，止痛藥較快產生療效且較持久
  4. （D）生理回饋較慢產生療效但較持久，止痛藥較快產生療效但較不持久

答案：（D）

詳解與考點

考點為緊張型頭痛的生理回饋與止痛藥療效比較。生理回饋起效較慢但療效較持久，止痛藥起效快但較不持久，故選 D。陷阱在於把兩者的起效速度與持久性配對顛倒；行為療法通常見效慢而效果維持較久，藥物則相反。
