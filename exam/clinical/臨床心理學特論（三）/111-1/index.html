第 1 題

根據近年來的流行病學調查結果，下列何種飲食疾患（eating disorder）之好發年齡最大？
  1. （A）嗜食症（binge eating disorder）
  2. （B）暴食症（bulimia nervosa）
  3. （C）厭食症（anorexia nervosa）
  4. （D）反芻疾患（rumination disorder）

答案：（A）

詳解與考點

正解：本題問的是各飲食疾患（eating disorder）好發年齡的高低比較——嗜食症（binge eating disorder）相較於其他三者好發年齡最大，常見於成年期甚至中年，此敘述與流行病學調查結果相符，故選 A。

B：暴食症（bulimia nervosa）好發年齡多起於青春期至成年早期，早於嗜食症，故非答案。這是最強誘答，因暴食症與嗜食症皆以暴食行為為核心特徵，分辨關鍵在於嗜食症不伴隨代償行為，且發病年齡層較暴食症更晚、分布更廣。

C：厭食症（anorexia nervosa）好發年齡多起於青春期，同樣早於嗜食症，故非答案。

D：反芻疾患（rumination disorder）好發年齡更早，可見於嬰幼兒期，是四者中好發年齡最小者，故非答案。

本題考點：飲食疾患（eating disorder）好發年齡的排序判準——反芻疾患最早（嬰幼兒期），厭食症與暴食症多起於青春期至成年早期，嗜食症（binge eating disorder）好發年齡最大、常見於成年期；分辨關鍵在於暴食症與嗜食症雖同有暴食行為，但兩者的好發年齡層與是否伴隨代償行為不同。

第 2 題

厭食症（anorexia nervosa）患者的死亡率高過正常健康族群數倍，有關罹患厭食症之直接致死原因，下列何者的比例最高？
  1. （A）月經不規律或停經
  2. （B）濫用瀉劑（laxative）
  3. （C）自發性的挨餓或拒絕進食
  4. （D）營養不良造成一般性醫療狀況

答案：（D）

詳解與考點

正解：判準是厭食症（anorexia nervosa）各項描述中，何者為造成患者直接死亡比例最高的原因——長期飢餓所導致的營養不良與其引發的一般性醫療併發症（如電解質失衡、心律問題）是厭食症患者直接致死原因中比例最高者，此敘述與流行病學資料相符，故選 D。

A：月經不規律或停經（amenorrhea）是厭食症因長期營養不足導致的生理特徵之一，但本身並非直接致死原因，故非答案。

B：濫用瀉劑（laxative abuse）是部分厭食症患者的代償行為，可能加重電解質失衡，但並非直接致死比例最高的原因，故非答案。

C：自發性的挨餓或拒絕進食是厭食症的核心行為表現，其致死路徑是透過造成營養不良與醫療併發症而致死，行為本身不等同於「直接致死原因」的統計歸類，故非答案。這是最強誘答，因挨餓拒食是厭食症最直觀的核心行為，容易被誤認為就是致死原因本身；但流行病學統計上把致死原因歸類為其造成的醫療併發症，而非行為本身。

本題考點：厭食症（anorexia nervosa）致死原因比例的判準——長期飢餓引發的營養不良與一般性醫療併發症是直接致死比例最高者，另一大死因是自殺；月經停止、瀉劑濫用、挨餓拒食本身雖是厭食症的特徵或代償行為，卻不是統計上的「直接致死原因」歸類項目。

第 3 題

根據Polivy等人的系列研究顯示，在給予體重較重的評價等實驗操弄後，並讓受試者進食少許高熱量的食物（如奶昔），再讓受試者自由食用冰淇淋，以測量其食用的量，會得到什麼結果？
  1. （A）克制量表（Restraint Scale）得分高的受試者比得分低的受試者吃得更多
  2. （B）克制量表得分高的受試者大部分拒絕再吃，但得分低者仍然食用顯著的分量
  3. （C）克制量表的分數沒有影響，都拒絕再吃
  4. （D）克制量表的分數沒有影響，兩組都吃得很多

答案：（A）

詳解與考點

正解：判準是 Polivy 等人克制飲食（restraint）研究中的反調節（counterregulation）現象——克制量表（Restraint Scale）得分高者接受體重評價操弄並食用高熱量前置負荷（如奶昔）後，節制反而瓦解，隨後食用冰淇淋的量比低克制者更多，此即抑制解除效應，故選 A。

B：得分高者「大部分拒絕再吃」與研究結果相反——高克制者正是在前置負荷後失去控制才吃得更多，並非拒食；分辨關鍵在於節食者被前置負荷觸發的是「破戒」而非更嚴格的節制，方向與直覺恰好相反，是本題最強誘答。

C：兩組都拒絕再吃，抹去了克制量表分數本應造成的組間差異，與反調節效果的核心發現不符。

D：兩組都吃得很多，同樣忽略了高、低克制者對前置負荷反應的差異，未反映出僅高克制者才出現反調節。

本題考點：克制飲食理論中的反調節（counterregulation）與抑制解除效應——判準是「前置負荷之後的食用量」，高克制者的節制在前負荷後瓦解而吃得更多，方向與一般直覺相反，不可誤記為「更節制」。

第 4 題

請問in vivo暴露療法是指：
  1. （A）先訓練個案產生心像的能力，然後進行想像暴露療法
  2. （B）先讓個案觀看害怕情境的影片畫面，然後再進行想像暴露療法
  3. （C）在真實生活情境中進行暴露療法
  4. （D）在虛擬實境（VR）的模擬情境中進行暴露療法

答案：（C）

詳解與考點

正解：in vivo（現場／實境）暴露的判準是「在真實生活情境中直接接觸令人害怕的刺激」，故選 C。

A：先訓練個案產生心像能力再進行想像暴露，屬想像暴露療法（imaginal exposure）的做法，並非現場實境暴露。

B：先觀看害怕情境的影片畫面再進行想像暴露，同樣是以影像為媒介的想像暴露形式，未涉及真實情境。

D：在虛擬實境（VR）模擬情境中暴露，屬虛擬實境暴露治療（virtual reality exposure therapy），以模擬情境取代真實情境；分辨關鍵在於 VR 情境仍屬模擬而非真實生活現場，這是最容易與 in vivo 混淆之處，屬本題最強誘答。

本題考點：暴露療法依刺激媒介分型——in vivo 指真實生活情境的直接暴露，想像暴露以心像或影片為媒介，VR 暴露以虛擬模擬情境為媒介，三者判準在於刺激來源是否為「真實現場」。

第 5 題

下列那一類焦慮症患者在進行暴露相關療法時不宜施作肌肉放鬆訓練？
  1. （A）恐慌症（panic disorder）
  2. （B）血液恐懼症（blood phobia）
  3. （C）動物恐懼症（animal phobia）
  4. （D）社交焦慮症（social anxiety disorder）

答案：（B）

詳解與考點

正解：關鍵在血液恐懼症（blood phobia）患者面對血液或針頭等刺激時的特殊生理反應——常出現血管迷走反應，血壓先升後驟降而導致暈厥，臨床上改採「應用緊張法（applied tension）」升高血壓以避免暈厥，而非肌肉放鬆訓練，故選 B 不宜施作放鬆訓練。

A：恐慌症（panic disorder）患者可搭配肌肉放鬆與呼吸控制降低生理喚起，屬適用範圍，無暈厥禁忌。

C：動物恐懼症（animal phobia）為典型的特定對象恐懼症，肌肉放鬆搭配漸進式暴露為常見做法，同樣無暈厥風險。

D：社交焦慮症（social anxiety disorder）患者的生理喚起以焦慮升高為主，並無血管迷走性暈厥風險，放鬆訓練仍適用；分辨關鍵在於一般焦慮症用放鬆訓練降低喚起皆有益，唯獨血液恐懼症因暈厥風險而是例外，此為本題最強誘答。

本題考點：血液恐懼症的雙相生理反應（血壓先升後驟降）與其治療禁忌——一般焦慮症用肌肉放鬆降低喚起，血液恐懼症因暈厥風險須改用應用緊張法（applied tension）升高血壓，判準在於該類疾患是否伴隨血管迷走性暈厥。

第 6 題

有關恐慌症的PCT（panic control therapy）治療，下列敘述何者錯誤？
  1. （A）治療中會設法引發個案產生類似恐慌發作的身體感覺
  2. （B）PCT的主要原理是暴露療法
  3. （C）在治療過程中個案被告知要充分覺察這些身體感覺，但不要去評價它
  4. （D）治療目標在增加個案對於恐慌發作與相關身體感覺的控制感

答案：（C）

詳解與考點

正解：本題問的是恐慌控制治療（panic control therapy, PCT）何者敘述錯誤——判準是 PCT 以暴露為核心原理，其中內感受暴露與認知重建是主要成分，並非強調「覺察而不評價」的正念（mindfulness）取向，故選 C 為錯誤敘述。

A：治療中會設法引發個案產生類似恐慌發作的身體感覺，此即內感受暴露（interoceptive exposure），為 PCT 的核心步驟之一，敘述正確。

B：PCT 的主要原理是暴露療法，透過反覆暴露於恐慌相關身體感覺與情境以降低恐懼反應，敘述正確。

D：治療目標在增加個案對恐慌發作與相關身體感覺的控制感，此為 PCT 的治療目標之一，敘述正確。

本題考點：恐慌控制治療（PCT）以暴露（含內感受暴露）與認知重建為核心，非正念的「覺察但不評價」取向；判別關鍵在於 PCT 要求個案主動辨識並重新詮釋身體感覺的意涵，而非單純不加評價地覺察。

第 7 題

MacLeod和Mathews（2012）採用點偵測作業（dot probe task）進行研究，他們要參與者將其注意力放在電腦螢幕的光點，其中，實驗組參與者的光點可能出現在負向字詞的位置，而控制組參與者的光點則是隨機出現在左側或右側，結果被要求注意負向字詞的參與者自陳報告有較高的焦慮感。依據上述研究結果，可知焦慮症患者可能是受到下列那一個認知因子影響而產生焦慮？
  1. （A）持續的未來負向信念
  2. （B）知覺到缺乏控制感
  3. （C）對威脅信號的注意力
  4. （D）僵化的思考方式

答案：（C）

詳解與考點

正解：判準是 MacLeod 與 Mathews（2012）點偵測作業（dot probe task）研究的自變項——被誘導將注意力持續導向負向字詞位置的參與者，事後自陳焦慮感較高，顯示焦慮與對威脅信號的注意力偏誤有關，故選 C。

A：持續的未來負向信念屬認知內容層次的偏誤，與本實驗操弄的注意力導向機制不直接對應。

B：知覺到缺乏控制感是焦慮的另一心理素質因子，但本實驗操弄的是注意力位置而非控制感知覺，不是此研究結果所指向的因子。

D：僵化的思考方式屬認知彈性層面的特徵，與點偵測作業測量的注意力偏誤機制不同；分辨關鍵在於區分「思考內容或彈性」與「注意力朝向何處」兩類不同的認知歷程，此為本題最強誘答。

本題考點：注意力偏誤（attentional bias）研究範式——點偵測作業（dot probe task）操弄的是注意力朝向的位置，其結果對應的認知因子是「對威脅信號的注意力」，須與負向信念、缺乏控制感、僵化思考等其他認知因子區分開。

第 8 題

「孫先生是一個35歲的男性個案，他向精神科醫師抱怨他長期睡眠品質不佳，日常生活也時常感覺浮躁與不耐煩，在工作上也容易覺得疲累或是不能專心，除此之外，孫先生似乎也對任何生活中的大小事情感到擔憂，尤其面對未來可能發生的事情，他也時常會設想最壞的情況。他覺得自己無法停止自己的擔心，因而嚴重影響生活的品質。」孫先生可能具有什麼樣的診斷？
  1. （A）恐慌症
  2. （B）雙相情緒障礙症
  3. （C）廣泛性焦慮症
  4. （D）鬱症

答案：（C）

詳解與考點

正解：關鍵在孫先生的臨床表現符合廣泛性焦慮症（generalized anxiety disorder, GAD）的核心特徵——長期失眠、煩躁不耐、易疲累難專注，且對生活大小事有難以控制的廣泛擔憂、常設想最壞情況，故選 C。

A：恐慌症（panic disorder）以反覆非預期的恐慌發作為核心，題幹未描述突發性強烈恐懼與身體症狀發作，不符合。

B：雙相情緒障礙症須有躁期或輕躁期的證據，題幹全無情緒高昂、活動量增加等表現，不符合。

D：鬱症以情緒低落或失樂為核心症狀；題幹雖有疲累與睡眠問題，但主軸是「無法停止的廣泛性擔憂」而非情緒低落，分辨關鍵在於失眠與疲累在鬱症與 GAD 皆可見，須看主訴聚焦於廣泛擔憂或情緒低落，此為本題最強誘答。

本題考點：廣泛性焦慮症（GAD）的核心判準是「難以控制的廣泛性擔憂」加上相關的生理與認知症狀（失眠、易疲累、難專注、煩躁）；須與恐慌症的發作性恐懼、雙相症的情緒高昂期、鬱症的情緒低落主軸區分。

第 9 題

有關社交焦慮症（social anxiety disorder）患者的認知特徵敘述，下列何者錯誤？
  1. （A）患者對於他們在社會情境下的表現結果時常具有負向預期
  2. （B）患者時常認為他人正負面地評價自己的表現
  3. （C）患者的焦慮升高時，將無暇專注在自己的內在感受上
  4. （D）患者時常相信自己很有可能受到他人的拒絕或批評

答案：（C）

詳解與考點

正解：本題問的是社交焦慮症（social anxiety disorder）患者認知特徵何者錯誤——判準是焦慮升高時患者的注意力方向。患者在焦慮升高時實則會過度自我聚焦、強化對自身表現與生理反應的內在監控，而非「無暇專注於自己的內在感受」，故選 C 為錯誤敘述。

A：患者對社會情境下的表現結果時常具有負向預期，此為社交焦慮症典型的預期性焦慮，敘述正確。

B：患者時常認為他人正負面地評價自己的表現，此為社交焦慮症核心的認知偏誤之一，敘述正確。

D：患者時常相信自己很有可能受到他人的拒絕或批評，屬社交焦慮症對社會評價的災難化解讀，敘述正確。

本題考點：社交焦慮症的自我聚焦式注意——焦慮升高時患者的注意力轉向內在監控自身表現與生理反應而非減少，判別關鍵在於區分「自我聚焦增加」與「注意力轉移他處」兩個相反方向。

第 10 題

儲物症（hoarding disorder）患者難以丟棄其持有物的理由，最有可能是下列何者？
  1. （A）相信這些持有物未來會增值
  2. （B）對於這些持有物有強烈的情緒依戀
  3. （C）害怕丟棄持有物會帶來厄運
  4. （D）相信這些持有物能帶來超能力

答案：（B）

詳解與考點

正解：儲物症（hoarding disorder）患者難以丟棄持有物最有可能的理由，判準是該症的核心動機為「對物品的強烈情緒依戀」，而非迷信式或誇大式的信念，故選 B。

A：相信持有物未來會增值屬理性化的實用性考量，並非儲物症的典型核心動機。

C：害怕丟棄會帶來厄運屬迷信式信念，較接近強迫症的魔幻思考型態，不是儲物症難以丟棄的主要理由。

D：相信持有物能帶來超能力屬妄想式信念，脫離現實檢驗，並非儲物症的典型特徵；分辨關鍵在於儲物症的核心是情感連結與捨棄決策困難，而非迷信或妄想內容，C、D 皆屬本題易混誘答。

本題考點：儲物症（hoarding disorder）難以丟棄物品的核心動機是強烈的情緒依戀與決策困難，須與強迫症的迷信式魔幻思考、妄想式信念區分。

第 11 題

有關強迫症之敘述，下列何者錯誤？
  1. （A）疾病的初發時期多在35歲以後的成年晚期，兒童與青少年期患者只是少數的比率
  2. （B）成人女性的診斷率略高於男性，而男性的初發年齡比女性來得早
  3. （C）兒童與青少年患者的症狀表現型態不如成人來得穩定，且強迫行為比起強迫思考較容易被診斷出來
  4. （D）雖然成人強迫症患者未接受治療的緩解率低，但是約40%的早發患者在成年早期可能經驗到症狀的緩解

答案：（A）

詳解與考點

正解：本題問的是強迫症流行病學特徵何者錯誤——判準是好發年齡。強迫症多在兒童青少年期至成年早期即已發病，而非題幹所述「35 歲以後的成年晚期」，兒童與青少年患者亦占相當比率而非僅屬少數，故選 A 為錯誤敘述。

B：成人女性的診斷率略高於男性，而男性的初發年齡比女性來得早，此為流行病學上普遍觀察到的性別差異，敘述正確。

C：兒童與青少年患者的症狀表現型態不如成人穩定，且強迫行為比強迫思考更容易被外顯觀察而診斷出來，敘述正確。

D：雖然成人強迫症患者未接受治療的緩解率低，但約 40% 的早發患者在成年早期可能經驗到症狀緩解，此為早發型強迫症病程的特徵之一，敘述正確；具體數值（40%）容易被誤認為需質疑的部分，但題幹問的是「錯誤」選項，此非本題爭議所在，屬本題最強誘答。

本題考點：強迫症的流行病學特徵——好發年齡多在兒童青少年期至成年早期而非成年晚期，這是最容易被記反的一點；性別差異（女性診斷率略高、男性初發較早）與早發型症狀緩解率（約 40%）屬既有實證特徵。

第 12 題

下列何者是強迫症（obsessive-compulsive disorder）與身體臆形症（body dysmorphic disorder）的共同特徵？
  1. （A）自我感喪失
  2. （B）重複擔憂自己罹患嚴重疾病
  3. （C）重複性思考與行為
  4. （D）非預期性的恐慌發作

答案：（C）

詳解與考點

正解：關鍵在強迫症與身體臆形症同屬 DSM-5 強迫及相關障礙症（obsessive-compulsive and related disorders）類別，兩者的核心共同表現是重複性思考與行為（如反覆檢查、照鏡、確認），故選 C。

A：自我感喪失屬解離症狀範疇，非強迫症或身體臆形症的核心特徵。

B：重複擔憂自己罹患嚴重疾病屬罹病焦慮（illness anxiety）的表現，與軀體症狀相關障礙症較相關；分辨關鍵在於身體臆形症關注的是「外觀缺陷」而非「罹患疾病」，容易與罹病焦慮混淆，屬本題最強誘答。

D：非預期性的恐慌發作是恐慌症（panic disorder）的核心特徵，與強迫症、身體臆形症的重複性思考行為機制不同。

本題考點：強迫症與身體臆形症（body dysmorphic disorder）同屬強迫及相關障礙症類別，共同核心是重複性思考與行為；須與罹病焦慮（重複擔憂患病）、解離症狀（自我感喪失）、恐慌發作等不同機制的症狀區分。

第 13 題

有關創傷後壓力症（posttraumatic stress disorder）的治療與預防方式，下列敘述何者正確？
  1. （A）在心理分析中，治療者主要運用自由聯想的方式來緩解個體經驗創傷後的受苦情緒
  2. （B）治療的目標在於協助個體有效地阻斷對創傷記憶的提取
  3. （C）選擇性血清素回收抑制劑（SSRIs）是治療創傷後壓力症症狀有療效的藥物之一
  4. （D）想像暴露療法的目的是為了讓個體未來再遇到相似的創傷事件時，不再有恐懼或是逃避的行為

答案：（C）

詳解與考點

考點為創傷後壓力症的治療與預防。SSRI 是 PTSD 有實證療效的藥物之一，故選 C 正確。A 把心理分析自由聯想當主要治法、B 主張阻斷創傷記憶提取、D 說暴露目的是面對未來真實創傷，皆有誤；暴露治療目的在處理既有創傷記憶與減敏，而非保證未來不再恐懼。陷阱是 D 對暴露目標的錯誤詮釋。

第 14 題

有關急性壓力症（acute stress disorder）與創傷後壓力症（posttraumatic stress disorder）的敘述，下列何者正確？
  1. （A）假如個體在創傷事件六個月之後才出現嚴重的壓力症狀，較適合被診斷為急性壓力症
  2. （B）創傷事件是診斷兩類疾病的唯一必要因子，因為所有經驗過創傷事件的個體皆會發展出創傷後壓力症或是急性壓力症
  3. （C）大部分被診斷為急性壓力症的個體最終不會發展出創傷後壓力症，因為兩者的病程與病因皆不相同
  4. （D）急性壓力症與創傷後壓力症主要差異在於個體暴露於創傷事件後到出現壓力症狀的時間

答案：（D）

詳解與考點

正解：急性壓力症（acute stress disorder, ASD）與創傷後壓力症（posttraumatic stress disorder, PTSD）的主要區辨點在於「個體暴露於創傷事件後到出現壓力症狀的時間」，故選 D。

A：假如個體在創傷事件六個月之後才出現嚴重壓力症狀，其時間點已遠超 ASD 的診斷時間窗（創傷後 3 天至 1 個月內），不適合診斷為 ASD，此描述方向相反。

B：創傷事件並非診斷兩類疾病的唯一必要因子，也並非所有經驗過創傷事件的個體皆會發展出 ASD 或 PTSD——個體差異與其他風險因子同樣影響是否發病，此敘述過於絕對。

C：大部分被診斷為 ASD 的個體最終確實未發展出 PTSD，但兩者的病程與病因並非完全不同，兩者診斷標準高度重疊；分辨關鍵在於「轉化率不高」這項觀察屬實，但不能據此推論病因病程完全不同，主要差異仍在時間軸而非病因，此為本題最強誘答。

本題考點：ASD 與 PTSD 的核心區辨判準是症狀出現與持續的時間軸——ASD 為創傷後 3 天至 1 個月內，超過 1 個月且症狀持續才符合 PTSD；不可誤以為兩者差異在症狀種類或完全不同的病因病程。

第 15 題

依據DSM-5創傷及壓力相關障礙症，診斷為反應性依附障礙症（reactive attachment disorder）的兒童，其發展年齡至少達到幾個月？
  1. （A）1個月
  2. （B）3個月
  3. （C）6個月
  4. （D）9個月

答案：（D）

詳解與考點

正解：本題問的是 DSM-5 反應性依附障礙症（reactive attachment disorder）診斷所要求的最低發展年齡——判準是個體須已具備形成選擇性依附的發展能力，DSM-5 規定發展年齡至少達 9 個月，故選 D。

A：1 個月的發展階段尚未具備形成選擇性依附的能力，不符合診斷所需的最低年齡門檻。

B：3 個月同樣早於嬰兒發展出選擇性依附能力的一般時程，不符合本症診斷要求。

C：6 個月雖已接近依附關係逐漸成形的階段，但仍早於 DSM-5 明訂的 9 個月門檻；6 個月與 9 個月同屬嬰兒依附發展的相近時間帶，容易混淆，屬本題最強誘答。

本題考點：DSM-5 反應性依附障礙症的診斷要件之一是發展年齡至少達 9 個月，確保個體已具備形成選擇性依附的發展能力，此為版本明訂的具體年齡門檻，須與其他相近月齡選項區分。

第 16 題

根據DSM-5，關於轉化症之敘述，下列何者正確？
  1. （A）女性患者多於男性
  2. （B）終生盛行率約3%
  3. （C）通常在中年時發病
  4. （D）最常與飲食疾患共病

答案：（A）

詳解與考點

正解：關鍵在 DSM-5 轉化症的性別分布——女性患者多於男性，故選 A。

B：轉化症的終生盛行率遠低於題幹所述的 3%，此具體數值與實際流行病學資料不符。

C：轉化症通常在青少年至成年早期發病，並非中年時期，此描述的好發年齡方向有誤。

D：轉化症最常與其他身體症狀相關障礙症及焦慮、憂鬱共病，而非最常與飲食疾患共病；飲食疾患同屬與身體意象或身體症狀相關的疾患範疇，容易被誤認為與轉化症有特殊共病關聯，屬本題最強誘答。

本題考點：DSM-5 轉化症的流行病學特徵——女性多於男性、盛行率遠低於 3%、好發於青少年至成年早期而非中年、共病以其他身體症狀及焦慮憂鬱為主而非飲食疾患；具體盛行率數值與發病年齡屬版本敏感的細節，須逐項核對而非直覺推測。

第 17 題

近一年來張先生深受頭痛所苦，看了許多醫師也做了多項檢查皆未發現問題，很擔心頭痛是嚴重腦病變的徵兆；為了減少壓力，甚至辭去工作專心在家休養。依據前述，最不可能符合DSM-5的何項診斷？
  1. （A）罹病焦慮症（illness anxiety disorder）
  2. （B）身體症狀障礙症（somatic symptom disorder）
  3. （C）人為障礙症（factitious disorder）
  4. （D）廣泛性焦慮症（generalized anxiety disorder）

答案：（C）

詳解與考點

正解：判準是各鑑別診斷是否需要「刻意偽造」症狀這項要件。張先生長期頭痛、多項檢查未發現異常、強烈擔心是腦病變徵兆、甚至辭職休養，表現的是真實的痛苦與擔憂，並無偽造或誇大症狀以扮演病人角色的線索；人為障礙症（factitious disorder）的核心正是「刻意偽造、誇大或製造身體或心理症狀」且無明顯外在誘因，與題幹描述不符，故選 C 最不可能。

A：罹病焦慮症（illness anxiety disorder）以身體症狀輕微或不存在為前提、焦慮集中在「罹患或將罹患重病」，張先生的強烈擔心與反覆就醫求證高度符合此輪廓，此診斷確有可能成立。

B：身體症狀障礙症（somatic symptom disorder）要求有實際且困擾的身體症狀（如頭痛）並伴隨過度的健康相關想法、感受與行為（辭職專心休養即為過度行為反應），與題幹描述相符，此診斷同樣有可能成立。

D：廣泛性焦慮症（generalized anxiety disorder）以難以控制的廣泛性擔憂為核心；本案擔憂雖高度聚焦於單一健康議題而非多項生活領域，符合程度不如 A、B，但仍高於 C 這種需要偽造症狀線索才成立的診斷，分辨關鍵在此，屬本題最強誘答。

本題考點：鑑別「最不可能」的診斷時，判準是該診斷所需的必要條件是否被題幹排除——人為障礙症要求刻意偽造症狀且無外在誘因，題幹全無此線索，故為最不可能成立者；罹病焦慮症與身體症狀障礙症皆環繞真實的健康焦慮與身體症狀，較為符合。廣泛性焦慮症（generalized anxiety disorder, GAD）雖聚焦程度略有不同，但同樣不涉及刻意偽造症狀，可能性同樣高於人為障礙症。

第 18 題

有關解離性身份障礙症（dissociative identity disorder, DID）與創傷後壓力症（posttraumatic stress disorder, PTSD）的鑑別診斷，下列何者錯誤？
  1. （A）DID的失憶包含每天生活的許多經驗；PTSD的失憶僅侷限於創傷事件相關的內容
  2. （B）DID可能不記得解離性再現（dissociative flashback）的內容，PTSD通常記得
  3. （C）DID的闖入記憶（intrusion）與轉換人格有關；PTSD的闖入記憶跟創傷事件有關
  4. （D）DID對解離症狀表現得漠不關心；PTSD對解離症狀有強烈的羞恥感

答案：（D）

詳解與考點

正解：本題問的是解離性身份障礙症（dissociative identity disorder, DID）與創傷後壓力症（posttraumatic stress disorder, PTSD）鑑別診斷何者錯誤——判準是情緒反應是否可作為兩者的可靠鑑別點。DID 與 PTSD 患者對解離症狀的情緒反應並非如題幹所述「漠不關心 vs 強烈羞恥感」這種截然對立的配對，此描述不成立，故選 D 為錯誤敘述。

A：DID 的失憶包含每天生活的許多經驗，PTSD 的失憶僅侷限於創傷事件相關的內容，此為兩者失憶範圍廣狹的正確對比。

B：DID 可能不記得解離性再現（dissociative flashback）的內容，PTSD 通常記得，此描述反映了兩者對閃回經驗的記憶保留程度不同，敘述正確。

C：DID 的闖入記憶（intrusion）與轉換人格有關，PTSD 的闖入記憶跟創傷事件有關，此為兩者闖入記憶內容來源的正確區分。

本題考點：DID 與 PTSD 的鑑別判準應落在失憶範圍、閃回記憶的保留程度、闖入記憶的內容來源等可觀察的症狀特徵上，而非以「情緒態度」（漠不關心或羞恥感）作鑑別，後者並非兩者間穩定可靠的區辨點。

第 19 題

下列何項最不可能發生在失自我感／失現實感障礙症（depersonalization/derealization disorder）的患者身上？
  1. （A）感覺記憶出現斷層（gap）
  2. （B）感覺自己從遠處看著自己
  3. （C）感覺周遭的場景很不真實
  4. （D）感覺自己的身體像機器人

答案：（A）

詳解與考點

正解：失自我感／失現實感障礙症（depersonalization/derealization disorder）患者「最不可能」出現的症狀，判準是該症的核心特徵是否涉及記憶內容的缺失。記憶出現斷層（gap）屬解離性失憶（dissociative amnesia）的特徵，並非失自我感／失現實感障礙症的核心表現，故選 A 最不可能。

B：感覺自己從遠處看著自己，是失自我感（depersonalization）的典型描述，確有可能出現。

C：感覺周遭場景很不真實，是失現實感（derealization）的典型描述，確有可能出現。

D：感覺自己的身體像機器人，同樣是失自我感常見的身體疏離感描述，確有可能出現；B、C、D 皆為該症核心症狀，須與 A 這種涉及記憶內容缺失的症狀區分開，此為本題最強誘答。

本題考點：失自我感／失現實感障礙症的核心是「疏離感」（對自身心智歷程、身體或周遭環境的不真實感），不涉及記憶內容本身的缺失；記憶斷層屬解離性失憶的特徵，判別關鍵在於區分「疏離感受」與「記憶內容喪失」兩種不同的解離症狀類型。

第 20 題

行為活化治療（behavioral activation treatment）為治療憂鬱的有效策略之一，其主要作用是在透過下列何者來降低憂鬱者的逃避、缺少活力等症狀？
  1. （A）增加正向增強
  2. （B）降低負向增強
  3. （C）增加正向懲罰
  4. （D）降低負向懲罰

答案：（A）

詳解與考點

正解：關鍵在行為活化治療（behavioral activation treatment）降低憂鬱者逃避與缺少活力等症狀的作用機轉——該治療透過安排活動、增加個體與環境的正向連結來達成，故選 A 增加正向增強。

B：降低負向增強雖與憂鬱者的逃避行為有關（逃避可暫時減少負向情緒此即負向增強），但行為活化的核心策略是主動提升正向增強來源，而非以降低負向增強為主要機轉；逃避行為的維持機制確實涉及負向增強，容易誤把治療機轉與症狀維持機制混為一談，此為本題最強誘答。

C：增加正向懲罰並非行為活化治療的作用方向，該治療不涉及以懲罰手段介入。

D：降低負向懲罰同樣非行為活化治療的核心機轉，該治療聚焦於增加正向增強而非調整懲罰性後果。

本題考點：行為活化治療的核心機轉是增加正向增強（透過安排活動重建個體與環境的正向連結），須與「憂鬱逃避行為由負向增強維持」這一症狀維持機制區分——治療策略是提升正向增強來源，而非單純降低負向增強。

第 21 題

根據Coyne與Joiner的理論，下列何者常見於憂鬱患者，其結果可能會使得周遭其他人感到厭煩而拒絕他？
  1. （A）高情緒表露（expressed emotion）
  2. （B）過度尋求再保證（reassurance seeking）
  3. （C）悲觀的歸因型態（attributional style）
  4. （D）童年受虐經驗

答案：（B）

詳解與考點

正解：判準是 Coyne 與 Joiner 理論特別強調的人際機制——過度尋求再保證（excessive reassurance seeking）：患者反覆要求他人確認自己被接納與重視，長期下來使周遭人感到厭煩而疏遠，故選 B。

A：高情緒表露（expressed emotion）通常指家屬對患者的批評、敵意或情緒過度涉入，是描述「他人對患者」的態度而非患者本身的行為，方向與本題所問（患者的行為引發他人厭煩）不同。

C：悲觀的歸因型態（attributional style）是憂鬱認知理論（如習得無助）強調的認知因子，涉及患者對事件成因的解讀方式，並非 Coyne 與 Joiner 理論所特別強調的引發他人拒絕的人際機制。

D：童年受虐經驗屬憂鬱症的風險因子之一，但並非 Coyne 與 Joiner 人際理論所指、直接導致他人厭煩拒絕的行為機制；童年受虐與憂鬱、人際困難皆有關聯，分辨關鍵在於本題問的是「理論所指的當下人際互動行為」而非早年風險因子，此為本題最強誘答。

本題考點：Coyne 與 Joiner 的人際憂鬱理論核心機制是過度尋求再保證——患者反覆求證是否被接納，長期消耗他人耐心而招致拒絕；須與高情緒表露（他人對患者的態度）、悲觀歸因（認知因子）、童年受虐（風險因子）等不同層次的變項區分。

第 22 題

根據DSM-5，有關鬱症（major depressive disorder）的病程發展與特徵，下列敘述何者正確？
  1. （A）中年與老年的鬱症患者有較高的自殺企圖
  2. （B）嗜食與嗜睡較常見於老年患者身上，精神動作障礙（psychomotor disturbances）則較常見於年輕患者身上
  3. （C）越早發病的鬱症患者越有可能伴隨人格障礙
  4. （D）男性的鬱症患者對治療的反應較差

答案：（C）

詳解與考點

正解：本題問的是 DSM-5 鬱症（major depressive disorder）病程發展與特徵何者正確——判準是發病年齡與人格障礙共病之間的關聯，越早發病的鬱症患者越有可能伴隨人格障礙，故選 C。

A：自殺企圖較高其實較常見於年輕族群，而非中年與老年患者；老年患者的自殺死亡率雖高，但企圖率的年齡分布與此描述方向不同，容易把企圖率與死亡率的年齡分布混淆，屬本題最強誘答。

B：嗜食與嗜睡、精神動作障礙（psychomotor disturbances）在不同年齡層的常見程度描述被對調——實際上精神動作障礙較常見於年長患者，非典型症狀（嗜食嗜睡）的年齡分布與題幹所述相反。

D：性別與治療反應之間並無穩定的實證支持顯示男性鬱症患者對治療的反應較差，此描述缺乏根據。

本題考點：DSM-5 鬱症病程特徵的判準——早發型鬱症與人格障礙共病率較高；自殺相關指標須區分企圖率與死亡率的年齡分布；精神動作障礙與非典型症狀（嗜食嗜睡）在年齡層的常見程度容易被誤記或對調，須逐項核對而非憑直覺配對。

第 23 題

有關憂鬱症認知理論的實徵證據，下列敘述何者正確？
  1. （A）憂鬱組比非憂鬱組有更多負向思考
  2. （B）憂鬱組認知三角是對他人、世界、事務感到毫無價值
  3. （C）憂鬱認知與自動化的認知訊息處理無關
  4. （D）憂鬱組比非憂鬱組記不起正向記憶，但兩組負向記憶量沒差

答案：（A）

詳解與考點

正解：本題問的是憂鬱症認知理論的實徵支持證據——判準是該證據是否呼應認知理論的核心主張。多項研究確認憂鬱組確實比非憂鬱組出現更多負向自動化思考，此為認知理論最直接的實徵支持，故選 A。

B：認知三角（cognitive triad）的原始定義指個體對自我、世界、未來三者的負向看法。這是本題最強的誘答——「認知三角」一詞用對了，內容也在講負向認知，但把三個對象替換成「他人、世界、事務」，判別關鍵在於三角的三個頂點固定是自我／世界／未來，並非隨題目情境替換的任意對象。

C：憂鬱認知的特徵之一正是自動化的認知訊息處理——負向基模一旦被促發，會自動、不費力地扭曲訊息解讀，此項否定兩者的關聯與實證方向相反。

D：實證顯示憂鬱組不僅較記不住正向記憶，對負向記憶的提取量也高於非憂鬱組，記憶偏誤具方向性；此項稱「兩組負向記憶量沒差」與此不符。

本題考點：憂鬱認知理論的實徵指標——負向自動化思考量增加、認知三角應為自我／世界／未來三個對象、記憶偏誤呈現「正向記憶較少、負向記憶較多」的雙向型態；三者中只要有一項被誤置對象或方向講反，該敘述即不成立。

第 24 題

根據DSM-5，持續性憂鬱症（persistent depressive disorder）的診斷標準，下列敘述何者最恰當？
  1. （A）一週中大部分時間心情憂鬱，維持至少2年
  2. （B）在出現困擾的期間內，無症狀時期從未超過3個月
  3. （C）反覆有死亡的想法或自殺意念亦可診斷為持續性憂鬱症
  4. （D）在18歲前初發者，屬早期初發（early onset）

答案：（C）

詳解與考點

考點為 DSM-5 持續性憂鬱症（輕鬱症）的診斷標準。其中反覆死亡想法或自殺意念也可作為症狀之一，故選 C 較恰當。A 應為「大部分日子」憂鬱至少 2 年（成人）、B 無症狀期不超過 2 個月（非 3 個月）、D 早發界定為 21 歲前（非 18 歲），故其餘選項數字有誤。陷阱在於各項門檻數字易記錯。

第 25 題

史小姐表示自己本來就容易認床、怕吵，生產完後睡眠品質有變差，但尚可應付白天工作，去年12月因被診斷為乳癌開始持續出現失眠問題，由醫師開立助眠藥物緩解化療療程中常見的失眠症狀，但化療療程已經結束，自陳還是無法順利停用藥物，因為一旦停藥就整晚都睡不著，很擔心沒有睡會影響免疫力，造成癌症復發。根據前述情形，下列配對何者錯誤？
  1. （A）前置因子─認床、怕吵的睡眠脆弱特質
  2. （B）促發因子─乳癌
  3. （C）促發因子─擔心睡不好癌症容易復發
  4. （D）持續因子─助眠藥物的依賴

答案：（C）

詳解與考點

正解：判準是失眠三因子模式（前置、促發、持續因子）中，認知性擔憂應歸類為維持失眠的持續因子，而非誘發失眠的促發因子。史小姐擔心沒睡好會使癌症復發，這種對失眠後果的災難化認知，是使失眠持續存在的機制，而非最初引發失眠的事件，此配對應屬「持續因子」而非「促發因子」，配對錯誤，故選 C。

A：認床、怕吵的睡眠脆弱特質屬個人長期具備的體質傾向，符合前置因子的定義，配對正確。

B：乳癌診斷是明確可指認的單一事件，觸發了失眠問題的出現，符合促發因子的定義，配對正確。

D：對助眠藥物產生依賴、擔心停藥後無法入睡，屬維持失眠不消退的機制，符合持續因子的定義，配對正確。

本題考點：失眠三因子模式的分類判準——前置因子是長期體質、促發因子是引發失眠的單一事件、持續因子是使失眠得以延續的認知與行為（含藥物依賴、災難化擔憂）；對失眠後果的擔憂雖與促發事件時間相近，但其作用機制是維持而非引發，應歸入持續因子。

第 26 題

小強就讀小學二年級，由父母帶來就診，表示他晚上經常會起來走動，對外界的刺激沒有反應，且早上通常不記得夜裡發生的事，依據DSM-5，小強的狀況最可能是下列何者？
  1. （A）非快速動眼睡醒障礙症─夢遊型
  2. （B）夢魘症
  3. （C）非快速動眼睡醒障礙症─睡驚型
  4. （D）快速動眼睡眠行為障礙症

答案：（A）

詳解與考點

正解：關鍵在小強「夜間起身走動、對外界刺激沒有反應、醒後不記得夜裡發生的事」這三個特徵的組合——判準是依 DSM-5，這正是非快速動眼（NREM）睡醒障礙症夢遊型的典型表現：行為發生在慢波睡眠期間，個案處於部分覺醒狀態，對外界刺激反應低，事後對此段經過通常失憶，故選 A。

B：夢魘症發生在快速動眼睡眠期，個案會因惡夢驚醒且能清楚記得夢境內容，與小強「不記得」的表現相反。

C：睡驚型同屬非快速動眼異睡症，但典型表現是突然的驚恐尖叫、明顯自主神經激發（心跳加速、冒汗），而非以起身走動為主要行為，兩者症狀重心不同。

D：快速動眼睡眠行為障礙症發生在快速動眼睡眠期，個案會將夢境內容演出為肢體動作，好發於年長者，與小強就讀國小二年級的年齡層不符。

本題考點：非快速動眼異睡症的鑑別判準——夢遊型以「起身走動、對外界無反應、醒後失憶」為核心，睡驚型以「驚恐尖叫、自主神經激發」為核心，兩者同屬慢波睡眠期但主要行為不同；快速動眼期（REM）的夢魘症與快速動眼睡眠行為障礙症則分別以「記得夢境」與「演出夢境、好發年長者」與之區隔。

第 27 題

承上題，小強的狀況最佳的處置方式為何？
  1. （A）請父母儘量將小強喚醒，以中止此一行為
  2. （B）給予父母相關衛教，並持續觀察小強的狀況
  3. （C）給予藥物治療，避免此一現象出現
  4. （D）延後上床時間，以矯正晝夜節律的偏差

答案：（B）

詳解與考點

正解：本題問的是兒童夢遊（非快速動眼異睡症，NREM）的最佳處置方式——判準是這類行為在兒童期多屬良性、隨年齡增長會自然改善，處置重點在確保安全與家長認知，而非中止或矯正行為本身，給予父母相關衛教並持續觀察最符合此原則，故選 B。

A：強行將發作中的個案喚醒，容易造成其意識混亂甚至情緒激動反應，並非建議做法，反而可能增加風險。

C：藥物治療並非兒童夢遊的首選處置，僅在發作頻繁、有明顯安全疑慮或合併其他睡眠障礙時才考慮使用，一般良性個案不需要。

D：延後上床時間是用於矯正晝夜節律偏差的處置，夢遊屬慢波睡眠期的部分覺醒現象而非晝夜節律問題，兩者機轉不同，此處置對夢遊並無針對性。

本題考點：兒童夢遊處置的核心判準——以居家安全防護與家長衛教為主、避免強行喚醒、非藥物優先；需與晝夜節律相關的處置（如調整上床時間）區分，因兩者針對的生理機轉不同。

第 28 題

張三有連續超過六個月的時間，在與伴侶進行性活動時，有明顯的勃起困難；伴侶於是鼓勵他來尋求臨床協助。張三必須符合下列那兩種狀況，才有可能被診斷為勃起障礙症（erectile disorder）？
  1. （A）勃起困難需導致張三產生臨床上顯著的苦惱，且並非導因於伴侶關係上的嚴重困擾
  2. （B）勃起困難需導致伴侶具有臨床上顯著的苦惱，且並非導因於伴侶關係上的嚴重困擾
  3. （C）勃起困難需導致張三產生臨床上顯著的苦惱，再加上導因於伴侶關係上的嚴重困擾
  4. （D）勃起困難需導致伴侶具有臨床上顯著的苦惱，且同時有嚴重的伴侶關係問題

答案：（A）

詳解與考點

正解：判準是 DSM-5 對性功能障礙的診斷要件——苦惱的主體須是個案本人，而非伴侶；且若症狀完全可由嚴重的伴侶關係困擾（或其他因素）所解釋，則不應獨立診斷勃起障礙症。張三本人因勃起困難產生臨床顯著苦惱，且此困擾並非僅由伴侶關係嚴重不睦所致，兩項條件同時符合，故選 A。

B：把苦惱主體放在伴侶身上——診斷要件要求的是個案本人感到臨床顯著苦惱，伴侶的感受並非診斷的必要條件，此項把主體張冠李戴。

C：後半把「排除」條件寫成「併存」條件——嚴重伴侶關係困擾應作為排除其他解釋的判準，而非與症狀共同存在才能診斷，方向恰好相反。

D：同時錯置苦惱主體（應為個案本人而非伴侶）與排除條件（應排除嚴重伴侶關係問題而非將其列為併存要件）。

本題考點：性功能障礙類診斷的兩層判準——苦惱主體須鎖定個案本人；伴侶關係嚴重困擾等其他可解釋因素屬排除項而非併存項，兩者只要有一項錯置即不成立診斷。

第 29 題

王先生一直覺得女性內衣對他很具有吸引力。在下列何種條件下，王先生最有可能被診斷為戀物症（fetishistic disorder）？
  1. （A）王先生同時有偷女性內衣的行為
  2. （B）王先生會用望遠鏡觀看鄰居女性穿／脫內衣
  3. （C）王先生會透過撫摸女性內衣來達到性興奮
  4. （D）王先生在房間中堆滿了他所買來的女性內衣

答案：（C）

詳解與考點

正解：判準是 DSM-5 對戀物症（fetishistic disorder）的核心定義——對非生命物體或非生殖部位產生反覆、強烈的性興奮，且此興奮須直接來自對該物的接觸或使用。王先生透過撫摸女性內衣獲得性興奮，符合以物體本身作為性興奮來源這項核心要件，故選 C。

A：偷竊女性內衣的行為指向的是竊盜症或其他偷竊動機，行為本身不必然涉及以該物取得性興奮，與戀物症的核心機轉不同。

B：用望遠鏡觀看他人穿脫內衣，性興奮來源是「窺視他人的行為過程」，屬窺視症的表現，與以物體本身為興奮來源的戀物症不同。

D：買來大量內衣堆放房間，僅描述物品的囤積行為，未涉及性興奮的產生方式，不足以判定為戀物症。

本題考點：戀物症的判準核心是「性興奮直接來自對非生命物體的接觸或使用」，需與偷竊（竊盜症）、窺視（窺視症）、單純囤積等表面上都涉及該物品、但性興奮來源不同的行為區分。

第 30 題

交感神經腎上腺髓質軸所分泌的物質主要為：
  1. （A）corticosteroids
  2. （B）catecholamines
  3. （C）cytokines
  4. （D）dopamine

答案：（B）

詳解與考點

正解：本題問的是交感神經－腎上腺髓質軸（SAM axis）受壓力刺激時的主要分泌物——判準是此軸由交感神經直接興奮腎上腺髓質，主要釋放兒茶酚胺（catecholamines，即腎上腺素與正腎上腺素），故選 B。

A：corticosteroids（含可體松 cortisol）是下視丘－腦垂腺－腎上腺皮質軸（HPA axis）的產物，屬另一條壓力反應路徑，並非 SAM 軸的分泌物。

C：cytokines（細胞激素）是免疫系統在發炎反應中釋放的物質，與 SAM 軸的神經內分泌機轉無直接對應關係。

D：dopamine 雖同屬兒茶酚胺家族的一員，但 SAM 軸受刺激時主要且大量釋放的是腎上腺素與正腎上腺素，dopamine 並非此軸的主要分泌物，範圍描述過窄且不精確。

正解：本題問的是負向情緒性（negative affectivity）人格特質與健康行為之間的關聯何者不成立——判準是這項特質是否真的使人較少出現某行為或傾向。具負向情緒性者傾向誇大身體不適，且傾向於頻繁求醫而非逃避就醫，「常不願就醫」與此方向相反，故選 D。

第 32 題

根據Sarafino和Smith（2017）的整理，改變階段模式（stages of change model）應用在提升健康行為上，那一項的研究相較起來，支持度較不顯著？

  2. （B）乳癌篩檢
  3. （C）減重
  4. （D）運動

答案：（C）

詳解與考點

正解：本題問的是改變階段模式（stages of change model）應用於各類健康行為時，何者的實證支持相對薄弱——根據 Sarafino 與 Smith（2017）的整理，判準是比較各行為領域的研究支持程度。戒菸、癌症篩檢、運動等領域的應用研究支持度較穩固，而減重領域的支持相對不顯著，故選 C。

D：運動行為的改變階段模式應用也累積相當豐富的實證資料，支持個體採行規律運動前會經歷不同準備階段。

本題考點：改變階段模式在不同健康行為領域的實證支持強弱有別——戒菸、篩檢、運動的應用支持較穩固，減重領域相對薄弱；此類「支持度較不顯著」的題目考的是各領域間的相對強弱比較，而非行為本身是否適用此模式。

第 33 題

信念與意圖是影響人們實踐健康行為與否的重要因素，下列相關的理論敘述何者正確？
  1. （A）計畫行為理論（the theory of planned behavior）主要是評估個體採取預防行動機率的模式
  2. （B）健康信念模式（health belief model）主要是描述意圖行為改變的階段與過程
  3. （C）動機性推理（motivated reasoning）主要是探索人類的理性對健康行為的影響，人需要理性與合乎邏輯的動機促進健康
  4. （D）衝突理論（conflict theory）主要是探討選擇合適因應行為的影響因素：風險性、希望感及是否有合適的時間

答案：（D）

詳解與考點

正解：本題問的是健康行為理論的核心定位辨識——判準是每個理論模式的定義是否被正確對應。衝突理論（conflict theory，即 Janis 與 Mann 提出的決策衝突模式）探討個體在因應壓力時選擇合適行為的影響因素，包括風險性、希望感，以及是否有合適的時間進行決策，此描述與衝突理論的定位相符，故選 D。

A：計畫行為理論（the theory of planned behavior）評估的是態度、主觀規範與知覺行為控制對行為意圖與行為本身的影響，並非題目所描述的「採取預防行動機率」這種以威脅評估為核心的定位，此描述與健康信念模式的定位混淆。

B：健康信念模式（health belief model）描述的是個體對疾病威脅與行動利弊的知覺如何影響其採取健康行為的可能性，並非描述「意圖行為改變的階段與過程」，該描述屬於改變階段模式的定位。

C：動機性推理（motivated reasoning）指人的推理過程受動機與欲望驅動，可能因情感需求而扭曲對訊息的理性判斷，並非探索「理性與合乎邏輯的動機」如何促進健康行為，此描述與其定義方向相反。

本題考點：健康行為理論的定位辨識判準——計畫行為理論看重態度、規範與知覺控制對意圖的預測，健康信念模式看重威脅知覺與利弊評估，改變階段模式看重意圖改變的階段歷程，動機性推理指推理受動機扭曲而非理性驅動，衝突理論（Janis 與 Mann）看重風險、希望感與決策時間對因應選擇的影響；各理論名稱與定義若被對調即成誤導。

第 34 題

某位個案因身體不適而到診所就醫。醫師告訴他：「我開藥給你，每餐飯後吃。你的工時太長，應該要減少工作量。另外，你完全沒有運動，又常熬夜，也不利於身體健康，一定要規律運動，早點睡覺。」依照醫囑遵從的特性，醫師的醫囑當中，個案最有可能做到的是下列何者？
  1. （A）服藥
  2. （B）減少工作量
  3. （C）規律運動
  4. （D）不熬夜

答案：（A）

詳解與考點

正解：本題問的是醫囑遵從性（adherence）的特性——判準是遵從程度與醫囑本身的複雜度、是否需要改變既有生活型態有關：愈簡單、明確、被動配合（如按時服藥）的醫囑遵從性愈高，愈需要主動改變長期生活習慣的醫囑遵從性愈低。個案最可能做到的是服藥，故選 A。

B：減少工作量涉及調整職場安排與收入等現實限制，屬需要大幅改變生活型態的長期行為，遵從難度較高。

本題考點：醫囑遵從性的判準——簡單、明確、被動配合的醫囑（如服藥）遵從性最高；需要個案主動且長期改變生活型態的醫囑（工時、運動、作息）遵從性較低，題目問「最可能做到」時應優先選擇被動配合類醫囑。

  1. （A）正念冥想／減壓（mindfulness-based meditation / stress reduction）
  2. （B）自我肯定（self-affirmation）

  4. （D）壓力預防模式（stress prevention model）

正解：本題問的是何者不是常見的因應處遇方式（interventions for coping）——判準是選項所列名稱是否對應到文獻中已確立的介入名稱。正念冥想／減壓（mindfulness-based meditation / stress reduction）、自我肯定（self-affirmation）、放鬆訓練（relaxation training）皆為公認且常被引用的因應介入，而「壓力預防模式（stress prevention model）」並非標準名稱，文獻中對應的介入應為 Meichenbaum 提出的壓力免疫訓練（stress inoculation training），故選 D。

本題考點：常見因應處遇的名稱辨識判準——正念減壓、自我肯定、放鬆訓練皆為文獻確立的介入名稱；名稱相近但非標準用語者（如題目自創的「壓力預防模式」）須與真正對應的介入（如 Meichenbaum 的壓力免疫訓練 stress inoculation training）區分，不可望文生義地當成既有處遇。

第 36 題

有關「預先因應（proactive coping）」的敘述，下列何者最為正確？
  1. （A）個人針對已知未來必然發生（例如：三個月後要國考）而非有可能不會發生（例如：可能無法結婚）的壓力先行進行因應
  2. （B）個人主動極積的去面對已發生的壓力情境，以減低壓力的衝擊（impact）
  3. （C）需要個人有「自我調節（self-regulatory）」的技巧，像是個人控制、導引及修正其因應行動（actions）的方式
  4. （D）和個人預期（anticipate）或偵測（detect）壓力的能力無關，而是和壓力管理（stress management）的能力有關

答案：（C）

詳解與考點

正解：本題問的是預先因應（proactive coping）的正確定義——判準是其核心機轉是否落在自我調節（self-regulatory）技巧上，即個人如何控制、導引並修正自己因應行動（actions）的方式，用以面對尚未發生的潛在壓力，此描述最符合預先因應的定義核心，故選 C。

A：把預先因應限定在「已知必然發生」的壓力事件上，過度窄化了範圍——預先因應同樣適用於有可能發生、但尚未確定的壓力情境，並非僅限於確定會發生的事件。

B：描述的是「主動積極面對已發生的壓力情境」，屬一般問題取向因應的範疇，而預先因應的重點在於壓力尚未發生前的準備，時間點錯置。

D：否定預先因應與個人預期（anticipate）或偵測（detect）壓力能力的關聯，與其定義相反——預先因應正是建立在個體能提前預期並偵測潛在壓力源的基礎上，才能進行後續的自我調節。

本題考點：預先因應的定義判準——核心是自我調節技巧（控制、導引、修正因應行動），作用時機在壓力發生之前，且建立在個體具備預期與偵測潛在壓力源的能力上；與一般問題取向因應（處理已發生壓力）的時間點不同。

第 37 題

根據Yerkes-Dodson Law，壓力與表現間呈現何種關係？
  1. （A）正相關的線性關係
  2. （B）倒U型曲線相關
  3. （C）U型曲線相關
  4. （D）負相關的線性關係

答案：（B）

詳解與考點

正解：本題問的是 Yerkes-Dodson 法則所描述的壓力（喚起）與表現之間的關係——判準是兩者並非單純的線性關係。該法則指出喚起程度過低或過高皆會使表現下降，唯有適度喚起時表現最佳，此一非線性型態呈現倒 U 型曲線，故選 B。

A：正相關的線性關係意味著喚起程度愈高、表現愈好，這與該法則所描述「喚起過高反而使表現下降」的現象不符。

C：U 型曲線相關意味著喚起在中等程度時表現最差、兩端表現較佳，方向與該法則所描述「中等喚起表現最佳」恰好相反。

D：負相關的線性關係意味著喚起愈高、表現愈差，忽略了低喚起同樣會使表現不佳的部分，同屬把非線性關係誤化為線性關係。

本題考點：Yerkes-Dodson 法則的核心判準——壓力（喚起）與表現呈倒 U 型曲線關係，適度喚起表現最佳，過低或過高的喚起皆使表現下降；需與正相關線性、負相關線性、U 型曲線等其他錯誤的關係型態區分。

第 38 題

下列與糖尿病（diabetes）照護相關的心理社會因素之敘述，何者錯誤？
  1. （A）壓力可經由影響個人自我照護（如飲食控制等）來影響糖尿病患者的血糖控制
  2. （B）壓力可經由促使正腎上腺素（norepinephrine）分泌，增加胰島素（insulin）的生成，而影響糖尿病患者的血糖控制
  3. （C）壓力可經由促使可體松（cortisol）分泌，增加肝臟葡萄糖（glucose）生成，而影響糖尿病患者的血糖控制
  4. （D）糖尿病患者完全依醫囑進行飲食控制後，仍有可能因為壓力等因素造成血糖控制不理想，因而感到挫折

答案：（B）

詳解與考點

正解：判準是壓力荷爾蒙對胰島素（insulin）分泌方向的影響是否正確。壓力促使正腎上腺素（norepinephrine）分泌時，實際作用是抑制胰島素分泌並促進肝醣分解、升高血糖，而非「增加胰島素的生成」，此項把作用方向講反了，故選 B。

A：壓力確實可透過影響個人自我照護行為（如飲食控制的遵從度下降）間接影響血糖控制，此為心理行為路徑，描述正確。

C：壓力促使可體松（cortisol）分泌，可體松會促進肝臟葡萄糖（glucose）新生與釋放，屬升糖的生理機轉，描述正確。

D：即使糖尿病患者完全遵照醫囑進行飲食控制，壓力仍可能透過上述生理機轉影響血糖，導致控制不理想並產生挫折感，描述符合臨床觀察。

本題考點：壓力影響糖尿病血糖控制的兩條路徑判準——心理行為路徑（透過自我照護遵從度）與生理內分泌路徑（正腎上腺素、可體松經不同機轉升高血糖）；正腎上腺素的作用方向是抑制胰島素分泌而非促進其生成，方向講反是本題最常見的誤答型態。

第 39 題

有關安寧療護（hospice care）概念的敘述，下列何者最不恰當？
  1. （A）安寧療護之主要目標是經由生理、心理、社會與靈性上的照顧，以增進病人與家屬之生活品質
  2. （B）讓末期病人與其家人能好好討論想要「在那裡往生（例如在家或在機構）」，是安寧療護很重要的主題之一
  3. （C）安寧療護重視個人心靈上的平靜，可鼓勵病人參與和自己有關的醫療討論，而減少參與家庭相關事務
  4. （D）安寧療護在病人往生後，仍提供家屬相關後續服務（follow-up care）

答案：（C）

詳解與考點

正解：判準是安寧療護（hospice care）強調全人照顧是否涵蓋家庭參與的面向。安寧療護重視病人心靈上的平靜沒有錯，但同時也重視家庭系統的參與和溝通，鼓勵病人在能力範圍內參與與自己相關的家庭事務討論，而非減少參與，此項前半正確、後半結論卻與安寧療護重視家庭參與的精神相違，故選 C 為最不恰當的敘述。

A：安寧療護的主要目標本就是透過生理、心理、社會與靈性上的整合照顧，增進病人與家屬的生活品質，屬全人照顧的核心定義，描述正確。

B：協助末期病人與家人討論善終地點（例如在家或在機構往生）是安寧療護重要的討論主題之一，讓病人自主決定臨終安排，描述正確。

D：安寧療護的服務範圍不因病人往生而終止，仍持續提供家屬相關後續服務（follow-up care），描述正確。

本題考點：安寧療護全人照顧的判準——涵蓋生理、心理、社會、靈性四個面向，尊重病人對善終地點的自主選擇，服務延伸至病人往生後的家屬後續照顧；心靈平靜與家庭參與並非互斥，鼓勵病人參與家庭事務討論同屬安寧照顧精神的一部分。

第 40 題

對於緊張型頭痛（tension type headache）患者的頭痛症狀，生理回饋（biofeedback）與止痛藥的療效比較，下列敘述何者正確？
  1. （A）生理回饋較快產生療效但較不持久，止痛藥較慢產生療效但較持久
  2. （B）生理回饋較快產生療效且較持久，止痛藥較慢產生療效且較不持久
  3. （C）生理回饋較慢產生療效且較不持久，止痛藥較快產生療效且較持久
  4. （D）生理回饋較慢產生療效但較持久，止痛藥較快產生療效但較不持久

答案：（D）

詳解與考點

正解：判準是生理回饋（biofeedback）與止痛藥對緊張型頭痛（tension type headache）的起效速度與療效持久性是否配對正確。行為取向的介入通常需要較長時間學習與練習才能產生效果，但一旦習得便能維持較久；藥物則多能快速緩解症狀，但效果會隨藥效消退而不持久。生理回饋較慢產生療效但較持久、止痛藥較快產生療效但較不持久，此配對正確，故選 D。

A：把生理回饋描述成「較快產生療效但較不持久」——起效速度實際上是較慢而非較快，此項把兩者的起效速度對調。

B：把生理回饋描述成「較快且較持久」，誇大了其起效速度並保留了持久性的正確描述，屬起效速度配對錯誤。

C：把生理回饋描述成「較慢且較不持久」——持久性方向講反，生理回饋的效果在習得後應較持久而非較不持久。

本題考點：行為取向介入（生理回饋）與藥物治療對慢性疼痛療效的判準——生理回饋起效較慢但效果較持久，藥物起效較快但效果較不持久；此類配對題須同時核對起效速度與持久性兩個維度，任一維度配對錯誤即整體錯誤。
