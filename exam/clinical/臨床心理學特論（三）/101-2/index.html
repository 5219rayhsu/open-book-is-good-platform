第 1 題

依據 Fairburn 的認知行為觀點，暴食的近因是節食失敗，但是根本原因是：
  1. （A）想藉暴食滿足慾望，帶來愉悅
  2. （B）朋友的批評或取笑
  3. （C）自尊低，且負向情緒強
  4. （D）節食後產生罪惡感

答案：（C）

第 2 題

心因性暴食症患者的自信心主要建立在：
  1. （A）體重遠低於正常值
  2. （B）體重在正常值
  3. （C）情緒控制良好
  4. （D）有良好的事業或課業成就

答案：（B）

第 3 題

  2. （B）出現對食物以外之事物有強迫意念或行為
  3. （C）只對食物有強迫行為
  4. （D）只要有強迫意念或行為即可，不論其對象為何

第 10 題

小明曾多次在社交情境有恐慌發作的情形，並且他擔心如果別人將他的焦慮看得一清二楚的話，就會對 他有負面評價。對於小明的鑑別診斷，下列敘述何者錯誤？
  1. （A）小明在社交情境的不自在，主要是擔心自己可能會恐慌發作，加上在非社交情境也有恐慌發作，因此 可診斷為恐慌症
  2. （B）小明只會在社交情境出現恐慌發作，因此不可診斷為恐慌症
  3. （C）小明的恐慌發作無跡可循，在社交情境中恐慌發作的時候，他也擔心自己的言行舉止，這同時符合了 恐慌症和社交恐懼症的診斷準則
  4. （D）小明曾多次在社交情境中出現恐慌，他也會預期在社交情境出現恐慌，因此應診斷為社交恐懼症

答案：（D）
