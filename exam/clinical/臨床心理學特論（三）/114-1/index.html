第 1 題

根據DSM-5，暴食症（bulimia nervosa）的診斷條件中，暴食行為（binge eating）與不適當補償行為（compensatory behavior）的相關條件為：
  1. （A）過去三個月內，兩者都必須出現，頻率至少一個月一次
  2. （B）過去三個月內，至少兩者之一曾出現，頻率至少一個月一次
  3. （C）過去三個月內，兩者都必須出現，頻率至少一週一次
  4. （D）過去一個月內，至少兩者之一曾出現，頻率至少一週一次

答案：（C）

詳解與考點

考點為 DSM-5 暴食症（bulimia nervosa）的頻率與期程準則。暴食與不適當補償行為「兩者皆須」出現，且平均至少「每週一次、持續三個月」，故 C 正確。陷阱在頻率與期程的數字組合：A、D 把每週誤為每月（頻率太低），B 誤為「兩者之一」（應為兩者皆須）。需同時記住三個月、每週、兩行為並存三要件。

第 2 題

若從認知行為或人格因子來解釋飲食障礙症（eating disorders）的發生，下列何者是最不可能具有的特徵？
  1. （A）完美主義
  2. （B）高自尊
  3. （C）負向情緒高
  4. （D）對於身材與吃食具有注意力上的偏好

答案：（B）

詳解與考點

考點為飲食障礙的認知行為與人格危險因子。飲食障礙者常見完美主義、高負向情緒、對身材飲食的注意力偏好，這些是危險特徵。正解 B「高自尊」最不可能：患者多為低自尊，常以體重身材作為自我價值來源。陷阱在誤把完美主義聯想成自信高自尊，但臨床上恰是低自尊伴隨苛刻自我要求。

第 3 題

下列何種特定對象畏懼症（specific phobia）在面對所害怕的對象或情境時，所展現出的生理反應與其他恐懼症不同？
  1. （A）懼高症（acrophobia）
  2. （B）血液-注射-受傷恐懼症（blood-injection-injury phobia）
  3. （C）幽閉恐懼症（claustrophobia）
  4. （D）蜘蛛恐懼症（spider phobia）

答案：（B）

詳解與考點

考點為特定畏懼症的生理反應型態差異。多數畏懼症面對刺激時為交感神經激發（心跳血壓上升）；唯獨血液-注射-受傷型呈現獨特的「雙相」反應，先升後驟降造成血壓心跳下降而易暈厥（vasovagal）。故 B 正確。陷阱在懼高、幽閉、蜘蛛恐懼皆屬典型升高反應，與血液型的暈厥傾向明顯不同。

第 4 題

依據DSM-5，一位患有選擇性不語症（selective mutism）的個案，可能具有下列那些特質？①過度害羞②社交孤立③有強迫特質④輕度的對立行為
  1. （A）僅①②
  2. （B）僅①②④
  3. （C）僅③④
  4. （D）①②③④

答案：（D）

詳解與考點

考點為 DSM-5 選擇性不語症（selective mutism）的伴隨特質。其常與過度害羞、社交孤立退縮、強迫特質，以及輕度對立反抗行為並存，故四者皆可能，正解 D「①②③④」全包含。陷阱在易低估強迫特質或對立行為，而誤選僅①②；但 DSM-5 確實列出這些關聯特徵。

第 5 題

社交焦慮症的治療若要提升暴露治療的療效，除了要教導個案適切的社交行為，同時應該減少個案表現出：
  1. （A）眼神接觸（eye contact）
  2. （B）安全行為（safety behavior）
  3. （C）補償行為（compensatory behavior）
  4. （D）非語言行為（nonverbal behavior）

答案：（B）

詳解與考點

考點為社交焦慮症暴露治療的成效關鍵。提升暴露療效須減少個案的「安全行為（safety behavior）」，因安全行為會阻止個案真正核驗恐懼預期、維持焦慮，故正解 B。陷阱在 A 眼神接觸：減少眼神接觸本身是安全行為之一，治療反而要增進而非減少；C 補償行為屬飲食障礙概念，與此無關。

第 6 題

依據DSM-5，焦慮症中最不可能與物質相關及成癮障礙症（substance-related and addictive disorders）共病的是下列何者？
  1. （A）社交焦慮症（social anxiety disorder）
  2. （B）特定對象畏懼症（specific phobia）
  3. （C）特定場所畏懼症（agoraphobia）
  4. （D）廣泛性焦慮症（generalized anxiety disorder）

答案：（D）

詳解與考點

正解 D。本題問依 DSM-5「最不可能」與物質相關及成癮障礙症共病的焦慮症。社交焦慮症（A）常見以飲酒等物質來緩解社交情境的焦慮，與酒精／物質使用障礙共病率相對偏高；特定場所畏懼症（C）與廣泛性焦慮症的焦慮較為瀰漫，也常見以物質自我緩解。

相對地，特定對象畏懼症（B，specific phobia）的焦慮僅侷限於特定刺激（如動物、打針、高處），個案多可藉「迴避該特定對象」即可控制焦慮，較不需以長期物質使用來因應，因此與物質障礙的共病傾向通常較低。

惟本題官方標準答案為 D（廣泛性焦慮症），作答以官方答案為準；命題脈絡顯然依其採用之特定教材所列共病數據，將 GAD 視為四者中相對最不易共病者。本題各選項共病高低在不同文獻間有出入，把握度較低，以官方答案 D 為準。

第 7 題

有關廣泛性焦慮症（generalized anxiety disorder, GAD）的治療，下列敘述何者錯誤？
  1. （A）Benzodiazepine與抗憂鬱劑都是經常用來治療GAD的藥物
  2. （B）就短期治療效用來看，藥物與心理治療的療效差不多，但就長期治療效用來看，心理治療的療效有可能比藥物好
  3. （C）正念取向（mindfulness-based approach）心理治療可以幫助患者增加對憂慮與不確定（uncertainty）的容忍度
  4. （D）CBT治療不適合用在患有GAD的兒童身上

答案：（D）

詳解與考點

考點為廣泛性焦慮症（GAD）的治療實證。Benzodiazepine 與抗憂鬱劑常用於 GAD，長期看心理治療療效可能優於藥物，正念可提升對不確定的容忍度，A、B、C 皆正確。正解 D 為錯誤：CBT 同樣適用於兒童 GAD，並非不適合。陷阱在 D 以「兒童」設限製造例外感。

第 8 題

有關焦慮症（anxiety disorder）的心理與藥物治療，下列敘述何者正確？
  1. （A）抗憂鬱劑很少使用在焦慮症病患的治療上
  2. （B）實境暴露療法（in vivo exposure therapy）有助於減低特定畏懼症患者的恐懼
  3. （C）恐慌控制療法（panic control therapy）是藉由行為模範的原理，教導病患恐慌發作時向他人求助的策略
  4. （D）系統減敏感法（systematic desensitization therapy）的原則是要求病患直接面對他最畏懼的刺激並嘗試自主放鬆

答案：（B）

詳解與考點

考點為焦慮症心理與藥物治療的正確配對。實境暴露（in vivo exposure）確能有效降低特定畏懼症的恐懼，故 B 正確。陷阱在 A：抗憂鬱劑其實廣泛用於焦慮症；C：恐慌控制療法是處理對身體感覺的災難化解讀與內感暴露，非教人求助；D：系統減敏感是「漸進」配合放鬆而非「直接面對最畏懼刺激」（那是洪水法）。

第 9 題

對身體臆形症（body dysmorphic disorder）患者採用暴露及儀式行為防止法（exposure and response prevention）時，當患者暴露於最害怕的情境中，例如與可能評價他們長相的人互動，最需禁止患者進行下列何種儀式行為？
  1. （A）照鏡子確認自己的長相
  2. （B）詢問他人對自己長相的評價
  3. （C）使用客觀的語言描述自身長相
  4. （D）與個案討論以外貌建立自信

答案：（A）

詳解與考點

考點為身體臆形症（BDD）的暴露不反應法（ERP）。BDD 核心儀式是反覆照鏡子確認外貌以暫時緩解焦慮，暴露時最需禁止的正是「照鏡子確認」，故 A 正確。陷阱在 B 詢問他人評價也是常見儀式，但題目要的是「最需禁止」、與照鏡這一最核心的安全/檢查行為相比次之；C、D 屬治療策略非儀式。

第 10 題

依據Menzies等人（2008）的研究，下列何者所包含的三個腦部區域，與強迫症及相關障礙症的關聯性最強？
  1. （A）海馬迴（hippocampus）、尾核（caudate nucleus）、杏仁核（amygdala）
  2. （B）眼窩額葉皮質（orbitofrontal cortex）、杏仁核（amygdala）、前扣帶迴皮質（anterior cingulate cortex）
  3. （C）眼窩額葉皮質（orbitofrontal cortex）、尾核（caudate nucleus）、海馬迴（hippocampus）
  4. （D）眼窩額葉皮質（orbitofrontal cortex）、尾核（caudate nucleus）、前扣帶迴皮質（anterior cingulate cortex）

答案：（D）

詳解與考點

考點為強迫症及相關障礙的神經迴路（CSTC 皮質-紋狀體-視丘迴路）。依 Menzies 等人（2008），關聯最強的三區為眼窩額葉皮質、尾核、前扣帶迴皮質，故正解 D。陷阱在 B 含杏仁核、A/C 含海馬迴：杏仁核、海馬迴較與焦慮、記憶相關，並非此題迴路核心。屬特定文獻指定答案。

第 11 題

強迫症的強迫行為（compulsions）通常是受到什麼因素的驅使而產生？
  1. （A）為追尋刺激
  2. （B）因為對行為目標物的渴望
  3. （C）妄想內容的驅使
  4. （D）為降低焦慮或防止災難發生

答案：（D）

詳解與考點

考點為強迫行為（compulsions）的功能性動機。強迫行為是為降低強迫思考引發的焦慮、或防止某種災難發生而執行的儀式，具負增強性質，故 D 正確。陷阱在 A 追尋刺激（屬衝動/成癮性質）、C 妄想驅使（屬精神病性，OCD 患者多保有病識感）皆與強迫行為的減焦慮功能不同。

第 12 題

有關儲物症（hoarding disorder）與強迫症（obsessive-complusive disorder）的區辨，下列敘述何者最恰當？
  1. （A）若儲物行為是基於典型強迫思考的後果，較適合被診斷為強迫症而非儲物症
  2. （B）儲物症患者無法從儲物中獲得愉悅感，強迫症患者藉由強迫行為來自我滿足
  3. （C）兩者皆有保存物品的強烈衝動，會不斷地想要獲得更多的物品當作自我酬賞
  4. （D）儲物症的儲物類型通常較強迫症來得詭異，像是收集尿液、指甲或是人類毛髮

答案：（A）

詳解與考點

考點為儲物症與強迫症的鑑別。若囤積是源於典型強迫思考（如怕汙染而不敢丟）所致的後果，則應診斷為強迫症而非儲物症，故 A 最恰當。陷阱在 B：儲物症患者獲取與保存物品反而帶來愉悅或減焦慮；C：過度想獲取較屬儲物症特徵；D：詭異收集物（尿液毛髮）反較常見於 OCD 而非儲物症。

第 13 題

創傷後壓力症的臨床表徵具有發展上的變異性。對六歲以下的兒童而言，下列敘述何者錯誤？
  1. （A）反覆出現的惡夢必定包含創傷事件的特定內容
  2. （B）侵入性的創傷記憶不一定表現出痛苦且可能於玩耍時重演
  3. （C）不願意探索新環境可能與逃避反應有關
  4. （D）相較於認知變化，較容易觀察到情緒的負向改變

答案：（A）

詳解與考點

考點為六歲以下兒童 PTSD 的發展變異表現。DSM-5 指出幼兒惡夢內容「不一定」能辨識與創傷直接相關，故 A「必定包含特定創傷內容」為錯誤、即正解。B 創傷記憶可於遊戲中重演、C 不願探索新環境屬逃避、D 較易見情緒負向改變，皆為正確的幼兒變異描述。陷阱在 A 用「必定」絕對化。

第 14 題

急性壓力症中常會出現自發性的恐慌發作，下列何種情況較可能被診斷是恐慌症？
  1. （A）當恐慌發作與經驗到的創傷事件記憶有關
  2. （B）當恐慌發作是不可預期的，且會擔心未來再發作或發作後帶來的後果
  3. （C）當恐慌發作是可預期的，且會逃避與創傷事件相關的線索
  4. （D）當恐慌發作是可預期的，且會誇大創傷線索引發的生理反應

答案：（B）

詳解與考點

考點為恐慌症與創傷相關恐慌發作的鑑別。恐慌症的核心是「不可預期的」恐慌發作，並伴隨對未來再發作或後果的持續擔心（預期焦慮），故 B 正確。陷阱在 A、C、D：恐慌與創傷線索相關、或屬可預期的情境誘發者，較傾向診斷為 PTSD/急性壓力症而非恐慌症。關鍵在「不可預期」與「擔心再發」。

第 15 題

DSM-5關於創傷後壓力症（PTSD）的核心症狀，下列敘述何者較為正確？
  1. （A）會發展成壓力相關疾病（stress-related diseases）
  2. （B）當想到受創事件時會引發恐慌發作
  3. （C）會有對受創事件的再經驗（re-experiencing）反應
  4. （D）會產生憂鬱症

答案：（C）

詳解與考點

考點為 DSM-5 PTSD 的核心症狀群。PTSD 必有對創傷事件的「再經驗（re-experiencing）」反應，如侵入記憶、惡夢、閃回，故 C 最正確。陷阱在 A 壓力相關疾病、B 引發恐慌發作、D 產生憂鬱症：這些可能是後果或共病，但非 PTSD 的核心定義症狀。再經驗、迴避、過度警覺、負向認知情緒才是四大核心。

第 16 題

患者對於自己身體外觀過度關切，最有可能為下列何種診斷？
  1. （A）身體症狀障礙症
  2. （B）身體臆形症
  3. （C）罹病焦慮症
  4. （D）轉化症

答案：（B）

詳解與考點

考點為身體相關障礙症的鑑別。對「身體外觀」過度關切、認為外表有缺陷，最符合身體臆形症（BDD），故 B 正確。陷阱在 A 身體症狀障礙症（聚焦於身體症狀困擾）、C 罹病焦慮症（怕得重病）、D 轉化症（神經功能症狀）：三者關切的核心是疾病或症狀，而非「外觀長相」。關鍵字在「外觀」。

第 17 題

身體症狀障礙症患者，通常具有下列何種認知特徵？
  1. （A）具有正確的健康與疾病常識
  2. （B）堅信自己已罹患嚴重疾病
  3. （C）認為其生理症狀將造成立即的威脅
  4. （D）自動化聚焦於身體健康相關訊息上

答案：（D）

詳解與考點

考點為身體症狀障礙症的認知特徵。患者傾向自動化地將注意力聚焦於身體健康相關訊息上，對身體感覺過度警覺與災難化解讀，故 D 正確。陷阱在 B 堅信已罹重病、C 認為立即威脅：這較接近罹病焦慮症的認知；A 具正確疾病常識則與患者扭曲認知相反。關鍵在「注意力偏向」此一認知歷程描述。

第 18 題

下列何者不是治療解離性身份障礙症（dissociative identity disorder）的常見策略？
  1. （A）辨識會誘發解離反應的刺激
  2. （B）教導因應嚴重壓力的方法
  3. （C）找出最重要的人格屬性
  4. （D）協助當事人成為一個功能整合的人

答案：（C）

詳解與考點

考點為解離性身份障礙症（DID）的治療策略。常見策略包括辨識誘發解離的刺激、教導因應壓力、並協助當事人整合成功能統合的人。正解 C「找出最重要的人格屬性」並非治療目標：治療不在挑選或強化某一身份，而在整合各身份，故為非常見策略。陷阱在 C 看似在認識人格，實則違背整合方向。

第 19 題

下列何者是解離性身份障礙症（dissociative identity disorder, DID）被誤診為思覺失調症（schizophrenia）的常見原因？
  1. （A）兩者都可能出現聽幻覺的現象
  2. （B）兩者都可能有嚴重自我傷害的行為
  3. （C）診斷醫師通常不相信解離經驗的真實性
  4. （D）兩者都可能有嚴重物質濫用的情況

答案：（A）

詳解與考點

考點為 DID 與思覺失調症的誤診原因。兩者都可能出現聽幻覺（DID 常為內在說話的不同身份聲音），易被誤判為精神病性幻聽，故 A 正確。陷阱在 C 醫師不信解離真實性：這是診斷爭議而非「兩症共有症狀」造成的誤診原因；B 自傷、D 物質濫用並非區辨兩症的關鍵交集。題目問的是症狀重疊。

第 20 題

下列何者是血清素再回收抑制劑（selective serotonin reuptake inhibitors）會比其他抗憂鬱劑（三環抗憂鬱劑或單胺氧化酶抑制劑）更廣泛被使用的最主要原因？
  1. （A）價格較便宜
  2. （B）療效較佳
  3. （C）沒有成癮性
  4. （D）副作用較小

答案：（D）

詳解與考點

考點為 SSRI 相較舊型抗憂鬱劑（三環、MAOI）被廣用的主因。SSRI 最主要優勢是「副作用較小」、安全性高、過量風險低，故 D 正確。陷阱在 B 療效較佳：實證上 SSRI 療效與三環相當而非更佳，廣用關鍵在耐受性與安全而非效果；A 價格、C 成癮性並非主要區辨理由。

第 21 題

下列那一個憂鬱的心理治療取向，最不重視探討與改變個案面對現實生活壓力時的想法內容？
  1. （A）認知行為治療
  2. （B）理情行為治療
  3. （C）人際取向治療
  4. （D）正念為基礎的認知治療

答案：（D）

詳解與考點

考點為各憂鬱心理治療取向對「改變想法內容」的重視程度。正念為基礎的認知治療（MBCT）強調以非評價的覺察「改變與想法的關係」，而非直接辯駁或改變想法的內容，故最不重視想法內容，正解 D。陷阱在 A CBT、B 理情行為治療（REBT）皆以重整不合理想法內容為核心，與正念取向取徑明顯不同。

第 22 題

  1. （A）前額葉腹內側（ventromedial prefrontal cortex）活化程度高於前額葉背外側（dorsolateral prefrontal cortex）
  2. （B）前額葉腹內側活化程度低於前額葉背外側
  3. （C）左側半腦前額葉活化程度高於右側半腦前額葉
  4. （D）左側半腦前額葉活化程度低於右側半腦前額葉

答案：（D）

詳解與考點

考點為 Davidson 等人（2009）的前額葉活化不對稱假說。憂鬱與「左側前額葉活化低於右側」有關，左前額葉與趨近/正向情緒相關，其活化不足對應憂鬱的退縮，故正解 D。陷阱在 C 左高於右（方向相反），以及 A、B 腹內側對背外側的對比：題目指的是左右半腦不對稱，非腹背向不對稱。

第 23 題

根據Brown與Barlow（2009）的描述，鬱症（major depressive disorder）在正向情感（positive affect）與負向情感（negative affect）上較符合下列何項敘述？
  1. （A）高正向情感&高負向情感
  2. （B）高正向情感&低負向情感
  3. （C）低正向情感&高負向情感
  4. （D）低正向情感&低負向情感

答案：（C）

詳解與考點

考點為三向度模式（Clark & Watson；Brown & Barlow 2009）。鬱症的情感特徵為「低正向情感&高負向情感」，低正向情感是憂鬱的特異指標，高負向情感為焦慮憂鬱共有，故正解 C。陷阱在誤把憂鬱想成只有高負向情感而忽略其特有的低正向情感（失樂、興趣減退），導致漏掉「低正向」這一關鍵。

  1. （A）①②③
  2. （B）①③②
  3. （C）③①②
  4. （D）③②①

答案：（B）

詳解與考點

考點為 DSM-5 三類憂鬱症 12 個月盛行率高低排序。鬱症（約 7%）最高，經期前情緒低落症（約 1.8%～5.8%）次之，持續性憂鬱症（約 0.5%～1.5%）最低，故由高到低為①③②，正解 B。陷阱在持續性憂鬱症名稱聽來常見而高估其盛行率，實際 12 個月盛行率反低於經期前情緒低落症。

第 26 題

  2. （B）stimulus control：conditioning arousal
  3. （C）cognitive treatments：unrealistic expectations and beliefs about sleep
  4. （D）graduated extinction：attentional bias

答案：（D）

詳解與考點

考點為失眠認知行為治療（CBT-I）各策略與其對應改變標的的配對。漸進放鬆對應身體緊張、刺激控制對應制約性激發、認知治療對應對睡眠的不切實際期待信念，A、B、C 皆正確。正解 D 為錯誤配對：graduated extinction（漸進消弱）主要用於兒童行為性失眠處理就寢哭鬧，並非處理「注意力偏向」。

第 27 題

  2. （B）睡眠酩酊（sleep drunkeness）
  3. （C）睡眠麻痺（sleep paralysis）
  4. （D）猝倒（cataplexy）

答案：（D）

詳解與考點

考點為猝睡症（narcolepsy）四大症狀的辨識。情緒激動（如大笑）誘發的突發性肌肉張力喪失、癱軟倒地，正是猝倒（cataplexy），故 D 正確。陷阱在 C 睡眠麻痺：那是入睡或醒來之際短暫無法動彈、且發生於睡眠交界，與情緒誘發的清醒癱軟不同；A 睡眠發作是無法抗拒的入睡，亦非癱軟。

第 35 題

有關韌力（resilience）敘述，下列何項錯誤？
  1. （A）韌力反應出高自尊（self-esteem）、高控制感及高樂觀（optimism）傾向等三個概念
  2. （B）高韌力者和低韌力者在評估（appraisal）負向事件的壓力程度上並無差異，但高韌力者能感受到較多正向情緒
  3. （C）有宗教信仰（religious belief）是能促進韌力的資源之一
  4. （D）當面對慢性病的衝擊時，能認識到這些健康問題對自己是「有好有壞」的，正是一種韌力的表現

答案：（B）

詳解與考點

正解 B。本題問韌力（resilience）敘述何者「錯誤」。B 宣稱「高韌力者與低韌力者在評估負向事件的壓力程度上『並無差異』，僅高韌力者感受較多正向情緒」，此敘述錯誤：韌力高者在認知評估（appraisal）階段，傾向把負向事件知覺為較可控、威脅性較低、較具因應資源，因此「對負向事件壓力程度的評估本身即有差異」，而不僅是事後正向情緒較多，故 B 為錯誤敘述。

A 正確：韌力常以高自尊、高控制感、高樂觀三個面向來描述。

C 正確：宗教信仰可作為提升韌力的資源之一（提供意義感與社會支持）。

D 正確：面對慢性病能進行「好處尋找／利益發現（benefit finding）」、認知到「有好有壞」，正是韌力的展現。

第 38 題

下列與血管相關疾病有關之心理社會因素的敘述，何者最不恰當？
  1. （A）「憂鬱」是血壓上升的風險因子
  2. （B）「負向的社會互動」是高血壓的風險因子，特別對女性來說
  3. （C）「慢性壓力」是冠狀動脈心臟病的風險因子，因此高社經地位者較容易罹患冠心病
  4. （D）「表達憤怒」同時是高血壓、中風及冠狀動脈心臟病的風險因子

答案：（C）

詳解與考點

考點為心理社會因素與血管疾病。正解 C 為最不恰當：慢性壓力雖是冠心病風險因子，但承受較高慢性壓力、進而較易罹患冠心病的多為「低社經地位」者而非高社經，題目因果說反。A 憂鬱、B 負向社會互動（尤其對女性）、D 表達憤怒，皆為正確的風險敘述。陷阱在 C 把社經與冠心病的方向倒置。

第 39 題

根據閘門控制理論（gate-control theory），能夠用來關閉疼痛閘門（亦即抑制疼痛）的心理因素不包括下列何者？
  1. （A）參與並熱衷於日常活動
  2. （B）分散注意力
  3. （C）增加正向情緒
  4. （D）關注於疼痛

答案：（D）

詳解與考點

考點為疼痛的閘門控制理論（gate-control theory）。能「關閉」疼痛閘門以抑制疼痛的心理因素，包括投入日常活動、分散注意力、增加正向情緒。正解 D「關注於疼痛」反而會「開啟」閘門、放大疼痛感受，故不屬於關閉因素。陷阱在 D 看似與疼痛有關而誤選，但其作用方向與抑制相反。

第 40 題

Rudolf Moos提出危機理論（crisis theory）來說明罹患疾病（危機）的調適歷程，其認為影響適應結果的核心因素為何？
  1. （A）疾病相關因素
  2. （B）因應歷程
  3. （C）背景與個人因素
  4. （D）身體與社會環境因素

答案：（B）

詳解與考點

考點為 Rudolf Moos 危機理論（crisis theory）對疾病調適的核心。Moos 認為影響適應結果的核心關鍵是「因應歷程（coping process）」，疾病、背景個人、環境等因素皆透過因應評估與技巧而影響結果，故正解 B。陷阱在 A、C、D 屬影響因應的前置/背景變項，而非 Moos 模式中決定適應的核心中介。
