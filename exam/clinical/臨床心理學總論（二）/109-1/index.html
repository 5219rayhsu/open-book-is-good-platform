第 1 題

Garb（1994, 1998, 2005）與 Wedding & Faust（1989）對於如何改善臨床判斷有一系列的建議， 下列何者錯誤？
  1. （A）為了避免遺漏重要訊息，盡量使用非結構化的方式進行晤談
  2. （B）謹慎地根據 DSM 或 ICD 診斷系統的具體標準做判斷
  3. （C）不光只依賴記憶，而應盡可能參考仔細記下來的筆記
  4. （D）做預測時，考慮行為發生的基準率（base rate）

答案：（A）

詳解與考點

正解：題眼在「改善臨床判斷」與「何者錯誤」——判準是降低遺漏與認知偏誤的方法應提高資訊蒐集與決策的可檢核性。為避免遺漏重要訊息，應適度採用結構化或半結構化會談，而不是盡量使用非結構化方式，故 A 為應選項。

B：依 DSM 或 ICD 的具體標準做判斷，可減少以模糊印象下結論的風險，故正確。

C：參考詳細筆記能減少記憶偏誤並保留判斷依據，故非答案。

D：預測行為時納入基準率，可避免忽略事件本來發生機率的錯誤，故正確。

本題考點：結構化會談（structured interview）——提高重要訊息蒐集的一致性；操作型診斷標準（operational diagnostic criteria）——使判斷可檢核；基準率（base rate）——預測時不可忽略的先驗發生機率。

第 2 題

相較於其他衡鑑情境，臨床心理師在法務系統中執行心理衡鑑需要特別注意的事項為：
  1. （A）徵詢檢察官或法官，請其協助將衡鑑結果告知個案或家屬
  2. （B）強調心理測驗的計分、執行與解釋的精確性
  3. （C）精通相關病理的科學知識及操作型定義
  4. （D）熟悉法律用語的使用以及不同用語間細微的差別

答案：（D）

詳解與考點

正解：題眼在「法務系統」——判準是法務心理衡鑑除了一般衡鑑的科學與技術品質外，還必須讓結論能被法律程序正確理解與檢視。熟悉法律用語及其細微差別可避免心理概念與法律門檻錯置，故選 D。

A：衡鑑結果的說明、知後同意與保密界限應由心理師依委託關係與程序處理，不能把責任交由檢察官或法官代為告知。

B：計分、執行與解釋精確是所有心理衡鑑的基本要求，並非在法務系統中特別新增的核心差異。

C：精通相關病理與操作型定義同樣是一般臨床衡鑑的基礎；法務情境的特殊處在於還要把專業意見對接法律問題。

本題考點：法務心理衡鑑（forensic psychological assessment）——需界定委託問題與法律標準；法律語言（legal language）——須避免和臨床診斷語言混用；衡鑑品質——仍須維持測驗與推論的科學性。

第 3 題

若欲選取某單一測驗以從受災者中篩檢日後可能出現心理障礙症者，下列何項資訊最適合做為參考？
  1. （A）預測效度（predictive validity）
  2. （B）增益效度（incremental validity）
  3. （C）聚斂效度（convergent validity）
  4. （D）區辨效度（discriminant validity）

答案：（A）

詳解與考點

正解：題眼在「篩檢日後可能出現」——問的是一項現在施測的工具，能否預測未來心理障礙症結果；判準是效度證據必須跨越時間、以後續結果作效標。預測效度正檢驗測驗分數對未來結果的預測能力，故選 A。

B：增益效度是某工具在既有資訊或工具之外，能否額外提升預測或分類效果；題幹明定選取單一測驗，並未比較額外貢獻。

C：聚斂效度看同一或相近建構的不同測量是否相關，不能直接回答是否能預測日後障礙症。

D：區辨效度看工具是否未與不相干建構過度相關，也不是未來篩檢效果的直接指標。

本題考點：預測效度（predictive validity）——測驗預測未來效標的能力；增益效度（incremental validity）——相對既有資訊的額外價值；建構效度（construct validity）——可含聚斂與區辨效度。

第 4 題

臨床心理師解釋個案在標準化智力測驗的得分為高分時，需要考慮是否有弗林效應（Flynn effect），何謂弗林效應？
  1. （A）測驗的練習過多
  2. （B）受測的動機過強
  3. （C）測驗的常模過時
  4. （D）受測時的情緒高張

答案：（C）

詳解與考點

正解：題眼在「高分」與「弗林效應」——判準是智力測驗常模與群體表現會隨世代改變；若使用過時常模，受測者的分數可能被高估。弗林效應指群體智力測驗表現的世代變化，實務上提醒心理師檢查測驗常模是否過時，故選 C。

A：練習過多造成的分數提升是練習效應，並非弗林效應。

B：受測動機會影響當次表現，但不涉及不同世代常模的系統性差異。

D：情緒高張可能影響測驗作答，屬受測狀態因素，不是常模隨時間改變的現象。

本題考點：弗林效應（Flynn effect）——群體智力測驗表現的世代變化；常模（norms）——解釋分數時須考量其適用性與更新狀態；練習效應（practice effect）——重複施測造成的表現改變。

第 5 題

為使心理衡鑑的執行更為順暢，如何做最適當？
  1. （A）熟悉臨床衡鑑的各個階段，專注在與個案的互動
  2. （B）為了標準化程序，對每個個案都施測同一套衡鑑工具
  3. （C）提醒個案時間有限，盡快完成所有測驗和問卷
  4. （D）盡量使用封閉式問題詢問，簡略記載，以節省時間

答案：（A）

詳解與考點

正解：題眼在「使心理衡鑑的執行更為順暢」——判準是良好衡鑑須依轉介問題規劃階段與工具，同時維持足夠的會談互動以觀察個案狀態與建立合作。熟悉各階段並專注與個案互動最能兼顧流程與資料品質，故選 A。

B：標準化指每項工具依其規範施測，不是對所有個案一律使用同一套工具；衡鑑工具應依待答問題選擇。

C：以時間壓力催促個案完成全部測驗和問卷，可能損及表現品質與合作關係。

D：封閉式問題與簡略紀錄雖節省時間，卻可能漏失重要敘事與行為脈絡。這是最強誘答，因為它看似有效率；錯在把速度當作衡鑑品質的主要判準。

本題考點：心理衡鑑（psychological assessment）——依轉介問題整合會談、觀察與測驗；個別化選擇工具（case-based test selection）——不是一套工具套用所有個案；治療聯盟與合作（working alliance）——影響資料品質與施測順利度。

第 6 題

精神狀態檢查 （Mental Status Examination, MSE） 的會談中，定向感喪失最常發生在下列何面向？
  1. （A）對人的定向
  2. （B）對地點的定向
  3. （C）對時間的定向
  4. （D）對事物的定向

答案：（C）

詳解與考點

正解：題眼在精神狀態檢查的「定向感喪失最常發生」——判準是定向感通常依時間、地點、人物的順序受影響，其中時間定向最易先出現困難。對時間的定向最常喪失，故選 C。

A：對人的定向通常較能保留，往往在定向障礙較嚴重時才受損，故非答案。

B：對地點的定向可受影響，但一般比時間定向較晚或較不常先出現。

D：精神狀態檢查的定向感慣例主要評估時間、地點與人物；「對事物」不是此題所指的標準定向面向。

本題考點：精神狀態檢查（Mental Status Examination, MSE）——系統性觀察認知與精神狀態；定向感（orientation）——常評估時間、地點與人物；時間定向（time orientation）——定向障礙中常最先受影響。

第 7 題

行為觀察中，依個案口語表達所得知的訊息，下列敘述何者錯誤？
  1. （A）談話速度快速可能與情緒高亢有關
  2. （B）假哲學（pseudophilosophical）的表達風格，是指說話常不合邏輯
  3. （C）有信心者的聲音常宏亮有力
  4. （D）思考型態會明顯影響到說話內容的組織方式

答案：（B）

詳解與考點

正解：題眼在「假哲學」與「何者錯誤」——判準是此種表達強調不必要的抽象、術語化或貌似深奧，並不等同於思考邏輯不合。把假哲學直接界定為「說話常不合邏輯」混淆了抽象化表達與形式思考障礙，故 B 為應選項。

A：談話速度快速可見於情緒高亢或躁症狀態，是行為觀察可記錄並納入判斷的線索。

C：聲音宏亮有力可能反映自信或高度喚起，但仍須配合情境與其他行為觀察解讀，故非答案。

D：思考型態會影響說話內容的連貫、組織與表達形式，故正確。

本題考點：假哲學式表達（pseudophilosophical speech）——以過度抽象或術語化製造深奧感；形式思考障礙（formal thought disorder）——涉及思考連貫與邏輯組織；行為觀察（behavioral observation）——單一線索須結合脈絡解釋。

第 8 題

有關主題統覺測驗（TAT），下列何者正確？
  1. （A）採用因素分析法進行測驗編製
  2. （B）TAT 所獲得的資料相當豐富，可單以 TAT 進行診斷
  3. （C）假設個人所編的故事反映其潛在的內在需求
  4. （D）計分方式客觀，且具有良好的評分者間信度

答案：（C）

詳解與考點

正解：題眼在「主題統覺測驗」——判準是投射技術以受測者對模糊刺激所編造的故事，作為理解其主觀世界、內在需求與人際主題的素材。TAT 的基本假設正是故事可能反映潛在內在需求，故選 C。

A：TAT 是投射測驗，並非以因素分析法建立的客觀量表。

B：TAT 可提供豐富質性資料，但不能單憑一項投射測驗做出診斷，必須與會談、觀察及其他衡鑑資料整合。這是最強誘答，因為資料豐富不等於診斷效度足以單獨決策。

D：TAT 的詮釋與計分常受系統與評分者影響，不能概括說其計分客觀且一律具有良好評分者間信度。

本題考點：主題統覺測驗（Thematic Apperception Test, TAT）——以敘事探查主觀需求與人際主題；投射測驗（projective test）——資料解釋須重視系統化與限制；多方法衡鑑（multimethod assessment）——不能以單一工具取代整合判斷。

第 9 題

有關臨床心理測驗的信度概念，下列敘述何者正確？
  1. （A）心理建構大多可直接測量
  2. （B）心理測驗的測量是精確的
  3. （C）用於個人臨床決策的工具，理想上信度係數至少為.70
  4. （D）信度的目的是估算測驗誤差造成的變異程度

答案：（D）

詳解與考點

正解：題眼在「信度概念」——判準是信度處理測量結果的穩定與一致程度，藉以估計觀察分數中由測量誤差造成的變異。D 正確指出信度的目的，故選 D。

A：心理建構如智力、憂鬱或人格特質多須透過指標間接推論，不能大多直接測量。

B：心理測驗含有測量誤差，不能說測量是精確無誤的。

C：用於個人臨床決策時，所需信度通常應比群體研究的基本要求更嚴格，一般要求信度係數達 .90 以上；以 .70 作為理想門檻過於寬鬆。

本題考點：信度（reliability）——測量結果的一致性與穩定性；測量誤差（measurement error）——觀察分數中非真實差異的來源；臨床決策——須依工具用途審慎評估信度。

第 10 題

關於心理衡鑑報告的行為觀察紀錄，下列敘述何者錯誤？
  1. （A）個案的穿著打扮不需要列入觀察項目
  2. （B）個案如果在測驗過程中打瞌睡，要考量影響其精神狀態的各種可能，並加以詢問與記錄
  3. （C）要記錄的不只是行為是否出現，還應包含發生的時間、頻率及強度
  4. （D）關於行為觀察的描述，要留意使用的文字是否能夠讓閱讀者理解

答案：（A）

詳解與考點

正解：題眼在行為觀察紀錄的「何者錯誤」——判準是凡可能影響個案精神狀態、測驗表現或臨床印象的可觀察資料，都應依其相關性客觀記錄。穿著打扮可能提供自我照顧、情境適切性等線索，不能一概排除，故 A 為應選項。

B：測驗中打瞌睡可能與睡眠、藥物、身心狀態或疲勞有關，應詢問並記錄，以利解讀結果。

C：紀錄時間、頻率與強度，能把「有沒有出現」轉為可供判斷的行為脈絡，故正確。

D：描述需讓後續閱讀者理解觀察內容，故應使用清楚、具體的文字。

本題考點：行為觀察紀錄（behavioral observation record）——記錄與衡鑑問題相關的外觀、行為與互動；客觀描述（objective description）——包含時間、頻率與強度；測驗效度（test validity）——受測狀態可能影響分數解釋。

第 11 題

有效的心理衡鑑需要有良好的資料收集和解釋判斷。根據心理學研究，對人的知覺準確性可能與 下列何者為負向相關？
  1. （A）智力水準
  2. （B）情緒調節能力
  3. （C）權威性格
  4. （D）對藝術的興趣

答案：（C）

詳解與考點

正解：題眼在「對人的知覺準確性」與「負向相關」——判準是能否開放接收與修正關於他人的訊息。權威性格傾向僵化地依權威與既定分類看待人，較不利於細緻、可修正的人際知覺，因此與準確性呈負向相關，故選 C。

A：智力可能有助於處理複雜社會資訊，題目並未把它列為與人際知覺準確性負向相關的特質。

B：情緒調節較好通常有助於在互動中不被強烈情緒淹沒，並非題意所指的負向因素。

D：對藝術的興趣可能與感受性或觀察經驗有關，不能據此推成負向關係。

本題考點：人際知覺準確性（interpersonal perception accuracy）——正確理解他人線索的能力；權威性格（authoritarian personality）——僵化分類與服從權威的傾向；認知彈性（cognitive flexibility）——有助於修正初步印象。

第 12 題

依據柯永河（2001），下列何項自我訓練方式較無法提升臨床敏感度（clinical sensitivity）？
  1. （A）常自問：「現在我看到或聽到什麼？」
  2. （B）常自問：「就診斷觀點而言，我所看到的這件事情有什麼意義？」
  3. （C）常自問：「我與個案到底該保持何種關係？」
  4. （D）常自問：「從人格理論的觀點而言，個案的行為表現是屬於那一種人格組型？」

答案：（C）

詳解與考點

正解：題眼在「較無法提升臨床敏感度」——判準是臨床敏感度的自我訓練先維持對當下可觀察資料的覺察，再形成可檢驗的診斷或理論假設。反覆問自己與個案該保持何種關係，主要聚焦專業關係與界線，並非直接訓練對臨床線索的察覺與意義判讀，故選 C。

A：自問目前看到或聽到什麼，能把注意力放在具體可觀察的資料上，是敏感度訓練的基礎。

B：從診斷觀點思考一項觀察的意義，有助於把資料轉成可檢驗的臨床假設。

D：從人格理論理解行為組型，雖不可僵化貼標籤，但作為反思假設可增進對行為模式的辨識，故非答案。

本題考點：臨床敏感度（clinical sensitivity）——覺察並辨識臨床重要線索的能力；假設形成（hypothesis generation）——把觀察連結至可檢驗的解釋；專業界線（professional boundaries）——重要但不是本題所問的敏感度核心訓練。

第 13 題

關於代表性偏誤（representative bias），下列敘述何者正確？
  1. （A）也可稱之為「代表性捷思法（representativeness heuristic）」
  2. （B）意指「最容易得取的資料，影響衡鑑決策的判斷」
  3. （C）意指「評估者高估了某種已知診斷的發生機率」
  4. （D）主要包含初始偏誤（primacy bias）與新近偏誤（recency bias）

答案：（A）

詳解與考點

正解：題眼在「代表性偏誤」——判準是評估者以個案看起來多像某一典型類別，作為快速判斷機率的捷思，而可能忽略基準率與個別證據。這正是代表性捷思法，故選 A。

B：最容易取得的資料影響判斷，描述的是可得性捷思法（availability heuristic），不是代表性捷思法。

C：高估已知診斷的發生機率較接近基準率使用失當或診斷偏誤，並非代表性捷思法的定義。它是強誘答，因為代表性捷思確實可能造成機率判斷錯誤；分辨關鍵在於其錯誤來源是「像不像典型」，不是單純高估發生率。

D：初始偏誤與新近偏誤是資訊順序影響判斷的現象，不構成代表性偏誤的主要內容。

本題考點：代表性捷思法（representativeness heuristic）——以典型相似度快速推論類別或機率；可得性捷思法（availability heuristic）——以資訊提取容易度判斷；基準率忽略（base-rate neglect）——忽略事件原本發生機率的偏誤。

第 14 題

在心理衡鑑資料整合的過程中，臨床工作者應同樣謹慎檢視支持與反對假設的資料證據，才可能 減少何種臨床判斷的偏誤？
  1. （A）確認偏誤（confirmatory bias）
  2. （B）行動偏誤（action bias）
  3. （C）故事偏誤（story bias）
  4. （D）自利偏誤（self-serving bias）

答案：（A）

詳解與考點

正解：題眼在「同樣謹慎檢視支持與反對假設的資料」——判準是是否主動搜尋能推翻初步假設的證據。確認偏誤是只注意或過度重視支持既有信念的資訊；同時檢視反證可降低這種選擇性蒐證與解釋，故選 A。

本題考點：確認偏誤（confirmation bias）——主動尋找反證以檢驗假設；心理衡鑑資料整合（clinical data integration）——支持與反對證據均須納入；可否證性（falsifiability）——結論應容許被資料挑戰。

  4. （D）常模需為常態分佈

正解：題眼在 DSM-5、神經認知類障礙症與「錯誤」——判準是認知衡鑑工具應具標準化程序與適切比較基準，並非其常模分數必須呈常態分佈。常模的功能在反映適當參照族群；其分佈可因構念與計分方式而不同，故 D 為錯誤敘述，應選 D。本題依題幹所指 DSM-5 的衡鑑原則作答，未延伸至版本外的準則細節。

第 17 題

  1. （A）失語症是語言表現相較於智能基準，成等比例下降
  2. （B）失語症是語言符號的利用與詮釋發生缺損
  3. （C）言語失用症（apraxia of speech）涉及語音共鳴、力量與協調的缺損
  4. （D）言語失用症是周邊與中樞神經系統的病理缺損

答案：（B）

詳解與考點

正解：題眼在「語言符號的利用與詮釋」——判準是失語症損害的是語言系統本身，包括理解、命名、複誦、閱讀或書寫等符號處理功能。B 正確描述失語症，故選 B。

A：失語症不是隨整體智能等比例下降；其特徵正是語言功能可相對於其他認知能力出現不成比例的缺損。

C：語音共鳴、力量與協調的缺損較符合構音障礙（dysarthria）。言語失用症的核心是言語動作的計畫與程式編排困難。

D：此敘述混淆言語失用症與構音障礙的病理層次；言語失用症主要與中樞神經系統受損相關，不以周邊與中樞病理並列界定。

本題考點：失語症（aphasia）——語言符號理解與表達的缺損；言語失用症（apraxia of speech）——言語動作計畫困難；構音障礙（dysarthria）——肌力、協調或控制造成的言語執行問題。

正解：題眼在「何者錯誤」與「療效指標均相同」——判準是不同心理治療取向雖可共同促進福祉，治療目標、改變機制與成效指標未必一致。把所有取向說成使用相同療效指標過度概括，故 D 為應選項。

第 22 題

關於完形治療中個案抗拒接觸（resistances to contact）的形式，下列解釋何者錯誤？
  1. （A）解離（deflection）：指個案把部分自我屏除的特質丟給外在對象
  2. （B）內攝（introjection）：指不加思索、未經消化，就接受他人的信念與標準
  3. （C）迴攝（retroflection）：指個案把想要對別人做的事情，轉回對自己做
  4. （D）混淆（confluence）：指個案無法區分自己與環境的界線

答案：（A）

詳解與考點

正解：題眼在完形治療的「抗拒接觸」與「錯誤」——判準是各名詞描述個案如何中斷自己與環境的接觸。把自己不承認的特質歸給外在對象是投射（projection），不是解離（deflection）；A 將概念對調，故為應選項。

B：內攝是未經檢驗或消化便接受他人的信念、規範與標準，敘述正確。

C：迴攝是把原本想向外表達的行動或情感轉向自己，例如把怒氣壓回自己身上，故非答案。

D：混淆指個體與他人或環境的界線不清，難以辨識自己的需要與感受，敘述正確。

本題考點：完形治療（Gestalt therapy）——促進當下覺察與完整接觸；投射（projection）——將不被接納的自身部分歸於他人；解離／轉移話題（deflection）——以迴避方式削弱接觸。

  2. （B）治療師在首次晤談會從個案陳述中進行評估與診斷
  3. （C）治療師的角色重點在本身的態度，而非知識技巧

第 34 題

  2. （B）心理師先與督導討論後，才能決定是否可與之分享
  3. （C）建議張太太直接與其先生討論
  4. （D）改由同事出面拒絕張太太的要求

答案：（C）

詳解與考點

正解：題眼在「從王心理師口中了解先生目前的困擾」——判準是保密義務與揭露治療關係的知後同意。即使張太太的推測正確，心理師也不能向未獲個案授權的配偶確認個案是否接受服務，更不能談論困擾內容；較適切的是（C）建議張太太直接與其先生討論，讓資訊是否揭露回到個案本人決定，故選 C。

本題考點：保密義務（confidentiality）——未經個案知後同意，不確認亦不揭露其接受服務與內容；知後同意（informed consent）——資訊是否對家屬分享由個案決定；專業回應——可引導家屬直接與個案溝通。

  4. （D）Cohen’s kappa

答案：（D）

詳解與考點

正解：題眼在「內部一致性」——判準是指標是否以同一測驗內各題項之間的同質性估計信度。（D）Cohen’s kappa 衡量的是評分者或分類結果間扣除偶然一致後的一致程度，屬評分者間一致性，不是內部一致性指標，故選 D。

A：折半信度（split-half reliability）把同一測驗題目分為兩半，再檢視兩半分數的一致性，是內部一致性的一種估計。

B：題項平均相關（average inter-item correlation）直接檢視各題項彼此的相關，正是在評估題項是否共同測量同一構念。

C：Cronbach’s alpha 由題項間共變異推估量表內部一致性，是最常見的內部一致性係數。

本題考點：內部一致性（internal consistency）——看同一量表題項是否同質；折半信度（split-half reliability）與 Cronbach’s alpha——皆屬內部一致性估計；評分者間信度（inter-rater reliability）——常以 Cohen’s kappa 表示，切面不同。

第 38 題

某研究團隊利用後設分析（meta-analysis）來探討認知功能上之「用進廢退」假說與阿茲海默症 的關聯性。該研究使用明確的篩選標準共整合了 22 個研究，得到的結果是有高認知活動者與較 低的失智症發生風險有關，其勝算比（odds ratio）為 0.54，95%信賴區間為 0.49 至 0.59。下列敘 述何者錯誤？
  1. （A）使用明確的篩選標準，可避免後設分析常被批評之「納入太多品質較差的研究」的問題
  2. （B）後設分析在統計上需要有一共通尺度（common scale），該研究所使用的是勝算比
  3. （C）該研究結果指出相較於低認知活動者，高認知活動者發生失智症的機率減少 54%
  4. （D）該後設分析研究無法提供證據證明低認知活動是造成阿茲海默症的原因

答案：（C）

詳解與考點

正解：題眼在「勝算比 0.54」及「何者錯誤」——判準是勝算比相對於 1 的意義。高認知活動組的失智症發生勝算為低活動組的 0.54 倍；相對降低量為 1−0.54=0.46，也就是降低 46%，不是降低 54%，故（C）為應選項。95% 信賴區間為 0.49 至 0.59，未跨過 1，與保護性關聯一致。

A：後設分析預先採用明確納入與排除標準，可降低任意混入品質不佳研究的風險；研究品質仍須另行評讀，故非答案。

B：整合不同研究時需要可比較的效果量；題幹明示本研究採用勝算比，符合後設分析的共通尺度概念。

D：觀察到低認知活動與失智症風險相關，不能單憑此後設分析確定因果方向或排除混淆因子，故非答案。這是最強誘答，因為效果量與因果結論常被混為一談；後設整合可增加關聯估計精確度，不會自動把相關變成因果。

本題考點：勝算比（odds ratio）——0.54 倍代表相對降低 46%；信賴區間（confidence interval）——區間未跨 1 支持關聯方向；後設分析（meta-analysis）——整合效果量，仍須區分相關與因果。

第 39 題

有關相關係數及其統計顯著性，下列敘述何者正確？
  1. （A）研究樣本愈大，達到統計顯著所需的相關係數愈大
  2. （B）相關係數通常以 r 表示，介於 0 至 1 之間
  3. （C）相關係數的統計顯著性，會受到兩變項之間關係大小的影響
  4. （D）研究樣本大小不會影響相關係數的統計顯著性

答案：（C）

詳解與考點

正解：題眼在「相關係數及其統計顯著性」——判準是相關強度與樣本數共同決定檢定結果。兩變項的關係愈強，相關係數絕對值通常愈大，愈可能達統計顯著；因此（C）正確，故選 C。

A：樣本愈大，標準誤通常愈小，同一顯著水準下反而可檢出較小的相關係數，方向講反了。

B：Pearson 相關係數通常以 r 表示，但範圍是 −1 至 1，不是 0 至 1；負值表示反向線性關係。

D：樣本大小會影響相關係數的統計顯著性；小樣本即使相關看來不小，也可能因估計不精確而未達顯著。

本題考點：相關係數（correlation coefficient）——範圍為 −1 至 1；統計顯著性（statistical significance）——受效果大小與樣本數影響；標準誤（standard error）——樣本增加時通常下降。

第 40 題

使用心理測驗評估心理治療效果，下列敘述何者錯誤？
  1. （A）可以收集不同個案資料來檢驗治療取向之有效性
  2. （B）可用來檢驗治療效果的穩定度
  3. （C）可以預測個案症狀再度復發的時間
  4. （D）有助於療效機制的了解

答案：（C）

詳解與考點

正解：題眼在「使用心理測驗評估心理治療效果」與「何者錯誤」——判準是重複測量能呈現治療前後及追蹤時點的症狀改變，卻不能單憑一次或一般療效評估預測個別個案何時復發。（C）把成效檢核誤當成復發時間的精確預測，故為應選項。

A：彙集多位個案的測驗資料，並以適當設計比較不同處遇，可檢驗治療取向的有效性，故非答案。

B：在不同時間點施測可觀察改善是否維持，能檢驗治療效果的穩定度。

D：若結合症狀、認知或歷程指標的改變，可協助理解哪些變化可能與療效有關；這是機制研究的資料來源之一。這是最強誘答，因為測驗改變本身不等於機制已被證明，仍須以合適研究設計檢驗。

本題考點：療效評估（treatment outcome assessment）——比較治療前後與追蹤變化；穩定度（stability）——看效果是否維持；治療機制（mechanism of change）——需由歷程資料與研究設計加以檢驗。
