  2. （B）相關係數通常以 r 表示，介於 0 至 1 之間
  3. （C）相關係數的統計顯著性，會受到兩變項之間關係大小的影響
  4. （D）研究樣本大小不會影響相關係數的統計顯著性

答案：（C）
