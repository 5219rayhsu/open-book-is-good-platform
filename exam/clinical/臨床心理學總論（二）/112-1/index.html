第 1 題

下列何者是臨床心理衡鑑最主要的目標？
  1. （A）與個案建立良好醫病關係
  2. （B）暸解及評估個案性格與能力
  3. （C）同理與支持個案所遇到的問題
  4. （D）幫助個案解決問題與協助作決定

答案：（D）

詳解與考點

考點為臨床心理衡鑑的主要目標。衡鑑最終目的是協助個案解決問題與作決定（提供決策參考），故 D 為主要目標。陷阱為 A 醫病關係、C 同理支持，這些是衡鑑或治療過程中的要素而非衡鑑「最主要目標」；B 了解性格與能力是手段而非終極目的，易誤選為標準答案。

第 2 題

關於心理衡鑑之「心理計量取向（psychometric approach）」的敘述，下列何者錯誤？
  1. （A）是資料導向（data-oriented）的評估方式，強調以客觀的測驗分數描述個人的能力或特質
  2. （B）當評估的目的涉及快速將大量的受測者進行分類或篩選時，心理計量取向是有用的策略
  3. （C）對於測驗分數的解釋較少考量個體所在的生活脈絡或情境因素
  4. （D）最大優點是客觀，可以減少晤談者的偏誤，因此可精準的評估較為複雜的人格特質或因應模式

答案：（D）

詳解與考點

考點為心理計量取向（psychometric approach）的特性。要選錯誤者。心理計量取向以客觀分數、標準化見長，但對於複雜人格特質或因應模式的精準評估其實有限（需脈絡與質性補充），D 過度宣稱故為答案。A、B、C 描述其資料導向、篩選分類有用、較少考量脈絡，皆正確。

第 3 題

關於羅夏克墨漬測驗Exner's Comprehensive System的詢問階段，下列敘述何者正確？
  1. （A）只要受試者說「毛毛的」，決定因子即可記錄為T（shading-texture）
  2. （B）如果受試者說：「就和前一個反應看的方法一樣」時，可不需要加以澄清
  3. （C）如果受試者並未說出「一對」的說明，需要再詢問「是看到一個還是兩個？」
  4. （D）如果受試者在詢問階段出現新的反應，不應列入計分

答案：（D）

詳解與考點

考點為羅夏克 Exner 綜合系統的詢問（inquiry）階段計分規則。詢問階段新出現的反應不列入計分（僅原反應階段的反應計分），故 D 正確。陷阱為 A，只說「毛毛的」不足以直接記為材質 T，需確認是否為觸感決定因子；B、C 對澄清與成對反應的處理描述也不符標準程序。

第 4 題

下列那一類信度有助於減少學習移轉效應（carryover effect）？
  1. （A）內部一致性信度
  2. （B）再測信度
  3. （C）庫李（Kuder-Richardson）信度
  4. （D）複本信度

答案：（D）

詳解與考點

考點為信度類型與學習移轉（carryover）效應。複本信度使用內容等值但題目不同的兩份測驗，可降低受試者因記得前次題目而產生的練習或移轉效應，故 D 正確。陷阱為 B 再測信度，因兩次用同一份測驗，反而最容易受 carryover 影響；A、C 屬內部一致性，與跨時間移轉議題不同。

第 5 題

關於使用電腦測驗輔助心理衡鑑的好處，下列何者錯誤？
  1. （A）節省專業人員的時間
  2. （B）改善再測信度
  3. （C）電腦測驗結果可作為診斷
  4. （D）降低主試者偏差

答案：（C）

詳解與考點

考點為電腦輔助心理測驗的優缺點。要選錯誤者。電腦測驗結果僅是資料蒐集與計分工具，診斷須由臨床心理師整合判斷，不能逕作為診斷，故 C 錯誤為答案。A 省時、B 改善再測信度（標準化施測）、D 降低主試者偏差，皆為電腦化的合理優點。陷阱在誤把客觀計分等同於可直接下診斷。

第 6 題

關於腦部心智功能篩選測驗，下列敘述何者錯誤？
  1. （A）簡式心智檢查（Mini-Mental State Examination, MMSE）可用來篩檢認知功能障礙
  2. （B）雷－歐式複雜圖形測驗（Rey-Osterrieth Complex Figure Test）可用來篩檢視覺建構功能異常
  3. （C）史楚普作業（Stroop task）可用來篩檢語言功能障礙
  4. （D）雷氏聽覺語文學習測驗（Rey Auditory Verbal Learning Test）可用來篩檢語文記憶異常

答案：（C）

詳解與考點

考點為神經心理篩選測驗的功能對應。要選錯誤者。史楚普作業（Stroop）測量的是選擇性注意與抑制控制等執行功能，而非語言功能障礙，故 C 錯誤為答案。MMSE 篩認知、Rey-O 複雜圖測視覺建構、RAVLT 測語文記憶，配對皆正確。陷阱在 Stroop 涉及字詞唸名，易誤連到語言功能。

第 7 題

關於Symptom Checklist-90-R（SCL-90-R），下列敘述何者正確？
  1. （A）由臨床專業人員以結構化晤談施測
  2. （B）評估個案過去半年內各種症狀的程度
  3. （C）評估結果可作為診斷之用
  4. （D）Brief Symptom Inventory（BSI）是它的簡版

答案：（D）

詳解與考點

考點為 SCL-90-R 自陳症狀量表的性質。BSI（Brief Symptom Inventory）正是 SCL-90-R 的簡版，故 D 正確。陷阱為 A，SCL-90-R 是自陳式而非結構化晤談；B 評估期間通常為近一週（非半年）；C 結果僅供症狀程度參考，不能逕作診斷。誤選多因不熟其施測方式與時間窗。

第 8 題

關於魏氏成人智力測驗第四版（WAIS-IV）的解釋方式，下列敘述何者錯誤？
  1. （A）當指數分數間的變異大，全量表智商的意義度變低
  2. （B）建議使用連續階層式的歷程來討論受試者的表現
  3. （C）最好使用日常的語言來說明，儘可能減少專業術語
  4. （D）只有在指數分數內之分測驗間差距大於5分時，該指數分數才有意義

答案：（D）

詳解與考點

考點為 WAIS-IV 解釋原則。要選錯誤者。指數分數內各分測驗差距大於 5 分該指數才有意義的說法為杜撰的硬性門檻，並非標準解釋規則，故 D 錯誤為答案。A 指數變異大則全量表智商意義降低、B 採階層歷程討論、C 用日常語言說明，皆為正確的解釋準則。陷阱在 D 給出看似精確的數字。

第 9 題

下列的表格記錄方式屬於何種行為觀察記錄法？
  1. （A）多重基準線記錄法
  2. （B）對照記錄法
  3. （C）事件記錄法
  4. （D）評比記錄法

答案：（C）

詳解與考點

考點為行為觀察記錄法的類型。依題目表格逐次記錄特定目標行為發生的次數，屬事件記錄法（event recording），故 C 正確。陷阱為 A 多重基準線（屬單一受試實驗設計）、D 評比記錄法（以等級量尺評定程度），與單純計次的事件記錄不同，易混淆。標 med，因需配合原圖表。

第 10 題

關於心理衡鑑報告提供回饋的準則，下列敘述何者錯誤？
  1. （A）可告訴個案心理衡鑑的基本概念與原理
  2. （B）強調病理比強調個案的適應能力重要
  3. （C）儘量以個案可以理解的語言與文字來呈現
  4. （D）可以建議未來處遇方向

答案：（B）

詳解與考點

考點為心理衡鑑回饋準則。要選錯誤者。良好回饋應平衡呈現病理與個案的適應能力與優勢，而非強調病理比適應能力重要，故 B 錯誤為答案。A 說明衡鑑概念、C 用個案可理解的語言、D 建議處遇方向，皆為適切準則。陷阱在 B 看似專業，實則違反正向、平衡回饋的倫理精神。

第 11 題

下列何者不是心理衡鑑的主要轉介目的？
  1. （A）智力評估
  2. （B）提供鑑別診斷的相關資訊
  3. （C）提供心理治療的建議
  4. （D）判定行為是否違法

答案：（D）

詳解與考點

考點為心理衡鑑的主要轉介目的。要選不是者。判定行為是否違法屬司法與法律裁定範疇，非心理衡鑑的核心轉介目的，故 D 為答案。A 智力評估、B 鑑別診斷資訊、C 治療建議，皆為衡鑑常見轉介目的。陷阱在司法心理鑑定雖相關，但「判定違法」是法官職權，心理師僅提供評估資訊。

第 12 題

Wright（2010）提出整合心理衡鑑資料，以完成個案概念化的四種模式，下列敘述何者錯誤？
  1. （A）發展模式（Developmental Model）強調個案的問題常導因於本身功能與環境要求間的落差
  2. （B）共通功能模式（Common Function Model）強調症狀或問題是為了達成某種功能的目的而產生
  3. （C）特異質－壓力模式（Diathesis-Stress Model）強調個體的內外在因素交互影響，不適合用心理動力學派的觀點來分析整合
  4. （D）複雜模式（Complex Model）是其他不同模式的混合版本，強調應運用不同模式的觀點，來分析個案問題的複雜度

答案：（C）

詳解與考點

考點依 Wright（2010）個案概念化四模式。要選錯誤者。特異質－壓力模式（Diathesis-Stress）強調內外在因素交互，仍可結合心理動力等多種觀點分析，敘述稱「不適合用心理動力觀點」屬誤述，故 C 為答案。A 發展模式、B 共通功能模式、D 複雜模式的描述皆正確。標 med，依特定教材。

第 13 題

當心理衡鑑目的為情緒功能與情緒症狀評估時，下列何種測驗被選擇的可能性最低？
  1. （A）簡式症狀量表（Brief Symptom Inventory）
  2. （B）羅夏克墨漬測驗（Rorschach Inkblot Test）
  3. （C）人格衡鑑量表（Personality Assessment Inventory）
  4. （D）Rey-Osterrieth複雜圖形測驗（Rey-Osterrieth Complex Figure Test）

答案：（D）

詳解與考點

考點為情緒功能評估的測驗選擇。要選可能性最低者。Rey-Osterrieth 複雜圖形測驗主要評估視覺建構與視覺記憶，屬神經心理範疇，與情緒功能評估最不相干，故 D 為答案。BSI、羅夏克、PAI 皆能提供情緒症狀或人格情緒面向資訊。陷阱在四者皆為常見測驗，須辨其測量向度。

第 14 題

在心理衡鑑報告中，下列何者不是逐一呈現各測驗結果與解釋的作法之缺點？
  1. （A）無法讓讀者瞭解推論的依據
  2. （B）反映臨床工作者未能整合資料
  3. （C）讀者對此作法的反應普遍不佳
  4. （D）強化評估者是施測技術員的形象

答案：（A）

詳解與考點

考點為衡鑑報告「逐一呈現各測驗結果」作法的缺點。要選不是缺點者。此作法的問題在於未整合、像技術員、讀者反應不佳，但它仍逐項列出推論依據，故「無法讓讀者瞭解推論依據」不是其缺點，A 為答案。B、C、D 皆為公認缺點。陷阱在題幹為反向題，須注意問的是「不是缺點」。

第 15 題

有些個案會為了獲得個人利益而詐病，下列何種問題最可能被個案過度誇大他的困難？
  1. （A）智力問題
  2. （B）記憶問題
  3. （C）人際問題
  4. （D）注意力問題

答案：（B）

詳解與考點

考點為詐病（malingering）的症狀誇大型態。為獲取利益而詐病者最常過度誇大記憶問題（如記憶喪失、失憶），因其主觀、難客觀驗證，故 B 最可能被過度誇大為答案。陷阱為 A 智力、D 注意力，這些有標準化測驗與效度指標較易辨識；記憶詐病則是臨床上最常見的誇大標的。

第 16 題

當接受正在進行心理治療個案的心理評估時，下列何者較不需要與轉介者澄清的衡鑑方向？
  1. （A）轉介者對於治療的概念是否與自己存在共識
  2. （B）轉介者是否面臨某些治療進展的議題，而需要衡鑑資料提供較佳的治療策略
  3. （C）轉介者是否想提供患者其他的治療方案或是評估治療的可能結果
  4. （D）轉介者是否想解決一些實務上的問題，例如患者對自己或他人是否具有危險性的評估

答案：（A）

詳解與考點

考點為對治療中個案進行衡鑑時的轉介澄清方向。要選較不需要澄清者。轉介者對治療的概念是否與自己有共識，較屬治療師個人理論立場，並非此次衡鑑必須先澄清的方向，故 A 為答案。B、C、D 涉及治療進展、替代方案、危險性評估等實務問題，皆需與轉介者澄清。標 med。

第 17 題

下列何者在其心理治療取向主張引導個案在真誠的關係下，進行經驗接觸、實驗探索等歷程，使其獲得重要的覺察、產生改變？
  1. （A）Erving Polster
  2. （B）Carl Rogers
  3. （C）Christine Padesky
  4. （D）Jon Kabat-Zinn

答案：（A）

詳解與考點

考點為完形治療（Gestalt）的核心主張與代表人物。強調真誠關係、此時此地的經驗接觸與實驗探索以促成覺察，是完形治療精神，Erving Polster 為完形學派代表，故 A 正確。陷阱為 B Rogers（個人中心）、C Padesky（認知治療）、D Kabat-Zinn（正念減壓），取向不同。

第 18 題

在心理治療歷程中檢視治療關係時，何種信念將有助於治療工作？
  1. （A）應改變自己的態度以符合個案期待
  2. （B）應認知到無法與每位個案都能有效工作的現實
  3. （C）要喜歡個案才能有效進行治療工作
  4. （D）要與個案有相同經驗才能有效進行治療工作

答案：（B）

詳解與考點

考點為治療關係中的健康信念。治療師應務實地認知到自己無法與每位個案都有效工作，這有助於治療彈性與轉介判斷，故 B 正確。陷阱為 A 一味改變自己迎合個案、C 必須喜歡個案、D 須有相同經驗，這些都是不切實際或妨礙專業界線的迷思，易因聽來「貼近個案」而誤選。

第 19 題

「透過治療使潛意識浮上意識，達到理智與情緒上的覺察；幫助個案再次體驗早期經驗，修通被壓抑的衝突，引導重建基本人格」，以上敘述最符合何種取向的治療目標？
  1. （A）認知行為治療
  2. （B）完形治療
  3. （C）現實治療
  4. （D）精神分析

答案：（D）

詳解與考點

考點為各治療取向的目標辨識。使潛意識意識化、修通被壓抑衝突、重建基本人格，是精神分析（psychoanalysis）的核心治療目標，故 D 正確。陷阱為 B 完形（重此時此地覺察）、C 現實治療（重當下選擇與責任），這些不談潛意識與人格重建；關鍵字「潛意識、壓抑、重建人格」直指精神分析。

第 20 題

關於女性主義治療的原則，下列敘述何者錯誤？
  1. （A）女性主義治療的目標不僅是個人改變，更是社會改變
  2. （B）強調與案主之間的平等關係
  3. （C）心理不適不見得是種疾病，而是試圖傳達系統的不正義
  4. （D）認為政治與社會的不公平，僅會對少數產生壓迫

答案：（D）

詳解與考點

考點為女性主義治療原則。要選錯誤者。女性主義治療認為政治社會的不公會對廣泛群體（不僅少數）產生壓迫，敘述稱「僅會對少數產生壓迫」與其精神相反，故 D 錯誤為答案。A 兼顧個人與社會改變、B 平等治療關係、C 視不適為系統不正義的訊號，皆為正確原則。

第 21 題

關於Carl R. Rogers所提的「真誠一致（congruence）」，下列敘述何者正確？
  1. （A）治療師將自身感受到個案所有的問題或情感立即地表達給個案
  2. （B）治療師在治療過程中對當下經驗的覺知抱持開放且有意願展現的態度
  3. （C）治療師努力在治療關係中選擇對於個案有益的部分表達給個案
  4. （D）唯有達到自我實現的治療師才能在治療中展現真誠一致

答案：（B）

詳解與考點

考點為 Rogers 的真誠一致（congruence）。真誠一致指治療師對當下經驗的覺知保持開放、表裡如一且願意適當展現，故 B 正確。陷阱為 A，congruence 不等於把所有感受立即全盤宣洩給個案（那忽略治療效益的拿捏）；C 選擇性表達偏向技巧操弄；D 須自我實現才能真誠，過度設限，皆誤。

第 22 題

存在主義取向治療中，關於自我覺察的主張，下列敘述何者正確？
  1. （A）個體具有行動或不行動的潛力，而不作為也是種決定
  2. （B）個體具有無限的時間與可能性，來完成人生的目標
  3. （C）個體能完全創造自身的命運
  4. （D）個體本質上是社會性的，因此才會體驗到孤獨

答案：（A）

詳解與考點

考點為存在主義治療的自我覺察主張。個體有行動或不行動的潛力，且「不作為」本身也是一種選擇與決定，符合存在主義對自由與責任的觀點，故 A 正確。陷阱為 B 無限時間（與存在主義強調死亡有限相反）、C 完全創造命運（過度誇大）、D 本質為社會性才感孤獨，皆與存在主義核心不符。

第 23 題

根據齊克果（Kierkegaard）的概念，關於存在焦慮（existential anxiety），下列敘述何者正確？
  1. （A）存在焦慮是病理性的
  2. （B）是生命覺醒的必要歷程
  3. （C）會毀壞我們的自我
  4. （D）是與他人的依附困難

答案：（B）

詳解與考點

考點為齊克果（Kierkegaard）的存在焦慮概念。存在焦慮被視為生命覺醒、面對自由與抉擇的必要歷程，具建設性意義，故 B 正確。陷阱為 A 病理性、C 會毀壞自我，這些把存在焦慮負面化，與齊克果觀點相反；D 與他人依附困難則是把存在焦慮誤導向人際依附議題。

第 24 題

有關著重正念（mindfulness）與接納的治療取向，下列敘述何者正確？
  1. （A）接納與承諾治療（acceptance and commitment therapy）強調辨識、挑戰與改變個案的失功能思考內容
  2. （B）辯證行為治療（dialectal behavioral therapy）融合了認知行為、精神分析及東方禪修訓練
  3. （C）正念減壓法（mindfulness-based stress reduction）源自正念認知治療（mindfulness-based cognitive therapy）
  4. （D）正念減壓法的成分強調認知行為技巧的教導

本題送分，無標準答案

詳解與考點

正解：本題經考選部公告一律給分，作答任一選項皆得分。原因是題目要找「正確」的敘述，但四個選項依主流教材都不成立：三個把不同取向的核心成分張冠李戴，一個把兩套課程的源流順序寫反。爭點集中在 B——辯證行為治療整合的是行為與認知技術、辯證哲學與東方禪修訓練，選項卻把辯證哲學換成精神分析；若採部分中文教材對其治療關係與情緒失調成因的寬鬆描述，B 又勉強可讀為對，命題依據因而不一致，故送分。

A：接納與承諾治療的核心是接納與認知去融合，改變的是個案與想法之間的關係並朝價值方向行動，不去辨識與挑戰思考內容；辨識、挑戰與改變失功能思考是認知治療的作法，術語掛錯了取向。

B：辯證行為治療確實融合了認知行為技術與東方禪修的正念訓練，但第三個成分是辯證哲學，強調接納與改變的對立統一，不是精神分析。這是四者中最接近成立的敘述，也是本題爭議所在。

C：方向反了——正念減壓法是較早發展的課程，正念認知治療才是把正念減壓法的架構與認知治療結合、用於預防憂鬱復發的後續產物，源流關係恰好相反。

D：正念減壓法以正念練習本身為主體，強調對身心經驗的覺察與不評價；認知行為技巧的教導是正念認知治療的成分，不是正念減壓法的重點。

本題考點：第三波行為治療各取向的成分辨識——接納與承諾治療（acceptance and commitment therapy）以接納與認知去融合為核心，辯證行為治療（dialectical behavior therapy）並用行為技術、辯證哲學與禪修正念，正念減壓法（mindfulness-based stress reduction）以正念練習為主體，正念認知治療（mindfulness-based cognitive therapy）則在正念減壓法的架構上加入認知治療元素以預防憂鬱復發；辨識的機械判準是先問這套取向要改變的是想法的內容，還是個案與想法之間的關係。

第 25 題

治療師提出外化（externalization）問句，將個案和其問題分離開來，此為何種心理治療學派的做法？
  1. （A）現實治療學派
  2. （B）交流分析學派
  3. （C）敘事治療學派
  4. （D）意義治療學派

答案：（C）

詳解與考點

考點為敘事治療（narrative therapy）的外化技術。將人與問題分開、提出外化問句（「問題是問題，人不是問題」），是敘事治療代表做法，故 C 正確。陷阱為 A 現實治療、B 交流分析、D 意義治療，雖各有特色技術，但「外化」是 White 與 Epston 敘事治療的標誌性概念。

第 26 題

下列何者為家族治療學者Bowen理論的核心概念？
  1. （A）自我分化
  2. （B）出生序
  3. （C）家庭連結
  4. （D）溝通模式

答案：（A）

詳解與考點

考點為 Bowen 家庭系統理論。自我分化（differentiation of self）是 Bowen 理論的核心概念，指個體在情感連結中保有自主與理智的能力，故 A 正確。陷阱為 B 出生序（屬 Adler 概念）、D 溝通模式（偏 Satir 或溝通取向），易與其他家族治療或人格理論混淆。

第 27 題

下列何者屬於阿德勒治療學派（Adlerian）瞭解個案的途徑？
  1. （A）田野觀察（field observation）
  2. （B）早年記憶（early recollection）
  3. （C）認知地圖（congnition map）
  4. （D）生活空間（living space）

答案：（B）

詳解與考點

考點為阿德勒（Adlerian）治療了解個案的途徑。早年記憶（early recollection）是阿德勒學派用以推斷生活風格與核心信念的重要技術，故 B 正確。陷阱為 D 生活空間（Lewin 場地論）、C 認知地圖（Tolman），這些屬其他學者概念；early recollection 為阿德勒標誌方法。

第 28 題

進行心理動力取向的年齡回歸（age regression）技術來治療解離性身份障礙症的個案，治療者需要留意下列那個事項？
  1. （A）要先給予個案藥物來協助放鬆
  2. （B）無須事先給予個案心理教育
  3. （C）喚起創傷事件的過程可能會惡化症狀
  4. （D）喚起創傷事件的過程治療師需坐在個案躺椅的斜後方

答案：（C）

詳解與考點

考點為心理動力年齡回歸技術治療解離性身份障礙的注意事項。喚起創傷事件的歷程可能使症狀惡化（再創傷風險），須謹慎，故 C 正確。陷阱為 B 無須心理教育（實則需事先準備與穩定化）、A 須先給藥、D 須坐躺椅斜後方，這些屬不必要或杜撰的硬性規定，易被當作專業細節誤選。

第 29 題

某個案的原生文化重視權威，期待專家給予指導與問題解決。下列何項治療可能相對上較不符合該個案的期待？
  1. （A）精神分析
  2. （B）理情行為治療
  3. （C）現實治療
  4. （D）行為活化

答案：（A）

詳解與考點

考點為治療取向與文化期待的適配。原生文化重視權威、期待專家給予指導與解答的個案，精神分析強調自由聯想、節制、由個案自行領悟，較不提供直接指導，最不符其期待，故 A 正確。陷阱為 B 理情行為、C 現實治療、D 行為活化，這些較具指導性與結構性，反而較符合該期待。

第 30 題

關於處理兒童問題行為需考慮的因素，下列敘述何者正確？
  1. （A）發展里程強調的是能力因素
  2. （B）發展年齡強調的是年齡因素
  3. （C）行為功能分析強調的是環境因素
  4. （D）應用行為分析強調的是作業難度因素

答案：（C）

詳解與考點

考點為處理兒童問題行為的考量因素配對。行為功能分析（functional analysis）著重辨識行為與前事、後果等環境變項的關係，強調環境因素，故 C 正確。陷阱在 A、B、D 把發展里程、發展年齡、應用行為分析與「能力／年齡／作業難度」做不當配對，概念對應錯置易誤選。

第 31 題

下列何種狀況違反臨床心理師保密原則？
  1. （A）在協助採證詢問兒童性侵害被害人時，讓家屬用攝影機在另一個房間觀看
  2. （B）對主管機關提出性侵害加害人的身心治療評估報告
  3. （C）當青少年個案未付清治療費用，聯繫其法定代理人說明治療出席狀況，請求處理
  4. （D）在成年個案同意下，於書中寫下個案的治療歷程與故事

答案：（A）

詳解與考點

考點為臨床心理師保密原則的界線。讓家屬用攝影機在另一房間觀看兒童性侵被害人的採證詢問，會洩漏個案隱私並可能造成傷害，違反保密原則，故 A 為答案。B 對主管機關提評估報告、C 聯繫法代理人處理費用、D 經同意書寫治療故事，皆屬合法或經同意的例外，不違反保密。

第 32 題

個案為3歲男童，臉部及身體有明顯外傷，已被緊急安置。個案出生後由祖母帶大，父母也已離婚。個案被母親接回監護已半年，並與母親、其同居人及所生的1歲女嬰同住，個案的外傷被高度懷疑是母親之同居人家暴造成。下列何者為最優先之處遇計畫？
  1. （A）由個案祖母照顧最安全
  2. （B）進行家庭功能、兒童安全評估和親職教育，確保個案安全
  3. （C）請個案母親接受心理輔導，就能照顧個案
  4. （D）家庭關係複雜，應留在安置機構最安全

答案：（B）

詳解與考點

考點為兒童保護的優先處遇。個案已因疑似家暴被緊急安置，最優先應進行家庭功能與兒童安全評估及親職教育以確保安全，故 B 正確。陷阱為 A 交祖母、C 母親受輔導就能照顧、D 留安置機構最安全，這些在尚未完成安全評估前皆屬未經評估的武斷安置決定，違反兒少保護程序。

第 33 題

臨床心理師給予個案個人社交軟體帳號，方便個案在痛苦情緒侵襲時，可以直接與他聯絡。亦會透過社交軟體邀約個案聚餐、出遊或看電影，藉此紓解個案的痛苦情緒。這呈現何項專業倫理爭議？
  1. （A）未能妥善保護個案在心理治療過程中的隱私
  2. （B）在未獲得個案同意下，即對個案採取一個新的治療策略
  3. （C）在進行臨床心理工作時，未具有相對應的專業能力
  4. （D）在心理治療期間，與個案發展專業關係以外的情感關係

答案：（D）

詳解與考點

考點為治療中的多重關係與專業界線。臨床心理師給個案私人帳號、邀約聚餐出遊看電影，已在治療關係外發展私人情感／社交關係，屬多重關係的倫理爭議，故 D 正確。陷阱為 A 隱私、B 未同意新策略、C 能力不足，雖皆為倫理議題，但本情境核心是逾越專業界線的關係糾葛。

第 34 題

根據臨床心理師倫理規範，有關心理治療紀錄與心理衡鑑原始資料的保管責任，下列敘述何者錯誤？
  1. （A）無論目的為何，須先徵得個案同意，方可使用相關的資料
  2. （B）若為專業教學需要，但無法取得個案同意時，應遮蔽任何可供辨識身分的資料
  3. （C）當接觸到社會矚目案件之個案時，為求公正透明，可公布精神鑑定的過程與結果
  4. （D）若個案有傷害他人或自殺的可能性時，應儘快通知其法定代理人或有關單位

答案：（C）

詳解與考點

考點為治療紀錄與衡鑑原始資料的保管倫理。要選錯誤者。即使是社會矚目案件，也不得以「公正透明」為由公布精神鑑定過程與結果，須保護個案隱私，故 C 錯誤為答案。A 使用須經同意、B 教學需遮蔽辨識資料、D 有傷人或自殺之虞應通報，皆為正確規範。陷阱在 C 以公益之名包裝洩密。

第 35 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「專業責任與價值」，下列那一項是臨床心理服務的社會基礎之一？
  1. （A）社會大眾的信任
  2. （B）臨床心理師的人格
  3. （C）專業倫理的訂定
  4. （D）科學知識的堅持

答案：（A）

詳解與考點

考點為臺灣臨床心理師倫理準則中「專業責任與價值」的社會基礎。臨床心理服務奠基於社會大眾的信任，此信任是專業存續的社會基礎，故 A 正確。陷阱為 B 人格、C 倫理訂定、D 科學知識，這些雖屬專業重要面向，但題目問的是「社會基礎」，最貼切者為社會大眾的信任。

第 36 題

若要評估心理治療療效，下列何種研究方法最具證據力？
  1. （A）個案研究法（case study）
  2. （B）隨機控制試驗（randomized controlled trial）
  3. （C）案例對照研究法（case-control study）
  4. （D）類比實驗法（analogue experiment study）

答案：（B）

詳解與考點

考點為心理治療療效研究的證據力層級。隨機控制試驗（RCT）以隨機分派控制干擾變項，是評估療效最具證據力的設計，故 B 正確。陷阱為 A 個案研究（缺對照、外推性低）、C 案例對照（回溯性、易偏誤）、D 類比實驗（情境模擬、外在效度受限），證據力皆低於 RCT。

第 37 題

某研究探討心理治療與藥物治療對憂鬱症的效果，安排參與者自行選擇任一治療參加。此作法最可能威脅下列何種效度？
  1. （A）外在效度
  2. （B）建構效度
  3. （C）內在效度
  4. （D）生態效度

答案：（C）

詳解與考點

考點為實驗效度與分組方式。讓參與者自行選擇治療（非隨機分派）會使兩組在治療前即存在系統差異（自我選擇偏誤），無法確定效果源自治療，最威脅內在效度，故 C 正確。陷阱為 A 外在效度（外推性）、B 建構效度、D 生態效度，這些與「分組是否能歸因因果」的核心問題不同。

第 38 題

關於心理治療研究中採用控制組設計，下列敘述何者錯誤？
  1. （A）有助釐清實驗組的改善是否源自治療本身
  2. （B）治療研究可採用不同類型的控制組
  3. （C）安慰劑組常採用等待接受治療名單
  4. （D）最嚴謹的控制組為已被證實有效的治療

答案：（C）

詳解與考點

考點為心理治療研究的控制組設計。要選錯誤者。安慰劑組（placebo）旨在控制非特定治療因素如期待，與等待治療名單（wait-list）控制組是不同類型；把安慰劑組等同等待名單屬概念混淆，故 C 錯誤為答案。A 釐清改善來源、B 多種控制組、D 以已證實有效治療為最嚴謹對照，皆正確。

第 39 題

關於創傷性腦傷之記憶衡鑑，下列敘述何者錯誤？
  1. （A）自傳記憶可反映回溯性（retrograde）失憶問題
  2. （B）立即和延宕回憶可反映前向性（anterograde）失憶問題
  3. （C）前向性失憶患者的數字逆序背誦表現可能為正常
  4. （D）「常識測驗」是回溯性失憶的主要指標之一

答案：（D）

詳解與考點

考點為創傷性腦傷的記憶衡鑑。要選錯誤者。常識測驗反映的是長期累積的舊知識與智力結晶，並非回溯性（retrograde）失憶的主要指標，故 D 錯誤為答案。A 自傳記憶反映回溯性失憶、B 立即與延宕回憶反映前向性失憶、C 前向失憶者數字逆序可能正常，配對皆正確。陷阱在 D 把舊知識誤當失憶指標。

第 40 題

關於實施心理測驗對於心理治療之功用，下列敘述何者錯誤？
  1. （A）滿足個案對心理測驗的好奇心
  2. （B）協助個案了解困擾問題
  3. （C）提供治療計畫的參考
  4. （D）描述個案的認知與情緒狀態

答案：（A）

詳解與考點

考點為心理測驗對心理治療的功用。要選錯誤者。實施測驗應服務於治療目標，「滿足個案對測驗的好奇心」並非心理測驗的正當治療功用，故 A 錯誤為答案。B 協助了解困擾、C 提供治療計畫參考、D 描述認知情緒狀態，皆為測驗的合理治療功用。陷阱在 A 看似貼近個案需求實則非專業目的。
