第 1 題

下列何者是臨床心理衡鑑最主要的目標？
  1. （A）與個案建立良好醫病關係
  2. （B）暸解及評估個案性格與能力
  3. （C）同理與支持個案所遇到的問題
  4. （D）幫助個案解決問題與協助作決定

答案：（D）

詳解與考點

正解：本題問的是臨床心理衡鑑最主要的目標——衡鑑最終目的是協助個案解決問題與作決定，提供決策參考，故選 D。

A、C：與個案建立良好醫病關係、同理與支持個案所遇到的問題，這些是衡鑑或治療過程中的必要要素，而非衡鑑本身最主要的目標。 B：暸解及評估個案性格與能力是達成衡鑑目標的手段與過程，並非衡鑑的終極目的，容易因描述貼近衡鑑內容而被列為答案。

本題考點：臨床心理衡鑑目標的判準——區分「過程要素」（建立關係、同理支持）、「衡鑑手段」（了解評估性格能力）與「終極目的」（協助解決問題與作決定）三個層次，衡鑑最主要目標落在終極目的這一層。

第 2 題

關於心理衡鑑之「心理計量取向（psychometric approach）」的敘述，下列何者錯誤？
  1. （A）是資料導向（data-oriented）的評估方式，強調以客觀的測驗分數描述個人的能力或特質
  2. （B）當評估的目的涉及快速將大量的受測者進行分類或篩選時，心理計量取向是有用的策略
  3. （C）對於測驗分數的解釋較少考量個體所在的生活脈絡或情境因素
  4. （D）最大優點是客觀，可以減少晤談者的偏誤，因此可精準的評估較為複雜的人格特質或因應模式

答案：（D）

詳解與考點

正解：關鍵在「客觀標準化」與「精準評估複雜人格特質」是否可以劃上等號。心理計量取向（psychometric approach）以客觀分數、標準化見長，但對於複雜人格特質或因應模式的精準評估其實有限，需搭配脈絡與質性資料補充，故 D 的敘述過度宣稱，為答案。

A：是資料導向（data-oriented）的評估方式，強調以客觀的測驗分數描述個人的能力或特質，符合心理計量取向的定義特徵。 B：當評估目的涉及快速將大量受測者分類或篩選時，心理計量取向是有用的策略，符合其標準化施測與計分的優勢。 C：對測驗分數的解釋較少考量個體所在的生活脈絡或情境因素，正是心理計量取向常受批評之處，敘述正確。

本題考點：心理計量取向（psychometric approach）的能力邊界判準——客觀、標準化、適合大量篩選分類是其優勢，但對複雜人格特質與因應模式的精準評估、以及脈絡情境的考量皆有其限制，不可把「客觀」直接等同於「能精準評估複雜構念」。

第 3 題

關於羅夏克墨漬測驗Exner's Comprehensive System的詢問階段，下列敘述何者正確？
  1. （A）只要受試者說「毛毛的」，決定因子即可記錄為T（shading-texture）
  2. （B）如果受試者說：「就和前一個反應看的方法一樣」時，可不需要加以澄清
  3. （C）如果受試者並未說出「一對」的說明，需要再詢問「是看到一個還是兩個？」
  4. （D）如果受試者在詢問階段出現新的反應，不應列入計分

答案：（D）

詳解與考點

考點為羅夏克 Exner 綜合系統的詢問（inquiry）階段計分規則。詢問階段新出現的反應不列入計分（僅原反應階段的反應計分），故 D 正確。陷阱為 A，只說「毛毛的」不足以直接記為材質 T，需確認是否為觸感決定因子；B、C 對澄清與成對反應的處理描述也不符標準程序。

第 4 題

下列那一類信度有助於減少學習移轉效應（carryover effect）？
  1. （A）內部一致性信度
  2. （B）再測信度
  3. （C）庫李（Kuder-Richardson）信度
  4. （D）複本信度

答案：（D）

詳解與考點

正解：本題問的是哪種信度設計能降低學習移轉效應（carryover effect）——判準是該信度是否讓受試者接觸相同或不同的題目。複本信度使用內容等值但題目不同的兩份測驗分別施測比較，因題目不同而降低受試者因記得先前作答內容產生的練習或移轉效應，故選 D。

A：內部一致性信度以單一測驗內部各題項的相關程度估計信度，屬同一次施測內部的計算，不涉及跨時間的移轉問題。

B：再測信度以同一份測驗前後施測兩次，受試者容易記得前次題目與作答內容，反而是四個選項中最容易受 carryover 影響的信度類型，是本題最強誘答——分辨關鍵在於再測信度用的是「同一份」測驗，複本信度用的是「內容等值但題目不同」的兩份測驗。

C：庫李（Kuder-Richardson）信度是計算內部一致性的一種公式，性質同 A，同樣與跨施測次數的移轉效應無關。

本題考點：信度類型與跨施測誤差來源的對應——複本信度以題目差異抵銷練習效應，再測信度與內部一致性信度（含庫李信度）皆無此設計；判準是該信度估計方式是否讓受試者接觸到相同題目。

第 5 題

關於使用電腦測驗輔助心理衡鑑的好處，下列何者錯誤？
  1. （A）節省專業人員的時間
  2. （B）改善再測信度
  3. （C）電腦測驗結果可作為診斷
  4. （D）降低主試者偏差

答案：（C）

詳解與考點

正解：關鍵在電腦測驗的角色僅止於標準化施測、計分與資料蒐集，診斷仍須由臨床心理師整合衡鑑資料與臨床判斷。電腦測驗結果本身不能逕自作為診斷依據，敘述稱「可作為診斷之用」誤把工具的客觀計分等同於臨床判斷的完成，故 C 為應選項（要選錯誤者）。

A：電腦施測與計分自動化，確實能節省專業人員逐題計分與整理的時間，屬合理優點。

B：電腦化施測的指導語、呈現順序與計時皆標準化，減少人為操作誤差，有助於提升再測信度，屬合理優點。

D：電腦施測排除主試者在呈現題目、記錄反應時的主觀介入，能降低主試者偏差，屬合理優點。

本題考點：電腦輔助心理衡鑑的能力邊界——標準化施測、計分與偏差控制是電腦化的合理優點，但診斷需整合衡鑑資料與臨床判斷，測驗結果本身不能直接等同診斷結論。

第 6 題

關於腦部心智功能篩選測驗，下列敘述何者錯誤？
  1. （A）簡式心智檢查（Mini-Mental State Examination, MMSE）可用來篩檢認知功能障礙
  2. （B）雷－歐式複雜圖形測驗（Rey-Osterrieth Complex Figure Test）可用來篩檢視覺建構功能異常
  3. （C）史楚普作業（Stroop task）可用來篩檢語言功能障礙
  4. （D）雷氏聽覺語文學習測驗（Rey Auditory Verbal Learning Test）可用來篩檢語文記憶異常

答案：（C）

詳解與考點

正解：判準是各測驗實際評估的認知向度，而非測驗形式上的相似聯想。史楚普作業（Stroop task）測量的是選擇性注意與抑制控制等執行功能，並非語言功能，敘述稱其可篩檢語言功能障礙屬配對錯誤，故 C 為應選項（要選錯誤者）。

A：簡式心智檢查（Mini-Mental State Examination, MMSE）以定向感、注意力、記憶、語言與視覺建構等多向度簡短題項篩檢整體認知功能障礙，配對正確。

B：雷－歐式複雜圖形測驗（Rey-Osterrieth Complex Figure Test）要求受試者臨摹並重畫複雜圖形，測量視覺建構與視覺記憶功能，配對正確。

D：雷氏聽覺語文學習測驗（Rey Auditory Verbal Learning Test）以反覆呈現字詞列表測量學習與延宕回憶，篩檢語文記憶功能，配對正確。

本題考點：神經心理篩選測驗的功能對應——Stroop task 涉及唸名字詞，容易被誤連到語言功能，實際測的是執行功能中的抑制控制；MMSE 測整體認知、Rey-O 複雜圖測視覺建構、RAVLT 測語文記憶，四者對應的認知向度須逐一分辨而非依測驗形式聯想。

第 7 題

關於Symptom Checklist-90-R（SCL-90-R），下列敘述何者正確？
  1. （A）由臨床專業人員以結構化晤談施測
  2. （B）評估個案過去半年內各種症狀的程度
  3. （C）評估結果可作為診斷之用
  4. （D）Brief Symptom Inventory（BSI）是它的簡版

答案：（D）

詳解與考點

正解：本題問的是關於 Symptom Checklist-90-R（SCL-90-R）敘述何者正確——判準是其施測方式、評估期間與簡版關係。Brief Symptom Inventory（BSI）取 SCL-90-R 各分量表的代表題項濃縮而成，是它的簡版，故選 D。

A：SCL-90-R 是受試者自行填寫的自陳式量表，並非由臨床專業人員以結構化晤談施測。

B：SCL-90-R 詢問的是近期（通常為過去一週）的症狀程度，並非過去半年的症狀。

C：SCL-90-R 的結果反映症狀嚴重程度的自陳資料，僅供臨床參考，不能單獨作為診斷依據，仍須整合其他衡鑑與晤談資訊。

本題考點：自陳症狀量表的性質辨識——施測方式（自陳非結構化晤談）、評估期間（近期而非半年）、結果用途（症狀程度參考而非逕自診斷）三者常被混淆；SCL-90-R 與其簡版 BSI 的關係是本題的直接判準。

第 8 題

關於魏氏成人智力測驗第四版（WAIS-IV）的解釋方式，下列敘述何者錯誤？
  1. （A）當指數分數間的變異大，全量表智商的意義度變低
  2. （B）建議使用連續階層式的歷程來討論受試者的表現
  3. （C）最好使用日常的語言來說明，儘可能減少專業術語
  4. （D）只有在指數分數內之分測驗間差距大於5分時，該指數分數才有意義

答案：（D）

詳解與考點

正解：關鍵在該敘述是否對應 WAIS-IV 標準化的解釋規則。解釋指引中確有分測驗量表分數差距約 5 分（約 1.5 個標準差）的參考門檻，但方向與選項相反：差距「小於」該門檻時，指數所測構念較為單一，該指數分數才具解釋意義；差距大於門檻反而使該指數的代表性降低。選項 D 把方向講反，故 D 為應選項（要選錯誤者）。

A：當各指數分數間的變異程度大，代表受試者的能力表現不平均，此時全量表智商作為單一總分的代表性與意義度隨之降低，屬正確的解釋原則。

B：建議先看全量表智商，再依序檢視各指數分數與分測驗表現的連續階層式歷程，逐層深入解讀，屬正確的解釋原則。

C：向個案與家屬說明結果時應儘量使用日常語言，減少專業術語造成的理解障礙，屬正確的解釋原則。

本題考點：WAIS-IV 解釋的分寸拿捏——指數間變異影響全量表智商的代表性、階層式解讀順序、日常語言說明皆屬公認準則；遇到附帶具體數字門檻（如分測驗差距約5分）的解釋規則，須先確認方向是否正確——差距小於門檻時指數才具單一構念的解釋意義，差距大於門檻則使指數代表性降低，不可把方向講反。

第 9 題

下列的表格記錄方式屬於何種行為觀察記錄法？
  1. （A）多重基準線記錄法
  2. （B）對照記錄法
  3. （C）事件記錄法
  4. （D）評比記錄法

答案：（C）

詳解與考點

考點為行為觀察記錄法的類型。依題目表格逐次記錄特定目標行為發生的次數，屬事件記錄法（event recording），故 C 正確。陷阱為 A 多重基準線（屬單一受試實驗設計）、D 評比記錄法（以等級量尺評定程度），與單純計次的事件記錄不同，易混淆。標 med，因需配合原圖表。

第 10 題

關於心理衡鑑報告提供回饋的準則，下列敘述何者錯誤？
  1. （A）可告訴個案心理衡鑑的基本概念與原理
  2. （B）強調病理比強調個案的適應能力重要
  3. （C）儘量以個案可以理解的語言與文字來呈現
  4. （D）可以建議未來處遇方向

答案：（B）

詳解與考點

正解：本題問的是心理衡鑑報告提供回饋的準則何者錯誤——判準是回饋內容是否兼顧病理與個案的適應能力與優勢。良好的回饋應平衡呈現個案的困難與其功能、資源與優勢，若強調病理重於適應能力，會使個案只看到問題而忽略自身可運用的資源，違反正向、平衡回饋的精神，故 B 為應選項。

A：向個案說明心理衡鑑的基本概念與原理，有助於個案理解衡鑑過程與結果的意義，屬適切準則。

C：儘量以個案能理解的語言與文字呈現結果，避免過多專業術語造成溝通障礙，屬適切準則。

D：在回饋中提出未來可行的處遇方向，使衡鑑結果能實際銜接後續治療決策，屬適切準則。

本題考點：心理衡鑑回饋的品質判準——內容須平衡呈現病理與適應能力（優勢與資源）、語言須貼近個案理解程度、並延伸至可行的處遇建議；任何把病理置於優先於適應能力之上的敘述，都違反平衡回饋的原則。

第 11 題

下列何者不是心理衡鑑的主要轉介目的？
  1. （A）智力評估
  2. （B）提供鑑別診斷的相關資訊
  3. （C）提供心理治療的建議
  4. （D）判定行為是否違法

答案：（D）

詳解與考點

正解：關鍵在該項工作屬於心理衡鑑的專業範圍，還是超出評估、屬於法律裁定的權責。判定行為是否違法是司法審理與法官職權的範疇，心理師在司法心理鑑定中至多提供心智狀態、認知功能或風險評估等資訊供法院參考，並非逕自判定違法與否，故 D 為應選項。

A：智力評估是心理衡鑑常見且核心的轉介目的之一，用以了解個案的認知能力水準。

B：提供鑑別診斷的相關資訊，協助釐清多個可能診斷間的區辨，是心理衡鑑的主要功能之一。

C：依衡鑑結果提供心理治療的建議，銜接後續處遇方向，同樣是心理衡鑑常見的轉介目的。

本題考點：心理衡鑑轉介目的的邊界——智力評估、鑑別診斷、治療建議皆屬衡鑑專業範圍內的常見目的；涉及司法判決（如是否違法）屬法官職權，心理師僅提供評估資訊供參考，不逕自做出法律判定。

第 12 題

Wright（2010）提出整合心理衡鑑資料，以完成個案概念化的四種模式，下列敘述何者錯誤？
  1. （A）發展模式（Developmental Model）強調個案的問題常導因於本身功能與環境要求間的落差
  2. （B）共通功能模式（Common Function Model）強調症狀或問題是為了達成某種功能的目的而產生
  3. （C）特異質－壓力模式（Diathesis-Stress Model）強調個體的內外在因素交互影響，不適合用心理動力學派的觀點來分析整合
  4. （D）複雜模式（Complex Model）是其他不同模式的混合版本，強調應運用不同模式的觀點，來分析個案問題的複雜度

答案：（C）

詳解與考點

考點依 Wright（2010）個案概念化四模式。要選錯誤者。特異質－壓力模式（Diathesis-Stress）強調內外在因素交互，仍可結合心理動力等多種觀點分析，敘述稱「不適合用心理動力觀點」屬誤述，故 C 為答案。A 發展模式、B 共通功能模式、D 複雜模式的描述皆正確。標 med，依特定教材。

第 13 題

當心理衡鑑目的為情緒功能與情緒症狀評估時，下列何種測驗被選擇的可能性最低？
  1. （A）簡式症狀量表（Brief Symptom Inventory）
  2. （B）羅夏克墨漬測驗（Rorschach Inkblot Test）
  3. （C）人格衡鑑量表（Personality Assessment Inventory）
  4. （D）Rey-Osterrieth複雜圖形測驗（Rey-Osterrieth Complex Figure Test）

答案：（D）

詳解與考點

正解：本題問的是心理衡鑑目的為情緒功能與情緒症狀評估時，何種測驗被選擇的可能性最低——判準是該測驗實際測量的向度是情緒相關構念，還是其他認知功能。雷－歐式複雜圖形測驗（Rey-Osterrieth Complex Figure Test）主要用於評估視覺建構與視覺記憶，屬神經心理功能範疇，與情緒功能評估的相關性最低，故選 D。

A：簡式症狀量表（Brief Symptom Inventory）直接以自陳題項測量多種心理症狀的嚴重程度，是情緒與症狀評估的常用工具。

B：羅夏克墨漬測驗（Rorschach Inkblot Test）透過投射反應探索個案的情緒運作與內在心理歷程，與情緒功能評估相關。

C：人格衡鑑量表（Personality Assessment Inventory）涵蓋多個臨床量表，能反映情緒困擾與人格病理面向，與情緒功能評估相關。

本題考點：測驗選擇須對應轉介目的所測量的構念——BSI、羅夏克、PAI 皆能提供情緒症狀或人格情緒面向的資訊，Rey-Osterrieth 複雜圖形測驗測的是視覺建構與視覺記憶等神經心理功能，與情緒評估的目的最不相干；判準是測驗名稱背後實際測量的構念，而非「常見於衡鑑」這種表面熟悉度。

第 14 題

在心理衡鑑報告中，下列何者不是逐一呈現各測驗結果與解釋的作法之缺點？
  1. （A）無法讓讀者瞭解推論的依據
  2. （B）反映臨床工作者未能整合資料
  3. （C）讀者對此作法的反應普遍不佳
  4. （D）強化評估者是施測技術員的形象

答案：（A）

詳解與考點

正解：關鍵在該敘述描述的現象是否確實會在逐一呈現各測驗結果的作法中發生。逐一呈現各測驗的結果與解釋，讀者仍能看到每項結果對應的解釋內容，並不會因此無法瞭解推論的依據，敘述與此作法的實際效果相反，故 A 為應選項。

B：逐一呈現各測驗結果，等於未將不同測驗的資料整合為一致的臨床圖像，反映臨床工作者未能整合資料，是公認的缺點。

C：這種條列式呈現讓報告顯得零碎、缺乏敘事整合，讀者對此作法的閱讀反應普遍不佳，是公認的缺點。

D：逐一列出每項測驗分數與制式解釋，容易讓報告讀起來像機械化的施測結果羅列，強化評估者僅是施測技術員而非臨床判斷者的形象，是公認的缺點。

本題考點：衡鑑報告書寫方式的優劣判準——逐一呈現各測驗結果的問題在於「未整合資料」「讀者反應不佳」「弱化臨床判斷形象」，但仍逐項列出每個結果的推論依據，並非「讓讀者無從瞭解依據」；題目為反向題，須先確認問的是「不是缺點」而非「是缺點」。

第 15 題

有些個案會為了獲得個人利益而詐病，下列何種問題最可能被個案過度誇大他的困難？
  1. （A）智力問題
  2. （B）記憶問題
  3. （C）人際問題
  4. （D）注意力問題

答案：（B）

詳解與考點

正解：判準是該問題領域在客觀檢驗上是否容易被辨識。記憶問題（如聲稱大範圍失憶）主觀性高、難以用單一客觀指標直接驗證，是詐病（malingering）者最常誇大的標的，故選 B。

A：智力問題有標準化智力測驗與常模比對，表現型態若與實際功能明顯不一致（如生活自理正常卻測驗分數極低）較容易被察覺不一致，較不易單靠誇大蒙混。

D：注意力問題同樣有標準化測驗與效度指標（如反應時間一致性、表現曲線）可資檢核，誇大時較容易在測驗內部不一致中被辨識。

C：人際問題多依賴個案主觀陳述與觀察者報告的交叉比對，不是本題情境中最典型被用來詐病誇大的困難類型，臨床上以記憶問題更為常見。

本題考點：詐病（malingering）症狀誇大的判別——愈難用客觀測驗或效度指標直接驗證的困難（如記憶主觀陳述）愈容易被誇大，愈有標準化常模與效度指標可比對的困難（如智力、注意力測驗）愈容易在表現不一致中被辨識。

第 16 題

當接受正在進行心理治療個案的心理評估時，下列何者較不需要與轉介者澄清的衡鑑方向？
  1. （A）轉介者對於治療的概念是否與自己存在共識
  2. （B）轉介者是否面臨某些治療進展的議題，而需要衡鑑資料提供較佳的治療策略
  3. （C）轉介者是否想提供患者其他的治療方案或是評估治療的可能結果
  4. （D）轉介者是否想解決一些實務上的問題，例如患者對自己或他人是否具有危險性的評估

答案：（A）

詳解與考點

考點為對治療中個案進行衡鑑時的轉介澄清方向。要選較不需要澄清者。轉介者對治療的概念是否與自己有共識，較屬治療師個人理論立場，並非此次衡鑑必須先澄清的方向，故 A 為答案。B、C、D 涉及治療進展、替代方案、危險性評估等實務問題，皆需與轉介者澄清。標 med。

第 17 題

下列何者在其心理治療取向主張引導個案在真誠的關係下，進行經驗接觸、實驗探索等歷程，使其獲得重要的覺察、產生改變？
  1. （A）Erving Polster
  2. （B）Carl Rogers
  3. （C）Christine Padesky
  4. （D）Jon Kabat-Zinn

答案：（A）

詳解與考點

正解：關鍵在該取向是否以此時此地的經驗接觸、實驗與覺察為核心技術。Erving Polster 是完形治療（Gestalt therapy）的代表人物之一，其取向強調在真誠的治療關係中，透過經驗接觸與實驗探索促成個案的重要覺察並產生改變，故選 A。

B：Carl Rogers 為個人中心治療（person-centered therapy）的創始者，核心技術是治療師提供真誠一致、無條件正向關懷與同理心，而非以實驗探索促成覺察為特色技術。

C：Christine Padesky 為認知治療（cognitive therapy）代表人物，取向著重辨識與修正個案的自動化思考與核心信念，不以經驗接觸與實驗探索為主要技術。

D：Jon Kabat-Zinn 為正念減壓（mindfulness-based stress reduction）的創始者，取向著重當下覺察與非評判的接納，技術核心是正念練習而非治療關係中的實驗探索。

本題考點：治療取向與代表人物的對應——完形治療強調真誠關係中的經驗接觸與實驗探索（Erving Polster），個人中心治療強調真誠一致與同理（Carl Rogers），認知治療著重思考修正（Christine Padesky），正念減壓著重當下接納（Jon Kabat-Zinn）；判準是題幹描述的核心技術是否為「實驗探索促成覺察」這項完形治療的特色。

第 18 題

在心理治療歷程中檢視治療關係時，何種信念將有助於治療工作？
  1. （A）應改變自己的態度以符合個案期待
  2. （B）應認知到無法與每位個案都能有效工作的現實
  3. （C）要喜歡個案才能有效進行治療工作
  4. （D）要與個案有相同經驗才能有效進行治療工作

答案：（B）

詳解與考點

正解：判準是該信念是否務實面對治療師與個案配對的現實限制，而非陷入不切實際的專業迷思。認知到自己無法與每位個案都能有效工作，是務實看待治療師個人特質與個案適配度的健康信念，有助於治療師在必要時評估轉介，避免勉強維持無效的治療關係，故選 B。

A：認為應改變自己的態度以符合個案期待，等於放棄治療師的專業立場去迎合個案，可能損及治療的界線與方向，屬不利信念。

C：認為要喜歡個案才能有效進行治療工作，把治療效果建立在個人好惡之上，忽略專業技術與治療關係本身可以獨立於個人喜好而發揮作用，屬不切實際的迷思。

D：認為要與個案有相同經驗才能有效進行治療工作，過度窄化治療師發揮同理與專業判斷的條件，忽視治療師可透過專業訓練理解不同於自身經驗的個案處境，屬不切實際的迷思。

本題考點：治療關係中的健康信念判準——務實承認治療師與個案配對存在限制（並非人人都能有效工作）是健康信念；「改變自己迎合個案」「須喜歡個案」「須有相同經驗」皆把治療效果的必要條件窄化到個人層面，忽略專業訓練與技術本身的作用，屬妨礙專業界線的迷思。

第 19 題

「透過治療使潛意識浮上意識，達到理智與情緒上的覺察；幫助個案再次體驗早期經驗，修通被壓抑的衝突，引導重建基本人格」，以上敘述最符合何種取向的治療目標？
  1. （A）認知行為治療
  2. （B）完形治療
  3. （C）現實治療
  4. （D）精神分析

答案：（D）

詳解與考點

正解：本題問的是使潛意識浮上意識、修通被壓抑衝突、重建基本人格的敘述最符合何種治療取向的目標——判準是該取向是否以潛意識、壓抑衝突與人格重建為核心概念。使潛意識意識化、幫助個案再次體驗早期經驗以修通被壓抑的衝突、進而重建基本人格，是精神分析（psychoanalysis）的核心治療目標，故選 D。

A：認知行為治療（cognitive behavioral therapy）著重辨識與修正個案當下的非適應性思考與行為模式，不以潛意識意識化與人格重建為目標。

B：完形治療（Gestalt therapy）著重此時此地的經驗接觸與覺察，不強調潛意識、壓抑或人格重建等精神分析式的概念。

C：現實治療（reality therapy）著重個案當下的選擇與責任，聚焦滿足基本需求的具體行為改變，不涉及潛意識與早期經驗修通。

本題考點：各治療取向治療目標的辨識——「潛意識意識化」「修通壓抑衝突」「重建基本人格」三個關鍵詞直指精神分析；完形治療聚焦此時此地覺察、現實治療聚焦當下選擇與責任、認知行為治療聚焦思考行為修正，皆不以這三個概念為核心目標。

第 20 題

關於女性主義治療的原則，下列敘述何者錯誤？
  1. （A）女性主義治療的目標不僅是個人改變，更是社會改變
  2. （B）強調與案主之間的平等關係
  3. （C）心理不適不見得是種疾病，而是試圖傳達系統的不正義
  4. （D）認為政治與社會的不公平，僅會對少數產生壓迫

答案：（D）

詳解與考點

正解：關鍵在該取向對社會不公平影響範圍的主張。女性主義治療認為政治與社會的不公平會對廣泛群體（不限於少數）造成系統性壓迫，個案的心理困擾常與此結構性壓迫相關，敘述稱「僅會對少數產生壓迫」與其強調結構普遍性壓迫的精神相反，故 D 為應選項（要選錯誤者）。

A：女性主義治療的目標兼顧個人層次的改變與更廣泛的社會改變，敘述正確。

B：女性主義治療強調治療師與案主之間建立平等關係，避免傳統治療中權力不對等的結構，敘述正確。

C：女性主義治療認為心理不適不見得是一種疾病，而可能是個體試圖傳達其所處系統中不正義的訊號，敘述正確。

本題考點：女性主義治療的核心原則——目標兼顧個人與社會改變、強調治療關係中的平等、視心理不適為系統不正義的訊號；其對政治社會不公平的主張是「廣泛群體皆受壓迫」而非「僅少數受壓迫」，這是本題辨析的關鍵方向。

第 21 題

關於Carl R. Rogers所提的「真誠一致（congruence）」，下列敘述何者正確？
  1. （A）治療師將自身感受到個案所有的問題或情感立即地表達給個案
  2. （B）治療師在治療過程中對當下經驗的覺知抱持開放且有意願展現的態度
  3. （C）治療師努力在治療關係中選擇對於個案有益的部分表達給個案
  4. （D）唯有達到自我實現的治療師才能在治療中展現真誠一致

答案：（B）

詳解與考點

正解：判準是該概念指涉治療師對自身當下經驗的覺知態度，而非行為表達的形式或前提條件。真誠一致指治療師對治療過程中當下的經驗保持開放的覺知，且有意願在治療關係中適當展現，故選 B。

A：真誠一致並非要求治療師將自身感受到個案的所有問題或情感立即全盤表達給個案，若不加拿捏地宣洩所有感受，可能忽略對個案的治療效益，與真誠一致的原意不同，是本題最強誘答——分辨關鍵在於真誠一致講的是「對經驗保持開放並願意展現」，不等於「毫無篩選地立即全部說出」。

C：治療師努力選擇對個案有益的部分表達給個案，帶有策略性篩選的意味，偏向技巧性操作，而非對自身經驗保持開放的真誠一致。

D：主張唯有達到自我實現的治療師才能展現真誠一致，對真誠一致的達成條件設下過高門檻，與 Carl Rogers 認為真誠一致是治療師可持續努力的態度、而非須先達到某種完美境界的觀點不符。

本題考點：Rogers 真誠一致（congruence）概念的精確界定——核心是治療師對當下經驗保持開放的覺知並願意適當展現，不等於「毫無篩選地全盤宣洩感受」，也不是「策略性選擇性表達」，更不以「先達到自我實現」為前提條件。

第 22 題

存在主義取向治療中，關於自我覺察的主張，下列敘述何者正確？
  1. （A）個體具有行動或不行動的潛力，而不作為也是種決定
  2. （B）個體具有無限的時間與可能性，來完成人生的目標
  3. （C）個體能完全創造自身的命運
  4. （D）個體本質上是社會性的，因此才會體驗到孤獨

答案：（A）

詳解與考點

正解：本題問的是存在主義取向治療中關於自我覺察的主張何者正確——判準是該取向如何看待個體的自由與抉擇。存在主義取向認為個體具有行動或不行動的潛力，而選擇不行動本身也是一種決定，個體須為此決定負起責任，故選 A。

B：存在主義治療強調人的時間與生命是有限的（尤其面對死亡的必然性），而非擁有無限的時間與可能性，敘述與其核心觀點相反。

C：存在主義治療認為個體在自由與限制之間做抉擇，並非能夠完全創造自身的命運，敘述過度誇大個體的能動性。

D：存在主義治療認為孤獨是人類存在的基本處境之一，與個體本質上是否為社會性無關；敘述把孤獨的來源歸因為社會性本質，與其觀點不符。

本題考點：存在主義治療對自我覺察與自由的主張——行動與不行動皆為個體的選擇並須承擔責任；生命時間有限、個體無法完全創造命運、孤獨為存在的基本處境而非源於社會性本質，皆是常見的誤植方向。

第 23 題

根據齊克果（Kierkegaard）的概念，關於存在焦慮（existential anxiety），下列敘述何者正確？
  1. （A）存在焦慮是病理性的
  2. （B）是生命覺醒的必要歷程
  3. （C）會毀壞我們的自我
  4. （D）是與他人的依附困難

答案：（B）

詳解與考點

正解：關鍵在該概念被賦予的是病理性意涵，還是生命成長的建設性意涵。齊克果（Kierkegaard）認為存在焦慮（existential anxiety）是個體面對自由與抉擇時必然伴隨的體驗，是生命覺醒的必要歷程，具建設性意義，故選 B。

A：將存在焦慮視為病理性，把這種源於自由與抉擇的正常存在經驗誤當成疾病狀態，與齊克果視其為生命歷程一部分的觀點相反。

C：認為存在焦慮會毀壞自我，同樣把存在焦慮負面化為破壞性的力量，與其被視為促成覺醒與成長的觀點相反。

D：將存在焦慮界定為與他人的依附困難，把源自面對自由、選擇與存在本身的焦慮，誤導向人際依附關係的議題，混淆了兩種不同性質的焦慮來源。

本題考點：齊克果存在焦慮（existential anxiety）概念的核心——存在焦慮源於個體面對自由與抉擇的處境，是生命覺醒的必要歷程而非病理狀態，也不等同於會毀壞自我或屬於人際依附困難；判準是焦慮的來源是否指向自由與抉擇本身。

第 24 題

有關著重正念（mindfulness）與接納的治療取向，下列敘述何者正確？
  1. （A）接納與承諾治療（acceptance and commitment therapy）強調辨識、挑戰與改變個案的失功能思考內容
  2. （B）辯證行為治療（dialectal behavioral therapy）融合了認知行為、精神分析及東方禪修訓練
  3. （C）正念減壓法（mindfulness-based stress reduction）源自正念認知治療（mindfulness-based cognitive therapy）
  4. （D）正念減壓法的成分強調認知行為技巧的教導

本題送分，無標準答案

詳解與考點

本題經考選部公告一律給分。作答任一選項皆得分。原因是題目要找「正確」的敘述，但四個選項依主流教材都不成立：三個把不同取向的核心成分張冠李戴，一個把兩套課程的源流順序寫反。爭點集中在 B——辯證行為治療整合的是行為與認知技術、辯證哲學與東方禪修訓練，選項卻把辯證哲學換成精神分析；若採部分中文教材對其治療關係與情緒失調成因的寬鬆描述，B 又勉強可讀為對，命題依據因而不一致，故送分。

A：接納與承諾治療的核心是接納與認知去融合，改變的是個案與想法之間的關係並朝價值方向行動，不去辨識與挑戰思考內容；辨識、挑戰與改變失功能思考是認知治療的作法，術語掛錯了取向。

B：辯證行為治療確實融合了認知行為技術與東方禪修的正念訓練，但第三個成分是辯證哲學，強調接納與改變的對立統一，不是精神分析。這是四者中最接近成立的敘述，也是本題爭議所在。

C：方向反了——正念減壓法是較早發展的課程，正念認知治療才是把正念減壓法的架構與認知治療結合、用於預防憂鬱復發的後續產物，源流關係恰好相反。

D：正念減壓法以正念練習本身為主體，強調對身心經驗的覺察與不評價；認知行為技巧的教導是正念認知治療的成分，不是正念減壓法的重點。

本題考點：第三波行為治療各取向的成分辨識——接納與承諾治療（acceptance and commitment therapy）以接納與認知去融合為核心，辯證行為治療（dialectical behavior therapy）並用行為技術、辯證哲學與禪修正念，正念減壓法（mindfulness-based stress reduction）以正念練習為主體，正念認知治療（mindfulness-based cognitive therapy）則在正念減壓法的架構上加入認知治療元素以預防憂鬱復發；辨識的機械判準是先問這套取向要改變的是想法的內容，還是個案與想法之間的關係。

第 25 題

治療師提出外化（externalization）問句，將個案和其問題分離開來，此為何種心理治療學派的做法？
  1. （A）現實治療學派
  2. （B）交流分析學派
  3. （C）敘事治療學派
  4. （D）意義治療學派

答案：（C）

詳解與考點

正解：本題問的是外化（externalization）問句所屬的心理治療流派。將個案與其問題分開、視「問題是問題，人不是問題」，是敘事治療（narrative therapy）由 White 與 Epston 建立的標誌性技術，故選 C。

A：現實治療學派聚焦於個案的選擇與責任、透過需求與行動的檢視協助個案面對現實，並未以「外化問句」區分人與問題作為核心技術，不構成本題判準。

B：交流分析學派以自我狀態與人際交流腳本分析為核心，同樣不涉及外化問句。

D：意義治療學派著重協助個案發現生命意義以因應苦難，技術上不以「將問題外化」作為標誌性做法。

本題考點：外化問句是敘事治療（White 與 Epston）的標誌性技術判準——凡題幹描述「將個案與問題分離、問題被賦予獨立身分」即指向本學派；現實治療、交流分析、意義治療各有自身核心技術，不應與外化技術混淆。

第 26 題

下列何者為家族治療學者Bowen理論的核心概念？
  1. （A）自我分化
  2. （B）出生序
  3. （C）家庭連結
  4. （D）溝通模式

答案：（A）

詳解與考點

正解：本題問的是鮑文（Bowen）家庭系統理論的核心概念。自我分化（differentiation of self）指個體在情感連結中仍保有自主思考與理智反應的能力，是 Bowen 理論用以說明個人與家庭情緒系統關係的核心構念，故選 A。

B：出生序是阿德勒（Adler）學派用以理解手足位置對人格形成影響的概念，非 Bowen 理論核心。

C：家庭連結為泛稱敘述，未指向任何特定理論的核心構念，不足以與 Bowen 理論的自我分化相提並論。

D：溝通模式偏向薩提爾（Satir）取向或溝通學派對家庭互動型態的描述，與 Bowen 強調情緒系統中自主與融合張力的自我分化屬不同理論脈絡。

本題考點：家族治療各學派核心概念的對應判準——Bowen 理論看自我分化，Adler 學派看出生序，Satir／溝通取向看溝通模式；題目問「某學者理論核心概念」時，先鎖定學者名再比對其標誌性構念，不得跨學派套用。

第 27 題

下列何者屬於阿德勒治療學派（Adlerian）瞭解個案的途徑？
  1. （A）田野觀察（field observation）
  2. （B）早年記憶（early recollection）
  3. （C）認知地圖（congnition map）
  4. （D）生活空間（living space）

答案：（B）

詳解與考點

正解：本題問的是阿德勒（Adlerian）治療了解個案生活風格的途徑。早年記憶（early recollection）是阿德勒學派用以推斷個案核心信念與生活風格的標誌性技術，透過個案主動回憶的早期片段反映其對自我、他人與世界的基本態度，故選 B。

A：田野觀察是一般研究方法學上蒐集自然情境資料的方式，並非阿德勒學派了解個案的特定技術。

C：認知地圖屬托爾曼（Tolman）在學習心理學中描述有機體對空間環境內在表徵的概念，與阿德勒學派了解個案生活風格的途徑無關。

D：生活空間屬勒溫（Lewin）場地論中描述個體行為受其心理環境全體影響的構念，同樣不屬阿德勒學派技術。

本題考點：阿德勒學派了解個案的標誌性途徑是早年記憶；生活空間、認知地圖分屬 Lewin 場地論與 Tolman 學習理論，題目問「某學派了解個案的途徑」時須鎖定該學派專屬技術，不與其他學者的一般心理學構念混淆。

第 28 題

進行心理動力取向的年齡回歸（age regression）技術來治療解離性身份障礙症的個案，治療者需要留意下列那個事項？
  1. （A）要先給予個案藥物來協助放鬆
  2. （B）無須事先給予個案心理教育
  3. （C）喚起創傷事件的過程可能會惡化症狀
  4. （D）喚起創傷事件的過程治療師需坐在個案躺椅的斜後方

答案：（C）

詳解與考點

正解：本題問的是心理動力取向年齡回歸（age regression）技術治療解離性身份障礙症時的注意事項。喚起創傷事件的歷程可能引發個案再度暴露於創傷經驗、使症狀短暫惡化甚至誘發解離發作，治療者須具備風險評估與穩定化能力，故選 C。

A：年齡回歸技術的實施重點在治療關係中的引導與穩定化，並非以藥物協助放鬆為必要前提，是否用藥屬精神科評估範疇，非本技術的固有要求。

B：喚起創傷記憶前應先給予個案心理教育，說明技術目的、可能反應與因應方式，以建立知後同意與穩定基礎；「無須事先給予心理教育」與臨床實務相反。

D：年齡回歸屬心理治療會談中的引導技術，並無「治療師須坐在個案躺椅斜後方」這種固定座位規定，此為杜撰的形式細節。

本題考點：心理動力取向處理解離性身份障礙的核心注意事項——喚起創傷歷程有再創傷與症狀惡化風險，須以事先心理教育與穩定化技巧為前提；座位安排、給藥與否等形式規定非技術核心，不應被當作專業細節誤選。

第 29 題

某個案的原生文化重視權威，期待專家給予指導與問題解決。下列何項治療可能相對上較不符合該個案的期待？
  1. （A）精神分析
  2. （B）理情行為治療
  3. （C）現實治療
  4. （D）行為活化

答案：（A）

詳解與考點

正解：本題問的是治療取向與個案文化期待的適配程度。原生文化重視權威、期待專家直接給予指導與解答時，精神分析強調由治療師保持節制、透過自由聯想引導個案自行領悟，較少提供直接建議與具體解答，與該個案的期待落差最大，故選 A。

B：理情行為治療具高度指導性與結構性，治療師主動指出非理性信念並給予具體因應建議，較符合權威取向的期待。

C：現實治療以檢視需求與行動計畫為架構，主動引導個案，同樣具高度指導性，符合期待專家給予方向的個案。

D：行為活化以具體行為排程與任務指派為主要介入方式，治療師的指導角色明確，亦符合該文化期待。

本題考點：治療取向的指導性程度與文化期待的適配判準——重視權威、期待專家直接解答的個案較契合具指導性與結構性的治療（理情行為、現實治療、行為活化），精神分析因強調節制與個案自行領悟、指導性最低，最不符合此類期待。

第 30 題

關於處理兒童問題行為需考慮的因素，下列敘述何者正確？
  1. （A）發展里程強調的是能力因素
  2. （B）發展年齡強調的是年齡因素
  3. （C）行為功能分析強調的是環境因素
  4. （D）應用行為分析強調的是作業難度因素

答案：（C）

詳解與考點

正解：本題問的是處理兒童問題行為時各分析架構所對應強調的因素。行為功能分析（functional analysis）透過辨識行為與其前事及後果等環境變項的關聯，據以理解行為被何種環境條件維持，強調的正是環境因素，故選 C。

A：發展里程描述的是特定年齡層預期出現的行為指標，屬對照年齡常模的年齡因素，而非能力因素；本選項將發展里程與能力因素配對，屬概念錯置。

B：發展年齡是以個體實際展現的能力水準換算而得的等值年齡，用以呈現能力發展與生理年齡的落差，強調的正是能力因素而非年齡因素；本選項的配對與 A 恰好互換錯置。

D：應用行為分析著重行為改變是否具有社會意義與實用價值，並非以作業難度為核心強調的因素；作業難度屬其他分析架構的考量範疇。

本題考點：處理兒童問題行為的因素配對判準——行為功能分析看環境前事與後果、應用行為分析看社會效度而非作業難度、發展里程對照年齡常模、發展年齡反映能力水準；四者概念相近但強調面向互異，題目常以互換配對設計誘答。

第 31 題

下列何種狀況違反臨床心理師保密原則？
  1. （A）在協助採證詢問兒童性侵害被害人時，讓家屬用攝影機在另一個房間觀看
  2. （B）對主管機關提出性侵害加害人的身心治療評估報告
  3. （C）當青少年個案未付清治療費用，聯繫其法定代理人說明治療出席狀況，請求處理
  4. （D）在成年個案同意下，於書中寫下個案的治療歷程與故事

答案：（A）

詳解與考點

正解：本題問的是臨床心理師保密原則的界線，判準在於觀看採證詢問的對象是否具備專業與程序上的正當理由。標準做法是由司法、社工、醫療等專業人員於另一房間透過單向鏡或攝影機觀看，以避免兒童重複陳述造成二度傷害；若改由家屬觀看，家屬既非承辦案件之專業人員，讓其得知兒童揭露的性侵害細節，已逾越偵訊程序所需之知悉範圍，構成隱私外洩與保密原則的違反，故選 A。

B：對主管機關提出性侵害加害人的身心治療評估報告，屬法規要求下的通報與陳報義務，是保密原則的合法例外，不構成違反。

C：當青少年個案未繳清治療費用，聯繫其法定代理人說明治療出席狀況以請求處理費用事宜，屬因監護關係而必要揭露的範圍，未逾越合理必要限度。

D：在成年個案同意下，於書中寫下其治療歷程與故事，已取得個案本人的知後同意，屬保密原則下合法的揭露方式。

本題考點：保密原則的例外判準——揭露對象是否具備專業或法定正當理由（司法程序中的專業人員、主管機關通報、監護人聯繫）或是否取得個案本人同意，是判斷是否違反保密的核心；讓不具正當理由的家屬觀看採證詢問過程，即使出於陪伴或知情動機，仍逾越保密界線。

第 32 題

個案為3歲男童，臉部及身體有明顯外傷，已被緊急安置。個案出生後由祖母帶大，父母也已離婚。個案被母親接回監護已半年，並與母親、其同居人及所生的1歲女嬰同住，個案的外傷被高度懷疑是母親之同居人家暴造成。下列何者為最優先之處遇計畫？
  1. （A）由個案祖母照顧最安全
  2. （B）進行家庭功能、兒童安全評估和親職教育，確保個案安全
  3. （C）請個案母親接受心理輔導，就能照顧個案
  4. （D）家庭關係複雜，應留在安置機構最安全

答案：（B）

詳解與考點

正解：本題問的是兒童保護案件中最優先的處遇計畫。個案已因疑似家暴外傷而被緊急安置，此時尚未完成對照顧環境安全性的完整評估，最優先應進行家庭功能評估、兒童安全評估，並提供親職教育以確保個案後續照顧安排的安全性，故選 B。

A：直接交由祖母照顧，是在尚未完成安全評估前即認定特定照顧者「最安全」的武斷判斷，未考慮祖母是否具備持續照顧能力與意願、家庭系統現況等因素。

C：僅以母親接受心理輔導作為條件，即認定其「就能」恢復照顧能力，忽略同居人涉嫌施暴的高風險因子仍未排除，屬過早、未經評估的結論。

D：認定家庭關係複雜即應長期留置安置機構，同樣是未經個別化評估而逕行決定的處遇方式，違背兒少保護以評估為基礎、盡量維繫或修復家庭功能的處遇原則。

本題考點：兒童保護案件處遇計畫的優先順序判準——緊急安置後應先完成家庭功能與兒童安全評估，再依評估結果規劃親職教育或後續照顧安排；逕行指定照顧者或安置去向，而未經個別化安全評估，皆屬程序上的武斷決定。

第 33 題

臨床心理師給予個案個人社交軟體帳號，方便個案在痛苦情緒侵襲時，可以直接與他聯絡。亦會透過社交軟體邀約個案聚餐、出遊或看電影，藉此紓解個案的痛苦情緒。這呈現何項專業倫理爭議？
  1. （A）未能妥善保護個案在心理治療過程中的隱私
  2. （B）在未獲得個案同意下，即對個案採取一個新的治療策略
  3. （C）在進行臨床心理工作時，未具有相對應的專業能力
  4. （D）在心理治療期間，與個案發展專業關係以外的情感關係

答案：（D）

詳解與考點

正解：本題問的是治療關係中專業界線的倫理爭議類型。臨床心理師給予個案個人社交軟體帳號、並透過社交軟體邀約聚餐、出遊或看電影以紓解個案情緒，已逾越治療所需的專業互動範圍，在治療關係之外發展出私人的情感或社交關係，構成多重關係的倫理爭議，故選 D。

A：本情境的核心問題不在於治療紀錄或談話內容等隱私資料是否被妥善保護，而在於治療師主動跨出治療架構、與個案發展治療外的私人往來，隱私保護並非本題描述的爭議焦點。

B：情境中並未涉及治療師在未取得同意下更換治療策略或技術，題目描述的是社交互動的界線問題，與治療策略的知後同意無關。

C：邀約聚餐出遊與具備何種臨床專業能力無關，題目情境並未顯示治療師在臨床工作上有能力不足之處，而是關係界線的逾越。

本題考點：治療關係中專業界線的判準——凡治療師以私人身分與個案發展治療目的以外的社交或情感往來（私訊聯繫、聚餐出遊等），即構成多重關係的倫理爭議；需與隱私保護、知後同意、專業能力等其他倫理面向區辨，核心差異在於是否逾越治療架構發展私人關係。

第 34 題

根據臨床心理師倫理規範，有關心理治療紀錄與心理衡鑑原始資料的保管責任，下列敘述何者錯誤？
  1. （A）無論目的為何，須先徵得個案同意，方可使用相關的資料
  2. （B）若為專業教學需要，但無法取得個案同意時，應遮蔽任何可供辨識身分的資料
  3. （C）當接觸到社會矚目案件之個案時，為求公正透明，可公布精神鑑定的過程與結果
  4. （D）若個案有傷害他人或自殺的可能性時，應儘快通知其法定代理人或有關單位

答案：（C）

詳解與考點

正解：本題問的是心理治療紀錄與心理衡鑑原始資料保管責任中，何者為錯誤敘述。即使個案為社會矚目案件之當事人，臨床心理師仍不得以求公正透明為由，逕行公布精神鑑定的過程與結果，個案的隱私保護不因社會關注程度而降低，故 C 為錯誤敘述、應選之答案。

A：無論資料使用目的為何，原則上須先徵得個案同意方可使用相關資料，此為保密原則的一般要求，敘述正確。

B：若因專業教學需要而無法取得個案同意，仍應遮蔽任何可供辨識身分的資料以保護隱私，此為教學使用下的必要防護措施，敘述正確。

D：若個案有傷害他人或自殺的可能性，基於危險個案的示警義務，應儘快通知其法定代理人或有關單位，此為保密原則的合法例外，敘述正確。

本題考點：治療紀錄與衡鑑資料保管的保密判準——使用須經同意、教學用途須去識別化、危及生命安全時有通報義務，此三者皆為保密原則下合法且必要的處理方式；社會矚目與否不構成公布個案鑑定資料的正當理由，以公益之名包裝洩密仍屬違反保密原則。

第 35 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「專業責任與價值」，下列那一項是臨床心理服務的社會基礎之一？
  1. （A）社會大眾的信任
  2. （B）臨床心理師的人格
  3. （C）專業倫理的訂定
  4. （D）科學知識的堅持

答案：（A）

詳解與考點

正解：本題問的是臺灣「臨床心理師倫理準則與行為規範」中，「專業責任與價值」基本準則所指的臨床心理服務社會基礎為何。臨床心理專業之所以能取得社會認可與委託執業的正當性，根本奠基於社會大眾對此專業的信任，此信任正是「社會基礎」一詞所指涉的內涵，故選 A。

B：臨床心理師個人的人格特質屬於個別執業者的素養層面，並非整體專業得以立足於社會的制度性基礎。

C：專業倫理的訂定是維繫專業信任的手段之一，但倫理準則本身是規範工具，而非社會基礎本身；社會基礎指的是倫理規範所欲維護的社會大眾信任。

D：科學知識的堅持屬於專業能力與實務品質的要求面向，與題目所問「社會基礎」的社會關係層次不同。

本題考點：專業倫理中「社會基礎」一詞的判準——指專業得以在社會中立足與運作所仰賴的公眾信任關係，而非個人特質、規範工具或知識能力本身；人格、倫理訂定、科學知識分屬其他層面的專業要求，不應與「社會基礎」混淆。

第 36 題

若要評估心理治療療效，下列何種研究方法最具證據力？
  1. （A）個案研究法（case study）
  2. （B）隨機控制試驗（randomized controlled trial）
  3. （C）案例對照研究法（case-control study）
  4. （D）類比實驗法（analogue experiment study）

答案：（B）

詳解與考點

正解：本題問的是評估心理治療療效時何種研究設計最具證據力。隨機控制試驗（randomized controlled trial, RCT）透過隨機分派將參與者分至治療組與對照組，得以控制組間先天差異等干擾變項，使觀察到的效果差異能較有信心地歸因於治療本身，是療效研究中證據力最高的設計，故選 B。

A：個案研究法僅針對單一或少數個案深入描述，缺乏對照組與隨機分派，結果難以類推至其他個案，證據力低於 RCT。

C：案例對照研究法屬回溯性設計，依結果反推可能成因，易受選樣偏誤與回憶偏誤影響，證據力同樣低於前瞻性且具隨機分派的 RCT。

D：類比實驗法以模擬情境或類似問題的樣本進行研究，雖具實驗控制，但外在效度受限，對實際臨床療效的推論證據力不及以真實個案進行的 RCT。

本題考點：療效研究證據力層級的判準——隨機分派加上對照組是證據力的核心來源，RCT 因兩者兼具而居首；個案研究缺對照、案例對照為回溯性設計、類比實驗受限於樣本與情境的外在效度，證據力皆低於 RCT。

第 37 題

某研究探討心理治療與藥物治療對憂鬱症的效果，安排參與者自行選擇任一治療參加。此作法最可能威脅下列何種效度？
  1. （A）外在效度
  2. （B）建構效度
  3. （C）內在效度
  4. （D）生態效度

答案：（C）

詳解與考點

正解：本題問的是研究方法中，參與者自行選擇治療方式此一設計最可能威脅的效度類型。當參與者依個人偏好自行選擇接受心理治療或藥物治療，而非隨機分派，兩組在接受治療前即可能因動機、症狀嚴重度或人格特質等因素存在系統性差異，使研究者難以確定觀察到的效果差異是源自治療本身還是這些先天組間差異，此正是內在效度所欲控制的問題，故選 C。

A：外在效度關注研究結果能否推論至其他母群體或情境，與本題「能否確認治療是效果來源」的因果推論問題不同層次。

B：建構效度關注研究所操弄或測量的變項是否確實反映其欲代表的理論構念，與分組方式所致的組間先天差異無直接關聯。

D：生態效度關注研究情境與真實生活情境的相似程度，同樣非本題非隨機分組所直接威脅的效度類型。

本題考點：實驗設計效度威脅的判準——非隨機分派使組間存在先天系統差異，直接威脅內在效度即能否將效果歸因於處理本身；外在效度看推論範圍、建構效度看變項操作是否符合理論構念、生態效度看情境真實性，四者關注面向互異，不可混淆。

第 38 題

關於心理治療研究中採用控制組設計，下列敘述何者錯誤？
  1. （A）有助釐清實驗組的改善是否源自治療本身
  2. （B）治療研究可採用不同類型的控制組
  3. （C）安慰劑組常採用等待接受治療名單
  4. （D）最嚴謹的控制組為已被證實有效的治療

答案：（C）

詳解與考點

正解：本題問的是心理治療研究採用控制組設計時，何者為錯誤敘述。安慰劑組（placebo group）旨在控制非特定治療因素，如個案對接受治療的期待與注意力效應，其設計通常涉及提供某種看似治療但不具特定治療成分的介入；等待接受治療名單（wait-list）則是讓控制組個案暫不接受任何治療、僅列於等候名單，兩者所控制的變項與操作方式不同，不可等同視之，故 C 為錯誤敘述、應選之答案。

A：控制組設計的基本目的正是透過比較有無介入或介入類型不同的組別，釐清實驗組的改善是否確實源自治療本身而非其他因素，敘述正確。

B：心理治療研究可依研究目的採用不同類型的控制組，如等待名單、安慰劑組、已證實有效治療對照組等，敘述正確。

D：以已被證實有效的治療作為對照組，可同時控制期待效應與非特定因素，並直接比較新介入相對於現行有效治療的效果，是療效研究中最嚴謹的控制組設計，敘述正確。

本題考點：心理治療研究控制組類型的判準——等待名單控制組（wait-list control group）是完全不給予介入的消極對照，安慰劑組（placebo group）是給予不具特定治療成分的介入以控制期待等非特定因素，兩者不可混為一談；以已證實有效治療為對照組因同時控制多重干擾因素而證據力最嚴謹。

第 39 題

關於創傷性腦傷之記憶衡鑑，下列敘述何者錯誤？
  1. （A）自傳記憶可反映回溯性（retrograde）失憶問題
  2. （B）立即和延宕回憶可反映前向性（anterograde）失憶問題
  3. （C）前向性失憶患者的數字逆序背誦表現可能為正常
  4. （D）「常識測驗」是回溯性失憶的主要指標之一

答案：（D）

詳解與考點

正解：本題問的是創傷性腦傷記憶衡鑑中，何者為錯誤敘述。常識測驗所測量的是個體長期累積、已鞏固為語意記憶的舊有知識，其表現受教育程度與智力等因素影響甚鉅，並非用以評估回溯性（retrograde）失憶的主要指標，故 D 為錯誤敘述、應選之答案。

A：自傳記憶涉及個人生活經驗的回憶，能反映患者能否提取受傷前既有的個人經歷，可用以評估回溯性失憶問題，敘述正確。

B：立即回憶與延宕回憶測驗評估的是個體學習新資訊並於短時間後提取的能力，能反映前向性失憶問題，敘述正確。

C：前向性失憶患者的即時記憶廣度通常保留完整，而數字逆序背誦涉及工作記憶的操弄而非新長期記憶的形成，其表現可能不受前向性失憶影響、維持正常，敘述正確。

本題考點：創傷性腦傷記憶衡鑑的判準——自傳記憶對應回溯性失憶、立即與延宕回憶對應前向性失憶、工作記憶（如數字逆序）不必然受前向性失憶影響；常識測驗反映的是穩固的語意記憶存量，不宜作為回溯性失憶的主要評估指標。

第 40 題

關於實施心理測驗對於心理治療之功用，下列敘述何者錯誤？
  1. （A）滿足個案對心理測驗的好奇心
  2. （B）協助個案了解困擾問題
  3. （C）提供治療計畫的參考
  4. （D）描述個案的認知與情緒狀態

答案：（A）

詳解與考點

正解：本題問的是實施心理測驗對心理治療功用之敘述，何者錯誤。心理測驗的實施應服務於治療目標與臨床決策，滿足個案對心理測驗本身的好奇心並非測驗實施的正當治療功用，故 A 為錯誤敘述、應選之答案。

B：測驗結果可協助個案更清楚地了解自身困擾問題的性質與嚴重程度，是測驗在治療歷程中的合理功用，敘述正確。

C：測驗結果可作為擬定治療計畫的參考依據，協助治療師選擇適切的介入方向，敘述正確。

D：測驗可用以描述個案當下的認知功能與情緒狀態，提供客觀資料輔助臨床判斷，敘述正確。

本題考點：心理測驗於治療脈絡中功用的判準——測驗實施須服務於治療目標，包括協助個案自我了解、提供治療計畫參考、描述認知情緒狀態等；個案或治療師個人的好奇心並非測驗實施的正當理由，不應與上述臨床目的混淆。
