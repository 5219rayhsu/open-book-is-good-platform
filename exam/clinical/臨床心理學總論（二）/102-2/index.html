第 1 題

下列何者不是執行心理衡鑑的臨床工作者應具有的基本能力？
  1. （A）心理測驗的背景知識、相關概念
  2. （B）對法律知識的通盤了解
  3. （C）對每一種使用的衡鑑工具有概念上的了解
  4. （D）臨床心理學的基礎知識

答案：（B）

詳解與考點

正解：題眼在「不是」心理衡鑑工作者的基本能力——基本能力須能支撐工具選擇、施測、解釋與臨床整合。臨床工作者應了解與工作相關的法律與倫理邊界，但不以「通盤了解」所有法律為執行心理衡鑑的基本能力，故選 B。

A：測驗背景知識與相關概念是判讀分數、限制與適用性的基礎，故非答案。

C：每一使用工具都須有概念性了解，才能選得適切並避免錯誤解釋，故非答案。

D：臨床心理學基礎知識使測驗結果能與轉介問題及臨床資料整合，故非答案。

本題考點：心理衡鑑（psychological assessment）的核心勝任能力；測驗知識（test knowledge）；法律與倫理的相關性判斷。

第 2 題

下列那一個測驗不屬於記憶功能領域的衡鑑工具？
  1. （A）WMS-III
  2. （B）RAVLT
  3. （C）BVRT
  4. （D）MMSE

答案：（D）

詳解與考點

正解：題眼在「不屬於記憶功能領域」——要分辨專門記憶測驗與廣泛認知篩檢工具。WMS-III、RAVLT 與 BVRT 分別評估不同形式的記憶或視覺保留功能；MMSE 是整體認知狀態的簡短篩檢，雖含記憶題目，並非記憶功能領域的專門衡鑑工具，故選 D。

A：WMS-III 是魏氏記憶量表，主要用於記憶功能衡鑑，故非答案。

B：RAVLT 以語詞學習與延宕回憶等表現衡量言語記憶，故非答案。

C：BVRT 評估視覺保留與視覺記憶相關功能，故非答案。

本題考點：記憶衡鑑（memory assessment）；魏氏記憶量表（Wechsler Memory Scale）；簡短心智狀態檢查（Mini-Mental State Examination, MMSE）是整體認知篩檢。

第 3 題

對於衡鑑報告中的行為觀察，下列敘述何者正確？
  1. （A）報告中可以寫道：「個案是憂鬱的。」
  2. （B）報告中可以寫道：「一位 14 歲的男孩卻有 18 歲的心智。」
  3. （C）報告中可以寫道：「某人看起來不修邊幅，但他的遣詞用句卻非常深奧。」
  4. （D）報告中可以寫道：「他說話很緩慢，顯示其在社交上是小心翼翼的。」

答案：（C）

詳解與考點

正解：題眼在「行為觀察」——行為觀察應記錄可直接觀察或可追溯的表現，並避免把推論、診斷或不精確標籤當作事實。C 描述外觀與遣詞用句的可觀察特徵，未越界推斷其心理狀態，故選 C。

A：「憂鬱」是臨床判斷或症狀概括，不是具體可觀察行為；應改記錄表情、語速或陳述內容。

B：「有 18 歲的心智」既不具明確可觀察性，也把複雜能力化成不精確的年齡標籤。

D：說話緩慢可觀察，但「顯示其在社交上小心翼翼」是未驗證的心理推論，不能混入行為觀察。

本題考點：行為觀察（behavioral observation）；描述與推論的區分；心理衡鑑報告的可追溯性。

第 4 題

下列何者最能說明心理衡鑑遞增效度（incremental validity）的意義？
  1. （A）多使用一份衡鑑工具能增加解釋和決策的正確性
  2. （B）進行愈多次衡鑑，可以獲得愈多關於個案的訊息
  3. （C）進行衡鑑時須同時包含行為觀察、智能與人格測驗
  4. （D）提供資料者愈多，對個案會有更全面的了解

答案：（A）

詳解與考點

正解：題眼在「遞增效度」——判準不是工具或資訊愈多愈好，而是新增資料是否在既有資料之外，實際提高解釋或決策的正確性。多一份衡鑑工具若提供不重複且有用的資訊，能改善判斷，即是遞增效度，故選 A。

B：衡鑑次數增加只代表資料量增加，未必改善決策。

C：同時使用多種方法是常見的多方法衡鑑思路，但未說明新增工具是否帶來額外效益。

D：資料提供者增加可使觀點更完整，仍須證明其資訊能超越既有資料提升判斷。這是最強誘答，因為它看似符合多元來源原則，錯在沒有遞增正確性的判準。

本題考點：遞增效度（incremental validity）；效度（validity）；新增資料的非重複貢獻與決策效益。

第 5 題

認知衡鑑與行為衡鑑的共同點為何？
  1. （A）以觀察法為蒐集資料的最主要方法
  2. （B）須將情境變項納入考慮
  3. （C）衡鑑資料容易受個案記憶偏差所影響
  4. （D）都須由行為資料推論內在歷程

答案：（B）

詳解與考點

正解：題眼在「認知衡鑑與行為衡鑑的共同點」——兩者都不能脫離個案行為發生的脈絡。認知衡鑑須考量測驗情境、文化與動機等因素；行為衡鑑也須分析前因、後果與環境條件，因此皆須將情境變項納入考慮，故選 B。

A：行為衡鑑重視觀察，但認知衡鑑常以標準化測驗、會談與作業表現蒐集資料，不能說兩者皆以觀察為最主要方法。

C：記憶偏差較直接影響自陳資料，不能作為兩種衡鑑共同的核心特徵。

D：行為衡鑑可著重可觀察的功能關係，未必都要由行為推論內在歷程；這把認知取向的推論要求套到行為衡鑑。

本題考點：認知衡鑑（cognitive assessment）；行為衡鑑（behavioral assessment）；情境變項（situational variables）與脈絡化解釋。

第 6 題

下列有關行為衡鑑的敘述，何者正確？
  1. （A）主要目標是了解個人的人格如何影響其行為
  2. （B）主要目標是了解個人的智能如何影響其行為
  3. （C）強調行為是某些持久的內在特質的結果
  4. （D）特別關切個體和環境互動時，明顯可觀察的層面

答案：（D）

詳解與考點

正解：題眼在「行為衡鑑」——其核心是觀察個體行為與環境條件的功能關係，包括前因、行為與後果，而非以固定內在特質作主要解釋。因此特別關切個體和環境互動時可觀察的層面，故選 D。

A：以人格影響行為為主要目標較接近人格取向，非行為衡鑑的中心。

B：智能如何影響行為屬認知或智能衡鑑的問題，非行為衡鑑的主要目標。

C：把行為歸因於持久內在特質，正與行為衡鑑重視情境及學習史的觀點相反。

本題考點：行為衡鑑（behavioral assessment）；功能分析（functional analysis）；前因—行為—後果（ABC）之環境互動。

第 7 題

關於主題統覺測驗（TAT）的使用原則之敘述，下列何者最為正確？
  1. （A）必須根據精神分析理論進行結果解釋
  2. （B）主要用來鑑別精神病人與非病人的人格狀態
  3. （C）可以對人格進行較全面性的評估，這稱為廣距（wide-band）取向
  4. （D）可以用一張主題統覺測驗的圖片進行分析

答案：（C）

詳解與考點

正解：題眼在「TAT 的使用原則」——主題統覺測驗可作為了解個案人際主題、需求、衝突與敘事組織的資料來源，通常要與會談、觀察及其他衡鑑資料整合；其可對人格作較廣泛的探索，稱為廣距取向，故選 C。

A：TAT 的歷史雖與心理動力傳統有關，結果不必只能依精神分析理論解釋。

B：TAT 不宜作為區分精神病人與非病人之主要診斷工具，因其解釋需審慎且不能單獨定論。

D：單一圖片可提供有限素材，但不能以一張卡片就完成可靠的人格分析；這是最強誘答，因為單張敘事確實能討論，錯在把局部臨床素材誤當完整衡鑑。

本題考點：主題統覺測驗（Thematic Apperception Test, TAT）；投射技術（projective techniques）；廣距取向（wide-band approach）與多元資料整合。

第 8 題

關於 WISC-IV 測驗結果的解釋：「立即性的問題解決能力」優於「以累積知識為基礎的問題解決能力」， 且兩者差異達到.05 顯著水準時，下列何者最為正確？
  1. （A）知覺推理高於語文理解
  2. （B）語文理解高於知覺推理
  3. （C）知覺推理高於處理速度
  4. （D）處理速度高於知覺推理

答案：（A）

詳解與考點

正解：題眼在「立即性的問題解決能力」優於「以累積知識為基礎的問題解決能力」——在 WISC-IV 中，前者主要對應知覺推理，後者主要對應語文理解；題目又明示兩者差異達顯著，故可判定（A）知覺推理高於語文理解，故選 A。此處為 WISC-IV 的版本敏感解釋，不可直接移用其他版的指數結構。

B：語文理解高於知覺推理把兩種能力的高低方向完全倒置；累積語文知識與語文概念推理較佳時，才會支持這個敘述。

C：處理速度是另一個指數，題幹沒有提供它與知覺推理的比較，不能由兩項能力的差異外推。這是最強誘答，因為它同樣提到知覺推理，但比較的對象已換成題幹未談及的處理速度。

D：同樣沒有處理速度高低的資訊，且與題幹所給的兩項指數比較無關。

本題考點：魏氏智力量表第四版（Wechsler Intelligence Scale for Children–Fourth Edition, WISC-IV）的指數解釋——知覺推理偏向新穎、非語文問題的推理；語文理解偏向已習得的語文知識與概念；顯著差異只能支持題幹明示的兩個指數比較。

第 9 題

關於羅氏墨跡測驗分數之意義，下列敘述何者正確？
  1. （A）整體反應部位多，代表組織與適應環境的能力強
  2. （B）發展品質分數反映個人正確知覺環境訊息的能力
  3. （C）色彩濃度之質感代表自我檢視的痛苦歷程
  4. （D）空白反應部位多，與否定態度有關

答案：（D）

詳解與考點

正解：題眼在「羅氏墨跡測驗分數之意義」與「空白反應部位」——空白部位反應指受試者把墨跡的空白當作知覺組織的一部分；在傳統羅夏克解釋中，較多此類反應可反映對外在刺激採取反向、否定或對抗的態度，故選 D。此類指標的意義受計分系統與整份反應脈絡影響，不宜單獨作人格定論。

A：整體反應部位多主要表示採用整張墨跡作答的傾向，不能直接等同於組織與適應環境能力強；組織品質仍須另看。

B：發展品質著重知覺組織的成熟與整合程度，不是單純衡量是否「正確知覺環境訊息」。

C：質感（texture, T）反應反映的是對親密與情感接觸的需求；對應痛苦自我檢視歷程的是立體（vista, V）反應。兩者同屬濃淡類決定因，選項把 T 的名稱配上 V 的意義，張冠李戴，故非答案。這是最強誘答，因為 V 確實代表痛苦的自我檢視，考生若只記住「濃淡類就是內在痛苦」而未分辨 T 與 V，就會誤選。

本題考點：羅夏克墨跡測驗（Rorschach Inkblot Test）——反應部位、發展品質與決定因分別描述不同的反應特徵；空白部位反應可提示否定或對抗傾向；投射測驗結果須結合反應內容、效度與臨床資料判讀。

第 10 題

王華在 WAIS-III 的符號替代、記憶廣度、算術及數字序列得分都低於平均數一個標準差，下列何者最可 能說明其得分低的意義？
  1. （A）速度慢
  2. （B）短期記憶有問題
  3. （C）動機低
  4. （D）排序有問題

答案：（D）

詳解與考點

正解：題眼在四個低分分測驗同時包含符號替代、記憶廣度、算術與數字序列——它們雖各涉及速度或短期記憶，但共同要求暫時保留、操作並依序排列資訊；最能整合這個跨分測驗型態的是排序／序列處理困難，故選 D。此為 WAIS-III 的版本敏感分測驗解釋，僅憑低分型態仍不能診斷單一認知缺陷。

A：符號替代確實與處理速度有關，但記憶廣度、算術與數字序列的共同低分不能全以速度慢解釋。

B：記憶廣度與數字序列涉及短期記憶，但符號替代與算術還要求其他歷程，範圍太窄。這是最強誘答，因為它抓到部分分測驗的共同成分，卻沒有涵蓋四項作業都需要的序列操作。

C：低動機可能影響表現，但題幹只給出特定認知作業的共同低分，沒有提供行為觀察或效度資料支持動機解釋。

本題考點：魏氏成人智力量表第三版（Wechsler Adult Intelligence Scale–Third Edition, WAIS-III）分測驗型態——解釋要找跨作業的共同認知需求；工作記憶（working memory）包含暫存與操作資訊；低分型態需配合行為觀察與其他衡鑑資料。

第 11 題

對會談資料的解釋原則，下列敘述何者正確？
  1. （A）測驗分數所支持的會談資料與轉介問題有關時，在最後的報告中應被強調
  2. （B）重要的會談資料，無論與轉介目的有無關係，都應被納入最後的報告
  3. （C）會談資料不能用來解釋個案的性格、因應型態及情緒
  4. （D）會談資料僅提供對個案過去歷史的了解，應依照時間先後順序加以解釋

答案：（A）

詳解與考點

正解：題眼在「會談資料」與「轉介問題」——心理衡鑑報告的選材判準是與待答轉介問題的關聯性；若會談資料又獲測驗分數支持，便形成跨方法的收斂證據，應在結論中適度強調，故選 A。

B：重要性不能脫離轉介目的判斷；無關資料全數納入會使報告失焦，也增加不必要的隱私揭露。

C：會談可提供個案的情緒、因應型態與人格功能假設，再與其他資料互相驗證，因此說「不能」過度限縮其功能。

D：會談不只用來重建過去史，也可觀察當下互動、情緒與認知；報告應依臨床問題組織，不必機械按時間排序。

本題考點：心理衡鑑報告（psychological assessment report）——以轉介問題導向選材；跨方法收斂證據（convergent evidence）提高解釋可信度；會談資料兼具病史、當下觀察與臨床假設功能。

第 12 題

下列關於回饋心理衡鑑報告給個案之敘述，何者正確？
  1. （A）主試者回饋衡鑑結果給個案時，需因個案的狀況而作適度的調整
  2. （B）主試者提供適當的衡鑑結果給個案，對治療的療效助益不大
  3. （C）主試者只需提供正確的臨床判斷，不需要考慮個案的整體生活脈絡
  4. （D）主試者的衡鑑報告應重視病理的專業性，但不應讓個案看到診斷結果

答案：（A）

詳解與考點

正解：題眼在「回饋」與「個案的狀況」——衡鑑回饋的目的在協助個案理解結果並能實際使用，故內容、語言、節奏與情緒支持都要依其認知能力、心理狀態及處遇脈絡調整，故選 A。調整是讓資訊可理解，不是扭曲臨床判斷。

B：適切且可理解的回饋可促進個案對問題與處遇的理解，不能概括說對療效助益不大。

本題考點：衡鑑回饋（assessment feedback）——個別化溝通；脈絡化解釋（contextualized interpretation）；知後同意（informed consent）與減少汙名化並行。

詳解與考點

正解：題眼在「眼動減敏重建法」——EMDR 以創傷記憶的處理為中心，透過雙側刺激等程序協助個案重新處理創傷經驗及其失功能信念；在四個選項中，（B）重建對創傷事件的認知最符合其主要用途，故選 B。

A：探索被壓抑的早期記憶較像精神分析式探索；EMDR 並非以挖掘被壓抑記憶為目標。

C：降低特定對象焦慮可用暴露等方法處理，但沒有指出創傷記憶的重新處理，範圍過窄。這是最強誘答，因為 EMDR 可能降低創傷相關焦慮，錯在將它誤寫成針對特定對象的單純恐懼處遇。

D：提升挫折忍受力可為不同治療的目標，非 EMDR 最具辨識性的核心。

本題考點：眼動減敏與歷程更新治療（Eye Movement Desensitization and Reprocessing, EMDR）——創傷記憶處理（trauma-memory processing）；失功能信念的重建（cognitive reprocessing）；創傷相關焦慮不同於特定恐懼症的暴露處遇。

第 26 題

Wubbolding 根據 Glasser 的現實治療方法發展出 WDEP 治療程序，下列臨床心理師的問話那一句屬於 E？
  1. （A）「你目前在做什麼？」
  2. （B）「你說你會停止憂鬱，那你現在要做什麼可以達到這個目標？」
  3. （C）「假如你的生活就是你要的，你會做些什麼？」
  4. （D）「你目前所做的可以讓你得到你想要的嗎？」

答案：（D）

詳解與考點

正解：題眼在 WDEP 的字母 E 與問句「可以讓你得到你想要的嗎」——WDEP 中 E 是 evaluation，邀請個案評估目前行為是否有效地滿足其想要的目標；因此（D）正是在評估行動效果，故選 D。

A：「你目前在做什麼？」是在問 Doing，屬 D。

B：「現在要做什麼可以達到這個目標？」是在形成具體計畫，屬 Planning，為 P。

C：「假如你的生活就是你要的」聚焦個案想要什麼，屬 Wants，為 W。這是最強誘答，因為它也要求反思生活，然而反思的對象是願望而非現行行為是否有效。

本題考點：WDEP 治療程序（WDEP system）——W＝想要（Wants）；D＝正在做的事（Doing）；E＝評估（Evaluation）；P＝計畫（Planning）。

第 27 題

培養父母領導的能力和解開家中錯誤的互動，為下列何種治療取向的主要治療目標？
  1. （A）阿德勒家族治療
  2. （B）多世代家族治療
  3. （C）結構派家族治療
  4. （D）策略派家族治療

答案：（A）

詳解與考點

正解：題眼在「培養父母領導能力」與「解開家中錯誤互動」——阿德勒家族治療重視家庭星座、目標導向行為與父母教養，透過鼓勵父母採取民主而有效的領導，修正錯誤目標和互動循環，故選 A。

B：多世代家族治療主要關注跨世代傳遞、分化與三角關係，並非以培養父母領導為最具辨識性的目標。

C：結構派家族治療也處理家庭權力與次系統界線，是最強誘答；但題幹的「錯誤互動」與父母領導能力是阿德勒取向的典型用語，而非結構派重組界線與階層的表述。

第 28 題

「內在對話的改變在個案行為的改變上扮演關鍵角色」，此為何種治療學派的觀點？
  1. （A）女性主義治療學派
  2. （B）現實治療學派
  3. （C）認知行為治療學派
  4. （D）意義治療學派

答案：（C）

詳解與考點

正解：題眼在「內在對話的改變」與「行為的改變」——判準是治療是否把自動想法、信念與自我對話視為行為改變的近端機制。認知行為治療學派主張個案對事件的解釋會影響情緒與行為；修正失功能的內在對話，便可帶動新的行為反應，故選 C。

A：女性主義治療重視性別權力關係、社會脈絡與增權，並非以改變內在對話作為其核心定義。

B：現實治療著重個案的選擇、責任與目前行為是否有效，核心提問是個案能做何種較有效的行動，不以認知重建為主要途徑。這是最強誘答，因為它同樣關心行為改變；關鍵差別是題幹把改變的樞紐放在「內在對話」。

D：意義治療聚焦於人在限制與苦難中尋找意義、承擔自由與責任，不能由題幹的認知改變線索推出。

本題考點：認知行為治療（cognitive behavioral therapy）——以自動想法與核心信念影響情緒、行為為判準；現實治療（reality therapy）——著重當下選擇與有效行動；意義治療（logotherapy）——著重生命意義。

第 29 題

下列何者符合個人中心治療學派（person-centered therapy）的同理瞭解（empathic understanding）概念？
  1. （A）同理瞭解要求治療者如同個案一般感受，直至無法分辨兩人的分別
  2. （B）同理瞭解並不涉及個案沒有表達的感受與情緒，以保持個案的自主
  3. （C）同理瞭解甚至可以感受到個案的超心靈感覺
  4. （D）同理瞭解是超越表層的理解，更加深入地觸及個案的經驗感受

答案：（D）

詳解與考點

正解：題眼在個人中心治療的「同理瞭解」——判準是治療者深入掌握個案主觀經驗，同時仍保有「如同」理解而不與個案混同。D 所說超越表層、深入觸及個案經驗感受，符合此一同理歷程，故選 D。

A：同理不是治療者變得與個案毫無分別；若失去自我與他人的界線，反而不能以治療者位置回應個案。

B：同理可嘗試理解個案尚未充分言說、但在敘述與情緒中顯露的經驗；是否探索須尊重個案步調，不等於只能重複已說出口的內容。

C：超心靈感覺不是個人中心治療對同理的定義。同理的依據是細緻聆聽與暫時進入個案的內在參照架構，不是通靈式感知。

本題考點：同理瞭解（empathic understanding）——深入理解個案內在參照架構，且維持自他界線；個人中心治療（person-centered therapy）——以同理、真誠與無條件積極關懷促進改變。

第 30 題

下列何者是阿德勒治療學派（Adlerian）處理過程中，與社會興趣有關的主要治療目標？
  1. （A）培養個案的內在興趣（inner interest）
  2. （B）改變個案的錯誤信念（faulty belief）
  3. （C）改變個案的生活風格（life style）
  4. （D）增強個案的意志力量（will power）

答案：（C）

詳解與考點

正解：題眼在阿德勒治療的「社會興趣」——判準是協助個案由自我中心的錯誤目標，轉向與他人合作、貢獻社群的生活方式。生活風格是個案早期形成、用以追求歸屬與優越的整體生活取向；治療藉由修正它來發展社會興趣，故選 C。

A：內在興趣不是阿德勒治療處理社會興趣時的主要概念；社會興趣指共同體感與對他人的關懷。

B：改變錯誤信念可出現在多種治療中，也可為阿德勒治療的工作內容，但題目問的是與社會興趣直接相連的主要治療目標，應是較整體的生活風格改變。

D：意志力量強調靠意志壓制或推動行為，不能說明個案如何形成合作與貢獻的關係取向。

本題考點：阿德勒治療（Adlerian therapy）——以生活風格（life style）理解個案的目標與關係模式；社會興趣（social interest）——指共同體感、合作與貢獻傾向。

第 31 題

「心理分析治療師維持中性態度，不表露自己」是為了最後讓個案：
  1. （A）轉化潛意識
  2. （B）移情潛意識
  3. （C）投射潛意識
  4. （D）分析潛意識

答案：（C）

詳解與考點

正解：題眼在心理分析治療師的「中性態度」與「不表露自己」——判準是降低治療師的現實特質對個案知覺的干擾，使個案將既有重要關係的感受與期待置入治療關係。這種把內在關係表徵歸於治療師的過程是移情；題目選項雖以「投射潛意識」表述，指向的正是讓個案把內在內容投射到治療師身上，故選 C。

A：轉化潛意識不是心理分析中由中性態度所直接要促成的標準概念。

B：移情是關鍵概念，但「移情潛意識」的措辭不精確；題目所述中性位置是讓個案投射其既有內在模式，之後才可在移情中加以分析。這是最強誘答，因為它抓到移情一詞，卻未對應選項所問的具體作用。

D：分析潛意識是治療工作的大方向，不能具體說明為何治療師要避免自我表露。

本題考點：中性（neutrality）——減少治療師現實特質干擾；移情（transference）——個案將早期關係中的感受與期待帶入治療關係；投射（projection）——將內在內容歸於外在他人。

第 32 題

下列何者符合個人中心治療學派（person-centered therapy）的接納（acceptance）概念？
  1. （A）完全接納個案必須贊成（approval）個案的行為
  2. （B）接納是肯認（recognition）個案有權表達自己的信念與感受
  3. （C）接納不能超越「無害」（harmless）的原則
  4. （D）接納是提醒治療者必須全程（at all times）地真誠接納與無條件積極關懷

答案：（B）

詳解與考點

正解：題眼在個人中心治療的「接納」——判準是尊重個案作為一個人的價值與其表達感受、信念的權利，而非認可每一項行為。B 正確指出接納是肯認個案可以表達其信念與感受，故選 B。

A：接納不等於贊成行為。治療者可以理解個案的感受與需要，同時不贊成傷害自己或他人的行為。

C：以「無害」作為接納不能跨越的界線，混淆了接納個人與對行為進行風險、倫理判斷兩件事。

D：無條件積極關懷是重要治療態度，但「全程」真誠接納把治療者的內在反應理想化為毫無波動；專業要求是覺察並適切處理反應，不是假裝沒有反應。這是最強誘答，因為它使用無條件積極關懷的術語，錯在將其化為不可能的全程情緒狀態。

本題考點：接納（acceptance）——尊重個案的價值、感受與表達權利；無條件積極關懷（unconditional positive regard）——重視個案作為人的價值，不等於贊成所有行為。

第 33 題

下列何者屬於存在治療學派（existential therapy）中的治療者任務？
  1. （A）協助個案認識到在治療中呈現的自己並不是個案全部的自己
  2. （B）支持個案面對他／她長久以來逃避的潛意識慾望
  3. （C）幫助個案完成自我生命的敘說
  4. （D）協助個案釐清生活任務的先後順序，並且教導他／她有效的執行步驟

答案：（A）

詳解與考點

正解：題眼在存在治療的治療者任務——判準是協助個案面對自由、責任、孤獨、死亡等存在議題，並以較真實的方式看待自己。A 讓個案認識治療中呈現的自己只是整體存在的一部分，可避免把暫時角色或症狀等同於全部自我，符合此取向，故選 A。

B：面對長久逃避的潛意識慾望是心理分析取向的典型工作語言。

C：協助個案完成生命敘說較接近敘事治療對故事重寫與替代故事的工作，不能單憑生命敘說判為存在治療。

D：釐清生活任務並教導有效執行步驟，偏向具體問題解決與行為技能訓練，非存在取向的核心任務。

本題考點：存在治療（existential therapy）——協助個案面對存在處境並真實地選擇；真實性（authenticity）——不將片段經驗或社會角色誤認為全部自我。

第 34 題

研究結果顯示，對於團體治療療效的看法，個案最重視下列何者？
  1. （A）醫病關係與臨床心理師人格特質
  2. （B）臨床心理師所採用的治療技巧與治療理念
  3. （C）個案的問題特性與心理特性
  4. （D）團體成員互動的特性與效應

答案：（A）

詳解與考點

正解：題眼在「個案最重視」的團體治療療效看法——判準是個案對有效治療最直接感受到的共同因素。治療關係的品質與臨床心理師展現的可信、同理與投入，常是個案評價療效時最重視的面向，故選 A。

B：治療技巧與理念會影響處遇，但個案未必以學派技術本身作為首要療效判準。

C：個案問題與心理特性會影響適配性與結果，卻不是個案評價治療是否有效時最直接重視的治療提供因素。

D：團體成員互動確為團體治療的重要療效因素，但題目問的是研究中個案最重視的因素；治療關係與治療者特質更居核心。這是最強誘答，因為它精準說到「團體」的特色，卻把重要團體機轉誤當成個案首要的療效評價。

本題考點：共同因素（common factors）——治療關係、同理與合作常與療效密切相關；治療聯盟（therapeutic alliance）——個案與治療者的工作合作與情感連結。

第 35 題

有關「有時限之動力心理治療」（Time-Limited Dynamic Psychotherapy, TLDP）之描述，下列何者錯誤？
  1. （A）TLDP 的治療焦點並不在於減輕症狀本身
  2. （B）TLDP 建基在人際理論、客體關係理論、自體心理學理論，以及認知行為取向
  3. （C）TLDP 的治療目標在於修正個人與他人建立關係的方式
  4. （D）TLDP 視移情為個案對於臨床心理師的一種扭曲認知

答案：（D）

詳解與考點

正解：題眼在「何者錯誤」與 TLDP 的理論整合——判準是它以人際循環中的重複關係模式為焦點，將移情視為可觀察與理解該模式的資料，而非單純錯誤認知。D 把移情說成個案對臨床心理師的扭曲認知，過度縮減了動力取向對移情的理解，故為應選項。

A：TLDP 的工作焦點在核心人際衝突與關係模式；症狀改善可隨之出現，但不以直接消除症狀作為唯一焦點，故此敘述可成立。

B：TLDP 整合人際、客體關係、自體心理學及認知行為觀點來理解關係循環，符合其整合性取向。

C：修正個案與他人建立關係的重複方式，正是以關係循環為焦點的治療目標。

本題考點：有時限之動力心理治療（Time-Limited Dynamic Psychotherapy, TLDP）——聚焦重複的人際關係模式；移情（transference）——是理解治療關係與既有關係表徵的臨床資料，不等同認知扭曲。

根據當代客體關係學者 Margaret Mahler 的觀點，沒有完成分離-個體化的嬰兒，可能會發展出下列何種疾 患？

  2. （B）依賴型人格
  3. （C）自戀型人格
  4. （D）邊緣型人格

  2. （B）同意個案律師的要求，將評估結果交給法院
  3. （C）暫時不要將評估結果交給法院，請個案與律師討論
  4. （D）尋求專家諮詢，若專家同意，則將評估結果交給法院

答案：（C）

詳解與考點

正解：題眼在法院心理評估、個案拒絕揭露與律師主張有利——判準是先釐清委託關係、知後同意與資訊揭露授權，不能由律師單方判斷取代個案對評估結果的決定。C 先暫不交付並請個案與律師討論，保留個案與法律代理人釐清授權及程序的空間，故選 C。

A：把報告帶至法院並預備隨時提供，等於在授權與程序未釐清前就讓機密資料面臨揭露風險。

B：律師認為結果有利，不當然構成臨床心理師對法院揭露資料的充分授權。

D：專家諮詢可協助倫理判斷，但不能由專家同意取代個案的知後同意或適當法律程序。這是最強誘答，因為它看似審慎，錯在把外部專家的意見誤作揭露權限的來源。

本題考點：知後同意（informed consent）——評估目的、資料用途與揭露範圍須預先釐清；保密（confidentiality）——未具適當授權或法定程序時不得任意揭露心理衡鑑資料。本題涉及司法委託的揭露程序，具體權限仍須依委託內容與法定程序確認。

第 38 題

下列何者符合研究與出版的倫理原則？
  1. （A）剔除某些數據使得統計分析達到顯著差異
  2. （B）沒有適當的貢獻下掛名為論文的共同作者
  3. （C）不論學生的貢獻多少，皆應以有學術地位的指導教授作為研究發表的第一作者
  4. （D）引用他人的研究或觀點，要適當地註明，以免與自己的內容混淆

答案：（D）

詳解與考點

正解：題眼在研究與出版的倫理原則——判準是研究紀錄與作者資訊必須忠實、可追溯，並清楚區分自己的工作與他人貢獻。D 要求適當引用他人研究或觀點，避免混同為自己的內容，符合學術誠信，故選 D。

A：為取得顯著差異而剔除資料，是以結果導向扭曲分析；資料排除必須有事先合理的方法學依據。

B：未有適當貢獻者掛名共同作者，違反作者資格應反映實質貢獻的原則。

C：作者排序應依實際貢獻與共同約定處理，不能不論學生貢獻一律將指導教授列為第一作者。

本題考點：學術誠信（research integrity）——誠實呈現資料與分析；作者資格（authorship）——應反映實質貢獻；引用（citation）——清楚標示他人觀點與研究來源。

第 39 題

有關心理治療的結案時機，下列何者最可能違反專業倫理？
  1. （A）個案認為不再需要接受心理治療，臨床心理師與個案討論她（他）想結案的動機
  2. （B）臨床心理師發現心理治療不再產生療效，因此主動與個案討論轉介事宜
  3. （C）臨床心理師發現自己的個案量太多，因此主動與個案討論結案的可能
  4. （D）臨床心理師發現個案原有的心理問題仍不見緩解，因此主動徵詢個案對終止治療關係的看法

答案：（C）

詳解與考點

正解：題眼在「最可能違反專業倫理」的結案時機——判準是終止治療須以個案利益、治療目標與適當轉介為優先，不能主要為了治療者自己的行政便利。C 因個案量太多而主動討論結案，若沒有連結個案需求與連續照護安排，最可能構成不當終止，故選 C。

A：個案提出不再需要治療時，討論其結案動機與準備程度是負責任的結案評估。

B：若治療未再產生療效，與個案討論轉介可維護其持續獲得適切服務的權益。

D：問題未緩解時可探詢個案對治療關係與終止的看法，但仍須評估風險、治療替代方案與轉介需要；此敘述本身不必然是為治療者方便而終止。

本題考點：終止治療（termination）——以個案福祉與治療目標為核心；不當終止（abandonment）——未妥善評估、轉介或交接而使個案失去必要服務。

第 40 題

有關臨床心理師的專業能力，下列何者最不會涉及倫理問題？
  1. （A）一位被診斷為雙極性疾患第 I 型的個案，正在家裡大吵大鬧，並且手中拿著刀子，揚言要自殺。您沒有 處理過該類型個案，但是附近沒有精神醫療院所，而鄰居知道您是臨床心理師，因此請您協助幫忙安 撫該個案
  2. （B）臨床心理師必須具有足以確保能夠勝任專業服務的能力，因此臨床心理師在任何情況之下，不得執行 與自己的能力不符的臨床心理師業務
  3. （C）一位小時候曾經被性騷擾的女性個案，要求被一位女性臨床心理師治療，而該機構只有一位未受過相 關訓練的女性臨床心理師，為了尊重個案的要求，該女性臨床心理師得以為這位個案進行治療
  4. （D）一位臨床心理師所治療的個案屢次在學校攻擊其他同學，因此學校計畫將這位個案退學，臨床心理師 為了維護個案的權益，決定到學校跟校長解釋個案的治療狀況

答案：（A）

詳解與考點

正解：題眼在「最不會涉及倫理問題」與立即自殺危機——判準是危急情境下，臨床心理師即使對該疾患沒有專門經驗，仍可在能力範圍內採取必要的緊急安全行動並尋求支援。A 是眼前持刀、自殺威脅且缺乏近端醫療資源的危機，協助安撫與啟動緊急處遇不等於逾越專業能力，故選 A。

B：「任何情況之下」都不得執行能力外業務，忽略緊急情境可以先做最低限度的安全處置、同時尋求督導或轉介的例外需要。

C：尊重個案偏好不能取代專業勝任；未受相關訓練者僅因性別符合要求就承接創傷治療，仍涉及能力不足。

D：為個案權益向校長說明治療狀況，若未取得適當授權或未限縮必要資訊，會涉及保密與資訊揭露問題。這是最強誘答，因為維護個案權益的目的正當，錯在不能跳過保密與授權程序。

本題考點：專業勝任（competence）——在受訓與能力範圍內服務；危機處遇（crisis intervention）——自殺、他傷等立即風險以安全優先，先採必要行動並取得支援；保密（confidentiality）——對外說明個案資訊須有適當依據。此題的緊急處遇界線與實際通報、轉介程序會受現場可用資源影響，應依當時風險採取必要安全行動。
