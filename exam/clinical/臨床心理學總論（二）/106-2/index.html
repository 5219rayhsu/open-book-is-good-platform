第 1 題

關於臨床晤談的敘述，下列何者錯誤？
  1. （A）是歷史發展上最早從個案身上得到資料的形式
  2. （B）受精神分析的影響，臨床晤談的風格變得比較開放
  3. （C）結構化晤談的興起，與強調診斷效率有關
  4. （D）結構化晤談，比較能夠收集個案的獨特性

答案：（D）

詳解與考點

正解：題眼在「何者錯誤」與「結構化晤談」——判準是結構化程度對資料標準化與個別敘事的影響。結構化晤談以固定題目和順序提升一致性與診斷效率，通常較不容易充分收集個案的獨特性；D 把方向講反了，故為應選項。

A：臨床晤談是直接從個案蒐集資料的早期且基本形式，故非答案。

B：精神分析重視自由聯想與個案主觀經驗，確實促成較開放的晤談風格，故非答案。

C：結構化晤談興起的重要目的之一是提高診斷的一致性與效率，故非答案。

本題考點：結構化晤談（structured interview）以標準化提高一致性；非結構化晤談（unstructured interview）較能追隨個案敘事與獨特性；診斷效率（diagnostic efficiency）與個別化資料深度須權衡。

第 1 題

關於魏氏記憶量表的解釋原則，下列何者錯誤？
  1. （A）記憶是複雜功能，會被記憶以外因素影響
  2. （B）分數組型（patterns）可以用來診斷特定臨床問題
  3. （C）有關記憶損傷的認定標準得視個案的情況而定
  4. （D）解釋結果時首重指數分數的表現

答案：（B）

詳解與考點

正解：題眼在「何者錯誤」與魏氏記憶量表的解釋原則——記憶表現必須結合病史、觀察、其他認知功能與轉介問題整合判斷，不能由分數組型單獨診斷特定臨床問題，故選 B。

A：注意力、語言、動機、情緒與感覺動作等非記憶因素都會影響記憶測驗表現，此敘述正確，故非答案。

C：記憶損傷的判定需參照個案原有能力、教育與文化背景、功能影響及其他衡鑑資料，不能只用單一固定標準，故正確。

D：指數分數提供主要認知構念的概括資訊，通常是解釋組型時的重要起點；仍須再看分測驗與其他資料，故此敘述並非錯誤。

本題考點：魏氏記憶量表（Wechsler Memory Scale）——評估結果須做多來源整合；分數組型解釋（profile interpretation）——可形成臨床假設，但不能單獨作為診斷依據。

第 2 題

一項心理測驗，可以在 100 名憂鬱症患者中篩檢出 90 名符合憂鬱症診斷者，並於 100 名非精神疾病患者 中確認出 95 名不符合憂鬱症診斷者，下列等式何者錯誤？
  1. （A）敏感度＝90/100
  2. （B）特異度＝95/100
  3. （C）偽陽性＝5/95
  4. （D）偽陰性＝10/100

答案：（C）

詳解與考點

正解：題眼在患者組與非精神疾病組各 100 人，以及「何者錯誤」——先列四格：患者組中篩出 90 人，真陽性＝90、偽陰性＝10；非精神疾病組中確認 95 人陰性，真陰性＝95、偽陽性＝5。敏感度＝真陽性／所有患者＝90/100；特異度＝真陰性／所有非患者＝95/100；偽陰性率＝偽陰性／所有患者＝10/100。偽陽性應以非患者組為分母，為5/100，而非5/95，故 C 錯誤。

A：90/100 是患者中被正確篩出的比例，符合敏感度定義，故非答案。

B：95/100 是非患者中被正確判為陰性的比例，符合特異度定義，故非答案。

D：10/100 是患者中未被篩出的比例，符合偽陰性率，故非答案。

本題考點：敏感度（sensitivity）＝真陽性／所有實際患者；特異度（specificity）＝真陰性／所有實際非患者；偽陽性率（false positive rate）＝偽陽性／所有實際非患者。

第 2 題

針對學校或教育場域中之兒童，臨床心理師進行衡鑑時，第一個階段的工作是？
  1. （A）評估家庭的特性
  2. （B）評估學習環境的本質與品質
  3. （C）擬訂教育安置計畫
  4. （D）實施完整的心理測驗

答案：（B）

詳解與考點

正解：題眼在學校或教育場域衡鑑的「第一個階段」——先釐清兒童所在學習環境的要求、資源、教學品質與問題情境，才能界定轉介問題並決定後續衡鑑，故選 B。

A：家庭特性是重要背景資料，但教育場域的初步工作先要掌握問題發生的學習脈絡。

C：教育安置計畫應在蒐集與整合資料後擬訂，不能先於問題界定。

D：完整心理測驗不是起點；未先評估環境與轉介問題就施測，容易蒐集到不切題資料。這是最強誘答，因為心理測驗確為衡鑑工具，錯在程序過早。

本題考點：教育場域衡鑑（school-based assessment）——先理解學習環境與轉介問題；生態觀點（ecological perspective）——兒童表現須放在家庭、班級與學校脈絡中理解。

第 3 題

在心理衡鑑中，關於臨床心理師的角色，下列何者最正確？
  1. （A）最重要的工作就是施測和計分
  2. （B）是一個全然客觀的專家，不涉入任何判斷
  3. （C）運用測驗資料對個案進行分類
  4. （D）必須蒐集與整合個案資料，並結合臨床心理學與相關領域的知識，以回答特定問題

答案：（D）

詳解與考點

正解：題眼在「心理衡鑑中」與「最正確」——判準是臨床心理師是否從轉介問題出發，整合多來源資料與專業知識形成可回答問題的判斷。蒐集並整合個案資料，結合臨床心理學及相關知識回答特定問題，正是心理衡鑑的核心角色，故選 D。

A：施測與計分只是資料蒐集環節，不能取代結果解釋、整合與臨床判斷。

B：專業判斷必須盡量客觀、可追溯，但心理衡鑑不可能完全不涉入判斷；重點在依證據作透明整合。

C：分類可為衡鑑的一部分，但僅把個案歸類過度限縮角色，未涵蓋轉介問題與個別處遇需求。這是最強誘答，因為診斷分類確實重要；但衡鑑不是只貼診斷標籤。

本題考點：心理衡鑑（psychological assessment）整合會談、測驗、觀察與背景資料；轉介問題（referral question）決定資料蒐集與解釋方向；臨床判斷（clinical judgment）須結合證據與專業知識。

第 3 題

在心理衡鑑中，下列何者不屬於臨床心理師應該擔負的角色？
  1. （A）對個案問題的可能成因形成假設，並提出治療相關建議
  2. （B）提供轉介來源相關的決策建議
  3. （C）仲裁個案與家屬對病情的判斷何者較為正確
  4. （D）整合所蒐集的各方面資料，回答轉介者的特定問題

答案：（C）

詳解與考點

正解：題眼在「不屬於」臨床心理師於心理衡鑑的角色——心理師應整合不同來源資料、提出假設與建議，卻不以權威身分仲裁個案與家屬誰對病情的看法較正確，故選 C。

A：對可能成因形成可檢驗假設，並依衡鑑結果提出處遇建議，是衡鑑的核心功能，故非答案。

B：回應轉介問題並提供決策所需資訊，是臨床心理師的重要角色，故非答案。

D：整合晤談、觀察、測驗與背景資料以回答特定轉介問題，正是心理衡鑑的基本任務，故非答案。

本題考點：心理衡鑑（psychological assessment）——整合多元資料以回答轉介問題；多方資訊（multi-informant data）——不同觀點應被比較與說明，而非由心理師簡化為誰對誰錯。

第 4 題

在測量工具之編製與信效度驗證時，無法進行下列何者之檢測？
  1. （A）內容效度
  2. （B）效標關聯效度
  3. （C）建構效度
  4. （D）概念效度

答案：（D）

詳解與考點

正解：題眼在「測量工具之編製與信效度驗證」與「無法進行」——判準是選項是否為心理計量學中可操作、可檢驗的效度類型。內容效度、效標關聯效度與建構效度都有明確的驗證途徑；「概念效度」不是此處標準的效度檢測類別，故選 D。

A：內容效度可由題目是否充分代表欲測內容領域來檢視，故非答案。

B：效標關聯效度可檢驗量表分數與外在效標的關係，故非答案。

C：建構效度可累積多種證據，檢驗工具是否測得欲測的理論建構，故非答案。

本題考點：內容效度（content validity）檢視題項代表性；效標關聯效度（criterion-related validity）檢視與外在效標的關聯；建構效度（construct validity）檢視工具是否反映理論建構。

第 4 題

關於投射測驗的敘述，下列何者錯誤？
  1. （A）計分系統複雜
  2. （B）計分過於主觀
  3. （C）診斷敏感度高
  4. （D）時間、金錢成本高

答案：（C）

詳解與考點

正解：題眼在「投射測驗」與「何者錯誤」——投射測驗的限制常包括施測與計分耗時、計分與解釋複雜，以及不同方法間的主觀性問題；不能概括宣稱其診斷敏感度高，故選 C。

A：投射測驗常涉及複雜的施測、編碼或解釋程序，此敘述正確，故非答案。

B：若缺乏標準化程序或評分者訓練，計分與解釋易受主觀判斷影響，是其常見批評，故非答案。

D：專業施測、計分與解釋所需時間及人力成本可能較高，故此敘述正確。

本題考點：投射測驗（projective tests）——以模糊刺激引出反應；診斷效度（diagnostic validity）——工具效用須依特定用途與證據判斷，不能因工具類型而概括保證。

第 5 題

根據 Groth-Marnat（2009），進行心理衡鑑時，使用行為觀察、心理測驗或個人史等資料，各自所形成的 暫時性假設間具有一致性傾向，則此衡鑑具有：
  1. （A）建構效度
  2. （B）概念效度
  3. （C）增益效度
  4. （D）內容效度

答案：（B）

詳解與考點

正解：題眼在「行為觀察、心理測驗或個人史」所形成的暫時性假設「具有一致性」——判準是不同資料來源是否共同支持同一個潛在概念。當獨立蒐集的資料收斂到相近的解釋時，表示衡鑑所測得的概念獲得多重證據支持，故選 B。

A：建構效度是較上位的總稱，包含收斂與區辨等多種證據；題幹特別問的是不同方法結果相互一致，較精確的名稱是概念效度中的收斂支持。

C：增益效度關心新加入的測驗資料，是否能在既有資料之外增加預測或判斷價值；題幹沒有比較加入前後的增益。

D：內容效度檢視測驗題目是否充分代表欲測的內容領域，重點在題目取樣，不在多種資料的結論是否一致。

本題考點：概念效度（concept validity）——多種資料來源收斂支持同一假設；增益效度（incremental validity）——新資訊是否增加判斷價值；內容效度（content validity）——題目是否代表內容領域。

第 5 題

有關行為衡鑑，下列敘述何者錯誤？
  1. （A）以可觀察之行為推論內在人格
  2. （B）再測信度易受環境變異的影響
  3. （C）發展初期常仰賴觀察法收集資料
  4. （D）注重對於行為的前置因素與結果進行功能分析

答案：（A）

詳解與考點

正解：題眼在行為衡鑑「何者錯誤」——行為衡鑑直接描述可觀察行為及其情境功能，不以觀察到的行為反推穩定的內在人格特質，故選 A。

B：行為會隨情境、時間與觀察條件改變，再測結果可能受環境變異影響，故非答案。

C：行為衡鑑早期常以直接觀察、紀錄與訪談蒐集資料，故非答案。

D：分析行為發生前的條件與行為後果，是功能分析的核心，故非答案。

本題考點：行為衡鑑（behavioral assessment）——以具體可觀察行為及情境為焦點；功能分析（functional analysis）——檢視前置因素、行為與結果的關係。

第 6 題

有關行為衡鑑與傳統衡鑑方式的差異，下列何者正確？
  1. （A）行為衡鑑強調行為是某些持久的內在特質的結果
  2. （B）行為衡鑑強調行為的環境決定因子
  3. （C）傳統衡鑑比較著重功能取向
  4. （D）傳統衡鑑強調症狀的情境脈絡

答案：（B）

詳解與考點

正解：題眼在「行為衡鑑」與「傳統衡鑑方式的差異」——判準是行為衡鑑把可觀察行為放回其前因、後果與情境中，尋找可改變的環境變項。它強調行為的環境決定因子，故選 B。

A：將行為視為持久內在特質的結果，是傳統特質取向較常採用的解釋，不是行為衡鑑的核心。

C：功能取向問的是行為在何種情境出現、帶來何種後果，正是行為衡鑑的特色；傳統衡鑑較常以症狀、特質或診斷分類組織資料。

D：症狀的情境脈絡也是行為衡鑑特別重視的資料，而非傳統衡鑑的主要強調處。

本題考點：行為衡鑑（behavioral assessment）——分析行為與環境條件的功能關係；功能分析（functional analysis）——聚焦前因、行為與後果；特質取向（trait approach）——以相對穩定的內在特質解釋行為。

第 6 題

心理生理衡鑑（Psychophysiological Assessment）常用的評估指標，不包含下列何者？
  1. （A）膚電反應
  2. （B）肌肉張力
  3. （C）簡易心智功能評估（MMSE）
  4. （D）腦波活動

答案：（C）

詳解與考點

正解：題眼在「心理生理衡鑑」與「不包含」——心理生理衡鑑記錄生理訊號以評估喚起或神經生理功能；MMSE 是以作答評估整體認知狀態的篩檢工具，不是生理訊號，故選 C。

A：膚電反應反映交感神經相關的皮膚導電變化，是常用心理生理指標，故非答案。

B：肌肉張力可透過生理紀錄反映緊張或放鬆狀態，故非答案。

D：腦波活動是神經電生理紀錄，可用於心理生理衡鑑，故非答案。

本題考點：心理生理衡鑑（psychophysiological assessment）——以生理訊號輔助評估；簡易心智功能評估（Mini-Mental State Examination, MMSE）——認知篩檢工具，非心理生理指標。

第 7 題

下列何者是結構式晤談的缺點？
  1. （A）容易產生月暈效應（halo effect）
  2. （B）容易忽略個案的獨特性及資料豐富性
  3. （C）會產生驗證性偏誤（confirmatory bias）
  4. （D）心理計量的信效度較低

答案：（B）

詳解與考點

正解：題眼在「結構式晤談的缺點」——判準是高度標準化雖提升不同施測者間的一致性，卻會限縮追問與調整空間。固定題目與順序容易忽略個案的獨特脈絡，也較難取得豐富的延伸資料，故選 B。

A：月暈效應是衡鑑者受單一突出印象影響整體判斷的偏誤；結構化程序反而有助於降低任意印象的影響。

C：驗證性偏誤是只尋找支持既有假設的資訊。它可能發生在任何會談，但不是結構式晤談最具代表性的限制。

D：結構式晤談的優點之一正是題目與評分一致，通常有較佳的心理計量信度；最強誘答在於把「彈性較少」誤當成「信效度較低」，兩者方向不同。

本題考點：結構式晤談（structured interview）——以標準化提問提升一致性；個案化資料（idiographic information）——需要彈性追問以保留脈絡與豐富性；衡鑑者偏誤（clinician bias）——應以程序化蒐證降低。

第 7 題

有關心理測驗之性質，下列敘述何者正確？
  1. （A）句子完成測驗屬於性向測驗
  2. （B）比西量表是一種團體式智力測驗
  3. （C）屋－樹－人測驗屬於投射性測驗
  4. （D）KMHQ 是性格的投射性測驗

答案：（C）

詳解與考點

正解：題眼在各測驗的「性質」——屋－樹－人測驗以繪圖反應作為投射性材料，屬投射性測驗，故選 C。

A：句子完成測驗通常依未完成語句的反應探索主題與態度，屬投射性或半結構式評估，不是性向測驗。

B：比西量表是個別施測的智力測驗，不是團體式測驗。

D：KMHQ 是人格量表，並非以模糊刺激引發自由反應的投射性測驗。這是最強誘答，因為它同樣用於人格相關評估，關鍵在量表與投射測驗的施測形式不同。

本題考點：屋－樹－人測驗（House-Tree-Person Test）——繪圖式投射性測驗；投射性測驗（projective test）——使用相對模糊的刺激蒐集反應；個別智力測驗（individual intelligence test）——由施測者一對一依標準程序進行。

第 8 題

使用魏氏智力測驗協助診斷智能不足時，下列敘述何者錯誤？
  1. （A）全量表總分可用來代表成人與孩童的智力
  2. （B）以常模來推論全量表總分 70 分以下的人口比例約為 2.3%
  3. （C）全量表總分 70 分以下時，即可診斷為智能不足
  4. （D）以離差（deviation）的概念來代表智力商數

答案：（C）

詳解與考點

正解：題眼在「協助診斷智能不足」與「何者錯誤」——判準是智力量表的全量表總分只能提供智力功能證據，診斷還必須整合適應功能與發展史等臨床資料。因此（C）把全量表總分 70 分以下直接等同診斷，錯在省略必要的適應功能衡鑑與整體判斷，故選 C。

A：魏氏智力量表的全量表總分可概括受測者的一般認知能力，成人與孩童各應使用相應版本的量表，故此敘述的方向正確。

B：以離差智商的常態分配概念解讀，70 分以下約落在平均數下兩個標準差附近；題目所列比例是此常模推論，並非診斷比例。

D：現代魏氏量表以受測者相對同齡常模的位置，也就是離差概念來表示智力商數，敘述正確。

本題考點：智能障礙症（intellectual disability）——診斷須整合智力功能、適應功能與發展期證據；離差智商（deviation IQ）——以同齡常模相對位置表示分數；心理衡鑑（psychological assessment）——不得以單一量表切截分數取代診斷。本題涉及魏氏量表版本與常模解讀，題幹的分數與比例僅能依其命題脈絡使用。

第 8 題

有關衡鑑晤談各項技巧的使用時機與注意事項，下列敘述何者正確？
  1. （A）不應使用面質的技術
  2. （B）臨床心理師應全心觀察個案的各種非口語行為
  3. （C）時間不應有限制，而是取決於蒐集的資訊是否已足夠而定
  4. （D）宜避免使用「為什麼」的問句

答案：（D）

詳解與考點

正解：題眼在衡鑑晤談技巧的「使用時機與注意事項」——「為什麼」問句容易使個案感到被質疑或被要求辯解，較適合改用開放且具體的問法，因此宜避免使用，故選 D。

A：面質可在關係與時機合宜時，用來指出言行或資料間的不一致；不能一概禁止。

B：臨床心理師須留意非口語行為，但「全心」只放在觀察可能忽略傾聽、互動與自我監測，並非恰當表述。

C：衡鑑晤談須有合理時間框架與流程安排；是否資訊足夠固然重要，卻不能因此完全不設時間限制。

本題考點：衡鑑晤談（assessment interview）——兼顧關係建立、資料蒐集與時間結構；開放式問句（open-ended question）——以較少防衛性的方式促進個案敘說。

第 9 題

羅夏克墨漬測驗 Exner's Comprehensive System 中的 HVI 指數，最可能與下列何種 DSM-IV-TR 心理疾患 的診斷有關？
  1. （A）強迫疾患
  2. （B）廣泛性焦慮疾患
  3. （C）妄想型思覺失調症
  4. （D）創傷後壓力疾患

答案：（C）

詳解與考點

正解：題眼在 Exner 綜合系統的「HVI 指數」——它是與過度警覺、猜疑式人際知覺相關的作答型態指標；在題目所列 DSM-IV-TR 診斷中，最貼近此種妄想與猜疑主題的是（C）妄想型思覺失調症，故選 C。本題沿用命題當時用語；現行 DSM-5 中文版稱思覺失調症，且不再以妄想型作為診斷亞型。

A：強迫疾患的核心是侵入性強迫思考與重複行為，不以猜疑性的人際警覺為主要判準。

B：廣泛性焦慮疾患是跨多領域、難以控制的過度擔憂；雖可能緊張警覺，仍不能把一般焦慮直接等同 HVI 所指的猜疑式知覺。

D：創傷後壓力疾患也可有過度警覺，是最強誘答；但其警覺反應必須置於創傷後的再經驗、迴避與威脅線索脈絡，而題幹所指的指標較貼近妄想性猜疑。

本題考點：HVI（Hypervigilance Index）——Exner 羅夏克綜合系統中與過度警覺相關的指標；妄想性（paranoid ideation）——以猜疑、威脅解讀為核心；DSM-IV-TR——舊題診斷名稱須依命題版本辨析。HVI 是系統特定的輔助指標，不能單獨作為診斷依據。

第 9 題

下列何者不是魏氏智力測驗中，類同分測驗所測量的核心能力？
  1. （A）邏輯抽象推理能力
  2. （B）語文概念的形成能力
  3. （C）一般事實性知識的廣度
  4. （D）語文概念的思考能力

答案：（C）

詳解與考點

正解：題眼在魏氏智力測驗的「類同」分測驗——它要求個案說明兩個概念有何相似，核心是抽象化、語文概念形成與概念性推理；一般事實知識廣度主要由知識分測驗衡量，故選 C。

A：找出概念間共同類別需要抽象與邏輯推理，屬類同的核心能力，故非答案。

B：將具體事物歸納成上位概念，反映語文概念形成能力，故非答案。

D：以語言比較概念並說明共同性，涉及語文概念思考，故非答案。

第 10 題

關於衡鑑會談的策略，下列那一項敍述不恰當？
  1. （A）需先向個案說明衡鑑相關訊息的保密性質
  2. （B）可運用個案史的檢核清單來確定是否已涵蓋重要的資訊
  3. （C）不應使用封閉式問句來限制個案談話內容的豐富性
  4. （D）可使用催化、澄清等技巧來獲得更多個案的資訊

答案：（C）

詳解與考點

正解：題眼在衡鑑會談策略的「不恰當」——判準是會談既要取得可比較的明確資訊，也要保留個案敘說的空間。封閉式問句可用於確認症狀、時間順序或具體事實；若說「不應使用」就是把工具絕對化，故（C）不恰當。

B：個案史檢核清單可減少重要發展、醫療或家庭資訊被遺漏，適合當作蒐集資料的輔助工具。

第 10 題

關於衡鑑會談，下列敘述何者錯誤？
  1. （A）心理師可以依據其理論取向與實務性的考量，來決定會談的結構化程度
  2. （B）增加會談的結構性可提高會談的評分者間信度
  3. （C）為建立良好關係，衡鑑會談初期應該採用結構化晤談
  4. （D）衡鑑會談的基本目的為定義問題行為及其原因

答案：（C）

詳解與考點

正解：題眼在「何者錯誤」及衡鑑會談初期的任務——初期須先建立安全感與合作關係，通常以較彈性、非過度僵化的方式開始；為建立關係就「應該採用結構化晤談」把程序方向講反了，故選 C。

A：會談的結構化程度可依轉介問題、理論取向與實務限制調整，故非答案。

B：提高結構性可使提問與評分較一致，通常有助於評分者間信度，故非答案。

D：界定問題行為及其可能成因是衡鑑會談的重要目的，故非答案。

本題考點：衡鑑會談（assessment interview）——界定轉介問題並形成初步假設；結構化晤談（structured interview）——有助資訊一致性，但關係建立仍須保有臨床彈性。

第 11 題

下列何種行為適合採用自然觀察法？
  1. （A）攻擊行為
  2. （B）社交性退縮行為
  3. （C）縱火行為
  4. （D）偷竊行為

答案：（B）

詳解與考點

正解：題眼在「自然觀察法」——判準是行為須能在自然情境中以低風險、較少干擾的方式重複觀察。社交性退縮可在教室、遊戲或團體互動中記錄頻率、持續時間與情境，故選 B。

A：攻擊行為雖可被觀察，但直接等待或安排其發生可能涉及安全風險；通常須先以既有紀錄、訪談及安全規劃判斷。

C：縱火的危險性極高，不能為了觀察而讓行為在自然情境中發生。

D：偷竊涉及違法與隱私問題，且觀察者介入或不介入都可能造成倫理困境，不適合以自然觀察作為首選。

本題考點：自然觀察法（naturalistic observation）——在日常情境記錄可見行為；行為取樣（behavior sampling）——記錄頻率、持續時間與發生脈絡；倫理風險（ethical risk）——危險或違法行為不可為觀察而放任。

第 11 題

有關貝克憂鬱量表第二版（Beck Depression Inventory-II, BDI-II），下列敘述何者正確？
  1. （A）基於信效度的考量，不應將過去 BDI 的研究結果類推至 BDI-II
  2. （B）可作為憂鬱的療效評估指標
  3. （C）使用於評估精神科病患的憂鬱症狀，較不適用於評估正常人
  4. （D）缺點是無法適用於不同種族或跨文化的對象

答案：（B）

詳解與考點

正解：題眼在 BDI-II 的用途——它可重複施測以追蹤憂鬱症狀嚴重度的變化，因此可作為療效評估的指標之一，故選 B。

A：BDI-II 與舊版的題目與計分內容不完全相同，解讀時確要注意版本差異；但不能據此斷言過去 BDI 研究結果一概不可參考。

C：BDI-II 可用於精神醫療與一般族群的憂鬱症狀評估；用途與解釋須配合對象，不能說一般人較不適用。

D：跨文化使用須檢視適切性與常模證據，但不能把它的缺點概括為無法適用於不同種族或文化對象。

本題考點：貝克憂鬱量表第二版（Beck Depression Inventory-II, BDI-II）——自陳式憂鬱症狀量表，可追蹤症狀變化；療效評估（treatment outcome assessment）——應結合臨床晤談與其他功能資料解讀。

第 12 題

個案因學業表現不佳就醫，進行心理衡鑑初期時，他退縮、不專注、不太講話，但關係建立後，發現個 案能適當互動，視知覺推理佳。關於個案文字閱讀有困難，下列建議何者恰當？
  1. （A）個案有語言表達、人際溝通的困難，建議語言治療
  2. （B）個案有注意力的問題，建議服用藥物
  3. （C）個案退縮，建議親子溝通心理治療
  4. （D）個案有閱讀障礙，建議視覺圖像輔助文字學習

答案：（D）

詳解與考點

正解：題眼在「文字閱讀有困難」以及關係建立後「能適當互動、視知覺推理佳」——這些線索把問題指向特定閱讀學習困難，而非廣泛語言、人際或注意力缺損。以視覺圖像輔助文字學習可利用個案相對優勢支持閱讀理解，故選 D。

A：題幹後續觀察到個案能適當互動，沒有支持語言表達或人際溝通障礙；將初期退縮直接推論為需語言治療，證據不足。

B：初期不專注可能受陌生會談與焦慮影響，不能據此直接判定注意力疾患或建議藥物。

C：退縮在關係建立後改善，較像情境性反應；親子溝通治療不是針對題幹所問閱讀困難的直接處遇。

本題考點：特定學習障礙症（specific learning disorder）——須辨認特定學業技能困難；優勢導向介入（strength-based intervention）——運用視知覺推理等相對強項；鑑別診斷（differential diagnosis）——不能把單次會談的退縮或不專注逕作疾患判定。

第 12 題

個案為學前幼兒，認知能力較弱，報告撰寫時，最恰當的敘述為何？
  1. （A）個案認知能力弱，宜接受早期療育
  2. （B）個案為發展遲緩兒，宜接受特教資源
  3. （C）個案願意學習，若找對方法，就有進步的空間
  4. （D）個案智能發展不足，宜加強認知訓練

答案：（C）

詳解與考點

正解：題眼在學前幼兒、認知能力較弱與「報告撰寫」——衡鑑報告應以描述可觀察優勢與可支持的發展可能為主，避免超出資料的診斷標籤或直接下處遇指令；C 同時保留個案優勢與支持方向，最恰當，故選 C。

A：僅以「認知能力弱」便直接推到早期療育，缺少對發展領域、功能需求與轉介問題的完整依據。

B：將個案直接稱為發展遲緩兒並建議特教資源，涉及分類與服務安置判斷，不能只由題幹的認知能力較弱推論。

D：以「智能發展不足」定性且直接指定認知訓練，語句過度標籤化，也未呈現個案的具體功能與優勢。

本題考點：衡鑑報告撰寫（assessment report writing）——以資料支持、功能導向且不污名的語言陳述；優勢觀點（strengths-based approach）——同時呈現個案可用能力與支持需求。

第 13 題

研究者在建立衡鑑工具時，在什麼目的下，須指出敏感度（sensitivity）與特異度（specificity）？
  1. （A）區分不同類型個案時
  2. （B）建立評分者信度時
  3. （C）建立效標效度時
  4. （D）區分信效度時

答案：（A）

詳解與考點

正解：題眼在「敏感度」與「特異度」——兩者都是分類工具區分有目標特徵與無目標特徵者的正確程度指標。當衡鑑工具要區分不同類型個案時，必須說明能否辨識應辨識者及排除不應辨識者，故選 A。

B：評分者信度關心不同評分者是否給出一致結果，主要以評分一致性指標檢驗，不是敏感度與特異度的用途。

C：效標效度可比較測驗與外部效標的關係；敏感度與特異度可成為診斷分類表現的證據，但題幹所問的直接目的仍是區分個案類型。

D：信度與效度是不同的測量品質概念，「區分信效度」不是敏感度與特異度的實際使用目的。

本題考點：敏感度（sensitivity）——辨識具有目標特徵者的能力；特異度（specificity）——正確排除不具目標特徵者的能力；診斷分類（diagnostic classification）——須同時考量漏判與誤判。

第 13 題

在進行魏氏智力測驗時，當個案的回答不完全時，下列何者處理恰當？
  1. （A）引導個案多說幾次，直到講出正確答案
  2. （B）對再次詢問，個案說「不知道」時，仍應鼓勵其再思考
  3. （C）把個案的回答重述一次，並請其針對所述再多說一些，若沒有補充，就進行下一題
  4. （D）只有測驗指導手冊中註明再詢問的答案才要再詢問

答案：（C）

詳解與考點

正解：題眼在魏氏智力測驗回答「不完全」的處理——施測者可中性地重述回答並依標準程序請個案補充，若無補充即往下一題，既釐清答案又不提供線索或教導，故選 C。

A：反覆引導到答對會提供不當提示，破壞標準化施測與分數效度。

B：個案已說不知道仍持續鼓勵再想，可能形成壓力或額外提示，並非中性再詢問。

D：手冊明定可再詢問時必須遵守；但個案回答不完整時，依標準程序進行中性澄清不能被概括成「只有」該種情況才可再詢問。這是最強誘答，因為它強調手冊的重要性，錯在把標準化程序誤縮限為單一情況。

本題考點：標準化施測（standardized administration）——依手冊且避免提示個案；再詢問（querying）——以中性澄清不完整反應，不改變題意或暗示答案。

第 14 題

有關簡式的魏氏智力量表，下列敘述何者正確？
  1. （A）與完整版的相關至少要達到 .85
  2. （B）最常使用的兩個分測驗是圖畫補充與詞彙
  3. （C）若以簡式施測則不得在衡鑑報告中呈現智商分數
  4. （D）簡式施測仍有其存在必要性

答案：（D）

詳解與考點

正解：題眼在「簡式的魏氏智力量表」——判準是簡式是時間或受測限制下的初步估計工具，不能取代完整衡鑑，卻仍有篩檢、快速估計與轉介決策價值，因此（D）正確。

A：簡式與完整版的相關門檻會隨所用分測驗、量表版本與樣本而異，不能以題述固定數值概括所有簡式。

B：常用簡式的選取原則是兼顧語文與非語文推理並維持與全量表的關聯，不可把「圖畫補充與詞彙」當作通用的固定組合。

C：簡式結果可在衡鑑報告中呈現，但必須明確標示其為估計、說明限制，且不宜據此單獨作重大診斷結論；最強誘答在於把「不能取代完整版」誤寫成「不得呈現」。

本題考點：簡式智力測驗（short-form intelligence assessment）——用於初步估計與篩檢；完整心理衡鑑（comprehensive psychological assessment）——重大結論須整合完整資料；結果詮釋（interpretation）——應清楚交代測量範圍與限制。

第 14 題

  1. （A）採用組內設計
  2. （B）採用多變項策略
  3. （C）採用雙盲設計
  4. （D）採用方便取樣

答案：（C）

詳解與考點

正解：題眼在提高研究的「內在效度」——內在效度要排除期待效應與評估偏差等替代解釋；雙盲設計使參與者與主要評估者不知道條件分派，可降低這些偏差，故選 C。

A：組內設計能控制部分個體差異，但也可能引入順序、練習或殘留效應，不能概括說是本題最適切作法。

B：多變項策略可同時探討多個變項，卻不必然控制研究者或受試者期待造成的偏差。

D：方便取樣主要影響樣本代表性與外在效度，無助於提高內在效度。

本題考點：內在效度（internal validity）——研究結果可歸因於操弄而非混淆因素的程度；雙盲設計（double-blind design）——降低受試者與評估者期待偏差。

第 15 題

  2. （B）應全以堅定直述的語氣，呈現出臨床工作者的專業性
  3. （C）將整段結論變成粗體字，讓讀者易於了解
  4. （D）僅根據測驗資料做結論，避免衡鑑者的臆測

答案：（A）

詳解與考點

正解：題眼在衡鑑報告「呈現結論的適當表達」——判準是結論強度必須與證據強度相稱。以「似乎」、「可能」、「極可能」等語詞校準肯定程度，能如實表達資料支持的範圍與不確定性，故選 A。

B：專業性不等於過度確定。證據尚不足時以堅定直述掩蓋限制，會使報告的推論超出資料。

C：粗體是版面設計，不能改善結論的證據品質或邏輯清晰度。

D：心理衡鑑應整合測驗、會談、行為觀察及背景資料；只依測驗分數反而忽略重要的臨床脈絡。

本題考點：衡鑑報告（psychological report）——結論須由多來源資料整合；推論強度（strength of inference）——語氣應與證據相稱；資料三角檢證（triangulation）——以不同資料來源交叉支持結論。

  2. （B）如果與記憶的得分相比，再認的分數沒有進步，有可能是詐病
  3. （C）測驗的表現若比用亂猜的得分還低時，有可能是詐病
  4. （D）比較日常生活功能與魏氏記憶量表的分數有戲劇化的差異時，有可能是詐病

  3. （C）區辨效度是屬於建構效度的一種
  4. （D）題目間的同質性高不一定反映良好建構效度

  1. （A）因為我們假設測量誤差的變異數為 1
  2. （B）因為我們假設真實分數與測量誤差間無相關
  3. （C）因為我們假設各次測得之真實分數間無相關
  4. （D）因為我們假設不同測驗所測得的測量誤差之間無相關

答案：（B）

詳解與考點

正解：題眼在「隨機出現」的粗心錯與古典測驗理論——判準是隨機測量誤差不應系統性偏向能力高或低的受測者，也就是與真實分數無相關。如此一來，粗心錯增加的是隨機誤差而非系統性扭曲真實能力的估計，故選 B。

第 26 題

關於操作制約（Operant conditioning）的技術，下列敘述何者正確？
  1. （A）增強（reinforcement）可增加目標行為的發生頻率
  2. （B）負增強（negative reinforcement）是移除個案所欲的酬賞物
  3. （C）削除（extinction）應單獨使用，以免產生替代行為
  4. （D）懲罰（punishment）是為了增加目標行為的發生頻率

答案：（A）

詳解與考點

正解：題眼在「操作制約」與「正確」——判準是結果出現後是否使目標行為未來發生頻率上升。增強的定義正是增加行為發生機率，無論加入愉悅刺激或移除嫌惡刺激，皆符合此判準，故選 A。

B：負增強不是移除個案想要的酬賞物；它是移除嫌惡刺激後，使行為增加。移除所欲酬賞物通常是反應代價，目的在降低行為。這是最強誘答，因為「負」容易被誤認為懲罰；分辨關鍵是負增強的行為結果仍為增加。

C：削除是停止提供原先維持行為的增強物，但通常需搭配替代行為的增強與一致執行；單獨使用可能出現暫時反彈或其他問題行為。

D：懲罰的功能是降低目標行為的發生頻率，不是增加。

本題考點：操作制約（Operant Conditioning）——以行為後果改變未來行為；增強（Reinforcement）增加行為；懲罰（Punishment）與削除（Extinction）用於降低行為。

正解：題眼在存在治療的「自由與責任」——自由帶來選擇與責任，也帶來焦慮；人可能把選擇交給他人或規範以逃避責任。（A）正確，故選 A。

第 27 題

理情行為治療（REBT）的 A-B-C 理論認為，不適當的行為結果與下列何者的關聯性最大？
  1. （A）行為的前置事件
  2. （B）情緒的防衛反應
  3. （C）前置事件的解釋
  4. （D）行為的負面效果

答案：（C）

詳解與考點

正解：題眼在 REBT 的「A-B-C」——判準是情緒與行為後果 C 並非由前置事件 A 直接決定，而主要受個案對事件的信念或解釋 B 所中介。非理性信念使同一事件被理解為災難、絕對必須或無法忍受，進而形成不適當後果，故選 C。

A：前置事件是 A 的位置，但 REBT 不把事件本身當成不適當後果的主要決定因子；關鍵在個案如何詮釋事件。

B：情緒反應通常屬 C 的一部分，不是用來解釋不適當行為後果的核心中介。

D：行為的負面效果是後果的描述，不能倒過來作為其主要成因。

本題考點：ABC 模式（ABC Model）——A 是前置事件、B 是信念、C 是情緒與行為後果；理情行為治療（REBT）——以辨識及修正非理性信念為核心。

第 31 題

某研究生認為不同性別在「衝動性」上的表現會不同，以量表收集 100 位大學生的衝動性資料，將男女 分成兩組後，利用「獨立樣本 t 檢定」進行分析。下列敘述何者錯誤？
  1. （A）男生、女生兩組的變異數相等是其基本假設
  2. （B）檢定概念是先計算兩組的平均數，再檢定平均數是否有差異
  3. （C）若要能準確的計算 t 值，兩組人數必須相等
  4. （D）虛無假設為：男生平均數＝女生平均數

答案：（C）

詳解與考點

正解：題眼在「獨立樣本 t 檢定」與「何者錯誤」——判準是比較兩個獨立群體平均數時，是否必須讓兩組樣本數相同。t 值可依兩組各自的樣本數、平均數與變異量計算，樣本數不必相等，故 C 為應選項；兩組人數不平衡會影響標準誤與檢定力，若同時不符合等變異數假設，宜改採 Welch t 檢定。

A：傳統 pooled-variance 的獨立樣本 t 檢定假設兩母群變異數相等；若不適合，則可採不假設等變異數的 Welch t 檢定。

B：此檢定以兩組平均數差異相對於其抽樣變異來判斷，敘述正確。

D：其虛無假設為兩組母群平均數相等，亦即男生平均數＝女生平均數。

本題考點：獨立樣本 t 檢定（Independent-Samples t Test）——比較兩獨立群體平均數，兩組人數不必相等；虛無假設（Null Hypothesis）——兩母群平均數相等；等變異數假設（Homogeneity of Variance）——屬傳統 pooled-variance 版本的條件，不成立時改用 Welch t 檢定。

第 32 題

某療效研究邀請 10 位受過同樣標準治療訓練的臨床心理師，男女各半，將 100 位個案隨機平均分給臨床 心理師，若想了解各臨床心理師及其性別是否會影響療效，下列何種分析方式最恰當？
  1. （A）先將 10 位臨床心理師分為 10 組進行單因子變異數分析，再以性別分 2 組進行獨立樣本 t 檢定
  2. （B）以完全交叉實驗設計（crossed experimental design）來處理，進行性別×各心理師的二因子變異數分析
  3. （C）以巢狀設計（nested design）來處理，進行性別（各心理師）的巢狀二因子變異數分析
  4. （D）進行受試者內設計的二因子變異數分析

答案：（C）

詳解與考點

正解：題眼在「各臨床心理師及其性別」——每位心理師只屬於一個性別，心理師這個因素因而巢狀於性別，兩者不能完全交叉。要同時檢驗性別及同一性別內不同心理師的療效差異，應用性別（各心理師）的巢狀二因子設計，故選 C。

A：分開做單因子變異數分析與 t 檢定會拆散原有的巢狀結構，也無法在同一模型中正確估計心理師層次的變異。

B：完全交叉設計要求每個心理師都能出現在每個性別水準中；人的性別不能如此安排。這是最強誘答，因為題目確有兩個因素，但「有兩因素」不等於因素可交叉。

D：每位個案僅接受分派的一位心理師，不是同一受試者重複接受各水準處遇，故非受試者內設計。

本題考點：巢狀設計（Nested Design）——一因素的水準隸屬於另一因素；完全交叉設計（Crossed Design）——每一因素水準可與另一因素所有水準組合；變異數分析（ANOVA）——依設計結構分解變異。

第 32 題

目前有關心理治療的研究，下列何者正確？
  1. （A）所有研究支持心理治療是有顯著療效
  2. （B）治療後得到正向改變，即可證實治療方法是有效
  3. （C）目前的研究結果很難進行比較，主要原因為對測量工具尚未取得共識
  4. （D）最常見的心理治療研究方法是個案研究法

答案：（C）

詳解與考點

正解：題眼在「目前有關心理治療的研究」——判準是跨研究比較療效時，最主要的障礙在哪裡。不同研究採用的結果指標與測量工具並不一致，有的看症狀量表分數，有的看功能水準或個案滿意度，評分者與計分方式也各異，療效大小因此難以放在同一把尺上互相比較，故選 C。

A：研究品質與結果並不一致，並非所有研究都支持顯著療效，故非答案。

B：治療後的改善可能來自自然恢復、回歸平均、期待效應或同時發生的其他生活事件；沒有可比較的控制條件，就不能把前後改變歸因於治療本身，故非答案。

D：個案研究法能提供深度資料，但心理治療成效研究以隨機分派的組間比較設計為主，個案研究並非最常見的方法，故非答案。

本題考點：心理治療研究（psychotherapy research）——跨研究比較受測量工具與結果指標不一致所限；結果測量（outcome measurement）；因果推論（causal inference）——前後改變不足以排除自然恢復與期待效應。

第 33 題

  1. （A）對個人資料的保密
  2. （B）參與研究的報酬

  4. （D）需要參與研究的受試者總人數

答案：（A）

詳解與考點

正解：題眼在「ABAB 設計」——A 代表基線期、B 代表介入期，於同一個案反覆撤回與重施介入以觀察行為是否隨條件改變，屬單一個案設計，故選 A。

B：多基線設計不撤回處遇，而跨行為、情境或個案錯開介入時點。

C：混合設計通常結合不同研究設計要素，非 ABAB 的標準分類。

D：巢狀設計處理資料或樣本的階層關係，不是 ABAB 設計。

本題考點：單一個案設計（single-case design）；ABAB 設計（reversal design）；基線（baseline）與介入（intervention）。

第 34 題

有關完形治療中的實驗（experiment）之應用，下列敘述何者正確？
  1. （A）完形實驗是預先計畫的現成技巧，用於達成特定目標
  2. （B）完形實驗的目的是擴展案主的覺察，協助採用新的行為模式
  3. （C）完形實驗並不強調安全的治療關係與準備
  4. （D）完形治療以實驗來實踐案主需努力克服抗拒（resistance）的重視

答案：（B）

詳解與考點

正解：題眼在完形治療的「實驗」——判準是實驗並非套用固定技巧，而是在安全關係中邀請個案嘗試新的覺察與經驗方式。其目的在擴展覺察，讓個案有機會發現並採取新的行為可能，故選 B。

A：完形實驗需依個案當下需要共同形成，不是預先計畫好的現成技術；技術若脫離覺察，便失去實驗精神。

C：實驗需要足夠的治療關係、安全感與個案準備度，不能忽略這些條件。

D：完形治療將抗拒理解為具有功能的創造性調適，重點是以覺察探索它，而非要求個案努力克服。

本題考點：完形治療（Gestalt Therapy）——重視當下覺察；實驗（Experiment）——共同創造經驗以擴展可能性；抗拒（Resistance）——應被探索其功能而非強迫排除。

第 34 題

阿明平常喜歡看電視，有一天他失手把家裡的花瓶打破後，媽媽非常生氣，不准他看電視。按照應用行 為分析的觀點，媽媽的做法最符合下列何項原理？
  1. （A）負增強
  2. （B）懲罰
  3. （C）削除（extinction）
  4. （D）正增強

答案：（B）

正解：題眼在「打破花瓶後」與「不准看電視」——原本可獲得的愉快刺激被移除，以降低日後打破花瓶這類行為的機率，屬反應代價形式的懲罰，故選 B。

A：負增強是移除嫌惡刺激以增加行為；本題是移除喜愛活動以減少行為，方向相反。

C：削除是停止提供原本維持行為的增強後果，不能概括為事後禁止看電視。

第 35 題

個案為國中生，罹患裘馨氏肌肉失養症（DMD）的罕見疾病，因肌肉萎縮造成行動受限，無法應對他人 異樣的眼光，醫療團隊轉介心理評估與諮詢。下列何種處遇方式與個案主訴的關聯性最低？
  1. （A）評估個案曾用過的解決方法，共同討論出問題情境的解決方案
  2. （B）同理個案的壓力，給予情緒上的支持
  3. （C）評估個案對疾病的看法與自我期待
  4. （D）評估家長對個案的期待

答案：（D）

詳解與考點

正解：題眼在個案的主訴是「無法應對他人異樣眼光」——處遇應優先連結其疾病意義、情緒壓力與在社交情境中的因應。家長期待可影響整體家庭調適，但與眼前主訴的直接關聯最低，故選 D。

B：疾病與行動受限造成的壓力需要同理與情緒支持，是建立處遇合作的重要部分。

C：個案如何看待疾病、能力與自我期待，會影響羞愧、退縮及社交因應，與主訴密切相關。

本題考點：以主訴為中心的處遇規劃（Problem-Focused Intervention）——優先處理當前困擾及其維持因素；疾病認知（Illness Perception）——影響情緒與因應；家庭脈絡（Family Context）——重要但須依轉介問題排序。

第 35 題

個案住院檢查後，其被疑有心因性疾病，經治療後病況明顯改善。但跟個案討論出院事宜後，其病況又 惡化，而照會臨床心理師評估個案對疾病的認知。下列何種處遇方式最為恰當？
  1. （A）若個案無法覺察病情與心理壓力的交互作用，建議個案出院並持續於門診追蹤
  2. （B）釐清個案是否覺察病情與心理壓力的交互作用，建議醫療團隊安排個案出院後做心理治療
  3. （C）確立心因性疾病的診斷，釐清個案是否覺察病情與心理壓力的交互作用，學習因應身心疾病的方法
  4. （D）請個案持續住院，待痊癒後再出院

答案：（C）

詳解與考點

正解：題眼在「討論出院後病況又惡化」與「心因性疾病」——這提示症狀可能與壓力及疾病行為互動，處遇判準是先完成適當的診斷與心理衡鑑，再協助個案建立可持續使用的因應方式，而非只處理出院安排。故（C）確立心因性疾病的診斷、釐清個案對心理壓力與病情交互作用的覺察，並學習因應身心疾病的方法，最能同時處理目前症狀與後續復發風險，故選 C。

A：若個案尚無法覺察壓力與病情的關聯便直接建議出院，只留下門診追蹤，跳過了當前需要的心理衡鑑與衛教；出院本身可能正是壓力觸發線索，不能當成優先處置。

B：釐清覺察並安排出院後心理治療的方向看似合理，卻錯在尚未確立診斷與立即介入需求，就先以出院為前提；（C）比它多了診斷整合與可操作的因應學習。

D：要求個案持續住院至「痊癒」不符合心因性症狀的處遇原則。住院依醫療必要性決定，不能以無限期住院取代對壓力、症狀與因應的處理。

本題考點：身心症狀的心理衡鑑（psychological assessment）——辨識壓力、疾病認知與症狀變化的關聯；生物心理社會處遇（biopsychosocial intervention）——診斷整合、衛教與因應策略須並行；出院計畫（discharge planning）——應建立在風險與需求評估上。

第 36 題

下列何者為存在主義與人文主義治療學派之理論概念不同之處？
  1. （A）相信個案有能力做出有建設性的決定
  2. （B）強調自由、個人責任的概念
  3. （C）個體隨時都面臨著抉擇的焦慮
  4. （D）將個案／治療者關係作為治療核心

答案：（C）

詳解與考點

正解：題眼在「不同之處」——人文主義與存在主義都相信個案可作有建設性的選擇，也都重視治療關係；但存在主義特別把人在自由下無可避免的選擇、責任與焦慮置於核心。因此「隨時面臨抉擇的焦慮」最能區分存在主義，故選 C。

A：相信個案有能力做出有建設性的決定，符合人文主義對成長潛能的看法，也與存在取向可相容，非主要差異。

B：自由與個人責任是存在取向的明顯主題，但人文取向亦承認個人自主，單獨列出不足以比 C 更精確地呈現差異。

D：兩者皆重視真實、尊重且有助於改變的個案／治療者關係，故非區分點。

本題考點：存在主義治療（Existential Therapy）——自由、責任、選擇與存在焦慮；人文主義治療（Humanistic Therapy）——重視成長潛能與治療關係；治療關係（Therapeutic Relationship）——為兩取向的共同基礎。

第 36 題

個案為燒燙傷患者，由於醫療團隊觀察到個案情緒低落，因此轉介個案做心理評估。個案表示：復健是 漫長的路，復健能看到的進步有限，卻又有不可中斷的無奈，每天還要忍受痛和癢，心情沮喪。下列何 種處遇方式最不恰當？
  1. （A）同理個案當下的情緒感受
  2. （B）告訴個案最大痛苦是身體上的而非情緒上的憂鬱
  3. （C）了解個案的需求回報給醫療團隊，促進醫病溝通
  4. （D）協助個案適當轉移注意力，來減緩身體的疼痛

答案：（B）

詳解與考點

正解：題眼在「最不恰當」與燒燙傷復健期間的疼痛、搔癢及沮喪——判準是承認身體痛苦與情緒反應會交互影響，先同理、評估需求並與醫療團隊合作，而非貶抑情緒困擾。故（B）把個案的最大痛苦斷言為身體而非情緒上的憂鬱，否定其主觀經驗並製造身心二分，最不恰當，故選 B。

A：同理個案面對長期復健、疼痛與有限進步的沮喪，是建立治療關係及進一步評估的適當起點，故非答案。

C：了解個案需求並回饋醫療團隊，可促進跨專業溝通，使疼痛、復健與心理支持被整合處理，故非答案。

D：協助使用適當的注意力轉移可作為疼痛管理策略之一，前提是配合個案狀況而非取代對情緒的理解，故非答案。

本題考點：醫療心理處遇（health psychology intervention）——身體症狀與情緒需整合看待；同理（empathy）——先理解個案經驗，不以專業判斷取代其感受；跨專業合作（interdisciplinary collaboration）——把個案需求納入醫療溝通。

第 37 題

關於當代心理動力治療的新趨勢，下列何者錯誤？
  1. （A）由於費用的關係，當代心理動力導向的治療將趨向短程
  2. （B）當代心理動力開始被運用到人格疾患的治療
  3. （C）當代心理動力強調治療中提早建立正向治療關係的重要
  4. （D）當代心理動力不適合用來治療兒童的疾病

答案：（D）

詳解與考點

正解：題眼在「當代心理動力治療」與「錯誤」——判準是當代心理動力取向已發展出適用於不同年齡與問題的短程及發展取向介入，不能概括為不適合兒童。故 D 的絕對否定錯誤，為應選項。

A：服務體系的時間與費用限制，使當代心理動力治療發展出較短程、聚焦的形式，敘述可成立。

B：心理動力概念及其結構化介入已被運用於人格疾患處遇，並非只限於神經症式問題。

C：及早建立工作聯盟與正向治療關係有助於個案投入及處理困難情感，是當代取向重視的治療條件。

本題考點：當代心理動力治療（Contemporary Psychodynamic Therapy）——可採短程與聚焦形式；治療聯盟（Therapeutic Alliance）——支持個案投入與治療歷程；兒童心理動力治療（Child Psychodynamic Psychotherapy）——可依發展階段調整介入。

第 37 題

當自我評估到某種特定願望的表達將引發焦慮時，個體會採取一些行動，下列何者不是精神分析的論點？
  1. （A）放棄這個願望以減輕焦慮
  2. （B）將焦慮轉化為病症以減輕焦慮
  3. （C）啟動防衛機制以減輕焦慮
  4. （D）將會引發焦慮的願望轉移到比較不會引發焦慮的願望

答案：（A）

詳解與考點

正解：題眼在「不是精神分析的論點」與「願望表達將引發焦慮」——精神分析觀點認為自我會透過防衛機制處理本我衝動與焦慮，常見的是壓抑、轉移或症狀形成，並非以有意識的理性放棄願望作為核心說明。故（A）放棄願望以減輕焦慮，較像直接的意識性決定，非精神分析對防衛性處理的典型論點，故選 A。

B：把內在衝突所致的焦慮轉化為症狀，可對應精神分析的症狀形成觀點；症狀雖造成困擾，也可能暫時表達並遮蔽衝突，故非答案。

C：自我啟動防衛機制以減輕焦慮，是精神分析的核心主張，故非答案。

D：將可能引發焦慮的願望轉向較可接受的目標，符合轉移或置換（displacement）的防衛性思路，故非答案。

本題考點：精神分析理論（psychoanalytic theory）——焦慮源於內在衝突；自我防衛機制（defense mechanisms）——以非意識方式減輕焦慮；症狀形成（symptom formation）——可被理解為衝突的折衷表現。

第 38 題

有關保密的作法，下列敘述何者正確？
  1. （A）為了精確診斷行為問題而需要對兒童錄影時，不需要徵求父母的同意
  2. （B）當個案無法定的行為能力且沒有指定的法律監護人，心理師仍不可對唯一的親密友人洩漏個案的資料
  3. （C）在危急狀態中，也應將保密之事列為優先
  4. （D）若心理治療費用是由健保給付，健保局可以調閱病人的心理治療筆記

答案：（D）

詳解與考點

正解：題眼在保密作法與由健保給付的醫療紀錄——官方答案為 D；惟此題涉及醫療給付與心理治療筆記的資料調閱界線，實務上須依當時適用的法規、給付規範及紀錄類型判斷。就題意，保密並非絕對，為核實給付所必要且具合法依據的範圍內，相關單位得調閱必要資料，故選 D。

A：對兒童錄影屬蒐集敏感資料，原則上須取得法定代理人知後同意；不能因診斷需要而省略。

B：個案欠缺行為能力且無指定監護人時，資料處理仍應以個案權益、必要性及適當法定程序為準，不能以「唯一親密友人」當然排除一切必要資訊分享。

C：危急狀態下，保護個案或他人安全可優先於通常保密義務；把保密一律列為優先，方向錯置。

本題考點：保密（Confidentiality）——原則上保護個案資料，但有安全與法定例外；知後同意（Informed Consent）——錄影與資料蒐集前的重要程序；本題所涉調閱範圍具法規與制度時效敏感性，應以現行規範及資料類型核定。

第 38 題

你的專長是老人心理學，但是因緣際會有一位厭食症的少女來求助，你所服務的區域以你的專長最為接 近。此時，較適切的處理方式為何？
  1. （A）堅定的拒絕接此個案，以免治療失敗
  2. （B）拒絕正式接案，但利用下班時間表示關心
  3. （C）自己接下此案例，並尋找一位有經驗的督導協助治療
  4. （D）建議這位少女尋求網路諮商

答案：（C）

詳解與考點

正解：題眼在專長是「老人心理學」但求助者為「厭食症少女」，且當地沒有更接近的專業資源——判準不是勉強宣稱自己已具備專長，而是在服務可近性與能力界線之間，透過具相關經驗的督導補強能力並持續監測需要。故（C）接案後尋找有經驗的督導協助治療，能讓個案得到可近的服務，也以督導維持專業勝任，故選 C。

A：僅因專長不完全相符便堅定拒絕，忽略了區域內缺乏替代服務與可透過督導提升勝任的可能，故非最佳作法。

B：拒絕正式接案卻在下班時間私下關心，會造成專業界線與責任歸屬不清，故非答案。

D：建議網路諮商看似提供替代管道，卻沒有確認其適切性、可近性與風險；厭食症可能涉及醫療及營養風險，不能以此取代有督導的正式處遇。

本題考點：專業勝任（professional competence）——服務超出既有經驗時應補強訓練、諮詢或督導；督導（supervision）——協助臨床判斷與能力發展；專業界線（professional boundaries）——不可用非正式私人關心取代正式服務。

第 39 題

下列何者不是臨床心理師公會全國聯合會訂定臺灣「臨床心理師倫理準則與行為規範」的主要目的？
  1. （A）促進社會大眾獲得最好的臨床心理專業服務
  2. （B）保護臨床心理師執行臨床心理業務的權利
  3. （C）為臨床心理師公會處理有關倫理申訴案件之基礎
  4. （D）維護臨床心理專業的社會信任，保護臨床心理師所服務之對象的福祉

答案：（B）

詳解與考點

正解：題眼在倫理準則「主要目的」與「不是」——判準是倫理規範首先保障服務對象福祉、專業服務品質與社會信任，並提供倫理申訴處理的依據；它不是以維護臨床心理師執業權利為主要宗旨，故選 B。

A：促進社會大眾獲得良好臨床心理服務，符合倫理準則以公共利益與服務品質為核心的目的。

C：倫理準則可作為公會處理倫理申訴的判斷基礎，敘述正確。

D：維護專業社會信任並保護服務對象福祉，是倫理規範的核心功能。

本題考點：專業倫理（Professional Ethics）——以服務對象福祉與公共信任為優先；倫理準則（Ethical Standards）——引導專業行為並提供申訴處理依據；本題依題述準則的目的作答，實際規範文字應以適用版本確認。

第 39 題

根據中華民國臨床心理師公會聯合會公告之「專業倫理申訴辦法」，地方公會組成之倫理調查小組，其 組成方式為何？
  1. （A）至少三人，其中一人須為社會公正人士
  2. （B）至少三人，其中一人須為全聯會倫理委員會委員
  3. （C）至少三人，其中一人須為申訴人指定之地方公會會員
  4. （D）至少三人，其中一人須為被申訴人所屬公會之外的其他公會會員

答案：（D）

詳解與考點

正解：題眼在「地方公會組成之倫理調查小組」——此題問的是特定公會申訴程序的組成保障；官方答案為 D，依該辦法所示，調查小組至少三人，且其中一人須為被申訴人所屬公會以外的其他公會會員，藉此增加調查的獨立性，故選 D。此類規範可能隨公會辦法修訂，作答應以題目指定辦法當時內容為準。

A：至少三人雖符合人數設計，但「社會公正人士」不是本題所問辦法的指定組成條件，故非答案。

B：全聯會倫理委員會委員並非地方公會倫理調查小組所要求的指定成員，故非答案。

C：由申訴人指定地方公會會員會損及調查小組的中立組成；程序保障在於獨立調查，不在於由一方指定調查者，故非答案。

本題考點：專業倫理申訴程序（professional ethics complaint procedure）——調查組織須有獨立性；利益衝突迴避（conflict-of-interest avoidance）——避免由與被申訴人同屬單一公會的成員完全主導；程序正義（procedural justice）——以可受檢視的組成保障公正。

第 40 題

有關心理衡鑑工具的使用，下列何者最不違反專業倫理？
  1. （A）臨床心理師在非專業性演講時，討論到心理衡鑑工具，只可使用模擬的題目
  2. （B）臨床心理師得因媒體要求而介紹心理測驗的內容
  3. （C）在進行大眾演講時，應使用正式出版的心理測驗項目，才不會誤導大眾
  4. （D）為了推廣及促進心理健康，臨床心理師可在媒體介紹一些醫院常用的心理測驗，例如憂鬱量表

答案：（A）

詳解與考點

正解：題眼在心理衡鑑工具使用中「最不違反專業倫理」——判準是兼顧公眾衛教與測驗安全，不公開正式題目、題庫內容或足以破壞工具效度的材料。非專業演講使用模擬題目可說明概念而不洩漏正式測驗內容，故選 A。

B：因媒體要求就介紹測驗內容，若涉及正式題目、作答材料或解釋規則，會損及測驗安全；媒體需求不是公開的理由。

C：正式出版不等於可在大眾演講中公開；公開正式項目反而可能使日後施測失真。

D：以醫院常用為由在媒體介紹特定量表，仍需嚴守測驗安全、適用範圍與專業解釋界線；相較 A 的模擬題目，此作法較不妥。這是最強誘答，因為心理健康推廣本身合理，錯在把衛教目的當成揭露特定測驗內容的授權。

本題考點：測驗安全（Test Security）——避免正式項目與施測材料外流；心理衡鑑（Psychological Assessment）——須由具勝任能力者依適用目的解釋；本題依一般專業倫理原則作答，公開溝通的具體界線仍應依現行規範判斷。

第 40 題

有關臨床心理師的專業能力範圍之描述，下列何者錯誤？
  1. （A）當臨床心理師覺察私人問題會干擾其工作職務的適切表現時，應立刻尋求專業諮詢或協助，以決定是 否要中止或結束工作相關職務
  2. （B）當臨床心理師覺察其私人的問題有可能會讓其無法以有效的方式執行工作相關的活動時，應該避免進 行該項活動
  3. （C）臨床心理師委請他人服務時，應該避免將該工作委任給與服務對象有多重關係的人
  4. （D）為確保個案獲得專業的關照，在任何情況下，臨床心理師絕對不能提供與自己能力不符的服務

答案：（D）

詳解與考點

正解：題眼在「何者錯誤」與「在任何情況下，絕對不能」——專業能力範圍的判準是不得在未具勝任能力時獨自執行服務，但遇到緊急、缺乏替代資源等情況，心理師可在取得諮詢、督導或必要訓練下提供有限且適切的服務。故（D）以絕對禁止描述所有情況，忽略例外情境與補強能力的責任，為錯誤敘述，故選 D。

A：私人問題已干擾職務表現時，尋求專業諮詢或協助並判斷是否暫停相關工作，符合自我監測與保護個案的倫理要求，故非答案。

B：私人問題可能妨礙有效執業時，避免從事該活動，是能力界線的適當作法，故非答案。

C：委請他人服務時，應避免把工作交給與服務對象有多重關係者，以降低利益衝突與偏頗風險，故非答案。

本題考點：專業勝任（professional competence）——不得超越能力獨自執業；自我照顧與能力受損（professional impairment）——干擾工作時應尋求協助或調整職務；多重關係（multiple relationships）——委任服務也要避免利益衝突。
