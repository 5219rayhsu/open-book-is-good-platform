全部 40 題

第 1 題

臨床工作者實施心理衡鑑時的主要角色功能為何？
  1. （A）與個案建立關係
  2. （B）同理個案在生活中遇到的問題
  3. （C）施測心理測驗，以便形成對個案問題的各種描述
  4. （D）回答轉介問題，並做出具體且合理的建議來協助個案

答案：（D）

詳解與考點

考點為心理衡鑑中臨床工作者的主要角色功能。衡鑑的核心目的是回答轉介問題並提出具體合理的建議以協助個案，故正解 D。建立關係、同理、施測測驗都是過程或手段，而非衡鑑的主要角色功能。主要陷阱是誤選 C（施測測驗形成描述），但施測只是蒐集資料的工具，最終要落實到回答轉介問題與提出建議。

第 2 題

當轉介心理衡鑑的理由模糊不清時，臨床工作者如何處理最為適當？
  1. （A）執行制式化心理測驗
  2. （B）請個案說明進行心理衡鑑的目的
  3. （C）主動與轉介者澄清轉介原因
  4. （D）自行判定兩三個最重要的議題評估

答案：（C）

詳解與考點

考點為轉介理由模糊時的處理原則。當轉介目的不清，最適當作法是主動與轉介者澄清轉介原因，確保衡鑑方向正確，故正解 C。主要陷阱是誤選 B（請個案說明目的）：個案未必清楚轉介者的真正疑問，澄清責任在轉介者；自行判定或執行制式測驗都可能偏離真正需求。

第 3 題

在評鑑心理衡鑑工具的常模時，下列何者不是理想常模的要件？
  1. （A）常模的標準化樣本夠大
  2. （B）採取分層立意抽樣
  3. （C）標準化樣本具代表性
  4. （D）納入特定次群體常模與全國常模

答案：（B）

詳解與考點

考點為理想常模的要件。理想常模應有夠大且具代表性的標準化樣本，並納入特定次群體與全國常模。正解 B「分層立意抽樣」不是理想要件：理想常模應採分層隨機抽樣以確保代表性，立意抽樣帶有主觀選樣偏誤。主要陷阱是把「分層」當成正確就忽略「立意」二字，隨機抽樣才是常模代表性的關鍵。

第 4 題

關於NEO Personality Inventory，下列敘述何者正確？
  1. （A）目的是用來探討臨床心理疾患之人格特質
  2. （B）無簡短版測驗
  3. （C）該測驗之標準化分數之平均數為100，標準差為15
  4. （D）量表包含五個主要特質量尺

答案：（D）

詳解與考點

考點為 NEO 人格量表的特性。NEO-PI 測量五大人格特質（神經質、外向、開放、親和、嚴謹），包含五個主要特質量尺，故正解 D。主要陷阱：A 錯在 NEO 測一般人格特質而非臨床疾患；B 錯在有簡短版（NEO-FFI）；C 的平均 100、標準差 15 是離差智商的設定，並非 NEO 的計分標準。

第 5 題

根據柯永河（2001）的臨床心理學專書，下列何項不是決定測驗施測順序應依循的原則？
  1. （A）簡單的測驗先執行，困難的測驗後執行
  2. （B）施測順序不要減低測驗原有的效度
  3. （C）易受疲勞影響的測驗應排在整套測驗的最前面進行
  4. （D）不計時、較費時，但不引起緊張的測驗安排在最後

答案：（C）

詳解與考點

正解 C。依柯永河（2001）對測驗施測順序的原則，安排順序應避免疲勞、緊張等因素「降低測驗原有的效度」，並兼顧難易、暖身等考量：一般採「先簡單、後困難」（A），施測順序不可損及測驗效度（B），不計時、較費時但不引起緊張的測驗安排在最後（D）。

C 之所以為「非原則」：易受疲勞影響的測驗不應排在「最前面」這樣的固定位置敘述並非其施測順序原則；正確的精神是要避免在受試者已疲勞時施測而使效度下降，並綜合考量難易、緊張程度與效度來安排，而非單以「易受疲勞就放最前面」為通則，故選 C。

A、B、D 皆為柯永河所列的施測順序原則，故不選。

第 6 題

有關結構式與非結構式會談的比較，下列敘述何者錯誤？
  1. （A）結構式會談具有較好的心理計量特性
  2. （B）結構式診斷會談不適用於兒童與青少年個案
  3. （C）非結構式會談比較能夠彈性的觀察個案特有的表現
  4. （D）非結構式會談比結構式會談更容易有會談者偏誤

答案：（B）

詳解與考點

考點為結構式與非結構式會談的比較。結構式信效度佳但彈性低，非結構式較能彈性觀察但易有會談者偏誤。正解 B 為錯誤：結構式診斷會談有專為兒童青少年設計的版本（如 K-SADS、DISC），並非不適用。主要陷阱是誤以為結構式太死板不適合兒童，但實務上兒少結構式會談工具相當普遍。

第 7 題

下列何項測驗較不常被用來評估執行功能？
  1. （A）Wisconsin Card Sorting Test
  2. （B）Raven's Progressive Matrices
  3. （C）Trail Making Test
  4. （D）Controlled Oral Word Association Test

答案：（B）

詳解與考點

考點為執行功能（executive function）的評估工具。威斯康辛卡片分類、路徑描繪 B、控制性口語連結（語文流暢）都評估轉換、抑制、計畫等執行功能。正解 B 瑞文氏漸進矩陣較不用於執行功能，它主要測非語文推理與一般智力（流體智力）。主要陷阱是把推理測驗誤當執行功能測驗，兩者構念不同。

第 8 題

關於羅夏克墨漬測驗Exner's Comprehensive System的特殊計分，下列何者不需區分層次（Level）？
  1. （A）偏差反應（DR）
  2. （B）寓言神奇式組合（FABCOM）
  3. （C）不協調的組合（INCOM）
  4. （D）抽象內容（AB）

答案：（D）

詳解與考點

考點為羅夏克 Exner 綜合系統的特殊計分是否需區分層次（Level 1/2）。DR、FABCOM、INCOM 屬認知特殊分數，需依嚴重程度區分層次。正解 D 抽象內容（AB）不需區分層次。主要陷阱是把所有特殊分數都當成需分層，但 AB 是內容性質的標記，並非依認知失誤嚴重度分層的項目。此題依 Exner 系統規則判定。

第 9 題

有關智力測驗，下列敘述何者錯誤？
  1. （A）魏氏成人智力測驗第四版（WAIS-IV）的語言智商與操作智商的平均數均為100
  2. （B）魏氏兒童智力測驗第四版（WISC-IV）並非依據特定的智力理論而建立
  3. （C）史比量表第五版主要依據Cattell-Horn-Carrol（CHC）的智力理論而建立
  4. （D）史比量表第五版利用項目反應理論（item-response theory）作為其心理計量的基礎

答案：（A）

詳解與考點

考點為各智力測驗的特性。WISC-IV 非依特定理論建立、史比五版依 CHC 理論並用項目反應理論，皆正確。正解 A 為錯誤：WAIS-IV 已取消語言與操作智商的二分架構，改為四個指數分數，故「語言智商與操作智商平均皆 100」的敘述不符 WAIS-IV。主要陷阱是沿用舊版 WAIS-III 的語言/操作二分概念。

第 10 題

關於心理衡鑑報告的呈現方式，下列敘述何者最適當？
  1. （A）建議的部分，應儘量選用專業術語
  2. （B）應儘量避免提供自助式的資源
  3. （C）可提供尋求心理協助的管道
  4. （D）不可呈現個案不想讓轉介醫師得知的內容

答案：（C）

詳解與考點

考點為心理衡鑑報告的呈現原則。報告應避免艱澀術語、可提供自助資源與求助管道，並以個案最佳利益呈現。正解 C 正確：可提供尋求心理協助的管道。主要陷阱：A 錯在建議應少用術語以利理解；B 錯在不應避免提供自助資源；D 過於絕對，報告呈現須兼顧臨床需要與倫理，非一概不可呈現。

第 11 題

進行臨床心理衡鑑的過程中，必須選擇特定之施測工具與方式時，下列何者不是選擇的重要考量？
  1. （A）衡鑑的目的
  2. （B）測驗工具所使用的時間長短
  3. （C）個案的年齡、教育程度以及生理狀態等
  4. （D）個案的情緒狀態

答案：（D）

詳解與考點

考點為選擇施測工具的重要考量。衡鑑目的、測驗耗時、個案年齡教育生理狀態都是選工具時須考量的因素。正解 D 個案情緒狀態較不是選擇工具的「重要考量」。主要陷阱是情緒狀態雖會影響施測表現與結果解讀，但它屬於施測時的觀察與控制變項，而非決定選用哪項工具的主要依據。此題以相對重要性判斷。

第 12 題

關於心理衡鑑的「可得取式偏誤（availability bias）」，下列敘述何者錯誤？
  1. （A）此偏誤代表衡鑑者常用手邊容易取得的資料來做判斷
  2. （B）衡鑑過程中最明顯或鮮明的資訊即為最容易取得的資料
  3. （C）此偏誤又可稱為「驗證式偏誤（confirmatory bias）」
  4. （D）轉介來源的敘述可能導致此偏誤

答案：（C）

詳解與考點

考點為衡鑑的可得取式偏誤（availability bias）。它指衡鑑者用手邊容易取得、最鮮明的資訊判斷，轉介來源敘述常引發此偏誤。正解 C 為錯誤：可得取式偏誤不等於驗證式偏誤（confirmatory bias），後者指只蒐集支持既有假設的證據，兩者是不同偏誤。主要陷阱是把兩個名稱相近的認知偏誤混為一談。

第 13 題

一位70歲老先生的心理衡鑑結果只呈現時間定向感較差，但臨床心理師事後從病歷中得知病患在神經內科、家醫科與復健科門診，都被診斷為失智症。因此在報告中做出失智症的判斷，他可能犯了何種衡鑑偏誤？
  1. （A）後見之明偏誤（hindsight bias）
  2. （B）基本率偏誤（base rate bias）
  3. （C）悔恨偏誤（regret bias）
  4. （D）代表性偏誤（representativeness bias）

答案：（A）

詳解與考點

考點為衡鑑偏誤辨識。心理師原本只見時間定向差，得知其他科已診斷失智後才在報告下失智判斷——這是事後得知結果再回溯認為「早該看出」，屬後見之明偏誤（hindsight bias），故正解 A。主要陷阱是誤選代表性偏誤或基本率偏誤，但本題關鍵在「事後得知結果而影響判斷」，正是後見之明的定義特徵。

第 14 題

關於臨床心理師接受精神科醫師轉介之心理衡鑑，下列何者最不適當？
  1. （A）理解醫師做病人入出院決策的法律與社會責任
  2. （B）留意醫師對療效評估的可能期待
  3. （C）理解醫師與臨床心理師在病理概念上可能的差異
  4. （D）留意精神疾病藥物資訊並直接給予用藥處方建議

答案：（D）

詳解與考點

考點為臨床心理師接受精神科醫師轉介衡鑑的適當作為。理解醫師的法律責任、療效期待、病理概念差異皆適當。正解 D 最不適當：直接給予用藥處方建議超出臨床心理師的業務範圍（用藥屬醫師職權），故不當。主要陷阱是把「留意藥物資訊」與「給予處方建議」混為一談，前者可，後者逾越專業分際。

第 15 題

迄今已發展出不少估計病前智商（premorbid IQ）的方法，下列何者不包括在內？
  1. （A）採用魏氏智力測驗中較不易受腦傷影響的數項分測驗（如詞彙、常識）
  2. （B）採用標準化閱讀測驗
  3. （C）採用以多項記憶力測驗分數為基礎的迴歸方程式
  4. （D）採用魏氏智力測驗中最高分的二或三項測驗

答案：（C）

詳解與考點

考點為估計病前智商（premorbid IQ）的方法。常用方法包括採不易受腦傷影響的分測驗（詞彙、常識）、標準化閱讀測驗、取最高分數項目來推估原有水準。正解 C 不包括：以「記憶力測驗分數」為基礎的迴歸方程式不是估計病前智商的標準方法，記憶力本身常受腦傷影響。主要陷阱是把記憶與智商穩定性混淆。

第 16 題

魏氏智力測驗的量尺分數（Scale Score）9、7、4分別對應的百分等級（PR）為何？
  1. （A）36、16、2
  2. （B）37、16、2
  3. （C）37、16、1
  4. （D）36、16、1

答案：（B）

詳解與考點

考點為魏氏量尺分數（平均 10、標準差 3）對應的百分等級。量尺分數 9 約對應 PR37、7 約對應 PR16、4 約對應 PR2，故正解 B（37、16、2）。主要陷阱是 9 分對應 PR 在 37 與 36 間易混淆，以及 4 分對應 PR2 易誤判為 PR1；須依常態分配 z 值換算（9 約 z=−0.33、4 約 z=−2）精確對照。

第 17 題

在臨床心理實務上，強調對某特定問題採用有實徵資料支持之特定介入方式，此概念稱為：
  1. （A）theory-based practice
  2. （B）evidence-based practice
  3. （C）medicine-based practice
  4. （D）culture-based practice

答案：（B）

詳解與考點

考點為實證取向實務的概念名稱。針對特定問題採用有實徵資料支持的特定介入方式，稱為實證本位實務（evidence-based practice），故正解 B。主要陷阱是誤選 theory-based practice：以理論為基礎不等於有實證資料支持；evidence-based 強調的是研究證據的支撐，這是當代臨床心理實務的核心原則。

第 18 題

根據Wampold（2001）的分析，下列何者為有效心理治療的核心因素？
  1. （A）工作同盟
  2. （B）特定治療技術
  3. （C）治療前的心理衡鑑
  4. （D）診斷的正確性

答案：（A）

詳解與考點

考點為 Wampold 對心理治療有效因素的分析。Wampold 的脈絡模式（contextual model）強調共同因素，其中工作同盟（治療關係）是有效治療的核心，故正解 A。主要陷阱是誤選特定治療技術：Wampold 的研究結論正是質疑特定技術的決定性，主張共同因素（如同盟）比特定技術更能解釋療效。

第 19 題

根據Corey（2017），下列何項治療師人格特質是有利於治療關係與效果？
  1. （A）能追求完美
  2. （B）模糊忍受度要低
  3. （C）能選擇與經營自己的生活
  4. （D）堅信自己一定可以幫助所有個案

答案：（C）

詳解與考點

考點為 Corey 所述有利治療關係的治療師人格特質。能選擇與經營自己的生活、展現真誠與自我覺察，有利治療關係，故正解 C。主要陷阱：A 追求完美、B 模糊忍受度低、D 堅信能幫助所有個案，皆為不利特質——好的治療師應能忍受模糊、不強求完美、保有現實的限制感，而非全能幻想。

第 20 題

關於阿德勒治療理論，下列敘述何者錯誤？
  1. （A）消除個體的自卑感是治療的主要任務
  2. （B）重視個體的整合性與不可分割性
  3. （C）認為個體會主動組織自己認定的事實，並依此賦予意義
  4. （D）認為社會興趣是天生的

答案：（A）

詳解與考點

考點為阿德勒治療理論。阿德勒重視整體不可分割性、個體主動建構意義、社會興趣為天生潛能，皆正確。正解 A 為錯誤：阿德勒並非要「消除」自卑感，自卑感是成長與追求卓越的動力，治療目標是培養社會興趣與健康的克服方式，而非消除自卑。主要陷阱是把自卑感當成純粹病態而誤以為要消除。

第 21 題

讓個案暴露於現實生活中的害怕情境是屬於下列何種暴露法？
  1. （A）in vivo exposure
  2. （B）imaginal exposure
  3. （C）interoceptive exposure
  4. （D）in vitro exposure

答案：（A）

詳解與考點

考點為暴露治療的類型。讓個案暴露於現實生活中真實的害怕情境，屬實境暴露（in vivo exposure），故正解 A。主要陷阱是誤選 imaginal exposure（想像暴露），那是在想像中面對情境；interoceptive exposure 是暴露於身體內感覺（如心跳）；in vitro 並非標準暴露法用語。關鍵字是「現實生活中」對應 in vivo。

第 22 題

依據Lazarus的多元模式治療（multimodal therapy），若要瞭解個案BASIC I.D.中有關「I（Image）」的訊息，可能會如何詢問個案？
  1. （A）你對生活中的重要他人有什麼期待？
  2. （B）你最重視的信念與價值是什麼？
  3. （C）你會如何看待你自己？
  4. （D）什麼樣的情緒目前最令你困擾？

答案：（C）

詳解與考點

考點為 Lazarus 多元模式治療 BASIC I.D. 中的 I（Image，心像）。Image 指個案的自我形象與心像，故詢問「你會如何看待你自己」最對應，正解 C。主要陷阱：問重要他人期待屬人際（I, Interpersonal）、問信念價值屬認知（C, Cognition）、問困擾情緒屬情感（A, Affect），各字母對應不同模式須分清。

第 23 題

尼采說「人只要參透為何而活，即能承受任何煎熬」，這句話最適合用來代表那一種心理治療取向？
  1. （A）Existential Therapy
  2. （B）Person-centered Therapy
  3. （C）Acceptance and Commitment Therapy
  4. （D）Psychodynamic Therapy

答案：（A）

詳解與考點

考點為治療取向與哲學語句的對應。「人只要參透為何而活，即能承受任何煎熬」（尼采，亦為 Frankl 意義治療引用），強調生命意義作為承受苦難的力量，最對應存在主義治療，故正解 A。主要陷阱是誤選 ACT：ACT 雖重視價值，但此句的意義與存在追問核心更貼近存在主義治療的精神。

第 24 題

有關完形治療理論的原則，下列敘述何者錯誤？
  1. （A）強調整體觀，認為所有的本質應該被視為統整且一致的，而整體不等於部分的總和
  2. （B）強調有機體的自我調整，認為當原有的平衡被擾動時，會儘可能以自身能力與環境資源進行調整
  3. （C）基於場地理論（field theory），認為有機體的行為應由環境、脈絡整體來理解
  4. （D）強調具體觀，認為心理治療的操作應該聚焦在明確且可客觀測量的外顯行為

答案：（D）

詳解與考點

考點為完形治療的原則。完形強調整體觀（整體不等於部分總和）、有機體自我調整、場地理論。正解 D 為錯誤：完形治療重視此時此刻的覺察與整體經驗，並不主張只聚焦「明確可客觀測量的外顯行為」，那是行為取向的立場。主要陷阱是把行為治療的可測量外顯行為原則誤套到完形治療上。

第 25 題

Natalie Rogers將Carl Rogers的創造力理論擴展至表達性藝術治療（Expressive Arts Therapy），用以促進個人成長。關於表達性藝術治療的概念原則，下列敘述何者錯誤？
  1. （A）表達性藝術引導個人進入潛意識，為個人帶來新的訊息與覺察
  2. （B）個人的想法與行為是能量來源，能夠透過表達性藝術被釋放與轉換
  3. （C）透過自我覺察、自我了解和頓悟，會達到個人成長和更高的意識狀態
  4. （D）每個人天生具有創造力，創造的歷程不僅有變化性，也有療癒性

答案：（B）

詳解與考點

考點為 Natalie Rogers 表達性藝術治療的原則。表達性藝術引人進入潛意識帶來覺察、透過自我覺察頓悟促成長、人天生具創造力且歷程具療癒性，皆正確。正解 B 為錯誤敘述：能量來源的描述與原理表述有偏差，依該理論核心應以感受與創造歷程為釋放轉換的媒介。

第 26 題

關於敘事治療的外化對話（externalizing conversations），下列敘述何者錯誤？
  1. （A）標認出問題對個案生活的影響
  2. （B）標認出個案生活對問題的影響
  3. （C）尋找生活未完全受問題影響的閃亮時刻（sparkling moments）
  4. （D）不宜用在已經診斷確立的個案

答案：（D）

詳解與考點

考點為敘事治療的外化對話。外化將問題與人分開，包括標認問題對生活的影響、生活對問題的影響、尋找閃亮時刻（獨特結果）。正解 D 為錯誤：外化對話並非「不宜用在診斷確立的個案」，敘事治療正可協助已診斷個案鬆動問題認同。主要陷阱是誤以為診斷確立就不適用外化，實則相反。

第 27 題

有關家族治療，下列何者比較偏向阿德勒學派的作法？
  1. （A）治療師仔細分析家人與治療師之間的三角關係與跨世代模式
  2. （B）治療師詢問家人的早期記憶以及出生排行，瞭解家人在互動上的目標
  3. （C）治療師指出個案家庭存在的次系統，並說明次系統設立的規則與界限
  4. （D）治療師觀察家人互動後指出，父母常用的溝通型態分別是指責型與討好型

答案：（B）

詳解與考點

考點為阿德勒學派家族治療的特徵作法。阿德勒重視早期記憶與出生排行，以理解家人互動的目標與生活風格，故正解 B。主要陷阱：分析三角關係與跨世代屬 Bowen 家族系統；指出次系統與界限屬結構派（Minuchin）；指責型與討好型溝通屬 Satir 模式。各學派招牌概念須對應正確。

第 28 題

家庭氣氛（family atmosphere）、家庭系統排列（family constellation）為下列何種治療取向的主要概念？
  1. （A）阿德勒家族治療
  2. （B）Satir模式家族治療
  3. （C）策略家族治療
  4. （D）結構派家族治療

答案：（A）

詳解與考點

考點為「家庭氣氛」與「家庭星座（family constellation）」的所屬學派。這兩個概念是阿德勒家族治療的核心，用以理解出生排行與家庭互動氛圍對個體的影響，故正解 A。主要陷阱是誤選 Satir 模式：Satir 的招牌是溝通姿態與家庭重塑，而家庭星座、出生排行是阿德勒的標誌性概念。

第 29 題

有關失智症心理介入的近期療效證據，下列敘述何者錯誤？
  1. （A）運動似乎對改善認知功能有適度效果
  2. （B）認知處理速度訓練對年長者的認知有正向效果
  3. （C）放鬆訓練可減輕失智者的妄想症狀
  4. （D）行為取向治療有助於代償記憶功能

答案：（C）

詳解與考點

考點為失智症心理介入的近期療效證據。運動對認知有適度效果、處理速度訓練有正向效果、行為取向有助代償記憶，皆有證據支持。正解 C 為錯誤：放鬆訓練可緩解焦慮或激躁，但「減輕妄想症狀」缺乏明確療效證據支持。主要陷阱是把放鬆對情緒的助益誇大為能改善精神病性的妄想症狀。

第 30 題

關於社交技巧訓練（social skills training），下列敘述何者錯誤？
  1. （A）適用於有溝通與社交困難的兒童
  2. （B）教導正確語言和正確行動
  3. （C）不涉及信念改變和情緒問題的處理
  4. （D）認知落後者經過環境調整和搭配行為改變技術亦能適用

答案：（C）

詳解與考點

考點為社交技巧訓練的內涵。它適用於有社交困難的兒童、教導正確語言與行動、認知落後者經調整亦可適用。正解 C 為錯誤：社交技巧訓練常結合認知重建與情緒處理（如解讀社交線索、處理焦慮），並非「不涉及信念與情緒」。主要陷阱是把社交技巧訓練窄化為純行為演練，忽略其認知與情緒成分。

第 31 題

有關憂鬱症的心理治療，下列敘述何者正確？
  1. （A）認知行為治療、人際心理治療、長期精神分析治療皆有大量臨床研究證據支持有效
  2. （B）行為活化可以改善憂鬱症患者的心情
  3. （C）認知行為治療與抗憂鬱藥物治療的療效相比，大量研究都一致支持前者優於後者
  4. （D）人際心理治療是長期心理治療，關注憂鬱症患者兒時與重要他人的依附關係

答案：（B）

詳解與考點

考點為憂鬱症心理治療的實證。正解 B 正確：行為活化（behavioral activation）能增加正向經驗、改善心情，是具實證的憂鬱治療成分。主要陷阱：A 錯在長期精神分析並無大量強證據；C 錯在 CBT 與抗憂鬱藥療效相當而非一致優於藥物；D 錯在人際心理治療是短期、聚焦當前人際問題，非長期分析兒時依附。

第 32 題

暴露不反應法（exposure and response prevention, ERP）能有效治療強迫症，下列敘述何者正確？
  1. （A）是行為取向治療，治療者應避免向個案說明ERP原理作法
  2. （B）暴露會先挑選誘發中等焦慮苦惱的情境或刺激開始練習
  3. （C）個案的動機會隨著暴露效果提升，治療者無須費心關注此部分
  4. （D）療效主要來自於個案學習到更有效因應強迫思考的行為策略

答案：（B）

詳解與考點

考點為暴露不反應法（ERP）治療強迫症的正確作法。正解 B 正確：暴露應依焦慮階層由中等苦惱情境開始循序漸進。主要陷阱：A 錯在應向個案說明 ERP 原理以提升配合；C 錯在治療者須持續關注並維持個案動機；D 錯在療效核心來自暴露後不執行儀式所達成的習慣化與消弱，而非僅學新因應策略。

第 33 題

個案同意參與為期兩天的研究，在第二天只剩10分鐘即可結束時，決定退出研究，研究者最適當的作法為何？
  1. （A）要求個案繼續將研究完成
  2. （B）同意個案的要求，並將兩天的研究資料銷毀
  3. （C）尊重個案退出但無須銷毀研究資料
  4. （D）僅須銷毀第二天的研究資料

答案：（B）

詳解與考點

考點為研究倫理中受試者的退出權。個案有權隨時退出研究，且退出時可要求銷毀其資料，研究者應尊重，故正解 B（同意退出並銷毀兩天資料）。主要陷阱是誤選 C（不須銷毀資料）：受試者退出時若要求，研究者應尊重其撤回同意並處理資料；要求個案繼續完成（A）更明顯違反自願原則。

第 34 題

下列何項不屬於心理治療專業保密原則所界定的例外？
  1. （A）依法令規定，揭露個案未付之治療費用
  2. （B）個案牽涉到兒童虐待與疏忽
  3. （C）個案涉及公共危險
  4. （D）個案敘述介入他人婚姻

答案：（D）

詳解與考點

考點為心理治療保密原則的例外情形。法定通報（兒虐疏忽）、公共危險（傷人傷己）屬保密例外。正解 D 為非例外：個案敘述介入他人婚姻，無立即危害他人生命安全或法定通報義務，不構成突破保密的正當理由。主要陷阱是把道德上不認同的行為誤當成保密例外，例外須以法律或重大危害為依據。

第 35 題

根據臨床心理師倫理規範，下列何項具有倫理爭議？
  1. （A）領養接受自己心理治療協助的家暴受虐兒
  2. （B）拒絕個案的期貨投資邀約
  3. （C）當個案的問題尚未獲解決，心理師因故無法繼續治療時，徵詢個案的意願並轉介
  4. （D）面對社會矚目案件的個案，能明確拒絕記者邀訪

答案：（A）

詳解與考點

考點為臨床心理師的倫理界線（雙重關係）。正解 A 具倫理爭議：領養正在接受自己治療的受虐兒，形成嚴重的雙重關係，損害治療客觀性與個案福祉，違反倫理。主要陷阱是 B、C、D 其實都是合宜處置（拒絕投資邀約、轉介前徵詢意願、拒絕記者邀訪），題目問的是「具爭議者」，須挑出違反界線的選項。

第 36 題

臨床心理師設計了一個檢驗認知行為治療在高怨懟的憂鬱症病患之療效研究，下列敘述何者錯誤？
  1. （A）需對研究中的「怨懟」與「憂鬱症」有明確的操作型定義
  2. （B）需明確說明所採用的手冊化的治療方式
  3. （C）控制組應採用「低怨懟的憂鬱症病患」
  4. （D）需要使用具信、效度的結果評估工具

答案：（C）

詳解與考點

考點為療效研究設計。研究高怨懟憂鬱症病患的 CBT 療效，須有明確操作型定義、手冊化治療、信效度評估工具，皆正確。正解 C 為錯誤：控制組應為「高怨懟憂鬱症」病患（與實驗組同質）接受對照處理，而非改用「低怨懟」病患，否則混淆了自變項。主要陷阱是把控制組與實驗組的關鍵特徵設成不同而破壞可比較性。

第 37 題

關於療效研究中的隨機控制試驗特性，下列敘述何者正確？
  1. （A）由參與者自主選擇實驗組或控制組
  2. （B）比起內在效度，更著重外在效度
  3. （C）主要用於判定治療的效能（efficacy）
  4. （D）有助於了解治療應用於真實世界的效果

答案：（C）

詳解與考點

考點為隨機控制試驗（RCT）的特性。RCT 採隨機分派、重視內在效度，主要用於判定治療的效能（efficacy，理想控制條件下的效果），故正解 C。主要陷阱：A 錯在應隨機分派而非自選組別；B 錯在 RCT 著重內在效度而非外在效度；D 真實世界的效果（effectiveness）屬效果研究，非 RCT 的主要目的。

第 38 題

某臨床心理師發表了一個10題的「慮病量表」，而該量表與貝克焦慮量表（BAI）之效標關連效度高達0.84。但細看後，發現該量表中有5題與BAI的題目內容非常相近，顯見BAI應不是此「慮病量表」的好效標，最主要的原因是：
  1. （A）效標可信度不足
  2. （B）效標所測之概念並不恰當
  3. （C）效標所測之內容易隨時間變動
  4. （D）效標受到測驗的污染

答案：（D）

詳解與考點

考點為效標關連效度中的效標污染（criterion contamination）。慮病量表有半數題目與 BAI 題目雷同，使兩者相關虛高，這是因效標與測驗內容重疊造成的污染，故正解 D。主要陷阱是誤選「效標概念不恰當」：問題不在 BAI 概念本身，而在題目內容重疊導致高相關是人為假象，屬效標污染。

第 39 題

某療效研究的結果顯示其統計檢定力（power）為0.45，關於虛無假設（H0）與替代假設（H1），下列敘述何者正確？
  1. （A）當H0為真時，正確拒絕H1的機會為45%
  2. （B）當H0為真時，錯誤接受H1的機會為45%
  3. （C）當H1為真時，正確拒絕H0的機會為45%
  4. （D）當H1為真時，錯誤接受H0的機會為45%

答案：（C）

詳解與考點

考點為統計檢定力（power）的定義。檢定力 = 當 H1 為真時正確拒絕 H0 的機率（1−β），故 power 0.45 表示當 H1 為真時正確拒絕 H0 的機會為 45%，正解 C。主要陷阱是把檢定力與 H0 為真的情境混淆：A、B 在 H0 為真下談論，屬於型一錯誤範疇；D「錯誤接受 H0」是型二錯誤（β），非檢定力本身。

第 40 題

下列何項測驗表現與執行功能的關聯性最低？
  1. （A）手指靈巧度測驗（Finger Dexterity Test）
  2. （B）語文流暢度測驗（Verbal Fluency Test）
  3. （C）Go-No Go測驗
  4. （D）路徑描繪測驗（Trail Making Test）

答案：（A）

詳解與考點

考點為與執行功能關聯最低的測驗。語文流暢度、Go-No Go、路徑描繪都評估抑制、轉換、提取等執行功能。正解 A 手指靈巧度測驗關聯最低，它主要測精細動作協調與手部靈巧，屬動作功能而非執行功能。主要陷阱是把動作測驗誤當認知執行測驗，須分清動作靈巧與前額葉執行控制的差別。
