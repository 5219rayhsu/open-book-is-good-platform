第 1 題

臨床工作者實施心理衡鑑時的主要角色功能為何？
  1. （A）與個案建立關係
  2. （B）同理個案在生活中遇到的問題
  3. （C）施測心理測驗，以便形成對個案問題的各種描述
  4. （D）回答轉介問題，並做出具體且合理的建議來協助個案

答案：（D）

詳解與考點

正解：判準是心理衡鑑歷程中「手段」與「最終目的」的區別。衡鑑的核心目的是回答轉介問題，並提出具體且合理的建議來協助個案，故選D。

A：與個案建立關係是進行衡鑑歷程中的必要基礎，但屬於歷程手段而非最終目的，故非答案。

B：同理個案在生活中遇到的問題同屬會談歷程中的態度或技巧，非衡鑑的主要角色功能，故非答案。

C：施測心理測驗以形成對個案問題的各種描述，是蒐集資料的工具性步驟，是最強誘答——它看似是衡鑑最具體可見的動作，分辨關鍵在於施測與描述只是蒐集資料的手段，最終仍要落實到回答轉介問題並提出建議，才是衡鑑的主要角色功能。

本題考點：心理衡鑑（psychological assessment）中臨床工作者角色功能的判準——建立關係、同理、施測測驗皆屬歷程手段；回答轉介問題並提出具體合理的建議，才是衡鑑的最終目的與主要角色功能，作答時須區分手段與目的層次。

第 2 題

當轉介心理衡鑑的理由模糊不清時，臨床工作者如何處理最為適當？
  1. （A）執行制式化心理測驗
  2. （B）請個案說明進行心理衡鑑的目的
  3. （C）主動與轉介者澄清轉介原因
  4. （D）自行判定兩三個最重要的議題評估

答案：（C）

詳解與考點

正解：關鍵在澄清轉介目的的責任歸屬——轉介目的不清時，最適當的作法是主動與轉介者澄清轉介原因，確保衡鑑方向正確，故選C。

A：執行制式化心理測驗在未釐清轉介目的前貿然進行，可能偏離真正需求，故非答案。

B：請個案說明進行心理衡鑑的目的，是最強誘答——個案未必清楚轉介者背後的真正疑問，澄清轉介目的的責任在轉介者本人，而非透過個案間接確認，分辨關鍵在於誰提出轉介、誰就該被詢問。

D：自行判定兩三個最重要的議題評估，缺乏與轉介者的核對，容易偏離轉介者真正想釐清的問題，故非答案。

本題考點：轉介理由模糊時的處理判準——澄清轉介目的的責任在轉介者，臨床工作者應主動與轉介者核對，而非透過個案間接確認、也不應在未釐清前自行判定評估方向或逕行制式化測驗。

第 3 題

在評鑑心理衡鑑工具的常模時，下列何者不是理想常模的要件？
  1. （A）常模的標準化樣本夠大
  2. （B）採取分層立意抽樣
  3. （C）標準化樣本具代表性
  4. （D）納入特定次群體常模與全國常模

答案：（B）

詳解與考點

正解：理想常模應採分層隨機抽樣以確保樣本代表性，「分層立意抽樣」的「立意」帶有主觀選樣偏誤，並非理想常模的要件，故選B。

A：常模的標準化樣本夠大，是理想常模的基本要件之一，故非答案。

C：標準化樣本具代表性，同為理想常模的核心要件，故非答案。

D：納入特定次群體常模與全國常模，能讓衡鑑結果對照更精確的參照群體，同屬理想常模的要件，故非答案。

本題考點：理想常模（norm）要件的判準——標準化樣本須夠大且具代表性，並納入特定次群體與全國常模；抽樣方法須採分層隨機抽樣，「立意抽樣」因帶有主觀選樣偏誤而不符合代表性要求，作答時勿因「分層」字面正確而忽略「立意」二字所代表的抽樣偏誤。

第 4 題

關於NEO Personality Inventory，下列敘述何者正確？
  1. （A）目的是用來探討臨床心理疾患之人格特質
  2. （B）無簡短版測驗
  3. （C）該測驗之標準化分數之平均數為100，標準差為15
  4. （D）量表包含五個主要特質量尺

答案：（D）

詳解與考點

正解：本題問的是關於NEO人格量表（NEO Personality Inventory, NEO-PI）敘述何者正確，判準是逐項比對其測量目的、版本與計分標準。NEO-PI測量五大人格特質（神經質、外向性、開放性、親和性、嚴謹性），量表包含五個主要特質量尺，故選D。

A：NEO-PI的目的是測量一般人格特質，而非探討臨床心理疾患，此敘述與量表編製目的不符，故非答案。

B：NEO-PI有簡短版測驗（NEO Five-Factor Inventory, NEO-FFI），並非「無簡短版」，故非答案。

C：平均數100、標準差15是離差智商（deviation IQ）常見的計分設定，並非NEO-PI的標準化分數計分方式，是最強誘答——分辨關鍵在於離差智商的常態化參數與人格量表的T分數（平均50、標準差10）等計分系統不同，不可混用。

本題考點：NEO人格量表（NEO Personality Inventory）的判準——測量目的為一般人格特質（五大人格：神經質、外向性、開放性、親和性、嚴謹性）而非臨床疾患，具簡短版（NEO-FFI），計分標準不同於智力測驗常用的離差智商（平均100、標準差15）參數，不可混用不同測驗系統的計分設定。

第 5 題

根據柯永河（2001）的臨床心理學專書，下列何項不是決定測驗施測順序應依循的原則？
  1. （A）簡單的測驗先執行，困難的測驗後執行
  2. （B）施測順序不要減低測驗原有的效度
  3. （C）易受疲勞影響的測驗應排在整套測驗的最前面進行
  4. （D）不計時、較費時，但不引起緊張的測驗安排在最後

答案：（C）

詳解與考點

正解 C。依柯永河（2001）對測驗施測順序的原則，安排順序應避免疲勞、緊張等因素「降低測驗原有的效度」，並兼顧難易、暖身等考量：一般採「先簡單、後困難」（A），施測順序不可損及測驗效度（B），不計時、較費時但不引起緊張的測驗安排在最後（D）。

C 之所以為「非原則」：易受疲勞影響的測驗不應排在「最前面」這樣的固定位置敘述並非其施測順序原則；正確的精神是要避免在受試者已疲勞時施測而使效度下降，並綜合考量難易、緊張程度與效度來安排，而非單以「易受疲勞就放最前面」為通則，故選 C。

A、B、D 皆為柯永河所列的施測順序原則，故不選。

第 6 題

有關結構式與非結構式會談的比較，下列敘述何者錯誤？
  1. （A）結構式會談具有較好的心理計量特性
  2. （B）結構式診斷會談不適用於兒童與青少年個案
  3. （C）非結構式會談比較能夠彈性的觀察個案特有的表現
  4. （D）非結構式會談比結構式會談更容易有會談者偏誤

答案：（B）

詳解與考點

正解：判準是結構式診斷會談是否具備兒童青少年適用版本。結構式會談因標準化程度高而具較好的心理計量特性，但這並不等於它不適用於兒童青少年——臨床上已發展出專為此族群設計的結構式診斷會談工具，如兒童情感性疾患及精神分裂症診斷會談（K-SADS）與兒童診斷會談量表（DISC），皆廣泛用於兒少個案，故 B 敘述與事實不符，為應選項。

A：結構式會談因程序固定、評分標準明確，具有較好的信效度等心理計量特性，是結構式會談相對非結構式會談的公認優勢，故非答案。

C：非結構式會談沒有固定程序框架，臨床心理師可依個案當下反應彈性追問、觀察其特有表現，這正是非結構式會談的長處，故非答案。

D：非結構式會談缺乏標準化流程，判斷高度仰賴會談者主觀，較容易受會談者本身的預期與偏好影響而產生會談者偏誤，相對結構式會談確實更容易有此問題，故非答案。

本題考點：結構式與非結構式會談的取捨——結構式勝在心理計量特性與較低的會談者偏誤，非結構式勝在觀察彈性；分辨「不適用於兒童青少年」是否成立時，要記得 K-SADS、DISC 等結構式工具本就有兒少版本，不能把「較死板」直接等同「不能用在兒童」。

第 7 題

下列何項測驗較不常被用來評估執行功能？
  1. （A）Wisconsin Card Sorting Test
  2. （B）Raven's Progressive Matrices
  3. （C）Trail Making Test
  4. （D）Controlled Oral Word Association Test

答案：（B）

詳解與考點

正解：關鍵在區分「執行功能（executive function）」與「流體智力（fluid intelligence）／非語文推理」這兩種不同構念。Wisconsin Card Sorting Test、Trail Making Test、Controlled Oral Word Association Test 分別評估類別轉換與抑制、視覺搜尋與轉換、語文流暢等執行功能次能力；Raven's Progressive Matrices 主要測的是非語文推理與一般智力中的流體智力成分，並非以執行功能為主要評估目的，故 B 為應選項。

A：Wisconsin Card Sorting Test（威斯康辛卡片分類測驗）要求受試者依回饋不斷調整分類規則，直接評估認知彈性與抑制控制，是執行功能的經典評估工具，故非答案。

C：Trail Making Test（路徑描繪測驗，尤其 B 部分）要求在數字與字母間交替連線，評估心理轉換與分配性注意力，屬執行功能評估工具，故非答案。

D：Controlled Oral Word Association Test（受控口語詞彙聯想測驗）評估語文流暢度，涉及自發性提取與策略性搜尋，屬執行功能中的語文流暢成分，故非答案。

本題考點：執行功能評估工具的辨識——WCST、TMT、COWAT 皆屬執行功能範疇；Raven's Progressive Matrices 屬一般智力／流體智力測驗，兩者構念層次不同，不能因為都是「認知測驗」就歸為同一類。

第 8 題

關於羅夏克墨漬測驗Exner's Comprehensive System的特殊計分，下列何者不需區分層次（Level）？
  1. （A）偏差反應（DR）
  2. （B）寓言神奇式組合（FABCOM）
  3. （C）不協調的組合（INCOM）
  4. （D）抽象內容（AB）

答案：（D）

詳解與考點

正解：判準是羅夏克墨漬測驗 Exner's Comprehensive System 中，哪些特殊計分是依「認知失誤的嚴重程度」分為 Level 1 與 Level 2，哪些只是內容性質的標記。偏差反應（DR）、寓言神奇式組合（FABCOM）、不協調的組合（INCOM）都屬「認知特殊分數」，需依語意脫序或組合失當的嚴重程度區分層次；抽象內容（AB）屬「內容特殊分數」，只是標記反應中含有抽象概念或象徵性內容，並非依失誤嚴重度分層的項目，故 D 為應選項。

A：偏差反應（DR）依語言表達脫離現實或邏輯鬆散的程度分為 Level 1（輕度）與 Level 2（明顯脫序），屬需分層的特殊計分，故非答案。

B：寓言神奇式組合（FABCOM）依物體間被賦予不合現實關係的荒謬程度分層，愈脫離現實者層次愈高，屬需分層的特殊計分，故非答案。

C：不協調的組合（INCOM）依物體特徵被不合理融合的程度分層，屬與 FABCOM 同類、需依嚴重度分層的認知特殊分數，故非答案。

本題考點：Exner 綜合系統特殊計分的分類——DR、FABCOM、INCOM 屬需區分 Level 的認知特殊分數，AB（抽象內容）等屬內容性質標記、不涉及嚴重度分層；分辨關鍵在於該計分描述的是「思考歷程是否脫序」還是「反應內容含有什麼元素」。

第 9 題

有關智力測驗，下列敘述何者錯誤？
  1. （A）魏氏成人智力測驗第四版（WAIS-IV）的語言智商與操作智商的平均數均為100
  2. （B）魏氏兒童智力測驗第四版（WISC-IV）並非依據特定的智力理論而建立
  3. （C）史比量表第五版主要依據Cattell-Horn-Carrol（CHC）的智力理論而建立
  4. （D）史比量表第五版利用項目反應理論（item-response theory）作為其心理計量的基礎

答案：（A）

詳解與考點

正解：判準是 WAIS-IV（魏氏成人智力測驗第四版）是否仍保留語言智商（VIQ）與操作智商（PIQ）的二分架構。WAIS-IV 已捨棄舊版 WAIS-III 的語言／操作二分，改以全量表智商外加語文理解、知覺推理、工作記憶、處理速度四個指數分數呈現，因此「語言智商與操作智商的平均數均為 100」這一敘述已不適用於 WAIS-IV，故 A 與事實不符，為應選項。

B：WISC-IV（魏氏兒童智力測驗第四版）並非依據單一特定的智力理論建構而成，而是綜合多方研究與臨床實務考量發展出四指數架構，敘述正確，故非答案。

C：史比量表第五版主要依據 Cattell-Horn-Carrol（CHC）智力理論建立，以流體推理、知識、量化推理、視覺空間處理、工作記憶五大因素為架構，敘述正確，故非答案。

D：史比量表第五版以項目反應理論（item-response theory）作為心理計量基礎，用以校準題目難度與建立常模，敘述正確，故非答案。

本題考點：智力測驗版本沿革的辨識——WAIS-IV 已以四指數分數取代 WAIS-III 的語言／操作智商二分；WISC-IV 不依單一理論建立；史比五版依 CHC 理論並以項目反應理論為心理計量基礎，三者的理論依據與計分架構須逐一對應版本，不可用舊版概念套用新版測驗。

第 10 題

關於心理衡鑑報告的呈現方式，下列敘述何者最適當？
  1. （A）建議的部分，應儘量選用專業術語
  2. （B）應儘量避免提供自助式的資源
  3. （C）可提供尋求心理協助的管道
  4. （D）不可呈現個案不想讓轉介醫師得知的內容

答案：（C）

詳解與考點

正解：本題問的是心理衡鑑報告呈現方式的適當性，判準是報告是否以個案能理解、能運用的方式撰寫，並顧及個案的求助需要。在報告中適度提供尋求心理協助的管道（如轉介資源、後續求助方式），有助於個案將衡鑑結果轉化為實際行動，符合報告服務個案的目的，故 C 為應選項。

A：建議部分應儘量選用專業術語——與呈現原則相反。衡鑑報告的建議是寫給個案、家屬或非心理專業的轉介來源看的，應以淺白易懂的語言呈現，過度使用專業術語反而阻礙理解，故非答案。

B：應儘量避免提供自助式的資源——同樣與適當做法相反。報告若能視情況提供自助資源，有助個案在正式療程之外持續獲得協助，避免提供反而減損報告的實用性，故非答案。

D：不可呈現個案不想讓轉介醫師得知的內容——此說法過於絕對。報告內容須兼顧個案福祉、保密原則與轉介需要之間的臨床判斷，並非一律不可呈現，須視資訊對治療決策的必要性而定，故非答案。

本題考點：心理衡鑑報告呈現原則——語言要淺白而非堆砌術語、可視情況提供自助資源與求助管道、內容取捨依個案福祉與臨床必要性做判斷而非絕對化的規則。

第 11 題

進行臨床心理衡鑑的過程中，必須選擇特定之施測工具與方式時，下列何者不是選擇的重要考量？
  1. （A）衡鑑的目的
  2. （B）測驗工具所使用的時間長短
  3. （C）個案的年齡、教育程度以及生理狀態等
  4. （D）個案的情緒狀態

答案：（D）

詳解與考點

正解：關鍵在區分「選擇施測工具時的重要考量」與「施測過程中須觀察與控制的變項」。衡鑑目的、測驗所需時間、個案的年齡教育程度與生理狀態，都直接決定該不該用某項工具、能不能施測；個案的情緒狀態雖會影響作答表現與結果解讀，但它是施測當下要留意與納入判讀的變項，而非事先決定「選用哪個工具」的主要依據，故 D 為應選項。

A：衡鑑的目的決定了要回答什麼問題，進而決定該選用哪類工具（如人格衡鑑、認知衡鑑或神經心理衡鑑），是選擇工具最上位的考量，故非答案。

B：測驗工具所需的施測時間長短，須配合個案的耐受度與可用時間安排，時間過長的工具在特定情境下未必可行，是實務上必要的考量，故非答案。

C：個案的年齡、教育程度以及生理狀態等，直接關係到某項工具是否有對應常模、題目難度是否合宜、個案生理狀況能否配合施測，是選擇工具時的核心考量，故非答案。

本題考點：施測工具選擇的考量層次——衡鑑目的、施測時間、個案的年齡教育與生理狀態，都是決定「該不該用這項工具」的事前考量；情緒狀態屬施測過程中的觀察與控制變項，兩個層次不宜混為一談。

第 12 題

關於心理衡鑑的「可得取式偏誤（availability bias）」，下列敘述何者錯誤？
  1. （A）此偏誤代表衡鑑者常用手邊容易取得的資料來做判斷
  2. （B）衡鑑過程中最明顯或鮮明的資訊即為最容易取得的資料
  3. （C）此偏誤又可稱為「驗證式偏誤（confirmatory bias）」
  4. （D）轉介來源的敘述可能導致此偏誤

答案：（C）

詳解與考點

正解：判準是可得取式偏誤（availability bias）與驗證式偏誤（confirmatory bias）是否為同一概念。可得取式偏誤指衡鑑者傾向以手邊容易取得、最鮮明的資訊做判斷；驗證式偏誤則指衡鑑者只蒐集、採信能支持既有假設的證據，兩者關注的焦點不同——一個是資訊「取得的難易與鮮明度」，一個是資訊「是否支持既有假設」，並非同一偏誤的兩種稱法，故 C 敘述有誤，為應選項。

A：可得取式偏誤確實代表衡鑑者常用手邊容易取得的資料做判斷，這是此偏誤最核心的定義，故非答案。

B：衡鑑過程中最明顯或最鮮明的資訊，往往也是最容易被注意到、最容易取得的資料，兩者高度重疊，敘述正確，故非答案。

D：轉介來源的敘述通常是衡鑑者最早接觸、印象最鮮明的資訊來源，若過度倚賴這些敘述做判斷，確實可能導致可得取式偏誤，敘述正確，故非答案。

本題考點：衡鑑歷程常見認知偏誤的辨識——可得取式偏誤聚焦資訊的取得難易與鮮明度（轉介來源敘述是常見來源），驗證式偏誤聚焦是否只採信支持假設的證據，兩者名稱相近但定義不同，不可互稱。

第 13 題

一位70歲老先生的心理衡鑑結果只呈現時間定向感較差，但臨床心理師事後從病歷中得知病患在神經內科、家醫科與復健科門診，都被診斷為失智症。因此在報告中做出失智症的判斷，他可能犯了何種衡鑑偏誤？
  1. （A）後見之明偏誤（hindsight bias）
  2. （B）基本率偏誤（base rate bias）
  3. （C）悔恨偏誤（regret bias）
  4. （D）代表性偏誤（representativeness bias）

答案：（A）

詳解與考點

正解：本題問的是心理師「先只見時間定向感較差、後來得知其他科已診斷失智，才在報告中做出失智判斷」這個歷程屬於哪種偏誤，判準是偏誤發生的時間點——是在得知結果「之後」才回頭認為原本的線索早該指向該結論。這正是後見之明偏誤（hindsight bias）的定義特徵：得知結果後，高估自己原本就能預見或看出該結果的程度，故 A 為應選項。

B：基本率偏誤（base rate bias）指忽略母群體中某現象的既有發生率、單憑個案表現做判斷，本題的問題不在於忽略失智症的盛行率，而在於受事後得知的結果影響判斷，故非答案。

C：悔恨偏誤（regret bias）指決策時過度考量未來可能後悔的感受而扭曲判斷，本題情境未涉及對決策後果的悔恨考量，故非答案。

D：代表性偏誤（representativeness bias）指依個案是否「像」某類典型而做判斷，忽略基本率等其他資訊，本題的關鍵不在於個案是否符合失智症的典型樣貌，而在於得知病歷結果後才回溯下判斷，故非答案。

本題考點：後見之明偏誤（hindsight bias）與其他衡鑑偏誤的分辨——判準是「是否在得知結果之後，才認為原本證據早已充分指向該結果」；與基本率偏誤（忽略發生率）、代表性偏誤（依典型樣貌判斷）、悔恨偏誤（考量未來悔恨）分屬不同的判斷歷程。

第 14 題

關於臨床心理師接受精神科醫師轉介之心理衡鑑，下列何者最不適當？
  1. （A）理解醫師做病人入出院決策的法律與社會責任
  2. （B）留意醫師對療效評估的可能期待
  3. （C）理解醫師與臨床心理師在病理概念上可能的差異
  4. （D）留意精神疾病藥物資訊並直接給予用藥處方建議

答案：（D）

詳解與考點

正解：本題問的是臨床心理師接受精神科醫師轉介衡鑑時，哪一項作為逾越其專業分際，判準是該作為是否屬於臨床心理師的法定業務範圍。留意精神疾病藥物資訊、了解藥物可能對衡鑑結果的影響，屬合理範圍；但直接給予用藥處方建議涉及診斷用藥的醫療決策，屬醫師（精神科醫師）依法的職權，非臨床心理師的業務範圍，故 D 為最不適當、為應選項。

A：理解醫師做病人入出院決策所承擔的法律與社會責任，有助臨床心理師掌握轉介脈絡、拿捏衡鑑報告的用詞與呈現方式，是適當且必要的準備，故非答案。

B：留意醫師對療效評估的可能期待，能幫助臨床心理師更精準地回應轉介問題，同時避免報告內容與臨床期待落差過大造成溝通困難，是適當的考量，故非答案。

C：理解醫師與臨床心理師在病理概念上的可能差異（如生物醫學模式與心理衡鑑觀點的側重不同），有助於雙方溝通與報告解讀，是合作轉介關係中適當的準備，故非答案。

本題考點：轉介合作中的專業分際——留意藥物資訊以利判讀衡鑑結果是本業範圍內的準備，直接給予用藥處方建議則逾越臨床心理師的法定業務範圍，須留給醫師決定；同時須掌握醫師的法律責任與療效期待、病理概念差異，以利跨專業合作。

第 15 題

迄今已發展出不少估計病前智商（premorbid IQ）的方法，下列何者不包括在內？
  1. （A）採用魏氏智力測驗中較不易受腦傷影響的數項分測驗（如詞彙、常識）
  2. （B）採用標準化閱讀測驗
  3. （C）採用以多項記憶力測驗分數為基礎的迴歸方程式
  4. （D）採用魏氏智力測驗中最高分的二或三項測驗

答案：（C）

詳解與考點

正解：判準是估計病前智商（premorbid IQ）的方法是否具備「不易受當前腦部病變影響」的穩定性。魏氏智力測驗中詞彙、常識等分測驗，以及標準化閱讀測驗中的字詞辨識，其表現多在腦傷發生前即已固化、較不受近期腦傷影響，可用來反推病前智商；記憶力則不然——記憶功能本身經常直接受腦傷、失智等病理歷程影響而下降，以多項記憶力測驗分數為基礎的迴歸方程式並非估計病前智商的標準方法，故 C 為應選項。

A：採用魏氏智力測驗中較不易受腦傷影響的分測驗（如詞彙、常識），是常見的病前智商估計方法之一，這類語意性知識累積早、受近期腦傷影響小，故非答案。

B：採用標準化閱讀測驗（如字詞唸讀正確率）估計病前智商，是另一常見方法，其原理同樣是閱讀字詞的能力多在成年前即已建立、受腦傷影響較小，故非答案。

D：採用魏氏智力測驗中最高分的二或三項測驗，以受試者現有表現中的最佳水準推估其原有能力水準，是常見的估計取徑之一，故非答案。

本題考點：估計病前智商方法的共通判準——用來估計的指標必須是「不易因近期腦部病變而下降」的能力，詞彙、常識、字詞閱讀與最佳表現分測驗皆符合此判準；記憶力本身容易受腦傷直接影響，不適合作為病前智商的估計基礎。

第 16 題

魏氏智力測驗的量尺分數（Scale Score）9、7、4分別對應的百分等級（PR）為何？
  1. （A）36、16、2
  2. （B）37、16、2
  3. （C）37、16、1
  4. （D）36、16、1

答案：（B）

詳解與考點

正解：本題是計算題，判準是魏氏智力測驗量尺分數（Scale Score）平均數為 10、標準差為 3 的常態分配，須將各量尺分數轉換為 z 分數後查對應的百分等級（PR）。量尺分數 9 的 z=(9-10)／3＝－0.33，查常態分配表對應累積機率約 0.37，即 PR37；量尺分數 7 的 z=(7-10)／3＝－1.00，對應累積機率約 0.16，即 PR16；量尺分數 4 的 z=(4-10)／3＝－2.00，對應累積機率約 0.02，即 PR2。三者依序為 37、16、2，故正解為 B。

A：36、16、2——第一項把 z＝－0.33 對應的累積機率算成 0.36，與常態分配表查得的約 0.37 相差一個百分等級，屬查表或估算時的常見誤差，故非答案。

C：37、16、1——第三項把 z＝－2.00 對應的百分等級算成 1，但常態分配表查 z＝－2.00 的累積機率約為 0.0228，四捨五入應為 PR2 而非 PR1，故非答案。

D：36、16、1——同時包含 A 與 C 兩項誤差（第一項算成 36、第三項算成 1），兩處皆與精確查表值不符，故非答案。

本題考點：魏氏量尺分數與百分等級的換算——先以平均數 10、標準差 3 將量尺分數轉為 z 分數，再查常態分配表得對應累積機率即為百分等級；z＝－0.33 對應 PR37 而非 PR36，z＝－2.00 對應 PR2 而非 PR1，換算時須以精確查表值為準，不可用整數估算取代。

第 17 題

在臨床心理實務上，強調對某特定問題採用有實徵資料支持之特定介入方式，此概念稱為：
  1. （A）theory-based practice
  2. （B）evidence-based practice
  3. （C）medicine-based practice
  4. （D）culture-based practice

答案：（B）

詳解與考點

正解：本題問的是「針對特定問題採用有實徵資料支持之特定介入方式」這個概念的英文名稱，判準是該詞是否直接扣住「以研究證據為支撐」這個核心。這正是實證本位實務（evidence-based practice）的定義：強調介入方式的選用須有實徵資料（研究證據）支持，而非僅憑理論推導或臨床習慣，故 B 為應選項。

A：theory-based practice（理論本位實務）強調的是介入以某個理論架構為依據，理論本身不等於已有實徵資料驗證其成效，兩者並不能劃上等號，故非答案。

C：medicine-based practice 並非臨床心理領域用以描述此概念的通用術語，且題幹強調的是「實徵資料支持」而非醫學模式本身，故非答案。

D：culture-based practice（文化本位實務）強調介入須考量文化脈絡的合宜性，關注點在文化適配而非實徵支持證據，與題幹描述的核心不同，故非答案。

本題考點：實證本位實務（evidence-based practice）的定義判準——核心是「介入方式有實徵資料支持」，與理論本位（依理論架構）、文化本位（依文化脈絡）等其他取向的區分關鍵在於是否以研究證據作為選用介入的依據。

第 18 題

根據Wampold（2001）的分析，下列何者為有效心理治療的核心因素？
  1. （A）工作同盟
  2. （B）特定治療技術
  3. （C）治療前的心理衡鑑
  4. （D）診斷的正確性

答案：（A）

詳解與考點

正解：本題問的是 Wampold（2001）分析心理治療療效因素後，指出哪一項是有效心理治療的核心，判準是其研究結論所支持的脈絡模式（contextual model）主張。Wampold 的分析發現，各學派特定治療技術之間的療效差異有限，真正能穩定預測療效的是治療關係本身，也就是工作同盟（治療師與個案在治療目標、任務與情感連結上的合作品質），故 A 為應選項。

B：特定治療技術——Wampold 的研究結論恰恰是質疑特定技術對療效的決定性，主張各學派特定技術之間的療效差異遠小於共同因素（如工作同盟）所能解釋的部分，故非答案。

C：治療前的心理衡鑑雖有助於了解個案問題與擬定治療計畫，但 Wampold 的分析並未將其列為療效的核心因素，故非答案。

D：診斷的正確性有助於選擇合適的治療方向，但 Wampold 的脈絡模式強調的核心是治療關係品質，而非診斷是否精準，故非答案。

本題考點：Wampold（2001）脈絡模式（contextual model）對療效因素的主張——工作同盟等共同因素才是有效心理治療的核心，特定治療技術、診斷正確性、治療前衡鑑本身並非其分析所指出的決定性因素。

第 19 題

根據Corey（2017），下列何項治療師人格特質是有利於治療關係與效果？
  1. （A）能追求完美
  2. （B）模糊忍受度要低
  3. （C）能選擇與經營自己的生活
  4. （D）堅信自己一定可以幫助所有個案

答案：（C）

詳解與考點

正解：本題問的是 Corey（2017）所述、有利於治療關係與效果的治療師人格特質，判準是該特質是否反映治療師本身的心理健康與現實感。能選擇並經營自己的生活，代表治療師具備自我覺察、能為自己的人生負責，這種現實感與心理健康程度會投射到治療關係中，是 Corey 所列有利特質之一，故 C 為應選項。

A：能追求完美——Corey 認為對完美的過度追求反而不利，好的治療師應能接納自己與個案的不完美，而非以完美主義要求自己或個案，故非答案。

B：模糊忍受度要低——與有利特質相反。治療歷程充滿不確定與模糊性，治療師須具備較高的模糊忍受度才能陪伴個案面對未明朗的議題，模糊忍受度低反而是不利特質，故非答案。

D：堅信自己一定可以幫助所有個案——這類全能式信念忽略了治療效果受個案、議題與情境等多重因素影響的現實限制，容易在遇到挫折時產生耗竭，並非 Corey 所指的有利特質，故非答案。

本題考點：Corey（2017）所列有利治療關係的治療師人格特質——能選擇與經營自己的生活、具現實感與自我覺察，並能忍受模糊、接納不完美；追求完美、模糊忍受度低、全能式信念皆屬不利特質。

第 20 題

關於阿德勒治療理論，下列敘述何者錯誤？
  1. （A）消除個體的自卑感是治療的主要任務
  2. （B）重視個體的整合性與不可分割性
  3. （C）認為個體會主動組織自己認定的事實，並依此賦予意義
  4. （D）認為社會興趣是天生的

答案：（A）

詳解與考點

正解：本題問的是阿德勒治療理論中，自卑感在治療歷程裡扮演的角色，判準是治療目標究竟是「消除」自卑感、還是「善用」自卑感作為成長動力。阿德勒學派認為自卑感是人與生俱來、驅動個體追求卓越與克服困難的動力來源，治療任務在於協助個案以健康、社會建設性的方式回應自卑感、發展社會興趣，而非將自卑感消除，故 A 敘述有誤，為應選項。

B：阿德勒治療重視個體的整合性與不可分割性，主張人的思想、情感、行為須放在整體脈絡中理解，不能拆解成獨立部分分析，敘述正確，故非答案。

C：阿德勒認為個體會主動組織自己認定的事實（生活型態、私人邏輯），並依此為經驗賦予意義，這是其現象學取向的核心主張，敘述正確，故非答案。

D：阿德勒理論認為社會興趣（social interest）是人與生俱來的潛能，需要透過後天環境與教養加以培養發展，敘述正確，故非答案。

本題考點：阿德勒治療對自卑感的定位——自卑感是追求卓越的天生動力來源，治療任務是引導其轉化為社會興趣與建設性行動，而非消除；同時須掌握整體不可分割性與個體主動賦予意義這兩項阿德勒理論的核心主張。

第 21 題

讓個案暴露於現實生活中的害怕情境是屬於下列何種暴露法？
  1. （A）in vivo exposure
  2. （B）imaginal exposure
  3. （C）interoceptive exposure
  4. （D）in vitro exposure

答案：（A）

詳解與考點

正解：判準是暴露情境的來源是「現實生活中的實際情境」還是「想像中建構的情境」。讓個案親身處在現實生活中真正會引發害怕的情境（如懼高症個案實際站上高處），屬實境暴露（in vivo exposure），這是暴露治療中最直接對應「現實生活」這個關鍵條件的類型，故 A 為應選項。

B：imaginal exposure（想像暴露）是讓個案在想像中生動地建構並面對害怕情境，而非置身於現實環境中，與題幹「現實生活中」的條件不符，故非答案。

C：interoceptive exposure（內感受暴露）是刻意誘發與焦慮相關的身體內在感覺（如心跳加速、呼吸急促），常用於恐慌症的治療，關注的是身體感覺而非外在的現實情境，故非答案。

D：in vitro exposure 並非暴露治療的標準分類用語（in vitro 原意為「在玻璃器皿中／體外」，屬實驗科學用語），與暴露治療的分類無關，故非答案。

本題考點：暴露治療類型的辨識——in vivo exposure 對應現實生活中的真實情境，imaginal exposure 對應想像中的情境，interoceptive exposure 對應身體內在感覺，三者依暴露對象的性質區分，in vitro 則非暴露治療用語。

第 22 題

依據Lazarus的多元模式治療（multimodal therapy），若要瞭解個案BASIC I.D.中有關「I（Image）」的訊息，可能會如何詢問個案？
  1. （A）你對生活中的重要他人有什麼期待？
  2. （B）你最重視的信念與價值是什麼？
  3. （C）你會如何看待你自己？
  4. （D）什麼樣的情緒目前最令你困擾？

答案：（C）

詳解與考點

正解：判準是 Lazarus 多元模式治療（multimodal therapy）BASIC I.D. 架構中，「I」所對應的究竟是 Imagery（心像／自我形象）還是 Interpersonal relationships（人際關係）——BASIC I.D. 中「I」出現兩次，分別代表這兩個不同的向度。詢問個案「你會如何看待你自己」，問的是個案對自我的心像與自我概念，對應 Image（Imagery），故 C 為應選項。

第 23 題

尼采說「人只要參透為何而活，即能承受任何煎熬」，這句話最適合用來代表那一種心理治療取向？
  1. （A）Existential Therapy
  2. （B）Person-centered Therapy
  3. （C）Acceptance and Commitment Therapy
  4. （D）Psychodynamic Therapy

答案：（A）

詳解與考點

正解：本題問的是尼采「人只要參透為何而活，即能承受任何煎熬」這句話最貼近哪一種心理治療取向的精神，判準是這句話所強調的核心——生命意義的追尋是承受苦難的力量來源。這正是存在主義治療（Existential Therapy）的核心關切，Frankl 的意義治療（logotherapy）便曾引用此語闡述其理論，強調協助個案在苦難中尋得生命意義，故 A 為應選項。

B：Person-centered Therapy（個人中心治療）核心在治療師提供真誠、無條件正向關懷與同理心，促成個案自我實現，並非以「生命意義」作為承受苦難的核心命題，故非答案。

C：Acceptance and Commitment Therapy（接納與承諾治療，ACT）雖同樣重視個人價值（values）在行動中的引導作用，但其核心精神在於以正念與心理彈性接納不可控的內在經驗，與此句聚焦生命意義本身的存在主義精神仍有側重差異，是本題最強的誘答，分辨關鍵在於「意義的追問」屬存在主義治療的核心命題，ACT 的價值概念則服務於促成投入行動的心理彈性。

D：Psychodynamic Therapy（精神動力治療）核心在探索潛意識衝突與早年經驗對現在行為的影響，並非以生命意義的追尋作為承受煎熬的核心主張，故非答案。

本題考點：存在主義治療（Existential Therapy）的核心精神——生命意義的追尋是承受苦難的力量來源，此觀點亦見於 Frankl 的意義治療；分辨與 ACT 的差異在於，前者聚焦意義本身，後者聚焦接納經驗以投入依循價值的行動。

第 24 題

有關完形治療理論的原則，下列敘述何者錯誤？
  1. （A）強調整體觀，認為所有的本質應該被視為統整且一致的，而整體不等於部分的總和
  2. （B）強調有機體的自我調整，認為當原有的平衡被擾動時，會儘可能以自身能力與環境資源進行調整
  3. （C）基於場地理論（field theory），認為有機體的行為應由環境、脈絡整體來理解
  4. （D）強調具體觀，認為心理治療的操作應該聚焦在明確且可客觀測量的外顯行為

答案：（D）

詳解與考點

正解：判準是完形治療理論是否主張心理治療的操作應聚焦在「明確且可客觀測量的外顯行為」。完形治療強調此時此刻的整體經驗與覺察，重視個體主觀經驗與場地脈絡中的互動，並不主張將治療操作侷限於可客觀測量的外顯行為——這種「具體觀」聚焦外顯行為測量的立場，是行為治療取向的核心特徵，而非完形治療的原則，故 D 敘述有誤，為應選項。

A：完形治療強調整體觀，認為所有本質應被視為統整且一致的整體，而整體不等於部分的總和，這是完形心理學（Gestalt psychology）延伸到治療取向的核心主張，敘述正確，故非答案。

B：完形治療強調有機體的自我調整（organismic self-regulation），認為當原有平衡被擾動時，有機體會盡可能運用自身能力與環境資源重新調整以恢復平衡，敘述正確，故非答案。

C：完形治療基於場地理論（field theory），主張有機體的行為必須放在其所處的環境與脈絡整體中理解，不能脫離場地孤立看待個別行為，敘述正確，故非答案。

本題考點：完形治療理論的核心原則——整體觀（整體不等於部分總和）、有機體自我調整、場地理論三者皆為完形治療所主張；「聚焦可客觀測量的外顯行為」的具體觀則屬行為治療取向的立場，不應套用到完形治療上。

第 25 題

Natalie Rogers將Carl Rogers的創造力理論擴展至表達性藝術治療（Expressive Arts Therapy），用以促進個人成長。關於表達性藝術治療的概念原則，下列敘述何者錯誤？
  1. （A）表達性藝術引導個人進入潛意識，為個人帶來新的訊息與覺察
  2. （B）個人的想法與行為是能量來源，能夠透過表達性藝術被釋放與轉換
  3. （C）透過自我覺察、自我了解和頓悟，會達到個人成長和更高的意識狀態
  4. （D）每個人天生具有創造力，創造的歷程不僅有變化性，也有療癒性

答案：（B）

詳解與考點

正解：本題問的是 Natalie Rogers 將 Carl Rogers 的創造力理論擴展為表達性藝術治療（Expressive Arts Therapy）後，該取向據以促進個人成長的核心原則，判準是哪一敘述誤植了「能量來源」的主詞。該取向原則主張感受與情緒（feelings and emotions）是一種能量來源，可透過表達性藝術被釋放與轉化；B卻把能量來源的主詞換成「個人的想法與行為」，與原理論不符，故B為與學理不符的錯誤敘述，應選。

C：透過自我覺察、自我了解和頓悟達到個人成長和更高的意識狀態，呼應 Carl Rogers 個人中心取向對自我實現歷程的描述，也是 Natalie Rogers 延伸此取向至藝術媒材時保留的核心主張，故非答案。

D：每個人天生具有創造力、創造歷程兼具變化性與療癒性，是表達性藝術治療的基本信念——創造力被視為人與生俱來的資源，其歷程本身即具療癒作用，故非答案。

本題考點：表達性藝術治療（Expressive Arts Therapy）主張感受與情緒是一種能量來源，可透過表達性藝術被釋放與轉化；判準是辨認選項是否把能量來源的主詞誤植（例如換成想法與行為），凡符合潛意識覺察、自我頓悟、天生創造力與其療癒性者皆屬理論本身主張。

第 26 題

關於敘事治療的外化對話（externalizing conversations），下列敘述何者錯誤？
  1. （A）標認出問題對個案生活的影響
  2. （B）標認出個案生活對問題的影響
  3. （C）尋找生活未完全受問題影響的閃亮時刻（sparkling moments）
  4. （D）不宜用在已經診斷確立的個案

答案：（D）

詳解與考點

正解：判準是外化對話（externalizing conversations）在敘事治療中的適用範圍是否受診斷狀態限制。外化對話的核心是把問題與人分開，讓個案得以從問題認同中鬆綁，這個技術對已有正式診斷的個案同樣適用、甚至更有意義——診斷本身常成為個案自我認同的一部分，外化正可協助鬆動「我等於疾病」的僵固敘事。D 敘述稱其「不宜用在已經診斷確立的個案」，方向恰好講反，故為錯誤敘述，應選。

A：標認出問題對個案生活的影響，是外化對話的基本步驟之一，先釐清問題如何滲透、限制個案的生活面向，故非答案。

B：標認出個案生活對問題的影響，是外化對話由「被問題支配」轉向「個案對問題仍有影響力」的關鍵步驟，用以鬆動問題的全面性，故非答案。

C：尋找生活未完全受問題影響的閃亮時刻（sparkling moments），是外化對話用以建構替代故事的重要素材，故非答案。

本題考點：外化對話（externalizing conversations）把問題與人分開，透過標認問題對生活的影響、生活對問題的影響、尋找閃亮時刻三個步驟鬆動問題認同；此技術對已確立診斷的個案同樣適用，並非例外，判準是別把「診斷已確立」誤讀為外化對話的禁忌情境。

答案：（C）

詳解與考點

正解：本題問的是失智症心理介入近期療效證據何者站不住腳，判準是各介入手法在實證文獻中被證實改善的目標症狀是否對應題目宣稱的效果。放鬆訓練確有助於減輕失智者的焦慮或激躁等情緒相關症狀，這與「減輕妄想症狀」看似都屬情緒穩定的效果，容易被視為同一件事；但妄想屬精神病性症狀，其成因與強化機轉不同於一般焦慮，放鬆訓練對妄想症狀缺乏明確療效證據支持。C 敘述把放鬆對情緒的助益誇大延伸到精神病性症狀，故為錯誤敘述，應選。

A：運動似乎對改善認知功能有適度效果，符合近期文獻對規律運動可延緩或改善失智者認知功能的證據支持，故非答案。

B：認知處理速度訓練對年長者的認知有正向效果，符合訓練型介入改善處理速度相關認知表現的實證，故非答案。

D：行為取向治療有助於代償記憶功能，符合以行為策略（如提示、環境調整、例行化）補償記憶缺損的介入原則，故非答案。

本題考點：失智症心理介入的療效證據須依「介入手法—目標症狀」的對應關係判讀，不可把某介入對情緒（焦慮、激躁）的助益誇大延伸至精神病性症狀（妄想）；運動、處理速度訓練、行為取向代償記憶皆各有其實證支持的目標症狀對應。

第 30 題

關於社交技巧訓練（social skills training），下列敘述何者錯誤？
  1. （A）適用於有溝通與社交困難的兒童
  2. （B）教導正確語言和正確行動
  3. （C）不涉及信念改變和情緒問題的處理
  4. （D）認知落後者經過環境調整和搭配行為改變技術亦能適用

答案：（C）

詳解與考點

正解：判準是社交技巧訓練（social skills training）是否只做行為演練、完全不處理認知與情緒層面。社交技巧訓練除了教導正確的語言與行動之外，通常同時涉及信念改變（如解讀社交線索的認知調整）與情緒問題的處理（如社交焦慮的因應）。C 敘述稱其「不涉及信念改變和情緒問題的處理」，把此訓練窄化為純行為演練，忽略其認知與情緒成分，故為錯誤敘述，應選。

A：社交技巧訓練適用於有溝通與社交困難的兒童，符合此介入常用於自閉症類群或社交能力落後兒童的臨床實務，故非答案。

B：教導正確語言和正確行動，是社交技巧訓練最基本的操作內容，透過示範、演練、回饋教導適切的社交語言與行為，故非答案。

D：認知落後者經過環境調整和搭配行為改變技術亦能適用，符合社交技巧訓練可視個案認知程度調整教材與行為策略、擴大適用族群的原則，故非答案。

本題考點：社交技巧訓練（social skills training）不只是行為演練，同時涉及信念調整與情緒處理的成分；判準是別把此訓練窄化為純語言行動的機械式演練，忽略其對社交認知與情緒因應的處理面向。

第 31 題

有關憂鬱症的心理治療，下列敘述何者正確？
  1. （A）認知行為治療、人際心理治療、長期精神分析治療皆有大量臨床研究證據支持有效
  2. （B）行為活化可以改善憂鬱症患者的心情
  3. （C）認知行為治療與抗憂鬱藥物治療的療效相比，大量研究都一致支持前者優於後者
  4. （D）人際心理治療是長期心理治療，關注憂鬱症患者兒時與重要他人的依附關係

答案：（B）

詳解與考點

正解：本題問的是憂鬱症心理治療何者正確，判準是各治療取向的實證支持強度與作用機轉描述是否與文獻相符。行為活化（behavioral activation）透過安排並增加正向、具酬賞性的活動，改善憂鬱症患者的心情與功能，是具紮實實證支持的憂鬱治療成分，B 敘述符合此實證，故選 B。

A：認知行為治療（CBT）、人際心理治療皆有大量臨床研究證據支持，但長期精神分析治療並無同等規模的強證據支持，把三者並列為皆有「大量」證據支持並不成立，故非答案。

C：CBT 與抗憂鬱藥物治療的療效相比，看似 CBT 效果更顯著而容易被直接判定為「一致優於」藥物，但研究結果大致顯示兩者療效相當，並非「大量研究都一致支持前者優於後者」，故非答案。

D：人際心理治療是短期、聚焦當前人際問題（如角色轉換、人際衝突、悲傷）的治療取向，並非長期分析兒時與重要他人的依附關係，故非答案。

本題考點：憂鬱症心理治療的實證判準——行為活化（behavioral activation）以增加正向經驗改善心情且具實證支持；CBT 與抗憂鬱藥物療效大致相當而非前者一致優於後者；人際心理治療是短期、聚焦當前人際議題的取向，並非長期分析取向。

第 32 題

暴露不反應法（exposure and response prevention, ERP）能有效治療強迫症，下列敘述何者正確？
  1. （A）是行為取向治療，治療者應避免向個案說明ERP原理作法
  2. （B）暴露會先挑選誘發中等焦慮苦惱的情境或刺激開始練習
  3. （C）個案的動機會隨著暴露效果提升，治療者無須費心關注此部分
  4. （D）療效主要來自於個案學習到更有效因應強迫思考的行為策略

答案：（B）

詳解與考點

正解：判準是暴露不反應法（exposure and response prevention, ERP）的暴露階序應如何安排。ERP 依焦慮階層由中等程度的苦惱情境開始練習，讓個案在可承受的強度下累積成功經驗，再逐步往上推進到高強度情境，B 敘述符合此循序漸進的暴露原則，故選 B。

A：ERP 是行為取向治療，但治療者應向個案清楚說明其原理與作法（如消弱、習慣化的機轉），以提升個案對治療的理解與配合，「應避免說明」與此原則相反，故非答案。

C：個案的動機在暴露過程中可能起伏，治療者須持續關注並主動維繫個案的參與動機，並非療效提升後即「無須費心關注」，故非答案。

D：療效核心來自暴露於誘發焦慮的刺激後、不執行強迫儀式所帶來的習慣化與消弱，看似「學會新的因應策略」也是療效的一部分而容易被視為主因，但差別在於因應策略只是伴隨結果，真正的機轉是習慣化與消弱本身，故非答案。

本題考點：暴露不反應法（ERP）的操作判準——暴露依焦慮階層由中等苦惱情境循序推進；治療者須說明原理並持續維繫個案動機；療效機轉是暴露後不執行儀式所致的習慣化與消弱，而非單純學會新因應策略。

第 33 題

個案同意參與為期兩天的研究，在第二天只剩10分鐘即可結束時，決定退出研究，研究者最適當的作法為何？
  1. （A）要求個案繼續將研究完成
  2. （B）同意個案的要求，並將兩天的研究資料銷毀
  3. （C）尊重個案退出但無須銷毀研究資料
  4. （D）僅須銷毀第二天的研究資料

答案：（B）

詳解與考點

正解：本題問的是研究參與者中途退出時，研究者最適當的處理方式，判準是受試者的自主退出權是否涵蓋對已蒐集資料的處置。個案在研究即將完成前決定退出，屬於受試者隨時可行使的自願退出權，撤回同意即涵蓋對已蒐集資料的處置，研究者應依受試者退出時的意願，將兩天份已蒐集的資料一併銷毀，故選 B。

A：要求個案繼續將研究完成，違反受試者可隨時自願退出的研究倫理原則，即使只剩極短時間也不能強留，故非答案。

C：尊重個案退出但無須銷毀研究資料，看似已經做到「尊重退出」，但差別在於還須處理個案對已蒐集資料的處置意願——若個案明確要求銷毀，研究者仍應處理其資料而非逕自保留，故非答案。

D：僅須銷毀第二天的研究資料，把退出權侷限在當次資料，但個案退出研究時若要求撤回同意，應涵蓋其已提供之全部資料而非僅限最後一天，故非答案。

本題考點：研究倫理中的自願退出權——受試者可隨時退出且無須完成研究；退出時若要求銷毀資料，研究者應尊重並處理其全部已蒐集資料，而非僅部分或逕自保留。

第 34 題

下列何項不屬於心理治療專業保密原則所界定的例外？
  1. （A）依法令規定，揭露個案未付之治療費用
  2. （B）個案牽涉到兒童虐待與疏忽
  3. （C）個案涉及公共危險
  4. （D）個案敘述介入他人婚姻

答案：（D）

詳解與考點

正解：判準是心理治療保密原則的例外情形須以法律明定的通報義務或重大危害為依據，而非道德上不認同的行為。個案敘述介入他人婚姻，屬於其個人的行為選擇，既非法定通報事項，也未對他人的生命安全構成立即危害，不構成突破保密的正當理由，D 不屬保密例外，故選 D。

A：依法令規定揭露個案未付之治療費用，是法律明文允許的保密例外情形之一，屬合法揭露事由，故非答案。

B：個案牽涉到兒童虐待與疏忽，屬強制通報事項，心理師依法負有通報義務，是保密原則的例外，故非答案。

C：個案涉及公共危險，涉及對他人生命安全的立即威脅，符合保密例外中「保護第三人」的原則，故非答案。

本題考點：心理治療保密原則的例外須以法律規定的通報義務或對他人生命安全的重大危害為依據——法定費用揭露、兒虐通報、公共危險皆屬合法例外；個人在道德上不被認同的行為（如介入他人婚姻）不構成保密例外的正當理由。

第 35 題

根據臨床心理師倫理規範，下列何項具有倫理爭議？
  1. （A）領養接受自己心理治療協助的家暴受虐兒
  2. （B）拒絕個案的期貨投資邀約
  3. （C）當個案的問題尚未獲解決，心理師因故無法繼續治療時，徵詢個案的意願並轉介
  4. （D）面對社會矚目案件的個案，能明確拒絕記者邀訪

答案：（A）

詳解與考點

正解：關鍵在題目問的是「具有倫理爭議」的選項，判準是該作法是否形成損害治療客觀性與個案福祉的雙重關係。領養正在接受自己心理治療協助的家暴受虐兒，使心理師同時身兼治療者與監護人兩種角色，形成嚴重的雙重關係，損害治療的客觀中立性與專業界線，也可能影響個案對治療關係的信任基礎，故選 A。

B：拒絕個案的期貨投資邀約，是心理師守住專業界線、避免財務利益與治療關係混淆的適當作法，並非倫理爭議，故非答案。

C：當個案的問題尚未獲解決、心理師因故無法繼續治療時，徵詢個案的意願並轉介，符合妥善結案與轉介的專業倫理程序，故非答案。

D：面對社會矚目案件的個案，能明確拒絕記者邀訪，是保護個案隱私與治療關係、避免資訊外洩的適當作法，故非答案。

本題考點：專業界線與雙重關係是臨床心理師倫理判準的核心——身兼治療者與其他重疊角色（如監護人）會損害治療客觀性與個案福祉，構成倫理爭議；拒絕財務邀約、妥善轉介、拒絕媒體邀訪皆屬守住界線的正當作法，不構成爭議。

第 36 題

臨床心理師設計了一個檢驗認知行為治療在高怨懟的憂鬱症病患之療效研究，下列敘述何者錯誤？
  1. （A）需對研究中的「怨懟」與「憂鬱症」有明確的操作型定義
  2. （B）需明確說明所採用的手冊化的治療方式
  3. （C）控制組應採用「低怨懟的憂鬱症病患」
  4. （D）需要使用具信、效度的結果評估工具

答案：（C）

詳解與考點

正解：直接切入本題的錯誤在於控制組的病患特徵設定破壞了與實驗組的可比較性。研究檢驗 CBT 在「高怨懟的憂鬱症病患」之療效，控制組應同樣採用「高怨懟的憂鬱症病患」接受對照處理（如等待名單或另一種治療），才能讓怨懟程度在兩組間維持一致、僅治療方式不同；若改採「低怨懟的憂鬱症病患」當控制組，等於同時改變了怨懟程度與治療方式兩個變項，混淆了自變項的因果推論。C 敘述違反這項設計原則，故為錯誤敘述，應選。

A：需對研究中的「怨懟」與「憂鬱症」有明確的操作型定義，是任何療效研究確保構念可測量、可重複驗證的基本要求，故非答案。

B：需明確說明所採用的手冊化的治療方式，是療效研究確保治療內容標準化、可重複實施的必要條件，故非答案。

D：需要使用具信、效度的結果評估工具，是療效研究確保結果測量準確可靠的基本要求，故非答案。

本題考點：療效研究設計的控制組判準——控制組須與實驗組在關鍵特徵（本題為怨懟程度）上維持同質，僅治療處理不同，否則會與自變項混淆而破壞因果推論；操作型定義、手冊化治療、具信效度的評估工具則是確保構念測量與治療內容標準化的基本要求。

第 37 題

關於療效研究中的隨機控制試驗特性，下列敘述何者正確？
  1. （A）由參與者自主選擇實驗組或控制組
  2. （B）比起內在效度，更著重外在效度
  3. （C）主要用於判定治療的效能（efficacy）
  4. （D）有助於了解治療應用於真實世界的效果

答案：（C）

詳解與考點

正解：判準是隨機控制試驗（randomized controlled trial, RCT）在分派方式、效度取向與研究目的三個面向的標準特徵。RCT 採隨機分派並在嚴格控制的理想條件下比較治療效果，其設計目的主要是判定治療的效能（efficacy），故選 C。

A：RCT 由研究者依隨機分派程序將參與者分配至實驗組或控制組，並非由參與者自主選擇，自選組別會引入選擇偏誤，破壞隨機化的意義，故非答案。

B：RCT 透過隨機分派與嚴格控制的實驗條件，著重的是內在效度（internal validity）而非外在效度（external validity）——這一點容易與「RCT 控制嚴謹、結果應該更能推論到現實」的直覺混淆，但差別在於嚴謹控制换來的是內在效度而非外在效度，故非答案。

D：有助於了解治療應用於真實世界的效果，指的是效果（effectiveness）研究在較貼近真實臨床情境下驗證治療效用，這是效果研究而非 RCT 的主要目的，故非答案。

本題考點：隨機控制試驗（RCT）的三個標準特徵——隨機分派而非自選組別；著重內在效度而非外在效度；目的在判定效能（efficacy），與貼近真實世界情境的效果（effectiveness）研究相對應，兩者判準不可混淆。

第 38 題

某臨床心理師發表了一個10題的「慮病量表」，而該量表與貝克焦慮量表（BAI）之效標關連效度高達0.84。但細看後，發現該量表中有5題與BAI的題目內容非常相近，顯見BAI應不是此「慮病量表」的好效標，最主要的原因是：
  1. （A）效標可信度不足
  2. （B）效標所測之概念並不恰當
  3. （C）效標所測之內容易隨時間變動
  4. （D）效標受到測驗的污染

答案：（D）

詳解與考點

正解：本題問的是「慮病量表」與貝克焦慮量表（BAI）效標關連效度異常偏高的最主要原因，判準是相關偏高是否來自效標本身的問題還是測驗與效標間的人為重疊。「慮病量表」中有半數（5 題）題目與 BAI 的題目內容非常相近，等於效標的內容混入了測驗本身要測的東西，使兩者相關虛高，這是效標污染（criterion contamination）——效標受到測驗內容污染所致，故選 D。

A：效標可信度不足會使相關係數被低估而非虛高，方向與題目描述的「相關異常高」相反，故非答案。

B：效標所測之概念並不恰當，看似也能解釋「BAI 不是好效標」，但差別在於問題不在 BAI 概念本身是否恰當，而在題目重疊導致的人為相關，故非答案。

C：效標所測之內容易隨時間變動，談的是效標的穩定性問題，與本題「題目內容重疊」造成的相關虛高無關，故非答案。

本題考點：效標污染（criterion contamination）——當測驗與效標的題目內容重疊時，兩者相關會被人為墊高，須與效標可信度不足（造成低估）、效標概念不當、效標內容不穩定等其他效度威脅區分；判準是看相關異常偏高的成因是否來自內容重疊本身。

第 39 題

某療效研究的結果顯示其統計檢定力（power）為0.45，關於虛無假設（H0）與替代假設（H1），下列敘述何者正確？
  1. （A）當H0為真時，正確拒絕H1的機會為45%
  2. （B）當H0為真時，錯誤接受H1的機會為45%
  3. （C）當H1為真時，正確拒絕H0的機會為45%
  4. （D）當H1為真時，錯誤接受H0的機會為45%

答案：（C）

詳解與考點

正解：關鍵在檢定力（power）的正確定義是「當 H1 為真時，正確拒絕 H0 的機率」，即 1 減型二錯誤率（1−β）。本題檢定力為 0.45，代入定義即為「當 H1 為真時，正確拒絕 H0 的機會為 45%」，C 敘述完全符合此定義，故選 C。

A：當 H0 為真時，正確拒絕 H1 的說法本身概念錯置——虛無假設檢定的架構是「拒絕或不拒絕 H0」，不存在「拒絕 H1」這個動作，且 H0 為真時談的是型一錯誤（α）而非檢定力，故非答案。

B：當 H0 為真時，錯誤接受 H1 的機會，指的是誤把 H0 為真的情況判為 H1 成立，屬型一錯誤（Type I error，α）的範疇，並非檢定力，故非答案。

D：當 H1 為真時，錯誤接受 H0 的機會，指的是 H1 為真時未能拒絕 H0，屬型二錯誤（Type II error，β），與檢定力互為 1 減 β 的關係，看似與檢定力同屬一組數字而容易混淆，但差別在於它是檢定力的互補事件，本身並非檢定力，故非答案。

本題考點：檢定力（power）＝ 1−β，定義為「當 H1 為真時，正確拒絕 H0 的機率」；判準是先確認情境是「H0 為真」還是「H1 為真」（決定是型一錯誤 α 還是型二錯誤 β／檢定力的範疇），再確認動作是「正確拒絕」還是「錯誤接受」，四個象限不可混淆。

第 40 題

下列何項測驗表現與執行功能的關聯性最低？
  1. （A）手指靈巧度測驗（Finger Dexterity Test）
  2. （B）語文流暢度測驗（Verbal Fluency Test）
  3. （C）Go-No Go測驗
  4. （D）路徑描繪測驗（Trail Making Test）

答案：（A）

詳解與考點

正解：關鍵在「與執行功能的關聯性最低」這個判準，須辨識各測驗主要評估的認知向度是否落在執行功能（executive function）的抑制、轉換、監控與提取等成分。手指靈巧度測驗（Finger Dexterity Test）主要測量精細動作協調與手部靈巧速度，屬於動作功能而非認知執行控制，與執行功能的關聯性最低，故選 A。

B：語文流暢度測驗（Verbal Fluency Test）要求個案在限定時間內依規則提取詞彙，涉及策略性搜尋、抑制不符規則的反應與自我監控，是評估執行功能常用的測驗，故非答案。

C：Go-No Go 測驗直接測量反應抑制能力，是執行功能中「抑制控制」成分的典型測量工具，故非答案。

D：路徑描繪測驗（Trail Making Test）尤其是 B 部分，要求在數字與字母間交替連線，測量認知彈性與轉換能力，是執行功能的核心測量工具，故非答案。

本題考點：執行功能測驗判準——語文流暢度測抑制與提取策略、Go-No Go 測反應抑制、路徑描繪測驗測認知轉換，皆屬執行功能核心成分；手指靈巧度測驗測的是精細動作協調，屬動作功能而非認知執行控制，關聯性最低。
