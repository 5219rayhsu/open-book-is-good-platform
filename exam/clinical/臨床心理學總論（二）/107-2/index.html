第 1 題

當轉介目的與教育安置計畫有關時，臨床心理師可能會到教室進行觀察，下列何者不是此種作法 的主要目的？
  1. （A）觀察兒童在自然情境下的行為
  2. （B）觀察教師與兒童的實際互動情形
  3. （C）蒐集老師之不當行為的證據
  4. （D）了解學校系統的運作與功能

答案：（C）

詳解與考點

正解：題眼在「教育安置計畫」與「教室觀察」的「主要目的」——判準是蒐集兒童在自然情境中的功能資料，並理解人際與系統因素以協助安置決策，不是預設立場地蒐證指控教師。蒐集老師不當行為的證據超出此衡鑑作法的主要目的，故 C 為應選項。

A：教室觀察可直接看到兒童在同儕、課程與規範中的自然行為表現，故非答案。

B：師生實際互動會影響兒童的行為與學習，屬安置評估的重要脈絡資料，故非答案。

D：了解學校系統如何支持或限制兒童功能，有助於提出可執行的教育建議，故非答案。

本題考點：自然情境觀察（naturalistic observation）——補足會談與測驗無法呈現的功能資料；教育安置衡鑑（educational placement assessment）——聚焦兒童、互動與系統的適配，而非單方歸責。

第 2 題

下列何者有助於臨床心理師增加臨床判斷正確性的方法？
  1. （A）考慮基準率（base rate）
  2. （B）重視初始的印象
  3. （C）對自己的直覺保持信心
  4. （D）忽略不支持的證據

答案：（A）

詳解與考點

正解：題眼在「增加臨床判斷正確性」——判準是判斷時是否納入與診斷或事件本身相關的先驗機率。基準率（base rate）提供某問題在特定族群或情境中的原有發生頻率；把它和個案的特徵、測驗結果一併整合，能降低只憑單一醒目線索作結論的偏誤，故選 A。

B：初始印象容易受到月暈效應與確認偏誤影響，後續資料反而可能被拿來維護第一印象，不能提高判斷正確性。

C：直覺可作為形成假設的起點，但臨床判斷仍須以系統資料檢驗；對直覺保持信心本身不是校正偏誤的方法。

D：忽略不支持的證據會造成確認偏誤，降低而非增加判斷的正確性。

本題考點：基準率（base rate）——先驗頻率是臨床推論的必要資訊；確認偏誤（confirmation bias）——應主動檢視反證，而非只蒐集支持初步假設的資料；臨床判斷（clinical judgment）——須整合多元證據。

第 3 題

有關臨床神經心理衡鑑的目的，可包含下列那些項目？①判斷病人的問題是「功能性」還是「器 質性」 ②評估神經心理缺損的性質與程度 ③評估與神經心理缺損相關的情緒問題 ④評估相 關社會資源補助的可得性
  1. （A）僅①③④
  2. （B）僅①②④
  3. （C）僅①②③
  4. （D）①②③④

答案：（D）

詳解與考點

正解：題眼在「臨床神經心理衡鑑的目的」——判準是該項工作是否服務於腦與行為關係的釐清，以及後續處遇規劃。①功能性與器質性問題的鑑別，是神經心理衡鑑最古典的轉介理由；②描述缺損的性質（哪些認知領域受損）與程度（相對於常模的落點），是衡鑑報告的核心產出；③認知缺損常伴隨憂鬱、焦慮或情緒調節困難，且情緒狀態會回頭影響測驗表現，必須一併評估；④衡鑑結論要落實為處遇建議，包括復健安排、回歸職場或就學的可行性，以及身心障礙鑑定與相關福利、補助資源的申請依據，故社會資源可得性的評估屬其處遇規劃面向。四項皆成立，故選 D。

A：此組合漏列②。描述缺損的性質與程度正是神經心理測驗最直接的產出，不能排除。

B：此組合漏列③。情緒困擾與認知缺損互相影響，漏掉會使測驗結果被過度解讀為器質性損傷。

C：此組合漏列④。衡鑑要能連到復健與社會資源的規劃才算完成臨床任務，④不應被排除。

本題考點：臨床神經心理衡鑑（clinical neuropsychological assessment）——兼含鑑別診斷、缺損描述、情緒共病評估與處遇規劃四個層次；鑑別診斷（differential diagnosis）協助區分功能性與器質性因素；衡鑑的終點是可執行的處遇建議，而非僅止於測驗分數。

第 4 題

在魏氏記憶量表第四版中，下列那一項不屬於 70 歲以上老人的記憶指數？
  1. （A）聽覺記憶
  2. （B）視覺記憶
  3. （C）立即記憶
  4. （D）視覺工作記憶

答案：（D）

詳解與考點

正解：題眼在「魏氏記憶量表第四版」與「70 歲以上」——判準是 WMS-IV 對高齡受測者採用的記憶指數結構，而非把較年輕年齡組的指數直接套用。高齡組可報告聽覺記憶、視覺記憶與立即記憶等指數；視覺工作記憶不是 70 歲以上組的記憶指數，故選 D。本題涉及 WMS-IV 的年齡別版本結構，應依該版手冊判讀。

A：聽覺記憶整合語文材料的立即與延宕記憶表現，屬高齡組可使用的指數。

B：視覺記憶反映非語文視覺材料的記憶表現，亦屬高齡組可使用的指數。

C：立即記憶呈現受測者剛接收訊息後的記憶能力，屬高齡組的記憶指數。

本題考點：魏氏記憶量表第四版（Wechsler Memory Scale–Fourth Edition, WMS-IV）——指數結構須依年齡組判讀；版本敏感性（version sensitivity）——不可把不同年齡組或版本的指數名稱互換。

第 5 題

在羅夏克墨漬測驗 Exner's Comprehensive System 中 ， 憂鬱症患者較不可能出現下列那一項反應？
  1. （A）總反應數少
  2. （B）Lambda 高
  3. （C）C’反應多
  4. （D）人類運動（M）多

答案：（D）

詳解與考點

正解：題眼在「憂鬱症患者較不可能」與 Exner 綜合系統——判準是憂鬱相關的反應型態通常呈現情緒壓抑、有限的心理資源與低產出，而不是豐富的人類運動想像。人類運動（M）多較反映複雜的內在想像與認知活動，並非憂鬱症患者典型較常見的型態，故選 D。

A：總反應數少可反映產出受限；在憂鬱狀態的退縮、遲滯或投入降低下，較可能出現。

B：Lambda 高表示反應較偏向簡化、避免複雜刺激處理，和憂鬱個案可能採取的收縮性處理方式相符。

C：C′反應多與壓抑或內化的情緒經驗有關，可見於憂鬱相關型態。這是最強誘答，因為它不是直接描述憂鬱情緒；關鍵在於 C′所指向的是受抑制的情感表達，而非外顯鮮明的情緒。

本題考點：羅夏克墨漬測驗 Exner 綜合系統（Exner’s Comprehensive System）——解釋須看反應群集而非單一指標；人類運動（human movement, M）——涉及內在想像與認知複雜度；憂鬱相關型態（depression-related pattern）——常見情緒壓抑與反應產出受限。

第 6 題

有關班達視覺動作完形測驗的 Lacks 計分系統，下列何者錯誤？
  1. （A）此計分系統聚焦於特定錯誤的形式與數量
  2. （B）主要是做為人格投射測驗使用之計分系統
  3. （C）適用於 12 歲以上的受測者
  4. （D）原始發展的目的為篩選腦傷的計分方式

答案：（B）

詳解與考點

正解：題眼在「Lacks 計分系統」——判準是它把班達視覺動作完形測驗的圖形錯誤系統化，用於篩檢可能的腦功能損傷，而不是把圖形當作人格投射素材。把它說成主要用於人格投射測驗的計分系統，錯置了工具目的，故選 B。

A：Lacks 系統會辨識特定圖形錯誤的形式與數量，這正是其結構化計分的特徵。

C：該系統適用於較大年齡的受測者，12 歲以上的敘述符合其使用範圍。

D：其原始發展目的在協助篩選腦傷相關的視覺動作整合困難，敘述正確。

本題考點：班達視覺動作完形測驗（Bender Visual-Motor Gestalt Test）——測量視覺動作整合表現；Lacks 計分系統（Lacks scoring system）——以錯誤型態篩檢可能的腦功能損傷；工具目的（test purpose）——神經心理篩檢不可誤當人格投射。

第 7 題

個案在開學後成績開始退步，家長懷疑可能是因為寒假的車禍，而引發的腦傷所致。在評估的策 略，何者是比較不重要？
  1. （A）與個案及家長晤談瞭解個案在人際、學習、生活等功能是否出現障礙
  2. （B）以晤談或測驗瞭解個案是否因情緒困擾而影響學習動機
  3. （C）請個案評估對學校環境與各科老師的教學滿意程度
  4. （D）實施智力測驗，評估認知功能的損傷程度

答案：（C）

詳解與考點

正解：題眼在「車禍後」與「腦傷所致」——判準是評估策略是否有助於釐清認知功能改變、日常功能受損與可能的替代解釋。對學校環境及各科教師的滿意度，與判定車禍後腦傷或其造成的學業退步關聯最弱，故選 C。

A：晤談個案與家長可建立車禍前後在人際、學習與生活功能的變化，是判斷功能衰退的重要資料。

B：情緒困擾可能降低動機、專注與表現，是腦傷以外必須鑑別的原因，故應評估。

D：智力測驗可提供認知功能表現的資料；實務上仍應與病史、觀察及其他神經心理資料整合，不能單憑一項測驗判定腦傷。

本題考點：神經心理評估策略（neuropsychological assessment strategy）——比較事件前後的功能改變；鑑別診斷（differential diagnosis）——須排除情緒與動機等替代解釋；生態效度（ecological validity）——日常功能資料有助於理解測驗結果。

第 8 題

有關臨床心理師執行心理衡鑑的敘述，下列何者錯誤？
  1. （A）要覺察患者的生理、心理和社會因素之間的相互影響
  2. （B）完全依據臨床心理學的用字遣詞，在衡鑑報告一字不漏的陳述出來
  3. （C）進行兒童衡鑑時，需考量其所屬的學習環境性質或品質
  4. （D）有責任瞭解心理衡鑑報告的閱讀對象，以及資訊可能如何被運用

答案：（B）

詳解與考點

正解：題眼在「心理衡鑑」與「何者錯誤」——判準是報告是否依閱讀者、用途與專業責任調整溝通方式，同時保留必要的準確性。衡鑑報告不能不分對象地以臨床術語一字不漏陳述；應以閱讀者能理解且不致誤用的方式表達，故選 B。

A：生理、心理與社會因素會相互影響，採生理心理社會觀點是衡鑑的基本原則。

C：兒童的學習環境品質會影響其行為與表現，兒童衡鑑必須納入此脈絡。

D：了解閱讀對象與資訊用途有助於決定報告內容、語言與保密界線，屬臨床心理師的責任。

本題考點：心理衡鑑報告（psychological assessment report）——須兼顧準確、可理解與用途；生理心理社會模式（biopsychosocial model）——以多層次脈絡理解問題；受眾意識（audience awareness）——避免專業資訊被誤讀或誤用。

第 9 題

有關羅夏克墨漬測驗 Exner's Comprehensive System 的解釋，下列何者正確？
  1. （A）彩色決定因子反映個人的外在世界與內在幻想世界的連結關係
  2. （B）組織活動（Z）與訊息處理的努力程度有關
  3. （C）常見的反應部位（D）多，代表思考僵化的傾向高
  4. （D）成對及鏡像反應多代表自我反省程度高

答案：（B）

詳解與考點

正解：題眼在「組織活動（Z）」——判準是 Exner 綜合系統中該變項所代表的心理歷程。Z 與受測者為組織刺激、整合訊息所投入的努力程度有關，故選 B。

A：彩色決定因子主要涉及情緒調節與情感表達方式，不能概括為外在世界與內在幻想世界的連結。

C：常見反應部位（D）多表示使用常規且顯著的墨漬區域，不等同思考僵化；把「常見」直接推成「僵化」是過度推論。

D：成對及鏡像反應較涉及自我意象與人際知覺的某些面向，不能單憑數量多就判定自我反省程度高。這是最強誘答，因為它把相關術語說得正向而合理；錯在將單一反應類型作成確定的人格結論。

本題考點：組織活動（organizational activity, Z）——反映刺激整合的處理努力；羅夏克墨漬測驗 Exner 綜合系統（Exner’s Comprehensive System）——單一變項須置於整體資料中解釋；過度推論（overinterpretation）——不可把反應位置或內容直接等同人格特質。

第 10 題

下列何者是多數行為衡鑑策略的限制？
  1. （A）缺乏充分的心理計量特性
  2. （B）與治療技巧的關係較為薄弱
  3. （C）不適用於因環境因素造成困擾的個案
  4. （D）無法提供多樣化的策略和技巧

答案：（A）

詳解與考點

正解：題眼在「多數行為衡鑑策略的限制」——判準是方法是否具有充分且可重複檢驗的信度、效度與常模等心理計量支持。行為衡鑑雖能直接觀察目標行為及其環境脈絡，但許多策略的標準化心理計量資料相對不足，故選 A。

B：行為衡鑑通常能直接連結功能分析與介入設計，和治療技巧的關係並不薄弱。

C：行為衡鑑特別重視前因、行為與後果，正適合分析環境因素造成的困擾。

D：行為衡鑑可用訪談、直接觀察、自我監測與功能分析等多種策略，並非無法提供多樣技巧。

本題考點：行為衡鑑（behavioral assessment）——重視可觀察行為與情境脈絡；心理計量特性（psychometric properties）——信度與效度支持是工具品質的重要限制；功能分析（functional analysis）——可直接連結問題行為與介入。

第 11 題

有關羅夏克墨漬測驗 Exner's Comprehensive System 之施測程序，下列敘述何者正確？
  1. （A）反應階段的主要指導語：「告訴我任何你看到的東西」
  2. （B）總反應數低於 17 個時，立即重測且要求更多反應
  3. （C）首張卡片的反應超過 4 個時，作出第 5 個反應後拿走卡片
  4. （D）主試者與受試者的座位安排不宜面對面，可以是「並肩同側」（side by side）

答案：（D）

詳解與考點

正解：題眼在「Exner 綜合系統之施測程序」——判準是施測者須維持標準化、避免以座位安排增加暗示性，並讓受測者能自然觀看卡片。主試者與受試者不宜面對面，可採並肩同側（side by side）的安排，故選 D。

A：反應階段的指導語重點是請受測者說出「那可能是什麼」，而不是要求其報告任何看到的東西；後者會改變作答作業的性質。

B：Exner 綜合系統確實訂有低反應數的處理程序：總反應數少於 14 個時，該紀錄視為無效，須當場重新施測並要求受測者多給一些反應；B 錯在把門檻寫成 17，而不是錯在「重測」這件事本身。

C：首張卡片反應多時不應以固定張數強制取走卡片；此作法會人為限制反應產出。

本題考點：羅夏克墨漬測驗 Exner 綜合系統（Exner's Comprehensive System）——施測程序須標準化；有效紀錄的最低總反應數為 14 個，未達者依標準程序當場重測；施測者中立性（examiner neutrality）——避免暗示或強迫受測者增加反應；座位安排（seating arrangement）——並肩同側可降低面對面的暗示性並利於共同觀看卡片。

第 12 題

下列那一項屬於撰寫「個案取向」（case-focused）心理衡鑑報告的原則？
  1. （A）報告要描述的是當事人而不只是測驗資料
  2. （B）報告要強調精確的診斷
  3. （C）報告儘量不要涉及未來的建議
  4. （D）報告儘量描述個案對自己症狀的主觀意見

答案：（A）

詳解與考點

正解：題眼在「個案取向（case-focused）」——判準是報告是否把測驗結果整合成對當事人的理解，而非只羅列分數或診斷標籤。個案取向報告描述的是當事人的功能、困擾、脈絡與資源，測驗資料只是支持這個理解的證據，故選 A。

B：診斷可在需要時說明，但個案取向不以追求精確診斷作為唯一或首要目標。

C：衡鑑報告應在資料支持時提出可行建議；刻意不涉及未來建議會降低報告的實用性。

D：個案主觀經驗很重要，但「儘量描述」不等於個案取向；仍須與行為觀察、測驗及他人資料整合。這是最強誘答，因為它重視個案聲音；錯在把單一主觀來源誤當成完整的個案理解。

本題考點：個案取向報告（case-focused report）——以整體個案而非分數為敘事核心；資料整合（data integration）——結合測驗、晤談、觀察與脈絡資料；建議（recommendations）——應回應轉介問題並具可行性。

第 14 題

  2. （B）測驗分數的意義不是由簡單的推論機制來決定，必須是由衡鑑者的綜合詮釋來完成
  3. （C）當不同測驗呈現出矛盾的結果，應交由精神科醫師進行判斷
  4. （D）當不同測驗呈現一致的結果，測驗分數即具有效度來證明個案的問題所在

答案：（B）

詳解與考點

正解：題眼在「使用心理測驗結果的適當原則」——判準是分數意義能否由多重資料與轉介問題整合，而非由單一常模、單一專業或測驗間表面一致性直接決定。測驗分數需要衡鑑者結合施測情境、行為觀察、病史及其他資料作綜合詮釋，故選 B。

A：常模與切截點是重要參考，但不能禁止專業詮釋；同一分數的意義仍受個案背景與測量限制影響。

C：不同測驗矛盾時，臨床心理師應檢查各工具的構念、效度與施測情境，不能把判斷責任一概交給精神科醫師。

D：不同測驗結果一致可增加支持力，卻不能自行證明測驗對此個案有效，也不能證明問題的因果。這是最強誘答，因為一致性確實有參考價值；錯在把一致直接等同效度證明。

本題考點：資料整合（data integration）——以多元資料形成衡鑑結論；效度（validity）——不是由測驗結果彼此一致就自動成立；切截點（cutoff score）——只能作為判讀參考，不能取代臨床整合。

  2. （B）依據實務或研究的目的而有不同的版本
  3. （C）僅適用於罹患精神病（psychosis）患者

第 18 題

有關羅夏克墨漬測驗 Exner's Comprehensive System 中特殊計分的意涵，下列敘述何者正確？
  1. （A）WsumC 是偵測躁症發作時最有效的認知扭曲指標
  2. （B）3 個以上的破壞性內容（MOR），顯示受試者的憂鬱或自殺的傾向高
  3. （C）合作性運動（COP）反應少，且攻擊性運動（AG）反應多，顯示受試者有較多被動攻擊行為
  4. （D）3 個以上的個人經驗反應（PER）表示受試者以順從方式來掩飾自己的不安全感

答案：（B）

詳解與考點

正解：題眼在「特殊計分」與「破壞性內容（MOR）」——判準是 MOR 所標記的內容是否反映負向、受損或病態的自我／客體表徵。MOR 達題目所述門檻時，可提示憂鬱或自殺相關風險升高，故選 B。本題涉及 Exner 系統特殊計分的門檻與解釋，需依該系統規範及完整臨床資料判讀。

A：WsumC 是色彩反應的加權總和，較關聯情緒經驗與表達，不能說是偵測躁症發作最有效的認知扭曲指標。

C：COP 少與 AG 多較可提示人際互動中的合作與攻擊意象失衡，但不能直接等同「被動攻擊行為」；這是最強誘答，因為它正確指出合作與攻擊內容的方向，錯在把反應內容過度化約為特定行為風格。

D：PER 多涉及個人經驗被不恰當地當作驗證依據，較可能指向固著於自身觀點，並非以順從掩飾不安全感。

本題考點：病態內容（morbid content, MOR）——反映負向或受損的表徵內容；特殊計分（special scores）——須結合其他羅夏克變項與臨床風險評估；人際運動（interpersonal movement）——COP 與 AG 不可單獨推論固定人格行為。

第 19 題

小王在魏氏成人智力測驗第三版（WAIS-III）之語文智商（VIQ）為 126，操作智商（PIQ）為 114，若測量標準誤分別為 VIQ=2.5，PIQ=4.0，且以 α= .05 視為統計上顯著，下列敘述何者正確？ （合計標準誤＝ 2 2 2 1 ） ＋（標準誤 ） （標準誤 ）
  1. （A）小王之語文智商顯著高於操作智商
  2. （B）小王的操作智商之 95%信賴區間為 110-118 之間
  3. （C）小王的語文智商之 95%信賴區間為 97-155 之間
  4. （D）小王之語文智商屬於中等程度

答案：（A）

詳解與考點

正解：題眼在「VIQ=126、PIQ=114」與合計標準誤公式——判準是先計算兩分數差異的標準誤，再以 α=.05 的雙尾臨界值檢驗。差異為 126−114=12；合計標準誤為 √（2.5²＋4.0²）＝√22.25≈4.72；差異比為 12÷4.72≈2.54，超過 1.96，故語文智商顯著高於操作智商，選 A。本題的信賴區間與顯著性結論均依題幹給定的測量標準誤與 α 值計算。

B：PIQ 的 95%信賴區間應為 114±（1.96×4.0），即約 106.16 至 121.84；110 至 118 把誤差範圍算得過窄。

C：VIQ 的 95%信賴區間應為 126±（1.96×2.5），即約 121.10 至 130.90；97 至 155 並非由題幹測量標準誤推得。

D：VIQ=126 的等級描述不屬中等程度；而且本題主要問兩智商差異的統計檢驗。

本題考點：差異檢定（difference significance test）——以分數差除以合計標準誤；合計標準誤（standard error of difference）——√（SEM₁²＋SEM₂²）；95%信賴區間（95% confidence interval）——估計值±1.96×測量標準誤。

第 20 題

有關衡鑑工具的信度，下列敘述何者正確？
  1. （A）當練習效果高時，理論上再測信度會比內部一致性信度更適用
  2. （B）若評分者方式較具主觀性時，評分方式需有良好的評分者間信度
  3. （C）當題數少時，適用折半信度
  4. （D）若測驗受語言文化等因素影響，可事後利用統計方法來進行分數的校正

答案：（B）

詳解與考點

正解：題眼在「評分者方式較具主觀性」——判準是誤差來源來自不同評分者時，應檢驗哪一種一致性。主觀評分可能因評分者標準不同而改變結果，因此必須有良好的評分者間信度（inter-rater reliability），故選 B。

A：練習效果高會使前後兩次表現受先前施測影響，反而限制再測信度的解釋，不是使其更適用。

C：題數少時折半後的兩部分更不穩定，不能因此說特別適用；應考量測驗內容與適切的信度估計方式。

D：語言與文化因素可能造成建構上的偏誤，事後只以統計校正分數不能取代工具的文化適切性檢驗。

本題考點：評分者間信度（inter-rater reliability）——檢驗不同評分者的一致性；再測信度（test-retest reliability）——易受練習效果影響；文化適切性（cultural appropriateness）——不可僅靠事後分數校正解決。

  2. （B）瞭解個案的家庭星座（family constellation）
  3. （C）以個案的早年記憶（early recollections）來篩選個案
  4. （D）以直接面質（direct confrontation）來增強個案的意志

  1. （A）皆強調駁斥個案非理性信念
  2. （B）皆強調駁斥個案自動化思考
  3. （C）皆強調個案接納自己
  4. （D）皆強調個案無條件積極關懷

答案：（C）

  2. （B）團體成員常競爭領導員的關注，類似早期的手足競爭
  3. （C）反移情源自治療師內在未解決的衝突，無助於瞭解團體的動力運作
  4. （D）成員可能在團體互動中重現社交情境，如同日常生活的縮影

答案：（C）

詳解與考點

正解：題眼在「精神分析理論在團體治療上的應用」與「錯誤」——判準是反移情雖可能源自治療師未解決的衝突，仍可經覺察與督導成為理解關係與團體動力的資料。說它無助於理解團體動力，把反移情的可能資訊價值完全否定，故 C 為應選項。

A：團體互動可重現早期重要關係與衝突，故非答案。

B：成員競爭領導者注意力可呈現手足競爭與移情關係，符合精神分析觀點。

D：團體常成為日常人際模式的縮影，使成員能在互動中觀察並工作，故非答案。

本題考點：反移情（countertransference）需被覺察與處理；團體治療（group therapy）可重現早期關係經驗；團體動力（group dynamics）可透過移情與互動加以理解。

第 36 題

有關精神分析的實務描述，下列何者最為正確？
  1. （A）治療的效果完全取決於治療師的詮釋是否正確
  2. （B）治療師若作了錯誤的詮釋，則會導致治療關係的惡化
  3. （C）治療師的詮釋若帶有暗示，可能會阻礙治療的進展
  4. （D）治療師使用標準結構化的臨床推論，比較容易做出正確的詮釋

答案：（C）

詳解與考點

正解：題眼在「精神分析的實務描述」——判準是詮釋須配合個案的準備度與治療關係，不能把治療師的推論當作必然真相。帶有暗示性的詮釋可能壓縮個案自由聯想與自主理解，因而阻礙治療進展，故選 C。

A：治療效果受治療關係、個案參與、時機與多種臨床因素影響，不會完全取決於單一次詮釋。

B：錯誤詮釋可能造成誤解，但可透過討論與修復處理，不必然導致關係惡化。

D：精神分析重視個案獨特的無意識脈絡，不以標準結構化推論保證詮釋正確。

本題考點：精神分析詮釋（psychoanalytic interpretation）須避免暗示性（suggestion）；自由聯想（free association）仰賴個案自主探索；治療關係修復（therapeutic repair）可處理理解落差。

第 37 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「人道與尊嚴」，不包括下列那一項 臨床心理師的行為陳述？
  1. （A）尊重每一個人的自由意志與人性尊嚴
  2. （B）為身心脆弱而影響自主能力者採取保護措施
  3. （C）對文化、族群、與個人的差異有敏感度，以避免偏見
  4. （D）尊重臨床心理知識的權威，避免因人設事的主觀判斷

答案：（D）

詳解與考點

正解：題眼在倫理準則的「人道與尊嚴」與「不包括」——判準是此原則保障個案的尊嚴、自主、脆弱者保護與文化敏感度，而非要求服從專業知識的權威。D 把尊重人轉為尊重權威，且「避免因人設事」也可能忽略個別差異，故 D 為應選項。

A：尊重自由意志與人性尊嚴，直接符合人道與尊嚴的倫理要求，故非答案。

B：對自主能力受影響的脆弱者採取適當保護，兼顧尊嚴與免受傷害，故非答案。

C：文化、族群與個別差異的敏感度有助避免偏見與歧視，故非答案。

本題考點：人道與尊嚴（humanity and dignity）保障自主與尊重；脆弱個案保護（protection of vulnerable persons）須兼顧自主；文化敏感度（cultural sensitivity）避免偏見，不等同於服從權威。

第 38 題

有關保密的作法，下列敘述何者正確？
  1. （A）應該避免用手機跟個案討論敏感問題，因為這種方式有保密上的風險
  2. （B）心理學家在上課或演講時，用假名就可以隱藏當事人的身分
  3. （C）心理治療筆記是治療師個人的記錄，病人無權力要求接觸這份筆記
  4. （D）某位研究生因為罹患心理疾患，心理師至系務會議上說明其遭遇，以保護她免於被退學

答案：（A）

詳解與考點

正解：題眼在「保密的作法」——判準是敏感資訊的傳輸、教學與揭露都須採取足以避免身分辨識及未授權接觸的保護措施。手機通訊可能被他人看到、遺失或透過不安全管道傳輸，避免以此討論敏感問題是適切的風險控管，故選 A。

B：只用假名未必足以去識別化；病史、罕見經驗或情境細節仍可能使當事人被辨認。

C：治療筆記的保存與接觸權須依適用法規、機構政策及個案權益審酌，不能以「治療師個人記錄」一概否定病人的接觸權。

D：研究生罹患心理疾患本身不構成向系務會議揭露的正當理由；即使出於保護目的，也應先評估必要性、最小揭露與取得適當同意。這是最強誘答，因為它訴諸保護，錯在跳過保密限制與程序。

本題考點：保密（confidentiality）要求安全傳輸與最小必要揭露；去識別化（de-identification）不等於只更換姓名；知後同意（informed consent）是教學與跨單位資訊分享的重要前提。

第 39 題

如果要進行全國學童的心理狀態評估，下列何種情況不屬於倫理原則的考量？
  1. （A）能否根據學童所熟悉的語言來施測
  2. （B）是否建立不同族群學童的信度與效度
  3. （C）能否有適當能力的人來解釋量表結果
  4. （D）能否蒐集到過去的相關研究證據

答案：（D）

詳解與考點

正解：題眼在「全國學童」與「不屬於倫理原則的考量」——判準是大規模心理衡鑑的倫理重點在公平施測、測驗適切性與結果解釋能力。蒐集既有研究證據有助研究設計，但不是此處直接關於對受測學童權益與專業責任的倫理考量，故 D 為應選項。

A：用學童熟悉的語言施測，關係到理解、文化公平與結果是否被誤解，故屬倫理考量。

B：不同族群的信度與效度支持測驗結果的適切解釋，若欠缺此基礎可能造成不公平，故非答案。

C：由具適當能力者解釋量表結果，是心理衡鑑的專業勝任與避免傷害要求，故非答案。

本題考點：心理衡鑑（psychological assessment）須考量文化與語言適切性；測驗公平（test fairness）依賴不同群體的效度證據；專業勝任（professional competence）包括正確解釋結果。

第 40 題

在沒有其他替代人選的情況下，一位沒有臨終照顧經驗的臨床心理師被要求對一名癌末個案進行 心理諮詢，下列何種作為最合於倫理原則？
  1. （A）根據一般的心理病理理論，自行研判該個案的心理狀態即可
  2. （B）因為沒有適當的訓練與經驗，婉拒這項要求
  3. （C）接受這項要求，同時尋求管道獲得臨終諮詢的相關知識
  4. （D）接受這項要求，以增加自己的經驗來服務下一位求助者

答案：（C）

詳解與考點

正解：題眼在「沒有其他替代人選」與「沒有臨終照顧經驗」——判準是專業勝任原則：通常應在受過訓練的能力範圍內服務，但當服務不可或缺且無替代人選時，可接受服務並立即補足知能、尋求諮詢或督導。C 同時回應當下個案需要與能力界線，故選 C。

A：僅憑一般心理病理理論自行判斷，忽略癌末處境與臨終照顧的特殊需求，違反專業勝任。

B：婉拒通常可避免超出能力範圍，但題幹已設定沒有替代人選；直接拒絕會使個案失去必要服務。

D：為累積自己經驗而接受服務，把學習利益置於個案福祉之前；最強誘答在於接受本身可能合理，錯在沒有立即取得相關知能與支持。

本題考點：專業勝任（professional competence）要求能力與服務相符；無替代服務者（unavailable alternative providers）的例外情境可在補足知能下提供服務；督導與諮詢（supervision and consultation）用以降低超出專長的風險。
