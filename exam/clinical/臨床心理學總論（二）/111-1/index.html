第 1 題

關於心理衡鑑，下列敘述何者錯誤？
  1. （A）是一個概念化、問題解決的複雜歷程
  2. （B）旨在做出有用的決策，衡鑑者應全面性蒐集個案的生活主題
  3. （C）衡鑑者需要具備的知識包括確立蒐集的資料與使用的工具，以及整合不同資訊的能力
  4. （D）瞭解心理測驗的執行、計分和解釋是衡鑑者需具備的重要技能之一

答案：（B）

詳解與考點

考點為心理衡鑑的本質。衡鑑是聚焦問題、做出有用決策的歷程，應依轉介問題有目的地蒐集資料，而非漫無目的「全面性蒐集所有生活主題」，故 B 為錯誤（正解）。其餘三項描述衡鑑者所需知識與技能，皆正確。

第 2 題

有關心理測驗在心理衡鑑中的功能，下列敘述何者正確？
  1. （A）心理測驗是心理衡鑑中最可靠的資料蒐集方法
  2. （B）在心理衡鑑中可使用心理測驗來了解個體在某一特質或能力上的個別差異
  3. （C）在心理衡鑑中使用測驗組合（test battery）可以保證獲得對個人全面性的了解
  4. （D）使用越多不同心理測驗，即可以提升心理衡鑑的推論效度

答案：（B）

詳解與考點

考點為心理測驗在衡鑑中的功能。心理測驗可用於了解個體在某特質或能力上的個別差異，故 B 正確。易誤選 A 或 C，但測驗並非「最可靠」的單一方法（須多源整合），使用測驗組合或更多測驗也無法「保證」全面了解或提升推論效度。

第 3 題

羅夏克墨漬測驗Exner's Comprehensive System中，如果2Ab + (Art + Ay)高於5，其可能的解釋意義為何？
  1. （A）以理智化的方式處理情緒
  2. （B）與外在關係較為疏離
  3. （C）在行為上較為被動
  4. （D）思考容易過於簡化

答案：（A）

詳解與考點

考點為羅夏克 Exner 系統的智性化指標。2Ab+(Art+Ay) 即 Intellectualization Index，高於 5 表示傾向以理智化方式來處理與隔離情緒，故選 A。其餘選項對應其他變項（如人際、被動性、思考簡化），與此指標不符。

第 4 題

關於電腦輔助的衡鑑方法的標準和守則，下列何者錯誤？
  1. （A）只有能符合一般心理測驗使用規範的工作者，才可以使用以電腦為基礎的衡鑑
  2. （B）使用者必須知道電腦化分數的計算方式，並評估該電腦測驗是否適用於衡鑑目的
  3. （C）電腦化解釋具有客觀性，應儘可能取代衡鑑者的臨床判斷
  4. （D）軟體開發者應在手冊中提供足夠的資訊，以供使用者參考

答案：（C）

詳解與考點

考點為電腦輔助衡鑑的使用守則。電腦化解釋應作為輔助，不能取代衡鑑者的臨床判斷，故 C 為錯誤（正解）。其餘三項強調使用者須具備測驗使用資格、了解計分方式並參考手冊資訊，皆為正確守則。

第 5 題

Wright（2010）提出心理衡鑑八個階段的概念化說明。此八個階段包括：①澄清和評估轉介問題②執行會談③形成假設④選擇測驗⑤蒐集測驗證據⑥拒絕、修正或接受假設⑦發展個人動力模式⑧發展建議。根據Wright的主張，下列敘述何者錯誤？
  1. （A）不同的衡鑑階段應按照順序逐項進行，以減少衡鑑偏誤
  2. （B）測驗分數通常能作為拒絕或排除一個假設的憑據，但較難作為接受假設的證據
  3. （C）衡鑑者需整合所蒐集到的資料，作出有意義的解釋，清楚地傳達給個案或轉介來源
  4. （D）所提出的建議要清楚、具體、合理，具備改善個案生活的可能性

答案：（A）

詳解與考點

考點為 Wright 衡鑑八階段的概念化。各階段並非僵化逐項照順序進行，實務上常需來回修正與整合，故 A 為錯誤（正解）。其餘三項描述測驗較適合排除假設、需整合資料清楚傳達、建議須具體可行，皆正確。

第 6 題

根據Groth-Marnat & Wright（2016），採用開放式問句為起始的會談，最大的好處為何？
  1. （A）減少個案的防衛性
  2. （B）讓個案在結構性較低的情境下瞭解、組織及表達自己
  3. （C）將隱含的訊息變成公開的材料，讓個案說出來
  4. （D）可以獲得個案各個生活面向的細節

答案：（B）

詳解與考點

考點為開放式問句起始會談的主要好處。開放式問句讓個案在結構較低的情境下自行組織與表達，最大好處在此，故選 B。易誤選 A 或 D，但「獲得各面向細節」較屬封閉式問句的功能，減少防衛並非其最主要優勢。

第 7 題

臨床心理師使用State Trait Anxiety Inventory（STAI）評估個案後，獲得下述印象「個案目前的焦慮可能由外在威脅造成，亦不會過度在意個人自尊受到威脅，應該可以藉由降低對該威脅的喚起程度來獲得改善」，該個案在STAI的得分，最可能為下列何者？
  1. （A）高情境焦慮／低特質焦慮
  2. （B）低情境焦慮／高特質焦慮
  3. （C）高情境焦慮／高特質焦慮
  4. （D）低情境焦慮／低特質焦慮

答案：（A）

詳解與考點

考點為 STAI 情境焦慮與特質焦慮的區辨。印象指焦慮源於外在威脅、不過度涉及自尊，且降低當下喚起即可改善，反映「狀態性、暫時性」焦慮，故為高情境／低特質焦慮（A）。高特質焦慮者會跨情境持續焦慮並涉及自尊，與描述不符。

第 8 題

以魏氏智力測驗協助智能不足之診斷評估，下列敘述何者正確？
  1. （A）全量表智商落在70分以下，即可診斷為智能障礙
  2. （B）IQ分數落於50～69的屬器質性智能障礙，而IQ分數低於50的屬非器質性智能障礙
  3. （C）魏氏智力測驗分數是判斷智能障礙唯一的準則
  4. （D）常識、算術、詞彙通常是智能障礙者最感困難的分測驗

答案：（D）

詳解與考點

考點為魏氏智力測驗用於智能障礙評估。常識、算術、詞彙等依賴知識累積與語文能力的分測驗，通常是智能障礙者最感困難的，故 D 正確。易誤選 A，但智能障礙診斷除 IQ 約 70 以下，還須同時符合適應功能缺損，非僅憑分數。

第 9 題

有關病前智商的估計，下列敘述何者正確？
  1. （A）在病前智商估計的正確性上，以人口變項為基礎的迴歸公式顯著優於過去工作與學業表現
  2. （B）常識、類同、圖形設計為三個最不受神經損傷波及的分測驗，可用於估計病前智商
  3. （C）以人口變項與分測驗為基礎的迴歸公式，用於推估原智商極高或極低者時，易產生錯估的現象
  4. （D）可採用二或三個得分相對最低的分測驗估計病前智商

答案：（C）

詳解與考點

考點為病前智商估計。以人口變項與分測驗為基礎的迴歸公式，對原本智商極高或極低者易產生迴歸至平均的錯估，故 C 正確。易誤選 D，但病前智商應以「最不受損傷影響」的分測驗（如詞彙、常識）估計，而非取得分最低者。

第 10 題

關於心理衡鑑各項測驗結果的呈現方式，下列敘述何者正確？
  1. （A）只要呈現原始分數即可
  2. （B）可呈現百分位數或標準分數
  3. （C）智力測驗只需列出全量表智力分數，無需列出分量表分數
  4. （D）需依序列出所使用測驗工具的花費時間

答案：（B）

詳解與考點

考點為衡鑑結果的呈現方式。原始分數須轉換為可比較的常模參照分數，故可呈現百分位數或標準分數，B 正確。易誤選 A，但僅呈現原始分數無法解讀；智力衡鑑通常也需列出分量表分數以呈現能力剖面，不只全量表分數。

第 11 題

根據Beutler與其同事有關評估個案問題複雜度（problem complexity）的系列研究，下列何項被歸類為複雜性問題？
  1. （A）情境特定性的行為
  2. （B）長期習慣而衍生的行為
  3. （C）與過去人際互動關係遠勝於目前關係的行為
  4. （D）短暫性的行為

答案：（C）

詳解與考點

考點為 Beutler 對問題複雜度的分類。與過去人際關係的關聯遠勝於當前關係的行為，反映根深的、跨情境的模式，被歸為複雜性問題，故選 C。其餘選項（情境特定、短暫性行為）多屬單純問題，與複雜性定義不符。

第 12 題

在心理衡鑑資料分析整合過程中，若出現推論方向不一致的證據X與Y時，下列何種呈現方式最不適當？
  1. （A）解釋造成X與Y推論差異的可能原因
  2. （B）主張應比較重視X或Y，並指出其它測驗結果做為支持
  3. （C）解釋X與Y看似衝突，但有可能同時存在
  4. （D）呈現X與Y的測驗結果，不應推論其差異

答案：（D）

詳解與考點

考點為衡鑑中矛盾證據的整合方式。面對推論不一致的 X 與 Y，應加以解釋、權衡或說明可能並存，不應只並列而拒絕進一步推論，故 D 最不適當（正解）。整合矛盾資料正是衡鑑者的核心任務，迴避整合違反衡鑑目的。

第 13 題

關於當今心理學文獻推薦的衡鑑資料統整形式，下列何者較不適當？
  1. （A）問題解決（problem-solving）
  2. （B）逐測驗說明（test-by-test）
  3. （C）以個案為中心（case-focused）
  4. （D）領域驅動（domain-driven）

答案：（B）

詳解與考點

考點為當代推薦的衡鑑資料統整形式。逐測驗（test-by-test）說明只羅列各測驗結果、缺乏整合，較不被推薦，故 B 較不適當（正解）。問題解決、以個案為中心、領域驅動等取向皆強調跨測驗的整合，較符合當代文獻建議。

第 14 題

有關班達完形測驗在人格評估上的效度，下列敘述何者正確？
  1. （A）多數「單一徵象指標」可有效測量人格變項
  2. （B）精神分析理論的投射性解釋有充分效度支持
  3. （C）用於人格評估的可靠性顯著優於腦傷篩檢
  4. （D）加總一系列指標的整體評分，在人格評估上的效度較佳

答案：（D）

詳解與考點

考點為班達完形測驗在人格評估的效度。研究顯示加總一系列指標的整體評分，效度優於單一徵象指標，故 D 正確。易誤選 A，但「單一徵象指標」的效度普遍不足；該測驗主要長處在腦傷篩檢，人格投射解釋的效度支持有限。

第 15 題

關於弱勢族群在智力測驗表現，下列敘述何者正確？
  1. （A）與匱乏的環境因素影響早期腦部發展有關
  2. （B）相較於主流族群測得的智力建構不同
  3. （C）智力測驗得分無法預測學業能力表現
  4. （D）針對視聽障的弱勢族群不宜使用標準化智力測驗

答案：（A）

詳解與考點

考點為弱勢族群的智力測驗表現。弱勢族群得分偏低常與匱乏環境影響早期腦部發展有關，故 A 正確。易誤選 B，但弱勢族群測得的智力建構與主流族群基本相同（測的是同一建構），分數差異反映環境而非測到不同的東西。

第 16 題

下列何項不是司法體系常見的心理衡鑑轉介問題？
  1. （A）評估學業成就
  2. （B）評估精神喪失
  3. （C）評估暴力傾向
  4. （D）評估兒童監護權歸屬

答案：（A）

詳解與考點

考點為司法心理衡鑑的常見轉介問題。司法情境常見轉介為評估精神喪失（責任能力）、暴力傾向、兒童監護權等，而「評估學業成就」屬教育場域而非司法問題，故 A 不是（正解）。

第 17 題

以正念為基礎的認知治療（MBCT）整合許多認知治療和正念減壓程序的面向，這屬於心理治療整合取向中的何種形式？
  1. （A）技術折衷
  2. （B）理論整合
  3. （C）同化整合
  4. （D）共同因素取向

答案：（C）

詳解與考點

考點為心理治療整合的形式分類。MBCT 是以認知治療為主體、再吸納正念元素融入既有架構，屬「同化整合」，故選 C。易誤選 B 理論整合，但理論整合是將兩取向融合為新理論架構，MBCT 較偏向在原有 CT 中吸收新成分。

第 18 題

哲學家尼采說：「只有知道自己為何而活的人，才能承受所有如何生存的問題」，最貼近下列那位大師的心理治療概念？
  1. （A）Alfred Adler
  2. （B）Viktor Frankl
  3. （C）Albert Ellis
  4. （D）Murray Bowen

答案：（B）

詳解與考點

考點為各治療大師的核心理念。尼采「知道為何而活就能承受如何生存」呼應意義治療，Frankl 主張人追尋生命意義（will to meaning），故選 B。易誤選 A Adler，雖重視目的與社會興趣，但「為何而活的意義」是 Frankl 的招牌主張。

第 19 題

下列何項心理治療取向，相對重視治療關係多於技術，且認為是治療結果最關鍵的決定因素？
  1. （A）認知治療
  2. （B）行為治療
  3. （C）現實治療
  4. （D）完形治療

答案：（D）

詳解與考點

題目問哪一取向「重視治療關係多於技術，並視治療關係為療效最關鍵決定因素」。本題官方標準答案為 D 完形治療（Gestalt therapy）。完形治療屬經驗／人本取向，強調此時此地的真誠相遇（I-Thou）、治療師與案主的真實接觸關係，相對較不倚賴標準化技術，視關係性接觸為改變的核心。A 認知治療與 B 行為治療皆為高度技術導向。C 現實治療（Reality therapy）雖也重視投入的治療關係，但其核心在於選擇理論與負責任行為的引導；依官方判定，最符合「關係重於技術、關係為療效關鍵」者為完形治療，故選 D。（須注意：人本取向中以個人中心治療對『關係為療效決定因素』的主張最為鮮明，本題未列入該選項，作答以官方答案 D 為準。）

第 20 題

關於團體心理治療帶領者的工作，下列敘述何者錯誤？
  1. （A）每位成員的非語言反應和語言反應都需要被留意與觀察
  2. （B）帶領者可用自己的價值觀去定義團體規範與成員的行為
  3. （C）需要留意帶領者自己在團體進行時的移情反應
  4. （D）和個別心理治療一樣，團體心理治療的保密原則仍是重要而必須的

答案：（B）

詳解與考點

考點為團體治療帶領者的工作守則。帶領者不應以自己的價值觀去定義團體規範與成員行為，規範宜由團體共同形成，故 B 為錯誤（正解）。其餘三項（觀察語言／非語言、覺察反移情、保密）皆為帶領者應有的正確作為。

第 21 題

關於認知治療中常用的認知技術，下列敘述何者錯誤？
  1. （A）時間投射技術（time-projection technique）常用於幫助個案去災難化，將個案的時間觀聚焦在此時此刻，減緩個案對所擔憂之負向結果的逃避
  2. （B）重新歸因技術（reattribution technique）透過考慮事件的其他原因，減少個案在證據不足下將事件歸因至單一人或單一因素
  3. （C）重新界定技術（redefining technique）是將問題就個人行為層面重新定義的具體明確，用來鬆動個案認定問題超乎能力所及的信念
  4. （D）去中心化技術（decentering technique）幫助焦慮個案用觀察外界替代聚焦內心的不舒服，緩減自認為是他人關注焦點的擔憂

答案：（A）

詳解與考點

考點為認知治療的認知技術定義。時間投射技術是引導個案想像「未來」情境以去災難化，而非把時間觀聚焦於此時此刻，故 A 敘述有誤（正解）。重新歸因、重新界定、去中心化三項技術的描述皆與其定義相符。

第 22 題

「生氣管理訓練（anger management training）」是何種理論技術的一種應用？
  1. （A）行為治療取向之社交技巧訓練（social skills training）
  2. （B）以正念為基礎的認知治療（mindfulness-based cognitive therapy, MBCT）
  3. （C）接納與承諾療法（acceptance and commitment therapy, ACT）
  4. （D）現實治療（reality therapy）

答案：（A）

詳解與考點

考點為生氣管理訓練的理論歸屬。生氣管理訓練屬行為治療取向下的社交技巧訓練應用，教導以適當技巧因應憤怒情境，故選 A。其餘 MBCT、ACT、現實治療雖也可處理情緒，但生氣管理的典型定位是社交技巧訓練。

第 23 題

根據Carl R. Rogers，促進治療性成長（therapeutic growth）最基本的治療條件為何？
  1. （A）真誠一致
  2. （B）同理性的了解
  3. （C）無條件的正向尊重
  4. （D）主動的揭露

答案：（A）

詳解與考點

考點為 Rogers 個人中心治療的核心條件。Rogers 提出三大核心條件，其中以真誠一致（congruence）為最根本、最基礎，故選 A。易誤選 C 無條件正向尊重，三者雖皆必要，但題目問「最基本」，Rogers 視真誠一致為前提。

第 24 題

關於家庭系統觀點的衡鑑與治療，下列敘述何者錯誤？
  1. （A）特別強調個案的失功能行為和家庭中其他成員彼此間的連結
  2. （B）評估個案的症狀時，會考量個案與家庭中其他成員彼此的連結
  3. （C）衡鑑個案的失功能行為時，會較為強調父親與子女之間的伊底帕斯情結
  4. （D）治療的目的在於修正家庭成員之間的互動交流形式

答案：（C）

詳解與考點

考點為家庭系統觀點的衡鑑與治療。家庭系統重視成員間的互動連結與整體系統，並不強調個別的伊底帕斯情結（屬精神分析），故 C 為錯誤（正解）。其餘三項皆強調症狀與家庭連結、以修正互動形式為治療目標，符合系統觀。

第 25 題

根據Wedding and Corsini（2019），關於治療初期的冥想（meditation）練習，下列敘述何者正確？
  1. （A）個案應避免單獨練習，必須由專家在旁引導
  2. （B）個案需要天天練習，且必須持續二小時
  3. （C）個案能很容易控制自己的注意力
  4. （D）個案可以使用視覺化來幫助練習

答案：（D）

詳解與考點

考點為治療初期冥想練習的指引（Wedding & Corsini, 2019）。初學者注意力不易控制，可運用視覺化（意象）來輔助練習，故 D 正確。其餘選項（須專家全程在旁、每天必須兩小時、能輕易控制注意力）對初期練習的要求皆不符實際。

第 26 題

Meichenbaum認為個案的行為發生改變會經歷三個階段，其中第二階段為何？
  1. （A）學習改變自己的內在對話
  2. （B）學習如何觀察自己的行為
  3. （C）學習辨識自己的認知謬誤
  4. （D）學習更有效的因應技巧

答案：（A）

詳解與考點

考點為 Meichenbaum 自我教導訓練的三階段。第一階段是觀察自己的行為，第二階段是學習改變內在對話（自我陳述），第三階段是習得新的因應技巧，故第二階段選 A。易誤選 B，但觀察自己的行為屬第一階段而非第二。

第 27 題

下列那一項是法蘭克（Viktor Frankl）對於人的本質之描述？
  1. （A）朝向享樂（will to pleasure）
  2. （B）朝向權力（will to power）
  3. （C）朝向道德（will to morality）
  4. （D）朝向意義（will to meaning）

答案：（D）

詳解與考點

考點為 Frankl 對人性本質的核心描述。Frankl 意義治療主張人最根本的驅力是「朝向意義」（will to meaning），故選 D。朝向享樂對應 Freud、朝向權力對應 Adler，皆為 Frankl 用以對照、區隔自身理論的概念。

第 28 題

下列何項治療相對上較不強調與考量個案的社會文化脈絡？
  1. （A）阿德勒取向治療
  2. （B）個人中心治療
  3. （C）敘事治療
  4. （D）女性主義治療

答案：（B）

詳解與考點

考點為各取向對社會文化脈絡的重視程度。個人中心治療聚焦個體內在經驗與自我實現，相對較不強調社會文化脈絡，故選 B。阿德勒（社會興趣）、敘事（社會建構）、女性主義治療皆高度重視文化與社會脈絡，與之對比明顯。

第 29 題

正念與接納為基礎的治療中，下列何者已廣泛應用於促進健康生活型態的改變，且證實可促進生理與心理健康？
  1. （A）焦點解決短期治療（SFBT）
  2. （B）後現代敘事分析（PMNA）
  3. （C）辯證行為治療（DBT）
  4. （D）正念減壓（MBSR）

答案：（D）

詳解與考點

考點為正念與接納取向中促進健康生活型態的代表方法。正念減壓（MBSR）已廣泛應用並有實證支持其促進生理與心理健康，故選 D。易誤選 C DBT，但 DBT 主要針對情緒調節與邊緣型人格，並非以「健康生活型態改變」為其廣泛應用標的。

第 30 題

曉華三天前搭火車不幸出軌翻車，身體受傷住院治療。醫生照會臨床心理師，發現曉華這幾天常做惡夢、心神不寧、不太想談翻車相關的事情、也不想看翻車相關的新聞。臨床心理師的建議，下列何者最適當？
  1. （A）這是罹患創傷後壓力症，建議進行延長暴露治療能有效改善
  2. （B）這些是經歷創傷事件後的正常反應，一定會隨時間消失，建議無需進一步心理治療
  3. （C）建議這段時間都不要想翻車事件，減少創傷喚醒物誘發身心反應
  4. （D）建議這段時間可以找信任的親友陪伴，減少身心反應的惡化

答案：（D）

詳解與考點

考點為急性創傷後的早期處置。事件僅三天、症狀屬創傷後常見的急性反應，最適當建議是提供社會支持、由信任親友陪伴以降低惡化，故選 D。A 過早診斷 PTSD 並施以暴露；B 斷言一定會消失且過度保證；C 鼓勵壓抑迴避，皆不適當。

第 31 題

依據Beck的認知治療，憂鬱症是負向基模和認知偏誤造成，因此針對憂鬱症的治療目標主要為何？
  1. （A）把負向人際關係當作是心智事件
  2. （B）改變不適應的思考模式
  3. （C）避免回想不愉悅經驗
  4. （D）增加正念練習

答案：（B）

詳解與考點

考點為 Beck 認知治療對憂鬱症的治療目標。Beck 認為憂鬱源於負向基模與認知偏誤，故治療目標在於辨識並改變不適應的思考模式，故選 B。其餘選項（去中心化、迴避回想、正念）並非 Beck 認知治療針對憂鬱的核心目標。

第 32 題

依據客體關係理論學者Margaret Mahler，邊緣型人格障礙症源自下列那一階段的障礙？
  1. （A）共生（symbiosis）
  2. （B）客體恆常（object constancy）
  3. （C）正常嬰兒自閉（normal infantile autism）
  4. （D）分離－個體化（separation-individuation）

答案：（D）

詳解與考點

考點為 Mahler 客體關係理論與邊緣型人格的發展根源。邊緣型人格被認為源自「分離－個體化」階段（特別是復合次階段）的障礙，故選 D。易誤選 A 共生，但共生階段的固著更常與更嚴重的精神病性問題相關，而非典型邊緣型病理。

第 33 題

某臨床心理師打算將其工作單位歷年來所收到100份病人的心理衡鑑資料，匿名處理後並投稿國際研討會，下列敘述何者正確？
  1. （A）需經倫理委員會核准才能進行資料整理
  2. （B）因為是匿名資料，無需倫理委員會的核准
  3. （C）經單位主管核准後就能使用
  4. （D）逐一打電話徵求病患或家屬同意後，方可使用資料

答案：（A）

詳解與考點

考點為衡鑑資料用於研究發表的研究倫理。即使去識別化，將病人衡鑑資料用於研究投稿仍涉及人類受試者，須經倫理委員會（IRB）審查核准，故 A 正確。匿名、單位主管同意皆不足以取代 IRB 審查，逐一致電徵詢亦非必要程序。

第 34 題

有關臨床心理師在專業治療關係中的作為，下列敘述何者是較不具有倫理爭議的？
  1. （A）向個案借款
  2. （B）撰寫病歷時，刻意掩飾個案對心理治療的不滿
  3. （C）考慮中止心理治療時，事先瞭解個案的看法與需求
  4. （D）將個案的案例集結成冊並出版，但未隱去可辨識個案身分的細節

答案：（C）

詳解與考點

考點為治療關係中的專業倫理判斷。考慮中止治療前，事先了解個案的看法與需求是負責且符合倫理的作為，較不具爭議，故選 C。向個案借款（雙重關係）、掩飾病歷、未去識別化出版個案資料，皆有明顯倫理爭議。

第 35 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「能力」，不包括下列那一項臨床心理師行為之陳述？
  1. （A）致力提昇對他人的關切
  2. （B）致力提昇對社會利益的覺察
  3. （C）致力提昇對職務地位的追求
  4. （D）致力提昇對專業知識的掌握

答案：（C）

詳解與考點

考點為臺灣臨床心理師倫理準則「能力」原則的內涵。「能力」聚焦於提昇對他人關切、社會利益覺察與專業知識掌握，而「追求職務地位」並非能力原則所涵蓋，故 C 不包括（正解）。

第 36 題

某自陳式量表僅以大專學生作為受測對象，進行心理計量特性檢驗，檢驗合宜後廣泛運用於所有成年群體。最可能出現下列何種問題？
  1. （A）常模適切性
  2. （B）施測程序標準化
  3. （C）建構效度
  4. （D）再測信度

答案：（A）

詳解與考點

考點為常模適切性。量表僅以大專生建立心理計量特性，卻廣泛用於所有成年群體，受測對象與常模母群不符，最可能出現常模適切性問題，故選 A。施測標準化、建構效度、再測信度雖也重要，但此情境直接威脅的是常模代表性。

第 37 題

針對有「前－後測」，主要結果指標為憂鬱分數，但測量方式不同（例如採用BDI或HADS等）的心理治療療效研究進行後設分析時，最適用的統計量為何？
  1. （A）未標準化平均數差異（unstandardized mean difference）
  2. （B）效果量（effect size）
  3. （C）風險比（risk ratio）
  4. （D）標準化均方根（standardized root mean square）

答案：（B）

詳解與考點

考點為後設分析的統計量選擇。各研究採用不同量表（BDI、HADS）測量憂鬱，量尺不同，須以效果量（如標準化平均數差異）使結果可跨研究比較，故選 B。未標準化平均數差異無法跨不同量尺比較；風險比適用於二分結果，皆不合。

第 38 題

關於世代研究法，下列敘述何者錯誤？
  1. （A）年齡效果（Age effects）：在特定年齡會受到特定事件的影響
  2. （B）世代效果（cohort effects）：不同時代，特定的成長期造成的影響不同
  3. （C）測量時間效果（Time-of-measurement effects）：在特定時間點進行測量評估時，受到當時特定事件所影響
  4. （D）選擇性死亡（selective mortality）：研究參與者因意外事件而退出研究

答案：（D）

詳解與考點

考點為世代研究法的概念辨識。選擇性死亡指的是研究中特定類型參與者（常與所測特質相關）流失或死亡而造成偏誤，並非單純「因意外事件退出」，故 D 敘述不精確為錯誤（正解）。年齡、世代、測量時間效果三者描述皆正確。

第 39 題

有關相關係數及其統計顯著性，下列敘述何者錯誤？
  1. （A）相關係數通常以r表示，介於-1.00至1.00之間
  2. （B）相關係數的統計顯著性，不受樣本人數多寡影響
  3. （C）通常相關係數絕對值越大，愈可能達到統計顯著性
  4. （D）研究樣本愈大，達到統計顯著所需的相關係數愈小

答案：（B）

詳解與考點

考點為相關係數的統計顯著性。相關係數的顯著性深受樣本人數影響，樣本越大、達顯著所需的 r 越小，故 B「不受樣本人數影響」為錯誤（正解）。其餘三項（r 介於 ±1、絕對值越大越易顯著、樣本越大門檻越低）皆正確。

第 40 題

使用心理測驗評估心理治療效果，下列何者不是最重要的考量？
  1. （A）測驗的再測信度
  2. （B）測驗是否具有複本
  3. （C）測驗的常模適切性
  4. （D）前後測的施測者要同一人

答案：（D）

詳解與考點

考點為以心理測驗評估治療效果的考量。再測信度、複本可用性、常模適切性皆為重要的測量特性考量；「前後測施測者須同一人」並非最重要的考量，故 D 不是（正解）。標準化測驗的目的本就是降低對個別施測者的依賴。
