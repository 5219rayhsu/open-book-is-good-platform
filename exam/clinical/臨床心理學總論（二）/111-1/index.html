第 1 題

關於心理衡鑑，下列敘述何者錯誤？
  1. （A）是一個概念化、問題解決的複雜歷程
  2. （B）旨在做出有用的決策，衡鑑者應全面性蒐集個案的生活主題
  3. （C）衡鑑者需要具備的知識包括確立蒐集的資料與使用的工具，以及整合不同資訊的能力
  4. （D）瞭解心理測驗的執行、計分和解釋是衡鑑者需具備的重要技能之一

答案：（B）

詳解與考點

正解：判準是衡鑑蒐集資料應以「轉介問題」為導向——本題問的是心理衡鑑相關敘述中哪一項錯誤。衡鑑的目的是做出有用的決策，衡鑑者應針對待答問題有目的地蒐集相關資料，而非漫無目的地蒐集個案的所有生活主題，B 敘述誇大蒐集範圍且偏離問題導向，故為錯誤敘述、為應選項。

A：心理衡鑑是一個概念化、問題解決的複雜歷程，此為衡鑑本質的基本描述，敘述正確、非答案。 C：衡鑑者需具備確立資料蒐集範圍與工具、以及整合不同來源資訊的能力，此為衡鑑者核心專業能力的描述，敘述正確、非答案。 D：瞭解心理測驗的執行、計分與解釋，是衡鑑者必備的重要技能之一，敘述正確、非答案。

本題考點：心理衡鑑歷程的判準——衡鑑是聚焦轉介問題、做出有用決策的複雜歷程，資料蒐集須依問題取捨而非漫無目的地全面蒐集所有生活主題；衡鑑者需具備資料蒐集規劃、多源資訊整合與心理測驗操作解釋的能力。

第 2 題

有關心理測驗在心理衡鑑中的功能，下列敘述何者正確？
  1. （A）心理測驗是心理衡鑑中最可靠的資料蒐集方法
  2. （B）在心理衡鑑中可使用心理測驗來了解個體在某一特質或能力上的個別差異
  3. （C）在心理衡鑑中使用測驗組合（test battery）可以保證獲得對個人全面性的了解
  4. （D）使用越多不同心理測驗，即可以提升心理衡鑑的推論效度

答案：（B）

詳解與考點

正解：判準是測驗的核心用途在於揭示個體在特定特質或能力上的個別差異——本題問的是心理測驗在心理衡鑑中的功能。心理測驗可用以了解個體在某一特質或能力上相對於常模或他人的個別差異，此為測驗最基本且明確的功能，故選 B。

A：心理測驗並非心理衡鑑中最可靠的單一資料蒐集方法，衡鑑仍須整合晤談、觀察、病史等多方來源，不能僅憑測驗結果下判斷，敘述不正確、非答案。 C：使用測驗組合（test battery）雖能從不同面向蒐集資訊，但並不能保證獲得對個人全面性的了解，仍受限於所選測驗的範圍與個案配合度等因素，敘述不正確、非答案。這是本題最強誘答，因為測驗組合確實比單一測驗更周全；分辨關鍵在於更周全不等於保證全面，衡鑑結論仍需臨床整合判斷，不能單靠測驗組合本身保證完整性。 D：使用越多不同心理測驗並不必然提升衡鑑的推論效度，測驗數量增加還可能帶來個案疲勞、資料整合困難等問題，敘述不正確、非答案。

本題考點：心理測驗在衡鑑中的功能判準——測驗的核心功能是呈現個體在特定特質或能力上的個別差異，而非衡鑑中最可靠的唯一方法；測驗組合與測驗數量的增加，皆不保證衡鑑的全面性或推論效度提升，衡鑑結論仍需仰賴臨床整合判斷。

第 3 題

羅夏克墨漬測驗Exner's Comprehensive System中，如果2Ab + (Art + Ay)高於5，其可能的解釋意義為何？
  1. （A）以理智化的方式處理情緒
  2. （B）與外在關係較為疏離
  3. （C）在行為上較為被動
  4. （D）思考容易過於簡化

答案：（A）

詳解與考點

正解：判準是羅夏克墨漬測驗（Rorschach）Exner's Comprehensive System 中的智性化指標（Intellectualization Index），其公式即為 2Ab+(Art+Ay)；當此數值高於 5，表示個案傾向以理智化（intellectualization）的方式來隔離與處理情緒經驗，而非直接感受或表達情緒，故選 A。

B：外在關係較為疏離對應的是人際孤立相關的變項（如孤獨指數），與智性化指標的計分邏輯無關。

C：行為上較為被動對應的是被動性相關指標，衡量的是行動傾向而非情緒處理策略，與 Ab、Art、Ay 這組計分無關。

D：思考容易過於簡化通常與認知複雜度或形式品質相關的變項對應，不是智性化指標所捕捉的現象。

本題考點：Exner 系統各衍生指標須各自對應其計分公式所指涉的心理現象——2Ab+(Art+Ay) 專指以理智化隔離情緒，不可與人際疏離、被動性、思考簡化等其他變項的計分混淆；判讀衍生分數時先確認公式組成，再回推其代表的心理歷程。

第 4 題

關於電腦輔助的衡鑑方法的標準和守則，下列何者錯誤？
  1. （A）只有能符合一般心理測驗使用規範的工作者，才可以使用以電腦為基礎的衡鑑
  2. （B）使用者必須知道電腦化分數的計算方式，並評估該電腦測驗是否適用於衡鑑目的
  3. （C）電腦化解釋具有客觀性，應儘可能取代衡鑑者的臨床判斷
  4. （D）軟體開發者應在手冊中提供足夠的資訊，以供使用者參考

答案：（C）

詳解與考點

正解：本題問的是電腦輔助衡鑑（computer-based assessment）標準與守則中何者錯誤。電腦化解釋僅具備計分與初步詮釋上的客觀性，其本質仍是依統計常模產生的初步假設，不能取代衡鑑者對個案脈絡、其他測驗證據與臨床觀察的整合判斷，故 C 敘述有誤，為應選項。

A：只有符合一般心理測驗使用規範的工作者才可使用電腦化衡鑑，這是資格把關的基本守則，敘述正確。

B：使用者必須了解電腦化分數的計算方式，並自行評估該工具是否適用於當前的衡鑑目的，這是避免誤用電腦化測驗的必要條件，敘述正確。

D：軟體開發者有義務在手冊中提供足夠資訊（如常模來源、信效度資料、計分邏輯），供使用者判斷工具的適用性，敘述正確。

本題考點：電腦輔助衡鑑的定位判準——電腦化分數與解釋是輔助工具而非決策主體，最終判斷責任仍在衡鑑者；使用資格、計分理解、手冊資訊揭露三者共同構成負責任使用電腦化測驗的守則。

第 5 題

Wright（2010）提出心理衡鑑八個階段的概念化說明。此八個階段包括：①澄清和評估轉介問題②執行會談③形成假設④選擇測驗⑤蒐集測驗證據⑥拒絕、修正或接受假設⑦發展個人動力模式⑧發展建議。根據Wright的主張，下列敘述何者錯誤？
  1. （A）不同的衡鑑階段應按照順序逐項進行，以減少衡鑑偏誤
  2. （B）測驗分數通常能作為拒絕或排除一個假設的憑據，但較難作為接受假設的證據
  3. （C）衡鑑者需整合所蒐集到的資料，作出有意義的解釋，清楚地傳達給個案或轉介來源
  4. （D）所提出的建議要清楚、具體、合理，具備改善個案生活的可能性

答案：（A）

詳解與考點

正解：本題問的是 Wright（2010）提出之心理衡鑑八階段概念化中，何者敘述錯誤。這八個階段——澄清與評估轉介問題、執行會談、形成假設、選擇測驗、蒐集測驗證據、拒絕或修正或接受假設、發展個人動力模式、發展建議——在實務上並非僵化地依序逐項完成，衡鑑者常需依蒐集到的證據回頭修正前一階段的假設或會談方向，來回反覆才是此概念化模式的精神，故 A 敘述有誤，為應選項。

B：測驗分數較容易提供反證來排除某項假設，但要單獨作為「接受」某項假設的充分證據則較為困難，仍需搭配其他資料源交叉驗證，此敘述正確。

C：衡鑑者需整合蒐集到的多方資料，形成有意義的解釋，並清楚傳達給個案或轉介來源，這是衡鑑報告撰寫的基本要求，敘述正確。

D：所提出的建議須清楚、具體、合理，並具備實際改善個案生活的可能性，這是衡鑑建議品質的判準，敘述正確。

本題考點：Wright 八階段概念化的性質判準——各階段是可回溯修正的循環歷程而非固定線性順序；測驗證據的角色偏向排除假設而非單獨確立假設；衡鑑成果須經整合、清楚傳達，且建議須具體可行。

第 6 題

根據Groth-Marnat & Wright（2016），採用開放式問句為起始的會談，最大的好處為何？
  1. （A）減少個案的防衛性
  2. （B）讓個案在結構性較低的情境下瞭解、組織及表達自己
  3. （C）將隱含的訊息變成公開的材料，讓個案說出來
  4. （D）可以獲得個案各個生活面向的細節

答案：（B）

詳解與考點

正解：關鍵在 Groth-Marnat 與 Wright（2016）對開放式問句最大效益的界定。開放式問句不預設答案的方向或範圍，讓個案得以在結構性較低的情境下，依自己的邏輯去理解、組織並表達其經驗，這才是其最主要的好處，故選 B。

A：減少個案的防衛性是開放式問句可能帶來的附帶效果，但並非其最主要、最核心的功能——封閉式問句在特定情境下同樣能降低防衛，兩者差在問句是否預設答案的結構，不在防衛程度的高低。

C：讓隱含訊息變成公開材料，較貼近會談歷程中催化揭露的功能，並非開放式問句相對於其他問法的獨特優勢。

D：獲得個案各生活面向的細節，這是最強誘答——它看似也是會談蒐集資料的目標；分辨關鍵在於要有系統地取得各面向的具體細節，通常仍須搭配結構化或封閉式問句逐一確認，開放式問句的長處在於「讓個案自行組織與表達」，不在於細節蒐集的完整度。

本題考點：開放式問句的核心效益判準——不預設答案結構，讓個案主導表達與組織自身經驗；防衛降低、揭露公開化、細節蒐集分別對應其他問法或會談技巧的效益，不可混為開放式問句的主要優勢。

第 7 題

臨床心理師使用State Trait Anxiety Inventory（STAI）評估個案後，獲得下述印象「個案目前的焦慮可能由外在威脅造成，亦不會過度在意個人自尊受到威脅，應該可以藉由降低對該威脅的喚起程度來獲得改善」，該個案在STAI的得分，最可能為下列何者？
  1. （A）高情境焦慮／低特質焦慮
  2. （B）低情境焦慮／高特質焦慮
  3. （C）高情境焦慮／高特質焦慮
  4. （D）低情境焦慮／低特質焦慮

答案：（A）

詳解與考點

正解：關鍵在 State Trait Anxiety Inventory（STAI）對情境焦慮（state anxiety）與特質焦慮（trait anxiety）的區分判準。個案的焦慮被判斷為由外在威脅所引發（情境性、當下觸發），且不涉及對個人自尊的持續性威脅感受（非跨情境的穩定人格傾向），並可藉由降低對該威脅的當下喚起程度而改善（暫時性、可調節），這三項特徵合起來對應的正是「高情境焦慮、低特質焦慮」的組合，故選 A。

B：低情境焦慮／高特質焦慮，反映的是個案跨情境持續存在焦慮傾向、且該焦慮常涉及自尊威脅的穩定人格特質，與題幹描述的「外在威脅引發、可藉降低喚起改善」方向相反。

C：高情境焦慮／高特質焦慮，代表個案不僅當下受外在威脅激發焦慮，本身也具有跨情境的高焦慮特質，題幹並未顯示個案有此種穩定的高焦慮傾向。

D：低情境焦慮／低特質焦慮，代表個案當下與跨情境皆處於低焦慮狀態，與題幹描述「目前有焦慮，且可歸因於外在威脅」的臨床印象不符。

本題考點：STAI 的情境焦慮與特質焦慮判準——情境焦慮看當下、可由外在事件觸發、可藉降低喚起而改善；特質焦慮看跨情境的穩定傾向、常涉及自尊威脅；辨識時先確認焦慮來源是當下事件還是穩定人格傾向。

第 8 題

以魏氏智力測驗協助智能不足之診斷評估，下列敘述何者正確？
  1. （A）全量表智商落在70分以下，即可診斷為智能障礙
  2. （B）IQ分數落於50～69的屬器質性智能障礙，而IQ分數低於50的屬非器質性智能障礙
  3. （C）魏氏智力測驗分數是判斷智能障礙唯一的準則
  4. （D）常識、算術、詞彙通常是智能障礙者最感困難的分測驗

答案：（D）

詳解與考點

正解：本題問的是魏氏智力測驗（Wechsler）用於智能障礙診斷評估時，何者敘述正確。常識、算術、詞彙這幾個分測驗高度仰賴後天累積的知識學習與語文能力，智能障礙者在這類分測驗上通常表現最為困難，相對地在較不倚賴知識累積的分測驗上落差較小，故 D 正確。

A：全量表智商落在 70 分以下即可診斷為智能障礙，這是最強誘答——它抓住了智能障礙診斷確實以 IQ 約 70 為參考切點這件事；分辨關鍵在於智能障礙的診斷除了智力測驗分數之外，還須同時符合適應功能（adaptive functioning）缺損的標準，僅憑單一 IQ 分數不足以診斷，故此敘述錯誤。

B：把「器質性」與「非器質性」智能障礙以 IQ 50～69 與低於 50 做切分，這是對智能障礙成因分類的錯置——器質性與非器質性的區分依據是有無明確的生理病因（如染色體異常、腦傷），不是以 IQ 分數區間界定，故此敘述錯誤。

C：魏氏智力測驗分數是判斷智能障礙唯一的準則，這與 A 犯的是同一類錯誤——智力測驗分數須搭配適應功能評估等多方證據，並非唯一準則，故此敘述錯誤。

本題考點：魏氏智力測驗於智能障礙診斷的三個判準——IQ 切點只是必要條件之一，須同時符合適應功能缺損；器質性與非器質性的區分依生理病因而非 IQ 區間；常識、算術、詞彙等仰賴知識累積的分測驗通常是智能障礙者表現最弱的部分。

第 9 題

有關病前智商的估計，下列敘述何者正確？
  1. （A）在病前智商估計的正確性上，以人口變項為基礎的迴歸公式顯著優於過去工作與學業表現
  2. （B）常識、類同、圖形設計為三個最不受神經損傷波及的分測驗，可用於估計病前智商
  3. （C）以人口變項與分測驗為基礎的迴歸公式，用於推估原智商極高或極低者時，易產生錯估的現象
  4. （D）可採用二或三個得分相對最低的分測驗估計病前智商

答案：（C）

詳解與考點

正解：判準是病前智商（premorbid IQ）估計方法各自的適用限制。以人口變項（如教育程度、職業）與分測驗表現為基礎所建立的迴歸公式，其原理是朝團體平均值收斂（regression to the mean），因此用於推估原本智商極高或極低者時，容易產生低估高智商者、高估低智商者的錯估現象，故 C 正確。

A：以人口變項為基礎的迴歸公式顯著優於過去工作與學業表現，這是把兩種不同性質的估計來源做了絕對優劣的比較——實務上兩者各有限制，過去工作與學業表現本身也是重要的病前功能參照，並無證據顯示迴歸公式必然顯著優於它，故此敘述錯誤。

B：常識、類同、圖形設計是三個最不受神經損傷波及的分測驗，這是把測驗名稱錯置——用於估計病前智商的分測驗須具備「相對不受神經損傷影響」的特性，常見討論多聚焦於詞彙、常識等語文性分測驗，圖形設計屬操作性分測驗，較容易受神經損傷波及，故此敘述錯誤。

D：可採用二或三個得分相對最低的分測驗估計病前智商，這是方向講反了——病前智商估計應選用「最不受損傷影響、能反映原有能力水準」的分測驗，而非取受損傷影響最大、得分最低的分測驗，故此敘述錯誤。

本題考點：病前智商估計的判準——迴歸公式因朝平均值收斂而在極端智商者身上容易錯估；估計應選用不易受神經損傷波及的分測驗（語文性質為主），而非得分最低者；不同估計來源（人口變項、過去表現）各有限制，不宜逕自判定何者顯著較優。

第 10 題

關於心理衡鑑各項測驗結果的呈現方式，下列敘述何者正確？
  1. （A）只要呈現原始分數即可
  2. （B）可呈現百分位數或標準分數
  3. （C）智力測驗只需列出全量表智力分數，無需列出分量表分數
  4. （D）需依序列出所使用測驗工具的花費時間

答案：（B）

詳解與考點

正解：本題問的是心理衡鑑各項測驗結果呈現方式，何者敘述正確。原始分數（raw score）本身不具跨測驗、跨個案的比較意義，須轉換為常模參照的百分位數或標準分數，才能讓報告使用者理解個案在常模團體中的相對位置，故 B 正確。

A：只要呈現原始分數即可，這與 B 犯的是同一類錯誤——原始分數缺乏可解釋性，報告若只列原始分數，讀者無從判斷其高低意涵，故此敘述錯誤。

C：智力測驗只需列出全量表智力分數、無需列出分量表分數，這忽略了分量表分數所呈現的能力剖面（profile）資訊——臨床衡鑑報告通常需要分量表分數以呈現個案在不同能力向度上的優弱勢，僅列全量表分數會遺失重要的臨床訊息，故此敘述錯誤。

D：需依序列出所使用測驗工具的花費時間，這是把行政記錄的內容錯置為衡鑑報告的核心呈現要求——測驗施測時間並非報告需依序呈現的重點內容，故此敘述錯誤。

本題考點：衡鑑結果呈現的判準——原始分數須轉換為常模參照分數（百分位數或標準分數）才具解釋力；智力測驗宜同時呈現全量表與分量表分數以顯示能力剖面；報告內容聚焦於分數的臨床意涵，而非施測的行政細節。

第 11 題

根據Beutler與其同事有關評估個案問題複雜度（problem complexity）的系列研究，下列何項被歸類為複雜性問題？
  1. （A）情境特定性的行為
  2. （B）長期習慣而衍生的行為
  3. （C）與過去人際互動關係遠勝於目前關係的行為
  4. （D）短暫性的行為

答案：（C）

詳解與考點

正解：Beutler 對問題複雜度（problem complexity）的分類判準，在於該行為模式是否根植於長期、跨情境、跨關係的深層結構，而非侷限於當下情境。若一個行為與個案過去人際互動關係的關聯遠勝於其與目前關係的關聯，代表該行為模式的根源深植於早期經驗，並持續跨越不同關係情境重複出現，這正是複雜性問題的核心特徵，故選 C。

A：情境特定性的行為侷限於特定情境下才出現，不具跨情境延續的性質，屬於單純問題（simple problem）的典型特徵，非複雜性問題。

B：長期習慣而衍生的行為雖具有時間上的持續性，但「習慣」本身不必然涉及跨關係、根植於過去人際模式的深層結構，其複雜度判準與 C 選項所指涉的機制不同，較不精確對應複雜性問題的定義。

D：短暫性的行為在時間向度上與複雜性問題所需的長期、根深特徵相反，屬於單純問題的另一項典型特徵。

本題考點：Beutler 問題複雜度分類的判準——複雜性問題根植於長期、跨情境、與過去人際關係高度關聯的深層模式；單純問題則表現為情境特定或短暫性的行為，兩者的區辨核心在於行為模式是否跨越時間與關係情境反覆重現。

第 12 題

在心理衡鑑資料分析整合過程中，若出現推論方向不一致的證據X與Y時，下列何種呈現方式最不適當？
  1. （A）解釋造成X與Y推論差異的可能原因
  2. （B）主張應比較重視X或Y，並指出其它測驗結果做為支持
  3. （C）解釋X與Y看似衝突，但有可能同時存在
  4. （D）呈現X與Y的測驗結果，不應推論其差異

答案：（D）

詳解與考點

正解：本題問的是心理衡鑑資料整合時，面對推論方向不一致的證據 X 與 Y，何種呈現方式最不適當。只並列呈現 X 與 Y 的測驗結果、卻拒絕對其差異做進一步推論或解釋，等於迴避了衡鑑者最核心的任務——整合矛盾證據、形成有意義的臨床理解，這種呈現方式對報告使用者毫無幫助，故 D 最不適當，為應選項。

A：解釋造成 X 與 Y 推論差異的可能原因，這是面對矛盾證據時的正面整合作法，透過分析情境因素、測驗性質差異等來理解不一致的來源，屬適當的呈現方式。

B：主張應較重視 X 或 Y，並指出其他測驗結果作為支持，這是以額外證據為依據做出取捨判斷，仍是一種有根據的整合方式，屬適當作法。

C：解釋 X 與 Y 看似衝突但有可能同時存在，這反映個案的行為或心理狀態本就可能因情境不同而呈現多面性，此種解釋方式承認並說明了表面矛盾的合理性，屬適當作法。

本題考點：矛盾證據整合的判準——衡鑑者面對推論不一致的資料，須主動解釋差異來源、權衡證據強弱、或說明看似衝突的結果如何可能並存；單純並列呈現而不做任何推論，等於放棄了整合資料、形成臨床理解的核心責任。

第 13 題

關於當今心理學文獻推薦的衡鑑資料統整形式，下列何者較不適當？
  1. （A）問題解決（problem-solving）
  2. （B）逐測驗說明（test-by-test）
  3. （C）以個案為中心（case-focused）
  4. （D）領域驅動（domain-driven）

答案：（B）

詳解與考點

正解：判準是當代心理衡鑑文獻對資料統整形式的推薦傾向。逐測驗說明（test-by-test）的統整方式，是依序羅列每個測驗各自的結果，測驗與測驗之間缺乏跨資料源的整合與交叉驗證，無法呈現個案問題的整體圖像，因此較不被當代文獻推薦，故選 B。

A：問題解決（problem-solving）取向以個案的轉介問題為出發點，整合各測驗證據回答具體的臨床問題，屬當代推薦的統整形式。

C：以個案為中心（case-focused）的統整方式，圍繞個案的整體樣貌組織資料，避免測驗結果各自獨立呈現，屬當代推薦的統整形式。

D：領域驅動（domain-driven）依認知、情緒、人格等心理功能領域整合跨測驗證據，同樣強調跨資料源的統整，屬當代推薦的統整形式。

本題考點：衡鑑資料統整形式的判準——當代文獻推薦的問題解決、以個案為中心、領域驅動三種取向，共同特徵是跨測驗整合證據以回應轉介問題或呈現個案整體樣貌；逐測驗說明僅羅列個別結果、缺乏整合，是較不被推薦的形式。

第 14 題

有關班達完形測驗在人格評估上的效度，下列敘述何者正確？
  1. （A）多數「單一徵象指標」可有效測量人格變項
  2. （B）精神分析理論的投射性解釋有充分效度支持
  3. （C）用於人格評估的可靠性顯著優於腦傷篩檢
  4. （D）加總一系列指標的整體評分，在人格評估上的效度較佳

答案：（D）

詳解與考點

正解：判準是班達完形測驗（Bender Gestalt Test）在人格評估上不同計分方式的效度比較。研究顯示將一系列指標加總而成的整體評分（aggregate scoring），其效度優於僅憑單一徵象指標（single sign）做判斷，故 D 正確。

A：多數「單一徵象指標」可有效測量人格變項，這與 D 所指的研究發現方向相反——單一徵象指標在人格評估上的效度普遍不足，僅憑某一項圖形特徵去推論人格特質缺乏穩定的實證支持，故此敘述錯誤。

B：精神分析理論的投射性解釋有充分效度支持，這是最強誘答——它符合班達完形測驗常被歸類為投射測驗（projective test）之一的直覺印象；分辨關鍵在於「常被當作投射測驗使用」不等於「其精神分析式的投射性解釋有充分實證效度支持」，實際上這類解釋的效度證據相當有限，故此敘述錯誤。

C：用於人格評估的可靠性顯著優於腦傷篩檢，這與該測驗實證支持的強項恰好相反——班達完形測驗最主要且效度最穩固的用途是腦傷篩檢（視覺動作整合功能的檢測），人格評估反而是其效度較弱的應用領域，故此敘述錯誤。

本題考點：班達完形測驗效度的判準——整體加總評分優於單一徵象指標；投射性人格解釋缺乏充分效度支持；該測驗最穩固的實證用途在腦傷篩檢而非人格評估，三者合起來說明其強項與局限分別落在不同的應用領域。

第 15 題

關於弱勢族群在智力測驗表現，下列敘述何者正確？
  1. （A）與匱乏的環境因素影響早期腦部發展有關
  2. （B）相較於主流族群測得的智力建構不同
  3. （C）智力測驗得分無法預測學業能力表現
  4. （D）針對視聽障的弱勢族群不宜使用標準化智力測驗

答案：（A）

詳解與考點

正解：本題問的是弱勢族群在智力測驗表現上，何者敘述正確。弱勢族群較低的智力測驗表現，常與其成長環境資源匱乏、進而影響早期腦部發展有關，這是解釋族群間分數差異的主要環境機制，故 A 正確。

B：相較於主流族群，弱勢族群測得的智力建構不同，這是最強誘答——它試圖用「測到不同東西」來解釋分數差異；分辨關鍵在於智力測驗測量的心理建構（construct）在不同族群間基本上是相同的，分數落差反映的是環境資源與早期發展機會的差異，而非測驗測到了不同的能力向度，故此敘述錯誤。

C：智力測驗得分無法預測學業能力表現，這與智力測驗的實證效度證據相反——智力測驗分數與學業表現之間存在穩定的正相關，具有一定的預測效度，故此敘述錯誤。

D：針對視聽障的弱勢族群不宜使用標準化智力測驗，這是把「須調整施測方式」誤植為「完全不宜使用」——視聽障族群通常需改用經過調整或替代形式（如非語文測驗）的標準化工具，而非全面排除標準化智力測驗，故此敘述錯誤。

本題考點：弱勢族群智力測驗表現的判準——分數差異主要歸因於環境資源匱乏對早期腦部發展的影響，而非測驗測到不同的智力建構；智力測驗對學業表現仍具預測效度；特殊感官障礙族群需調整施測形式，而非全面排除標準化測驗。

第 16 題

下列何項不是司法體系常見的心理衡鑑轉介問題？
  1. （A）評估學業成就
  2. （B）評估精神喪失
  3. （C）評估暴力傾向
  4. （D）評估兒童監護權歸屬

答案：（A）

詳解與考點

正解：本題問的是司法體系常見的心理衡鑑轉介問題，何者不屬於其中。評估學業成就屬於教育場域中的心理衡鑑用途（如特殊教育鑑定、學習障礙評估），與司法程序中所需回答的法律問題（如刑事責任能力、危險性、監護權判定）性質不同，故 A 不是司法體系常見的轉介問題，為應選項。

B：評估精神喪失，對應的是刑事案件中判斷被告是否因精神狀態而不具刑事責任能力，是司法心理衡鑑的核心轉介問題之一。

C：評估暴力傾向，對應的是危險性評估（risk assessment），用於量刑、假釋、監護處分等司法決定，是司法心理衡鑑的常見轉介問題。

D：評估兒童監護權歸屬，對應的是家事案件中協助法院判斷監護安排是否符合兒童最佳利益，是司法心理衡鑑的常見轉介問題。

本題考點：司法心理衡鑑轉介問題的判準——聚焦於與法律程序直接相關的問題，如刑事責任能力（精神喪失）、危險性（暴力傾向）、家事監護判定；學業成就評估屬教育場域的衡鑑用途，不落在司法轉介的範疇內。

第 17 題

以正念為基礎的認知治療（MBCT）整合許多認知治療和正念減壓程序的面向，這屬於心理治療整合取向中的何種形式？
  1. （A）技術折衷
  2. （B）理論整合
  3. （C）同化整合
  4. （D）共同因素取向

答案：（C）

詳解與考點

正解：判準是心理治療整合取向（psychotherapy integration）中各形式的定義差異。以正念為基礎的認知治療（mindfulness-based cognitive therapy, MBCT）是以認知治療（cognitive therapy, CT）作為主體架構，再將正念減壓（mindfulness-based stress reduction）的程序元素吸納、融入既有的認知治療框架中，而非另立全新的理論體系，這正是同化整合（assimilative integration）的定義特徵，故選 C。

A：技術折衷（technical eclecticism）是不預設共同理論基礎，純粹依實證效果挑選不同取向的技術組合使用，MBCT 有明確的認知治療理論主體，並非單純的技術拼湊，與此定義不符。

B：理論整合（theoretical integration）是將兩個或以上的取向融合，發展出一套全新的統整性理論架構，這是最強誘答——它同樣涉及「結合不同取向」；分辨關鍵在於理論整合會產生新的理論體系，而 MBCT 仍以認知治療為主體、正念為吸納進來的成分，並未形成獨立於認知治療之外的新理論，較貼近同化整合而非理論整合。

D：共同因素取向（common factors approach）聚焦於不同治療取向共享的療效因子（如治療關係），並不涉及將特定技術程序整合進某一主體理論的操作，與 MBCT 的整合方式不同。

本題考點：心理治療整合形式的判準——技術折衷不預設理論基礎、純依效果選用技術；理論整合融合出全新理論體系；同化整合以某一主體理論為核心、吸納其他取向的元素（MBCT 即為代表）；共同因素取向聚焦跨取向共享的療效因子，四者的分辨關鍵在於「是否有主體理論」與「是否形成新理論體系」。

第 18 題

哲學家尼采說：「只有知道自己為何而活的人，才能承受所有如何生存的問題」，最貼近下列那位大師的心理治療概念？
  1. （A）Alfred Adler
  2. （B）Viktor Frankl
  3. （C）Albert Ellis
  4. （D）Murray Bowen

答案：（B）

詳解與考點

正解：關鍵在尼采「只有知道自己為何而活的人，才能承受所有如何生存的問題」這句話所呼應的治療核心主張——追尋生命意義（will to meaning）是人類最根本的驅力，唯有找到生命的意義，才能承受隨之而來的種種痛苦與困境，此一主張正是 Viktor Frankl 意義治療（logotherapy）的核心命題，故選 B。

A：Alfred Adler 的個體心理學（individual psychology）強調個人目的性、生活風格與社會興趣（social interest），雖同樣重視「目的」對行為的引導作用，但尼采這句話聚焦的是「意義」本身作為承受苦難的憑藉，而非社會興趣或生活風格的形塑，這是最強誘答——兩者都談目的性，分辨關鍵在於 Adler 談的是社會性目的，Frankl 談的是生命意義本身。

C：Albert Ellis 的理性情緒行為治療（rational emotive behavior therapy）核心在辨識與駁斥非理性信念，聚焦認知歷程的改變，與尼采這句話強調的生命意義追尋無直接對應關係。

D：Murray Bowen 的家庭系統理論（family systems theory）核心概念是自我分化（differentiation of self）與代間傳遞，聚焦於家庭系統中的關係動力，與個人生命意義的追尋屬不同層次的理論關懷。

本題考點：治療大師核心理念的判準——Frankl 意義治療以追尋生命意義（will to meaning）為核心，能承受苦難的關鍵在於知道為何而活；Adler 個體心理學重社會興趣與目的性、Ellis 理情行為治療重非理性信念、Bowen 家庭系統理論重自我分化，四者須依各自的核心命題與尼采引言精確對應，不可因同樣涉及「目的」而混淆 Adler 與 Frankl。

第 19 題

下列何項心理治療取向，相對重視治療關係多於技術，且認為是治療結果最關鍵的決定因素？
  1. （A）認知治療
  2. （B）行為治療
  3. （C）現實治療
  4. （D）完形治療

答案：（D）

詳解與考點

正解：本題問的是何種心理治療取向相對重視治療關係多於技術，且視治療關係為療效最關鍵的決定因素，依官方標準答案，此取向為完形治療（Gestalt therapy）。完形治療屬經驗性／人本取向，強調此時此地（here-and-now）治療師與案主之間真誠、真實的相遇關係（I-Thou relationship），相對不倚賴標準化的操作技術，將這種真實的關係性接觸視為改變發生的核心機制，故選 D。

A：認知治療（cognitive therapy）以辨識與修正個案的認知扭曲、自動化思考為核心工作內容，技術結構性高，治療關係雖仍重要，但並非其理論所強調的療效關鍵因素。

B：行為治療（behavior therapy）以行為改變技術（如系統減敏感法、行為塑造）為核心，技術導向的程度更高，治療關係在其理論架構中屬輔助性角色。

C：現實治療（Reality therapy）雖也重視治療者投入且真誠的治療關係，其核心理論在於選擇理論（choice theory）與引導個案為自己的選擇與行為負責，關係在此取向中是達成行為改變的媒介，而非理論本身界定的療效最終決定因素；依本題官方判定，最符合「關係重於技術、關係本身即為療效關鍵」者為完形治療。

本題考點：心理治療取向對治療關係與技術相對重要性的判準——完形治療以此時此地的真實相遇（I-Thou relationship）為療效核心；認知治療與行為治療皆屬高度技術導向；現實治療雖重視真誠關係，其理論核心仍落在選擇理論與行為責任的引導，與完形治療把關係本身視為療效決定因素的定位不同。

第 20 題

關於團體心理治療帶領者的工作，下列敘述何者錯誤？
  1. （A）每位成員的非語言反應和語言反應都需要被留意與觀察
  2. （B）帶領者可用自己的價值觀去定義團體規範與成員的行為
  3. （C）需要留意帶領者自己在團體進行時的移情反應
  4. （D）和個別心理治療一樣，團體心理治療的保密原則仍是重要而必須的

答案：（B）

詳解與考點

正解：本題問的是團體心理治療帶領者的工作，何者敘述錯誤。團體規範與成員行為的界定，應由帶領者引導團體成員共同討論形成，並考量團體發展階段與成員需求，而非由帶領者單方面以自己的個人價值觀強加定義，故 B 敘述有誤，為應選項。

A：每位成員的非語言反應和語言反應都需要被留意與觀察，這是團體帶領者掌握團體動力、覺察成員狀態的基本工作要求，敘述正確。

C：需要留意帶領者自己在團體進行時的移情反應（countertransference），覺察自身情緒反應是否受個人議題影響、進而干擾對團體的判斷，這是帶領者專業自我覺察的必要功課，敘述正確。

D：和個別心理治療一樣，團體心理治療的保密原則仍是重要而必須的，雖然團體情境涉及多位成員、保密的複雜度較個別治療更高，但保密原則本身的重要性並未因此降低，敘述正確。

本題考點：團體治療帶領者工作守則的判準——團體規範應由團體共同形成而非帶領者單方面依個人價值觀界定；帶領者須同時留意成員的語言與非語言反應、覺察自身的反移情反應；保密原則在團體情境中依然重要且必須維持。

第 21 題

關於認知治療中常用的認知技術，下列敘述何者錯誤？
  1. （A）時間投射技術（time-projection technique）常用於幫助個案去災難化，將個案的時間觀聚焦在此時此刻，減緩個案對所擔憂之負向結果的逃避
  2. （B）重新歸因技術（reattribution technique）透過考慮事件的其他原因，減少個案在證據不足下將事件歸因至單一人或單一因素
  3. （C）重新界定技術（redefining technique）是將問題就個人行為層面重新定義的具體明確，用來鬆動個案認定問題超乎能力所及的信念
  4. （D）去中心化技術（decentering technique）幫助焦慮個案用觀察外界替代聚焦內心的不舒服，緩減自認為是他人關注焦點的擔憂

答案：（A）

詳解與考點

正解：本題問的是認知治療中常用的認知技術，何者敘述錯誤。時間投射技術（time-projection technique）的操作方式，是引導個案將時間觀投射到「未來」的情境（例如想像該負向結果發生一段時間後的狀況），藉此協助個案降低對當下負向結果的災難化評估，而非把時間觀聚焦在此時此刻，故 A 敘述有誤，為應選項。

B：重新歸因技術（reattribution technique）透過引導個案考慮事件的其他可能原因，減少個案在證據不足的情況下，將事件的成因單一地歸咎於某人或某一因素，此敘述正確描述了該技術的操作邏輯。

C：重新界定技術（redefining technique）將個案原本模糊、超出個人能力範圍的問題，重新界定為具體、明確且屬於個人行為層面可處理的問題，藉此鬆動個案認為問題超乎自身能力所及的信念，此敘述正確。

D：去中心化技術（decentering technique）協助焦慮的個案將注意力從聚焦於自身內在的不舒服感受，轉而觀察外界的實際情況，藉此減緩個案自認為是他人關注焦點的擔憂，此敘述正確。

本題考點：認知治療常用技術的操作定義判準——時間投射技術是把時間觀投射到未來以去災難化，而非聚焦當下；重新歸因技術考慮事件的其他成因、重新界定技術把問題具體化到可處理的行為層面、去中心化技術把注意力從內在轉向外界，四者須依各自技術的操作方向精確對應，不可把「聚焦此時此刻」誤植為時間投射技術的定義。

第 22 題

「生氣管理訓練（anger management training）」是何種理論技術的一種應用？
  1. （A）行為治療取向之社交技巧訓練（social skills training）
  2. （B）以正念為基礎的認知治療（mindfulness-based cognitive therapy, MBCT）
  3. （C）接納與承諾療法（acceptance and commitment therapy, ACT）
  4. （D）現實治療（reality therapy）

答案：（A）

詳解與考點

正解：判準是生氣管理訓練（anger management training）在心理治療理論脈絡中的定位。生氣管理訓練的操作核心，是教導個案辨識憤怒的觸發線索，並學習以適當的社交技巧因應引發憤怒的人際情境，藉此取代衝動性的攻擊反應，這正是行為治療取向之社交技巧訓練（social skills training）的典型應用，故選 A。

B：以正念為基礎的認知治療（mindfulness-based cognitive therapy, MBCT）的核心操作是透過正念覺察練習，協助個案以不評判的態度觀察自身的想法與情緒，與生氣管理訓練聚焦教導具體人際因應技巧的操作方式不同。

C：接納與承諾療法（acceptance and commitment therapy, ACT）的核心是協助個案以心理彈性面對內在經驗、承諾採取符合個人價值的行動，其操作邏輯與社交技巧訓練式的生氣管理有明顯差異。

D：現實治療（reality therapy）以選擇理論為基礎，聚焦協助個案評估自己的選擇是否能滿足其需求，並為行為負責，雖同樣可用於處理憤怒相關議題，但其典型定位並非生氣管理訓練這類技巧教導取向的應用。

本題考點：生氣管理訓練的理論歸屬判準——其操作核心是教導辨識憤怒線索並學習適當人際因應技巧，屬行為治療取向之社交技巧訓練（social skills training）的典型應用；MBCT 聚焦正念覺察、ACT 聚焦心理彈性與價值行動、現實治療聚焦選擇與責任，皆與社交技巧訓練式的操作邏輯不同。

第 23 題

根據Carl R. Rogers，促進治療性成長（therapeutic growth）最基本的治療條件為何？
  1. （A）真誠一致
  2. （B）同理性的了解
  3. （C）無條件的正向尊重
  4. （D）主動的揭露

答案：（A）

詳解與考點

正解：本題問的是 Rogers 人本中心治療三大核心條件中，何者是促成治療性成長的最根本前提。真誠一致（congruence）指治療者在關係中內外一致、不戴專業面具，Rogers 認為唯有治療者先具備這份一致性，同理心與正向尊重才有真實展現的基礎，因此三條件中它居於最基礎的位置，故選 A。

B：同理性的了解（empathic understanding）是三大核心條件之一，指治療者能準確體會個案的內在參照架構並回應之，但它建立在治療者本身真誠一致的前提上，並非三者中最基礎的一項。

C：無條件的正向尊重同樣是核心條件之一，指治療者對個案的接納不附加評價條件；這是最強誘答，因為它與真誠一致同屬三大條件、地位相近，分辨關鍵在於題目問的是「最基本」而非「同等重要」，Rogers 明確將真誠一致列為前提性條件。

D：主動的揭露不是 Rogers 三大核心條件之一，人本中心治療雖不排斥治療者適度自我揭露，但其理論核心從未把它列為促成成長的必要條件。

本題考點：Rogers 人本中心治療三大核心條件的位階區分——真誠一致是前提性條件，同理性的了解與無條件的正向尊重建立在其上；辨識「最基本」類問題時，須找出條件之間的邏輯先後而非只認定同屬核心清單即可。

第 24 題

關於家庭系統觀點的衡鑑與治療，下列敘述何者錯誤？
  1. （A）特別強調個案的失功能行為和家庭中其他成員彼此間的連結
  2. （B）評估個案的症狀時，會考量個案與家庭中其他成員彼此的連結
  3. （C）衡鑑個案的失功能行為時，會較為強調父親與子女之間的伊底帕斯情結
  4. （D）治療的目的在於修正家庭成員之間的互動交流形式

答案：（C）

詳解與考點

正解：關鍵在辨認「伊底帕斯情結」這個概念屬於哪個治療取向。家庭系統觀點的衡鑑焦點是家庭成員之間的互動模式與連結，而非個體內在的性心理衝突；伊底帕斯情結是精神分析理論對兒童期親子三角關係的解釋概念，家庭系統取向並不以此作為衡鑑失功能行為的依據，故 C 的敘述與家庭系統學理不符，為應選項。

A：特別強調個案的失功能行為與家庭其他成員彼此間的連結，正是家庭系統觀點的核心主張——症狀被視為系統互動的產物而非個體孤立問題，故此敘述正確，非答案。

B：評估症狀時考量個案與家庭成員的連結，同樣是家庭系統衡鑑的基本作法，與 A 一致地反映系統觀對關係脈絡的重視，此敘述正確，非答案。

D：修正家庭成員之間的互動交流形式，是家庭系統治療常見的介入目標（如改變溝通模式、打破僵化的互動循環），此敘述正確，非答案。

本題考點：家庭系統觀點以「互動連結」與「整體系統」為衡鑑與治療的核心單位，區別於精神分析取向聚焦個體內在心理衝突（如伊底帕斯情結）；判準是概念的理論歸屬——連結與互動屬系統觀，個體內在情結屬精神分析。

第 25 題

根據Wedding and Corsini（2019），關於治療初期的冥想（meditation）練習，下列敘述何者正確？
  1. （A）個案應避免單獨練習，必須由專家在旁引導
  2. （B）個案需要天天練習，且必須持續二小時
  3. （C）個案能很容易控制自己的注意力
  4. （D）個案可以使用視覺化來幫助練習

答案：（D）

詳解與考點

正解：判準是 Wedding 與 Corsini（2019）對治療初期冥想練習的具體指引，與初學者常見困難之間的對應關係。初學者在練習初期普遍難以直接控制注意力，因此可藉由視覺化（意象引導）作為輔助工具，幫助個案將注意力錨定在具體畫面上，逐步培養專注能力，故選 D。

A：個案應避免單獨練習、必須由專家在旁引導——冥想練習的設計本就鼓勵個案逐步發展獨立練習的能力，並非要求全程由專家陪同，此敘述不符合治療初期指引的實際作法。

B：個案需要天天練習且必須持續二小時——治療初期對練習時間與頻率的要求通常循序漸進、由短而長，並非一開始就要求高強度的每日兩小時，此敘述誇大了實際要求。

C：個案能很容易控制自己的注意力——這與初學者的實際狀態相反，初學者的注意力控制能力尚未成熟，正因如此才需要視覺化等輔助工具，此敘述與練習初期的現實不符。

本題考點：治療初期冥想練習的指引重點在於順應初學者注意力控制能力尚弱的現實，以視覺化等輔助工具循序漸進地培養專注，而非要求高強度時數或全程專業陪同。

第 26 題

Meichenbaum認為個案的行為發生改變會經歷三個階段，其中第二階段為何？
  1. （A）學習改變自己的內在對話
  2. （B）學習如何觀察自己的行為
  3. （C）學習辨識自己的認知謬誤
  4. （D）學習更有效的因應技巧

答案：（A）

詳解與考點

正解：Meichenbaum 自我教導訓練將行為改變歷程分為三個依序推進的階段，判準是各階段的任務內容與其順序。第一階段是個案先學習觀察自己的行為，第二階段建立在觀察之上，進一步學習改變自己的內在對話（自我陳述），第三階段才是習得更有效的因應技巧並加以運用，故第二階段選 A。

B：學習如何觀察自己的行為是第一階段的任務——這是最強誘答，因為觀察行為與改變內在對話同屬自我教導訓練的核心歷程，分辨關鍵在於階段順序，觀察行為是改變內在對話的前置步驟，兩者不能互換位置。

C：學習辨識自己的認知謬誤並非 Meichenbaum 三階段模型中的獨立階段，認知謬誤的辨識較常見於 Beck 認知治療的架構，不屬於本題所問的三階段內容。

D：學習更有效的因應技巧是三階段中的第三階段，發生在個案已能觀察自己行為並改變內在對話之後，屬於歷程末端而非第二階段。

本題考點：Meichenbaum 自我教導訓練三階段的順序判準——先觀察行為、再改變內在對話、最後習得因應技巧；答題時須鎖定「第幾階段」對應的具體任務，不能只認定選項內容屬於這套理論的範疇就作答。

第 27 題

下列那一項是法蘭克（Viktor Frankl）對於人的本質之描述？
  1. （A）朝向享樂（will to pleasure）
  2. （B）朝向權力（will to power）
  3. （C）朝向道德（will to morality）
  4. （D）朝向意義（will to meaning）

答案：（D）

詳解與考點

正解：本題問的是法蘭克（Viktor Frankl）意義治療對人性本質的核心主張。Frankl 認為人最根本的驅力並非享樂或權力，而是朝向意義（will to meaning）——個體終其一生都在尋求生命的意義與目的，即使身處極端苦難仍能藉由意義感支撐存在，故選 D。

A：朝向享樂（will to pleasure）是 Frankl 用以對照自身理論的概念，對應佛洛伊德（Freud）以享樂原則與本能滿足為核心的驅力觀，並非 Frankl 自己對人性本質的描述。

B：朝向權力（will to power）同樣是 Frankl 用以區隔理論的對照概念，對應阿德勒（Adler）強調追求優越與掌控感的驅力觀，非 Frankl 意義治療的主張。

C：朝向道德（will to morality）不是意義治療的用語，Frankl 理論中沒有以此作為人性本質核心驅力的提法，此選項屬於混淆式的干擾選項。

本題考點：Frankl 意義治療以「朝向意義」為人性本質的核心主張，並刻意以朝向享樂（對應 Freud）與朝向權力（對應 Adler）作為理論對照，答題時須掌握三個驅力概念分別對應哪位理論家。

第 28 題

下列何項治療相對上較不強調與考量個案的社會文化脈絡？
  1. （A）阿德勒取向治療
  2. （B）個人中心治療
  3. （C）敘事治療
  4. （D）女性主義治療

答案：（B）

詳解與考點

正解：關鍵在比較四個治療取向對「社會文化脈絡」的理論重視程度。個人中心治療的理論核心聚焦於個體內在的主觀經驗、自我概念與自我實現傾向，介入焦點主要放在治療關係中的個體歷程，相對而言較不特別強調外在的社會文化脈絡，故選 B。

A：阿德勒取向治療以社會興趣（social interest）與人際脈絡為理論核心，個體的行為與適應被放在社會關係網絡中理解，對社會文化脈絡的重視程度高，非答案。

C：敘事治療立基於社會建構論，強調個人故事是在社會文化與權力關係中被建構出來的，治療歷程常涉及解構主流文化論述對個案的影響，對社會文化脈絡的重視程度高，非答案。

D：女性主義治療明確以性別與社會權力結構作為理解個案困境的核心架構，強調個人議題與社會脈絡的不可分割，對社會文化脈絡的重視程度最高，非答案。

本題考點：比較不同治療取向對社會文化脈絡的理論定位——個人中心治療聚焦個體內在經驗，阿德勒、敘事、女性主義治療則分別以社會興趣、社會建構、性別權力結構將社會文化脈絡納入核心理論。

第 29 題

正念與接納為基礎的治療中，下列何者已廣泛應用於促進健康生活型態的改變，且證實可促進生理與心理健康？
  1. （A）焦點解決短期治療（SFBT）
  2. （B）後現代敘事分析（PMNA）
  3. （C）辯證行為治療（DBT）
  4. （D）正念減壓（MBSR）

答案：（D）

詳解與考點

正解：判準是「已廣泛應用於促進健康生活型態改變、並有實證支持促進生理與心理健康」這個描述具體對應哪一種方法。正念減壓（MBSR）自發展以來即廣泛應用於一般族群的健康促進，累積大量實證支持其對減壓、情緒調節與生理健康指標的助益，最符合題幹描述，故選 D。

A：焦點解決短期治療（SFBT）是以目標導向、聚焦解決方案的心理治療模式，主要應用於各類心理諮商情境，並非以「促進健康生活型態改變」為其廣泛應用與實證累積的焦點領域。

B：後現代敘事分析（PMNA）屬敘事取向的分析方法，關注個案故事的建構與重寫，同樣不是以健康生活型態促進為主要應用與實證累積方向。

C：辯證行為治療（DBT）主要發展並應用於情緒調節困難與邊緣型人格的治療，這是最強誘答，因為 DBT 同屬正念與接納取向、也有紮實實證基礎，分辨關鍵在於應用範疇——DBT 聚焦臨床族群的情緒調節，MBSR 才是廣泛用於一般健康促進的代表方法。

本題考點：正念與接納取向中不同方法的應用範疇區分——MBSR 廣泛用於一般族群的健康生活型態促進，DBT 聚焦臨床族群的情緒調節，答題須依「廣泛應用於健康促進」這個描述鎖定對應方法而非泛稱同屬正念取向即可。

第 30 題

曉華三天前搭火車不幸出軌翻車，身體受傷住院治療。醫生照會臨床心理師，發現曉華這幾天常做惡夢、心神不寧、不太想談翻車相關的事情、也不想看翻車相關的新聞。臨床心理師的建議，下列何者最適當？
  1. （A）這是罹患創傷後壓力症，建議進行延長暴露治療能有效改善
  2. （B）這些是經歷創傷事件後的正常反應，一定會隨時間消失，建議無需進一步心理治療
  3. （C）建議這段時間都不要想翻車事件，減少創傷喚醒物誘發身心反應
  4. （D）建議這段時間可以找信任的親友陪伴，減少身心反應的惡化

答案：（D）

詳解與考點

正解：本題問的是創傷事件發生三天後、症狀屬急性期常見反應時，臨床心理師最適當的處置方向。曉華的做惡夢、心神不寧、迴避談論與迴避相關新聞，皆是經歷重大意外事件後常見的急性壓力反應，此階段最適當的處置是連結既有的社會支持系統，建議由信任的親友陪伴，以降低身心反應惡化的風險，同時持續觀察後續病程，故選 D。

A：這是罹患創傷後壓力症、建議進行延長暴露治療——事件僅發生三天，尚未達到 PTSD 診斷所需的病程時間，過早給予診斷標籤並直接施以暴露治療，忽略了急性期反應本身多屬正常病程的可能性，此建議不適當。

B：斷言這些反應一定會隨時間消失、建議無需進一步心理治療——把病程結果講死並過度保證，忽略了仍需持續觀察與追蹤的必要性，一旦症狀未如預期消退便會失去及時介入的時機，此建議不適當。

C：建議這段時間都不要想翻車事件、減少創傷喚醒物誘發身心反應——鼓勵個案主動壓抑與迴避，這與創傷後恢復歷程中「逐步且安全地處理創傷經驗」的原則相違，長期迴避反而不利復原，此建議不適當。

本題考點：急性創傷後早期處置的判準——症狀發生時間未達診斷病程門檻前，不宜過早貼上診斷標籤或施以特定治療技術，也不宜斷言病程結果或鼓勵壓抑迴避，最適當的做法是連結社會支持並持續觀察。

第 31 題

依據Beck的認知治療，憂鬱症是負向基模和認知偏誤造成，因此針對憂鬱症的治療目標主要為何？
  1. （A）把負向人際關係當作是心智事件
  2. （B）改變不適應的思考模式
  3. （C）避免回想不愉悅經驗
  4. （D）增加正念練習

答案：（B）

詳解與考點

正解：判準是 Beck 認知治療對憂鬱症病因的理論主張與其治療目標之間的邏輯對應。Beck 認為憂鬱症源自個體的負向基模（negative schema）與系統性的認知偏誤，這些偏誤導致個體對自我、世界與未來產生扭曲且不適應的解讀，因此治療目標直指這個病因鏈的核心，也就是辨識並改變這些不適應的思考模式，故選 B。

A：把負向人際關係當作是心智事件——這種「去中心化」的描述方式較接近正念取向對認知內容的處理原則，並非 Beck 傳統認知治療針對憂鬱症所設定的核心治療目標。

C：避免回想不愉悅經驗——鼓勵個案迴避不愉悅經驗，這與 Beck 認知治療要求個案正視並檢視自身思考內容、進而修正認知偏誤的取向相反，並非其治療目標。

D：增加正念練習屬於正念與接納取向的介入策略，雖然近年認知行為治療也吸納正念元素，但這並非 Beck 傳統認知治療針對憂鬱症負向基模所設定的原始治療目標。

本題考點：Beck 認知治療的病因—目標對應關係——憂鬱症的病因是負向基模與認知偏誤，治療目標因此鎖定在改變不適應的思考模式本身，而非迴避負向內容或採用其他取向（去中心化、正念）的介入策略。

第 32 題

依據客體關係理論學者Margaret Mahler，邊緣型人格障礙症源自下列那一階段的障礙？
  1. （A）共生（symbiosis）
  2. （B）客體恆常（object constancy）
  3. （C）正常嬰兒自閉（normal infantile autism）
  4. （D）分離－個體化（separation-individuation）

答案：（D）

詳解與考點

正解：Mahler 客體關係發展理論將邊緣型人格障礙症的病理根源，對應到分離－個體化（separation-individuation）階段的發展障礙，判準是各發展階段固著與成年病理嚴重度之間的對應關係。分離－個體化階段，特別是其中的復合次階段（rapprochement），涉及幼兒在追求自主與仍需依附照顧者之間的心理張力，這個階段若發展受阻，被認為與成年後邊緣型人格的核心特徵（強烈的分離焦慮、關係中的理想化與貶抑擺盪）密切相關，故選 D。

A：共生（symbiosis）階段的固著，理論上更常與較嚴重的精神病性問題相關，而非典型邊緣型病理——這是最強誘答，因為共生與分離－個體化在時序上前後相連、同屬 Mahler 理論的早期發展階段，分辨關鍵在於固著發生的階段不同、對應的成年病理嚴重度也不同。

B：客體恆常（object constancy）是分離－個體化歷程的最終達成目標，指個體能穩定持有對客體的正向內在表徵，即使客體不在場或曾令人挫折也不動搖；邊緣型病理被理解為這個目標未能穩固達成的結果，而非客體恆常階段本身出了障礙。

C：正常嬰兒自閉（normal infantile autism）是 Mahler 理論中最早的發展階段，指嬰兒尚未區分自己與外界的原始未分化狀態，此階段的固著與邊緣型人格的關聯性遠不如分離－個體化階段。

本題考點：Mahler 客體關係發展階段與病理嚴重度的對應——共生階段固著多連結精神病性問題，分離－個體化階段（尤其復合次階段）的障礙才是邊緣型人格病理的核心根源，客體恆常則是該階段未竟的目標而非障礙發生的階段本身。

第 33 題

某臨床心理師打算將其工作單位歷年來所收到100份病人的心理衡鑑資料，匿名處理後並投稿國際研討會，下列敘述何者正確？
  1. （A）需經倫理委員會核准才能進行資料整理
  2. （B）因為是匿名資料，無需倫理委員會的核准
  3. （C）經單位主管核准後就能使用
  4. （D）逐一打電話徵求病患或家屬同意後，方可使用資料

答案：（A）

詳解與考點

正解：本題問的是將既有病人衡鑑資料匿名後用於研討會投稿，是否仍須經過研究倫理審查。即使資料已去識別化處理，只要其內容源自人類受試者並用於學術發表，此研究計畫仍須提交機構的倫理委員會（IRB）審查並取得核准後才能進行資料整理與使用，這是研究倫理審查的基本要求，故選 A。

B：因為是匿名資料、無需倫理委員會核准——去識別化只能降低受試者身分曝光的風險，並不能免除研究計畫本身仍涉及使用人類受試者資料這個事實，此敘述誤把「匿名」等同於「不受倫理審查規範」，並不正確。

C：經單位主管核准後就能使用——單位主管的行政核准屬於機構內部管理程序，與具有審查研究倫理正當性的倫理委員會審查是不同層級的機制，主管核准不能取代倫理委員會的審查，此敘述不正確。

D：逐一打電話徵求病患或家屬同意後方可使用——資料已完成匿名處理、且屬於既有臨床病歷的回溯性使用，逐一聯繫當事人徵求同意在實務上未必可行也非必要程序，是否需要個別再同意應由倫理委員會依研究性質判斷，並非一律必要的固定作法。

本題考點：既有臨床資料用於學術發表的倫理審查判準——資料是否去識別化不影響研究計畫仍須經倫理委員會（IRB）審查核准的要求，單位主管核准與逐一徵求當事人同意皆不能取代此審查程序。

第 34 題

有關臨床心理師在專業治療關係中的作為，下列敘述何者是較不具有倫理爭議的？
  1. （A）向個案借款
  2. （B）撰寫病歷時，刻意掩飾個案對心理治療的不滿
  3. （C）考慮中止心理治療時，事先瞭解個案的看法與需求
  4. （D）將個案的案例集結成冊並出版，但未隱去可辨識個案身分的細節

答案：（C）

詳解與考點

正解：關鍵在辨認四個選項中，哪一項是負責任且符合專業倫理的作為，而非構成倫理爭議的行為。考慮中止心理治療前，事先了解個案對此的看法與需求，是治療關係結束階段應有的專業態度，有助於評估個案的準備度並降低終止治療對個案造成的衝擊，屬於較不具倫理爭議的作為，故選 C。

A：向個案借款涉及治療者與個案之間金錢往來所形成的雙重關係，容易模糊專業界線並影響治療歷程的中立性，是明顯具有倫理爭議的作為。

B：撰寫病歷時刻意掩飾個案對心理治療的不滿，違反病歷記錄應真實反映臨床歷程的要求，也可能影響後續照護的連貫性與品質，是明顯具有倫理爭議的作為。

D：將個案案例集結成冊出版但未隱去可辨識身分的細節，直接侵犯個案的保密權與隱私權，即使案例具教學或學術價值，未經去識別化處理出版也是明顯具有倫理爭議的作為。

本題考點：專業治療關係中的倫理判斷——雙重關係（借款）、病歷記錄失真、未去識別化出版個案資料，皆構成明確的倫理爭議；相對地，終止治療前主動了解個案的看法與需求，是負責任且符合倫理的專業作為。

第 35 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「能力」，不包括下列那一項臨床心理師行為之陳述？
  1. （A）致力提昇對他人的關切
  2. （B）致力提昇對社會利益的覺察
  3. （C）致力提昇對職務地位的追求
  4. （D）致力提昇對專業知識的掌握

答案：（C）

詳解與考點

正解：判準是臺灣「臨床心理師倫理準則與行為規範」基本準則中「能力」這一項所涵蓋的具體內容。「能力」原則聚焦於臨床心理師持續提昇自身專業效能的面向，包含對他人（個案與相關人士）處境的關切、對社會利益的覺察，以及對專業知識與技能的掌握，這些都是與提升服務品質直接相關的能力面向；追求職務地位的提升則屬於個人職涯發展的範疇，並非「能力」原則所規範的內容，故 C 不包括在內，為應選項。

A：致力提昇對他人的關切，是「能力」原則所涵蓋的內容之一，反映臨床心理師須持續提升對個案與相關他人處境的敏感度與關注，故此項包含在內，非答案。

B：致力提昇對社會利益的覺察，同樣是「能力」原則所涵蓋的內容，反映專業能力不只侷限於臨床技術，也包含對執業所處社會脈絡與公共利益的覺察，故此項包含在內，非答案。

D：致力提昇對專業知識的掌握，是「能力」原則最直接對應的核心內容，持續精進專業知識與技能本就是能力原則的基本要求，故此項包含在內，非答案。

本題考點：臺灣臨床心理師倫理準則「能力」原則的範疇——涵蓋對他人的關切、對社會利益的覺察、對專業知識的掌握，這些皆指向專業效能與服務品質的提升；個人職務地位的追求則不屬於此項倫理原則規範的內容。

第 36 題

某自陳式量表僅以大專學生作為受測對象，進行心理計量特性檢驗，檢驗合宜後廣泛運用於所有成年群體。最可能出現下列何種問題？
  1. （A）常模適切性
  2. （B）施測程序標準化
  3. （C）建構效度
  4. （D）再測信度

答案：（A）

詳解與考點

正解：判準是量表建立心理計量特性時所依據的受測樣本，與後續實際施測對象之間是否相符。此量表僅以大專學生作為受測對象進行心理計量特性檢驗，其常模因此建立在大專學生這個特定群體之上；一旦將其廣泛運用於所有成年群體，受測對象的年齡層、生活經驗與心理特質都可能與原本的常模母群有明顯落差，最直接受到威脅的就是常模適切性，故選 A。

B：施測程序標準化指的是施測指導語、時間限制、計分方式等程序是否一致，這與受測樣本是誰無關，量表原本檢驗合宜的施測程序不會因為使用對象改變而受到影響。

C：建構效度指量表是否確實測到其宣稱測量的心理構念，這項特性主要取決於量表題項與構念之間的理論連結，不會因為施測對象從大專生擴大到所有成年人而直接動搖——這是最強誘答，因為聽起來也與「適用性」有關，分辨關鍵在於建構效度關注的是「測到了什麼」，而常模適切性關注的是「和誰比較」。

D：再測信度指量表在不同時間點測量結果的穩定程度，這項特性同樣不因施測對象的擴大而直接改變，除非另外對新的對象群體重新檢驗。

本題考點：量表推廣使用時的核心風險判準——受測樣本與適用對象不符時，最直接受威脅的是常模適切性（能否用同一套常模比較不同群體），而非施測程序標準化、建構效度或再測信度這些不隨使用對象改變而直接受影響的特性。

第 37 題

針對有「前－後測」，主要結果指標為憂鬱分數，但測量方式不同（例如採用BDI或HADS等）的心理治療療效研究進行後設分析時，最適用的統計量為何？
  1. （A）未標準化平均數差異（unstandardized mean difference）
  2. （B）效果量（effect size）
  3. （C）風險比（risk ratio）
  4. （D）標準化均方根（standardized root mean square）

答案：（B）

詳解與考點

正解：多篇心理治療療效研究若都採用「前－後測」設計、但測量憂鬱程度所用的量表不同（如 BDI 或 HADS），進行後設分析時就須選用不受量尺單位影響的統計量以整合這些結果，判準即在此。由於不同量表的量尺單位與範圍不同，直接比較原始分數的差異並無意義，必須將各研究的結果轉換為共同指標，也就是效果量（effect size，如標準化平均數差異），才能跨研究進行有意義的比較與整合，故選 B。

A：未標準化平均數差異（unstandardized mean difference）保留原始量尺的單位，當各研究使用的量表不同（BDI 與 HADS 的分數範圍與意義並不相同）時，直接以未標準化的平均數差異合併會使結果失去可比較性，並不適用於本情境。

C：風險比（risk ratio）是用於比較二分類結果（如是否發生某事件）的統計量，本題的主要結果指標是憂鬱分數這種連續變項，並非二分類結果，風險比並不適用。

D：標準化均方根（standardized root mean square）並非後設分析中用於整合不同研究憂鬱分數差異的常用效果量指標，與本題所需的「跨量尺可比較的效果指標」用途不符。

本題考點：後設分析統計量的選擇判準——當各研究採用不同量尺測量同一構念時，須以效果量（如標準化平均數差異）消除量尺差異的影響，才能跨研究整合；未標準化的差異量無法跨量尺比較，風險比則僅適用於二分類結果。

第 38 題

關於世代研究法，下列敘述何者錯誤？
  1. （A）年齡效果（Age effects）：在特定年齡會受到特定事件的影響
  2. （B）世代效果（cohort effects）：不同時代，特定的成長期造成的影響不同
  3. （C）測量時間效果（Time-of-measurement effects）：在特定時間點進行測量評估時，受到當時特定事件所影響
  4. （D）選擇性死亡（selective mortality）：研究參與者因意外事件而退出研究

答案：（D）

詳解與考點

正解：判準是「選擇性死亡（selective mortality）」這個概念的精確定義，與題目敘述是否相符。選擇性死亡指的是研究參與者的流失或退出並非隨機發生，而是與被研究的特質本身有系統性關聯（例如身體較弱、認知功能較差的參與者更容易在長期追蹤研究中提前退出或死亡），這種非隨機的流失會使剩下的樣本產生偏誤；題目將其描述為單純「因意外事件而退出研究」，忽略了「與研究特質相關」這個核心要件，敘述並不精確，故 D 為錯誤（正解）。

A：年齡效果（Age effects）指個體在特定年齡階段會受到與該年齡相關的特定事件或發展歷程影響，此敘述正確地描述了年齡效果的定義，非答案。

B：世代效果（cohort effects）指不同世代的成長時期經歷不同的時代背景與重大事件，因而造成世代之間的差異，此敘述正確地描述了世代效果的定義，非答案。

C：測量時間效果（Time-of-measurement effects）指在特定時間點進行測量時，受到當時特定社會事件或情境的影響，此敘述正確地描述了測量時間效果的定義，非答案。

本題考點：世代研究法三種效果與選擇性死亡的精確定義——年齡、世代、測量時間效果分別對應個體發展階段、世代成長背景、測量當下情境三種不同的影響來源；選擇性死亡的核心要件是樣本流失與研究特質存在系統性關聯，而非泛指任何原因的退出。

第 39 題

有關相關係數及其統計顯著性，下列敘述何者錯誤？
  1. （A）相關係數通常以r表示，介於-1.00至1.00之間
  2. （B）相關係數的統計顯著性，不受樣本人數多寡影響
  3. （C）通常相關係數絕對值越大，愈可能達到統計顯著性
  4. （D）研究樣本愈大，達到統計顯著所需的相關係數愈小

答案：（B）

詳解與考點

正解：本題問的是相關係數統計顯著性與樣本人數之間的關係是否如選項所述。相關係數的統計顯著性檢定與樣本人數密切相關，樣本人數越多，即使相關係數的絕對值不大，也越容易達到統計顯著；反之樣本人數越少，即使相關係數看起來不小，也可能未達顯著。因此「不受樣本人數多寡影響」這個敘述與統計顯著性檢定的基本原理相違，故 B 為錯誤（正解）。

A：相關係數通常以 r 表示，其數值範圍介於負 1.00 至正 1.00 之間，這是相關係數的基本定義，此敘述正確，非答案。

C：通常相關係數絕對值越大，代表變項間線性關聯的強度越高，在樣本人數固定的前提下也確實愈可能達到統計顯著性，此敘述正確，非答案。

D：研究樣本愈大，達到統計顯著所需的相關係數門檻愈小，這與 B 選項所述的關係互為表裡——樣本越大，越小的相關係數也能被判定為顯著，此敘述正確，非答案。

本題考點：相關係數統計顯著性的判準——顯著與否同時取決於相關係數的絕對值大小與樣本人數多寡，兩者共同決定顯著性檢定的結果，樣本人數越大，達顯著所需的相關係數門檻越低，並非顯著性只取決於相關係數本身而與樣本人數無關。

第 40 題

使用心理測驗評估心理治療效果，下列何者不是最重要的考量？
  1. （A）測驗的再測信度
  2. （B）測驗是否具有複本
  3. （C）測驗的常模適切性
  4. （D）前後測的施測者要同一人

答案：（D）

詳解與考點

正解：關鍵在辨認以心理測驗評估治療效果時，哪一項並非測量學上最重要的考量。標準化心理測驗的設計目的之一，就是透過統一的施測程序與計分方式降低結果對個別施測者的依賴，因此「前後測的施測者要同一人」並非評估治療效果時最重要的考量，故 D 不是（正解）。

A：測驗的再測信度反映測驗結果在不同時間點測量的穩定程度，這對於區辨「治療效果造成的改變」與「測量本身的隨機誤差」至關重要，是評估治療效果時的重要考量，非答案。

B：測驗是否具有複本，關係到前後測是否能使用不同版本的題目以降低練習效應（practice effect）對分數變化的干擾，是評估治療效果時的重要考量，非答案。

C：測驗的常模適切性關係到測驗分數的解讀是否有恰當的參照依據，若常模不適用於受測群體，即使分數有所變化也難以正確解讀其臨床意義，是評估治療效果時的重要考量，非答案。

本題考點：以心理測驗評估治療效果的重要考量排序——再測信度、複本可用性、常模適切性皆直接影響能否正確判讀分數變化的意義；標準化測驗的設計本就是為了降低結果對個別施測者的依賴，因此前後測施測者是否同一人並非核心考量。
