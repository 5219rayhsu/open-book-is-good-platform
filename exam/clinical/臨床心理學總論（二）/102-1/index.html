第 1 題

關於行為衡鑑基本假設之敘述，下列何者正確？
  1. （A）行為為個人內在心理歷程之顯現
  2. （B）測量行為以推論長期穩定之人格特質
  3. （C）了解行為的環境特性與行為如何改變
  4. （D）行為測量結果不穩定的主要原因為測量工具之系統性誤差

答案：（C）

詳解與考點

正解：題眼在「行為衡鑑基本假設」——判準是把行為放回其發生的情境與後果中，找出可改變的功能關係。行為衡鑑關心環境特性如何影響行為，以及行為如何隨前因與後果改變，故選 C。

A：把行為視為內在心理歷程的顯現較接近心理動力或特質取向，不是行為衡鑑的基本假設。

B：以測量推論長期穩定人格特質是傳統特質衡鑑的目標，與行為衡鑑著重情境特異性不同。

D：行為測量結果隨情境而變不必然表示工具有系統性誤差；這是最強誘答，因為它把變異都當成測量問題，卻忽略行為本身具有情境依賴性。

本題考點：行為衡鑑（behavioral assessment）——分析行為與環境的功能關係；功能分析（functional analysis）——檢視前因、行為與後果；情境特異性（situational specificity）——是行為資料的重要特性。

第 2 題

下列何者不是在考慮一份測驗常模充分性的重要因素？
  1. （A）標準化樣本是否有分組常模
  2. （B）標準化樣本是否夠大
  3. （C）標準化樣本是否有基本的閱讀能力
  4. （D）標準化樣本是否足以代表主試者想施測的群體

答案：（C）

詳解與考點

正解：題眼在「不是」與「常模充分性」——判準是標準化樣本能否在規模與組成上代表預定受測群體，並提供有用的比較基準。樣本有無基本閱讀能力是個別受測者能否理解某測驗的施測適切性問題，不是評估常模本身充分性的核心因素，故 C 為應選項。

A：分組常模可讓不同年齡、教育程度或其他相關群體得到較適切的比較，屬常模充分性的重要考量。

B：樣本量影響常模估計的穩定性，樣本是否夠大是重要因素。

D：標準化樣本能否代表主試者要施測的群體是常模能否適用的關鍵。這是最強誘答，因為閱讀能力確實影響測驗結果；但它影響的是測驗是否適合該個案，而非樣本代表性。

本題考點：常模（norms）——提供受測者與標準化樣本的比較基準；代表性（representativeness）——是常模適用性的核心；施測適切性（appropriateness of administration）——須與常模品質分開判斷。

第 3 題

認為個案無法覺察自己行為的原因，因此對個案的口頭報告持懷疑態度，這是何種理論傾向的臨床心理 師會有的偏好？
  1. （A）心理動力論
  2. （B）行為理論
  3. （C）認知理論
  4. （D）系統理論

答案：（A）

詳解與考點

正解：題眼在「無法覺察自己行為的原因」及因此懷疑口頭報告——判準是何種理論最重視無意識歷程與自我覺察的限制。心理動力論認為行為可受無意識衝突與防衛機制影響，個案未必能直接報告真正的動機，故選 A。

B：行為理論通常重視可觀察行為與環境功能關係，對自陳資料可能採多方法驗證，但「無意識而無法覺察」不是其核心理由。

C：認知理論重視個案對想法與信念的報告，雖承認自動思考未必立刻被察覺，仍常以合作方式引導覺察，與題幹的基本假設不同。

D：系統理論關心關係系統與互動循環，不是以無意識動機解釋個案無法自覺。這是最強誘答，因為系統中的互動也可能不被個案察覺；但其理論焦點不是心理動力論的無意識衝突。

本題考點：心理動力論（psychodynamic theory）——強調無意識衝突與防衛機制；自陳資料（self-report）——其可信度應依理論假設與其他資料來源整合判讀。

第 4 題

Schwartz 及 Wiedel（1981）的研究發現病史、腦波圖、生理檢查再搭配 MMPI 有助於正確診斷。此時選 用 MMPI 主要是基於何種考慮？
  1. （A）內容效度
  2. （B）效標效度
  3. （C）概念效度
  4. （D）遞增效度

答案：（D）

詳解與考點

正解：題眼在「再搭配 MMPI 有助於正確診斷」——判準是加入一項工具後，是否在既有病史、腦波圖與生理檢查之外，額外提升診斷判斷。MMPI 的價值在於提供先前資料未涵蓋的增額資訊，因此屬遞增效度，故選 D。

A：內容效度問測驗題目是否充分涵蓋欲測內容，與加入 MMPI 後是否提升診斷正確性不同。

B：效標效度問測驗分數與外在效標的關聯；本題特別強調它在既有資料之外的附加貢獻。

C：概念效度問測驗是否測得理論構念，不能直接回答多一項資料是否使診斷更準確。這是最強誘答，因為 MMPI 當然需要有效測量人格與症狀；但題目問的是「搭配後多帶來什麼」。

本題考點：遞增效度（incremental validity）——新工具在既有資訊之外增加預測或診斷效益；效標效度（criterion-related validity）——檢驗分數與外在效標的關聯；多方法衡鑑（multimethod assessment）——重點在各來源的互補資訊。

第 5 題

有關行為衡鑑的敘述，下列何者最正確？
  1. （A）行為治療師關心的議題是如何針對個案與群體間的差異進行行為功能分析
  2. （B）行為衡鑑著重行為的個別分析，而不重視工具的心理計量特性
  3. （C）貝克憂鬱量表、自我肯定量表等自陳式量表常被誤認為是行為衡鑑工具
  4. （D）許多行為治療師仍認為非結構且針對個案的取向才合適

答案：（D）

詳解與考點

正解：題眼在「行為衡鑑」與「最正確」——判準是此取向是否以個案在具體情境中的行為功能為核心。許多行為治療師認為，非結構且針對個案的取向較能掌握前因、後果與功能關係，故選 D。

A：行為功能分析主要比較同一個案在不同情境下的行為與後果，不是以個案和群體之間的差異為中心。

B：行為衡鑑雖重視個別分析，仍不能不重視工具的信度、效度與測量品質。

C：自陳式量表可被用於行為衡鑑，只要其內容與功能分析問題相連；不能一概說它們只是被誤認為行為衡鑑工具。這是最強誘答，因為「自陳」不是直接觀察；但資料來源不決定其能否服務於行為衡鑑。

本題考點：個案取向衡鑑（idiographic assessment）——聚焦個案在情境中的功能關係；功能分析（functional analysis）——不是群體比較；心理計量特性（psychometric properties）——即使在個案取向中仍須重視。

第 6 題

WAIS-III 的那個指數最能反映個案「學校教育的學習成果」？
  1. （A）語文理解
  2. （B）知覺組織
  3. （C）工作記憶
  4. （D）處理速度

答案：（A）

詳解與考點

正解：題眼在「WAIS-III」與「學校教育的學習成果」——判準是各指數主要反映的能力來源。語文理解指數包含受教育與文化經驗累積所形成的語詞知識、常識與語文推理，因此最能反映學校教育的學習成果，故選 A。本題涉及版本敏感的 WAIS-III 指數結構，依題幹版本作答。

B：知覺組織較著重非語文的視覺空間與知覺推理能力，不是教育學習成果的最佳指標。

C：工作記憶主要反映短暫保持與心智操作資訊的能力，不能直接等同於累積的學校學習。

D：處理速度反映簡單視覺資訊的掃描與作業效率，也不是教育累積知識的主要表徵。這是最強誘答，因為學校作業確實需要速度；但題目問的是「學習成果」而非作業效率。

本題考點：WAIS-III（Wechsler Adult Intelligence Scale-III）——作答須依版本的指數結構；語文理解（Verbal Comprehension）——較反映教育與文化累積的晶體能力；晶體能力（crystallized ability）——不同於處理速度與工作記憶。

第 7 題

若想了解個案的長期記憶能力，最適當的 WAIS-III 之組合為下列那個選項？
  1. （A）理解與常識
  2. （B）詞彙與常識
  3. （C）詞彙與記憶廣度
  4. （D）理解與類同

答案：（B）

詳解與考點

正解：題眼在「長期記憶能力」與 WAIS-III 分測驗組合——判準是分測驗是否需要提取長期累積、已儲存的知識。詞彙與常識都要求提取教育與生活經驗中已習得的語文知識，因此最適合用來推估長期記憶的知識提取面向，故選 B。本題涉及版本敏感的 WAIS-III 分測驗解釋，依題幹版本作答。

A：理解也運用既有知識，但較偏向社會判斷與實際知識的應用；與常識配對不如詞彙與常識直接聚焦於長期語意知識。

C：記憶廣度主要測量短期記憶與注意力／工作記憶，與題幹所問的長期記憶方向不同。

D：類同主要測抽象語文推理與概念形成，不能與理解一起作為長期記憶的最佳組合。這是最強誘答，因為兩者皆需要語文作答；但語文作答不等於主要在測長期知識提取。

本題考點：長期記憶（long-term memory）——可由已學得知識的提取加以推估；詞彙與常識（Vocabulary and Information）——較依賴語意知識；工作記憶（working memory）——須與長期記憶區分。

第 8 題

智能較高的受試者在羅氏墨跡測驗中可能出現何種表現？
  1. （A）組織活動多
  2. （B）人類部分反應多
  3. （C）單純形狀多
  4. （D）從眾反應多

答案：（A）

詳解與考點

正解：題眼在「智能較高」與「羅夏克墨跡測驗」——判準是反應是否顯示知覺組織與整合的複雜度。智能較高的受試者較能把墨跡的多個部分組織成有意義的整體，因此組織活動多是較常見的表現，故選 A。

B：人類部分反應是以人體局部作答的內容類別，較可反映對人際或自我表徵的關注，不能直接作為智能高低的主要指標。

C：單純形狀多表示反應較少運用墨跡的複雜組織特徵，與本題所問的整合能力方向不符。這是最強誘答，因為它也像是在描述作答方式；但智能較高的關鍵是組織更複雜，不是形狀更單純。

D：從眾反應指常見反應的比例，主要關乎知覺常規性與現實接觸，並非智能較高的特徵。

本題考點：羅夏克墨跡測驗（Rorschach Inkblot Test）的組織活動——能整合多個墨跡特徵的反應通常反映較複雜的知覺組織；人類部分反應（human detail response）與從眾反應（popular response）分別屬內容與常規性線索，不能替代組織活動。

第 9 題

有關精神狀態檢查（mental status examination）之敘述，下列何者錯誤？
  1. （A）可偵測右側腦半球的損傷
  2. （B）可作為初步評估病人心智功能的方法
  3. （C）可評估病人的認知損傷狀態
  4. （D）檢查者可彈性選擇欲檢查之計分項目

答案：（A）

詳解與考點

正解：題眼在「精神狀態檢查」與「錯誤」——判準是其定位為以會談與觀察進行的初步心智功能篩檢，而非定位特定腦半球病灶的神經心理測驗。精神狀態檢查可發現定向感、注意力、記憶、語言與思考等功能異常，但不能據此偵測或定位右側腦半球損傷，故 A 為應選項。

B：精神狀態檢查可在初談或醫療處遇中快速掌握病人的心智功能，正是其基本用途，故非答案。

C：認知損傷狀態是其重要評估面向，例如可藉定向感、注意力與記憶的表現初步辨識異常，故非答案。

D：檢查項目可依轉介問題與病人狀況彈性選擇；彈性不等於任意省略必要項目，仍須記錄足以支持臨床判斷的觀察，故非答案。

本題考點：精神狀態檢查（mental status examination）——用於初步評估心智與認知功能；神經心理衡鑑（neuropsychological assessment）才以特定功能型態協助推論腦部損傷，二者的診斷層次不可混同。

第 10 題

有關電腦輔助的衡鑑方法之敘述，下列何者正確？
  1. （A）電腦版測驗解釋報告與臨床工作者的臨床判斷可達 90%的一致性
  2. （B）電腦版測驗施測者不須具有像傳統測驗施測者的使用資格
  3. （C）傳統測驗的紙筆版與電腦版的測驗結果幾乎相同
  4. （D）使用電腦施測的測驗結果精準、客觀，不須考慮個案的脈絡背景

答案：（C）

詳解與考點

正解：題眼在「電腦輔助衡鑑」——判準是電腦化施測若與紙筆版測量相同構念，通常可取得高度可比的結果，但不能取代專業資格與脈絡判斷。傳統測驗的紙筆版與電腦版結果通常高度相近，故選 C。

A：電腦產出的解釋報告與臨床判斷不應以固定百分比宣稱一致；兩者處理的資料脈絡與專業整合不同。這是最強誘答，因為精確百分比看似有研究依據，錯在把軟體輸出與臨床判斷說成可普遍等同。

B：電腦化不會取消測驗使用資格、知後同意、施測監控與結果解釋的專業責任，故非答案。

D：電腦能使計分與呈現標準化，卻不能自行判斷個案的文化、情緒狀態、作答投入或轉介脈絡；把客觀計分誤當成完整衡鑑即為錯誤。

本題考點：電腦輔助衡鑑（computer-assisted assessment）——紙筆與電腦版本須檢驗測量等值性；電腦化施測（computerized testing）可提升標準化，但心理衡鑑仍需由合格專業人員整合個案脈絡。

第 11 題

有關行為觀察法的敘述，下列何者正確？
  1. （A）敘事紀錄法須將行為清楚地量化
  2. （B）事件紀錄法是等待目標行為發生時，將行為相關的細節記錄下來
  3. （C）評比紀錄法最適合用在經常發生且沒有清楚地開始或結束的外顯行為上
  4. （D）時距紀錄法通常是用來記錄關於抽象行為的整體印象

答案：（B）

詳解與考點

正解：題眼在「事件紀錄法」——判準是以目標行為每次發生為起點，記下其前因、行為與後果等可觀察細節。等待目標行為出現後再記錄相關細節，正是事件紀錄法的做法，故選 B。

A：敘事紀錄法重在以文字保留情境與行為歷程，不以清楚量化為必要條件，故非答案。

C：評比紀錄法適合評定行為或特質的程度，不能以「經常發生且無清楚起訖」作為其最適用的定義；那類行為較常以時距取樣處理。

D：時距紀錄法是在預定時段觀察並記下目標行為是否發生或持續，記錄的是可操作化行為，不是對抽象行為的整體印象。

本題考點：行為觀察（behavioral observation）——事件紀錄法（event recording）依行為事件記錄細節；敘事紀錄法（narrative recording）保留脈絡；時距紀錄法（interval recording）以固定時段取樣可觀察行為。

第 12 題

採取專業性風格（professional style）取向撰寫衡鑑報告時的風格特徵，下列何者正確？
  1. （A）應強調病理現象
  2. （B）應客觀呈現各個測驗結果，保持中立的立場
  3. （C）每個段落要簡短，並且要聚焦於單一的概念上
  4. （D）為讓內容具吸引力，使用誇張的描述是不可避免的

答案：（C）

詳解與考點

正解：題眼在「專業性風格」——判準是報告以清楚、精確、可供跨專業使用的方式傳達結論。每個段落簡短並聚焦單一概念，有助於讀者辨識證據與建議的關聯，故選 C。

A：專業報告應依轉介問題呈現功能與困難，不能預設以病理現象為唯一重點，故非答案。

B：客觀呈現測驗結果是必要條件，但只逐項羅列結果而未整合資料與回答轉介問題，不足以構成專業性風格。這是最強誘答，因為「客觀、中立」聽起來專業；錯在把報告寫成測驗清單，而非有論證的衡鑑結論。

D：誇張描述會削弱資料的精確性與可追溯性，不是增加報告吸引力的正當作法。

本題考點：心理衡鑑報告（psychological assessment report）的專業性風格（professional style）——清楚、精確、段落聚焦並整合資料；客觀性（objectivity）不等於逐項堆列測驗結果，仍須回應轉介問題。

第 13 題

下列關於心理衡鑑報告原則之敘述，何者正確？
  1. （A）篇幅愈長、愈詳盡，報告品質愈好
  2. （B）報告內容應以能回答轉介問題為原則
  3. （C）報告的用詞應以精簡、抽象的專門術語為原則
  4. （D）認知、情緒和性功能是衡鑑報告中常見的主題，足以對受試者形成了解，其他不須贅述

答案：（B）

詳解與考點

正解：題眼在「衡鑑報告原則」——判準是所有資料、解釋與建議都要服務於轉介問題。報告內容應以能回答轉介問題為取捨依據，故選 B。

A：篇幅長不必然代表品質好；不相關的資訊會掩沒重要發現，故非答案。

C：報告應以精簡且讀者可理解的語言撰寫，過度抽象的專門術語會妨礙個案、家屬與轉介人員使用結果，故非答案。

D：認知、情緒與性功能雖常重要，仍不足以自動形成完整理解；是否納入其他資料須由轉介問題、發展史與功能影響決定。

本題考點：心理衡鑑報告（psychological assessment report）——相關性（relevance）以轉介問題為核心；可讀性（readability）要求精確但可理解；資料整合（data integration）不可用篇幅或固定主題取代。

第 14 題

心理衡鑑階段包含：評估轉介問題、獲取與轉介問題相關的知識、資料蒐集及解釋資料。臨床心理師對 上述心理衡鑑階段應有的正確看法是什麼？
  1. （A）應逐步依順序進行
  2. （B）這四階段常是同時發生且互相影響
  3. （C）不須管階段的順序，憑直覺完成
  4. （D）此四階段乃獨立存在，需各自完成

答案：（B）

詳解與考點

正解：題眼在「心理衡鑑階段」——判準是衡鑑為假設導向、反覆修正的歷程，不是單向線性流程。釐清轉介問題會引導資料蒐集，初步資料又可能改變所需知識與問題界定，因此四階段常同時發生且互相影響，故選 B。

本題考點：心理衡鑑歷程（psychological assessment process）——轉介問題（referral question）引導資料蒐集；假設修正（hypothesis revision）使評估、知識取得、蒐集與解釋形成互動循環。

第 15 題

  1. （A）添畫、圖形漸大、圖形簡化
  2. （B）圖形過大、順序紊亂、筆觸過重
  3. （C）波狀線條、圖形過小、以點取代圓
  4. （D）圖形旋轉、閉合困難、續畫

答案：（D）

詳解與考點

正解：題眼在「班達測驗」與「可能有腦傷」——判準是視覺動作整合中出現具臨床意義的結構性錯誤，而非單一筆跡或大小偏好。圖形旋轉、閉合困難與續畫皆可能顯示視覺知覺與動作整合的異常，故選 D。

本題考點：班達視覺動作完形測驗（Bender Visual-Motor Gestalt Test）——圖形旋轉（rotation）、閉合困難（closure difficulty）與續畫（perseveration）可作為神經心理異常的篩檢線索；篩檢結果仍須結合病史與完整心理衡鑑判讀。

第 16 題

Heimberg（1994）認為，在衡鑑社會畏懼症的維持因素時，下列何者最需要進行評估？
  1. （A）人際互動技巧之缺損
  2. （B）與人際威脅有關之認知缺損
  3. （C）安全行為的類型
  4. （D）社交情境中的焦慮強度

答案：（B）

詳解與考點

正解：題眼在「Heimberg（1994）」與「維持因素」——本題限題幹所指的社會畏懼症認知模型作答，判準是個案如何解讀社交威脅及其後果。與人際威脅有關的認知缺損會使個案偏向預期負面評價並維持焦慮，故選 B。社會焦慮之所以持續，關鍵在個案對人際威脅的負向解讀與對負面評價的預期，衡鑑維持因素時應優先評估這組認知歷程。

A：人際互動技巧可能影響社交表現，但不是該模型辨識維持因素時最核心的認知評估焦點，故非答案。

C：安全行為是社會焦慮的重要維持機制，然而本題依題幹所指模型要辨識的是對人際威脅的認知處理，故不選 C。這是最強誘答，因為安全行為確實常見；錯在題目問的是特定模型所優先評估的認知缺損。

D：焦慮強度可描述嚴重度，卻不能單獨說明焦慮如何被負向社交威脅認知維持，故非答案。

本題考點：社會焦慮的認知模型（cognitive model of social anxiety）——負向評價預期（negative evaluation expectancy）與人際威脅認知是維持焦慮的關鍵；安全行為（safety behavior）與症狀強度（symptom severity）需與模型的核心判準區分。

第 17 題

若以 WAIS-III 推估病前功能，下列何種分測驗之組合具有最佳的預測力？
  1. （A）詞彙、常識與圖畫補充
  2. （B）詞彙、圖形設計與矩陣推理
  3. （C）常識、記憶廣度與數符替代
  4. （D）類同、連環圖系與符號搜尋

答案：（A）

詳解與考點

正解：題眼在「WAIS-III」與「病前功能」——判準是選用受目前腦部狀態影響較小的保留型（hold）分測驗。詞彙與常識反映長期累積的語意知識與一般知識，圖畫補充依賴既有的視覺常識辨識，三者都不隨急性腦傷或病程明顯下滑，組合起來對病前智力的預測力最佳，故選 A。

B：圖形設計與矩陣推理較仰賴當下的視覺空間與流體推理表現，受腦部狀態影響的可能性較高，不是本題最佳組合。

C：記憶廣度與數符替代包含注意力、工作記憶與處理速度成分，較容易反映目前認知狀態，故非答案。

D：連環圖系與符號搜尋同樣較依賴處理速度及視覺組織，不能取代長期知識型指標來推估病前功能。

本題考點：病前功能推估（premorbid functioning estimation）——採用受目前腦部狀態影響較小的保留型（hold）分測驗，如詞彙、常識與圖畫補充；易變型分測驗——記憶廣度、數符替代、符號搜尋等反映當下的注意、工作記憶與處理速度；上述為 WAIS-III（Wechsler Adult Intelligence Scale–Third Edition）所用的分測驗名稱，其他版本不可直接套用。

第 22 題

下列何者是存在主義治療學派（existential therapy）與個人中心治療學派（person-centered therapy）的 共同點？
  1. （A）同樣相信人如橡實有其先存的自然潛能，如果獲得適當的條件，就會自我發展為成熟的橡樹
  2. （B）同樣認為每一個人都是獨一無二的，治療師必須進入個人的主體經驗才能完整瞭解一個人
  3. （C）同樣相信面對死亡是人建設性選擇的來源
  4. （D）同樣強調理性力量在追求自由時的重要性

答案：（B）

詳解與考點

正解：題眼在「存在主義」與「個人中心」的「共同點」——判準是兩者都重視個人的主體經驗與獨特存在，而非共享同一套人格發展或死亡觀。兩派皆認為每個人獨一無二，治療師須進入個人的主體經驗才能充分理解，故選 B。

C：面對死亡與有限性是存在主義的重要主題，但不是個人中心治療的核心共同點，故非答案。

D：兩派皆不把理性力量置於治療的唯一中心；存在主義重視選擇與責任，個人中心重視經驗與成長，故非答案。

本題考點：存在主義治療（existential therapy）——關注自由、責任、有限性與主體存在；個人中心治療（person-centered therapy）——重視主觀經驗與自我實現傾向；兩派的共同人本取向在於尊重個體的獨特性。

第 23 題

  1. （A）對於間接溝通型態（indirect communication）文化的個案而言，面對治療師的貫串（congruence）態度 會感到不自在
  2. （B）對個人自主價值的強調等同於對於人類理性（reason）的過度依賴
  3. （C）因為對人文價值的堅持，拒絕以實徵研究（empirical research）來檢證治療效果
  4. （D）治療師有可能因支持個案而讓個案停留在自己的想像世界（imaginative world）中

一位臨床心理師已經約了個案要進行腦神經測驗結果的回饋，由於臨時需要進行危機處理，因此必須臨 時將該項工作委任他人進行，則下列何種委任方式最為恰當？

  2. （B）臨床心理師邀請一位全職實習生為個案進行測驗結果的回饋，因為該實習生已經被該臨床心理師督導 半年
  3. （C）臨床心理師邀請其具有臨床心理師資格的主任為個案進行測驗結果的回饋，雖然該主任對於神經心理 測驗並不熟
  4. （D）由於醫院內沒有受過足夠神經心理衡鑑的其他臨床心理師，因此該臨床心理師與個案另約時間進行測 驗結果回饋

答案：（D）

詳解與考點

正解：題眼在「腦神經測驗結果回饋」與臨時委任——判準是承接者須具備該項神經心理衡鑑及回饋的勝任能力，且避免利益衝突；不能只因職稱、關係或受督導時間而替代專業能力。院內沒有足夠勝任者時，與個案另約由原心理師回饋最適當，故選 D。

本題考點：專業勝任能力（competence）——服務須在受訓與經驗範圍內提供；神經心理衡鑑（neuropsychological assessment）的回饋須能正確整合結果；多重關係（multiple relationships）可能損及專業判斷。

  3. （C）不把聽聞的內容當做評量被督導者的參考

詳解與考點

正解：題眼在「聽聞」且直接督導中未見歧視行為——判準是督導評量與紀錄應以可查證的專業觀察、具體行為及適當程序為基礎。將未經驗證的傳聞寫成被督導者的潛在歧視傾向，既可能不實又造成不公平不利，最不符合倫理，故選 B。
