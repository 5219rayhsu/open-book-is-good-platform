第 1 題

關於為了教育安置所做的心理衡鑑，下列敘述何者錯誤？
  1. （A）除了評估個案的短處，也應評估個案的長處，並給予合宜、可行的建議
  2. （B）除非正規的課程對於個案沒有同等的助益，否則不應建議個案接受特殊教育
  3. （C）建議事項即是本次為了教育安置所做的心理衡鑑之最終產物
  4. （D）應持續追蹤個案，並根據一開始的評估結果修改建議事項

答案：（C）

詳解與考點

考點為教育安置心理衡鑑的程序。錯誤敘述是(C)：建議事項並非「最終產物」，衡鑑應持續追蹤並動態修正建議。陷阱是(B)，最少限制環境原則下，普通課程有同等助益就不建議特教，敘述正確不應選。

第 34 題

依據臺灣「臨床心理師倫理準則與行為規範」 ，有關違反專業倫理的非正式解決之道，下列敘 述何者正確？
  1. （A）臨床心理師若在不知悉倫理守則項目下從事了違反專業倫理的行為，可有一次的豁免權利
  2. （B）臨床心理師若不清楚某一特殊情況或行動過程是否違反專業倫理時，應迴避該項工作
  3. （C）臨床心理師認為其他臨床心理師可能違反專業倫理，優先以非正式解決之道，設法讓該人 注意到倫理的爭議
  4. （D）當服務機構的要求與倫理規範有衝突時，臨床心理師不可進入任何的協商歷程，以維護倫 理規範的完整

答案：（C）

詳解與考點

正解：題眼在「違反專業倫理的非正式解決」——判準是發現同業可能有倫理疑義時，若適當且不致造成傷害，先以直接、非正式的方式提醒並促成改善。C 符合此優先處理原則，故選 C。

A：不知悉倫理規範不能構成違反倫理的豁免。專業人員有持續了解適用規範的責任。

B：遇到倫理不確定處，應尋求督導、同儕諮詢或其他適切協助，不是必然迴避所有相關工作。

D：機構要求與倫理規範衝突時，應設法釐清、溝通並維護倫理責任；禁止任何協商的說法過度絕對。

本題考點：非正式倫理解決（informal resolution）——適當時先提醒同業並促成改善；倫理諮詢（ethical consultation）——不確定時尋求督導或專業協助。本題涉及倫理準則，實際處理仍須依當時適用規範與個案風險判斷。

第 25 題

有關結構家族治療（structural family therapy），下列敘述何者正確？
  1. （A）重視個體從原生家庭的分化過程，使得個體得以承擔其感受、知覺及行動上的個人責任
  2. （B）治療者常以領導者的角色融入家庭，重構家庭的組織及設定界線
  3. （C）治療者透過行動取向的指導及矛盾介入使得家庭的實質問題得以處理解決
  4. （D）常運用雕塑、角色扮演等技術幫助家庭形成一致的溝通

答案：（B）

詳解與考點

正解：題眼在「結構家族治療」——判準是治療師主動加入家庭互動，辨識並重整次系統、權力結構與界線。治療者以領導者身分融入家庭，促成新的互動安排與適當界線，正是結構家族治療的核心，故選 B。

A：強調從原生家庭分化與承擔個人責任，較符合 Bowen 家族系統取向。

C：行動指導與矛盾介入較接近策略取向家族治療；它看似同樣主動，錯在結構取向的主軸是重組結構與界線。

D：雕塑與角色扮演常用於經驗取向家族治療，以促進溝通與情感表達，不是結構取向的代表技術。

本題考點：結構家族治療（structural family therapy）重視家庭結構（family structure）；加入（joining）與界線設定（boundary making）是核心介入；須與 Bowen、策略及經驗取向家族治療區辨。

第 16 題

下列何種疾患最不適合以魏氏記憶量表進行與一般群體的鑑別診斷？
  1. （A）帕金森氏症
  2. （B）長期酒精濫用
  3. （C）重鬱症
  4. （D）思覺失調症

答案：（C）

詳解與考點

正解：題眼在「魏氏記憶量表」與「鑑別診斷」——判準是疾患是否常有具特徵性的記憶缺損型態，可與一般群體比較。重鬱症的認知表現常受情緒、動機與精神動作遲滯影響，記憶表現未必形成可供此量表單獨鑑別的穩定特徵，故 C 最不適合。

A：帕金森氏症可能伴隨執行功能與提取困難，記憶衡鑑可作為神經認知變化的臨床資料之一，故非答案。

B：長期酒精濫用可能與記憶編碼、保持或提取問題有關，記憶量表可協助描述其缺損型態，故非答案。

D：思覺失調症可見認知與記憶功能困難，雖不能只憑單一量表診斷，仍可與一般群體比較其認知表現，故非答案。

本題考點：心理衡鑑中的鑑別診斷（differential diagnosis）——記憶量表用於描述認知功能型態，不能脫離病史與其他衡鑑資料；情緒疾患的表現易受當下症狀影響，單靠記憶分數的鑑別力較低。

第 10 題

下列何者是使用羅夏克墨跡測驗（Rorschach inkblot test）的優點？
  1. （A）能夠評估受試者的潛意識層面
  2. （B）可有效區辨偽裝的妄想型精神分裂症與真正的精神分裂症
  3. （C）計分容易
  4. （D）應用在兒童時，可獲得較長期的信度

答案：（A）

詳解與考點

正解：題眼在「羅夏克墨跡測驗的優點」——此投射性測驗以模糊刺激引出受試者的知覺、聯想與組織方式，可作為探索不易直接陳述的內在心理歷程之一項資料，因此（A）是題目所指優點，故選 A。

B：羅夏克不能有效地用來區辨「偽裝」與「真正」的妄想型思覺失調症；以單一工具作如此確定的診斷鑑別過度延伸。

C：羅夏克的施測、編碼與解釋需受過專業訓練，計分不屬容易。

D：兒童的長期信度不是此測驗的公認優點；發展變化與施測條件都會影響結果。

本題考點：羅夏克墨跡測驗（Rorschach inkblot test）是投射性測驗（projective test）；其資料可補充內在經驗與知覺組織的理解；心理衡鑑（psychological assessment）不可由單一測驗直接做出確診或偽裝判定。
