第 1 題

下列那一種行為觀察記錄法，可適用於多數的行為？
  1. （A）敘事記錄法（narrative recording）
  2. （B）時距記錄法（interval recording）
  3. （C）事件記錄法（event recording）
  4. （D）評比記錄法（ratings recording）

答案：（B）

詳解與考點

正解：題眼在「適用於多數的行為」——行為觀察方法的判準是行為是否頻繁、可計次，以及是否需取得在一段時間內出現與否的代表性樣本。時距記錄法在連續時段中記錄行為是否發生或持續，對多數行為都可調整時距後使用，故選 B。

A：敘事記錄可保留前因後果與情境細節，但耗時且難以長時間、系統性地適用於多數行為。

C：事件記錄法適合界線清楚且頻率不過高的行為；若行為持續很久或發生過於頻繁，逐次記錄會不實用。

D：評比記錄仰賴觀察者的整體判斷，較易受主觀印象影響，不能如時距記錄般提供跨多種行為的系統性取樣。

本題考點：時距記錄法（interval recording）——以時間區段取樣，適用範圍廣；事件記錄法（event recording）——適合可清楚界定且可逐次計數的行為；敘事記錄法（narrative recording）——重視行為脈絡。

第 2 題

關於神經心理衡鑑的敘述，下列何者錯誤？
  1. （A）班達完形測驗可用來篩檢認知功能缺損
  2. （B）Stroop task 可用來篩檢注意力的問題
  3. （C）可用來追蹤認知復健的效果
  4. （D）不適合用來做為診斷的參考

答案：（D）

詳解與考點

正解：題眼在「何者錯誤」與「神經心理衡鑑」——神經心理衡鑑整合病史、行為觀察與測驗表現，可協助辨識認知功能型態、鑑別診斷與追蹤改變，因此說它不適合做為診斷參考是錯誤的，故為應選項。

A：班達完形測驗可提供視覺動作整合與可能認知功能困難的篩檢線索，故此敘述正確，非答案。

B：Stroop 作業可反映選擇性注意與抑制控制的困難，故此敘述正確，非答案。

C：重複施測與臨床資料整合可用於觀察認知復健後的變化，故此敘述正確，非答案。

本題考點：神經心理衡鑑（neuropsychological assessment）——協助描述認知功能、鑑別診斷與追蹤成效；Stroop 作業（Stroop task）——常用於觀察抑制控制與選擇性注意。

第 3 題

下列何者不是臨床心理師在心理衡鑑中選用心理測驗時應考量的主要因素？
  1. （A）施測者對測驗的偏好
  2. （B）測驗的心理計量特性
  3. （C）測驗能否提供診斷上的參考
  4. （D）測驗能否幫助提供治療上的相關建議

答案：（A）

詳解與考點

正解：題眼在「不是」選用心理測驗的主要因素——心理衡鑑應由轉介問題、測驗的心理計量品質，以及結果能否支持診斷與處遇決策來選擇工具；施測者個人偏好不能凌駕這些專業判準，故選 A。

B：信度、效度、常模與適用性等心理計量特性會影響結果可解釋性，是主要考量，非答案。

C：測驗能否對鑑別診斷或診斷假設提供資訊，是選用時的重要考量，非答案。

D：測驗結果能否協助形成治療目標、介入建議或轉介方向，也是心理衡鑑的實務價值，非答案。

本題考點：心理衡鑑（psychological assessment）——依轉介問題整合適切工具與臨床資料；心理計量特性（psychometric properties）——信度、效度與適用性是測驗選擇的核心；處遇規劃（treatment planning）——衡鑑結果應能回應實際決策需要。

第 4 題

下列何者比較不可能與高偽陽性（false positive）同時出現？
  1. （A）低基準率（base rate）
  2. （B）低敏感度（sensitivity）
  3. （C）低特異度（specificity）
  4. （D）高切截點（cutoff）

答案：（D）

詳解與考點

正解：題眼在「高偽陽性」與「比較不可能同時出現」——偽陽性是實際無疾患者被判為陽性；低特異度會直接增加偽陽性，低基準率也會使陽性結果中偽陽性的比例升高。相對地，提高切截點通常使判為陽性的門檻更嚴格、減少陽性判定，故高切截點較不可能與高偽陽性並存，選 D。

A：在低基準率族群，即使測驗表現不差，陽性結果中仍可能有較高比例是假陽性，故非答案。

B：低敏感度主要增加偽陰性，並非高偽陽性的直接原因；但它不必然如高切截點般與高偽陽性呈反向關係，因此不是本題最佳答案。

C：特異度低表示對無疾患者的正確排除能力差，方向上就是偽陽性增加，故非答案。這是最強誘答的反面判準：看到「低特異度」應直接連到高偽陽性。

本題考點：偽陽性（false positive）——無疾患者被判為陽性；特異度（specificity）——降低時偽陽性增加；切截點（cutoff）——提高通常使陽性判定更嚴格，並傾向降低偽陽性。

第 5 題

有關投射測驗使用的現況，下列何者錯誤？
  1. （A）羅夏克墨漬測驗在美國臨床機構使用頻率的排名從 1935 年以來一直在前十名之列
  2. （B）臨床專業強調量化的紙筆測驗在實務工作中的重要性，投射測驗的重要性因而下降
  3. （C）美國兒童臨床心理師比較喜歡使用投射測驗
  4. （D）美國臨床實務界認為投射測驗需要花費的時間及金錢成本過高，不符合臨床上的需求

答案：（C）

詳解與考點

正解：題眼在「投射測驗使用的現況」與「何者錯誤」——判準是區分臨床工作者對投射測驗的使用偏好，與其實際使用成本及量化測驗興起的趨勢。兒童臨床心理師並非因服務兒童就比較偏好投射測驗；兒童的評估仍須依轉介問題、發展程度與工具的信效度選擇，故 C 為錯誤敘述、應選 C。

A：羅夏克墨漬測驗長期是知名且持續被使用的投射測驗之一；此項是在描述其歷史使用地位，並不違反題目所採的現況整理，故非答案。

B：臨床實務日益重視可量化、可比較的紙筆測驗，確會相對削弱投射測驗的中心性，故非答案。

D：投射測驗常需較長施測、計分與解釋時間，成本與效率的考量確是臨床使用上的限制，故非答案。

本題考點：投射測驗（projective tests）的使用現況——工具選擇須看轉介目的與證據基礎，不由個案年齡直接決定；量化心理測驗（objective tests）的可比較性與效率提升其臨床重要性；羅夏克墨漬測驗（Rorschach Inkblot Test）雖持續使用，仍須注意施測與解釋成本。

第 6 題

關於魏氏智力測驗的工作記憶指數（Working Memory Index, WMI），下列敘述何者正確？
  1. （A）與個案的學業表現及知識廣度無關
  2. （B）該指數容易受焦慮的影響而得低分
  3. （C）反映的是解決視覺空間問題的心理及動作速度能力
  4. （D）包含算術、記憶廣度、數符替代三個分測驗

答案：（B）

詳解與考點

正解：題眼在「工作記憶指數」——判準是暫時保持並心智操作資訊的能力，而非知識廣度、視覺空間能力或處理速度。焦慮會占用注意資源並干擾心智操作，因此 WMI 容易受焦慮影響而降低，故選 B。

A：WMI 與學習和學業表現有關，尤其會影響多步驟指令、心算與新資訊處理；它不是與學業表現及知識廣度完全無關，故非答案。

C：解決視覺空間問題屬知覺推理或視覺空間能力，心理與動作速度則屬處理速度，兩者都不是 WMI 的核心構念。

D：數符替代測量的是處理速度，不是工作記憶的分測驗；這是最強誘答，因為算術與記憶廣度確與工作記憶相關，錯在把另一指數的分測驗併入。

本題考點：工作記憶（working memory）——暫存與操作資訊的能力；焦慮（anxiety）——可藉注意資源分散影響測驗表現；處理速度（processing speed）與視覺空間能力（visuospatial ability）——須與工作記憶區分。

第 7 題

下列那一項心理測驗原始編製的目的，用來評估個案的內在需求及其對外在環境的反應？
  1. （A）班達完形測驗
  2. （B）魏氏智力測驗
  3. （C）健康性格習慣量表
  4. （D）主題統覺測驗

答案：（D）

詳解與考點

正解：題眼在「內在需求」及「對外在環境的反應」——這正是以含糊刺激引出個案主題、動機與人際知覺的投射性評估目的。主題統覺測驗要求個案依圖片編故事，可從故事主題理解其需求與環境壓力的互動，故選 D。

A：班達完形測驗主要評估視覺動作統整與可能的神經心理功能困難，不以內在需求及環境反應為原始目的。

B：魏氏智力測驗評估多面向認知能力與智力表現，並非透過故事內容探究需求。

C：健康性格習慣量表屬結構化的自陳式人格評量，不是以投射方式呈現內在需求。

本題考點：主題統覺測驗（Thematic Apperception Test, TAT）——藉故事內容探索需求、衝突與人際知覺；投射測驗（projective test）——以較含糊刺激引出個案的主觀組織；結構化測驗（objective test）——依固定題目與計分方式蒐集資料。

第 8 題

依據大多數學者與 Groth-Marnat（2009）建議的會談策略使用方式，下列敘述何者錯誤？
  1. （A）先以開放式問句開始會談
  2. （B）運用澄清的方式可以發覺隱含的訊息
  3. （C）面質的目的主要是為了直接挑戰個案
  4. （D）可採用口語或非口語的方式鼓勵個案進行自我探索

答案：（C）

詳解與考點

正解：題眼在「會談策略」及「何者錯誤」——判準是介入是否用來促進個案理解與自我探索，而非為了對個案施壓。面質可指出陳述、情緒與行為間的不一致，但目的在協助個案覺察，不是直接挑戰個案，故 C 為錯誤敘述、應選 C。

A：以開放式問句開場能讓個案用自己的脈絡描述困擾，有助建立初步理解，故非答案。

B：澄清能確認語意、具體化含混內容，並可能呈現個案未明說的訊息，故非答案。

D：適當的口語與非口語鼓勵可維持會談的安全感與敘說流動，促進個案探索，故非答案。

本題考點：會談（clinical interview）——先以開放式問句建立敘事脈絡；澄清（clarification）——確認與具體化訊息；面質（confrontation）——溫和呈現不一致以促進覺察，不是攻擊或直接挑戰。

第 9 題

根據羅夏克墨漬測驗 Exner’s Comprehensive System，組成 WSum6 的六項特殊計分中，下列那一 項指標是加權計分最重的？
  1. （A）FABCOM
  2. （B）CONTAM
  3. （C）ALOG
  4. （D）INCOM

答案：（B）

詳解與考點

正解：題眼在 Exner 綜合系統（Comprehensive System）的「WSum6」與「加權計分最重」——這是在辨識特殊認知計分的既定權重，不是比較名詞聽起來多嚴重。依該系統的權重，污染反應 CONTAM 的加權為 7，且是六項中唯一不分計分層級、恆居最高的一項，故選 B。

A：FABCOM 指把兩個以上物件描述成不可能或荒謬的關係（如兩隻動物一起舉重），加權依層級為 4 或 7，只有在第二層級才與 CONTAM 相當，並非恆為最重者。

C：ALOG 指以牽強的推理說明自己的反應理由（自閉邏輯），加權 5，低於 CONTAM。

D：INCOM 指單一物件的特徵或活動彼此不相容（如長了四隻手的人），加權依層級為 2 或 4，屬六項中偏低者；最強誘答在於它與 FABCOM 同屬結合類異常，不能只憑類別名稱推定權重。

本題考點：羅夏克墨漬測驗綜合系統（Exner’s Comprehensive System）——以明確規則編碼反應；WSum6——六項特殊認知計分的加權總和；污染反應（CONTAM）——兩個以上不相容的意象重疊成單一反應，加權最高。

第 10 題

WISC-Ⅳ刪除語文與作業智商的最主要原因：
  1. （A）節省計算分數及解釋的時間
  2. （B）增加此測驗的信度及效度
  3. （C）它們都不是在測量單一的能力
  4. （D）語文及作業智商不具有臨床解釋的功能

答案：（C）

詳解與考點

正解：題眼在 WISC-IV「刪除語文與作業智商的最主要原因」——判準是新版指數架構是否比二分法更能反映認知能力的多面向性。語文智商與作業智商都由異質分測驗組成，不能視為各自單一、純粹的能力，因此改以較具構念意義的指數呈現，故選 C。本題涉及特定量表版本的架構，解釋時須以 WISC-IV 的手冊為準。

A：計分效率可能是附帶效益，卻不是取消二分智商的主要心理計量理由。

B：改版不能概括說成必然增加所有分數的信度與效度；核心理由是舊二分架構的構念限制。

D：語文與作業智商過去確有臨床解釋功能，錯在把「不是單一能力」說成「沒有解釋功能」。這是最強誘答，因為它抓到新版不再主打二分智商，卻把原因講得過頭。

本題考點：WISC-IV（Wechsler Intelligence Scale for Children–Fourth Edition）——以指數架構描述兒童認知能力；構念效度（construct validity）——分數是否反映可辨識的能力構念；語文／作業二分法——因各自非單一能力而不再作為主要架構。

第 11 題

個案在算術測驗表現不規律，難的題目做對、容易的題目做錯，但其他能力測驗表現穩定。有關 其問題，下列推論何者適當？
  1. （A）因個案算術表現不穩定，故無法排除個案有數學學習困難
  2. （B）因個案其他能力表現穩定，故沒有數學學習困難
  3. （C）因個案算術表現不穩定，故一定是猜的
  4. （D）因個案算術表現不穩定，故一定有注意力持續的問題

答案：（A）

詳解與考點

正解：題眼在「難題做對、易題做錯」且「其他能力穩定」——判準是單一分測驗反應不規律只能提示需進一步釐清，不能直接推出特定原因或排除學習困難。算術表現不穩定仍可能涉及數學學習困難、注意、焦慮、理解策略或偶發因素，故尚無法排除數學學習困難，選 A。

B：其他能力穩定不等於數學能力必然沒有特異困難；跨測驗穩定不能取代對數學表現的進一步衡鑑。

C：不規律作答不必然是猜測，難題答對本身也不能證明猜測。

D：注意力持續問題可能是待檢驗的假設，但「一定有」超出現有資料；這是最強誘答，因為注意力確會造成表現波動，錯在把可能性當成定論。

本題考點：測驗行為觀察（test behavior observation）——不規律反應要納入解釋；鑑別假設（differential hypothesis）——由資料提出並再檢驗，不可直接定論；數學學習困難（mathematics learning difficulty）——須結合多元資料判定。

第 12 題

班達完形測驗對下列何種腦傷類型較為敏感？
  1. （A）右頂葉腦傷與廣泛性腦傷
  2. （B）右頂葉腦傷與左顳葉腦傷
  3. （C）左頂葉腦傷與廣泛性腦傷
  4. （D）廣泛性腦傷與左顳葉腦傷

答案：（A）

詳解與考點

  1. （A）兩次測量間的時間間隔對再測信度的影響很大
  2. （B）主要缺點之一在於可能會有練習效果
  3. （C）可用 Chronbach’s alpha 來取代
  4. （D）折半信度的基本概念與再測信度不同

詳解與考點

正解：題眼在「再測信度」與「何者錯誤」——判準是同一工具在不同時間點的一致性，必須以兩次施測結果的關聯估計。Cronbach’s alpha 衡量的是單次施測內各題項的內部一致性，不能取代再測信度，故 C 為錯誤敘述、應選 C。

D：折半信度比較同一次測驗內兩半題項的一致性，再測信度比較兩個時間點，基本概念不同，故非答案。

第 23 題

在理情行為治療（Rational Emotive Behavior Therapy, REBT）的 A-B-C 架構中，ABCDEF 所代表 意義，下列何者正確？
  1. （A）A 是誘發事件（Activating event）、E 是效果（Effect）、F 是感受（Feeling）
  2. （B）B 是行為（Behavior）、D 是駁斥（Disputing）、E 是情緒（Emotion）
  3. （C）A 是前置事件（Antecedent）、C 是結果（Consequence）、F 是追蹤（Follow up）
  4. （D）B 是信念（Belief）、C 是認知（Cognition）、D 是辯論（Debate）

答案：（A）

詳解與考點

正解：題眼在 REBT 的「A-B-C 架構」延伸到 ABCDEF——判準是 Ellis 模式中各字母的功能：A 為誘發事件（Activating event），B 為信念（Belief），C 為結果（Consequence），D 為駁斥（Disputing），E 為效果（Effect），F 為新的感受（Feeling）。因此 A 的配對正確，故選 A。

B：B 不是行為而是信念；E 不是情緒而是經駁斥後的效果，故非答案。

C：A 可泛稱前置情境，但本模式的正式名稱是誘發事件；F 也不是追蹤，而是新的感受，故不正確。

D：B 為信念正確，但 C 應是信念帶來的情緒與行為結果，不是單指認知；D 也應是駁斥而非泛稱辯論。這是最強誘答，因為它保留了兩個相近詞，錯在 C、D 的精確功能。

本題考點：理情行為治療（Rational Emotive Behavior Therapy, REBT）——以非理性信念為介入焦點；ABCDEF 模式——從誘發事件、信念、結果到駁斥與新效果；駁斥（disputing）——檢驗並修正不合理信念。

  3. （C）前者強調生命空無，後者強調既有潛能
  4. （D）前者強調靈性修行，後者強調人際調和

答案：（C）

詳解與考點

正解：題眼在存在主義與人本主義的「差別」——判準是兩者對人類困境的核心焦點。存在主義面對自由、孤獨、死亡與生命空無等存在焦慮；人本主義較強調人具有成長、選擇與實現既有潛能的傾向，故選 C。

A：存在主義不只強調自由，也強調自由選擇伴隨的責任；把責任完全歸給人本主義是錯置。

B：存在主義確重視選擇，但人本主義的重點不是單純環境，而是促成個案成長的關係條件與潛能。

D：靈性或人際調和可在某些取向中被討論，卻不是區分這兩個取向的核心判準。

本題考點：存在主義治療（existential therapy）——處理存在焦慮與生命意義；人本主義治療（humanistic therapy）——相信個案具有成長與自我實現潛能；存在空無（existential emptiness）——是本題用以區別兩取向的關鍵。

第 25 題

下列那一個心理治療學派認為行為是目標導向的（behavior is goal-oriented）？
  1. （A）認知治療學派
  2. （B）精神分析學派
  3. （C）阿德勒學派
  4. （D）行為學派

答案：（C）

詳解與考點

正解：題眼在「行為是目標導向的」——判準是何種學派把行為理解為個體為了追求目的、克服自卑或建立生活風格所作的選擇。阿德勒學派（Adlerian therapy）認為行為具有目的性，而非只是由過去經驗或外在刺激機械決定，故選 C。

A：認知治療重視自動化思考、核心信念與認知扭曲如何影響情緒及行為；雖會討論目標設定，並不以「行為目標導向」作為核心的人性觀。

B：精神分析學派著重無意識衝突、早期經驗與心理結構的動力，不能以阿德勒的目的論概括。

D：行為學派主要以學習歷程、增強與制約解釋行為；它同樣可能使用行為目標，但理論焦點不是行為內在的目的性。

本題考點：阿德勒學派（Adlerian therapy）——以目的論（teleology）理解行為，重視個體追求目標與其生活風格；精神分析（psychoanalysis）偏向心理動力；行為治療（behavior therapy）偏向學習原理。

第 26 題

在精神分析中，超我（superego）的意涵最接近下列何者？
  1. （A）操作策略
  2. （B）現實條件
  3. （C）自然力量
  4. （D）目標規範

答案：（D）

詳解與考點

正解：題眼在「超我」——判準是佛洛伊德結構理論中，哪一部分內化社會與父母的道德要求。超我（superego）代表良心與理想自我，以應然的目標、規範評價欲望和行為，故選 D。

A：操作策略是為達成目標所採取的方法，並非心理結構理論中的超我功能。

B：現實條件最接近自我（ego）遵循現實原則、在本我需求與外界限制間協調的工作。

C：自然力量較接近本我（id）的本能衝動與快樂原則，與超我的道德約束相反。

本題考點：人格結構理論（structural model）——本我（id）遵循快樂原則；自我（ego）遵循現實原則；超我（superego）內化道德規範與理想。

第 27 題

有關存在治療對焦慮的觀點，下列敘述何者錯誤？
  1. （A）死亡、自由、選擇、孤獨與無意義是生命深處的結構與既定事實
  2. （B）當個體遭逢存在的既定事實時，便會產生焦慮
  3. （C）焦慮可以是種改變的訊號，能成為改變的動力、刺激人的成長
  4. （D）因所有焦慮都是源於生命的必然處境，故治療目標不需聚焦於焦慮議題

答案：（D）

詳解與考點

正解：題眼在「存在治療」與「何者錯誤」——判準是存在焦慮雖源於生命不可避免的處境，治療仍須協助個案覺察、承擔並回應它。把焦慮的必然性推成「無須聚焦焦慮議題」，錯把不可消除當成不可處理，故 D 為應選項。

A：死亡、自由與選擇、孤獨及無意義，都是存在治療用以描述人類終極關懷的基本面向，故非答案。

B：個體意識到這些既定事實時可能產生存在焦慮，符合存在取向的觀點。

C：焦慮也可成為覺察與改變的訊號；存在治療不只將其視為病理症狀，故非答案。

本題考點：存在治療（existential therapy）——存在既定事實（givens of existence）可引發焦慮；存在焦慮（existential anxiety）可被覺察與轉化為成長動力；治療重點是對自由、選擇與責任的回應。

第 28 題

下列何者符合存在治療學派（existential therapy）的團體治療取向？
  1. （A）團體提供其成員相互模仿學習的有利條件
  2. （B）團體討論將讓個案面對其理性上的缺損
  3. （C）團體中成員將面對生命的矛盾，如我們無可避免地必須做出選擇
  4. （D）團體提供了一個讓個案可以找到適合自己的朋友

答案：（C）

詳解與考點

正解：題眼在「存在治療」的團體取向——判準是團體如何讓成員直接面對自由、選擇、責任與生命限制。團體中的互動能使成員看見自己無法逃避選擇及其後果，正對應存在取向的人類處境，故選 C。

A：相互模仿學習較符合社會學習與行為取向對團體的功能描述，不是存在治療的核心。

B：存在治療關注的不是「理性上的缺損」，而是個案如何活在其有限、自由且須負責的處境中。

D：建立友誼可能是團體附帶的收穫，但不是存在團體的主要治療目標。這是最強誘答，因為團體確能提供關係支持，錯在把支持效果誤當成存在取向的核心工作。

本題考點：存在團體治療（existential group therapy）——透過此時此地關係面對自由、選擇、責任與限制；團體凝聚力（group cohesion）可支持治療，但不等於學派的核心判準。

第 29 題

下列何者是存在治療學派（existential therapy）對於人之限制與生命中悲劇的看法？
  1. （A）身心症狀的來源
  2. （B）人類處境的基本面向
  3. （C）因缺乏正向信念所造成的
  4. （D）必須加以避免防治的

答案：（B）

詳解與考點

正解：題眼在「人之限制與生命中悲劇」——判準是存在治療是否把死亡、孤獨、自由及意義問題視為普遍人類處境。這些並非個人失敗或單一症狀的來源，而是人類處境的基本面向，故選 B。

A：身心症狀可受壓力與心理因素影響，但不能將所有生命限制化約為症狀來源。

C：正向信念不足是某些認知取向可能探討的因素；存在治療不把悲劇單純歸因於信念不足。

D：存在取向不主張逃避不可避免的限制，而是協助個案以真誠的方式面對並作出選擇。

本題考點：存在治療（existential therapy）——人類處境（human condition）包含不可避免的限制；終極關懷（ultimate concerns）不是待防治的病理，而是需要被面對與賦予意義的生命課題。

第 30 題

下列何種心理治療學派以選擇理論（choice theory）作為其人格理論？
  1. （A）行為治療
  2. （B）認知治療
  3. （C）現實治療
  4. （D）多元模式治療

答案：（C）

詳解與考點

正解：題眼在「選擇理論」——判準是該理論所屬的治療學派。選擇理論（choice theory）是現實治療（reality therapy）的人格與行為觀基礎，強調個體對自身行為及滿足需求的選擇負責，故選 C。

A：行為治療以古典制約、操作制約與社會學習等原理為主要基礎，不以選擇理論命名。

B：認知治療著重自動化思考、認知基模與信念的修正，與選擇理論的學派來源不同。

D：多元模式治療整合多個行為與經驗面向，並非以選擇理論作為單一人格理論。

本題考點：現實治療（reality therapy）——以選擇理論（choice theory）理解行為；基本需求（basic needs）與負責任的選擇是其重要概念。

第 31 題

進行臨床心理研究時，常將第一型錯誤（type I error, α）設為.05，請問 α = .05 的意義是： （註：H0 為虛無假設；H1 為替代假設）
  1. （A）當 H0 為真時，我們錯誤「接受」H1 的機會為 95%
  2. （B）當 H1 為真時，我們錯誤「接受」H0 的機會為 95%
  3. （C）當 H0 為真時，我們錯誤「拒絕」H0 的機會為 5%
  4. （D）當 H1 為真時，我們錯誤「拒絕」H1 的機會為 5%

答案：（C）

詳解與考點

正解：題眼在「第一型錯誤」與「α＝.05」——判準是第一型錯誤定義為虛無假設為真卻將它拒絕。α 是此錯誤的機率；代入 α＝.05，即當 H0 為真時，錯誤拒絕 H0 的機會為 5%，故選 C。

A：當 H0 為真卻接受 H1，實質上就是錯誤拒絕 H0，但機率應為 5% 而非 95%，方向與數值皆錯。

B：當 H1 為真卻接受 H0 是第二型錯誤（type II error，β），不由 α 直接表示。

D：當 H1 為真卻拒絕 H1，同樣是在描述未偵測到真實效果的情況，較接近第二型錯誤而非第一型錯誤。

本題考點：第一型錯誤（type I error）——H0 為真而拒絕 H0，機率為 α；第二型錯誤（type II error）——H1 為真而未拒絕 H0，機率為 β；顯著水準（significance level）是事先設定的 α。

第 32 題

以關注-安慰劑（attention-placebo）為療效研究的控制組，下列敘述何者錯誤？
  1. （A）可以避免隨機分派個案的麻煩
  2. （B）可以排除某些可能影響療效的混淆因素
  3. （C）仍可能會產生其他的混淆因素
  4. （D）在操作上應避免加入療效已獲證實的治療方法

答案：（A）

詳解與考點

正解：題眼在「關注—安慰劑控制組」與「何者錯誤」——判準是此控制設計仍以隨機分派維持組間可比性，藉由相近的接觸與關注控制非特異性因素。它不能免除隨機分派，故 A 為應選項。

B：關注—安慰劑組可控制治療師注意、期待及接觸時間等非特異性因素，因此能排除部分混淆。

C：即使設有這類控制組，仍可能有未控制的治療成分或期待差異，故非答案。

D：若控制組加入療效已獲證實的特定治療技術，便難以分辨實驗治療的特異效果；應避免此種污染。

本題考點：關注—安慰劑控制（attention-placebo control）——控制注意與期待等非特異性治療因素；隨機分派（random assignment）仍是內在效度的重要程序；治療污染（treatment contamination）會削弱組間比較。

第 33 題

有關動機式晤談（motivational interviewing）的敘述，下列何者正確？
  1. （A）人本主義、個案中心、非指導性的治療取向
  2. （B）個案在治療中的改變，是依序經歷五個階段
  3. （C）採用面質、挑戰的方式處理抗拒
  4. （D）起初是用於治療酗酒的短期介入模式

答案：（D）

詳解與考點

正解：題眼在「動機式晤談」的起源——判準是其最初的臨床用途，而非相近治療模式的特徵。動機式晤談（motivational interviewing）起初發展為處理酒精使用問題的短期介入模式，故選 D。

A：人本與個案中心取向強調非指導性；動機式晤談雖重視同理與自主性，仍是有方向地引出改變談話的合作式晤談，不能等同於完全非指導性。

B：五階段的依序改變是跨理論模式（transtheoretical model）的改變階段概念，不是動機式晤談本身的定義。這是最強誘答，因為兩者都用於促進改變，錯在把改變階段模型當成晤談方法。

C：動機式晤談避免以面質或挑戰處理抗拒，會以反映、肯定與探索矛盾來降低對立。

本題考點：動機式晤談（motivational interviewing）——採合作、同理且具方向性的方式引出改變談話（change talk）；抗拒處理（resistance handling）重在避免對抗；改變階段（stages of change）屬跨理論模式。

第 34 題

有關壓力免疫訓練（Stress Inoculation Training）之內涵與特色，下列敘述何者正確？
  1. （A）從治療初期開始，就持續讓案主面對與因應強烈刺激以增加壓力耐受性
  2. （B）在辨識與駁斥非理性想法上，直接面質壓力經驗
  3. （C）第一階段是技巧學習與鞏固階段（skill acquisition & consolidation phase）
  4. （D）強調修正個人在壓力情境中的信念與自我陳述，以改善因應壓力的能力

答案：（D）

詳解與考點

正解：題眼在「壓力免疫訓練」——判準是其是否協助個案辨識壓力下的認知與自我陳述，並練習較有效的因應技能。壓力免疫訓練（stress inoculation training）會修正不利的信念與自我對話，以提升因應能力，故選 D。

A：一開始持續面對強烈刺激較像洪水法；壓力免疫訓練通常循序建立因應資源，不以強烈暴露作為起點。

B：辨識與駁斥非理性想法可見於認知治療，但「直接面質壓力經驗」不是壓力免疫訓練的核心特色。

C：技巧學習與鞏固是中間階段；初期先是概念化階段，協助個案了解壓力及其因應模式。

本題考點：壓力免疫訓練（stress inoculation training）——概念化（conceptualization）、技能取得與演練（skill acquisition and rehearsal）、應用與後續追蹤（application and follow-through）三階段；自我陳述（self-statements）是重要介入標的。

第 35 題

個案罹患腫瘤，術後接受化療，醫護團隊觀察個案與母親關係緊張、常因拒絕進食而發生口角， 照會臨床心理師評估處遇，針對情緒需求，下列何種處遇方式較不適切？
  1. （A）同理個案希望被母親了解的心情
  2. （B）引導個案思考母親生氣的可能原因，促進溝通
  3. （C）同理個案因腫瘤、化療等因素導致味覺改變，進食上的困難是旁人所難以了解的
  4. （D）教導個案進食的重要性，以減少口角發生的頻率

答案：（D）

詳解與考點

正解：題眼在腫瘤化療、拒絕進食與「針對情緒需求較不適切」——判準是先理解病人身體變化與關係壓力，再促進情緒表達與溝通。直接教導進食的重要性把焦點移到勸導行為，未先處理病人的感受、味覺改變和母子衝突，故 D 為應選項。

A：同理病人想被母親理解的需要，有助於建立會談關係並釐清衝突中的情緒。

B：在充分同理後，引導病人思考母親生氣的可能原因可增加觀點取替，促進溝通，故非答案。

C：化療與疾病可能造成味覺及進食困難；承認旁人不易理解這份經驗，符合情緒支持與疾病調適的需要。

本題考點：醫療心理處遇（health psychology intervention）——先評估並同理疾病經驗與情緒需求；觀點取替（perspective taking）可促進家屬溝通；心理介入不宜以單向勸導取代情緒處理。

第 36 題

以傳統系統減敏感法（systematic desensitization）為依據的暴露治療法，包含下列那二個類型？
  1. （A）現場重現法（in vivo）與洪水法
  2. （B）洪水法與眼動減敏重建法
  3. （C）想像驗證法與現場重現法
  4. （D）洪水法與想像驗證法

答案：（A）

詳解與考點

正解：題眼在「以傳統系統減敏感法為依據」——判準是暴露治療中由恐懼刺激的實際接觸或高強度持續接觸所構成的類型。現場重現法（in vivo exposure）與洪水法（flooding）都屬行為暴露技術，故選 A。

B：眼動減敏與歷程更新法是另一種創傷治療取向，不能和洪水法併列為傳統系統減敏感法的兩類暴露。

C：想像暴露可用於暴露治療，但「想像驗證法」不是本題所問的標準類型名稱；本組也漏掉洪水法。

D：洪水法雖正確，另一項「想像驗證法」名稱不當，故整組不成立。

第 37 題

下列何者不是 Aaron T. Beck 所提出的憂鬱認知三角（cognitive triad）之成分？
  1. （A）對未來抱持無望的信念
  2. （B）對自己抱持負向的信念
  3. （C）對過去抱持負向的信念
  4. （D）對世界抱持負向的信念

答案：（C）

詳解與考點

正解：題眼在 Beck 的「憂鬱認知三角」與「不是」——判準是三角固定指向自己、世界與未來。它不以「過去」構成三角的一角，故 C 為應選項。

A：對未來無望是憂鬱認知三角的未來向度，故非答案。

B：負向自我觀是三角中的自己向度。

D：負向世界觀是三角中的世界或經驗向度，故非答案。

本題考點：憂鬱認知三角（cognitive triad）——負向看待自己（self）、世界（world）與未來（future）；自動化思考（automatic thoughts）是認知治療評估與修正的主要材料。

第 38 題

目前對自閉症兒童的治療方案中，多半包含訓練父母來教導孩子，效果良好主要來自下列何者？
  1. （A）父母提供的酬賞比較新奇、多樣化
  2. （B）父母可以在多種情境中教導
  3. （C）父母可採用較嚴格、權威的方式來下指令
  4. （D）父母可以自行訂定目標行為

答案：（B）

詳解與考點

正解：題眼在訓練父母教導孩子的「效果良好主要來自」——判準是技能能否跨情境、跨時間被反覆運用。父母能在日常生活的多種自然情境中提供練習與回饋，因而促進學習的類化，故選 B。

A：酬賞的新奇或多樣化未必是介入有效的主要機制；關鍵在一致、適切地安排學習機會。

C：較嚴格或權威的指令並非親職訓練的效益來源，且可能妨礙親子互動與合作。

D：目標行為通常應依個別孩子的功能性需求、治療目標與專業協作設定，不能把家長自行訂定視為主要療效機制。

本題考點：親職訓練（parent training）——自然情境教學（naturalistic teaching）增加練習機會；類化（generalization）是將所學行為帶到不同人、地與情境；自閉症類群障礙症（autism spectrum disorder）介入重視個別化與家庭合作。

第 39 題

臺灣「臨床心理師倫理準則與行為規範」中，下列何者屬於專業責任與價值的範疇？
  1. （A）社會大眾對臨床心理專業的信任是臨床心理專業能夠貢獻於社會的基礎
  2. （B）臨床心理專業的存在條件在於其嚴格的科學知識與標準化操作
  3. （C）臨床心理師與其他專業是競爭關係，因此必須隨時突顯本身的優越價值
  4. （D）臨床心理師應認識到個人的專業作為由其個人自行負擔責任，不至影響整個專業的形象

答案：（A）

詳解與考點

正解：題眼在題幹所指倫理準則的「專業責任與價值」——判準是臨床心理師是否維護專業公信力，並讓專業得以服務社會。社會大眾的信任確是專業能發揮社會貢獻的基礎，故選 A。本題依題幹所指準則用語作答，倫理規範的適用仍須以現行正式文本為準。

B：科學知識與標準化操作很重要，但將專業存在條件化約為此二者，遺漏倫理責任、勝任能力與公共信任。

C：臨床心理師應與其他專業合作以促進病人福祉，不以競爭和突顯優越性作為專業責任。

D：個人的專業行為會影響社會對整個專業的信任；說成不影響專業形象，方向講反了。

本題考點：專業責任（professional responsibility）——維護公眾信任與專業聲譽；跨專業合作（interprofessional collaboration）服務病人福祉；倫理規範（ethical standards）須依現行正式文本適用。

第 40 題

有關行為衡鑑，下列敘述何者正確？
  1. （A）相當仰賴自陳式問卷來收集資料
  2. （B）因認知自陳式問卷信效度低，因此不主張採用
  3. （C）只關注於個案如何表達，甚於他/她所表達的內容
  4. （D）關注情境因素甚於特質因素

答案：（D）

詳解與考點

正解：題眼在「行為衡鑑」——判準是以可觀察行為與其發生情境、前因後果作為分析單位，而非把穩定人格特質當作主要解釋。行為衡鑑特別關注情境因素甚於特質因素，故選 D。

A：自陳可作為補充資料，但行為衡鑑不會相當仰賴自陳問卷，而會結合直接觀察、訪談與行為紀錄。

B：不主張只因自陳問卷信效度低就一概排除；是否使用應看轉介問題、測量目的與多方法資料的整合。

C：只關注表達方式而輕忽內容，不足以進行功能分析；行為衡鑑須了解行為本身及其情境功能。

本題考點：行為衡鑑（behavioral assessment）——功能分析（functional analysis）檢視前因、行為與後果；情境因素（situational factors）通常比人格特質更具優先性；多方法衡鑑（multimethod assessment）可整合自陳與觀察資料。
