第 1 題

在進行學童的教育安置計畫時，下列那一項不是首要考量的因素？
  1. （A）學童能力
  2. （B）家長需求
  3. （C）教師個人特性
  4. （D）學校的規模

答案：（D）

詳解與考點

正解：題眼在教育安置的「首要考量」——判準是安置是否回應學童的個別能力與教育需求。學校規模本身不能直接判斷安置是否適切，故 D 為不是首要考量的選項。

A：學童能力決定所需支持、課程調整與安置選擇，屬核心資料。

B：家長需求與家庭可配合的支持條件會影響安置可行性，需納入協作。

C：教師個人特性會影響支持與教學能否落實，雖非唯一依據，仍比單純校規模更具教育意義。

本題考點：教育安置（educational placement）——以學童的個別需求與能力為中心；家庭及教學支持條件須一併評估；機構規模不是首要判準。

第 2 題

下列那一個分測驗，在魏氏成人智力測驗第四版是核心測驗，但是在魏氏兒童智力測驗第四版是替代測驗？
  1. （A）類同測驗
  2. （B）常識測驗
  3. （C）理解測驗
  4. （D）圖形設計

答案：（B）

詳解與考點

正解：題眼在 WAIS-IV「核心」與 WISC-IV「替代」的版本配置——須逐一比對同名分測驗在兩套量表的角色。常識測驗在 WAIS-IV 為核心測驗、在 WISC-IV 可作替代測驗，故選 B。

A：類同測驗在兩版本中均屬核心配置，未符合題目所問的角色差異。

C：理解測驗不是本題所指的「成人核心、兒童替代」對應。

D：圖形設計在兩版本皆是重要的核心視覺空間作業；它看似容易因兩版題材不同而被誤選，錯在沒有符合核心／替代的分類。

本題考點：魏氏成人智力量表第四版（WAIS-IV）與魏氏兒童智力量表第四版（WISC-IV）——分測驗的核心或替代身分具版本敏感性；解題須依題目指定版本比對，不可由名稱直覺推論。

第 3 題

在心理衡鑑中，何者不是臨床心理師選擇心理測驗需優先考量的因素？
  1. （A）測驗的信效度
  2. （B）臨床心理師本身是否受過足夠的相關訓練
  3. （C）計分的方便性
  4. （D）是否有適切的常模

答案：（C）

詳解與考點

正解：題眼在選擇心理測驗的「優先考量」——判準是測驗結果能否被勝任地施測、解釋且適切用於個案。計分方便只關乎行政效率，不足以保證衡鑑品質，故選 C。

A：信度與效度關係到分數是否穩定且支持其解釋，是首要條件。

B：臨床心理師須具備足夠訓練，否則即使測驗良好也可能施測或解釋失當。

D：適切常模是判讀個案相對表現的基礎，應優先確認。

本題考點：心理測驗選擇（test selection）——優先看信效度、施測者勝任能力與常模適切性；方便性可考量，但不能凌駕衡鑑效度。

第 4 題

關於智商的敘述，下列何者正確？
  1. （A）學齡前的智商穩定不易變化
  2. （B）教育可以增加晶體（crystallized）智力的分數
  3. （C）智商是正確精密的測量
  4. （D）智商分數不需要考慮誤差範圍

答案：（B）

詳解與考點

正解：題眼在晶體智力——判準是它主要累積自教育、文化與經驗所學的知識與技能，因此教育可提升晶體智力相關作業的分數，故選 B。

A：學齡前的認知表現仍受發展速度、情境與測量誤差影響，不能說穩定不易變化。

C：智商是依標準化程序得到的估計值，不是正確精密到無誤差的測量。

D：智商分數必須搭配測量誤差範圍解釋；它看似追求明確結論，錯在把單一分數當成毫無不確定性的真值。

本題考點：晶體智力（crystallized intelligence）——受教育與經驗影響；智商（IQ）是估計分數，解釋時須考量發展與測量誤差。

第 5 題

儘管已有許多制式化的行為衡鑑技術，許多行為治療師仍主張：
  1. （A）使用信效度良好的行為衡鑑自陳式量表
  2. （B）運用生理回饋記錄加上自陳式行為量表
  3. （C）使用結構化且具有客製化的行為衡鑑策略
  4. （D）使用非結構化且具有客製化的行為衡鑑策略

答案：（D）

詳解與考點

正解：題眼在行為治療師面對制式化衡鑑仍主張什麼——判準是行為衡鑑須依個案目標、前因後果與情境功能客製化，而非預設固定題項。非結構化且客製化的策略較能貼近個案的實際行為功能，故選 D。

A：自陳量表可作補充，但單用制式量表不足以掌握特定行為的情境脈絡。

B：生理回饋與自陳資料仍只是部分資料來源，不能取代功能分析。

C：結構化雖增加一致性，卻可能限制對個案獨特前因與後果的探索；最強誘答在於它同樣說「客製化」，錯在行為衡鑑的核心不是以既定結構收束資料。

本題考點：行為衡鑑（behavioral assessment）——強調行為的情境功能與個別化資料；制式量表可輔助，但不能取代功能分析。

第 6 題

有關整理會談資料的組織原則或方式，下列敘述何者錯誤？
  1. （A）依據時間序的方式整理與轉介目的相關的會談資料
  2. （B）依據核心主題或議題的方式整理個案的過去史
  3. （C）依據會談者的個人興趣撰寫個案的生活紀錄
  4. （D）可從會談資料中推論個案的性格

答案：（C）

詳解與考點

正解：題眼在會談資料的「組織原則」且問錯誤——判準是資料取捨要服務轉介問題與臨床假設，不能由會談者私人的興趣主導。依會談者個人興趣撰寫生活紀錄缺乏相關性，故 C 為錯誤敘述。

A：依時間序整理與轉介目的相關的資料，有助於理解問題的發展與變化。

B：以核心主題整理過去史可呈現跨時期模式，是合理的組織方式。

D：會談資料可作為性格推論的依據之一，但須與其他衡鑑資料整合，故非本題的錯誤處。

本題考點：臨床會談資料（clinical interview data）——依轉介問題組織並保留時間與主題脈絡；人格推論須整合證據；會談者興趣不是取捨標準。

第 7 題

有關結構式會談與非結構式會談的比較，下列敘述何者錯誤？
  1. （A）非結構式會談比結構式會談能夠更有彈性地觀察個案特有的因素
  2. （B）結構式會談比非結構式會談較具有心理計量學上的精準度
  3. （C）非結構式會談涵蓋的範圍比結構式會談更可以降低診斷的錯誤率
  4. （D）非結構式會談比結構式會談更易產生會談者的偏誤

答案：（C）

詳解與考點

正解：題眼在結構式與非結構式會談的比較且問錯誤——判準是診斷涵蓋與評分一致性通常由結構式程序提升。非結構式會談的範圍不一定更完整，反而較依賴會談者取向與提問，不能說更可降低診斷錯誤率，故 C 為錯誤敘述。

A：非結構式會談可隨個案反應深入探索，較能捕捉其特有脈絡。

B：結構式會談有標準題目與評分規則，通常具有較佳的一致性與心理計量精準度。

D：非結構式會談較受會談者選題與詮釋影響，較易產生偏誤。

本題考點：結構式會談（structured interview）——優勢是涵蓋與一致性；非結構式會談（unstructured interview）——優勢是彈性與個別化，但較易受會談者偏誤影響。

第 8 題

在羅夏克墨漬測驗 Exner's Comprehensive System 的計分系統中，下列何者是 Zd 指標所代表的面向？
  1. （A）個體對訊息處理的效能與正確性
  2. （B）個體嘗試進行複雜組織活動的企圖心
  3. （C）個體對訊息處理的動機與努力
  4. （D）個體的理智化程度

答案：（A）

詳解與考點

正解：題眼在 Exner Comprehensive System 的 Zd 指標——此指標用來判讀個體處理刺激訊息的效率與正確性，而不是單純投入多少努力，故選 A。

B：複雜組織活動的企圖心較涉及組織反應等其他計分訊息，非 Zd 的主要意義。

C：對訊息處理的動機與努力把「投入程度」與「處理效能」混為一談；它是最強誘答，因為處理訊息確實需要努力，錯在 Zd 判讀的是效能與正確性。

D：理智化是防衛或認知風格的概念，不能直接以 Zd 指標代表。

本題考點：羅夏克墨漬測驗綜合系統（Exner Comprehensive System）——Zd 指標（Zd）用於訊息處理效能與正確性的判讀；計分指標須與其指定構念對應。

第 9 題

下列敘述何者不是編製簡短式治療規劃與成效評估測驗的準則？
  1. （A）應可降低個案概念化的推論偏誤
  2. （B）需直接與治療計畫和成效評估有關
  3. （C）對重要的症狀變化很靈敏
  4. （D）完成測驗所需時間短

答案：（A）

詳解與考點

正解：題眼在簡短式治療規劃與成效評估測驗的「準則」且問非——判準是工具要直接、快速且能敏感反映重要症狀變化。降低個案概念化的推論偏誤是臨床推理的廣泛要求，不是此類短測驗本身的特定編製準則，故選 A。

B：測驗必須直接連結治療計畫與成效評估，才有追蹤價值。

C：對重要症狀變化敏感，才能偵測治療期間的進展或惡化。

D：完成時間短符合反覆施測與臨床可行性的需求。

本題考點：治療監測測驗（treatment monitoring measure）——需與目標直接相關、對變化敏感且施測負擔低；廣義的個案概念化偏誤不等於工具編製規準。

第 10 題

關於羅夏克墨漬測驗 Exner's Comprehensive System 施測程序的敘述，下列何者正確？
  1. （A）引發受試者適度的焦慮，以獲得放鬆狀態下無法獲得的訊息
  2. （B）告知受試者此為智力測驗，以提高受試者的動機
  3. （C）減少主試者非口語行為的影響
  4. （D）提醒受試者可以旋轉卡片，以看出不同的圖案

答案：（C）

詳解與考點

正解：題眼在羅夏克綜合系統的「施測程序」——判準是以標準化方式降低主試者對反應的影響。減少主試者非口語行為的影響可維持施測一致性，故選 C。

A：施測目標不是刻意引發焦慮，而是取得可依標準程序解釋的反應。

B：不得把羅夏克測驗誤稱智力測驗來提高動機，這會誤導受試者並破壞知後同意。

D：卡片是否旋轉應依標準指示處理，不宜主動提醒以誘導特定反應；它看似有助多角度觀察，錯在主試者不得主動塑造受試者的作答方式。

本題考點：羅夏克墨漬測驗（Rorschach Inkblot Test）施測——標準化與主試者中性是核心；避免暗示、誤導或刻意操弄受試者情緒。

第 11 題

個案成績不好、好動且衝動，認知測驗有粗心錯誤，電腦注意力測驗則正常，家長報告個案丟三落四，作業要花三、四小時才能完成，家長轉述老師觀察到個案上課不專心愛講話，下列的推論何者最適當？
  1. （A）由電腦注意力測驗正常，可推論個案應沒有注意力問題
  2. （B）由電腦注意力測驗正常，可推論個案對電腦活動有高度興趣
  3. （C）由認知測驗的粗心錯誤，可推論個案可能有注意力問題
  4. （D）由成績不好，可推論個案是練習不夠所導致

答案：（C）

詳解與考點

正解：題眼在多來源資料彼此不一致——判準是單一電腦注意力測驗正常不能排除日常環境中的注意力困難，須整合認知測驗、家長與教師觀察。認知測驗的粗心錯誤連同跨情境不專心資料，支持「可能有注意力問題」的審慎推論，故選 C。

A：由單一電腦測驗正常便排除注意力問題，是把特定情境表現過度概化到所有情境。

B：正常表現不等於已證明個案對電腦活動有高度興趣，該推論缺乏直接證據。

D：成績不好可有注意力、學習、情緒或教學等多重原因，不能直接歸因於練習不足。

本題考點：多方法衡鑑（multi-method assessment）——整合測驗、家長與教師資料；單一測驗正常不排除情境性的困難；粗心錯誤可提示假設，不能單獨確診。

第 12 題

進行魏氏智力測驗的算術分測驗時，個案聽完題目後，詢問該問題的答案為何，下列何種處理最適當？
  1. （A）把問題再重述一次
  2. （B）解釋該題目的意思
  3. （C）不理會個案的要求
  4. （D）鼓勵個案猜猜看

答案：（A）

詳解與考點

正解：題眼在魏氏算術分測驗的標準化處理——個案詢問答案時，主試者應依既定程序重述題目，而不提供內容提示或答案。因此（A）把問題再重述一次最能兼顧理解與施測一致性，故選 A。

B：解釋題意會超出標準化指示，可能改變題目所要求的理解與推理負荷。

C：完全不理會要求欠缺適切回應，也不符合可重述題目的標準程序。

D：鼓勵猜測會影響主試者的提示程度；它看似能維持作答動機，錯在未依標準化規則處理澄清要求。

本題考點：魏氏智力量表（Wechsler Intelligence Scale）施測——遵循標準化指示；可依規則重述題目，但不可解釋、提示或給答案。

第 13 題

進行心理衡鑑時，個案不願意讓家屬離開，下列處理何者適當？
  1. （A）因為要評估個案獨自完成測驗的能力，仍堅持個案與家屬分開
  2. （B）待個案願意獨自受測後再安排
  3. （C）跟家屬說明陪伴注意事項，給予閱讀書報，將此狀況記錄在報告中
  4. （D）直接與家屬晤談，獲取個案的資訊

答案：（C）

詳解與考點

正解：題眼在個案不願與家屬分開受測——判準是兼顧個案當下安全感、測驗條件與可解釋性，而非強迫分離或放棄衡鑑。向家屬說明陪伴注意事項、安排安靜閱讀並將陪伴狀況記入報告，能讓結果在脈絡中解釋，故選 C。

A：強迫分離可能使焦慮升高並損害合作，所得表現也未必能代表能力。

B：一律延後至能獨自受測，會不必要地中斷可在合理調整下完成的衡鑑。

D：直接改與家屬晤談不能取代個案的測驗與會談資料，且未處理當下受測需求。

本題考點：心理衡鑑調整（assessment accommodation）——兼顧個案合作與標準化條件；任何陪伴或調整都要記錄，作為結果解釋的一部分。

第 14 題

根據柯永河（1978）下列何種判斷資料是有意義的原則，一般而言在臨床上最常被使用？
  1. （A）偏離常模原則
  2. （B）偏離過去模式原則
  3. （C）前後不一致原則
  4. （D）反覆出現原則

答案：（A）

詳解與考點

C：前後不一致可形成待釐清的臨床假設，不能單獨作為最常用的意義判準。

第 17 題

  2. （B）70 分
  3. （C）60 分
  4. （D）50 分

正解：題眼在魏氏記憶量表第四版的「損傷標準」——判準是指標分數在量尺上的相對位置，而不是分數本身看起來高低。WMS-IV 指標分數採平均 100、標準差 15 的量尺；70 分正好落在平均以下 2 個標準差，這是神經心理衡鑑慣用的損傷切截，故選 B。

第 18 題

在 WAIS-IV 中，下列那個指標分數對腦傷最為敏感？
  1. （A）語文理解
  2. （B）知覺推理
  3. （C）處理速度
  4. （D）短期記憶

答案：（C）

詳解與考點

正解：題眼在「WAIS-IV」與「對腦傷最為敏感」——判準是比較各指標對腦傷後常見認知速度下降的敏感度。處理速度指標涵蓋視覺掃描、速度化作業與注意力效率，腦傷後此類效率常先受影響，故選 C。惟敏感度仍會隨腦傷位置、嚴重度與施測狀態改變，本題未提供這些資訊，故以一般教科書取向作答。

A：語文理解主要反映累積的語文知識與語文推理，較屬晶體能力，通常不像速度化作業那樣是腦傷的敏感指標。

B：知覺推理反映非語文推理與視覺空間處理；雖可能受特定腦傷影響，但不能據此視為一般腦傷最敏感的 WAIS-IV 指標。

D：短期記憶是題目沿用的概稱，WAIS-IV 對應工作記憶向度；其可受腦傷影響，但本題比較的是指標敏感度，處理速度較符合。這是最強誘答，因為注意與記憶困難確實常見，錯在把「可能受損」等同於「最敏感」。

本題考點：魏氏成人智力量表第四版（WAIS-IV）指標——處理速度（processing speed）著重快速且正確的視覺—動作與注意作業；工作記憶（working memory）與語文理解（verbal comprehension）也可受腦傷影響，但不宜混同為同一敏感性判準。

第 19 題

臨床研究者須參照特殊行為特質、診斷在一般群體中的比率或基準率（base rate），通常是因為要探討下列何者？
  1. （A）臨床資料蒐集的一致性
  2. （B）臨床判斷的正確性
  3. （C）臨床概念效度的敏感性
  4. （D）臨床人際知覺的偏誤

答案：（B）

詳解與考點

正解：題眼在「一般群體中的比率或基準率」——判準是任何臨床判斷的正確性都取決於該特徵或診斷原本出現的機率。即使某項線索看似支持診斷，若疾患基準率低，陽性判斷仍可能有不少誤判；參照基準率是為了校正判斷的後驗機率，故選 B。

A：資料蒐集的一致性關心不同衡鑑者或不同時間得到的資料是否相近，屬信度問題，並非基準率的主要用途。

C：概念效度關心工具是否真正測得欲測構念；敏感度則是辨識真陽性的能力，兩者都不能取代基準率在判斷正確性中的角色。這是最強誘答，因為敏感度也用於診斷研究，但只看敏感度會忽略偽陽性受基準率影響。

D：臨床人際知覺偏誤是判斷者可能犯的偏誤，與一般群體中的盛行比率不是同一層次。

本題考點：基準率（base rate）——診斷或預測的正確性須同時考慮基準率、敏感度（sensitivity）與特異度（specificity）；基準率忽略（base-rate neglect）會使臨床判斷偏離實際機率。

第 20 題

有關提升臨床判斷正確性的措施，下列敘述何者正確？
  1. （A）需考慮既存的勝算率
  2. （B）盡力避免各種類型的偏誤
  3. （C）提升對自己判斷正確性的信心
  4. （D）盡可能依賴統計預測

答案：（B）

詳解與考點

正解：題眼在「提升臨床判斷正確性」——判準是降低系統性偏誤並以可檢驗資料修正判斷。臨床工作中的確認偏誤、過度自信與刻板印象都會扭曲資訊權重，因此主動辨識並避免各種類型偏誤最符合提升正確性的原則，故選 B。

A：既存的勝算率不是本題討論的標準術語；即使意指基準率，也只是判斷時應納入的一項資訊，不能取代對多種偏誤的控制。

C：對自身判斷更有信心不會自動提高正確率，反而可能形成過度自信。這是最強誘答，因為有把握感容易被誤當成專業能力，兩者須由校正後的判斷表現區分。

D：統計預測在適用情況可提供有用基準，但「盡可能依賴」過度化了原則；臨床判斷仍須整合個案脈絡、資料品質與專業倫理。

本題考點：臨床判斷偏誤（clinical judgment biases）——以反證資料、結構化程序與回饋降低確認偏誤（confirmation bias）及過度自信；統計預測（statistical prediction）是輔助，不是免除臨床整合的替代品。

第 21 題

下列何種學派在治療目標上，致力於協助個案發展歸屬感、了解自身獨特的生活型態，及採用具社群感與社會興趣特徵的行為？
  1. （A）個人中心治療（Person-centered therapy）
  2. （B）敘事治療（Narrative therapy）
  3. （C）阿德勒治療（Adlerian therapy）
  4. （D）完形治療（Gestalt therapy）

答案：（C）

詳解與考點

正解：題眼在「歸屬感」「生活型態」「社群感與社會興趣」——這組概念直接指向阿德勒治療的核心。阿德勒取向把個案的困擾放在其獨特生活型態與社會連結中理解，治療目標是發展歸屬感、社會興趣與具建設性的行動，故選 C。

A：個人中心治療重視同理、真誠與無條件積極關懷，以促進個案的自我實現傾向，並不以社會興趣作為其標誌性目標。

B：敘事治療著重問題外化與重寫生命故事，關鍵不在阿德勒式的生活型態與社群感。

D：完形治療重視此時此地的覺察與未竟事務，並非以歸屬感和社會興趣為主要概念。這是最強誘答，因為它也關心個案的整體經驗，錯在核心治療語言不同。

本題考點：阿德勒治療（Adlerian therapy）——生活型態（lifestyle）是個案對自我、他人與世界的慣常取向；社會興趣（social interest）與歸屬感（belongingness）是其健康人格與治療目標的重要判準。

第 22 題

針對老年個案的偏執（paranoia）的處理方式，下列何者最為適當？
  1. （A）立即住院治療
  2. （B）立即對家屬進行衛教，面質個案的偏執是不正確的
  3. （C）提供心理支持與認知調適
  4. （D）立即停止所有藥物的使用

答案：（C）

詳解與考點

正解：題眼在「老年個案的偏執」與「最為適當」——判準是先維持安全與治療聯盟，再依個案狀態進行現實檢驗與認知調適；單憑偏執描述不足以直接採取強制或停藥措施。提供心理支持並協助個案調整對情境的解讀，能兼顧情緒安定與後續衡鑑，故選 C。惟題幹未提供精神病性症狀、失智、譫妄、感官缺損與用藥史，不能據此作出診斷或藥物結論。

A：立即住院需有明確急性危險、嚴重失能或其他必要臨床條件，不能只因有偏執就直接推論。

B：立即面質偏執「不正確」容易增加防衛與不信任；對家屬衛教可有幫助，但不是以對質作為首要處遇。這是最強誘答，因為家屬資訊確實重要，錯在程序上跳過個案的安全感與治療關係。

D：停止所有藥物可能造成風險；是否調整藥物須由適格醫療專業人員依病史、身體狀況與處方評估。

本題考點：老年偏執（paranoia in older adults）處遇——先作心理衡鑑與風險評估，再以支持性介入（supportive intervention）和認知調適（cognitive adjustment）維持合作；住院與藥物調整須有個別化臨床依據。

第 23 題

一對夫妻長期感情不睦，無法面對彼此間的衝突，但他們卻共同將問題歸咎於女兒的叛逆行為。此現象在家庭系統理論中稱為：
  1. （A）家庭基模
  2. （B）三角關係
  3. （C）移情作用
  4. （D）外在歸因偏誤

答案：（B）

詳解與考點

正解：題眼在「夫妻無法面對衝突」卻「共同歸咎女兒」——判準是家庭系統中的二人緊張關係是否拉入第三人，以轉移焦慮並暫時穩定原關係。夫妻把衝突集中到女兒的叛逆行為，正是三角關係，故選 B。

第 24 題

  1. （A）在性別角色分析（gender-role analysis）中，個案可學會辨認來自媒體的訊息
  2. （B）賦能（empowerment）技術主要促使個案成為主動代理者（active agent）
  3. （C）權力分析（power analysis）是為了讓個案覺察並理解治療關係中的權力不對等
  4. （D）運用社會行動（social action）策略，治療師會鼓勵個案投入各式社會政治活動中

詳解與考點

正解：題眼在「何者錯誤」與「權力分析」——判準是女性主義治療的權力分析不只檢視治療室內的人際關係，而是協助個案辨識性別、文化與社會結構如何分配權力及形塑困擾。C 把權力分析限縮為治療關係中的權力不對等，錯置了介入焦點，故為應選項。

B：賦能技術旨在增進個案的選擇、發聲與行動能力，使其成為主動代理者，敘述正確，故非答案。

D：社會行動策略可鼓勵個案依其價值與情境參與改善不平等的行動，敘述正確，故非答案。這是最強誘答，因為它容易被誤解為治療師強迫政治參與；重點是支持個案自主選擇行動。

本題考點：女性主義治療（feminist therapy）——性別角色分析（gender-role analysis）辨識社會化訊息；權力分析（power analysis）連結個人困擾與結構性權力；賦能（empowerment）與社會行動（social action）促進個案自主性。

第 25 題

完形治療（Gestalt therapy）發展出許多獨特的介入與練習，下列敘述何者正確？
  1. （A）反向練習（reversal exercise）讓個案表現出所欲消除的症狀，藉以獲得該症狀功能的覺察
  2. （B）排演練習（rehearsal exercise）讓個案發現自己如何不停透過內在排演來符合他人的期待
  3. （C）誇張練習（exaggeration exercise）讓個案誇大其口語，藉以說出心中所想卻從未說出的話
  4. （D）留在感覺中（staying with the feeling）能讓個案重複經驗該感受，以獲得對負面感受的習慣化

答案：（B）

詳解與考點

正解：題眼在「排演練習」——判準是辨識個案在與人實際接觸前，如何透過內在預演來安排自己、迎合他人或避免真實接觸。完形治療的排演練習正是讓個案覺察這種內在排演及其功能，故選 B。

A：反向練習是請個案刻意誇張或表現其慣常壓抑的相反面，以覺察其內在兩極與未被承認的部分；不能簡化為表現欲消除症狀。

C：誇張練習通常是誇大姿勢、動作、語調等非語言表現以增加覺察，而非單純誇大口語來說出未說的話。這是最強誘答，因為「誇大」聽似能促進表達，錯在把介入的覺察焦點改成口語告白。

D：留在感覺中是邀請個案不逃離當下感受、深入覺察其經驗，不以對負面感受的習慣化作為主要目的。

本題考點：完形治療（Gestalt therapy）實驗——排演練習（rehearsal exercise）揭露內在預演；誇張練習（exaggeration exercise）放大表現以提升覺察；留在感覺中（staying with the feeling）強調此時此地的經驗接觸。

第 26 題

關於家庭系統取向治療，下列何者最為符合？
  1. （A）重視個案家庭中每個成員的準確 DSM 診斷
  2. （B）強調透過個體生理、認知及情緒的交互作用來了解個案的困難

D：從心理病理機制協助個體發展因應策略偏向個別治療的問題形成模式；家庭系統取向會優先問症狀如何嵌入關係循環。這是最強誘答，因為因應策略本身可能有用，錯在治療分析單位放在個體而非家庭系統。

  2. （B）CBM 重視面質當事人的不理性想法，以增加壓力認知的免疫能力
  3. （C）認為改變的第一個步驟是學習如何觀察自己的行為，以增加行為的敏感度
  4. （D）較注重幫助當事人察覺自我對話，並學會改變不當的內在對話

A：他人評價可能引發焦慮，但不是完形治療對抗拒的核心定義。

  2. （B）個人理性的發展

正解：題眼在「存在治療」與「人類存在的基本條件」——判準是存在取向關注人無法迴避的終極限制，例如死亡、自由、孤獨與意義。對死亡與虛無的覺察直接呈現此類存在焦慮，故選 A。

  2. （B）提升行為技能（behavior skill）
  3. （C）改善情緒困擾（emotional disturbance）
  4. （D）增進自我肯定（self assertion）

答案：（A）

詳解與考點

正解：題眼在現實治療的「主要治療目標」——判準是協助個案檢視自己想要的關係與生活圖像，並選擇較負責任、有效的行為來接近它。品質世界是個案內在重要需求、人物與生活圖像的組成，治療即在協助個案以有效選擇接近品質世界，故選 A。

B：行為技能可能是實踐計畫所需資源，但不是現實治療最具辨識性的主要目標。

C：現實治療不把改善情緒困擾當作直接目標，而是透過改善選擇與關係，使情緒隨之可能改變。

本題考點：現實治療（Reality Therapy）——品質世界（quality world）是個案重要需求與理想關係的內在圖像；選擇理論（Choice Theory）強調檢視目前行為是否有效並規劃負責任的改變。

第 31 題

下列何者是佛洛伊德精神分析理論中的人格結構？
  1. （A）意識、前意識、潛意識
  2. （B）自我、本我、超我
  3. （C）生之驅力、死之驅力
  4. （D）阻抗、衝突、防衛

正解：題眼在佛洛伊德理論中的「人格結構」——判準是區分人格的結構模型與意識層次、驅力理論及心理病理概念。佛洛伊德的結構模型由本我、自我與超我構成，故選 B。

第 32 題

黃臨床心理師進行「臨床兒童心理治療訓練與行為改變成效」的研究，結果如下：受過訓練且成功改變兒童問題行為的有7人；受過訓練且未成功的有3人；未受訓練且成功的有1人；未受訓練且未成功的有9人。他以卡方檢定進行分析，下列敘述何者錯誤？
  1. （A）虛無假設為「是否受訓」與「改變是否成功」兩變項是獨立的
  2. （B）自由度為1
  3. （C）即使有多個細格人數為0 亦能有效計算
  4. （D）過程中需計算各細格之期望值

答案：（C）

詳解與考點

正解：題眼在「卡方檢定」與「何者錯誤」——本題是 2×2 列聯表：受訓練者成功／未成功為 7/3，未受訓練者為 1/9；列總數各為 10，欄總數成功為 8、未成功為 12，總數為 20。虛無假設是兩變項獨立，自由度為（2−1）×（2−1）＝1；各細格期望值依「列總數×欄總數÷總數」為 4、6、4、6。卡方檢定仰賴足夠的期望次數；若有多個細格人數為 0，不能逕稱仍可有效計算，故 C 為應選項。

A：卡方獨立性檢定的虛無假設正是「是否受訓」與「改變是否成功」彼此獨立，敘述正確，故非答案。

B：2×2 表的自由度為（列數−1）×（欄數−1）＝1，敘述正確，故非答案。

D：卡方統計量須逐格比較觀察值與期望值，因此需先計算各細格期望值，敘述正確，故非答案。這是最強誘答，因為本題觀察次數都不是 0；但適用性看的是期望次數與資料分布，不能由本題表格推成「多格為 0 仍有效」。

本題考點：卡方獨立性檢定（chi-square test of independence）——檢驗類別變項是否獨立；期望值（expected frequency）以列總數×欄總數÷總數計算；自由度（degrees of freedom）為（r−1）（c−1），並須注意期望次數的適用條件。

第 33 題

有關研究的方便取樣（samples of convenience）之批評，下列敘述何者正確？
  1. （A）無法確認因果關係
  2. （B）研究程序欠缺倫理考量
  3. （C）受試樣本的年齡層太低
  4. （D）不應該給受試者金錢作為酬勞

答案：（A）

詳解與考點

正解：題眼在「方便取樣」的批評——判準是依可近性招募到的受試者能否代表目標母群。官方答案為 A；惟方便取樣最核心的限制在代表性與外部效度：樣本組成與各種未受控的特性糾結在一起，研究者難以分辨結果反映的是研究變項，還是這群人本身就與母群不同，因此把結果推論到母群、進而主張變項間的因果關係都受到削弱。若研究內部另有隨機分派，對該樣本仍可作因果推論，本項應理解為對整體推論效力的批評，故選 A。

B：倫理與否取決於知後同意、風險管理與研究審查等程序，不能由方便取樣本身直接判定，故非答案。

C：方便樣本可能涵蓋任何年齡層，年齡太低不是此取樣法的必然問題，故非答案。

D：支付合理酬勞不必然不當；重點在避免不當誘因與保障受試者自主。這是最強誘答，因為方便樣本常以招募酬勞取得，但酬勞議題不同於取樣造成的推論限制，故非答案。

本題考點：方便取樣（convenience sampling）——依可近性招募受試者，容易產生選擇偏誤（selection bias）與混淆；代表性與外部效度（external validity）是其首要限制，而因果推論（causal inference）另須靠隨機分派等設計支撐。

第 34 題

有關暴露治療法對於焦慮症的應用，下列敘述何者正確？
  1. （A）現場暴露（in vivo exposure）強制個案長時間地暴露於引發強烈焦慮的刺激
  2. （B）洪水法（flooding）僅適用於焦慮刺激的實際暴露
  3. （C）想像暴露（imaginal exposure）不適合用於創傷倖存者
  4. （D）在焦慮症的行為治療上，暴露治療是最有效的技術且效果持久

答案：（D）

詳解與考點

正解：題眼在「暴露治療法對焦慮症」與「何者正確」——判準是暴露以系統、重複且足量地接觸恐懼線索，降低逃避與安全行為，讓個案學習能承受焦慮及修正威脅預期。暴露治療是焦慮疾患行為治療中具強實證支持且效果可維持的重要技術，故選 D。

A：現場暴露是在真實情境接觸恐懼線索，不等於強制個案長時間承受最強焦慮刺激；強度、步調與知後同意須依個案共同規劃。

B：洪水法可使用實際情境或想像情境，不是僅限於實際暴露。

C：想像暴露可用於創傷相關症狀的治療，並非不適合創傷倖存者；是否使用及如何進行須依個案穩定度與治療計畫評估。這是最強誘答，因為創傷記憶可能使想像暴露辛苦，錯在把需要審慎實施說成一律不適合。

本題考點：暴露治療（exposure therapy）——現場暴露（in vivo exposure）接觸真實線索；想像暴露（imaginal exposure）處理記憶或難以重現的線索；洪水法（flooding）為高強度暴露形式，臨床須重視合作、風險與個別化。

第 35 題

個案腦瘤術後復健，醫療團隊照會評估認知功能，下列何種醫病溝通處遇方式較為適切？
  1. （A）與家屬溝通病情，應避免讓個案知情，造成情緒波動
  2. （B）針對病情、復健目標及可能的預後，適度讓個案參與聆聽、表達想法
  3. （C）澄清家屬對疾病的認識，協助家屬心理調適
  4. （D）協助認識安寧，促進團隊與家屬的醫病溝通

答案：（B）

詳解與考點

正解：題眼在「腦瘤術後復健」與「醫病溝通」——判準是個案即使有認知功能困難，仍應依其理解與決策能力獲得適度資訊、表達偏好並參與照護討論。針對病情、復健目標與可能預後讓個案參與聆聽和表達想法，最符合尊重自主與支持決策的原則，故選 B。惟題幹未交代認知損傷程度與決策能力，實務上仍須先作個別化衡鑑，不能將參與方式一概而論。

A：為避免情緒波動而全面排除個案知情，忽略其知情與參與權利；應調整訊息呈現方式與支持程度，而非直接剝奪參與。

C：澄清家屬疾病認識與協助調適有其價值，但沒有直接回應個案如何參與醫療決策，故非最適切。

D：安寧溝通在適當病程可重要，但題幹聚焦術後認知功能照會與復健，直接跳到安寧未依目前問題設定優先序。這是最強誘答，因為預後溝通確可能涉及安寧，錯在未先依個案當前復健與決策參與需求處遇。

本題考點：醫病共享決策（shared decision-making）——依個案理解能力調整溝通與支持，而非排除其知情；決策能力（decision-making capacity）需個別衡鑑，家屬溝通不能取代個案的適度參與。

第 36 題

  2. （B）解釋呼吸、心跳、自律神經與壓力之關聯，說服個案一定要做心理治療
  3. （C）澄清疑慮，評估個案自我覺察的狀況，共同確定改善目標

詳解與考點

正解：題眼在「對轉介有所疑慮」——判準是身心功能調節處遇的起點應先理解個案如何解釋症狀、其疑慮與準備度，再共同訂定可接受的目標。澄清疑慮、評估自我覺察，並與個案共同確定改善目標，能建立合作與提升處遇契合度，故選 C。

A：說明檢查正常與可能的壓力關聯可以是衛教的一部分，但直接要求遵循醫囑，未處理個案對轉介的疑慮。

B：呼吸、心跳與壓力的連結可被說明，但以「一定要」心理治療的說服方式違反共同決策與治療合作原則。

D：身心功能檢測可能提供資訊，卻不能保證個案「就會明白」；先以檢測取代疑慮澄清，是把工具回饋誤作治療聯盟的捷徑。這是最強誘答，因為客觀檢測有助討論，錯在程序上跳過個案的理解與目標協商。

本題考點：治療聯盟（therapeutic alliance）——先探索個案的疾病信念（illness beliefs）與轉介疑慮；共同目標（shared goals）與合作決策是身心處遇的優先基礎。

第 37 題

下列何者不是佛洛依德所提出的心理病理學理論？
  1. （A）病症的初發與不愉快的經驗會同時發生
  2. （B）與不愉快的經驗有關的情感會轉化為症狀
  3. （C）症狀是慾望壓抑的結果
  4. （D）歇斯底里是一種情感壓抑的轉化形式

答案：（A）

詳解與考點

正解：題眼在「不是佛洛伊德所提出的心理病理學理論」——判準是佛洛伊德將症狀理解為被壓抑的欲望、衝突與情感經由妥協或轉化形成，而不是主張病症初發必定與不愉快經驗在同一時間發生。A 把時間上的同時發生說成病理理論，故為應選項。

B：與不愉快經驗相關而未被處理的情感可經轉化表現為症狀，符合早期精神分析對歇斯底里症狀的理解，故非答案。

C：症狀可被理解為欲望、禁令與防衛衝突下的妥協形成，壓抑是其中重要機制，敘述正確，故非答案。

D：歇斯底里可被精神分析理解為被壓抑情感的轉化表現，敘述正確，故非答案。這是最強誘答，因為現行診斷分類已不用「歇斯底里」作為正式疾患名；本題考的是佛洛伊德理論史中的概念。

本題考點：精神分析心理病理（psychoanalytic psychopathology）——壓抑（repression）與衝突（conflict）可形成症狀；轉化（conversion）是情感衝突以身體症狀表現的歷史性理論概念；症狀形成不以事件與發病同時發生為必要判準。

第 38 題

臺灣「臨床心理師倫理準則與行為規範」之基本準則中有關「保護與發展」，不包括下列那一項陳述？
  1. （A）社會大眾尋求臨床心理服務的原因是為了個人與相關人士的保護與發展
  2. （B）個人保護與發展的最佳方法是依賴科學實驗成果的保證
  3. （C）臨床心理服務有可能造成傷害，臨床心理師要時時覺察自己的限制
  4. （D）面對自己的職責與關懷之間發生衝突時，要採取合理程序來解決衝突

答案：（B）

詳解與考點

正解：題眼在倫理基本準則的「保護與發展」與「不包括」——判準是臨床心理師須以專業能力、避免傷害與負責任的程序來促進個人福祉，而非承諾科學實驗結果必能保證個人的最佳發展。科學證據可作為處遇依據，卻不能保證單一個案的結果，故選 B。

A：說明民眾尋求服務與保護、發展福祉的目的相符，故非答案。

C：臨床服務可能造成傷害，心理師應覺察能力與限制並採取適當因應，正是避免傷害的倫理要求，故非答案。

D：職責與關懷衝突時依合理程序處理，有助於維持專業責任與個案權益，故非答案。

本題考點：保護與發展（protection and development）——以個案福祉與避免傷害為判準；實證實務（evidence-based practice）可支持專業判斷，但不等於保證結果；倫理衝突須依負責任程序處理。

第 39 題

在規劃一個哀傷治療團體的過程中，臨床心理師的重要他人突然意外過世，情緒遭受重大衝擊。但團體治療已經計劃於兩週內開始，且報名人數已經額滿。臨床心理師如何做最合乎專業倫理？
  1. （A）顧及報名者的權益，雖然臨床心理師還處在非常痛苦的哀傷中，哀傷治療團體如期進行
  2. （B）逕自請另一位臨床心理師代班
  3. （C）向報名者道歉與說明，由於事出突然，必須延宕該哀傷治療團體的進行
  4. （D）臨床心理師因意識到自己還處在非常痛苦的哀傷中，故臨時將哀傷治療團體改為藝術治療團體

答案：（C）

詳解與考點

正解：題眼在治療者正處「重大哀傷衝擊」卻要帶領哀傷團體——判準是心理師能否維持足以勝任的專業功能及保護團體成員。既已覺察自身哀傷可能妨礙工作，應誠實說明並延後團體，以安排合宜的後續服務，故選 C。

A：報名者權益重要，但不能凌駕勝任能力與避免傷害；在高度未處理的哀傷中如期帶領同質團體，可能使治療者與成員皆承受額外風險。

B：臨時由他人代班看似兼顧時程，卻未確認代班者的同意、資格、團體準備與成員的知後同意，程序不足。

D：改成藝術治療並未處理治療者當下的勝任限制，且擅改原定治療目標與形式，故非答案。

本題考點：專業勝任能力（professional competence）——覺察功能受損時須調整服務；避免傷害（nonmaleficence）優先於既定時程；知後同意（informed consent）要求團體的重要變更不得逕自決定。
