  2. （B）在分數標準化之後，當神經質分數為 0 時，療效分數亦會為 0
  3. （C）單以此統計方法無法回答「神經質」與「療效」之間是否可能為非線性關係
  4. （D）「神經質」對「療效」的解釋變異量為 64%

答案：（D）

第 39 題

有關學齡兒童注意力問題的心理衡鑑，下列敘述何者正確？

  3. （C）需詢問出生史、發展史、家族病史、一般健康狀況、課業表現等
  4. （D）衡鑑過程不合作致無法完成注意力測驗，即為注意不足過動的行為表現
