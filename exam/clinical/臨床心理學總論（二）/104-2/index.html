104 年第 2 次臨床心理師臨床心理學總論（二）試題與答案

這一頁是民國 104 年第 2 次臨床心理師臨床心理學總論（二）的整份歷屆試題，共 40 題，題目與標準答案出自考選部「國家考試試題及測驗式試題答案」開放資料。以下逐題列出題幹、選項與答案；要計時作答或記錄成績，請用線上練習。

全部 40 題

第 1 題

下列何者是臨床心理衡鑑的主要目的？
  1. （A）回答特定問題，並協助作出相關的決定
  2. （B）收集測驗分數，以便作成對個案的各種描述
  3. （C）與個案建立關係
  4. （D）創造機會展現同理心

答案：（A）

第 2 題

有關心理衡鑑的敘述，下列何者正確？
  1. （A）心理衡鑑是完全標準化的過程，所有個案都接受同一套測驗
  2. （B）心理衡鑑是解決問題的歷程
  3. （C）臨床工作者的取向不會影響心理衡鑑的方向
  4. （D）心理衡鑑是綜合許多心理測驗結果的過程

答案：（B）

第 3 題

在撰寫一份針對個案（case-focused）的心理衡鑑報告時，下列那種做法最不合適？
  1. （A）針對轉介者所提出的問題撰寫
  2. （B）逐一詳述各項心理測驗的結果與個別推論
  3. （C）描述個案在不同的情境中可能出現的行為
  4. （D）提供治療處置的建議

答案：（B）

第 4 題

一份測驗工具能真正辨識出沒有問題之個體（真陰性，true negatives）的相對百分比稱為：
  1. （A）基礎率（base rate）
  2. （B）敏感度（sensitivity）
  3. （C）特異度（specificity）
  4. （D）勝算比（odds ratio）

答案：（C）

第 5 題

根據 Exner Comprehensive System，下列何者與分析及綜合訊息的能力有關？
  1. （A）反應部位
  2. （B）發展品質
  3. （C）決定因子
  4. （D）形狀品質

答案：（B）

第 6 題

下列那一組測驗表現最能反映個案的實用知識及社會規範的判斷能力？
  1. （A）理解分測驗與常識分測驗
  2. （B）常識分測驗與羅夏克墨漬測驗
  3. （C）HPH 與連環圖系分測驗
  4. （D）連環圖系分測驗與班達完形測驗

答案：（A）

第 7 題

WAIS-IV 的全量表智商的標準差為多少？
  1. （A）5
  2. （B）10
  3. （C）15
  4. （D）20

答案：（C）

第 8 題

心理衡鑑報告最終應以何種方式呈現個案問題的整體性，以幫助個案解決問題與做出決定？
  1. （A）科學性（scientific）
  2. （B）比較性（comparative）
  3. （C）主觀性（subjective）
  4. （D）功能性（functional）

答案：（D）

第 9 題

根據 Exner Comprehensive System 羅夏克墨漬測驗的解釋，下列何者可反映出個人的自我內省與延宕滿足 的能力？
  1. （A）Fr
  2. （B）FD
  3. （C）FT
  4. （D）FV

答案：（B）

第 10 題

決定心理衡鑑報告的內容，要考慮：
  1. （A）要遵守巴南效應（Barnum effect）
  2. （B）要遵守初始效應（primary effect）
  3. （C）不論與衡鑑問題是否有關，都應強調個案過去的特殊經驗
  4. （D）提供符合個案需求，且最能回答轉介問題的資訊

答案：（D）

第 11 題

由於臨床樣本較難蒐集，小華嘗試透過大學生樣本發展憂鬱量表，找出量表極端高分的受試者，以作為 該量表的效標，這屬於何種研究法？
  1. （A）類比研究法
  2. （B）臨床試驗法
  3. （C）個案研究法
  4. （D）單一受試者研究法

答案：（A）

第 12 題

承上題，若該量表後續研究可以正確地篩檢出 85%的憂鬱症患者，此量表具備優良的：
  1. （A）特異度
  2. （B）敏感度
  3. （C）內部一致性
  4. （D）折半信度

答案：（B）

第 13 題

某男性大學生相當孤僻，無法與同學相處，每次需要與同學分組合作時，都要老師協助安排。自幼發展 正常，無重大生理疾病史，能夠規律上學，學業成績中等，但其人際問題早在國中時期已有跡象，且與 父母、兄姊的關係也非常冷淡。依據 DSM-5，他可能的診斷為何？
  1. （A）思覺失調症
  2. （B）適應障礙症
  3. （C）A 群人格障礙症
  4. （D）B 群人格障礙症

答案：（C）

第 14 題

承上題，根據 Exner Comprehensive System，應可預期他在羅夏克墨漬測驗的那一個特殊指數會達到顯著？
  1. （A）因應缺失指數（CDI）
  2. （B）憂鬱指數（DEPI）
  3. （C）自殺組合指數（S-CON）
  4. （D）完美型態指數（OBS）

答案：（A）

第 15 題

下列何者是根據 Murray 的需求-壓力理論（needs-press theory）所發展出來的測驗？
  1. （A）班達測驗（B-G test）
  2. （B）主題統覺測驗（TAT）
  3. （C）羅氏夏克測驗（Rorschach）
  4. （D）明尼蘇達多相人格測驗（MMPI）

答案：（B）

第 16 題

Maloney & Ward（1976）主張，在衡鑑時產生假設、驗證假設，並將驗證後的資料整合成合理的剖析， 以期對受試者做出正確的結論。這個過程稱之為：
  1. （A）概念效度（conceptual validity）
  2. （B）遞增效度（incremental validity）
  3. （C）聚斂效度（convergent validity）
  4. （D）區辨效度（discriminate validity）

答案：（A）

第 17 題

針對阿茲海默症的支持性心理治療，下列何者最正確？
  1. （A）治療可改善患者記憶
  2. （B）治療取向以心理動力為主
  3. （C）治療聚焦在幫助患者承認並了解自己的認知缺陷與限制
  4. （D）治療聚焦在幫助個案與家屬處理疾病產生的影響

答案：（D）

第 18 題

下列何者是完形治療學派治療師會採取的作法？
  1. （A）操弄個案
  2. （B）自我表露
  3. （C）認知重構
  4. （D）主導行為改變

答案：（B）

第 19 題

下列有關對智能不足個案提供認知行為治療（CBT）的敘述，何者正確？
  1. （A）CBT 只能用於訓練智能不足個案自我照顧技能
  2. （B）CBT 可以教導智能不足個案使用自我指導來引導自己解決問題
  3. （C）CBT 與心理動力療法合併可幫助智能不足個案了解並因應他人排斥
  4. （D）CBT 完全不適用於智能不足個案

第 20 題

理情行為治療提出 ABCDEF 的架構，其中 E 代表下列何者？

  2. （B）評估（Evaluation）
  3. （C）效果（Effect）

第 21 題

Berne 所提的三元自我系統（tripartite ego system）指的是：
  1. （A）本我（id），自我（ego），超我（superego）
  2. （B）父母（parent），成人（adult），小孩（child）
  3. （C）身體自我（somatic ego），心智自我（mental ego），靈性自我（spiritual ego）
  4. （D）理想自我（ideal-self），真實自我（real-self），應該自我（ought-self）

第 22 題

存在治療師（existential therapist）主要在那些層面幫助個案面對終極關懷（ultimate concerns）？

第 24 題

  1. （A）辯證行為治療（dialectical behavior therapy）

  1. （A）嬰兒期的衝突完全被解決
  2. （B）個案與治療師之間的移情完全不存在

  4. （D）個案不會再對他人產生投射

第 26 題

下列何者屬於個人中心治療學派（person-centered therapy）治療歷程之目標？

  2. （B）對存在敬畏
  3. （C）對規範堅持

第 27 題

有關認知或行為治療（cognitive or behavior therapy）學派的敘述，下列何者錯誤？
  1. （A）認知治療協助個案將負面、扭曲的想法轉為較客觀、符合現實的想法
  2. （B）憂鬱的認知三元素（cognitive triad）是指對自己、環境及未來呈現負面的想法
  3. （C）行為治療認為行為可透過刺激、反應、行為後果等的操弄加以矯治
  4. （D）行為治療不適用於腦傷患者的復健治療

答案：（D）

第 28 題

實施代幣制度（token economy）時，代幣是屬於何種增強物？
  1. （A）初級增強物（primary reinforcer）

  3. （C）社會性增強物（social reinforcer）
  4. （D）負向增強物（negative reinforcer）

第 30 題

阿德勒治療學派（Adlerian therapy）認為，何者能夠提供個案對未來行動預演（rehearsal）的可能方向？

  3. （C）正念認知治療（mindfulness-based cognitive therapy）

第 35 題

  1. （A）治療師若能仔細思索自己的反移情，則反移情可被用來作為對於個案狀況的理解
  2. （B）診療室出現的反移情通常與治療師自己沒有處理好的問題有關，因此常常是對個案有傷害的
  3. （C）治療師的反移情愈少，愈不會干擾治療的進行
  4. （D）若治療師面對某位個案特別會出現反移情的反應，則表示這位治療師不適合治療這位個案
