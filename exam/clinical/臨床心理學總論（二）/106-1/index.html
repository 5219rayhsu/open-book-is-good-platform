第 1 題

客觀性心理計量取向的方法，最適合用來作為那一種類型的測驗？
  1. （A）智力功能
  2. （B）人格特質
  3. （C）憂鬱問題
  4. （D）焦慮問題

答案：（A）

第 2 題

行為衡鑑較少被用來評估下列那一類問題？

  2. （B）抽菸（smoking）
  3. （C）妄想（delusion）
  4. （D）恐懼（phobia）

  4. （D）評估個案在病房的自殺風險性

第 4 題
