  2. （B）人格障礙症的內在經驗與行為樣態，通常是穩定且持久的，其發作最早可以追溯至兒童時期
  3. （C）人格障礙症的內在經驗與行為樣態，無法歸因於某些物質（例如毒素暴露、藥物濫用等） 的生理效應所引起
  4. （D）人格障礙症是一種內在經驗與行為樣態，而且顯著偏離其個人所處的文化期待

答案：（B）

第 37 題

根據 Gray 的理論，行為抑制系統（behavioral inhibition system, BIS）與酬賞系統的失衡可用 來解釋心理病態者（psychopath）的行為，這兩個系統在心理病態者身上的特性為：
  1. （A）行為抑制系統活動高，酬賞系統活動高
  2. （B）行為抑制系統活動高，酬賞系統活動低
  3. （C）行為抑制系統活動低，酬賞系統活動高
  4. （D）行為抑制系統活動低，酬賞系統活動低

答案：（C）

第 38 題

有關畏避型人格障礙症成因與治療敘述，下列何者錯誤？
  1. （A）過去研究指出，父母教養的過度溺愛與放縱，是發展成為畏避型人格障礙症的主因
  2. （B）畏避型人格障礙症通常在兒童時期具有不良的磨人氣質（difficult temperament）
  3. （C）針對畏避型人格障礙症患者的社會技巧訓練能有效協助他們適應生活
  4. （D）治療關係的穩定是與畏避型人格障礙症患者進行治療工作的重要條件

答案：（A）

第 39 題

下列有關人格障礙症與其他精神疾病（mentaldisorders）共病與鑑別診斷的敘述，何者錯誤？
  1. （A）罹患強迫症的患者，有很高比例也具有強迫型人格障礙症
  2. （B）如果個案的依賴型行為是因為其他精神疾病的影響 （例如恐慌疾患） ，則不能被診斷為依賴 型人格障礙症
  3. （C）反社會人格障礙症個案時常合併有物質使用障礙症
  4. （D）透過比較自殺行為頻率、衝動性高低、以及自我概念是否穩定等特徵，可以區辨邊緣型人 格障礙症與自戀型人格障礙症

答案：（A）

第 40 題

有關 DSM-5 之 B 群人格障礙症，下列敘述何者錯誤？
  1. （A）反社會型人格障礙症的病程緩慢，而且隨著個案年長後其困擾的緩解並不顯著
  2. （B）邊緣型人格障礙症的特徵之一是人際關係、自我形象、以及情感的極度不穩定
  3. （C）做作型人格障礙症個案在自己不是他人的注意焦點時，會感到極端的不舒服
  4. （D）自戀型人格障礙症的特徵之一是誇大的自尊與缺乏同理心

答案：（A）
