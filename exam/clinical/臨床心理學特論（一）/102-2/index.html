第 1 題

有關自殺行為的生物性因素之研究發現，下列何者正確？
  1. （A）自殺行為與基因無關
  2. （B）自殺行為與兒茶酚胺（CA）有關
  3. （C）自殺行為與瘦素（Leptin）有關
  4. （D）自殺行為與體內低濃度的 5-輕基引朵醋酸（5-HIAA）有關

答案：（D）

第 2 題

  1. （A）考慮藥物治療

  3. （C）評估自殺危險性與自殺計畫
  4. （D）與個案簽訂不自殺契約

答案：（B）

第 3 題

  3. （C）父親失業
  4. （D）母親失業

第 4 題

  3. （C）自殺前常很矛盾，想要死，也想活

第 5 題

  4. （D）類分裂型人格疾患（schizoid personality disorder）

第 7 題

下列有關自殺的社會文化影響因素之敘述，何者錯誤？

  2. （B）知名或公眾人物的自殺將會顯著的增加自殺率
  3. （C）日本文化中的切腹（hara kiri）被視為是一種失序型的自殺（anomic suicide）
  4. （D）社會孤立者通常會有較高的自殺率

第 26 題

下列有關尼古丁（Nicotine）使用的描述，何者正確？

  2. （B）尼古丁戒斷時會造成食慾下降

  4. （D）高劑量的尼古丁使用，會造成血壓下降

答案：（A）

情況：老王因大量喝酒後，發生痙攣而送醫急救。他高職畢業後，接下父親營造廠工作，經常要到工地，爬上 建造中的大樓。他有懼高症，很緊張，為了消除緊張，他大量喝酒，藉酒壯膽。從此，愈喝愈多。後來 健康檢查顯示酒精性肝炎，他想要戒酒，但已戒不掉。他每天早上一起來就要找酒喝，不喝就手發抖， 煩躁不安。這次，更嚴重了，只因感冒，而未喝酒，就痙攣發作了
