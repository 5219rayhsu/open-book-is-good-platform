第 1 題

下列何者不是路易氏體認知障礙症（neurocognitive disorder with Lewy bodies）患者之特色？
  1. （A）病程早期有動作障礙
  2. （B）病程早期有認知障礙
  3. （C）病程早期注意力不受影響
  4. （D）患者常有視幻覺

答案：（C）

詳解與考點

考點為路易氏體認知障礙症特色。題目問非其特色者。路易氏體型早期即出現注意力與警醒度波動、視幻覺、帕金森氏動作障礙；C「早期注意力不受影響」與其波動性注意力缺損相反，故為正解。陷阱在易把注意力受損誤認為阿茲海默早期才明顯，但路易氏體早期即受影響。

第 2 題

下列何者為DSM-5建議之認知障礙症（Major Neurocognitive Disorders, Major NCDs）與輕型認知障礙症（Mild Neurocognitive Disorders, Mild NCDs）診斷間的主要區別？
  1. （A）Major NCDs患者具有較廣泛之認知功能受損
  2. （B）Mild NCDs患者基本日常生活功能未受損
  3. （C）Major NCDs患者罹患預後較差之生理疾病
  4. （D）Mild NCDs患者對於症狀較不在意

答案：（B）

詳解與考點

考點為 DSM-5 重度與輕度認知障礙症的主要區別。關鍵在功能：輕度認知障礙症（Mild NCD）患者基本日常生活功能尚未受損，重度則已影響獨立生活，故 B 正確。陷阱在 A、C、D 把區別放在受損廣度、生理預後或病識感，但 DSM-5 的核心界線是日常功能是否受損。

第 3 題

有關阿茲海默病引起的認知障礙症之盛行率的敘述，下列何者錯誤？
  1. （A）盛行率隨年齡快速上升
  2. （B）大約占所有失智症的半數以上
  3. （C）盛行率的估計值與收案來源有關
  4. （D）在80歲以上以男性患者居多

答案：（D）

詳解與考點

考點為阿茲海默病所致認知障礙症的盛行率。題目問錯誤者。其盛行率隨年齡快速上升、約占失智症半數以上、估計值受收案來源影響皆正確；D「80 歲以上以男性患者居多」錯誤，高齡層女性患者較多（與女性較長壽相關），故為正解。

第 4 題

蔡先生54歲即被診斷可能患有Alzheimer's Disease，神經內科醫師將他轉介給您。下列何者應該不符合他的狀況？
  1. （A）有可能是中高教育的知識分子
  2. （B）極可能是多次中風的患者
  3. （C）極可能語言與記憶功能都有減退現象
  4. （D）可能家屬也有類似案例

答案：（B）

詳解與考點

考點為阿茲海默症的典型臨床特徵與危險因子。正解 B 屬「多次中風」的描述，那是血管型失智症的成因而非阿茲海默症，故不符合本案狀況。阿茲海默症與高教育（認知存量）、語言記憶減退、家族史皆相符。最易誤選 C，但記憶與語言退化正是阿茲海默症核心表現，反而符合。

第 5 題

研究發現有些措施可以降低譫妄的程度，但下列何者不宜？
  1. （A）避免在晨間打擾患者睡眠
  2. （B）術後儘早下床走動
  3. （C）提供眼鏡與助聽器
  4. （D）避免飲水以減少頻尿

答案：（D）

詳解與考點

題目問降低譫妄的措施中「不宜」者。譫妄的非藥物預防著重於：維持定向感、改善感官輸入、促進活動與正常睡眠週期、維持水分與營養。D「避免飲水以減少頻尿」不宜，因限制飲水易導致脫水與電解質失衡，反而會誘發或惡化譫妄，選 D。A 適當：避免在晨間（睡眠時段）不必要地打擾患者，有助維持正常睡眠—清醒週期。B 適當：術後及早下床活動可降低譫妄風險。C 適當：提供眼鏡與助聽器以矯正視聽覺、改善感官輸入與定向，是經典的譫妄預防措施（如 HELP 方案）。

第 6 題

下列何者不是譫妄常見的病因？
  1. （A）額顳葉退化
  2. （B）藥物戒斷
  3. （C）營養不均
  4. （D）髖關節置換手術

答案：（A）

詳解與考點

考點為譫妄的常見病因。正解 A「額顳葉退化」屬慢性神經退化（失智症）病程，而非譫妄這類急性、可逆的意識障礙成因。藥物戒斷、營養不均、術後（如髖關節置換）皆為典型誘因。易誤選 D，但大手術後正是譫妄高發情境，確為常見病因。

第 7 題

下列何者不屬於訊息處理模式的記憶歷程階段（stage of memory processing）？
  1. （A）前瞻記憶（prospective memory）
  2. （B）登錄（registration）
  3. （C）感覺記憶（sensory memory）
  4. （D）覆誦（rehearsal）

答案：（A）

詳解與考點

考點為訊息處理模式的記憶階段。正解 A「前瞻記憶」是指記得未來要執行的事，屬記憶內容類型而非處理階段。登錄、感覺記憶、覆誦皆屬從輸入到保存的處理歷程階段。易誤選 C 感覺記憶，但它確實是訊息處理的起始階段，並非答案。

第 8 題

下列何者最可能為寡語型原發性漸進失語症（primary progressive aphasia-logopenic type）患者主要病理位置？
  1. （A）左側下部頂葉皮質（left inferior parietal lobe）
  2. （B）前額葉（prefrontal cortex）
  3. （C）外側膝狀核（lateral geniculate body）
  4. （D）初級聽覺皮質（primary auditory cortex）

答案：（A）

詳解與考點

考點為原發性漸進失語症的亞型與病灶定位。寡語型（logopenic type）的核心問題是詞彙提取與重複困難，主要病理位於左側下部頂葉皮質，故正解 A。前額葉與非流暢型較相關。易誤選 D 初級聽覺皮質，但寡語型並非單純聽知覺缺損，定位不在此。

第 9 題

針對執行功能障礙患者的「自我覺察（self-awareness）」困難，介入目標不包括下列那一項？
  1. （A）對自身狀況的覺知
  2. （B）對環境線索的覺知
  3. （C）對他人想法的覺知
  4. （D）社交線索的覺知

答案：（C）

詳解與考點

考點為執行功能障礙之自我覺察介入。自我覺察介入聚焦於對自身狀況、環境線索與社交線索的覺知。正解 C「對他人想法的覺知」較屬心智理論範疇，非自我覺察的直接介入目標。易誤選 D 社交線索，但覺察社交線索仍屬自我監控訓練的一環。

第 10 題

針對執行功能障礙患者的「計畫、決策」困難，下列何者不是介入訓練的目標？
  1. （A）將問題概念化的能力
  2. （B）制定替代方案、權衡與抉擇能力
  3. （C）衝動抑制能力
  4. （D）自我覺察能力

答案：（D）

詳解與考點

考點為執行功能中「計畫與決策」困難的介入目標。計畫決策訓練聚焦問題概念化、擬定替代方案與權衡抉擇、以及衝動抑制。正解 D「自我覺察能力」屬另一獨立的覺察向度，非計畫決策的直接訓練目標。易誤選 C 衝動抑制，但抑制干擾確為達成有效決策所需。

第 11 題

醫師轉介某患者，要求進行執行功能衡鑑。當完成威斯康辛圖片分類測驗（WCST）之後，發現和常模比較，患者的完成類別太少，這時下列那項資料的蒐集最能協助撰寫完整的報告？
  1. （A）施測智力測驗
  2. （B）施測MMSE
  3. （C）施測Token Task
  4. （D）施測Boston Naming Test

答案：（A）

詳解與考點

考點為 WCST 結果的補充衡鑑。WCST 完成類別過少可能反映執行功能缺損，但也可能受整體智力水準影響，故施測智力測驗（正解 A）最能釐清是否為一般能力低落或特定執行缺損，使報告完整。易誤選 B MMSE，但 MMSE 為粗篩工具，無法精確說明 WCST 表現的成因。

第 12 題

下列詞彙何者對於深層失讀症（deep dyslexia）患者而言最容易閱讀？
  1. （A）貓咪
  2. （B）快樂
  3. （C）愚蠢
  4. （D）音樂

答案：（A）

詳解與考點

考點為深層失讀症的閱讀特性。深層失讀症患者對高心像性、具體名詞較易閱讀，對抽象詞與功能詞困難。正解 A「貓咪」最具體、心像性最高，故最易讀。易誤選 D 音樂，雖為名詞但抽象度高於具體動物，心像性較低，閱讀較困難。

第 13 題

下列何者是屬於神經心理衡鑑的範疇，但不是其直接檢查的主要目的？
  1. （A）對假性失智症的鑑別診斷
  2. （B）對早期或輕微腦功能異常之偵測
  3. （C）對患者治療方式的療效評估
  4. （D）對患者病前職業與社會適應之問題進行評估

答案：（D）

詳解與考點

考點為神經心理衡鑑的目的範疇。神經心理衡鑑直接目的包括鑑別假性失智、偵測早期腦功能異常、評估治療療效。正解 D「病前職業與社會適應」屬病史背景蒐集，非神經心理測驗直接檢查的主要目的。易誤選 A 假性失智鑑別，但那正是衡鑑的核心直接用途。

第 14 題

下列何種疾患，較少需要與外傷性腦傷（traumatic brain injury）引起的認知障礙症做鑑別診斷？
  1. （A）頭部外傷造成的失智症
  2. （B）人為障礙症
  3. （C）譫妄
  4. （D）身體症狀障礙症

答案：（C）

詳解與考點

題目問哪一項「較少需要」與外傷性腦傷（TBI）引起的認知障礙做鑑別。A 頭部外傷造成的失智症本身即與 TBI 同源，臨床上需釐清是急性後遺認知缺損或進展為失智；B 人為障礙症（偽造或誇大認知症狀）與 D 身體症狀障礙症（過度的身體／認知抱怨）都可能模擬或混淆 TBI 後的認知表現，需要鑑別。相對而言，C 譫妄與 TBI 後認知障礙症在病程與機轉上區別較明確（譫妄為急性、波動性、注意力與意識清晰度受損，常有明確誘因且可逆），臨床上較不構成主要鑑別難題，故選 C。注意 C 是「譫妄」而非「人為障礙症」（人為障礙症是 B），且本題方向是「較少需要鑑別」，與譫妄。

第 15 題

下列那兩項腦內神經傳導物質的失調，對於造成注意力不足／過動症（attention-deficit/hyperactivity disorder）扮演相當重要的角色，這兩項神經傳導物質中的第一項主要是負責心理動作活動（psychomotor activity）及獎勵尋求（reward seeking），第二項則主要是負責在需求被延宕（delay）時，令個體產生嫌惡感（aversion）？
  1. （A）腦內啡（endorphin）；血清素（serotonin）
  2. （B）多巴胺（dopamine）；血清素（serotonin）
  3. （C）腦內啡（endorphin）；γ-胺基丁酸（γ-AminoButyricAcid, GABA）
  4. （D）多巴胺（dopamine）；γ-胺基丁酸（γ-AminoButyricAcid, GABA）

答案：（B）

詳解與考點

考點為 ADHD 的神經傳導物質機制。正解 B 多巴胺負責心理動作活動與獎勵尋求，血清素則與需求被延宕時的嫌惡感相關。腦內啡與 GABA 並非 ADHD 此二角色的核心。易誤選 D，雖多巴胺正確，但第二項應為血清素而非 GABA，故錯。

第 16 題

根據Solanto等人（2007）的研究發現，注意力不足／過動症（attention-deficit/hyperactivity disorder, ADHD）–過動／衝動表現型（predominantly hyperactive/impulsive presentation）相較於ADHD–混合表現型（combined presentation）之兒童，有較高的可能在下列那兩項功能上皆出現問題？
  1. （A）持續性注意力、工作記憶
  2. （B）行為抑制、行為持久性（behavioral persistence）
  3. （C）認知彈性、行為持久性（behavioral persistence）
  4. （D）警覺性注意力、行為抑制

答案：（B）

詳解與考點

考點為 Solanto 等人（2007）對 ADHD 表現型的研究。正解 B 指過動／衝動型相較混合型，較易在行為抑制與行為持久性兩功能上出問題。其他選項組合（持續注意、工作記憶等）較屬注意力不足或混合型特徵。

第 17 題

問題解決技巧訓練（problem-solving skills training）已被一些研究證實，能有效處理行為規範障礙症（conduct disorder），下列敘述何者正確？
  1. （A）屬於案主中心治療中的一種
  2. （B）著重於處理具行為規範障礙問題兒童及青少年在人際互動情境中所產生的認知缺陷與曲解
  3. （C）著重於教導父母新的教養技巧，例如：如何給清楚的命令、如何有系統地提供孩子獎勵
  4. （D）認為改變父母的教養行為，將會造成子女行為規範問題的改變

答案：（B）

詳解與考點

考點為問題解決技巧訓練對行為規範障礙症的機轉。正解 B 強調處理這些兒少在人際情境中的認知缺陷與曲解，屬認知取向的個案層次介入。著重教導父母技巧、改變教養行為者屬親職訓練；案主中心治療則非此取向。易誤選 D 親職層次，但問題解決訓練焦點在兒童本身的認知。

第 18 題

根據DSM-5，下列何者不是行為規範障礙症（conduct disorder）的主要診斷標準？
  1. （A）時常霸凌、威脅或恐嚇別人
  2. （B）會出現反覆的攻擊性爆發行為，這些行為並非事先經過思慮
  3. （C）曾經直接面對受害者搶劫或偷竊
  4. （D）十三歲之前就開始經常逃學

答案：（B）

詳解與考點

考點為 DSM-5 行為規範障礙症診斷準則。霸凌威脅、面對受害者搶劫、十三歲前逃學皆屬準則。正解 B「未經思慮的反覆攻擊性爆發」更貼近間歇暴怒障礙症的描述，非行為規範障礙症的核心準則。易誤選 D 逃學，但經常逃學確屬嚴重違規類準則之一。

第 19 題

有關於心智理論（theory of mind）之說明，下列何者正確？
  1. （A）大部分的3歲孩子即可以通過初級錯誤信念的心智理論作業
  2. （B）自閉症類群疾患（autism spectrum disorder）的患者皆無法通過心智理論的作業
  3. （C）心智理論的能力與語言和互動能力有正相關
  4. （D）一般孩子通過心智理論作業時只涉及直覺推論

答案：（C）

詳解與考點

考點為心智理論（ToM）的發展與相關性。正解 C 正確：ToM 能力與語言及社會互動能力呈正相關。A 錯在初級錯誤信念約四歲才通過而非三歲；B 過於絕對，部分高功能自閉症可通過；D 錯在通過 ToM 涉及推論而非僅直覺。易誤選 A，但三歲多半尚未穩定通過。

第 20 題

下列何者是自閉症類群患者最常伴隨的問題？
  1. （A）癲癇問題
  2. （B）自傷問題
  3. （C）攻擊他人問題
  4. （D）焦慮問題

答案：（D）

詳解與考點

考點為自閉症類群最常伴隨的共病問題。正解 D 焦慮問題是自閉症患者最常見的共病，盛行率偏高。癲癇、自傷、攻擊雖也常見，但比率不及焦慮普遍。易誤選 A 癲癇，雖確有相當比例共病，但整體最常伴隨者仍為焦慮。

第 21 題

根據Tallal（2003）的研究，顳平面（planum temporale）被認為是與視覺組織缺損（pervasive visual- organizational deficits）相關的大腦解剖位置，且與語言訊息處理相關。對於閱讀障礙（reading disorder）的人而言，下列何者正確？
  1. （A）左側顳平面大於右側顳平面
  2. （B）右側顳平面大於左側顳平面
  3. （C）兩側顳平面同樣大小
  4. （D）左與右顳平面在大腦皮質的位置不對稱

答案：（C）

詳解與考點

考點為 Tallal（2003）對閱讀障礙與顳平面的研究。正解 C 指閱讀障礙者兩側顳平面大小趨於對稱（同樣大小），失去一般人左側大於右側的不對稱性。易誤選 D 位置不對稱，但研究重點在兩側體積對稱化而非皮質位置。判準在於該研究主張的是兩側體積差異消失，而非皮質位置移位。

第 22 題

唐氏症患者的智能不足大多落在那個範圍？
  1. （A）輕度智能不足
  2. （B）中度智能不足
  3. （C）重度智能不足
  4. （D）極重度智能不足

答案：（B）

詳解與考點

考點為唐氏症的智能障礙程度分布。正解 B：唐氏症患者的智能障礙多落在中度範圍。雖個別差異大，但典型分布以中度為主，部分為輕度。易誤選 A 輕度，但整體平均落點仍偏向中度智能不足。

第 23 題

下列有關共享式注意力（joint attention）的敘述，何者錯誤？
  1. （A）指的是能將注意力調整在社交同伴，或彼此有興趣的事物上
  2. （B）其正常發展時間大約在幼兒18個月到24個月時出現
  3. （C）會透過用手指、展示、注視、或是溝通而分享其興趣
  4. （D）幼兒早期缺乏視線接觸，與其後續欠缺共享式注意力有關

答案：（B）

詳解與考點

考點為共享式注意力（joint attention）的發展。正解 B 為錯誤敘述：共享式注意力的正常發展約在 9 至 12 個月即開始出現，而非題述的 18 至 24 個月。其餘對定義、表現方式（手指、注視）與早期視線接觸關聯的敘述皆正確。易誤選 D，但早期缺乏視線接觸確與後續缺陷有關。

第 24 題

有關受虐兒童的家庭特徵，下列何者錯誤？
  1. （A）通常家庭結構，特別是單親父母，為受虐兒童的高風險因子
  2. （B）通常忽略兒童的是母親
  3. （C）通常性侵兒童的是男性
  4. （D）受虐兒童與家庭經濟狀況無關

答案：（D）

詳解與考點

考點為受虐兒童的家庭特徵。正解 D 為錯誤：受虐與家庭經濟狀況並非無關，低社經為已知風險因子。單親結構為高風險、忽略者多為主要照顧的母親、性侵者多為男性皆屬常見特徵描述。易誤選 B，但忽略型虐待確常與母親為主要照顧者相關。

第 25 題

有關兒童青少年焦慮症的心理介入，下列敘述何者錯誤？
  1. （A）Coping Cat是針對兒童焦慮症發展的治療方式
  2. （B）Exposure是針對兒童青少年畏懼症的主要治療方式
  3. （C）Systematic Desensitization是針對兒童青少年焦慮症的主要治療方式
  4. （D）兒童焦慮症的治療以兒童的Cognitive-Behavioral Therapy為主，父母參與治療效果不大

答案：（D）

詳解與考點

考點為兒童青少年焦慮症的心理介入。正解 D 為錯誤：兒童焦慮治療中父母參與往往有助療效，並非效果不大。Coping Cat 確為兒童焦慮的代表方案、暴露法為畏懼症主要治療、系統減敏感法亦常用，皆正確。易誤選 C，但系統減敏感法確為焦慮常見技術。

第 26 題

下列那個理論認為青少年憂鬱是因為無法統整與長期目標有關的行為，且欠缺自我評估、自我監控，及自我增強？
  1. （A）心理動力理論
  2. （B）行為學派
  3. （C）自我控制理論
  4. （D）認知理論

答案：（C）

詳解與考點

考點為青少年憂鬱的理論取向。正解 C 自我控制理論認為憂鬱源於無法統整長期目標行為，且缺乏自我評估、自我監控與自我增強，這三組件正是該理論核心。易誤選 D 認知理論，但認知理論聚焦負向認知三角與扭曲思考，非自我監控組件。

第 27 題

有關青少年憂鬱的診斷，下列敘述何者錯誤？
  1. （A）DSM-5中Major Depressive Disorder（MDD）的成人診斷不適用於青少年
  2. （B）青少年的Major Depressive Disorder（MDD）較多焦躁情緒而非憂鬱情緒
  3. （C）青少年Major Depressive Disorder（MDD）最常共病的障礙症是焦慮症
  4. （D）青少年憂鬱首次出現自殺企圖的高峰期是13～14歲

答案：（A）

詳解與考點

考點為青少年憂鬱的診斷特性。正解 A 為錯誤：DSM-5 的 MDD 成人診斷準則大致適用於青少年，僅情緒可以易怒呈現等微調。青少年常見焦躁取代憂鬱情緒、最常共病焦慮症、自殺企圖高峰約在 13 至 14 歲皆屬正確。易誤選 B，但青少年以易怒呈現確為特徵。

第 28 題

思覺失調症目前被確立的風險對偶（risk alleles）基因，與下列那個障礙症相對而言關聯性最低？
  1. （A）自閉症
  2. （B）雙相情緒障礙症
  3. （C）憂鬱症
  4. （D）強迫症

答案：（D）

詳解與考點

考點為思覺失調症風險基因與其他障礙症的遺傳關聯。正解 D 強迫症與思覺失調症共享的風險對偶基因關聯相對最低。自閉症、雙相情緒障礙、憂鬱症與思覺失調症在基因層次有較多重疊。

第 29 題

有關思覺失調症治療的敘述，下列何者錯誤？
  1. （A）可以用認知提升治療來加強注意力、記憶等認知功能
  2. （B）藥物治療合併認知行為治療可以降低妄想與幻覺
  3. （C）前額葉切除手術是改善思覺失調症狀有效的方法
  4. （D）可以採跨領域的團隊提供完整的個案管理

答案：（C）

詳解與考點

考點為思覺失調症治療方式的正誤。正解 C 為錯誤：前額葉切除術早已被淘汰，並非改善思覺失調症狀的有效方法。認知提升治療、藥物併認知行為治療降低妄想幻覺、跨領域團隊個案管理皆為當代正確作法。易誤選 B，但藥物併 CBT 確有實證支持。

第 30 題

下列何種敘述，是自閉症類群障礙症與思覺失調症出現共病的條件？
  1. （A）為了取得藥物的方便性，只要出現重複行為、對人不信任與逃避人群，都可以同時診斷自閉症類群障礙症與思覺失調症
  2. （B）以診斷的優先次序來看，自閉症類群障礙症優先於思覺失調症的診斷
  3. （C）以藥物有效性的觀點來看，思覺失調症的診斷應該永遠優先於自閉症類群障礙症
  4. （D）過去已確診為自閉症類群障礙症，必須符合思覺失調症的診斷準則，並且要持續一個月有明顯的妄想、幻覺，才可同時診斷為自閉症類群障礙症與思覺失調症

答案：（D）

詳解與考點

考點為自閉症與思覺失調症共病的診斷條件。正解 D：DSM-5 規定既有自閉症診斷者，須額外符合思覺失調症準則且至少一個月有明顯妄想或幻覺，才可同時診斷。A、B、C 將診斷簡化或以取藥、優先次序為由皆不符準則。易誤選 B 優先次序，但 DSM-5 並無此一律優先規則。

第 31 題

現今在DSM-5中有關思覺失調症流行病學的描述，何者正確？
  1. （A）思覺失調症是穩定出現的疾病，從古至今都是如此，終生盛行率約等於1.5%，不同國家、文化、種族和城鄉居住地的發生率與表現都差不多，男女沒有顯著差異
  2. （B）思覺失調症的終生盛行率約為0.3%～0.7%；不同種族、國家、地理位置、性別都會有差異
  3. （C）思覺失調症的男性罹病率略多於女性，但女性發病年齡較早持續時間也較長
  4. （D）情感性思覺失調症的流行率與思覺失調症相當，男女發病率也相當

答案：（B）

詳解與考點

考點為 DSM-5 思覺失調症流行病學。正解 B：終生盛行率約 0.3% 至 0.7%，且在種族、國家、地理、性別間確有差異。A 誇大為 1.5% 且宣稱毫無差異；C 的性別與發病年齡描述方向有誤（男性通常發病較早）；D 的情感思覺失調症盛行率描述不符。

第 32 題

DSM-5關於精神病的前驅症狀（prodromal symptoms in psychotics）的敘述，下列何者最恰當？
  1. （A）不管何種思覺失調類群的診斷類別，都一定會先有前驅症狀（prodromal symptoms），再出現活躍期（active phase）症狀，最後呈現殘餘症狀（residual symptoms）
  2. （B）不會出現退縮、情緒低落、動機低落等負性症狀
  3. （C）是輕微的妄想和幻覺，所以是短暫精神病症（brief psychotic disorder）的主要症狀
  4. （D）會出現不尋常或奇特的信念或知覺經驗，也會出現不尋常的行為或模糊的語句

答案：（D）

詳解與考點

考點為精神病前驅症狀的特性。正解 D：前驅期常出現不尋常或奇特的信念、知覺經驗，以及怪異行為或模糊語句。A 過於絕對（非必然依固定三階段）；B 錯在前驅期常見退縮、低落等負性症狀；C 將前驅症狀誤等同短暫精神病症。易誤選 A，但病程順序並非一成不變。

第 33 題

關於思覺失調症前額葉影響的敘述，下列何者正確？①前額葉皮質在說話、做決定等功能上有受損情形②前額葉皮質的灰質減少，但是整體容量沒有減少③前額葉工作記憶的功能受損④前額葉皮質的葡萄糖代謝速率較為快速
  1. （A）①②
  2. （B）①③
  3. （C）②③
  4. （D）②④

答案：（B）

詳解與考點

考點為思覺失調症的前額葉異常。正解 B（①③）：前額葉在說話、決策等功能受損，且工作記憶功能受損，皆為正確。②錯在灰質減少常伴隨整體容量改變；④錯在前額葉葡萄糖代謝多呈低下（hypofrontality）而非加快。易誤選②，但容量描述不符。

第 34 題

第一型雙相情緒障礙症（bipolar I disorder）最常見的共病為下列何者？
  1. （A）行為規範障礙症（conduct disorder）
  2. （B）焦慮症（anxiety disorder）
  3. （C）酒精使用障礙症（alcohol use disorder）
  4. （D）注意力不足過動症（ADHD）

答案：（B）

詳解與考點

考點為第一型雙相情緒障礙症最常見的共病。正解 B 焦慮症為其最常見共病。酒精使用障礙、ADHD、行為規範障礙雖也可能共病，但盛行最高者為焦慮症。易誤選 C 酒精使用障礙，雖常見但非最常見共病。

第 35 題

根據DSM-5，有關第一型雙相情緒障礙症（bipolar I disorder）的敘述，下列何者錯誤？
  1. （A）要下此障礙症的診斷，必須一生當中至少出現一次躁症發作
  2. （B）鬱症發作並非是此障礙症的診斷要件
  3. （C）若同時符合躁症與輕躁症發作準則，應註明混合型特徵
  4. （D）此疾病之初發可能發生在一生中的任何階段

答案：（C）

詳解與考點

考點為 DSM-5 第一型雙相情緒障礙症準則。正解 C 為錯誤：DSM-5 已移除「混合發作」獨立類別，改以混合特徵之標註附加於躁症或鬱症發作，而非「同時符合躁症與輕躁症」即註明混合型。診斷只需一生至少一次躁症發作、鬱症非必要件、可發生於任何年齡皆正確。

第 36 題

依據DSM-5，相較於第一型雙相情緒障礙症，第二型雙相情緒障礙症一生的總發作次數有何差異﹖
  1. （A）次數較少
  2. （B）次數較多
  3. （C）次數相同
  4. （D）沒有定論

答案：（B）

詳解與考點

考點為第一型與第二型雙相情緒障礙症的發作次數比較。正解 B：第二型一生的總發作次數較第一型為多，因其循環較頻繁。易誤選 A 次數較少，但第二型雖躁症較輕（為輕躁），整體發作頻率反而更高。

第 37 題

依據Kring（2018）等人的研究整理資料，躁症發作時大腦活性（activity level）減少的區域是下列何者？
  1. （A）杏仁核（amygdala）
  2. （B）海馬迴（hippocampus）
  3. （C）前扣帶迴（anterior cingulate）
  4. （D）紋狀體（striatum）

答案：（B）

詳解與考點

考點為 Kring 等人整理之躁症發作腦區活性變化。正解 B 海馬迴在躁症發作時活性減少。杏仁核、前扣帶迴、紋狀體等情緒與酬賞區域多呈活性增加。判準在於躁症的腦影像變化以邊緣與酬賞系統活性上升為主，海馬迴則屬活性減少的區域。

第 38 題

有關雙相情緒障礙症的藥物治療敘述，下列何者錯誤？
  1. （A）大部分患者於服用鋰鹽（lithium）後仍持續會有一些輕躁症狀和輕度憂鬱症狀
  2. （B）通常一開始服用鋰鹽（lithium），建議必須終身服用
  3. （C）抗癲癇藥物divalproex sodium可用來治療急性躁症症狀
  4. （D）服用鋰鹽（lithium）是用來治療躁症症狀，對緩解憂鬱症狀無效

答案：（D）

詳解與考點

考點為雙相情緒障礙症的藥物治療。正解 D 為錯誤：鋰鹽不僅治療躁症，對預防與緩解憂鬱症狀亦有效，並具抗自殺效果。服鋰後仍可能殘留輕躁與輕鬱症狀、通常建議長期甚至終身服用、divalproex 可治急性躁症皆正確。易誤選 B 終身服用，但臨床確常建議長期維持。

第 39 題

當思覺失調症患者面臨的問題是無法有效過濾訊息輸入，以致無法區辨那些是重要的訊號時，最適當的認知行為介入技巧主要是下列何者﹖
  1. （A）注意力轉換（attention switching）
  2. （B）注意力縮小（attention narrowing）
  3. （C）覺察訓練（awareness training）
  4. （D）再歸因（reattribution）

答案：（B）

詳解與考點

考點為思覺失調症訊息過濾困難的認知行為介入。正解 B 注意力縮小（attention narrowing）：當患者無法過濾過多輸入、難辨重要訊號時，縮小注意焦點可降低干擾。注意力轉換適用反芻或幻聽分心；再歸因處理妄想信念。易誤選 A 注意力轉換，但其目的在轉移而非縮小過載輸入。

第 40 題

一開始診斷為類思覺失調症的患者，大約有多少比率在發病6個月之後會被診斷為思覺失調症或情感思覺失調症？
  1. （A）將近三分之一
  2. （B）將近三分之二
  3. （C）將近四分之三
  4. （D）將近五分之四

答案：（B）

詳解與考點

考點為類思覺失調症（schizophreniform）的轉歸。正解 B：約三分之二的類思覺失調症患者在六個月後會被診斷為思覺失調症或情感思覺失調症，因症狀持續超過六個月即不再符合短病程定義。
