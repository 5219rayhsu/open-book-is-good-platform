第 1 題

陳爺爺於 4 年前中風，因行動能力恢復良好，所以獨自住在鄉下老家。過年時，被發現經常半夜在田間 走動，而且數日不歸，回家時，常常衣物髒髒的或身上帶有傷口。此一行為最不可能是下列何種問題？
  1. （A）失智症
  2. （B）憂鬱症
  3. （C）失用症
  4. （D）譫妄症

答案：（C）

詳解與考點

正解：題眼在「半夜走動、數日不歸」與「最不可能」——判準是該現象是否能直接解釋迷途、定向混亂或日夜節律改變；失用症則是已知動作技能的執行困難。（C）失用症可使個案難以完成熟悉動作，但不會以夜間離家遊走、數日不歸為主要表現，故最不可能，應選 C。

A：失智症可有定向感受損、走失與日夜節律紊亂，能解釋此行為。

B：憂鬱症雖非最典型原因，但高齡個案的情緒疾患可伴隨睡眠障礙、功能退縮或認知困擾，不能僅憑現象完全排除。

D：譫妄可造成急性注意力、定向與睡眠—清醒週期變動，因而需要鑑別。它看似只是一時混亂，錯在老年人出現急性夜間異常行為時，譫妄是必須優先排除的可逆原因。

本題考點：失用症（apraxia）——無法正確執行已學會的動作，不等於迷途；老年遊走（wandering）——須考慮失智症與急性譫妄等定向、注意力問題。

第 2 題

有關早期失智症患者的衡鑑，下列何種測驗工具較不適用？
  1. （A）老年憂鬱量表與情緒問卷
  2. （B）魏氏成人記憶力測驗組
  3. （C）手部靈巧測驗
  4. （D）語文與非語文工作記憶測驗

答案：（C）

詳解與考點

正解：題眼在「早期失智症患者的衡鑑」與「較不適用」——早期鑑別的判準是工具能否敏感呈現記憶、工作記憶、情緒與日常認知變化；與轉介問題關聯較低的工具優先度較低。（C）手部靈巧測驗主要衡量精細動作與手部操作速度，對以早期認知改變為主的失智症衡鑑較不適用，故選 C。測驗選擇仍須依疑似病因、教育背景與神經學狀態整合判斷。

A：老年憂鬱量表與情緒問卷可協助辨識憂鬱造成的認知抱怨或共病情緒困擾，具鑑別價值。

B：魏氏成人記憶力測驗組可衡量不同記憶功能，與早期失智症的記憶主訴相關。

D：語文與非語文工作記憶測驗可提供注意力與工作記憶訊息，亦可用於認知功能剖面。

本題考點：早期失智症心理衡鑑（early dementia assessment）——以記憶、注意與執行等認知構念為主；手部靈巧測驗（manual dexterity test）——主要反映動作功能，非早期失智症的核心篩檢工具。

第 3 題

下列何者不是高齡長輩常有的問題？
  1. （A）主觀抱怨記憶功能退化
  2. （B）認知功能大量退化而導致無法獨立生活
  3. （C）非情緒因素導致性生活的興趣下降
  4. （D）情緒抱怨與人際關係困境

答案：（B）

詳解與考點

正解：題眼在「高齡長輩常有的問題」與「不是」——判準是區分正常老化與常見主訴，和已造成失去獨立生活能力的重大認知障礙。（B）認知功能大量退化至無法獨立生活，指向失智症等重大神經認知障礙，並非一般高齡長輩的常態問題，故選 B。

A：主觀抱怨記憶退化在高齡族群常見，可能與正常老化、情緒或初期認知改變有關。

C：疾病、身體功能改變、伴侶狀況等非情緒因素都可能影響性生活興趣，並非罕見議題。

D：情緒抱怨與人際關係困境可隨退休、喪失、照顧負荷與角色轉換出現，故非答案。

本題考點：正常老化（normal aging）——可有主觀記憶抱怨與心理社會困擾；重大神經認知障礙（major neurocognitive disorder）——功能損害到無法獨立生活時，不能視為正常老化。

第 4 題

76 歲婆婆，未受教育，傳統家庭主婦，去年首度因疑似失智症就診。今年追蹤實施 MMSE 時，下列何者 最能看出患者之立即記憶力功能？
  1. （A）這裡是什麼地方
  2. （B）請看這寫什麼，請做做看
  3. （C）請跟著我唸三種東西
  4. （D）請將這個圖畫在這裡

答案：（C）

詳解與考點

正解：題眼在「立即記憶力」——判準是受試者能否立刻登錄並複誦剛呈現的新訊息，而不是測定定向感、閱讀理解或視覺建構。（C）要求受試者跟著唸三種東西，直接檢驗剛呈現訊息的立即登錄與複誦，最能反映立即記憶力功能，故選 C。教育程度會影響部分 MMSE 項目的表現，臨床解釋須合併背景資料。

A：詢問所在地點主要測量定向感，非立即記憶。

B：閱讀指令後執行，主要涉及閱讀理解、注意與指令執行。

D：複製圖形主要反映視覺空間建構與動作整合能力，不是立即記憶。這是最強誘答，因為它也要求當下完成作業，錯在沒有要求保留並複誦新呈現的語詞。

本題考點：立即記憶（immediate memory）——以新訊息的即時登錄與複誦衡量；MMSE（Mini-Mental State Examination）——不同題項分測定向、注意、語言與視覺建構等構念。

第 5 題

下列何者不是譫妄症候群常見的症狀表現？
  1. （A）白天嗜睡，夜間焦躁不安
  2. （B）活動量降低，同時伴隨有鮮明的幻覺
  3. （C）語無倫次，主題跳躍混亂
  4. （D）注意力散漫，無法集中在特定主題

答案：（B）

詳解與考點

正解：題眼在「譫妄症候群常見的症狀表現」與「不是」——判準是急性起伏的注意力障礙、思考混亂與睡眠—清醒週期改變；幻覺雖可見，但鮮明幻覺搭配活動量降低並非典型常見組合。（B）活動量降低可見於低活動型譫妄，但「同時伴隨鮮明的幻覺」不是其常見典型描述，故選 B。

A：白天嗜睡、夜間焦躁反映睡眠—清醒週期顛倒，可見於譫妄。

C：語無倫次與主題跳躍可反映思考混亂，符合譫妄的認知改變。

D：注意力散漫、無法持續聚焦是譫妄最核心的表現之一，非答案。

本題考點：譫妄（delirium）——急性發作、症狀波動與注意力障礙是核心；活動型態（psychomotor subtype）——低活動與高活動表現不同，不能把所有症狀任意拼接。

第 6 題

下列有關於譫妄治療後之後遺症的描述，何者最適當？
  1. （A）各種認知功能的下降
  2. （B）行為問題與適應問題
  3. （C）情緒困擾轉為外化、具高攻擊性
  4. （D）一般沒有明顯的後遺症

答案：（D）

詳解與考點

正解：題眼在「譫妄治療後」與「最適當」——判準是譫妄通常由急性、可逆的生理或藥物因素引起；若及時找出並處理原因，意識與認知狀態可隨之恢復。（D）一般而言，譫妄解除後沒有明顯持續後遺症，是最適當的概括敘述，故選 D；若原有神經認知障礙或病因未處理，恢復情況則須另行評估。

A：廣泛認知功能持續下降較需考慮原有或後續的神經認知障礙，不能視為譫妄治療後的通常結果。

B：持續行為與適應問題不是譫妄解除後的一般性後遺症。

C：情緒困擾固定轉為外化高攻擊性，並非譫妄的典型治療後軌跡。

本題考點：譫妄可逆性（reversibility of delirium）——處理病因後通常可改善；病因評估（etiological assessment）——恢復不佳時須考慮未解決病因或共存神經認知障礙。

第 7 題

臨床上，譫妄較不需要與下列何者作鑑別診斷？
  1. （A）血管性失智症
  2. （B）阿茲海默型失智症
  3. （C）邊緣性人格疾患
  4. （D）詐病

答案：（C）

詳解與考點

正解：題眼在「譫妄較不需要鑑別診斷」——判準是其他狀態是否也可能造成急性認知混亂、注意力改變或症狀表現不一致。（C）邊緣性人格疾患的核心是長期人際關係、自我意象與情緒調節不穩定，通常不以急性意識與注意力波動表現，因此較不需要作為譫妄的優先鑑別，故選 C。

A：血管性失智症可有認知缺損與步階式變化，與譫妄共存或被混淆時需要鑑別。

B：阿茲海默型失智症須與急性譫妄區分，尤其需注意慢性退化上疊加急性譫妄的情形。

D：詐病可能刻意呈現或誇大症狀，當表現與觀察不一致時可納入鑑別。這是最強誘答，因為詐病不是真正的認知疾患；但鑑別診斷也包含確認症狀是否為蓄意製造。

本題考點：譫妄鑑別診斷（differential diagnosis of delirium）——優先區分失智症、物質或醫療因素與症狀製造；邊緣型人格疾患（borderline personality disorder）——屬長期人格模式，非急性注意力障礙。

第 8 題

下列何者是前向失憶症（Anterograde amnesia）？
  1. （A）無法記得受傷後發生的事件
  2. （B）無法記得受傷前發生的事件
  3. （C）無法記得自己的名字
  4. （D）無法記得家人的名字

答案：（A）

詳解與考點

正解：題眼在「前向失憶症」——判準是以受傷或致病事件為時間界線：事件之後無法形成或保留新記憶，才是前向失憶。（A）無法記得受傷後發生的事件，表示受傷後的新經驗無法被正常記憶，符合前向失憶症，故選 A。

B：無法記得受傷前發生的事件是逆向失憶症，時間方向與前向失憶相反。這是最強誘答，因為兩者都涉及「失去記憶」，分辨只看遺忘事件位在受傷時間點之前或之後。

C：無法記得自己的名字可能涉及自傳式記憶或身分定向問題，不能僅由內容判定為前向失憶。

D：無法記得家人的名字同樣是特定既有知識或自傳式記憶問題，不等於受傷後無法形成新記憶。

本題考點：前向失憶症（anterograde amnesia）——受傷後的新記憶形成障礙；逆向失憶症（retrograde amnesia）——受傷前既有記憶的喪失；時間定向（temporal reference）——以致病事件為界判讀失憶方向。

第 9 題

神經心理學者米爾納（B. Milner）提到「對於左腦掌管語言的患者來說，若在左側顳葉損傷時，無論利用 何種刺激呈現的方式，例如：視覺或口語，他們對於語文材料的學習與再認，皆有明顯障礙。」上述內 容主要描述何種現象？
  1. （A）語意記憶缺損（Semantic memory loss）
  2. （B）材料特定性記憶缺損（Material-specific memory loss）
  3. （C）暫時性全面失憶症（Transient global amnesia）
  4. （D）隱性記憶缺損（Implicit memory loss）

答案：（B）

詳解與考點

正解：題眼在「左側顳葉損傷」與「語文材料」，且不論以視覺或口語呈現都受損——判準是記憶缺損是否隨材料的語文／非語文性質而改變。左半球語言優勢者的左顳葉受損，會使語文材料的學習與再認特別困難，這正是材料特定性記憶缺損，故選 B。

A：語意記憶缺損是概念、詞義與一般知識的喪失；題幹強調的是對一類材料的學習與再認受損，不能據此直接判作語意系統缺損。

C：暫時性全面失憶症是突發且暫時的廣泛記憶障礙，題幹描述的是與病灶側化及材料類型相連的缺損，並非短暫全面失憶。

D：隱性記憶涉及不依賴意識提取的技能或促發效果；題幹明示的是語文材料的學習與再認，較屬外顯記憶表現。

本題考點：材料特定性記憶缺損（material-specific memory loss）——語言優勢半球的顳葉病灶較影響語文記憶；語意記憶（semantic memory）與外顯／隱性記憶（explicit/implicit memory）須依受損內容與作業類型區分。

第 10 題

帕佩茲迴路（Papez Circuit）不包含下列何者？
  1. （A）扣帶皮質（Cingulate Cortex）
  2. （B）海馬（Hippocampus）
  3. （C）穹窿（Fornix）
  4. （D）視丘背內核（Dorsomedial Nucleus of Thalamus）

答案：（D）

詳解與考點

正解：題眼在「帕佩茲迴路」與「不包含」——判準是辨認其經典路徑：海馬經穹窿連至乳頭體，再經視丘前核投向扣帶皮質，形成與情緒及記憶相關的環路。視丘背內核不在此經典路徑中，故 D 為應選項。

A：扣帶皮質是帕佩茲迴路的皮質節點，接收來自視丘前核的投射，故非答案。

B：海馬是此迴路的起始核心結構之一，透過穹窿與下游結構相連，故非答案。

C：穹窿是海馬輸出至乳頭體的重要白質纖維束，屬迴路組成，故非答案。

本題考點：帕佩茲迴路（Papez circuit）——核心節點包括海馬、穹窿、乳頭體、視丘前核與扣帶皮質；視丘核團須分辨，背內核不是該經典迴路的節點。

第 11 題

下列有關 DSM-IV-TR 中提出，對於腦震盪後疾患（Postconcussional disorder）的研究指標（Research criteria）之敘述，何者錯誤？
  1. （A）患者記憶缺損的主觀報告
  2. （B）患者要有腦震盪的病史
  3. （C）患者的認知功能缺損要比受傷前差
  4. （D）患者的社會職業功能明顯下降

答案：（A）

詳解與考點

正解：題眼在 DSM-IV-TR 的「研究指標」及「何者錯誤」——判準是腦震盪後疾患不能只憑個案主觀抱怨成立，而要有腦震盪病史、可客觀支持的認知改變及功能受損。A 僅為記憶缺損的主觀報告，未能取代客觀認知缺損的要求，故為應選項。

B：腦震盪病史是把後續認知與情緒症狀連結到腦傷事件的前提，屬研究指標的必要脈絡，故非答案。

C：認知功能須較受傷前下降，重點在確認可觀察的改變，而非僅有不適感，故非答案。

D：社會或職業功能明顯下降顯示症狀具臨床意義，故非答案。

本題考點：腦震盪後疾患（postconcussional disorder）——本題依 DSM-IV-TR 的研究分類作答，現行診斷架構已不同；神經認知診斷須結合腦傷病史、客觀認知證據與功能損害，主觀抱怨本身不足以確立。

第 12 題

臨床上一名語言功能受損的患者，他有明顯命名困難，雖然講話流利，但理解能力不佳。如果要更精確 診斷他患有何種失語症，應繼續做何種衡鑑？
  1. （A）聽覺理解
  2. （B）口語閱讀
  3. （C）句子覆誦
  4. （D）書寫測驗

答案：（C）

詳解與考點

正解：題眼在「命名困難、說話流利、理解不佳」——這組表現已落在流暢型失語症的範圍；要再往下區分韋尼克失語症與經皮質感覺型失語症，關鍵判準就在句子覆誦是否保留——覆誦受損為韋尼克失語症，覆誦相對完整為經皮質感覺型失語症。故應續做（C）句子覆誦衡鑑。

A：聽覺理解已由題幹指出不佳，再測可量化嚴重度，但較不能提供此題所問的關鍵鑑別訊息。

B：口語閱讀會補充閱讀功能，但不是流暢型失語症分類最具辨識力的首要作業。

D：書寫測驗可了解書寫語言是否同受影響，卻不能像覆誦表現那樣直接切分相關失語症型態。這是最強誘答，因為書寫也屬語言衡鑑；錯在它沒有對準本題的鑑別軸。

本題考點：失語症（aphasia）鑑別——命名、理解、流暢度與覆誦是基本軸線；句子覆誦（sentence repetition）特別有助於區分流暢型失語症的類型。

第 13 題

有關「注意力缺失／過動疾患兒童」的父母處理訓練（parent management training），下列何者不屬於常 見的技巧？
  1. （A）以行為處理原理及技巧來處理孩子對立反抗、不聽話，及破壞性行為
  2. （B）以學校和家裡為基礎的獎勵方案（school-home based reward program），來處理孩子在校的行為問題
  3. （C）透過有效的情緒管理，以訓練父母冷靜面對及處理孩子問題行為
  4. （D）單純以無條件尊重態度，來協助改善孩子在校的人際互動問題

答案：（D）

詳解與考點

正解：題眼在 ADHD 父母處理訓練與「不屬於常見技巧」——判準是此訓練以行為原理、具體規則、立即後果及家校一致合作來改變可觀察行為。D 的無條件尊重是人本取向的治療態度，並非父母處理訓練用以改善校園人際行為的標準技術，故為應選項。

A：以增強、忽略、明確指令等行為技巧處理對立與破壞行為，是父母處理訓練的常見內容，故非答案。

B：家校連結的獎勵方案可使目標行為與後果一致，是 ADHD 行為處遇常用做法，故非答案。

C：父母辨識並調節自身情緒，有助於穩定、一致地執行管教策略，屬實務上常見的訓練內容，故非答案。

本題考點：父母處理訓練（parent management training）——以行為改變（behavior modification）為核心；家校合作（school-home collaboration）與一致的增強後果是重要條件；治療態度不能替代可操作的行為方案。

第 14 題

Blair et al（2006）將下列何者，定義為一種冷酷無情的、操控的、欺騙的，和不懊悔的行為模式？
  1. （A）精神官能症（neurosis）
  2. （B）精神病（psychosis）
  3. （C）精神病態（psychopathy）
  4. （D）社會精神官能病態（socio-neuro-pathy）

答案：（C）

詳解與考點

正解：題眼在「冷酷無情、操控、欺騙、不懊悔」這組人格與人際特徵——判準是持續的冷酷無情特質、操弄與缺乏悔意，指向精神病態而非精神病性症狀。故選 C。

A：精神官能症是較舊的廣義用語，常指焦慮、強迫等非精神病性困擾，並不以冷酷操弄及無悔意為核心。

B：精神病的核心是現實檢驗受損，例如妄想或幻覺；題幹描述的是人格特質與人際行為模式，故非答案。這是最強誘答，因為中文名稱相近；錯在 psychosis 與 psychopathy 是不同概念。

D：社會精神官能病態不是此處的標準診斷或人格構念名稱，不能對應題幹定義。

本題考點：精神病態（psychopathy）——核心包含冷酷無情（callousness）、操弄、欺騙與缺乏悔意；精神病（psychosis）則指現實檢驗失調，兩者不可望文生義混同。

第 15 題

Gard 等人（2007）發現，精神分裂患者並非對所有的事物均缺乏愉悅感（anhedonia）。根據此研究，當 患者在進行下列何種活動時，最容易突顯其缺乏愉悅感的缺陷？
  1. （A）享用一頓佳餚
  2. （B）觀賞一齣喜劇
  3. （C）期待隔天將外出旅遊
  4. （D）回憶昨日一場歡樂的聚會

答案：（C）

詳解與考點

正解：題眼在精神分裂患者「並非對所有事物均缺乏愉悅感」——判準是區分當下經驗的愉悅與對未來活動的預期愉悅。患者在當下享用食物或看喜劇時未必缺少愉悅，但較常在預期未來獎賞時低估或難以期待快樂；（C）期待明日旅行最能突顯此缺陷，故選 C。

A：享用佳餚測得較接近當下的消費性愉悅，未必是此研究所指最明顯的缺損。

B：觀賞喜劇也是正在進行的愉悅經驗，不能直接代表預期性愉悅的困難。

D：回憶既往歡樂聚會涉及記憶與回顧評價，與預期未來獎賞的歷程不同。

本題考點：愉悅缺失（anhedonia）——須區分消費性愉悅（consummatory pleasure）與預期性愉悅（anticipatory pleasure）；思覺失調症的相關困難常較明顯出現在對未來正向經驗的預期。

第 16 題

當運用問題解決技巧訓練（problem-solving skills training）時，下列何者不是有品行問題的兒童與青少年 該學會的技巧？
  1. （A）評估所處的社會情境
  2. （B）指認出自己在所處情境，當下的自我陳述及反應
  3. （C）不需對在場其他兒童或青少年動機做歸因
  4. （D）較敏感地察覺其他兒童或青少年的感覺，及產生對問題適當的解決方式

答案：（C）

詳解與考點

正解：題眼在品行問題兒少的「問題解決技巧訓練」與「不是」——判準是訓練要修正敵意歸因偏誤，使個案能先解讀社會線索、考量他人可能意圖，再選擇非攻擊性的回應。C 主張不需對他人動機做歸因，跳過了社會訊息處理的重要步驟，故為應選項。

A：評估社會情境可避免在資訊不足下立即做出攻擊反應，是訓練的起點，故非答案。

B：辨認自己的自我陳述與反應，有助於發現衝動或敵意想法，故非答案。

D：辨識他人感受並產生適切替代方案，能擴充非攻擊性的問題解決反應，故非答案。

本題考點：問題解決技巧訓練（problem-solving skills training）——涵蓋社會線索解讀、自我陳述覺察、歸因重建與替代方案生成；敵意歸因偏誤（hostile attribution bias）是品行問題的重要介入目標。

第 17 題

下列何者不屬於 ADHD 的兒童與青少年常見的認知功能缺陷？
  1. （A）學習疾患
  2. （B）學業功能受損
  3. （C）智能不足
  4. （D）執行功能缺陷

答案：（C）

詳解與考點

正解：題眼在 ADHD「常見的認知功能缺陷」與「不屬於」——判準是 ADHD 的核心困難常延伸到注意力調節、執行功能及學業表現，但不把整體智能不足視為其典型認知缺損。故 C 為應選項。

A：學習疾患與 ADHD 常可共病，讀寫或數學困難也會加重學業負荷，故非答案。

B：持續注意力、作業組織與衝動控制困難可造成學業功能受損，是常見表現，故非答案。

D：抑制、工作記憶、規劃等執行功能困難與 ADHD 高度相關，故非答案。

本題考點：注意力不足／過動症（ADHD）——常見執行功能缺陷（executive dysfunction）與學業功能受損；共病學習疾患須辨識，但智能障礙症不是 ADHD 的典型認知缺損。

第 18 題

關於 ADHD 兒童，下列何者可能成為其日後傾向發展成品性問題（conduct problem）的一項特殊預兆？
  1. （A）認知抑制性（cognitive inhibition）
  2. （B）認知易衝動性（cognitive impulsivity）
  3. （C）行為易衝動性（behavioral impulsivity）
  4. （D）行為抑制性（behavioral inhibition）

答案：（C）

詳解與考點

正解：題眼在 ADHD 日後發展品行問題的「特殊預兆」——判準是會直接推動違規、攻擊或不顧後果行為的外顯控制困難。行為易衝動性使兒童較容易在未停下評估後果前就採取行動，與後續品行問題的風險相連，故選 C。

A：認知抑制性指能壓住不合宜想法或反應的能力，若功能較佳反而具有保護意義，故非答案。

B：認知易衝動性涉及思考歷程快而不周延，但本題所指較具預測力的是可觀察的行為失控。這是最強誘答，因為兩者都帶有「衝動」；錯在認知傾向不等同外顯違規行為的直接預兆。

D：行為抑制性是暫停反應、等待與遵守規範的能力，方向與風險因子相反，故非答案。

本題考點：衝動性（impulsivity）——須區分認知易衝動性與行為易衝動性（behavioral impulsivity）；品行問題（conduct problem）的風險評估尤其關注外顯行為抑制不足。

第 19 題

關於非語言學習障礙（NLD）之缺陷敘述，下列何者錯誤？
  1. （A）左側大腦功能異常，右側大腦功能正常
  2. （B）數學能力比閱讀能力表現差
  3. （C）社交技巧、空間概念有缺陷
  4. （D）對複雜情境之整合判斷能力有缺陷

答案：（A）

詳解與考點

正解：題眼在非語言學習障礙的缺陷與「何者錯誤」——判準是其典型輪廓偏向視覺空間、整合與社會知覺困難，常被認為與右半球功能失調較有關。A 將半球方向講反：左側功能異常、右側正常不符合這個經典描述，故為應選項。

B：非語言學習障礙者常有相對保留的閱讀解碼能力，但數學與視覺空間推理較弱，故非答案。

C：社交線索掌握與空間概念困難是其常見的非語言缺陷，故非答案。

D：面對複雜、需整合多重線索的情境時判斷困難，符合其整合處理弱勢，故非答案。

本題考點：非語言學習障礙（nonverbal learning disability, NLD）——相對強項常在語文解碼，弱項在視覺空間、社會知覺與整合；半球側化的說法屬經典理論性描述，臨床衡鑑仍須以個別認知輪廓為準。

第 20 題

關於普拉德威利症（Prader-Willi syndrome）的敘述，下列何者錯誤？
  1. （A）容易產生輕到中度智能不足
  2. （B）2 到 6 歲易因食量過多而體重過重
  3. （C）主要因第 12 對染色體異常造成
  4. （D）嬰兒時期出現肌肉張力過低現象

答案：（C）

詳解與考點

正解：題眼在普拉德威利症與「何者錯誤」——判準是其遺傳異常並非第 12 對染色體，而是涉及第 15 對染色體區域的基因表現問題。C 的染色體編號錯誤，故為應選項。

A：此症患者可有輕至中度的智能與適應功能困難，故非答案。

B：幼兒期出現食慾亢進、難有飽足感而體重過重，是典型發展歷程的一部分，故非答案。

D：嬰兒期肌肉張力過低是常見早期臨床線索，故非答案。

本題考點：普拉德威利症（Prader-Willi syndrome）——早期常見肌肉張力過低，後續可出現過度進食與肥胖風險；其遺傳機轉涉及第 15 對染色體相關區域，不是第 12 對。

第 21 題

有關 Disorder of Written Expression 常見的症狀，下列何者錯誤？
  1. （A）句子中常出現文法或標點錯誤
  2. （B）手部運動協調困難
  3. （C）段落組織不良
  4. （D）筆跡難以辨識

答案：（B）

詳解與考點

正解：題眼在書寫表達障礙的「常見症狀」與「何者錯誤」——判準是核心困難在書面語言產出，如拼字、文法、標點及組織，而非手部動作協調本身。B 的手部運動協調困難較指向發展性協調問題，不能作為書寫表達障礙的典型症狀，故為應選項。

第 22 題

根據 DSM-IV-TR 的分類方式，智能不足的患者人數以何種程度所占比例最高？
  1. （A）輕度智能不足
  2. （B）中度智能不足
  3. （C）重度智能不足
  4. （D）極重度智能不足

答案：（A）

詳解與考點

正解：題眼在 DSM-IV-TR 的分類及「比例最高」——判準是該版本的智能不足嚴重度分布中，輕度者在人數上最多，較嚴重等級所占比例依序較少。故選 A。

第 23 題

關於兒童期精神分裂症之特徵敘述，下列何者正確？
  1. （A）目前認為，診斷標準與成年期精神分裂症之診斷標準不同
  2. （B）通常發生於 18 歲之前
  3. （C）通常是突然發生，沒有任何前兆
  4. （D）儘早治療，其預後較成年期精神分裂症好

答案：（B）

詳解與考點

正解：題眼在「兒童期精神分裂症」的特徵——判準是將其視為極早發病的思覺失調症，核心症狀與成人期相同但起病在成年前。B 表示通常發生於 18 歲之前，符合兒童期／早發性範圍，故選 B。

A：其診斷原則基本沿用成人期思覺失調症，差別在發展階段的表現與鑑別，不是另一套診斷標準。

C：多數個案在明顯精神病症狀前可見前驅的社會、學業或發展功能改變，並非通常毫無前兆地突然發生。

D：越早發病常伴隨較長的病程及發展衝擊，預後通常不較成人期更好。這是最強誘答，因為早期介入有助處遇；錯在早治療的原則不能改變早發病本身較不利的預後關聯。

本題考點：兒童期思覺失調症（childhood-onset schizophrenia）——本題沿用舊題名稱，現行中文名稱為思覺失調症；早發病可有前驅期，診斷標準與成人期核心相同，整體預後較具挑戰。

第 24 題

嵌入圖形測驗（embedded figure test）可用來檢測自閉症兒童的何種認知缺陷？
  1. （A）心智理論能力（theory of mind）
  2. （B）執行功能（executive function）
  3. （C）共享式注意力（joint attention）
  4. （D）核心統整能力（central coherence）

答案：（D）

詳解與考點

正解：題眼在嵌入圖形測驗——判準是此作業要求從複雜整體中抽離出局部圖形，因而檢驗偏重局部、較難整合成整體意義的認知風格。這對應自閉症的核心統整能力弱勢，故選 D。

A：心智理論測量的是理解他人信念、意圖與觀點的能力，常用錯誤信念等社會認知作業，不是嵌入圖形測驗的主要指標。

B：執行功能包括抑制、轉換與規劃；雖與自閉症相關，嵌入圖形測驗的核心要求不是這些控制歷程。

C：共享式注意力是與他人共同指向、追隨注意焦點的早期社會溝通能力，不能由圖形抽離作業直接檢測。

本題考點：嵌入圖形測驗（embedded figure test）——評估從整體背景抽離局部訊息的能力；核心統整（central coherence）理論主張自閉症類群障礙症可呈現較偏局部處理的認知風格。

第 25 題

有關兒童期的心理疾患，下列何者的初發年齡範疇最大？
  1. （A）創傷後壓力疾患
  2. （B）注意力不足過動疾患
  3. （C）自閉性疾患
  4. （D）學習疾患

答案：（A）

詳解與考點

正解：題眼在「初發年齡範疇最大」——判準不是何者最早被發現，而是疾患可在生命歷程中首次出現的年齡跨度。創傷後壓力疾患須有創傷暴露，而創傷可發生在不同年齡，因此初發範疇可從兒童延伸至成人，最為寬廣，故選 A。

B：ADHD 的症狀須在兒童發展早期出現，其初發窗較集中於兒童期，故非答案。

C：自閉性疾患屬早期神經發展性疾患，症狀在幼兒發展階段即顯現，故非答案。

D：學習疾患多於正式學習需求增加時被辨識，初發與發現年齡皆較集中於學齡階段，故非答案。

本題考點：初發年齡（age at onset）——創傷後壓力疾患（posttraumatic stress disorder, PTSD）的發病需連結創傷時點，因而跨度廣；神經發展性疾患的症狀出現則主要集中於早期發展與學習階段。

第 26 題

有關 DSM-IV-TR 焦慮性疾患的病程發展，那一項的男性出現年紀會明顯比女性要早？
  1. （A）強迫性疾患
  2. （B）社交焦慮疾患
  3. （C）廣泛性焦慮疾患
  4. （D）創傷後壓力疾患

答案：（A）

詳解與考點

正解：題眼在 DSM-IV-TR 焦慮性疾患的病程及「男性明顯較早」——判準是比較各疾患的性別起病型態。強迫性疾患的男性個案常較早發病，女性則可在較晚年齡出現較多個案，故選 A。

B：社交焦慮疾患多在兒童後期至青少年期出現，題目所問的明顯男性早發差異不是其典型辨識點。

C：廣泛性焦慮疾患的病程常較慢性，症狀起始未以男性明顯較早為主要特徵，故非答案。

D：創傷後壓力疾患的起病與創傷暴露時點密切相關，不能以此作為男性早發的典型性別差異，故非答案。

本題考點：強迫性疾患（obsessive-compulsive disorder, OCD）——本題依 DSM-IV-TR 的病程描述作答；流行病學與診斷分類均具版本及樣本差異，考試上以「男性較早發病」作為此題的辨識線索。

第 27 題

關於兒童及青少年憂鬱症的神經生物學論述，下列何者錯誤？
  1. （A）HPA 軸的活化問題較少涉入
  2. （B）Amygdala 有過度活化問題
  3. （C）涉及學習與情緒記憶的區域較多活化
  4. （D）涉及注意力及感官歷程的腦區會過少活動

答案：（A）

詳解與考點

正解：題眼在兒童及青少年憂鬱症的神經生物學與「何者錯誤」——判準是憂鬱相關壓力反應並非較少涉及 HPA 軸；壓力調節與 HPA 軸活化異常正是重要研究方向。A 把方向講反，故為應選項。

B：杏仁核常見對負向或情緒刺激反應偏高的發現，符合情緒顯著性處理異常，故非答案。

C：與情緒記憶及學習相關的神經網路活動改變，屬兒少憂鬱症可探討的神經生物學面向，故非答案。

D：注意力與感官歷程相關腦區的低活化，可與憂鬱的注意資源及動機問題相連，故非答案。

本題考點：兒少憂鬱症（depression in children and adolescents）——HPA 軸（hypothalamic-pituitary-adrenal axis）與壓力調節是重要面向；杏仁核（amygdala）情緒反應與注意控制網路的功能改變須以方向辨析。

第 28 題

下列何者不是兒童及青少年憂鬱症的理論解釋？
  1. （A）依附理論（Attachment theory）
  2. （B）心理動力理論（Psychodynamic theory）
  3. （C）高壓理論（Coercion theory）
  4. （D）反應連結的正增強（Response-contingent positive reinforcement）

答案：（C）

詳解與考點

正解：題眼在兒童及青少年憂鬱症的「理論解釋」與「不是」——判準是該理論是否本來就在解釋失落、負向自我表徵、增強不足或親子關係與內化症狀的路徑。高壓理論主要用於說明親子互動中強制性的負向循環與外化行為問題，不是憂鬱症的典型理論解釋，故 C 為應選項。

A：依附理論可從早期依附關係、內在運作模式與情緒調節解釋憂鬱脆弱性，故非答案。

B：心理動力理論可由失落、內化的憤怒與自我評價理解憂鬱，故非答案。

D：反應連結的正增強不足可解釋活動減少、退縮與低落情緒的循環，是行為取向的憂鬱模型，故非答案。

本題考點：兒少憂鬱症理論（theories of child and adolescent depression）——依附理論（attachment theory）、心理動力理論（psychodynamic theory）與反應連結的正增強（response-contingent positive reinforcement）可用於解釋內化症狀；高壓理論（coercion theory）主要關注外化行為的互動循環。

第 29 題

根據 DSM-IV-TR ， 患者只要持續一個月出現下列何種症狀 ， 即符合精神分裂症的特徵性症狀 （characteristic symptoms）？
  1. （A）相信自己被檢調單位監視
  2. （B）感覺皮下有蟲在爬
  3. （C）說話內容很難令人理解，溝通困難
  4. （D）相信自己的思想受外星人掌控

答案：（D）

詳解與考點

正解：題眼在「DSM-IV-TR」與「只要持續一個月」——判準是準則 A 的單項即足例外。特徵性症狀原則上須兩項以上持續一個月，但妄想若屬怪異（bizarre，內容在現實中不可能發生），則單一症狀持續一個月即符合。D 的「相信自己的思想受外星人掌控」屬怪異的被控制妄想，正落在該例外，故選 D。現行 DSM-5 中文版稱思覺失調症。

A：相信自己被檢調單位監視屬非怪異妄想——遭到監視在現實中確實可能發生，不適用單項即足的例外，故非答案。

B：感覺皮下有蟲在爬屬觸幻覺，不在該例外所列（例外只涵蓋怪異妄想，以及持續評論當事人行為或兩人以上交談的幻聽），故非答案。

C：說話內容難以理解可能是失序語言，同樣不在單項即足之列，仍須與其他特徵性症狀併計。這是最強誘答，因為它接近典型的失序症狀；錯在題目問的是哪一項症狀單獨持續一個月即符合準則。

本題考點：DSM-IV-TR 準則 A（characteristic symptoms）——原則上須兩項症狀持續一個月；怪異妄想（bizarre delusion）與特定形式的幻聽——單項即足的例外；被控制妄想（delusion of control）——思想或行為受外力支配。

第 30 題

下列何種心理治療典範，會直接針對精神分裂患者妄想的症狀與內容進行介入？
  1. （A）認知提升治療（Cognitive enhancement therapy）
  2. （B）認知行為治療（Cognitive behavior therapy）
  3. （C）社交技巧訓練（Social skills training）
  4. （D）個案管理（Case management）

答案：（B）

詳解與考點

正解：題眼在「直接針對」妄想內容——判準是治療是否檢視信念證據、替代解釋與因應策略。認知行為治療會合作評估妄想及其困擾，故選 B。

A：認知提升治療訓練注意、記憶與執行功能，不以妄想內容為核心。

C：社交技巧訓練改善溝通與人際能力，不能直接檢驗妄想。

D：個案管理整合醫療與社會資源。這是最強誘答，因為它能降低照護中斷，錯在處理服務協調而非妄想內容。

本題考點：精神病性疾患認知行為治療（cognitive behavioral therapy for psychosis）——直接處理信念；認知復健（cognitive remediation）——改善認知；個案管理（case management）——協調照護。

第 31 題

下列何種因素與精神分裂症的預後較差有關？
  1. （A）初次發病年齡較晚（如：40 歲後）
  2. （B）有情感性疾患的家族史
  3. （C）症狀的活躍期（active phase）較短
  4. （D）男性

答案：（D）

詳解與考點

正解：題眼在「預後較差」——判準是病程與功能恢復的風險因子。男性通常與較早發病、較差病前適應及較不利病程有關，故選 D；題幹舊名現稱思覺失調症。

A：較晚發病通常保留較多病前社會與職業功能，整體較有利。

B：情感性疾患家族史不是典型不良預後指標。

C：活躍期較短代表嚴重症狀持續較少，通常較有利。最強誘答在於「活躍期」聽來嚴重，但較短的方向其實較佳。

本題考點：精神分裂症預後（prognosis）——較晚發病、較佳病前功能及較短活躍期通常較有利；性別差異（sex differences）——男性病程風險較不利。

第 32 題

研究顯示有高比例的精神分裂患者出生時均有併發症；但在出生時有併發症的群體中，罹患精神分裂的 比例卻沒有比一般人高。此結果說明了下列何者？
  1. （A）這類的研究多仰賴回溯性的資料，所以容易有不一致的現象
  2. （B）出生時有無併發症應與精神分裂疾患無關
  3. （C）同時有疾病的基因素質（genetic diathesis）與併發症才可能會增高罹病的風險
  4. （D）是否罹患精神分裂疾患是由基因遺傳決定

答案：（C）

詳解與考點

正解：題眼在患者中併發症比例高、但有併發症者未較高風險——判準是素質與壓力的交互作用。出生併發症可能只在具遺傳素質者身上提高罹病風險，故選 C。

A：回溯偏差不能具體解釋題幹呈現的風險模式。

B：患者中比例偏高仍提示可能是風險因子；不是充分原因不等於完全無關。

D：遺傳素質重要，不等於完全由基因決定。這是最強誘答，因為它抓到遺傳因素，卻忽略環境交互作用。

本題考點：素質—壓力模型（diathesis-stress model）——易感性與環境壓力共同影響風險；基因—環境交互作用（gene-environment interaction）——暴露效果因素質而異。

第 33 題

有關情緒表露（expressed emotion）的研究敘述，下列何者正確？
  1. （A）高情緒表露家庭中，其成員的負面批評會致使精神分裂患者的症狀更惡化
  2. （B）低情緒表露家庭中，成員只要稍有負面批評就會使精神分裂患者的症狀更惡化
  3. （C）低情緒表露家庭中，患者的負性症狀較正性症狀更易復發
  4. （D）高情緒表露家庭中，患者的負性症狀較正性症狀更易復發

答案：（A）

詳解與考點

正解：題眼在「情緒表露」——判準是高情緒表露家庭的批評、敵意與過度情緒涉入會增加復發及症狀惡化風險，故選 A；題幹舊名現稱思覺失調症。

B：低情緒表露不是任何微小批評都必然致惡化，其核心正是較低批評與情緒涉入。

C：低情緒表露不是以負性症狀特別容易復發為定義。

D：高情緒表露的重點是整體復發，非負性症狀必比正性症狀易復發。這是最強誘答，因為保留正確術語卻錯置結果。

本題考點：情緒表露（expressed emotion）——批評、敵意與過度情緒涉入；復發風險（relapse risk）——高情緒表露與較不利病程相關。

第 34 題

根據 DSM-IV-TR，張先生 65 歲，6 個月前第一次出現精神症狀，他於 5 週前開始服用抗精神病藥物 （antipsychotic drugs），但於近日內卻開始有臉部、舌頭、嘴巴及身體不自主且重複的動作（如：用嘴唇 發出波波的聲響、身體前後擺動與發出咀嚼的聲音）等症狀，這表示張先生可能有：
  1. （A）抗精神病藥物惡性症候群（Neuroleptic Malignant Syndrome）
  2. （B）抗精神病藥物誘發之巴金氏症（Neuroleptic-Induced Parkinsonism）
  3. （C）抗精神病藥物誘發之遲滯性運動失能（Neuroleptic-Induced Tardive Dyskinesia）
  4. （D）抗精神病藥物誘發之靜坐失能（Neuroleptic-Induced Akathisia）

答案：（C）

詳解與考點

正解：題眼在用藥後「臉、舌、嘴巴」反覆不自主動作——判準是遲滯性運動失能的口面舌部重複動作，故選 C。本題依 DSM-IV-TR 與題幹藥物舊分類辨析；不良反應處置具時效敏感性，須由臨床醫師評估。

A：抗精神病藥物惡性症候群是高熱、肌肉僵硬與自主神經不穩等全身反應。

B：藥物誘發巴金氏症較像僵硬、顫抖與動作遲緩，方向是動作減少。

D：靜坐失能是坐立難安；最強誘答是它也會反覆動作，錯在其是內在不安與整體活動，不是典型口面舌不自主運動。

本題考點：遲滯性運動失能（tardive dyskinesia）——口面舌不自主動作；藥物誘發巴金氏症（drug-induced parkinsonism）——僵硬與動作遲緩；靜坐失能（akathisia）——坐立難安。

第 35 題

王強因為腦瘤而在過去半年中出現過兩次符合躁狂發作的週期，此時 DSM-IV-TR 的第一軸該記載的診斷 名稱最可能是下列何者？
  1. （A）雙極性疾患第一型
  2. （B）一般醫療情況導致的情感疾患
  3. （C）雙極性疾患第一型；一般醫療情況導致的情感疾患
  4. （D）第一軸不做任何診斷，僅在第三軸記載「腦瘤」

答案：（B）

詳解與考點

正解：題眼在「腦瘤」與躁狂週期——判準是症狀若為一般醫療情況的直接生理結果，DSM-IV-TR 第一軸應診斷一般醫療情況導致的情感疾患，故選 B。本題依題幹的 DSM-IV-TR 多軸系統辨析；現行分類已不採此軸別。

A：原發性雙極性疾患第一型不應用於已明示由腦瘤引起的躁狂症狀。

C：不能把同次由腦瘤引起的症狀又診斷為原發性雙極性疾患。

D：第三軸可記腦瘤，但不能取代第一軸精神疾患診斷。這是最強誘答，因腦瘤確要記錄，錯在病因記載不能取代診斷。

本題考點：一般醫療情況導致的情感疾患（mood disorder due to a general medical condition）——直接生理效應；鑑別診斷（differential diagnosis）——區分原發性與醫療狀況所致。

第 36 題

下列何者為抗精神病藥物（antipsychotic drugs）？
  1. （A）Olanzapine（如，金菩薩 Zyprexa）
  2. （B）Lithium（鋰鹽）
  3. （C）Imipramine（如，妥富腦 Tofranil）
  4. （D）Divalproex sodium（如，帝拔癲 Depakote）

答案：（A）

詳解與考點

正解：題眼在「抗精神病藥物」——判準是主要藥理分類。Olanzapine 是非典型抗精神病藥物，故選 A。本題藥物分類依題幹用語辨析；處方與副作用監測具時效敏感性，須依醫囑與現行指引。

B：Lithium 是情緒穩定劑，不是抗精神病藥物。

C：Imipramine 是三環抗憂鬱劑。

D：Divalproex sodium 是抗癲癇藥兼情緒穩定劑。這是最強誘答，因它可用於躁期，但「治療躁期」不等於抗精神病藥物分類。

本題考點：抗精神病藥物（antipsychotics）——用於精神病性症狀；情緒穩定劑（mood stabilizers）——調節雙相情緒障礙症病程；三環抗憂鬱劑（tricyclic antidepressants）——抗憂鬱類別。

第 37 題

根據 DSM-IV-TR，若躁狂發作患者僅出現下列那一項主要情感症狀（診斷準則 A），則需要至少四項附 屬症狀（診斷準則 B）才符合診斷？
  1. （A）意念飛躍
  2. （B）易怒心情
  3. （C）高昂心情
  4. （D）開闊心情

答案：（B）

詳解與考點

正解：題眼在「僅出現」與躁狂發作準則 A——判準是 DSM-IV-TR 對單獨易怒心情的較嚴格附屬症狀要求：只有易怒、沒有高昂或開闊心情時，才須至少四項附屬症狀，故選 B。本題依題幹 DSM-IV-TR 準則作答；門檻具版本敏感性。

A：意念飛躍是附屬症狀，不是主要情感症狀。

C：高昂心情不是提高門檻的情況。

D：開闊心情規則與 C 相同。這是最強誘答，因它也見於躁期；關鍵是「只有易怒」才適用較高門檻。

本題考點：躁狂發作（manic episode）——主要情感與附屬症狀分層判讀；易怒心情（irritable mood）——單獨出現時適用較嚴格 DSM-IV-TR 門檻。

第 38 題

依 DSM-IV-TR，成人循環性情感疾患（Cyclothymic Disorder）的病程所需時間至少為：
  1. （A）6 個月
  2. （B）9 個月
  3. （C）1 年
  4. （D）2 年

答案：（D）

詳解與考點

正解：題眼在「成人循環性情感疾患」與「至少」——判準是 DSM-IV-TR 成人病程最低時間。成人至少須持續 2 年，故選 D。本題依題幹 DSM-IV-TR 診斷要件作答；現行 DSM-5 中文版稱循環性情緒障礙症。

A：6 個月不足成人最低病程。

B：9 個月同樣不足。

C：1 年仍不足。這是最強誘答，因未成年人的門檻不同，題幹明確限定成人。

本題考點：循環性情感疾患（cyclothymic disorder）——慢性波動的輕躁與憂鬱症狀；病程門檻（duration criterion）——成人 DSM-IV-TR 至少 2 年；版本敏感性（version sensitivity）——依題幹版本判讀。

第 39 題

有關分裂情感性疾患（Schizoaffective Disorder）與精神分裂症之敘述，下列何者錯誤？
  1. （A）前者患者必須有情感性症狀，後者患者必須無情感性症狀
  2. （B）前者的慢性化程度通常比後者更輕
  3. （C）兩者患者的社會功能損害皆很常見
  4. （D）前者比後者更少見

答案：（A）

詳解與考點

正解：題眼在「何者錯誤」與分裂情感性疾患——判準是前者有情感與精神病性症狀，但精神分裂症並非必須完全沒有情感性症狀。A 把後者說成「必須無」情感性症狀，錯誤，故為應選項；本題依 DSM-IV-TR 舊名辨析，現行稱思覺失調症。

B：分裂情感性疾患的慢性化程度通常可較精神分裂症輕，為可接受概括。

C：兩者都常見社會與職業功能損害，故非答案。

D：前者較後者少見，故非答案。最強誘答是 B，因預後不能視為所有個案必然結果；但題問一般趨勢，A 的絕對化錯誤更明確。

本題考點：分裂情感性疾患（schizoaffective disorder）——情感與精神病性症狀的病程關係；精神分裂症（schizophrenia）——可有情感症狀；絕對化語句——「必須無」須檢驗。

第 40 題

有關短期精神病性疾患（Brief Psychotic Disorder）的敘述，下列何者錯誤？
  1. （A）診斷準則為出現精神分裂症活躍期的正性或負性症狀至少一項
  2. （B）患者通常會經驗到強烈情緒波動或意識混亂
  3. （C）患者通常有高自殺危險
  4. （D）此疾患最終會完全康復

答案：（A）

詳解與考點

正解：題眼在「何者錯誤」與短期精神病性疾患——判準是 DSM-IV-TR 至少包括妄想、幻覺、失序語言等核心正性症狀之一，不能僅以負性症狀成立。A 說正性或負性症狀至少一項，錯誤，故為應選項。本題依 DSM-IV-TR 作答，病程與診斷要件具版本敏感性。

B：急性發作可見強烈情緒波動或混亂，故非答案。

C：急性精神病性狀態可能伴隨自殺風險，須做危機評估，故非答案。

D：診斷概念包含回復原先功能水準的預期。最強誘答在於「完全康復」很絕對，但它反映與慢性精神病性疾患的核心區別；A 的錯誤更明確。

本題考點：短期精神病性疾患（brief psychotic disorder）——急性症狀與功能恢復；正性症狀（positive symptoms）——妄想、幻覺與失序；負性症狀（negative symptoms）——不能單獨滿足本題核心條件。
