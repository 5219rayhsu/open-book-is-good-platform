第 1 題

關於簡短智能狀態評估（Mini-Mental State Examination, MMSE）的敘述，下列何者錯誤？
  1. （A）施測相當簡易
  2. （B）攜帶方便
  3. （C）對於不同類型腦部功能受損偵測特異性佳
  4. （D）廣泛被使用

答案：（C）

詳解與考點

考點為簡短智能狀態評估（MMSE）的特性與限制。MMSE施測簡易、攜帶方便、使用廣泛，但其缺點是無法針對不同類型腦部受損做特異性鑑別（特異性不佳），故「特異性佳」的敘述錯誤為正解C。陷阱在MMSE作為篩檢工具優點明顯，易忽略它僅能粗略篩檢、無法定位病灶類型的限制。

第 2 題

下列何因素最可能造成可逆性失智症（reversible dementia）？
  1. （A）水腦症（hydrocephalus）
  2. （B）巴金森氏症（Parkinson’s disease）
  3. （C）腦血管中風（cerebrovascular accident）
  4. （D）庫-賈氏症（Creutzfeldt-Jakob disease）

答案：（A）

詳解與考點

考點為可逆性失智症的成因。常壓性水腦症是典型可逆性失智，經腦脊髓液引流可改善認知，故正解為水腦症A。陷阱在帕金森氏症、腦中風、庫賈氏症皆為不可逆的神經退化或破壞性病變，須掌握水腦症（連同甲狀腺低下、維生素缺乏等）屬可治療可逆的類別。

第 3 題

行為型額顳葉型失智症（behavioral variant frontotemporal dementia）患者出現下列何項症狀或症候群之可能性最低？
  1. （A）執行功能缺損（dysexecutive syndrome）
  2. （B）淡漠（apathy）
  3. （C）失去抑制（disinhibition）
  4. （D）視空間能力（visuospatial abilities）受損

答案：（D）

詳解與考點

考點為行為型額顳葉型失智症（bvFTD）的症狀特徵。bvFTD以額葉受損為主，表現執行功能缺損、淡漠、去抑制等行為人格變化，視空間能力相對保留，故出現視空間受損的可能性最低，為正解D。陷阱在阿茲海默症早期即見視空間障礙，易把兩種失智混淆，bvFTD的視空間相對完好是鑑別重點。

第 4 題

王同學騎摩托車，因速度太快而撞上安全島，送至急診室治療，他在Glasgow coma scale為12分且失去意識約1小時，根據DSM-5，他是屬於下列何項程度的traumatic brain injury（TBI）？
  1. （A）不符合TBI
  2. （B）輕度（mild TBI）
  3. （C）中度（moderate TBI）
  4. （D）重度（severe TBI）

答案：（C）

詳解與考點

考點為DSM-5創傷性腦傷（TBI）的嚴重度分級。本例昏迷指數12分、意識喪失約1小時，意識喪失介於30分鐘至24小時、GCS於後續落在9-12區間，符合中度TBI的判準，故正解為C。陷阱在GCS 12分單看接近輕度上限，但意識喪失達1小時（超過30分鐘）即拉高至中度，須以意識喪失時間綜合判定。

第 5 題

有關失智與譫妄的鑑別，下列何者最不適當？
  1. （A）失智症的病程通常是逐漸變差、譫妄則是急速發生
  2. （B）兩者都可能出現注意力缺失
  3. （C）失智症通常為漸進式退化、譫妄通常病程可逆
  4. （D）失智症在老年人較常發生、譫妄則與年齡無關

答案：（D）

詳解與考點

考點為失智症與譫妄的鑑別診斷。失智多為慢性、漸進退化，譫妄則急性發作、病程常可逆，兩者都可能有注意力缺損。選項 D「譫妄與年齡無關」最不適當，因為高齡正是譫妄的重要危險因子，老年人因腦儲備不足更易發作，故 D 錯。陷阱在 B，注意力缺失看似只屬譫妄，但失智後期亦會出現，故 B 敘述其實正確不選。

第 6 題

譫妄（delirium）之盛行率在下列何項族群中為最高？
  1. （A）住院病患
  2. （B）臨終病患
  3. （C）機構中的老年人
  4. （D）急診病患

答案：（B）

詳解與考點

考點為譫妄盛行率的族群差異。譫妄在生理急劇惡化、多重器官衰竭時最易發作，臨終病患因瀕死過程代謝紊亂，盛行率最高（常達八成以上），故答案 B。陷阱在 C 機構老年人，雖屬高危險群且常被誤選，但其盛行率仍低於臨終階段。住院與急診病患亦高，但都不及臨終病患的極端比例。

第 7 題

下列何者最不可能是導致失憶症的病因？
  1. （A）單純皰疹腦炎
  2. （B）後大腦動脈梗塞
  3. （C）顳葉切除手術
  4. （D）外頸動脈栓塞

答案：（D）

詳解與考點

考點為失憶症的神經解剖病因，關鍵在內側顳葉與海馬迴的供血與構造。單純皰疹腦炎、後大腦動脈梗塞、顳葉切除手術都直接傷及內側顳葉記憶系統。外頸動脈主要供應顏面與頭皮，不灌流腦內記憶結構，故 D 最不可能致失憶。陷阱在易把外頸動脈與內頸／後大腦動脈混淆，後者才供應海馬迴。

第 8 題

下列何種失智症的神經病理最可能以失語症為主要表現？
  1. （A）額顳葉型失智症（frontotemporal dementia）
  2. （B）路易氏體症（Lewy body disease）
  3. （C）巴金森氏症（Parkinson's disease）
  4. （D）後部皮質退化病（posterior cortical atrophy）

答案：（A）

詳解與考點

考點為各類失智症的核心臨床表現對應。額顳葉型失智的語言變異型（如原發性進行性失語）以失語症為主要表現，故答案 A。陷阱在 D 後部皮質退化，雖也屬退化性，但其核心是視覺空間與視知覺缺損而非語言。路易氏體以波動認知與視幻覺、巴金森以動作症狀為主，皆非以失語為主。

第 9 題

多數學者認為執行功能包含多種向度能力，而執行功能障礙患者之介入計畫，應儘可能含括各向度能力的訓練，其中不包括？
  1. （A）意圖行為（intentional behavior）的促成
  2. （B）制定目標、形成計畫與決策能力
  3. （C）整體智能的提升
  4. （D）目標導向行為的維持、自我監控與修正能力

答案：（C）

詳解與考點

考點為執行功能障礙的復健介入向度。執行功能含意圖行為促成、目標設定與計畫決策、目標導向行為的維持自我監控與修正等。整體智能提升並非執行功能訓練的目標，執行功能與一般智能是相對獨立的構念，故答案 C 不包括。陷阱在誤以為提升智商可連帶改善執行功能，實際介入是針對特定歷程而非整體 IQ。

第 10 題

根據M. Lezak等人（2012）的定義，自我調整（self-regulation）功能亦是執行功能的構成要件之一。下列何者並非自我調整功能的主要內涵？
  1. （A）促成行為／反應的產出（productivity）
  2. （B）保持思考的彈性（flexibility）、不僵化
  3. （C）衝動行為的控制
  4. （D）思考時能保持概念轉換順暢

答案：（C）

詳解與考點

正解 C。依 Lezak 等人（2012）的架構，執行功能包含「意志（volition）」「計畫（planning）」「有目的的行動（purposive action）」與「有效表現（effective performance/self-regulation／自我監控）」等成分；題幹所指的自我調整功能，主要內涵在於監控與調節正在進行中的行為，包括維持思考彈性、不僵化（B）、概念轉換的順暢（D），以及確保行為／反應能被有效產出（A，即監控執行效能）。

C「衝動行為的控制」屬於更上游的注意力／抑制控制與行為啟動調節範疇，並非 Lezak 自我調整功能（有效表現／自我監控）的主要內涵，故為本題的「非主要內涵」，選 C。

注意：本題在問「並非」自我調整主要內涵者，A、B、D 皆屬之，僅 C 不屬於該層次的核心成分。

第 11 題

下列何種執行功能障礙與大腦位置之配對較為正確？
  1. （A）失去行為抑制功能，上內側額葉受損
  2. （B）失去判斷優先順序之功能，下內側額葉受損
  3. （C）工作記憶功能下降，腹內側額葉受損
  4. （D）失去彈性思考，背外側額葉受損

答案：（D）

詳解與考點

考點為執行功能障礙與額葉分區的配對。背外側額葉與彈性思考、工作記憶、計畫有關，受損致僵化與轉換困難，故答案 D 正確。陷阱在前三項配對錯置：行為抑制與判斷優先順序主要關乎眶額／腹內側區，工作記憶屬背外側而非腹內側，易因區位名稱相近而誤選。

第 12 題

患者左右手都無法依照指令做動作，也無法模仿別人的動作，但是卻在偶然間做出同樣的動作，這是下列何者的症狀？
  1. （A）意念型失用症（ideational apraxia）
  2. （B）意動型失用症（ideomotor apraxia）
  3. （C）建構型失用症（constructional apraxia）
  4. （D）肢動型失用症（limb-kinetic apraxia）

答案：（B）

詳解與考點

考點為失用症分型。病人無法依指令或模仿做動作，卻在自然情境中偶然能完成同一動作，這種「指令與自發分離」是意動型失用症（ideomotor apraxia）的典型表現，故答案 B。陷阱在 A 意念型失用，其特徵是無法執行連續性多步驟動作的程序順序，而非指令與自發的分離。

第 13 題

針對建構型失用症（constructional apraxia）的評估，若檢查時間受限，下列那一項測驗不會列為優先選擇？
  1. （A）魏氏智力測驗之圖形設計分測驗
  2. （B）Benton視覺保留測驗（Benton Visual Retention Test）
  3. （C）魏氏智力測驗之圖畫補充（Picture Completion）分測驗
  4. （D）三度空間方塊建構測驗（Three-Dimensional Block Construction Test）

答案：（C）

詳解與考點

考點為建構型失用症的評估工具選擇。建構型失用須評估視覺空間建構能力，圖形設計、Benton 視覺保留、三度空間方塊建構都直接測建構。圖畫補充測的是視覺概念與細節辨識，非建構操作，時間有限時不優先選，故答案 C。陷阱在誤以為凡屬視知覺測驗皆適用建構評估。

第 14 題

王先生車禍後被家人緊急送院，一時間無法自行答話。大約30分鐘之後，醫生問他住址、職業等都可以回答如流，但是對於他在何處受傷、如何受傷、誰和他同車等問題卻無法答覆，這可能是下列那一種認知功能受損？
  1. （A）前瞻性記憶受損
  2. （B）自傳式記憶受損
  3. （C）空間型記憶受損
  4. （D）逆行性記憶受損

答案：（D）

詳解與考點

考點為記憶分類。王先生能答住址職業（受傷前長期記憶完整），卻無法回憶受傷當下的經過，屬於對事件發生前後一段時間記憶喪失的逆行性記憶受損，故答案 D。陷阱在 B 自傳式記憶，住址職業亦屬自傳式且完好，故非整體自傳式受損；前瞻性記憶指對未來待辦的記憶，與本題情境不符。

第 15 題

根據DSM-5，下列有關注意力不足／過動症（attention-deficit/hyperactivity disorder, ADHD）之診斷標準何者正確？
  1. （A）7歲之前就有數種不專注或過動─衝動的症狀
  2. （B）不專注的症狀中，包括經常太多話
  3. （C）過動─衝動的症狀中，包括經常無法安靜地玩或從事休閒活動
  4. （D）數種不專注或過動─衝動的症狀需在一種或更多的情境出現

答案：（C）

詳解與考點

考點為 DSM-5 ADHD 診斷準則細節。正解 C「無法安靜玩或從事休閒活動」確屬過動─衝動症狀之一。陷阱密集：A 錯在發病年齡改為 12 歲前非 7 歲前；B「太多話」屬過動而非不專注；D 錯在症狀須在兩種以上情境出現而非一種。多處細節改動是本題易錯來源。

第 16 題

根據McBurnett等人（1991）的研究發現，相較於僅患有行為規範障礙症（conduct disorder, CD）的男孩，同時患有CD和焦慮症（anxiety disorder）的男孩，可能因為下列何種原因，而對自身的攻擊行為有較好的抑制能力，此研究發現支持共病焦慮症可能為患有CD兒童的保護因素之一之理論？
  1. （A）具有較高的唾液皮質醇（salivary cortisol）
  2. （B）具有較高的甲狀腺激素（thyroid hormone）
  3. （C）具有較高的胰島素（insulin）
  4. （D）具有較高的生長激素（growth hormone）

答案：（A）

詳解與考點

考點為 CD 共病焦慮症的生理保護機制。McBurnett 等人研究指出，CD 合併焦慮的男孩有較高唾液皮質醇，反映 HPA 軸與行為抑制系統較活躍，故對攻擊衝動有較好抑制，支持焦慮為保護因子，答案 A。陷阱在誤選其他激素，皮質醇才是與壓力反應、行為抑制直接相關的指標。

第 17 題

根據DSM-5，有關對立反抗症（oppositional defiant disorder, ODD）與行為規範障礙症（conduct disorder, CD）之異同處，下列敘述何者正確？
  1. （A）相較於ODD的行為問題，CD的行為問題通常較不嚴重
  2. （B）兩者的共同點，是皆與個體會與成人或其他權威人物（例如：老師、工作督導）起衝突的行為問題有關
  3. （C）相較於ODD，CD不包含對人或動物的攻擊、破壞所有物、偷竊或欺騙的行為模式
  4. （D）CD包含情緒失調（生氣、易怒情緒）問題，此問題是不被包括在ODD的診斷標準之中

答案：（B）

詳解與考點

考點為 ODD 與 CD 的異同。正解 B：兩者共同點皆涉及與成人或權威人物的衝突行為。陷阱：A 反了，CD 通常較 ODD 嚴重；C 反了，攻擊、破壞、偷竊欺騙正是 CD 的核心而非不包含；D 反了，憤怒易怒情緒是 ODD 的準則向度而非 CD 獨有。三個錯項皆為反向敘述。

第 18 題

有關多重系統治療（multisystemic therapy）的敘述，下列何者錯誤？
  1. （A）有行為規範問題的青少年是在交互連結的社會系統中（例如：家庭、學校、鄰近區域，法院等）運作
  2. （B）青少年的反社會行為，是經社會系統內或在系統間交互作用後被維持住，或是交互作用後產生的結果
  3. （C）此治療策略之一，乃希望灌注主要照顧者力量，來改善有行為規範問題的青少年及其家庭功能
  4. （D）此治療強調個案的自我衝突的解決及成長

答案：（D）

詳解與考點

考點為多重系統治療（MST）的核心理念。MST 視青少年偏差行為為家庭、學校、社區、法院等多重系統交互作用的產物，介入著重賦能照顧者改善整體系統功能。強調個案內在自我衝突的解決與成長屬個人取向心理治療的觀點，非 MST 焦點，故答案 D 錯誤。陷阱在誤把個別動力治療概念套入系統取向。

第 19 題

Jones & Klin（2013）研究自閉症類群障礙症的社會動機理論發現，下列敘述何者錯誤？
  1. （A）一般的嬰兒對於人相關訊息是有興趣的
  2. （B）自閉症類群障礙症的嬰幼兒不太注視人是因為較無法從中獲得大量的增強
  3. （C）自閉症類群障礙症的嬰幼兒在2～6個月與人眼神注視（eye contact）的次數與一般嬰幼兒無異
  4. （D）由於較少注意他人，因此較難發展與人互動的能力

答案：（C）

詳解與考點

考點為自閉症社會動機理論（Jones & Klin, 2013）。該研究發現自閉嬰兒在 2 至 6 個月眼神注視即已開始衰退，並非與一般嬰兒無異，故 C 敘述錯誤。陷阱在 B，社會動機理論主張自閉兒因較難從社會訊息獲得增強而減少注視，此為正確核心論點，易被誤判為錯。

第 20 題

小明在小學二年級階段接受魏氏兒童智力測驗測得智商為95，但是他升上三年級後，學習出了很大的問題。如果小明是符合特定的學習障礙症的個案，下列敘述何者最不恰當？
  1. （A）常有發音錯誤的問題
  2. （B）有字彙記憶的困難
  3. （C）有數數和計算的困難
  4. （D）有行為抑制功能缺損

答案：（D）

詳解與考點

考點為特定學習障礙症的核心特徵。學習障礙涉及閱讀、書寫、數學等學業技能，故發音錯誤、字彙記憶困難、數數計算困難皆可能出現。行為抑制功能缺損屬 ADHD 的執行功能問題，非學習障礙的定義特徵，故答案 D 最不恰當。陷阱在 ADHD 與 SLD 常共病，易把抑制缺損誤歸於學習障礙本身。

第 21 題

下列何者不是溝通障礙症（communication disorders）的主要治療原則與想法？
  1. （A）增進與提升患者的詞彙量
  2. （B）調整環境以符合患者的溝通需求
  3. （C）增加人際互動的多樣性
  4. （D）增進患者有關語言的知識與能力

答案：（C）

詳解與考點

考點為溝通障礙症的治療原則。治療著重增進詞彙量、語言知識與能力，並調整環境以符合溝通需求。增加人際互動的多樣性並非溝通障礙的主要治療原則，焦點應放在語言能力本身與情境支持，故答案 C。陷阱在「多互動」聽來合理，但非教科書列舉的核心原則。把握度標 med。

第 22 題

有關溝通障礙症（communication disorders）的病因問題，下列敘述何者錯誤？
  1. （A）相關研究中顯示50%～75%有家族病史
  2. （B）與時間歷程缺損（temporal processing deficits）有關
  3. （C）兒童期中耳炎反覆感染可能有直接的影響
  4. （D）父母缺乏言語的互動是主要原因

答案：（D）

詳解與考點

考點為溝通障礙症的病因。研究支持高家族遺傳率（約 50 至 75%）、時間歷程處理缺損、反覆中耳炎影響聽覺輸入。父母缺乏言語互動並非主要病因，溝通障礙主因為神經發展與遺傳，環境互動不足非決定性因素，故答案 D 錯誤。陷阱在過度歸因於教養環境。

第 23 題

下列何種染色體異常疾病與智能不足較無顯著關連？
  1. （A）苯酮尿症（phenylketonuria, PKU）
  2. （B）X染色體易脆症（Fragile X syndrome）
  3. （C）47XXY克萊費特症（Klinefelter's syndrome）
  4. （D）47XYY染色體異常(XYY syndrome)

答案：（D）

詳解與考點

正解 D。47,XYY 症候群的個案多數智力落在正常範圍，雖可能伴隨語言發展遲緩、學習困難或行為問題，但與「智能不足（智能障礙）」並無顯著、必然的關連，故與智能不足「較無顯著關連」者選 D。

A 苯酮尿症（PKU）：嚴格說是「體染色體隱性遺傳的代謝性疾病」而非染色體數目／結構異常；若未及早以飲食控制治療，苯丙胺酸堆積會造成嚴重智能障礙，與智能不足關係密切。

B X 染色體易脆症（Fragile X syndrome）：是遺傳性智能障礙最常見的原因之一，與智能不足高度相關。

C 克萊費特症（47,XXY）：常見語言、學習與認知功能的弱項，部分個案智商偏低，整體而言與認知／智能問題有相當關連，相對於 XYY 更常被連結到智能與發展困難。

四者相比，D（XYY）與智能不足的關連最不顯著。

第 24 題

由於幼兒情緒與想法的表現方式不同，DSM-5針對兒童期創傷後壓力症（PTSD）又新增幾歲以下不同的診斷準則？
  1. （A）8歲
  2. （B）7歲
  3. （C）6歲
  4. （D）5歲

答案：（C）

詳解與考點

考點為 DSM-5 兒童期 PTSD 的特別準則。DSM-5 新增「6 歲以下兒童」的 PTSD 亞型診斷準則，因幼兒情緒與想法表達方式不同而另立標準，故答案 C 為 6 歲。陷阱在年齡數字記憶，易與其他疾患的年齡門檻混淆，正確記點是 6 歲以下（preschool subtype）。

第 25 題

有關Disruptive Mood Dysregulation Disorder（DMDD）的敘述，下列何者錯誤？
  1. （A）DMDD的臨床特徵是頻繁的脾氣爆發和嚴重的易怒情緒
  2. （B）DMDD被歸類在DSM-5的侵擾行為、衝動控制及行為規範障礙症類別中
  3. （C）DMDD的初發年齡必需在10歲以下
  4. （D）DMDD不能和雙相情緒障礙症共同診斷

答案：（B）

詳解與考點

考點為 DMDD 的分類與特徵。DMDD 以頻繁脾氣爆發與持續易怒為核心，初發須在 10 歲前，不可與雙相情緒障礙共同診斷。其在 DSM-5 被歸類於憂鬱症類別而非侵擾行為類別，故 B 敘述錯誤。陷阱在 DMDD 表現像行為問題，易誤以為屬侵擾行為與行為規範障礙類別。

第 26 題

關於青少年憂鬱症與自殺之敘述，下列何者錯誤？
  1. （A）這些青少年的自殺嘗試，13～14歲時是第一個高峰
  2. （B）這些青少女的自殺意念及嘗試都高於青少男
  3. （C）這些青少年的自殺嘗試，20～22歲時是第二個高峰
  4. （D）這些青少年出現自殺嘗試時，大多處於憂鬱症狀中

答案：（C）

詳解與考點

考點為青少年憂鬱與自殺的流行病學。自殺嘗試的第一高峰約在 13 至 14 歲，青少女自殺意念與嘗試高於青少男，且自殺嘗試多伴隨憂鬱症狀。第二高峰並非 20 至 22 歲，故 C 錯誤。陷阱在年齡數字，第二高峰落點與選項不符，須留意題組設定的年齡區間。把握度標 med。

第 27 題

在DSM-5的陳述中，侵擾性情緒失調症不能和下列那種障礙症共同診斷？
  1. （A）憂鬱症
  2. （B）焦慮症
  3. （C）行為規範障礙症
  4. （D）對立反抗症

答案：（D）

詳解與考點

考點為 DMDD（侵擾性情緒失調症）的共病排除規則。DSM-5 規定 DMDD 不能與對立反抗症同時診斷，因兩者症狀高度重疊（易怒、反抗），若符合 DMDD 則不另下 ODD，故答案 D。陷阱在 DMDD 可與憂鬱症、焦慮症、CD 等共病，唯獨與 ODD 互斥，易誤選其他。

第 28 題

情緒失調（mood dysregulation）是瞭解思覺失調症心理病理的重要取向，下列敘述何者最恰當？
  1. （A）思覺失調症無法適切地表達情緒，主觀情緒經驗也是缺乏的
  2. （B）思覺失調症無法適切地表達情緒，但仍能經驗到主觀的情緒感受
  3. （C）思覺失調症在沒有任何危險在時，也是害怕、焦慮、憤怒與攻擊的，只是無法辨認與表達
  4. （D）思覺失調症會長期經驗到悲傷與其他負面情緒，只是因為現實感不好，所以會不斷否認與忽視這些情緒

答案：（B）

詳解與考點

考點為思覺失調症的情緒病理。研究指出患者外顯情緒表達平板（情感平淡），但其主觀的內在情緒經驗仍存在且可被感受到，故答案 B 最恰當。陷阱在 A，把外顯表達缺乏直接等同主觀經驗缺乏是常見誤解，實際是「表達」與「經驗」分離，內在情緒並未喪失。

第 29 題

Gottesman等人（2010）的家族研究結果顯示，雙親皆為思覺失調症者，其罹患思覺失調症的概率大約多少﹖

  4. （D）47%

考點為思覺失調症遺傳風險（Gottesman 等人 2010 家族研究）。雙親皆罹病時，子女罹病風險約 27%，故答案 B。陷阱在易把不同親屬的風險數字相混：同卵雙胞胎共病率約 48%、單親罹病子女約 13%，皆與「雙親皆病」的 27% 不同，須緊扣題目指定的親屬關係作答。

第 30 題

依據Malaspina等人（2000）的研究，思覺失調症的那一種症狀有較強的遺傳性﹖
  1. （A）聽幻覺
  2. （B）被害妄想
  3. （C）解構的語言
  4. （D）無動機

答案：（D）

詳解與考點

考點為思覺失調症症狀的遺傳性差異（Malaspina, 2000）。研究顯示負性症狀（如無動機）較正性症狀有更強的遺傳性，反映其與體質性神經基礎關聯較深，故答案 D。陷阱在直覺認為幻覺妄想等顯著正性症狀遺傳性高，實則無動機等負性症狀的家族聚集性更強。把握度標 med。

第 31 題

下列何者不是思覺失調症的負性症狀？
  1. （A）失樂症狀（anhedonia）
  2. （B）無社會性（asociality）
  3. （C）貧語症（alogia）
  4. （D）精神動作激動（psychomotor agitation）

答案：（D）

詳解與考點

考點為思覺失調症負性症狀的範圍。失樂（anhedonia）、無社會性（asociality）、貧語（alogia）皆為負性症狀，反映功能缺損。精神動作激動屬於興奮、活動增加，並非缺損性的負性症狀，故答案 D 不是負性症狀。陷阱在把任何異常動作都歸為負性，激動其實偏向正性／緊張型表現。

第 32 題

研究發現，相較於常人，思覺失調症患者的額葉及顳葉的軸突纖維有何差異？
  1. （A）較多
  2. （B）無差異
  3. （C）較少
  4. （D）有許多空洞

答案：（C）

詳解與考點

考點為思覺失調症的腦白質病變。研究發現患者額葉與顳葉的軸突纖維（白質連結）較常人為少，反映神經連結與整合受損，故答案 C 較少。陷阱在 A 較多，與實際發現相反；思覺失調的神經病理偏向連結不足與灰質減少，而非纖維增生。

第 33 題

若欲區分基因與環境對思覺失調症的影響，下列何者是行為遺傳學較理想的研究方法？
  1. （A）家族研究（family studies）
  2. （B）雙生子研究（twin studies）
  3. （C）關聯分析（association analysis）
  4. （D）領養研究（adoption studies）

答案：（D）

詳解與考點

考點為行為遺傳學區辨基因與環境的研究法。領養研究讓遺傳（生父母）與養育環境（養父母）分離，最能釐清基因與環境各自貢獻，故答案 D。陷阱在 B 雙生子研究，雖也估遺傳率，但同卵雙胞胎常共享環境，難完全分離基因與環境；領養設計在此議題上更理想。

第 34 題

根據DSM-5，下列何者心理疾病的平均發病年齡最早？
  1. （A）恐慌症（panic disorder）
  2. （B）短暫精神病症（brief psychotic disorder）
  3. （C）第一型雙相情緒障礙症（bipolar I disorder）
  4. （D）第二型雙相情緒障礙症（bipolar II disorder）

答案：（C）

考點為各疾患平均發病年齡比較。選項中第一型雙相情緒障礙症的平均發病年齡最早（青少年晚期至成年早期），早於恐慌症、短暫精神病症與第二型雙相，故答案 C。陷阱在易認為第二型較早或恐慌症較早，實際依 DSM-5 資料第一型 bipolar 起病最早。把握度標 med。

第 35 題

有關循環型情緒障礙症（cyclothymic disorder）之臨床病程特徵敘述，下列何者正確？
  1. （A）出現多次躁症發作與鬱症發作
  2. （B）出現多次輕躁症發作與鬱症發作
  3. （C）出現多次不符躁症發作準則之躁症症狀與多次鬱症發作
  4. （D）出現多次不符輕躁症發作準則之輕躁症症狀，以及多次不符鬱症發作準則之憂鬱症狀

答案：（D）

詳解與考點

考點為循環型情緒障礙症（cyclothymia）的病程準則。其特徵為長期反覆出現不達輕躁症準則的輕躁症狀，以及不達鬱症發作準則的憂鬱症狀，皆為閾下症狀，故答案 D。陷阱在 B，若出現完整的輕躁與鬱症發作即屬第二型雙相而非循環型；循環型的關鍵是「未達準則」的閾下波動。

第 36 題

下列何者是躁症發作最可能的預測因子（predictor）？
  1. （A）神經質（neuroticism）
  2. （B）睡眠剝奪
  3. （C）負向生活事件
  4. （D）高情緒表達（high expressed emotion）

答案：（B）

詳解與考點

考點為躁症發作的預測因子。睡眠剝奪是觸發躁症發作最有力的近端預測因子，睡眠減少可直接誘發或惡化躁症，故答案 B。陷阱在 D 高情緒表達，雖與復發及病程相關，但更常與憂鬱或思覺失調復發連結；針對躁症發作的特異觸發因子以睡眠剝奪最具預測力。

第 37 題

有關HPA系統調節功能的皮質類固醇抑制檢驗（dexamethasone suppression test）的依據，下列何者正確？
  1. （A）皮質類固醇會增加皮質醇（cortisol）的分泌
  2. （B）皮質類固醇會抑制皮質醇的再回收
  3. （C）皮質類固醇會抑制皮質醇的分泌
  4. （D）皮質類固醇會抑制皮質醇的分解

答案：（C）

詳解與考點

考點為地塞米松抑制試驗（DST）的生理機制。外源性皮質類固醇（dexamethasone）經負回饋抑制 HPA 軸而抑制內生皮質醇分泌；憂鬱患者常出現抑制失敗（脫抑制）。故答案 C：皮質類固醇會抑制皮質醇的分泌。陷阱在誤選增加分泌或抑制再回收，機制核心是負回饋下調分泌。

第 38 題

下列何者是躁症（mania）的症狀？
  1. （A）活動量低
  2. （B）疲倦
  3. （C）自我誇大
  4. （D）連貫且明確的言談

答案：（C）

詳解與考點

考點為躁症的症狀辨識。躁症表現為活動量增加、精力旺盛、自我膨脹誇大、言談急促跳躍。選項中自我誇大（誇大性）是典型躁症症狀，故答案 C。陷阱在 D「連貫且明確的言談」，躁症言談多為意念飛躍、不連貫；活動量低與疲倦則屬鬱症方向，皆與躁症相反。

第 39 題

妄想症與思覺失調症在診斷準則上最主要的差異是下列何項？
  1. （A）妄想症缺乏思覺失調症的診斷準則A
  2. （B）妄想症缺乏思覺失調症前驅期的症狀
  3. （C）妄想症缺乏思覺失調症殘餘期的症狀
  4. （D）妄想症的功能後果較思覺失調症更好

答案：（A）

詳解與考點

正解 A。依 DSM-5，妄想症（delusional disorder）與思覺失調症最主要的鑑別在於「妄想症從未符合思覺失調症的診斷準則 A」。思覺失調症準則 A 要求至少出現妄想、幻覺、混亂言語、明顯混亂或僵直行為、負性症狀等中的兩項（且須含前三項之一）；妄想症則以一個或多個妄想為主，整體功能與行為相對未明顯混亂，故 A 正確。

需注意：妄想症並非「完全沒有幻覺」——若出現幻觸或幻嗅等，且與妄想主題相關、不顯著，仍可符合妄想症，因此不能用「有無幻覺」來絕對區分，關鍵在於「是否曾達到準則 A」。

B、C 錯誤：前驅期（prodromal）與殘餘期（residual）症狀是思覺失調症「病程」描述的概念，並非兩者鑑別診斷的主要準則差異。

D 錯誤：妄想症的整體功能後果通常確實優於思覺失調症，但這是病程／預後的差異，並非診斷準則上「最主要」的區別。

第 40 題

下列那個精神病症的診斷通常由極強的壓力引發的？
  1. （A）妄想症
  2. （B）類思覺失調症
  3. （C）短暫精神病症
  4. （D）情感思覺失調症

答案：（C）

詳解與考點

考點為壓力引發的精神病症。短暫精神病症常由極強的壓力事件（如喪親、重大創傷）急性誘發，病程短於一個月後完全緩解，故答案 C。陷阱在 D 情感思覺失調症與 A 妄想症，雖也可受壓力影響，但其診斷不以強烈壓力為典型誘發特徵；短暫精神病症最強調急性壓力觸發。
