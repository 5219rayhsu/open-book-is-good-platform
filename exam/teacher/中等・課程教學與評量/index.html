第 1 題

規劃校訂課程時，先分析該校學生的學習需求和在地文化特色，再據以擬訂校訂課程目標與內涵。此做法較符合下列何種課程設計模式？
  1. （A）目標模式
  2. （B）歷程模式
  3. （C）情境模式
  4. （D）逆向模式

答案：（C）

詳解與考點

正解：課程設計的情境模式（situational model，以Skilbeck為代表）主張課程發展應先進行情境分析，評估校內外因素，包括學生需求、社區與在地文化、教師特質、資源條件等，再據以擬訂課程目標與內涵，強調課程應回應在地脈絡與學習者需求。題幹描述先分析學生學習需求與在地文化特色，再擬訂校訂課程目標與內涵，正符合情境模式由情境分析出發的設計邏輯，故選C。

A：目標模式（以泰勒（R. Tyler）為代表）主張課程設計應先明確界定教育目標，再據以選擇經驗、組織內容與評鑑，是由目標直接出發，而非先做情境分析，與題幹先分析需求、後訂目標的順序不同。

B：歷程模式（以Stenhouse為代表）不預先設定具體行為目標，而重視教育過程中的原理原則與探究價值本身，關注的是教學互動歷程，與題幹「先分析情境以擬訂目標」的邏輯出發點不同。

D：逆向模式（重理解的課程設計，由Wiggins與McTighe提出）雖也重視及早確立預期結果，但其核心特徵是「以終為始」——先定目標與評量證據、再設計教學活動，起點仍是預期學習結果，並非在地情境分析，與題幹強調的學生需求及在地文化分析重點有別。

本題考點：課程設計模式的比較。目標模式（Tyler，目標導向、線性設計）、歷程模式（Stenhouse，重過程與原理原則）、情境模式（Skilbeck，情境分析先行）、逆向設計（Wiggins與McTighe，以終為始）；解題關鍵在辨認題幹描述的設計起點究竟是目標、歷程、情境或預期結果。

第 6 題

張同學認為要知道全班所有同學的成績,才能判斷自己的表現好不好。其對成績的看法較接近下列何種概念?
  1. （A）常模參照
  2. （B）標準參照
  3. （C）效標參照
  4. （D）歷程參照

答案：（A）

詳解與考點

正解：張同學認為必須知道全班所有同學的成績才能判斷自己的表現好不好，這種以團體其他成員的表現作為比較基準、藉由相對位置來詮釋個人分數意義的看法，正是常模參照（norm-referenced）評量的核心特徵——個人分數的意義建立在與常模團體比較後的相對位置上，故答案為（A）。

B、C：標準參照與效標參照二者概念相通，同指依事先訂定的絕對標準或精熟程度判斷表現，判斷依據是個人表現與既定標準的比對，並不需要參照或知道其他同學的分數分布，與張同學一定要知道全班成績的想法方向相反。

D：歷程參照並非測驗與評量學界通用的標準分類概念，屬於似是而非的干擾選項，並無明確定義可與題幹描述的藉由團體比較判斷相對位置之概念對應。

本題考點：測驗與評量結果詮釋方式的分類——常模參照與標準（效標）參照的對比。常模參照著重個人分數在團體中的相對位置，需仰賴團體的分數分布；標準參照著重個人表現是否達到事先訂定的絕對精熟標準，不須比較他人成績；作答關鍵在辨識題幹描述的判斷依據是相對於他人或相對於既定標準。

第 11 題

以下為三位教師在社群會議的對話: 甲:「最近AI非常熱門,學習運用AI是未來必須具備的能力。因此早自習時我偶爾會安排運用AI的活動,學生們都很有興趣。」 乙:「我覺得AI會扼殺學生的思考能力,我個人還滿排斥的。學生受我影響,回家會勸爸媽少用ChatGPT。」 丙:「我覺得AI已無法避免,如何正確使用AI更為重要。雖然目前沒有這樣的課程,但我覺得它是需要的。」 甲、乙、丙三位教師的對話,依序反映何種課程觀點?
  1. （A）正式課程-潛在課程-懸缺課程
  2. （B）正式課程-懸缺課程-潛在課程
  3. （C）非正式課程-外顯課程-潛在課程
  4. （D）非正式課程-潛在課程-懸缺課程

答案：（D）

詳解與考點

正解：甲於早自習（非部定學科課程時間）安排運用AI的活動，屬學校在正式課表之外所安排、但仍具教育意圖的學習活動，即「非正式課程」；乙雖未直接教導「排斥AI」的內容，卻透過個人言行、態度潛移默化影響學生對ChatGPT的觀感，使學生返家後也勸誡父母少用AI，此為經由潛藏的氛圍、身教而非明訂內容產生學習，即「潛在課程」；丙認為AI正確使用的素養課程有其必要，但學校目前並未開設此類課程，屬「學校應教而未教」之課程，即「懸缺課程」。三者依序對應非正式課程、潛在課程、懸缺課程，故選D。

A：正式課程－潛在課程－懸缺課程──乙、丙之判斷正確，但甲的早自習AI活動被誤歸為「正式課程」。正式課程係指部定、列入正式課表的學科課程，早自習屬課表外由學校彈性安排之活動，雖具教育意圖卻非部定學科本身，應歸為非正式課程，故A之判斷有誤。

B：正式課程－懸缺課程－潛在課程──同樣誤將甲的早自習AI活動歸為「正式課程」，早自習屬課表外由學校彈性安排之活動而非部定學科，應歸為非正式課程；此外B亦將乙、丙的判斷順序互換：乙是透過言行潛移默化影響學生，屬潛在課程而非懸缺課程；丙是指出學校「應教而未教」的AI素養課程，屬懸缺課程而非潛在課程，兩者恰好對調，故B共有三處判斷有誤。

C：非正式課程－外顯課程－潛在課程──甲之判斷正確，但乙、丙判斷有誤。外顯課程（即正式課程）指公開明訂、正式規劃並列入課表的課程內容，乙並未明訂教導排斥AI的課程，而是藉由個人態度潛移默化感染學生，應屬潛在課程而非外顯課程；丙指出的是學校尚未開設卻應該開設的AI正確使用課程，屬懸缺課程而非潛在課程，故C亦有兩處判斷錯誤。

本題考點：課程類型的分類與辨析──正式課程（外顯課程，部定列入課表）、非正式課程（學校安排但非學科課程本身，如朝會、社團、早自習活動）、潛在課程（未明訂卻透過氛圍、身教產生的學習）、懸缺課程（應教而未教的課程），解題關鍵在逐一比對甲乙丙三人情境所屬的課程類型判準。

第 16 題

某校課程發展委員會進行學校課程評鑑時,其評鑑層面之一為「合理的課程組織」。 下列何者是根據課程組織原則「順序性」所訂定的評鑑標準?
  1. （A）課程能統整不同學習階段的內容
  2. （B）課程內容依難易度安排在適切的學習階段
  3. （C）課程能讓學生熟習不同學習階段的關鍵知能
  4. （D）課程設計能逐步運用單一到多元的學習媒材

答案：（B）

詳解與考點

正解：課程組織原則中的「順序性」指課程內容的先後安排，應依難易程度、由簡而繁、由具體而抽象，循序漸進地安排在適切的學習階段，使學生的學習經驗隨階段推進而逐步加深加廣。選項（B）「課程內容依難易度安排在適切的學習階段」正是針對內容難易度做階段性先後安排的敘述，完全對應順序性原則的定義，故選（B）。

A：（A）「課程能統整不同學習階段的內容」涉及跨階段內容間的連貫整合，關注的是不同階段內容彼此的橫向連結與統合，較接近課程組織原則中的「統整性」，而非順序性所強調的難易先後安排。

C：（C）「課程能讓學生熟習不同學習階段的關鍵知能」強調關鍵知能在不同階段中反覆出現、逐步加深熟練的累積歷程，較接近課程組織原則中的「繼續性」，與順序性著重「先後次序」的定義不同，容易因同樣涉及「不同學習階段」而與順序性混淆。

D：（D）「課程設計能逐步運用單一到多元的學習媒材」談的是教學媒材種類由少至多的漸進安排，並非以學習內容本身的難易程度作為排序依據，與順序性以內容難易為核心的定義不符。

本題考點：課程組織三大規準——順序性（依難易程度先後安排）、繼續性（關鍵知能反覆加深）、統整性（跨領域或跨階段內容的橫向連結）。作答關鍵在辨識選項描述的是「先後次序」「反覆熟練」還是「橫向整合」，據以對應正確的組織原則。

第 21 題

某校課程發展步驟為:分析學校的內外在條件、訂定課程目標、規劃課程、實施課程、進行課程評鑑與回饋。下列何者為該校採用的課程發展模式?
  1. （A）自然模式(natural model)
  2. （B）歷程模式(process model)
  3. （C）情境模式(situational model)
  4. （D）慎思模式(deliberation model)

答案：（C）

詳解與考點

正解：情境模式（situational model，Skilbeck 提出）的課程發展步驟為：情境分析（涵蓋社會文化等外在因素，以及學生、教師、資源等內在因素）→擬定課程目標→規劃課程方案→實施→監控評鑑並回饋修正。這與題幹「分析內外在條件→訂目標→規劃→實施→評鑑回饋」完全吻合，故選C。

A：自然模式（Walker提出）強調課程發展是「平台（信念立場）→慎思→設計」的非線性歷程，起點在於澄清參與者的先備信念與立場，而非以系統化分析內外在情境條件為起點，與題幹描述的步驟順序不符。

B：歷程模式（Stenhouse提出）主張課程應揭示教與學的原理原則與過程本身的價值，反對以預先設定的行為目標為導向；題幹卻明白將「訂定課程目標」列為第二步驟，與歷程模式反目標的立場相悖。

D：慎思模式（Schwab提出）著重教師、學生、教材、環境等課程要素間的實際審議折衝以形成決定，是一種反覆折衝的專業判斷歷程，並非固定的線性步驟流程，也未特別強調以分析內外在條件為起始步驟。

本題考點：課程發展模式的比較。目標模式（Tyler，目標為起點）、歷程模式（Stenhouse，重過程原理）、情境模式（Skilbeck，情境分析為起點）、自然模式（Walker，平台與慎思）、慎思模式（Schwab，審議折衝）；解題關鍵在辨識題幹描述的步驟序列對應哪個模式的標誌性起點與流程。
