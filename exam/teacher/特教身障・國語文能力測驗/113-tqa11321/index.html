詳解與考點

正解：文末強調「傳世名作有時僅是人們日常書寫的自然表現」，重點在於不假雕琢、隨興而至的自然書寫本身即是一種美，「無論他人覺得好不好看，創作都是一種展現自我的方式」。（D）「逸筆餘興，淋漓揮灑，或妍或醜，百態橫生」正是描述隨興揮灑、不刻意講究美醜工拙的自然書寫狀態，其中「或妍或醜」呼應文末「無論他人覺得好不好看」的態度，最貼近作者強調自然真率勝過刻意工整的觀點，故選（D）。

A：（A）「義之書字勢雄逸，歷代寶之，永以為訓」讚揚王羲之字勢雄偉、歷代奉為典範，屬於對特定書家的歷史地位評價，聚焦在「被推崇為法則」，與文末強調隨興自然、不求工拙的觀點方向相反。

C：（C）「皇頡作文，因物構思；觀彼鳥跡，遂成文字」講述倉頡觀察鳥獸足跡而創造文字的起源傳說，談的是文字的起源，而非書法創作的審美價值，與文末觀點無關。

第 5 題

根據文章敘述, 瓦剌來襲, 明代朝廷內發生了什麼事?
  1. （A）吏部尚書力排眾議, 鼓勵皇帝親征
  2. （B）眾將領擁皇帝親征, 官員倉促逃亡
  3. （C）皇帝貼身太監被殺, 憤而決定親征
  4. （D）皇帝勿促決定親征, 大臣反對無效

答案：（D）

詳解與考點

正解：本文引用《明史紀事本末》記載，瓦剌也先大舉入寇之際，太監王振勸英宗親征，皇帝「命下，二日即行」，決定極為倉促；當時「吏部尚書王直及大小群臣，伏闕懇留，不允」，可見大臣們極力勸阻卻未能改變皇帝心意，英宗仍執意倉促親征，終致土木堡之變、皇帝被俘。這正對應選項D「皇帝倉促決定親征，大臣反對無效」，故選D。

A：「吏部尚書力排眾議，鼓勵皇帝親征」與史實相反，實際上是吏部尚書王直等大小群臣「伏闕懇留」，極力勸阻皇帝親征，而非鼓勵親征；提出親征建議的是太監王振，並非吏部尚書。

B：「眾將領擁皇帝親征，官員倉促逃亡」與本文記載不符，本文並未提及將領擁戴親征或官員逃亡的情節，群臣的反應是伏闕勸阻，而非擁戴或逃亡。

C：「皇帝貼身太監被殺，憤而決定親征」時序有誤。王振是在親征途中、土木堡兵敗之後，才被護衛將軍樊忠以錘擊死，並非在親征之前已遭殺害；因此皇帝決定親征的原因不可能是太監被殺後的憤怒。

本題考點：史料閱讀中事件時序與因果關係的釐清。作答須逐句核對史料原文，避免把不同時間點發生的事件（親征前的勸阻與兵敗後的太監之死）錯置因果，或將史料中角色的立場張冠李戴。

  3. （C）尚書王直
  4. （D）皇帝英宗

答案：（B）

詳解與考點

正解：文中多段獨白裡，英宗提到「先生鼓勵朕御駕親征」「先生屍骨未寒，他們就急著抄先生的家」「朕當太上皇這幾年，時常想為先生平反」，對照《明史紀事本末》原文「太監王振勸上親征」及後文「陳鑑奉令旨，籍振并其黨」「詔復振官」，可知獨白中反覆被英宗稱為「先生」、事後遭抄家又被平反者，正是太監王振。王振自英宗年幼時便侍奉在側、深得信任，英宗因此以師禮尊稱他「先生」而不以宦官視之，這正是王振後來能慫恿皇帝親征的背景，故選B。

C：王直是反對親征、伏闕懇留未果的吏部尚書，獨白裡英宗說「王直他們實在是太懦弱了」，是被英宗批評、抱持異議立場的臣子，並非受尊稱的對象。

D：獨白中「先生」一詞是英宗對他人（王振）的稱呼，說話者本人即是皇帝英宗，語法上稱呼詞不會回指說話者自身，故不可能是英宗本人。

本題考點：文言人物稱謂與敘事視角的判讀。解題關鍵在辨認獨白的說話者是誰（英宗），再依稱謂「先生」在上下文中的指涉對象（受尊寵、後遭抄家又獲平反的人物）比對《明史紀事本末》原文人物關係，鎖定王振。

  1. （A）由於戰事「告急」, 許多年輕學子也被徵召入伍

詳解與考點

第 12 題

  1. （A）跟風的網路現象,缺乏自我思考
  2. （B）快速交友的流程,致使友誼淡薄
  3. （C）強迫公開生活,因此無法有個人隱私
  4. （D）營造虛假自我,卻又期待被他人理解

答案：（D）

詳解與考點

正解：作者引用《論語》「不患人之不己知」與「人不知而不慍，不亦君子乎」，原意是孔子教人不因他人不了解自己而心生怨懟，坦然自處於「不被知」的狀態。但作者藉此對比社群網站上的現象：許多人「苦心在社群中營造出與自我截然不同的面目」，刻意經營美化、失真的自我形象以博取關注度，卻又「期待著將流量轉化為真實的情誼」，內心仍渴望被他人真正理解與認同。這種「明明營造虛假形象，卻又期待被理解」的矛盾心態，恰與孔子「不慍」的坦然背道而馳，正是D「營造虛假自我，卻又期待被他人理解」所指涉的現象，故選D。

A：文中確實提到人們「趨之若鶩」追逐流行語與關注度，帶有從眾意味，但《論語》引文針對的核心矛盾是「不被理解仍求關注」的心理反差，而非單純的跟風缺乏思考；文中並未把該段引文用來批判缺乏自我思考的問題。

B：文中談及友誼淡薄的線索（如「輕輕按下一個鈕便消失殆盡」）位於引用《論語》之前，用以鋪陳社群交友之速食性質，並非該段引文所欲揭示的重點；引文緊扣的是「經營形象」與「渴望理解」的落差，而非交友流程本身。

C：文章通篇談的是使用者主動公開展現自我以獲取關注，並非被迫公開生活而喪失隱私；「隱私」議題在原文中並未出現，屬於無中生有的選項，與引文脈絡無關。

本題考點：文言引文在論說文中的功能判讀。作者引用經典語句常用以形成古今對比或反襯論點，解題須先確認引文本身的原意，再對照上下文找出作者藉此凸顯的當代現象，而非望文生義地套用選項字面。

  4. （D）想要透過修圖相片尋找真愛

詳解與考點

正解：文中批判的網路人際現象，是有些人苦心在社群中「營造出與自我截然不同的面目」，藉此享受從未有過的關注，卻又「期待著將流量轉化為真實的情誼」——也就是以經營虛假的外在形象換取他人的理解與真心情感連結，然而這種建立在造假之上的情誼，「只要輕輕按下一個鈕便消失殆盡」。選項（D）「想要透過修圖相片尋找真愛」正是以美化、失真的外在形象包裝自己，卻期望藉此獲得真摯的愛情，與作者批判的「假我換真情」現象完全對應，故選（D）。

A：（A）「揭示歷史人物的神化過程」只涵蓋文章前段鄭成功、王延稟、莘七娘等歷史案例的鋪陳內容，屬於論述的材料與過程，並非文章借古喻今、指向當代造神現象的最終用意，層次上不及（B）完整。

C：（C）「討論人神分際的模糊化現象」偏向宗教學或哲學層次對「何謂神」的抽象探討，但文章的重點始終落在「人如何被權力或群眾造成神」的社會過程與現象批判，而非探討人與神在本質定義上的界線模糊，方向有別。

D：（D）「說明信仰在文化中的重要性」語氣正面肯定信仰的價值，但文末「神壇之所以稱為神壇，那便表示不是人可以居住的地方，以人作神，跌落神壇也只是必然的事」明顯帶有警惕與批判意味，與肯定信仰重要性的正面論調相反，不符文章基調。

本題考點：文章主旨與寫作手法判讀——藉古喻今、以敘代議。作者透過歷史封神案例的鋪陳，最終導向對當代造神運動的諷刺與反思；解題須先辨識文中敘述的層次（材料鋪陳與最終用意），再依末段的評論性語句確認作者真正的批判對象與態度。

史家陳寅恪在其撰寫的《柳如是別傳》序言中提到,他旅居昆明時,偶然購得常熟白茆港錢氏故園中紅豆一粒,從而箋釋錢、柳二人詩作,隨之便有起草此書的念頭。這錢氏故園為明末文士錢謙益的故居,柳則是名列秦淮八艷的名妓柳如是。我們無法得知陳寅恪是否真因紅豆而著手寫作,但在錢、柳二人所居住的宅院中,的確種有一株紅豆樹,此宅也因而得名紅豆山莊。紅豆自古喻有相思之情,據傳是待夫歸鄉的女子,因朝盼暮望最終泣血而亡,血淚化作了艷麗的赤豆。而回顧錢柳二人的生平,似乎沒什麼關於相思的事,更多人關注的,反而是二人才子佳人的傳奇故事。 那時錢謙益已五十多歲,但其文壇泰斗的身分,引得柳如是做男裝喬扮,主動尋訪這位名士,進而展開一段忘年之戀。其後錢謙益在六十歲時迎娶二十四歲的柳如是,紅顏白髮的組合,實屬驚世駭俗,卻也羨煞旁人。對柳如是來說,她為愛情傾出所有,在出嫁後一首:「裁紅暈碧淚漫漫,南國春來正薄寒。此去柳花如夢裡,向來煙月是愁端。畫堂訊息何人曉,翠帳容顏獨自看。珍重君家蘭桂室,東風取次一憑闌。」便顯露出她的心情。不過兩人與紅豆確實有件事可說。 錢謙益八十歲大壽那年,紅豆山莊二十年未曾開花的紅豆樹,恰巧在秋日結出一顆子,柳如是便贈紅豆祝壽,錢氏因物感興而寫下詠物詩:「院落秋風正颯然,一枝紅豆報鮮妍。夏梨弱棗尋常果,此物真堪薦壽筵。」可見,錢謙益因疼愛柳如是,儘管只是一枚紅豆子,但他仍然將此物視作慶壽的瑞兆,紅豆有如錢、柳二人情緣象徵之物。 不過話說回來,王維一首〈相思〉,本身也不是談男女之愛,而是對摯友李龜年傳達眷念之情。如要從紅豆談相思,或許林夕所填詞的〈紅豆〉中:「還沒為你把紅豆熬成纏 綿的傷口。」一句更能引起共鳴。當時林夕看了木村拓哉所演的日劇,其中一幕女主角不小心燒糊了一鍋紅豆湯,他便隨手寫入詞中,如同「此物最相思」之語句傳誦至今,一如研磨烹煮成柔軟似泥的紅豆餡,那團甜膩的香氣更能引人遐思。也許只有當人們陷入戀人絮語的情境時,才能在「紅豆」兩字間讀出所謂的一往情深

第 21 題

下列選項中，何者與「箋釋」的「箋」讀音相同？
  1. （A）肩
  2. （B）簽
  3. （C）盞
  4. （D）貞

答案：（A）

詳解與考點

正解：「箋」讀作ㄐㄧㄢ，聲母ㄐ、韻母ㄧㄢ、陰平調。「肩」同樣讀作ㄐㄧㄢ，聲母、韻母、聲調三者完全相同，故為同音字，選（A）。

B：「簽」讀作ㄑㄧㄢ，韻母與聲調皆與「箋」相同，但聲母為ㄑ而非ㄐ，屬形近讀音的鄰近誤讀，並非同音字。

C：「盞」讀作ㄓㄢˇ，聲母ㄓ、聲調上聲，與「箋」的聲母ㄐ、陰平調皆不同，僅韻母相近而已。

D：「貞」讀作ㄓㄣ，聲母ㄓ與「箋」的ㄐ不同，韻母ㄣ與「箋」的ㄧㄢ亦不同，兩者僅聲調相同，並非同音字。

本題考點：形聲字聲符與實際讀音的對應辨識。「箋」屬形聲字，作答時須逐一比對聲母、韻母、聲調三要素是否完全一致，方能判定為同音字，不可僅憑部件或聲符相似即誤判。

第 23 題

本文中柳如是於出嫁後所作的詩主要傳達什麼心情？
  1. （A）表現出留戀不捨的夫妻之情
  2. （B）透過歌詠紅豆表達相思之情
  3. （C）藉應和之詩歌傳遞祝壽之意
  4. （D）以閨怨之情傳達對夫君之盼

答案：（D）

詳解與考點

正解：柳如是出嫁後所作之詩「裁紅暈碧淚漫漫，南國春來正薄寒……畫堂訊息何人曉，翠帳容顏獨自看」，寫的是深閨女子獨守畫堂、無人知曉音訊、獨自對鏡的孤寂景況，通篇以閨閣女子思念遠方夫君的口吻著筆，透過傳統閨怨詩的哀婉筆調，傳達出她對夫君歸來、音訊的殷切期盼，故選D。

A：留戀不捨的夫妻之情，語氣通常偏向離別當下、共處時光的不捨與追憶，而此詩所寫的是婚後獨處畫堂、盼望音訊的心境，情感重心在盼望而非離別當下的不捨，兩者情境不同。

B：透過歌詠紅豆表達相思之情，是本文後段錢謙益八十歲壽宴時，柳如是贈紅豆、錢氏因物感興所作的詠物祝壽詩所涉及的意象，與此處柳如是出嫁後所作的閨怨詩是不同時空、不同性質的兩首作品，不應混為一談。

本題考點：題組文本中不同詩作的情境辨析。解題關鍵在準確定位柳如是出嫁後所作之詩在本文中的位置與內容，並與後段錢柳唱和的紅豆祝壽詩區分開來，避免因兩詩皆與柳如是相關而混淆其寫作時空與情感性質。

第 24 題

「還沒為你把紅豆熬成纏綿的傷口。」一句的寫作手法，與下列何者最相近？
  1. （A）把回憶風乾，晚年下酒
  2. （B）歷史是一幅畫，時間是絢麗的色彩
  3. （C）他的笑聲，響亮到足以讓沉睡的山峰甦醒
  4. （D）慢慢的拼湊，拼湊成一個完全不屬於真正的我

答案：（A）

詳解與考點

正解：「還沒為你把紅豆熬成纏綿的傷口」一句，是把「紅豆」這項具體食材，透過「熬」這個具體的烹煮動作，轉化為「傷口」這種可感知的抽象情感結果——原本抽象難以言說的相思情感，藉由烹煮食物的具體動作被賦予形體與痛感。選項「把回憶風乾，晚年下酒」同樣是將「回憶」這一抽象事物，透過「風乾」這個具體的食物加工動作，轉化為晚年可佐酒回味的具象存在；兩句都是以食物製備、加工動作作為中介，將抽象情感或記憶轉化為具體可感的意象，寫作手法最為相近，故選（A）。

B：「歷史是一幅畫，時間是絢麗的色彩」是將歷史、時間兩個抽象概念，各自比擬為畫、色彩這類具體事物，屬於單純的譬喻（暗喻），並未透過動作將抽象事物加工轉化，與題幹句子藉由「熬」這一具體動作進行轉化的手法不同。

C：「他的笑聲，響亮到足以讓沉睡的山峰甦醒」是誇飾兼擬人手法，重點在誇大笑聲的音量效果，並賦予山峰沉睡、甦醒的人的動作，聚焦於聲響的渲染，與題幹句子將情感具象化為傷口的轉化邏輯不同。

D：「慢慢的拼湊，拼湊成一個完全不屬於真正的我」雖同樣把抽象的自我認同予以具象化，但採用的是拼湊這種組合、堆疊意象的動作，與題幹句子熬煮這種經加溫轉化而成的意象性質不同，兩者所選用的具體動作類型並不相同。

本題考點：現代文學修辭中「抽象情感具象化」的寫作手法，須辨析其中介動作的性質（如熬煮、加工類動作對比拼湊、組合類動作對比純粹譬喻對比誇飾擬人），判斷手法是否相近時應聚焦於用什麼具體動作把抽象事物轉化成什麼可感形體這一核心結構，而非僅看表面是否都涉及情感描寫。

第 25 題

作者透過紅豆一物主要是想要表達什麼看法？
  1. （A）藉紅豆詠嘆文士與名妓間愛情故事
  2. （B）對故友或戀人的相思之情古今皆同
  3. （C）物品象徵意涵會隨觀者詮釋而不同
  4. （D）歌詠之物於各時代皆會有不同樣貌

答案：（C）

詳解與考點

正解：本文以紅豆為線索，串起陳寅恪撰寫《柳如是別傳》的機緣、錢謙益與柳如是的情緣、以及林夕填詞〈紅豆〉時借物抒情等多個層次。同一物象在陳寅恪筆下是考證柳如是生平的學術契機，在錢謙益與柳如是之間是情緣祝壽的瑞兆，在林夕詞作中又化為現代流行文化裡的相思意象。全文反覆呈現的是：紅豆並沒有固定不變的單一意涵，而是隨著不同觀者的際遇與詮釋角度，被賦予截然不同的象徵，故答案為C。

A：（A）僅將紅豆定位為詠嘆文士與名妓愛情故事的媒介，只涵蓋錢謙益與柳如是這一段情緣，未能涵蓋陳寅恪據以考證的學術線索、林夕填詞的現代詮釋等文中其他層次，範圍過於侷限。

B：（B）主張相思之情古今皆同，強調的是情感內涵的恆常不變；但文中特別指出王維〈相思〉本非詠男女之情、而是懷念摯友李龜年，與錢柳、林夕的用法各異，正說明「相思」的所指會隨語境轉變，與B所述的恆常不變恰好相反。

D：（D）聚焦歌詠之物的樣貌隨時代不同，重點放在紅豆這一物件外在形貌或用途的改變；但全文真正著力鋪陳的是紅豆所承載的「意涵」如何因觀者不同而轉變，而非紅豆這項物品本身的樣貌變化，方向有所偏移。

本題考點：託物言志散文的閱讀理解，掌握「物象」與「象徵意涵」的區辨——同一物象可因敘事脈絡、觀看者身分與時代語境而承載不同的象徵意義，須綜合全文多個事例歸納作者真正的論旨，而非只擷取單一段落的表面訊息。
