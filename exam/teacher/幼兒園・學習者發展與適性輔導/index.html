第 2 題

小安經常在教室中橫衝直撞碰倒桌椅,下列老師的回應,何者較符合「我訊息」(I-message)的原則?
  1. （A）「我已經說過很多次了喔!再跑你會受傷喔!」
  2. （B）「你在教室又衝又跑,我擔心你會受傷,請你用走的。」
  3. （C）「我生氣了喔!你不記得和我的約定嗎?在教室中要怎樣?」
  4. （D）「你很愛用衝的跑的,我覺得這是不可以的行為,請你用走的。」

答案：（B）

詳解與考點

正解：「我訊息」的完整結構是：客觀描述具體行為→表達自身感受→提出具體請求，且不對當事人做人身評價或指責。選項（B）「你在教室又衝又跑，我擔心你會受傷，請你用走的」依序做到了描述行為、表達感受、提出請求，完整符合我訊息的結構，故選（B）。

A：「我已經說過很多次了喔！再跑你會受傷喔！」偏向重複告誡與警告的語氣，並未清楚表達教師自身的感受，語句仍帶有指責、翻舊帳的意味，不符合我訊息強調當下感受表達的原則。

C：「我生氣了喔！你不記得和我的約定嗎？在教室中要怎樣？」雖以「我生氣了」開頭表達情緒，但隨即反問質疑幼兒是否遵守約定，帶有責備、質問的語氣，實質上仍是聚焦於指責對方「你」的行為，屬「你訊息」的變形。

D：「你很愛用衝的跑的，我覺得這是不可以的行為，請你用走的」以「你很愛用衝的跑的」為開頭，對幼兒的行為傾向貼上負面標籤、做出人格化的評價，屬於評價幼兒行為模式的「你訊息」，即使後面接了請求，開頭的指責性描述已違背我訊息不評價人身的原則。

本題考點：溝通分析中的「我訊息」與「你訊息」。我訊息聚焦於「描述行為＋表達感受＋提出請求」，避免對他人做評價或貼標籤；你訊息則常見於指責、質問、貼標籤等語句，關鍵差異在於語句是否聚焦於說話者自身的感受與需求，而非對聽者的評價。

第 7 題

小班的阿群在幼兒園做了一隻鍬形蟲，老師和其他幼兒都稱讚他的作品。回家後他開心的告訴媽媽：「班上的同學都說我很會做鍬形蟲，我是最會做鍬形蟲的人！」阿群的行為表現較符合哪一項能力發展？
  1. （A）自我概念(self-concept)
  2. （B）後設認知(meta-cognition)
  3. （C）自我調節(self-regulation)
  4. （D）社會參照(social referencing)

答案：（A）

詳解與考點

正解：阿群將老師與同儕對其作品的稱讚，內化為「我是最會做鍬形蟲的人」這樣對自身能力的具體評價，這正是自我概念（self-concept）的展現——幼兒對自己特質、能力的認識與評價，學前階段的自我概念常建立在具體技能表現與他人回饋之上，故選（A）。

B：（B）後設認知（meta-cognition）指對自己「思考歷程」本身的覺察與監控（例如知道自己用了什麼方法解題、是否理解某個概念），阿群的表現是對自身能力結果的評價，並非對思考歷程本身的反思，故不選。

C：（C）自我調節（self-regulation）指管理自己的情緒、行為以達成目標或符合情境要求的能力（例如延宕滿足、控制衝動），與阿群單純評價自己作品能力表現的行為無關，故不選。

D：（D）社會參照（social referencing）指幼兒在情境意義不明確、無法自行判斷時，觀察他人（通常是照顧者）的情緒反應以決定自己該如何反應或感受，通常出現在幼兒面對陌生或不確定情境時；本題阿群面對的是已獲得明確稱讚、已內化為自我能力評價的情境，與觀察他人情緒以定向反應的社會參照不同，故不選。

本題考點：幼兒社會情緒發展中的相近構念辨析——自我概念（對自身特質能力的認識評價）、後設認知（對思考歷程的覺察）、自我調節（對情緒行為的管理控制）、社會參照（情境不明時參考他人情緒反應）。判準在於該行為指涉的對象是「能力自評」「思考歷程」「情緒行為控制」還是「情境判斷的參考依據」。

第 11 題

下列老師的引導用語,何者較有助於創造互助合作的班級氛圍?
  1. （A）用餐時間,老師說:「我來看看你們誰可以第一個吃完。」
  2. （B）戶外運動時間,老師說:「你們跑得最快的人可以得到禮物。」
  3. （C）學習區時間,老師說:「你們這組可以把積木堆得比昨天高嗎?」
  4. （D）集合時間,老師說:「你們誰鞋子穿得最快,就可以排第一個。」

答案：（C）

詳解與考點

正解：選項（C）「你們這組可以把積木堆得比昨天高嗎？」以小組為單位、並以「與自己過去表現比較」（比昨天）作為努力目標，鼓勵同組幼兒共同合作以達成進步，過程中幼兒彼此協力而非互相較勁，最有助於營造互助合作的班級氛圍，故選（C）。

A、B、D：（A）「誰可以第一個吃完」、（B）「跑得最快的人可以得到禮物」、（D）「誰鞋子穿得最快，就可以排第一個」三者引導邏輯相同，皆是以「個人」的速度或完成順序分出高下，並搭配名次、獎勵或排隊優先權作為誘因，使幼兒彼此競速搶快、視同儕為競爭對手；差別僅在誘因形式——A是「第一名」的名義、B是實質獎品、D是排隊優先權，但三者本質皆強化個人間的競爭關係，與合作氛圍的營造方向相反。

本題考點：班級經營中競爭導向與合作導向引導語的辨析。合作導向的引導語通常具備兩項特徵：以小組（而非個人）為單位、以自我或團隊的進步（而非贏過他人）為目標；教師的用語選擇直接形塑幼兒之間是競爭關係還是合作關係。

第 15 題

玩攀爬活動時,小杏不慎墜落,哭著喊痛。李老師發現他右前臂腫脹且輕微彎曲,但沒有傷口。李老師的緊急照護方式,下列何者不適當?
  1. （A）幫小杏冰敷,以減少皮下出血、腫脹及疼痛
  2. （B）固定後將右前臂抬高,超過心臟的水平高度
  3. （C）將小杏移至陰涼處之後,再以夾板固定右前臂
  4. （D）將夾板放在右前臂底下,並固定上下兩端的關節

答案：（C）

詳解與考點

正解：小杏右前臂腫脹且輕微彎曲，高度懷疑骨折，正確的緊急處理原則是應先以夾板固定患肢，避免在搬移過程中骨折斷端錯位、刺傷周邊血管神經或加重組織損傷，確定固定妥當後才移動傷者。選項C卻是「先將小杏移至陰涼處，之後才固定夾板」，順序恰好顛倒——在未固定之前移動患肢，正是骨折急救最應避免的錯誤，故C為不適當的做法，本題答案為C。

A：冰敷可使局部血管收縮，減少皮下出血、腫脹及疼痛，是疑似骨折初期常見且正確的處理方式，並非不適當。

B：固定完成後將患肢抬高、超過心臟水平，有助於促進靜脈回流、減輕腫脹與疼痛，是骨折固定後的正確後續處理，並非不適當。

D：夾板應置於患肢底下，並固定住骨折處上、下兩端的關節（即腕關節與肘關節），才能達到有效固定、避免斷端在搬移過程中錯位的效果，此為夾板固定的正確原則，並非不適當。

本題考點：疑似骨折的現場急救處理原則。核心原則為「先固定、後移動」——搬移傷者之前務必先以夾板固定患肢並跨越上下兩端關節，同時輔以冰敷消腫、抬高患肢促進回流；本題陷阱在於把「先移動、後固定」包裝成合理的先後步驟，須留意處置順序才是判斷關鍵，而非各單項措施本身是否正確。

第 19 題

五歲的小童家裡主要使用的兩種語言是華語和越南語，因為媽媽鼓勵他學習越南語，特意和他以自己的母語(越南語)交談。平常和其他家人互動則以華語為主。小童的老師可以給小童家人什麼建議？
  1. （A）繼續如此做，小童長大後自然成為雙語聽與說的使用者
  2. （B）繼續如此做，但慢慢減少越南語的使用，以免干擾華語的學習
  3. （C）不必如此做，因為家裡使用的兩種語言不同，不會有好的學習效果
  4. （D）不必如此做，因為家裡使用多種語言的環境，會增加小童的學習負擔

答案：（A）

詳解與考點

正解：學前階段是幼兒語言發展的關鍵期，幼兒具備同時習得兩種甚至多種語言的能力。題幹中媽媽以自己的母語（越南語）與小童互動、其他家人以華語互動，形成類似一人一語（one parent, one language）的雙語教養模式；只要環境中持續且穩定地提供充足的語言輸入，幼兒便能自然發展成兼具聽與說能力的雙語使用者，此作法應予肯定並鼓勵延續，故選A。

B：主張應繼續但慢慢減少越南語的使用，以免干擾華語的學習，此建議假設雙語環境會互相干擾、排擠母語（華語）的發展，但雙語習得研究並不支持此一假設，穩定的雙語輸入本身並不會妨礙幼兒對另一語言的發展，減少越南語反而可能中斷一人一語模式原有的語言輸入品質。

C：主張不必如此做，因為家裡使用的兩種語言不同，不會有好的學習效果，此說法對幼兒雙語學習能力的評估有誤——幼兒的語言學習彈性遠高於成人預期，不同語言之間的差異並不會使雙語學習沒有效果。

D：主張不必如此做，因為多語環境會增加小童的學習負擔，同樣是對幼兒認知與語言學習彈性的錯誤假設；研究顯示穩定的多語環境不僅不會造成過度負擔，反而有利幼兒的認知彈性與語言發展。

本題考點：幼兒雙語習得（bilingual first language acquisition）。學前幼兒具備同時發展兩種語言的能力，一人一語是常見且有效的雙語教養策略，關鍵在於維持穩定、充足的語言輸入；作答時應辨識題幹描述的教養方式是否符合雙語習得的正向條件，而非預設多語環境必然造成干擾或負擔。
