第 1 題

黃老師在教五年級分數四則計算時,發現學生無法理解 1/3 和 4/12 為等值分數。依據皮亞傑(J. Piaget)的認知發展理論,下列何種教學策略較合適?
  1. （A）提供數棒條或圓形切片,讓學生實際操作並比較整體大小
  2. （B）直接示範約分或擴分的規則,並要求學生反覆的練習計算
  3. （C）先測驗學生等值分數公式的知識,再依結果進行補救教學
  4. （D）講解等值分數的計算步驟,讓學生模仿解題再練習應用題

答案：（A）

詳解與考點

正解：五年級學生約十至十一歲，依皮亞傑認知發展理論，多處於具體運思期，此階段兒童的邏輯思考仍高度仰賴具體事物的操作與感官經驗，尚難單憑抽象符號、口頭規則理解「等值」這種涉及量的保留（守恆）概念的抽象關係。提供數棒條或圓形切片，讓學生親手切割、拼合、比較整體大小，能使學生透過實際操作具體感受 1/3 與 4/12 所代表的量相同，最符合具體運思期學生需藉具體操作物建構抽象概念的認知特性，故選（A）。

B：直接示範約分或擴分的規則並要求反覆練習計算，屬於形式運思期才較能單憑抽象符號運作的教學方式，跳過了具體運思期學生所需的具體操作鷹架，學生即使能機械記憶規則，也未必真正理解「等值」背後量的意義。

C：先測驗學生等值分數公式的知識、再依結果補救教學，仍停留在抽象紙筆測驗層次，並未提供具體操作經驗協助學生建立量的概念，無法對應具體運思期兒童認知發展的需求。

D：講解等值分數的計算步驟、讓學生模仿解題再練習應用題，同樣以抽象符號講述與模仿為主要方式，未觸及具體運思期學生所需透過實物操作、感官經驗建構抽象概念的歷程。

本題考點：皮亞傑認知發展理論中具體運思期的特徵與教學應用。此階段兒童需藉具體操作物建立邏輯關係與守恆概念，教學上應提供可操作、可觀察的教具，而非直接以抽象符號規則講述。

第 6 題

丁老師在教槓桿原理之前,先讓學生到室外玩翹翹板,體驗坐在距離支點不同的位置如何影響翹翹板的平衡,以幫助學生學習新知識。丁老師運用以下哪種策略?
  1. （A）自我提問
  2. （B）提取練習
  3. （C）前導組織
  4. （D）理解監控

答案：（C）

詳解與考點

正解：丁老師在正式教授槓桿原理之前，先安排學生到室外體驗翹翹板兩端距支點遠近如何影響平衡，目的是在學生尚未接觸抽象的槓桿原理之前，先啟動並連結他們既有的生活經驗，為新知識搭建一座銜接的橋樑。這正是奧蘇貝爾（D. Ausubel）意義學習論中的「前導組織」（advance organizer）策略：教師在正式教學前，提供一個涵蓋性較廣、能與學生既有認知結構產生連結的引導活動或概念架構，使新學習內容有所依附，故選（C）。

A：自我提問是學習者在學習歷程中，主動針對教材內容向自己提出問題以促進理解與監控的後設認知策略，發動者是學生本人、且發生在學習「進行中」，與丁老師在課前安排的體驗活動性質不同。

B：提取練習是指學習者透過測驗、回憶或默寫等方式，主動從記憶中檢索已經學過的內容，藉此強化長期記憶的保留，屬於學習「之後」的複習鞏固策略，與課前建立先備經驗的用意相反。

D：理解監控是學習者在閱讀或學習過程中，持續檢核自己是否確實理解內容、並適時調整策略的後設認知能力，同樣發生在學習歷程「之中」，並非教師於教學前所安排的暖身經驗。

本題考點：奧蘇貝爾意義學習論中的前導組織（advance organizer），功能是在正式教學前搭建舊經驗與新知識的橋樑；並需與自我提問、理解監控等後設認知策略，以及提取練習等複習策略相區辨，判準在於介入的時間點（課前導入 vs. 學習中或學習後）與發動者（教師安排 vs. 學生自發）。

第 11 題

小凱是新來的轉學生,王老師出於善意跟大家介紹:「小凱因為父親有家暴行為,父母離異後由外公照料,轉學到班上,請大家要多關心他」。王老師最可能違反下列何種學生輔導工作倫理守則?
  1. （A）隱私權
  2. （B）公正對待
  3. （C）知後同意
  4. （D）預警責任

答案：（A）

詳解與考點

正解：王老師在全班同學面前，未經小凱或其監護人同意，逕自公開小凱父親家暴、父母離異、由外公照料等高度私密的家庭資訊，即使出於希望大家關心他的善意，仍構成對學生隱私的侵犯。學生輔導工作倫理守則明定學生的家庭背景、身心狀況等資訊應予保密，僅能在必要且經當事人同意的範圍內揭露，故王老師最可能違反的是（A）隱私權。

B：公正對待指教師應一視同仁對待所有學生，不因家庭背景、身心狀況而有差別待遇。王老師的用意是要大家關心小凱，並非對小凱有差別待遇或不公平的處置，與本題所涉的資訊揭露問題角度不同。

C：知後同意通常指在提供輔導、測驗或介入服務之前，事先向當事人說明內容並取得同意，重點在服務「開始前」的告知義務。本題情境不是輔導服務前的說明程序，而是未經同意逕自公開隱私資訊，性質不同，故不選C。

D：預警責任指當事人有危及自己或他人安全之虞時，輔導人員對可能受害的第三方負有示警義務。本題情境並未涉及任何安全危害的預警需求，王老師公開資訊的出發點是善意介紹而非示警，故不成立。

本題考點：學生輔導工作倫理守則中的隱私權與知後同意之區辨。隱私權規範「是否、如何揭露當事人資訊」，知後同意規範「服務提供前是否告知並取得同意」，兩者作用階段與對象不同，須依情境判斷所違反的是哪一項倫理守則。

第 16 題

小志要參加校外教學,前一天晚上就買好隔日的午餐(御飯糰加飲料)放在冰箱內。為了怕忘記帶午餐,特別在門把上夾了一張紙條,上面畫了一個三角形提醒自己。小志使用的是下列哪一項記憶策略?
  1. （A）精緻化 (elaboration)
  2. （B）意元集組 (chunking)
  3. （C）選擇性注意 (selective attention)
  4. （D）外在記憶輔助 (external memory aids)

答案：（D）

詳解與考點

正解：小志在門把上夾紙條並畫上三角形，是運用外部的物理提示物（紙條、圖示）來提醒自己攜帶午餐，而非依賴大腦內部對訊息本身進行加工的認知歷程，這正是外在記憶輔助（external memory aids）的定義——透過清單、便條、鬧鐘等外部工具來輔助記憶與提醒待辦事項，故選（D）。

A：精緻化（elaboration）是將新訊息與既有知識、經驗產生意義上的連結以增進記憶，例如為抽象內容編故事或找關聯；題幹中小志並未對「帶午餐」這件事賦予任何意義連結，紙條上的三角形只是外部提示符號，並非精緻化的內在編碼歷程。

B：意元集組（chunking）是將零碎、獨立的訊息組織成有意義的較大單位以減輕記憶負荷，例如將電話號碼分段記憶；題幹情境只有單一待辦事項（帶午餐），並不涉及將多筆零散訊息重新組織集組。

C：選擇性注意（selective attention）指從眾多刺激中挑選特定訊息加以注意處理，強調的是注意力資源的分配，而非藉助外部工具來輔助記憶，與題幹紙條提示的性質不同。

本題考點：後設記憶策略中內在策略與外在策略的區分。精緻化、意元集組屬於對訊息本身進行認知加工的內在記憶策略；外在記憶輔助則是藉助紙條、清單、鬧鐘等外部物理工具來提示或儲存待記憶的內容，判準在於記憶負荷是放在大腦內部歷程還是外部工具上。

第 21 題

小學五年級的小和來自新移民家庭,平常就能夠很自然的使用國語以及越南語溝通。 相較於只習慣使用國語溝通的同學,小和在下列哪一項能力的發展較為有利?
  1. （A）執行功能
  2. （B）情緒覺察
  3. （C）圖形辨識
  4. （D）知覺廣度

答案：（A）

詳解與考點

正解：雙語兒童因日常需在兩套語言系統間切換、並抑制非目標語言的干擾，其執行功能較單語兒童更具發展優勢，此為雙語認知優勢研究領域中最一致的核心發現。小和自然使用國語與越南語溝通，正持續在鍛鍊語言切換與抑制干擾的歷程，故相較於只使用國語的同學，小和在執行功能的發展較為有利，選（A）。

B：（B）情緒覺察指個體對自身與他人情緒狀態的辨識能力，屬社會情緒發展的範疇，雙語經驗主要作用於認知控制層面，與情緒辨識能力並無直接、一致的關聯，故非雙語優勢的核心領域。

C：（C）圖形辨識屬視覺知覺與圖形認知能力，雙語切換所鍛鍊的是語言層面的抑制與監控機制，與視覺圖形處理屬不同的認知系統，雙語文獻並未一致支持雙語經驗對圖形辨識具有優勢。

D：（D）知覺廣度指個體同時能處理的訊息量或注意力所能涵蓋的範圍，雙語研究較少將其列為雙語優勢的主要指標；相較之下，執行功能才是雙語兒童認知優勢文獻中最一致、最核心的發現。

本題考點：雙語經驗與執行功能（executive function）的關聯，即所謂雙語認知優勢（bilingual advantage）。雙語兒童因持續在兩語言系統間切換、抑制非目標語言的干擾，其抑制控制、認知彈性等執行功能成分較單語兒童更具優勢，須與情緒覺察、圖形辨識、知覺廣度等其他能力區辨。
