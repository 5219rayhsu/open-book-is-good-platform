第 1 題

依據 Betts(1985)提出的自主學習者模式(Atonomous Learner Model, ALM)，下列哪些向度名稱與其對應的內涵有誤？
  1. （A）甲乙
  2. （B）乙丙
  3. （C）丙丁
  4. （D）丁戊

答案：（D）

詳解與考點

正解：Betts（1985）提出的自主學習者模式（Autonomous Learner Model, ALM）共有五個向度，依序為：定向（Orientation）——協助學習者認識自身資優特質、了解課程內容並建立正向自我概念；個別發展（Individual Development）——培養學習者人際互動、學習策略與生涯規劃等終身學習能力；充實活動（Enrichment Activities）——由教師依學生興趣安排正式課程之外的探索性學習，重在拓展學習廣度；研討會（Seminars）——學習者以小組形式選定主題、蒐集資料並向同儕發表，重在溝通表達與教學相長；深入研究（In-depth Study）——學習者針對感興趣的主題進行個人或小組的長期深度探究，並產出成果對外發表，重在鑽研深度。五個向度中，「研討會」與「深入研究」皆涉及學習者自選主題、蒐集資料並對外發表，性質最為相近，是最容易被誤植名稱與內涵的一組；官方答案指出丁、戊兩個向度的名稱與其內涵敘述配對有誤，最可能即出現在這一組易混淆的向度上，故正確答案為（D）丁戊。

A、B、C：本題所列甲、乙、丙、丁、戊五項向度的原始敘述文字未收錄於本題資料中，僅能依官方答案「丁戊」回推丁、戊二者的名稱與內涵配對有誤，甲、乙、丙三者則應為正確配對。凡組合中排除丁戊、改納入甲、乙、丙任一者者（A之甲乙、B之乙丙、C之丙丁）皆與官方答案不符，故A、B、C皆不成立。

本題考點：Betts（1985）自主學習者模式（Autonomous Learner Model, ALM）的五大向度。依序為定向、個別發展、充實活動、研討會、深入研究；其中研討會與深入研究皆屬學習者自主探究、對外發表的性質，差異在於「廣度分享」（研討會）與「深度鑽研」（深入研究），是此模式中最容易混淆的一組向度。

第 2 題

冠宇是輕度自閉症的數理資優學生，他在獨立研究課程中，常出現尖叫及用手打頭的自傷行為。資優班老師可以運用哪一種評量方式，較有助於了解冠宇的特質與需求？
  1. （A）功能評量
  2. （B）生態評量
  3. （C）動態評量
  4. （D）實作評量

答案：（A）

詳解與考點

正解：功能評量透過觀察行為發生的前因、行為本身與後果，分析行為所欲達成的功能（如逃避作業、尋求關注、感官刺激等），藉此擬定對應的支持策略。冠宇出現尖叫及用手打頭等自傷行為，教師最需要先了解這些行為背後所欲達成的目的或原因，才能對症擬定介入策略，故功能評量最有助於了解冠宇的特質與需求，選（A）。

B：（B）生態評量著重評估學生在生活情境與例行活動中的實際表現與環境需求間的落差，多用於功能性生活技能課程的規劃，並非針對特定問題行為背後成因的分析工具，與本題聚焦「尖叫及打頭行為」的評量目的不符。

C：（C）動態評量透過「測驗－教學－再測驗」的歷程評估學生的學習潛能與可教育性，適用於認知學習能力的評估，與分析自傷行為的功能成因屬不同評量目的，容易因兩者皆強調「歷程」而混淆，但動態評量評的是學習潛能而非行為功能。

D：（D）實作評量是透過實際操作任務或作品評量學生的能力與學習成果，聚焦於學業或技能表現的展現，同樣非用於解析自傷行為的成因與功能。

本題考點：功能評量的核心概念，透過前因-行為-後果分析行為的溝通功能，是特殊教育中處理問題行為的標準介入起點；需與生態評量（生活技能落差）、動態評量（學習潛能）、實作評量（技能展現）等不同目的的評量工具做區辨。

第 3 題

行動不便的雙重特殊需求學生往往成為體育課的客人，為讓其參與體育課，下列哪種作法較不適切？
  1. （A）結合音樂共振效應設計體育課
  2. （B）安排一對一的體育活動避免危險
  3. （C）提供雙重特殊需求學生體育自我決策機會
  4. （D）透過適應體育設計讓雙重特殊需求學生參與其中

答案：（B）

詳解與考點

正解：題目詢問哪一種做法「較不適切」。選項B「安排一對一的體育活動避免危險」雖然立意在保障安全，但實務上容易讓行動不便的雙重特殊需求學生因此脫離班級團體活動，形成另一種形式的隔離與旁觀，未能真正達到讓學生參與體育課、融入同儕互動的目標，反而可能強化其「成為體育課客人」的處境，故此做法較不適切，選B。

A：「結合音樂共振效應設計體育課」透過感官刺激的調整，讓行動不便學生能以自己可及的方式感知與參與課程活動，屬於積極的適應性教學設計，有助於融入。

C：「提供雙重特殊需求學生體育自我決策機會」讓學生依自身身體狀況與能力選擇參與方式，有助於提升其參與動機與自主性，屬於適切的融合作法。

D：「透過適應體育設計讓雙重特殊需求學生參與其中」直接調整活動內容、規則或器材，使學生得以在調整後的活動中與班級同儕共同參與，是體育融合教育的核心作法。

本題考點：雙重特殊需求（行動不便）學生的適應體育（adapted physical education）融合原則。適切做法應以「調整活動內容、規則、器材或感官刺激」使學生融入班級團體參與為核心，而非以個別隔離的方式換取安全，作答時須辨別做法究竟是促進融入、抑或造成另一種形式的排除。

第 4 題

資優生小雯擅長動手操作,小強能言善道,小靖想像力豐富。教師在進行環境保護議題的區分性教學時,分別派予三位學生行動者、宣導者及創新者的任務。此種安排較屬於下列哪些設計? 甲、認知能力分組 乙、興趣領域分組 丙、優勢能力分組 丁、學習特性分組
  1. （A）甲乙
  2. （B）甲丁
  3. （C）乙丙
  4. （D）丙丁

答案：（D）

詳解與考點

正解：教師依小雯擅長動手操作、小強能言善道、小靖想像力豐富的各自優勢，分別指派行動者、宣導者、創新者的任務，這正是依學生各自擅長的能力面向來分派任務，屬於丙「優勢能力分組」的展現；同時，動手操作、口語表達、想像創造也反映三人各自不同的學習特性（偏好以行動、語言或創意方式學習與表現），因此也符合丁「學習特性分組」之設計，故選（D）丙丁。

A（甲乙）：甲「認知能力分組」指依學生認知能力高低分組，但題幹並未顯示三人能力有高低落差，只呈現能力「性質」不同而非「高低」不同，故甲不成立；乙「興趣領域分組」指依學生對議題的不同興趣分組，但題幹中三人關注的其實是同一項環境保護議題，並無不同興趣領域可言，乙同樣不成立，故此選項不能選。

B（甲丁）：丁本身敘述正確，但選項同時納入不成立的甲——題幹未提及三人認知能力有高低差異，僅呈現優勢能力性質不同，故整體不能選。

C（乙丙）：丙本身敘述正確，但選項同時納入不成立的乙——三人並非依對議題的不同興趣分組，而是依各自擅長的能力被賦予不同任務，故整體不能選。

本題考點：資優教育差異化教學中的分組設計類型辨析。優勢能力分組依學生各自擅長之能力分派任務、學習特性分組依學生偏好的學習與表現方式分組，兩者皆有別於依認知能力高低分組（能力分組）與依主題興趣不同分組（興趣分組），須從題幹描述的差異是「性質不同」還是「高低不同」「興趣不同」來判斷。

第 5 題

李老師呈現一則在臺北市集會遊行的新聞報導,主辦單位宣稱參加遊行者達15萬人。李老師依據新聞照片請學生估算主辦單位宣稱的人數是否合理,並上臺報告。試問李老師的作法,最接近下列哪一種評量方式?
  1. （A）功能評量
  2. （B）生態評量
  3. （C）動態評量
  4. （D）實作評量

答案：（D）

詳解與考點

正解：李老師讓學生依新聞照片實際估算遊行人數是否合理，並公開報告推論過程與結果，這是要求學生在具體情境中實際操作、產出成果的任務，符合透過實際操作或表現產出具體成果的評量特徵，屬於實作評量，故選（D）。

A：（A）功能評量分析行為，尤其是問題行為發生的前因、後果與功能，用以擬定行為介入策略，與本題估算人數的認知推理任務性質不同。

B：（B）生態評量評估個人在其生活環境中所需具備的技能，常用於身心障礙學生的功能性課程鑑定，聚焦生活適應而非學科認知任務，與本題情境不符。

C：（C）動態評量採「測驗－教學－再測」模式，重在評估學生透過中介教學介入後的學習潛能與進步幅度；本題僅要求學生獨立估算並報告，並無教師中介教學與再測的歷程，故不符。C容易與D混淆，因為兩者都強調學生的主動參與，但動態評量的核心在教學介入前後的能力變化，實作評量的核心在產出成果的品質，本題只涉及後者。

本題考點：多元評量方式的辨析。實作評量重在學生實際操作、產出具體成果；功能評量重在問題行為的前因後果分析；生態評量重在生活環境所需技能；動態評量重在教學中介後的學習潛能變化；辨析關鍵在於題幹描述的評量歷程中是否包含教學介入、再測，或僅是要求學生完成一項具體任務。

第 6 題

耀揚剛剛通過資優鑑定成為國小資優班的新鮮人,資優班的汪老師發現耀揚的社經地位不利,使其無法在班級學習上充分發展潛能。汪老師可以提供下列哪一種服務較有助於耀揚的順利學習與成長?
  1. （A）安排豐富的探索性活動,拓展耀揚的視野
  2. （B）提供耀揚經濟補助,讓他參加各種課外輔導
  3. （C）個別為耀揚開設情意課程,降低同學對他的偏見
  4. （D）積極鼓勵耀揚追求完美,擺脫社經地位不利的背景

答案：（A）

詳解與考點

正解：耀揚雖已通過資優鑑定、具備潛能，但因社經地位不利，成長過程中較缺乏機會接觸多元、豐富的學習經驗與刺激，導致既有潛能無法在班級學習中充分展現。因此，汪老師最應優先提供的是安排豐富的探索性活動（enrichment activities），透過拓展耀揚的生活經驗與視野，補足其因社經弱勢而缺乏的多元接觸機會，讓他有更多機會發現並開展自身的潛能領域，故選（A）。

B：提供經濟補助讓耀揚參加各種課外輔導，固然能緩解其因經濟弱勢而無法參與校外學習活動的處境，但補助本身只是解決「有沒有錢去參加」的問題，並不保證所參加的輔導活動具有拓展視野、發掘多元潛能的探索性質，性質偏向消極補救而非積極拓展。

C：個別為耀揚開設情意課程以降低同學對他的偏見，處理的是同儕人際互動與情意適應的問題，這與社經地位不利導致視野與經驗受限、潛能未能充分發展的核心困境並非同一層次的問題，並非當前最迫切需要提供的服務。

D：積極鼓勵耀揚追求完美以擺脫社經地位不利的背景，不僅未能真正處理視野與經驗受限的根本問題，完美主義（perfectionism）本身更是資優生常見、需要被引導與調適的負向特質，鼓勵學生以追求完美作為突破背景的手段，反而可能加重其心理壓力，並不適切。

本題考點：資優教育中對社經地位不利資優生的服務策略——優先透過豐富化（enrichment）的探索性活動拓展其生活經驗與視野，補足環境刺激的不足，而非僅止於經濟補助或情意支持等次要或消極的做法；同時須留意資優生常見的完美主義傾向不宜被鼓勵強化。

第 7 題

為培養資優學生的批判能力,張老師請學生探究「哥倫布發現新大陸」的議題,再於期末讓學生以辯論方式,由正方和反方爭辯此議題對人類發展的影響。根據張老師的教學設計,可以培養資優學生達成哪些教學成效? 甲、領導指揮才能 乙、分析後設能力 丙、溝通辯證能力 丁、創造發明能力
  1. （A）甲乙
  2. （B）甲丁
  3. （C）乙丙
  4. （D）丙丁

答案：（C）

詳解與考點

正解：張老師先讓學生探究「哥倫布發現新大陸」議題，此歷程需要學生蒐集資料、拆解議題脈絡並反思思考歷程，培養分析與後設思考能力，即乙；期末再以辯論方式由正反方針對此議題對人類發展的影響進行論辯，需要學生組織論點、掌握證據並與對方交鋒說服，培養溝通辯證能力，即丙。二者皆吻合教學設計的兩個階段，故正確組合為乙丙，選C。

A（甲乙）：乙成立如前所述，但甲領導指揮才能與本活動性質不符——探究議題與辯論皆著重個人或小組的論證與說服，並非團體任務中的指揮調度，甲不成立。

B（甲丁）：甲不成立如A所述；丁創造發明能力也不符，本活動聚焦既有歷史事件的分析與立場論辯，並非要求學生產出原創發明或新構想，丁亦不成立。

D（丙丁）：丙成立，但丁不成立，理由同B。

本題考點：批判思考教學活動與能力指標的對應。探究式議題分析對應分析、後設能力，正反方辯論對應溝通辯證能力；領導指揮才能通常對應團體任務分工情境，創造發明能力則對應原創產出情境，須依教學活動的具體操作內容逐一比對。

第 8 題

資優班黃老師在指導學生進行獨立研究時,因應疫情停課改為居家線上學習,下列哪些原則較符合該種課程設計的理念? 甲、考量學生學習風格使用同步或非同步的內容講解模式 乙、提供不同難易度的網站或網路資源，讓學生自主學習 丙、讓每位學生皆以「疫情對學習的影響」為題進行研究 丁、請家長了解學生研究進度，並適時管控電腦使用時間
  1. （A）甲乙丙
  2. （B）甲乙丁
  3. （C）甲丙丁
  4. （D）乙丙丁

答案：（B）

詳解與考點

D（乙丙丁）：本選項除納入丙之外，也未包含甲（依學習風格彈性採同步或非同步講解），而學習風格的因應正是居家線上學習能否兼顧個別差異的關鍵原則之一，缺漏甲、又納入丙，故不成立。

第 10 題

  2. （B）甲丙
  3. （C）乙丁
  4. （D）丙丁

答案：（B）

詳解與考點

正解：評量資優學生主題探究課程的學習表現，宜採用能反映個別化探究歷程、並培養學生自我監控能力的作法。「甲」師生共同建構評量規準，能提升學生對評量標準的理解與參與感，使評量規準更貼合探究主題的實際內容；「丙」允許學生運用規準進行自評與互評，有助於培養學生的後設認知與自我調整能力，也是主題探究課程強調學生自主學習精神的具體落實。甲、丙皆為適切作法，合併即為B。

  2. （B）甲丙
  3. （C）乙丁
  4. （D）丙丁

正解：DISCOVER模式的六個問題層次，是提供教師依聚斂或擴散程度彈性選用、設計問題的參考架構，其精神在於容許學生依自身多元智能的優勢能力，以不同的形式展現學習成果（乙），並著重高層次思考與問題解決能力的培養（丁），故正確組合為乙丁，答案為（C）。

本題考點：多元族群優勢智能發展模式（DISCOVER）的六個問題層次運用原則。此模式強調教師應依學生的多元智能優勢與能力現況，彈性選用聚斂或擴散程度不同的問題類型，重視高層次思考與問題解決能力的培養，而非要求每節課窮盡所有類型，也非依固定順序機械式教學。

第 14 題

資優班五年級學生為了活化學校閒置空間的使用,決定以問題本位學習(problem-based learning)的模式進行探究,希望將研究結果提供學校作為校舍規劃的參考。下列哪一項作法較不符合問題本位學習的理念?
  1. （A）學生可依學習特質做任務編組,以小組方式探究閒置空間的使用
  2. （B）學生決定從學校行政及師生的觀點,蒐集對閒置空間使用的期望
  3. （C）學生反思如何融合行政考量及師、生需求,探究閒置空間的使用
  4. （D）探究過程中,教師要掌握學生研究進度,隨時控管學生探究行為

答案：（D）

詳解與考點

正解：問題本位學習（problem-based learning, PBL）強調以學生為中心的自主探究，教師的角色是引導者、促進者與資源提供者，而非主導或控制探究歷程本身。選項D「探究過程中，教師要掌握學生研究進度，隨時控管學生探究行為」若解讀為教師全程緊迫盯人、隨時介入控管，將剝奪學生自主規劃、嘗試錯誤與承擔探究責任的空間，使探究流於教師主導而非學生自主，與PBL強調學生自主性的核心精神相違背，故D最不符合問題本位學習理念，答案為D。

A：學生可依學習特質做任務編組，以小組方式探究閒置空間的使用——此作法符合PBL強調的合作學習精神，依學生特質彈性分工能發揮各自專長，是PBL常見且被鼓勵的實施方式。

B：學生決定從學校行政及師生的觀點，蒐集對閒置空間使用的期望——此作法符合PBL重視真實情境中多元利害關係人觀點的資料蒐集原則，學生自主決定蒐集資料的方向與對象，正是自主探究能力的展現。

C：學生反思如何融合行政考量及師、生需求，探究閒置空間的使用——此作法符合PBL要求學生統整多方考量、以解決真實問題為導向的核心歷程，學生自主進行整合與反思，同樣是PBL精神的具體實踐。

本題考點：問題本位學習（problem-based learning）的教師角色定位。PBL強調學生為探究主體，教師僅扮演引導、鼓勵、提供資源與適時提問的促進者角色，不宜過度介入、掌控或指導探究進度與行為，此與講述式教學中教師主導、學生被動接受的角色分工有本質差異。

第 17 題

下列哪些作法符合拼圖式閱讀教學? 甲、將能力相近的學生分在同組進行閱讀 乙、每位學生只負責部分閱讀主題與任務 丙、老師個別指導未精熟閱讀內容的組員 丁、透過小組討論整合各項任務完成閱讀

  2. （B）甲丙
  3. （C）乙丁
  4. （D）丙丁

答案：（C）

詳解與考點

正解：拼圖式閱讀教學（Jigsaw Reading）的核心設計，是把整篇閱讀材料拆解成幾個子任務，讓每位學生只負責其中一項、成為該部分的「專家」，如同拼圖中的一片；之後各組再回到共同小組，透過討論把各自負責的部分拼合起來，完成對整篇文本的理解。乙「每位學生只負責部分閱讀主題與任務」正是專家分工的設計，丁「透過小組討論整合各項任務完成閱讀」正是拼合階段的設計，兩者合起來即拼圖法的完整流程，故選（C）。

A（甲乙）：甲「將能力相近的學生分在同組」是同質分組，但拼圖法為使各組員能互補分工、彼此依賴進行同儕教學，通常採異質分組，讓不同能力、不同專長的學生共同組成一組，甲與拼圖法精神相反，A因含甲而不成立。

B（甲丙）：甲同樣採同質分組，與拼圖法異質分組的精神相反；丙「老師個別指導未精熟閱讀內容的組員」，其重點是教師對個別學生做一對一補救指導，而拼圖法的核心機制是讓學生彼此教學、相互依賴以完成拼圖，不是仰賴教師介入指導，丙較接近補救教學而非拼圖法的定義性特徵，B因含甲、丙皆不成立。

D（丙丁）：丙側重教師個別指導，並非拼圖法藉同儕相互教學完成拼圖的核心機制；丁雖成立，但因丙不成立，D整體不能選。

本題考點：拼圖式閱讀教學（Jigsaw Reading）的核心流程。其設計要素為異質分組、個人負責子任務成為專家、專家組討論深化、返回原組教學同儕，最終透過整合各任務完成整體閱讀理解；需與同質分組、教師直接補救指導等其他教學安排區辨。

第 20 題

林老師希望在兒童節活動中,讓學生籌備一項嶄新且具學校風格特色的活動,若以真實評量的方式評估學生的表現,下列哪些方式較為適切? 甲、活動結束後透過標準化工具,測驗學生對於兒童節的概念是否清楚 乙、以學習歷程檔案蒐集學生籌備兒童節活動的完整紀錄及其心得反思 丙、在兒童節活動課程中加入學生的自我評量,讓學生能夠反思與批判 丁、在兒童節課程活動前明訂評量方式,以確保能記錄學生真實的表現
  1. （A）甲乙
  2. （B）甲丁
  3. （C）乙丙
  4. （D）丙丁

答案：（C）

詳解與考點

正解：真實評量（authentic assessment）強調在具真實情境意義的任務中，蒐集學生實作歷程與反思的完整證據，而非僅測驗片段知識。乙敘述以學習歷程檔案完整蒐集學生籌備兒童節活動的紀錄及心得反思，直接呈現學生在真實任務中的實作歷程與反思深度；丙敘述在活動課程中加入學生自我評量，讓學生對自己的表現進行反思與批判，同樣是真實評量重視學習者主動建構與後設反思的核心作法。乙、丙兩項皆扣緊真實評量的精神，故選C（乙丙）。

A（甲乙）：甲以標準化工具在活動結束後測驗學生對兒童節「概念」是否清楚，本質是脫離情境的紙筆知識測驗，與真實評量要求「在真實任務中直接展現能力」的精神相違，A雖含適切的乙，但因含有甲而不成立。

B（甲丁）：B同樣因含有甲而不成立；丁主張活動前明訂評量方式雖立意良好，但「評量方式須事先訂定」是任何評量（不論是否為真實評量）都應具備的一般程序原則，並非真實評量獨有的判準，不足以單獨支持B成立。

D（丙丁）：丙固然適切，但丁如前段所述僅屬一般評量的共通程序、非真實評量的特有內涵，D因含有丁而不成立。

本題考點：真實評量（authentic assessment）與傳統標準化測驗的差異。真實評量強調在生活化、情境化的任務中，藉由學習歷程檔案、自我評量等方式蒐集學生實作歷程與反思證據；判斷關鍵在於評量是否測量「情境中的實作與反思」，而非只看評量方式是否事先規劃。

第 21 題

資優班陳老師藉由新興科技的探究與應用,如人工智慧、虛擬實境、擴增實境與大數據分析等,引導學生進行獨立研究。下列哪些作法較為適切? 甲、教師將所有獨立研究課程安排於電腦教室,運用AI教學 乙、讓學生應用虛擬實境或擴增實境於研究成果中,模擬真實情境的體驗 丙、引導學生學習大數據分析技能,檢視不同主題與其研究方法的關聯性 丁、指導學生運用生成式人工智慧,並挑選適合給學生後續進行研究的題目
  1. （A）甲乙
  2. （B）甲丁
  3. （C）乙丙
  4. （D）丙丁

答案：（C）

詳解與考點

正解：資優教育的獨立研究強調學生的自主探究與問題所有權，教師角色應是引導與支援，而非主導或限制學生的選擇空間。乙敘述「讓學生應用虛擬實境或擴增實境於研究成果中，模擬真實情境的體驗」，是由學生自主運用新興科技呈現研究成果；丙敘述「引導學生學習大數據分析技能，檢視不同主題與其研究方法的關聯性」，是由教師引導學生習得分析技能、進而自行探究主題與方法的關聯。兩者皆善用新興科技輔助學生自主探究，且保留學生的自主性，故乙丙皆為適切作法，答案應包含乙丙，選（C）。

A（甲乙）：甲敘述主張將「所有」獨立研究課程都安排於電腦教室、以AI教學進行，把獨立研究這種本應保有彈性、可依主題選擇不同場域與方法的學習形式，窄化為單一場域（電腦教室）與單一方法（AI教學），不符合獨立研究應保有多元樣貌與彈性的精神，故甲不適切，選項A因包含甲而不能成立。

B（甲丁）：丁敘述由教師運用生成式人工智慧，並「挑選」適合學生後續研究的題目，等於由教師（藉AI之手）代替學生決定研究方向，剝奪了學生自主選題、界定問題的空間，違背獨立研究重視學生自主性與問題所有權的核心精神，故丁不適切；選項B同時包含甲、丁兩項不適切作法，皆不能成立。

D（丙丁）：丙雖為適切作法（見前段），但丁由教師代為挑選研究題目、限制學生自主選題的空間，並不適切，選項D因包含丁而不能成立。

本題考點：資優教育獨立研究（independent study）的核心精神與教師角色定位。獨立研究強調學生的自主探究、問題所有權與方法多元性，教師的角色應是提供技能引導、資源支援與情境模擬的工具（如新興科技），而非代為選定主題或限制探究場域與方法，作答時須辨認選項描述的是「支援學生自主」還是「教師主導或限制學生自主」。

第 22 題

有關資優教育全校充實模式(school-wide enrichment model)與多層次服務策略(levels of service approach)的比較,下列哪些敘述較為適切? 甲、均強調訂定明確的鑑定篩選程序與通過標準 乙、均強調充實學習而不採用加速形式進行學習 丙、均基於學校本位實踐資優教育普通化的理念 丁、均重視學生才能發展,強調個別化和區分性
  1. （A）甲乙
  2. （B）甲丁
  3. （C）乙丙
  4. （D）丙丁

答案：（D）

詳解與考點

正解：全校充實模式（school-wide enrichment model, SEM）由Renzulli提出，主張以廣納具潛能學生的「人才庫」取代單一標籤化鑑定，並提供全校性的三合充實課程；多層次服務策略（levels of service approach）由Treffinger提出，主張以連續性、彈性化的服務層級取代單一鑑定標準，依學生實際需求調整服務內容與強度。兩者皆以學校為本位，將資優教育的精神普及化、融入一般學校情境，而非侷限於少數經鑑定通過學生的抽離式方案，故丙「均基於學校本位實踐資優教育普通化的理念」正確；兩者也都強調應依學生個別才能發展的樣貌，提供個別化與區分性（differentiated）的服務或課程內容，故丁「均重視學生才能發展，強調個別化和區分性」亦正確；丙丁皆正確，對應選項（D），故選D。

A（甲乙）：（A）納入甲「均強調訂定明確的鑑定篩選程序與通過標準」，然而兩模式恰恰是為了打破傳統以單一測驗分數為門檻、標籤化篩選的侷限而提出，主張以連續性服務或人才庫廣納方式取代嚴格的鑑定通過標準，甲敘述與兩模式的精神相反，A不能成立。

B（甲丁）：（B）雖納入正確的丁，但同時納入甲；甲主張兩模式皆強調訂定明確的鑑定篩選程序與通過標準，恰與兩模式為打破單一鑑定門檻、追求彈性化服務而生的精神相反，屬錯誤敘述，故B不能成立。

C（乙丙）：（C）雖納入正確的丙，但同時納入乙「均強調充實學習而不採用加速形式進行學習」；多層次服務策略本質上是依學生需求彈性配置服務層級，並不排除加速等其他型態的服務選項，「均不採用加速」的敘述過於絕對，與該模式強調彈性依需求配置服務的精神不符，C不能成立。

本題考點：資優教育學校本位服務模式的比較——全校充實模式（Renzulli）與多層次服務策略（Treffinger）。兩者共通點在於以學校為本位推動資優教育普及化、重視學生個別才能發展與區分性服務；差異則在於課程與服務的具體設計方式；作答時須留意選項是否誇大兩模式對鑑定標準的堅持，或錯誤限縮兩模式對加速等服務形式的排斥程度。

第 23 題

資優班張老師在設計專題課程時,以「里仁為美」為主題,結合七年級社會領域中之「社區生活」單元,並融入學校「愛鄉土」之願景,引導學生針對社區改造提出構想。 此作法與下列哪些敘述較為相符? 甲、課程屬性在強化學校特色及發展學校願景 乙、可藉由社區議題的連結,使學習內容具統整性 丙、本課程的目的在養成學生對社會領域知識的基本了解 丁、課程可以藉由社區田野調查,在實際情境中整合活用
  1. （A）甲丁
  2. （B）甲丙
  3. （C）乙丙
  4. （D）乙丁

答案：（D）

詳解與考點

正解：此專題課程結合七年級社會領域「社區生活」單元、融入學校「愛鄉土」願景，引導學生對社區改造提出構想，屬資優課程設計中強調「統整性」與「情境化實作」的區分性課程原則。乙、藉由社區議題的連結，使學習內容跨越單一學科、具備統整性；丁、藉由社區田野調查，讓學生在真實情境中整合運用所學知識與技能，兩者皆精準點出此課程的核心特質，故選（D）乙丁。

A、B：兩者皆誤納甲「課程屬性在強化學校特色及發展學校願景」。學校願景「愛鄉土」在此僅是選題的背景脈絡與命題動機之一，並非此資優專題課程設計的根本屬性或核心目的；若將強化學校特色與願景視為課程主要屬性，屬本末倒置，故甲不成立：A（甲丁）除誤納甲外，丁判斷正確；B（甲丙）則同時誤納甲、丙兩項。

C：誤納丙「本課程的目的在養成學生對社會領域知識的基本了解」。資優課程設計應強調深度、複雜度與抽象化的加深加廣學習（如提出社區改造構想涉及分析、評估、創新等高層次思考），而非僅止於一般學生程度的「基本」了解，此敘述與資優課程的差異化設計原則不符，故丙不成立；乙判斷正確。

本題考點：資優教育課程的差異化設計原則。資優專題課程應強調跨領域統整性、真實情境中的高層次應用（如田野調查、方案提案），並以加深加廣取代基本知識了解；學校願景或特色僅屬選題脈絡，非課程設計的核心屬性。

第 24 題

張老師將社區發展融入創造力課程,內容分為「社區生活與社區美學營造」及「創造思考相關技能」兩大向度,並在成果評量時以「完成社區美學營造任務的動機」作為重要的評量向度之一。試問張老師採用的理論最符合哪一位學者的觀點?
  1. （A）Amabile 創造力成分模式
  2. （B）Gardner 創造力互動觀點模式
  3. （C）Csikszentmihalyi 創造力系統理論
  4. （D）Sternberg 與 Lubart 創造力投資理論

答案：（A）

詳解與考點

正解：Amabile的創造力成分模式（componential model of creativity）主張，個人的創造力表現由三項要素共同構成：領域相關技能（domain-relevant skills）、創造力相關技能（creativity-relevant skills），以及工作動機（task motivation，尤其是內在動機）。本題張老師的課程設計恰好一一對應此三要素：「社區生活與社區美學營造」對應領域相關技能，「創造思考相關技能」對應創造力相關技能，成果評量時納入「完成社區美學營造任務的動機」則呼應工作動機這項要素，三者逐一對應，故選（A）。

B：Gardner的創造力互動觀點模式著重智能表現與所處領域（domain）、他人（field，如專家社群）之間的社會互動脈絡，強調創造力是個人、領域與他人互動下的產物，並未以「技能＋技能＋動機」這種三分結構描述創造歷程，與本題課程設計的對應架構不符。

C：Csikszentmihalyi的創造力系統理論（systems model）聚焦個體（individual）、領域（domain）與學門／領域守門人（field）三者的互動，強調創造力是社會認可下的產物，關注的是創造成果如何被社會系統評價與接納，而非本題課程設計中「技能培養＋動機評量」的個人內在成分結構。

D：Sternberg與Lubart的創造力投資理論（investment theory）主張創造力需智力、知識、思考風格、人格、動機、環境六項資源共同投入，動機僅為六項資源之一，並未特別以「領域技能＋創造技能＋動機」的三分架構呈現，且本題課程設計並未涉及思考風格、人格、環境等其餘資源面向，故不符投資理論的完整架構。

本題考點：創造力理論中個人取向與系統取向模式的區辨。Amabile的成分模式屬個人內在取向，強調領域技能、創造技能、動機三要素；Gardner與Csikszentmihalyi的模式則屬系統／社會互動取向，納入他人與社會評價機制；作答時應辨認課程設計描述的是「個人內在的技能與動機組成」還是「個人與社會系統的互動歷程」。

第 25 題

在評定創造力作品或提案時常邀請跨領域專家進行共識或合意評量(consensual assessment)。下列有關共識或合意評量的敘述何者較為適切?
  1. （A）邀請跨領域專家對作品進行評定,屬於結果導向的評量
  2. （B）專家須先對作品的評量建立共識,以符合評量的信效度
  3. （C）評定作品根據各領域專業標準獨立評斷,不宜相互比較
  4. （D）相關經驗專家須依固定的順序與標準針對作品進行評量

答案：（A）

詳解與考點

正解：共識或合意評量（consensual assessment technique）由Amabile提出，做法是邀集該領域具經驗的專家，各自依其對創造力的主觀判斷，針對已完成的作品進行整體評定，屬於結果導向而非歷程導向的評量方式，故選A。

B：主張專家須先對作品建立評量共識，以符合評量的信效度，恰與此技術的精神相反——其信度並非靠專家事先商定準則而來，而是仰賴多位專家各自獨立評分後，再統計檢驗評分之間的一致性（評分者間信度）而建立，故B錯誤。

C：主張各領域專家依其專業標準獨立評斷、不宜相互比較，然而此技術通常要求評審在同一批作品中進行相對比較評定，藉由排序或評分的相對高低呈現作品間創造力的相對位置，並非各自獨立、互不比較，故C錯誤。

D：主張專家須依固定順序與標準進行評量，然而此技術的特色正是不預先設定固定的評量準則或程序，而是仰賴專家依其領域經驗對創造力所做的內隱、主觀判斷，故D錯誤。

本題考點：共識評量法（consensual assessment technique, CAT）。由Amabile提出，核心特徵是邀集該領域專家、不預設固定標準，各自依主觀判斷對完成作品進行整體（結果導向）評定，再以評分者間一致性建立信度，適用於創造力等難以用客觀標準量化的能力評量。
