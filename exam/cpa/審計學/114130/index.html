第 1 題

下列有關審計準則中對於可擴縮性之敘述，何者錯誤？
  1. （A）我國審計準則之基本準則適用所有企業之查核，無論其性質及情況複雜與否
  2. （B）查核人員可使用自動化工具及技術執行風險評估程序
  3. （C）在查核較不複雜受查者時，對於受查者之瞭解及相關事項無須全面書面化，為可擴縮性之範例
  4. （D）查核規模較小的企業，皆可適用審計準則中與可擴縮性有關之規定

答案：（D）

詳解與考點

正解：題幹的關鍵在於「可擴縮性」並非以企業規模作唯一判準，而是依受查者性質及情況複雜度調整查核工作；D 將小規模企業一概視為可適用，敘述過於絕對，故 D 為正解。

A：審計準則的基本準則適用於所有企業之查核，不因企業性質或情況複雜度而排除，正確。

B：查核人員得使用自動化工具及技術執行風險評估程序，正確。

C：查核較不複雜受查者時，對受查者之瞭解及相關事項可依情況調整書面化程度，正是可擴縮性的範例，正確。它看起來不像可擴縮性，是因為容易把「書面化」誤認為任何案件都須完全相同。

本題考點：審計準則可擴縮性——依受查者性質及情況複雜度調整查核工作，不得僅以企業規模判斷；基本準則適用所有企業，調整的是程序執行方式與範圍。

第 2 題

下列有關品質管理準則2 號「案件品質複核」之敘述，何者正確？
  1. （A）案件品質複核人員雖為案件服務團隊之成員，但對案件服務團隊所作之重大判斷及據此達成之結論須執行客觀評估
  2. （B）事務所應訂定政策或程序協助案件主辦會計師指派具備專業能力、適任能力之人員擔任案件品質複核人員
  3. （C）案件品質複核人員亦可為事務所外部之服務機構
  4. （D）若案件品質複核人員對案件服務團隊所作之重大判斷是否適當存有未解決之疑慮時，案件品質複核人員之主要責任係將此情形作成書面紀錄以釐清未來之責任歸屬

答案：（C）

詳解與考點

正解：案件品質複核人員須對重大判斷作客觀評估；適格的外部服務機構亦可擔任複核人員，故 C 正確。

A：案件品質複核人員不得為案件服務團隊成員，否則不能獨立客觀評估團隊的重大判斷，錯誤。

B：事務所應訂定政策或程序，將案件品質複核人員的指派責任交由具備專業能力、適任能力及適當權限之人員；不能表述為由事務所協助案件主辦會計師指派，錯誤。

D：對重大判斷存有未解決疑慮時，複核人員應與主辦會計師溝通，且在疑慮解決前不得作成結論；不能僅以書面紀錄作為釐清未來責任的處理，錯誤。它看起來對，是因為書面紀錄確有保存責任的作用，卻不能替代解決疑慮。

本題考點：案件品質複核——複核人員須獨立於案件服務團隊並客觀評估重大判斷；事務所須妥適設計複核人員指派機制；未解決的重大疑慮存在時，不得作成案件品質複核結論。

第 3 題

有關財務報導架構之說明，下列何者錯誤？
  1. （A）為符合廣大使用者對一般財務資訊需求所設計之財務報導架構為一般用途財務報導架構
  2. （B）財團法人中華民國會計研究發展基金會發布之企業會計準則為一般用途財務報導架構
  3. （C）一般用途財務報導架構通常為允當表達架構
  4. （D）遵循架構係指財務報導架構，要求其遵循該架構規定，並明示或隱含管理階層可能需提供超出架構所明訂之揭露

答案：（D）

詳解與考點

正解：題幹要求辨別允當表達架構與遵循架構；允當表達架構才可能要求超出架構明訂揭露，D 卻將此特徵放入遵循架構，故 D 錯誤。

A：為符合廣大使用者一般財務資訊需求設計的架構，屬一般用途財務報導架構，正確。

B：財團法人中華民國會計研究發展基金會發布的企業會計準則，屬一般用途財務報導架構，正確。

C：一般用途財務報導架構通常為允當表達架構，正確。

本題考點：財務報導架構分類——一般用途架構服務廣大使用者的一般財務資訊需求；允當表達架構可能要求額外揭露，遵循架構則以遵循明定規定為判準。

第 4 題

有關查核案件獨立性之敘述，下列何者正確？
  1. （A）查核案件小組成員家屬，係指其配偶（同居人）、子女及受扶養親屬
  2. （B）受獨立性約束之重要查核會計師，除主辦會計師外，尚包含負責案件品質複核之人員
  3. （C）若查核案件小組成員曾擔任受查核客戶之董監事，則可能因辯護緣故而影響其獨立性
  4. （D）當查核案件小組成員收受受查核客戶董監事價值重大之禮物餽贈，則可能因自我利益緣故而影響其獨立性

答案：（B）

詳解與考點

正解：受獨立性約束的重要查核會計師範圍；除主辦會計師外，負責案件品質複核的人員亦包括在內，故官方答案為 B。惟 D 依現有文字也可能成立，已形成複數正確選項。

A：獨立性規範區分直系親屬與主要近親等不同層級；將配偶、同居人、子女及受扶養親屬一概界定為「家屬」，範圍與用語不夠精確，錯誤。

C：查核案件小組成員曾任受查核客戶董監事，主要涉及自我評估或熟悉度威脅，不是辯護威脅，威脅分類錯誤。

D：收受受查核客戶董監事價值重大的禮物餽贈，確實可能造成自我利益威脅；選項只說「可能」，也未排除熟悉度或被脅迫等其他威脅，故依現有文字可成立。若題目原意為僅 B 正確，須修正 D 的敘述以消除複數正解。

本題考點：查核獨立性——重要查核會計師包含主辦會計師及案件品質複核人員；職業道德威脅應按自我利益、自我評估、熟悉度、辯護或被脅迫等性質辨識；同一情況可能同時產生一種以上威脅，不能因另有其他威脅便否定某一威脅可能存在。

第 5 題

下列有關會計師職業道德規範之敘述，何者正確？
  1. （A）會計師間不得相互介紹業務
  2. （B）事務所中僅會計師必須遵循會計師職業道德規範
  3. （C）會計師事務所設立分事務所，應由會計師親自主持
  4. （D）會計師不得作任何宣傳或廣告

答案：（C）

詳解與考點

正解：題幹考會計師職業道德規範對分事務所主持的要求；會計師事務所設立分事務所，應由會計師親自主持，故 C 正確。

A：會計師間得相互介紹業務，並非一律不得介紹，錯誤。

B：職業道德規範的遵循不僅限於會計師，事務所全體從業人員均應遵循，錯誤。

D：會計師並非完全不得宣傳或廣告，而是不得為誇大、不實或誤導的宣傳，故「不得作任何」過於絕對，錯誤。它看起來對，是因為職業專業性要求宣傳受高度限制，卻不是全面禁止。

本題考點：會計師職業道德——分事務所應由會計師親自主持；業務介紹與宣傳並非全面禁止，但不得誇大、不實或誤導。

第 6 題

有關審計準則265 號「內部控制缺失之溝通」之規定，下列敘述何者錯誤？
  1. （A）該準則所稱查核人員須與受查者溝通之內部控制缺失，僅限於就查核財務報表時所辨認之內部控制缺失
  2. （B）查核人員一定要以書面方式，與管理階層及治理單位溝通內部控制顯著缺失
  3. （C）內部控制缺失是否顯著，取決於不實表達是否已實際發生及實際發生之潛在影響
  4. （D）管理階層或治理單位如要求查核人員出具敘明其於查核過程中，未辨認出內部控制顯著缺失之書面溝通，查核人員得出具該書面溝通

答案：（C）

詳解與考點

正解：內部控制缺失是否顯著的判準，應看潛在不實表達發生的可能性及其潛在影響，而非不實表達是否已實際發生；C 錯誤。

A：準則所稱應溝通的內部控制缺失，限於查核財務報表時辨認者，正確。

B：內部控制顯著缺失應以書面與管理階層及治理單位溝通，正確。

D：管理階層或治理單位要求時，查核人員得出具於查核過程中未辨認內部控制顯著缺失的書面溝通，正確。

本題考點：內部控制缺失溝通——顯著性以潛在不實表達的可能性與影響判斷，不以實際發生為必要條件；辨認出的顯著缺失應書面溝通管理階層及治理單位。

第 7 題

在規劃查核時，查核人員所考量之查核風險，下列敘述何者正確？
  1. （A）當財務報表存有重大不實表達時，查核人員無法適當修正其意見的風險
  2. （B）受查者設置內部稽核人員，無法查出其帳戶餘額易遭受重大不實表達的風險
  3. （C）與受查者的前任會計師聯繫，瞭解前任會計師未能辨認財務報表潛在重大之錯誤風險
  4. （D）受查者設有內部控制制度，而仍無法偵出重大不實表達的風險

答案：（A）

詳解與考點

正解：題幹要求查核風險的完整定義；當財務報表有重大不實表達時，查核人員未能適當修正查核意見的風險，即為查核風險，故 A 正確。

B：此項描述帳戶餘額易遭受重大不實表達的風險，並非查核風險的完整定義，錯誤。

C：與前任會計師聯繫是接任前或規劃時的程序，並非查核風險定義，錯誤。

D：設有內部控制仍無法偵出重大不實表達，僅接近控制風險或偵查風險的構面，未涵蓋查核意見未適當修正的結果，錯誤。它看起來對，是因為內部控制失效確會提高查核風險，卻不是其定義。

本題考點：查核風險——重大不實表達存在且查核人員未適當修正意見的風險；控制風險與偵查風險屬風險模型構面，不能取代完整定義。

第 8 題

依據審計準則210 號「查核案件條款之協議」，下列何項條款為必須記載於查核委任書或其他適當形式之書面協議？
  1. （A）會計師賠償責任之限制
  2. （B）酬金之確定金額及收款方式
  3. （C）會計師查核財務報表之責任
  4. （D）提供查核工作底稿予第三方之義務

答案：（C）

詳解與考點

正解：查核委任書的強制記載事項；書面協議須載明會計師查核財務報表的責任，故 C 正確。

A：會計師賠償責任的限制不是準則要求必載的條款，錯誤。

B：酬金金額及收款方式雖可於實務協議，並非準則強制必載事項，錯誤。它看起來對，是因為公費約定在委任關係中很常見。

D：提供查核工作底稿予第三方的義務不是查核委任書的必載事項，錯誤。

本題考點：查核案件條款協議——書面協議應載明查核人員查核財務報表的責任、管理階層責任及查核範圍；實務常見約定不當然等於準則必載事項。

第 9 題

有關查核規劃作業之性質及範圍，下列何項非主要考量之因素？
  1. （A）查核團隊主要成員對受查者之查核經驗
  2. （B）查核期間有關情況之改變
  3. （C）查核公費的高低
  4. （D）受查者之規模與複雜度

答案：（C）

詳解與考點

正解：題幹問查核規劃性質及範圍的非主要考量因素；查核公費高低屬接案或商業條件，非規劃查核範圍與深度的主要因素，故 C 正確。

A：查核團隊主要成員對受查者的查核經驗會影響規劃，正確。

B：查核期間有關情況的改變會影響規劃，正確。

D：受查者規模與複雜度會影響規劃的性質及範圍，正確。

本題考點：查核規劃——受查者規模與複雜度、環境變動及團隊經驗均影響程序性質、時間及範圍；公費高低不應作為降低必要查核工作的判準。

第 10 題

有關財務報表之查核案件，下列程序之執行順序為何？①簽訂委任書 ②評估會計師職業道德規範之遵循 ③向管理階層取得書面聲明 ④瞭解受查者及其環境，以辨認並評估重大不實表達風險 ⑤執行內部控制測試
  1. （A）①②④⑤③
  2. （B）②①④⑤③
  3. （C）②①③④⑤
  4. （D）①③④⑤②

答案：（B）

詳解與考點

正解：查核案件的先後依存關係：接案前先評估職業道德規範遵循，再簽訂委任書，之後辨認風險、執行控制測試，最後取得書面聲明；順序為②①④⑤③，故 B 正確。

A：將簽訂委任書①置於職業道德規範遵循評估②之前，漏掉接案前的獨立性及職業道德確認，錯誤。

C：將書面聲明③置於風險評估④及控制測試⑤之前；書面聲明應在查核接近完成時取得，錯誤。

D：將書面聲明③置於前段，且將職業道德評估②置於最後，均違反程序順序，錯誤。

本題考點：查核程序順序——先評估職業道德與獨立性，再協議案件條款；先瞭解受查者並評估風險、執行必要程序，最後取得管理階層書面聲明。

第 11 題

查核人員於訂定整體查核策略時，下列何者通常非考量之事項？
  1. （A）與受查者溝通查核案件委任之內容
  2. （B）辨認查核案件之特性以決定查核範圍
  3. （C）依專業判斷考量重要因素，以指引查核團隊之查核方向
  4. （D）確認執行查核案件所需資源之性質、時間及範圍

答案：（A）

詳解與考點

正解：整體查核策略所處階段；與受查者溝通委任內容屬接案及委任書事項，不是訂定整體查核策略時通常考量的事項，故 A 正確。

B：辨認查核案件特性以決定查核範圍，是整體查核策略的考量事項，正確。

C：依專業判斷考量重要因素以指引查核團隊方向，是整體查核策略的考量事項，正確。

D：確認執行查核所需資源的性質、時間及範圍，是整體查核策略核心事項，正確。它看起來像行政安排，但資源配置直接決定策略能否執行。

本題考點：整體查核策略——先辨認案件特性決定範圍，再考量重要因素指引方向並配置資源；案件委任內容的溝通屬接案與條款協議階段。

第 12 題

在查核案件中，下列何者是審計準則所稱查核團隊之成員？
  1. （A）執行查核案件之事務所聘僱之專家
  2. （B）執行查核案件之查核人員外部專家
  3. （C）案件品質複核人員
  4. （D）主辦會計師決定在查核報告中提及之被提及查核人員

答案：（A）

詳解與考點

正解：審計準則對查核團隊成員的定義；執行查核案件之事務所聘僱專家屬於查核團隊成員，故 A 正確。

B：查核人員外部專家不屬查核團隊成員，錯誤。

C：案件品質複核人員須保持對案件服務團隊的客觀性，故不屬查核團隊成員，錯誤。它看起來對，是因為其參與案件品質控制，但不執行團隊查核工作。

D：主辦會計師在查核報告中提及的其他查核人員，不當然屬查核團隊成員，錯誤。

本題考點：查核團隊——事務所聘僱並執行查核案件的專家屬團隊成員；外部專家、案件品質複核人員及被提及的其他查核人員應依獨立性與職務角色區分。

第 13 題

有關管理階層踰越控制之風險，下列何者錯誤？
  1. （A）管理階層踰越控制之風險存在所有受查者中
  2. （B）無論所評估受查者管理當局踰越控制之風險高低，查核人員皆應測試會計分錄及編製財務報表所做其他調整之適當性
  3. （C）為評估管理階層踰越控制之風險，查核人員應評估受查客戶不尋常交易之動機及合理性
  4. （D）評估管理階層踰越控制之風險，管理階層過去的誠信程度為主要考量

答案：（D）

詳解與考點

正解：管理階層踰越控制風險的預設與因應；此風險不能僅以管理階層過去誠信程度作主要判斷，D 錯誤。

A：管理階層踰越控制的風險存在於所有受查者中，正確。

B：無論所評估風險高低，查核人員均應測試會計分錄及編製財務報表所作其他調整的適當性，正確。

C：評估不尋常交易的動機及合理性，是因應管理階層踰越控制風險的程序，正確。

本題考點：管理階層踰越控制——所有查核案件均須回應此預設舞弊風險；應測試分錄與其他調整並檢視不尋常交易，不能以過去誠信取代風險評估。

第 14 題

繼任會計師為對本期財務報表表示意見及查明本期財務報表所採用的會計政策是否與上期一致，應蒐集足夠適切的證據，其蒐集方式不包括：
  1. （A）對重要之期初科目餘額與上期交易事項採行適當之查核程序
  2. （B）向前任會計師查詢有關事項
  3. （C）詢問管理階層的品德
  4. （D）借閱前任會計師之工作底稿

答案：（C）

詳解與考點

正解：繼任會計師取得期初餘額及會計政策一致性證據的方式；詢問管理階層品德與期初餘額證據無直接關聯，故 C 為不包括的方式。

A：對重要期初科目餘額及上期交易事項採行適當查核程序，可取得相關證據，正確。

B：向前任會計師查詢有關事項，可協助蒐集期初餘額及會計政策一致性的證據，正確。

D：借閱前任會計師工作底稿，可作為取得證據的方法之一，正確。

本題考點：繼任會計師——期初餘額證據可由本期查核程序、向前任會計師查詢及借閱前任工作底稿取得；程序須直接服務於期初餘額與會計政策一致性。

第 15 題

下列有關審計抽樣之敘述，何者錯誤？
  1. （A）預期母體偏差率與樣本量呈正向關係
  2. （B）可容忍誤差愈小，查核人員所要求之樣本量愈小
  3. （C）在評估屬性抽樣結果時，不需要知道預期母體偏差率
  4. （D）通常查核人員對現金支出之核准情形作控制測試時，適合採用屬性抽樣

答案：（B）

詳解與考點

正解：審計抽樣中可容忍誤差與樣本量的反向關係；可容忍誤差愈小，為維持查核確信程度所需樣本量愈大，B 說愈小樣本量愈小，故錯誤。

A：預期母體偏差率愈高，通常需要較大樣本量，呈正向關係，正確。

C：評估屬性抽樣結果時，重點在將樣本偏差率與可容忍偏差率比較，不必以預期母體偏差率作評估結論，正確。

D：現金支出核准情形的控制測試，適合採用屬性抽樣，正確。

本題考點：審計抽樣——可容忍誤差愈小，樣本量愈大；預期母體偏差率愈高，樣本量愈大；控制是否遵循的測試通常採屬性抽樣。

第 16 題

查核人員為就已知訴訟或索賠辨認出重大不實表達風險，或所執行之查核程序顯示可能存在其他重大訴訟或索賠時，除執行其他審計準則規定之程序外，應與受查者之外部法律顧問直接溝通。當管理階層拒絕查核人員與外部法律顧問溝通或會面，或外部法律顧問拒絕回覆時，會計師依審計準則之規定，出具下列何種查核報告較適宜？①無保留意見 ②保留意見 ③否定意見 ④無法表示意見
  1. （A）僅④
  2. （B）①②
  3. （C）②③
  4. （D）②④

答案：（D）

詳解與考點

正解：外部法律顧問溝通受拒絕所造成的查核範圍受限；依受限對財務報表可能影響的重大性及廣泛性，應出具保留意見或無法表示意見，即②④，故 D 正確。

A：僅④忽略範圍受限未達廣泛時可出具保留意見②，錯誤。

B：包含無保留意見①不妥；法律顧問溝通受阻使證據取得受限，不應直接出具無保留意見，錯誤。

C：否定意見③適用於已取得足夠適切證據後認定財務報表有重大且廣泛不實表達，不適用於本題的範圍受限，錯誤。

本題考點：查核範圍受限——未能取得足夠適切證據時，依可能影響的重大性及廣泛性選擇保留意見或無法表示意見；否定意見以已證實的重大且廣泛不實表達為前提。

第 17 題

查核人員於執行財務報表查核時，若辨認出受查者員工疑似有未遵循法令之情況，下列何者並非正確行動？
  1. （A）評估所辨認疑似未遵循法令事項對財務報表之潛在財務影響
  2. （B）對治理單位保密，以免洩漏疑似未遵循法令事項
  3. （C）必要時向主管機關報告未遵循或疑似未遵循法令事項
  4. （D）評估疑似未遵循法令事項對查核風險評估之影響

答案：（B）

詳解與考點

正解：查核人員辨認疑似未遵循法令時對治理單位的溝通責任；不得為避免洩漏而對治理單位保密，B 並非正確行動。

A：應評估疑似未遵循法令事項對財務報表的潛在財務影響，正確。

C：必要時向主管機關報告未遵循或疑似未遵循法令事項，屬可能的正確行動，正確。它看起來越權，是因為保密義務通常存在，但法令或公眾利益要求時可能例外。

D：應評估疑似未遵循法令事項對查核風險評估的影響，正確。

本題考點：未遵循法令——查核人員應評估財務報表影響及查核風險，並與適當層級的治理單位溝通；對外報告須依適用法令及情況判斷。

第 18 題

有關採用內部稽核人員之工作之敘述，下列何者錯誤？
  1. （A）於受查者有內部稽核職能之查核案件，查核人員即可採用內部稽核工作並據以修正擬由查核人員直接執行查核程序之性質、時間或範圍
  2. （B）內部稽核職能之專業能力較為不足時，查核人員應規劃採用較少之內部稽核工作，並直接執行較多之工作
  3. （C）查核人員應就查核目的對所採用之內部稽核工作是否係屬適當，取得足夠及適切之證據
  4. （D）個別項目聲明之重大不實表達風險較高時，查核人員應規劃採用較少之內部稽核工作，並直接執行較多之工作

答案：（A）

詳解與考點

正解：採用內部稽核人員工作之前須先評估其客觀性與專業能力；僅因受查者設有內部稽核職能即逕行採用，A 過於絕對，故錯誤。

B：內部稽核職能專業能力較不足時，應規劃採用較少內部稽核工作並直接執行較多工作，正確。

C：查核人員應就查核目的，對所採用內部稽核工作是否適當取得足夠及適切證據，正確。

D：個別項目聲明的重大不實表達風險較高時，應採用較少內部稽核工作並直接執行較多工作，正確。

本題考點：採用內部稽核工作——先評估內部稽核職能的客觀性及專業能力；能力不足或重大不實表達風險較高時，增加查核人員直接執行的工作。

第 19 題

查核人員對於下列何項資產之續後衡量，最可能須執行額外的查核程序？
  1. （A）受查者使用直線法提列機器設備之折舊
  2. （B）受查者之不動產、廠房及設備採用重估價模式
  3. （C）受查者將$5,000 以內之支出均列為當期費用，不予資本化
  4. （D）受查者購買上市公司股票作為投資之有價證券

答案：（B）

詳解與考點

正解：續後衡量的估計不確定性與證據力；不動產、廠房及設備採重估價模式須以公允價值衡量，常涉及評價假設與專家工作，最可能需要額外查核程序，故 B 正確。

A：機器設備採直線法提列折舊，計算通常可依成本、耐用年限及殘值驗證，較少需要額外程序，錯誤。

C：將$5,000以內支出列為當期費用，是資本化門檻的會計政策運用，通常不如重估價涉及複雜評價，錯誤。

D：上市公司股票雖以公允價值衡量，但有公開報價可供驗證，估計複雜度通常低於不動產、廠房及設備重估價，錯誤。它看起來對，是因為兩者都涉及公允價值，差別在公開報價的證據力。

本題考點：續後衡量查核——公允價值若依重估價、重大假設或專家評價決定，須增加估計與證據程序；有活絡市場公開報價者，通常較易取得可靠證據。

第 20 題

查核人員採用查核人員專家或管理階層專家之工作時，下列敘述何者錯誤？
  1. （A）查核人員專家是指查核人員聘僱或委任具有會計或審計領域以外專門知識之個人或組織
  2. （B）查核人員如擬採用管理階層專家工作，應評估該專家工作的重要性、專業能力、適任能力、客觀性及工作適切性
  3. （C）查核人員應就查核目的評估查核人員專家工作之適當性，包含專家工作涉及重大假設及方法之攸關性與合理性
  4. （D）會計師不得於所有類型之查核報告中，提及查核人員專家之工作

答案：（D）

詳解與考點

正解：查核報告提及查核人員專家的限制；非無保留意見且專家工作攸關時，查核報告得提及該專家工作，D 稱所有類型報告均不得提及，過於絕對，故錯誤。

A：查核人員專家是查核人員聘僱或委任、具會計或審計領域以外專門知識的個人或組織，正確。

B：擬採用管理階層專家工作時，應評估其工作的重要性、專業能力、適任能力、客觀性及工作適切性，正確。

C：應就查核目的評估查核人員專家工作是否適當，包括重大假設及方法的攸關性與合理性，正確。

本題考點：專家工作——查核人員專家提供會計或審計以外的專門知識；採用管理階層或查核人員專家工作時，應評估能力、客觀性及方法與假設的適切性；查核報告是否提及專家應依意見類型與工作攸關性判斷。

第 21 題

採用外部函證程序時，可能執行替代查核程序的相關敘述，下列何者錯誤？
  1. （A）未回函時，替代查核程序之性質與範圍受須確認之科目及聲明所影響
  2. （B）應收帳款函證未回函時，可能執行之替代查核程序為：查核期後收款、送貨單及接近期末之銷貨
  3. （C）應付帳款函證未回函時，可能執行之替代查核程序為：查核期後付款或與供應商之往來函件及其他紀錄
  4. （D）應收帳款回函不符時，即應要求執行替代查核程序，以取得攸關且可靠之查核證據

答案：（D）

詳解與考點

正解：題幹關鍵在「回函不符」而非「未回函」；替代查核程序是未收到外部函證回函時，為取得攸關且可靠證據所採取的程序。D 把回函不符直接等同未回函，故為錯誤敘述。

A：未回函時，替代程序的性質與範圍確受欲確認科目及相關聲明影響，例如存在、完整性或評價。

B：應收帳款函證未回函時，可查核期後收款、送貨單及接近期末之銷貨，以取得應收帳款存在及相關交易的證據。

C：應付帳款函證未回函時，可查核期後付款、與供應商之往來函件及其他紀錄，以查核負債的完整性。它看起來容易被排除，是因為應收與應付帳款的查核方向不同；但未回函的應付帳款仍可用期後付款等替代程序。

本題考點：外部函證替代程序——僅在未回函或無法取得充分適切回函時，依科目與查核聲明設計程序；回函不符——先調查差異原因及其影響，不得逕以替代程序取代差異調查。

第 22 題

查核人員透過查詢函直接與受查者之外部法律顧問溝通，下列何者為最不可能被告知之事項？
  1. （A）有關保證之資訊
  2. （B）所知悉之訴訟與索賠
  3. （C）對訴訟與索賠結果之評估
  4. （D）對訴訟與索賠所產生財務影響（包括訴訟成本）之估計

答案：（A）

詳解與考點

正解：題幹問外部法律顧問查詢函「最不可能」告知的事項；查詢函以已知訴訟與索賠、結果評估及其財務影響為核心，A 的保證資訊通常不是法律顧問告知範圍，故 A 為正解。

B：法律顧問通常會就其所知悉的訴訟與索賠提供資訊，屬查詢函的重要內容。

C：法律顧問對訴訟與索賠結果的評估，與或有事項的衡量及揭露有關，通常可在查詢函中說明。

D：訴訟與索賠的財務影響，包括訴訟成本估計，通常也是查詢函可能涵蓋的事項。它看起來容易被選為最不可能，是因為金額估計帶有不確定性；但法律顧問仍可能就其所知事項提供評估。

本題考點：法律顧問查詢函——查核人員直接與外部法律顧問溝通，以取得訴訟、索賠、結果評估及財務影響的證據；範圍判準——事項須與法律顧問所知悉的法律風險及其財務報導影響有關。

第 23 題

執行電腦輔助查核技術（computer-assisted audit techniques, CAAT）時，下列何者可在受查者操作人員於處理真實交易時，同時以虛擬交易測試相關內部控制作業的有效性？
  1. （A）測試資料法（test data）
  2. （B）平行模擬（parallel simulation）
  3. （C）整體測試設施（integrated test facility）
  4. （D）人工智慧（artificial intelligence）中的專家系統（expert system）

答案：（C）

詳解與考點

正解：題幹的關鍵是「受查者操作人員處理真實交易時，同時以虛擬交易測試」；整體測試設施會將虛擬交易混入正常處理流程，以測試相關內部控制作業的有效性，故 C 為正解。

A：測試資料法是以虛擬資料測試受查者系統，但不以將虛擬交易與真實交易同時併行處理為必要特徵。它看起來對，是因為兩者都使用虛擬交易；差別在整體測試設施會把交易嵌入正常作業。

B：平行模擬是查核人員另行撰寫程式重跑資料，再與受查者系統的結果比對，並非在受查者處理真實交易時混入虛擬交易。

D：專家系統是人工智慧的應用，可協助推論或決策，並非此種內部控制測試技術。

本題考點：電腦輔助查核技術——整體測試設施將虛擬交易置入正常處理流程，以測試控制有效性；測試資料法——以設計資料測試系統處理；平行模擬——由查核人員獨立重算並比對結果。

第 24 題

下列何者非屬查核報告中納入強調事項段之事項？
  1. （A）受查客戶於合併財務報表之查核報告日已出具個體財務報表之查核報告
  2. （B）於財務報導日前發生之重大火災事項
  3. （C）呆滯存貨評估之說明
  4. （D）於查核報告日前判決確定之重大訴訟事項

答案：（A）

詳解與考點

正解：題幹問「非屬」強調事項段的事項；強調事項段以財務報表已適當表達或揭露、但對使用者理解財務報導極為重要的事項為前提，且不影響查核意見。A 僅為另一份個體財務報表查核報告的出具時程，與合併財務報表已揭露的重要事項無關，故 A 為正解。

B：財務報導日前發生的重大火災，若已於財務報表適當揭露且對使用者理解重要，得列入強調事項段；此為報導日前事件，不是期後事項。

C：呆滯存貨評估涉及重大不確定性與重大判斷，若已適當揭露，得以強調事項段提醒使用者注意。

D：查核報告日前判決確定的重大訴訟，若影響財務報表且已適當揭露，得列入強調事項段。它看起來像應導致意見修正，是因為訴訟重大；但在已適當表達或揭露的前提下，可用強調事項段提示而不影響意見。

本題考點：強調事項段——限於財務報表已適當表達或揭露且對使用者理解極重要的事項；判斷步驟——先確認事項與受查財務報表相關，再確認已適當揭露及不影響查核意見。

第 25 題

下列有關作業審計之敘述，何者正確？
  1. （A）作業審計報告必須提供外部人士（如股東、債權人）作為決策參考
  2. （B）作業審計所蒐集之證據，應作成工作底稿，以佐證其結論或建議
  3. （C）作業審計涉及企業營運之評估，只能交由內部稽核部門執行，不宜委託外界專家
  4. （D）內部稽核人員依專業判斷決定作業審計的目標，並進而規劃及執行作業審計工作

答案：（B）

詳解與考點

正解：題幹問作業審計的正確敘述；作業審計所蒐集的證據應作成工作底稿，以佐證結論或建議，故 B 為正解。

A：作業審計報告主要供管理階層或委託者改善營運使用，不必提供外部股東、債權人作為決策參考。

C：作業審計雖涉及企業營運評估，仍可委託外界專家協助，並非只能由內部稽核部門執行。

D：作業審計的目標通常由委託者或管理階層設定，內部稽核人員再依目標規劃及執行；不得把目標決定權與執行專業判斷混為一談。它看起來對，是因為內部稽核人員確會規劃工作，但其規劃須以既定目標為基礎。

本題考點：作業審計——評估營運的經濟性、效率性及效果性，報告主要供內部改善使用；工作底稿——記錄所蒐集證據並支持結論或建議；權責判準——委託者設定目標，執行者據以規劃查核。
