第 1 題

有關Erikson提出的發展理論基礎，下列敘述何者錯誤？
  1. （A）來自於Erikson自身的精神分析背景所形成的發展理論
  2. （B）提出認同危機（identification crisis）的概念
  3. （C）認為嬰兒最早的危機，在於主動性與羞愧的對應發展
  4. （D）此發展理論也成為人格心理學理論的重要基礎

答案：（C）

詳解與考點

考點為Erikson心理社會發展理論。正解C錯誤：嬰兒最早的危機是「信任對不信任」，而非「主動性對羞愧」；主動性對罪惡感屬學齡前期，自主對羞愧屬幼兒期。其餘精神分析背景、認同危機概念、作為人格心理學基礎皆為正確敘述。

第 2 題

下列何者為Rogers對治療的基本主張？
  1. （A）掌握與個案間對話、診斷的主控權
  2. （B）信任個案改變行為的動機與努力
  3. （C）避免移情（transference）現象的發生
  4. （D）鼓勵移情的發展

答案：（B）

詳解與考點

考點為Rogers個人中心治療的基本主張。正解B正確：Rogers信任個案自我實現的傾向，相信其改變的動機與努力。陷阱在A，掌握對話與診斷主控權與個人中心的非指導精神相反；C、D對移情的處理屬精神分析觀點，非Rogers的核心主張。

第 3 題

在進行嬰幼兒認知行為衡鑑時，當測驗者呈現給受試者一個蘋果的圖案，然後翻下一頁，裡頭有蘋果、香蕉與鳳梨，希望受試者指出或說出剛剛所看到的蘋果，這是以何種作業進行嬰幼兒的認知能力評估？
  1. （A）配對
  2. （B）再認
  3. （C）回憶
  4. （D）再建構

答案：（B）

詳解與考點

考點為記憶與認知衡鑑的作業類型。正解B再認（recognition）：在多個選項中指認先前看過的刺激（蘋果），屬再認作業。陷阱在C回憶（recall），回憶需在無提示下主動提取，而本題有選項可供辨識，故為再認而非回憶。

第 4 題

有關Bowlby對於依附的看法，下列何者對於嬰兒建立安全依附行為（secure attachment）或不安全依附行為（insecure attachment）具有決定性的影響力？
  1. （A）手足關係
  2. （B）主要照顧者
  3. （C）家中所有成員一樣重要
  4. （D）嬰兒自身的氣質與性格

答案：（B）

詳解與考點

考點為 Bowlby 依附理論。安全或不安全依附的形成，關鍵在嬰兒與「主要照顧者」互動中能否得到敏感、一致的回應，故選 B。陷阱在 D「嬰兒氣質」：氣質會影響互動品質，但 Bowlby 強調照顧者的回應性才具決定性，氣質非主因。

第 6 題

根據維高斯基（Vygotsky）的認知發展觀點，下列敘述何者最正確？
  1. （A）不同的文化系統會提供發展中的兒童完全相同的智能適應工具（tools of intellectual adaptation）來提升基本的心智能力
  2. （B）成年人或是專家的介入協助經常會提高學習壓力，無助於提升兒童對問題的瞭解及解決問題的能力
  3. （C）在引導式參與（guided participation）的過程中，兒童可以與一同參與活動的成人或其他能力較高的同伴互動而形塑認知的發展
  4. （D）學齡後的兒童才會表現出使用私我語言（private speech）的方法調整自己的行為

答案：（C）

詳解與考點

考點為 Vygotsky 社會建構觀。透過引導式參與，兒童與成人或能力較高同伴互動而形塑認知發展，符合鷹架與近側發展區概念，故選 C。陷阱在 A：文化提供的是「不同」而非「完全相同」的智能工具，敘述與 Vygotsky 文化中介論相反。

第 7 題

小婷與哥哥不斷大聲爭吵，媽媽先是厲聲叫他們停止，兩人只好小聲地吵，但媽媽認為他們沒有真的聽話，所以就口頭威脅他們再吵就把兩個人都抓起來揍，兩人這時便不再以口頭爭吵，轉而破壞對方的物品。根據Patterson的高壓強制環境理論（coercive home environment），接著媽媽做出下列何種後續行為，最可能會增強小婷與哥哥的攻擊行為？
  1. （A）對兩人好言相勸
  2. （B）隔離兩人，並進行暫停法（time-out）的懲罰
  3. （C）離開現場，讓兩人自行解決衝突
  4. （D）帶他們一起去看電影、吃館子培養快樂的手足互動經驗

答案：（C）

詳解與考點

考點為 Patterson 高壓強制環境理論，攻擊行為因負增強而被維持。媽媽「離開現場讓兩人自行解決」等於撤除壓力、讓攻擊得逞，反而增強攻擊，故選 C。陷阱在 B 暫停法：那是削弱攻擊的有效懲罰，方向相反。

第 8 題

星期天，陳雄想去騎腳踏車，他打電話給王威，王威說他不想去。陳雄認為「王威不再是我的朋友，因為我要他去騎腳踏車的時候，他不跟我去」。此情形在Selman理論的友誼階段中，是屬於下列那個階段？
  1. （A）階段0：短暫的玩伴
  2. （B）階段1：單向的協助
  3. （C）階段2：雙向的同享樂，但不共患難之合作
  4. （D）階段3：親密，互相分享的關係

答案：（B）

詳解與考點

考點為 Selman 友誼發展階段。以「他不照我意思做就不是朋友」這種單方、工具性、以自我需求為準的觀點，屬階段 1 單向協助，故選 B。陷阱在階段 2：雙向合作須有互惠考量，本例只看自己利益，尚未達雙向。

第 9 題

陳老師在教導國中生學會新的知識和技能時，會在學生已經具備的能力上，再加深和加廣，透過協助學生學習以引導學生發展，陳老師是依據那一個認知發展理論？
  1. （A）Piaget的認知發展論
  2. （B）Vygotsky的社會建構論
  3. （C）David Elkind自我中心主義
  4. （D）Sternberg智力三元論

答案：（B）

詳解與考點

考點為認知發展理論的辨識。在學生既有能力上加深加廣、透過協助引導發展，正是 Vygotsky 近側發展區與鷹架概念，故選 B。陷阱在 A Piaget：其強調兒童自我建構與階段成熟，較少強調他人協助引導的角色。

第 10 題

當國一的小華說：「我的同學常常交頭接耳，他們都在偷偷的評論我，讓我壓力很大」，此為David Elkind所提出的自我中心思考（egocentric thought），根據Newman和Newman（1999）所提出的協助青少年發展形象思考的途徑，助人者要改變小華想法，可以如何做？
  1. （A）請小華找出同學在評論他的證據
  2. （B）跟小華說：「他們說的可能不是你，而是別人」
  3. （C）鼓勵小華與這些同學建立關係，以了解自己和同學想法的不同
  4. （D）請小華不要太在意別人的看法，只要關注在自己的優點

答案：（C）

詳解與考點

考點為Elkind青少年自我中心之「想像觀眾」現象。依Newman提出的路徑，助人者協助青少年發展形式運思、去中心化，宜鼓勵與他人實際互動、比對彼此想法，故選C建立關係了解差異。陷阱在A找證據易淪為辯駁，B直接否認、D壓抑感受，皆未觸及自我中心的認知發展本質。

第 11 題

十五歲的志偉與三十五歲的俊賢參與了某項與情緒有關的研究，在看引發恐懼情緒的刺激時，藉由功能性核磁共振顯影（fMRI）對照兩人的大腦活動情況，通常會發現俊賢在那個大腦區域的相對活動量會比志偉高？
  1. （A）前額葉
  2. （B）枕葉
  3. （C）顳葉
  4. （D）杏仁核

答案：（A）

詳解與考點

考點為情緒調節的大腦發展。前額葉負責理性控制與情緒抑制，成熟較晚，35 歲成人比 15 歲青少年發展完整，面對恐懼刺激時前額葉相對活動量較高，故選 A。陷阱在 D 杏仁核：青少年杏仁核反應反而較強，方向相反。

第 12 題

在子女離家的空巢期，關於父母與孩子關係的敘述，下列何者正確？
  1. （A）父親比母親對與孩子未來關係的成長有更多正向的感覺
  2. （B）父母鼓勵孩子依賴會讓親子關係更好
  3. （C）親子變得更對等，關係更好
  4. （D）親子的關係變得更緊張

答案：（C）

詳解與考點

考點為空巢期親子關係發展。研究顯示子女離家後親子趨於對等、衝突減少、關係改善，故選 C。陷阱在 D「關係變緊張」：與多數實證相反；早期空巢症候群觀點已被修正，多數父母適應良好。

第 13 題

薛耶（Schaie）所發現的降低老年人認知衰退風險之變項，下列何者不包含在內？
  1. （A）擁有高認知狀態的伴侶
  2. （B）在朋友眼中是個固守原則有所堅持的人
  3. （C）在青壯年的歲月中努力改善居家環境成為自己所喜愛的狀態
  4. （D）在進入老年期前沒有心血管疾病和其他慢性病

答案：（B）

詳解與考點

考點為 Schaie 老年認知衰退的保護因子，包括高認知伴侶、改善生活環境、無慢性病等。選 B「固守原則有所堅持」非保護因子，反而彈性、開放的人格才有助維持認知，故選 B 為不包含者。把握度標 low，屬冷僻細節。

第 14 題

信任是影響親密關係的重要元素，下列敘述何者有助於增進伴侶間的信任？
  1. （A）先生表示接受了公司升遷以及後續的超長且不固定工時的要求，期待太太能請求工作調動，以兼顧家庭與經濟
  2. （B）太太非常不滿意先生將家事認定為太太的職責，看見先生主動做家事感到懷疑且不斷對先生質疑
  3. （C）太太為了公司同事間的流言蜚語感到心煩，先生理性說明八卦文化的正常性，希望太太無須介意
  4. （D）先生於伴侶爭執過程表示自己快要失控，指出自己近日順應太太要求的行為，並要求暫停爭論，之後再議

答案：（D）

詳解與考點

考點為親密關係中信任的建立。D 中先生坦承情緒、指出自己近日的配合、提議暫停爭論，展現自我揭露與責任承擔，有助建立信任，故選 D。陷阱在 B：對伴侶善意行為持續質疑會侵蝕信任，方向相反。

第 15 題

關於年長者喪偶與對婚姻關係的評估，下列敘述何者正確？
  1. （A）傷慟的寡婦和鰥夫對婚姻的評估相較於未喪偶者較負面
  2. （B）傷慟的寡婦和鰥夫愈憂鬱，對婚姻的評價愈負面
  3. （C）年長寡婦傾向將過世的丈夫神聖化
  4. （D）婚姻關係愈差，傷慟的配偶愈思念過世的配偶

答案：（C）

詳解與考點

考點為年長者喪偶與婚姻評估。研究顯示喪偶年長者傾向將過世配偶理想化、神聖化，故選 C。陷阱在 D：婚姻關係愈差愈思念，與實證相反；通常關係佳者思念較深，喪偶評估也較正向。

第 16 題

何爺爺雖然已經80歲，但是身體健康非常良好，體適能表現跟60歲的人一樣。因此，60歲代表何爺爺的那一種年齡？
  1. （A）生理年齡（chronological age）
  2. （B）機能年齡（functional age）
  3. （C）器官年齡（organic age）
  4. （D）健康年齡（health age）

答案：（B）

詳解與考點

考點為老化的年齡概念。體能表現如同 60 歲反映的是身體機能水準，屬「機能年齡」，故選 B。陷阱在 A 生理年齡：那是依出生算的實際歲數（80 歲），與功能表現無關，易混淆 chronological 與 functional。

第 17 題

人格心理學家將研究中可用到的資料分為LOTS四類，其中「O」代表下列何者？
  1. （A）個體對自我表現的結果預期（outcome expectation）
  2. （B）個體對自我的客觀認識（objective knowledge）
  3. （C）以開放式問卷（open-ended questionnaire）蒐集個體性格特徵
  4. （D）周遭父母、師長及朋友對個體的觀察（observation data）

答案：（D）

詳解與考點

考點為人格研究的 LOTS 資料分類。O 代表 observer data，即周遭父母、師長、朋友對個體的觀察，故選 D。陷阱在 B objective knowledge：LOTS 的 O 非客觀認識，而是觀察者資料；T 才是測驗、S 為自陳。

第 18 題

關於心理分析論及認知論針對潛意識的觀點比較，下列敘述何者正確？
  1. （A）心理分析論強調符合邏輯與理性的潛意識歷程
  2. （B）心理分析論強調潛意識內容中的動機與慾望；認知論強調潛意識內容中的思考
  3. （C）心理分析論注意潛意識運作的非動機面向；認知論強調潛意識運作的動機面向
  4. （D）認知論強調意識與潛意識歷程間的基礎差異

答案：（B）

詳解與考點

考點為心理分析論與認知論對潛意識的比較。精神分析強調潛意識中的動機與慾望（驅力），認知論強調潛意識的訊息處理與思考，故選 B。陷阱在 A：精神分析的潛意識是非邏輯、原始歷程，與「符合邏輯理性」相反。

第 19 題

在Freud的理論當中，人格中完全的無意識、非理性的部分，同時尋求生理需求與驅力的立即性的滿足，被享樂原則所操控的人格結構稱之為下列何者？
  1. （A）生之本能（libido）
  2. （B）自我（ego）
  3. （C）本我（id）
  4. （D）超我（superego）

答案：（C）

詳解與考點

考點為 Freud 人格結構。完全無意識、非理性、受享樂原則支配、追求驅力立即滿足者為「本我（id）」，故選 C。陷阱在 D 超我：超我代表道德良知，B 自我依現實原則運作，皆與享樂原則無關。

第 20 題

有一個小孩子的寵物狗死了，他卻表現的好像這隻狗還活著一樣。根據心理分析理論，這是什麼心理防衛機轉？
  1. （A）否認
  2. （B）昇華
  3. （C）投射
  4. （D）合理化

答案：（A）

詳解與考點

考點為心理分析防衛機轉。表現得像狗還活著，是拒絕承認令人痛苦的現實，屬「否認」，故選 A。陷阱在 D 合理化：合理化是為行為找藉口解釋，本例並非找理由，而是直接不接受事實，故非合理化。

第 21 題

Erikson較常使用的心理衡鑑技術為下列何者？
  1. （A）投射測驗（projective test）
  2. （B）角色建構測驗（role construct repertory test）
  3. （C）心理史分析（psychohistorical analysis）
  4. （D）Q分類法（Q-sort technique）

答案：（C）

詳解與考點

考點為理論家與其衡鑑方法的配對。Erikson 重視個體心理社會發展與生命歷程，常用「心理史分析」研究歷史人物的生命，故選 C。陷阱在 A 投射測驗：那較屬精神分析臨床評估，非 Erikson 的代表方法。

第 22 題

小孩本來不會怕蟑螂，但是看見母親碰到蟑螂時，總是驚聲尖叫，後來這個小孩看到蟑螂也會產生害怕的感覺，最可能是下列何種反應？
  1. （A）刺激的區辨反應
  2. （B）自動化反射反應
  3. （C）刺激的類化反應
  4. （D）制約化情緒反應

答案：（D）

詳解與考點

考點為情緒的習得歷程。小孩透過觀察母親見蟑螂尖叫而習得恐懼，官方答案為D制約化情緒反應，視母親尖叫為非制約刺激、蟑螂與恐懼連結成制約反應。陷阱在C類化指對相似刺激的反應擴散，與本題新習得恐懼不符；A區辨、B反射亦不切題。

第 23 題

當學生上課講話時，教師就不斷嘮叨，學生為了耳根清淨，上課就保持安靜。教師的嘮叨對學生上課保持安靜而言，是行為學派所主張的那一種原則？
  1. （A）正增強
  2. （B）負增強
  3. （C）正懲罰
  4. （D）負懲罰

答案：（B）

詳解與考點

考點為操作制約四象限。教師嘮叨是嫌惡刺激，學生安靜後嘮叨「移除」，因而增加安靜行為，屬負增強，故選 B。陷阱在 C 正懲罰：懲罰目的在減少行為，本例是增加安靜行為，方向相反，且為移除而非施加。

第 24 題

關於A型－B型性格（type A-type B personality）與健康的關聯之敘述，下列何者錯誤？
  1. （A）A型性格者在挫折時較容易產生敵意與憤怒
  2. （B）早期研究顯示A型人格是心臟病的良好預測指標
  3. （C）實驗室研究顯示，B型人格者在成就作業的表現勝於A型人格者
  4. （D）根據研究，B型性格的高中生較少參與課外活動

答案：（C）

詳解與考點

考點為 A 型／B 型性格與健康。題目找錯誤敘述。C 稱 B 型成就表現勝於 A 型有誤，實驗多顯示 A 型在成就作業較積極，故選 C。陷阱在 B：早期研究確曾把 A 型當心臟病預測指標，敘述正確，非答案。

第 25 題

相較於英裔美國兒童，亞裔美國兒童在下列何種狀況下，會引發出較大的內在動機？
  1. （A）由權威對象或同儕決定
  2. （B）由自己決定
  3. （C）依照外在酬賞而定
  4. （D）非競爭性情境

答案：（A）

詳解與考點

考點為文化差異與內在動機。研究顯示亞裔兒童在由權威或信任的同儕為其選擇時，內在動機反而較高（重視關係與和諧），故選 A。陷阱在 B 自己決定：那是西方個人主義文化提升動機的條件，英裔兒童才適用。

第 26 題

下列何者可以讓我們很快地解釋複雜刺激的心智結構？
  1. （A）標準（standards）
  2. （B）特質（traits）
  3. （C）基模（schemas）
  4. （D）期待（expectancies）

答案：（C）

詳解與考點

考點為社會認知的心智結構。能快速解釋、組織複雜刺激的認知框架是「基模（schemas）」，故選 C。陷阱在 D 期待：期待是對未來事件的預測，B 特質描述穩定傾向，皆非用以快速理解複雜刺激的組織結構。

第 27 題

關於「公平世界信念（belief in a just world）」的敘述，下列何者錯誤？
  1. （A）公平世界信念是一種防衛歸因（defensive attributions）
  2. （B）公平世界信念可使我們感到安心
  3. （C）社會財富分布愈平均，人們愈相信公平世界信念
  4. （D）公平世界信念有助於人們認為生活是規律而可預測的

答案：（C）

詳解與考點

考點為公平世界信念。題目找錯誤者。C 稱財富分布愈平均愈相信公平世界，並無此實證關係，故選 C 為錯誤。陷阱在 A：公平世界信念確屬防衛性歸因、可帶來安心與可預測感，A、B、D 皆為正確敘述。

第 28 題

根據跨文化研究顯示，下列何者不屬於人類的基本臉部表情？
  1. （A）厭惡
  2. （B）快樂
  3. （C）悲傷
  4. （D）困惑

答案：（D）

詳解與考點

考點為基本情緒臉部表情的跨文化普遍性。Ekman 六種基本表情為快樂、悲傷、憤怒、厭惡、恐懼、驚訝，「困惑」不在其中，故選 D。陷阱在 A 厭惡：厭惡屬六種基本表情之一，為正確項，非答案。

第 29 題

當我們討論過大學生不夠用功的話題後，馬上聽到其他同學熱烈地參加校外聯誼活動，因而對這些同學產生負向評價，這是受到基模的什麼特徵所導致？
  1. （A）重要性作用
  2. （B）提示作用
  3. （C）初始性作用
  4. （D）接近性作用

答案：（B）

詳解與考點

考點為基模的可及性（priming）。先談用功話題後，立即影響對其後同學行為的負向評價，是前面情境「促發」相關基模所致，故選 B 提示作用。陷阱在 C 初始性：初始效應指最先接收訊息影響較大，與此情境的促發機制不同。

第 30 題

小明問小華是否喜歡某位藝人的歌，小華一時無法確定自己的態度，想了想，發現自己最近有幾次曾主動播放這位藝人的歌來聽，於是回答「喜歡」。下列那一個理論最能詮釋小華對於自己態度的認識？
  1. （A）古典制約理論（classical conditioning）
  2. （B）自我知覺理論（self-perception theory）
  3. （C）自我覺察理論（self-awareness theory）
  4. （D）認知失調理論（cognitive dissonance theory）

答案：（B）

詳解與考點

考點為態度形成的自我知覺理論。態度不明時，個體藉觀察自己的行為（多次主動播放）來推論自己的態度，故選 B。陷阱在 D 認知失調：失調須先有兩相衝突的認知產生不適，本例無衝突，只是由行為推態度，故非失調。

第 31 題

上課時，余老師滔滔不絕的講課，但底下學生睡成一片。下課後，張同學上前跟余老師說：「老師你上得真好，我好喜歡聽你講課。」假如張同學這段話並非出自其內心真正的感受，他最可能是試圖要使用那一種自我呈現策略？
  1. （A）逢迎（ingratiation）
  2. （B）懇求（supplication）
  3. （C）典範化（exemplication）
  4. （D）自我推銷（self-promotion）

答案：（A）

詳解與考點

考點為自我呈現策略。藉恭維、討好他人以贏得好感屬「逢迎（ingratiation）」，故選 A。陷阱在 D 自我推銷：自我推銷是強調自己能力使人覺得有才幹，本例是稱讚對方而非推銷自己，方向不同。

第 32 題

根據Margaret Clark與Judson Mills（1993）的理論，共享關係（communal relationships）中人們會關心並回應對方的需求。關於共享關係的敘述，下列何者錯誤？
  1. （A）會隨時記錄雙方在關係中的貢獻
  2. （B）異性戀和同性戀在關係中的承諾和共享程度相同
  3. （C）在共享關係裡，伴侶對於在任何時刻達成公平的基礎較為寬鬆
  4. （D）共享關係多發生於親密朋友、家人和浪漫伴侶之間

答案：（A）

詳解與考點

考點為 Clark 與 Mills 的共享關係與交換關係之別。題目找錯誤。A「隨時記錄雙方貢獻」是交換關係特徵，共享關係不計較得失，故選 A 為錯誤。陷阱在 C：共享關係對即時公平較寬鬆，敘述正確，非答案。

第 33 題

根據學者對於依附風格（attachment styles）的研究，下列敘述何者錯誤？
  1. （A）人們對人際關係的期待，基礎在於嬰兒時期與主要照顧者建立的關係
  2. （B）屬於焦慮╱矛盾依附風格的人，其親密關係最短命
  3. （C）人們表現出的依附風格會受情境影響，面對不同對象會展現出不同依附風格
  4. （D）依附風格是一致且穩定的，不會受到經驗學習而有所影響

答案：（D）

詳解與考點

考點為依附風格研究。題目找錯誤。D 稱依附風格穩定不受經驗影響有誤，依附可因新關係經驗而改變，故選 D。陷阱在 C：依附風格確會因情境與不同對象而有差異，是正確敘述，與 D 互為對照。

第 34 題

假設現在你與一位陌生人兩人一組，連續進行了兩場討論式互動，在這兩次討論後的休息時間，你都在無意間聽到了對方對你的評價。根據Aronson和Linder所提出的得失理論（gain-loss theory），那一種情況出現時，你會最不喜歡對方？
  1. （A）對方兩次都給你負向評價
  2. （B）對方兩次都給你正向評價
  3. （C）對方第一次給你負向評價，第二次給你正向評價
  4. （D）對方第一次給你正向評價，第二次給你負向評價

答案：（D）

詳解與考點

考點為 Aronson 與 Linder 得失理論。評價由正轉負（先好後壞）造成的失落感最強，使人最不喜歡對方，故選 D。陷阱在 A 兩次都負向：雖始終負向，但無落差衝擊，依得失理論不如「由正轉負」令人厭惡。

第 35 題

社會心理學家採取各種取向讓人們對環境有更負責的行為，其中一種取向是提醒人們社會規範的存在。關於社會規範的研究之敘述，下列何者正確？
  1. （A）看見別人撿起紙袋是提醒描述性規範，可降低人們亂丟垃圾的比例
  2. （B）清理環境中所有的垃圾，是強制性規範的最佳方式
  3. （C）相較於一塵不染的環境，留下一小件垃圾的方式更能發揮描述性規範的提醒作用
  4. （D）在維護環境整潔方面，顯示單一違反強制性規範的效果最好

答案：（C）

詳解與考點

考點為描述性規範與環境行為。研究顯示在大致乾淨但留一小件垃圾的環境，最能凸顯多數人不亂丟的描述性規範，提醒效果最強，故選 C。陷阱在 A：看到別人撿垃圾屬突顯規範，但留一小件垃圾的對比設計效果更佳。

第 36 題

下列何種方法對於減少暴力行為最沒有效果？
  1. （A）宣洩
  2. （B）看到攻擊者受到懲罰
  3. （C）獎勵非暴力行為
  4. （D）明確指出攻擊不恰當

答案：（A）

詳解與考點

考點為減少攻擊行為的有效方法。宣洩（catharsis）假說已被推翻，發洩攻擊反而可能增強攻擊，最無效，故選 A。陷阱在 B 看到攻擊者受罰：替代性懲罰可抑制攻擊，屬有效方法，非答案。

第 37 題

社會助長（social facilitation）意指共同行動者或觀眾會使行為者表現提高的效果。下列關於社會助長的敘述何者正確？
  1. （A）高激發狀態會使行為表現改進，與作業的難易度無關
  2. （B）作業難度增加，會降低社會助長的效果
  3. （C）當行為者對該作業比較不熟練，會有比較明顯的社會助長效果
  4. （D）若是他人在場，會使行為表現者注意力範圍擴大，因此產生社會助長效果

答案：（B）

詳解與考點

考點為社會助長理論。他人在場提高激發，對簡單／熟練作業表現提升，對困難作業則表現下降，故選 B「作業難度增加會降低社會助長」正確。陷阱在 A：稱與難易度無關有誤，難易度正是調節社會助長與抑制的關鍵。

第 38 題

關於性別刻板印象的敘述，下列何者錯誤？
  1. （A）性別刻板印象通常誇大兩性差異，也看到相同性別之人格特質的個別差異
  2. （B）對女性抱持負面的刻板印象，認為女性天生比較不聰明、不懂數學和科學等，稱為敵意性別刻板印象
  3. （C）慈善性別刻板印象雖然充滿溫情，其實是父權化態度
  4. （D）對女性抱持正面的刻板印象，認為女性比男性更友善、更有同情心等，稱為慈善性別刻板印象

答案：（A）

詳解與考點

考點為性別刻板印象。題目找錯誤。A 把「縮小個別差異」說反，刻板印象是誇大兩性差異並忽略同性別內差異，故選 A。陷阱在 C：慈善型刻板印象表面溫情、實為父權態度，敘述正確，非答案。

第 39 題

當我們希望降低在牆壁上塗鴉的行為，以維持環境的整齊，若告示牌上寫「絕對禁止在牆上寫字」會比「請不要在牆上寫字」出現更多塗鴉的原因為何？
  1. （A）抗拒理論（reactance theroy）
  2. （B）免疫理論（inoculation theory）
  3. （C）不可更改的承諾（unchangable commitment）
  4. （D）認知失調理論（cognitive dissonance theory）

答案：（A）

詳解與考點

考點為心理抗拒理論（reactance）。強硬命令（絕對禁止）威脅自由感，引發逆反而增加違規行為，故選 A。陷阱在 D 認知失調：失調涉及行為與態度不一致的內在不適，本例是對禁令的自由反彈，機制不同。

第 40 題

如何「稱讚」才能對兒童產生長久的正面影響？
  1. （A）不管兒童做什麼，都要大力稱讚
  2. （B）在競爭後獲得勝利時，更要大力稱讚，讓競爭變成習慣
  3. （C）要針對兒童的能力稱讚，讓他對自己的能力產生信心
  4. （D）特別要針對其努力來稱讚，這樣兒童即使失敗，才會繼續努力

答案：（D）

詳解與考點

考點為稱讚對成就動機的影響（Dweck 成長心態）。針對「努力」稱讚能培養成長心態，失敗時仍願堅持努力，故選 D。陷阱在 C 稱讚能力：稱讚天賦／能力易養成固定心態，遇挫折時反而退縮，與長久正面效果相反。
