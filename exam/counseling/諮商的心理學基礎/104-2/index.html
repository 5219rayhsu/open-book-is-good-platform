第 3 題

在語言發展研究中，下列那一項證據支持先天論者（nativist）的觀點？
  1. （A）失語症成人經過治療後可以完全恢復原有的語言功能
  2. （B）早期學會第二語言的雙語者，說兩種語言所活化的是腦部的不同區域
  3. （C）一起生活的聽障幼兒會創造出他們自己的手語
  4. （D）聽障兒童無法發展出咕咕聲（cooing）及咿呀聲（babbling）

答案：（C）

詳解與考點

正解：先天論者（nativist，如 Chomsky）主張人類天生具有語言習得的內在機制，即使缺乏完整而結構化的語言輸入，語言能力仍會自發浮現。研究發現，一群共同生活但缺乏正式手語教學的聽障幼兒，會自行發展出屬於他們自己、具有一定語法結構的手語系統，這說明語言的浮現並非單純仰賴外在教導與模仿，而是內建的能力驅動其自發創造，最能支持先天論的觀點，故選 C。

A：失語症成人經治療後恢復語言功能，反映的是大腦受損後語言功能的可塑性與復健成效，屬於神經復健與腦傷後功能重組的議題，並未直接說明語言本身是否為先天內建的能力。

B：雙語者使用兩種語言時活化不同腦區，反映的是語言習得時機對大腦語言表徵組織方式的影響，屬於語言習得時程與腦部功能分化的議題，與語言能力是否先天存在的核心爭議關聯較間接。

D：若聽障兒童因缺乏聽覺輸入而無法發展出咕咕聲及咿呀學語，反而說明語言前期發聲高度仰賴外在聽覺回饋才能出現，這樣的敘述傾向支持環境與輸入決定語言發展的經驗論觀點，也與實徵上聽障嬰兒仍會出現手部咿呀學語的發現不符，並不能作為支持先天論的證據。

本題考點：語言發展先天論（nativism，Chomsky 語言習得裝置）——語言能力被視為內建於人腦、可在輸入不完整下自發浮現；聽障幼兒自創手語——支持先天語言能力存在的經典證據。

第 7 題

關於組成語言要素的描述，下列何者正確？
  1. （A）包含語音（phonology）、語法（syntax）、語用（pragmatics）與語言獲得（language acquisition）
  2. （B）包含語音（phonology）、語意（semantics）、語用（pragmatics）與語言獲得（language acquisition）
  3. （C）包含語意（semantics）、語法（syntax）、語用（pragmatics）與語言獲得（language acquisition）
  4. （D）包含語音（phonology）、語法（syntax）、語用（pragmatics）與語意（semantics）

答案：（D）

詳解與考點

正解：語言學與心理語言學對語言結構要素的標準分類為：語音學（phonology，研究語音系統與規則）、語法／句法學（syntax，研究詞彙組合成合乎文法句子的規則）、語意學（semantics，研究詞語與句子的意義）、語用學（pragmatics，研究語言在情境脈絡中的實際使用），這四者共同構成語言的組成要素；「語言獲得」是語言發展的歷程而非語言本身的結構要素，不應與前述四項並列。因此正確的組合是語音、語法、語用與語意四項，故選 D。

A：以「語言獲得」取代「語意」，把語言習得的發展歷程誤植為語言的結構性組成要素，語言獲得描述的是兒童如何學會語言的歷程，並非語言本身包含的要素，因此組合錯誤。

B：同樣以「語言獲得」取代「語法」，遺漏了語法這個描述詞彙如何組合成句的核心語言要素，改以發展歷程混充結構要素，組合錯誤。

C：以「語言獲得」取代「語音」，遺漏了語音系統這個語言最基礎的聲音結構層次，同樣把發展歷程當成語言的組成要素，組合錯誤。

本題考點：語言的結構要素——語音學（phonology）、語法學（syntax）、語意學（semantics）、語用學（pragmatics）四個核心層次；語言獲得（language acquisition）——語言發展歷程，非語言本身的結構要素，兩者不應混淆。

第 14 題

一位剛接導師的新任國中老師，發現班上同學很愛照鏡子，且非常在意穿著與打扮。老師覺得這樣是不 健康的。因此特別提醒大家不應太過注重外貌。其實這位老師忽略了青少年期的下列何種現象？
  1. （A）內隱性格（implicit personality）
  2. （B）觀點取替（perspective taking）
  3. （C）個人不朽（personal fable）
  4. （D）假想觀眾（imaginary audience）

答案：（D）

詳解與考點

正解：Elkind 提出青少年自我中心（adolescent egocentrism）包含「假想觀眾」（imaginary audience）與「個人不朽（寓言）」（personal fable）兩個核心現象。假想觀眾指青少年主觀認為周遭他人時時刻刻都在關注、評價自己的一言一行與外表，因而格外在意穿著打扮與他人眼光，即使實際上並沒有人特別留意。題幹中學生「很愛照鏡子、非常在意穿著與打扮」，正是假想觀眾現象的典型表現，老師只從行為表面判斷為「不健康」，忽略了這是青少年發展階段常見且具功能性的心理現象，故選 D。

A：內隱性格是指人們對特質之間關聯性所持有的直覺性、未必準確的認知基模，用來推論他人的人格特質，與題幹中在意外貌、擔心他人眼光的現象無直接關係。

B：觀點取替是指理解並考量他人立場與想法的能力，屬於社會認知發展的一環，題幹描述的是青少年對他人如何看待「自己」的過度在意，而非對他人觀點的理解能力，兩者性質不同。

C：個人不朽是青少年自我中心的另一面向，指青少年主觀認為自己的經驗獨一無二、他人無法理解，甚至覺得自己不會受到傷害；這與題幹中在意他人如何評價自己外貌打扮的焦點不同，個人不朽談的是「獨特感與無敵感」，不是「被注視感」。

本題考點：青少年自我中心（adolescent egocentrism，Elkind）——青少年在認知發展過程中出現的自我聚焦傾向；假想觀眾（imaginary audience）——誤以為他人持續關注、評價自己外表與行為的現象；個人不朽（personal fable）——與假想觀眾並列但強調獨特性與無敵感的另一面向。

第 20 題

下列何者是 G. Allport 主張的人類動機有「功能自主（functional autonomy）」的現象？
  1. （A）動機的功能是自己決定的
  2. （B）自主就是一種動機的功能
  3. （C）人類的動機是以追求自主為主
  4. （D）早期為了消除緊張的動機，當成長後，動機就會獨立出來，並轉成自身愉悅的來源

答案：（D）

詳解與考點

正解：G. Allport 提出的功能自主（functional autonomy）主張，某個行為或動機最初可能是為了滿足某種基本需求或消除緊張（例如兒童一開始練習彈琴是為了討好父母、避免被責罰），但隨著行為不斷重複與成熟發展，這個行為逐漸脫離原本的驅力來源，轉變成個體自身就樂在其中、能獨立帶來愉悅與意義的動機（例如成年後純粹因為喜歡音樂本身而彈琴），也就是選項 D 所描述「早期為了消除緊張的動機，當成長後，動機就會獨立出來，並轉成自身愉悅的來源」，這正是功能自主「手段變目的」的核心主張，故選 D。

A：「動機的功能是自己決定的」這句話語意含糊，並未觸及功能自主真正要說明的重點——動機來源的轉變過程（從外在驅力轉為內在自足），只是把「自主」直接套在動機的定義上，未能說明機制。

B：「自主就是一種動機的功能」把功能自主的因果順序倒置，功能自主要講的是動機本身如何「變得」自主，而非把自主本身當成動機所具備的某種功能，邏輯上顛倒了主詞與述詞的關係。

C：「人類的動機是以追求自主為主」把功能自主誤讀成一種普遍的人性驅力假設，等於主張所有動機的終極目標都是自主，這已超出 Allport 原意，Allport 談的是特定行為動機如何隨發展而獨立化，並非主張人類動機整體以追求自主為核心目的。

本題考點：功能自主（functional autonomy）——G. Allport 人格理論核心概念，主張成熟行為的動機可脫離原始驅力來源而獨立存在；人格心理學中的動機發展觀——動機並非一成不變，會隨個體成熟而轉化性質。

第 21 題

Walter Mischel 的兒童延宕滿足實驗中，下列何者不是他的研究發現？
  1. （A）人能夠克服延宕滿足所產生的挫折感
  2. （B）延宕滿足所需的自我控制對學業表現有影響，但對控制酒精藥物的使用較無影響
  3. （C）學齡前能成功延宕滿足的兒童，其後來青少年時期的專注力也較高
  4. （D）能延宕滿足的兒童，在後來青少年時期學術性向測驗之語文表現較佳

答案：（B）

詳解與考點

正解：Mischel 及後續追蹤研究發現，學齡前能成功延宕滿足的兒童，到了青少年時期不只在學業表現（如學術性向測驗語文分數）上較佳，在自我控制相關的行為指標上也表現得更好，其中包括較低的物質使用（酒精、藥物）風險，也就是說延宕滿足所需的自我控制，其影響同時延伸到學業表現與物質使用控制兩個層面，而非「對控制酒精藥物使用較無影響」；B 的敘述與研究發現相反，故不是 Mischel 的研究發現，答案選 B。

A：延宕滿足實驗中的兒童在等待過程中必須忍受想立即獲得獎賞的衝動與挫折感，Mischel 的研究顯示兒童能運用各種策略（如轉移注意力）克服這種挫折感以完成等待，此為其研究發現之一，敘述正確。

C：後續追蹤發現，學齡前成功延宕滿足的兒童在青少年時期展現出較佳的專注力與應對挫折的能力，這與自我控制能力的持續發展一致，屬於 Mischel 的研究發現，敘述正確。

D：追蹤研究也發現，兒時延宕滿足能力較佳者，到青少年階段的學術性向測驗語文分數表現較優，顯示自我控制能力與學業表現之間存在正向關聯，屬於研究發現，敘述正確。

本題考點：延宕滿足（delay of gratification）——Mischel 的棉花糖實驗與自我控制概念；縱貫追蹤研究發現——幼年自我控制能力與後續學業表現、物質使用風險的長期關聯。

第 23 題

宗教家以「有信仰／無信仰」，醫師以「有病／無病」，心理師以「適應良好／適應不良」等來區分不 同的人，這種現象，可以用那個人格理論來說明？
  1. （A）Kelly 的個人構念理論
  2. （B）Cattell 的性格特質論
  3. （C）Mischel 的社會認知論
  4. （D）Sullivan 的人際取向論

答案：（A）

詳解與考點

正解：Kelly 的個人構念理論（personal construct theory）主張，每個人如同科學家一般，會發展出一套個人獨特的構念系統來解釋與預測世界，而構念的核心特性就是二分（dichotomous）——每個構念都同時包含一組相對的兩極，例如「善、惡」「聰明、愚笨」。不同角色或專業背景的人，會依其熟悉的構念向度來理解與分類他人，宗教家慣用「有信仰、無信仰」、醫師慣用「有病、無病」、心理師慣用「適應良好、適應不良」，正是同一群人以各自的二元構念系統在區分他人，完全對應 Kelly 理論中構念的二分性（dichotomy corollary），故選 A。

B：Cattell 的性格特質論以因素分析找出構成人格的根源特質（source traits），並以連續向度上的分數高低描述個人差異，強調的是特質量的多寡，而非以二元對立類別區分不同的人，與題幹所述的二分現象不合。

C：Mischel 的社會認知論強調行為的一致性會隨情境而變，著重認知與情境變項如何交互決定行為表現，關注的是跨情境行為為何不一致，並未特別論述人們用二元對立的構念來分類他人。

D：Sullivan 的人際取向論以人際關係與焦慮的互動經驗來理解人格發展，核心概念是自我系統與人際場域中的動力歷程，重點在人際互動本身，而非個人如何用二分類別去建構對他人的理解。

本題考點：Kelly 個人構念理論（personal construct theory）——人以個人化的二元構念系統理解世界；構念的二分性（dichotomy corollary）——每個構念皆具相對兩極，不同角色依熟悉向度分類他人。

Kohlberg 主要根據受試者對道德兩難情境的反應中那些特徵來決定受試者的道德成熟度？
  1. （A）對兩難情境的情緒反應
  2. （B）決定行為反應的理由
  3. （C）兩難情境中主角的行為
  4. （D）兩難情境中主角的結局

答案：（B）

詳解與考點

正解：Kohlberg判斷受試者道德發展階段的關鍵，不在於受試者對兩難情境中主角「應該怎麼做」這個表面行為選擇的對或錯，而在於受試者為這個選擇所提出的推理理由（reasoning）——例如是出於害怕懲罰、遵守規則、還是基於普遍倫理原則，這個理由的結構性質才是判斷道德成熟度所在的核心依據，故選B。

A：對兩難情境的情緒反應屬於情感層面的表現，Kohlberg的道德認知發展理論關注的是認知推理歷程，而非受試者面對情境時產生的情緒強弱或種類。

C：兩難情境中主角的行為是題目所描述的既定情節（如是否偷藥），並非受試者自己的判斷內容，道德發展階段的評定不是看故事主角做了什麼，而是看受試者如何為自己的立場說理。

本題考點：Kohlberg道德發展理論（Kohlberg's theory of moral development）——以受試者對兩難情境判斷背後的推理結構區分道德發展階段；道德推理（moral reasoning）——強調判斷的「理由」而非判斷的「結論」，是評定道德成熟度的核心依據。

第 31 題

當內在線索不明顯時，個人常會根據自己的行為推論該行為發生的原因，此一現象可以用下列何種理論 來說明？
  1. （A）認知失調論
  2. （B）自我知覺論
  3. （C）社會衝擊論
  4. （D）增強理論

答案：（B）

詳解與考點

正解：自我知覺論（self-perception theory）由Bem提出，主張當個人內在的態度、情緒等線索模糊不清或難以直接覺察時，個人會像旁觀者觀察他人一樣，藉由觀察自己外顯的行為以及行為發生的情境，回頭推論出自己當下的態度或感受是什麼；題幹所描述「當內在線索不明顯時，個人常會根據自己的行為推論該行為發生的原因」，正是自我知覺論對於態度形成歷程的核心主張，故選B。

A：認知失調論主張的是個人在同時持有兩個彼此矛盾的認知（如態度與行為不一致）時，會產生心理上的不舒服感，進而改變態度或行為以消除這種不一致，重點在處理矛盾認知帶來的緊張，而非內在線索不明顯時如何從行為推論原因，兩者觸發的情境條件不同。

C：社會衝擊論探討的是他人（如團體規模、接近性、重要性）如何對個人的態度與行為產生影響力，關注的是外在社會力量的作用歷程，與題幹描述個人如何從自身行為推論內在狀態的自我認識歷程無關。

D：增強理論強調行為的習得與維持是透過獎賞與懲罰等後果所塑造，重點在外在增強物對行為頻率的影響，並未處理個人如何在內在線索模糊時，透過觀察自己的行為來推論內在狀態的問題。

本題考點：自我知覺論（self-perception theory）——內在線索模糊時，藉由觀察自身行為推論自己的態度；與認知失調論的對比——兩者都討論態度與行為的關係，觸發條件與心理歷程不同。

第 37 題

根據心理學家研究，下列何種情況較不易被說服？
  1. （A）自尊心低落時
  2. （B）吃美食時
  3. （C）心情不好時
  4. （D）當我們的自由與自主未受到挑戰時

答案：（C）

詳解與考點

正解：說服研究（persuasion research）發現，個體的情緒狀態會影響其對說服訊息的處理方式。當人心情不好時，往往會啟動較為謹慎、系統化的訊息處理（systematic processing），對說服訊息中的論證品質、邏輯漏洞更為敏感與挑剔，因此比起心情好或情緒平穩時更不容易被輕易說服，故答案為 C。

A：自尊心低落的人對自己的判斷缺乏信心，容易懷疑自己原有的立場，因此在面對外來說服訊息時反而更容易被影響而改變態度，屬於較易被說服的情境，而非較不易。

B：吃美食等愉悅經驗與說服訊息同時出現時，正向情緒會透過類似古典制約的機制與訊息內容產生聯結，讓人在愉悅氛圍下對訊息採取較不設防、較依賴直覺捷思的態度，反而更容易被說服。

D：當個人的自由與自主未受到挑戰時，不會引發抗拒理論（reactance theory）所描述的心理抗拒反應，個體較沒有理由本能地抵制外來訊息，此時反而比自主感受到威脅時更容易被說服，並非較不易被說服的情境。

本題考點：說服的情緒與認知歷程（systematic vs. heuristic processing）——負向情緒促使人更謹慎地評估論證品質；心理抗拒理論（psychological reactance theory）——自由自主受威脅時才會引發對說服的抵制。

  2. （B）人們傾向將他人行為歸因於個人特性，而自己行為歸因於情境因素
  3. （C）人們傾向於將行為的發生歸因於情境因素高於個人特性
  4. （D）人們傾向於將行為的發生歸因於個人特性高於情境因素

答案：（D）

詳解與考點

正解：D。基本歸因謬誤（fundamental attribution error）指的是人們在解釋他人（乃至一般）行為的成因時，普遍存在一種傾向：過度強調行為者的內在特質、人格傾向等「個人因素」的影響力，而低估情境脈絡、外在限制等「情境因素」的作用，即便情境因素其實可能才是行為發生的主要原因。這是一種普遍性的歸因偏誤傾向，強調「個人特性解釋優先於情境因素」，D 正確掌握了這個定義的核心，故選 D。

A：把「他人行為歸因於情境、自己行為歸因於個人特性」描述成基本歸因謬誤，方向恰好相反，且這種自己與他人歸因不同調的現象，其實更接近另一個相關但不同的概念——行動者與觀察者偏誤（actor-observer bias），並非基本歸因謬誤的定義。

B：「他人行為歸因於個人特性、自己行為歸因於情境」這個對比同樣描述的是行動者與觀察者偏誤中「自己與他人歸因方向不同」的特定現象，而基本歸因謬誤原本的定義並不特別區分「自己」與「他人」，只強調一般而言人們解釋行為時偏重個人特質，B 把兩個相關但不同的概念混為一談。

C：基本歸因謬誤描述的方向是人們傾向「高估個人特性、低估情境因素」，C 卻主張情境因素的影響力高於個人特性，方向與定義完全相反。

本題考點：基本歸因謬誤（fundamental attribution error）——解釋行為時普遍高估個人特質、低估情境因素的傾向；行動者與觀察者偏誤（actor-observer bias）——自己與他人的歸因方向不同調的相關但不同的概念，須與基本歸因謬誤區辨。
