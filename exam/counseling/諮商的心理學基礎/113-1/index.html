第 1 題

下列那一個陳述最不符合Vygotsky的社會文化理論？
  1. （A）認知的普遍性發展現象是被確定的
  2. （B）在文化上的影響差異是被確認的
  3. （C）鷹架作用可幫助小孩完成困難的工作
  4. （D）和有經驗的指導者之合作式互動是有幫助的

答案：（A）

詳解與考點

考點為 Vygotsky 社會文化理論（選最不符者）。正解 A：強調「認知普遍性發展被確定」與 Vygotsky 重視文化脈絡、個別差異的立場相反，普遍階段論偏向 Piaget。鷹架、文化差異、與指導者合作互動皆為 Vygotsky 核心。

第 3 題

關於兒童語言發展的過程，下列何者錯誤？
  1. （A）即使是孩子在剛出生時尚無法發出不同聲音，我們可以用吸吮奶嘴的頻率了解孩子的喜好與偏惡
  2. （B）單字期的孩子以單字代替全部的語句，雖然沒有表達出完整的文法結構，但已可以開始理解簡單的文法
  3. （C）代名詞（你、我、他）的成熟使用，通常需要完整的語言文法表達後才能習得
  4. （D）多字期的過程可以看到語言表達的發展，為名詞、動詞的順序，最後會有形容詞的加入，再漸漸形成完整的語法表達

答案：（C）

詳解與考點

考點為兒童語言發展（選錯誤者）。正解 C 為錯誤：代名詞使用並不需等到完整文法表達後才習得，幼兒在語法成熟前即能使用你我他（雖易混淆）。A、B、D 描述的吸吮偏好、單字期理解、多字期詞序皆正確。

第 4 題

在Cummings等人一系列有關家庭中背景憤怒（background anger）的研究中，關於兩歲幼童對成人間口語爭吵的反應，下列敘述何者正確？
  1. （A）不論女童或男童，都會表現出害怕或退縮的反應
  2. （B）不論女童或男童，都會表現出亂打、亂踢或攻擊玩伴的反應
  3. （C）女童會表現出害怕退縮的反應，男童會表現出亂打、亂踢或攻擊玩伴的反應
  4. （D）男童會表現出害怕退縮的反應，女童會表現出亂打、亂踢或攻擊玩伴的反應

答案：（C）

詳解與考點

考點為 Cummings 背景憤怒研究中的性別差異。正解 C：女童多表現害怕退縮，男童多表現攻擊外顯（亂打亂踢）。把握度中等，屬須記憶特定研究結果的細項題，方向為女退縮、男攻擊。

第 5 題

小琪渴望參加學校校外活動，但父母不允許，也沒有商量空間，特別是父母對小琪的成績表現極度不滿意。依據Baumrind的父母教養方式，下列何者可能為小琪父母所採用的教養方式？
  1. （A）教條式
  2. （B）獨裁式
  3. （C）權威式
  4. （D）剝奪式

答案：（B）

詳解與考點

考點為 Baumrind 教養類型。正解 B 獨裁（專制）式：高要求、低回應，不允許商量、對成績極度不滿，符合 authoritarian。最易誤選 C 權威（authoritative）——權威式高要求但高回應、願溝通，與本案「沒有商量空間」相反。

第 6 題

關於兒童性別刻板印象的敘述，下列何者正確？
  1. （A）國小兒童發展出學科與技能領域的性別刻板印象，影響兒童對特定科目的喜好與勝任感
  2. （B）學齡前兒童對於班上男同學塗指甲油雖深感奇怪，但通常仍會接受對方成為自己的朋友
  3. （C）學齡前的兒童早已發展出人格特質的性別刻板印象，包含男性為殘忍的，女性為溫和的
  4. （D）兒童期的性別刻板化彈性仍偏固著化，直到進入青春期，認知能力大躍進使得兒童看待性別特質更有彈性

答案：（A）

詳解與考點

考點為兒童性別刻板印象（選正確者）。正解 A：國小兒童發展出學科技能的性別刻板印象，影響其科目喜好與勝任感。其餘選項（學前已成型人格特質刻板、青春期才變彈性等）描述與發展研究不符或過度化。

第 7 題

小明在13個月大時，跟著新移民母親回到母親的家鄉，10歲回到臺灣進入小學就讀。依據語言發展觀點評估或協助提升小明語言能力的作法，下列何者正確？
  1. （A）以小明離開臺灣的年紀尚未進入說話知覺窄化期，其大腦仍應具備辨識中文母音的能力
  2. （B）以小明準備學習中文作為第二語言的年齡，可提供長期且密集的個人化語言訓練之規劃
  3. （C）大腦在出生時就內建了一套普遍語法，有助於語言的學習，僅需採取觸發普遍語法的教學方式
  4. （D）提供小明大量中文繪本，應足以發展出辨識詞彙的能力

答案：（B）

詳解與考點

考點為第二語言學習與關鍵期。正解 B：以小明學中文為第二語言的年齡（10 歲），宜提供長期且密集的個人化語言訓練。最易誤選 A——13 個月離台已過早期母音知覺窄化期；C、D 將普遍語法與繪本作用過度簡化。把握度中等。

第 8 題

八年級的國華與同學吵架，國華氣到想趁同學不注意時，摔壞同學的手機來報復，但後來國華沒有如此做。若以Freud心理分析取向之道德理論，其最有可能的原因為下列何者？
  1. （A）擔心被同學發現而被學校記過
  2. （B）想到從小媽媽不斷告訴他的話：「不可以破壞別人的東西」
  3. （C）他一向被認為是個好好先生，過去從來沒有破壞過別人的東西
  4. （D）擔心同學們知道後會排擠和討厭他

答案：（B）

詳解與考點

考點為 Freud 道德理論（超我）。正解 B：因內化了母親「不可以破壞別人東西」的訓示（超我/良心），而非因怕被罰或被排擠（那是外在後果）。最易誤選 A、D——怕記過、怕被排擠屬外在現實考量，非超我的道德內化。

第 9 題

關於青少年自尊的敘述，下列何者正確？
  1. （A）社會比較會形塑個體的整體自尊
  2. （B）在青少年時期，同儕對自尊的影響會變得更不顯著
  3. （C）來自集體主義社會的青少年，其整體自尊高於來自個人主義社會的青少年
  4. （D）根據E. Erikson的說法，進入國中之後的青少年其自尊有上升的趨勢

答案：（A）

詳解與考點

考點為青少年自尊的發展心理學。社會比較理論指出，個體透過與他人比較來評估自我，會形塑整體自尊，故 A 正確。陷阱在 B：青少年期同儕影響其實更顯著而非更不顯著，與發展事實相反，最易誤選。C、D 亦非定論。

第 10 題

父母親與青少年子女的衝突內容，最常與下列何者有關？
  1. （A）情感性議題，如孩子想要維持對父母的依賴
  2. （B）價值觀的討論，如宗教選擇的議題
  3. （C）日常事務，如：衣著打扮、家事或休閒活動等議題
  4. （D）倫理的議題，如婚前性行為或墮胎等議題

答案：（C）

詳解與考點

考點為親子衝突的內容研究。實證顯示父母與青少年最常起衝突的是日常瑣事，如衣著、家事、作息與休閒，故 C 正確。陷阱在價值觀、倫理等重大議題（B、D），看似嚴重卻非最常見的衝突來源，易被高估而誤選。

第 11 題

47歲的莉玲當小學老師已經有二十幾年。最近他一直在思考人生最重要的事情是什麼？若以Erikson的心理社會理論來看，莉玲最有可能會視什麼為最重要的事？
  1. （A）為自己的退休生活做準備
  2. （B）經營美好的婚姻關係
  3. （C）將自己的專業傳承給新進國小教師
  4. （D）與同事之間有更好的連結和關係

答案：（C）

詳解與考點

考點為 Erikson 心理社會理論中年期的「生產繁衍對停滯」。47 歲處於此階段，核心任務是傳承與貢獻下一代，故將專業傳承給新進教師（C）最符合。陷阱在 B 親密關係屬成年早期、A 退休準備偏老年期，階段不對而誤選。

第 12 題

關於婚姻幸福美滿維持的敘述，下列何者錯誤？
  1. （A）增進夫妻的親密感，可以提升婚姻的滿意度
  2. （B）只要降低夫妻的衝突，婚姻的滿意度即會提升
  3. （C）有效的壓力與衝突降低策略，有助維持婚姻滿意度
  4. （D）共同宗教信仰對低社經地位族群伴侶，更能增加婚姻品質

答案：（B）

詳解與考點

考點為婚姻滿意度的維持因素，題目問「錯誤」。婚姻幸福並非只靠降低衝突，還須正向親密互動，B 把單一條件絕對化故錯誤、為答案。陷阱在易把「降衝突」當成充分條件，忽略親密與正向情感同樣關鍵。

第 13 題

根據Baltes等人對老年人心理特性的系列研究結果，下列敘述何者錯誤？
  1. （A）老年人的流體智力並不比中年人或年輕人差
  2. （B）老年人的自尊並不比中年人或年輕人差
  3. （C）老年人的自我控制感並不比中年人或年輕人差
  4. （D）老年人表現出相當的心理強韌性

答案：（A）

詳解與考點

考點為 Baltes 老化研究，問「錯誤」。流體智力（推理、處理速度）會隨年齡下降，老人確實不如年輕人，A 敘述相反故為答案。陷阱在自尊、控制感、心理強韌性（B、C、D）多能維持，屬正確敘述，易被誤判。

第 14 題

關於老年虐待與忽視，下列敘述何者正確？
  1. （A）對老年虐待已經有精確的定義
  2. （B）不同文化族群對老年虐待的定義與看法是一致的
  3. （C）老年虐待最普遍的虐待形式是忽視
  4. （D）大多數老年虐待的施虐者是看護人員

答案：（C）

詳解與考點

考點為老年虐待與忽視，問「正確」。研究指出忽視是最普遍的老年虐待形式，故 C 對。陷阱在 A、B：老年虐待定義其實未精確、跨文化看法也不一致；D 施虐者多為家人而非看護，這些絕對化敘述易誤選。

第 15 題

依據美國相關研究指出，孱弱老人的居住選擇與心理健康，下列敘述何者正確？
  1. （A）由於「地方感」（sense of place），在家老去具有心理意義
  2. （B）生活輔助機構比護理之家可以提供更密集與適切的醫療照顧
  3. （C）通常老年人居住於護理之家是年長者自己做的決定
  4. （D）居住在家中的孱弱老人罹患憂鬱症比長期照顧機構中較高

答案：（A）

詳解與考點

考點為老年居住與心理健康。「地方感（sense of place）」使在家老去具情感與心理意義，故 A 正確。陷阱在 C：入住護理之家多非長者本人決定，而是家屬安排；B、D 與研究結論相反，易誤選。

第 16 題

不同人格取向的理論，對憂鬱有不同的解釋，下列敘述何者錯誤？
  1. （A）根據精神分析取向的看法，憂鬱是朝向內在的攻擊
  2. （B）特質論者所關心的是如何找出具有憂鬱傾向的人
  3. （C）人本取向的人格心理學家以童年創傷經驗來解釋憂鬱
  4. （D）行為論者主張憂鬱源自生活中缺乏正增強物

答案：（C）

詳解與考點

考點為各人格取向對憂鬱的解釋，問「錯誤」。以童年創傷經驗解釋憂鬱是精神分析的觀點，非人本取向，C 張冠李戴故為答案。陷阱在把人本與精神分析混淆；A 內射攻擊、D 缺正增強分別正確。

第 17 題

人格心理學家們定義了四種在研究中可能會用到的資料類型，又稱之為LOTS資料。關於這四種資料類型的敘述，下列何者錯誤？
  1. （A）L資料是由個人生活史或生活紀錄中獲得的資料所組成，然而許多心理特徵，較難透過此類客觀資料獲得
  2. （B）O資料是由父母、朋友或老師等熟知個體的觀察者所提供的資料所組成，主要來自對特定或一般行為的觀察
  3. （C）T資料是透過實驗程序或標準化測驗獲得，比如說個體在標準化智力測驗上的表現
  4. （D）S資料是由研究參與者自己報告的資料所組成，然而透過網路問卷得到的資料，常常和傳統施測方式所得到的資料結果有極大差異

答案：（D）

詳解與考點

考點為人格研究的 LOTS 四類資料，問「錯誤」。S 資料是自陳報告，研究指出網路問卷與傳統施測結果其實相當一致，D 稱「極大差異」故為答案。陷阱在 L 資料難測心理特徵（A）敘述正確，反易被誤判為錯。

第 18 題

在精神分析的理論中，過去的罪惡感與焦慮阻礙了成長，而分析情境卻使個體有機會重新處理過往的衝突。關於此一主張，下列敘述何者錯誤？
  1. （A）過往的衝突可以在較安全的情境中進行處理
  2. （B）個案接受分析時已較年長成熟，能利用自我中已發展的部分，應付尚未發展好的心理運作方式
  3. （C）諮商心理師採取與個案父母不同的態度來處理
  4. （D）個案在接受分析時能夠增進自我效能

答案：（D）

詳解與考點

考點為精神分析的「重新處理過往衝突」，問「錯誤」。分析強調修通衝突與洞察，「自我效能」是 Bandura 社會認知概念，與精神分析框架不合，D 為答案。陷阱在 A、B、C 描述安全情境與成熟自我運作皆正確。

第 19 題

Freud提出的那一個發展階段跟性格的支配、權力與控制感有關？
  1. （A）口腔期
  2. （B）肛門期
  3. （C）性蕾期
  4. （D）潛伏期

答案：（B）

詳解與考點

考點為 Freud 性心理發展階段。肛門期（約 1 至 3 歲）涉及如廁訓練，與控制、支配、權力感的人格特質有關，故 B 正確。陷阱在性蕾期（C）易誤選，但其核心是性別認同與戀親情結，非控制感。

第 20 題

當人們不喜歡自己的某些特徵，而說是別人的，是使用何種心理防衛機制以減少焦慮？
  1. （A）隔離（isolation）
  2. （B）反射（reflection）
  3. （C）投射（projection）
  4. （D）移情（transference）

答案：（C）

詳解與考點

考點為心理防衛機制。把自己不喜歡的特質歸到別人身上，是投射（projection），故 C 正確。陷阱在移情（transference，D）：那是把對重要他人的情感轉移到諮商師身上，並非把自身特質外推，易混淆。

第 21 題

根據Adler取向研究的觀點，尋求報復、攻擊他人，最符合下列何種生活風格（style of life）？
  1. （A）支配型
  2. （B）獲得型
  3. （C）逃避型
  4. （D）矛盾型

答案：（A）

詳解與考點

考點為 Adler 的生活風格類型。尋求報復、攻擊他人屬高活動度、低社會興趣的「支配型（ruling type）」，故 A 正確。陷阱在獲得型（B）偏依賴索取、逃避型（C）退縮，攻擊性不明顯，易誤選。

第 22 題

Horney認為個體為了因應基本焦慮，可能會對他人極為順從，藉以獲得他人的接納與贊同。這是屬於下列何種神經質傾向？
  1. （A）趨近型神經質傾向
  2. （B）反抗型神經質傾向
  3. （C）逃避型神經質傾向
  4. （D）矛盾型神經質傾向

答案：（A）

詳解與考點

考點為 Horney 三種神經質傾向。為因應基本焦慮而順從、討好以求接納屬「趨向他人（moving toward）」，故 A 趨近型正確。陷阱在反抗型（B，moving against）以攻擊支配對抗他人、逃避型（C，moving away）以疏離自保求獨立，方向相反易誤選。

第 23 題

長期被毆打的妻子多次試圖離家，但是皆被丈夫發現而更嚴厲地毆打她。之後，即使丈夫仍持續毆打她，她也不再試圖逃離家。下列那一個選項最適合說明這位妻子的反應？
  1. （A）斯德哥爾摩症候群（Stockholm syndrome）
  2. （B）負增強（negative reinforcement）
  3. （C）習得無助（learned helplessness）
  4. （D）懲罰（punishment）

答案：（C）

詳解與考點

考點為 Seligman 的習得無助。多次逃離失敗後即使環境可變仍放棄嘗試，是習得無助，故 C 正確。陷阱在斯德哥爾摩症候群（A）強調對加害者產生認同與依附，本題重點是「放棄逃離」而非情感認同，易誤選。

第 24 題

關於Skinner的性格理論敘述，下列何者錯誤？
  1. （A）Skinner不強調性格結構，因為不可見的性格結構無法直接觀察
  2. （B）行為是對情境影響力的適應，因此行為具有跨情境的一致性
  3. （C）人類行為不可避免地受制於所經驗到的環境
  4. （D）Skinner認為自己是用新的方式思考行為以取代性格理論

答案：（B）

詳解與考點

考點為 Skinner 行為論的人格觀，問「錯誤」。Skinner 主張行為受情境控制、隨情境而變，因此強調情境特定性而非「跨情境一致性」，B 與其立場相反故為答案。陷阱在誤以為一致性是行為論主張。

第 25 題

關於個人中心治療的特性，下列何者錯誤？
  1. （A）強調治療者與個案所建立的關係
  2. （B）相信個案改變行為的能力
  3. （C）強調指導個案談話內容的重要
  4. （D）強調治療之初，個案的內心是不一致的

答案：（C）

詳解與考點

考點為個人中心治療特性，問「錯誤」。Rogers 強調非指導、跟隨個案，由個案主導談話內容，C「強調指導內容」與核心相反故為答案。陷阱在 A、B、D 描述治療關係、信任個案、初期不一致皆正確。

第 26 題

關於自我揭露的研究，下列何者正確？
  1. （A）自我揭露越多的人，擁有越好的親密關係
  2. （B）以書寫方式揭露個人創傷經驗有益於心理健康
  3. （C）人本取向主張個案在心理治療需要自我揭露，但諮商心理師則不宜自我揭露
  4. （D）親密朋友或伴侶之間會出現最高程度的自我揭露回報性

答案：（B）

詳解與考點

本題問自我揭露研究「何者正確」，官方答案為 (B)。(B) 正確：Pennebaker 等人的表達性書寫（expressive writing）研究顯示，以書寫方式揭露個人創傷或情緒經驗，有助於身心健康（如改善情緒、免疫與生理指標）。其餘錯誤：(A) 過度絕對，自我揭露與親密關係品質並非單純「越多越好」的線性關係，過度或不適切的揭露反而可能有害，須視適當性與情境；(C) 不正確，人本取向（如 Rogers）並不主張治療師一概不宜自我揭露，真誠一致（congruence）反而鼓勵治療師適度、真實的自我表露，是否揭露應依取向、目的與界線判斷；(D) 不正確，自我揭露具回報性（reciprocity）效應，多出現在關係發展的初期與建立階段，藉相互揭露增進親近；在已高度親密的朋友或伴侶之間，回報性的「需求」反而下降，未必呈現最高程度的回報性，故 (D) 的絕對化敘述錯誤。

第 27 題

社會認知理論認為人們之間的差異，主要是因為下列何者的不同？
  1. （A）原型（archetypes）
  2. （B）特質組成（traits）
  3. （C）能力（competencies）
  4. （D）自我實現（self-actualization）的程度

答案：（C）

詳解與考點

考點為社會認知理論（Mischel、Bandura）。該理論認為人際差異主要源於認知社會的「能力（competencies）」等個人變項，故 C 正確。陷阱在原型（A，榮格）、特質（B，特質論）、自我實現（D，人本），分屬其他學派而誤選。

第 28 題

根據文化心理學對文化與心智的研究，下列敘述何者錯誤？
  1. （A）不同文化的人對於自我和社會，具有相當不同的基模
  2. （B）人類的心智就像是充滿各式工具的箱子，但文化會影響人們常使用的工具
  3. （C）所有類型的思考方式，都會受到文化影響
  4. （D）文化會強烈影響我們對世界的記憶和注意力

答案：（C）

詳解與考點

考點為文化心理學對文化與心智的研究，問「錯誤」。文化影響廣泛但非「所有」類型的思考都受文化影響，C 過度絕對化故為答案。陷阱在 A、B、D 談自我基模、工具箱、記憶注意力受文化影響皆正確，易被當作可疑選項。

第 29 題

小明看了一部刺激的警匪片，回家路上看到警察在臨檢一群機車。因為剛看過電影，小明覺得那些機車騎士像是飆車族，很可能會和警察起衝突。小明的想法可以用下列何者解釋？
  1. （A）控制式思考（controlled thinking）
  2. （B）促發作用（priming）
  3. （C）社會誘導（social induction）
  4. （D）觀察學習（observational learning）

答案：（B）

詳解與考點

考點為社會認知的促發作用（priming）。先前接觸的刺激（警匪片）活化相關概念，影響後續判斷，故 B 正確。陷阱在觀察學習（D）：那是模仿他人行為後習得反應，本題是概念被活化而影響知覺解讀，非習得行為。

第 30 題

關於基本歸因謬誤（fundamental attribution error）的定義，下列何者最佳？
  1. （A）團體決策不論是否經過特定的基本歷程，都一定有失誤的可能性
  2. （B）對行為的解釋偏重個人特性的因素，低估環境因素的影響力
  3. （C）團體決策過程若是沒有經過特定的基本歷程，很可能會出現失誤
  4. （D）對行為的解釋偏重環境因素，低估個人特性因素的影響力

答案：（B）

詳解與考點

考點為基本歸因謬誤的定義。指解釋他人行為時高估個人特質、低估情境因素，故 B 正確。陷阱在 D 方向恰相反（偏重環境），A、C 談的是團體迷思而非歸因，屬不同概念易混淆而誤選。

第 31 題

心理學家Carol Dweck（2006）將人們對於自己能力的信念區分為固定心態和成長心態兩種，下列敘述何者正確？
  1. （A）固定心態無法改變成為成長心態，成長心態可以改變成為固定心態
  2. （B）固定心態可以改變成為成長心態，成長心態無法改變成為固定心態
  3. （C）固定心態可以改變成為成長心態，成長心態也可以改變成為固定心態
  4. （D）固定心態無法改變成為成長心態，成長心態也無法改變成為固定心態

答案：（C）

詳解與考點

考點為 Dweck 的心態（mindset）理論。固定與成長心態皆非天生固定，兩者可雙向改變，故 C 正確。陷阱在 B（只能單向變成成長）這類片面選項，忽略心態可逆、會因環境與信念而改變的核心，易誤選。

第 32 題

小敏學科考試不及格，覺得自己很差勁。陳老師鼓勵她：「有好幾位同學考得比妳差，況且，妳雖然考試表現不如預期，但妳很有領導能力。」陳老師企圖協助小敏採用那些作法來保有自尊？
  1. （A）社會比較、自我肯定
  2. （B）調整歸因、恐懼管理
  3. （C）社會比較、焦慮管理
  4. （D）自我肯定、恐懼管理

答案：（A）

詳解與考點

考點為維護自尊的策略。老師指出別人考更差是「社會比較」（向下比較），肯定其領導能力是「自我肯定」，故 A 正確。陷阱在恐懼管理理論（B、D）涉及死亡焦慮，與本情境無關，屬干擾項易誤選。

第 33 題

下列何者屬於向上社會比較（upward social comparison）？
  1. （A）張姓營業員查閱了前一個月所屬部門中各個營業員的業績
  2. （B）月領基本工資的林先生發現其他兄弟賺的錢比自己少，因而感到寬慰
  3. （C）陳同學比對自己的詩作和詩人余光中的詩作，發現自己寫作技巧不足之處
  4. （D）運動選手李先生檢視自己上次比賽的成績，期許自己這次比賽能有更好的成績

答案：（C）

詳解與考點

考點為社會比較方向。向上社會比較指與優於自己者比較，學生比對自己與名詩人余光中的作品即是，故 C 正確。陷阱在 B 與賺得少的兄弟比是向下比較、A、D 屬中性或自我比較，方向不符易誤選。

第 34 題

在「無可救藥愛上你（Possession）」這部影片中，A. S. Byatt的一句名言「我既無法讓你將我燒盡，亦無法抗拒你。沒有人能夠站立於火中而不被消耗殆盡。」。依Sternberg提出愛情三角理論，這句電影台詞包含了那兩個元素？
  1. （A）親密（intimacy）與熱情（passion）
  2. （B）熱情（passion）與承諾（commitment）
  3. （C）承諾（commitment）與親密（intimacy）
  4. （D）友誼（friendship）與親密（intimacy）

答案：（A）

詳解與考點

考點為 Sternberg 愛情三角理論。台詞透露無法抗拒的強烈渴望（熱情）與情感連結（親密），但無長期承諾，故 A 親密與熱情。陷阱在 B、C 含承諾：台詞充滿被燃燒消耗的衝動感，看不到承諾元素，易誤選。

第 35 題

在Byrne等人（1986）所提出的吸引力兩階段模式（two-stage model of the attraction process）中，下列何者為影響兩個階段篩選吸引對象的主要因素？
  1. （A）相似性
  2. （B）需求互補性
  3. （C）時空接近性
  4. （D）外表吸引力

答案：（A）

詳解與考點

考點為 Byrne 等人吸引力兩階段模式。研究指相似性是貫穿兩個篩選階段、影響吸引的主要因素，故 A 正確。陷阱在外表吸引力（D）與時空接近性（C）：它們是重要因素，但非橫跨兩階段的核心，易誤選。

第 36 題

關於團體凝聚力與團體工作表現兩者之間的關係，下列何者正確？
  1. （A）兩者關係在大團體中最為明顯
  2. （B）兩者關係不受到工作性質的影響
  3. （C）兩者關係不受到團體規範的影響
  4. （D）兩者互相影響，且後者影響前者較大

答案：（D）

詳解與考點

考點為團體凝聚力與表現的關係。兩者雙向相關，且「表現好提升凝聚力」的方向影響較強，故 D 正確。陷阱在 A、B、C：關係受團體大小、工作性質與規範調節，這些「不受影響」的絕對敘述皆錯，易誤選。

第 37 題

佳佳開車上班時，遇到闖紅燈的車輛而差點被撞。驚魂未定地趕到辦公室準備開會，卻發現秘書沒有準備好開會的資料。佳佳一反平常的溫和告誡，破口大罵。此為下列何種現象？
  1. （A）敵意歸因偏誤（hostile attributional bias）
  2. （B）媒體暴力影響
  3. （C）激發遷移（excitation transfer）
  4. （D）激怒與報復

答案：（C）

詳解與考點

考點為攻擊的激發遷移（excitation transfer）。前一情境（險被撞）的生理激發殘留，被錯誤歸到後一情境而放大怒氣，故 C 正確。陷阱在敵意歸因偏誤（A）：那是把他人意圖解讀為敵意，本題重點是激發殘留遷移。

第 38 題

下列何者不是演化心理學解釋人願意犧牲自己來幫助別人的利社會行為？
  1. （A）近親選擇
  2. （B）回報規範
  3. （C）助人的代價與酬賞
  4. （D）團體選擇

答案：（C）

詳解與考點

考點為利社會行為的演化解釋，問「不是」。近親選擇、回報規範、團體選擇皆屬演化觀點；「助人的代價與酬賞」是社會交換／社會心理學的解釋，非演化論，故 C 為答案。陷阱在誤把成本效益也歸入演化解釋。

第 39 題

某高中禁止同學在校內抽菸，結果卻讓一些不抽菸的同學產生很高的興趣，因而偷抽菸，這種現象最可以用什麼理論來說明？
  1. （A）自我辯證理論
  2. （B）行為計劃理論
  3. （C）抗拒理論
  4. （D）增強理論

答案：（C）

詳解與考點

考點為 Brehm 的心理抗拒理論（reactance）。自由被限制（禁菸）反激起恢復自由的動機，使不抽菸者偏要嘗試，故 C 抗拒理論正確。陷阱在增強理論（D）：禁令並未提供增強物，無法解釋逆反行為，易誤選。

第 40 題

在嚴格控制的實驗室裡，當你看電腦中的影片，螢幕上快速閃過｢喝芒果可樂｣的字樣。根據閾下知覺的研究，下列敘述何者最正確？
  1. （A）你會選擇喝芒果可樂，但只有在你口渴的時候
  2. （B）不論你是否口渴，都會選擇喝芒果可樂
  3. （C）你更不會想要喝芒果可樂
  4. （D）不論你是否口渴，都會選擇喝自己喜歡品牌的可樂

答案：（A）

詳解與考點

考點為閾下知覺（subliminal perception）。研究顯示閾下廣告效果有限，僅在個體已有相應需求（如口渴）時才可能引導選擇，故 A 正確。陷阱在 B「不論是否口渴都會選」高估閾下訊息的強制力，與實證不符易誤選。
