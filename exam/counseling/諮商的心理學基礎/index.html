第 1 題

下列何種理論強調動作技能是主動重組已經精熟的能力，以主動探索並發展和外界更有效的互動方式？
  1. （A）互動理論（Interactive Approach）
  2. （B）動態系統理論（Dynamical Systems Theory）
  3. （C）訊息處理理論（Information Processing Theory）
  4. （D）社會文化理論（Sociocultural Theory）

答案：（B）

詳解與考點

正解：「主動重組已經精熟的能力」及「與外界更有效互動」——這正是動態系統理論將動作發展視為個體、任務與環境持續互動後自我組織的觀點。（B）正確，故選 B。

A：互動理論並非本題所述以動作系統主動重組為核心的理論。

C：訊息處理理論著重注意、記憶與認知運算，非以動作系統自我組織解釋技能發展。

D：社會文化理論強調社會互動與文化工具對發展的中介作用，非本題的動作重組觀點。

本題考點：動態系統理論的動作發展觀——判準是動作技能是否由既有能力、環境與任務互動下的主動探索及重組而來；若重點是認知運算或社會文化中介，則分屬其他理論。

第 18 題

下列何者不是佛洛伊德認為個體所體驗的焦慮？
  1. （A）道德焦慮
  2. （B）攻擊性焦慮
  3. （C）神經性焦慮
  4. （D）現實焦慮

答案：（B）

詳解與考點

正解：「不是佛洛伊德認為」的正式焦慮分類。佛洛伊德列出現實焦慮、神經性焦慮與道德焦慮，未將攻擊性焦慮列為獨立類型，故 B 為應選項。

A：道德焦慮與超我的懲罰或譴責有關，屬正式分類，故非答案。

C：神經性焦慮與本我衝動可能失控的威脅有關，屬正式分類，故非答案。

D：現實焦慮是面對外在威脅的焦慮，屬正式分類，故非答案。

本題考點：佛洛伊德焦慮類型——判準是外在威脅為現實焦慮、本我衝動為神經性焦慮、超我懲罰為道德焦慮；非此三類的名稱不可因字面相關而誤認。

第 33 題

美貌的人較吸引人的原因，下列何者錯誤？
  1. （A）美貌的人通常社交技巧較好
  2. （B）一般人都有美即是好的刻板印象，跨文化皆然
  3. （C）美貌的臉孔對稱特徵代表健康良好，適合生存繁衍
  4. （D）只要和美貌的人在一起，就可提升別人對我們的評價，不論此人是否為我們所認識

本題送分，無標準答案

詳解與考點

正解：本題經考選部公告一律給分，作答任一選項皆得分。原因是題目要找美貌何以較具吸引力的錯誤解釋，但可以判為錯誤的敘述有兩個：（D）把輻射效應說成不論雙方是否相識都會提升他人對自己的評價，忽略了對比效應的作用；（B）把美即是好的刻板印象說成跨文化皆然，也與跨文化研究只支持刻板印象普遍存在、不支持其內容一致的結果有出入。複數選項成立，故送分。

A：外表吸引力較高者從小獲得較多正向互動的機會，久之發展出較佳的社交技巧，這是以自我應驗歷程解釋吸引力的標準說法，敘述成立。

B：美即是好的刻板印象在許多文化都測得到，但被歸給美貌者的正向特質內容隨文化而異——個人主義文化較常聯想到強勢與獨立，集體主義文化較常聯想到誠實與關懷他人，因此跨文化皆然這個絕對化說法並不精確。

C：臉部對稱與平均臉被視為發育穩定與健康狀況良好的線索，演化取向據此解釋人們對美貌的偏好，是教材中的常見說法，敘述成立。

D：與外表出眾者同行會提升他人對自己的評價，前提是雙方被知覺為有關係；若只是恰好同處一地的陌生人，對比效應反而會使自己的外表評價被拉低，不論此人是否相識這個條件因此不成立。

本題考點：外表吸引力刻板印象（physical attractiveness stereotype）的跨文化普遍性與內容差異；輻射效應（radiation effect）與對比效應（contrast effect）的適用條件不同，關鍵在於觀察者是否知覺到兩人之間存在關係。

第 8 題

根據依附理論之「內在運作模式（internal working model）」的解釋，孩子會對「自己」建構出「正向的」 認知表徵，是因為他有下列何種與人互動的經驗？
  1. （A）一直得到足夠的觸感刺激
  2. （B）在早期階段即具備物體恆存的概念
  3. （C）很快地克服分離焦慮及陌生人焦慮
  4. （D）在自己需要時引發他人敏感性的照顧

答案：（D）

詳解與考點

正解：「正向的自己表徵」與「內在運作模式」——依附理論中，孩子在需要時能引發照顧者敏感且可回應的照顧，會形成「我是值得被照顧的」內在表徵，故選 D。

A：觸感刺激可能有助安撫與發展，但不足以說明依附關係中對自我價值的正向表徵。

B：物體恆存是認知發展概念，並非由照顧者回應形成的自我內在運作模式。

C：分離與陌生人焦慮的表現不能直接等同正向自我表徵；關鍵是照顧者對需求的敏感回應。

本題考點：內在運作模式（internal working model）——依附經驗所形成的自我與他人關係表徵；敏感回應（sensitive responsiveness）——支持安全依附與正向自我感。

第 24 題

小寶貝晚上不肯睡覺，一放進搖籃就大哭，直到被抱起來為止。他的父母覺得這習慣非改不可，於是將 小寶貝放進搖籃隨他哭。但是父母做不到充耳不聞，因擔心萬一是生病，有時會把小寶貝抱起來。從此， 小寶貝每放進搖籃，就哭得更大聲也更久。下面那一個選項最適合說明這樣的現象？
  1. （A）連續強化（continuous reinforcement）
  2. （B）部分強化安排（partial-reinforcement schedule）
  3. （C）逐步接近（successive approximations）
  4. （D）強化遞變（gradient of reinforcement）

答案：（B）

詳解與考點

正解：父母「有時」會在哭泣後把孩子抱起來——哭泣並非每次都獲得抱起，卻偶爾得到強化；這種不規則的結果會使行為更持久、消退更困難。故最適合的是部分強化安排（partial-reinforcement schedule），選 B。

A：連續強化是每一次目標行為都得到強化；題幹明示父母並非每次抱起，故不符。

C：逐步接近（successive approximations）是塑造法中強化逐漸接近目標的行為，例如先強化短暫安靜再延長時間，題幹沒有這種漸進標準。

D：強化遞變指強化效果隨反應與條件差異呈現梯度，不能直接解釋偶發抱起使哭泣拉長。A 最易被誤選，因為抱起確實會增強哭泣；關鍵在強化並非每次發生，而是間歇發生。

本題考點：部分強化（partial reinforcement）——反應僅有部分次數得到強化；部分強化消退效應（partial-reinforcement extinction effect）——間歇強化的行為較不易消退；正增強（positive reinforcement）——抱起可能使哭泣行為維持。
