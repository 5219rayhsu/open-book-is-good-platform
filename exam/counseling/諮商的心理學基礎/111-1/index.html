第 1 題

精準的把認知分解成可被研究的小單位，是以下何種認知發展取向的優點？
  1. （A）建構論取向
  2. （B）核心知識論取向
  3. （C）訊息處理取向
  4. （D）社會認知取向

答案：（C）

詳解與考點

考點為認知發展取向。訊息處理取向（information-processing）把認知歷程比擬電腦運作，將之分解為編碼、儲存、提取等可被精準研究的小單位，正是其優點，故 C。陷阱在與建構論混淆：建構論重整體基模建構，較不主張細部分解。

第 2 題

關於嬰幼兒生理發展的敘述，下列何者錯誤？
  1. （A）一出生時的嬰兒其實是大近視，視覺神經以及對焦功能都在發展
  2. （B）大約3～4個月時會開始有翻身的能力
  3. （C）一出生的嬰兒雖然肌肉張力都正在發展，但是可以靠吸吮的反射維持進食
  4. （D）嬰兒會先發展出手指夾物的能力再發展出手掌抓握的力量

答案：（D）

詳解與考點

考點為嬰幼兒動作發展的近遠律與大小肌肉順序。動作發展遵循「先大肌肉後小肌肉」，故先發展手掌整體抓握，再發展手指精細的夾物（鉗形抓握），D 的順序顛倒，為錯誤選項即正解。陷阱在 A：新生兒視力確實不佳、對焦在發展中，敘述正確，易被誤判為錯。

第 3 題

關於語言發展互動論（interactionist approach）的觀點，下列何者錯誤？
  1. （A）語言發展的普遍性主要是導因於發展環境的相似性，而非來自先天的特定語言能力
  2. （B）不同的兒童導向的說話方式（child-directed speech）會影響語言的發展
  3. （C）在互動中向成人模仿語言技巧和內容是兒童學習語言的唯一途徑
  4. （D）父母的正向回饋及糾正，有助於語言的學習

答案：（C）

詳解與考點

考點為語言發展的互動論，強調先天能力與後天環境交互作用。互動論不認為模仿是「唯一」途徑，兒童具主動建構與先天傾向，故 C 把模仿說成唯一途徑為錯誤，即正解。陷阱在 A：互動論確實重視環境相似性的解釋，敘述合理，易被當成錯項。

第 4 題

有關新生兒對臉孔偏好的敘述，下列何者正確？
  1. （A）注視照片時，對閉上眼睛的臉孔偏好大過於睜開眼睛的臉孔
  2. （B）對成人普遍認為漂亮的臉孔，並沒有特殊偏好
  3. （C）以直立或倒置方向呈現臉孔刺激，並不會影響嬰兒的偏好
  4. （D）2～3個月以前，臉孔偏好決定於刺激是否在嬰兒的視域內移動

答案：（D）

詳解與考點

考點為新生兒臉孔偏好的研究。2～3個月以前嬰兒主要受外部運動與是否落在視域內影響，之後才轉向內在特徵，故 D 正確。陷阱在 A：嬰兒偏好睜眼而非閉眼臉孔，且對漂亮臉孔確有偏好（B 錯）、倒置會影響偏好（C 錯），易誤選。

第 5 題

關於兒童性別認識與認同的敘述，下列何者正確？
  1. （A）小芬知道自己不是男生就是女生，並且能標示自己是個女生，已進入性別不變階段
  2. （B）小明知道男孩會變成男人，女孩會變成女人，已進入性別不變階段
  3. （C）曉鈴知道自己穿男生衣服也不會變成男生，已進入性別標示階段
  4. （D）小華認為男性若扮演媽媽角色也不會隨情況與個人願望而變成女性，顯示他已進入性別不變階段

答案：（D）

詳解與考點

考點為 Kohlberg 性別概念三階段：標示、穩定、恆常。性別恆常指理解性別不因外觀、情境或意願改變，D 描述「扮媽媽也不變女性」正是恆常，故正確。陷阱在 A／C：能標示自己是女生只是「性別標示」階段，非不變階段，最易誤選 A。

第 6 題

關於兒童虐待的敘述，下列何者錯誤？
  1. （A）常生病的兒童與不成熟的兒童行為，容易成為家庭虐待的高風險族群
  2. （B）家庭環境為貧窮與社會孤立，以及父母本身曾經受虐，較可能助長兒童虐待的發生
  3. （C）相較於嬰幼兒與學齡前的兒童，學齡期兒童更容易受到家庭虐待
  4. （D）父母採用無效的教養方式，對兒童有不切實際的期待，較容易助長兒童虐待

答案：（C）

詳解與考點

考點為兒童虐待的高風險因子。相較學齡兒童，嬰幼兒與學齡前幼兒因依賴度高、表達與自保能力弱，更易受虐，故 C 的比較方向錯誤，為正解。陷阱在 A、B、D 皆屬公認風險因子（生病、不成熟、貧窮孤立、父母受虐史、不當教養），敘述正確易被排除。

第 7 題

關於認知策略（cognitive strategies）發展的描述，下列何者最正確？
  1. （A）Siegler認為任何年齡的兒童都擁有多種策略，而且策略產生和使用的發展有固定的階段性
  2. （B）較年幼兒童受到產出缺陷（production deficiency）對認知作業的影響，是無法以任何教導方式改善的
  3. （C）年長的兒童所使用的策略未必會比年幼兒童更多而且更複雜，較佳的認知表現要依據認知策略對問題解決的適合程度而定
  4. （D）有些兒童儘管從教導之中可以學會比較好的認知策略，但因使用缺陷（utilization deficiency）的限制而無法自發地應用認知策略

答案：（C）

詳解與考點

考點為 Siegler 的認知策略發展與重疊波理論。策略選擇是看其對問題的適合度，而非單純「年長者策略一定較多較複雜」，故 C 最正確。陷阱在 A：Siegler 主張策略並非固定階段性，而是多策略並存競爭，故 A「固定階段性」說法錯誤。

第 8 題

某國中發生男學生集體霸凌一位同學，在調查過程中，一位學生說：「其實我不認識那個被打的同學，但因為我的好朋友們都打他」，此位同學的說法，最符合青少年發展的那個特徵？
  1. （A）學生暴力事件與偏差行為以國中階段最為嚴重
  2. （B）青少年男生比女生有較多的攻擊行為
  3. （C）青少年的從眾行為是生活中常見的行為模式
  4. （D）青少年在尋求獨立時，更需要同儕的情緒支持

答案：（C）

詳解與考點

考點為青少年發展中的同儕影響與從眾行為。學生因好友都打人而跟著打、與被害者本不相識，最符合「從眾行為」，故 C 正確。陷阱在 D：尋求獨立需同儕情緒支持雖也是青少年特徵，但此例核心是行為跟隨群體，而非情緒支持，易混淆。

第 9 題

針對青少年自我認同的敘述，下列何者正確？
  1. （A）以文化期望為形象標準之認同，皆為正向認同
  2. （B）自我認同是隨著期望變化的一種動態歷程
  3. （C）自我認同是一間歇性的社會化歷程
  4. （D）與同儕的關係可取代與父母的親密度，所以其自我認同不受父母影響

答案：（B）

詳解與考點

考點為 Erikson／Marcia 取向的自我認同概念。認同是隨經驗與期望持續調整的動態歷程，故 B 正確。陷阱在 A：以文化期望為標準的認同未必皆為正向（可能是早閉型 foreclosure），且認同是持續而非間歇歷程（C 錯），父母仍有影響（D 錯）。

第 10 題

面對家中青少年的孩子，父母較佳的教養方式為下列何者？
  1. （A）高度接納和回應；低度的行為控制；高度的心理控制
  2. （B）高度接納和回應；高度的行為控制；低度的心理控制
  3. （C）高度接納和回應；低度的行為控制；低度的心理控制
  4. （D）低度接納和回應；高度的行為控制；高度的心理控制

答案：（B）

詳解與考點

考點為 Baumrind 教養類型，最佳為開明權威（authoritative）。理想組合是高接納回應、高行為控制（合理規範）、低心理控制（不操控情感），故 B 正確。陷阱在 C：誤以為「低行為控制」較好，但放任缺乏規範並非最佳；心理控制才應降低，易混淆兩種控制。

第 11 題

性別角色社會化（gender-role socialization）對成人生涯的影響為何？
  1. （A）女性投入職場後，其在家庭中的角色與期望隨之減少
  2. （B）男性在職業抉擇，較傾向於高支持性的環境
  3. （C）雙薪家庭最大的家庭困境是老人及幼童的照顧問題
  4. （D）男女對職業成功相關技能有相同的期望

答案：（C）

詳解與考點

考點為性別角色社會化對成人生涯的影響。雙薪家庭最大困境常為老幼照顧（照顧責任仍多落在女性），故 C 正確。陷阱在 A：女性投入職場後家庭角色期望未必減少，反而常面臨雙重負擔，敘述與事實相反，易誤選。

第 12 題

關於創造生命末期最後的劇本（final scenario）的定義，下列敘述何者正確？
  1. （A）重新敘說個人生命故事並將之編寫為劇本
  2. （B）發揮個人創意編寫劇本並獲得演出機會
  3. （C）對自己生命末期與死後的安排做出選擇
  4. （D）家屬為即將過世或已過世的家人敘寫其生平故事

答案：（C）

詳解與考點

考點為生死學中 final scenario（最後劇本）的概念，由 Corr 等提出。指個人對自己生命末期及死後安排（醫療、後事、告別等）所做的自主選擇，故 C 正確。陷阱在 A／D：易誤以為是敘說生命故事或家屬撰寫生平，但重點在「對臨終與身後的自主安排」。

第 13 題

關於年長者的人際關係，下列敘述何者正確？
  1. （A）年長者傾向形成社會團隊（social convoy），以肯定「我是誰？」
  2. （B）年長者的生活滿意度和其子女及孫子女數量與關係品質有高度相關
  3. （C）年長者的友誼型態與年輕時的型態無關
  4. （D）年長者傾向讓年輕朋友取代因死亡而失去的朋友

答案：（A）

詳解與考點

考點為老化的社會關係理論，social convoy（社會護衛隊）。年長者傾向維持核心的社會支持網絡以肯定自我認同，故 A 正確。陷阱在 B：生活滿意度與子孫「數量」相關不高，關係品質才重要，把數量當高相關易誤選。

第 14 題

一位55歲的文創工作者，感覺自己的體力大不如前，也覺得自己呈現初老的症狀，下列何者符合初老年期的症狀？
  1. （A）隨著年齡的增長，自己的創作品質水準會下降
  2. （B）自己的結晶智力（crystallized intelligence）會漸漸的衰退
  3. （C）因為注意力有缺陷而影響創作品質
  4. （D）對事件記憶和反應比年輕時退化

答案：（D）

詳解與考點

考點為成年中後期的認知老化。初老期最先出現的是事件記憶與反應速度（流體智力相關）的退化，故 D 符合初老症狀。陷阱在 B：結晶智力（經驗、知識）通常維持甚至提升、不會早衰；且創作品質、注意力缺陷並非初老必然，易誤選。

第 15 題

有關中西方家庭生命週期異同的敘述，下列何者錯誤？
  1. （A）兩方都只照顧孩子到成年
  2. （B）中國家庭成員較不重視個人隱私空間
  3. （C）西方家庭較強調家庭中個別成員的利益
  4. （D）西方家庭較強調夫妻關係，中國家庭較重視親子倫理

答案：（A）

詳解與考點

考點為中西方家庭生命週期的文化差異。中國家庭常照顧子女至成年後仍持續支持（不只到成年），故 A「兩方都只照顧到成年」錯誤，為正解。陷阱在 B、C、D 皆為公認差異（隱私、個人利益、夫妻 vs 親子倫理），敘述正確易被排除。

第 16 題

在人格心理學研究裡，有些實驗情境中的隱微線索，會暗示受試者有關實驗者所持有的某些假設，而受試者會以自己的行動，來證明實驗者的假設，這個影響因素稱為什麼？
  1. （A）受試者預期效果（participant expectancy effects）
  2. （B）要求特徵（demand characteristics）
  3. （C）反應心向（response style）
  4. （D）霍桑效應（Hawthorne effect）

答案：（B）

詳解與考點

考點為研究方法中的實驗效度威脅。隱微線索讓受試者猜出實驗假設並配合表現，稱為「要求特徵」（demand characteristics），故 B 正確。陷阱在 D：霍桑效應指受觀察而改變行為，A 受試者預期效果概念相近但非標準術語，B 才是此定義的專名。

第 17 題

根據佛洛伊德的性心理發展階段，個體主動表現出與同性別互動的強烈慾望而對異性不感興趣，以及化解伊底帕斯情結（Oedipus complex），依序是在下列那兩個階段？
  1. （A）兩性期（genital stage）；潛伏期（latency stage）
  2. （B）肛門期（anal stage）；兩性期（genital stage）
  3. （C）性器期（phallic stage）；潛伏期（latency stage）
  4. （D）潛伏期（latency stage）；兩性期（genital stage）

答案：（D）

詳解與考點

本題依序問兩件事，官方答案為 (D)。第一件「主動表現出與同性別互動的強烈慾望、對異性不感興趣」對應潛伏期（latency stage，約 6 歲至青春期）：此期性驅力相對潛沉，兒童多與同性同儕往來、發展社會技能與認同，故呈現親近同性、疏遠異性的現象。第二件「化解伊底帕斯情結」對應兩性期（genital stage，青春期之後）：伊底帕斯情結雖在性器期（phallic stage）出現並開始被壓抑，但真正的整合與化解、將性能量導向成熟的異性親密關係，是在青春期進入兩性期後完成。因此依序為潛伏期、兩性期，選 (D)。其餘選項順序皆不符：(A) 兩性期在前不合；(B) 起於肛門期不符同性互動描述；(C) 把化解情結放在潛伏期，但佛洛伊德觀點中情結的最終整合屬兩性期，故不選。

第 18 題

下列何者不是佛洛伊德認為個體所體驗的焦慮？
  1. （A）道德焦慮
  2. （B）攻擊性焦慮
  3. （C）神經性焦慮
  4. （D）現實焦慮

答案：（B）

詳解與考點

考點為佛洛伊德的三種焦慮：現實焦慮、神經性焦慮、道德焦慮。三者對應外在威脅、本我衝動、超我懲罰。B「攻擊性焦慮」並非佛洛伊德所列類型，故為正解。陷阱在於四個選項看似都與焦慮有關，但只有道德、神經性、現實三者為其正式分類。

第 19 題

在學校被老師處罰之後，將怒氣發洩在家人身上，這是那種心理防衛機制的表現？
  1. （A）合理化（rationalization）
  2. （B）否認（denial）
  3. （C）反向作用（reaction formation）
  4. （D）替代作用（displacement）

答案：（D）

詳解與考點

考點為心理防衛機制。被老師處罰卻把怒氣轉向較安全的對象（家人），是把情緒轉移到替代目標，屬「替代作用」（displacement），故 D 正確。陷阱在 C 反向作用：反向是表現出相反情緒，而此例是情緒轉移對象，非情緒反轉，易混淆。

第 20 題

出生序的研究是Adler重要的貢獻之一，有關出生序對於性格的影響，下列何者錯誤？
  1. （A）長子／長女通常注重過去，對於維持秩序與權威較具興趣
  2. （B）次子／次女通常較不受重視，對未來較為悲觀
  3. （C）么子／么女因為較常受到父母或兄姊的照顧，長大後可能較為依賴
  4. （D）獨生子女通常較為早熟，展現出成人的行為和態度

答案：（B）

詳解與考點

考點為 Adler 的出生序與性格。Adler 對次子／中間子的看法多為較具競爭性、企圖超越兄姊，並非「不受重視、對未來悲觀」，故 B 錯誤為正解。陷阱在 A、C、D 皆符合 Adler 對長子、么子、獨生子的典型描述，敘述正確易被排除。

第 21 題

最常使用投射測驗衡鑑性格的學派為下列何者？
  1. （A）人本學派
  2. （B）心理動力學派
  3. （C）行為學派
  4. （D）社會認知學派

答案：（B）

詳解與考點

考點為人格衡鑑與學派對應。投射測驗（如羅夏克墨漬、TAT）假設個體會將潛意識投射到模糊刺激，最常為心理動力學派採用，故 B 正確。陷阱在於行為與社會認知學派偏好客觀量表與行為觀察，人本重現象學晤談，皆非投射測驗主流。

第 22 題

為了降低學童的攻擊行為，Skinner建議老師可以採用何種因應策略，最為有效？
  1. （A）代幣制度
  2. （B）系統減敏感法
  3. （C）洪水法
  4. （D）觀察學習

答案：（A）

詳解與考點

考點為操作制約在班級經營的應用。Skinner 主張以正增強塑造行為，代幣制度（token economy）以可兌換增強物提升好行為、降低攻擊，最有效，故 A 正確。陷阱在 B、C 系統減敏與洪水法屬處理焦慮的行為技術，D 觀察學習屬 Bandura，非 Skinner 主張。

第 23 題

沉迷於賭博的人，不容易戒掉賭博的行為，主要是因為賭博是屬於何種增強時制（schedule of reinforcement）？
  1. （A）固定時距
  2. （B）固定比率
  3. （C）逐步漸進
  4. （D）變動比率

答案：（D）

詳解與考點

考點為增強時制與行為持久性。賭博的獎賞不可預測、需不定次數才中獎，屬「變動比率」（variable ratio）時制，反應率最高且最難消弱，故 D 正確。陷阱在 B 固定比率：固定比率是每固定次數才增強，而賭博的關鍵在於「不固定」，易混淆。

第 24 題

相較於Eysenck的觀點，下列主張何者最接近Cattell的觀點？
  1. （A）強調描述性格的外在行為
  2. （B）強調性格中的生物性變項
  3. （C）相信表面特質（surface traits）並非存在於外顯的表面，且無法被直接觀察
  4. （D）強調性格的組織結構，深源特質（source traits）是理解可觀察行為傾向下的心理結構

答案：（D）

詳解與考點

考點為特質論中 Cattell 與 Eysenck 的差異。Cattell 以因素分析找出潛在的「根源特質」（source traits），視其為理解可觀察行為的心理結構，故 D 最接近其觀點。陷阱在 B：強調生物性變項（如喚起水準）是 Eysenck 的特色，而非 Cattell，易誤選。

第 25 題

依據Maslow的理論，關於自我實現者的敘述，下列何者錯誤？
  1. （A）其動機是匱乏動機
  2. （B）追求後設需求
  3. （C）具有社會興趣
  4. （D）偏向追求刺激與挑戰

答案：（A）

詳解與考點

考點為 Maslow 需求層次與自我實現者。自我實現者的動機是「成長（存在）動機」而非匱乏動機，追求後設需求、具社會興趣與挑戰，故 A「匱乏動機」錯誤，為正解。陷阱在於 B、C、D 皆為自我實現者的正確特徵，敘述正確易被排除。

第 26 題

小明考試考差了，怪罪出題老師出得太差，而自己念的都沒考。此現象最適合以下列何種概念做解釋？
  1. （A）自我驗證（self-verification）
  2. （B）自我提升（self-enhancement）
  3. （C）自我效能（self-efficacy）
  4. （D）自我懲罰（self-punishment）

答案：（B）

詳解與考點

考點為自我相關的社會認知動機。把考差歸咎出題老師、保全自我形象，屬「自我提升」（self-enhancement）的自利歸因，故 B 正確。陷阱在 A 自我驗證：自我驗證是尋求與既有自我概念一致的回饋，而此例是維護正面形象，動機方向不同，易混淆。

第 27 題

Hazel Markus採用反應時間法研究自我基模，她發現人們對與自己基模相關的性格特質之判斷，具有下列那一個特性？
  1. （A）較保守
  2. （B）較快速
  3. （C）較防衛
  4. （D）較嚴苛

答案：（B）

詳解與考點

考點為 Markus 的自我基模（self-schema）研究。她以反應時間法發現，對與自我基模相關的特質判斷會「較快速」（因該訊息已組織化、易提取），故 B 正確。陷阱在於 A、C、D 偏向情緒或防衛性描述，但研究指標是反應「速度」而非態度，易誤選。

第 28 題

研究者密集觀察30個小學三年級學生在學習乘法前後一個月之間對於數字概念的變化，每週進行一次測驗，這項研究設計屬於下列何者？
  1. （A）微觀設計（microgenetic design）
  2. （B）序列設計（sequential design）
  3. （C）實驗設計（experimental design）
  4. （D）橫斷設計（cross-sectional design）

答案：（A）

詳解與考點

考點為發展研究設計。對少數兒童在短期內密集、多次測量以觀察某能力的變化歷程，屬「微觀發生設計」（microgenetic design），故 A 正確。陷阱在 C 實驗設計：本研究是密集追蹤觀察而非操弄變項分組，重點在捕捉變化過程，易誤選。

第 29 題

當我們快速地對他人形成印象時，通常會運用那兩種概括的「內隱人格理論（implicit personality theory）」作出判斷？
  1. （A）親切與能力
  2. （B）內外向與能力
  3. （C）親切與情緒穩定度
  4. （D）內外向與情緒穩定度

答案：（A）

詳解與考點

考點為印象形成中的內隱人格理論。研究指出人們快速判斷他人時，主要依「溫暖（親切）」與「能力」兩大向度，故 A 正確。陷阱在於內外向、情緒穩定屬大五人格特質，並非印象形成的兩大核心維度，易與人格理論混淆而誤選。

第 30 題

針對基模的提取速度，下列敘述何者錯誤？
  1. （A）基模可能因為過去的經驗而保持活躍，故易於提取
  2. （B）涉及當前目標的基模，較容易提取
  3. （C）負面內容的基模比正面內容的基模，更容易被提取
  4. （D）近期經驗可以使基模暫時容易被提取

答案：（C）

詳解與考點

考點為基模的可及性（accessibility）與提取。基模因近期經驗（促發）、當前目標及過去經驗而易提取；但「負面內容一定比正面更易提取」並非通則，故 C 錯誤為正解。陷阱在於 A、B、D 皆為基模提取的標準原則，敘述正確易被排除。

第 31 題

李媽媽想要知道如何使用獎賞來促進孩子的好行為，下列建議何者最為適當？
  1. （A）基於操作制約理念，只要給予孩子獎賞，就可以帶來長久的行為改變
  2. （B）基於自我辯護概念，應給予孩子少量的獎賞，較能帶來長久的行為改變
  3. （C）基於過度辯護效應，只要發現孩子有興趣想去做一個好行為，就應該要趕快給予獎賞，以免錯失良機
  4. （D）基於過度辯護效應，宜使用任務為條件而非表現為條件的方式來獎賞孩子

答案：（B）

詳解與考點

考點為過度辯護效應與自我辯護對獎賞的影響。給予「少量」外在獎賞較不會削弱內在動機，反而透過自我辯護帶來較持久的態度改變，故 B 正確。陷阱在 A：操作制約的外在獎賞一旦撤除行為常消退，並非「只要給獎賞就能長久改變」，易誤選。

第 32 題

根據社會心理學家Elliot Aronson、Ben Willerman和Joanne Floyd的研究結果，由最不受歡迎到最受歡迎的人排列順序為何？①能力優異的人②能力優異但犯小錯的人③能力平庸的人④能力平庸但犯小錯的人
  1. （A）③④①②
  2. （B）③④②①
  3. （C）④③②①
  4. （D）④③①②

答案：（D）

詳解與考點

考點為 Aronson 等人的「出醜效應」（pratfall effect）。能力優異者犯小錯反而最討喜，平庸者犯錯則更不討喜。由最不到最受歡迎為：④平庸犯錯、③平庸、①優異、②優異犯錯，故 D 正確。陷阱在於易忽略平庸者犯錯反而墊底，排錯順序。

第 33 題

關於公平理論（equity theory）的敘述，下列何者錯誤？
  1. （A）關係中的當事人會使他們雙方共同的酬賞達到最大
  2. （B）在關係中獲得利益過多的人最為滿意快樂
  3. （C）關係不公平時，當事人會採取步驟回復公平
  4. （D）當事人會發展公平的分配原則使集體酬賞得到最大

答案：（B）

詳解與考點

考點為人際關係的公平理論（equity theory）。公平理論主張人們追求投入與回報的「公平」比例，關係不公平時會設法回復公平。獲益過多者其實會感到內疚而非「最滿意快樂」，故 B 錯誤為正解。陷阱在於誤以為得到越多越快樂，忽略過度獲益的不適。

第 34 題

根據Hancock與Toma（2012）對於網路人際關係的研究結果，下列敘述何者正確？
  1. （A）為了方便欺瞞，會增加第一人稱代名詞使用
  2. （B）為了取得對方信任，使用簡短自我介紹
  3. （C）使用負面敘述或否定句來形容自己的簡介，其可信度較低
  4. （D）男性使用修圖過後照片的比率比女性高

答案：（C）

詳解與考點

考點為網路自我呈現與欺瞞的語言線索研究。Hancock 與 Toma 發現自介中用負面或否定句描述自己時可信度較低，故 C 正確。此題屬較冷僻的特定研究結果，A、B、D 的具體方向（代名詞、長短、性別修圖比率）難以單憑通則判斷，把握度偏低。

第 35 題

當人們有「想要與他人接觸、建立關係的慾望」，最屬於下列何種心理狀態？
  1. （A）自尊
  2. （B）自我保護
  3. （C）親和需求
  4. （D）社交焦慮

答案：（C）

詳解與考點

考點為人際動機。「想與他人接觸、建立關係的慾望」即「親和需求」（need for affiliation），故 C 正確。陷阱在 D 社交焦慮：社交焦慮是對社交情境的害怕，與主動親近的需求方向相反；自尊、自我保護亦非此定義，易混淆。

第 36 題

從Kohlberg的理論來看，在設計道德教育課程時，最應注重下列何者？
  1. （A）須能引發學生的興趣
  2. （B）須能引發認知衝突與社會互動
  3. （C）須灌輸道德原則，並讓學生多練習
  4. （D）教師應以身作則

答案：（B）

詳解與考點

考點為 Kohlberg 道德發展理論在教育的應用。其主張透過呈現道德兩難、引發「認知衝突」與「社會互動（角色取替）」來促進道德推理發展，故 B 正確。陷阱在 C：直接灌輸道德原則與反覆練習屬傳統德育，與 Kohlberg 建構取向相違，易誤選。

第 37 題

下列有關攻擊行為的性別差異，何者是錯誤的？
  1. （A）因為女性鮮少有攻擊行為，女性自殺炸彈客較男性表現攻擊行為時更為瘋狂
  2. （B）女孩傾向以隱藏的方式表達攻擊情緒，例如八卦
  3. （C）男孩子較常用肢體攻擊，女孩子則較多關係攻擊
  4. （D）男性比女性更容易表現攻擊行為

答案：（A）

詳解與考點

考點為攻擊行為的性別差異。男性整體較常表現外顯（肢體）攻擊，女性較多關係攻擊。A 稱「女性鮮少攻擊、故女自殺炸彈客更瘋狂」屬偏見且無實證，敘述錯誤為正解。陷阱在於 B、C、D 皆符合研究通說（八卦、關係攻擊、男性肢體攻擊），易被排除。

第 38 題

社會心理學家Elliot Aronson等人發明拼圖技術（jigsaw technique）來消除偏見，Diane Bridgeman進一步以兒童為實驗對象，發現此法最主要可提升兒童的何種心理特質？
  1. （A）正向信念
  2. （B）認知評價
  3. （C）同理心
  4. （D）自尊

答案：（C）

詳解與考點

考點為 Aronson 拼圖技術（jigsaw classroom）。其讓學生互賴合作以消除偏見，Bridgeman 的後續研究發現此法最能提升兒童的「同理心」（角色取替能力），故 C 正確。陷阱在 D 自尊：自尊雖也可能改善，但該研究主要凸顯同理心的提升，易誤選。

第 39 題

小哈說他搭車同意繫上安全帶，根據計畫行為理論（theory of planned behavior），下列何者最能預測小哈當天會繫安全帶？
  1. （A）小哈最好的朋友小賴也在車上，且繫上安全帶
  2. （B）小哈知道自己常忘記繫上安全帶
  3. （C）小哈不太能提取對安全帶的態度
  4. （D）小哈不反對行車安全的重要性

答案：（A）

詳解與考點

考點為計畫行為理論（TPB）的三大前因：態度、主觀規範、知覺行為控制。好友在場且繫安全帶屬「主觀規範」的具體影響，最能預測行為，故 A 正確。陷阱在 B、C：常忘記、難提取態度反映控制感或態度可及性偏弱，預測力較弱，易誤選。

第 40 題

在Asch線段實驗中，參與者獨自判斷時，有98%給予正確答案。然而當他與實驗小組一起判斷時，該實驗小組成員對某些判斷會一致給予錯誤答案，76%參與者至少給予一次錯誤答案。Asch的實驗顯示了下列何者？
  1. （A）公開順從但非私下接納
  2. （B）訊息式影響
  3. （C）基本歸因謬誤
  4. （D）公開順從與私下接納

答案：（A）

詳解與考點

考點為 Asch 線段從眾實驗的詮釋。多數受試者公開附和錯誤答案是因群體壓力（規範性影響）下的「公開順從」，但私下並未真正接納正確判斷已改變，故 A 正確。陷阱在 D／B：此屬規範性而非訊息式影響，且非真正內化（私下接納），易誤選。
