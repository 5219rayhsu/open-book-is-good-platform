第 1 題

精準的把認知分解成可被研究的小單位，是以下何種認知發展取向的優點？
  1. （A）建構論取向
  2. （B）核心知識論取向
  3. （C）訊息處理取向
  4. （D）社會認知取向

答案：（C）

詳解與考點

正解：「分解成可被研究的小單位」，這是訊息處理取向的研究方法特徵，判準是是否將認知歷程拆為可觀察、可測量的步驟。訊息處理取向把認知比擬為資訊運作，區分編碼、儲存與提取等歷程，因而能精準研究小單位，故選 C。

A：建構論重視個體如何主動建構基模與理解世界，不以細部分解作為其主要優點。

B：核心知識論關注嬰幼兒先天具備的特定知識領域，重點不在將認知歷程拆解。

D：社會認知取向著重社會互動、觀察學習與社會脈絡，非題幹所指的方法。A 最易因同樣研究認知發展而誤選，但兩者的分析單位不同。

本題考點：認知發展取向——訊息處理取向的判準是將認知拆成編碼、儲存、提取等可研究的處理歷程；若重點是基模建構、先天核心知識或社會互動，則屬其他取向。

第 2 題

關於嬰幼兒生理發展的敘述，下列何者錯誤？
  1. （A）一出生時的嬰兒其實是大近視，視覺神經以及對焦功能都在發展
  2. （B）大約3～4個月時會開始有翻身的能力
  3. （C）一出生的嬰兒雖然肌肉張力都正在發展，但是可以靠吸吮的反射維持進食
  4. （D）嬰兒會先發展出手指夾物的能力再發展出手掌抓握的力量

答案：（D）

詳解與考點

正解：「手指夾物」與「手掌抓握」的發展順序——嬰幼兒動作發展遵循先大肌肉、後小肌肉的原則。手掌整體抓握先於手指精細的夾物能力，D 將順序顛倒，與發展原則不符，故為錯誤選項。

A：新生兒視力尚不成熟，視覺神經與對焦功能仍在發展，敘述正確，故非答案。

B：約 3～4 個月開始具備翻身能力，符合嬰兒早期大肌肉動作發展，故非答案。

C：新生兒雖肌肉張力仍在發展，但可透過吸吮反射進食，敘述正確，故非答案。

本題考點：嬰幼兒動作發展順序——判準是先發展大肌肉控制與整體動作，再發展手指等精細動作；看到抓握與夾物時，先確認手掌抓握在前、手指夾物在後。

第 3 題

關於語言發展互動論（interactionist approach）的觀點，下列何者錯誤？
  1. （A）語言發展的普遍性主要是導因於發展環境的相似性，而非來自先天的特定語言能力
  2. （B）不同的兒童導向的說話方式（child-directed speech）會影響語言的發展
  3. （C）在互動中向成人模仿語言技巧和內容是兒童學習語言的唯一途徑
  4. （D）父母的正向回饋及糾正，有助於語言的學習

答案：（C）

詳解與考點

正解：「唯一途徑」——互動論以先天傾向、兒童主動建構與環境互動共同解釋語言發展，判準是不能把任一學習機制絕對化。模仿成人的技巧與內容固然重要，卻不是唯一途徑，C 違反互動論觀點，故為錯誤選項。

A：互動論重視發展環境的相似性對語言普遍性的解釋，並非只以先天特定語言能力說明，敘述合理，故非答案。

B：成人以兒童為導向的說話方式不同，會影響兒童可獲得的語言互動與學習，故非答案。

D：父母的正向回饋與適當糾正可提供語言使用的互動訊息，有助語言學習，故非答案。

本題考點：語言發展互動論——判準是語言發展由兒童的主動性與先天傾向，和成人互動、回饋及環境共同形塑；將模仿或任何單一因素說成唯一來源即不符此取向。

第 4 題

有關新生兒對臉孔偏好的敘述，下列何者正確？
  1. （A）注視照片時，對閉上眼睛的臉孔偏好大過於睜開眼睛的臉孔
  2. （B）對成人普遍認為漂亮的臉孔，並沒有特殊偏好
  3. （C）以直立或倒置方向呈現臉孔刺激，並不會影響嬰兒的偏好
  4. （D）2～3個月以前，臉孔偏好決定於刺激是否在嬰兒的視域內移動

答案：（D）

詳解與考點

正解：「2～3 個月以前」——此年齡階段的新生兒臉孔偏好主要受可察覺的外在刺激特徵影響，判準是刺激是否在視域內移動。故 D 的敘述正確。

A：嬰兒對睜開眼睛的臉孔較有偏好，不是閉眼臉孔，故非答案。

B：嬰兒對成人普遍認為漂亮的臉孔具有偏好，說其沒有特殊偏好不正確，故非答案。

C：臉孔以直立或倒置呈現會影響嬰兒偏好，倒置並非沒有差異，故非答案。

本題考點：新生兒臉孔偏好——判準是區分早期外在知覺線索與後續臉孔內在特徵的影響；2～3 個月以前，刺激是否在視域內移動是重要條件。

第 5 題

關於兒童性別認識與認同的敘述，下列何者正確？
  1. （A）小芬知道自己不是男生就是女生，並且能標示自己是個女生，已進入性別不變階段
  2. （B）小明知道男孩會變成男人，女孩會變成女人，已進入性別不變階段
  3. （C）曉鈴知道自己穿男生衣服也不會變成男生，已進入性別標示階段
  4. （D）小華認為男性若扮演媽媽角色也不會隨情況與個人願望而變成女性，顯示他已進入性別不變階段

答案：（D）

詳解與考點

正解：「扮演媽媽角色也不會變成女性」——性別不變的判準是理解性別不會隨外觀、情境或個人願望改變。小華能作此判斷，正符合性別不變階段，故選 D。

A：知道自己是女生屬於能辨識並標示自身性別的性別標示階段，尚非性別不變階段，故非答案。

B：知道男孩會成為男人、女孩會成為女人，反映性別穩定的理解；但尚未顯示其理解外表改變不會改變性別，故非答案。

C：穿男生衣服不會變成男生，正是性別不變的理解，卻被說成性別標示階段，故非答案。A 與 C 都容易混淆，判斷關鍵在性別標示只會命名，性別不變則能排除衣著或角色造成的改變。

本題考點：Kohlberg 性別概念——判準依序是性別標示、性別穩定與性別不變；能理解衣著、角色、情境或意願不改變性別，才是性別不變。

第 6 題

關於兒童虐待的敘述，下列何者錯誤？
  1. （A）常生病的兒童與不成熟的兒童行為，容易成為家庭虐待的高風險族群
  2. （B）家庭環境為貧窮與社會孤立，以及父母本身曾經受虐，較可能助長兒童虐待的發生
  3. （C）相較於嬰幼兒與學齡前的兒童，學齡期兒童更容易受到家庭虐待
  4. （D）父母採用無效的教養方式，對兒童有不切實際的期待，較容易助長兒童虐待

答案：（C）

詳解與考點

正解：「相較於嬰幼兒與學齡前兒童」的比較方向——判準是年齡較小者依賴度高、自我保護與表達能力較弱，因此更易受家庭虐待。C 說學齡期兒童更容易受虐，顛倒了風險比較，故為錯誤選項。

A：常生病或行為較不成熟的兒童，可能增加照顧壓力而成為家庭虐待的高風險族群，故非答案。

B：貧窮、社會孤立與父母受虐經驗，皆可能增加家庭壓力或暴力代間傳遞風險，故非答案。

D：無效教養及對兒童抱持不切實際期待，會使衝突與不當處罰風險升高，故非答案。

本題考點：兒童虐待高風險因子——判準是辨識兒童的脆弱性、家庭壓力與照顧者教養因素；年齡愈小、依賴度愈高且自保能力愈弱者，風險通常愈高。

第 7 題

關於認知策略（cognitive strategies）發展的描述，下列何者最正確？
  1. （A）Siegler認為任何年齡的兒童都擁有多種策略，而且策略產生和使用的發展有固定的階段性
  2. （B）較年幼兒童受到產出缺陷（production deficiency）對認知作業的影響，是無法以任何教導方式改善的
  3. （C）年長的兒童所使用的策略未必會比年幼兒童更多而且更複雜，較佳的認知表現要依據認知策略對問題解決的適合程度而定
  4. （D）有些兒童儘管從教導之中可以學會比較好的認知策略，但因使用缺陷（utilization deficiency）的限制而無法自發地應用認知策略

答案：（C）

詳解與考點

正解：「策略對問題解決的適合程度」——Siegler 的策略發展觀點強調多種策略並存與競爭，判準不是年齡愈大就必然使用愈多、愈複雜的策略，而是策略是否適合當前作業。C 符合此觀點，故選 C。

A：兒童雖可同時擁有多種策略，但策略發展不是固定的階段性歷程；重疊波觀點正反對僵硬階段說，故非答案。

B：產出缺陷可透過教導與練習改善，並非無法以任何方式改善，故非答案。

D：使用缺陷是兒童能學會並使用較佳策略，卻未因使用而立即提升作業表現；選項所稱無法自發應用較接近產出缺陷，故非答案。

本題考點：Siegler 認知策略發展——判準是多策略可並存、策略選擇隨作業適配性而變；固定階段論與「年長必然更複雜」都不是其核心主張。

第 8 題

某國中發生男學生集體霸凌一位同學，在調查過程中，一位學生說：「其實我不認識那個被打的同學，但因為我的好朋友們都打他」，此位同學的說法，最符合青少年發展的那個特徵？
  1. （A）學生暴力事件與偏差行為以國中階段最為嚴重
  2. （B）青少年男生比女生有較多的攻擊行為
  3. （C）青少年的從眾行為是生活中常見的行為模式
  4. （D）青少年在尋求獨立時，更需要同儕的情緒支持

答案：（C）

詳解與考點

正解：「因為我的好朋友們都打他」且自己並不認識被害者——行為是追隨同儕群體，而非基於個人判斷，判準即為青少年常見的從眾行為，故選 C。

A：國中階段的暴力與偏差行為程度是整體發展現象的描述，無法直接解釋此學生因好友行動而跟隨，故非答案。

B：男生可能較常出現攻擊行為，但性別差異不能說明其特定的跟隨原因，故非答案。

D：青少年尋求獨立時需要同儕情緒支持是合理描述，但本題重點是模仿群體行為，而非尋求情緒支持，故非答案。它最易混淆，因兩者都涉及同儕；判斷關鍵在本例呈現的是行為一致性。

本題考點：青少年同儕影響——判準是若個體因同儕正在做某事而跟隨，核心為從眾；若重點是獲得安慰、認同或情感依靠，才較接近同儕情緒支持。

第 9 題

針對青少年自我認同的敘述，下列何者正確？
  1. （A）以文化期望為形象標準之認同，皆為正向認同
  2. （B）自我認同是隨著期望變化的一種動態歷程
  3. （C）自我認同是一間歇性的社會化歷程
  4. （D）與同儕的關係可取代與父母的親密度，所以其自我認同不受父母影響

答案：（B）

詳解與考點

正解：「隨著期望變化」——青少年自我認同不是一次完成的標籤，而會隨經驗、角色探索與承諾持續調整，判準是其是否為動態歷程。B 的敘述正確，故選 B。

A：依循文化期望形成的認同不必然正向，也可能缺少探索而呈現早閉型認同，故非答案。

C：自我認同是持續發展的社會化歷程，不是間歇性歷程，故非答案。

D：同儕關係雖重要，不能取代與父母的親密關係；父母仍會影響青少年自我認同，故非答案。

本題考點：青少年自我認同——判準是認同隨探索、承諾與社會關係持續調整；文化期待不必然形成正向認同，同儕影響也不會消除父母影響。

第 10 題

面對家中青少年的孩子，父母較佳的教養方式為下列何者？
  1. （A）高度接納和回應；低度的行為控制；高度的心理控制
  2. （B）高度接納和回應；高度的行為控制；低度的心理控制
  3. （C）高度接納和回應；低度的行為控制；低度的心理控制
  4. （D）低度接納和回應；高度的行為控制；高度的心理控制

答案：（B）

詳解與考點

正解：「較佳的教養方式」與三個向度——開明權威教養的判準是高接納與回應、以合理規範維持高行為控制，但不以罪惡感或情感操控進行心理控制。B 正是高接納和回應、高行為控制、低心理控制，故選 B。

A：高度心理控制會侵害青少年的自主與心理發展，即使有高接納也不是較佳組合，故非答案。

C：低心理控制正確，但低行為控制代表缺少合理規範；它最易被誤選，因為容易把所有控制都視為不佳，實際上應降低的是心理控制，而非必要的行為規範。

D：低接納和回應加上高度心理控制，不符合支持自主與溫暖回應的較佳教養原則，故非答案。

本題考點：Baumrind 教養類型——判準是區分行為控制與心理控制；較佳的開明權威方式保有清楚合理的行為規範，同時維持高回應與低心理控制。

第 11 題

性別角色社會化（gender-role socialization）對成人生涯的影響為何？
  1. （A）女性投入職場後，其在家庭中的角色與期望隨之減少
  2. （B）男性在職業抉擇，較傾向於高支持性的環境
  3. （C）雙薪家庭最大的家庭困境是老人及幼童的照顧問題
  4. （D）男女對職業成功相關技能有相同的期望

答案：（C）

詳解與考點

正解：性別角色社會化對「成人生涯」的影響——家庭與職場中的性別角色期待會影響照顧責任分配，判準是雙薪家庭最突出的結構性壓力。老人及幼童照顧常成為雙薪家庭的主要困境，故選 C。

A：女性投入職場後，家庭中的角色與期待未必減少，反而常面臨職場與家庭的雙重負擔，故非答案。

B：男性職業抉擇不以高支持性環境為主要傾向，敘述不符合一般性別角色社會化的描述，故非答案。

D：男女對職業成功相關技能的期待未必相同，性別角色社會化可能造成不同的期待與機會，故非答案。

本題考點：性別角色社會化與成人生涯——判準是辨認性別期待如何延續到職場選擇與家庭照顧分工；雙薪不等於家庭角色消失，老幼照顧常是重要壓力來源。

第 12 題

關於創造生命末期最後的劇本（final scenario）的定義，下列敘述何者正確？
  1. （A）重新敘說個人生命故事並將之編寫為劇本
  2. （B）發揮個人創意編寫劇本並獲得演出機會
  3. （C）對自己生命末期與死後的安排做出選擇
  4. （D）家屬為即將過世或已過世的家人敘寫其生平故事

答案：（C）

詳解與考點

正解：final scenario（最後劇本）中的「生命末期與死後」——此概念的判準是由本人預先對臨終醫療、後事與告別等安排做出選擇。C 說明個人對生命末期與死後安排的自主選擇，故正確。

A：重新敘說生命故事是生命回顧或敘事工作，不等同於最後劇本，故非答案。

B：以創意編寫並演出劇本，著重藝術創作，未涉及個人臨終與死後安排，故非答案。

D：家屬為親人敘寫生平故事屬追憶或紀念，最後劇本的主體則是當事人本人，故非答案。A 與 D 都像是在處理生命故事，最易混淆；分辨關鍵在最後劇本處理的是本人對未來臨終與身後事的安排。

  4. （D）對事件記憶和反應比年輕時退化

  2. （B）要求特徵（demand characteristics）
  3. （C）反應心向（response style）
  4. （D）霍桑效應（Hawthorne effect）

正解：「隱微線索」使受試者猜到實驗者假設，並以行動證明它。這正是要求特徵（demand characteristics）：受試者從情境線索推測研究目的後調整反應，故選 B。

C：自我效能指個體相信自己能完成特定任務的能力信念，本題未在評估能力信念。

  2. （B）基於自我辯護概念，應給予孩子少量的獎賞，較能帶來長久的行為改變
  3. （C）基於過度辯護效應，只要發現孩子有興趣想去做一個好行為，就應該要趕快給予獎賞，以免錯失良機
  4. （D）基於過度辯護效應，宜使用任務為條件而非表現為條件的方式來獎賞孩子

答案：（B）

詳解與考點

正解：以獎賞促進好行為時，詢問的是「最為適當」且涉及長久改變。少量外在獎賞較不會削弱內在動機，並可透過自我辯護帶來較持久的態度改變，故選 B。

C：過度辯護效應指出過多外在獎賞可能削弱原有內在動機；它看起來像及時鼓勵，錯在忽略孩子本已有興趣時加上獎賞可能造成反效果。

D：以任務為條件而非表現為條件的獎賞，未能避免過度辯護效應的核心問題，故非最適當建議。

本題考點：自我辯護與過度辯護效應——判準是少量外在理由較可能促成內化，過多或不必要的外在獎賞則可能削弱內在動機；獎賞撤除後也須考慮行為維持。

第 32 題

  2. （B）③④②①
  3. （C）④③②①
  4. （D）④③①②

答案：（D）

詳解與考點

正解：出醜效應（pratfall effect）對能力與小錯的交互作用。能力優異者犯小錯反而最討喜，能力平庸者犯錯則更不討喜；由最不受歡迎到最受歡迎依序為④能力平庸但犯小錯、③能力平庸、①能力優異、②能力優異但犯小錯，故選 D。

B：將②排在①之前，忽略能力優異者犯小錯反而更討喜。

C：雖正確將④置於最前，卻將②與①的相對順序顛倒。

本題考點：出醜效應——判準是小錯對能力優異者可增加親近感，對能力平庸者則降低吸引力；排序時先區分能力水準，再判斷犯錯的方向。

  3. （C）基本歸因謬誤
  4. （D）公開順從與私下接納

答案：（A）

詳解與考點

正解：受試者原本能正確判斷，卻在團體一致作答時公開改答。Asch 線段實驗顯示，受試者為避免與多數人不一致而產生公開順從，但未必在私下真正接受該錯誤判斷，故選 A。

B：訊息式影響發生於個人把他人當作正確資訊來源；本題線段答案明確，受試者主要承受的是多數壓力，屬規範性影響。

C：基本歸因謬誤是過度以人格特質解釋他人行為、低估情境影響，與從眾實驗的結果不同。

D：公開順從與私下接納表示真正內化群體觀點，是最強誘答；但 Asch 的結果重點是外在附和，不能據此推定私下判斷已改變。

本題考點：Asch 從眾實驗——判準是「公開附和是否源於避免群體排斥，且私下是否真正改變信念」；規範性影響可造成公開順從，未必造成私下接納。
