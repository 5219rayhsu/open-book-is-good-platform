第 1 題

國一的阿華在父母離異後，由父親取得監護權，但經常遭受父親的身體暴力對待，在無法委託代理人的情況下，依據家庭暴力防治法的規定，下列何者無法代替阿華向法院聲請通常保護令或暫時保護令？
  1. （A）阿華的媽媽
  2. （B）阿華的姑姑
  3. （C）阿華的姨丈
  4. （D）阿華的諮商心理師

答案：（D）

詳解與考點

考點為家庭暴力防治法第10條保護令聲請人資格。被害人為未成年人、身心障礙者或難委任代理人時，其法定代理人、三親等以內之血親或姻親，及檢警、主管機關得代為聲請；諮商心理師不在法定聲請人之列，故選 D。陷阱在 A、B、C：媽媽、姑姑、姨丈均屬三親等以內血親或姻親，具聲請資格，非答案。

第 2 題

諮商心理師在進行危機處理的班級輔導時，下列何者最不適切？
  1. （A）協助學生瞭解災難事件，讓學生談論受災經驗，表達害怕與憂慮
  2. （B）進行非結構團體，依照團體成員的需求來調整時間與架構
  3. （C）辨識創傷後壓力症候群學生
  4. （D）介紹災害防治相關資源

答案：（B）

詳解與考點

考點為危機事件班級輔導。危機處理宜採結構化、明確架構以提供安全感，B 採「非結構團體、依需求隨時調整」最不適切，故選 B。陷阱在 A：協助談論受災經驗、表達情緒是危機輔導常見且適當作法，非答案。

第 3 題

關於諮商專業保密，下列敘述何者正確？
  1. （A）不論在任何場域任職的諮商心理師，都應該做到同樣的保密程度
  2. （B）依據刑事訴訟法第182條，諮商心理師享有溝通特權（privileged communication）
  3. （C）依據刑法316條，諮商心理師不得無故洩漏因業務知悉或持有之他人秘密
  4. （D）即使個案願意放棄特權溝通，諮商心理師也應堅持溝通特權

答案：（C）

詳解與考點

考點為保密的法律依據。刑法第 316 條規定醫事人員等不得無故洩漏業務上知悉之他人秘密，諮商心理師適用，故選 C 正確。陷阱在 D：個案有權放棄溝通特權，此時心理師應尊重而非堅持特權，敘述錯誤。

第 4 題

個案在諮商晤談中提及下列那一種情況，諮商心理師須立即進行預警或通報？
  1. （A）林美美十分憤怒先生外遇在先，現在又提出離婚訴訟，她揚言要殺了先生
  2. （B）小凱對於一再嘲笑他的同學非常生氣，他在書包放了一把水果刀，準備下課時給他們一點顏色瞧瞧
  3. （C）小志今天數學又考不及格，他非常難過與無助，覺得自己不管再怎麼努力都沒有用，不如死了算了
  4. （D）小堅對於自己被傳染上AIDS憤恨不已，他咒罵那個傳染給他的人

答案：（B）

詳解與考點

考點為預警／通報義務（傷害他人之危險）。B 中小凱已備刀、有明確對象與行動計畫，構成對特定第三人的立即危險，須立即預警通報，故選 B。陷阱在 A：揚言殺夫雖具敵意，但屬情緒性威脅，急迫性與具體計畫不及 B。

第 5 題

不同專業組織的倫理守則雖然有差異，但是有一些共同的主題。下列何者不包括在這些共同主題之中？
  1. （A）促進消費者的福祉
  2. （B）避免剝削
  3. （C）通報的相關規定
  4. （D）維護個案的隱私權

答案：（C）

詳解與考點

考點為各專業倫理守則的共同主題，包括促進案主福祉、避免剝削、維護隱私等。選 C「通報的相關規定」屬各國各法規差異大，非共通主題，故選 C 不包括。把握度 low，屬比較性細節判斷。

第 6 題

從多元文化觀點來思考諮商心理師的倫理責任，下列敘述何者最適切？
  1. （A）諮商心理師必須對自己的文化假設有所覺察，和個案一起討論如何進行諮商
  2. （B）諮商心理師必須讓自己有能力對所有文化背景的個案進行諮商
  3. （C）遇到和自己文化背景不同的個案，就要進行轉介，以免傷害個案
  4. （D）諮商心理師必須發展出適用於所有文化背景個案的介入技巧

答案：（A）

詳解與考點

考點為多元文化諮商倫理。核心是覺察自身文化假設，並與個案合作討論諮商進行方式，故選 A。陷阱在 B：要求對「所有」文化背景都有能力並不切實際；C 一律轉介、D 發展通用技巧，皆違反文化謙遜與個別化原則。

第 7 題

關於轉介的作法，下列敘述何者最適切？
  1. （A）將轉介視為最後的處遇方式，在轉介之前要儘量溝通與努力
  2. （B）為個案福祉著想，只要遇到超過自己專業能力的案例就進行轉介
  3. （C）經過諮商心理師的評估與判斷，認為轉介對個案較好就進行轉介
  4. （D）個案要求轉介，要尊重其意願立刻進行轉介

答案：（A）

詳解與考點

考點為轉介倫理。轉介應視為最後手段，之前須盡力溝通與努力以維護諮商關係連續性，故選 A 最適切。陷阱在 D：個案一要求就立刻轉介，未經評估即放棄，未必符合個案最佳利益，過於被動。

第 8 題

關於通訊諮商方式的敘述，下列那一項最不適切？
  1. （A）個案要求通訊諮商，諮商心理師應先進行評估，再決定是否適合進行通訊諮商服務
  2. （B）線上服務的諮商心理師，必須先接受相關的技術訓練，具有足夠的通訊諮商能力，才能提供線上服務
  3. （C）在通訊諮商期間，可穿插安排一些實體晤談，並可用網際網路來協助個案家庭作業的進行
  4. （D）通訊諮商未必能夠有效解決個案個人的深層問題與人際議題，故生涯諮商較難派上用場

答案：（D）

詳解與考點

考點為通訊（線上）諮商倫理。題目找最不適切。D 稱生涯諮商較難用於通訊諮商，並無依據，生涯議題反而適合線上進行，故選 D。陷阱在 A：先評估個案是否適合通訊諮商，是正確的事前把關，非答案。

第 9 題

關於使用測驗的倫理考量，下列敘述何者錯誤？
  1. （A）諮商心理師對測驗目的及結果充分了解
  2. （B）諮商心理師對選擇測驗的理由，能清楚陳述
  3. （C）諮商心理師必須與個案探討測驗結果對個案的意義
  4. （D）諮商心理師相信任何測驗對個案，都是有用的

答案：（D）

詳解與考點

考點為測驗使用倫理。題目找錯誤。D 稱「相信任何測驗對個案都有用」過度概化，違反審慎選擇與限制覺察原則，故選 D。陷阱在 C：與個案探討測驗結果的意義是正確倫理作法，非答案。

第 10 題

諮商與心理治療的紀錄常包含S（subjective）、O（objective）、A（assessment）及P（planning）等四項，下列何項紀錄是O所含括的內容？
  1. （A）個案眼中泛著淚光，但精神狀況比上週好，且略施薄妝
  2. （B）個案表示因與男友分手，引發極度的人際不安全感
  3. （C）提供穩定與支持的諮商關係，並引導個案看見自己的人際資源
  4. （D）個案自陳最近飲食及睡眠狀況已有改善，對學校生活也逐漸適應

答案：（A）

詳解與考點

考點為 SOAP 紀錄。O（客觀）指治療師可觀察的外顯行為與徵象，「泛淚、精神狀況、施薄妝」屬可觀察客觀資料，故選 A。陷阱在 B、D：個案自陳分手感受、飲食睡眠改善屬主觀（S）；C 是治療計畫（P）。

第 11 題

關於辯證式行為療法（dialectical behavior therapy），下列敘述何者錯誤？
  1. （A）是對於邊緣型人格有效的治療方法
  2. （B）優先處理個案干擾治療行為，再處理危險行為
  3. （C）採用正念（mindfulness）技巧
  4. （D）辯證（dialectical persuasion）是在兩個極端之間，找到一個解決方法

答案：（B）

詳解與考點

考點為辯證行為治療（DBT）的處理階段。題目找錯誤。DBT 第一階段優先處理「危及生命行為」，其次才是干擾治療行為，B 把順序顛倒，故選 B。陷阱在 D：辯證指在兩極端間求綜合解，敘述正確，非答案。

第 12 題

相較於新手諮商心理師，資深諮商心理師比較容易擔心出現下列何種情況？
  1. （A）被個案拒絕
  2. （B）疏忽諮商倫理
  3. （C）個案流失或不再續約
  4. （D）專業成長停滯

答案：（D）

詳解與考點

考點為新手與資深諮商師的關注差異。新手多擔心被拒、技巧、倫理疏漏；資深者經驗成熟後，較易擔心專業成長停滯與耗竭，故選 D。陷阱在 A 被個案拒絕：那是新手較典型的焦慮，非資深者主要擔憂。

第 13 題

思敏的父親是大學教授，哥哥是物理博士，妹妹是臺大法律系碩士班的書卷獎得主，從小家中只有她在讀書方面的表現是最讓父母擔心的，這狀況剛好與諮商心理師的狀況雷同。下列何種作法，對諮商心理師的專業成長最沒有幫助？
  1. （A）諮商心理師應在諮商時多列舉與思敏的雷同點，讓諮商心理師在後續諮商時可分享更多因應技巧
  2. （B）諮商心理師應警覺自己在與思敏諮商時與其他諮商狀況的不同，並探求差異的可能原因
  3. （C）諮商心理師應在督導時提出討論，以了解這種相似性是否已阻礙其聽到思敏的真正問題
  4. （D）諮商心理師需重聽與思敏的諮商錄音帶，以了解諮商的內容是思敏的需求或是諮商心理師的需求

答案：（A）

詳解與考點

考點為反移情與自我覺察。題目找最沒幫助。A 要心理師「多列舉雷同點、分享更多因應技巧」會強化過度認同與反移情，妨礙專業，故選 A。陷阱在 B、C、D：覺察差異、督導討論、重聽錄音皆有助處理反移情，非答案。

第 14 題

下列何者不是諮商心理師應關注的事項？
  1. （A）諮商心理師應有內在一致的理論基礎
  2. （B）諮商心理師應注意個案在諮商過程中的經驗
  3. （C）諮商心理師應注意不要造成對個案的傷害
  4. （D）個案在求助之前都應該具體知道自己的問題是什麼，否則不利治療的進行

答案：（D）

詳解與考點

考點為諮商基本態度。題目找非應關注事項。D 要求個案求助前須「具體知道自己問題」並非前提，協助澄清問題本就是諮商任務，故選 D。陷阱在 B：注意個案歷程中的經驗是核心關注，敘述正確，非答案。

第 15 題

關於諮商歷程中的移情與反移情，下列何者最容易對晤談效能造成負面影響？
  1. （A）諮商心理師挑起的移情（therapist-induced transference）
  2. （B）諮商心理師挑起的反移情（therapist-induced countertransference）
  3. （C）個案挑起的移情（client-induced transference）
  4. （D）個案挑起的反移情（client-induced countertransference）

答案：（B）

詳解與考點

考點為移情與反移情對效能的影響。由治療師自身議題挑起的反移情最易扭曲判斷、傷害晤談效能，故選 B。陷阱在 C 個案挑起的移情：那是治療常見且可運用的素材，相對而言負面影響不如治療師反移情。

第 16 題

某諮商心理師預期將結束與某機構合作，須安排個案事宜，下列作法何者最不適當？
  1. （A）召開轉案會議，將個案的資料提供給即將接手的諮商心理師
  2. （B）剩下一次諮商時告知個案，以免個案對諮商結束過度焦慮和抗拒
  3. （C）向個案強調新諮商心理師的優點和能力，以賦能新的諮商心理師
  4. （D）提供至少三個機構內或外的相關訊息，讓個案有機會選擇適合的諮商心理師

答案：（B）

詳解與考點

考點為結束與轉案的倫理。題目找最不適當。B「剩最後一次才告知」未給足夠時間處理結束情緒，違反妥善結案原則，故選 B。陷阱在 A 召開轉案會議：經同意提供資料給接手者以利連續性，屬適當作法，非答案。

第 17 題

某諮商心理師跟一個患有憂鬱症子女的家庭進行初次晤談，下列諮商心理師的敘述何者最不適當？
  1. （A）關於孩子的憂鬱情緒，之前曾接受過其他諮商嗎？效果如何？
  2. （B）接下來有那些家人會來接受諮商呢？
  3. （C）我定期會向一位督導諮詢，這裡有一份錄影同意書，請你們每一位在同意書上簽名
  4. （D）我要求你們在諮商中做的練習，每一個人都必須參與

答案：（D）

詳解與考點

考點為家族治療初次晤談的適切性。題目找最不適當。D「要求每個人都必須參與練習」過於強制、未尊重自主，故選 D。陷阱在 C 簽錄影同意書：告知督導並取得知情同意是正確倫理程序，非答案。

第 18 題

關於立即性技巧，下列敘述何者正確？
  1. （A）對於來自較保守與注重隱私家庭的個案，不宜使用立即性技巧
  2. （B）這是一種後設溝通，諮商心理師要小心平衡對個案的挑戰與支持
  3. （C）諮商心理師與個案討論諮商關係，並且建議個案調整互動方式
  4. （D）強調個案的行為對他人的影響，並請其承擔起對引發諮商心理師感受的責任

答案：（B）

詳解與考點

考點為立即性技巧。立即性是針對當下諮商關係的後設溝通，須在挑戰與支持間取得平衡，故選 B。陷阱在 D：把感受責任歸咎個案、要其承擔「引發治療師感受的責任」是誤用，立即性重在揭露此時此刻而非責備。

第 19 題

個案在晤談中自顧自地述說其生活經歷或目前的困境。下列關於此類喋喋不休個案之敘述或處遇方式，何者最不正確？
  1. （A）個案的喋喋不休有時是一種防衛方式，藉此將諮商心理師維持在一段安全的距離之外
  2. （B）喋喋不休的談話形式是一種陳述，非情感或認知行為的探索，較難帶來治療性改變
  3. （C）諮商心理師若直接打斷個案的敘述，可能會妨礙治療關係，並讓個案覺得自己做錯了某些事
  4. （D）諮商心理師謹慎地干涉、打斷個案說話，先同理個案在溝通上的困難，進而採用立即性技術指出個案的防衛是有效的處遇

答案：（D）

詳解與考點

本題問對「喋喋不休個案」之敘述或處遇「最不正確」者，官方答案為 (D)。(D) 把「謹慎干涉、打斷個案，先同理其溝通困難，再以立即性技術直接指出個案的防衛」一概斷定為「有效的處遇」，說法過於武斷。即便先行同理，過早、直接地向個案點出其「防衛」仍有風險：可能讓個案感到被貼標籤、被責備或不被理解，反而強化防衛、傷害治療關係；是否揭露防衛應視關係穩固程度與時機審慎為之，不宜被通則化為「有效」，故 (D) 最不正確、為正解。其餘皆為適切的理解：(A) 正確，喋喋不休常是一種防衛，藉此把諮商師維持在安全距離外；(B) 正確，純陳述式的滔滔不絕缺乏情感或認知的深度探索，較難帶來治療性改變；(C) 正確，直接打斷確實可能妨礙關係、讓個案覺得自己做錯事，故須謹慎。

第 24 題

第 25 題

  2. （B）「積極不確定論」係以直覺、開放的心靈來抉擇生涯；「個人主義論」強調生涯抉擇歷程的複雜性與獨特性

  4. （D）「因素刪除法」是以「預期效用論」為精神所發展出來的生涯抉擇模式，以電腦輔助生涯輔導系統為工具

詳解與考點

考點為性侵創傷倖存者的工作焦點。正解 D：認可個案的性創傷經驗、協助其找回主控權（empowerment），是創傷處遇的核心。陷阱是 A 協助忘卻、B 體諒父母無奈、C 原諒家人，皆變相否定創傷或要求個案承擔修復責任，反而二度傷害。

第 37 題

關於遭受性虐待或創傷兒童，下列敘述何者最不適切？
  1. （A）受虐兒童常因內在混亂而出現各種不適應行為，如以暴食來滋養自己
  2. （B）受虐兒童常因無法理解那些難以承受的情緒而依賴不健康的防衛方式，如以解離來保護他們免於經驗到痛苦
  3. （C）受虐兒童常有失控及無力感，自我感經常是殘缺且破碎的
  4. （D）受虐兒童之前的祕密關係使他們成為受害者，諮商心理師象徵「拯救者」，因此較易發展出信任的諮商關係

答案：（D）

詳解與考點

考點為受虐／創傷兒童的諮商關係。題問「最不適切」，正解 D：受虐兒因過往被信任者背叛，對「拯救者」式諮商師往往更難建立信任，而非「較易」。A、B、C 正確描述受虐兒的暴食、解離防衛與破碎自我感。陷阱是直覺以為救助者角色能快速贏得信任。

第 38 題

關於犯罪被害人創傷的敘述，下列何者錯誤？
  1. （A）犯罪被害人及其家屬易呈現生理病痛
  2. （B）倖存者能將創傷經驗轉換為內在力量
  3. （C）被害人大多數傾向尋求專業協助
  4. （D）協助目標之一是能與創傷經驗共存，仍保有自主性

答案：（C）

詳解與考點

考點為犯罪被害人創傷反應。題問「錯誤」，正解 C：被害人「大多數傾向尋求專業協助」與實況不符，多數被害人因羞愧、不信任等因素並不主動求助。A、B、D 正確描述生理病痛、創傷後成長與共存目標。陷阱是高估被害人主動求助的比例。

第 39 題

關於困難或不正常悲傷的反應，下列敘述何者最適切？
  1. （A）通常個案無法意識到自己尚未走過悲傷，因此慢性化悲傷反應不易被發現或診斷出來
  2. （B）個案在父親往生後發展出恐慌反應與焦慮性疾患，可推測個案的問題是偽裝的悲傷反應
  3. （C）相對於過往的失落事件，個案對目前經驗之悲傷事件反應程度明顯過多過強，可推測此為過往失落事件延宕的悲傷反應
  4. （D）個案的先生在發現胃癌三個月後去世，個案在先生隔年的忌日當天開始胃痛，可推測個案正經驗誇大的悲傷反應

答案：（C）

詳解與考點

考點為困難／複雜性悲傷的型態辨識（延宕、慢性、誇大、偽裝）。正解 C：對當前失落的反應明顯過強過多，反映的是「過往未竟失落的延宕悲傷」被觸發。陷阱是 D，忌日當天身體出現亡者症狀屬「偽裝性／週年反應」，並非「誇大」反應，類別配對錯誤。

第 40 題

一位男跨女的跨性別者，因穿著女裝被公司解僱而尋求諮商。下列諮商心理師的處遇何者最不適切？
  1. （A）可以與律師和工會形成合作同盟，向公司主張個案享有職場性別平等待遇的權利
  2. （B）與反性別歧視團體合作，喚起社會大眾對性別歧視此議題的意識
  3. （C）進行法案遊說，倡議性別工作平等法的修法
  4. （D）與公司人資部門協商，提出讓個案持續接受諮商以降低穿女裝頻率為條件，讓個案保有工作

答案：（D）

詳解與考點

本題問對男跨女跨性別個案（因穿女裝被解僱）「最不適切」的處遇，官方答案為 (D)。(D) 與人資協商，以「個案持續接受諮商以降低穿女裝頻率」為保住工作的條件，等於把個案的性別表達當成問題加以矯正、配合歧視性的職場要求，違反尊重個案自主與多元性別認同、不歧視的倫理精神，故最不適切、為正解。其餘屬適切的倡議與系統性協助：(A) 正確，與律師、工會結盟，主張個案的職場性別平等待遇與權利；(B) 正確，與反歧視團體合作，提升社會大眾對性別歧視議題的意識；(C) 正確，進行法案遊說、倡議修法以保障性別工作平等。（註：相關法規現行名稱為《性別平等工作法》，民國 112 年由原《性別工作平等法》修正更名。）
