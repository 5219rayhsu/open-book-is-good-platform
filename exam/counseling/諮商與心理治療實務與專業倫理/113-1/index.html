第 1 題

當諮商心理師與個案發生性關係時，會造成有意義的治療關係終止，違反下列那項倫理準則？
  1. （A）自主權
  2. （B）受益權
  3. （C）免受傷害權
  4. （D）公正權

答案：（B）

詳解與考點

本題問諮商師與個案發生性關係、造成有意義治療關係終止，違反哪項倫理原則，官方答案為 (B) 受益權。倫理四（五）大原則中，受益（beneficence）要求專業人員應促進個案的福祉與最佳利益。題幹特別強調此舉「造成有意義的治療關係終止」，亦即剝奪了個案本應從治療中獲得的助益、未能促進其福祉，核心落在違反「受益權」，故選 (B)。其餘原則雖亦相關但非本題官方取向：(A) 自主（autonomy）強調尊重個案自主決定；(C) 免受傷害（nonmaleficence，勿傷害）著重不對個案造成傷害；(D) 公正（justice）指公平對待。性關係固然也涉及傷害個案，但依題幹「致使治療關係終止、無法獲益」的指向，官方答案定在受益權 (B)。

第 2 題

在心理諮商所從事自費心理諮商業務，關於收費與付費，下列作法何者最明顯違反諮商專業倫理？
  1. （A）提供社會局委託方案固定次數的諮商後，與個案討論後續各種諮商管道
  2. （B）對學生個案給予收費的折扣
  3. （C）轉介個案給精神科診所收取轉介費
  4. （D）在初次晤談告知個案收費標準與付費方式

答案：（C）

詳解與考點

考點為收費的專業倫理，問「最明顯違反」。向轉介對象收取「轉介費」屬利益分贓、利益衝突，明顯違反倫理，故 C 為答案。陷阱在 B 給折扣：合理彈性收費可被接受，並非違反，易被誤當問題作法。

第 3 題

有位因為人際議題尋求諮商的個案，將每次與諮商心理師晤談情形以小說形式在網路社群公開，引起相關人不滿並批評諮商心理師專業能力。諮商心理師知悉此事之後，下列處理方式何者最不適切？
  1. （A）尊重個案自主權利，不做任何聲明
  2. （B）個案已公開隱私，可以就個人專業責任做聲明澄清
  3. （C）為維護專業責任應結束諮商關係，要求個案聲明澄清
  4. （D）免受傷害，應蒐集證據向網友提告

答案：（D）

詳解與考點

考點為個案公開隱私後的專業倫理處理，問「最不適切」。蒐證向網友提告（D）將諮商師置於對立攻擊位置、逾越專業角色，最不適切故為答案。陷阱在 C 結束關係看似激烈，但 D 主動興訟更明顯失當。

第 4 題

個案在晤談時不滿意諮商心理師對其面質而憤怒丟擲文具，未造成諮商心理師受傷，下列諮商心理師的作法何者最適當？
  1. （A）向個案道歉並請息怒
  2. （B）請個案冷靜並轉移話題
  3. （C）告知個案這是危險行為，可能會通報求援
  4. （D）視而不見，以避免破壞諮商關係

答案：（C）

詳解與考點

考點為晤談中危機行為的處理。個案丟擲文具屬危險行為，告知這是危險行為並說明可能通報求援，兼顧界限與安全，最適當故 C。陷阱在 D 視而不見：忽視危險行為反失專業責任，A 道歉則錯置責任歸屬。

第 5 題

關於諮商心理師的執業疏失與風險管理，下列敘述何者正確？
  1. （A）當諮商心理師長期選擇在速食店執業則容易有發生執業疏失的風險
  2. （B）當諮商心理師被申訴違反專業倫理時，受理單位為衛生局
  3. （C）當諮商心理師被檢舉違反心理師法時，受理單位是諮商心理師公會全國聯合會
  4. （D）當諮商心理師違反心理師法可能受到的裁罰方式包括申誡、接受繼續教育等

答案：（A）

詳解與考點

本題敘述判斷較冷僻，僅就概念方向作答。依《心理師法》，申訴受理、裁罰種類等實務細節需查法條核對；標準答案標示 A，方向涉及執業場域不符規範易增疏失風險。其餘選項涉及受理單位與裁罰類別之精確認定，把握度較低。

第 6 題

關於心理測驗受測者的權利，下列敘述何者錯誤？
  1. （A）有權利獲得關於測驗內容、風險、益處等資訊
  2. （B）在諮商心理師說明後，有權利拒絕接受測驗
  3. （C）如果當次諮商未做完測驗，有權利要求把測驗題本帶回家做
  4. （D）有權利要求諮商心理師提供關於測驗結果的詳細回饋，包括完整的報告

答案：（C）

詳解與考點

考點為心理測驗受測者權利，問「錯誤」。為維護測驗保密性與效度，受測者無權把題本帶回家做，C 違反測驗安全故為答案。陷阱在 A、B、D 談知情、拒測、獲得結果回饋皆屬正當權利，反易被誤判。

第 7 題

知後同意有三個主要構成法律層面基礎的成分，下列何者不包括在內？
  1. （A）告知時機
  2. （B）行為能力
  3. （C）對訊息的瞭解
  4. （D）自願性

答案：（A）

詳解與考點

考點為知後同意的法律三要件，問「不包括」。構成要件為行為能力、對訊息的瞭解、自願性；「告知時機」非法律基礎成分，故 A 為答案。陷阱在易把實務上的「時機」誤當必要法律要件而選錯。

第 8 題

某位諮商心理師剛與結婚14年的先生辦完離婚手續，此時剛好被派案與婚姻議題的個案進行諮商。下列何種作法最不適切？
  1. （A）諮商心理師發現自己與個案非常有話聊，於是盡情的分享離婚後的心情，也鼓勵個案勇敢走出婚姻
  2. （B）諮商心理師宜帶著戒慎的心情接案，並於接案後重聽錄音帶，以免將自己的問題帶入個案的問題中
  3. （C）諮商心理師此時應勇敢告訴派案的主管，自己剛離婚目前可能還不宜接受相似問題的個案
  4. （D）諮商心理師宜尋求督導或諮商的協助，以幫助自己了解離婚對自己專業所造成的影響

答案：（A）

詳解與考點

考點為個人議題與專業界限，問「最不適切」。剛離婚就向個案盡情傾訴自身心情並鼓吹其離婚（A），是不當自我揭露與價值強加，最不適切故為答案。陷阱在 B、C、D 皆屬自我覺察與尋求督導的負責作法。

第 9 題

依心理師法規定，諮商心理師製作個案紀錄時，應載明之內容不包含下列何項？
  1. （A）姓名
  2. （B）國民身分證統一編號
  3. （C）出生年月日
  4. （D）家長／法定代理人

答案：（D）

詳解與考點

考點為《心理師法》個案紀錄應載明事項，問「不包含」。紀錄須載姓名、身分證號、出生年月日等基本資料；「家長／法定代理人」非法定必載項目，故 D 為答案。陷阱在直覺認為未成年須記代理人，但法條未列入。

第 10 題

根據兒童及少年福利與權益保障法規定，醫事人員、社會工作人員、教育人員、保育人員、警察、司法人員及其他執行兒童及少年福利業務人員，知悉兒童及少年有被虐待的情事者，應立即向直轄市、縣（市）主管機關通報，至遲不得超過多少小時？
  1. （A）72小時
  2. （B）48小時
  3. （C）36小時
  4. （D）24小時

答案：（D）

詳解與考點

考點為《兒少福利與權益保障法》的通報時限。知悉兒少受虐應立即通報，至遲不得超過 24 小時，故 D 正確。陷阱在 B 48 小時：那是社政後續調查相關時程，責任通報的法定上限是 24 小時，易混淆。

第 11 題

關於諮商心理師的反移情現象，下列敘述何者最不適當？
  1. （A）過度保護個案
  2. （B）渴望獲得個案的肯定
  3. （C）常常提供個案建議
  4. （D）與個案發展清楚的心理界限

答案：（D）

詳解與考點

考點為反移情現象，問「最不適當」。過度保護、渴望肯定、頻給建議皆屬反移情徵兆；「發展清楚的心理界限」是健康專業表現而非反移情，故 D 為答案。陷阱在誤把正向的界限維持當成反移情。

第 12 題

關於諮商心理師容易出現的工作耗竭，下列敘述何者錯誤？
  1. （A）在工作中遇到重要的價值觀衝突易導致工作耗竭
  2. （B）低落的工作士氣是工作耗竭的表徵之一
  3. （C）即使已經精疲力竭，仍然應該盡力完成諮商工作
  4. （D）長期為個案提供心理撫慰與支持，導致冷漠與同理心疲乏現象

答案：（C）

詳解與考點

考點為諮商師工作耗竭，問「錯誤」。已精疲力竭仍硬撐完成工作（C）會加劇耗竭、危及個案福祉，違反自我照顧原則故為答案。陷阱在 A、B、D 談價值衝突、士氣低落、同理疲乏皆為耗竭正確敘述。

第 13 題

下列何種說法最貼近Gerig（2007）所提有關近代的諮商領域對於處理人類靈性層面議題的看法？
  1. （A）神的議題對於諮商而言太龐大，應該把祂排除在諮商室外
  2. （B）諮商心理師不可能對靈性議題置之不理，故應至少接受一種宗教信仰
  3. （C）諮商心理師需對靈性和宗教內容或程序如何影響個案，具備一定的敏感度
  4. （D）宗教的本質是相通的，諮商心理師需找到信仰的本質，才能一體適用於不同的宗教信仰上

答案：（C）

詳解與考點

考點為 Gerig（2007）對諮商中靈性議題的看法。現代主張諮商師應對靈性與宗教如何影響個案具備敏感度，故 C 正確。陷阱在 B 要求接受某一宗教、D 找共通本質一體適用，皆過度或失當，易誤選。

第 14 題

個案的父母長期忽視其成就，每當其自我炫耀時則斥責之，因此將別人對他的肯定都視為嘲笑。當個案告知諮商心理師最近職位升遷時，下列諮商心理師的那個回應最可協助個案獲取矯正性情緒經驗？
  1. （A）哇，太好了！很高興你能跟我分享你的工作成就，我看到你在工作上的努力，你自己又是怎樣看待自己的努力呢？
  2. （B）哇，太棒了！你的老闆真的看到你的能力了。你想未來還可以做什麼讓自己的表現更耀眼來博取父母的賞識？
  3. （C）哇，太好了！你的老闆真的很賞識你！那為何你的家人這麼吝嗇讚賞你呢？真不明白他們對你的期待怎麼會如此高呢？
  4. （D）哇，真是恭喜你！我實在為你感到驕傲，只要持續努力一定會更上一層樓！

答案：（A）

詳解與考點

考點為矯正性情緒經驗。個案習慣把肯定視為嘲笑，諮商師以真誠肯定並邀其自我評價（A），提供與父母不同的新關係經驗，最能矯正，故 A。陷阱在 B、C 提父母期待或博取賞識，反強化舊有負向框架。

第 15 題

採用「對抗攻擊」人際因應策略的個案，在晤談中對諮商心理師的問話不耐煩且大聲質疑其專業度。諮商心理師回應：「我很好奇你是否注意到此刻你的聲音很大，感覺你很生氣。平常當你這樣對其他人說話時，他們是如何回應你？」上述諮商心理師的回應，下列敘述何者不正確？
  1. （A）可避免諮商心理師的反移情
  2. （B）諮商心理師正在進行人際歷程評論
  3. （C）諮商心理師協助個案聚焦個人情緒與人際模式
  4. （D）諮商心理師正在重演個案生活中的人際互動模式

答案：（D）

詳解與考點

考點為人際歷程取向的歷程評論，問「不正確」。諮商師當下指出個案語氣與情緒、連結其人際模式，是在「評論」而非「重演」其互動模式，D 為答案。陷阱在易混淆歷程評論與重演（reenactment）兩個概念。

第 16 題

曉明初次離家念大學，因適應不良而求助諮商，初次諮商時曉明顯得很安靜沉默。下列何者是諮商心理師有效運用歷程評論（process comments）的敘述？
  1. （A）對你而言要開始談話通常都不容易，還是因為我的緣故讓你較難開始談話？
  2. （B）你才剛離家來上大學，你會想念家人且感到孤單是正常的
  3. （C）大多數的新生第一次離家都會有想家的感覺，過了這個過渡期，就會好起來
  4. （D）我瞭解你的感覺，我第一次離家去上大學時也有這種孤單的感覺

答案：（A）

詳解與考點

考點為歷程評論（process comments）。針對此時此刻的互動發問（A，是否因我而難開口），聚焦當下關係歷程，故 A 正確。陷阱在 B、C、D 屬正常化或自我揭露，是內容回應而非歷程評論，易誤選。

第 17 題

關於重述技巧的運用，下列敘述何者正確？
  1. （A）適用於個案積極探索情緒時，可催化個案對情緒的覺察
  2. （B）常以暫時性的敘述或直述句型呈現
  3. （C）目的在幫助個案獲得洞察並有所行動
  4. （D）諮商心理師事先準備對話的主題，有助於問題的聚焦和解決

答案：（B）

詳解與考點

考點為重述（restatement）技巧，問「正確」。重述常以暫時、試探性的直述句呈現個案所言，故 B 正確。陷阱在 A：催化情緒覺察是情感反映而非重述；C 求洞察行動偏詮釋；D 預設主題違反跟隨原則。

第 18 題

關於結案的敘述，下列何者最不適切？
  1. （A）實習諮商心理師與個案晤談10次後，發現個案有很大的進展，因此在第11次晤談時告知個案諮商將於下一次（即第12次）結束
  2. （B）實習諮商心理師進行結案時邀請個案回顧整個諮商歷程，進行認知與情緒上的摘要，並進一步鞏固個案於諮商中獲得之重要成果
  3. （C）實習諮商心理師將第一次晤談時與個案共同建立的諮商目標做成書面清單，於結案時請個案寫下那些目標已經有那些進步，還有那些目標需要繼續努力
  4. （D）實習諮商心理師因實習即將結束而與個案討論結案事宜。實習諮商心理師評估可以結案，但個案認為尚有議題需要繼續諮商。經再評估後實習諮商心理師協助個案進行轉介

答案：（A）

詳解與考點

考點為結案倫理，問「最不適切」。第 11 次才告知下一次即結束（A），未預留足夠時間處理分離與道別，過於倉促故為答案。陷阱在 B、C、D 談回顧、書面目標檢核與轉介皆為良好結案實務。

第 19 題

在諮商關係初期，下列何者作法，最不利於與個案建立合作同盟關係？
  1. （A）鼓勵個案改變，面質個案對於改變的抗拒
  2. （B）瞭解個案對諮商的期待與想法
  3. （C）探詢個案過去的諮商經驗

  2. （B）直接跟個案說同志是時代趨勢，請他接受
  3. （C）邀請個案接觸同志社群，打破刻板印象
  4. （D）因為無法認同個案的價值觀，所以轉介個案接受他人的諮商

答案：（A）

詳解與考點

考點為諮商倫理中對科學實證與不歧視的把持。正解 A：提供「改變性傾向（迴轉療法）無效且有害」的實證資料，既尊重個案又守住專業倫理與科學立場。B 直接說教、C 強行安排接觸均強加價值或越界。D 因價值不同就轉介屬價值強加式的不當轉介。陷阱在 D，轉介看似中立，但因不認同個案價值而轉介違反倫理。

第 39 題

諮商心理師與有物質成癮議題的個案一起工作時，下列作為何者最沒有幫助？
  1. （A）了解法律對於成癮者的相關規定，以教導成癮者避免誤觸法網
  2. （B）了解社會對於成癮者的污名對個案可能產生的偏見或歧視
  3. （C）學習各種成癮物質可能帶給使用者的正向功能，以了解使用者可能的內在心理需求
  4. （D）增強學習有關精神疾患的評估能力，以幫助個案獲得適合的協助

答案：（A）

詳解與考點

考點為物質成癮工作的助人方向。正解 A「最沒有幫助」：教導成癮者如何避免誤觸法網偏離治療焦點、流於規避法律的技術性協助。B 理解污名、C 理解物質的正向功能以掌握內在需求、D 強化精神疾患評估，皆有助理解與協助個案。陷阱在 C，學習成癮物質「正向功能」聽來像鼓勵使用，實則用以理解心理需求，故有幫助。

第 40 題

某一原住民基金會決定要在部落成立原住民心理健康諮詢中心。關於其要聘請的諮商心理師最基本條件的敘述，下列何者最適當？
  1. （A）諮商心理師至少需具備處理酗酒、家暴、性侵創傷等議題專長，才適合原鄉部落的現況
  2. （B）諮商心理師至少需經過多元文化訓練，能對自己及其他文化具敏覺與尊重的態度與能力
  3. （C）諮商心理師至少應提出原住民血統證明，以確保能以原住民的立場為原住民進行諮商
  4. （D）在原住民偏遠地區願意來的人已不多，就現實考量只要有專業證照就有保證品質

答案：（B）

詳解與考點

考點為原鄉部落諮商的多元文化勝任能力。正解 B：聘任的最基本條件是受過多元文化訓練、對自身與他文化具敏覺與尊重。A 特定創傷專長非「最基本」。C 要求原住民血統證明屬不當的本質論限制。D 只憑證照即保證品質忽略文化適配。陷阱在 A，列舉酗酒家暴性侵專長看似切合現況，但非最基本、最優先的條件。
