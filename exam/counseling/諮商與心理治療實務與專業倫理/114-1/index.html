第 1 題

在運用「標準問題管理流程」協助個案尋求提升生活的結果時，需要詢問自己四個問題，其中「我需要的是什麼？」是屬於那一個階段的提問？
  1. （A）階段一：當前圖像（current picture）
  2. （B）階段二：首選圖像（preferred picture）
  3. （C）階段三：前進之路（way forward）
  4. （D）階段四：我如何讓這一切發生

答案：（B）

詳解與考點

考點為 Egan 標準問題管理流程（含 current picture、preferred picture、way forward）。「我需要的是什麼？」在描繪個案『想要的未來與目標』，屬階段二首選圖像（preferred picture），故 B 正確。最易誤選 A 當前圖像，那聚焦『現況與問題』；本題問的是渴望與需求，屬未來導向，故選首選圖像。

第 2 題

依據Egan和Reese的觀點，在針對個案進行探問時，下列何者最不適合？
  1. （A）指出需要更進一步弄清楚的陳述
  2. （B）避免使用具提問或要求功能的詞語
  3. （C）詢問開放式問句
  4. （D）不要同時問很多問題

答案：（B）

詳解與考點

考點為 Egan 與 Reese 的探問技巧。良好探問應用開放式問句、一次只問一個、指出待澄清處；而「避免使用具提問或要求功能的詞語」反而限制了適切的提問，最不適合，故正解 B。最易誤選 D，但一次不問多個問題確為正確原則，並非最不適合者。

第 3 題

個案在諮商當中提到：「我覺得主管一定對我有意見，每一次繳交的報告他都不滿意，也不說那裡需要修改就要我回去看，花時間修過之後又馬上打回票，我就覺得改好了啊！也看不出來那裡有問題了，為什麼不直接明說！」下列回應何者最能精確回應個案的關鍵經驗、想法或行為？
  1. （A）噢，你真的好慘，真是辛苦
  2. （B）主管不說明清楚，讓你很生氣
  3. （C）其實你很努力地想要完成工作，但因為不知道那裡需要調整讓你很挫折
  4. （D）主管真的不應該這樣對你，這會讓你很困擾且浪費彼此的時間

答案：（C）

詳解與考點

考點為同理心回應，需精確反映個案的核心經驗、想法與情緒。C 兼顧個案的努力與因不知如何調整而生的挫折，最貼近其關鍵經驗，故正確。最易誤選 B（生氣），但個案核心更偏向努力卻無從改進的『挫折』；A、D 偏向附和或評斷主管，未聚焦個案內在經驗。

第 4 題

關於面質技巧，下列敘述何者最不恰當？
  1. （A）須評估諮商關係是否足夠信任
  2. （B）須注意到個案的準備度
  3. （C）須敏察到個案的不一致
  4. （D）先面質再同理可以增進諮商效果

答案：（D）

詳解與考點

考點為面質（挑戰）技巧的使用原則。須評估關係信任、個案準備度、敏察不一致皆正確；而「先面質再同理」順序不當，應先建立同理基礎再面質，故最不恰當為 D。最易誤選其他，但唯有 D 把同理放在面質之後，違反先理解後挑戰的原則。

第 5 題

關於「解釋」技巧，下列敘述何者最適當？
  1. （A）宜多用專有名詞陳述，增加解釋的說服性
  2. （B）諮商心理師可和個案合作共同建構解釋
  3. （C）諮商心理師在單次諮商中應重複並多做解釋，才能突破個案的防衛
  4. （D）解釋不可超過個案所能覺察的範圍，否則個案將無法思考、處理

答案：（B）

詳解與考點

考點為「解釋」技巧的適切運用。最適當為 B：諮商師可與個案『合作共同建構』解釋，符合協同、尊重個案主體性的精神，故正確。最易誤選 D，但其敘述過於絕對；A 多用專有名詞反增距離、C 單次重複多做解釋易引發防衛，皆不當，唯 B 強調合作建構最妥。

第 6 題

個案在第一次晤談時迫不及待地告訴諮商心理師個人的困境與問題的歷史。諮商心理師展現下列那項行為最有助於建立信任的諮商關係？
  1. （A）一邊傾聽，一邊記筆記，以免遺忘重要訊息
  2. （B）在適當時機打斷個案的敘述，詢問其陳述的某些細節
  3. （C）輕聲發出「是」、「嗯哼」等話語，提供輕微的鼓勵
  4. （D）認真觀察個案的語言與非語言訊息，尋找適當時機將自己的觀察反映給個案知道

答案：（C）

詳解與考點

考點為初次晤談建立信任的傾聽技巧。當個案迫不及待傾吐時，輕聲「嗯哼」等最低限度鼓勵能不打斷其敘說、傳達專注，最有助建立關係，故 C 正確。最易誤選 B 適時打斷詢問細節，但初次傾吐時打斷易破壞信任流動；C 的不干擾式鼓勵更恰當。

第 7 題

諮商心理師對個案說：「你有幾次提到關於媽媽的事情，但你並沒有持續，我的猜測是，媽媽對你而言是一個相當重要的對象，但也許也相當棘手。」諮商心理師的意圖為下列何者？
  1. （A）協助個案看到更大的圖像
  2. （B）協助個案瞭解自己可能忽略的事務
  3. （C）協助個案瞭解涵意並得出結論
  4. （D）協助個案開放

答案：（D）

詳解與考點

考點為諮商師意圖辨識。諮商師指出個案『反覆提起卻未深入』媽媽的話題，意在鼓勵個案進一步開放、談論其迴避之處，故意圖為 D 協助個案開放。最易誤選 B 看到忽略之事，但此回應重點在『邀請個案打開』棘手議題而非點出盲點，故選協助開放。

第 8 題

下列那種依附類型的個案，於晤談中對諮商心理師坦誠時，會傾向忽略個人情緒採取迴避策略，因此諮商心理師在諮商中最好放慢速度，尊重他們的需求？
  1. （A）焦慮依附型（Preoccupied Attachment Style）
  2. （B）排除依附型（Dismissive Attachment Style）
  3. （C）害怕依附型（Fearful Attachment Style）
  4. （D）安全依附型（Secure Attachment Style）

答案：（B）

詳解與考點

考點為依附類型與晤談因應。排除（逃避）依附型（Dismissive）傾向忽略自身情緒、採迴避策略、重視自主，故諮商宜放慢速度、尊重其需求，正解 B。最易誤選 A 焦慮（preoccupied）依附，那類個案反而過度涉入情緒、渴求親近，與『忽略情緒、迴避』的描述相反。

第 9 題

在諮商過程中探討個案的童年經驗時，個案出現一段沉默不語的情況，下列諮商心理師的做法，何者最適當？
  1. （A）找出可能的話題繼續引導
  2. （B）檢視先前的談話方向
  3. （C）解釋沉默的意義
  4. （D）等待個案一段時間，不急於作反應

答案：（D）

詳解與考點

考點為晤談中沉默的處理。探討童年等深刻議題時出現沉默，往往是個案內在整理的歷程，最適當做法是給予空間、等待一段時間而不急於介入，故 D 正確。最易誤選 A 找話題引導，但急於填補沉默可能打斷個案的內在處理，反不利深化。

第 10 題

下列關於PTSD臨床議題的敘述，何者最為適當？
  1. （A）性別為男性者罹患PTSD的終身盛行率是性別為女性者的兩倍
  2. （B）創傷年齡可以預測PTSD的治療結果
  3. （C）一般相信，慢性PTSD更難治療
  4. （D）發展階段的認知因素通常不是影響PTSD評估與治療方法的因素

答案：（C）

詳解與考點

考點為 PTSD 臨床議題。一般認為慢性 PTSD 較急性更難治療，故 C 最適當。最易誤選 A，但女性 PTSD 終身盛行率約為男性兩倍（題目說反）；發展階段的認知因素確會影響評估與治療（D 說反），故唯 C 正確。

第 11 題

依據113年12月18日修正之學生輔導法之敘述，諮商心理師擔任學生輔導諮商中心之專業輔導人員，每學年應接受在職進修課程至少幾小時？
  1. （A）12
  2. （B）18
  3. （C）24
  4. （D）32

答案：（B）

詳解與考點

考點為學生輔導法（113.12.18 修正）對專業輔導人員在職進修時數的規定。學生輔導諮商中心專業輔導人員每學年應至少接受 18 小時在職進修，故 B 正確。屬法規記憶題，易在 12、24 小時間誤判，須記得學生輔導法定為 18 小時。

第 13 題

諮商心理師與新住民個案工作時，下列何種實務工作準備狀態最不適當？
  1. （A）諮商心理師需認識臺灣社會對於新住民之整體氛圍以及移民相關政策，以理解新住民個案之身處脈絡
  2. （B）諮商心理師尊重新住民個案之文化脈絡，同時也清楚告知固定與一對一諮商架構的重要性，並共同遵守此架構進行諮商
  3. （C）諮商心理師需更敏感於諮商專業之主流思維，例如：強調個人內在感受與認知，並持續發展能夠靠近新住民個案之諮商介入策略
  4. （D）諮商心理師應時刻覺察與反思自身對於新住民之刻板印象，於諮商歷程留意與管理此刻板印象對於諮商互動之影響

答案：（B）

詳解與考點

考點為新住民個案的多元文化實務準備。最不適當為 B：以「清楚告知並要求共同遵守固定、一對一架構」為重，過度強調主流諮商框架、忽略文化彈性，故不當。最易誤選 C，但 C 強調覺察主流思維並發展貼近策略，方向正確；唯 B 把僵化架構置於文化脈絡之上。

第 14 題

下列晤談過程所出現的情境，何者顯示諮商心理師有可能超越適當的界線而應採取預防行動？
  1. （A）穩定和個案晤談並準時開始與結束
  2. （B）對個案所談的內容都感興趣而不僅限於享受某特定議題
  3. （C）想獲得個案的認可
  4. （D）覺得除了自己以外，其他人應該也可以讓個案受益

答案：（C）

詳解與考點

考點為諮商界線與反移情警訊。「想獲得個案的認可」反映諮商師的個人需求介入專業關係，可能逾越界線而須採預防行動，故 C 正確。最易誤選 B，但對個案各種內容皆感興趣屬適切投入；唯 C 把滿足自身被認可需求帶入晤談，是越界警訊。

第 15 題

有關校園危機事件之三級輔導工作，下列敘述何者錯誤？
  1. （A）危機事件發生後，校園輔導工作優先順序依序為處遇性輔導、介入性輔導，最後是發展性輔導
  2. （B）針對危機事件受衝擊對象進行減壓團體，屬於介入性輔導
  3. （C）危機事件受衝擊人數較多，以量表檢測篩選需要協助之對象，屬於發展性輔導
  4. （D）提供目睹危機事件相關人員心理諮詢與相關資源，屬於處遇性輔導

答案：（C）

詳解與考點

考點為校園危機三級輔導。以量表篩選需協助對象屬『介入性輔導』而非發展性輔導，故錯誤敘述為 C。最易誤選 A，但危機後優先順序確為處遇性、介入性再到發展性，敘述成立；唯 C 將篩選高風險對象誤歸為發展性輔導，層級錯置。

第 16 題

關於諮商紀錄的保存，目前依據不同的法規有不同的規定。下列何者正確？
  1. （A）依據學生輔導法施行細則，學生輔導資料之保存年限應自學生畢業或離校後保存7年
  2. （B）依據醫療法，醫療機構之病歷，應指定適當場所及人員保管，並應至少保存8年
  3. （C）依據機密檔案管理辦法，個案結案後兩年，可進行諮商紀錄解密
  4. （D）依據心理師法，心理諮商所對於執行業務之紀錄等，應至少保存10年

答案：（D）

詳解與考點

考點為諮商紀錄保存的法規年限。依心理師法相關規定，心理諮商所執行業務之紀錄應至少保存 10 年，故 D 正確。屬法規記憶題，易與醫療法病歷（至少 7 年）、學生輔導資料保存年限混淆，須分別記住各法規定的年限。

第 17 題

諮商心理師的下列何項作為，可能會增加法律訴訟的機率？
  1. （A）將價值觀加諸在個案身上
  2. （B）確實撰寫諮商紀錄
  3. （C）留意個人的語言與行為
  4. （D）建立與維持適當的界線

答案：（A）

詳解與考點

考點為降低法律訴訟風險的執業行為。「將價值觀加諸個案」違反尊重自主、可能造成傷害，最易引發倫理申訴與訴訟，故 A 正確。最易誤選其他，但確實撰寫紀錄、留意言行、維持適當界線皆屬降低風險的良好實務，唯 A 是增加訴訟機率的作為。

第 18 題

關於知後同意，下列敘述何者錯誤？
  1. （A）內容必須將個案與諮商心理師的權利與義務同時用口語說明與書面資料的方式呈現
  2. （B）諮商心理師必須與個案討論諮商的益處與風險，還有諮商帶來的間接影響
  3. （C）諮商心理師通知個案其在諮商中的權利與義務，即是充分進行知後同意
  4. （D）在諮商歷程中隨時都可能需要進行知後同意

答案：（C）

詳解與考點

考點為知後同意（informed consent）的性質。知後同意是『持續歷程』而非一次性告知即完成，故「通知權利義務即是充分進行知後同意」為錯誤，正解 C。最易誤選 A，但口語加書面並陳確為適當做法；D 隨時可能需再行知後同意亦正確，唯 C 把它窄化為單次完成。

第 19 題

依據心理師法第8條規定，諮商心理師執業應接受繼續教育，並每6年提出完成繼續教育證明文件，辦理執業執照更新，此項規定呼應下列那一個倫理準則的精神？
  1. （A）忠誠權
  2. （B）公正權
  3. （C）自主權
  4. （D）免受傷害權

答案：（D）

詳解與考點

考點為繼續教育規定對應的倫理原則。要求每 6 年完成繼續教育以更新執照，旨在維持專業能力、避免因能力不足而傷害個案，呼應『免受傷害權（不傷害）』，故 D 正確。最易誤選 A 忠誠權，但持續進修的核心是確保勝任、防止傷害，故對應免受傷害權。

第 20 題

諮商心理師為有外遇議題的夫妻進行諮商，諮商過程當中太太堅決否認自己外遇，而先生也擔心過度猜忌可能為其婚姻帶來負面影響。然，在一次非正式與太太的聊天中，太太向諮商心理師坦承自己有外遇的事實。有關諮商心理師的處理，下列何者最為適當？
  1. （A）為避免隱瞞而產生的動力影響，在伴侶諮商中主動邀請太太表達
  2. （B）徵求太太的同意後，約先生個別討論該狀況，協助其緩解心理衝擊
  3. （C）與太太討論此隱瞞對親密關係以及諮商關係的影響，並說明保密的限制，鼓勵太太主動表達
  4. （D）基於保護太太的隱私，以及先生可能的受傷，選擇保密

詳解與考點

第 26 題

第 28 題

第 33 題

  2. （B）考量喪事已經辦完，評估個案哀傷歷程已走到後期，沒有太大的感觸是正常狀態
  3. （C）評估個案可能想逃避喪妻的事實，諮商心理師需要明確指出並邀請個案練習增加和孩子相處的時間

第 34 題

  2. （B）先重新評估個案被虐之事是否為真
  3. （C）先從個案願意討論的議題開始
  4. （D）先由轉介之社工或老師處理，確認是否發生兒虐事件

第 35 題

第 36 題

  2. （B）與微觀系統連結的社會環境，是個人生存的正式或非正式社會結構，屬於中層系統（mesosystem）
  3. （C）人類生態發展系統之第四系統為鉅觀系統（macrosystem），包含文化價值、信念、歷史事件等，都可能影響其他生態系統
  4. （D）青少年的發展與問題需要放在真實情境，即生態下去思考

答案：（B）

第 37 題

第 38 題

答案：（D）

詳解與考點

考點為多元生涯路徑模式的退休型態。即將退休的資深員工，常以漸進、減量方式逐步退出職場，對應「老驥伏櫪型／漸進退休（phased retirement）」，故 D 正確。陷阱在於將其誤選為晚期高峰型（事業後期才達巔峰），兩者描述的生涯曲線不同。

第 39 題

衛生福利部於110年9月27日修訂完成之「高齡社會白皮書」，揭示自主、自立、共融及永續四大願景，下列何者不是具體實施之目標？
  1. （A）促進世代和諧共融
  2. （B）增進高齡者健康與自主
  3. （C）擴展高齡者持續進修機會
  4. （D）提升高齡者社會連結

答案：（C）

詳解與考點

考點為衛福部 110 年「高齡社會白皮書」四大願景（自主、自立、共融、永續）下的具體目標。健康自主、世代共融、社會連結屬其推動方向，而「擴展高齡者持續進修機會」非該白皮書列出的具體目標，故選 C。屬政策法規記憶題，把握度中等。

第 40 題

當高齡個案將諮商心理師視為其子女或家人般的關切、分享秘密時，諮商心理師的作法下列何者最適當？
  1. （A）利用此信任關係統整個案之心理經驗
  2. （B）面質個案是否常如此與年輕人建立關係
  3. （C）詢問個案還向那些人分享了秘密
  4. （D）運用立即性技巧澄清個案的心理期待

答案：（A）

詳解與考點

考點為高齡諮商中的關係運用與移情處理。個案視心理師如家人並分享秘密，反映信任與依附，最適當是善用此關係協助統整其心理經驗，故 A。陷阱在 B：面質個案的關係模式會破壞好不容易建立的信任，對高齡者並不適切。
