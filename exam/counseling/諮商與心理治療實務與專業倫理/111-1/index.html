第 1 題

依據心理師法第14條規定，下列何者非諮商心理師之業務執行範圍？
  1. （A）精神官能症之心理治療
  2. （B）社會適應偏差與障礙之心理治療
  3. （C）腦部心智功能之心理治療
  4. （D）心理發展偏差與障礙之心理治療

答案：（C）

詳解與考點

考點為心理師法第14條諮商心理師業務範圍。諮商心理師業務不含「腦部心智功能」之心理治療（屬臨床心理師範圍），故 C 為正解。陷阱在於 A、B、D（精神官能症、社會適應、心理發展偏差之心理治療）確屬諮商心理師法定業務，敘述正確易被排除。

第 2 題

下列何者非諮商心理師考慮結案的適宜時機？
  1. （A）個案覺得沒有受益
  2. （B）個案不按時付費
  3. （C）個案要求結束
  4. （D）個案無法轉介

答案：（D）

詳解與考點

考點為結案（終止諮商）的適宜時機與倫理。「個案無法轉介」並非結案的恰當理由，反而應審慎處理避免遺棄個案，故 D 為正解。陷阱在於 A、B、C（個案覺無受益、未付費、主動要求結束）皆為實務上合理的結案考量時機，易被排除。

第 3 題

依據兒童及少年福利與權益保障法關於兒童及少年安置期間，下列敘述何者錯誤？
  1. （A）安置機構必須行使父母對於未成年子女的權利義務
  2. （B）兒童及少年的學校老師經過主管機關同意後，可以探視兒童及少年
  3. （C）主管機關要同意兒童及少年的老師前來探視前，須取得原監護人的同意
  4. （D）安置期間，如果並非以兒童及少年的福祉為考量，不可以讓兒童及少年接受偵訊

答案：（C）

詳解與考點

考點為兒少福利與權益保障法的安置探視規定。主管機關同意老師探視時，係以兒少最佳利益為準，不需取得原監護人同意（監護權已受限），故 C 敘述錯誤為正解。陷阱在於 A、B、D 皆為合法規定，敘述正確；C 多加「須原監護人同意」為陷阱。

第 4 題

關於督導的知後同意書內容，下列何者最不需要列入？
  1. （A）督導的目的
  2. （B）督導過程的細節
  3. （C）評量受督者表現的程序
  4. （D）督導者的年齡、執登地點

答案：（D）

詳解與考點

考點為督導知後同意書應載明的內容。督導者個人的「年齡、執登地點」與督導關係的目的、程序、評量等核心資訊無關，最不需列入，故 D 為正解。陷阱在於 A、B、C（目的、過程、評量程序）均為知後同意應告知受督者的必要事項，易被排除。

第 6 題

小五學生的導師期待能瞭解該生與專輔教師的諮商內容，以便有效地幫助其在學校的適應。下列何者最符合學生輔導工作倫理守則的原則？
  1. （A）應遵循「最適量、正當性」原則
  2. （B）應遵循「最少量、必要性」原則
  3. （C）應遵循「最適量、最佳合作性」原則
  4. （D）學生的諮商內容應充分保密

答案：（B）

詳解與考點

考點為學生輔導工作倫理守則中資訊揭露的原則。導師欲了解諮商內容時，應遵循「最少量、必要性」原則，僅在必要範圍內提供協助所需資訊，故 B 正確。陷阱在 D：學生諮商內容雖須保密，但非絕對；為協助學校適應可在最少必要範圍揭露，易誤選。

第 7 題

某諮商心理師在學校工作，諮商中心主任為接受校務評鑑而要求諮商心理師將個案紀錄陳列於評鑑會場。下列處理方式何者最不恰當？
  1. （A）與主任溝通，不宜陳列個案紀錄之考量
  2. （B）尊重主任的決定，提供個案紀錄供評鑑委員查閱
  3. （C）將個案紀錄中可能辨識出個案身分之資料隱匿或彌封
  4. （D）與主任溝通，改採其他量化資料呈現

答案：（B）

詳解與考點

考點為紀錄保密與評鑑需求的倫理衝突。為評鑑而直接陳列可辨識個案身分的紀錄，違反保密義務，故 B「尊重主任決定提供查閱」最不恰當為正解。陷阱在於 A、C、D（溝通、隱匿身分資料、改採量化資料）皆為兼顧保密的妥適作法，易被排除。

第 8 題

一位國中生即將進入高中就讀，該校評估後認為該生應列入轉銜名冊中，然家長拒絕同意。依據學生轉銜輔導及服務辦法，下列何者非該辦法之考量而可逕行轉銜？
  1. （A）經過三名以上的專家進行專業評估，學生確有轉銜之必要
  2. （B）基於保護學生生命、身體或健康之必要
  3. （C）基於維護公共利益之必要，經學校主管機關同意
  4. （D）學生主動請求轉銜輔導

答案：（A）

詳解與考點

考點為學生轉銜輔導及服務辦法中得不經家長同意逕行轉銜的要件。逕行轉銜限於保護學生生命健康、維護公共利益（經核准）或學生主動請求等情形；「三名專家評估有必要」非該辦法所列逕行要件，故 A 為正解。陷阱在於另三項皆為法定考量，易被排除。

第 9 題

依據「社團法人中華民國諮商心理師公會全國聯合會會員自律公約」：本會會員及所屬公會會員執行諮商心理師業務，應遵守下列那些項目？①法令②諮商心理師公會組織章程③專業倫理與自律公約④臺灣輔導與諮商學會諮商專業倫理守則
  1. （A）僅①②③
  2. （B）僅①③④
  3. （C）僅②③④
  4. （D）①②③④

答案：（A）

詳解與考點

考點為諮商心理師公會全聯會會員自律公約應遵守事項。依公約規定為：法令、公會組織章程、專業倫理與自律公約三項（①②③），故選僅①②③，A 正確。陷阱在於 ④臺灣輔導與諮商學會的倫理守則並非該自律公約明列遵守項目，易被多選而誤。

第 10 題

關於諮商心理師的自我照顧，下列作為何者最無幫助？
  1. （A）承認並尊重自己的限制
  2. （B）要求自己與所有同事及朋友都維持良好關係
  3. （C）注意自己在工作及休閒時間的平衡
  4. （D）維持生活品質，注意自己的心情起落及幸福感

答案：（B）

詳解與考點

考點為諮商心理師的自我照顧。要求自己與「所有」同事朋友都維持良好關係是不切實際的完美期待，反增壓力，對自我照顧最無幫助，故 B 為正解。陷阱在於 A、C、D（承認限制、工作休閒平衡、注意心情與幸福感）皆為健康自我照顧，易被排除。

第 11 題

關於接受與承諾治療（Acceptance and Commitment Therapy），下列敘述何者錯誤？
  1. （A）結合行為治療（Behavioral Therapy）的技術
  2. （B）重視個案語言的使用
  3. （C）協助個案接納他們逃避的感覺
  4. （D）解除策略（defusion strategies）的運作，是跟個案討論想法並解除想法的控制

答案：（D）

詳解與考點

考點為接受與承諾治療（ACT）的核心歷程。認知解離（defusion）是協助個案與想法保持距離、不被想法控制，而非「與個案討論並解除想法」式的內容辯駁，故 D 敘述錯誤為正解。陷阱在於 A、B、C（結合行為技術、重視語言、接納逃避感受）皆正確。

第 12 題

關於諮商心理師進行諮商時的作為，下列敘述何者最不適切？
  1. （A）運用某個諮商理論作為諮商介入依據，有助於個案概念化與評估
  2. （B）個案概念化與治療計畫目標，設定後仍可修正與調整
  3. （C）擔任初始晤談的諮商心理師應即為後續接案者，以減少個案重複敘述之困擾
  4. （D）初始晤談時可採用制式表格作為資訊蒐集的方法之一

答案：（C）

詳解與考點

考點為諮商歷程中的接案與個案概念化。初始晤談者「不必」即為後續接案者，可依專業分工轉介，硬性要求同一人反而僵化，故 C 最不適切為正解。陷阱在於 A、B、D（理論作概念化依據、目標可修正、用制式表格蒐集資訊）皆屬合理作為，易被排除。

第 13 題

個案為少數民族，因為經濟因素而考慮中斷諮商，諮商心理師感受到其無奈與困境，免費為其諮商，並且請其幫忙打掃家裏，以幫助她度過經濟難關。下列對諮商心理師行為的敘述，何者最恰當？
  1. （A）諮商心理師很可能是少數民族促進會的重要決策者之一
  2. （B）諮商心理師可能具有文化敏感度訓練的經驗，能覺察少數民族的困境
  3. （C）諮商心理師具有同情心，能救人於危難之中，具有難能可貴的助人情操
  4. （D）諮商心理師沒有覺察其協助方式，有可能損害了諮商關係

答案：（D）

詳解與考點

考點為雙重關係與界限的倫理。免費諮商又請個案到家中打掃，形成雙重關係並可能損害諮商關係與專業界限，故 D 最恰當為正解。陷阱在 C：把此舉美化為「助人情操」忽略了界限問題，看似讚許實則違反倫理，易誤選。

第 14 題

個案在初次晤談時詢問諮商心理師：「老師，我該怎麼準備考研究所？」下列諮商心理師的敘述何者最適當？
  1. （A）生涯興趣量表可以測量一個人的興趣，也許我們先做個測驗，看看你適合報考那一類型的研究所
  2. （B）我通常會先整理重點筆記，然後練習考古題，我覺得很有幫助，也許你可以試試看
  3. （C）關於這個問題你之前曾經詢問過那些人？你蒐集了那些資料？
  4. （D）我記得當時在準備考試時，覺得壓力很大，讓我幾乎想放棄，不知道你是不是也跟我有一樣的感覺？

答案：（C）

詳解與考點

考點為初次晤談的回應技巧與賦能。面對「怎麼準備考研究所」的求問，先探問個案已詢問過誰、蒐集了哪些資料，屬聚焦於個案資源與探索的開放式回應，最適當，故 C 正確。陷阱在 A、B：太快導向測驗或給自身經驗建議，未先了解個案脈絡，易誤選。

第 15 題

關於移情的敘述，下列何者錯誤？
  1. （A）個案告訴諮商心理師：「你剛剛的建議是我媽媽常對我說的」
  2. （B）成人個案談到失敗經驗時，聲音會變得像七八歲的兒童
  3. （C）青少年個案控訴諮商心理師：「你們大人都一樣，只會罵我們這裡錯，那裡錯」
  4. （D）小六的個案告訴諮商心理師，他被老師沒收鏡子，很生氣

答案：（D）

詳解與考點

考點為移情（transference）的辨識。移情是個案將過去重要他人的情感投射到諮商師身上；A、B、C 皆屬此（聯想到媽媽、退化聲音、把諮商師當成大人）。D 對老師沒收鏡子生氣是針對現實事件的情緒，非投射到諮商師，故為錯誤即正解。

第 16 題

Hill（2014）對助人歷程的描述，下列何者正確？
  1. （A）分為關係、探索與行動三階段
  2. （B）關係階段是助人歷程中最重要的
  3. （C）晤談過程可能在各階段間進進退退
  4. （D）晤談過程需由第一階段順利發展至第三階段，方能產生具體治療成效

答案：（C）

詳解與考點

考點為 Hill 三階段助人模式：探索、洞察、行動。歷程並非單向直線推進，而可能在各階段間來回進退，故 C 正確。陷阱在 D：晤談不必嚴格從第一到第三階段順利推進才有效；B「關係最重要」、A 階段名稱亦有出入，易誤選。

第 17 題

個案企圖跳樓輕生，被人發現通知教官。教官事後將個案帶至諮商中心。諮商心理師告訴個案其行為已不在保密範圍內，因此須通知家長。個案拒絕且激動地表示：「要通報都是為了你們自己，因為法令規定，我說了幾百遍不要告訴我父母，你有聽到嗎？」下列諮商心理師的作法何者最適切？
  1. （A）否認通報是為了保護自己，再次澄清通報是為了符合個案的最佳利益
  2. （B）先同理個案對通報一事與對諮商心理師的憤怒，再詢問個案對告知父母此事的擔心或想法為何
  3. （C）溫和地澄清通報的目的在於保護個案，如果個案願意簽署不自殺契約，也不一定要告知父母此事
  4. （D）先同理個案憤怒與激動的情緒，告訴個案如果想獨處，可讓他在晤談室獨自思考10分鐘後，再繼續跟他討論

答案：（B）

詳解與考點

考點為自殺通報情境下的危機處理與情緒同理。面對個案憤怒拒絕通報，應先同理其對通報與諮商師的憤怒，再探問其對告知父母的擔心，兼顧關係與評估，故 B 最適切。陷阱在 C：以「簽不自殺契約就不一定告知父母」交換條件，違反通報義務與安全評估，易誤選。

第 18 題

對於過度安靜個案之敘述或處遇方式，下列何者最不適當？
  1. （A）個案過度安靜的原因可能因為害羞、對人際互動感到焦慮或恐懼，或對諮商心理師的抗拒或敵意
  2. （B）諮商心理師可退一步跟隨個案的步調，等待個案想說的時候再說
  3. （C）封閉式問句對於過度安靜的個案非常有幫助，可讓個案不用開口表達自己，以降低其焦慮
  4. （D）採用正向重新架構（positive reframing）技術，有助於退縮個案願意試著開口說話

答案：（C）

詳解與考點

考點為對過度安靜（沉默）個案的處遇。封閉式問句易讓個案只簡答而阻礙表達、無助於開展，故 C「封閉式問句非常有幫助」最不適當為正解。陷阱在於 A、B、D（理解沉默原因、跟隨步調、正向重新架構）皆為合宜處遇，敘述正確易被排除。

第 19 題

下列何者不是諮商心理師用來促成個案執行計畫的能力與意願的策略之一？
  1. （A）預演行動
  2. （B）道德規勸
  3. （C）角色扮演
  4. （D）自我契約書

答案：（B）

詳解與考點

考點為促進個案執行計畫（行動階段）的策略。預演行動、角色扮演、自我契約皆能提升執行的能力與意願；「道德規勸」屬說教式勸誡，非有效的行動促成策略，故 B 為正解。陷阱在於另三項均為實務常用的行動技術，敘述正確易被排除。

第 20 題

  1. （A）模仿
  2. （B）跟循
  3. （C）隱喻
  4. （D）假裝

答案：（A）

詳解與考點

考點為家族治療中加入（joining）的技巧。諮商師模仿家庭成員的姿態、動作（如跟著脫外套）以建立連結，屬「模仿」（mimesis）技術，故 A 正確。陷阱在 B 跟循（tracking）：跟循是順著家庭內容與溝通脈絡，而此例是模仿其行為動作，易混淆。

第 21 題

關於何倫（Holland）生涯類型論，下列敘述何者最適切？

  3. （C）無一致性（inconsistent）的職業代碼為數非常多
  4. （D）生涯諮商目標常會探討適配性和分化性，而非一致性

答案：（D）

考點為 Holland 生涯類型論的三大指標：適配性、分化性、一致性。生涯諮商目標常探討適配性與分化性，而較少直接探討一致性，故 D 最適切。陷阱在 A：社會型在社區助人機構工作屬高適配（congruence 高），題目稱「較低」說反，易誤選。

第 22 題

第 23 題

關於生涯建構系統評量，下列敘述何者錯誤？
  1. （A）生涯建構系統的理論以個人建構理論為依據
  2. （B）建構是兩級的，稱為建構極，產生建構的要件必須至少是三種
  3. （C）個案所產生的建構即是生涯諮商的目的，因為產生的建構可以說明其生涯認知內涵
  4. （D）一般學者以認知複雜度作為「認知分化性」的指標；認知分化性高者，其認知建構中的階層較為複雜

第 24 題

  2. （B）幻想技術適合於各種類型的個案，可消除諮商中的防衛，也可投射出未來的生涯願景
  3. （C）根據Richardson（1981）之研究顯示，約有75%的人能夠無礙地進入幻想的狀況
  4. （D）個案無法接受幻想技術時，諮商心理師可和個案一同探討未能進入幻想的原因

答案：（B）

詳解與考點

考點為生涯諮商的幻想（引導式想像）技術。無法進入幻想者可邀其列席聆聽、共同探討原因，Richardson 研究約 75% 能順利進入，均正確。B 錯在過度宣稱「適合各種類型個案」，事實上對防衛強或現實感不足者並非人人適用，屬過度概化的陷阱選項。

第 25 題

  2. （B）當兒童干擾上課，老師只需隔離他與其他同學，不需再額外處罰，是運用自然的後果
  3. （C）諮商心理師回應兒童：「你心裡不高興時，也想要讓大家都不開心」，是合理化兒童的行為

答案：（D）

詳解與考點

考點為阿德勒學派技巧，核心是鼓勵（encouragement）與自然/邏輯後果。D 正確：強調內在動機與投入歷程本身即是酬賞，符合阿德勒重視內在價值。最易誤選 A，但「高亢語調讚美作品多美」是讚美（praise）而非鼓勵，鼓勵應聚焦努力與歷程，非評價結果。

第 26 題

建華在班上被同學排擠、霸凌，每天到學校都覺得壓力很大。下列何者是以問題為焦點的壓力因應策略？

  2. （B）報名參加有氧運動課
  3. （C）練習肌肉放鬆訓練和冥想
  4. （D）跟家人訴苦，尋求支持

答案：（A）

詳解與考點

考點為 Lazarus 與 Folkman 壓力因應，分問題焦點與情緒焦點。A 參加社交技巧訓練直接改變被排擠的問題來源，屬問題焦點。其餘有氧運動、肌肉放鬆冥想、向家人訴苦求支持都在調節情緒或紓壓，屬情緒焦點，易誤選因都「有助益」但未針對問題本身。

第 27 題

答案：（B）

詳解與考點

考點為物質使用個案的處遇原則。接納並設限、結合校家關懷系統、了解使用動機並找無害替代都有幫助。B 最沒幫助：僅憑「態度良好、保證不再用」就完全相信，忽略成癮的反覆性與後續監督，屬過度天真的處置。

第 40 題

關於多元性別的敘述，下列何者錯誤？
  1. （A）性別表達是指個人透過行為、衣著、髮型、聲音或身體特徵，來向他人傳達自己認同的性別
  2. （B）性傾向是指個人在情感上或情慾上受到何種性別的吸引，一般來說包括同性戀、異性戀、雙性戀等
  3. （C）順性別（cisgender）是指與社會文化賦予性別的規範一致者
  4. （D）LGBTI中的T（transgender）代表跨性別，I（intersex）代表雙性人

答案：（C）

詳解與考點

考點為多元性別概念定義。性別表達、性傾向、跨性別 T 與雙性人 I 的敘述均正確。C 錯在順性別（cisgender）定義：應指「性別認同與出生指定性別一致者」，而非「與社會性別規範一致」，混淆了性別認同與性別角色規範。
