第 1 題

在運用「標準問題管理流程」協助個案尋求提升生活的結果時，需要詢問自己四個問題，其中「我需要的是什麼？」是屬於那一個階段的提問？
  1. （A）階段一：當前圖像（current picture）
  2. （B）階段二：首選圖像（preferred picture）
  3. （C）階段三：前進之路（way forward）
  4. （D）階段四：我如何讓這一切發生

答案：（B）

詳解與考點

正解：Egan 標準問題管理流程的提問「我需要的是什麼？」。「需要」指向個案想達成的未來、目標與渴望，故屬階段二的首選圖像（preferred picture），故選 B。

A：當前圖像聚焦現況、困擾及已有資源，問的是「現在發生什麼」，不是想要什麼。

C：前進之路是把目標轉成可行策略與選項的階段，須先有首選圖像。

D：我如何讓這一切發生，著重選定行動後的執行與承諾，非需求辨識。

本題考點：Egan 標準問題管理流程——判準是現況與問題屬當前圖像；想要的未來屬首選圖像；策略選項屬前進之路；承諾執行則進入行動階段。

第 18 題

對於過度安靜個案之敘述或處遇方式，下列何者最不適當？
  1. （A）個案過度安靜的原因可能因為害羞、對人際互動感到焦慮或恐懼，或對諮商心理師的抗拒或敵意
  2. （B）諮商心理師可退一步跟隨個案的步調，等待個案想說的時候再說
  3. （C）封閉式問句對於過度安靜的個案非常有幫助，可讓個案不用開口表達自己，以降低其焦慮
  4. （D）採用正向重新架構（positive reframing）技術，有助於退縮個案願意試著開口說話

答案：（C）

詳解與考點

正解：「最不適當」及過度安靜個案；判準是介入能否擴展個案安全表達，而非只求降低當下開口壓力。封閉式問句通常只導向簡短回答，容易縮減敘說與探索，不能說對過度安靜個案非常有幫助，故 C 為應選項。

A：害羞、人際焦慮或對諮商心理師的抗拒與敵意，都可能形成沉默；先理解功能才能選擇合宜介入，故非答案。

B：適度跟隨個案步調、容納沉默，有助建立安全感，故非答案。

D：正向重新架構可協助退縮個案看見嘗試開口的資源與可能性，故非答案。

本題考點：沉默個案的處遇——判準是理解沉默功能並創造可表達的安全空間；封閉式問句若使回答更侷限，便不利開展。

第 33 題

在醫院執業之諮商心理師為癌末住院治療個案進行安心服務，下列晤談目標何者最適切？
  1. （A）鼓勵個案接受積極性治療
  2. （B）運用同理心理解個案的困難
  3. （C）釐清諮商關係與倫理議題
  4. （D）探詢個案現在有什麼待完成的需求與心願

答案：（D）

詳解與考點

正解：「癌末住院治療個案」與「安心服務」——臨終諮商的近期目標是回應個案此刻的未竟事務、關係與心願，支持其保有選擇與尊嚴。探詢個案現在想完成的需求與心願，才能據此安排溝通、資源或告別，最切合安寧照護的全人取向，故選 D。

A：是否接受積極性治療應由個案在充分醫療資訊下決定；諮商心理師不宜把鼓勵接受特定醫療處置當成晤談目標。

B：同理理解個案困難是所有諮商關係的基本態度，但未具體指向癌末階段的當前需要。它看似最溫暖，錯在層次過於一般，無法取代對未竟需求與心願的直接探詢。

C：關係界線與倫理議題固須妥善處理，但不是在資訊不足下最優先的晤談目標；應先以個案此刻的需求為中心。

本題考點：安寧與臨終心理服務（palliative psychological care）——著重生活品質、尊嚴與未竟事務；當事人自主權（autonomy）——醫療選擇不由心理師以鼓勵特定決定取代。

第 9 題

在成為專業諮商心理師之前，先接受諮商或是心理治療的主要理由為何？
  1. （A）了解自己主要反移情的反應方式，學習如何處理反移情
  2. （B）在幫助他人之前要先完全處理掉自己的內在衝突
  3. （C）提升對當事人移情反應的覺察，以避免造成諮商的阻礙
  4. （D）模擬當事人在諮商情境中的反應，增加對當事人的了解

答案：（A）

詳解與考點

正解：專業助人者要求受訓者或執業者先接受個人諮商或治療，核心理由是自我覺察與自我了解：唯有透過親身作為當事人的經驗，諮商師才能辨識出自己在諮商情境中容易被誘發的情緒、未竟事務與慣性反應模式，也就是反移情（countertransference）——心理師因自身未處理的議題而對當事人產生的情緒反應。覺察反移情的來源與樣貌，才能學會辨識它何時被觸發、如何不讓它干擾專業判斷與治療關係，這正是要求準諮商心理師先接受個人治療最主要的理由，故選 A。

B：接受治療的目的是提升自我覺察與因應能力，而不是要求在助人之前「完全處理掉」所有內在衝突；衝突與未竟事務是持續終身、隨情境再度浮現的歷程，把目標訂成「完全處理掉」不合乎治療的實際樣貌，也不是個人治療的主要理由。

C：移情（transference）是當事人對心理師產生的情感投射，覺察當事人的移情反應固然重要，但那是諮商技巧與臨床訓練要處理的課題，個人治療的重點在心理師「自己」的反應模式，也就是反移情而非當事人的移情，選項把兩者的方向弄反了。

D：透過扮演當事人角色確實可能附帶增加對當事人處境的體會，但這只是接受治療的附帶效果，並非制度上要求心理師先接受治療的主要理由；核心考量仍是自我覺察與反移情管理。

本題考點：反移情（countertransference）——心理師因自身未竟議題而對當事人產生的情緒反應；個人治療（personal therapy）於諮商師訓練中的功能——提升自我覺察、辨識並管理反移情以保護治療關係。

第 25 題

當家長帶領網路成癮個案前來求助時，下列諮商心理師的專業作法何者最不適切？
  1. （A）協助個案對自己的上網行為有病識感
  2. （B）協助個案覺察導致過度上網的潛在心理困擾
  3. （C）建議家長接受個案因心理困擾而沉迷網路的行為
  4. （D）建議家長一起協助個案發展替代上網的正向活動

答案：（C）

詳解與考點

正解：面對網路成癮個案，諮商心理師的專業目標之一，是協助家長理解「過度上網」背後常隱藏著個案未被處理的心理困擾（如人際挫折、課業壓力、家庭衝突等），並進一步協助家長與個案一起發展替代性的正向因應方式，而不是讓家長單純「接受」個案沉迷網路的行為本身。建議家長「接受個案因心理困擾而沉迷網路的行為」，等於把沉迷網路這個適應不良的因應方式正常化、放任其持續，缺乏進一步協助個案發展病識感、覺察潛在困擾、建立替代活動等積極介入方向，是最不適切的專業建議，故選 C。

A：協助個案對自己的上網行為建立病識感，是介入網路成癮的第一步，唯有個案自己能覺察行為的失控與影響，後續改變的動機才有可能建立，是合宜且必要的做法。

B：協助個案覺察導致過度上網的潛在心理困擾（如逃避現實壓力、尋求人際歸屬感等），是從根本處理成癮行為背後成因的重要介入方向，有助於個案理解自己「為什麼」會沉迷網路，是合宜的專業做法。

D：建議家長一起協助個案發展替代上網的正向活動（如運動、社團、其他興趣），是實務上常用且有效的介入策略，透過建立其他能滿足需求、帶來成就感的活動，逐步降低對網路的依賴，是合宜且具建設性的建議。

本題考點：網路成癮的介入原則（internet addiction intervention）——著重病識感建立、潛在心理困擾覺察與替代活動發展，而非放任接受成癮行為；家庭系統在成癮介入中的角色——家長的態度與參與方式直接影響介入成效。
