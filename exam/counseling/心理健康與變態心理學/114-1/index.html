第 1 題

下列有關Super生涯發展論的階段描述，何者錯誤？
  1. （A）建立期是15～24歲，特性為選擇範圍縮小，尚未做決定
  2. （B）成長期是出生～15歲，特性為發展態度、能力、興趣、需求
  3. （C）衰退期是65歲以後，特性為退休前考慮，工作輸出，最後退休
  4. （D）維持期是45～65歲，特性為調適過程，維持工作地位、情境

答案：（A）

詳解與考點

考點為 Super 生涯發展論的階段與年齡。建立期約 25～44 歲，特性為建立穩定職位；15～24 歲應為探索期，故 A 把建立期說成 15～24 歲且尚未做決定為錯誤敘述。陷阱在成長、維持、衰退三期描述大致正確，易忽略建立期的年齡被張冠李戴。

第 2 題

大中是家中長子，父親早逝，他身兼父職，常常需要犧牲課業與興趣，照顧母親與弟妹。大中最可能因為下列何種現象而出現身心困擾？
  1. （A）性別角色衝突（gender role conflict）
  2. （B）角色累積（role accumulation）
  3. （C）角色過度負荷（role overload）
  4. （D）角色模糊（role ambiguity）

答案：（C）

詳解與考點

考點為角色壓力的類型。大中同時承擔課業與照顧家庭的多重要求、時間精力不足，屬角色過度負荷（role overload），故選 C。陷阱在角色累積（B）指多重角色帶來的正向資源，與此處的負荷困擾相反；角色模糊（D）則指職責不清，並非本題的負荷過重。

第 3 題

家庭的功能之一是要幫助家庭成員自我分化（differentiation of self），根據此理念，下列何者錯誤？
  1. （A）幫助家庭成員建立清楚的自我界線
  2. （B）接納家人的不同期待，但也保有自己的獨特需求
  3. （C）滿足做自己的需求，不被家人影響
  4. （D）太僵化或黏密的家庭關係，較不利於家庭成員自我分化

答案：（C）

詳解與考點

考點為 Bowen 家庭系統的自我分化。分化是在連結與獨立間取得平衡，能保有自我又與家人情感連結，故 C「不被家人影響」過度切割、屬未分化的情緒切斷，為錯誤。陷阱是把「分化」誤解為完全不受影響的孤立，其實健康分化仍維持關係。

第 4 題

「喜歡獨立自主，不願意相信別人，避免情感上過度依賴而受到傷害」，根據Bartholomew等人研究，這是屬於下列何種愛情依附風格？
  1. （A）安全型（secure）
  2. （B）恐懼型（fearful）
  3. （C）過分投入型（preoccupied）
  4. （D）排拒型（dismissing）

答案：（D）

詳解與考點

考點為 Bartholomew 的成人依附四型。題述喜歡獨立、不信任他人、避免依賴，屬正向自我、負向他人的排拒型（dismissing），故選 D。陷阱在恐懼型（B）也逃避親密，但其自我評價為負、既渴望又害怕，與排拒型的高自我、主動疏離不同。

第 6 題

睡眠對適應負荷（allostatic load）的影響最能說明影響適應負荷的那個因素？
  1. （A）暴露總量（amount of exposure）
  2. （B）反應性大小（magnitude of reactivity）
  3. （C）恢復速率（rate of recovery）
  4. （D）資源回復（resource restoration）

答案：（D）

詳解與考點

考點為適應負荷（allostatic load）的影響因素。睡眠提供身體系統休養與資源再補充，最能說明資源回復（resource restoration）這個因素，故選 D。陷阱在恢復速率（C）指壓力反應消退快慢，與睡眠提供的資源再生不同，易混淆兩者概念。

第 7 題

下列何者不屬於HPA軸？
  1. （A）海馬迴
  2. （B）腎上腺
  3. （C）腦下垂體
  4. （D）下視丘

答案：（A）

詳解與考點

考點為 HPA 軸組成。HPA 即下視丘（Hypothalamus）、腦下垂體（Pituitary）、腎上腺（Adrenal）三者，海馬迴雖參與壓力調節與回饋，但不屬 HPA 軸三元件，故選 A。陷阱是因海馬迴與壓力記憶有關而誤以為它是 HPA 軸的一環。

第 8 題

關於疼痛（pain）的敘述，下列何者正確？
  1. （A）痛覺訊息傳遞到脊髓，進而傳遞到大腦，由杏仁核（amygdala）接收訊息
  2. （B）任何疼痛都可找到生理上的原因
  3. （C）身體疼痛與社會拒絕造成的「心痛」，在腦部的激發位置很類似
  4. （D）大腦是疼痛的控制閘門，可調節疼痛的程度

答案：（C）

詳解與考點

考點為疼痛的神經機制。研究顯示身體疼痛與社會排斥的「心痛」在前扣帶迴等腦區激發位置相似，故 C 正確。陷阱在 D「大腦是疼痛控制閘門」混淆了閘門控制理論（閘門在脊髓），A、B 則為過度絕對的錯誤敘述。

第 9 題

相對於男性，女性面對壓力時的反應，下列何者正確？
  1. （A）有較多戰和逃的反應
  2. （B）壓力生理反應較大
  3. （C）要花比較久的時間，讓壓力生理反應回復到基準期
  4. （D）有較多親和與友善的反應以維持親近的社會連結

答案：（D）

詳解與考點

考點為性別的壓力反應差異。Taylor 提出女性面對壓力較傾向「照顧與結盟」（tend-and-befriend），以親和友善維持社會連結，故選 D。陷阱在「戰或逃」（A）為較傳統男性化的反應描述，B、C 的生理反應較大或回復較慢亦無一致支持。

第 10 題

以生理指標評估個體的壓力程度，通常會採集其血液、尿液或口水，檢驗腎上腺在壓力下所分泌的賀爾蒙濃度，其測量的指標，不包括下列何者？
  1. （A）皮質醇（cortisol）
  2. （B）腎上腺素（epinephrine）
  3. （C）褪黑激素（melatonin）
  4. （D）正腎上腺素（norepinephrine）

答案：（C）

詳解與考點

考點為壓力的腎上腺激素指標。皮質醇、腎上腺素、正腎上腺素皆由腎上腺分泌、是壓力常用指標，褪黑激素（melatonin）由松果體分泌、調節睡眠節律，不屬腎上腺壓力荷爾蒙，故選 C。陷阱是因褪黑激素與壓力、睡眠相關而誤選為壓力指標。

第 11 題

關於工作耗竭（job-related burnout），下列敘述何者錯誤？
  1. （A）工作耗竭多為壓力引發
  2. （B）職場新鮮人最容易面臨此問題
  3. （C）改善職場人際問題是一種防止工作耗竭的方法
  4. （D）了解一個人對工作抱持的期許，有助於了解其是否會面臨工作耗竭

答案：（B）

詳解與考點

考點為工作耗竭（burnout）的成因與防治。耗竭多由長期壓力累積，與期望落差、職場人際有關，並非職場新鮮人最易面臨，故 B 為錯誤敘述。陷阱在直覺認為新人壓力大易耗竭，但耗竭通常發生於投入一段時間、理想與現實落差顯現之後。

第 12 題

關於自殺防治，下列敘述何者正確？
  1. （A）自殺防治研究困難度高，結果也顯示效果有限
  2. （B）只有少數自殺者是在衝動下執行的
  3. （C）討論此議題可能導致自殺率提高
  4. （D）服用理思必妥（Risperidone）有助於降低思覺失調症患者自殺企圖

答案：（D）

詳解與考點

考點為自殺防治實證。正解 D：研究顯示理思必妥等抗精神病藥可降低思覺失調症患者自殺企圖（最強證據為 clozapine）。陷阱在 C「討論自殺會提高自殺率」是常見迷思，適當談論反能降低風險；A 防治雖難仍有成效、B 多數自殺含衝動成分，皆與實證不符。

第 13 題

根據Maton與Salem（1995）的研究，發現四項能激勵員工賦權的機構特徵，下列何者錯誤？
  1. （A）重視缺點之檢討與改善
  2. （B）支持系統以同儕為基礎
  3. （C）主管領導風格具啟發性
  4. （D）鼓勵員工自我成長

答案：（A）

詳解與考點

考點為 Maton 與 Salem（1995）員工賦權的機構特徵。研究指出啟發性領導、以同儕為基礎的支持、鼓勵自我成長等正向特徵，A「重視缺點之檢討與改善」非其所列特徵，故為錯誤。把握度較低，僅依概念方向判斷其偏重正向賦權而非檢討缺失。

第 14 題

職場過勞和機構因素息息相關，下列何者不是可能的機構因素？
  1. （A）能否參與決策的「控制」因素
  2. （B）個人與機構所追求目標是否一致的「價值」因素
  3. （C）能否具備飲食供給的「環境」因素
  4. （D）是否具有社會性支持的「社群」因素

答案：（C）

詳解與考點

考點為職場過勞的機構因素。Maslach 模式列出工作負荷、控制、報酬、社群、公平、價值六面向，A 控制、B 價值、D 社群皆屬之，C「飲食供給的環境因素」不在其列，故選 C。陷阱是把物理環境誤當成過勞的核心機構因素。

第 15 題

諮商心理師以青少年犯罪的知識為基礎（例如：家庭系統的可能性影響），在社區進行親職講座，對父母宣導青少年發展之困境，此種作法屬於三級預防中的那個層級？
  1. （A）初級
  2. （B）二級
  3. （C）三級
  4. （D）非屬於三級預防層級

答案：（A）

詳解與考點

考點為三級預防層級。在問題尚未發生前對父母宣導、預防青少年犯罪，屬針對一般大眾的初級（一級）預防，故選 A。陷阱在二級預防是早期篩檢高風險者、三級是已發生後的處遇與復健，本題講座為事前宣導，屬最前端的初級。

第 16 題

關於高度工作投入（high job engagement）的特徵，下列何者錯誤？
  1. （A）能發揮自己的專長與能力
  2. （B）對工作感到滿意與驕傲
  3. （C）工作就是生活的核心
  4. （D）對工作時間太長能勇敢拒絕

答案：（D）

詳解與考點

考點為高度工作投入（job engagement）的特徵。投入者通常活力、奉獻、專注，能發揮專長、感到滿意驕傲、以工作為核心（A、B、C），D「對工作時間太長能勇敢拒絕」屬界線與自我照顧，非投入的定義特徵，故為錯誤。陷阱是把健康界線誤列為投入指標。

第 17 題

關於心理障礙症（psychological disorder）的界定方式，下列敘述何者錯誤？
  1. （A）正常和異常的心理功能之間界線是清楚的，出現偏離常態的行為，必然代表有心理障礙症
  2. （B）許多人都有輕微的不適反應（例如：看到血，感到噁心），但未必構成心理障礙症
  3. （C）痛苦是每個人生活的一部分，並非所有心理障礙症都會伴隨有痛苦的感受
  4. （D）某些行為在特定文化可能被接受，但在其他文化背景可能被視為心理障礙症

答案：（A）

詳解與考點

考點為心理障礙症的界定。正常與異常並非清楚二分，偏離常態不必然代表有障礙症（須綜合痛苦、功能、文化等），故 A 為錯誤。陷阱在直覺以為「偏離常態就是異常」，但異常的判定需多重標準，非單一偏離即成立。

第 18 題

由生物心理社會模式（biopsychosocial model）角度來看糖尿病人的血糖控制，下列何者正確？
  1. （A）糖尿病是新陳代謝的問題，屬於生理疾病
  2. （B）糖尿病人的血糖容易受壓力與情緒的影響，因此只能由心理層面進行血糖控制
  3. （C）糖尿病人一旦罹病後，調整自我心理狀態、家庭工作與人際的比重以及運動飲食等的生活型態，對血糖控制將有助益
  4. （D）糖尿病人的飲食控制對血糖的影響非常大，一旦罹病就意味著自己無法控制血糖，因此只能由家人幫忙進行飲食控制

答案：（C）

詳解與考點

考點為生物心理社會模式看慢性病。此模式強調生理、心理、社會交互作用，故 C 主張罹病後調整心理、家庭工作人際與生活型態有助血糖控制最正確。陷阱在 A 只談生理、B 只談心理、D 只談飲食或無力感，皆為單一面向的窄化觀點。

第 19 題

關於診斷與評估的信度（reliability）與效度（validity），下列敘述何者正確？
  1. （A）不穩定或不可靠的測量，仍可以獲得良好的效度
  2. （B）內部一致性信度（internal consistency reliability）是指兩位醫師對心理障礙症診斷的一致性
  3. （C）有高信度的測驗工具，可保證一定有高效度
  4. （D）測驗複本（alternate-form）所獲得的測量分數一致性高，讓心理師在評估工具選擇上有更多的選項

答案：（D）

詳解與考點

考點為信度與效度。複本（alternate-form）分數一致性高代表測量穩定，可提供更多評估工具選擇，故 D 正確。陷阱在 B 把內部一致性誤當評分者間一致性，C 高信度不保證高效度（信度為效度必要非充分），A 不可靠就難有好效度。

第 20 題

關於診斷的類別（categorical）與向度（dimensional）取向之敘述，下列何者正確？
  1. （A）類別分類取向可以精確描述出單一個體的獨特性
  2. （B）向度診斷系統描述了症狀的嚴重程度，例如：對憂鬱情緒使用1～10分來做評分
  3. （C）向度診斷系統沒有辦法幫助我們找出亞臨床（subclinical）的個體
  4. （D）類別分類取向在心理障礙症診斷所設定的診斷標準，例如：同時呈現其中的4個症狀才符合某診斷，都具有充分的研究證據支持

答案：（B）

詳解與考點

考點為類別取向與向度取向。向度系統以連續分數描述症狀嚴重度（如憂鬱 1～10 分評分），故 B 正確。陷阱在 A 類別取向難呈現個體獨特性、C 向度反而較能辨識亞臨床、D 類別診斷的切點未必都有充分證據，皆為錯誤敘述。

第 21 題

有關自閉症類群障礙症（ASD）的基因病理，下列敘述何者錯誤？
  1. （A）基因相似度的貢獻度最高
  2. （B）共享環境有顯著的貢獻
  3. （C）非共享環境也可解釋ASD的風險
  4. （D）ASD可由特定的單一基因所決定

答案：（D）

詳解與考點

考點為自閉症類群障礙症（ASD）的基因病理。ASD 為多基因加環境的複雜遺傳，基因相似度貢獻高、共享與非共享環境皆有作用，D「可由特定單一基因決定」與多基因本質相違，故為錯誤。陷阱是誤以為 ASD 有單一致病基因。

第 22 題

關於DSM-5-TR中對適應障礙症的描述，下列何者正確？
  1. （A）為獨立診斷，屬於思覺失調譜系中的一類疾病
  2. （B）是壓力事件發生之後三天到一個月內出現的情緒與行為症狀
  3. （C）是可辨識的壓力事件發生後三個月內出現的顯著情緒或行為症狀，在壓力源停止後症狀未持續超過六個月
  4. （D）壓力等同於創傷，因此許多生活瑣事累積的情緒與行為困擾應視同創傷後壓力症進行治療

答案：（C）

詳解與考點

考點為 DSM-5-TR 適應障礙症準則。可辨識壓力源後三個月內出現顯著情緒或行為症狀、壓力源消失後症狀不超過六個月，故 C 正確。陷阱在 B 將其與急性壓力症的時程混淆，A 誤歸思覺失調譜系，D 把一般壓力等同創傷，皆錯。

第 23 題

下列何者不是DSM-5中性功能障礙（sexual dysfunction）定義的面向？
  1. （A）性慾
  2. （B）高潮
  3. （C）疼痛
  4. （D）對象

答案：（D）

詳解與考點

考點為 DSM-5 性功能障礙的界定面向。其涵蓋性慾、興奮/喚起、高潮、性交疼痛等面向，「對象」屬性偏好或性別取向議題，不在性功能障礙的定義面向，故選 D。陷阱是把伴侶或對象因素誤當成性功能障礙的診斷向度。

第 24 題

有關思覺失調症的描述，下列何者錯誤？
  1. （A）終生盛行率約為3％
  2. （B）遺傳傾向明顯
  3. （C）男性個案的預後較差
  4. （D）女性平均好發年齡較晚

答案：（A）

詳解與考點

考點為思覺失調症的流行病學。其終生盛行率約 1%（非 3%），故 A 為錯誤。陷阱在遺傳傾向明顯、男性預後較差、女性好發年齡較晚（B、C、D）皆正確，易因記不清盛行率數字而漏選 A 這個被誇大的數據。

第 25 題

雨辰對飲食失去了控制，她經常會狼吞虎嚥地吃下大量的高油高鈉餐點，經常在30分鐘內就攝取熱量超過2,000卡路里以上。這導致雨辰的體重持續迅速增加，BMI達30以上。下列何者最符合雨辰的診斷？
  1. （A）暴食症（bulimia nervosa）
  2. （B）厭食症（anorexia nervosa）
  3. （C）嗜食症（binge eating disorder）
  4. （D）過重（overweight）

答案：（C）

詳解與考點

考點為飲食障礙症的鑑別。雨辰反覆大量暴食、體重增加、BMI≥30，但題述未提及催吐等代償行為，最符合嗜食症（binge eating disorder），故選 C。陷阱在暴食症（A）有暴食加上代償行為（如催吐），本題缺代償，故非暴食症。

第 26 題

對於廣泛性焦慮症（generalized anxiety disorder, GAD）的敘述，下列何者正確？
  1. （A）GAD的症狀以擔憂為主，鮮少出現生理相關症狀（例如疲倦、肌肉緊繃）
  2. （B）個案須持續經驗過度、無法控制的擔憂至少三個月以上才能診斷為GAD
  3. （C）認知觀點認為GAD個案可能是利用擔憂來迴避更為強烈的負向情緒
  4. （D）GAD一旦慢性化之後，就不會再對重要生活領域造成干擾

答案：（C）

詳解與考點

考點為廣泛性焦慮症（GAD）。認知觀點主張個案以擔憂來迴避更強烈的負向情緒（迴避理論），故 C 正確。陷阱在 A 忽略 GAD 常伴疲倦、肌肉緊繃等生理症狀，B 診斷需擔憂至少六個月（非三個月），D 慢性化仍會干擾生活，皆錯。

第 27 題

關於思覺失調型人格障礙症（schizotypal personality disorder），下列敘述何者正確？
  1. （A）不會經歷任何精神病性發作（psychotic episodes）
  2. （B）有過度的社交焦慮，且社交焦慮程度不會因熟悉而減少
  3. （C）多數會逐漸發展成思覺失調症
  4. （D）最主要的症狀是妄想

答案：（B）

詳解與考點

考點為思覺失調型人格障礙症（schizotypal）。其核心為認知知覺扭曲與古怪行為，並有過度社交焦慮且不因熟悉而減少，故 B 正確。陷阱在 A 仍可能有短暫精神病性發作、C 多數不會發展成思覺失調症、D 妄想非其最主要症狀，皆錯。

第 28 題

根據DSM-5，畏避型人格障礙症（avoidant personality disorder）的行為描述及診斷準則，下列何者最正確？
  1. （A）雖然渴望感情，但因害怕他人拒絕，因而逃避與他人接觸
  2. （B）要求完美，極端重視次序維持
  3. （C）常見的共病為妄想型人格障礙症（paranoid personality disorder）
  4. （D）日本文化出現「對人畏懼症（taijin kyoufusho）」是指對人恐懼，症狀表現等同於DSM-5的畏避型人格障礙症

答案：（A）

詳解與考點

考點為畏避型人格障礙症（avoidant）。其特徵是渴望感情卻因怕被拒絕而逃避人際接觸，故 A 最正確。陷阱在 B 描述強迫型人格、D 誤把日本「對人畏懼症」完全等同畏避型（兩者文化內涵與表現有別），C 共病敘述亦不準確。

第 29 題

關於強迫症的敘述，下列何者錯誤？
  1. （A）強迫症可能在十歲之前發病
  2. （B）強迫症個案通常沒有病識感
  3. （C）大多數的強迫症症狀都是慢性化的
  4. （D）強迫症個案往往難以做決定

答案：（B）

詳解與考點

考點為強迫症（OCD）。多數強迫症個案其實有病識感、知道想法不合理卻無法控制，故 B「通常沒有病識感」為錯誤。陷阱在可能十歲前發病、症狀多慢性化、常難以決斷（A、C、D）皆正確，易把 OCD 誤想成缺乏自知。

第 30 題

關於莫瑞爾雙因素模式（Mowrer's two-factor model）對焦慮症發展歷程的敘述，下列何者正確？
  1. （A）古典制約歷程可解釋害怕或焦慮如何形成
  2. （B）古典制約形成的關鍵在於制約刺激與制約反應的連結
  3. （C）操作制約可說明那些中性刺激會引發焦慮
  4. （D）操作制約說明迴避行為增強害怕或焦慮反應

答案：（A）

詳解與考點

考點為 Mowrer 雙因素模式。第一因素古典制約解釋害怕/焦慮如何形成，故 A 正確。陷阱在 B 古典制約關鍵是制約刺激與「非制約刺激」連結（非與制約反應），C 引發焦慮屬古典制約，D 操作制約的迴避行為是「維持」非增強害怕，皆錯。

第 31 題

關於飲食障礙症病因的敘述，下列何者正確？
  1. （A）雙生子研究發現，遺傳可解釋暴食症60％的變異量
  2. （B）厭食症與暴食症個案體內血清素代謝物的含量偏低
  3. （C）厭食症個案看到食物時腦部背紋狀體區的GABA活動增加
  4. （D）飲食障礙症女性個案的DRD2多巴胺基因之表現過多

答案：（B）

詳解與考點

考點為飲食障礙症的神經生物病因。研究發現厭食症與暴食症個案體內血清素代謝物含量偏低，故 B 正確。把握度中等，A 遺傳變異量數字、C 背紋狀體 GABA、D DRD2 表現等細節較冷僻，多為與實證不符的錯誤敘述，故依概念方向選 B。

第 32 題

王小姐在被診斷出罹患第一期乳癌後便寢食難安、憂心病情惡化以及治療的副作用，甚至失去與朋友來往的動力，也不再做家事。依據DSM-5，王小姐最符合的診斷是下列何者？
  1. （A）創傷後壓力症
  2. （B）焦慮症
  3. （C）社交焦慮症
  4. （D）適應障礙症

答案：（D）

詳解與考點

考點為適應障礙症的鑑別。王小姐在可辨識壓力源（確診乳癌）後出現顯著情緒與功能退縮，未達創傷後壓力症或特定焦慮症準則，最符合適應障礙症，故選 D。陷阱在症狀像焦慮（B）或社交退縮（C），但成因明確是壓力事件反應，應歸適應障礙症。

第 33 題

注意力不足／過動症治療中，設計最好的隨機控制臨床研究為多模式治療（MTA），進行14個月的研究，比較標準社區照顧、單獨藥物治療、藥物治療加父母及教師密集行為治療、單獨行為治療四種治療方式。下列針對多模式治療的敘述何者錯誤？
  1. （A）單獨接受藥物治療的兒童比單獨接受行為治療的兒童有更多的注意力不足／過動症症狀
  2. （B）接受合併治療的效果稍微優於單獨藥物治療
  3. （C）合併治療比單獨藥物治療更能改變社交技巧功能
  4. （D）單獨藥物治療和合併治療優於社區照顧

答案：（A）

詳解與考點

考點為 ADHD 的 MTA 多模式治療研究。研究顯示單獨藥物對核心症狀效果優於單獨行為治療，故 A「單獨藥物者比單獨行為治療者有更多 ADHD 症狀」與結果相反，為錯誤。陷阱在 B、C、D（合併略優、改善社交、皆優於社區照顧）皆符合 MTA 結論。

第 34 題

關於認知障礙症家屬的描述，下列何者最正確？
  1. （A）家屬通常對於個案不甚關心
  2. （B）家屬罹患憂鬱症的機率高
  3. （C）家屬通常能夠得心應手地照顧個案
  4. （D）家屬很少有睡眠困擾

答案：（B）

詳解與考點

考點為認知障礙症（失智症）照顧者的身心。長期照顧負荷使家屬罹患憂鬱症機率偏高，故 B 最正確。陷阱在 A 不關心、C 得心應手、D 很少睡眠困擾，皆與照顧者壓力與負荷的研究發現相反，屬過度樂觀的錯誤描述。

第 35 題

針對罹病焦慮症（illness anxiety disorder）的認知行為治療，下列何者敘述正確？
  1. （A）引導個案專注於身體的某些部分來創造症狀，容易讓個案產生失控感受
  2. （B）針對罹病的焦慮，教導個案要尋求醫師提供足夠的保證
  3. （C）讓個案反覆接觸與健康相關的材料，例如：疾病衛教片，同時需配合有讓其安心的保證，才能減少對疾病的焦慮症狀
  4. （D）認知行為治療著重在辨別和挑戰個案對身體感覺的錯誤解釋

答案：（D）

詳解與考點

考點為罹病焦慮症（illness anxiety）的認知行為治療。CBT 著重辨識並挑戰個案對身體感覺的錯誤解釋，故 D 正確。陷阱在 B、C 教個案尋求醫師保證或安心保證，反而強化尋求保證的維持行為，與 CBT 減少安全行為的原則相違。

第 36 題

暴露及反應防止法（exposure and response prevention, ERP）最不適用下列何種心理障礙症？
  1. （A）轉化症
  2. （B）身體臆形症
  3. （C）儲物症
  4. （D）強迫症

答案：（A）

詳解與考點

考點為暴露及反應防止法（ERP）的適用。ERP 對強迫症、身體臆形症、儲物症等強迫相關障礙有效，轉化症（功能性神經症狀）機制不同，最不適用，故選 A。陷阱是把 ERP 視為通用焦慮療法，忽略轉化症並非以強迫迴避為核心的問題。

第 37 題

對於菸癮的治療模式，下列敘述何者錯誤？
  1. （A）尼古丁貼片的療效較安慰劑貼片好
  2. （B）立即性戒斷法比逐漸性戒斷法有效
  3. （C）尼古丁替代法（例如口香糖）可以逐漸替代對於抽菸的渴望
  4. （D）尼古丁替代法結合心理治療，比起只採替代療法更有效

答案：（B）

詳解與考點

考點為菸癮的治療實證。研究上立即性（一次性）戒斷與逐漸減量戒斷效果相近，並無「立即性必然比逐漸性有效」的定論，故 B 為錯誤敘述。陷阱在尼古丁貼片優於安慰劑、替代法可減渴求、替代結合心理治療更佳（A、C、D）皆正確。

第 38 題

下列何種生活型態，最不建議用來減緩認知退化的發生或降低認知障礙症風險？
  1. （A）從事社交活動
  2. （B）從事需要智力的活動
  3. （C）增加運動的介入
  4. （D）服用抗精神病藥物

答案：（D）

詳解與考點

考點為延緩認知退化的生活型態。社交活動、智力活動、運動皆有保護作用，服用抗精神病藥物不僅無預防效果、對失智者反增風險，故最不建議選 D。陷阱是誤把藥物當成積極預防手段，實則認知退化預防重在生活型態介入。

第 39 題

關於有效改善身體症狀障礙症的疼痛症狀，下列何種治療法最不適當？
  1. （A）接受與承諾治療
  2. （B）認知行為治療
  3. （C）催眠
  4. （D）高劑量的抗憂鬱劑

答案：（D）

詳解與考點

考點為身體症狀障礙症疼痛的治療。接受與承諾治療、認知行為治療、催眠皆為實證或常用的非藥物選項，「高劑量抗憂鬱劑」非首選且風險高，最不適當，故選 D。陷阱是直覺以為加重藥物劑量能更有效止痛，忽略此類疼痛重在心理介入。

第 40 題

關於身體臆形症（body dysmorphic disorder, BDD）的介入，下列敘述何者正確？
  1. （A）治療方式和強迫症有明顯不同
  2. （B）認知行為治療療效不如純藥物治療
  3. （C）藥物治療最常使用抗憂鬱劑
  4. （D）BDD鮮少和社交焦慮症（social phobia）共病，故社交焦慮症的治療方式無參考價值

答案：（C）

詳解與考點

考點為身體臆形症（BDD）的介入。BDD 藥物治療最常使用抗憂鬱劑（特別是 SSRI），故 C 正確。陷阱在 A、D 否認 BDD 與強迫症及社交焦慮症的關聯（其實治療相近、常與社交焦慮共病），B 貶低 CBT 療效，皆與實證不符。
