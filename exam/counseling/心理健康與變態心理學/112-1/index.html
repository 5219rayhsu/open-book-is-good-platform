第 1 題

關於自我概念的研究發現，下列敘述何者正確？
  1. （A）生物界中，只有人類、猴子、海豚可以辨識自我
  2. （B）在內在的面向我對自己的瞭解，比友人對我的瞭解更正確
  3. （C）「獨立我」的人比「互依我」的人對自己的了解更正確
  4. （D）在具評價性的面向上，我對自己的瞭解，並不比友人對我的瞭解更正確

答案：（D）

詳解與考點

考點為自我概念與自我認識的準確性研究。正解D正確：在具評價性的面向上，他人觀察往往比自評更客觀，故自我了解並不比友人更正確。陷阱在B，認為內在面向自己一定比友人更了解，忽略自我評價在評價性向度上的偏誤。

第 2 題

Rosenzweig將挫折進行分類，以下何者錯誤？
  1. （A）吃不飽可能導致「匱乏挫折」
  2. （B）設定較高的人生目標有助於產生追求的動機，挫折感自然就低
  3. （C）失戀導致的挫折來自失去曾擁有的感情
  4. （D）返鄉的遊子因火車誤點可能導致「阻礙挫折」

答案：（B）

詳解與考點

考點為Rosenzweig的挫折分類。正解B錯誤：設定過高目標通常會「增加」挫折感，而非自然降低，此敘述邏輯與挫折理論相反。其餘匱乏挫折（吃不飽）、失去挫折（失戀）、阻礙挫折（火車誤點）皆為其正確分類舉例。

第 3 題

「對他人常作敵意性歸因、負面解讀他人行為的人，其攻擊行為可能較高。」此一陳述主要符合下列何種對攻擊的理論？
  1. （A）挫折－攻擊假說
  2. （B）社會學習理論
  3. （C）社會生物學理論
  4. （D）社會訊息處理理論

答案：（D）

詳解與考點

考點為攻擊行為理論。正解D社會訊息處理理論：對他人作敵意歸因、負面解讀其行為而引發攻擊，正是該理論強調的認知偏誤機制。陷阱在A挫折-攻擊假說，強調的是受阻挫折引發攻擊，而非歸因解讀歷程，故不符題意。

第 4 題

正向心理學所提出的正向心理特質不包括下列那一項？
  1. （A）自尊
  2. （B）順從
  3. （C）控制感
  4. （D）樂觀

答案：（B）

詳解與考點

考點為正向心理學的正向特質。正解B順從不屬於正向心理特質。正向心理學重視自尊、控制感、樂觀、希望等促進幸福與適應的優勢，順從並非其列舉的正向人格力量，故為應選的「不包括」項。

第 5 題

Hans Selye提出的「一般適應症候群」（General Adaptation Syndrome, GAS）主張壓力反應是非特定性的（nonspecific），其論點受到學者質疑而提出不同反證，關於學者提出的反證不包括下列何者？
  1. （A）個體對短期立即壓力和長期慢性壓力有不同的生理反應
  2. （B）有些壓力比起其他壓力引發更強的情緒反應
  3. （C）個體的壓力反應與其努力程度及痛苦程度有關
  4. （D）個體的壓力反應與其認知評估歷程有關

答案：（A）

詳解與考點

本題問「不包括」哪一項反證，官方答案為 (A)。Selye 的一般適應症候群（GAS）主張壓力反應是非特定性的（nonspecific），即不論壓力源為何，身體都以相同的生理反應模式（警覺、抵抗、耗竭）回應。後續學者的反證，核心在於指出壓力反應其實會「因壓力源性質或個體歷程而異」，從而反駁「非特定」。(B)（不同壓力引發不同強度情緒反應）、(C)（反應與努力及痛苦程度有關）、(D)（反應與認知評估歷程有關，呼應 Lazarus 的評估理論）都直接說明反應因壓力種類、情緒或認知歷程而不同，屬於反駁非特定性的證據。(A)「對短期與長期壓力有不同生理反應」描述的是同一壓力源在不同時間歷程的反應差異，本即與 GAS 的階段觀相容，並非用來反駁「非特定性」的核心證據，故 (A) 不包括在內、為正解。

第 6 題

李小姐是機場飛航管制員，需要目視指揮飛機從準備的滑行到起飛，每天的工作壓力都很大，在這種慢性壓力狀態下，其免疫功能可能因為那一種激素長期分泌而受影響？
  1. （A）甲狀腺素（thyroid hormones）
  2. （B）胰高血糖素（glucagon）
  3. （C）胰島素（insulin）
  4. （D）可體松（cortisol）

答案：（D）

詳解與考點

考點為慢性壓力與免疫。正解D可體松（皮質醇）：長期壓力使HPA軸持續分泌可體松，會抑制免疫功能。陷阱在A甲狀腺素，雖與代謝有關，但長期壓力抑制免疫的核心壓力激素是可體松，並非甲狀腺素。

第 7 題

一般而言，包括快速眼動期（rapid eye movement, REM）與非快速眼動期（non-REM）的一個睡眠週期大約幾分鐘？
  1. （A）30分鐘
  2. （B）50分鐘
  3. （C）70分鐘
  4. （D）90分鐘

答案：（D）

詳解與考點

考點為睡眠週期長度。正解D約90分鐘：一個包含非快速眼動與快速眼動期的完整睡眠週期約90分鐘，一夜循環約4至6次。其餘30、50、70分鐘皆短於標準週期長度，為常見的數字干擾項。

第 8 題

壓力（stress）與健康息息相關，值得高度關注，請問以下何者正確？
  1. （A）壓力為個體對內部或外部壓力源（stressor）生理或心理反應
  2. （B）壓力有其正面意義，長期暴露於壓力之中，會讓個體保持高度專注
  3. （C）壓力因應唯有靠自己，與社會支持無關
  4. （D）每個人對壓力的感受是穩定的

答案：（A）

詳解與考點

考點為壓力的基本概念。正解A正確：壓力是個體對內外壓力源的生理或心理反應。其餘為錯誤敘述：長期暴露壓力有害而非保持專注、壓力因應與社會支持高度相關、每個人對壓力的感受具個別差異並非穩定不變。

第 9 題

暴露於壓力中，可能導致個體罹患身心疾病的因素，包括以下何者？①免疫系統反應②交感神經系統反應③人格特質④壓力因應策略⑤社會支持程度
  1. （A）僅①②③④
  2. （B）僅①②④⑤
  3. （C）僅①③④⑤
  4. （D）①②③④⑤

答案：（D）

詳解與考點

考點為壓力致病的多重因素。正解D全選①②③④⑤：免疫反應、交感神經反應、人格特質、因應策略與社會支持程度皆會影響壓力是否導致身心疾病。本題為整合題，五項皆屬公認的壓力-健康中介或調節因子。

第 10 題

急性和慢性疼痛對個體造成的影響不同，關於疼痛的敘述，下列何者正確？
  1. （A）有急性疼痛的人常採用適應不良的因應方式
  2. （B）慢性疼痛者多有憂鬱問題
  3. （C）醫學的疼痛控制技術對慢性疼痛效果佳
  4. （D）不管急性還是慢性，對生活造成的影響大同小異

答案：（B）

詳解與考點

考點為急慢性疼痛差異。正解B正確：慢性疼痛者多伴隨憂鬱問題。其餘為錯誤：適應不良因應較多見於慢性而非急性、醫學疼痛控制對慢性疼痛效果有限、急慢性疼痛對生活影響差異甚大並非大同小異。

第 11 題

有關賦權（empowerment）在社區工作的概念，下列敘述何者最正確？
  1. （A）社區工作者是問題解決的專家，分析案主生態優劣，為其解決生態系統的問題
  2. （B）以案主的生態系統為基礎，連結其優點與能力，主動參與社會政策與社會改革來面對生活困境
  3. （C）讓案主可以感知自身的全能，主動解決自身所面臨的問題
  4. （D）社區工作者是被動的工作者，避免接受案主的請託與要求

答案：（B）

詳解與考點

考點為社區工作的賦權概念。正解B最正確：賦權以案主生態系統為基礎，連結其優勢與能力，主動參與社會政策與改革。陷阱在A與C，把工作者當全能專家替案主解決、或讓案主感到「全能」皆非賦權，賦權強調協力與能力培力而非代理。

第 12 題

關於目前多數研究學者認為預測個體主觀幸福感的因素，下列何者錯誤？
  1. （A）社會關係
  2. （B）工作身分
  3. （C）財富增加
  4. （D）身體健康

答案：（C）

詳解與考點

考點為主觀幸福感的預測因子。正解C錯誤：研究多顯示財富「增加」與幸福感關聯有限（超過基本所得後邊際效益遞減），並非穩定預測因子。社會關係、健康等才是較強預測因子，工作身分亦有一定影響。

第 13 題

組織中的社會支持（social support）可以協助工作者因應壓力，下列敘述何者錯誤？
  1. （A）社會支持可以降低警察在緊急事件的焦慮
  2. （B）護士的彼此支持可以減低一般壓力程度，也可以協助妥善面對病人死亡之處境
  3. （C）社會支持可以協助被解僱人員降低失業的衝擊
  4. （D）在所有的機構，社會支持都可促進工作者健康

答案：（D）

詳解與考點

考點為組織中的社會支持。正解D錯誤：社會支持的效果並非在「所有」機構皆能促進健康，效果受情境與支持品質影響，過度絕對化的全稱敘述有誤。其餘關於警察、護士、被解僱者的支持效果皆為合理研究發現。

第 14 題

若在捷運、火車或高鐵月台架設月台門，來阻隔月台與列車行經之軌道，以防止民眾臥軌自殺事件的發生。從自殺防治的角度，其最主要的理由為下列何者？
  1. （A）因為月台門的架設讓民眾感受到安全
  2. （B）因為難以看到軌道，就不會誘發死的本能
  3. （C）因為月台門增加了自殺行動的困難度
  4. （D）因為月台門通常會貼有珍惜生命的標語

答案：（C）

詳解與考點

考點為自殺防治的手段限制（means restriction）。正解C：月台門透過增加自殺行動的困難度與阻隔可及性來預防衝動性自殺，是手段限制的核心理由。陷阱在B「死的本能」屬精神分析概念，與自殺防治的環境限制策略無關。

第 15 題

關於目前學生輔導法針對高級中等以下學校專任輔導教師員額編制，下列敘述何者錯誤？
  1. （A）國民小學二十四班以下者，員額編制為一人
  2. （B）一所共有十五班的國民中學，該校員額編制為一人
  3. （C）專任輔導教師除輔導相關課程外，也可安排其他科目授課
  4. （D）高級中等學校十二班以下者，員額編制為一人

答案：（C）

詳解與考點

考點為學生輔導法的專任輔導教師員額。正解C錯誤：依法專任輔導教師應專責輔導工作，不得排授輔導以外的其他科目，「可安排其他科目授課」與法規相違。其餘國中小與高中職的班級數對應員額敘述符合規定。

第 16 題

關於心血管疾病的心理社會復健計畫的研究結果，下列敘述何者正確？
  1. （A）電話諮商服務對於心血管疾病患者的憂鬱是無效的
  2. （B）參與復健計畫數年後，死亡風險降低20%～25%
  3. （C）對女性有效，男性不盡然
  4. （D）認知行為治療能減少心臟病發作和死亡率

答案：（B）

詳解與考點

考點為心血管疾病的心理社會復健研究。正解B正確：參與復健計畫數年後死亡風險可降低約20%至25%。其餘為錯誤：電話諮商對憂鬱並非無效、效果並非僅限女性、CBT雖有助情緒但減少心臟病發作與死亡率的直接證據敘述不正確。

第 17 題

有關唐氏症（Down syndrome）的敘述，下列何者錯誤？
  1. （A）因為染色體疾病之故，多有心血管疾病
  2. （B）為第18對染色體的三管體（trisomy）病變
  3. （C）智力發展與動作發展在早期往往較一般同齡兒童緩慢
  4. （D）外觀上也稍異於常人（如鼻樑低、雙眼間距較大等）

答案：（B）

詳解與考點

考點為唐氏症的病因。正解B錯誤：唐氏症為第21對染色體三體（trisomy 21），而非第18對；第18對三體是愛德華氏症。其餘合併心血管疾病、早期智力動作發展遲緩、外觀特徵皆為唐氏症的正確描述。

第 18 題

下列何者不是智能不足（intellectual disability）最常共病（comorbidity）的精神和神經發展障礙症？
  1. （A）衝動控制障礙症
  2. （B）身體症狀障礙症
  3. （C）焦慮症
  4. （D）自閉症類群障礙症

答案：（B）

詳解與考點

考點為智能不足的常見共病。正解B身體症狀障礙症較不屬於智能障礙最常見的共病。最常與智能障礙共病者包括自閉症類群、焦慮症、衝動控制與注意力相關障礙等神經發展或精神障礙，身體症狀障礙症相對少見。

第 19 題

大雄在報上讀到一段關於「精神困擾患者」的報導，下列何者最會讓大雄對此患者產生污名化，如「厭惡、想遠離」的反應？
  1. （A）僅描述其個人生活、人格與問題行為（如：情緒高昂、失眠、坐立不安）
  2. （B）描述其個人生活、人格與問題行為等訊息，以及其治療歷程與經驗
  3. （C）描述其個人生活、人格與問題行為等訊息，以及家屬困擾的描述片段
  4. （D）描述其個人生活、人格與問題行為等訊息，以及其對自己困擾的描述與看法

答案：（A）

詳解與考點

考點為精神疾病的污名化研究。正解A最會引發污名：僅呈現症狀與問題行為而缺乏脈絡（治療歷程、本人觀點、家屬處境）時，讀者最易產生厭惡與想遠離的反應。補充治療經驗或當事人觀點等脈絡資訊則有助降低污名。

第 20 題

DSM-5以兼顧偏差、文化等向度定義心理障礙症，下列敘述何者錯誤？
  1. （A）心理障礙症是具有臨床顯著困擾的認知、情緒調節與行為層面的症候群
  2. （B）生物性、心理性或發展歷程方面的病因皆會造成失功能
  3. （C）文化中所被允許的壓力或失落反應不視為心理障礙症
  4. （D）個人對抗社會規範所導致的偏差行為，應視為反社會人格疾患

答案：（D）

詳解與考點

考點為DSM-5對心理障礙症的定義。正解D錯誤：DSM-5明指純粹的社會偏差或個人與社會的衝突（除非源自個體失功能）不應視為心理障礙症，不能逕自等同反社會人格疾患。其餘關於症候群定義、病因失功能、文化允許反應的排除皆正確。

第 21 題

關於童年是否受虐與血清素轉運子基因（5-HTT）的交互作用，下列何種組合在成年時出現憂鬱症的機會最高？
  1. （A）童年時受虐，且具有至少一個短的5-HTT對偶基因的群體
  2. （B）童年時受虐，且具有兩個長的5-HTT對偶基因的群體
  3. （C）童年時沒有受虐，且具有兩個短的5-HTT對偶基因的群體
  4. （D）童年時沒有受虐，且具有兩個長的5-HTT對偶基因的群體

答案：（A）

詳解與考點

考點為基因與環境交互作用（Caspi等的5-HTT研究）。正解A：童年受虐且帶至少一個短型5-HTT對偶基因者，成年罹患憂鬱症的風險最高，體現基因敏感性與逆境的交互作用。長型基因或無受虐者風險較低，故其餘組合不符。

第 22 題

關於強迫症患者可能出現的強迫行為，下列何者錯誤？
  1. （A）重複要求訪客清洗身體才能進屋
  2. （B）重複儀式性的行為
  3. （C）重複賭博
  4. （D）重複檢查門窗

答案：（C）

詳解與考點

考點為強迫症的強迫行為。正解C錯誤：重複賭博屬於成癮或衝動控制問題，並非強迫症定義下的強迫行為。強迫行為是為緩解焦慮而重複的儀式（如清洗、檢查、要求他人清潔），與賭博的酬賞驅動本質不同。

第 23 題

依據DSM-5，醫師將游小姐診斷為急性壓力症，下列描述何者與此診斷一致？
  1. （A）游小姐不斷做與創傷事件無關的噩夢
  2. （B）游小姐一直努力回想創傷事件
  3. （C）創傷事件發生在昨天早上
  4. （D）創傷事件係發生在游小姐的親人身上

答案：（D）

詳解與考點

考點為DSM-5急性壓力症的診斷準則。正解D與診斷相符：創傷事件可發生在親人身上（直接經歷或目睹、得知近親遭遇皆屬暴露途徑）。陷阱在C，急性壓力症需事件後三天至一個月，「昨天早上」未滿三天，尚不符病程；噩夢與努力回想等敘述亦有偏差。把握度med。

第 24 題

相對於成人，青少年憂鬱症患者較可能出現下列何種症狀？
  1. （A）體重下降
  2. （B）易怒心情
  3. （C）嗜睡
  4. （D）專注力下降

答案：（B）

詳解與考點

考點為青少年與成人憂鬱症的症狀差異。正解B易怒心情：相較成人，青少年憂鬱更常以易怒（irritable mood）表現，DSM-5亦允許兒童青少年以易怒取代憂鬱情緒。其餘體重下降、嗜睡、專注力下降非青少年特有的鑑別特徵。

第 25 題

小娟確信國家安全局將電腦晶片植入她的大腦，所以很多想法都是被強制置入的。小娟的妄想屬於下列何者？
  1. （A）思考廣播（thought broadcasting）
  2. （B）思考插入（thought insertion）
  3. （C）關連性意念（ideas of reference）
  4. （D）被迫害妄想（persecutory delusion）

答案：（B）

詳解與考點

考點為思覺失調症的妄想類型。正解B思考插入（thought insertion）：堅信想法是被外力強制置入腦中，即典型的思考插入。陷阱在A思考廣播（想法被他人知曉/外播）與D被迫害妄想（被加害），均與「想法被植入」的核心不符。

第 26 題

有關嗜食症（binge eating disorder）與肥胖（BMI超過30）之異同，下列敘述何者正確？
  1. （A）嗜食症的診斷標準包含肥胖，但肥胖不一定符合嗜食症的診斷標準
  2. （B）嗜食症會暴食重複發作，但肥胖多數不會重複發生暴食行為
  3. （C）兩者在進食時都有感覺失控的議題
  4. （D）觀察在實驗室的飲食行為，在相同肥胖的情況下，兩者攝取的卡路里無顯著差異

答案：（B）

詳解與考點

考點為嗜食症與肥胖的異同。正解B正確：嗜食症以反覆暴食發作為核心，而肥胖多數不必然有重複暴食行為。陷阱在A，嗜食症診斷並不以肥胖為標準；C失控感是嗜食症特徵而非肥胖共有；D實驗室攝取卡路里兩者其實有差異。

第 27 題

劉文目前八歲，為家中長子，從小就覺得自己是女生，家長深感困擾而帶劉文就醫。關於診斷與處置的敘述，下列何者正確？
  1. （A）性別不安要到成年才能確定，可以請家長不用操心，等成年再就醫即可
  2. （B）兒童的發展與家長的態度息息相關，家長應從生活中強化劉文的男性自覺與認同
  3. （C）需要評估與自我的調和程度、堅信程度…等指標，才能確定劉文的狀況
  4. （D）需要評估渴望、穿著、幻想、遊戲、同伴…等指標，才能確定劉文的狀況

答案：（D）

詳解與考點

考點為兒童性別不安的評估。正解D正確：兒童性別不安需綜合評估渴望、穿著偏好、幻想、遊戲與同伴選擇等多項指標。陷阱在B，建議家長強化其生理性別認同屬不當的矯正取向；A延後就醫、C僅以調和堅信程度判定亦不正確。

第 28 題

流行病學調查發現，隨著年紀越大酒精使用者比率越低，下列何者為最可能的原因？
  1. （A）長期使用者死亡年齡比一般人提早
  2. （B）年紀大酗酒意願減低
  3. （C）年紀長者自我控制與約束力越佳
  4. （D）年紀大社會資源多，酒精使用者下降

答案：（A）

詳解與考點

考點為酒精使用的流行病學詮釋。正解A最可能：年長者酒精使用比率下降，主因之一是長期重度使用者較早死亡（存活者偏誤），而非單純意願或自制力提升。其餘以意志、社會資源解釋皆缺乏流行病學的存活效應依據。

第 29 題

研究比較高解離症狀組與低解離症狀組之被強暴婦女，在實驗期間談論被強暴議題時的生理心理激發差異程度，下列何者正確？
  1. （A）高解離組的生理激發程度高於低解離組
  2. （B）高解離組的生理激發程度低於低解離組
  3. （C）高解離組與低解離組的生理激發程度都高
  4. （D）高解離組與低解離組的生理激發程度都低

答案：（B）

詳解與考點

考點為解離與創傷的生理激發研究。正解B：高解離組在談論創傷時的生理激發程度「低於」低解離組，反映解離具有情緒與生理麻木、隔離痛苦的功能。陷阱在A，誤以為解離者激發更高，與解離的去激發本質相反。

第 30 題

根據DSM-5，下列何者不是診斷焦慮症的必要準則？
  1. （A）症狀會干擾重要的生活領域或引發顯著苦惱
  2. （B）症狀發作前須有明顯可識別的壓力事件
  3. （C）無法以其他心理障礙症做更好的解釋
  4. （D）症狀並非由藥物或一般醫學狀況引發

答案：（B）

詳解與考點

考點為DSM-5焦慮症診斷準則。正解B不是必要準則：焦慮症（如廣泛性焦慮）並不要求發作前須有「明顯可識別的壓力事件」，那較接近壓力相關障礙的特徵。其餘干擾生活或顯著苦惱、排除其他障礙、排除物質或醫學因素皆為共通必要準則。

第 31 題

7歲的小可經常出現易怒，且每週二至三次脾氣爆發、罵人或打人的情形，持續一年多，常會嚇到媽媽、同學跟老師。小可最可能是DSM-5的何種診斷？
  1. （A）對立反抗症
  2. （B）行為規範障礙症
  3. （C）反社會型人格障礙症
  4. （D）侵擾性情緒失調症

答案：（D）

詳解與考點

考點為兒童情緒行為障礙的DSM-5鑑別。正解D侵擾性情緒失調症（DMDD）：持續易怒加上頻繁的嚴重發脾氣、持續一年以上，符合DMDD。陷阱在A對立反抗症，雖也有易怒對立，但DMDD更強調慢性嚴重的情緒失調與爆發頻率，較貼合題述。

第 32 題

依據DSM-5中ADHD的診斷準則，下列那一個診斷準則不屬於過動及衝動？
  1. （A）經常在組織工作與活動上有困難
  2. （B）經常打斷或侵擾他人進行的活動
  3. （C）經常無法安靜地玩或從事休閒活動
  4. （D）經常在該維持安坐時離席

答案：（A）

詳解與考點

考點為DSM-5的ADHD診斷準則分群。正解A：「組織工作與活動有困難」屬於「不專注」面向，而非過動及衝動。其餘打斷侵擾他人、無法安靜遊玩、該坐時離席皆屬過動/衝動症狀，故A為應選的「不屬於」項。

第 33 題

下列那一項特徵不屬於DSM-5依賴型人格障礙症（dependent personality disorder）？
  1. （A）不切實際地專注於不被他人照顧的害怕
  2. （B）因為害怕尷尬，通常不願意冒個人風險或從事任何新活動
  3. （C）因為害怕失去支持或認可，而困難於對他人表達不同意
  4. （D）難於獨自實施新計畫或做事

答案：（B）

詳解與考點

考點為DSM-5依賴型人格障礙症特徵。正解B不屬於：「因害怕尷尬而不願冒險或從事新活動」較接近畏避型人格的特徵。依賴型核心為害怕失去照顧與支持，故有難以表達異議、難獨自啟動計畫、過度擔心被遺棄等表現，B並非依賴型典型準則。

第 34 題

關於貝克的憂鬱症認知治療，其中的負向三角包括對那三方面的負面看法？
  1. （A）心理、生理、社會
  2. （B）生命、工作、人際
  3. （C）自己、世界、未來
  4. （D）過去、現在、未來

答案：（C）

詳解與考點

考點為Beck憂鬱症認知三角（負向三角）。正解C正確：負向三角指對「自己、世界、未來」的負面看法。陷阱在D（過去、現在、未來）為時間向度的混淆項，與Beck的認知三角內容不符。此為基本概念，把握度high。

第 35 題

研究顯示，對暴食症（bulimia nervosa）患者給予抗憂鬱劑的治療，可改善的現象為何？
  1. （A）測量體重的頻率
  2. （B）清除與暴食行為
  3. （C）暴食發作時攝取的食物量
  4. （D）暴食後的自我形象

答案：（B）

詳解與考點

本題問抗憂鬱劑治療暴食症（bulimia nervosa）可改善的現象，官方答案為 (B)。研究顯示抗憂鬱劑（尤其 SSRI，如 fluoxetine）能顯著減少暴食症患者的暴食（binge eating）與清除（purging，如自我催吐、濫用瀉劑）行為的頻率，故 (B)「清除與暴食行為」正確。其餘並非抗憂鬱劑主要改善的標的：(A)「測量體重的頻率」屬強迫性檢查行為，非藥物直接改善的核心療效指標；(C)「暴食發作時攝取的食物量」研究證據不一致，藥物主要降低的是發作頻率而非單次攝取量；(D)「暴食後的自我形象」涉及身體意象與認知扭曲，較屬認知行為治療（CBT）的處理範疇，非抗憂鬱劑的主要作用，故皆不選。

第 37 題

關於思覺失調症（schizophrenia）患者的長期預後觀點，下列敘述何者正確？
  1. （A）約有50％的思覺失調症患者可以完全復原
  2. （B）持續服藥即可完全復原
  3. （C）接受心理治療即可完全復原
  4. （D）能完全復原的思覺失調症患者是少見的

答案：（D）

詳解與考點

考點為思覺失調症的長期預後。正解D正確：能完全復原的患者是少見的，多數為慢性病程或部分緩解。其餘為錯誤：並非約50%可完全復原、單靠持續服藥或單靠心理治療皆無法保證完全復原，預後需綜合多因素。

第 38 題

譫妄（delirium）常見的藥物治療方式，以下何者最正確？
  1. （A）抗生素類藥物（antibiotic medication）
  2. （B）苯二氮平類藥物（benzodiazepine medication）
  3. （C）抗憂鬱劑類藥物（antidepressant medication）
  4. （D）視譫妄成因而採取不同藥物

答案：（D）

詳解與考點

本題問譫妄（delirium）的藥物治療，官方答案為 (D)。譫妄的首要處置是找出並治療其潛在成因（如感染、電解質失衡、缺氧、藥物中毒或戒斷等），故用藥須「視譫妄成因而採取不同藥物」，(D) 最正確。其餘各為僅適用特定情況、不可一概而論：(A) 抗生素只在感染所致的譫妄才適用，非通用；(B) 苯二氮平類（benzodiazepine）主要用於酒精或鎮靜藥物戒斷引起的譫妄，但對一般譫妄反而可能加重意識混亂，並非首選；(C) 抗憂鬱劑並非譫妄的常規或常見治療藥物。臨床上若需控制嚴重躁動或精神病症狀，常選用低劑量抗精神病藥（如 haloperidol），但根本仍以處理病因為先，故選 (D)。

第 39 題

針對酒精相關障礙症的介入，下列何者主要著重在教導個案辨識容易引發飲酒的情境？
  1. （A）預防復發（relapse prevention）
  2. （B）無名戒酒會（Alcoholics Anonymous）
  3. （C）後效管理（contingency management）
  4. （D）動機增強療法（motivational enhancement therapy）

答案：（A）

詳解與考點

考點為酒精障礙的介入方法。正解A預防復發（relapse prevention）：核心在教導個案辨識並因應容易引發飲酒的高風險情境。陷阱在D動機增強療法，著重提升改變動機與化解矛盾，而非情境辨識；後效管理用酬賞、戒酒會走互助模式。

第 40 題

關於儲物症（hoarding disorder）的敘述，下列何者正確？
  1. （A）好發於中年
  2. （B）認知行為治療對儲物症有短期療效
  3. （C）缺乏病識感是診斷儲物症的條件之一
  4. （D）男性比女性多

答案：（B）

詳解與考點

考點為儲物症的臨床特徵。正解B正確：認知行為治療對儲物症有短期療效。其餘為錯誤：儲物症好發且隨年齡加重而非僅中年、病識感不足並非診斷的必要條件、盛行率上女性與男性差異敘述（男多於女）不正確。把握度med。
