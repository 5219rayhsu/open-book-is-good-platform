第 1 題

關於新手諮商心理師如何兼顧專業性並保持個人性，下列敘述何者錯誤？
  1. （A）自我照顧是對諮商心理師的倫理要求
  2. （B）要能做到自我照顧，當務之急即是諮商心理師學會自我監控
  3. （C）為防止專業耗竭，新手諮商心理師應隨時檢視並覺察自己的身心狀態
  4. （D）即便諮商心理師忽略了自我照顧，個案仍然可以得到最好的協助

答案：（D）

詳解與考點

考點為心理師的自我照顧倫理與耗竭預防。正解 D 錯誤：心理師若忽略自我照顧，身心受損會影響專業品質，個案無法得到最好協助。A 自我照顧是倫理要求、B 學會自我監控、C 隨時覺察身心狀態皆正確。陷阱在 B，「自我監控為當務之急」說法略強，但仍屬正確自我照顧步驟，非錯項。

第 2 題

關於諮商歷程中諮商心理師對於價值觀所持的立場，下列敘述何者正確？
  1. （A）應做到完全的客觀與中立
  2. （B）可表達與個案問題有關的某些價值觀，但不強迫其接受
  3. （C）諮商心理師應堅決表達自己的觀點，才能影響個案
  4. （D）透過任何形式表達個人的價值觀均是不被允許的

答案：（B）

詳解與考點

考點為諮商中心理師對價值觀的立場。正解 B：心理師可表達與個案議題相關的某些價值觀，但不強迫接受，符合價值透明又不強加的原則。A 完全客觀中立不可能。C 堅決表達以影響個案屬價值強加。D 認為任何形式表達都不被允許過於絕對。陷阱在 A，「保持中立」常被誤為理想，但完全客觀中立並不可行。

第 3 題

關於諮商關係中的責任承擔，下列敘述何者錯誤？
  1. （A）諮商的成效應由諮商心理師與個案共同承擔責任
  2. （B）訂定契約會是讓個案為自己負責的好方法
  3. （C）諮商關係開始即應對責任的分擔進行討論
  4. （D）擬定合適的治療計畫不應是諮商心理師的責任

答案：（D）

詳解與考點

考點為諮商關係中的責任分擔。正解 D 錯誤：擬定合適的治療計畫正是心理師的專業責任。A 成效共同承擔、B 訂契約助個案負責、C 開始即討論責任分擔皆正確。陷阱在 A，成效「共同承擔」聽來像推卸，但符合個案需為自己負責的協同觀，故非錯項。

第 4 題

依據心理動力學派的觀點，倘若個體無法融合對自己或他人的愛與恨，可能會將兩種感覺彼此區隔，此一內在歷程為何？
  1. （A）分裂（splitting）
  2. （B）解離（dissociation）
  3. （C）隔離（isolation）
  4. （D）反向作用（reaction formation）

答案：（A）

詳解與考點

考點為心理動力（客體關係）防衛機轉。正解 A 分裂（splitting）：無法整合對自己或他人的愛與恨，將之截然二分為全好/全壞即「分裂」。B 解離是意識斷裂、C 隔離（isolation）是切斷情感與想法的連結、D 反向作用是化為相反行為。陷阱在 C，隔離與分裂中文皆有「隔開」意味，但隔離切的是情感與認知，非愛恨的整合。

第 5 題

某諮商心理師觀察到當個案具有強烈自我專注、需要大量讚賞、情感空洞、剝削傾向以及寄生性的人際關係等特質。依據上述，其最可能的評估為何？此觀點是何人所提？
  1. （A）自戀型人格；肯伯格（Otto Kernberg）
  2. （B）邊緣型人格；肯伯格（Otto Kernberg）
  3. （C）自戀型人格；寇哈特（Heinz Kohut）
  4. （D）邊緣型人格；寇哈特（Heinz Kohut）

答案：（A）

詳解與考點

考點為自戀型人格與客體關係理論家。正解 A：強烈自我專注、需大量讚賞、情感空洞、剝削、寄生人際是自戀型人格特徵；肯伯格（Kernberg）以衝突/驅力觀點描述病態自戀。寇哈特（Kohut）則以自體心理學的自體客體缺失解釋自戀。陷阱在 C，寇哈特同樣談自戀，但題述偏剝削、攻擊的描述較貼近肯伯格的觀點。

第 6 題

關於榮格（Jung）學派對「象徵（symbols）」的觀點，下列何者正確？
  1. （A）象徵起於和諧與統整
  2. （B）象徵是意識的凝聚物
  3. （C）象徵為自我提供能量
  4. （D）象徵是諮商心理師所提供的治療性隱喻

答案：（C）

詳解與考點

本題問榮格（Jung）學派對「象徵（symbols）」的觀點，何者正確，官方答案為 (C)。在榮格理論中，象徵是來自無意識（尤其集體無意識與原型）、指向尚未被意識完全掌握之意義的活躍載體，它具有轉化心理能量（libido）的功能，能為人格的核心（自性 Self／自我發展）提供與引導心理能量，故 (C)「象徵為自我提供能量」最貼近其觀點而正確。其餘錯誤：(A) 象徵往往起於心理的張力、對立與衝突（對立面的兩極），是整合對立、邁向統整的途徑，而非「起於和諧與統整」；(B) 顛倒，象徵源於無意識而非「意識的凝聚物」；(D) 錯誤，象徵在榮格觀點中是個案無意識自發產生的內容，並非由諮商師提供的治療性隱喻。

第 7 題

阿德勒學派運用生活型態評估技術的目的，下列何者正確？
  1. （A）找出個案因應生活任務的模式
  2. （B）了解個案生命經驗中的優勢力量
  3. （C）找出個案阻礙自我覺察的原因
  4. （D）徹底修正個案人格結構

答案：（A）

詳解與考點

考點為阿德勒學派的生活型態（lifestyle）評估。正解 A：生活型態評估旨在找出個案因應生活任務的一貫模式與私人邏輯。B 優勢力量偏焦點解決、C 阻礙自我覺察非其主要目的、D 徹底修正人格結構屬精神分析式的誇大目標。陷阱在 B，找正向資源像阿德勒鼓勵精神，但生活型態評估的核心是辨識因應模式。

第 8 題

下列那一種諮商關係，最能描述阿德勒治療的主張？
  1. （A）合作的平等關係
  2. （B）當下同在的經驗
  3. （C）我／汝（I/thou）的關係
  4. （D）積極無條件關懷

答案：（A）

詳解與考點

考點為阿德勒治療主張的諮商關係。正解 A 合作的平等關係：阿德勒強調治療是平等、合作的夥伴關係。B 當下同在偏完形/存在、C 我/汝關係出自 Buber 與存在取向、D 積極無條件關懷是個人中心的核心。陷阱在 C，我/汝亦談平等相遇，但屬存在主義語彙，阿德勒最標誌性的是「合作平等」。

第 9 題

關於阿德勒學派治療中的「鼓勵（encouragement）」，下列敘述何者正確？①鼓勵的目的是幫助個案生出勇氣②鼓勵的過程，為激發與強化個案社會興趣的關鍵所在③鼓勵不是一種技術，而是諮商心理師的治療處遇態度④如果個案覺得他自己的改變是不可能的，諮商心理師必須努力鼓勵個案相信，進步與改變是可能的
  1. （A）僅①②③
  2. （B）僅②③④
  3. （C）僅①③④
  4. （D）①②③④

答案：（D）

詳解與考點

考點為阿德勒學派的「鼓勵」概念。正解 D（①②③④全對）：鼓勵助個案生出勇氣、是激發社會興趣的關鍵、是治療態度而非單一技術、且須助個案相信改變可能。四項均符合阿德勒對鼓勵的定義。把握度高：此為阿德勒通說，四敘述彼此一致、無互斥之處。

第 10 題

關於存在主義治療的治療關係之敘述，下列何者錯誤？
  1. （A）諮商心理師與個案在治療的過程中本真（authentic）交會
  2. （B）在治療的過程中，諮商心理師與個案充分的同在
  3. （C）過度專注移情關係，不會影響到諮商心理師與個案間的本真（authentic）關係
  4. （D）諮商心理師應對自己保持本真（authentic），並本真地對個案開放

答案：（C）

詳解與考點

考點為存在主義治療的本真（authentic）關係。正解 C 錯誤：過度專注移情關係會妨礙心理師與個案的本真相遇，存在取向重視此時此地的真實同在而非移情分析。A 本真交會、B 充分同在、D 對己與對個案保持本真開放皆正確。陷阱在 A/B，本真與同在用語抽象，但皆為存在治療正面主張，非錯項。

第 11 題

關於存在主義治療的敘述，下列何者錯誤？
  1. （A）具有特定的治療技巧與方法
  2. （B）協助個案處理人類自由與責任的議題
  3. （C）檢驗個人對自我的察覺
  4. （D）協助個案處理人類存在與死亡的議題

答案：（A）

詳解與考點

考點為存在主義治療的方法特性。正解 A 錯誤：存在主義治療並無特定、固定的治療技巧與方法，而是一種哲學態度與看待人的觀點。B 處理自由與責任、C 檢驗自我覺察、D 處理存在與死亡皆屬其核心關懷。陷阱在 C/D，這些議題聽來抽象，但正是存在治療的標誌主題，故非錯項。

第 12 題

針對存在主義治療與個人中心治療的共同點的敘述，下列何者錯誤？
  1. （A）兩者皆認為治療關係是治療的核心
  2. （B）兩者都受到現象學的影響
  3. （C）兩者都認為選擇的焦慮會驅使我們追尋生命意義
  4. （D）兩者都強調個案的自我覺察

答案：（C）

詳解與考點

考點為存在主義與個人中心治療的共同點。正解 C 錯誤：「選擇的焦慮驅使追尋生命意義」是存在主義特有的主張，個人中心並不強調此點，故非兩者共同點。A 治療關係為核心、B 受現象學影響、D 強調自我覺察皆為兩派共通。陷阱在 B，現象學影響聽來偏存在主義，但個人中心同樣以現象學為基礎，故仍是共同點。

第 13 題

提出「我／汝（I/thou）」這個概念的人是下列何者？
  1. （A）Carl Rogers
  2. （B）Maslow
  3. （C）Yalom
  4. （D）Büber

答案：（D）

詳解與考點

考點為「我/汝（I/Thou）」概念的提出者。正解 D Büber（馬丁·布伯）：此概念出自布伯的哲學，後被存在與人本取向引用。A Rogers 借用該精神但非提出者、B Maslow、C Yalom 皆非。把握度高：我/汝出自布伯為哲學與諮商通識。

第 14 題

大德經常酒後對伴侶施暴，下列何者是個人中心取向的諮商心理師最有可能採取的問題概念化觀點？
  1. （A）大德想要被愛，卻經驗到不被伴侶接納的不一致經驗
  2. （B）大德也是暴力的受害者，是暴力代間傳遞的結果
  3. （C）大德對憤怒的衝動控制能力不足，需要透過諮商加以訓練矯正
  4. （D）與伴侶互動的經驗勾起大德過去的受暴經驗，需透過諮商幫助他覺察憤怒情緒的來源

答案：（A）

詳解與考點

考點為個人中心取向的問題概念化。正解 A：個人中心以「不一致（incongruence）」概念化，大德想被愛卻經驗到不被接納的不一致是其核心觀點。B 代間傳遞偏家族/系統、C 衝動控制訓練偏行為、D 覺察憤怒來源偏動力或創傷取向。陷阱在 D，覺察情緒來源聽來人本，但個人中心著眼自我經驗的不一致而非追溯過去。

第 15 題

關於動機式晤談的敘述，下列何者正確？
  1. （A）是由William R. Miller和Leslie Greenberg所創
  2. （B）是以個案為中心的一種非指導性治療方法
  3. （C）諮商心理師運用面質、駁斥技巧，挑戰個案的抗拒，以增加改變的動機
  4. （D）諮商心理師喚起個案的不一致和矛盾，增進個案想要改變的內在動機

答案：（D）

詳解與考點

考點為動機式晤談（MI）。正解 D：MI 透過喚起個案的不一致與矛盾，增進其改變的內在動機。A 創始者是 Miller 與 Rollnick（非 Greenberg）。B MI 雖以個案為中心但具方向性，非純非指導。C MI 反對面質駁斥、強調與抗拒同行。陷阱在 B，MI 確以個案為中心，但「非指導性」說法不準，MI 是有方向的引導。

第 16 題

關於完形治療取向的核心精神，下列敘述何者正確？
  1. （A）重視單一線性因果模式
  2. （B）強調絕對客觀的真實
  3. （C）重視個體與外在環境的關聯
  4. （D）強調心智與身體二元對立

答案：（C）

詳解與考點

考點為完形治療的核心精神。正解 C：完形重視個體與外在環境的整體關聯（場地論、有機體-環境的接觸）。A 反對單一線性因果、B 不主張絕對客觀真實（重現象經驗）、D 反對心身二元、強調整體。陷阱在 B/D，這些是完形所反對的觀點，誤把反命題當核心即會選錯。

第 17 題

小畢在辦公室對同事的要求有求必應不敢拒絕。諮商心理師要求他扮演一個拒人於千里之外的角色，諮商心理師最可能是運用下列何種技術？
  1. （A）嫌惡練習
  2. （B）預演練習
  3. （C）誇大練習
  4. （D）倒轉練習

答案：（D）

詳解與考點

考點為完形治療的實驗技術。正解 D 倒轉練習（reversal）：要有求必應者扮演拒人於千里之外的相反角色，藉以接觸被壓抑的另一極。A 嫌惡練習偏行為、B 預演練習是排練未來情境、C 誇大練習是放大某動作或語句。陷阱在 C，誇大也是完形技術，但題述是扮演「相反」的角色，屬倒轉而非放大。

第 18 題

個案上課時將作業撕毀並辱罵老師，諮商心理師協助其評量自己的行為時，下列問話何者最不符合現實治療的精神？
  1. （A）你的行為對你有幫助還是有害？
  2. （B）老師做了什麼讓你這麼生氣？
  3. （C）你做的事可以得到你想要的嗎？
  4. （D）若有一個人在上課時做你所做的事，是否恰當？

答案：（B）

詳解與考點

考點為現實治療（WDEP）的自我評量精神。正解 B「老師做了什麼讓你這麼生氣？」最不符合：此問句歸因於外在他人，違反現實治療強調個案為自身行為負責、聚焦自我選擇的精神。A、C、D 均引導個案評量自己行為是否有效、能否得到所要、是否恰當。陷阱在 D，假設性問句聽來繞，但仍是引導自我評量，符合精神。

第 19 題

關於少數族群使用現實治療的注意事項，下列敘述何者錯誤？
  1. （A）環境的限制會使得少數族群的個案難以自主的選擇
  2. （B）過分強調個案能為自己的生活負責時，會讓個案覺得不被瞭解
  3. （C）諮商心理師可幫助個案找到屬於自身認同的身分及主流文化間的平衡
  4. （D）少數族群的壓力過重，不宜期待他們做出改變社會的行動

答案：（D）

詳解與考點

考點為現實治療用於少數族群的注意事項。正解 D 錯誤：不宜因壓力過重就斷定不能期待少數族群做出改變社會的行動，這帶有貶抑與限制。A 環境限制使其難自主選擇、B 過度強調個人負責會讓個案不被理解、C 協助在自身認同與主流文化間取得平衡皆為適切提醒。陷阱在 B，看似批評現實治療，實為正確的文化敏感提醒。

第 20 題

第 21 題

第 22 題

關於正念認知治療（MBCT）八個階段本質，下列敘述何者錯誤？

第 23 題

第 24 題

上課的時候李強故意發出怪聲，但宋老師不予理會，仍然繼續上課。宋老師的做法屬於下列何者？
  1. （A）消弱（extinction）
  2. （B）隔離（isolation）
  3. （C）增強（negative reinforcement）
  4. （D）系統減敏感法（systematic desensitization）

答案：（A）

詳解與考點

考點為操作制約的行為原理。正解 A 消弱（extinction）：對已被增強的行為（怪聲求關注）不予理會、撤除增強，使其逐漸減少即消弱。B 隔離是移除個體至無增強環境、C 負增強是移除嫌惡刺激以增強行為、D 系統減敏感法處理焦慮。陷阱在 B，不理會聽來像隔離，但純粹忽視撤除注意屬消弱，非移走當事人。

第 25 題

關於認知治療的機轉，下列敘述何者錯誤？
  1. （A）改變個案功能失調的假設，會導致有效的認知
  2. （B）在情緒未被激發的情況下，思考也能被察覺及加以修正
  3. （C）個案覺得一個問題情境已構成真正威脅時，他才會產生改變
  4. （D）單只是激發情緒及伴隨的認知，並無法促成持久性的改變

答案：（B）

詳解與考點

考點為認知治療的改變機轉。正解 B 錯誤：認知治療認為情緒被激發（熱認知）時，相關認知才較易被察覺與修正；在情緒未激發的冷靜狀態下，思考較難被有效觸及修正。A、C、D 描述改變失功能假設、需感到威脅才改變、單純激發情緒不足以持久改變皆正確。陷阱在 C，「構成威脅才改變」聽來怪，實為認知治療觀點。

第 26 題

關於家族治療的系統觀點，下列敘述何者錯誤？
  1. （A）從系統的脈絡去理解個案的問題
  2. （B）從系統的脈絡為個案的症狀下診斷
  3. （C）從系統的資源來尋求解決之道
  4. （D）認為改變的途徑不只侷限在個人身上

答案：（B）

詳解與考點

考點為家族治療的系統觀。正解 B 錯誤：系統觀不主張「為個案的症狀下診斷」，而是視症狀為系統脈絡的功能展現，反對將病理定位於個人。A 從系統脈絡理解問題、C 從系統資源尋解、D 改變不侷限於個人皆符合系統觀。陷阱在 B，「從系統脈絡下診斷」混入個人診斷思維，與系統去病理化精神相悖。

第 27 題

下列那一項家族治療的理論概念最可能因中西文化差異，而導致對此現象的不同解讀？

  4. （D）雙重束縛

第 28 題

下列那一個家族治療取向的諮商心理師，其態度最不具教育與指導性成分？
  1. （A）多世代取向
  2. （B）阿德勒取向
  3. （C）結構取向
  4. （D）薩提爾取向

答案：（D）

詳解與考點

本題問哪一家族治療取向的諮商師態度「最不具教育與指導性」，官方答案為 (D) 薩提爾取向。薩提爾（Satir）的經驗／溝通取向強調真誠接觸、體驗、滋養性的同在與成長導向，治療師以溫暖、人本、歷程體驗的姿態陪伴家庭，相對最不具教導與指導色彩，故選 (D)。其餘取向的指導與教育性都較明顯：(A) 多世代取向（Bowen）治療師如教練／教師，帶領家庭理解自我分化、家庭系統與多世代傳遞，具教育性；(B) 阿德勒取向重視心理教育、提供洞察與再教育，指導性高；(C) 結構取向（Minuchin）治療師主動加入並重塑家庭結構，運用扮演、設界線等技術，是高度主動、介入與指導性的取向，故皆不選。

第 29 題

面對在學校打架的兒子，父親在家庭會談中對諮商心理師說：「這孩子太任性，完全沒有考慮我工作那麼辛苦是為了什麼？」，下列諮商心理師的回應何者最符合「循環問話」？

  2. （B）聽起來爸爸是辛苦的，媽媽你怎麼看爸爸說的辛苦呢？

  4. （D）爸爸要不要多說一點，你的辛苦是什麼呢？

答案：（B）

詳解與考點

考點為系統/家族治療的「循環問話（circular questioning）」。正解 B：請媽媽「怎麼看爸爸說的辛苦」，邀請第三方對關係互動作觀察評論，正是循環問話的形式。A 問誰造成屬歸因/線性、C 直接問當事人雙方非循環、D 請爸爸多說屬一般澄清。陷阱在 A，問「你覺得是誰造成」像在探系統，但其方向是歸咎，非循環觀察。

答案：（C）

詳解與考點

本題以焦點解決短期治療（SFBT）第一次諮商後的後續晤談開場為題，問「何者錯誤」，官方答案為 (C)「僅①③」（即①與③為錯誤敘述）。逐項判斷：①錯誤——SFBT 後續晤談的標準開場是 EARS 中的「E（Elicit）」，常用「從上次到現在，有什麼變得比較好（What's better）？」來引出進展與例外，預設方向是正向；而「有沒有比較好一點？」是封閉式、易引向「沒有」的問法，不符 SFBT 引導正向例外的開場精神，故①為錯誤敘述。②正確——SFBT 相信「解決之道主要建構於對例外的知覺」，因此會探討有進展的理由、放大例外與成功經驗，②符合 SFBT 觀點。③錯誤——當個案沒有進展時，SFBT 採合作、非責備（non-blaming）、聚焦因應（coping）的態度，而非去「檢視個案有無徹底執行前次建議」這種帶責備、檢核作業意味的作法，故③為錯誤敘述。錯誤敘述為①③，正解為 (C)。

第 39 題

下列何者並非心理劇常見的使用技術？
  1. （A）角色互換（role reversal）
  2. （B）替身（double technique）
  3. （C）過去投射（past projection）
  4. （D）完成演出（act fulfillment）

答案：（C）

詳解與考點

考點為心理劇（psychodrama）常見技術。正解 C 過去投射（past projection）並非心理劇標準技術；心理劇常用未來投射（future projection）。A 角色互換、B 替身、D 完成演出（act fulfillment）皆為心理劇技術。陷阱在 D，完成演出名稱較陌生，易誤選，但它確為心理劇技術，過去投射才是杜撰般的非標準項。

第 40 題

下列那一個遊戲治療取向在治療關係中和兒童有平等的權力，在遊戲治療中使用追蹤、重述內容、反映感覺、角色扮演、一起清理遊戲室等技巧？
  1. （A）非指導取向
  2. （B）兒童中心取向
  3. （C）阿德勒取向
  4. （D）榮格取向

答案：（C）

詳解與考點

考點為遊戲治療各取向的關係與技巧。正解 C 阿德勒取向：在治療關係中與兒童保持平等的權力（民主平等），並使用追蹤、重述、反映感覺、角色扮演、一起收拾遊戲室等技巧。非指導/兒童中心取向則由兒童主導、不會一起清理或角色扮演到此程度。陷阱在 B，兒童中心也用追蹤反映，但「平等權力與一起清理」較指向阿德勒。
