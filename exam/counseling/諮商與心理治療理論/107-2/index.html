  2. （B）將更重指導性、強調心理衛教
  3. （C）將採取結構性、問題解決導向
  4. （D）常會合併認知行為治療法

答案：（A）

第 2 題

下列對諮商心理師個人接受諮商（被諮商）經驗之敘述，何者錯誤？
  1. （A）要成為諮商心理師前一定要沒有個人內在衝突及生命困境
  2. （B）被治療經驗有機會看到反移情
  3. （C）被治療的經驗有助於提高自我覺察
  4. （D）透過被治療經驗增加日後面對當事人的同理與理解

答案：（A）

詳解與考點

正解：諮商心理師的養成強調自我覺察與被治療經驗的價值，但這不等於要求諮商心理師在執業前必須「完全沒有」個人內在衝突或生命困境——事實上，多數助人工作者本身也帶著自己的議題與傷痕進入這個專業，重點在於是否有能力覺察並適當處理這些議題，避免影響專業判斷與當事人福祉，而非要求一種不存在人性限制的完美狀態。題幹A將「沒有個人內在衝突及生命困境」設為成為諮商心理師的必要條件，是不切實際且錯誤的敘述，故選 A。

B：諮商心理師在被治療的位置上，有機會觀察到自己對治療者產生的情感投射與反應模式，這正是日後能辨識自己在與當事人工作時可能出現的反移情的重要練習機會，敘述正確。

C：親身經歷被治療的歷程，讓諮商心理師更貼近地理解自己的內在世界、盲點與慣性反應模式，有助於提升自我覺察，敘述正確。

D：透過被治療的親身經驗，諮商心理師更能體會當事人在諮商關係中的感受與需要，進而在日後面對當事人時展現更深的同理與理解，敘述正確。

本題考點：諮商心理師的自我覺察與個人治療（personal therapy for therapists）——被治療經驗有助於覺察反移情、提升同理，而非要求從業前毫無內在議題。

第 3 題

下列有關雙重關係的敘述，何者正確？
  1. （A）雙重關係極為普遍，常可以加以辨認
  2. （B）雙重關係可全然避免
  3. （C）雙重關係有潛在的傷害性，必然造成傷害
  4. （D）避免雙重關係主要在防止誤用權力，對當事人剝削及對客觀性的損害等

答案：（D）

詳解與考點

正解：雙重關係（dual relationship／multiple relationship）是指助人者與當事人之間，除了專業的諮商關係外，還同時存在其他角色關係，例如同時是師生、僱傭、朋友或親屬等。倫理規範之所以要求心理師對雙重關係保持警覺並儘量避免，核心考量並非「雙重關係本身就是罪惡」，而是它容易衍生三種具體風險：心理師濫用其專業與角色所賦予的權力、對當事人造成剝削性後果、以及損害心理師原本應保持的客觀判斷與專業界線。D 正是把握到這個核心，故為正解。

A：雙重關係在實務中的確相當普遍，尤其在小型社區、校園或偏鄉等人際網絡密集重疊的場域更難避免，但「普遍」不等於「容易辨認」。許多雙重關係是逐漸滲入、當事人與心理師雙方都未必立即察覺其存在與影響，這也是雙重關係之所以危險的原因之一，A 後半段的描述與實務經驗相反。

B：倫理守則要求心理師避免不必要、可預防的雙重關係，但從未主張雙重關係可以「全然避免」。在資源有限的小社區、原住民部落或特殊機構情境中，心理師與當事人本就可能透過生活圈自然重疊，完全杜絕並不切實際，倫理準則因此轉而強調覺察、預防與管理，而非全面禁絕。

C：雙重關係具有「潛在」傷害性，是指它有較高的風險導致權力濫用或剝削，但潛在風險並不等於必然發生傷害的結果。許多雙重關係經過妥善的覺察、界線設定與督導處理後，未必造成當事人的損害，C 把「可能」誤植為「必然」，過度絕對化。

本題考點：雙重關係／多重關係（dual／multiple relationship）——諮商倫理中角色重疊的界線議題；專業權力與剝削（power misuse／exploitation）——雙重關係倫理規範所要防範的核心風險。

第 7 題

Adler 治療認為何者是導致個人功能失序的基本因素？
  1. （A）喪失勇氣
  2. （B）自卑
  3. （C）出生序
  4. （D）家庭星座

答案：（A）

詳解與考點

正解：Adler 學派認為，追求卓越與克服自卑感是人類發展的正常動力，適度的自卑感反而能激發個人努力與成長；真正導致個人功能失序、出現偏差或問題行為的根本原因，是個體在面對生活任務（工作、社交、愛情）時失去了面對困難、繼續嘗試的信心與勇氣，也就是喪失勇氣（discouragement）。喪失勇氣的個體會採取消極、逃避甚至偏差的因應方式來掩飾自己的無力感，這正是 Adler 治療將「鼓勵」（encouragement）視為核心治療機制、以恢復個案勇氣為目標的理論基礎，故選 A。

B：自卑感（inferiority feeling）在 Adler 理論中是普遍且正常的人類經驗，是驅動個人追求卓越、努力成長的原始動力，本身並非病理或功能失序的根源；只有當自卑感未被妥善轉化、個體因而喪失面對生活的勇氣時，才會導致功能失序，因此自卑感是起點而非導致失序的「基本因素」本身。

C：出生序（birth order）是 Adler 理論中用來理解個人早期經驗如何形塑其生活型態（如長子、次子、么子在家庭中不同的處境與因應方式）的重要參考變項，但只是形塑人格風格的其中一項脈絡因素，並非導致功能失序的核心機轉。

D：家庭星座（family constellation）指整個原生家庭的結構、氣氛與成員互動關係，同樣是 Adler 理論中理解個人生活型態形成背景的重要概念，性質上屬於形塑人格與生活型態的脈絡因素，而非直接導致個人功能失序的基本因素。

本題考點：Adler 個體心理學（Individual Psychology）——強調追求卓越與社會興趣的人格理論；喪失勇氣（discouragement）——Adler 治療視為功能失序核心成因，也是鼓勵技術（encouragement）介入的理論依據。

第 8 題

關於 Adler 心理治療的敘述，下列何者錯誤？
  1. （A）強調目的導向
  2. （B）諮商心理師是自我導向
  3. （C）使用按鈕技術
  4. （D）早期記憶的回顧是治療中的重要過程

答案：（B）

詳解與考點

正解：Adler學派心理治療強調人的行為受未來目標牽引，是目的導向而非單純由過去原因決定（A正確）；治療中常運用按鈕技術，協助當事人覺察自己能透過選擇不同的想法而創造不同的情緒感受（C正確）；早期記憶的回顧被視為理解個人生活型態核心信念的重要素材，是治療歷程中的重要工作（D正確）。至於自我導向，Adler學派強調的是當事人本身具有自我決定、能主動選擇改變的能力，諮商心理師的角色則偏向積極、合作、教育性的引導者，而非以「諮商心理師是自我導向」來描述治療關係的核心精神，B將自我導向的主體錯置在諮商心理師身上，是錯誤的敘述，故選B。

A：Adler學派主張人的行為受個人對未來的主觀目標牽引，而非純粹由過去經驗決定，強調目的導向是其核心主張，敘述正確。

C：按鈕技術透過請當事人回想愉快與不愉快的經驗、並觀察伴隨的情緒變化，協助當事人體會自己能主動選擇聚焦的想法，進而影響情緒感受，是Adler學派常用技巧，敘述正確。

D：早期記憶被視為反映個人生活型態與核心信念的重要投射材料，回顧早期記憶是Adler治療歷程中理解當事人內在世界的重要工作，敘述正確。

本題考點：Adler學派心理治療（Adlerian therapy）——目的論（teleology）、生活型態（lifestyle）與自我決定（self-determination）；按鈕技術與早期記憶回顧作為理解與介入的具體技巧。

第 12 題

依個人中心治療的觀點，下列有關「情感轉移」的說明，何者正確？
  1. （A）是治療過程中自然會出現的真實關係
  2. （B）是治療成功的結果
  3. （C）是諮商過程中必然會出現的現象
  4. （D）並非治療過程中的基本或重要療效因素

答案：（D）

詳解與考點

正解：個人中心治療（person-centered therapy）由Rogers提出，強調治療關係本身是真實、平等的相遇，療效的核心來自治療師提供的同理心、無條件正向關懷與一致性這三項核心條件，而非如精神分析取向那樣，把當事人對治療師產生的移情反應視為理解潛意識、推動改變的必要素材。因此在個人中心觀點下，情感轉移並不被視為治療過程中的基本或重要療效因素，故選D。

A：個人中心治療確實強調治療關係的真實性，但這裡談的是治療師以真誠一致的態度與當事人相遇的「真實關係」，而非把「情感轉移」本身定義為這種真實關係，兩者概念不同。

B：個人中心治療的成功與否，關鍵在核心條件是否被當事人知覺到，而非情感轉移的出現與否，把情感轉移當作治療成功的結果並無理論依據。

C：個人中心治療並不像精神分析那樣預設治療歷程必然會出現情感轉移現象，也不特別著重辨識或處理它，說它「必然會出現」與此取向的立場不符。

本題考點：個人中心治療（person-centered therapy）——以核心條件（同理、無條件正向關懷、一致性）為療效機轉；情感轉移（transference）——精神分析取向重視、但人本取向不視為關鍵療效因素的現象。

第 13 題

Rogers 所提出的真誠一致是指下列那一項諮商心理師的態度或行為表現？
  1. （A）諮商心理師個人本身是自我實現的，如此才能成為治療者
  2. （B）諮商心理師也可以衝動地對當事人表達內心的生氣、挫折、與煩悶
  3. （C）治療過程中諮商心理師能真實開放地對當事人表達情感及想法
  4. （D）對當事人產生負向價值，但只表達出相反的正向價值

答案：（C）

詳解與考點

正解：Rogers 提出的核心條件（core conditions）中，真誠一致（congruence／genuineness）指的是治療者在諮商關係中對自己內在的經驗保持覺察，並能真實、不防衛地將此刻的感受與想法適當地開放給當事人，讓治療者的外在言行與內在經驗相符一致。C 描述的正是治療過程中諮商心理師能真實開放地表達情感與想法，符合這個定義，故選 C。

A：自我實現（self-actualization）描述的是個人朝向充分發揮潛能的傾向，是 Rogers 人格理論對所有人（含當事人）的普遍假設，而非真誠一致這項特定治療態度的定義；把「治療者已自我實現」當成真誠一致的內涵，混淆了人格理論的預設與治療技術的界定。

B：真誠一致不等於毫無節制地宣洩情緒。若諮商心理師任意衝動地對當事人發洩生氣、挫折與煩悶，等於把治療焦點轉移到自己身上，反而違背了以當事人為中心、負責任地運用自我揭露的原則，這是對真誠一致常見的誤解。

D：對當事人存有負向評價卻只表現出相反的正向態度，正是不一致（incongruence）的典型例子——內在經驗與外在表達出現落差，恰與真誠一致的定義相反。

本題考點：Rogers 核心條件（core conditions）——真誠一致、無條件正向關懷、同理心三者構成個人中心治療的必要且充分條件；真誠一致（congruence）——治療者內在經驗與外在表達的一致性，不同於情緒宣洩或人格完善。

第 19 題

行為治療使用示範技術主要是依據下列何人的理論？
  1. （A）Skinner
  2. （B）Jacobson
  3. （C）Bandura
  4. （D）Eysenck

答案：（C）

詳解與考點

正解：示範技術（modeling）源自 Bandura 的社會學習理論（social learning theory），主張個體可以透過觀察他人（楷模）的行為及其後果，不必親身經歷嘗試錯誤，即能習得新行為或改變既有反應，這是行為治療中示範法的理論基礎，故選 C。

A：Skinner 的操作制約理論聚焦於行為與其後果（增強、懲罰）之間的關係，說明行為如何因結果而被塑造，但並未特別發展「觀察他人示範以習得行為」的機制。

B：Jacobson 以漸進式肌肉放鬆訓練聞名，其理論核心是透過系統性地緊繃與放鬆肌肉群來降低生理喚起，與示範技術的觀察學習機制無關。

D：Eysenck 以人格特質理論與制約論取向解釋精神官能症的形成，並大力推動行為治療的實徵驗證，但示範技術的理論根源仍歸於 Bandura 而非 Eysenck。

本題考點：社會學習理論（social learning theory）——透過觀察楷模學習行為的機制；示範技術（modeling）——行為治療中運用觀察學習改變行為的技術。

第 21 題

有關認知治療和行為治療的比較，下列敘述何者錯誤？
  1. （A）行為治療為問題導向，認知治療則不是
  2. （B）兩者皆講求實證性，重視現在
  3. （C）行為治療進行行為改變時，認知改變也一起運作
  4. （D）Beck 等一些人的研究顯示，行為改變產生之後，並不一定會產生期待的認知改變

答案：（A）

詳解與考點

正解：認知治療與行為治療都是聚焦於當事人具體困擾、講求可驗證成效的問題導向（problem-focused）取向，兩者皆非僅止於抽象探討內在衝突，而是針對當事人陳述的具體問題設定目標並評估改變；「行為治療為問題導向，認知治療則不是」把兩者對立起來，與事實不符，是錯誤敘述，故選 A。

B：認知治療與行為治療同屬實證取向，重視可觀察、可驗證的資料與此時此地的因應，而非探究早年潛意識衝突，這項共通點的敘述正確。

C：行為治療在改變外顯行為的同時，當事人對自身能力、情境意義的想法（認知）往往也會隨之調整，兩者常同步發生，敘述正確。

D：Beck 等人的研究確實發現，行為改變之後不必然伴隨相對應的認知改變，行為與認知之間並非簡單的一對一連動關係，這項發現支持認知治療需要額外針對想法本身進行工作，敘述正確。

本題考點：認知治療（cognitive therapy）與行為治療（behavior therapy）的異同——共同的問題導向、實證取向，以及行為改變與認知改變之間非必然連動的關係。

第 22 題

下列敘述何者為認知治療學派 Beck 的主張？
  1. （A）心理苦惱主要受到認知基模的影響，而認知基模與當下經驗無關
  2. （B）心理苦惱主要受到認知基模的影響，而認知基模會受幼年經驗影響
  3. （C）心理苦惱主要受到非理性的認知基模所致
  4. （D）心理苦惱主要是負向信念所致，治療的焦點在於協助當事人以正向信念取代負向信念

答案：（B）

詳解與考點

正解：B。Beck 認知治療理論主張，個人在成長過程（尤其幼年經驗）中，透過與重要他人及環境的互動，逐漸形成一套穩定的核心認知基模（schema），這些基模平時處於潛伏狀態，一旦被當下生活事件或壓力情境激發活化，就會產生偏誤的自動化思考，進而導致情緒困擾與心理苦惱。也就是說，認知基模的形成受到幼年經驗深刻影響，而其作用又必須透過與當下情境的互動被激發，兩者環環相扣，B 完整掌握了這個發展性與情境激發並存的觀點，故選 B。

A：Beck 理論強調認知基模平時或許處於潛伏，但必須經由當下的生活事件或壓力情境加以激發活化，才會實際影響情緒與行為；A 主張基模「與當下經驗無關」，忽略了基模被激發歷程正是 Beck 理論的關鍵環節。

C：「非理性認知」是 Ellis 理性情緒行為治療（REBT）慣用的核心術語，Beck 的認知治療雖然同樣關注思考偏誤，但其理論用語聚焦於認知基模、自動化思考、認知扭曲，並非以「非理性」作為核心概念，C 把 Ellis 學派的術語誤植為 Beck 的主張。

D：Beck 治療取向雖然處理負向信念，但其核心技術是協助當事人以實徵檢驗的方式檢視想法與現實證據是否相符（如蘇格拉底式提問、行為實驗），而非單純以「正向信念取代負向信念」的正向思考置換；D 把認知治療簡化成正向思考訓練，混淆了認知重建（cognitive restructuring）與正向思考的差異。

本題考點：Beck 認知治療（Beck's cognitive therapy）——認知基模受幼年經驗形塑並經當下情境激發而致苦惱；認知重建（cognitive restructuring）——透過檢驗想法真實性而非單純正向取代來改變認知。

第 23 題

關於認知治療的敘述，下列何者錯誤？
  1. （A）認知治療對單極憂鬱症的療效普遍被肯定
  2. （B）認知治療重視對非理性信念的處理
  3. （C）在心理層面領悟力較高的當事人，較能從認知治療中獲益
  4. （D）語言技術常用來誘發當事人的自動化思考

答案：（B）

詳解與考點

正解：Beck 所發展的認知治療（cognitive therapy）處理的核心概念是自動化思考（automatic thoughts）與認知扭曲（cognitive distortion），聚焦於當事人對特定情境的即時、常未經檢核的想法；「非理性信念」（irrational beliefs）一詞則是 Ellis 理性情緒行為治療（REBT）的核心概念，指涉個人抱持的僵化、絕對化信念系統，兩者雖然同屬認知取向，理論架構與處理焦點並不相同。本題將「重視非理性信念的處理」歸於認知治療，混淆了 Beck 認知治療與 Ellis REBT 的核心概念，敘述錯誤，故選 B。

A：認知治療對單極憂鬱症（unipolar depression）的療效，累積了大量隨機對照試驗的實證支持，是目前實證基礎最穩固的心理治療取向之一，這個敘述正確。

C：認知治療的介入仰賴當事人能覺察並檢視自己的想法、參與蘇格拉底式對話與認知重建的歷程，心理層面領悟力較高的當事人通常更能配合這類自我省察的工作，因此較能從中獲益，敘述正確。

D：認知治療常運用向下箭頭技術、思考紀錄表等語言性技術，引導當事人辨識在特定情境下自動浮現、未經檢核的自動化思考，這是認知治療的核心技術之一，敘述正確。

本題考點：Beck 認知治療（cognitive therapy）——聚焦自動化思考與認知扭曲的處理；Ellis 理性情緒行為治療（REBT）——聚焦非理性信念的處理，兩者理論脈絡不同，考題常設計混淆陷阱。

第 24 題

家族治療中最常見的促成改變型式有下列那二者？①家庭圖的分析 ②實際演出 ③想法重建 ④作業分配
  1. （A）僅①②
  2. （B）僅③④
  3. （C）僅①③
  4. （D）僅②④

答案：（D）

詳解與考點

正解：實際演出（enactment）與作業分配（homework assignment）是家族治療中最常見、跨取向普遍採用的促成改變形式。實際演出源自結構取向家族治療，讓家庭成員在晤談現場真實展演彼此互動的模式，使治療者得以直接觀察並當場介入調整家庭的互動序列與結構；作業分配則廣泛見於策略取向、行為取向等多種家族治療流派，透過指派家庭在晤談之外具體執行的任務，將晤談中的洞察延伸並落實到日常生活情境中。這兩者都直接以行動促成家庭實質的改變，故選 D（僅②④）。

A（①②）：家庭圖的分析主要用於系統性地蒐集與呈現家庭跨世代的結構、關係與重要事件，屬於評估與概念化家庭系統的工具，而非直接促成改變的介入形式，與②實際演出的性質不同，不宜合併為答案。

B（③④）：想法重建著重修正個人不合理或扭曲的認知信念，是個別認知行為取向常用的技術，並非家族治療中最具代表性、跨取向公認最常見的促成改變形式，與④作業分配的普及程度與取向代表性不同，不宜合併為答案。

C（①③）：家庭圖分析屬評估性質、想法重建屬個別認知介入，兩者皆非以家庭系統中的行動與互動為核心的改變促成形式，與題幹所問家族治療中最常見的促成改變型式的方向不符。

本題考點：家族治療常見改變技術（common change-promoting techniques in family therapy）——實際演出（enactment，源自結構取向）、作業分配（homework assignment，跨取向常用）；評估工具與介入技術的區辨——家庭圖分析屬評估、非直接改變介入。

第 25 題

依據完形治療觀點，有關夢的理論和工作，下列何者錯誤？
  1. （A）是以投射為核心概念
  2. （B）諮商心理師會對夢中的各個元素進行詮釋
  3. （C）夢是通往統整的皇家大道
  4. （D）在治療過程中真實地演出夢境，夢者成為他夢中的部分

答案：（B）

詳解與考點

正解：完形治療對夢的處理主張夢是通往統整（integration）的皇家大道，將夢中出現的每個人物、物件與情境元素，都視為作夢者自身被投射出去、尚未整合的部分；治療進行時，心理師會邀請當事人在此時此刻真實地扮演、重新演出夢中的每個元素，讓夢者親身成為夢中的各個部分，藉由這個經驗歷程使當事人重新擁有並整合這些被投射的自我面向，而不是由心理師代替當事人對夢境元素進行分析與詮釋；因此「諮商心理師會對夢中的各個元素進行詮釋」與完形治療強調當事人親身體驗、而非治療師詮釋的取向相反，是錯誤的敘述，故選B。

A：完形治療的夢工作正是以投射為核心概念，將夢中的元素視為當事人自身未被整合部分的投射，敘述正確。

C：完形治療創始人Perls將佛洛伊德「夢是通往潛意識的皇家大道」的說法，重新詮釋為夢是通往自我統整的皇家大道，這是完形治療對夢的經典主張，敘述正確。

D：完形治療進行夢工作時，會請當事人在治療室中實際扮演夢中的角色或物件，透過真實演出讓夢者成為夢的一部分，藉此體驗並整合被投射出去的自我，敘述正確。

本題考點：完形治療的夢工作（Gestalt dream work）——以投射與親身演出取代詮釋，協助當事人整合自我；統整（integration）——完形治療對夢境功能的核心理解，與精神分析詮釋取向的對比。

第 28 題

在家庭治療理論中，「回饋迴路」用來指家庭系統之自我修正，以維持平衡的狀態，或達到特定 目標。下列何者是指系統會試圖維持原有衡定狀態？
  1. （A）正向回饋
  2. （B）負向回饋
  3. （C）循環回饋
  4. （D）終極回饋

答案：（B）

詳解與考點

正解：家庭治療的一階模控論（first-order cybernetics）以回饋迴路說明系統如何運作。負向回饋（negative feedback）是指系統在偏離既有平衡點時，會啟動一連串修正動作，把狀態拉回原本的衡定點（homeostasis），例如家庭成員以責備、沉默等慣性反應把偏離常軌的行為拉回原有互動模式。題幹描述的正是系統「試圖維持原有衡定狀態」，對應的就是負向回饋，故選 B。

A：正向回饋（positive feedback）作用方向相反，它會放大系統內部的偏差，使系統偏離原有平衡、朝新的狀態演化，例如家庭危機被放大到必須改變原有規則，這是促成改變而非維持現狀。

C：循環回饋並非模控論中用來區分「維持衡定」或「促成改變」的專有分類，它比較接近描述系統中「原因即是結果、結果又回頭成為原因」的循環因果（circular causality）概念，屬於系統觀的思考方式，而非題幹所問的特定回饋類型。

D：終極回饋不是家庭治療模控論的標準術語，題幹要問的是系統自我修正、維持恆定的機制，與「終極」所暗示的終點或目的性用語不相符，屬於混淆用語的干擾選項。

本題考點：模控論回饋迴路（cybernetic feedback loop）——負向回饋維持系統平衡、正向回饋放大偏差促成改變；家庭系統衡定（homeostasis）——家庭系統傾向自我修正以維持慣常互動模式。

第 29 題

下列對女性主義治療關係的描述，何者有誤？
  1. （A）不強調諮商心理師的專家角色
  2. （B）諮商心理師可能會與當事人一同參與社會運動
  3. （C）相同性別的諮商心理師及當事人的配對是較理想的組合
  4. （D）當事人可參與自己症狀的評估與診斷

答案：（C）

詳解與考點

正解：女性主義治療強調諮商關係應建立在平權（egalitarian）的基礎上，重視性別與權力議題對當事人議題的影響，鼓勵治療師依情境彈性運用多元的關係型態（包括共同參與社會行動），但並未主張同性別配對是「較理想」的固定原則——治療師的性別覺察與平權態度，比諮商師與當事人是否同性別更為關鍵，配對是否理想需視個案與情境而定，並非女性主義治療的核心主張。C選項將「同性別配對」宣稱為較理想的組合，與女性主義治療重視彈性與情境考量、而非以性別配對作為理想原則的立場不符，是本題錯誤的敘述，故選C。

A：女性主義治療批判傳統治療關係中諮商師高高在上的專家權威，主張建立平權、去階層化的治療關係，敘述符合女性主義治療的核心精神，正確。

B：女性主義治療重視個人議題與社會結構的關聯，鼓勵治療師在合宜的情況下與當事人一同投入社會行動，以實踐改變壓迫性社會結構的理念，敘述正確。

D：女性主義治療反對將診斷標籤視為治療師單方面的專業裁定，主張當事人應被邀請共同參與對自身症狀的理解、評估與命名歷程，體現賦權（empowerment）精神，敘述正確。

本題考點：女性主義治療（feminist therapy）——強調平權治療關係、社會行動與當事人賦權；性別配對迷思——女性主義治療重視治療師的性別覺察與平權態度，而非將同性別配對視為理想的固定原則，是本題判斷C選項錯誤的關鍵。

第 30 題

下列何者不是女性主義治療的目標？
  1. （A）調適自我，以適應社會文化的變遷
  2. （B）自我照顧並提昇自尊
  3. （C）賦權與增能
  4. （D）參與社會行動

答案：（A）

詳解與考點

正解：女性主義治療強調賦權與社會行動，目標在協助案主看見個人困擾背後的社會文化與性別權力結構因素，進而提升自我覺察、增能與採取行動改變不公平的結構，而不是要案主單方面調整自己去配合、適應既有的社會文化變遷；「調適自我以適應社會文化的變遷」這種以個人適應為導向的說法，恰與女性主義治療反對將個人問題純粹個人化、要求個人單方面配合社會的立場相反，故選 A 為非其治療目標。

B：協助案主自我照顧並提昇自尊，是女性主義治療重視個人主體價值、修復因性別壓迫而受損之自我概念的核心目標之一，屬於治療目標。

C：賦權與增能（empowerment）是女性主義治療的核心概念之一，強調協助案主重新取得對自己生活的掌控感與行動力，屬於治療目標。

D：鼓勵案主參與社會行動，將個人議題與更大的社會結構性別議題連結、進而投入改變行動，是女性主義治療「個人的即是政治的」核心精神的具體實踐，屬於治療目標。

本題考點：女性主義治療（feminist therapy）——賦權與增能（empowerment）；個人的即是政治的（the personal is political）——反對將結構性壓迫問題化約為個人單方面適應的問題。

第 31 題

女性主義治療的晤談過程中，諮商心理師會以下列何種方式與當事人建立治療關係？
  1. （A）主動說明自己的專業訓練
  2. （B）分享自己的生命經驗
  3. （C）提供當事人女性主義相關的理念之說明
  4. （D）提供當事人對其目前心理症狀的診斷

答案：（B）

詳解與考點

正解：B。女性主義治療（feminist therapy）強調治療關係應是平權（egalitarian）而非傳統專家與病人式的權力不對等關係，適度的治療師自我揭露（self-disclosure），尤其是分享自己的生命經驗，是女性主義治療常用以拉近雙方位階、去除治療師神秘專家形象、建立真誠平等關係的重要技巧，故選B。

A：主動說明自己的專業訓練屬於「去神秘化」（demystifying therapy）的做法，讓當事人清楚治療的性質與限制，有助於權力透明化，但這是關於治療架構資訊的告知，並非女性主義治療用以建立關係最核心強調的自我揭露技巧。

C：提供當事人女性主義相關理念的說明，屬於意識覺醒（consciousness-raising）或心理教育的介入內容，目的在協助當事人理解社會性別結構對其困擾的影響，性質上是教育性介入，而非建立治療關係本身的技巧。

D：提供當事人對其心理症狀的診斷，隱含將當事人問題病理化、標籤化，與女性主義治療反對將個人困擾窄化為個體病理、忽略社會脈絡因素的立場相違背，也不是用來建立平權關係的做法。

本題考點：女性主義治療（feminist therapy）——強調平權治療關係與社會脈絡分析；治療師自我揭露（self-disclosure）——女性主義治療用以降低權力不對等、建立真誠關係的技巧。

第 32 題

下列有關女性主義的敘述何者適切？
  1. （A）協助女性學習個人調適方式
  2. （B）幫助女性改變其自己個人生活
  3. （C）幫助女性接納個人的身體和情慾
  4. （D）協助女性探索個人心理問題的內在因素

答案：（C）

詳解與考點

正解：女性主義治療（feminist therapy）主張「個人的即政治的」（the personal is political），強調女性長期受父權文化對身體與情慾的規範、貶抑與污名所壓迫，因此協助女性重新認識、接納自己的身體與情慾，擺脫社會加諸的羞恥感與自我否定，是女性主義治療重要的賦權（empowerment）工作之一，故選 C。

A：「協助女性學習個人調適方式」隱含要女性去適應既有的社會處境與角色期待，這正是女性主義治療所批判的傳統治療取向——傳統治療常要求個案調適於壓迫性的環境，而非挑戰環境本身，與女性主義治療重視社會改變、質疑父權結構的立場相反。

B：只強調「改變個人生活」，把焦點侷限在個人層次，忽略了女性主義治療同樣重視集體行動與社會政治面向的改變；女性主義治療認為個人困擾往往根源於性別權力結構，單靠改變個人生活無法觸及問題核心。

D：把重點放在「探索個人心理問題的內在因素」，延續了傳統治療將問題內在化、病理化個人的取向，這正是女性主義治療所批評的——過度聚焦個案內在心理因素，會忽視性別壓迫、社會文化脈絡對女性困擾的實質影響。

本題考點：女性主義治療（feminist therapy）——個人即政治、賦權與社會改變並重；身體與情慾的自主接納——挑戰父權文化對女性身體的規範與污名。

第 33 題

下列對於焦點解決短期治療有關諮商歷程的描述，何者有誤？
  1. （A）諮商心理師應該成為創造改變情境的專家
  2. （B）重視合作的治療關係
  3. （C）諮商關係基本上是一種短期的形式
  4. （D）歷程中不建議以量尺評量方式，了解問題解決的程度

答案：（D）

詳解與考點

正解：焦點解決短期治療（solution-focused brief therapy, SFBT）的核心技術之一就是量尺問句（scaling question），諮商心理師會請當事人以 0 到 10 分的量尺，具體評估目前問題解決的程度、對改變的信心或期待改變後的樣貌，藉此將抽象的感受具體化、幫助當事人覺察自身已有的進展並設定下一步的小目標。因此量尺評量不僅被建議使用，更是 SFBT 歷程中的關鍵工具，「歷程中不建議以量尺評量方式，了解問題解決的程度」與實務做法相反，是錯誤敘述，故選 D。

A：SFBT 強調心理師的專業性在於引導與催化改變情境的形成，而非診斷病理或提供答案；心理師運用問句技巧（如奇蹟問句、例外問句）協助當事人自行建構解決之道，這種「創造改變情境的專家」定位正是 SFBT 對諮商師角色的描述，敘述正確。

B：SFBT 高度重視治療關係中的合作與平等，心理師採取「不知」（not-knowing）的姿態，視當事人為自身生活的專家，雙方共同建構解決方案，合作式關係是 SFBT 的基本精神，敘述正確。

C：SFBT 顧名思義即為短期治療取向，強調在有限次數的晤談中聚焦於當事人的目標與資源，快速促成具體而微小的改變，療程通常遠短於傳統長期心理動力治療，敘述正確。

本題考點：焦點解決短期治療（SFBT）——聚焦資源與例外、建構解決之道的短期治療取向；量尺問句（scaling question）——將改變程度具體化的核心技術；不知的姿態（not-knowing posture）與合作式治療關係。

第 34 題

下列那種描述，是敘事治療中常運用的「問題外化」的提問方式？
  1. （A）「憤怒」通常什麼時候會找上你？
  2. （B）朋友們會如何描述正在「憤怒」的你？
  3. （C）當你感到「憤怒」時，會作些什麼事情？
  4. （D）你喜歡「憤怒」的自己嗎？

答案：（A）

詳解與考點

正解：敘事治療主張「人不等於問題，問題本身才是問題」，外化（externalizing the problem）就是在語言上把問題從當事人身上分離出來，將它描述成一個獨立於當事人之外、會出現會離去、有自己出沒時機的存在。選項 A 把「憤怒」說成一個會「找上你」的對象，探問的是它出現的時機與條件，這種語言結構正是外化提問的典型樣貌，順著這個句型還可以繼續追問憤怒如何影響當事人的生活、當事人又如何反過來影響憤怒，藉此開啟例外經驗與獨特結果的敘說，故選 A。

B：問朋友們會如何描述「正在憤怒的你」，憤怒仍然是附著在當事人身上的形容詞，等於把外界對當事人既有的描述再複述一次，容易強化「充滿問題」的自我認同，方向與外化想要鬆動的目標相反。

C：問感到憤怒時做了些什麼，停留在行為層次的描述，情緒本身仍被視為當事人內在的狀態，這類問句在功能分析或認知行為取向中很常見，但並沒有完成「人與問題分離」的外化語言結構。

D：問喜不喜歡憤怒的自己，直接把憤怒等同於自我並要求當事人對自己做出價值評判，是典型的內化語言，可能反而加深當事人的自責，與外化的方向相反。

本題考點：敘事治療（narrative therapy）——透過重寫故事鬆動當事人「充滿問題」的自我敘說；問題外化（externalizing the problem）——將問題擬人化並與當事人本身分離的語言技術。

第 40 題

下列有關心理劇使用之技巧及其目的之敘述，何者正確？
  1. （A）利用鏡像（mirror）技巧可以協助當事人消除自我中心傾向
  2. （B）角色互換（role reversal）可以協助表達與澄清主角未說出的想法
  3. （C）透過替身（double）可幫助當事人培養對他人的同理心
  4. （D）運用角色訓練（role training）可幫助當事人為某件事情做準備

答案：（D）

詳解與考點

正解：角色訓練（role training）是心理劇技術之一，讓當事人在安全的舞台情境中，預先演練即將面臨的真實情境所需的行為、對話或角色，透過反覆排演增進當事人的因應能力與信心，協助其為現實生活中的特定事件做好準備，敘述正確，故選 D。

A：鏡像技巧是讓當事人退到舞台一旁，觀看由替身或其他成員重演自己剛才的言行，藉由站在外面看自己的視角，獲得對自己行為模式較為客觀的覺察，核心功能是提升自我覺察，而非直接針對消除自我中心傾向這種人格特質的改變，敘述並不準確。

B：角色互換是讓當事人與劇中的另一角色互換位置，站在對方立場說話與感受，藉此增進對他人處境與感受的理解，屬於培養同理心的技巧；而表達與澄清主角未說出的想法是替身技巧的功能，此處將兩種技巧的目的對調，敘述不正確。

C：替身是由輔角站在當事人身旁或身後，代替當事人說出其內心尚未表達出口的想法與感受，協助當事人更清楚覺察並表達內在經驗；培養對他人的同理心則是角色互換的效果，此處選項將兩種技巧的目的互換，敘述不正確。

本題考點：心理劇（psychodrama）技巧——鏡像、角色互換、替身、角色訓練各自的功能與目的區辨。
