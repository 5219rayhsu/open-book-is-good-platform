第 1 題

對於成為具多元文化能力的諮商心理師，下列敘述何者錯誤？
  1. （A）多元文化能力的培養應由覺察個人所擁有的文化價值、偏見及態度開始
  2. （B）想要成為具多元文化能力的諮商心理師，就必須挑戰自己自動化的價值觀
  3. （C）諮商心理師的角色是協助個案做出與諮商心理師價值觀一致的決定
  4. （D）諮商心理師發展出對文化差異的敏感度是倫理上應有的責任

答案：（C）

詳解與考點

考點為多元文化諮商能力。培養須從覺察自身文化價值與偏見開始、挑戰自動化價值觀、發展文化敏感度屬倫理責任。C 錯：諮商師不應引導個案做出與「諮商師價值觀一致」的決定，這違反尊重個案自主與價值中立原則。

第 2 題

關於新手諮商心理師反移情的敘述，下列何者錯誤？
  1. （A）反移情可能是連帶地受到個案的情緒經驗所影響
  2. （B）反移情是諮商過程中對個案問題的情緒性反應與投射
  3. （C）於諮商過程中不宜占用到與個案晤談的時間，處理自己的反移情
  4. （D）透過督導是解決反移情引發個人議題的最有效方式

答案：（D）

詳解與考點

考點為反移情。反移情是諮商師對個案的情緒反應與投射，可能受個案情緒感染，不宜佔用晤談時間處理自己的議題，均正確。D 錯在「督導是最有效方式」用詞過絕，反移情常需個人治療、自我覺察並行，督導非唯一最有效途徑。

第 3 題

關於諮商的定義，下列何者錯誤？
  1. （A）諮商目標是由個案決定並由其承擔責任
  2. （B）諮商關係是建立在雙方的互信基礎上
  3. （C）維持諮商的信任關係主要條件是保守諮商機密
  4. （D）個案的積極合作及參與是達成諮商目標的關鍵

答案：（A）

詳解與考點

考點為諮商的基本定義。互信基礎、保密維持信任、個案積極參與是達成目標關鍵均正確。A 錯：諮商目標應由諮商師與個案「共同」協商訂定，且責任非全由個案承擔，敘述過於片面，故為錯誤。

第 4 題

關於心理分析治療學派的敘述，下列何者正確？
  1. （A）自我心理學（ego psychology）強調統整與個體化
  2. （B）榮格（Jung）分析心理學著重分離個體化
  3. （C）自體心理學（self psychology）關注自戀發展與早期親子關係
  4. （D）客體關係學派著重社會適應與人生週期發展

答案：（C）

詳解與考點

考點為精神分析各支派定位。C 正確：自體心理學（Kohut）關注自戀發展與早期親子（鏡映、理想化）關係。A 錯（個體化是榮格概念）、B 錯（分離個體化是 Mahler 客體關係的概念）、D 錯（社會適應與人生週期是 Erikson）。各支派配對易混淆。

第 5 題

依據拉賓（Rabin）的觀點，下列何者不屬於當代精神分析中的典範轉移（paradigm shift）？
  1. （A）後設心理學
  2. （B）關係理論
  3. （C）社會建構論
  4. （D）互為主體理論

答案：（A）

詳解與考點

考點為當代精神分析的典範轉移。關係理論、社會建構論、互為主體理論都是當代由一人心理學轉向關係取向的新典範。A「後設心理學（metapsychology）」屬古典 Freud 的傳統理論架構，非新典範，故為不屬於者。

第 6 題

下列那一個概念是Jung所指的「人的本質是所有心靈歷程的總和，由意識與潛意識組成」？
  1. （A）自我（ego）
  2. （B）自體（self）
  3. （C）心靈（psyche）
  4. （D）原型（archetype）

答案：（C）

詳解與考點

考點為榮格的核心概念。題幹定義「由意識與潛意識組成的所有心靈歷程總和」即心靈（psyche），故 C 正確。易誤選 B 自體（self），但自體是人格的核心與整合原型；ego 是意識中心；archetype 是集體潛意識的原型，層次不同。

第 7 題

阿德勒學派特別重視探索手足關係和出生序，下列敘述何者錯誤？
  1. （A）同一家庭經驗，可能產生不同的心理位置
  2. （B）實際的出生序和個人的詮釋，在應用上一樣重要
  3. （C）了解手足競爭可能形成的特定人格傾向
  4. （D）主張家庭關係是影響最大的社會系統

答案：（B）

詳解與考點

考點為阿德勒學派的手足關係與出生序。同一家庭不同心理位置、了解手足競爭形成的人格、家庭是最重要社會系統均正確。B 錯：阿德勒強調「心理出生序」即個人主觀詮釋比實際排行更重要，而非兩者「一樣重要」。

第 8 題

如果諮商心理師詢問個案下列問題，例如：「這個問題是如何在你的生活中出現的？」、「有那些引發事件？」、「曾接受那些治療（包括過去與目前的疾病醫療史）？」、「過去的社交史如何？」、「何以現在要接受心理治療？」。請問在阿德勒治療中，這是使用何種技術以蒐集個案資料？
  1. （A）早期回憶
  2. （B）客觀性晤談
  3. （C）家庭星座
  4. （D）主觀性晤談

答案：（B）

詳解與考點

考點為阿德勒的評估晤談技術。題幹問題聚焦現病史、誘發事件、過去治療與社交史等客觀事實資料的蒐集，屬客觀性晤談，故 B 正確。主觀性晤談著重個案的生命故事與主觀經驗，早期回憶與家庭星座是其中特定技術，易混淆。

第 9 題

下列何者為阿德勒治療學派認為個案建構其生活型態的哲學基礎？
  1. （A）私人邏輯
  2. （B）早期回憶
  3. （C）認知地圖
  4. （D）虛構目的論

答案：（A）

詳解與考點

考點為阿德勒學派生活型態的哲學基礎。A 私人邏輯（private logic）是個體據以建構生活型態的個人化信念與認知架構，為其哲學基礎。早期回憶是評估工具、虛構目的論是動力方向、認知地圖非阿德勒核心用語，故選私人邏輯。

第 10 題

下列何者是存在主義治療最後階段的治療重點？
  1. （A）幫助個案找到方法，將他們的力量運用在生活中
  2. （B）鼓勵個案檢視其價值系統的來源
  3. （C）幫助個案辨別和澄清其內心對世界的假設
  4. （D）幫助個案認識其焦慮的本質

答案：（A）

詳解與考點

考點為存在主義治療的階段重點。最後（行動/統整）階段重在協助個案把覺察轉化為力量、實踐於生活，故 A 正確。檢視價值來源、澄清世界假設、認識焦慮本質屬較早的覺察階段，易誤選因都屬存在治療內容但階段不符。

第 11 題

下列何者最不可能是存在主義治療師對存在的罪惡（existential guilt）所做之描述？
  1. （A）「個案想成為一個受歡迎的人，可是為什麼總是適得其反！」
  2. （B）「個案覺得自己像一本書的某一頁，每一個人都很快的翻過，但是沒人願意讀它！」
  3. （C）「個案想跟他爸爸說他好愛他，但他總說不出口。」
  4. （D）「個案已經接受半年的心理治療了，但是為什麼他還依然固著在他原先的行為？」

答案：（D）

詳解與考點

考點為存在的罪惡（existential guilt）——指未能實現潛能、逃避自由與真實存在而生的罪惡感。A、B、C 都隱含個案未活出真實自我或潛能。D「接受治療半年仍固著於原行為」描述的是治療進展/抗拒問題，非存在罪惡，故最不可能。

第 12 題

關於存在主義治療對本真性（authenticity）的敘述，下列何者錯誤？
  1. （A）願意面對個人存在的限制
  2. （B）擁有自己的價值與目標
  3. （C）因自由、責任、死亡等議題經驗到罪惡感
  4. （D）以親密感為導向

答案：（C）

詳解與考點

考點為存在主義的本真性（authenticity）。本真即願面對存在限制、擁有自己的價值與目標。C 錯：因自由、責任、死亡而「經驗到罪惡感」描述的是存在焦慮/罪惡的狀態，而非本真性的特徵，敘述混淆了兩個概念。

第 13 題

關於個人中心學派人格理論的敘述，下列何者錯誤？
  1. （A）從外在獲得的正向關注，影響個人的自我關注
  2. （B）價值制約引發個人的自我經驗與他人互動上之不一致
  3. （C）為了反轉個人經驗的價值制約，必須有一些無條件的正向關注，自我關注才會增強
  4. （D）負責任的享樂主義是人們發展的理想目標

答案：（D）

詳解與考點

考點為個人中心學派人格理論（Rogers）。外在正向關注影響自我關注、價值制約造成自我與經驗不一致、無條件正向關注可逆轉制約均正確。D 錯：「負責任的享樂主義」是現實治療/Glasser 的概念，非個人中心的理想目標。

第 14 題

關於個案在個人中心學派中的經驗，下列敘述何者錯誤？
  1. （A）個案學習到在諮商關係中可以為自己負責
  2. （B）隨著諮商的進展，個案更能探索自己的情感或信念
  3. （C）個案被接納和了解後，防衛就會下降
  4. （D）諮商心理師創造個案成長並啟動其改變

答案：（D）

詳解與考點

考點為個人中心學派中個案的經驗與改變機轉。個案學會為己負責、更能探索情感、被接納後防衛下降均正確。D 錯：個人中心強調改變動力源自個案自身的自我實現傾向，諮商師是提供條件促進者，而非「創造成長並啟動改變」的主導者。

第 15 題

關於情緒焦點治療，下列敘述何者正確？
  1. （A）起源於意義治療法
  2. （B）著重在覺察、接納和理解情緒的內在經驗
  3. （C）情緒的困擾來自非理性信念
  4. （D）情緒在心理治療性改變中的角色並不重要

答案：（B）

詳解與考點

考點為情緒焦點治療（EFT, Greenberg）。B 正確：核心在覺察、接納並理解情緒的內在經驗。A 錯（起源於人本/個人中心與經驗取向，非意義治療）、C 錯（非理性信念是 REBT）、D 錯（EFT 強調情緒在改變中扮演關鍵角色）。

第 16 題

關於完形治療取向的實驗，下列敘述何者正確？
  1. （A）是一種現成的技術，常在個別工作中催化工作同盟
  2. （B）是事先計畫妥善的活動，常用來引發情緒，產生行動，達到特定的目標
  3. （C）是將諮商的焦點從談論某個主題，轉化成行動的一種方法
  4. （D）由個案自己設計，目的是要開展出治療互動的主題

答案：（C）

詳解與考點

考點為完形治療的實驗（experiment）。C 正確：實驗是把焦點從「談論」主題轉化為「行動」體驗的方法。A 錯（非現成既定技術）、B 錯（實驗具即興、隨歷程生成性，非事先計畫好的活動）、D 錯（由諮商師與個案共同在當下開展，非個案獨自設計）。

第 17 題

關於現實治療對行為的看法，下列何者錯誤？
  1. （A）人們透過自己正在做的行為向外傳遞訊息
  2. （B）藉由諮商心理師的判斷能幫助個案了解其行為是否滿足需求
  3. （C）調整個案正在做的完全行為（total behavior）改變其生活
  4. （D）諮商的焦點在個案能負起責任並做出選擇

答案：（B）

詳解與考點

考點為現實治療（Glasser）對行為的看法。行為對外傳遞訊息、調整完全行為、聚焦負責與選擇均正確。B 錯：現實治療強調由「個案自己」評估行為是否滿足需求，而非由諮商師判斷，這違反其自我評估的核心精神。

第 18 題

關於現實治療對治療關係的看法，下列敘述何者錯誤？
  1. （A）良好的治療關係可教導個案與重要他人建立關係
  2. （B）治療關係是個案能有效改變的基礎
  3. （C）諮商心理師接受個案的移情有助於促進治療關係
  4. （D）真誠投入的氣氛可協助個案深層瞭解自己

答案：（C）

詳解與考點

考點為現實治療的治療關係觀。良好關係可示範與重要他人連結、是改變基礎、真誠投入助深層自我了解均正確。C 錯：現實治療不採用精神分析的移情概念，「接受個案移情」並非其立場，屬學派混淆的陷阱。

第 19 題

個案因分手後嚴重缺課，經由導師轉介進行諮商。當個案訴說伴侶無情的迴避他，讓他覺得很痛苦。下列何者符合現實治療取向之個案概念化觀點？①伴侶的迴避勾起個案童年的分離焦慮②面對伴侶的迴避，個案選擇了痛苦③痛苦的感受讓個案得以逃避課業壓力④透過安全的諮商關係可解決個案的痛苦，使他穩定上課
  1. （A）①②
  2. （B）②③
  3. （C）③④
  4. （D）①④

答案：（B）

詳解與考點

考點為現實治療/選擇理論的個案概念化。②個案面對迴避「選擇了痛苦」、③痛苦讓個案逃避課業壓力，符合選擇理論（行為是選擇、症狀有其功能）。①分離焦慮屬精神分析、④把改變歸於安全諮商關係屬個人中心，故選②③。

第 20 題

承上題，若諮商心理師想要瞭解個案的完全行為（total behavior），下列敘述何者正確？
  1. （A）完全行為只包括正在做的、想的、感覺的與心理經驗
  2. （B）完全行為都是個案自主的（voluntary）
  3. （C）諮商心理師在治療過程中持續進行完全行為的評估
  4. （D）必須先處理感覺才能改變個案的所做所思

答案：（C）

詳解與考點

考點為現實治療的完全行為（total behavior）。C 正確：諮商師在治療中持續評估完全行為。A 錯（完全行為含行動、思考、感覺與生理四成分）、B 錯（直接可控的是行動與思考，感覺生理非全自主）、D 錯（改變從行動思考著手，不必先處理感覺）。

第 21 題

關於各諮商理論學派之敘述，下列何者錯誤？
  1. （A）協助個案成為功能充分發揮的人（fully functioning person）是個人中心治療的自我理論觀點
  2. （B）完形治療越來越重視此時此刻的經驗，認為覺察是個體發展與成長的核心
  3. （C）理性情緒行為治療法目標在運用認知控制，改變或修正個案認知結構
  4. （D）行為治療法認為操作制約是被引發的，而古典學習歷程行為具有自發性

答案：（D）

詳解與考點

考點為各學派核心主張的辨識。A、B、C 對個人中心、完形、REBT 的描述均正確。D 錯且顛倒：操作制約的行為是「自發後被強化」、古典制約的反應才是「被引發（誘發）」的，本選項把兩者的引發/自發性說反了。

第 22 題

在Lazarus所創的多重模式治療法（multimodal therapy）中的BASIC I.D.涵蓋下列那些層面？①行為（behavior）②情感（affect）③直覺（intuition）④感官（sensation）
  1. （A）僅①③④
  2. （B）僅①②④
  3. （C）①②③④
  4. （D）僅②③

答案：（B）

詳解與考點

考點為 Lazarus 多重模式治療的 BASIC ID。七面向為行為、情感、感官、心像、認知、人際、藥物/生理。題目①行為②情感④感官均屬之，③「直覺」不在其中（I 為 Imagery 心像），故選僅①②④。

第 23 題

選擇性緘默症患者在學校可能出現獨處、不說話等狀況，但在其他場合（如家裡）就會說話，此現象可以被解釋為下列那一個現象？
  1. （A）區辨學習
  2. （B）消弱
  3. （C）負增強
  4. （D）處罰

答案：（A）

詳解與考點

考點為操作/辨別制約。選擇性緘默者在學校（某刺激情境）不說話、在家（另一刺激情境）說話，是行為受不同情境刺激控制的區辨學習（stimulus discrimination），故 A 正確。消弱、負增強、處罰指涉行為頻率的增減機制，與情境辨別不符。

第 24 題

關於Meichenbaum的壓力免疫訓練，下列敘述何者錯誤？
  1. （A）在概念化教育階段，焦點在於和個案建立良好合作的關係
  2. （B）個案進行內在對話時，會思考「是那些想法造成我這樣的想法，我必須要克服它」
  3. （C）個案進行自我陳述時，會將所學到的新技巧嘗試運用到現實生活
  4. （D）個案會嘗試在預防復發階段，將不順遂視為學習的機會

答案：（B）

詳解與考點

考點為 Meichenbaum 壓力免疫訓練（SIT）三階段。概念教育期建立合作關係、技巧獲得後在現實演練、預防復發期視挫折為學習機會均正確。B 錯：自我內在對話應是「正向、因應性」的自我陳述，題述的責備式想法不符合 SIT 的內言訓練精神。

第 25 題

關於接納與承諾治療（acceptance and commitment therapy，簡稱ACT），下列敘述何者錯誤？
  1. （A）是一種以正念為基礎的治療法
  2. （B）承諾行動的方式，會透過家庭作業和行為練習來達成
  3. （C）治療目標在促使個體能夠覺察、檢驗自己的思緒，學習改變與接納
  4. （D）個體能否專注於當下，取決於對過去經驗的理解

答案：（D）

詳解與考點

考點為接納與承諾治療（ACT）。ACT 以正念為基礎、透過家庭作業與行為練習承諾行動、目標含覺察檢驗思緒與接納均正確。D 錯：ACT 強調「活在當下」是直接的接觸經驗，並非「取決於對過去經驗的理解」，這偏向其他取向。

第 26 題

關於認知學派的諮商目標或介入策略，下列敘述何者正確？
  1. （A）幫個案找出私人邏輯的謬誤，並據以訂定後續的介入策略
  2. （B）鼓勵個案辨認其自動化思考如何影響情緒，並訂定後續的介入策略
  3. （C）將個案過去的早期經驗納入諮商，並以此為諮商的主要目標
  4. （D）協助個案處理心理困擾時，會強調過去負向經驗累積帶來的影響

答案：（B）

詳解與考點

考點為認知學派（Beck）介入策略。B 正確：辨認自動化思考如何影響情緒，再據以擬定介入。A 錯（私人邏輯是阿德勒）、C 與 D 錯：認知治療聚焦此時此刻的認知，雖會參考過去但不以早期經驗或過去負向累積為主要目標，易誤選 A。

第 27 題

關於理情行為治療的人格理論，下列何者錯誤？
  1. （A）不相信人類性格的生物性因素
  2. （B）主張個體有許多尚未被發覺的成長資源
  3. （C）許多困擾來自於不理性信念所導致
  4. （D）個案的困擾來自於應該、必須及一定等信念

答案：（A）

詳解與考點

考點為理情行為治療（REBT, Ellis）人格理論。REBT 主張人有未發掘的成長資源、困擾源自不理性信念與「應該/必須/一定」的絕對化要求，均正確。A 錯：Ellis 認為人有先天的生物傾向（趨向理性也趨向非理性），並非「不相信生物性因素」。

第 28 題

小飛計畫出國留學，但父親突然罹癌，辭掉工作在家靜養，家中經濟受到影響，母親每天以淚洗面。小飛決定休學打工養家，並經常安撫母親的情緒。依照Bowen的觀點，小飛最可能是下列何種現象？
  1. （A）情緒截斷
  2. （B）家庭投射歷程
  3. （C）跨世代聯盟
  4. （D）界限

答案：（B）

詳解與考點

考點為 Bowen 家庭系統概念。父母焦慮投射到子女、使子女承接家庭功能與情緒負荷，即家庭投射歷程，故 B 正確。情緒截斷是切斷與原生家庭連結、跨世代聯盟是隔代結盟、界限屬結構學派用語，與本情境不符。

第 29 題

關於結構取向家族治療的治療策略與技術，下列敘述何者正確？
  1. （A）使用家庭雕塑
  2. （B）評估家庭失功能的互動模式
  3. （C）評估家庭成員的個別功能
  4. （D）使用矛盾策略法

答案：（B）

詳解與考點

考點為結構取向家族治療（Minuchin）。B 正確：核心在評估家庭失功能的互動模式（次系統、界限、聯盟）。A 家庭雕塑屬 Satir 經驗取向、C 評估個別功能偏個人取向、D 矛盾策略屬策略/系統取向，皆非結構學派核心技術。

第 30 題

關係取向精神分析採取的雙人（two-person）心理學立場，著重下列何者間的互動與影響？
  1. （A）個案的自體和內在客體
  2. （B）個案與重要他人
  3. （C）個案與諮商心理師
  4. （D）個案的主觀自我和客觀自我

答案：（C）

詳解與考點

考點為關係取向精神分析的雙人心理學。C 正確：雙人心理學著重「個案與諮商師」之間的互動與相互影響（互為主體）。A、D 屬一人心理學的內在客體/內在自我，B 個案與重要他人非治療室內的雙人互動焦點。

第 31 題

關於家庭系統取向之主要人物與技術，下列配對何者正確？
  1. （A）Minuchin：去三角關係（detriangulation）
  2. （B）Bowen：影響輪（wheel of influence）
  3. （C）Satir：界線標定（boundary marking）
  4. （D）Madanes：開門見山的任務（straightforward tasks）

答案：（D）

詳解與考點

考點為家庭系統取向人物與技術配對。D 正確：Madanes（策略取向）使用開門見山的任務。A 錯（去三角化是 Bowen，非 Minuchin）、B 錯（影響輪非 Bowen 之代表技術）、C 錯（界線標定是 Minuchin 結構學派，非 Satir）。配對易張冠李戴。

第 32 題

女性主義治療師為了建立權力均等的治療關係，會採取下列那個技術以去除治療關係的神祕性？
  1. （A）重新框架
  2. （B）自我揭露
  3. （C）重新標籤
  4. （D）權力分析

答案：（B）

詳解與考點

考點為女性主義治療去神祕化、建立平權關係的技術。B 自我揭露：諮商師適度揭露可去除治療關係的神祕與權力落差，故正確。重新框架、重新標籤、權力分析雖屬女性主義常用技術，但去除「神祕性」最對應的是自我揭露。

第 33 題

關於女性主義治療主張「個人即政治」，下列敘述何者錯誤？
  1. （A）個案係受到社會及政治體制的影響，特別是女性
  2. （B）每個人都應該有均等的政治參與權，女性不應被排除
  3. （C）女性尋求心理治療的個人問題是源自於社會和政治的壓迫
  4. （D）如果個案個人要改變，則社會環境中有害的成分也要被改變

答案：（B）

詳解與考點

考點為女性主義「個人即政治」。個案受社會政治體制影響、個人問題源自社會壓迫、個人改變需連帶改變有害社會成分均正確。B 錯：「均等政治參與權」是泛論的政治權利主張，並非「個人即政治」這一治療概念的內涵，屬離題誤導。

第 34 題

關於多元文化諮商的觀點，下列敘述何者正確？①並非僅限於來自不同種族或國籍背景之個案與諮商心理師所形成的諮商關係②是關於諮商與助人關係的「思考方式」或「後設理論」③強調具有文化智性（culturally-informed）的諮商心理師與諮商關係
  1. （A）僅①②
  2. （B）僅①③
  3. （C）僅②③
  4. （D）①②③

答案：（D）

詳解與考點

考點為多元文化諮商的本質。正解為①②③全部正確：多元文化諮商不限於不同種族或國籍背景所形成的關係（廣義含性別、階級、宗教等多元差異）；它是一種看待助人關係的「思考方式」或後設理論；並強調諮商師需具文化智性。故答案為 D。陷阱在誤以為多元文化只談種族國籍。

第 35 題

關於敘事治療的治療精神或特色，下列敘述何者錯誤？
  1. （A）以優勢為基礎
  2. （B）聚焦於過去，甚於現在
  3. （C）重視合作的治療同盟
  4. （D）相信個案是自己的專家

答案：（B）

詳解與考點

本題為「何者錯誤」，官方答案為 (B)。敘事治療（narrative therapy，White 與 Epston）屬後現代取向，並不主張「聚焦於過去甚於現在」。其核心是透過外化、解構問題故事、尋找獨特意義事件（unique outcomes）與例外，協助個案重寫偏好的故事，著眼於當下與未來的故事重構，而非執著於探究過去成因，故 (B) 敘述錯誤、為正解。(A) 正確：敘事治療以個案的優勢與資源為基礎（strengths-based）。(C) 正確：強調平等、合作的治療同盟，治療師採「去中心而有影響力」的姿態。(D) 正確：相信個案才是自己生命經驗的專家（the client is the expert），治療師抱持「不知道」（not-knowing）的態度。

第 36 題

關於後現代取向諮商心理師的態度，下列敘述何者最正確？
  1. （A）重視創造矯正性的經驗
  2. （B）諮商之前宜先形成個案概念化
  3. （C）諮商心理師應提出有效能的介入策略
  4. （D）對故事的答案與發展保持好奇的態度，心中無定見

答案：（D）

詳解與考點

本題問後現代取向諮商心理師「最正確」的態度，官方答案為 (D)。後現代取向（如敘事治療、焦點解決短期治療、合作取向）強調社會建構、去專家化與多元觀點，治療師對個案故事的內容與發展保持好奇、抱持「不知道」（not-knowing）的姿態、心中不預設定見，讓意義由對話共構，故 (D) 最正確。其餘為較傳統或現代主義取向的特徵：(A) 創造矯正性情緒經驗（corrective emotional experience）是精神分析／心理動力取向的概念；(B) 諮商前先形成個案概念化（case conceptualization）反映實證、診斷導向的現代主義立場，與後現代「不預設」的精神相左；(C) 由治療師主導提出「有效能的介入策略」，預設治療師為專家，亦不符後現代去中心、共構的態度，故皆不選。

第 37 題

焦點解決短期治療中，當個案對諮商心理師提出奇蹟問句（miracle question）的回答是：「我不會再這樣焦慮啊，就像一般正常人。」下列何者是諮商心理師接下來會引導的問句？①你不再這樣焦慮，那麼取而代之的會是什麼樣子呢？②當你就像是你所說的「一般正常人」時，你會去做什麼呢？③你的好友可能會跟你說，要如何做到像個「一般正常人」呢？④可否多說一些你的「焦慮」是如何讓你覺得自己不像個「一般正常人」？
  1. （A）僅①②
  2. （B）僅②③
  3. （C）①②③
  4. （D）①③④

答案：（A）

詳解與考點

考點為焦點解決短期治療奇蹟問句後的延續引導。①請個案描述「取而代之」的正向圖像、②探問成為「正常人」時會去做什麼，均屬聚焦於目標與例外、引導建構解決圖像，故選①②（答案 A）。③訴諸好友建議偏離個案主體、④回頭聚焦「焦慮如何讓你不正常」屬問題導向，與 SFBT 精神相違。

第 38 題

榮格對於曼陀羅繪畫治療的觀點，下列敘述何者錯誤？
  1. （A）創作過程能催化個案的情緒令其穩定
  2. （B）曼陀羅象徵自我的核心，亦稱本我（self），中心點則是自己（ego）的人格中心
  3. （C）強調個案內在世界與外在環境的平衡以及對話
  4. （D）創作歷程即是個案個體化歷程的展現

答案：（C）

詳解與考點

本題為「何者錯誤」，官方答案為 (C)。(C) 把榮格（Jung）的概念張冠李戴：榮格理論中「self（自性）」才是人格的核心與整體中心，象徵整合的目標；而「ego（自我）」是意識的中心，並非整體人格的核心。曼陀羅（mandala）象徵的是自性（Self），其中心點代表自性而非「ego」，且 (C) 又把 self 譯為「本我」、把 ego 稱為「人格中心」，概念與術語對應錯誤，故為正解。其餘為榮格對曼陀羅繪畫的正確觀點：(A) 正確，曼陀羅創作具安定、催化情緒並使之穩定的作用；(C) 以外的 (B) 正確，曼陀羅反映內在世界與外在環境的平衡與對話；(D) 正確，創作歷程即個體化（individuation）歷程的展現。

第 39 題

關於Jones（1996）戲劇治療九個核心過程，下列敘述何者錯誤？
  1. （A）不同層面的自我投射到角色與戲劇內容
  2. （B）觀眾與演出者間的互動與見證，可以達到高峰經驗
  3. （C）藉由擬人化與模仿，可將治療中待處理的議題展現出來
  4. （D）參與者會在演出過程避免角色錯亂，減少演員、導演或觀眾多重角色的交換

答案：（D）

詳解與考點

本題為「何者錯誤」，官方答案為 (D)。Jones（1996）戲劇治療的核心過程強調角色的流動與多重身分的交換，參與者可在演員、導演、觀眾等不同角色間轉換，藉此獲得距離化（distancing）與多元視角；治療正是運用這種角色交換與彈性，而非「避免角色錯亂、減少角色交換」，故 (D) 敘述錯誤、為正解。其餘為正確描述：(A) 正確，不同層面的自我可投射到角色與戲劇內容中（投射 projection）；(B) 正確，觀眾與演出者間的互動與見證（witnessing）可帶來深刻體驗甚至高峰經驗；(C) 正確，藉由擬人化（personification）與模仿（impersonation）可將待處理議題具象展現。

第 40 題

兒童中心遊戲治療（CCPT）的治療歷程有四個階段，下列順序何者正確？
  1. （A）準備、攻擊、退化、熟練
  2. （B）準備、退化、攻擊、熟練
  3. （C）準備、攻擊、熟練、退化
  4. （D）退化、攻擊、準備、熟練

答案：（A）

詳解與考點

兒童中心遊戲治療（CCPT）治療歷程依序為：準備（建立安全關係）→攻擊（宣洩敵意與負向情緒）→退化（出現依賴、倒退行為）→熟練（情緒整合、發展掌控感），故選（A）；其餘選項順序錯置。階段名稱與分期請對照教材查證。
