第 1 題

有關諮商心理師被諮商的經驗，下列敘述何者錯誤？
  1. （A）基於倫理考量，並不強制將被諮商的經驗納入訓練課程
  2. （B）有被諮商的經驗，主要在強調其自我覺察的重要性
  3. （C）在正式從事諮商之前，務必接受個別諮商
  4. （D）被諮商的經驗有助於諮商心理師了解諮商歷程

答案：（C）

詳解與考點

考點為諮商師個人受諮商經驗的訓練意義。題問「錯誤」，正解 C：「正式從事前務必接受個別諮商」過於絕對，受諮商經驗被鼓勵但非強制硬性要求。B、D 正確指出其有助自我覺察與理解歷程；A 也指基於倫理不強制納入課程。陷阱是把「鼓勵」誤讀成「強制」。

第 2 題

下列那個諮商理論取向最強調諮商關係的重要性？
  1. （A）古典精神分析治療
  2. （B）個人中心治療
  3. （C）認知行為治療
  4. （D）現實治療

答案：（B）

詳解與考點

考點為各學派對治療關係的重視程度。正解 B 個人中心治療：Rogers 視真誠、無條件積極關注、同理三大核心條件為改變的充要條件，最強調關係本身即療效。陷阱是古典精神分析（強調詮釋與移情分析）或 CBT（強調技術），關係雖重要但非核心定位。

第 3 題

諮商歷程中，若諮商心理師經驗到難以克服的價值衝突，下列處理方式何者最不適切？
  1. （A）審慎評估將手中的個案轉介給他人處理
  2. （B）若諮商心理師的價值觀與諮商目標相符，則仍應堅持
  3. （C）諮商心理師可考慮採取一種所謂「暫置括弧（bracketing）」的處置態度
  4. （D）尋求專業督導的協助，以有效處理這些差異

答案：（B）

詳解與考點

考點為價值衝突的倫理處理。題問「最不適切」，正解 B：「價值觀與諮商目標相符就應堅持」會把諮商師價值強加於個案，違反價值中立。A 評估轉介、C 暫置括弧（懸置自身價值）、D 尋求督導皆為適切作法。陷阱是誤以為價值一致就可主導個案方向。

第 4 題

下列那一項榮格（Jung）學派的諮商技術是一種將意識中心的「自我」與「集體潛意識」連結的方法？
  1. （A）字詞聯想
  2. （B）主動想像
  3. （C）自由聯想
  4. （D）創造意象

答案：（B）

詳解與考點

考點為榮格學派技術。正解 B 主動想像（active imagination）：刻意進入半清醒狀態，讓意識的自我與集體潛意識的意象對話、連結，是榮格獨有技術。陷阱是 C 自由聯想（屬佛洛伊德）與 A 字詞聯想（榮格用於情結偵測，非連結意識與集體潛意識）。

第 5 題

依據寇哈特（Heinz Kohut）的觀點，所謂「雙極的自體（bipolar self）」是由何者所組成？
  1. （A）真我（true self）與假我（false self）
  2. （B）貧弱自體（depleted self）與全能自體（omnipotent self）
  3. （C）理想化自體（idealized self）與現實自體（actual self）
  4. （D）自大自體（grandious self）與理想的父母形象（idealized parental image）

答案：（D）

詳解與考點

考點為寇哈特自體心理學的「雙極自體」。正解 D：雙極自體由「自大自體（誇大展現極）」與「理想化父母形象（理想化極）」兩極構成。陷阱是 A 真我假我（Winnicott）。把握度 med，因人名概念較冷僻，但 D 為自體心理學標準定義。

第 6 題

下列何者是精神分析／心理分析在初期晤談（initial set of interviews）時的原則？
  1. （A）運用並列出治療大綱
  2. （B）避免訂定分析合約
  3. （C）進行完整且正式的歷史訪談
  4. （D）個案憑直覺決定討論主題之優先次序

答案：（D）

詳解與考點

考點為精神分析初期晤談原則。正解 D：分析強調讓個案憑自由聯想、依直覺決定討論主題的優先次序，治療師不主導大綱。陷阱是 A 列治療大綱、C 完整正式的歷史訪談，這些屬結構式取向而非古典精神分析的初期作法。把握度 med。

第 7 題

阿德勒學派主要透過何種技術幫助個案達到自我了解和領悟？
  1. （A）詮釋（interpretation）
  2. （B）動機式晤談（motivational interviewing）
  3. （C）對話練習（dialogue exercise）
  4. （D）自由聯想（free association）

答案：（A）

詳解與考點

考點為阿德勒學派達到領悟的技術。正解 A 詮釋（interpretation）：阿德勒透過對生活型態、私人邏輯、早期回憶的詮釋，幫助個案自我了解與領悟。陷阱是 D 自由聯想（佛洛伊德）、B 動機式晤談（Miller & Rollnick）、C 對話練習（完形空椅）皆非阿德勒核心。

第 8 題

關於阿德勒取向與心理分析治療的差異，下列何者錯誤？
  1. （A）阿德勒取向更強調個人抉擇與責任
  2. （B）阿德勒取向揚棄心理分析所採用詮釋分析方法
  3. （C）阿德勒取向相信人可以經由社會學習而有所改變
  4. （D）阿德勒取向更強調人的功能與正向層面

答案：（B）

詳解與考點

考點為阿德勒取向與精神分析的差異。題問「錯誤」，正解 B：阿德勒並未「揚棄詮釋分析方法」，他同樣大量使用詮釋（如早期回憶、生活型態詮釋）。A、C、D 正確指出阿德勒更重抉擇責任、社會學習與正向功能。陷阱是把兩派差異過度誇大成完全不用詮釋。

第 9 題

對於阿德勒學派的描述，下列何者正確？①治療過程可謂是一個合作冒險之旅②當代阿德勒理論為一種結合認知建構論、存在論、系統論及心理動力論的統整取向③視個案為障礙症患者，並積極培養其勇氣與自信④治療過程在幫助個案覺察自己的生活型態，以帶動感覺與行為上的改變
  1. （A）僅①③
  2. （B）僅②④
  3. （C）僅①②④
  4. （D）①②③④

答案：（C）

詳解與考點

考點為阿德勒學派特徵。正解 C（①②④）：①合作冒險之旅、②結合認知建構、存在、系統、心理動力的統整取向、④覺察生活型態以帶動改變，皆正確。③錯在「視個案為障礙症患者」，阿德勒採成長／非病理觀，視個案為氣餒而非有病。陷阱即③的病理化敘述。

第 10 題

下列何者是存在主義治療的主要代表人物？
  1. （A）Friedrich Nietzsche
  2. （B）Fritz Perls
  3. （C）Rollo May
  4. （D）Leslie Greenberg

答案：（C）

詳解與考點

考點為存在主義治療代表人物。正解 C Rollo May（與 Yalom、Frankl 並列存在治療代表）。陷阱是 A Nietzsche 為存在哲學先驅但非治療家、B Perls 為完形、D Greenberg 為情緒焦點治療創始者。把握度 high。

第 11 題

存在主義治療對於自由與責任的觀點，下列敘述何者錯誤？
  1. （A）個案雖然有選擇的自由但仍無法決定自己的命運
  2. （B）人們渴望自由，卻常常自我設限，逃避自由
  3. （C）存在的罪惡感就是覺察到自己在逃避承諾
  4. （D）在幫助個案檢視其選擇時需考量文化因素

答案：（A）

詳解與考點

考點為存在主義的自由與責任觀。題問「錯誤」，正解 A：存在主義主張人即使受限，仍能透過選擇與態度「形塑自己的命運」，並非「無法決定命運」。B、C、D 正確描述逃避自由、存在罪惡感與文化考量。陷阱是把存在主義誤讀成宿命論。

第 12 題

關於存在主義治療的敘述，下列何者錯誤？
  1. （A）傾向於描述、理解、探索個案的主觀世界
  2. （B）對於個人的創造性開放是存在主義治療的基本概念
  3. （C）在過程中個案和諮商心理師都願意去碰觸他們的生命，兩人都會有所改變
  4. （D）非常重視診斷的類別及特定的困擾行為

答案：（D）

詳解與考點

考點為存在主義治療特性。題問「錯誤」，正解 D：存在主義「非常重視診斷類別與特定困擾行為」與事實相反，它反對病理分類、重視主觀經驗與存在處境。A、B、C 正確描述探索主觀世界、開放於創造性、雙方都改變。陷阱是把它誤當成診斷導向。

第 13 題

一位研究生抱怨指導教授沒有好好指導他，下列何者是個人中心取向諮商心理師會採取的作法？
  1. （A）你認為指導教授沒盡全力指導你，似乎你對自己能否獨自完成研究感到不確定
  2. （B）不少學生會有類似的抱怨，但有時候指導教授會希望學生能主動學習，為自己的學習負責任
  3. （C）你怎麼會有這種感覺呢？指導教授做了什麼讓你有這種想法？
  4. （D）當你現在跟我說這件事的時候，你心裡的想法是什麼？

答案：（A）

詳解與考點

考點為個人中心取向的反映回應。正解 A：反映個案的感受與背後對自我能力的不確定，是同理性的情感反映。陷阱是 B（給建議與說教）、C（質問「你怎麼會」帶評價）皆偏離反映；D 雖開放但 A 更貼近 Rogers 式的同理反映。

第 14 題

關於情緒焦點治療（emotion-focused therapy）的敘述，下列何者正確？
  1. （A）起源於存在主義治療，並結合認知行為治療的技術發展而成
  2. （B）治療目標在引導個案體驗情緒，理解情緒的起因，修正其非理性信念
  3. （C）諮商心理師擔任專家，設計並指導個案投入情緒歷程的實驗
  4. （D）諮商心理師以個人中心取向的核心治療條件建立治療關係

答案：（D）

詳解與考點

考點為情緒焦點治療（EFT, Greenberg）。正解 D：EFT 以個人中心的核心治療條件建立關係，再引導情緒處理。陷阱是 B（修正非理性信念是 REBT）、C（諮商師當專家設計實驗較像行為／完形），A 把 EFT 起源誤描述。把握度 med。

第 15 題

關於Carl Rogers的治療觀點，下列敘述何者錯誤？
  1. （A）在治療過程中，治療者是啟動個案成長的主要角色
  2. （B）強調治療關係中治療者的態度
  3. （C）治療過程中，個案的改變在於治療者與個案是同在的
  4. （D）個案具有足夠資源做正向改變

答案：（A）

詳解與考點

考點為 Rogers 個人中心觀點。題問「錯誤」，正解 A：Rogers 認為「個案自己」才是成長的主要角色，治療師只是提供促進成長的關係條件，並非「啟動成長的主要角色」。B、C、D 正確強調治療師態度、同在與個案自我資源。陷阱是把治療師誤定位成主導者。

第 16 題

關於完形治療的改變與成長依序會經歷的五個層次，下列敘述何者正確？
  1. （A）僵局→恐懼→虛假→內爆→外爆
  2. （B）虛假→恐懼→僵局→外爆→內爆
  3. （C）恐懼→僵局→虛假→外爆→內爆
  4. （D）虛假→恐懼→僵局→內爆→外爆

答案：（D）

詳解與考點

考點為完形治療人格成長五層次。正解 D：虛假→恐懼（恐懼症）→僵局→內爆→外爆，由表層虛偽逐步突破到能量向外釋放。陷阱是各選項把層次順序打亂，尤其誤把「內爆」與「外爆」前後對調或將僵局放在最前。把握度 med，需記憶順序。

第 17 題

下列何者為完形治療學派欲協助個案達到的基本目標？
  1. （A）由環境支持進而能夠自我支持
  2. （B）尋找潛意識中的改變動力
  3. （C）挑戰個人的生活哲學
  4. （D）使潛意識能夠意識化

答案：（A）

詳解與考點

考點為完形治療的基本目標。正解 A：協助個案由依賴環境支持轉為「自我支持」（self-support）、達到成熟與覺察。陷阱是 B、D 講潛意識動力與意識化（屬精神分析語言）、C 挑戰生活哲學（較像存在／理情），皆非完形核心目標。

第 18 題

個案說：「爸爸難以控制的脾氣，讓我至今見到權威就畏縮不已。」下列何者最不可能是現實治療諮商心理師的反應？①著力於個案的家庭成長經驗②瞭解權威畏縮對個案現在的影響③拒絕與個案談論過去的經驗④協助個案訂定計畫面對權威
  1. （A）①②
  2. （B）①③
  3. （C）②③
  4. （D）②④

答案：（B）

詳解與考點

考點為現實治療的時間焦點。題問「最不可能」，正解 B（①③）：現實治療聚焦現在與行為計畫，①著力於家庭成長經驗（過去）、③拒絕談論過去皆不符——它不深究過去，但也不會「拒絕」談。②看過去對現在影響、④訂計畫面對權威才是現實治療作法。

第 19 題

下列那位學者將現實治療擴展實施於多元文化情境中？
  1. （A）Robert Wubbolding
  2. （B）Allen Ivey
  3. （C）William Glasser
  4. （D）Gerald Corey

答案：（A）

詳解與考點

考點為現實治療的多元文化擴展者。正解 A Robert Wubbolding：他發展 WDEP 系統並將現實治療推廣至多元文化情境。陷阱是 C Glasser（現實治療創始者）、D Corey（教科書作者）、B Ivey（微諮商技巧）。把握度 med，屬人名辨識題。

第 20 題

下列何者最符合現實治療取向諮商心理師所採取的態度？
  1. （A）完全接納個案做不到的部分
  2. （B）維持客觀中立，避免反移情
  3. （C）堅定支持而不放棄
  4. （D）批判個案失敗的藉口

答案：（C）

詳解與考點

考點為現實治療諮商師態度。正解 C「堅定支持而不放棄」：現實治療師不接受藉口、堅持要個案為行為負責，同時保持關懷不放棄。陷阱是 A 完全接納做不到（縱容藉口）、D 批判失敗（過度嚴厲）、B 客觀中立避免反移情（屬精神分析語言）皆不符。

第 21 題

有關眼動去敏感重組法（EMDR）的描述，下列何者錯誤？
  1. （A）當前的心理問題來自過去經驗不當地儲存在大腦記憶中
  2. （B）最初是為創傷後壓力症候群（PTSD）所設計
  3. （C）諮商心理師若未受過認證指導員的訓練，切勿使用此技術
  4. （D）尚未發展適合兒童的技術

答案：（D）

詳解與考點

考點為眼動減敏與歷程更新（EMDR, Shapiro）。題問「錯誤」，正解 D：EMDR「尚未發展適合兒童的技術」與事實不符，已有兒童適用的改良作法。A、B、C 正確描述記憶儲存不當、最初為 PTSD 設計、須受認證訓練才可施作。陷阱是誤以為 EMDR 不能用於兒童。

第 22 題

關於行為治療的特色，下列敘述何者錯誤？
  1. （A）關注個人的信念系統
  2. （B）基於科學方法的原理與程序
  3. （C）教育及行動取向
  4. （D）為個案量身訂做治療技術

答案：（A）

詳解與考點

考點為行為治療特色。題問「錯誤」，正解 A：「關注個人的信念系統」屬認知治療而非傳統行為治療，行為治療聚焦可觀察行為與環境後果。B、C、D 正確描述科學方法、教育行動取向、量身訂做技術。陷阱是把認知元素混入純行為取向。

第 23 題

諮商心理師協助怕髒而經常洗手的個案，在進行焦慮情境的功能分析、建立焦慮狀態階層表之前，必須先做什麼，才能開始進行系統減敏感法？
  1. （A）教導個案放鬆技術
  2. （B）諮商心理師示範焦慮時能忍耐不逃避
  3. （C）找到適合練習的實際情境
  4. （D）進行個案的自我指導訓練

答案：（A）

詳解與考點

本題問進行系統減敏感法（systematic desensitization）前必須先做什麼，官方答案為 (A)。系統減敏感法以交互抑制（reciprocal inhibition）為原理，須讓個案在面對焦慮階層時能以放鬆狀態與焦慮相抗衡，因此「教導個案放鬆技術」（如漸進式肌肉放鬆）是整個程序的首要基礎步驟。題幹特別點出此步驟在「焦慮情境功能分析、建立焦慮狀態階層表之前」，這正符合系統減敏感的標準流程：先習得放鬆 → 建立焦慮階層 → 想像或實境逐級配對放鬆進行減敏，故 (A) 正確。其餘皆非系統減敏的前置必要步驟：(B) 治療師示範忍耐不逃避偏向示範學習／暴露法；(C) 找實際練習情境屬實境減敏的後續安排；(D) 自我指導訓練（self-instructional training）是 Meichenbaum 的認知行為技術，並非系統減敏的前置作業，故皆不選。

第 24 題

有關認知行為治療的理論，下列何者錯誤？
  1. （A）Padesky和Mooney的優勢基礎認知行為治療，認為合作的治療關係最重要，不強調生活阻礙的內容，也不重視該如何處理
  2. （B）Meichenbaum的認知行為矯治法之特徵是在改變個案的自我對話
  3. （C）Ellis的理性情緒行為治療法，認為困擾人們的是對事情僵化且極端的想法，而非事情本身
  4. （D）Beck的認知治療認為人們陷入困境的主因是因為使用不實際的規則來標籤、解釋與評估事件

答案：（A）

詳解與考點

考點為各 CBT 取向辨識。題問「錯誤」，正解 A：Padesky 與 Mooney 的優勢／韌性取向 CBT 重視合作關係沒錯，但「不強調生活阻礙、不重視如何處理」描述錯誤，它仍協助處理阻礙。B（Meichenbaum 自我對話）、C（Ellis 僵化想法）、D（Beck 不實際規則）皆正確。

第 25 題

運用辯證行為治療學派（Dialectical Behavior Therapy, DBT）協助藥酒癮患者，下列敘述何者錯誤？
  1. （A）初期目標會訂在幫助個案了解酒精和藥物的副作用，分析戒斷後生活型態的優缺點
  2. （B）場面構成後，會尊重個案的出席意願，不強調承諾
  3. （C）進行並維持戒癮行為的改變，與個案討論如何處理各種情況
  4. （D）建立正向的生活型態，透過家庭作業逐步養成好的生活模式

答案：（B）

詳解與考點

考點為辯證行為治療（DBT）於成癮處遇。題問「錯誤」，正解 B：DBT 高度「強調承諾」（commitment），會運用承諾策略而非「不強調承諾」。A、C、D 正確描述初期分析利弊、維持戒癮改變、以家庭作業建立正向生活型態。陷阱是把 DBT 誤當不重承諾。

第 26 題

下列那位家族治療師最常使用「回饋小組」技巧？
  1. （A）Tom Andersen
  2. （B）Michael White
  3. （C）Virginia Satir
  4. （D）Carl Whitaker

答案：（A）

詳解與考點

考點為家族治療師與其代表技術。正解 A Tom Andersen：他創用「反映團隊／回饋小組（reflecting team）」技巧。陷阱是 B White（敘事治療、外化）、C Satir（溝通／雕塑）、D Whitaker（象徵經驗治療）。把握度 med，屬人名配技術。

第 27 題

面對拒學的女兒，母親在家庭會談中說：「我真不知道她在想什麼，我已經很努力在幫她了，她還是不肯去上學，我實在不知道該怎麼辦？」下列諮商心理師的回應，何者最符合家庭系統取向中的「重新框架」？
  1. （A）聽起來，媽媽真的感到很挫折
  2. （B）聽起來，媽媽雖然對女兒又生氣又失望，但也還是有些期待
  3. （C）當媽媽這樣說時，女兒你的感受是什麼？
  4. （D）媽媽有沒有想過，怎麼樣解決這樣的狀況？

答案：（B）

詳解與考點

考點為家庭系統取向的「重新框架」（reframing）。正解 B：把母親的「生氣失望」重新詮釋為「仍帶有期待」，賦予行為新的正向意義，正是重新框架。陷阱是 A（單純情感反映）、C（轉問女兒）、D（問解決方法）皆未改變對行為的詮釋角度。

第 28 題

關於家族治療中代罪羔羊的敘述，下列何者正確？①代罪的家庭成員經常是被動參與代罪過程②代罪的家庭成員經常帶有症狀③代罪的家庭成員可能固著於指派的角色與任務④常有轉移父母衝突的效果
  1. （A）僅①③
  2. （B）僅①②④
  3. （C）僅②③④
  4. （D）①②③④

答案：（C）

詳解與考點

考點為家族治療「代罪羔羊」概念。正解 C（②③④）：代罪成員常帶症狀、可能固著於被指派角色、且具轉移父母衝突的功能。①「經常被動參與」錯誤，代罪過程是家庭互動共同形塑，成員也可能主動扮演此角色。陷阱即①的被動化敘述。

第 30 題

下列人本取向家庭溝通模式的那一個角色具有固執立場、不與他人親密、總是冷靜及避免情緒化的特質？
  1. （A）指責者（blamer）
  2. （B）討好者（placeater）
  3. （C）打岔者（irrelevant）
  4. （D）超理智者（super-reasonable）

答案：（D）

詳解與考點

考點為 Satir 人本溝通（求生存）姿態。正解 D 超理智者（super-reasonable）：固守立場、不與人親密、冷靜避免情緒化，只講道理。陷阱是 A 指責者（攻擊他人）、B 討好者（迎合）、C 打岔者（轉移焦點），各自情緒姿態不同。把握度 high。

第 31 題

個案的丈夫常在酒後對個案暴力相向，諮商過程中個案決定嘗試向丈夫表達感受，並探討法律、金錢、生理及心理等自我保護層面之行動，這是運用下列何種女性主義諮商技術？
  1. （A）性別角色分析
  2. （B）重新詮釋
  3. （C）文化干預
  4. （D）權力分析

答案：（D）

詳解與考點

考點為女性主義諮商技術。正解 D 權力分析（power analysis）：協助個案看見關係中的權力不平等，並透過法律、金錢、生理、心理等行動爭取自我保護與賦權。陷阱是 A 性別角色分析（檢視性別社會化訊息）、B 重新詮釋、C 文化干預，焦點不在權力結構行動。

第 32 題

關於女性主義的治療關係，下列敘述何者錯誤？
  1. （A）僅適用於對女性個案的治療
  2. （B）治療關係是以平等與賦權為基礎
  3. （C）強調個案在治療關係中扮演主動參與的角色
  4. （D）偏好使用性別角色分析瞭解個案的困擾

第 33 題

關於敘事治療中諮商心理師的角色和功能，下列敘述何者錯誤？
  1. （A）常運用提問技術
  2. （B）是積極的催化員
  3. （C）接受個案的故事引導
  4. （D）重視對個案經驗的解釋

答案：（D）

詳解與考點

考點為敘事治療諮商師的角色。題問「錯誤」，正解 D：敘事治療採後現代立場，不視諮商師為「解釋個案經驗」的權威，意義由個案主導建構，諮商師抱持「不知」（not-knowing）態度。A、B、C 正確：常提問、是催化者、接受個案故事引導。

第 34 題

關於焦點解決短期治療秉持的專業價值，下列敘述何者正確？①重視能夠提升個案自我決定與賦能感②幫助身心障礙者與其痛苦或失能共處③要與個案建立為他（for him）或對他（to him）工作的合作關係
  1. （A）僅①②
  2. （B）僅②③
  3. （C）僅①③
  4. （D）①②③

答案：（A）

詳解與考點

考點為焦點解決短期治療（SFBT）的專業價值。正解 A（僅①②）：①提升自我決定與賦能、②協助與痛苦／失能共處皆符合 SFBT。③錯在「為他（for）／對他（to）工作」，SFBT 強調的是「與個案（with）」合作。陷阱即③的介系詞配對錯誤。

第 35 題

關於焦點解決短期治療的敘述，下列何者錯誤？
  1. （A）該治療不談過去，只重視現在和未來
  2. （B）要解決問題不需要知道問題發生的原因
  3. （C）雖非病理取向，但仍然需探究問題歷史的癥結
  4. （D）著重營造可能改變的正向期待

答案：（C）

詳解與考點

考點為焦點解決短期治療特性。題問「錯誤」，正解 C：SFBT 非病理取向，「仍需探究問題歷史癥結」與其精神相違——它不深究問題成因與歷史。A、B、D 正確：重現在未來、解決不需知成因、營造正向改變期待。陷阱是把成因分析混入 SFBT。

第 36 題

下列何者是森田療法所使用的諮商技術？
  1. （A）重新建構
  2. （B）思考中斷
  3. （C）臥床休息
  4. （D）積極想像

答案：（C）

詳解與考點

考點為森田療法技術。正解 C 臥床休息（絕對臥褥期）：森田療法首階段讓個案絕對臥床、隔離，再逐步進入作業期。陷阱是 A 重新建構、B 思考中斷（行為／認知技術）、D 積極想像（榮格），皆非森田療法所用。把握度 med，屬冷僻學派。

第 37 題

個案無法解決其問題時，下列那些是焦點解決短期治療會採取的介入？①請個案做些不一樣的事情②協助個案找到問題的例外情形③諮商心理師將自己擁有的資源提供給個案④請個案多做一些有效的事情
  1. （A）①②③
  2. （B）①③④
  3. （C）②③④
  4. （D）①②④

答案：（D）

詳解與考點

考點為焦點解決短期治療的介入。正解 D（①②④）：①做些不一樣的事、②找問題例外、④多做有效的事，皆為 SFBT 標準介入。③「諮商師將自己的資源提供給個案」錯誤，SFBT 重視發掘個案既有資源與優勢，而非由諮商師給予。陷阱即③。

第 38 題

關於諮商心理師具備多元文化諮商能力的敘述，下列何者錯誤？
  1. （A）與不同文化背景的個案工作時，需使用特定的技術
  2. （B）修正原有的介入方式，不強迫個案配合某一諮商取向
  3. （C）應尋找與個案生活經驗及文化價值觀相融合的諮商目標
  4. （D）碰到與自己不同文化背景的個案，應優先考慮轉介

答案：（D）

詳解與考點

考點為多元文化諮商能力。題問「錯誤」，正解 D：「碰到不同文化背景就優先轉介」並非適切，多元文化能力要求諮商師調整自身以服務多元個案，而非規避。A、B、C 正確：因人調整技術、修正介入、尋找契合文化的目標。陷阱是把轉介當成標準作法。

第 39 題

關於正念減壓療法，下列敘述何者錯誤？
  1. （A）強調禪坐靜修、身體掃描與明心瑜珈三個技巧
  2. （B）Kabat-Zinn指出心律脈動的控制，為進行正念技巧過程重要的角色
  3. （C）所持有的態度應是不批判、有耐心、信任、接納、放下等
  4. （D）所應覺察的領域包含身體和感官、心和感受情緒、心智和思考想法以及主宰生命之原理原則

答案：（B）

詳解與考點

考點為正念減壓療法（MBSR, Kabat-Zinn）。題問「錯誤」，正解 B：Kabat-Zinn 強調的是「不批判的覺察」而非「心律脈動的控制」，控制心律並非正念核心。A（禪坐、身體掃描、瑜珈）、C（七種態度）、D（覺察領域）皆正確。陷阱是把生理回饋式控制誤植入正念。

第 40 題

以繪畫和視覺創作為主的藝術治療，下列描述何者正確？
  1. （A）主要是運用視覺刺激來達到治療效果，缺乏對個案生理功能的助益
  2. （B）藝術即治療取向，強調是透過語言的方式來詮釋與理解創作圖像
  3. （C）運用潛意識的投射技巧，將內在思想與感受向外呈現出來
  4. （D）應避免同時連結過去、現在與未來不同時空關係之事件，以免個案混亂

答案：（C）

詳解與考點

考點為藝術治療取向。正解 C：藝術治療運用潛意識投射，把內在思想與感受外化呈現。陷阱是 A（說缺乏生理助益，過於武斷）、B（藝術即治療反而強調創作歷程本身，非靠語言詮釋）、D（連結過去現在未來正是其價值，不應避免）皆錯。
