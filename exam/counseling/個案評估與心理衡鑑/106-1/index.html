第 1 題

下列那一類評量工具不是為了求取受試者的「典型表現」（typical performance）？
  1. （A）性向測驗
  2. （B）興趣測驗
  3. （C）態度測驗
  4. （D）適應測驗

答案：（A）

詳解與考點

正解：「不是典型表現」——典型表現測量平常的偏好、態度或調適，不以答對多少為目標；判準是工具測量的是能力上限還是慣常樣貌。性向測驗旨在估計受試者的潛在能力或學習能力，屬最大表現而非典型表現，故選 A。

B：興趣測驗了解受試者偏好的活動或職業領域，測量典型表現。

C：態度測驗測量對人事物相對穩定的評價傾向，屬典型表現。

D：適應測驗了解日常生活與人際、情緒等調適情況，亦屬典型表現。

本題考點：典型表現（typical performance）——測量平常的偏好、態度與適應；最大表現（maximum performance）——測量能力或可達成的表現，如性向測驗。

第 2 題

下列何者不屬常態化標準分數？
  1. （A）標準九（stanine）
  2. （B）T 量表分數（T-scaled score）
  3. （C）C 量表分數（C-scaled score）
  4. （D）百分等級（percentile rank）

答案：（D）

詳解與考點

正解：「不屬常態化標準分數」——判準是分數是否依常態分配轉換並使用等距量尺。標準九、T 量表分數及 C 量表分數皆為常態化標準分數；百分等級只表示相對位置，百分等級間的距離不等，故選 D。

A：標準九將常態分配切為九個區段，是常態化標準分數。

B：T 量表分數是以常態分配轉換的標準分數，故非答案。

C：C 量表分數同屬常態化量尺，故非答案。

本題考點：常態化標準分數（normalized standard score）——依常態分配轉換並具有等距解讀；百分等級（percentile rank）——表示相對名次，非等距量尺。

第 3 題

在進行個案初次晤談（intake）時，下列評估向度何者的重要性相對最低？
  1. （A）評估個案問題的嚴重或危機程度
  2. （B）評估個案需要的協助方式或資源
  3. （C）評估個案對諮商機構的了解程度
  4. （D）評估個案的求助需求或期待

答案：（C）

詳解與考點

正解：「初次晤談」與「重要性相對最低」——初談優先建立對主訴、需求與風險的基本理解，判準是資訊是否直接關係危機處遇與服務規劃。個案對諮商機構的了解程度可在說明服務與知後同意時補充，但相較於危機、需求與期待，通常不是最先要釐清的評估向度，故選 C。

A：嚴重度與危機程度直接影響是否需立即危機處遇或轉介，優先性高。

B：所需協助方式與可用資源影響後續服務規劃，重要性高。

D：求助需求與期待可協助界定主訴、建立合作目標，初談中應予評估。

本題考點：初次晤談（intake）——優先掌握危機程度、主訴與求助期待；危機評估（risk assessment）——直接影響立即處遇與轉介決策。

第 4 題

在諮商過程中為了解個案，下列有關評量之敘述何者較不妥適？
  1. （A）僅利用學業成績推斷個案智力
  2. （B）使用個人日記了解問題發生的情境
  3. （C）利用平衡單了解個案對不同方案的嚮往程度
  4. （D）使用症狀檢核表評量個案問題類型與嚴重程度

答案：（A）

詳解與考點

正解：智力是一個涵蓋抽象思考、推理、問題解決等多重能力的建構，需要透過標準化智力測驗（如魏氏智力量表）才能適切評估。學業成績雖然與智力有一定相關，但同時受到學習動機、努力程度、家庭資源、教學品質、情緒狀態等許多非智力因素影響，僅憑學業成績推斷個案智力，效度不足、容易產生誤判，屬於評量上的不妥適作法，故選 A。

B：個人日記屬於個案自然情境下的第一手書寫紀錄，能呈現問題發生的脈絡、當下的想法與情緒，是質性資料蒐集的合適管道，用來瞭解問題發生情境並無不妥。

C：平衡單（decisional balance sheet）列出不同方案的利弊得失，讓個案逐一評估每個選項的吸引力與代價，是生涯與決策諮商中常用且合適的工具，用以瞭解個案對不同方案的嚮往程度並無不妥。

D：症狀檢核表以條列方式蒐集個案自陳的症狀出現與否及嚴重程度，是快速篩檢問題類型與嚴重度的標準化工具，使用上並無不妥。

本題考點：心理衡鑑工具的適切性（assessment validity）——不同評量方法各有適用範圍，需依評量目的選用效度足夠的工具；智力評估的多元方法——標準化測驗與間接推論（如學業成績）效度不同。

第 5 題

以魏氏智力測驗為例，當發現個案上個月進行過同項測驗時，衡鑑者的後續選擇不包括下列那一項？
  1. （A）繼續進行同項測驗，並整合兩次測驗成果進入評估報告中
  2. （B）終止施測，考慮以其他智力測驗替代
  3. （C）終止施測，試著取得上次於他機構之衡鑑結果，以其他智力測驗取代，並將此次結果合併上次測驗結果
  4. （D）終止施測，試著取得上次於他機構之衡鑑結果，改以行為觀察與會談方式，並將此次結果合併上次的 測驗結果

答案：（A）

詳解與考點

正解：「上個月進行過同項測驗」——短期重複施測會產生練習效應，判準是此次分數是否仍能有效代表受試者能力。仍繼續同項測驗並把兩次結果直接整合，無法排除熟悉題型與記憶造成的分數提升，因此不屬適切的後續選擇，故選 A。

B：終止同項施測並考慮其他智力測驗，可降低練習效應，故非答案。

C：取得前次衡鑑結果、改用其他工具並整合可比較的資料，有助於完整解讀，故非答案。

D：若不宜立即改用另一項智力測驗，取得既有結果並補以行為觀察和會談，可增加衡鑑的多元證據，故非答案。

本題考點：練習效應（practice effect）——短期重測可能因熟悉測驗而影響分數；心理衡鑑（psychological assessment）——應整合測驗、會談與行為觀察等多元資料。

第 6 題

以五點量表評定受試者的行為特質，下列何者為此種評量方式？
  1. （A）評定量表
  2. （B）檢核表
  3. （C）軼事紀錄
  4. （D）Q 技術

答案：（A）

詳解與考點

正解：「五點量表評定行為特質」——判準是評量者是否依程度等級判斷特質。評定量表以數個等級讓評量者標示行為或特質的程度，五點量表正是其典型形式，故選 A。

B：檢核表通常只勾選行為是否出現，未必呈現程度差異。

C：軼事紀錄是對具體事件的敘事性觀察紀錄，非固定等級評分。

D：Q 技術要求受試者或評量者依相對排序配置陳述卡片，並非單純五點程度量表。

本題考點：評定量表（rating scale）——以等級評定特質或行為程度；檢核表（checklist）——記錄行為有無出現。

第 8 題

有些人格測驗，測驗的結果是採取自比性分數（ipsative score），所謂自比性分數是採取下列那一種解釋 測驗結果的方式？
  1. （A）不同人之間在各測驗項目結果的比較
  2. （B）個人測驗項目與他人測驗項目的比較
  3. （C）不同團體間相同測驗項目測驗結果的比較
  4. （D）自己與自己在各測驗項目間測驗結果的比較

答案：（D）

詳解與考點

正解：自比性分數（ipsative score）是一種以個人自身作為比較基準的計分方式，測驗結果呈現的是受試者「自己在各個測驗項目（分量表）之間」的相對高低排序，例如某人在量表中「支配性」得分是否高於自己在「順從性」上的得分，而不涉及與其他人或常模團體的比較，故選D。

A：不同人之間在各測驗項目結果的比較，是屬於常模參照（norm-referenced）或組間比較的計分邏輯，重點在跨個體的比較，與自比性分數「僅比較個人內部項目高低」的性質相反。

B：個人測驗項目與他人測驗項目的比較，同樣涉及跨個體的比較架構，並非自比性分數所強調的「個人內部各項目互相比較」，用詞看似接近但比較對象錯置。

C：不同團體間相同測驗項目測驗結果的比較，屬於團體層次的常模比較，關注的是團體與團體之間在同一測驗項目上的差異，與自比性分數聚焦個人內部相對高低的邏輯無關。

本題考點：自比性分數（ipsative score）——以受試者個人內部各項目相對高低作為解釋依據，區別於常模參照（normative）計分方式；人格測驗計分方式的區辨（ipsative vs. normative scoring）。

第 9 題

某國中校長很關心該校園的霸凌問題，請輔導處幫忙，先粗略找到可能的受害學生與加害學生，並預期 受害學生可能會有情緒上的困擾，而加害學生可能有違規行為。下列測量工具何者最適合？
  1. （A）貝克兒童及青少年量表（BYI-II）
  2. （B）貝克憂鬱量表（BDI-II）
  3. （C）貝克焦慮量表（BAI）
  4. （D）人際行為量表（IBS）

答案：（A）

詳解與考點

正解：要「粗略找到」霸凌受害與加害學生，且分別預期情緒困擾與違規行為；判準是工具須同時涵蓋兒童青少年的情緒與行為面向。（A）BYI-II 包含憂鬱、焦慮、憤怒、行為外顯與自我概念等分量表，最符合初篩目的，故選 A。

B：BDI-II聚焦憂鬱單一向度，無法涵蓋加害學生可能的違規行為。

C：BAI只測量焦慮，涵蓋面同樣不足。

D：IBS主要評估自我肯定與人際因應風格，不是情緒困擾與違規行為的多向度篩檢工具。

本題考點：心理衡鑑工具選用——判準是先依篩檢目的與受試年齡選擇涵蓋所需構念的工具；BYI-II——可同時檢視兒童青少年的多種情緒與行為面向。

第 10 題

對於測驗工具的選用，下列何者不是諮商師可以控制的考量因素？
  1. （A）使用測驗的目的
  2. （B）受測者受測動機
  3. （C）選用測驗的品質
  4. （D）施測的成本與時間

答案：（B）

詳解與考點

正解：「諮商師可以控制的考量因素」——判準是該因素由專業人員在選用與施測規劃中決定，還是來自受測者當下狀態。受測者的受測動機受其意願、情緒與情境影響，諮商師可以評估與促進，但無法直接控制，故選 B。

A：使用目的由諮商問題與衡鑑目標界定，是諮商師可掌握的選用考量。

C：測驗品質可透過查核信度、效度與適用性加以選擇，屬可控制的專業判斷。

D：成本與時間可在服務資源及施測安排中規劃，屬可控制因素。

本題考點：測驗選用（test selection）——須考量目的、品質與可行性；受測動機（test-taking motivation）——影響作答表現，但不能由衡鑑者直接控制。

第 11 題

當諮商心理師聽了個案的主訴後，先給個案填寫問題檢核表，來了解個案關注問題的種類與嚴重程度時， 這位心理師最可能在進行心理衡鑑中的那一項步驟？
  1. （A）讓個案接受問題所在
  2. （B）幫助個案界定與澄清主訴議題
  3. （C）與個案形成可解決問題的行動方案
  4. （D）評估諮商是否產生效果

答案：（B）

詳解與考點

正解：「先填寫問題檢核表」與「了解關注問題的種類與嚴重程度」——這是在把初步主訴轉化為可辨識的問題範圍，判準是衡鑑步驟尚未進入介入或成效檢核。問題檢核表有助於界定與澄清個案的主訴議題，故選 B。

A：讓個案接受問題所在較偏向介入中的覺察與動機工作，不是檢核表的首要衡鑑功能。

C：形成行動方案需先完成問題界定與目標協商，不能由此一步直接推出。

D：評估諮商效果是在介入後比較改變的歷程；本題尚在初步了解問題。

本題考點：主訴澄清（problem clarification）——以檢核表等工具界定問題種類與嚴重度；成效評估（outcome evaluation）——用於檢核介入後的改變。

第 12 題

Lazarus 的 BASIC-ID 是一以七大功能來解釋人格結構的多重模式，下列敘述何者錯誤？
  1. （A）不單只是個案評估模式，也是一治療模式，各層面間會互相影響
  2. （B）只檢視某一層面也是恰當的
  3. （C）是一整合性的行為治療取向
  4. （D）是一個多元的系統，重視治療的彈性與多樣性

答案：（B）

詳解與考點

正解：BASIC-ID是Lazarus多重模式治療的核心架構，涵蓋行為、情感、感覺、想像、認知、人際關係、藥物與生理七個層面，強調完整評估個案在各層面的功能，且各層面彼此會互相影響，唯有掌握全貌才能規劃出周延而有效的治療計畫。若只檢視某一層面，會忽略層面之間交互影響的訊息，無法呈現個案問題的完整樣貌，這樣的做法並不恰當，題幹問的是錯誤的敘述，故選B。

A：BASIC-ID確實不只是評估架構，Lazarus同時將其發展為治療取向的組織架構，各層面在評估與治療歷程中會相互牽動影響，這個敘述正確。

C：多重模式治療根植於行為治療，並整合認知與其他取向的技術，屬於一種整合性的行為治療取向，這個敘述正確。

D：BASIC-ID強調同時考量多個層面、彈性運用不同技術因應個案的不同需要，是一個講求多元與治療彈性的系統，這個敘述正確。

本題考點：多重模式治療（multimodal therapy）與BASIC-ID架構——以七大功能層面完整評估個案、規劃整合性治療計畫的模式；整合性評估（comprehensive assessment）——單一層面評估不足以反映個案問題全貌的原則。

第 13 題

某企業轉介一位員工到企業諮商中心進行心理評估，主管的看法是：「該員工曾經得過憂鬱症，個性內 向、人際關係不好，現在的單位功能調整，需要團體合作，他需不需要換單位？」下列那一項是諮商心 理師要最先進行的評估議題？
  1. （A）評估該員工是否要進行興趣評估與生涯規劃
  2. （B）評估該員工自己有沒有要換單位的意願
  3. （C）告知企業主管，應先評估該員工的績效與職能
  4. （D）評估該員工目前的心理狀況，提供企業做其工作調整的參考

答案：（D）

詳解與考點

正解：企業主管以既往憂鬱症與人際印象推問「需不需要換單位」——轉介目的雖涉及工作調整，首要判準仍是先以直接資料了解員工目前心理狀況與功能，而非接受主管的標籤式推論。評估當前心理狀況並提供工作調整參考，最能先建立與問題相關的專業依據，故選 D。

A：興趣與生涯規劃可能是後續議題，但不能取代對目前心理狀況與工作功能的初步衡鑑。

B：員工對換單位的意願涉及自主與合作，但先確認其目前狀況，才能將意願置於適當的評估脈絡。

C：績效與職能資料確有參考價值，卻是企業管理端資料；它看似最貼近調職決策，錯在未先處理轉介所指的心理狀況與支持需要。

本題考點：轉介衡鑑（referral assessment）——先釐清當前心理狀況、功能與轉介問題；工作調整（work accommodation）——應以相關專業資料為參考，避免以診斷標籤直接推論人事處置。

第 14 題

評估者如果只尋找和自己所喜歡之假設的證據，而忽略其他的證據，這可能會發生那一種評估上的偏誤？
  1. （A）迴歸效應（regression effect）
  2. （B）歸因誤差（attribution bias）
  3. （C）驗證性偏差（confirmatory bias）
  4. （D）文化偏差（cultural bias）

答案：（C）

詳解與考點

正解：驗證性偏差（confirmatory bias，即確認偏誤）指評估者一旦形成某個假設或先入為主的判斷，之後蒐集與解讀資料時會傾向選擇支持該假設的證據，同時忽略或輕估與假設不符的訊息，導致評估結果失真。題幹描述評估者「只尋找和自己所喜歡之假設的證據，而忽略其他的證據」，正是這種選擇性蒐證、驗證自身假設的傾向，故選 C。

A：迴歸效應指極端分數在重複測量時有向平均數靠近的統計現象，屬測量重複施測時分數變化的統計性質，與評估者主觀偏好證據的蒐集方式無關。

B：歸因誤差指個人在解釋他人行為原因時，過度歸因於內在特質而低估情境因素（如基本歸因誤差），關注的是行為成因的解釋方向，而非蒐集證據時是否只挑支持自己看法的資料。

D：文化偏差指評估工具或評估者的判斷標準未能考量受評者的文化背景，以主流文化的常模或觀點來解讀不同文化個案的行為，導致評估失真，重點在文化脈絡的忽略，而非蒐證時選擇性偏好某個假設。

本題考點：驗證性偏差（confirmatory bias／確認偏誤）——只蒐集支持既有假設證據的評估偏誤；心理衡鑑常見偏誤類型的辨析（歸因誤差、文化偏差、迴歸效應）。

第 15 題

某位諮商心理師在評估個案的人格功能時，表示：「該個案自我控制較高，作事情非常有組織，且給予 自己高度的紀律要求」，則該心理師可能正在推論那一個性格向度？
  1. （A）神經質
  2. （B）外向性
  3. （C）開放性
  4. （D）嚴謹性

答案：（D）

詳解與考點

正解：Big Five 人格模型中的嚴謹性（conscientiousness）向度，核心內涵包括自我控制、做事有條理有組織、對自己要求高度紀律與責任感，題幹描述的「自我控制較高、做事非常有組織、給予自己高度紀律要求」正是嚴謹性向度的典型行為指標，故選 D。

A：神經質（neuroticism）反映的是情緒不穩定、焦慮、易受負向情緒困擾的傾向，與題幹描述的自律、組織性無關。

B：外向性（extraversion）指向社交活躍、熱情、尋求刺激等人際互動面向的特質，題幹並未提及社交或情緒表達層面，不符合外向性的描述。

C：開放性（openness to experience）強調對新經驗、想像力、審美與求知慾的開放程度，與題幹所描述的紀律、組織性屬於不同向度。

本題考點：Big Five 人格五因素模型（Five-Factor Model）——嚴謹性（conscientiousness）向度以自我控制、組織性與紀律為核心特徵。

第 16 題

在衡鑑過程中，心理師可能會問個案：「你的姓名？所處何處？某件事情發生於何時？」這最可能是在 評估個案的那一種能力？
  1. （A）依賴性
  2. （B）判斷力
  3. （C）專注力
  4. （D）定向感

答案：（D）

詳解與考點

正解：詢問「姓名、所處何處、事情發生於何時」——這三類問題分別核對人物、地點與時間，是精神狀態檢查中定向感（orientation）的核心面向。能正確辨認自己、當前所在環境及時間脈絡，表示定向感尚可；混淆其中任一面向則可能提示意識、認知或精神狀態的改變，故選 D。

A：依賴性是人格與人際功能中過度需要他人支持、難以自行作決定的傾向，不能由姓名、地點與時間的回答判定。

B：判斷力看的是個案能否衡量後果並作出合宜決定，例如遭遇危險時如何處理；本題不是要求他提出決策。

C：專注力評估的是持續將注意放在作業上的能力，常可透過倒數、心算或持續操作觀察；定向問題雖需要注意，但題組的固定判準仍是人物、地點、時間。

本題考點：定向感（orientation）——判準是人物、地點、時間與情境的正確辨識；專注力（attention）——看注意能否持續與轉換；判斷力（judgment）——看能否依後果作合宜決定。

第 17 題

諮商心理師需要具備的個案評估能力，下列敘述何者最正確？
  1. （A）諮商心理師不做心理疾病的診斷，可以不熟悉精神疾病診斷準則手冊 DSM-5 的內容
  2. （B）在個案的評估方面，諮商心理師需要做的是會談評估
  3. （C）諮商心理師需要視轉介問題的種類決定需要應用那些評量方式或工具資料
  4. （D）個案評估資料的解釋，諮商心理師一定要標準化依據指導手冊進行說明

答案：（C）

詳解與考點

正解：諮商心理師在進行個案評估時，應依個案的轉介問題性質決定應採用晤談、心理測驗、行為觀察或其他評量方式與工具，評估策略須因應問題的類型與評估目的彈性調整，而非固定套用單一方式，這是評估能力中最核心且正確的原則，故選C。

A：諮商心理師雖不具醫療診斷權限，但熟悉DSM-5的診斷準則有助於理解個案的臨床表現、與精神醫療系統溝通轉介，並非「可以不熟悉」，敘述將專業要求限縮過窄，並不恰當。

B：會談評估固然是個案評估的重要方法之一，但將評估方式限定為「需要做的是會談評估」，忽略了心理測驗、行為觀察等其他評估工具依轉介問題彈性搭配使用的必要性，敘述過於絕對而不完整。

D：心理測驗結果的解釋固然應參考指導手冊的常模與程序，但同時也需要納入臨床判斷、個案背景脈絡等因素綜合說明，「一定要」完全依循手冊而排除臨床判斷的敘述過於絕對，並不恰當。

本題考點：個案評估方法的選擇（assessment method selection）——依轉介問題與評估目的彈性搭配晤談、測驗與觀察等工具；心理衡鑑資料解釋（test interpretation）——結合常模參照與臨床判斷，而非僅機械套用手冊。

第 18 題

在心理衡鑑中評估個案接受心理治療的準備程度，若個案已經進入能夠覺察自己的問題，但尚未許下改 變的承諾，依據 Prochasks 等人對改變的觀點，這可能顯示個案在心理治療的準備度處於那一個階段？
  1. （A）前深思熟慮期
  2. （B）深思熟慮期
  3. （C）準備期
  4. （D）行動期

答案：（B）

詳解與考點

正解：「已經覺察自己的問題，但尚未許下改變的承諾」——依 Prochaska 等人的跨理論改變模式，能意識到問題並開始權衡改變利弊、卻尚未承諾行動，正是深思熟慮期（contemplation）的特徵，故選 B。

A：前深思熟慮期（precontemplation）通常尚未將行為視為問題，或未考慮改變，與題幹已能覺察問題不合。

C：準備期（preparation）已從思考走向承諾，通常開始規劃近期的具體改變；本題明說尚未許下承諾，正卡在此門檻之前。這是最強誘答——兩期都可能談到改變，但分界在是否已形成行動承諾與計畫。

D：行動期（action）是已實際採取可觀察的改變行為，不是僅覺察問題或思量利弊。

本題考點：跨理論改變模式（Transtheoretical Model）——前深思熟慮期尚未認知問題，深思熟慮期開始考慮，準備期形成承諾與計畫，行動期已實際改變。

第 19 題

某高二生會花很多時間寫信給政府機關的首長，批判他認為不公不義的事；他知道這已經造成生活上的 困擾，但不寫信又會不舒服。家長帶他到精神科，他接受醫師的診斷，但他覺得藥物或心理治療都沒有 幫助，不願意接受治療。該生病識感較接近下列何者？
  1. （A）良好病識感（good insight）
  2. （B）情緒性病識感（emotional insight）
  3. （C）理智性病識感（intellectual insight）
  4. （D）低病識感（poor insight）

答案：（C）

詳解與考點

正解：病識感依程度可分為缺乏病識感、理智性病識感與情緒性（真實）病識感等層次。理智性病識感指當事人在認知上承認自己有症狀、也接受醫師所下的診斷，但這份「知道」並未真正轉化為配合治療的動機，仍然認為藥物或心理治療對自己沒有幫助而拒絕接受協助，行為模式（強迫式寫信）依舊持續。題幹中的高二生正是這種狀態：他承認診斷、也知道行為造成困擾，卻不認同治療的必要性而拒絕介入，符合理智性病識感的定義，故選 C。

A：良好病識感是指當事人不僅承認自己有病，也能理解症狀與治療的關聯，並願意配合治療、努力改變，題幹中該生明確拒絕接受治療，並不符合良好病識感。

B：情緒性病識感強調當事人不只認知上理解，更在情感層面真正接納自己生病的事實，並因此產生尋求協助、改變行為的動力；題幹中該生僅止於接受診斷這個事實，並未因此在情感或行動上轉向配合治療，尚未到達情緒性病識感的程度。

D：低病識感是指當事人根本不認為自己有病，會否認症狀或診斷本身；但題幹明確指出該生「接受醫師的診斷」，顯示他並非否認生病的事實，因此不屬於低病識感。

本題考點：病識感（insight）分級——理智性病識感與情緒性病識感、良好病識感、低病識感的區別，聚焦「認知上承認」與「行動上配合治療」是否一致。

第 20 題

心理師依據 Lazarus（1973）所發展的 BASIC-ID 的模式進行衡鑑時，不會包含下列那一項？
  1. （A）行為
  2. （B）意象
  3. （C）藥物
  4. （D）文化

答案：（D）

詳解與考點

正解：題幹的關鍵條件，須依其所觸發的理論判準作答。 Lazarus 所發展的 BASIC-ID 模式是多重模式治療（multimodal therapy）的衡鑑架構，七個字母分別代表 Behavior（行為）、Affect（情感）、Sensation（感覺）、Imagery（意象）、Cognition（認知）、Interpersonal relationships（人際關係）與 Drugs/biology（藥物／生理），文化並不是這七個模式向度之一，故答案為 D。

A：行為（Behavior）是 BASIC-ID 的第一個向度，關注個案外顯可觀察的具體行為表現，屬於此模式的內容。

B：意象（Imagery）是 BASIC-ID 的向度之一，關注個案內在的心像、幻想與自我形象等，屬於此模式的內容。

C：藥物（Drugs，對應 D=Drugs/biology）是 BASIC-ID 的向度之一，關注個案的生理狀態與用藥情形等生物層面因素，屬於此模式的內容。

本題考點：Lazarus 多重模式治療（multimodal therapy）BASIC-ID 衡鑑架構——涵蓋行為、情感、感覺、意象、認知、人際關係、藥物／生理七個評估向度。

第 21 題

國二的吳生被導師轉介到輔導室，比較恰當而避免責難批評的初談（intake）評估問法為：
  1. （A）你知道是發生什麼事導師要你來輔導室嗎？
  2. （B）你知道今天為什麼要來輔導室？
  3. （C）你知道為什麼導師要你來輔導室嗎？
  4. （D）導師為什麼轉介你到輔導室？

答案：（A）

詳解與考點

正解：「國二生」「導師轉介」與「避免責難批評的初談問法」——初談宜用中性、開放且不預設學生有過錯的語句，讓學生能先說出自己理解的情況。（A）詢問他知道發生什麼事而被轉介，焦點放在事件脈絡，不把「來輔導室」本身說成應受責備的結果，故選 A。

B：「今天為什麼要來輔導室」雖看似一般詢問，卻容易使轉介被學生解讀為自己做錯事後被帶來處理，較少觸及事件與關係脈絡。

C：把問題直接綁定為「為什麼導師要你來」，容易讓學生感到被導師指控或需為轉介辯解，責難意味較重。

D：直接追問導師的轉介理由，要求學生替導師說明動機，較像究責；（A）同樣談轉介卻先邀請學生描述發生的事，是最容易混淆之處，差別在於是否預設誰必須為轉介負責。

本題考點：初談（intake）——以中性、開放問題建立工作關係；非責難式提問（nonjudgmental questioning）——先探索事件脈絡與學生觀點，不預設過錯或動機。

第 22 題

在 MMPI 測量工具中的效度量尺，主要為了能區分個案是否用一種不合現實的正向態度來描述自己的傾 向，此一量尺為下列那一個？
  1. （A）說謊量尺（L）
  2. （B）裝病量尺（FBS）
  3. （C）反應不一致量尺（VRIN）
  4. （D）罕見－病態量尺（Fp）

答案：（A）

詳解與考點

正解：「不合現實的正向態度來描述自己」——MMPI 的說謊量尺（L）用以偵測把自己過度美化、否認一般人也可能有的小缺點的防衛性作答型態，故選 A。

B：裝病量尺（FBS）關切的是以不尋常方式呈現身心症狀、可能涉及症狀誇大的反應型態，不是把人格描述得不合現實地完美。

C：反應不一致量尺（VRIN）檢查內容相近或相反題目的回答是否前後矛盾，判斷的是作答一致性而非正向自我呈現。

D：罕見－病態量尺（Fp）著重極少見的病理症狀陳述；它與 B 都可能涉及不尋常症狀，但 L 的判準是「美化自己」，方向恰好不同。

第 23 題

某位大學生填寫貝克憂鬱量表（BDI-II）後，獲得總量表分數為 50 分，該生的憂鬱程度，依據手冊最可 能是？
  1. （A）極輕微憂鬱
  2. （B）輕微憂鬱
  3. （C）中度憂鬱
  4. （D）嚴重憂鬱

答案：（D）

詳解與考點

正解：「BDI-II 總量表分數 50 分」——本題須依題幹所稱手冊的分級判讀；50 分已落在嚴重憂鬱的區間，故選 D。量表分數反映自陳症狀嚴重度，仍須與晤談、功能受損及風險資訊整合為心理衡鑑判斷。

A：極輕微憂鬱對應的是量表低分範圍，與 50 分的高總分不符。

B：輕微憂鬱雖表示已有症狀，但其分數帶低於嚴重程度，不能用來判讀本題的 50 分。

C：中度憂鬱是介於輕微與嚴重之間的分級；最強誘答在於把高分只概括為「中度」，但依本題指定手冊的切分，50 分已越過嚴重門檻。

第 24 題

某國中輔導教師正為學生進行高中職不同學群選擇的適性輔導工作，挑選此類測驗工具在概念上特別需 要注重那種效度？
  1. （A）同時效度
  2. （B）內容效度
  3. （C）預測效度
  4. （D）建構效度

答案：（C）

詳解與考點

正解：「高中職不同學群選擇」——測驗結果要用來推估學生未來在不同教育或職業路徑的適配與表現，最需關切測驗對未來外在結果的預測效度（predictive validity），故選 C。

A：同時效度（concurrent validity）看測驗分數與同一時點既有標準的關聯，較適用於檢驗目前狀態的判別，不是重點放在未來選群結果。

B：內容效度（content validity）檢查題目是否充分涵蓋欲測內容範圍，例如課業測驗是否涵蓋教學目標，不能直接證明其可預測未來適配。

D：建構效度（construct validity）驗證測驗是否真的測到理論建構，如興趣或性向；它是重要基礎，但本題已指定「選擇」所指向的未來結果，預測效度更直接。

本題考點：預測效度（predictive validity）——看測驗能否預測未來標準；同時效度（concurrent validity）——看與當前標準的關聯；建構效度（construct validity）——看是否測得理論建構。

第 25 題

下列有關評定量表的描述，何者錯誤？
  1. （A）經由評定量表取得的均是客觀化資料
  2. （B）評定量表包含他人評量與環境評量
  3. （C）月暈效應（halo effect）是評定量表常見缺失
  4. （D）籃內技術（in-basket technique）是評定量表的一種技術

答案：（A）

詳解與考點

正解：「何者錯誤」與「評定量表」——評定量表的分數由評定者依觀察與判斷給出，難免受到評定者知覺、期待與偏誤影響，不能說取得的「均是客觀化資料」。A 忽略此主觀判斷成分，故為應選項。

B：評定量表可由他人對個案的行為或特質評量，也可納入對環境條件的系統化評估，敘述正確，故非答案。

C：月暈效應（halo effect）是評定者以某一突出印象推及其他面向的常見偏誤，例如因一項優點而全面給高評分，敘述正確，故非答案。

D：籃內技術（in-basket technique）讓受評者處理模擬工作文件或情境；其作答表現可由評定者依行為向度與量尺評分，依本題分類可列為評定量表技術，故非答案。

本題考點：評定量表（rating scale）——資料經由評定者判斷，不等同完全客觀；月暈效應（halo effect）——單一整體印象污染多項評分；籃內技術（in-basket technique）——以模擬工作情境評量表現。

第 26 題

當個案有精神疾病病史，評估後需要進行轉介至其他的醫療機構，此時在檔案資料中需要注意的倫理議 題不包括下列那一個？
  1. （A）個案的個人基本資料需要在個人資料保護法的保護下使用
  2. （B）需要告知個案轉介的目的與內容後方得以轉介
  3. （C）與轉介單位清楚說明轉介目的與考量
  4. （D）向個案說明未來治療單位的治療目的和方式

答案：（D）

詳解與考點

正解：「轉介至其他醫療機構」與「檔案資料中需要注意的倫理議題不包括」——轉介前應處理個人資料保護、知後同意及必要資訊的適當傳遞；至於未來治療單位實際採取何種治療目的與方式，應由該單位在建立服務關係時向個案說明，並非原轉介檔案處理的必要事項，故選 D。

B：告知轉介目的與內容，讓個案理解並同意資訊如何流動，是知後同意與尊重自主的重要實踐，故非答案。

C：向轉介單位清楚說明轉介目的與專業考量，有助其理解接案需求與安排服務；重點是限於必要且經同意的資訊，故非答案。

本題考點：轉介（referral）——須釐清目的、必要資訊與服務銜接；知後同意（informed consent）——個案應理解並同意資訊的使用與傳遞；最小必要原則（minimum necessary principle）——僅提供完成轉介所需資料。

第 27 題

下列何者不屬於行為的功能衡鑑（functional assessment）之評估要項？
  1. （A）行為與情境之交互作用
  2. （B）確認目標行為
  3. （C）個案的優勢與劣勢
  4. （D）預後的分析

答案：（D）

詳解與考點

正解：「行為的功能衡鑑」與「不屬於」——功能衡鑑旨在找出目標行為在何種前因、情境與後果中被引發或維持，以形成可介入的功能假設；預後分析是推估未來結果，並非其基本評估要項，D 故為應選項。

A：行為與情境的交互作用可辨識觸發條件、情境線索與維持因素，是功能衡鑑的重要內容，故非答案。

B：確認目標行為才能界定要觀察、記錄與改變的是什麼，故非答案。

C：個案的優勢與劣勢會影響可用資源、因應能力及介入設計，屬整體功能衡鑑可納入的脈絡資料，故非答案。

本題考點：功能衡鑑（functional assessment）——界定目標行為，分析前因、行為、後果與情境功能；預後（prognosis）——推估未來發展，不等於找出行為功能。

第 28 題

有關認知行為衡鑑的資訊，下列何者描述錯誤？
  1. （A）和行為衡鑑不同，認知行為衡鑑重視的是從自我所引發的內在觀點
  2. （B）以認知行為觀點進行衡鑑，其缺點是可能限制了資料的來源
  3. （C）讓評估者得以使用自陳式量表的方式合併觀察來進行會談
  4. （D）以認知行為客觀科學的態度，可以避免泛文化的偏誤

答案：（D）

詳解與考點

正解：「認知行為衡鑑」與「避免泛文化的偏誤」——認知行為取向雖強調以可檢驗的假設、觀察與自陳資料理解個案的想法與行為，但方法本身不會自動消除文化偏誤；評估者仍須檢視量表、概念與詮釋是否適合個案文化脈絡。D 把客觀科學態度誤當成文化中立保證，故為應選項。

A：認知行為衡鑑重視個案對事件的自動想法、信念與主觀意義，較能處理由自我引發的內在觀點，敘述正確，故非答案。

B：若過度侷限於既定認知行為架構或自陳工具，可能縮窄可蒐集的資料來源，這是實務上須警覺的限制，故非答案。

C：自陳式量表可與會談、行為觀察等資料交叉檢核，正是認知行為衡鑑可採的多元蒐證方式，故非答案。

本題考點：認知行為衡鑑（cognitive-behavioral assessment）——整合想法、情緒、行為與情境資料；文化偏誤（cultural bias）——任何測量與詮釋都須檢視其文化適切性；多元方法評估（multimethod assessment）——以量表、會談與觀察交叉檢核。

第 29 題

對於智力商數（ratio intelligence quotient，IQ）的敘述，下列何者的說法較為適切？
  1. （A）任何一個智力商數的解釋都應該參考其他個人相關的資料
  2. （B）智商是固定的、天生的、不會改變的
  3. （C）智力商數是用來評估個人興趣的指標
  4. （D）用比率智商來表示老年人的智力，比使用離差智商表示來得恰當

答案：（A）

詳解與考點

正解：A。任何一個智力測驗分數，都只是在特定情境、特定常模下取得的估計值，會受到受試者當時的身心狀態、文化背景、施測情境、動機等因素影響，因此任何一個智力商數的解釋，都應該參照當事人其他相關的個人資料（如生活史、學業表現、臨床觀察等），才能做出適切而完整的解讀，這是心理測驗解釋的基本原則，故選 A。

B：智力商數並非固定不變的天生特質，個體的智力表現會隨著發展、教育、環境刺激等因素而有所變化，把 IQ 視為終身固定不變，忽略了智力發展的可塑性。

C：智力商數評估的是認知能力（如推理、記憶、語文與空間能力等），而非個人的興趣傾向；評估興趣通常使用職業興趣量表等工具，C 混淆了智力測驗與興趣測驗的用途。

D：比率智商（以心智年齡除以實足年齡計算）在成年後會因心智年齡趨於停滯而失去意義，對老年人的智力評估，一般改採以同齡常模比較個人相對位置的離差智商，較能反映真實的認知功能，D 的敘述方向與測驗學原理相反。

本題考點：智力商數的性質與解釋原則（interpretation of IQ scores）——測驗分數須結合其他個人資料綜合解讀；比率智商與離差智商（ratio IQ vs. deviation IQ）——離差智商較適用於成人與老年族群的智力比較。

  1. （A）①②
  2. （B）②③
  3. （C）③④
  4. （D）④⑤

正解：「WMS-III 中文版」與「工作記憶指數」——此題考特定版本的分測驗歸類，工作記憶指數由數－字序列測驗與空間記憶廣度測驗構成，即④⑤，故選 D。本題的分測驗編組應以 WMS-III 中文版手冊為準。

某創意廣告公司招聘創意設計人員，每位應聘人寄送 10 幅作品以進行匿名評審，並依成績高低擇優錄取。 請問此評審方式比較像下列那一種？

  1. （A）學習與讀書策略量表
  2. （B）學習適應量表
  3. （C）G567 學術性向測驗
  4. （D）多向度性向測驗組合（MDATB）

正解：題幹的重點是這名國小四年級學生各項表現中等、唯獨學業成績差，輔導教師想了解的是造成其學習低落的相關適應因素（如學習方法、學習態度、人際與家庭因素對學習的影響），而非測量其抽象能力或性向的高低。學習適應量表正是為國小、國中學生設計，用以評估其在學習方法、學習習慣、學習環境與人際適應等面向上是否存在困難，適合用來診斷表現正常卻學業低落背後的適應性因素，故選B。

  2. （B）直接詢問一個人他最喜歡和不喜歡的人、事、物為何
  3. （C）從行為上觀察一個人經常接觸的人、事、物為何

第 34 題

下列何者較不是職業興趣組合卡的功能？
  1. （A）提供一種結構化的生涯晤談技術
  2. （B）提供豐富的觀察資訊
  3. （C）提供明確職業選擇的方向
  4. （D）反映出個案內在的衝突

答案：（C）

詳解與考點

正解：職業興趣組合卡（occupational card sort）是一種質性生涯評量工具，讓個案透過分類卡片上的職業名稱（喜歡／不喜歡／不確定），呈現出結構化的晤談歷程，諮商師可從個案分類與說明理由的過程中，蒐集豐富的觀察資訊，並藉此反映出個案在生涯選擇上尚未覺察的內在衝突或矛盾。然而組合卡是一種探索、澄清取向的質性工具，並不像量化的職業興趣量表那樣，能提供明確、具體的職業選擇方向或排序建議，此並非其設計目的，故選C（此為它「較不是」的功能）。

A：組合卡透過分類卡片、詢問分類理由的固定流程，本質上就是一種結構化的生涯晤談技術，讓晤談有章法可循，這確實是它的功能。

B：組合卡的價值主要來自諮商師在旁觀察個案分類行為、猶豫與理由陳述的歷程，能蒐集到量化測驗無法呈現的豐富質性資訊，這確實是它的功能。

D：個案在分類卡片時，常會出現分類矛盾、猶豫不決或情緒反應，這些現象有助於揭露個案內在尚未整合的衝突或價值拉扯，這確實是它的功能。

本題考點：職業興趣組合卡（occupational card sort）——質性生涯評量工具的功能與限制；質性與量化生涯衡鑑工具在「提供明確方向」上的差異。

第 35 題

價值澄清練習（values clarification exercises）常用於生涯輔導中，下列有關價值澄清練習之陳述，何者錯 誤？
  1. （A）價值澄清練習無法展現質性評量的優點
  2. （B）典型的價值澄清練習包括價值觀拍賣、引導式幻想
  3. （C）個案較易在價值澄清練習中進行深層的自我探索
  4. （D）在價值澄清練習時，個案可以更主動、積極地探索與表達個人價值觀

答案：（A）

詳解與考點

正解：價值澄清練習（values clarification exercises）本身就是質性評量取向的典型代表，強調個案主動參與、開放式表達與個別化的探索歷程，能呈現量化測驗難以捕捉的個人意義與價值脈絡，正是質性評量重視脈絡、彈性與當事人主體性的優點之展現。題幹敘述「無法展現質性評量的優點」與事實相反，故為錯誤敘述，答案為 A。

B：價值觀拍賣（values auction）與引導式幻想（guided fantasy）確實是生涯輔導中常見的價值澄清練習形式，透過具體活動引導個案排序或想像未來，藉以釐清內在價值優先順序，敘述正確。

C：由於練習形式開放、貼近個人經驗，個案在參與過程中較容易觸及深層的自我覺察與探索，這也是質性評量法優於制式量表之處，敘述正確。

D：價值澄清練習仰賴個案親自參與活動、主動思考與口語表達，個案在歷程中扮演主動角色，能積極探索並說出個人價值觀，敘述正確。

本題考點：價值澄清練習（values clarification exercises）——生涯輔導中的質性評量技術；質性評量（qualitative assessment）——強調脈絡、個別化與當事人主動參與的評量取向。

第 36 題

面對重大災變倖存者時，蒐集與澄清相關資訊是危機處遇很重要的一環，但諮商心理師應避免與倖存者 討論下列那一類資訊？
  1. （A）重要他人死亡後的哀悼歷程
  2. （B）對災變引起的創傷感受作深入描述
  3. （C）既有的生理和心理疾患
  4. （D）災變引起的罪惡感

答案：（B）

詳解與考點

正解：「重大災變倖存者」「危機處遇」與「避免」——危機初期蒐集資訊的目標是安全、基本需求、支持系統與當前功能，避免強迫或過早要求倖存者對創傷感受作深入描述，以免增加失控感或痛苦；B 故為應選項。

A：重要他人死亡後的哀悼歷程有助了解失落、支持資源與當前需求，可依個案可承受程度關懷，故非答案。

C：既有生理和心理疾患會影響危機風險、轉介與處遇安排，是必要的背景資訊，故非答案。

D：災變引起的罪惡感可能伴隨自責與風險，適切而不逼迫地澄清有助危機評估，故非答案。

本題考點：危機處遇（crisis intervention）——優先安全、穩定與當前資源；創傷知情處遇（trauma-informed care）——避免強迫深入重述創傷；哀傷評估（grief assessment）——依個案承受度理解失落與支持。

第 37 題

關於心理衡鑑報告的撰寫原則，下列何者正確？
  1. （A）衡鑑報告的撰寫風格，具有一定的格式，應以專業術語和科學的方式呈現
  2. （B）衡鑑報告最好儘量完整，最好能記錄下整個衡鑑晤談對話
  3. （C）衡鑑報告主要以心理疾患的觀察與判斷為主，人際行為或背景史是為了判斷該疾患的嚴重程度
  4. （D）衡鑑報告應避免只根據某項原始資料就寫出判斷結果

答案：（D）

詳解與考點

正解：「衡鑑報告撰寫原則」——心理衡鑑結論必須由多項資料彼此印證，包括晤談、觀察、測驗結果與背景脈絡，避免只憑單一原始資料作出判斷，D 正確，故選 D。

A：報告須專業、清楚且有組織，但應依讀者需要使用可理解的語言，不能把大量術語當成唯一適當的呈現方式。

B：完整不等於逐字記錄整段晤談對話；報告應擇取與衡鑑問題相關的資料並保護個案隱私。

C：衡鑑報告不應只以心理疾患為中心，人際行為、生活史、優勢與環境脈絡本身都是理解與處遇規劃的重要資料。

本題考點：心理衡鑑報告（psychological assessment report）——以問題導向、相關且可理解的方式整合資料；多元資料整合（data integration）——結論須由不同來源交叉支持；最小揭露原則（minimum disclosure）——僅記載完成專業目的所需資訊。

第 38 題

有關歷程紀錄（progress notes），下列何者較不是問題取向為主的記錄方法？
  1. （A）主觀、客觀資料、評估與處遇計畫紀錄（SOAP notes）
  2. （B）個案與情境的描述、評估、反應與處遇紀錄（DART notes）
  3. （C）個案與情境的描述、臨床的印象、反應與處遇紀錄（DIRT notes）
  4. （D）時間順序紀錄（Time-Sequenced notes）

答案：（D）

詳解與考點

正解：「較不是問題取向」——問題取向紀錄會將資料、評估、反應與處遇計畫依問題加以組織；時間順序紀錄（Time-Sequenced notes）主要按事件發生先後編排，未必以問題架構統整，故選 D。

A：SOAP notes 依主觀資料、客觀資料、評估與計畫組織，是典型的問題取向紀錄，故非答案。

B：DART notes 將描述、評估、反應與處遇連結到所處理的問題，仍具有問題取向的結構，故非答案。

C：DIRT notes 雖採不同欄位名稱，仍把描述、臨床印象、反應與處遇串連於臨床問題，故非答案。

本題考點：問題取向紀錄（problem-oriented record）——以臨床問題組織資料、評估與計畫；SOAP notes——主觀、客觀、評估、計畫；時間順序紀錄（time-sequenced notes）——以事件先後而非問題分類。

第 39 題

對於測驗與衡鑑所引發的標籤化效應，心理師應對個案所處脈絡有所反思，下列論述何者較不恰當？
  1. （A）當透過衡鑑形成診斷，診斷有可能會形成標籤與自我實現預言，必須思考其傷害性
  2. （B）以醫學模式來界定個案的生病角色，可協助其更為自己負責且對自身脈絡有更清楚的認識
  3. （C）個案可能會將自己看成是「心理健康『助人者』權力結構下的一個無助而被動的受害者」
  4. （D）標籤化可能是一種社會烙印，可能會限制了成長與創意，以致於侷限了個人或系統的發展

答案：（B）

詳解與考點

正解：「標籤化效應」與「較不恰當」——醫學模式若將人固定為「生病角色」，可能弱化其主體性、忽略社會文化脈絡，並加深標籤化；它不必然使個案更能負責或更清楚認識自身處境。B 的正向推論不恰當，故為應選項。

A：診斷可能帶來標籤與自我實現預言，心理師應衡量其效益與可能傷害，敘述恰當，故非答案。

C：個案可能在心理健康專業的權力結構中感到無助與被動，這正是反思衡鑑權力關係的觀點，敘述恰當，故非答案。

D：社會烙印可能限制個人或系統的成長、創意與發展，符合對標籤化後果的批判，敘述恰當，故非答案。

本題考點：標籤化（labeling）——診斷分類可能影響自我概念與社會互動；自我實現預言（self-fulfilling prophecy）——他人期待可能反過來影響行為；醫學模式（medical model）——須與個案的社會文化脈絡及主體性一併反思。

第 40 題

關於測驗安全性的維護與測驗資料的揭露，下列描述何者錯誤？
  1. （A）測驗工具必須妥善保管，若隨處可得的話，就會失去測驗的信度
  2. （B）測驗結果的安全性也要維護，需嚴謹考慮倫理與相關法律責任
  3. （C）維護測驗的安全性不只是一種倫理上的義務，也是與測驗購買有關的責任
  4. （D）任何一個有版權的測驗都不可以複印

答案：（A）

詳解與考點

正解：A。測驗安全性一旦喪失，題目與作答方式廣為流傳，應試者可能事先取得題目內容或作答技巧而準備，這會讓測驗分數不再真實反映其欲測量的心理特質，破壞的是測驗的效度（validity，測驗是否真正測到想測的東西），而不是信度（reliability，測驗結果的穩定一致性）。信度與題目是否外流並無直接關聯，即使題目公開，只要施測程序一致，測驗仍可能維持一定的內部一致性或重測穩定性，因此「隨處可得就會失去信度」的說法把效度問題誤植為信度問題，是錯誤敘述，故選 A。

B：測驗結果內容涉及當事人隱私與衡鑑資料，其保存與揭露確實需嚴謹考量專業倫理規範與相關法律責任（如個資保護），敘述正確。

C：測驗安全性的維護不只是倫理義務，出版社在授權購買測驗時通常也附有保密與限制流通的合約責任，違反可能涉及違約與版權責任，敘述正確。

D：具版權的測驗工具受著作權保護，未經授權複印屬侵權行為，「任何有版權的測驗都不可以複印」在原則上正確描述了測驗使用者應遵守的規範。

本題考點：測驗安全性與測驗效度（test security and validity）——題目外流影響的是效度而非信度；測驗使用之專業倫理與著作權責任。
