第 1 題

下列何者不是心理衡鑑時需要特別考量的「心理計量」因素？
  1. （A）評分者間信度
  2. （B）蒐集個案資料範圍與內容的一致性
  3. （C）衡鑑工具對個案的適用性
  4. （D）衡鑑工具對個案問題的鑑別力

答案：（B）

詳解與考點

考點為心理衡鑑的心理計量（psychometric）特性。評分者間信度、工具對個案的適用性、對問題的鑑別力都屬心理計量範疇。B「蒐集資料範圍與內容的一致性」屬衡鑑流程/實施層面，非心理計量指標，故為不是者。

第 2 題

關於心理衡鑑歷程的敘述，下列何者正確？
  1. （A）各步驟間通常要儘可能的相互獨立
  2. （B）資料整合是在最後一個步驟進行
  3. （C）推論或假設通常是在衡鑑中期以後才會形成
  4. （D）第一階段通常是以搜集個案資料為主

答案：（D）

詳解與考點

考點為心理衡鑑歷程。D 正確：第一階段通常以蒐集個案資料為主。A 錯（各步驟相互關聯回饋而非力求獨立）、B 錯（資料整合貫穿全程而非僅最後一步）、C 錯（推論與假設在衡鑑早期即開始形成並持續修正），易誤選 A。

第 3 題

關於常模的敘述，下列何者錯誤？
  1. （A）受試者應達到之目標
  2. （B）常模團體之測驗表現
  3. （C）代表性樣本之典型表現
  4. （D）參照母群之常態表現

答案：（A）

詳解與考點

考點為常模（norm）定義。常模是常模團體或代表性樣本在測驗上的典型、常態表現，作為個人分數比較的參照，屬常模參照測驗概念。(A)「受試者應達到之目標」是標準參照測驗（criterion-referenced）的精熟標準，與常模意涵不符，故為錯誤敘述。陷阱在誤把常模當成及格門檻或目標值，混淆了「比較參照」與「精熟標準」兩種不同的測驗詮釋取向。

第 4 題

有關測驗分數應用與信度的關係之敘述，下列何者錯誤？
  1. （A）測驗分數若要具應用價值，則其信度係數至少需有0.70
  2. （B）臨床診斷用測驗的信度不宜太低
  3. （C）信度稍低之初步篩選用測驗仍具應用價值
  4. （D）測驗分數信度的高低會因測驗類型而異

答案：（A）

詳解與考點

考點為信度（reliability）與測驗應用價值的關係。通說：篩選用測驗信度可較低（約 0.70 左右仍可用），臨床診斷則需更高信度，信度也隨測驗類型而異。(A)稱「至少需 0.70」過於絕對，篩選用途即使略低於此仍具參考價值，故為錯誤。陷阱是把 0.70 視為硬性門檻，忽略了應用目的不同、可接受信度標準也不同的彈性原則。

第 5 題

將身心障礙者在測驗上的表現與具有同樣障礙者相互比較，這種常模屬於何種類型？
  1. （A）一般常模
  2. （B）特殊常模
  3. （C）全國常模
  4. （D）地區常模

答案：（B）

詳解與考點

考點為常模的分類。把身心障礙者與「同樣具該障礙者」相比，是針對特定次群體建立的參照基準，屬特殊常模（special norm）。(B)正確。陷阱為(A)一般常模，指以一般母群為比較對象；本題刻意限定同障礙群體，比較對象並非常態母群而是特定特殊族群，故選特殊常模而非一般、全國或地區常模。

第 6 題

在心理衡鑑中涉及心理師對個案問題看法準確性的概念效度（conceptual validity），下列何者正確？
  1. （A）關注測驗構念的實務檢核
  2. （B）在衡鑑初期即可以確定
  3. （C）主要以衡鑑方法為中心
  4. （D）主要以個案為中心

答案：（D）

詳解與考點

考點為概念效度（conceptual validity），指心理師對個案問題的理解與看法是否準確貼近個案。它以個案為中心（D正確），需隨衡鑑歷程逐步形成、不斷修正，非初期即能確定。陷阱為(C)以衡鑑方法為中心，方向相反；概念效度強調對「這位個案」理解的正確性，而非測驗工具的構念檢核，後者較屬一般效度概念。

第 7 題

下列分測驗何者可用來偵測個案的彈性思考能力？①矩陣推理②符號替代③圖形設計④圖畫補充
  1. （A）①②③
  2. （B）僅①②
  3. （C）僅①③
  4. （D）②④

答案：（C）

詳解與考點

考點為魏氏智力量表分測驗測量的能力。彈性思考（流體推理、抽象問題解決）主要由矩陣推理①與圖形設計③反映，故(C)僅①③正確。陷阱為把符號替代②納入，但它測的是處理速度；圖畫補充④測知覺組織與細節辨識，皆非彈性思考核心，易因「都像推理題」而誤選。

第 8 題

在準備心理衡鑑時，評估人員發現個案在三個多月前於另一個單位已經做過相同的項目，下列何者是評估人員再次實施該衡鑑項目的充分理由？
  1. （A）因要更換諮商心理師進行諮商
  2. （B）因不確定前一個單位的衡鑑是否準確
  3. （C）因個案在近期經歷重大負向生活事件
  4. （D）前後兩個單位衡鑑時間距離超過三個月

答案：（C）

詳解與考點

考點為重複施測的正當理由。心理狀態因近期重大負向生活事件而可能改變，此時重測能反映最新狀況，(C)為充分理由。陷阱是(D)以「間隔超過三個月」此一時間長度作為理由，但時間本身不等於需重測，缺乏臨床必要性；更換諮商師或單純懷疑前次準確性，也非重做衡鑑的充分依據。

第 9 題

諮商過程中，諮商心理師經常運用問題解決模式作為心理評量的便利工具。有關問題解決模式的五個心理評量步驟之順序，下列何者最為正確？
  1. （A）界定問題→問題導向→驗證→可能的方案選擇→決策
  2. （B）界定問題→可能的方案選擇→問題導向→決策→驗證
  3. （C）可能的方案選擇→界定問題→問題導向→驗證→決策
  4. （D）問題導向→界定問題→可能的方案選擇→決策→驗證

答案：（D）

詳解與考點

考點為問題解決模式的評量步驟順序。較通行的序列為：問題導向（定向、態度準備）→界定問題→提出可能方案→決策（選擇方案）→驗證執行，故(D)最正確。陷阱在把「界定問題」放最前而略過問題導向定向階段；此模式強調先建立面對問題的正向心態與覺察，再進入界定與解決，順序易被打亂。

第 10 題

對個案進行系統化評估以利介入與個案管理，下列何者不是重要的評估焦點？
  1. （A）積極訓練個案使用各項資源的能力
  2. （B）確認個案目前擁有的內在與外在資源
  3. （C）瞭解個案家庭和外在資源連結的生態
  4. （D）瞭解個案使用資源的能力與限制

答案：（A）

詳解與考點

考點為優勢觀點與生態系統取向的資源評估。評估焦點在「了解、確認」個案內外在資源及其連結與使用限制，屬蒐集現況的評估工作。(A)「積極訓練個案使用資源的能力」是介入處遇而非評估焦點，故為非。陷阱是把後續的訓練、增能誤當成評估階段任務，混淆了評估（理解現況）與介入（促成改變）的分界。

第 11 題

下列何者較能反應多元文化評量（multicultural assessment）的概念？
  1. （A）將評量工具轉譯為多種語言
  2. （B）能評量不同文化背景者的心理特質
  3. （C）特別為不同文化背景者編製評量工具
  4. （D）評量結果有助於來自不同文化者的融合

答案：（B）

詳解與考點

考點為多元文化評量（multicultural assessment）的核心精神，即能公平、有效地評量不同文化背景者的心理特質，(B)最切合。陷阱為(A)僅將工具翻譯成多語，這只是表面語言轉換，未必達成跨文化的測量等值與適切性；為各文化分別編製或促進融合，並非多元文化評量概念的直接定義，易被字面誘導誤選。

第 12 題

下列何者最不符合「生物心理社會－系統理論」心理評估的工作內涵？
  1. （A）在諮商歷程中觀察誰是被指認的個案（identified patient）
  2. （B）重視個案主訴議題的脈絡
  3. （C）強調引發個案主訴議題的病因學
  4. （D）同時關注生物性、心理素質及家庭社會文化脈絡與個案主訴議題的關聯

答案：（C）

詳解與考點

考點為生物心理社會—系統理論的評估內涵，重視被指認個案、脈絡、生理心理家庭社會多面向關聯。(C)「強調引發主訴的病因學」屬線性、單因病因醫療模式思維，與系統觀重關係脈絡而非單一病因相違，故最不符。陷阱在「病因學」聽來專業正確，但系統取向強調循環互動與脈絡，刻意淡化單一線性致病因。

第 13 題

某位諮商心理師運用焦點解決短期治療（solution-focused brief therapy）的概念，來評估個案對於改變的準備程度，發現該個案大部分都在談論母親在教養上的錯誤，很少談到自己行為對家庭的影響，這位個案最可能處於何種狀態？
  1. （A）消費者
  2. （B）來訪者
  3. （C）抱怨者
  4. （D）無意義感

答案：（C）

詳解與考點

考點為焦點解決短期治療對改變準備度的三類來談者。個案只談母親的錯、少談自身責任，屬抱怨者（complainant）：能描述問題卻將焦點放在他人、尚未視自己為解決一環。(C)正確。陷阱為消費者（customer），其願意把自己當改變主體並採取行動；本題個案缺乏這份自我承擔，故非消費者。

第 14 題

關於個案評估的敘述，下列何者正確？
  1. （A）評量的資料以自我報告（self-report）為主，因為個案的自我知覺最重要
  2. （B）諮商關注的是個人，外在環境的評量是不需要的
  3. （C）使用生理回饋儀器主要是評量個案非自主的生理反應
  4. （D）自我監控技術是屬於回溯性的評量

答案：（C）

詳解與考點

考點為個案評估的多元方法與生理回饋。生理回饋儀器主要量測心率、肌電等非自主生理反應，(C)正確。陷阱：(A)僅靠自我報告會偏頗；(B)外在環境評量在生態與行為取向中不可或缺；(D)自我監控是當下、即時記錄行為，屬前瞻而非回溯性評量，三者皆為易誤選的錯誤敘述。

第 15 題

下列何者不是危機電話會談要考慮的主要目的？
  1. （A）提供立即資源以滿足緊急問題需求
  2. （B）轉移或減緩危險狀況的可能傷害
  3. （C）鼓勵來電者在危機後進入正式的治療模式以深入解決問題
  4. （D）評估來電者的人際關係

答案：（D）

詳解與考點

考點為危機電話會談的主要目的：提供立即資源、減緩立即危險、銜接後續正式治療。(D)「評估來電者的人際關係」非危機熱線的主要目的，危機介入聚焦安全與穩定當下，故為非。陷阱是人際關係評估在一般諮商中重要，但在分秒必爭的危機通話中並非核心任務，易被一般諮商思維帶偏。

第 16 題

Lazarus自1973年所發展出的BASIC-ID模式中，第一個I所指的是意象（imagery），第二個I所指的為下列何者？
  1. （A）認同（identification)
  2. （B）意向（intention）
  3. （C）理想（idealization）
  4. （D）人際關係（interpersonal relations）

答案：（D）

詳解與考點

考點為 Lazarus 多模式治療 BASIC-ID 的字母對應。B 行為、A 情感、S 感官、I 意象、C 認知、I 人際關係、D 藥物/生理。第二個 I 指人際關係（interpersonal relations），(D)正確。陷阱在四個選項皆為 I 開頭的英文詞誘導混淆，須記住 BASIC-ID 中兩個 I 分別是 imagery 與 interpersonal。

第 17 題

個案填寫自陳式量表時，習慣依照社會可接受的答案回答，而不是如實地反應自己的真實態度。此種作答方式稱為下列何者？
  1. （A）反應風格（response style）
  2. （B）反應不一（response inconsistency）
  3. （C）社會期許（social desirability）
  4. （D）偽裝（faking）

答案：（C）

詳解與考點

考點為自陳量表的作答偏誤類型。受試者依「社會可接受」方向作答而非真實態度，稱社會期許（social desirability），(C)正確。陷阱為(A)反應風格，那是廣義作答傾向（如極端化、默許）的上位概念；偽裝(D)多指刻意造假以求特定結果。社會期許特指趨向被社會認可形象的偏誤，較精確對應題意。

第 18 題

關於心理測驗安全性的維護，下列敘述何者錯誤？
  1. （A）心理測驗材料應該存放在一個安全的地方
  2. （B）任何一個有版權的心理測驗都不可以複印
  3. （C）個案或監護人可以看到心理測驗結果
  4. （D）司法機關需要看心理測驗報告時，諮商心理師仍應堅守保密原則加以拒絕

答案：（D）

詳解與考點

考點為心理測驗安全與保密的界限。保密非絕對，當有法律強制（如司法機關依法調閱）時須讓步，諮商師不能一律拒絕，故(D)為錯誤敘述。陷阱在把「堅守保密」當成最高原則；測驗材料保管、版權不得複印、當事人有權知結果皆正確，唯保密在合法調閱前並非可無條件拒絕。

第 19 題

蓉蓉正在編製國小學童行為適應的測驗，欲請專家學者評估測驗內容是否能代表所欲測量的行為領域，此效度考驗方法屬於下列何種？
  1. （A）同時效度（concurrent validity）
  2. （B）內容效度（content validity）
  3. （C）預測效度（predictive validity）
  4. （D）輻合效度（convergent validity）

答案：（B）

詳解與考點

考點為效度類型。請專家學者判斷題目是否充分代表所欲測量的行為領域，屬內容效度（content validity），(B)正確。陷阱為同時效度與預測效度，二者屬效標關聯效度需外在效標資料佐證；輻合效度需與相近構念測量相關。本題僅靠專家邏輯判斷內容代表性，故為內容效度。

第 20 題

下列何者不是檔案評量（portfolio assessment）的特性？
  1. （A）強調過程評量重於結果評量
  2. （B）強調呈現整體學習成效
  3. （C）強調表現個人反思
  4. （D）強調長期的評鑑

答案：（A）

詳解與考點

本題為「何者不是檔案評量特性」，官方答案為 (A)。檔案評量（portfolio assessment）蒐集學習歷程中的代表性作品，兼重「歷程」與「成果」的整體呈現，並不主張「過程評量重於結果評量」這種偏廢一方的對立排序，故 (A) 不是其特性、為正解。其餘皆為檔案評量的特性：(B) 正確，透過多元作品呈現整體、全貌式的學習成效；(C) 正確，重視學習者的個人反思與自我評鑑；(D) 正確，屬長期、持續累積的評鑑，能反映成長與進步軌跡。

第 21 題

下列何者不是評估個案ADHD問題的重要參考資料？
  1. （A）教室觀察
  2. （B）檔案資料
  3. （C）相關第三人訪談
  4. （D）飲食偏好

第 22 題

關於實作評量的敘述，下列何者錯誤？
  1. （A）直接測量能力
  2. （B）可以嵌入課程中
  3. （C）僅用來評估實作過程
  4. （D）可評估情感與社會技能

答案：（C）

詳解與考點

考點為實作評量（performance assessment）的特性：直接測量能力、可嵌入課程、能評情意與社會技能，並兼顧過程與結果。(C)「僅用來評估實作過程」過於狹隘，實作評量同時看過程與成品結果，故為錯誤。陷阱在「實作」易讓人以為只重過程，但其特色正是能整合過程與最終表現一併評量。

第 23 題

Multimodal therapy評估個人7個biopsychosocial的向度，Lazarus用BASIC-ID來代表，下列那個英文縮寫是「生理」的部分？
  1. （A）A
  2. （B）B
  3. （C）C
  4. （D）D

答案：（D）

詳解與考點

考點為 BASIC-ID 中代表生理/藥物的字母。D 代表 Drugs/biology（藥物與生理），(D)正確。陷阱在 B 易被直覺當成 biology，但 B 其實是 Behavior（行為）；生理面向在 Lazarus 模式中歸於 D（drugs、藥物與生物層面），須牢記字母與向度的正確對應。

第 24 題

在進行ABC功能分析時，諮商心理師也需要同時去了解情境事件的因素，關於情境事件的概念，下列敘述何者錯誤？
  1. （A）情境事件指的是情境、氣氛或使行為隨之增強發生的情況
  2. （B）情境事件是指發生在問題行為的前幾秒或前幾小時內的情況
  3. （C）情境事件可以源自於與環境有關的促發因素
  4. （D）在學校中，低度刺激或高度刺激的教室均是可能引發問題行為的情境事件

答案：（B）

詳解與考點

考點為 ABC 功能分析中情境事件（setting event）與前事（antecedent）的區分。情境事件是較遠、背景性的促發脈絡（情境、氣氛、環境因素）。(B)把「發生在問題行為前幾秒到幾小時」當成情境事件，那其實是緊鄰的前事/觸發事件，故為錯誤。陷阱在情境事件與前事都「在行為之前」，但情境事件更遠更背景，時間緊鄰者屬前事。

第 25 題

解釋魏氏智力量表的工作包含：①解釋分測驗間差異②解釋全量表智商分數③質性或受測過程分析④解釋組合分數⑤解釋分測驗內差異⑥解釋百分等級與信賴區間⑦解釋個人的強弱項。其步驟依序為下列何者？
  1. （A）③②①⑦⑥④⑤
  2. （B）②⑥④⑦①③⑤
  3. （C）③⑦⑤①④②⑥
  4. （D）⑦①③⑤④⑥②

答案：（B）

詳解與考點

考點為魏氏智力量表解釋的步驟順序。通行序列由整體到細部：先全量表智商②，再百分等級與信賴區間⑥，接組合分數④，個人強弱⑦，分測驗間差異①，質性/過程分析③，最後分測驗內差異⑤，即(B)②⑥④⑦①③⑤。陷阱為先談分測驗細節再回整體的逆向排列，違反「由總分到細項」的標準解釋邏輯。把握度較低，順序版本多。

第 26 題

在會談過程中，諮商心理師發現個案有詐病的可能性，進一步透過明尼蘇答多相人格測驗（Minnesota Muliphasic Personality Inventory-2, MMPI-2）加以評估。下列四個MMPI-2量尺中，何者可協助諮商心理師衡量上述現象？
  1. （A）撒謊量尺（L）
  2. （B）罕見反應量尺（F）
  3. （C）不知道量尺（?）
  4. （D）反應不一致量尺（VRIN）

答案：（B）

詳解與考點

考點為 MMPI-2 效度量尺與詐病偵測。F（罕見反應）量尺偏高反映誇大、製造病態或詐病傾向，(B)正確。陷阱為(A)L 撒謊量尺，那測的是刻意呈現過度良好形象（裝好）；VRIN 測作答前後不一致。詐病是「裝病、誇大症狀」，對應的是 F 量尺而非裝好的 L。

第 27 題

關於人格測驗中常存在受試者「偽裝」的議題，下列敘述何者正確？
  1. （A）自陳式人格測驗比投射式更容易偽裝
  2. （B）施測者與受試者的信任關係與偽裝程度無關
  3. （C）有些人格測驗編製時會有偽裝量尺，但加州心理量表沒有編製有關偽裝的量尺
  4. （D）明尼蘇答多相人格測驗中的F量尺，是測受試者是否企圖製造過度正面的印象

答案：（A）

詳解與考點

考點為人格測驗的偽裝（faking）。自陳式題目意義透明、受試者可推測理想答案，故較投射式更易偽裝，(A)正確。陷阱：(B)信任關係會影響偽裝程度；(C)加州心理量表 CPI 其實設有效度/偽裝相關量尺；(D)MMPI 的 F 量尺測的是裝病而非製造過度正面印象（裝好對應 L），三者皆為錯誤敘述。

第 28 題

  3. （C）因情感衝動而受挫
  4. （D）無助的感受

答案：（C）

考點為羅夏克測驗純彩色反應（pure C）的臨床意義。純 C 缺乏形狀調節，反映情緒未經理性控制、衝動且易受挫，(C)「因情感衝動而受挫」最貼近。陷阱在其他選項描述抑鬱、缺愛、無助等情緒內容，但純彩色反應的核心解釋是情感調控薄弱、衝動性，而非特定情緒主題。把握度中等。

第 29 題

關於成就測驗與性向測驗的敘述，下列何者錯誤？
  1. （A）成就測驗比較重視內容效度
  2. （B）性向測驗並不假定先前有學習經驗，主要在測量學習潛力
  3. （C）性向測驗主要重視預測效度
  4. （D）成就測驗假定先前有學習經驗，主要測量學習態度

答案：（D）

考點為成就測驗與性向測驗的區別。成就測驗重內容效度、假定先前已學習，性向測驗重預測效度、測學習潛力。(D)稱成就測驗「主要測量學習態度」錯誤，它測的是已習得的知識成果而非態度。陷阱在前半「假定先前有學習經驗」正確，後半偷換成「學習態度」，須留意成就測驗測的是成果（成就）而非態度。

第 35 題

  4. （D）評估個案自殺意念

第 37 題

  2. （B）基本用語在描述一個人的獨特性上比較精確
  3. （C）基本用語可和較多群眾溝通
  4. （D）使用基本用語顯示衡鑑者對資料有比較深度的瞭解

答案：（A）

第 38 題

諮商心理師某甲曾在二年前和偉中（當時是國小三年級）諮商十二次。現在偉中的父母離婚，正在爭取監護權，偉中的爸爸認為某甲熟悉他們，向法官建議由某甲評估他們的身心狀態。關於某甲的作法，下列何者最適切？
  1. （A）如果時間許可就答應評估，因他對偉中熟悉，事半功倍
  2. （B）某甲只熟悉偉中，對於其父母仍要運用各種方式評估
  3. （C）評估和諮商不同，不管是偉中還是他父母，都必須評估
  4. （D）某甲應拒絕進行評估，因為他與偉中曾進行諮商

答案：（D）

詳解與考點

考點為多重關係與角色衝突的倫理。某甲曾與偉中有諮商治療關係，再擔任監護權評估者會形成角色衝突、損害客觀性與兒童權益，應拒絕，(D)正確。陷阱為以「熟悉、事半功倍」為由答應，看似便利實則違反避免雙重關係的倫理；先前治療關係正是不宜再承接司法評估的關鍵理由。

第 39 題

一名家暴受害婦女到一心理諮商機構進行心理評估，他對諮商心理師說自己日後會申請一份這次的心理評估結果報告交給她委任的律師，以進行後續相關的法律程序。諮商心理師在交給個案的評估報告中，不需包括下列何者？
  1. （A）評估中使用的心理測驗的分數
  2. （B）對個案目前情緒狀況的描述
  3. （C）評估中使用的心理測驗題目
  4. （D）個案的相關背景資料

答案：（C）

詳解與考點

考點為測驗安全與報告揭露界限。交付當事人的評估報告可含測驗分數、情緒描述、背景資料，但「測驗題目本身」涉及測驗保密與版權安全，不應放入，(C)為不需包括者。陷阱在誤以為完整透明須附上題目；維護測驗材料安全是專業義務，題目外流會破壞測驗效度，故須排除。

答案：（D）

詳解與考點

考點為電腦計分/解釋測驗的使用倫理。最正確作法是：計分與解釋具良好效度，且諮商師仍以專業判斷與其他衡鑑資料交叉驗證，(D)。陷阱為(C)「有實證即可依其解釋」，過度仰賴電腦報告、放棄專業整合判斷；倫理要求電腦解釋僅為輔助，不能取代心理師的綜合判斷與多源驗證。
