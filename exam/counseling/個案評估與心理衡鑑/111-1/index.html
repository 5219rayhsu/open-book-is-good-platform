第 1 題

在使用心理測驗前，諮商心理師應最優先了解那些重要的評估工具訊息？①測驗的發展者②測驗的出版年、月③測驗的理論取向④標準化樣本的適當性⑤測驗的信效度⑥實務考量
  1. （A）①②③⑥
  2. （B）②③④⑤
  3. （C）③④⑤⑥
  4. （D）①②④⑤

答案：（C）

詳解與考點

正解：「最優先」了解的評估工具訊息——判準是資訊是否直接決定測驗可否適切施用於這位當事人。③理論取向決定測量的是什麼，④標準化樣本適當性關乎可否合理比較，⑤信效度關乎結果可信與是否測到預定構念，⑥實務考量關乎施測條件與用途；四者均成立，故選 C。

A：本組含①發展者與②出版年、月。二者是可參考的背景資訊，卻不能取代標準化樣本適當性與信效度，故不符最優先的完整判準。

B：本組雖有③、④、⑤，卻漏掉施測時間、成本、受試者負荷及用途等⑥實務考量，不能構成完整選擇依據。

D：本組含①、②而漏③理論取向與⑥實務考量，把背景資訊置於直接影響適用性的要件之前。

本題考點：測驗選用——判準是先確認理論構念、常模樣本與當事人是否相稱、信效度及實務可行性；發展者和出版時間可供查考，但不是單獨決定適切性的核心。

第 2 題

心理測驗是透過有系統地使用一些簡單的原則，來測量那些可以描述與理解個人的重要屬性。關於心理測驗的應用，下列何者錯誤？
  1. （A）可以參考測驗結果來決定人事的錄用
  2. （B）可以參考測驗結果來選擇適合個案的處遇方式
  3. （C）可以透過測驗結果來決定或建議個人所適合擔任的職務
  4. （D）可以透過測驗結果來決定一個人的價值

答案：（D）

詳解與考點

正解：負向題「何者錯誤」及「決定一個人的價值」——測驗只能在適切解釋下描述特定屬性、輔助決策，不能把分數擴張為人的整體價值判定。D 將測驗用途越界為評斷個人價值，與心理衡鑑倫理不符，故為應選項。

A：在人事錄用中參考測驗結果可作為多元資料之一；須配合職務相關性與適當程序，並非測驗應用本身錯誤，故非答案。

B：測驗結果可與晤談及其他資料整合，協助選擇處遇方向，故非答案。

C：測驗可提供職務適配的參考資訊，但不應取代完整判斷；作為建議用途仍屬正當應用，故非答案。

本題考點：測驗倫理與用途——判準是測驗結果用於描述特質與輔助決策，且須結合脈絡及其他資料；不能由單一結果推定人的尊嚴或價值。

第 3 題

「標準九分」尺度是透過什麼樣的轉換過程而產生的？
  1. （A）線性轉換
  2. （B）z分數轉換
  3. （C）T分數轉換
  4. （D）面積轉換

答案：（D）

詳解與考點

正解：「標準九分」——判準是轉換後各類別依常態曲線下的面積劃分，而不是以固定加減乘除維持原分數的等距關係。標準九分將分數依常態曲線下面積切為九段，屬面積轉換或常態化轉換，故選 D。

A：線性轉換以固定公式轉換各分數，會保留相對等距關係；標準九分按面積切段，非單純線性轉換。

B：z 分數是以平均數與標準差作線性標準化，本身不是將常態面積劃成九類的作法。

C：T 分數由 z 分數線性轉換而得，同樣不是標準九分的面積切段程序。

本題考點：標準九分——判準是以常態曲線下面積劃分九個等級；z 分數與 T 分數屬線性標準分數，不能與面積轉換混為一談。

第 4 題

李老師編製了一個國二學生適用的智力測驗，他以國一學生時的國文與數學成績的平均來驗證其效度，這是屬於何種類型的效度？
  1. （A）建構效度
  2. （B）內容效度
  3. （C）同時效度
  4. （D）預測效度

答案：（C）

詳解與考點

正解：以「國一學生時的國文與數學成績」驗證國二適用智力測驗——判準是測驗分數與效標資料是否在同一時期或可立即對照，而不是由目前分數預測未來結果。此處以既有學業成績作效標進行對照，屬同時效度，故選 C。

A：建構效度檢驗測驗是否真能測得理論構念，通常看內部結構、與相關構念的關係等；本題明確以外部學業效標驗證，非此重點。

B：內容效度檢視題目內容是否充分代表欲測領域，重點在試題取樣，非與學業成績對照。

D：預測效度要求目前測驗分數能預測日後才會出現的效標；本題效標是已存在且可取得的成績，故非答案。

本題考點：效標關聯效度——判準是效標的時間關係；同期或立即可取得的效標看同時效度，未來表現才看預測效度。

第 5 題

關於基準率（base rate）於臨床實務應用中的敘述，下列何者正確？
  1. （A）是指某特殊行為在臨床個案上出現的頻率
  2. （B）是指某特殊行為出現在一般群體的比率
  3. （C）是指對於個案問題的正確診斷率
  4. （D）指排除個案為某種問題的正確率

答案：（B）

詳解與考點

正解：「基準率（base rate）」——判準是某行為或特徵在作為參照的一般母群中原本出現的比率。B 指某特殊行為出現在一般群體的比率，正是基準率，亦是判讀篩檢與診斷結果的重要背景，故選 B。

A：把範圍限於臨床個案，混淆了臨床樣本中的出現比例與一般母群的基準率。它看似貼近臨床實務，錯在參照群體被限縮。

C：正確診斷率是在描述診斷表現，不是某特徵原本的盛行比例。

D：正確排除某問題的比率屬診斷分類的正確性概念，也不是基準率。

本題考點：基準率——判準是先界定一般母群，再看特徵在其中的原始出現比例；診斷正確率與排除正確率是測驗判別表現，概念不同。

第 6 題

對個案評估的意義與功能而言，結構化的臨床晤談已被證實是一可靠且有效的評估方法。下列何者不屬於結構化的晤談工具？
  1. （A）診斷性晤談量表（diagnostic interview schedule）
  2. （B）DSM結構式臨床會談（structured clinical interview for the DSM）
  3. （C）行為和態度檢核表（behavior and attitude checklist）
  4. （D）雷納診斷性面談（Renard diagnostic interview）

答案：（C）

詳解與考點

正解：「不屬於結構化的晤談工具」——判準是工具是否具有標準化題序、提問與診斷流程，由晤談者實際進行會談。C 的行為和態度檢核表是評定或自陳式清單，不是結構化臨床晤談，故為應選項。

A：診斷性晤談量表以系統化問題蒐集診斷資訊，屬結構化晤談工具，故非答案。

B：DSM 結構式臨床會談依診斷架構安排標準提問與判定流程，正屬結構化晤談，故非答案。

D：雷納診斷性面談屬結構化診斷晤談工具；名稱較陌生而像非晤談，卻不可只按熟悉度判斷，故非答案。

本題考點：結構化臨床晤談——判準是有標準化問題與診斷流程的會談；檢核表雖能提供衡鑑資料，仍屬量表或清單，非晤談工具。

第 7 題

心理衡鑑可應用於不同的專業、問題領域和族群，下列有關心理衡鑑之敘述何者正確？
  1. （A）心理衡鑑已將個案的生活脈絡納入考量，但不考慮文化因素
  2. （B）心理衡鑑的核心是藉由持續地蒐集資料以形成或確認有關個案的推論或概念化
  3. （C）單一來源的資料，才能確保心理衡鑑的正確訊息
  4. （D）測驗分數是臨床工作者最依賴的資料來源，也是最有效的資料來源

答案：（B）

詳解與考點

正解：「心理衡鑑」——判準不是一次測驗得出結論，而是持續蒐集、整合並檢驗多種資料，以形成或確認對個案的推論與概念化。B 正確描述此歷程，故選 B。

A：生活脈絡與文化因素都會影響資料意義及解釋，不能納入前者卻排除後者，故不正確。

C：單一來源容易受方法與情境限制；心理衡鑑反而強調多來源資料的交叉檢核。

D：測驗分數可提供重要資訊，卻不能凌駕晤談、觀察、生活脈絡與其他資料。它看似客觀，錯在把單一資料來源當成最有效的結論。

本題考點：心理衡鑑——判準是持續蒐集與整合多元資料，形成可修正的個案概念化；文化脈絡與資料來源交叉檢核都是解釋結果的必要條件。

第 8 題

下列那些是為了瞭解諮商效果，於後測時較適合納入的衡鑑工具？①測量症狀的工具②具病理基礎的測量工具③個案的智力水準④因應策略
  1. （A）僅①③
  2. （B）僅②④
  3. （C）①②③④
  4. （D）僅①②④

答案：（D）

詳解與考點

正解：「瞭解諮商效果」與「後測」——判準是工具所測內容是否可能隨諮商而改變，因而能與前測比較。①症狀、②具病理基礎的測量與④因應策略都可反映介入後的變化；③智力水準通常是較穩定特質，不宜作短期諮商效果指標，故正確組合為①②④，選 D。

A：本組含①、③；③智力水準通常不因短期諮商而改變，將它列入後測會偏離成效檢核目的。

B：本組僅含②、④，漏掉可直接反映困擾變化的①症狀測量，內容不完整。

C：本組含③，誤把相對穩定的智力水準當作諮商後測的改變指標。

本題考點：諮商成效後測——判準是選擇對介入敏感、可合理預期改變的指標；症狀、病理相關狀態與因應策略可比較前後變化，穩定能力特質通常不適用。

第 9 題

下列何者不是諮商中進行個案評估的目的？
  1. （A）協助確認問題所在
  2. （B）找出解決方案的可能性
  3. （C）確認諮商的有效性
  4. （D）蒐集符合初始效應的資料

答案：（D）

詳解與考點

正解：負向題「不是諮商中進行個案評估的目的」——判準是評估應開放蒐集與整合資料，以理解問題、規劃方向及檢核效果，而非選擇性蒐集支持既有印象的證據。D 的初始效應資料蒐集會造成確認偏誤，不是評估目的，故為應選項。

A：協助確認問題所在，是形成個案概念化與決定工作焦點的基本目的，故非答案。

B：找出可能解決方案有助於規劃後續介入，故非答案。

C：確認諮商是否有效可作為成效評估，故非答案。

本題考點：個案評估目的——判準是界定問題、發展介入可能性與檢核成效；評估須避免為了支持初步印象而選擇性蒐證。

第 10 題

Myers-Briggs Type Indicator人格測驗是根據下列那一個學派理論所發展出的量化人格衡鑑工具？
  1. （A）Jung分析與治療
  2. （B）情緒焦點治療
  3. （C）現實治療
  4. （D）敘事治療

答案：（A）

詳解與考點

正解：「Myers-Briggs Type Indicator」與「量化人格衡鑑工具」——判準是其人格類型構面源自哪一套理論。MBTI 由 Myers 與 Briggs 依 Jung 的心理類型論發展，採內外向、感知—直覺、思考—情感等類型概念，故選 A。

B：情緒焦點治療著重情緒經驗與關係改變，並非 MBTI 的類型理論基礎。

C：現實治療以選擇理論與需求為核心，未構成 MBTI 的人格類型架構。

D：敘事治療探討問題故事與替代故事，也不是 MBTI 的理論來源。

本題考點：MBTI——判準是由 Jung 心理類型論衍生的人格偏好分類；治療取向的介入技術或哲學不能因同樣談人格便視為其測驗理論根源。

第 11 題

如果結合三級預防的概念來選擇適當的測驗工具，下列何種測驗工具較為適合運用在初級預防之評估？
  1. （A）大學生學習與讀書策略量表
  2. （B）貝克憂鬱量表第二版
  3. （C）羅夏克測驗
  4. （D）健康、性格、習慣量表

答案：（A）

詳解與考點

正解：「初級預防」——判準是面向一般族群、著重健康促進與發展性需求，而不是辨識或處理已出現的病理。A 的大學生學習與讀書策略量表可用於一般學生的學習促進，最適合初級預防評估，故選 A。

B：貝克憂鬱量表第二版著重憂鬱症狀，較適合症狀辨識或臨床追蹤，非一般性初級預防的優先工具。

C：羅夏克測驗用於深入人格與臨床衡鑑，施測與解釋均較專門，非一般族群健康促進的首選。

D：健康、性格、習慣量表看似涵蓋健康，卻不如 A 直接聚焦一般學生可促進的學習與讀書策略；本題依三級預防的發展性用途選 A。

本題考點：三級預防——判準是初級預防服務一般族群、促進健康與能力；當工具主要測量症狀、病理或深入臨床人格時，通常不屬初級預防的優先選擇。

第 12 題

關於評估會談的意圖與功能，下列何者錯誤？
  1. （A）評估會談的目的，主要是從中界定要改變的問題
  2. （B）評估會談是資料收集的過程，較不重視投契關係
  3. （C）評估會談通常也會討論將來可能進行的介入計畫
  4. （D）評估會談的最後，通常會協助個案提升其改變動機

答案：（B）

詳解與考點

正解：負向題「評估會談的意圖與功能何者錯誤」——判準是評估雖須蒐集資料，仍要建立足以讓當事人合作與表達的投契關係。B 認為評估會談較不重視投契，錯置資料蒐集與關係建立的關係，故為應選項。

A：界定需要改變的問題是評估會談的重要功能，能協助形成後續工作焦點，故非答案。

C：評估會談可討論可能的介入計畫，讓當事人理解後續方向，故非答案。

D：會談結尾協助提升改變動機，有助於當事人投入後續工作，故非答案。

本題考點：評估會談——判準是同時蒐集資料、建立投契、界定問題並討論後續介入；投契不是治療開始後才需要的附加事項，而是取得可信資料與合作的基礎。

第 13 題

在家族治療的評估會談中，某位諮商心理師詳細詢問母親與兒子在家庭裡的平時對話內容，包括通常誰開始說話，另一個人如何回應，回應時的心情如何，最後怎麼結束話題。該諮商心理師是運用了那一種評估家庭功能的技巧？
  1. （A）聚焦
  2. （B）反映
  3. （C）調整步調
  4. （D）追蹤互動

答案：（D）

詳解與考點

正解：依序追問「誰開始說話、如何回應、心情如何、怎麼結束」——判準是是否重建家庭成員間的互動序列與循環。D 的追蹤互動正是循序了解對話如何展開、回應及終止，以評估家庭功能，故選 D。

B：反映是回應或重述成員的感受、內容或互動，未必系統追查先後與循環。

C：調整步調是配合家庭成員的速度、語氣或情緒強度以建立工作聯結，重點不在描繪互動序列。

第 14 題

下列那一種衡鑑會談的問句方式，最能讓個案表達自己較重要但卻不尋常的特質？
  1. （A）開放式問句
  2. （B）中度指導性問句
  3. （C）高度指導性問句
  4. （D）封閉式問句

答案：（A）

詳解與考點

正解：「重要但卻不尋常的特質」——衡鑑會談若要讓個案帶出訪談者尚未預期的個人經驗，判準是問句保留多少回答空間。A：開放式問句不預設內容或方向，個案可自行選擇陳述重點，最能引出重要卻未被直接問及的獨特特質，故選 A。

B：中度指導性問句雖仍可延伸回答，但已由訪談者設定主題或方向，較可能漏掉個案未預期提出的特質。

C：高度指導性問句將回答導向特定資訊，適合確認假設，不利探索不尋常的個人特質。

D：封閉式問句通常限於特定答案或簡短回應，回答範圍最窄。它看起來有效率，卻不符合本題要蒐集未知特質的目的。

本題考點：衡鑑會談問句的結構化程度——判準是「要探索未知、個別化內容時用開放式問句；要確認特定事實時才提高指導性」；問句愈結構化，個案自主展開的空間愈小。

第 15 題

某公司長年以來透過能力測驗A甄選員工。該公司發現新進員工中，年終考績B以上者在能力測驗A的總分都高於250分。因此，自去年起，訂定能力測驗A總分250分為該公司錄取員工的決斷分數（cutoff score）。去年有位新進員工在能力測驗A的總分為300分，但年終考績卻不及格。此種情況屬於下列何者？
  1. （A）正確肯定（correct positive）
  2. （B）錯誤肯定（false positive）
  3. （C）正確否定（correct negative）
  4. （D）錯誤否定（false negative）

答案：（B）

詳解與考點

正解：「300 分高於 250 分決斷分數」但「年終考績不及格」——須交叉判讀測驗預測與實際效標。B：測驗分數高於切截分，預測其會錄取並有良好表現；實際考績卻不及格，屬預測肯定、實際否定的錯誤肯定（false positive），故選 B。

A：正確肯定是測驗預測成功，實際效標也成功，例如分數達切截分且考績 B 以上，與本題不符。

C：正確否定是測驗預測不成功，實際效標也不成功，本題的測驗預測並非否定。

D：錯誤否定是低於切截分而被預測失敗，實際卻成功；它最易與 B 混淆，分辨關鍵在本題是「預測會成功卻失敗」，不是「預測會失敗卻成功」。

本題考點：切截分數的命中矩陣——判準是先看測驗預測為肯定或否定，再看效標結果成功或失敗；預測肯定但實際失敗，即為錯誤肯定。

第 18 題

某國文老師對於上課安靜、守秩序的林同學印象良好，也習慣給該生較高的作文分數。這種評分問題稱為下列何者？
  1. （A）月暈偏誤（halo effect error）
  2. （B）寬大偏誤（generosity error）
  3. （C）趨中偏誤（central tendency error）
  4. （D）嚴格偏誤（severity error）

答案：（A）

詳解與考點

正解：老師因「安靜、守秩序」的良好印象而給同一學生較高作文分數——判準是非目標特質的整體印象是否外溢到另一項評分。A：月暈偏誤是評定者以某一突出的好或壞特質概括其他表現；本題把守秩序的印象延伸到作文評分，故選 A。

B：寬大偏誤是評定者對多數或所有受評者一概偏向給高分，不是只對特定學生因既有印象加分。它最易被誤選，因為結果同樣是分數偏高；關鍵在偏高的來源是整體寬鬆還是印象外溢。

C：趨中偏誤是避免極端評分、將多數人評在中間，與本題無關。

D：嚴格偏誤是普遍給分偏低，方向與本題相反。

本題考點：評定誤差——判準是「單一印象牽連其他向度」為月暈偏誤；「普遍給高分」為寬大偏誤；「普遍給中間分」為趨中偏誤。

第 21 題

  4. （D）難以推論行為發生的方式和原因

第 24 題

  2. （B）進行適應測驗，至少一個適應領域是受損的，就可以診斷為智能不足

  4. （D）進行成就測驗，如果與FSIQ有1.5～2個標準差，就可以診斷為學習障礙

D：成就測驗與 FSIQ 的差距可提供學習表現資訊，但不能直接處理本題的智能不足判斷。

本題考點：DSM-5 智能不足的衡鑑——整合智能功能、適應功能、發展史與測量誤差；不是以 IQ 70 作為硬性切點。

第 25 題

下列四種人格測驗，何者是透過因素分析法編製而成？
  1. （A）健康、性格、習慣量表（Health, Personality, and Habit Test, HPH）

D：MBTI 依心理類型理論建構，不是以因素分析法作為編製核心。

本題考點：人格測驗的編製方法——判準是因素分析法從題項相關中萃取人格向度；實證效標法以效標群體區分選題；理論建構法則依既有心理理論設計題目。

第 30 題

若一個測量標準誤為10的生涯測驗，小花測驗結果得到60分，下列何者最接近小花95%的信賴區間分數？
  1. （A）(55.25, 64.75)
  2. （B）(50.50, 69.50)
  3. （C）(50.25, 69.75)
  4. （D）(40.40, 79.60)

答案：（D）

詳解與考點

正解：「測量標準誤為 10」與「95% 信賴區間」——應用公式為「觀察分數 ± z×SEM」，95% 信賴水準的 z 為 1.96。代入數字：60 ± 1.96×10；先算誤差幅度 1.96×10=19.6；下限為 60-19.6=40.4，上限為 60+19.6=79.6，得區間（40.40，79.60），故選 D。

A：區間（55.25，64.75）距 60 分各 4.75 分，計算為 4.75÷10=0.475 個 SEM，連約 68% 信賴水準的 1 個 SEM 都不到，誤差幅度算得過窄。

B：區間（50.50，69.50）距 60 分各 9.5 分，9.5÷10=0.95 個 SEM，約為 1 個 SEM，對應約 68% 而非 95%。

C：區間（50.25，69.75）距 60 分各 9.75 分，9.75÷10=0.975 個 SEM，同樣僅約 1 個 SEM，不是 95% 區間。

本題考點：測量標準誤與信賴區間——判準是先由信賴水準定 z 值，95% 取 1.96，再算觀察分數 ± z×SEM；95% 的半寬約為 2 個 SEM，不是 1 個 SEM。

  2. （B）權力（power）

  4. （D）舒適（comfort）

  2. （B）該生督導性的真實分數約有95%機率會落在34～46分之間

  4. （D）比較該生分測驗的側面圖，可解釋該生說服性工作氣質高於督導性工作氣質

本題考點：SEM 與真實分數帶——判準是約 68% 用觀察分數 ±1×SEM，約 95% 用觀察分數 ±1.96×SEM；比較分測驗表現時，不能忽略誤差範圍與量尺可比較性。

  4. （D）衡鑑工具的效度

答案：（D）

詳解與考點

正解：「比較不會涉及受試者的倫理議題」——要區分直接保護受試者權益的規範，與研究設計的技術品質。（D）衡鑑工具的效度關乎測量品質與研究方法，較不直接屬於受試者權益保護的倫理議題，故選 D。

A：知後同意使受試者了解研究目的、程序與可能影響後自行決定是否參與，直接涉及自主權。

B：隱私權保護受試者不被不必要地蒐集或揭露私人資訊，直接涉及倫理議題。

C：保密要求研究者妥善處理已取得的可識別資訊，直接涉及受試者權益。

本題考點：研究衡鑑倫理——判準是該事項是否直接關係受試者的自主、隱私或資訊保護；知後同意、隱私與保密屬倫理核心，效度主要是方法學品質。

第 38 題

關於衡鑑過程中，標籤化對個案的負面影響，下列何者錯誤？
  1. （A）個案會利用標籤化逃避自己的行為
  2. （B）個案會因為怕標籤化而不自覺的揭露個人的訊息
  3. （C）標籤化可能限制了個案個人的發展
  4. （D）個案透過標籤化的預期角色會產生自我驗證的預言

答案：（B）

詳解與考點

正解：「標籤化的負面影響」與「錯誤」——負向題須找出與標籤化機制相反的敘述。（B）個案因害怕被標籤而不自覺揭露個人訊息，將害怕標籤與增加揭露錯置；較合理的影響是減少或壓抑揭露，故為應選項。

A：個案可能援引標籤逃避自身行為責任，確可能是標籤化的負面後果，故非答案。

C：標籤可能限縮個案對自身能力與發展可能性的看法，確可能限制個人發展，故非答案。

D：個案依標籤預期自己的角色而形成自我驗證預言，確是常見負面影響；它看似負面而容易被當成錯誤，關鍵是此機制本身確實會強化標籤。

本題考點：標籤化的影響——判準是標籤是否造成逃避責任、限制發展、自我驗證或抑制揭露；害怕被標籤通常不會使個案增加揭露。

第 39 題

小妍疑似患有憂鬱症，諮商心理師評估後要撰寫「個案取向」的心理衡鑑報告給她參考，下列內容何者最恰當？
  1. （A）個案憂鬱的可能壓力源與目前呈現的狀態的關聯、可運用之治療方式的選擇
  2. （B）個案目前處於憂鬱狀態，不適合工作，建議在家休養一段時間
  3. （C）個案的憂鬱症來自工作壓力及人際關係，建議心理諮商
  4. （D）個案只是心情不佳，未達憂鬱症程度，只要心理諮商就好

答案：（A）

詳解與考點

正解：「個案取向」與「給她參考」——報告應讓個案理解目前狀態並能參與後續選擇。（A）說明可能壓力源與目前狀態的關聯，以及可運用治療方式的選擇，兼顧理解、彈性與賦能，最為恰當，故選 A。

B：直接判定個案不適合工作並建議在家休養，結論過度武斷，未呈現衡鑑依據或個案可參與的選擇。

C：直接斷言憂鬱症來自工作壓力與人際關係，把可能因素說成確定因果，過度簡化個案處境。

D：逕稱只是心情不佳、只要心理諮商即可，同樣以未充分說明的判斷取代完整衡鑑與選擇討論。

本題考點：個案取向心理衡鑑報告——判準是以個案可理解、可運用的語言連結現況與可能因素，並說明可選處遇；避免把推論寫成定論或替個案單方面決定。

第 40 題

衡鑑報告除了個案之外，評估者須對報告內容加以保密，而下列那些情況是保密的例外？①在法律程序上爭監護權的父母之身心評估報告②自殺未遂者而做的危機評估報告③大三學生到諮商中心做的焦慮評估報告④張先生因為家庭議題而到醫院做的情緒狀態評估報告
  1. （A）②④
  2. （B）①③
  3. （C）①②
  4. （D）③④

答案：（C）

詳解與考點

正解：「保密的例外」——判準是是否有法律程序需求或迫切重大安全風險。①若已知作為法律鑑定，並經當事人授權、依法院命令或依其他法律要求提供時，監護權爭議的身心評估報告得在必要範圍內揭露；②自殺未遂者的危機評估涉及生命安全與危機處遇。兩者均屬本題所問的保密受限情況，故選 C。

A：②正確，但④僅為家庭議題下的情緒狀態評估，未見法律程序或重大安全風險，故組合錯誤。

B：①正確，但③為大三學生的一般焦慮評估，仍應受保密保護，故組合錯誤。

D：③與④皆屬一般衡鑑情境，題幹未呈現保密例外的條件，故組合錯誤。

本題考點：心理衡鑑保密例外——判準是授權、法院命令或其他法律要求，以及危及生命安全等足以限制保密的具體條件；一般焦慮或家庭議題的衡鑑，不因評估本身而失去保密。
