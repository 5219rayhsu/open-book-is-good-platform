第 1 題

在使用心理測驗前，諮商心理師應最優先了解那些重要的評估工具訊息？①測驗的發展者②測驗的出版年、月③測驗的理論取向④標準化樣本的適當性⑤測驗的信效度⑥實務考量
  1. （A）①②③⑥
  2. （B）②③④⑤
  3. （C）③④⑤⑥
  4. （D）①②④⑤

答案：（C）

詳解與考點

考點為選用測驗前的專業評估要件。正解③④⑤⑥強調理論取向、標準化樣本適當性、信效度與實務考量，這些直接決定測驗能否正確施用於該對象。陷阱在含①②的選項：發展者、出版年月屬背景資訊，雖可參考，但非「最優先」的品質判準，誤把背景當核心。

第 2 題

心理測驗是透過有系統地使用一些簡單的原則，來測量那些可以描述與理解個人的重要屬性。關於心理測驗的應用，下列何者錯誤？
  1. （A）可以參考測驗結果來決定人事的錄用
  2. （B）可以參考測驗結果來選擇適合個案的處遇方式
  3. （C）可以透過測驗結果來決定或建議個人所適合擔任的職務
  4. （D）可以透過測驗結果來決定一個人的價值

答案：（D）

詳解與考點

考點為測驗倫理與測驗的正當用途。正解D錯誤，因測驗只能描述屬性、輔助決策，不能用來判定一個人的「價值」，這違反專業倫理。陷阱在A、C：用於人事錄用、職務建議確屬合理應用，易被誤判為錯誤，但它們是測驗的正當功能。

第 3 題

「標準九分」尺度是透過什麼樣的轉換過程而產生的？
  1. （A）線性轉換
  2. （B）z分數轉換
  3. （C）T分數轉換
  4. （D）面積轉換

答案：（D）

詳解與考點

考點為標準九分（stanine）的轉換性質。正解D面積轉換（常態化轉換），因stanine把分數依常態曲線下面積劃為九段，屬非線性的常態化標準分數。陷阱在A線性轉換：T分數、z分數才是線性轉換，stanine並非單純線性，故易誤選。

第 4 題

李老師編製了一個國二學生適用的智力測驗，他以國一學生時的國文與數學成績的平均來驗證其效度，這是屬於何種類型的效度？
  1. （A）建構效度
  2. （B）內容效度
  3. （C）同時效度
  4. （D）預測效度

答案：（C）

詳解與考點

考點為同時效度與預測效度之區分，關鍵在效標與測驗分數蒐集的時間關係。正解C同時效度：以同期（或已存在、可立即取得）的學業成績作效標來驗證測驗，效標與測驗近乎同時對照。陷阱在D預測效度，預測指以測驗預測「未來」效標，本題並非預測未來表現，故非預測效度。

第 5 題

關於基準率（base rate）於臨床實務應用中的敘述，下列何者正確？
  1. （A）是指某特殊行為在臨床個案上出現的頻率
  2. （B）是指某特殊行為出現在一般群體的比率
  3. （C）是指對於個案問題的正確診斷率
  4. （D）指排除個案為某種問題的正確率

答案：（B）

詳解與考點

考點為基準率（base rate）的定義。正解B：基準率指某行為或特徵在「一般母群」中出現的比率，是判讀診斷正確性的分母基礎。陷阱在A：把出現場域限縮在「臨床個案」上，混淆了母群範圍，最易誤選。

第 6 題

對個案評估的意義與功能而言，結構化的臨床晤談已被證實是一可靠且有效的評估方法。下列何者不屬於結構化的晤談工具？
  1. （A）診斷性晤談量表（diagnostic interview schedule）
  2. （B）DSM結構式臨床會談（structured clinical interview for the DSM）
  3. （C）行為和態度檢核表（behavior and attitude checklist）
  4. （D）雷納診斷性面談（Renard diagnostic interview）

答案：（C）

詳解與考點

考點為結構化臨床晤談工具的辨識。正解C行為和態度檢核表，因檢核表屬評定/自陳量表，非具標準化題序與診斷流程的結構化晤談。陷阱在D雷納診斷性面談（Renard，DIS前身）：名稱較冷僻易被誤判為非晤談，實則是結構化晤談。

第 7 題

心理衡鑑可應用於不同的專業、問題領域和族群，下列有關心理衡鑑之敘述何者正確？
  1. （A）心理衡鑑已將個案的生活脈絡納入考量，但不考慮文化因素
  2. （B）心理衡鑑的核心是藉由持續地蒐集資料以形成或確認有關個案的推論或概念化
  3. （C）單一來源的資料，才能確保心理衡鑑的正確訊息
  4. （D）測驗分數是臨床工作者最依賴的資料來源，也是最有效的資料來源

答案：（B）

詳解與考點

考點為心理衡鑑的本質與多元資料原則。正解B：衡鑑核心是「持續蒐集資料以形成並驗證對個案的推論與概念化」。陷阱在D：把測驗分數說成最可靠來源，但衡鑑強調多來源整合，過度依賴單一測驗分數是錯誤觀念，故易誤選。

第 8 題

下列那些是為了瞭解諮商效果，於後測時較適合納入的衡鑑工具？①測量症狀的工具②具病理基礎的測量工具③個案的智力水準④因應策略
  1. （A）僅①③
  2. （B）僅②④
  3. （C）①②③④
  4. （D）僅①②④

答案：（D）

詳解與考點

考點為諮商效果後測工具的選擇。正解D（①②④）：症狀測量、病理測量、因應策略皆為可隨諮商改變的指標，適合做前後比較。陷阱在③智力水準：智力屬穩定特質，短期諮商不會改變，納入後測無意義，含③的選項即錯。

第 9 題

下列何者不是諮商中進行個案評估的目的？
  1. （A）協助確認問題所在
  2. （B）找出解決方案的可能性
  3. （C）確認諮商的有效性
  4. （D）蒐集符合初始效應的資料

答案：（D）

詳解與考點

考點為個案評估的目的。正解D屬「不是目的」：刻意蒐集符合初始效應的資料是評估偏誤來源，而非評估目的。陷阱在A、B、C皆為正當目的（確認問題、找解法、檢核成效），易因都「看似正確」而選錯方向。

第 10 題

Myers-Briggs Type Indicator人格測驗是根據下列那一個學派理論所發展出的量化人格衡鑑工具？
  1. （A）Jung分析與治療
  2. （B）情緒焦點治療
  3. （C）現實治療
  4. （D）敘事治療

答案：（A）

詳解與考點

考點為MBTI的理論根源。正解A：MBTI由Myers與Briggs依Jung的心理類型論（內外向、感知—直覺、思考—情感等）發展。陷阱在其餘三項（EFT、現實治療、敘事）皆為治療學派而非類型論基礎，與MBTI無關，但易因不熟Jung關聯而亂選。

第 11 題

如果結合三級預防的概念來選擇適當的測驗工具，下列何種測驗工具較為適合運用在初級預防之評估？
  1. （A）大學生學習與讀書策略量表
  2. （B）貝克憂鬱量表第二版
  3. （C）羅夏克測驗
  4. （D）健康、性格、習慣量表

答案：（A）

詳解與考點

考點為三級預防與測驗選擇的對應。正解A學習與讀書策略量表：初級預防針對一般族群、發展性與促進性，適用此類非病理工具。陷阱在B貝克憂鬱、C羅夏克：屬病理/臨床診斷取向，對應次級或三級預防，易誤把臨床工具放到初級。

第 12 題

關於評估會談的意圖與功能，下列何者錯誤？
  1. （A）評估會談的目的，主要是從中界定要改變的問題
  2. （B）評估會談是資料收集的過程，較不重視投契關係
  3. （C）評估會談通常也會討論將來可能進行的介入計畫
  4. （D）評估會談的最後，通常會協助個案提升其改變動機

答案：（B）

詳解與考點

考點為評估會談的功能。正解B錯誤：評估會談雖以蒐集資料為主，但仍須建立投契關係（rapport），不能「較不重視」。陷阱在A、C、D皆為會談正當功能（界定問題、討論介入、提升動機），易因找不到明顯錯處而選錯。

第 13 題

在家族治療的評估會談中，某位諮商心理師詳細詢問母親與兒子在家庭裡的平時對話內容，包括通常誰開始說話，另一個人如何回應，回應時的心情如何，最後怎麼結束話題。該諮商心理師是運用了那一種評估家庭功能的技巧？
  1. （A）聚焦
  2. （B）反映
  3. （C）調整步調
  4. （D）追蹤互動

答案：（D）

詳解與考點

考點為家族治療中評估互動歷程的技巧。正解D追蹤互動（tracking）：諮商師循序追問誰先說、如何回應、如何結束，重建家庭溝通序列與循環。陷阱在A聚焦：聚焦是集中於單一主題，與「追蹤完整互動鏈」不同，最易混淆。

第 14 題

下列那一種衡鑑會談的問句方式，最能讓個案表達自己較重要但卻不尋常的特質？
  1. （A）開放式問句
  2. （B）中度指導性問句
  3. （C）高度指導性問句
  4. （D）封閉式問句

答案：（A）

詳解與考點

考點為衡鑑問句型態與個案表達自由度。正解A開放式問句：不預設方向，最能引出個案重要卻不尋常、未被問及的特質。陷阱在B、C指導性問句與D封閉式：問句愈結構化愈限制回答範圍，難以呈現獨特特質，方向相反。

第 15 題

某公司長年以來透過能力測驗A甄選員工。該公司發現新進員工中，年終考績B以上者在能力測驗A的總分都高於250分。因此，自去年起，訂定能力測驗A總分250分為該公司錄取員工的決斷分數（cutoff score）。去年有位新進員工在能力測驗A的總分為300分，但年終考績卻不及格。此種情況屬於下列何者？
  1. （A）正確肯定（correct positive）
  2. （B）錯誤肯定（false positive）
  3. （C）正確否定（correct negative）
  4. （D）錯誤否定（false negative）

答案：（B）

詳解與考點

考點為決斷分數的命中矩陣判讀。正解B錯誤肯定（false positive）：測驗預測會通過（高於切截分）但實際效標失敗（考績不及格），即偽陽性。陷阱在D錯誤否定：偽陰性是「被刷掉卻其實會成功」，與本題方向相反，最易混淆正負方向。

第 16 題

關於貝克憂鬱量表第二版（BDI-II）的敘述，下列何者正確？
  1. （A）BDI-II包含悲傷、哭泣、失去興趣等24個評估憂鬱症狀的題項
  2. （B）BDI-II每題皆以1～4分來計分
  3. （C）BDI-II第2題（悲觀）是評估自殺風險的重要指標之一
  4. （D）依據BDI-II使用手冊的建議，總分介於10～19分為輕度憂鬱

答案：（C）

詳解與考點

考點為BDI-II的具體題項與計分。正解C：第2題悲觀是與自殺風險相關的重要指標之一。陷阱在A、B、D的數字細節皆有誤（題數為21而非24、每題0至3分而非1至4分、切截分數區間不符手冊），屬冷僻細節，把握度較低。

第 17 題

下列何者屬於情意測驗的評量範疇？
  1. （A）語文理解
  2. （B）科學性向
  3. （C）數學態度
  4. （D）表達能力

答案：（C）

詳解與考點

考點為情意（態度、興趣、價值）測驗的範疇。正解C數學態度：態度屬情意領域。陷阱在A語文理解、B科學性向、D表達能力，皆屬認知或能力（性向/成就）範疇，易把「數學」連結到認知能力而誤選其他項。

第 18 題

某國文老師對於上課安靜、守秩序的林同學印象良好，也習慣給該生較高的作文分數。這種評分問題稱為下列何者？
  1. （A）月暈偏誤（halo effect error）
  2. （B）寬大偏誤（generosity error）
  3. （C）趨中偏誤（central tendency error）
  4. （D）嚴格偏誤（severity error）

答案：（A）

詳解與考點

考點為評定誤差類型。正解A月暈效應（halo effect）：因守秩序的好印象延伸到作文評分，以單一特質概括其他。陷阱在B寬大偏誤：寬大是對「所有人」普遍給高分，本題是針對特定學生因印象牽連，故非寬大誤差。

第 19 題

對智能不足的個案最不適合使用下列何種評量方式？
  1. （A）檔案評量
  2. （B）實作評量
  3. （C）教室觀察
  4. （D）聯想式投射技術

答案：（D）

詳解與考點

考點為智能不足個案的評量方式適配。正解D聯想式投射技術最不適合：投射測驗需較高語言與抽象表達能力，智能不足者難以勝任且解釋困難。陷阱在B實作評量、C教室觀察：兩者直接觀察具體行為，反而適合，易誤選。

第 20 題

關於個案紀錄的敘述，下列何者錯誤？
  1. （A）諮商知情同意書上應該有個案或監護人的簽名
  2. （B）個案無權審視諮商心理師的個人心理治療筆記（psychotherapy notes）
  3. （C）個案的進展紀錄（progress notes）應該放進檔案資料中
  4. （D）個案有權保留受測時使用的題本

答案：（D）

詳解與考點

考點為個案紀錄與測驗材料的權利歸屬。正解D錯誤：題本屬受版權與測驗安全保護的測驗材料，個案無權保留。陷阱在B心理治療筆記：個案確實無權審視治療者的私人歷程筆記，此項為正確，易被誤當錯誤選項。

第 21 題

有關事件記錄法（event recording）的說明，下列敘述何者錯誤？
  1. （A）觀察者將行為的相關細節（次數、強度）記錄下來
  2. （B）適用於記錄出現頻率高的外顯行為
  3. （C）不適用沒有清楚的開始和結束的行為
  4. （D）難以推論行為發生的方式和原因

答案：（B）

詳解與考點

考點為事件記錄法（event recording）的適用條件。正解B錯誤：事件記錄適用於頻率「低至中」、有明確起訖的離散行為；若頻率過高則難以逐次計數，故「適用頻率高」的敘述錯誤。陷阱在C：無明確起訖的行為確實不適用，此為正確敘述，易誤判。

第 22 題

關於大聲思考（thinking aloud）的認知記錄方法，下列敘述何者錯誤？
  1. （A）個案會很自然的說出與他平時內在思考一致的想法
  2. （B）個案可能不會誠實的將每件事情都報告出來
  3. （C）個案可能只說出全部認知的一部分
  4. （D）口頭報告的思考和真正在腦中持續出現的思考可能會有差異

答案：（A）

詳解與考點

考點為大聲思考（thinking aloud）法的限制。正解A錯誤：個案不一定能自然說出與內在思考完全一致的想法，口頭報告會受篩選與失真影響。陷阱在B、C、D皆正確指出其失真與不完整，正因A把限制反向描述成優點，故為錯誤項。

第 23 題

依據心理生理衡鑑資料進行有意義的心理學解釋會遇到一些困難，下列何者是錯誤的？
  1. （A）減緩呼吸速度時會改變心臟血液的輸出
  2. （B）測量時容易出現混淆因素而導致解讀困難
  3. （C）測量儀器需有過濾系統排除噪音
  4. （D）大腦訊號判讀容易因施測者眼球活動而影響

答案：（D）

詳解與考點

考點為心理生理衡鑑解釋的困難來源。正解D錯誤：腦波判讀受干擾的典型來源是受測者本身的眼動偽跡，而非「施測者」的眼球活動，主詞錯置。陷阱在B混淆因素、C噪音過濾皆為真實困難，易因D文意近似而看漏主詞錯誤。

第 24 題

依照DSM-5的界定，假若兒童當事人的智能測驗總分FSIQ = 69，SEM（standard error of measurement）= 5，下列何者是最恰當的專業決定？
  1. （A）進行適應測驗，如果與FSIQ有1.5～2個標準差，就可以診斷為智能不足
  2. （B）進行適應測驗，至少一個適應領域是受損的，就可以診斷為智能不足
  3. （C）進行詳細心理社會會談，再判斷所需的進一步評估
  4. （D）進行成就測驗，如果與FSIQ有1.5～2個標準差，就可以診斷為學習障礙

答案：（C）

詳解與考點

考點為DSM-5智能不足的診斷流程與SEM的運用。正解C：FSIQ=69含測量誤差，分數帶跨越70切點，宜先做詳細心理社會會談再決定後續評估，不可僅憑單一分數定論。陷阱在A、B：以固定標準差或單一適應領域受損即下診斷，過度機械化，誤解DSM-5的臨床判斷原則。

第 25 題

下列四種人格測驗，何者是透過因素分析法編製而成？
  1. （A）健康、性格、習慣量表（Health, Personality, and Habit Test, HPH）
  2. （B）明尼蘇答多相人格測驗（Minnesota Muliphasic Personality Inventory-2, MMPI-2）
  3. （C）艾森克人格量表第二版（Eysenck Personality Questionnaire-II, EPQ-II）
  4. （D）梅－布二氏型態量表（Myers-Briggs Type Indicator, MBTI）

答案：（C）

詳解與考點

考點為人格測驗的編製方法。正解C艾森克人格量表（EPQ）：Eysenck以因素分析萃取E、N、P等向度。陷阱在B MMPI-2：MMPI採實證效標（經驗）取向編製而非因素分析，最易與因素分析法混淆而誤選。

第 26 題

有關主題統覺測驗的實施，下列何者正確？
  1. （A）施測時20張卡片應一一呈現，個案說完20個故事
  2. （B）個案需將20張卡片串連成一個主題故事
  3. （C）依個案呈現的問題，建議選擇8～12張卡片施測
  4. （D）個案應簡單扼要陳述故事，每張卡片限時3分鐘

答案：（C）

詳解與考點

考點為主題統覺測驗（TAT）的實施方式。正解C：實務常依個案問題挑選約8至12張卡片施測，並非全用。陷阱在A：誤以為固定一一呈現全部20張並說滿20個故事，過於機械化，與彈性選卡的臨床做法不符，最易誤選。

第 27 題

關於兒童的人格衡鑑，下列做法何者正確？①不只是測驗的解釋而已，還需要評估學校，家庭等環境狀況②兒童的人格發展尚不穩定，人格特質隨時間而改變的可能性大③兒童的年齡尚小無法直接評估，所以必須依賴他人觀察的客觀資料④兒童衡鑑報告為了教育需要，最好陳述其需改善之缺點
  1. （A）①②
  2. （B）②③
  3. （C）①③
  4. （D）②④

答案：（A）

詳解與考點

考點為兒童人格衡鑑的正確做法。正解A（①②）：需納入學校家庭等環境脈絡，且兒童人格尚未穩定、隨時間變動大。陷阱在③④：③否定可直接評估兒童、④只陳述缺點，皆違反衡鑑原則（兒童可直接評估、報告應兼顧優勢），含③④即錯。

第 28 題

我國在《身心障礙及資賦優異學生鑑定辦法》中，對學習障礙的鑑定準則，下列何者正確？
  1. （A）智力正常或在正常程度以上，且在特定領域的學習表現有顯著困難者
  2. （B）個人內在與外在能力皆有顯著差異者
  3. （C）任一能力表現有顯著困難，但能透過學習輔導而顯著改善者
  4. （D）專家學者、指導教師與家長皆可推薦

答案：（A）

詳解與考點

考點為《身心障礙及資賦優異學生鑑定辦法》學習障礙準則。正解A：智力正常或以上，且特定學習領域有顯著困難。陷阱在B「內在與外在能力皆有差異」：學障準則強調「個人內在能力顯著差異」，外在差異敘述不符法規用語，易誤選。

第 29 題

關於檔案評量法的負面評價，下列敘述何者錯誤？
  1. （A）評量歷程過於耗時
  2. （B）所需花費的時間可能比其他評量方式多
  3. （C）施測計分複雜繁瑣
  4. （D）評量易流於主觀

答案：（C）

詳解與考點

考點為檔案評量（portfolio）的限制。正解C錯誤：檔案評量的問題在耗時、主觀，而非「施測計分複雜繁瑣」（後者較像標準化測驗的特性）。陷阱在A、B耗時與D主觀皆為檔案評量公認缺點，C把標準化測驗特性誤套到檔案評量上。

第 30 題

若一個測量標準誤為10的生涯測驗，小花測驗結果得到60分，下列何者最接近小花95%的信賴區間分數？
  1. （A）(55.25, 64.75)
  2. （B）(50.50, 69.50)
  3. （C）(50.25, 69.75)
  4. （D）(40.40, 79.60)

答案：（D）

詳解與考點

本題考測量標準誤（SEM）與信賴區間的計算。95% 信賴區間約為「分數 ± 1.96 × SEM」，常以 ±2 個 SEM 近似。本題 SEM = 10、得分 = 60，精確計算為 60 ± 1.96 × 10 = 60 ± 19.6，即（40.40, 79.60），故 (D) 最接近，正確。其餘選項對應的並非 95% 區間：(A)（55.25, 64.75）為 ±4.75，約等於 ±0.475 個 SEM，遠太窄；(B)（50.50, 69.50）為 ±9.5，僅約 ±0.95 個 SEM，相當於約 68% 信賴水準（±1 SEM）而非 95%；(C)（50.25, 69.75）為 ±9.75，同樣只約 ±1 SEM，亦非 95% 區間。唯有 (D) 的寬度（±19.6）對應 1.96 個 SEM，符合 95% 信賴區間，故選 D。

第 31 題

莉莉表示自己想要從事機械工程師的工作，因為這個工作能夠發揮自己的所長。根據工作調適理論（TWA），莉莉這個想法是屬於那個工作價值觀？
  1. （A）成就感（achievement）
  2. （B）權力（power）
  3. （C）利他（altruism）
  4. （D）舒適（comfort）

答案：（A）

詳解與考點

考點為工作調適理論（TWA）的工作價值觀分類。正解A成就感（achievement）：強調「發揮所長、運用能力」即對應成就向度。陷阱在D舒適：舒適指工作環境與待遇的安適，與「發揮能力」無關，但易因不熟TWA六大價值而混淆。

第 32 題

王同學在工作氣質測驗的部分測驗結果如下：督導性的原始分數為36分（對照男性常模樣本，該生在此面向之百分等級為90，上下一個測量標準誤的百分等級為94與83）；說服性的原始分數為39分（對照男性常模樣本，該生在此面向之百分等級為94，上下一個測量標準誤的百分等級為97與90）。假設督導性與說服性分測驗的測量標準誤皆為3分，下列何者正確？
  1. （A）該生督導性的真實分數約有68%機率會落在29～40分之間
  2. （B）該生督導性的真實分數約有95%機率會落在34～46分之間
  3. （C）該生說服性的真實分數約有68%機率會落在36～42分之間
  4. （D）比較該生分測驗的側面圖，可解釋該生說服性工作氣質高於督導性工作氣質

答案：（C）

詳解與考點

考點為以測量標準誤推估真實分數的信賴區間。正解C：±1個SEM對應約68%，說服性39±3得36～42分，正確。陷阱在A、B：把督導性原始分搭配錯誤的SEM倍數或機率（如68%卻用約2個SEM寬度），混淆68%與95%對應的SEM倍數而誤選。

第 33 題

DSM-5鬱症（major depressive disorder）的診斷準則中，至少要包括兩個症狀的其中一項，這兩個症狀是「憂鬱情緒」和下列何者？
  1. （A）幾乎每天失眠或嗜睡
  2. （B）對幾乎所有事情失去興趣或愉悅感
  3. （C）非刻意減（增重）地體重明顯減輕或增加
  4. （D）幾乎每天自我感到無價值感

答案：（B）

詳解與考點

考點為DSM-5鬱症的兩大核心症狀之一。正解B：診斷需至少含「憂鬱情緒」或「對幾乎所有活動失去興趣或愉悅（anhedonia）」其一。陷阱在A失眠/嗜睡、C體重變化：這些屬其餘附加症狀而非兩大核心之一，易把一般症狀誤當核心。

第 34 題

下列那種型式的測驗最需要留意受測者偽裝差（faking bad）的答案？
  1. （A）興趣測驗
  2. （B）成就測驗
  3. （C）人格測驗
  4. （D）性向測驗

答案：（C）

詳解與考點

考點為偽裝差（faking bad，誇大病態）最需防範的測驗類型。正解C人格測驗：人格/臨床量表答案無對錯，受測者易為某目的誇大症狀，故設效度量尺防偽。陷阱在B成就測驗：成就有客觀對錯，偽裝差較無意義，最易因不熟faking概念誤選。

第 35 題

Selye所提出的身體對壓力之反應階段，不包括下列何者？
  1. （A）警訊（alarm）
  2. （B）衰竭（exhustion）
  3. （C）適應（adaption）
  4. （D）退化（regeression）

答案：（D）

詳解與考點

考點為Selye一般適應症候群（GAS）三階段。正解D退化不屬其中：GAS為警覺（alarm）、抗拒/適應（resistance）、衰竭（exhaustion）。陷阱在C適應：抗拒期亦稱適應期，屬正確階段，易把同義的「適應」誤判為非階段而選錯。

第 36 題

依據專業倫理守則，下列何者不是諮商心理師在撰寫心理評估與心理衡鑑報告時之要求？
  1. （A）計算評估工具間的信效度
  2. （B）考慮個案的個別差異
  3. （C）考量參照基準
  4. （D）考量評估工具的特性

答案：（A）

詳解與考點

考點為撰寫衡鑑報告的倫理要求。正解A屬「非要求」：諮商師應「使用」並「說明」工具的信效度，而非自行「計算工具間的信效度」，後者是測驗編製者的工作。陷阱在B、C、D（個別差異、參照基準、工具特性）皆為報告應考量之事項，易誤選。

第 37 題

為了研究目的所做的衡鑑，比較不會涉及受試者的倫理議題為下列何者？
  1. （A）知後同意
  2. （B）隱私權
  3. （C）保密
  4. （D）衡鑑工具的效度

答案：（D）

詳解與考點

考點為研究目的衡鑑涉及的倫理議題。正解D衡鑑工具的效度：效度屬測驗的「品質/方法學」議題，較不屬受試者「保護」的倫理範疇。陷阱在A知後同意、B隱私、C保密皆直接涉及受試者權益保護，是核心倫理議題，易誤選。

第 38 題

關於衡鑑過程中，標籤化對個案的負面影響，下列何者錯誤？
  1. （A）個案會利用標籤化逃避自己的行為
  2. （B）個案會因為怕標籤化而不自覺的揭露個人的訊息
  3. （C）標籤化可能限制了個案個人的發展
  4. （D）個案透過標籤化的預期角色會產生自我驗證的預言

答案：（B）

詳解與考點

考點為標籤化（labeling）對個案的負面影響。正解B錯誤：標籤化通常使個案「不敢/減少」揭露，而非「因怕標籤而不自覺揭露」，敘述自相矛盾。陷阱在D自我應驗預言：標籤化引發自我驗證確為真實負面影響，此項正確，易誤判為錯。

第 39 題

小妍疑似患有憂鬱症，諮商心理師評估後要撰寫「個案取向」的心理衡鑑報告給她參考，下列內容何者最恰當？
  1. （A）個案憂鬱的可能壓力源與目前呈現的狀態的關聯、可運用之治療方式的選擇
  2. （B）個案目前處於憂鬱狀態，不適合工作，建議在家休養一段時間
  3. （C）個案的憂鬱症來自工作壓力及人際關係，建議心理諮商
  4. （D）個案只是心情不佳，未達憂鬱症程度，只要心理諮商就好

答案：（A）

詳解與考點

考點為「個案取向」衡鑑報告的撰寫重點，即以利於個案理解與運用為目的。正解A：呈現可能壓力源與當前狀態的關聯及可選治療方式，兼顧理解與賦能。陷阱在B、C：直接下「不適合工作」「就是工作壓力」等武斷結論，未保留彈性與個案參與，較不恰當。

第 40 題

衡鑑報告除了個案之外，評估者須對報告內容加以保密，而下列那些情況是保密的例外？①在法律程序上爭監護權的父母之身心評估報告②自殺未遂者而做的危機評估報告③大三學生到諮商中心做的焦慮評估報告④張先生因為家庭議題而到醫院做的情緒狀態評估報告
  1. （A）②④
  2. （B）①③
  3. （C）①②
  4. （D）③④

答案：（C）

詳解與考點

考點為保密例外的判斷，核心是涉及法律程序或重大安全風險。正解C（①②）：①爭監護權的法律程序、②自殺未遂的危機評估，皆屬保密例外。陷阱在③④：③一般焦慮評估、④家庭議題情緒評估屬常規諮商，不構成例外，含③或④即錯。
