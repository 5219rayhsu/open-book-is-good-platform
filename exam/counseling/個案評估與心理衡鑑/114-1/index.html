第 1 題

社會適應表現檢核表上的智能障礙學生組常模為下列那一類常模？
  1. （A）特殊團體常模
  2. （B）鑑定常模
  3. （C）地區常模
  4. （D）分級常模

答案：（A）

詳解與考點

正解：「智能障礙學生組常模」——常模若專為某一特定群體建立，用來與同類群體比較，即為特殊團體常模；智能障礙學生組屬特定群體，故選 A。

B：鑑定常模著眼於鑑定目的或標準，題幹的分類依據是受試群體特性，故非答案。

C：地區常模依地理區域建立，題幹未以所在地區區分，故非答案。

D：分級常模依年級或年齡分級建立，題幹以智能障礙學生身分分組，故非答案。

本題考點：常模的類型——判準是「依何種母群或分組基礎建立對照」；依特殊身分群體為特殊團體常模，依地區為地區常模，依年級或年齡為分級常模。

第 2 題

下列何種測驗最易受社會期望（social desirability）的影響？
  1. （A）成就測驗
  2. （B）性向測驗
  3. （C）自陳測驗
  4. （D）投射測驗

答案：（C）

詳解與考點

正解：「社會期望」——自陳測驗由受試者直接報告自己的特質或行為，最可能為呈現社會期待的形象而美化答案，故選 C。

A：成就測驗多有較明確的學習內容與正確答案，社會期望較難直接改變作答正誤，故非答案。

B：性向測驗通常評量能力潛能或表現傾向，亦較不以自我形象陳述作答，故非答案。

D：投射測驗使用較模糊的刺激，受試者較難判定何種回答最符合社會期待，社會期望影響相對較低，故非答案。這是最強誘答，因為投射測驗同樣涉及人格，然而其間接作答形式反而不易直接迎合理想形象。

本題考點：社會期望效應——判準是「受試者能否看出理想形象，並直接控制自我呈現」；自陳測驗的可控性最高，投射測驗因刺激模糊而相對較低。

第 3 題

關於效標參照的心理測驗，下列敘述何者正確？
  1. （A）較不適用於教育情境
  2. （B）可用來評量個案的進步狀況
  3. （C）重點在了解個案在團體中的表現
  4. （D）無法提供切截分數的相關資訊

答案：（B）

詳解與考點

正解：「效標參照」——效標參照測驗以預先設定的絕對標準判斷是否達成目標，可用於檢視當事人是否精熟及其進步狀況，故選 B。

A：效標參照測驗適用於教育情境，例如判斷是否達成某項學習目標，故非答案。

C：了解當事人在團體中的相對位置，是常模參照測驗的重點，非效標參照，故非答案。這是最強誘答，因為兩者都使用測驗分數；關鍵在效標參照比較的是既定標準，不是他人表現。

D：效標參照測驗可提供切截分數相關資訊，以區分是否達到標準，故非答案。

本題考點：效標參照測驗——判準是「以既定能力或精熟標準判定表現，並可設定切截分數」；若比較個人在團體中的相對排名，則是常模參照。

第 4 題

某企業主管有鑑於社會自殺事件頻傳，擬邀請諮商心理師協助防治工作，諮商心理師以心理測驗作為篩檢工具，對員工進行施測，主要可達到心理測驗的那一項功能？
  1. （A）評估
  2. （B）預測
  3. （C）診斷
  4. （D）治療

答案：（A）

詳解與考點

正解：「對員工進行施測」與「篩檢工具」——對尚未個別判定問題的全體員工進行初步辨識，觸發的是心理測驗的評估與篩選功能。以測驗篩出可能需要進一步關注的自殺風險者，屬大範圍的評估，故選 A。

B：預測是依目前資料推估未來表現或結果；本題的目的在辨識目前可能有風險的員工，非推估其未來表現。

C：診斷須結合個別資料與臨床判斷，確認特定問題；篩檢自殺風險看似在「診斷」，但全員初篩仍是評估層次，不能直接當作個別診斷。

D：治療是介入與改善問題的歷程，不是心理測驗本身的功能。

本題考點：心理測驗功能——判準是施測目的與對象範圍；對群體作初步辨識為評估／篩檢，推估未來為預測，結合臨床資料確認個別問題才是診斷。

第 5 題

某位個案在初步會談中對諮商心理師表示：「你不覺得我的前男友非常過分嗎？他竟然會因為我的外貌，就決定要分手？」若以Brickman等人的理論來評估，個案對進行諮商的準備度和期待，最可能屬於下列那一種模式？
  1. （A）道德模式（moral model）：對自己的問題負責，也為解決問題的方法負責
  2. （B）補償模式（compensatory model）：不會對自己的問題負責，認為應該由情境來負責
  3. （C）啟蒙模式（enlightenment model）：對自己的問題負責，但不能為問題的解法方式負責
  4. （D）醫學模式（medical model）：既不能對問題且不能對解決方法負責

答案：（B）

詳解與考點

正解：個案將分手歸因於「前男友」與外貌條件，表示她不把問題歸為自己的責任；依 Brickman 等人的責任歸因模式，這正是補償模式對問題責任的定位。補償模式認為個人不必為問題負責，但仍可為解決方法負責，故選 B。

A：道德模式認為個人既要對問題負責，也要對解決方法負責；題述明顯將問題歸咎於外在情境，不符此模式。

C：啟蒙模式是個人對問題負責，但不能單靠自己為解法負責，須接受他人協助；與題幹的不負問題責任不同。

D：醫學模式認為個人既不對問題負責，也不對解決方法負責；題幹只呈現對問題的外歸因，不能因此推成兩者皆不負責。

本題考點：Brickman 等人的責任歸因模式——判準是分開判斷「誰對問題負責」與「誰對解決方法負責」；不負問題責任而負解決責任為補償模式，兩者皆不負責才是醫學模式。

第 6 題

從自殺線索和危機程度評估個案的自殺風險時，下列敘述何者最正確？
  1. （A）個案說了很多次「死了事情就解決了、解脫了」，「死」已成為他的口頭禪，他不會有自殺危機
  2. （B）個案說：「我不知道活著有什麼用，但只要想到我死亡，我爸媽他們心理上會很難過，還要面對親友的眼光」，個案尚有牽絆，自殺風險相對較低
  3. （C）個案說：「我離開了，小黑（小狗）就沒人照顧了，我把牠送人了；我也把籃球送給我好朋友了」，個案可能想出去散心，不用擔心
  4. （D）有過自殺經驗的個案，他是以自我傷害來得到關注，會再自我傷害，但危及生命的機率不大，可以不用做自殺評估

答案：（B）

詳解與考點

正解：個案想到死亡時仍牽掛父母的痛苦與社會壓力——這些與重要他人的連結是自殺風險評估中的保護因子。雖不能據此排除風險，但相較於沒有牽絆者，其立即自殺風險相對較低，故選 B。

A：反覆把死亡說成解脫是需進一步評估的自殺意念線索，不能因它成為口頭禪便認定沒有危機。

C：送走小狗與籃球等重要物品，可能是在安排後事或切斷牽絆，是高風險訊號；把它解讀成單純散心最危險。

D：既往自殺經驗是重要風險因子；即使行為有求助或尋求關注成分，仍可能危及生命，必須進行自殺風險評估與危機處遇。

本題考點：自殺風險評估——判準是同時辨識保護因子與警訊；重要關係牽絆可相對降低立即風險，死亡意念、安排後事與既往自殺經驗則均不可輕忽。

第 7 題

在評估個案的主觀性痛苦時，下列敘述何者錯誤？
  1. （A）監控個案主觀性痛苦程度的最好方式之一是時常回顧晤談資料，包括行為觀察和相關病史
  2. （B）個案功能性缺損和主觀性痛苦最具相關
  3. （C）主觀性痛苦可能受環境性的事件所影響，常常會有變化
  4. （D）主觀性痛苦低的個案大半是來自非自願的轉介個案

答案：（B）

詳解與考點

正解：「主觀性痛苦」——此概念問的是個案自己感受的困擾程度，不可直接以外在功能受損替代。功能性缺損與主觀性痛苦未必高度一致：有人功能受損明顯卻不感痛苦，也有人功能尚可卻十分煎熬，故 B 錯誤，為應選項。

A：時常回顧晤談資料、行為觀察與相關病史，有助於持續掌握個案主觀痛苦的變化，敘述正確，故非答案。

C：主觀性痛苦會受環境事件影響而起伏，須隨歷程反覆評估，敘述正確，故非答案。

D：非自願轉介個案常未自覺或未承認自身困擾，主觀性痛苦可能較低，敘述正確，故非答案。

本題考點：主觀性痛苦的評估——判準是以個案主觀感受及其歷程資料為核心；功能性缺損可作參考，但不能與主觀痛苦畫成必然對應。

第 8 題

依據個人史和臨床觀察評估個案的因應模式，下列何者不是個案將問題「內化（internalization）」的指標？
  1. （A）理智化
  2. （B）尋求刺激
  3. （C）淡化問題
  4. （D）與自律神經系統有關的身體化作用

答案：（B）

詳解與考點

正解：「不是」與「內化」——內化是將困擾轉向自身、以內在心理或身體症狀呈現；尋求刺激則是以衝動、向外活動處理困擾，屬外化傾向，故選 B。

A：理智化藉由抽象分析隔開情緒，主要在個人內在處理困擾，可作為內化指標。

C：淡化問題看似是否認或逃避，但仍是把痛苦內收、不對外表現為衝動行動的方式，屬內化指標。

D：與自律神經系統有關的身體化作用，是心理困擾以身體反應呈現，屬內化指標。

本題考點：內化與外化因應模式——判準是困擾的表達方向；轉為內在認知、情緒或身體症狀為內化，衝動行動或向外尋求刺激為外化。

第 9 題

諮商心理師以Lazarus的BASIC－ID模式進行評估時，發現個案的問題癥結在C面向上，下列那一種處遇較能回應其問題？
  1. （A）行為改變技術
  2. （B）精神分析法
  3. （C）理情行為治療法
  4. （D）生物性治療法

答案：（C）

詳解與考點

正解：BASIC-ID 的「C」——C 代表 Cognition（認知），問題癥結在此面向時，處遇應直接處理想法與信念。理情行為治療法以辨識與修正非理性信念為核心，最能回應認知問題，故選 C。

A：行為改變技術主要對應 B（Behavior，行為）面向，不是 C 面向。

B：精神分析法不以 BASIC-ID 各字母作一對一處遇配對，本項不是認知面向最直接的選擇。

D：生物性治療法主要對應 D（Drugs/biology，生物與藥物）面向；B 與 D 都各自對應其他字母，是最易混淆之處。

本題考點：Lazarus BASIC-ID 多重模式——判準是先將字母還原為問題面向，再選對應處遇；C 是認知，適合處理非理性信念的理情行為治療法。

第 10 題

在評估會談的策略選擇上，下列的敘述何者錯誤？
  1. （A）一般而言，會談順序應該以指導性會談開始，而後以非指導性會談結束
  2. （B）會談中使用催化技巧可以鼓勵個案針對問題進行回應
  3. （C）一般來說，會談中會避免頻繁使用「為什麼」的問句
  4. （D）會談者可以透過眼神接觸、表情或肢體動作等，傳達對個案的關注

答案：（A）

詳解與考點

正解：「會談順序」——評估會談通常先以開放、非指導性的方式建立關係並廣泛蒐集資料，後段才逐步轉為指導性與聚焦式澄清。A 將此順序顛倒，故為應選項。

B：催化技巧能鼓勵個案針對問題進一步回應與探索，敘述正確，故非答案。

C：頻繁追問「為什麼」容易使個案感到被質疑或防衛，一般會避免過度使用，敘述正確，故非答案。

D：眼神接觸、表情與肢體動作可傳達關注，是重要的非語言會談技巧，敘述正確，故非答案。

本題考點：評估會談策略——判準是先開放後聚焦；前段以非指導性建立關係與蒐集脈絡，後段才以指導性問題澄清特定資訊。

第 11 題

經驗取向（experiential approach）的諮商心理師，若在個別諮商中欲評估原生家庭經驗對個案行為的影響，通常會採取那一種會談形式？
  1. （A）非指導性會談
  2. （B）指導性會談
  3. （C）結構性會談
  4. （D）不會主動詢問原生家庭經驗

答案：（A）

詳解與考點

正解：「經驗取向」與「原生家庭經驗」——經驗取向重視個案主觀經驗及當下感受的自然流露，評估時會提供開放空間讓個案敘說其家庭脈絡。非指導性會談最符合此取向，故選 A。

B：指導性會談由會談者以問題與方向帶領資料蒐集，較不符合經驗取向強調個案經驗自然展開的精神。

C：結構性會談依預定題目與順序進行，彈性較低，較不適合作為此取向的典型形式。

D：經驗取向不是忽略原生家庭經驗，而是以開放方式探索；「不會主動詢問」把非指導性誤解為完全不探索。

本題考點：經驗取向會談——判準是會談是否優先容納個案的主觀感受與自發敘說；探索仍可進行，但不以預設題目強力主導。

第 12 題

關於評估會談（assessment interview）和一般閒聊的差異，下列敘述何者最正確？
  1. （A）因受過訓練的會談員較具同理，在評估會談中會儘量避免碰觸敏感話題
  2. （B）為了多瞭解個案，所以評估會談不會設定主題或會談方向
  3. （C）有較多的自由和彈性，在評估會談中由個案來主導想談的主題以及決定何時結束
  4. （D）評估會談較能夠和初次見面的個案在短時間內建立專業關係

答案：（D）

詳解與考點

正解：「評估會談和一般閒聊的差異」——評估會談具有明確目的、專業角色與會談技巧，可與初次見面的個案在較短時間建立工作關係。D 正確，故選 D。

A：同理不等於避開敏感議題；在適當關係與方式下，評估會談仍須碰觸與問題相關的敏感資訊。

B：評估會談會依評估目的設定主題與方向，不是為了多瞭解個案便毫無焦點。

C：評估會談可保有彈性，但會談者仍須維持專業架構、掌握方向與結束時機；把彈性當作個案完全主導，是最強誘答。

本題考點：評估會談的專業性——判準是有目的、有架構且具彈性；它不同於閒聊之處，在於會談者能以專業關係與技巧聚焦蒐集資料。

第 13 題

有關貝克憂鬱量表的使用，下列何者最適當？
  1. （A）適用於治療期間或治療後施測，作為理解治療效果的工具
  2. （B）初談時，請個案自行施測作為分類個案的工具
  3. （C）施測時應強調個案以當天的狀態來回答題目
  4. （D）有大量文獻佐證信效度，能作為臨床診斷工具

答案：（A）

詳解與考點

正解：「貝克憂鬱量表的使用」——BDI 是自陳量表，適合重複施測以追蹤憂鬱症狀與理解治療效果。治療期間或治療後施測可比較變化，故 A 最適當。

B：初談可將量表作為初步資訊，但不能單憑其結果把個案分類；量表分數須與會談及其他資料整合判讀。

C：施測須依量表規定的作答時間範圍回答，不能一概要求只依當天狀態作答，故不適當。

D：即使有信效度研究支持，BDI 仍是評估與篩檢工具，不能取代臨床診斷；「信效度佳」看似足以診斷，錯在混淆量表評估與診斷晤談。

本題考點：BDI 的用途——判準是以自陳症狀量表追蹤程度與改變，不以單一分數下臨床診斷；施測與解釋須依工具規範並整合其他資料。

第 14 題

有關第二版明尼蘇答多相人格測驗（MMPI-2）的發展與編製，下列說明何者最為適當？
  1. （A）根據精神疾病理論來編寫題項，以提高題項間的內部一致性
  2. （B）根據題項在臨床與對照樣本之差異表現來選題
  3. （C）透過心理專業人員組成的審查小組，來選題並歸類
  4. （D）藉由搜集數據進行項目分析來檢視題項在所屬量表的適當性

答案：（B）

詳解與考點

正解：MMPI-2 的「發展與編製」——其核心是實證效標法，依題項在臨床樣本與對照樣本的作答差異來選題，而非先由理論推導題意。B 正確，故選 B。

A：根據精神疾病理論編寫題項、追求題項間內部一致性，是理論導向的作法，不是 MMPI-2 的實證效標法。

C：由心理專業人員組成審查小組選題與歸類，主要是內容效度或邏輯內容取向的作法。

D：以項目分析檢視題項是否適合所屬量表，著重量表內部特性；MMPI-2 的編製判準在臨床組與對照組的差異表現。

本題考點：MMPI-2 編製法——判準是題項能否區分臨床與對照樣本；依實證差異選題為實證效標法，不能誤認為理論建構或專家內容審查。

第 15 題

由於許多的文化因素均可能會影響智力測驗對於不同文化或不同族的公平性與正確性，因此有學者倡議應該編製所謂的「智力文化公平測驗（culture free test）」。下列何者不是編製文化公平測驗的常見做法？
  1. （A）測驗材料主要是非語文，並包含各種文化團體均熟悉的圖案或作業活動
  2. （B）縮短測驗的時間，以減除速度因素的影響
  3. （C）考量編製適合該文化的母語測驗版本
  4. （D）檢視測驗中的構念在不同文化的對等性

答案：（B）

詳解與考點

正解：「不是文化公平測驗的常見做法」——文化公平著眼於減少不同文化背景在語言、經驗與構念上的不對等。（B）若要減少速度因素，應給予充足作答時間或降低時限壓力；縮短測驗時間反而使處理速度更影響分數，故為應選項。

A：採主要為非語文、且不同文化團體皆熟悉的材料，可降低特定語言與文化經驗的影響，敘述正確，故非答案。

C：考量編製適合該文化的母語版本，可減少語言造成的理解差異，敘述正確，故非答案。

D：檢視構念在不同文化間是否對等，是文化公平的重要工作，敘述正確，故非答案。

本題考點：文化公平測驗——判準是降低語言、文化經驗與構念不對等所造成的偏差；非語文材料、母語版本與跨文化構念對等性均直接相關，縮短時限反而會放大速度對分數的影響。

  4. （D）簡化的評估流程

第 17 題

  2. （B）運用會談資料進行診斷
  3. （C）不屬於心理評估的範圍
  4. （D）運用客觀測驗資料進行問題描述

  1. （A）僅①②

  1. （A）敘事紀錄法（narrative recording）
  2. （B）時距紀錄法（interval recording）
  3. （C）評比紀錄法（rating recording）
  4. （D）自由觀察法（free recording）

答案：（B）

詳解與考點

正解：「每 5 分鐘為單位」並記錄該時段內是否出現分心行為——固定時間區段是時距紀錄法的判準。每格劃記的是該時距內行為有無出現，故選 B。

C：評比紀錄法是依預定等級評定行為強度、頻率或程度，本題未要求等級評分。

D：自由觀察法沒有固定的觀察時段或結構；本題明確以每 5 分鐘為單位。

本題考點：行為衡鑑紀錄法——判準是觀察單位；固定時段內記錄行為有無為時距紀錄，逐次計數為事件紀錄，測量等級則為評比紀錄。

A：MBTI 依類型論區分人格偏好，不是以因素分析建立人格向度，故不選。

B：CPI-III 採實證效標法選題，並非以因素分析建構人格向度，故不選。

C：MMPI-2 同樣採實證效標法選題；它題數多、用途廣，容易使人誤以為必由因素分析建構，但核心方法不同，故不選。

本題考點：人格測驗的建構方法——判準是 NEO-PI-R 對應因素分析與五大人格；MBTI 對應類型論；CPI-III、MMPI-2 對應實證效標法。

第 27 題

有關性向測驗與成就測驗的敘述，下列何者正確？
  1. （A）性向測驗取材範圍較廣泛普遍，成就測驗取材在控制和限定下的學習結果
  2. （B）性向測驗強調習得的知識技能的水準，成就測驗強調學習新事物的能力
  3. （C）性向測驗測量已發展的能力，成就測驗測量未發展的能力
  4. （D）性向測驗重視同時效度，成就測驗強調預測效度

答案：（A）

詳解與考點

正解：「性向測驗與成就測驗」的取材範圍——判準是性向測驗用目前能力預測未來學習或表現，成就測驗檢核限定教學範圍內已習得的結果。A 正確對比兩者取材性質，故選 A。

B：強調學習新事物能力的是性向測驗，強調已習得知識技能水準的是成就測驗，本項將兩者顛倒，故不選。

C：成就測驗測量已發展、已習得的能力；性向測驗也常以目前能力預測未來表現，不能簡化為測量未發展能力，故不選。

D：性向測驗特別重視預測效度，成就測驗較重內容效度與同時效度，本項對應顛倒，故不選。

本題考點：性向測驗與成就測驗——判準是性向看較廣泛的潛能與預測效度；成就看限定學習內容的已習得表現及內容效度。

第 28 題

某類學習評量方式之目的在於瞭解學生認知改變的情形。在施測、評量的過程中，可能調整施測程序或工具，儘量協助受測者充分回答、展現所有的能力。這一種學習的評量方式稱為下列何者？
  1. （A）紙筆評量（paper and pencil assessment）
  2. （B）檔案評量（portfolio assessment）
  3. （C）真實評量（authentic assessment）
  4. （D）動態評量（dynamic assessment）

答案：（D）

詳解與考點

正解：「施測過程可能調整程序或工具」及「協助受測者充分展現能力」——這觸發動態評量在測量中介入、觀察可改變性的作法。D 的動態評量旨在瞭解認知改變，施測中可調整程序或提供中介協助，呼應近側發展區，故選 D。

A：紙筆評量主要以固定題目與作答蒐集表現，不以施測中調整和中介協助為核心，故不選。

B：檔案評量重視累積作品與學習歷程，非在施測中提供協助以檢視可改變性，故不選。

C：真實評量重視貼近真實情境的任務表現；它看似也重視能力展現，但題幹決定性的線索是「施測中調整與協助」，故不選。

本題考點：動態評量——判準是「測中提供中介協助，再看認知改變與可改變性」；若強調固定紙筆、作品累積或真實任務，分別屬其他評量方式。

  2. （B）生涯發展上的選擇議題，需要生涯諮商
  3. （C）情境因素造成的心理焦慮，需要放鬆訓練
  4. （D）可能是依賴型人格造成生涯困境，需要探討其依附關係

本題考點：生涯議題的個案概念化——判準是先辨認困擾是否由生涯選擇與發展任務觸發；未有持續、跨情境證據時，不將正常的情境性焦慮診斷化。

  2. （B）具有良好的信度與效度

  1. （A）僅在結果顯示高度危險時與個案討論
  2. （B）應就評估結果，適度地與個案、家屬進行討論及後續處遇
  3. （C）評估結果應保密，不應與個案或其他人分享
  4. （D）如果結果顯示低危險，則不需要進行任何後續行動

B：個案可參與知後同意與表達需求，但不宜由其決定哪些測驗問題可詢問，以免破壞衡鑑目的與標準化，故不選。

C：智力測驗中提供提示看似能減少挫折，卻會改變標準化施測條件與分數意義，故不選。

本題考點：心理衡鑑實施倫理——判準是尊重個案意願並維持測驗標準化、保密和安全；口譯須受明確保密與不提示指示，不能自行改變題目或協助作答。

第 39 題

為了進行心理衡鑑，諮商心理師應該要在事前取得個案的知情同意（informed consent）之書面文件，下列那一項較不需列入同意書的內容？
  1. （A）衡鑑資訊的保密原則及例外情況
  2. （B）衡鑑的流程與程序
  3. （C）衡鑑所採用的測驗及分量尺類型
  4. （D）衡鑑取得資料的可能用途

答案：（C）

詳解與考點

正解：「較不需列入知情同意書」——判準是同意書讓個案理解衡鑑的程序、保密限制與資料用途，而不必揭露影響測驗安全的過細測驗內容。C 的具體測驗及分量尺類型較不需列入，故選 C。

A：衡鑑資訊的保密原則及例外直接關係個案權益，應列入，故不選。

B：衡鑑流程與程序有助個案作出知後決定，應列入，故不選。

D：資料可能用途影響個案是否同意接受衡鑑，應列入，故不選。

本題考點：心理衡鑑的知情同意——判準是說明流程、保密及例外、資料用途與個案權益；具體分量尺清單不是必要重點，避免過度揭露測驗內容而影響測驗安全。

第 40 題

在心理衡鑑過程中，需要特別注意相關的倫理議題，下列敘述何者錯誤？
  1. （A）在衡鑑過程中，可能會取得一個人不自覺或是不欲人知的訊息
  2. （B）即使諮商心理師提供了清楚的訊息，個案也對衡鑑的程序表示同意，也可能會有無法預見的狀況發生
  3. （C）針對衡鑑過程中所取得的資訊，諮商心理師有權力決定測驗資料如何被使用
  4. （D）在衡鑑過程中，諮商心理師需有敏感度去察覺可能會引發個案焦慮的主題

答案：（C）

詳解與考點

正解：「何者錯誤」與「誰決定測驗資料如何使用」——判準是衡鑑資料使用受知情同意、保密與個案權益規範，並非心理師的單方權力。C 說心理師有權自行決定資料用途，與倫理原則不符，故為應選項。

A：衡鑑可能取得個案不自覺或不欲人知的資訊，正是須重視保密與敏感度的原因，敘述正確，故非答案。

B：即使已清楚說明且個案同意，衡鑑仍可能有未預見狀況，須持續處理倫理議題，敘述正確，故非答案。

D：心理師需敏感察覺可能引發個案焦慮的主題，並適當處理，敘述正確，故非答案。

本題考點：心理衡鑑資料倫理——判準是資料蒐集與使用均依知情同意、保密原則及個案權益處理；專業判斷不等於可單方支配個案資料。
