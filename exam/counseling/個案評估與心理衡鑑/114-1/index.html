第 1 題

社會適應表現檢核表上的智能障礙學生組常模為下列那一類常模？
  1. （A）特殊團體常模
  2. （B）鑑定常模
  3. （C）地區常模
  4. （D）分級常模

答案：（A）

詳解與考點

考點為常模（norm）的類型。正解 A 特殊團體常模：以智能障礙學生這一特定群體建立的對照標準，屬特殊團體常模。B 鑑定常模、C 地區常模（依地理區）、D 分級常模（依年級）皆非以特殊母群為基礎。把握度標 med：依「智障學生組」屬特定特殊群體判斷。

第 2 題

下列何種測驗最易受社會期望（social desirability）的影響？
  1. （A）成就測驗
  2. （B）性向測驗
  3. （C）自陳測驗
  4. （D）投射測驗

答案：（C）

詳解與考點

考點為社會期望（social desirability）對測驗的影響。正解 C 自陳測驗：受試者自我報告，最易為迎合社會期望而美化作答。A 成就、B 性向測驗有客觀對錯，較不受影響。D 投射測驗刺激模糊，受試難判斷何為理想答案，社會期望影響相對低。陷阱在 D，投射測驗也測人格，但其間接性反而降低社會期望作假空間。

第 3 題

關於效標參照的心理測驗，下列敘述何者正確？
  1. （A）較不適用於教育情境
  2. （B）可用來評量個案的進步狀況
  3. （C）重點在了解個案在團體中的表現
  4. （D）無法提供切截分數的相關資訊

答案：（B）

詳解與考點

考點為效標參照（criterion-referenced）測驗。正解 B：效標參照測驗以絕對標準評量個案是否達成目標，最適合評估個案的進步狀況。A 它很適用於教育情境（如精熟學習）。C 重視團體中相對排名的是常模參照。D 它正能提供切截分數資訊。陷阱在 C，把「了解個案在團體中表現」誤當效標參照，實為常模參照特性。

第 4 題

某企業主管有鑑於社會自殺事件頻傳，擬邀請諮商心理師協助防治工作，諮商心理師以心理測驗作為篩檢工具，對員工進行施測，主要可達到心理測驗的那一項功能？
  1. （A）評估
  2. （B）預測
  3. （C）診斷
  4. （D）治療

答案：（A）

詳解與考點

考點為心理測驗的功能分類。正解 A 評估（assessment/篩檢）：以測驗對全體員工施測作自殺風險篩檢，屬大範圍評估篩選功能。B 預測偏推估未來表現、C 診斷是對個別進行臨床判斷、D 治療非測驗功能。陷阱在 C，篩檢自殺像在「診斷」，但對全員初篩屬評估篩檢層次，個別確診才是診斷。

第 5 題

某位個案在初步會談中對諮商心理師表示：「你不覺得我的前男友非常過分嗎？他竟然會因為我的外貌，就決定要分手？」若以Brickman等人的理論來評估，個案對進行諮商的準備度和期待，最可能屬於下列那一種模式？
  1. （A）道德模式（moral model）：對自己的問題負責，也為解決問題的方法負責
  2. （B）補償模式（compensatory model）：不會對自己的問題負責，認為應該由情境來負責
  3. （C）啟蒙模式（enlightenment model）：對自己的問題負責，但不能為問題的解法方式負責
  4. （D）醫學模式（medical model）：既不能對問題且不能對解決方法負責

答案：（B）

詳解與考點

考點為 Brickman 等人的助人歸因四模式。正解 B 補償模式（compensatory）：個案不認為問題是自己的責任（怪前男友），但補償模式者不對問題負責、卻為解決方法負責。題述重點在「不為問題負責、歸咎情境」。A 道德模式（兩者皆負責）、C 啟蒙模式、D 醫學模式（兩者皆不負責）方向不同。把握度標 med：四模式定義易混淆。

第 6 題

從自殺線索和危機程度評估個案的自殺風險時，下列敘述何者最正確？
  1. （A）個案說了很多次「死了事情就解決了、解脫了」，「死」已成為他的口頭禪，他不會有自殺危機
  2. （B）個案說：「我不知道活著有什麼用，但只要想到我死亡，我爸媽他們心理上會很難過，還要面對親友的眼光」，個案尚有牽絆，自殺風險相對較低
  3. （C）個案說：「我離開了，小黑（小狗）就沒人照顧了，我把牠送人了；我也把籃球送給我好朋友了」，個案可能想出去散心，不用擔心
  4. （D）有過自殺經驗的個案，他是以自我傷害來得到關注，會再自我傷害，但危及生命的機率不大，可以不用做自殺評估

答案：（B）

詳解與考點

考點為自殺風險與線索的評估判斷。正解 B：個案因牽掛父母而有所牽絆，相對降低立即自殺風險（保護因子）。A 把「死」當口頭禪不代表沒危機，反需警覺。C 送走寵物與物品是處理後事的高風險訊號，絕不可輕忽。D「有自殺史只為關注、不必評估」是危險的錯誤觀念。陷阱在 A/C，誤把警訊解讀為無危機最危險。

第 7 題

在評估個案的主觀性痛苦時，下列敘述何者錯誤？
  1. （A）監控個案主觀性痛苦程度的最好方式之一是時常回顧晤談資料，包括行為觀察和相關病史
  2. （B）個案功能性缺損和主觀性痛苦最具相關
  3. （C）主觀性痛苦可能受環境性的事件所影響，常常會有變化
  4. （D）主觀性痛苦低的個案大半是來自非自願的轉介個案

答案：（B）

詳解與考點

考點為主觀性痛苦（subjective distress）的評估。正解 B 錯誤：與主觀性痛苦最相關的並非「功能性缺損」；功能缺損與主觀痛苦未必高度一致（有人功能差卻不痛苦，反之亦然）。A 回顧晤談行為觀察與病史、C 主觀痛苦受環境影響而變動、D 非自願轉介個案主觀痛苦常較低皆正確。把握度標 med。

第 8 題

依據個人史和臨床觀察評估個案的因應模式，下列何者不是個案將問題「內化（internalization）」的指標？
  1. （A）理智化
  2. （B）尋求刺激
  3. （C）淡化問題
  4. （D）與自律神經系統有關的身體化作用

答案：（B）

詳解與考點

考點為因應模式的內化（internalizing）vs 外化指標。正解 B 尋求刺激（sensation seeking）：屬外化（externalizing）的衝動向外宣洩，不是內化指標。A 理智化、C 淡化問題、D 身體化（自律神經相關）皆為將困擾向內轉的內化指標。陷阱在 C，淡化問題像否認逃避，但仍屬把痛苦內收的內化方式，非外化。

第 9 題

諮商心理師以Lazarus的BASIC－ID模式進行評估時，發現個案的問題癥結在C面向上，下列那一種處遇較能回應其問題？
  1. （A）行為改變技術
  2. （B）精神分析法
  3. （C）理情行為治療法
  4. （D）生物性治療法

答案：（C）

詳解與考點

考點為 Lazarus 多重模式（BASIC-ID）中 C 面向的處遇。正解 C 理情行為治療法：BASIC-ID 中 C 代表 Cognition（認知），最對應處理非理性信念的理情行為治療（REBT）。A 行為改變對應 B（Behavior）、B 精神分析非對應任一字母、D 生物性治療對應 D（Drugs/biology）。陷阱在 A/D，B 與 D 各對應其他字母，C 才是認知。

第 10 題

在評估會談的策略選擇上，下列的敘述何者錯誤？
  1. （A）一般而言，會談順序應該以指導性會談開始，而後以非指導性會談結束
  2. （B）會談中使用催化技巧可以鼓勵個案針對問題進行回應
  3. （C）一般來說，會談中會避免頻繁使用「為什麼」的問句
  4. （D）會談者可以透過眼神接觸、表情或肢體動作等，傳達對個案的關注

答案：（A）

詳解與考點

考點為評估會談的會談順序與技巧。正解 A 錯在順序顛倒：標準做法是先以開放、非指導性會談建立關係、廣泛蒐集資料，後段才轉指導性、聚焦特定主題與澄清細節。B、C、D 皆為正確的會談原則（催化、慎用「為什麼」、非語言關注）。陷阱在誤把「先指導後非指導」當合理流程，實則相反。

第 11 題

經驗取向（experiential approach）的諮商心理師，若在個別諮商中欲評估原生家庭經驗對個案行為的影響，通常會採取那一種會談形式？
  1. （A）非指導性會談
  2. （B）指導性會談
  3. （C）結構性會談
  4. （D）不會主動詢問原生家庭經驗

答案：（A）

詳解與考點

考點為經驗取向會談形式。經驗取向重視個案主觀經驗與當下感受的自然流露，故評估原生家庭影響時採非指導性會談（A），讓個案自由敘說。結構性、指導性會談以預設題目主導，較不符經驗取向精神。陷阱是選 D「不會主動詢問」，誤以為經驗取向忽略原生家庭，其實仍探索，只是用開放方式。

第 12 題

關於評估會談（assessment interview）和一般閒聊的差異，下列敘述何者最正確？
  1. （A）因受過訓練的會談員較具同理，在評估會談中會儘量避免碰觸敏感話題
  2. （B）為了多瞭解個案，所以評估會談不會設定主題或會談方向
  3. （C）有較多的自由和彈性，在評估會談中由個案來主導想談的主題以及決定何時結束
  4. （D）評估會談較能夠和初次見面的個案在短時間內建立專業關係

答案：（D）

詳解與考點

考點為評估會談與閒聊的本質差異。正解 D：評估會談有明確目的與專業訓練，能在短時間與初次個案建立專業（工作）關係，此為最關鍵區別。A 錯在不會避碰敏感話題、B 錯在會設主題方向、C 錯在由會談者而非個案主導。陷阱是 C 把「彈性」誤當成個案完全主導。

第 13 題

有關貝克憂鬱量表的使用，下列何者最適當？
  1. （A）適用於治療期間或治療後施測，作為理解治療效果的工具
  2. （B）初談時，請個案自行施測作為分類個案的工具
  3. （C）施測時應強調個案以當天的狀態來回答題目
  4. （D）有大量文獻佐證信效度，能作為臨床診斷工具

答案：（A）

詳解與考點

考點為貝克憂鬱量表(BDI)的適切用途。正解 A：BDI 為自陳篩檢與療效追蹤工具，適合治療期間或治療後施測以理解效果。B 錯在當分類工具、D 錯在當「臨床診斷工具」（量表只能評估傾向不能單獨下診斷）。陷阱是 D 看似「信效度佳」就能診斷，但篩檢量表不可取代診斷晤談。

第 14 題

有關第二版明尼蘇答多相人格測驗（MMPI-2）的發展與編製，下列說明何者最為適當？
  1. （A）根據精神疾病理論來編寫題項，以提高題項間的內部一致性
  2. （B）根據題項在臨床與對照樣本之差異表現來選題
  3. （C）透過心理專業人員組成的審查小組，來選題並歸類
  4. （D）藉由搜集數據進行項目分析來檢視題項在所屬量表的適當性

答案：（B）

詳解與考點

考點為 MMPI-2 的編製方法。正解 B：MMPI 採「實證效標法」，依題項在臨床組與正常對照組的作答差異來選題，不依理論內容。A、C、D 分別描述內容效度、邏輯/理論建構法，非 MMPI 特色。陷阱是 A「依精神疾病理論編題」，這是理論導向法，與 MMPI 的實證對比選題相反。

第 15 題

由於許多的文化因素均可能會影響智力測驗對於不同文化或不同族的公平性與正確性，因此有學者倡議應該編製所謂的「智力文化公平測驗（culture free test）」。下列何者不是編製文化公平測驗的常見做法？
  1. （A）測驗材料主要是非語文，並包含各種文化團體均熟悉的圖案或作業活動
  2. （B）縮短測驗的時間，以減除速度因素的影響
  3. （C）考量編製適合該文化的母語測驗版本
  4. （D）檢視測驗中的構念在不同文化的對等性

答案：（B）

詳解與考點

考點為文化公平測驗(culture-fair)的編製做法。正解 B「縮短測驗時間」並非常見做法，且減速度因素與文化公平無直接關聯。常見做法是用非語文材料(A)、編母語版本(C)、檢視構念跨文化對等性(D)。陷阱是把「減速度影響」誤當文化公平策略，實則屬測驗速度議題而非文化偏誤。

第 16 題

針對諮商個案的心理評估進行檔案評量時，下列那一項方法對於增進個案的自我認識最重要？
  1. （A）客觀測量工具的使用
  2. （B）定期的反思與自我評估
  3. （C）統一的評估標準
  4. （D）簡化的評估流程

答案：（B）

詳解與考點

考點為檔案評量(portfolio)對自我認識的功能。正解 B：檔案評量強調歷程與成長，透過定期反思與自我評估最能增進個案自我認識。客觀工具、統一標準、簡化流程偏向標準化測量，非檔案評量精神。陷阱是 A 客觀測量工具，雖精確但不促進自我覺察，與檔案評量的反思核心不符。

第 17 題

諮商心理師藉助少年的法律訴訟文件及個人獎懲文件進行評量，此一評量策略是屬於那一種類別之衡鑑？
  1. （A）運用檔案資料進行問題評估
  2. （B）運用會談資料進行診斷
  3. （C）不屬於心理評估的範圍
  4. （D）運用客觀測驗資料進行問題描述

答案：（A）

詳解與考點

考點為衡鑑資料來源的分類。法律訴訟文件、獎懲紀錄屬既存的檔案/檔案資料，故為「運用檔案資料進行問題評估」(A)。非經會談(B)或客觀測驗(D)取得，也確屬心理評估範圍(故非C)。陷阱是 C 誤以為文件資料不算心理評估，其實檔案資料是衡鑑重要來源之一。

第 18 題

下列那些資料可用於瞭解個案的人格特質？①人格測驗結果②個案的日記③行為觀察
  1. （A）僅①②
  2. （B）僅①③
  3. （C）僅②③
  4. （D）①②③

答案：（D）

詳解與考點

考點為人格特質的多元評估來源。人格測驗結果、個案日記、行為觀察三者皆可用以了解人格特質，故選 D①②③全部。陷阱在誤排除日記或行為觀察，以為只有標準化測驗才算，實則自陳資料與觀察都是人格衡鑑的合法來源。

第 19 題

有一位兒童專長心理師，為了想要確認小學三年級的個案是否有注意力不足的問題，在初次晤談後，他請導師攜回一張記錄卡，而後請導師在一堂國語課中，以每5分鐘為單位，觀察個案是否有東張西望的分心行為；若有出現上述行為一次，則在該五分鐘的小格中劃記，連續出現則連續劃記。試問該位心理師採取的紀錄法，是行為衡鑑中的那一種方法？
  1. （A）敘事紀錄法（narrative recording）
  2. （B）時距紀錄法（interval recording）
  3. （C）評比紀錄法（rating recording）
  4. （D）自由觀察法（free recording）

答案：（B）

詳解與考點

考點為行為衡鑑的記錄方法。以「每5分鐘為一單位」觀察行為是否出現並劃記，屬時距記錄法(interval recording)(B)。敘事法是描述事件經過、評比法是評定程度、自由觀察無固定時段。陷阱是與「事件記錄」混淆，但本題以固定時距為觀察單位而非計次每一事件，故為時距法。

第 20 題

關於行為衡鑑中的觀察法，下列敘述何者錯誤？
  1. （A）需考慮目標行為的複雜性
  2. （B）觀察人員需經過系統性的訓練
  3. （C）較不常出現的特定行為，很難觀察和監控
  4. （D）設定抽樣方式即可得代表性的行為樣本而不需考慮抽樣數多寡

答案：（D）

詳解與考點

考點為觀察法的限制與品質。正解 D 錯在「設定抽樣方式即可不需考慮抽樣數」，行為樣本代表性同時需要適當的抽樣方式與足夠的樣本數。A、B、C 皆正確（需考量行為複雜性、觀察員訓練、稀有行為難觀察）。陷阱是忽略「數量」也影響代表性，只顧抽樣方法。

第 21 題

某資源班老師想要評估「在給予一個安靜的手勢指令給某位學生後，該生要多久才會做到」的行為測量，下列記錄方法何者最適當？
  1. （A）時距記錄
  2. （B）事件記錄
  3. （C）持續時間記錄
  4. （D）潛伏時間記錄

答案：（D）

詳解與考點

考點為行為測量的時間向度記錄法。測量「給指令後到行為出現需多久」是測量反應的延宕時間，屬潛伏時間記錄(latency recording)(D)。持續時間記錄測行為持續多長、事件記錄計次數、時距記錄看時段內有無。陷阱是與持續時間記錄混淆，但本題測的是「開始反應前的等待時間」而非行為本身持續長度。

第 22 題

關於瑞文氏彩色圖形推理測驗（CPM），下列敘述何者正確？
  1. （A）適用對象是9.5～12.5歲的兒童
  2. （B）測驗功能是測量年幼兒童的非語文普通能力
  3. （C）主要評量兒童的語文能力
  4. （D）適用於所有兒童期的對象

答案：（B）

詳解與考點

考點為瑞文氏彩色圖形推理測驗(CPM)的功能與對象。正解 B：CPM 測量年幼兒童(約5至11歲)的非語文普通推理能力。適用約9.5–12.5歲是標準型(SPM)而非CPM(故A錯)、CPM非語文(故C錯)、不適用所有兒童期(故D錯)。陷阱是 A 的年齡區間其實屬SPM。

第 23 題

  2. （B）比較不會受到神經缺損的影響
  3. （C）是總智商的最佳單一指標
  4. （D）反映遵守社會規範標準的程度

答案：（D）

詳解與考點

考點為魏氏智力測驗詞彙(Vocabulary)分測驗特性。正解 D 錯在「反映遵守社會規範程度」，那是理解(Comprehension)分測驗的特色。詞彙分測驗確為最可信賴的語文理解指標、較不受神經缺損影響、是總智商最佳單一指標(A、B、C皆對)。陷阱是把理解分測驗的社會規範特性錯安到詞彙上。

第 24 題

  4. （D）施測該量表後，須將原始分數轉為百分等級，且依據百分等級進一步繪製五等級表

第 26 題

下列那一個測驗是透過因素分析法建構出人格向度？
  1. （A）梅－布二氏型態量表（Myers-Briggs Type Indicator, MBTI）
  2. （B）加州心理量表第三版（California Psychological Inventory-III, CPI-III）
  3. （C）明尼蘇答多相人格測驗第二版（Minnesota Multiphasic Personality Inventory-2, MMPI-2）
  4. （D）新人格量表修訂版（NEO Personality Inventory-Revised, NEO-PI-R）

答案：（D）

詳解與考點

考點為以因素分析建構人格向度的測驗。正解 D：NEO-PI-R 的五大人格(Big Five)係以因素分析萃取的人格向度。MBTI 為類型論、CPI與MMPI採實證效標法選題，非因素分析建構。陷阱是誤以為MMPI這類大型人格測驗也是因素分析，其實它是實證對比選題。

第 27 題

有關性向測驗與成就測驗的敘述，下列何者正確？
  1. （A）性向測驗取材範圍較廣泛普遍，成就測驗取材在控制和限定下的學習結果
  2. （B）性向測驗強調習得的知識技能的水準，成就測驗強調學習新事物的能力
  3. （C）性向測驗測量已發展的能力，成就測驗測量未發展的能力
  4. （D）性向測驗重視同時效度，成就測驗強調預測效度

答案：（A）

詳解與考點

本題問性向測驗與成就測驗之敘述「何者正確」，官方答案為 (A)。(A) 正確：性向測驗（aptitude test）取材範圍較廣泛、普遍，著重一般化、跨情境的潛能（用以預測未來學習或表現）；成就測驗（achievement test）則取材於受控制、限定範圍內的特定學習結果（如某科教學內容），(A) 對兩者取材性質的對比正確。其餘錯誤：(B) 顛倒，強調「學習新事物的能力」者為性向測驗，強調「已習得知識技能水準」者為成就測驗；(C) 錯誤，成就測驗測量的是「已發展（已習得）」的能力，而非「未發展」的能力，且性向測驗也並非完全不涉及已發展能力，其常以目前已具備的能力為基礎來預測未來表現，故 (C) 的二分敘述錯誤；(D) 錯誤，性向測驗特別重視預測效度（predictive validity，預測未來表現），成就測驗則較重內容效度與同時效度，(D) 將兩者對應顛倒，故皆不選。

第 28 題

某類學習評量方式之目的在於瞭解學生認知改變的情形。在施測、評量的過程中，可能調整施測程序或工具，儘量協助受測者充分回答、展現所有的能力。這一種學習的評量方式稱為下列何者？
  1. （A）紙筆評量（paper and pencil assessment）
  2. （B）檔案評量（portfolio assessment）
  3. （C）真實評量（authentic assessment）
  4. （D）動態評量（dynamic assessment）

答案：（D）

詳解與考點

考點為動態評量(dynamic assessment)的概念。正解 D：動態評量旨在了解認知改變歷程，施測中可調整程序或提供協助(中介)以展現潛能，呼應Vygotsky近側發展區。紙筆、檔案、真實評量均不強調過程中介協助。陷阱是與真實評量混淆，但動態評量的核心是「測中提供協助看可改變性」。

第 29 題

自我探索量表（Self-Directed Search）、大學入學考試中心興趣量表、職業興趣組合卡這三種生涯評量工具的共通點為下列何者？
  1. （A）適用的評量對象都以在學學生為主
  2. （B）都是標準化的興趣測驗
  3. （C）都是以Holland人格類型分類方式編製而成
  4. （D）強調個案興趣的持久性

答案：（C）

詳解與考點

考點為三種生涯興趣評量工具的共通點。自我探索量表(SDS)、大考中心興趣量表、職業興趣組合卡皆以Holland(何倫)人格類型(RIASEC)為編製基礎，故選 C。它們對象、是否標準化、是否強調持久性並不一致(故A、B、D皆非共通)。陷阱是誤選 B「都是標準化測驗」，但組合卡屬質性工具未必標準化。

第 30 題

關於諮商心理師使用職業組合卡實施階段的步驟，下列何者正確？
  1. （A）選排卡片－敘述理由－決定職業順序－計算何倫（Holland）碼－綜合整理
  2. （B）選排卡片－決定職業順序－敘述理由－計算何倫（Holland）碼－進行諮商
  3. （C）選排卡片－決定職業順序－敘述理由－計算一致性與區分性－綜合整理
  4. （D）選排卡片－敘述理由－決定職業順序－計算一致性與區分性－進行諮商

答案：（A）

詳解與考點

考點為職業組合卡的實施步驟。正解 A 的順序為：選排卡片→敘述理由→決定職業順序→計算何倫碼→綜合整理。重點在「先敘述理由再排順序」並計算Holland碼(而非一致性與區分性)。陷阱是選含「計算一致性與區分性」的選項，那是Holland六角形的概念而非組合卡計分步驟。

第 31 題

一位主修電子工程的大四學生到諮商中心希望探討畢業後的規劃，經過初談後發現：該生對未來從事科技業沒有興趣；當看到同學都在準備考研究所，但自己又不想升學，因而感到很焦慮。下列那一個評估結果敘述最恰當？
  1. （A）就業的焦慮來自焦慮性人格，需要從諮商中學習自我肯定
  2. （B）生涯發展上的選擇議題，需要生涯諮商
  3. （C）情境因素造成的心理焦慮，需要放鬆訓練
  4. （D）可能是依賴型人格造成生涯困境，需要探討其依附關係

答案：（B）

詳解與考點

考點為生涯議題的個案概念化。個案對科技業無興趣、面臨升學或就業抉擇而焦慮，核心是生涯發展的選擇議題，需生涯諮商(B)。將之歸為焦慮性人格、依賴型人格(A、D)屬過度病理化；僅放鬆訓練(C)未觸及生涯核心。陷阱是把情境性生涯焦慮誤診為人格病理。

第 32 題

貝克憂鬱量表第二版（BDI-II）是心理師經常使用於憂鬱傾向評估的自陳式量表之一，關於BDI-II的敘述，下列何者錯誤？
  1. （A）包含21組題目，每組題目的得分範圍是0到3分
  2. （B）具有良好的信度與效度
  3. （C）將答案相互比較，可以找出與憂鬱有關的非理性信念
  4. （D）運用在多元族群上的效度較差，需小心解釋

答案：（D）

詳解與考點

考點為BDI-II的特性與使用限制。正解 D 錯：BDI-II 在多元族群仍具相當效度，並非「效度較差需小心解釋」。其21組0–3分計分(A)、良好信效度(B)皆正確；C「比較找出非理性信念」較牽強但相對D非屬明確錯誤的標準敘述。陷阱是把對少數族群謹慎解釋的一般提醒，誤推成「效度差」。

第 33 題

下列有關羅夏克墨漬測驗（Rorschach Inkblot Test）的敘述何者正確？
  1. （A）包含10張隱含故事主題的墨跡圖片
  2. （B）測驗圖片的墨跡全都是黑灰白色的組成
  3. （C）施測第一張圖片時，需要提供受試者回答內容的範例
  4. （D）當對象是兒童個案時，測驗結果只能說明個案這段時間的性格狀態

答案：（D）

詳解與考點

考點為羅夏克墨漬測驗(Rorschach)的事實。正解 D：對兒童個案，因人格尚在發展，結果多反映此段時間的狀態而非穩定特質。圖片共10張、其中部分為彩色非全黑灰白(故B錯)、第一張不提供範例(故C錯)、墨漬非「隱含故事主題」(故A錯)。陷阱是 B 誤以為墨漬全為黑白，實有彩色圖。

第 34 題

在自殺危險評估的過程中，心理師應如何處理評估結果最適當？
  1. （A）僅在結果顯示高度危險時與個案討論
  2. （B）應就評估結果，適度地與個案、家屬進行討論及後續處遇
  3. （C）評估結果應保密，不應與個案或其他人分享
  4. （D）如果結果顯示低危險，則不需要進行任何後續行動

答案：（B）

考點為自殺危險評估後的處理倫理。正解 B：應就評估結果適度與個案、家屬討論並安排後續處遇，兼顧知情與安全。只在高危時討論(A)、一律保密不分享(C)、低危即不處理(D)皆違反風險管理與保護原則。陷阱是把保密原則絕對化，忽略傷害自己屬保密例外。

第 35 題

進行鑑別診斷時，選擇適當心理測驗是一項重要的工作之一，因此需考慮之關鍵點應包含那些？①對心理測驗的施測和解釋能力②心理測驗的信效度③有電腦化施測和解釋④主試者熟悉的心理測驗
  1. （A）②③④
  2. （B）①②③
  3. （C）①③④
  4. （D）①②④

答案：（D）

詳解與考點

考點為鑑別診斷選測驗的關鍵考量。正解 D①②④：須考量施測解釋能力、信效度、主試者熟悉度。第③「有電腦化施測」非必要關鍵點，只是便利性。陷阱是把「電腦化」當必備條件，但測驗品質與施測者專業才是核心，電腦化非選測驗的關鍵依據。

第 36 題

心理評估報告的格式內容不包括下列那一項？
  1. （A）個案背景資料
  2. （B）澄清轉介問題
  3. （C）一般性陳述
  4. （D）作成結論與建議

答案：（C）

詳解與考點

考點為心理評估報告的標準格式。正解 C「一般性陳述」不屬報告固定項目；報告應含個案背景資料、澄清轉介問題、結論與建議等。陷阱是「一般性陳述」字面似合理，但評估報告強調具體的衡鑑發現與依轉介問題的個別化結論，非泛泛一般敘述。把握度中。

第 37 題

個案評估報告的撰寫，某些心理師反對將精神疾病的診斷結果納入報告的理由，不包括下列何者？
  1. （A）可能會有標籤化的效果
  2. （B）恐讓個案有自我預期效果
  3. （C）恐讓個案去責任化
  4. （D）會影響轉介

答案：（D）

詳解與考點

考點為反對將精神診斷納入報告的理由。正解 D「會影響轉介」不屬反對理由(診斷往往有助轉介溝通)。反對理由通常是標籤化(A)、自我預期效果(B)、去責任化(C)。陷阱是 D 把「影響轉介」當壞處，但提供診斷反而利於轉介銜接，故非反對的論點。

第 38 題

下列關於心理評估的實施，何者最適當？
  1. （A）對未成年個案實施評估時，孩子堅持說不要參加，雖然如此，但因為已經取得家長同意書，仍然可以開始施測
  2. （B）進行評估前，個案可以參與決定，那些方面的測驗問題可以詢問，以達到尊重個案決策的原則
  3. （C）向年紀較小的小朋友施測智力測驗時，若他們回答不出來，適時地給予一些提示，讓他們在測驗過程中不要那麼挫折而影響表現
  4. （D）如果評估過程中需要有口譯人員協助，需要事先向口譯人員說明流程，並請口譯人員不可外流測驗題目、不要解釋題目或提示答案等注意事項

答案：（D）

詳解與考點

考點為心理評估實施的倫理。正解 D：使用口譯時須事先說明流程並要求保密、不解釋題目、不提示答案，維護測驗安全與標準化。A 違反未成年人同意/拒絕權、B 不應由個案決定測哪些題、C 智測中給提示破壞標準化。陷阱是 C 看似體貼，卻違反施測標準化原則。

第 39 題

為了進行心理衡鑑，諮商心理師應該要在事前取得個案的知情同意（informed consent）之書面文件，下列那一項較不需列入同意書的內容？
  1. （A）衡鑑資訊的保密原則及例外情況
  2. （B）衡鑑的流程與程序
  3. （C）衡鑑所採用的測驗及分量尺類型
  4. （D）衡鑑取得資料的可能用途

答案：（C）

詳解與考點

考點為心理衡鑑知情同意書的內容。正解 C：所採用測驗及分量尺的具體類型較不需列入同意書(屬測驗安全，過細反失意義)。同意書應含保密原則與例外、流程程序、資料用途(A、B、D皆需列)。陷阱是誤以為要詳列每個分量尺，但同意重點在程序、保密與用途而非測驗清單。

第 40 題

在心理衡鑑過程中，需要特別注意相關的倫理議題，下列敘述何者錯誤？
  1. （A）在衡鑑過程中，可能會取得一個人不自覺或是不欲人知的訊息
  2. （B）即使諮商心理師提供了清楚的訊息，個案也對衡鑑的程序表示同意，也可能會有無法預見的狀況發生
  3. （C）針對衡鑑過程中所取得的資訊，諮商心理師有權力決定測驗資料如何被使用
  4. （D）在衡鑑過程中，諮商心理師需有敏感度去察覺可能會引發個案焦慮的主題

答案：（C）

詳解與考點

考點為衡鑑歷程的倫理。正解 C 錯：諮商師並非「有權力獨自決定」測驗資料如何被使用，資料使用須遵循知情同意、保密與個案權益，並非心理師單方權力。A、B、D 皆為正確的倫理敏感度敘述。陷阱是把專業判斷誤當成可單方支配個案資料的權力。
