第 1 題

當某個測驗的再測信度可能受練習與記憶帶來的學習移轉效果影響時，可以透過具有下列何種信度的測驗加以避免？
  1. （A）評分者間信度
  2. （B）內部一致性
  3. （C）複本信度
  4. （D）庫李信度

答案：（C）

詳解與考點

考點為信度類型與練習效果。正解 C 複本信度：使用內容對等的複本可避免再測時的練習與記憶（學習移轉）效果。陷阱是 A 評分者間信度（測評分一致）、B 內部一致性與 D 庫李信度（測題目同質性），皆無法解決重測的練習污染。

第 2 題

某諮商心理師自行編製一份與學習評量有關之測驗，應如何檢驗此測驗具備內容效度？
  1. （A）每一試題難度接近0.5
  2. （B）每一試題與總分之點二系列相關值達顯著水準
  3. （C）題目數量符合雙向細目表之比重
  4. （D）與測量相同構念之其他測驗有高相關

答案：（C）

詳解與考點

考點為內容效度的檢驗方式。正解 C：依「雙向細目表」比重編題，確保題目涵蓋教學目標與內容範疇，即建立內容效度。陷阱是 A 難度 0.5（屬難度分析）、B 點二系列相關（鑑別度／效標）、D 與他測驗高相關（屬效標關聯／聚斂效度）。

第 3 題

某諮商心理師在一場個案研討會中提出下列四項他對「心理評估」的看法，下列那一項最不正確？
  1. （A）係針對個案心理狀態、行為反應與環境特性等三者交互作用所實施的評估歷程
  2. （B）針對蒐集到的個案資料進行分析、推論與驗證的過程
  3. （C）實施個案心理評估時，心理測驗是不可或缺的工具
  4. （D）專業人員必須具備心理學領域的知識、了解心理測驗本質並整合其他資料以形成與個案相關的描述

答案：（C）

詳解與考點

考點為心理評估本質。題問「最不正確」，正解 C：「心理測驗是不可或缺的工具」過於絕對，心理評估可整合會談、觀察等多元資料，測驗並非必要。A、B、D 正確描述人境互動評估、分析推論驗證、需專業整合多元資料。陷阱是把測驗當成評估的唯一必備工具。

第 4 題

從問題解決評量的模式來看，有關心理衡鑑的實施，下列敘述何者最適當？
  1. （A）心理衡鑑的第一步是進行標準化測驗
  2. （B）協助個案將問題常態化（normalize），有助於個案了解與接受問題
  3. （C）心理衡鑑面對的是人，因而解決個案問題的有效性是無法評估的
  4. （D）和個案的家人或轉介者溝通時，需依據平衡單（balance sheets）

答案：（B）

詳解與考點

考點為問題解決評量模式下的衡鑑實施。正解 B：協助個案將問題常態化（normalize），有助其理解與接受問題，是適切作法。陷阱是 A（第一步並非先做標準化測驗，應先界定問題）、C（有效性並非無法評估）、D（平衡單用於決策權衡，非與家人溝通的依據）。

第 5 題

在校園中實施「生涯興趣量表」，以幫助學生探索自己的興趣，作為日後生涯規劃的參考。這是屬於何種層級的校園輔導工作？
  1. （A）初級發展
  2. （B）次級篩選
  3. （C）三級介入
  4. （D）間接服務

答案：（A）

詳解與考點

考點為學校三級輔導架構。正解 A 初級發展：對全體學生實施生涯興趣量表以促進發展與自我探索，屬初級預防／發展性輔導。陷阱是 B 次級篩選（針對高風險群）、C 三級介入（針對嚴重個案處遇），本題是面向全體學生的發展性工作。

第 6 題

動態評量（dynamic assessment）是以下列何種理論為基礎？
  1. （A）Freud的心理分析論
  2. （B）Piaget的認知發展論
  3. （C）Bandura的社會學習論
  4. （D）Vygotsky的社會發展認知論

答案：（D）

詳解與考點

考點為動態評量的理論根源。動態評量強調「教學中評量」，透過提示與中介引導觀察學習潛能，正是 Vygotsky 社會發展認知論「近側發展區（ZPD）」的延伸應用，故 D 正確。最易誤選 B（Piaget），因兩者皆談認知發展，但 Piaget 重個體自然成熟、屬靜態評量觀，與動態評量的社會中介取向不同。

第 7 題

在進行心理衡鑑時，有關心理測驗選擇的敘述，下列何者錯誤？
  1. （A）選擇心理測驗時，需要考慮這個測驗是否有助於回應心理衡鑑目的
  2. （B）所選擇的測驗工具必須具備良好的心理計量特性
  3. （C）在實務工作上，有時會將測驗以不同的方式組合起來，變成核心套裝測驗組合（core battery）
  4. （D）在進行認知功能評估時，使用簡式量表不但可以取代原本的測驗，還可以節省時間

答案：（D）

詳解與考點

考點為選測倫理與計量原則。題目找「錯誤」者，D 主張簡式量表可「取代」原測驗為誤——簡式僅供快速篩檢，無法取代完整認知衡鑑的廣度與精度，會犧牲效度。A、B、C 分別講合目的性、心理計量品質、核心套裝測驗組合，皆為正確實務原則。陷阱在 C「core battery」名詞較陌生，易被誤判為錯。

第 8 題

下列何種諮商或治療方法最適合用於經評估為「抗拒性強」的個案？
  1. （A）矛盾技術（paradoxical techniques）
  2. （B）認知重建（cognitive reconstruction）
  3. （C）分析與詮釋（analysis and interpretation）
  4. （D）勸告（persuasion）

答案：（A）

詳解與考點

考點為抗拒個案的處遇技術。對高抗拒者，正面說服或直接詮釋常引發反作用，宜用「矛盾技術」（如症狀處方），順勢操作其抗拒以鬆動防衛，故 A 正確。最易誤選 D 勸告或 C 分析詮釋，但對抗拒性強者直接勸說、詮釋反而強化阻抗，效果不佳。

第 9 題

心智狀態檢查（mental status examination）在個案評估與諮商的主要用途為何？
  1. （A）壓力檢測
  2. （B）一般精神或心理功能檢測
  3. （C）過往人際關係評估
  4. （D）人格特質評量

答案：（B）

詳解與考點

考點為心智狀態檢查（MSE）的用途。MSE 系統觀察個案外觀、情緒、思考、知覺、認知、判斷力等，目的是即時評估「一般精神或心理功能」當前狀態，故 B 正確。陷阱是 D 人格特質——MSE 評的是當下功能而非穩定人格；A 壓力、C 過往人際也非其核心焦點。

第 10 題

關於「家族圖譜（genograms）」在個案評估與諮商中的應用，下列敘述何者錯誤？
  1. （A）根據Bowen的家庭系統理論
  2. （B）不適用於沉默個案
  3. （C）收集家族三代重要資訊
  4. （D）探索家庭重複的功能和關係類型

答案：（B）

詳解與考點

考點為家族圖譜的應用。題找「錯誤」，B 稱「不適用於沉默個案」為誤——家族圖譜以繪圖結構化蒐集三代資訊，反而適合協助沉默或不易口語表達的個案開啟對話。A（Bowen 家庭系統理論基礎）、C（三代資訊）、D（重複功能與關係型態）皆正確。

第 11 題

諮商心理師選用心理測驗首重下列那一個條件？
  1. （A）信度
  2. （B）效度
  3. （C）常模
  4. （D）便利性

答案：（B）

詳解與考點

考點為選測時最優先的計量條件。效度回答「測驗是否真的測到所欲測的特質」，是測驗能否達成衡鑑目的之根本，故首重 B 效度。陷阱是 A 信度——信度是效度的必要而非充分條件，測驗可穩定卻測錯方向；便利性更非首要考量。

第 12 題

下列何者是行為晤談（behavioral interview）的目的與重點？
  1. （A）了解前置因素、行為本身和後續結果（ABC）之間的關係
  2. （B）認知執行功能的合宜
  3. （C）了解疾病的成因與其過去發展史
  4. （D）人格與決策能力的相關性

答案：（A）

詳解與考點

考點為行為晤談的核心。行為取向重視功能分析，聚焦前置事件（A）、行為（B）、後果（C）三者的關聯，藉以理解行為的觸發與維持機制，故 A 正確。陷阱 C「了解疾病成因與過去發展史」屬精神動力或醫學取向，與行為晤談的此時此地功能分析取向不同。

第 13 題

依據DSM-5，在思覺失調症的評估中，個案的症狀持續時間至少需要多久，才有可能形成思覺失調症的診斷？
  1. （A）二個星期
  2. （B）一個月
  3. （C）三個月
  4. （D）六個月

答案：（D）

詳解與考點

考點為 DSM-5 思覺失調症的病程準則。診斷要求症狀持續徵候至少六個月（含至少一個月活躍期症狀），故 D 正確。陷阱是 B 一個月——一個月僅為活躍期門檻，亦對應「類思覺失調症」的時間範圍，整體診斷門檻為六個月。

第 14 題

在評估會談中所蒐集的個案資訊，可分成內容性資訊與歷程性資訊，下列那一項資訊較符合歷程性資訊？
  1. （A）觀察到個案在講述原生家庭經驗時，開始顯得侷促不安
  2. （B）個案依照時間序列陳述自己轉換過那些學校
  3. （C）個案陳述自己對男友的看法
  4. （D）個案表達對於諮商的期望

答案：（A）

詳解與考點

考點為內容性與歷程性資訊之別。歷程性資訊指個案「如何」陳述及伴隨的非語言、情緒反應；A 觀察到講述原生家庭時侷促不安，反映的是當下歷程而非陳述內容，故 A 正確。B、C、D 皆是個案口語陳述的「內容」，為內容性資訊。

第 15 題

將測驗分數與特定標準比較來進行結果的判斷與解釋，此種測驗稱為下列何者？
  1. （A）效標參照測驗（criterion-referenced test）
  2. （B）常模參照測驗（norm-referenced test）
  3. （C）等化參照測驗（equating-referenced test）
  4. （D）期望參照測驗（expectancy-referenced test）

答案：（A）

詳解與考點

考點為效標參照與常模參照之分。將分數與「特定標準（精熟門檻）」比較、判斷是否達標者為效標參照測驗，故 A 正確。陷阱是 B 常模參照——其比較對象是同儕團體分布、反映相對位置，而非絕對標準。

第 16 題

下列四項測驗工具，何者不屬於情意測量工具？
  1. （A）工作氣質測驗
  2. （B）我喜歡做的事
  3. （C）人際行為量表
  4. （D）區分性向測驗

答案：（D）

詳解與考點

考點為情意測量工具的辨識。情意測量涵蓋興趣、態度、人格氣質等非能力面向；D 區分性向測驗測的是認知能力與性向，屬認知（能力）測量，故為「不屬於」者。A 工作氣質、B 興趣量表、C 人際行為皆屬情意領域。

第 17 題

下列何項測驗是評估人格五因素模型（five-factor model）的自陳式量表？
  1. （A）Millon Clinical Multiaxial Inventory
  2. （B）NEO Personality Inventory
  3. （C）California Psychological Inventory
  4. （D）Edwards Personal Preference Schedule

答案：（B）

詳解與考點

考點為五因素人格模型對應的量表。NEO Personality Inventory（NEO-PI）正是 Costa 與 McCrae 依五大人格因素（OCEAN）編製的自陳量表，故 B 正確。陷阱是 C（CPI）與 A（MCMI），前者測一般人格量尺、後者測臨床人格障礙，皆非五因素架構。

第 18 題

下列何者最能解決多元族群測驗對等性的問題？
  1. （A）了解測驗分數對不同族群的意義
  2. （B）訂定所有族群共用的測驗分數常模
  3. （C）建立共通且完整的效標測量
  4. （D）對各個族群施測及解釋測驗時，要保持相同的態度

答案：（A）

詳解與考點

考點為多元族群測驗對等性。對等性問題的根本在於同一分數對不同文化族群是否具相同意義，故 A「了解測驗分數對不同族群的意義」最能解決。陷阱是 B 訂共用常模或 C 共通效標，這些做法忽略文化差異，反而可能掩蓋偏誤而非解決對等性。

第 19 題

臨床工作者在選擇與治療計畫有關的測驗時，下列那個原則最適切？
  1. （A）應依據測驗的經濟性來選擇測驗
  2. （B）應依據測驗在心理治療中被使用的普遍性來選擇測驗
  3. （C）應依據測驗在心理治療計畫中的有用性來選擇測驗
  4. （D）應依據測驗工具使用的便利性來選擇測驗

答案：（C）

詳解與考點

考點為與治療計畫相關的選測原則。為擬定處遇，應以測驗對「治療計畫的有用性」為首要依據，使衡鑑結果能導向具體介入，故 C 正確。陷阱是 A 經濟性、B 普遍性、D 便利性，這些是次要的實務考量，不應凌駕於對治療目的的貢獻。

第 20 題

考試是學生主要的壓力來源之一，面對即將進入國三的學生，國中基本能力測驗是一場不可避免的重大考試。某國中校長希望在開學之初找出對壓力反應傾向較高的學生，以便協助因應考試壓力。下列測驗何者最合適？
  1. （A）情境焦慮量表
  2. （B）特質焦慮量表
  3. （C）貝克憂鬱量表（BDI-II）
  4. （D）貝克焦慮量表（BAI）

答案：（B）

詳解與考點

考點為情境焦慮與特質焦慮之別。要找出「反應傾向較高」即穩定的焦慮易感性，應測特質焦慮，故 B 正確。陷阱是 A 情境焦慮——其反映當下特定情境的暫時焦慮狀態，會隨時間波動，不適合用來預先篩出傾向高者。

第 21 題

如果就心理測驗（psychological testing）和心理衡鑑（psychological assessment）加以比較，下列的敘述中，那一項的敘述是不適切的？
  1. （A）心理測驗是一種工具，而心理衡鑑是解決問題的過程
  2. （B）心理測驗是測量個案的特定心理向度，而心理衡鑑是針對個案的臨床問題做整體的評估
  3. （C）心理測驗的結果較適用於特定個案問題的深入了解，而心理衡鑑的結果較適合於做個別差異比較，反映個案在團體中的相對位置
  4. （D）實施心理測驗可以測量到智力、性向、成就等能力特質，而心理衡鑑關心的不是分數的多寡，而是個案問題是如何形成的？如何協助個案解決問題？

答案：（C）

詳解與考點

考點為心理測驗與心理衡鑑之區辨。題找「不適切」，C 將兩者敘述對調為誤——應是測驗結果適合做個別差異比較、反映團體相對位置，衡鑑才適合對特定個案問題深入整體理解。A、B、D 對「工具 vs 歷程」「特定向度 vs 整體」的描述皆正確。

第 22 題

下列那一種資料不需放進個案的正式檔案紀錄中？
  1. （A）個案的學業成績
  2. （B）有關個案的研討資料
  3. （C）諮商心理師的個人心理治療筆記（psychotherapy notes）
  4. （D）個案母親與你電話溝通個案病前狀況的訊息

答案：（C）

詳解與考點

考點為正式檔案紀錄的範圍。心理治療筆記（psychotherapy notes）屬心理師個人歷程備忘，享較高保密層級、不納入正式個案檔案，故 C 為「不需放進」者。A 學業成績、B 研討資料、D 家屬提供的病前訊息皆屬可納入正式紀錄的客觀資料。

第 23 題

下列有關傳記測量的敘述何者錯誤？
  1. （A）傳記測量屬於非標準化評量程序
  2. （B）傳記測量的資料是預先計畫的
  3. （C）傳記測量根據事實陳述而非依據判斷
  4. （D）學習歷程檔案屬於傳記測量之一種

答案：（B）

詳解與考點

考點為傳記測量的特性。題找「錯誤」，B 稱「資料是預先計畫的」為誤——傳記測量蒐集的是個案過去已發生的真實生活事件，屬事後事實而非預先安排。A（非標準化）、C（依事實而非判斷）、D（學習歷程檔案為一例）皆正確。

第 24 題

有關行為觀察與晤談、治療的概念，下列敘述何者錯誤？
  1. （A）在晤談的前、中、後期通常都還需要進行行為觀察
  2. （B）行為觀察所要使用的特定方法，通常在進行初步的行為晤談時就已經決定
  3. （C）行為觀察欲瞭解在晤談中所討論到的行為及其相關領域
  4. （D）為了保持客觀性，行為觀察必須由受過訓練的專家來執行

答案：（D）

詳解與考點

考點為行為觀察的執行。題找「錯誤」，D 稱「必須由受過訓練的專家執行」過於絕對——行為觀察常可訓練教師、家長等自然情境中的相關人員協助記錄，不限專家。A（前中後期皆需）、B（方法於初步晤談時決定）、C（瞭解相關行為領域）皆正確。

第 25 題

事件記錄法只記錄具體行為是否發生，請問下列何種行為較不適合使用此方法？
  1. （A）離開座位
  2. （B）要求幫忙
  3. （C）說髒話
  4. （D）注意集中

答案：（D）

詳解與考點

考點為事件記錄法的適用行為。事件記錄只計次「是否發生」，適合有明確起訖的離散行為；D「注意集中」是持續狀態、難界定單次發生，較適合用時間取樣或持續時間記錄，故為「較不適合」者。A 離座、B 求助、C 說髒話皆為可計次的離散行為。

第 26 題

有關Cattell流體（fluid）智力和晶體（crystallized）智力的說明，下列何者是最適切的？
  1. （A）瑞文氏非文字推理測驗測量的是流體智力
  2. （B）流體智力主要受教育與文化的影響
  3. （C）晶體智力高的人各項領域表現普遍較佳
  4. （D）晶體智力高的人流體智力往往較低

答案：（A）

詳解與考點

本題問對 Cattell 流體智力與晶體智力「最適切」的說明，官方答案為 (A)。流體智力（fluid intelligence, Gf）指與文化、學習較無關的抽象推理、問題解決能力；瑞文氏非文字推理測驗（Raven's Progressive Matrices）以圖形矩陣推理測量，文化負荷相對低，主要評量的正是流體智力，故 (A) 正確（須注意其為「文化負荷較低」而非「完全不受文化影響」）。其餘錯誤：(B) 顛倒，受教育與文化影響的是晶體智力（crystallized intelligence, Gc，即後天習得的知識與技能），而非流體智力；(C) 過度推論，晶體智力高代表特定知識經驗豐富，未必各領域表現皆較佳；(D) 錯誤，流體與晶體智力之間並非負相關，晶體智力高者流體智力未必較低，兩者反而常呈正相關，故皆不選。

第 27 題

實施主題統覺測驗時，諮商心理師的指導語那一種說法錯誤？
  1. （A）此刻圖片中正發生什麼事
  2. （B）是什麼事件導致圖片中目前的景象
  3. （C）結局會如何
  4. （D）在說這個故事時，你的感覺是什麼

答案：（D）

詳解與考點

考點為主題統覺測驗（TAT）指導語。TAT 標準指導語請個案就圖片編故事，涵蓋「正發生什麼、之前何事、結局如何、人物想法感受」；D 問「你（個案本人）說故事時的感覺」偏離 TAT 投射故事的編製要求，故為錯誤說法。A、B、C 皆屬標準指導內容。

第 28 題

有關人格衡鑑的方法，下列何者正確？
  1. （A）自陳式人格衡鑑，測量的是一個人特質、思考、行為的最大表現
  2. （B）投射測驗沒有解釋的標準，只能依個案的狀況決定
  3. （C）生理心理評量是人格衡鑑常用的方法
  4. （D）評估會談是人格衡鑑的方法之一

答案：（D）

詳解與考點

考點為人格衡鑑方法的正確敘述。評估會談確為人格衡鑑的重要方法之一，故 D 正確。陷阱：A 錯在自陳量表測的是「典型表現」而非「最大表現」；B 過度誇大投射測驗無任何標準；C 生理心理評量並非人格衡鑑的常用主流方法。

第 29 題

Groth-Marnat（2019）建議解釋症狀檢核表90修訂版（SCL-90- R）的順序是什麼？
  1. （A）整體指數→症狀向度→症狀程度／題目
  2. （B）症狀向度→症狀程度／題目→整體指數
  3. （C）整體指數→症狀程度／題目→症狀向度
  4. （D）症狀程度／題目→症狀向度→整體指數

答案：（A）

詳解與考點

考點為 Groth-Marnat 對 SCL-90-R 的解釋順序。建議由整體（GSI 等整體指數）入手，再看症狀向度，最後檢視個別症狀程度／題目，呈由廣到細的漏斗式解讀，故 A 正確。此題屬教科書特定建議，記憶導向，其餘順序皆不符其框架。

第 30 題

關於主題統覺測驗，下列敘述何者錯誤？
  1. （A）基本假定個人所編製的故事與其生活情境密切相關
  2. （B）所提供的刺激比羅夏克墨漬測驗有結構
  3. （C）解釋分析依據個人故事反應的數量而定
  4. （D）圖片內容多為人物與風景物象畫為主

答案：（C）

詳解與考點

考點為主題統覺測驗特性。題找「錯誤」，C 稱「解釋依故事反應數量而定」為誤——TAT 解釋重質性主題、需求與情節內容，而非量化反應次數（後者較近羅夏克的反應數計分）。A（故事與生活情境相關）、B（比墨漬有結構）、D（圖片多為人物畫）皆正確。

第 31 題

在臺灣身心障礙及資賦優異學生鑑定辦法中，對資賦優異的鑑定準則，下列何者錯誤？
  1. （A）在相關標準化測驗表現需高於平均數以上2個標準差，或達百分等級九十七以上者
  2. （B）專家學者、指導教師或家長皆可推薦，並檢附專長才能特質與表現的具體資料者
  3. （C）資賦優異的鑑定著重於鑑定潛能或傑出表現
  4. （D）鑑定單位由醫療機構進行

答案：（D）

詳解與考點

考點為身心障礙及資賦優異學生鑑定辦法。題找「錯誤」，D 稱「由醫療機構鑑定」為誤——資優鑑定由各縣市鑑輔會（鑑定及就學輔導會）依教育系統程序辦理，非醫療機構。A（高於平均 2 個標準差／PR97）、B（多元推薦檢附資料）、C（重潛能或傑出表現）皆符規定。

第 32 題

當採用認知訊息處理模式（cognitive information-processing model）協助個案探討決策歷程時，個案表示雖然知道自己可以選擇的選項，但卻很難決定這些選項對自己的優先排序。這位個案的狀態符合CASVE決策歷程的那一個步驟？
  1. （A）C
  2. （B）S
  3. （C）E
  4. （D）V

答案：（D）

詳解與考點

考點為認知訊息處理（CIP）的 CASVE 決策循環。個案已知選項卻難以排序、評估各選項對自己的價值，正是 V（Valuing，評估與排序）階段的任務，故 D 正確。陷阱是 S（Synthesis，產生選項）——個案已有選項，卡點不在產生而在價值排序。

第 33 題

做完Holland興趣類型的測驗後，小華覺得測驗不準，明明就覺得自己喜歡研究型的工作，但測驗結果卻顯示他的研究型興趣不高。遇到此一情況時，可用Holland提出的那個概念來和小華做討論？
  1. （A）適配性（congruence）
  2. （B）一致性（consistency）
  3. （C）認同性（identity）
  4. （D）分化性（differentiation）

答案：（C）

詳解與考點

考點為 Holland 理論概念辨識。小華自評興趣與測驗結果不符，反映其職業自我概念清晰度的議題，可用「認同性（identity）」即個人對自身目標、興趣、才能的明確穩定程度來討論，故 C 正確。陷阱是 A 適配性（人境媒合）與 D 分化性（類型高低落差），皆非處理自評與結果落差的核心概念。

第 34 題

下列四種測量工具，何者不是採用自比式（ipsative）題型編製而成的測驗？
  1. （A）職業評估量表（Career Assessment Inventory, CAI）
  2. （B）愛德華個人興趣量表（Edwards Personal Preference Schedule, EPPS）
  3. （C）庫德職業興趣量表（Kuder Occupational Interest Survey, KOIS）
  4. （D）傑克遜職業興趣調查表（Jackson Vocational Interest Survey, JVIS）

答案：（A）

詳解與考點

考點為自比式（ipsative）題型的辨識。自比式採強迫選擇、量尺間相互依存，EPPS、KOIS、JVIS 皆為代表；CAI 採常模參照計分而非自比式，故 A 為「不是」者。陷阱在 ipsative 概念冷僻，且四者皆為生涯興趣相關量表，易混淆。

第 35 題

使用DSM-5來判斷精神疾病個案時，下列那一項障礙症或症候群在診斷時須依據其「判斷嚴重度的標準」來加以註明？
  1. （A）躁症發作
  2. （B）特定場所畏懼症
  3. （C）恐慌發作
  4. （D）解離性身份障礙症

答案：（A）

詳解與考點

考點為 DSM-5 需註明嚴重度標準的診斷。躁症發作的診斷準則本身即依症狀對功能損害程度等界定其嚴重度註記，故 A 正確。其餘為較不確定之細項辨識；恐慌發作、特定畏懼症、解離性身份障礙症在嚴重度註明的處理方式與躁症不同。

第 36 題

徐曉慧是高三的學生，面臨學測壓力，又覺得自己成績跟不上，心情低落，不但讀書提不起勁，連他最喜歡的畫畫也不想畫了，以上的情形已經超過兩個星期。導師轉介心理評估，諮商心理師較適當的作法是下列何者？
  1. （A）對家長預警注意個案有自我傷害、危及生命的可能
  2. （B）先了解個案是否有自殺意念或計畫等，再判斷自殺風險及是否需要預警
  3. （C）先預警，預警對象不只是家長，還包括學校相關人員
  4. （D）立刻召開個案會議，討論如何分工合作，分擔風險

答案：（B）

詳解與考點

考點為憂鬱與自傷風險的衡鑑倫理程序。面對情緒低落逾兩週的個案，應先評估是否有自殺意念或計畫，據以判斷風險高低，再決定是否預警，故 B 正確。陷阱是 A、C 在未評估前即逕行預警，違反先評估後處置的順序；D 立即召開個案會議亦過早。

第 37 題

若參考Gordon Paul對於衡鑑報告撰寫所提出的「what, whom, this, that」看法，以協助處遇計畫的擬定，下列何者非主要的考慮因素？
  1. （A）個案特定的問題
  2. （B）需要何種治療計畫
  3. （C）選擇何種測驗
  4. （D）個案在特定環境下

答案：（C）

詳解與考點

本題依 Gordon Paul 的衡鑑核心提問，問「非」主要考慮因素者，官方答案為 (C)。Paul（1967）的經典命題在問：對「有此特定問題的這個人（what／whom），由誰來執行何種處遇（what treatment, by whom），在何種情境條件下（under which set of circumstances）最為有效」。其核心關注的是個案的特定問題、個案所處的特定情境，以及需要何種處遇計畫，目的在擬定處遇。對應之下，(A) 個案特定的問題、(B) 需要何種治療計畫、(D) 個案在特定環境下，都屬此架構的主要考慮因素；而 (C)「選擇何種測驗」是衡鑑工具的選擇問題，並非 Paul 此處遇配對命題所聚焦的主要因素，故 (C) 為正解。

第 38 題

實習諮商心理師在實習機構中使用心理測驗時，應該要注意與使用測驗有關的倫理議題，下列敘述何者錯誤？
  1. （A）在正式施測前，需要預先熟讀指導手冊內容
  2. （B）應在領有心理師執照的資深諮商心理師督導下，對個案進行施測
  3. （C）考慮專業學習的需要，應儘量練習使用機構中所有的心理測驗來對個案進行施測
  4. （D）實習諮商心理師所撰寫的衡鑑報告，需要與實習機構的督導討論確認後，再向個案解釋結果

答案：（C）

詳解與考點

考點為實習生使用測驗的倫理。題找「錯誤」，C 主張「儘量練習使用機構所有測驗對個案施測」為誤——測驗應依衡鑑目的審慎選用，不能為個人學習而對個案濫施測驗。A（熟讀指導手冊）、B（在督導下施測）、D（報告經督導確認再解釋）皆為正確倫理實務。

第 39 題

有關心理衡鑑的倫理，下列敘述何者錯誤？
  1. （A）原則上在衡鑑前應得到個案的同意
  2. （B）若個案為自願的國、高中生，可視情況或需要知會父母
  3. （C）法庭上的鑑定，可視情況而決定不需個案的簽名
  4. （D）十二歲以下兒童的評估需要經過家長的同意才可以進行

答案：（B）

詳解與考點

考點為心理衡鑑的同意與保密倫理。題找「錯誤」，B 稱「自願的國高中生可視情況知會父母」表述有偏差——未成年人衡鑑原則上仍須取得法定代理人同意，非僅「視情況」。A（事前同意）、C（法庭鑑定可免簽名）、D（12 歲以下需家長同意）皆符倫理規範。

第 40 題

下列何種測驗，施測者最需要接受特定的專業訓練？
  1. （A）區分性向測驗
  2. （B）魏氏兒童智力量表
  3. （C）庫德職業興趣量表
  4. （D）孟氏行為困擾調查表

答案：（B）

詳解與考點

考點為施測者所需專業訓練的程度。魏氏兒童智力量表（WISC）屬個別化、需嚴格標準化施測與計分的測驗，施測者須受特定專業訓練，故 B 最需。陷阱是其餘團體紙筆式的性向、興趣、行為困擾量表，施測程序相對簡易、訓練門檻較低。
