第 1 題

下列何者不是支持性團體的特性？
  1. （A）成員多為有共同議題者
  2. （B）領導者是團體主要的帶領角色
  3. （C）團體目標是促進成員彼此直接且個人化的交談
  4. （D）可能會與其他的諮商或成長團體性質重疊

答案：（B）

詳解與考點

考點為支持性團體特性。支持性團體成員多有共同議題、可與其他團體性質重疊，目標在促進成員彼此直接且個人化交談、相互支持。(B)「領導者是主要帶領角色」最不符，支持性團體以成員互助為核心，領導者多扮演催化而非主導者。陷阱在以一般諮商團體領導者較主導的印象誤判。

第 2 題

關於團體輔導、團體諮商、團體心理治療的比較，下列敘述何者錯誤？
  1. （A）皆需考量團體動力的運作，催化人際互動的產生
  2. （B）目的均希望協助成員有更好的生活適應及身心發展
  3. （C）側重的層面均需探究成員潛意識、過去成長史對人的影響
  4. （D）皆以心理學為基礎，運用科學、系統的方法，進行實務的操作

答案：（C）

詳解與考點

考點為團體輔導、諮商、治療三者比較。三者皆重團體動力、皆助適應與發展、皆以心理學科學方法為基礎。(C)稱三者「均需探究潛意識、過去成長史」錯誤，深度探討潛意識主要是團體心理治療層次，輔導與諮商未必深入至此。陷阱在把治療層次的深度工作泛化套用到三者，忽略其工作深度的層級差異。

第 3 題

關於自助團體（self-help group）與治療性團體（therapeutic group）的差異，下列敘述何者正確？
  1. （A）有心理疾病與嚴重心理健康問題之成員較不適合自助團體
  2. （B）治療性團體的探討主題比自助團體更聚焦而單一
  3. （C）自助團體的改變機制主要在於成員的互動和相互檢核
  4. （D）諮商心理師若參與自助團體，其角色應該要被界定為一般成員以避免干擾

答案：（A）

詳解與考點

考點為自助團體與治療性團體的差異。患有嚴重心理疾病者較需專業治療性團體，不適合僅靠同儕互助的自助團體，(A)正確。陷阱：(B)治療性團體主題未必更單一；(C)自助團體核心是同儕支持互助；(D)專業者參與自助團體不必然只能當一般成員。須掌握自助團體以同儕經驗分享為主、不替代專業治療的定位。

第 4 題

領導者發現成員彼此間有隱微的負向情緒，可能造成衝突的發生。下列敘述何者最不適當？
  1. （A）應儘可能的將敵意抺除，創造團體和平的氣氛
  2. （B）若團體凝聚力足夠，可適度鼓勵表達此負向情緒
  3. （C）團體氣氛、成員感受，與其是否能自由表達情感有關
  4. （D）團體衝突過多或過少都可能影響成員的人際學習經驗

答案：（A）

詳解與考點

考點為團體衝突與負向情緒的建設性處理。衝突與負向情緒若適當表達，可成為人際學習契機，不應一味抹除。(A)「儘可能抹除敵意、創造和平」最不適當，過度壓抑衝突反失去治療性。陷阱在直覺認為和諧才好，但團體治療重視在安全中表達與處理衝突，刻意消音反而剝奪成員的人際學習經驗。

第 5 題

在治療性團體的初期，關於領導者建立與維護規範的敘述，下列何者錯誤？
  1. （A）運用技術專家的角色形塑正向團體規範
  2. （B）運用隱微的社會增強技巧來形塑成員自在互動的溝通形式
  3. （C）仰賴理想的成員來發揮示範的效果
  4. （D）有時為了維持團體運作，會讓不適合團體的成員離開

答案：（C）

詳解與考點

考點為治療性團體初期領導者建立規範的方式：示範、社會增強、技術專家角色，必要時請不適合者離開。(C)「仰賴理想成員來示範」較不妥，規範建立應由領導者主動形塑，過度依賴特定理想成員並不可靠且不公允。陷阱在借助楷模似合理，但初期規範主責在領導者，把示範重任交付成員並非建立規範的正確主軸。

第 6 題

從不和諧理論（dissonance theory）來看團體異質性組合，下列敘述何者錯誤？
  1. （A）當個體處於一種不和諧狀態時，必須努力於改變或降低這種不和諧所帶來的不適感，如此有助於學習新行為
  2. （B）不和諧所帶來的挫折與挑戰，有助於展現另一種人際風格
  3. （C）團體應包含具有多種不同人際風格以及內在衝突的成員
  4. （D）團體異質性組合有助於凝聚力的產生，是理想的團體組成方式

答案：（D）

詳解與考點

考點為不和諧理論看團體異質性組合。適度不和諧帶來挑戰，促進新行為學習與人際風格展現，故主張納入不同人際風格成員。(D)稱異質組合「有助凝聚力、是理想組成」錯誤，異質性反易在初期降低凝聚力、製造張力。陷阱在把異質的學習價值誤推為有利凝聚；不和諧理論強調的是衝突帶來的成長，而非凝聚。

第 7 題

關於諮商團體開始階段的敘述，下列何者最適當？
  1. （A）尊重成員的狀態，並讓成員自己決定在團體中積極參與的程度
  2. （B）通常前兩次聚會成員處於不知所措的狀態，因此應採用高強度指導策略
  3. （C）成員易帶著「公共形象」參與團體，領導者宜設計活動讓成員卸下虛假的面具
  4. （D）團體開始前對成員進行篩選，不會影響成員參與團體彼此之間的信任感

答案：（A）

詳解與考點

考點為諮商團體開始階段的領導原則。初期宜尊重成員步調、由其自決參與程度，營造安全感，(A)最適當。陷阱：(B)初期採高強度指導易增防衛；(C)強行要成員卸下面具操之過急；(D)事前篩選其實會影響信任氛圍。開始階段重在建立安全與自主，而非強力推進或忽視篩選的影響。

第 8 題

根據Yalom對於進階（advanced）團體衝突的說明，下列敘述何者錯誤？
  1. （A）團體衝突是無法避免的，缺少時會阻礙團體發展
  2. （B）投射性認同（projective identification）是團體產生敵意及衝突的來源之一
  3. （C）競爭是團體衝突的來源之一
  4. （D）凝聚力越高的團體若發生衝突，更會帶來危機

答案：（D）

詳解與考點

考點為 Yalom 對進階團體衝突的觀點：衝突不可避免、缺少反阻礙發展，投射性認同與競爭皆為衝突來源。(D)稱「高凝聚力團體若衝突更會帶來危機」錯誤，高凝聚力反而提供承載衝突的安全基礎，使衝突可被建設性處理。陷阱在直覺以為凝聚力高者一衝突就崩，實則凝聚力是化解衝突的保護因子。

第 9 題

關於領導者處理團體結束階段的敘述，下列何者正確？
  1. （A）當領導者經驗到團體結束時不舒服的感受，應與督導討論，而非跟成員分享經驗
  2. （B）領導者鼓勵成員分享團體外愉快的經驗，可協助成員處理團體結束的痛苦
  3. （C）領導者應協助成員收集彼此的聯絡資訊、安排社交聚會，以協助度過失落的感受
  4. （D）成員可能會否認或忽略團體結束的感受，領導者應帶領成員正視即將結束的事實

答案：（D）

詳解與考點

考點為團體結束階段的處理。領導者應協助成員正視、面對即將結束的失落，因成員常否認或迴避結束感受，(D)正確。陷阱：(A)領導者適度分享自身感受可示範；(B)只談團體外愉快經驗是迴避結束；(C)鼓勵互留聯絡、安排聚會反妨礙好好道別。結束階段核心是直面失落而非繞開或延續。

第 10 題

在人際取向的諮商與心理治療團體初期，領導者的帶領策略，何者最不適當？
  1. （A）採取歷程取向的而非內容取向的領導策略
  2. （B）運用團體資源協助成員解決問題
  3. （C）使用示範來建立團體信任感
  4. （D）幫助成員訂定個人的目標

答案：（B）

詳解與考點

考點為人際取向團體初期的領導策略：採歷程取向、用示範建信任、協助訂個人目標。(B)「運用團體資源協助成員解決問題」最不適當於初期，初期重在建立關係與此時此刻歷程，急於解決問題屬較後期工作。陷阱在解決問題聽來積極，但人際取向初期聚焦歷程與信任，問題解決並非初期重點。

第 11 題

面對團體的轉換階段，下列領導者的行為，何者最不適當？
  1. （A）清楚了解該階段的特徵與動力的發展
  2. （B）理性分享自己在轉換階段中的焦慮與抗拒
  3. （C）支持成員彼此之間可以相互依賴，並擁有自主性
  4. （D）協助成員面對焦慮與處理防衛，以及成員間的衝突

答案：（B）

詳解與考點

考點為團體轉換（轉換）階段的領導行為。領導者宜了解該階段特徵、協助成員面對焦慮防衛與衝突、支持自主與適度互賴。(B)「理性分享自己在轉換階段的焦慮與抗拒」最不適當，領導者過度暴露自身焦慮恐動搖團體穩定。陷阱在自我揭露通常正向，但轉換期領導者宜穩住容器，分享自身抗拒易反成干擾。

第 12 題

對於已進入工作階段的大學生自我探索諮商團體，每次聚會為2小時，下列領導者的行為何者最適當？
  1. （A）每次在設計活動方案時，會額外準備一個計畫，以備不時之需
  2. （B）每次聚會皆聚焦在一兩位最需要協助的成員，以深化團體療效並提升利他性治療因素
  3. （C）每次聚會開始時讓成員相互噓寒問暖20分鐘，除可增加團體凝聚力外，亦可作為暖身活動
  4. （D）某次聚會內容設計為觀看與自我探索相關電影100分鐘，之後進行15分鐘的心得分享與討論

答案：（A）

詳解與考點

考點為工作階段的領導行為與方案規劃。專業領導者會預備備案以應變，(A)最適當。陷阱：(B)只聚焦一兩位會排擠其他成員；(C)每次開場閒聊 20 分鐘過長、稀釋工作時間；(D)看 100 分鐘電影僅留 15 分鐘討論，比例失衡、壓縮處理。工作階段重在有效運用時間深化全體成員的探索。

第 13 題

Corey建議學習者可逐步發展團體領導者的特質，下列敘述何者最正確？
  1. （A）願意開放自己的感受，並在有情緒感受時能立即表達
  2. （B）對團體歷程的價值深具信心，相信適度催化，團體自有療效
  3. （C）努力幫助所有成員改變，形成記錄做為下個團體希望感的示範
  4. （D）修習更高的學歷，在團體中多說明自己曾經帶領過的成功經驗

答案：（B）

詳解與考點

考點為 Corey 對團體領導者特質的建議。領導者應對團體歷程價值有信心，相信適度催化下團體本身具療效，(B)最正確。陷阱：(A)有情緒就立即表達未必妥當，需專業判斷時機；(C)強求所有成員改變不切實際；(D)炫耀學歷與成功經驗無助領導效能。核心在信任歷程與催化，而非控制或自我表現。

第 14 題

領導者帶領大學生人際關係團體時，對於那些成員間的對話需要設限？
  1. （A）你到底交過多少女朋友？你跟她們都有過性行為嗎？
  2. （B）你有過被同學背叛的經驗！其實我也有過
  3. （C）我覺得只要講真話就會得罪人，怎麼做都無法讓同學滿意？所以同學間不需要說清楚
  4. （D）你喜歡XX明星嗎？我超喜歡她的，她不僅有才藝又很漂亮

答案：（A）

詳解與考點

考點為團體中需設限的對話。涉及隱私、具侵犯性或可能造成傷害的探問需設限，如(A)逼問交往對象數量與性行為，過度侵犯隱私，須設限。陷阱在其他選項（談背叛經驗、表達溝通困惑、聊喜歡的明星）屬一般自我揭露或閒談，無傷害性。設限針對的是侵犯性、傷害性的內容，而非單純話題輕重。

第 15 題

關於繞圈發言技術的敘述，下列何者最適當？
  1. （A）可用在團體開場的對焦，以及活動結束後的感受整理
  2. （B）繞圈通常由領導者左手邊做開始，最後結束在領導者右手邊
  3. （C）是最常用的技術，幾乎不需任何設計，團體沉默時就可使用
  4. （D）僅適宜能用一句話、一個詞或數字簡單表達意見的時機，以免占用團體時間

答案：（A）

詳解與考點

考點為繞圈發言技術的適用。可用於團體開場對焦與活動結束後的感受整理，讓每位成員都有發言機會，(A)最適當。陷阱：(B)繞圈方向不必固定左到右；(C)並非可在任何沉默時隨意使用；(D)繞圈不限於一句話/數字的簡短表達，也可用於較完整分享。繞圈核心在普及參與與聚焦，而非死板規則。

第 16 題

關於使用回饋（feedback）的敘述，下列何者最不適當？
  1. （A）團體初期儘量不使用面質性和矯正性回饋
  2. （B）成員彼此使用措辭不當的矯正性回饋易產生反效果
  3. （C）對衝突較高的成員提供消極性回饋易產生正向效果
  4. （D）對整個團體給予任務回饋，有助於凝聚力的發展

答案：（C）

詳解與考點

考點為回饋（feedback）的運用原則。初期少用面質與矯正性回饋、措辭不當的矯正回饋易反效果、團體任務回饋助凝聚。(C)稱「對衝突高的成員給消極性回饋易產生正向效果」最不適當，對衝突成員施以消極回饋恐加劇對立。陷阱在誤以為負面回饋能矯正衝突者，實則更可能激化防衛與衝突。

第 17 題

關於Yalom對團體凝聚力（group cohesiveness）的看法，下列何者錯誤？
  1. （A）在團體中被接納與重視，常常是團體成員改變的主要助力
  2. （B）團體凝聚力有助於成員避免團體早期的挫折感
  3. （C）團體凝聚力提供了成員安全感及精神支持
  4. （D）高凝聚力的團體，成員能放心地自我探索，尋求人際間的回饋與實驗新的行為

答案：（B）

詳解與考點

考點為 Yalom 的團體凝聚力（cohesiveness）概念。凝聚力提供被接納、安全感與支持，使成員敢自我探索與實驗新行為，是改變主力。(B)稱「凝聚力有助成員避免早期挫折感」錯誤，凝聚力屬團體逐漸發展的成果，早期挫折感仍難避免。陷阱在凝聚力的諸多益處中，混入「避免早期挫折」這一不成立的功能。

第 18 題

領導者在非治療性團體中，遇到特定成員可能需要心理治療時，下列何種反應最不適當？
  1. （A）思考與決定此時此刻進行治療是否有足夠的時間
  2. （B）思考與判斷自己的專業訓練是否能夠承擔治療的責任
  3. （C）徵詢其他成員是否願意將團體焦點改換到對該成員的簡短治療
  4. （D）鼓舞該成員機不可失，立即建議他在團體中接受協助

答案：（D）

詳解與考點

考點為非治療性團體中遇成員需心理治療時的處理。領導者應先評估時間是否足夠、自身專業能否承擔責任、是否徵詢他人。(D)「鼓動成員機不可失、立即在團體中接受治療」最不適當，未經審慎評估即倉促治療不負責任。陷阱在「把握機會」聽似積極，但跨越團體性質界限、未評估準備度即施治療並不專業。

第 19 題

成員甲在前一次團體因深度揭露，在團體進行到中途暫時離開，回到團體時表示謝謝大家的關心；然而在本次團體開始後，原本都很準時出席的甲卻沒有出現，團體此時的討論有點散漫，出現沉默的互望。下列領導者的作法，何者最不適當？
  1. （A）描述前次及這次的團體現象，請成員分享對此現象的想法
  2. （B）反映甲這次沒有出現，似乎對今天的團體產生了影響
  3. （C）在沉默時，請成員繞圈說說現在的感受或在想什麼
  4. （D）建議成員回到前次討論熱烈的話題，帶回高峰氣氛

答案：（D）

詳解與考點

考點為深度揭露成員缺席後的團體處理。領導者宜描述團體現象、反映該成員缺席的影響、以繞圈邀請成員表達當下感受。(D)「建議回到前次熱烈話題、帶回高峰氣氛」最不適當，迴避了缺席與此時此刻的情緒，屬逃避歷程。陷阱在想重拾正向氣氛似善意，實則否認當下動力、錯失處理團體真實感受的契機。

第 20 題

關於團體成員間有衝突或敵意時的處理，下列何者最不適當？
  1. （A）領導者可以在衝突當下面質雙方，使他們有不同於過往的經驗
  2. （B）衝突若是來自其中某成員特異的行為型態，建議其離開團體，轉介個別諮商
  3. （C）成員衝突可能是團體外的人際互動型態，領導者可運用團體來協助成員有新的洞察
  4. （D）當衝突嚴重，必要時可請其中一位或兩位成員離開團體

答案：（A）

詳解與考點

考點為團體衝突或敵意的處理。可運用團體協助新洞察、必要時請成員離開，但面質須謹慎。(A)「在衝突當下直接面質雙方」最不適當，衝突高張時立即面質易升高對立、傷害成員。陷阱在面質是有力技術，但時機錯誤（衝突當下）反成傷害；處理衝突宜先穩定情緒、營造安全，而非火上加油的即時面質。

第 21 題

關於團體成員沉默的處理，下列何者最不適當？
  1. （A）團體初期，領導者不用刻意打破沉默，等待成員發言即可
  2. （B）從團體發展歷程來看，成員沉默易在團體初期發生
  3. （C）團體中，當成員思考某個事件或議題時，領導者不宜太快打破沉默
  4. （D）成員環顧團體、迴避眼神接觸、等別人分享的沉默是正常的，領導者無需做太多介入

答案：（D）

詳解與考點

考點為團體沉默的處理。沉默常見於初期、成員思考時不宜太快打斷。(D)稱成員迴避眼神、等他人分享的沉默「正常、領導者無需太多介入」最不適當，這類迴避型沉默常反映焦慮防衛，領導者宜適度介入催化。陷阱在把所有沉默都當自然現象放任，忽略了迴避性沉默背後的人際焦慮需被處理。

第 22 題

移情可以是團體歷程的有效治療工具，但領導者必須善加利用並解決它。下列何者是Yalom提到促進移情解決的方法之一？
  1. （A）加強成員篩選工作
  2. （B）催化成員自我揭露
  3. （C）進行一致性確認
  4. （D）減少領導者的透明度

答案：（C）

詳解與考點

考點為 Yalom 對移情（transference）解決的方法。促進移情解決的途徑之一是「進行一致性確認（consensual validation）」，讓成員透過他人回饋核對自己的知覺扭曲，(C)正確。陷阱為(D)減少領導者透明度，方向相反；Yalom 主張適度增加領導者透明度才有助移情澄清。一致性確認是化解移情扭曲的關鍵機制。

第 23 題

關於保護成員免於參加團體可能遇到的風險，下列何者錯誤？
  1. （A）謹慎地篩選團體成員
  2. （B）提醒已經做出情緒宣洩的成員不要退出團體
  3. （C）鼓勵成員將團體所學應用到生活中的重大決定
  4. （D）強調成員自己決定要探討什麼及探索的深度

答案：（C）

詳解與考點

考點為團體成員的保護倫理。正解C錯誤：諮商倫理強調團體所學需審慎驗證後再應用，鼓勵成員把團體經驗直接套用到「重大」人生決定，反而可能造成傷害，違反保護成員原則。主要陷阱在B，提醒做過情緒宣洩的成員別中途退出，是合理的善後保護，並非錯誤。

第 24 題

關於團體諮商的倫理考量，下列何者正確？
  1. （A）當團體成員猶豫不決是否要揭露特定資訊時，領導者應介入瞭解其困擾及說明保密原則
  2. （B）領導者應鼓勵成員做深入探索，以增加個人成長
  3. （C）領導者應建議有自傷危機的成員，同時與領導者做個別諮商及團體諮商
  4. （D）領導者應對自己的受訓背景保密，以避免發生雙重關係

答案：（A）

詳解與考點

考點為團體諮商倫理。正解A正確：成員猶豫揭露時，領導者宜介入了解困擾並說明保密規範，協助知情決定。陷阱在C，安排同一領導者同時做個別與團體諮商易形成雙重關係與資訊界線問題，並非適當建議；D要求對受訓背景保密更違反告知義務。

第 25 題

關於團體諮商中非自願個案的處理策略，下列敘述何者錯誤？
  1. （A）當有兩個或兩個以上的團體時，可以尊重個案的選擇來安排團體諮商
  2. （B）領導者應該儘可能的讓非自願個案瞭解團體相關事宜，例如團體性質、主題與目標......等
  3. （C）團體初期宜避免非自願個案分享對於參與團體的感受，例如失去選擇的自由、對團體的擔心與害怕等，以增加團體凝聚力
  4. （D）事先告知非自願個案會將其在團體中的表現與進步等，會被回報給轉介單位，讓非自願個案在知情的情況下，決定自己如何參與團體

答案：（C）

詳解與考點

考點為非自願個案處理。正解C錯誤：團體初期應允許並接納非自願成員表達抗拒、被迫感與擔憂，這正是建立信任與凝聚的關鍵；刻意避免反而壓抑情緒。陷阱在D，事先告知會回報轉介單位看似不利，實則是知情同意的正確做法。

第 26 題

關於團體領導者的能力養成與技術運用，下列敘述何者不符合倫理考量？
  1. （A）領導者須具有敏銳的自我覺察，並瞭解個人特質對於團體的影響
  2. （B）使用各種技術來測試團體成員的反應與想法，以增進領導者的技術熟練度與能力
  3. （C）熟悉團體諮商的歷程階段和成員角色，具備團體動力和團體治療的基礎知識
  4. （D）使用團體技術時應預先保留充分時間，以處理成員高漲的情緒

答案：（B）

詳解與考點

考點為領導者能力養成的倫理。正解B不符倫理：把成員當作練習技術的對象、以「測試反應」來精進自己，是把成員工具化，違反成員福祉優先。其餘自我覺察、具備團體動力知識、預留處理情緒時間皆為合宜的專業能力要求。

第 27 題

根據Yalom對個別諮商與團體諮商效果的整理，下列何者錯誤？
  1. （A）在團體中，因為領導者與成員的專注傾聽，使成員比在個別諮商時更易沈迷與專注於自我狀態
  2. （B）在團體中，當成員A給B建議時，此歷程可能因為A傳達的是對於B的興趣與關懷，而對團體有助益
  3. （C）成員會帶著與家人互動或衝突的方式，與領導者及其他成員互動，這些衝突在個別諮商中會較晚出現
  4. （D）對自戀型的當事人而言，團體諮商較會使當事人被注意的渴求浮現

答案：（A）

詳解與考點

考點為Yalom對個別與團體治療效果的比較。正解A錯誤：團體中成員注意力分散於眾人互動，較不會比個別諮商更「沈迷專注於自我狀態」，此敘述與團體特性相反。其餘關於人際回饋、家庭衝突重現、自戀者渴求浮現皆符合Yalom觀點。

第 28 題

關於老人哀傷失落團體的敘述，下列何者最適當？
  1. （A）老人多數已經歷過多種不同的死亡事件，故而面對重要他人過世事件，其影響已較不嚴重
  2. （B）為避免老人重新經歷失去親人的痛苦，宜在團體中教導成員隔離接觸已逝者物品的重要性
  3. （C）哀傷團體的目的不在協助儘快回復正常，而是在共同陪伴中接納哀傷過程會產生的各種反應
  4. （D）在團體過程中，宜儘量避免擁抱或各種身體接觸的活動設計，以預防哀傷團體中產生依賴或移情的後果

答案：（C）

詳解與考點

考點為老人哀傷失落團體。正解C最適當：哀傷團體目的不在催促回復常態，而是在陪伴中接納哀傷歷程的各種反應。陷阱在A，認為老人經歷多次死亡故影響已減輕，忽略每次失落的獨特性；隔離遺物、禁止身體接觸亦非適當原則。

第 29 題

關於安心減壓團體的敘述，下列何者錯誤？
  1. （A）目的在支持情緒，而非挖掘創傷
  2. （B）通常只進行一次
  3. （C）成員同質性愈高愈好
  4. （D）主要任務是鼓勵成員自由發言

答案：（D）

詳解與考點

考點為安心減壓團體（危機後減壓）。正解D錯誤：此類團體聚焦支持情緒與心理教育，並非「鼓勵自由發言」深挖創傷，過度宣洩反有二次傷害風險。其餘支持情緒不挖創傷、通常單次、成員同質性高皆為其特徵。

第 30 題

在大學校園中要舉辦人際關係的諮商團體，關於成員的篩選，下列何者最不正確？
  1. （A）篩選是領導者與報名成員的雙向溝通過程
  2. （B）篩選的程序常是主觀的，而且領導者的直覺和判斷也是重要的
  3. （C）主要考量是導師及報名成員都認為可以從團體中獲益
  4. （D）領導者要確認成員的需求、期待與團體目標的相符合程度

答案：（C）

詳解與考點

考點為團體成員篩選原則。正解C最不正確：篩選的核心是成員需求與團體目標的契合，而非「導師認為可獲益」這類第三方主觀判斷。其餘雙向溝通、領導者直覺判斷、確認需求與目標相符皆為正確的篩選考量。

第 31 題

關於個人中心諮商與心理治療應用於國小學童促進自我概念團體，下列敘述何者正確？
  1. （A）領導者會協助成員更開放並積極自我表達
  2. （B）領導者會協助成員留意別人對自己的評價，並加以判斷是否正確
  3. （C）領導者主要應用家庭作業協助成員自我表達
  4. （D）領導者會將感受到的團體情緒及意義留給自己，且引導成員正向思考

答案：（A）

詳解與考點

考點為個人中心學派應用於兒童團體。正解A正確：個人中心強調無條件接納，協助成員開放並積極自我表達。陷阱在B，引導成員留意並判斷別人的評價，違反個人中心重視內在評價而非外在評價的精神；C家庭作業屬行為取向；D把團體情緒留給自己違反真誠一致。

第 32 題

關於心理劇中的主角（protagonist），下列敘述何者正確？
  1. （A）依據Zerka Moreno觀點，心理劇成員人人都是主角
  2. （B）團體需求與期望優先於主角的偏好
  3. （C）導演和輔角的作用是為了服務主角
  4. （D）導演是心理劇中想像的源頭

答案：（C）

詳解與考點

考點為心理劇的主角角色。正解C正確：導演與輔角的功能都是為服務主角而存在。陷阱在A，「人人都是主角」與心理劇單一主角的設計不符；B團體需求優先於主角偏好亦與主角中心相反；D導演非想像源頭，想像源頭是主角。

第 33 題

家暴加害人團體中，領導者將焦點放在肯定成員的能力，負起自身責任以解決問題，而不是強調成員的人格弱點與心理病理。下列何者最可能是領導者的理論取向？
  1. （A）家庭動力取向
  2. （B）心理動力取向
  3. （C）焦點解決取向
  4. （D）個人中心取向

答案：（C）

詳解與考點

考點為辨識諮商理論取向。正解C焦點解決取向：聚焦肯定成員既有能力、承擔責任解決問題，而非探究人格弱點與病理，正是焦點解決的優勢觀點。陷阱在B心理動力，恰好相反地著重內在病理與潛意識，與題幹描述方向衝突。

第 34 題

關於當代認知行為取向團體，下列敘述何者錯誤？
  1. （A）領導者會搭配「以接納為本」（acceptance-based）的內觀技巧訓練
  2. （B）強調教導成員將習得的技巧應用於日常生活中，而能過自我引導的生活
  3. （C）每次團體的開始會請成員報告一週來的進展、作業，及當次聚會欲處理的主題
  4. （D）整個團體過程中皆強調自我負責，團體結束之後並不會做追蹤

第 35 題

進行失業者敘事治療支持團體時，關於領導者的引導方向，下列何者最為適當？
  1. （A）不要讓每位成員敘說個人的失業故事，以免造成強大的無力感
  2. （B）在外化失業問題時，接納成員為自己的失業找藉口
  3. （C）透過解構個人失業，體驗主流社會經濟不景氣與勞動法規不公平的論述與影響
  4. （D）失業者也可以支持失業者，彼此可以見證新故事的發展

答案：（D）

詳解與考點

本題問失業者敘事治療支持團體中領導者「最適當」的引導方向，官方答案為 (D)。敘事治療支持團體重視成員間的見證（witnessing）與會員重新整合（re-membering），由失業者支持失業者、彼此見證並協助新故事（偏好故事）的發展，最貼近支持團體的精神與本題情境，故 (D) 最適當。(A) 不當：敘說個人故事正是敘事治療的核心，刻意不讓成員敘說，反而剝奪外化與重寫故事的機會。(B) 不當：外化（externalizing）是把問題與人分開，並非接納或鞏固「為失業找藉口」的卸責說法。(C) 雖然敘事治療確實重視解構主流論述、看見社會經濟與制度脈絡，方向本身並無錯，但本題問「最適當」，(C) 偏向引導成員聚焦於控訴外部結構，較不及 (D) 直接促成成員相互支持與新故事的共構，故相較之下仍以 (D) 為最佳。

第 36 題

關於青少年團體的敘述，下列何者最不適當？
  1. （A）要運用結構性較低的團體來進行
  2. （B）帶領方式要讓團體變得有趣
  3. （C）成員最理想人數是6～8人
  4. （D）留意保密性議題，破壞保密的協定可能得離開團體

答案：（A）

詳解與考點

考點為青少年團體帶領。正解A最不適當：青少年團體通常需要較高結構性以維持安全與聚焦，過低結構易失序，「結構性較低」敘述有誤。其餘趣味化帶領、理想6至8人、重視保密並訂破壞保密的後果皆為適當原則。

第 37 題

關於兒童中心學派的團體遊戲治療的敘述，下列何者最不適當？
  1. （A）不強調團體凝聚力，每一位成員可以各自從事活動，而不和其他成員有關係
  2. （B）團體遊戲治療的一個轉折就是兒童可以從「玩出（playing out）」到「說出（saying out）」
  3. （C）團體遊戲中的玩具及成員的遊戲，可以提供象徵性的發洩管道
  4. （D）領導者對兒童的接納和尊重，可以產生替代父母（parent surrogate）的正向效果

答案：（B）

詳解與考點

考點為兒童中心遊戲治療團體。正解B最不適當：兒童中心強調以遊戲本身作為表達媒介，不刻意要求兒童從「玩出」轉為「說出」，此種強迫口語化的轉折不符該學派精神。其餘象徵性發洩、替代父母的接納效果、不強求凝聚力皆為合理特徵。

第 38 題

領導者帶領性侵害倖存者復原團體的介入原則，下列敘述何者最為正確？
  1. （A）團體目標、規則及聚會頻率到第一次聚會再跟所有成員討論，不需事先告知
  2. （B）團體人數不宜過多，以免無法兼顧成員心理需求與個別狀況
  3. （C）挑選成員時，最好確定其進入團體後，再同時安排個別諮商較為安全
  4. （D）領導者應在團體過程中鼓勵成員鉅細靡遺地討論他們的創傷經驗

答案：（B）

詳解與考點

考點為性侵倖存者復原團體介入原則。正解B最正確：團體人數宜少以兼顧個別心理需求與安全。陷阱在D，鼓勵鉅細靡遺重述創傷易造成二次傷害，並不適當；A目標規則延到首次才談違反事前知情；C成員與安全安排敘述亦不妥。

第 39 題

自閉症兒童家長支持團體的中期，某成員提出他長久以來的困境：教養這樣的孩子，承受了很多的親族壓力，也感到自卑……。下列領導者的介入，何者最不適當？
  1. （A）鼓勵該成員敘說更多他的故事，確認其困境與情緒，並將團體焦點都放在他身上
  2. （B）鼓勵其他成員分享類似經驗，將困境主題擴展到大部分成員都可以參與分享與討論的議題
  3. （C）邀請曾有類似經驗但現在已經走過來的成員分享其成功經驗
  4. （D）在分享與討論該主題後，邀請所有成員回顧對這段互動經驗的感受、看法與學習

答案：（A）

詳解與考點

考點為支持團體中期的領導介入。正解A最不適當：把團體焦點長時間集中在單一成員身上，忽略其他成員參與，違反團體共通性與普同感的運用。其餘擴展為共通議題、邀請過來人分享成功經驗、引導全員回顧學習皆為適當的團體層次介入。

第 40 題

許多領導者帶領成對伴侶馬拉松團體後會舉辦追蹤聚會，其主要目的為何？
  1. （A）探討先前團體未及處理的議題
  2. （B）完成團體的結束與分離任務
  3. （C）支持和強化曾處理過的改變
  4. （D）回顧與檢視先前團體的歷程

答案：（C）

詳解與考點

考點為馬拉松伴侶團體追蹤聚會的目的。正解C：追蹤聚會主要在支持與強化先前團體已處理過的改變，鞏固成效。陷阱在D（回顧歷程）與A（處理未竟議題），這些屬團體結束時或新團體的工作，並非追蹤聚會的主要功能。
