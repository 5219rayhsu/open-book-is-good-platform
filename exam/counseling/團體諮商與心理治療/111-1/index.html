第 1 題

關於團體輔導、團體諮商或團體治療的敘述，下列何者正確？
  1. （A）有些諮商理論較適用於團體輔導，有些則較適用在團體治療
  2. （B）新手諮商心理師帶領團體輔導比較好
  3. （C）學校場域不會開設團體治療
  4. （D）團體輔導較著重在主題的傳達，團體諮商則在成員內在心理的探究

答案：（D）

詳解與考點

考點為團體輔導、諮商、治療三者的層次區別。正解D：團體輔導偏重主題/資訊傳達，團體諮商更深入成員內在心理探究。陷阱在A：理論取向並非以「適合輔導或治療」二分，敘述以偏概全，易因看似合理而誤選。

第 2 題

下列那一種成員最可能被排除在異質性門診病人的治療團體之外，主要原因為其無法參與團體的重要任務？
  1. （A）妄想症患者
  2. （B）厭食症患者
  3. （C）胃癌術後患者
  4. （D）憂鬱症患者

答案：（A）

詳解與考點

考點為異質門診治療團體的成員篩選與排除。正解A妄想症患者：其多疑與現實扭曲使其難以建立信任、參與互動性團體任務，常被排除。陷阱在D憂鬱症：憂鬱者一般仍能參與互動性團體，反而適合，易誤選為最該排除者。

第 3 題

關於成長與經驗性團體的團體動力敘述，下列何者正確？
  1. （A）領導者須特別注意成員們個別行為的改變
  2. （B）大部分的成員出現負向的感受時，領導者最好把焦點放在少數成員所關心的議題上
  3. （C）成員間對於彼此的感覺是最重要的團體動力
  4. （D）當成員間的競爭性升高時，是一種有利的團體動力，可促進團體療效

答案：（C）

詳解與考點

考點為成長/經驗性團體的團體動力核心。正解C：成員彼此間「此時此地」的感受互動是最重要的團體動力。陷阱在D：把「競爭性升高」當成有利動力，但過度競爭通常不利凝聚與安全感，敘述方向錯誤，易誤選。

第 4 題

關於團體氣氛與治療效果的敘述，下列何者錯誤？
  1. （A）凝聚力是一種療效因子，也是團體健康的直接特徵
  2. （B）成員集體的依附型態較個人的依附型態能預測團體氣氛
  3. （C）團體衝突具有治療功能，沒有衝突可能會減少人際學習
  4. （D）團體氣氛愈傾向參與和工作導向時，成員的改變愈多

答案：（A）

詳解與考點

考點為團體氣氛與凝聚力的療效角色。正解A錯誤：凝聚力是團體療效的「必要條件/間接基礎」，多被視為近似個別治療的關係，把它說成「健康的直接特徵」過度簡化。陷阱在C衝突具治療功能：此為正確觀念，易被誤判為錯。把握度偏低。

第 5 題

領導者邀請某一成員分享對當前團體互動狀況的感受或想法，此成員卻是基於過去團體互動所衍生的感受或想法給予回應。Yalom稱此現象為下列何者？
  1. （A）置換（displacement）
  2. （B）後設溝通（metacommunications）
  3. （C）毐性扭曲（parataxic distortion）
  4. （D）高腳杯議題（goblet issues）

答案：（A）

詳解與考點

考點為Yalom的人際互動概念。正解A置換（displacement）：成員把對過去團體互動的情緒「轉移」到當前情境回應，屬置換。陷阱在C毒性扭曲（parataxic distortion）：扭曲指以過去關係模式錯誤知覺「現在的人」，與單純情緒移置有別，最易混淆。

第 6 題

小美在團體裡說：「我害怕對大家說話，我擔心有人會批評我，不想和我做朋友。在團體前我都一直練習，希望能把話說清楚，不要引起誤會。」在不同團體階段，領導者對小美的處理，下列何者最不適當？
  1. （A）在開始階段，領導者鼓勵其他成員也談談自己的擔心，特別是別人怎麼看待自己的部分
  2. （B）在轉換階段，領導者詢問小美：「在這個團體裡，有那些事是你曾經想過或感覺到，但你沒有說出來的？」
  3. （C）在工作階段，領導者邀請其他成員聽完小美的擔心後，分享、回饋或表達接納
  4. （D）在結束階段，領導者詢問小美：「當你出現這些擔心時，誰最容易讓你有這樣的感覺？」

答案：（D）

詳解與考點

考點為依團體階段選擇最適處遇。正解D屬「最不適當」：結束階段應收斂統整，卻去深挖「誰最讓你有此感覺」是開啟新議題，時機不符。陷阱在B轉換階段邀其說出未說的話，符合階段任務，易被誤認不當而選錯。

第 7 題

某機構的諮商心理師準備招募長期性的人際互動治療團體，關於團體的籌備、成員的招募與篩選的考量，下列何者最不適當？
  1. （A）明顯的和其他成員格格不入的「特異人士」，都應避免將之納入團體中
  2. （B）成員的組成是重要且需慎重考慮的議題，因此團體前的篩選是必要的程序
  3. （C）最好篩選出人際風格一致的成員，以避免團體衝突發生
  4. （D）成員是否能夠穩定出席、全程參與是重要的考慮

答案：（C）

詳解與考點

考點為長期人際團體的成員組成原則。正解C最不適當：刻意只選「人際風格一致」以避免衝突，反而削弱人際學習與多元互動，違背異質互動的療效。陷阱在A排除明顯格格不入者：屬合理篩選原則，易被誤當錯誤而選錯。

第 8 題

關於領導者對團體發展階段的評估方式，下列何者最適當？
  1. （A）根據團體進行的次數來評估
  2. （B）根據團體的方案設計的進展來評估
  3. （C）根據成員的關係發展程度來評估
  4. （D）根據團體動力與成員互動狀況來評估

答案：（D）

詳解與考點

考點為團體發展階段的評估依據。正解D：應依「團體動力與成員互動狀況」判斷階段，而非僅次數或方案進度。陷阱在A以進行次數評估：次數只是表面指標，階段未必與次數對應，最易被當成簡便標準而誤選。

第 9 題

關於團體結束階段時領導者的主要任務，下列何者最不適當？
  1. （A）增進團體成員間的高凝聚力
  2. （B）處理成員面對分離的情緒
  3. （C）幫助成員統整所學
  4. （D）促進成員之間給予與接受建設性的回饋

答案：（A）

詳解與考點

考點為團體結束階段的主要任務。正解A最不適當：結束階段應處理分離、統整所學與回饋，而非再去「增進高凝聚力」（凝聚屬前期/工作期任務）。陷阱在D給予接受回饋：屬結束期重要任務，易誤判為不當而選錯。

第 10 題

在團體轉換階段，成員甲生氣地說：「在這裡不管我說什麼或做什麼，好像都『不對』一樣，我不知道什麼才是『對的』，為什麼我不能用自己的方法來做？」下列領導者的回應，何者最不適當？
  1. （A）我沒有在檢核你的對錯，我關心的是你要怎麼做才能達到自己訂定的目標
  2. （B）我沒有在檢核你的對錯，我只是希望你不要再逃避談論生活中困難的部分
  3. （C）在團體裡，你想要怎麼做，對你是最有幫助的？
  4. （D）可以請你多說一些，在團體裡有那些部分對你有幫助或沒有幫助

答案：（B）

詳解與考點

考點為轉換階段面對抗拒成員的回應品質。正解B最不適當：「希望你不要再逃避」帶評價與指責，易升高防衛。陷阱在A：同樣以「我沒在檢核對錯」開頭但聚焦於協助達成其目標，較具支持性，易與B混淆而誤選。

第 11 題

芬芳終於在團體裡開口了：「我不說話是因為不管我說什麼，都會有人不同意我的看法，甚至還會批評我，這讓我很難過。」若此時團體已進入工作階段，根據Corey等人的建議，領導者的回應，下列何者最適當？
  1. （A）「當你心裡出現這個擔心時，你覺得團體裡那一個人最可能會批評你？」
  2. （B）「你可以自己決定在團體中說或不說」
  3. （C）「如果沒有了這個擔心，你在這個團體裡會有什麼不一樣？」
  4. （D）「不知有誰和芬芳有同樣的擔心？」若其他成員分享了同樣的狀況，接著請其他成員直接跟芬芳談談她的擔心

答案：（C）

詳解與考點

考點為工作階段促進成員探索的回應，依Corey建議。正解C：以例外/未來導向問句「沒有這擔心會有什麼不一樣」，推動覺察與改變。陷阱在B「你可自己決定說或不說」：屬尊重但較消極、未促進工作，工作階段宜更積極推進，易誤選。

第 12 題

下列何者不是暖身活動的功能？
  1. （A）為團體打破僵局
  2. （B）增加團體凝聚力
  3. （C）為主要活動作準備
  4. （D）預告下次團體的主題

答案：（D）

詳解與考點

考點為暖身活動的功能。正解D屬「非功能」：預告下次主題是收尾/銜接工作，不是暖身的目的。陷阱在B增加凝聚力：暖身確能促進初步連結與凝聚，屬正當功能，易被誤判為非功能而選錯。

第 13 題

下列關於領導者使用摘要的技巧，何者最不適當？
  1. （A）適用於團體的開場和結束的時候
  2. （B）目的是將前次團體未處理的主題，提到本次聚會再處理
  3. （C）可讓領導者視成員的需求，決定停留或改變主題
  4. （D）可由領導者或成員來進行

答案：（B）

詳解與考點

考點為團體中摘要技巧的適當使用。正解B最不適當：摘要是濃縮統整當下內容，而非「把上次未處理主題搬到本次再處理」（那較屬連結/銜接，非摘要定義）。陷阱在C依需求決定停留或轉主題：屬摘要正當用途，易誤選。

第 14 題

關於協同領導模式（co-leadership model）的敘述，下列何者最不適切？
  1. （A）適合非結構團體
  2. （B）領導者彼此的理論取向最好相似
  3. （C）領導者彼此的領導風格相似性高，有利於團體的發展
  4. （D）在團體初期，領導者彼此意見分歧時，最好在團體內溝通

答案：（D）

詳解與考點

考點為協同領導（co-leadership）模式原則。正解D最不適切：團體「初期」領導者公開分歧易讓成員不安、損及安全感，宜團體外溝通。陷阱在B、C理論取向與風格相似：通常被視為有利協同，屬合理敘述，易誤判為不適切。

第 15 題

在一個以有效管理時間為訓練目標的團體，下列那一種情況領導者最適合採用保持焦點（focusing）技術？
  1. （A）某位成員提到最近一次選舉的結果，大家對此主題很感興趣
  2. （B）某位成員分享自己的女友最近提出分手，讓他心情十分沮喪
  3. （C）某位成員談到再兩星期就期中考，他不知道要怎麼準備考試
  4. （D）某位成員接續上週於團體中分享的故事，報告後續發展結果

答案：（C）

詳解與考點

考點為保持焦點（focusing）技術的適用時機，目的是拉回團體目標。正解C：在時間管理主題團體中，成員談「如何準備考試」貼近目標，宜聚焦深化。陷阱在B分手沮喪：雖重要但偏離團體訓練目標，易誤把情緒議題當焦點而選錯。

第 16 題

某家暴受害婦女團體已進入第四次，團體開始十幾分鐘之後，領導者對成員說：「我想分享自己對團體的感受，團體已經過了十幾分鐘，但大家好像都在閒聊生活瑣事，我感覺大家似乎害怕談自己。」領導者最可能在使用那一種技術？
  1. （A）自我揭露
  2. （B）發問
  3. （C）澄清
  4. （D）同理

答案：（A）

詳解與考點

考點為團體領導技術的辨識。正解A自我揭露：領導者主動說出「我對團體的感受」，分享自身狀態屬自我揭露（此處兼具歷程評論）。陷阱在D同理：同理是反映成員感受，而本句說的是領導者自己的感覺，主體不同，最易混淆。

第 17 題

領導者對於團體中特殊事件的處理，下列何者最不適當？
  1. （A）某成員經常出現「捉住領導者」（get the leader）行為。領導者與其私下談過後仍出現此類行為，在確認團體意向後，邀請其他人對該成員的行為給予回饋
  2. （B）某非志願成員不斷出現抗拒行為。領導者審慎評估後發現，每次處理此抗拒行為不僅無效，更浪費其他成員時間，因此減少將焦點放在該成員身上
  3. （C）某成員經常率先打破沉默，也會漫無邊際地重複談話。領導者評估後發現該成員有神經質，說話的目的是為了減輕焦慮，因此不打斷該成員的談話，以減少其在團體中的焦慮感
  4. （D）某成員在其他人分享身為第三者的痛苦後，大肆批評身為第三者的不道德。領導者切斷該成員並鼓勵其以開放態度聆聽。該成員又故態復萌，領導者再次切斷無效後，便要該成員離開團體

答案：（C）

詳解與考點

考點為特殊成員行為的處理適當性。正解C最不適當：因成員以說話減焦慮就「放任不打斷」其漫談，會犧牲團體效益，領導者仍須適度介入結構。陷阱在B減少聚焦於無效抗拒的非志願成員：屬合理策略，易被誤判為不當而選錯。

第 18 題

團體進行了幾次之後，領導者發現有一位成員一直不積極，每次反應充滿防衛，甚至引發其他成員的焦慮，讓團體陷入僵局，無法改善。從團體動力與心理治療的觀點，Yalom認為此時領導者最適宜的作法，下列何者正確？
  1. （A）避免該成員有被遺棄的感覺，仍必須讓其繼續參與團體
  2. （B）直接終止該成員繼續參與團體，並介紹其他適合的治療方式
  3. （C）與團體成員討論此現象，徵詢大家的意見
  4. （D）邀請該成員參加最後一次團體後，再請他離開

答案：（B）

詳解與考點

考點為Yalom對長期阻礙團體之防衛成員的處置。正解B：當成員持續高防衛、引發他人焦慮且無法改善、使團體僵局時，宜終止其參與並轉介更適切的治療。陷阱在A仍讓其續留以免被遺棄：對團體整體不利，違反Yalom立場，最易誤選。把握度偏低。

第 19 題

玉如參加受暴婦女的諮商團體，當她談到過往的受虐經驗時，痛哭流淚。下列領導者的處理，何者最適當？
  1. （A）直接請其他相同經驗的成員安慰她，擁抱她
  2. （B）團體時間不夠時，徵求其他成員的同意以繼續團體的進行
  3. （C）為避免影響其他人，請玉如在團體結束後留下來談一談
  4. （D）詢問玉如是否願意在團體中討論她的問題

答案：（D）

詳解與考點

考點為團體中成員情緒宣洩當下的處理。正解D最適當：先「詢問玉如是否願意在團體中討論」，尊重其意願與自主。陷阱在A請他人立即安慰擁抱：未經當事人同意的肢體接觸與代為處理，可能造成壓力，易誤以為是支持而選錯。

第 20 題

一個為期10週，每週進行2小時的成人諮商團體，到了第5次及第6次團體各有一位成員流失。依據專業判斷，下列何者最不可能是成員流失的原因？
  1. （A）團體凝聚力不夠
  2. （B）團體不符合成員的期望
  3. （C）領導者無法準時結束聚會
  4. （D）對於團體的自我揭露感到害怕

答案：（C）

詳解與考點

考點為成員流失（drop-out）原因的判斷。正解C最不可能：領導者無法「準時結束」雖屬瑕疵，但較不會成為成員退出的主因。陷阱在A凝聚力不夠、B不符期望、D害怕自我揭露：皆為常見流失主因，易誤把它們當成最不可能而選錯。

第 21 題

關於次團體的現象與介入，下列敘述何者最適當？
  1. （A）次團體必然有害，領導者必須極力的防範次團體的形成
  2. （B）次團體並無害，是普遍發生的現象，順其自然即可，領導者不需要處理
  3. （C）當次團體干擾到團體的運作時，領導者需要嚴厲地面質次團體成員，並請他們停止結盟的行為
  4. （D）當次團體干擾到團體的運作時，領導者可以運用結構式活動，分開次團體的成員

答案：（D）

詳解與考點

考點為次團體（subgroup）的處理。次團體是團體中普遍出現的自然現象，無須全面禁止，但干擾運作時須介入。D 以結構式活動重新分組，屬溫和而有效的調節做法，故正確。最易誤選 C：嚴厲面質與要求停止結盟會升高防衛、傷害關係，並非適切介入。

第 22 題

領導者正籌劃帶領人際關係主題的諮商團體，在招募的過程中，他發現有一位正在接受他個別諮商的案主也報名參與。關於領導者的處理方式，何者最適合？
  1. （A）做團體前的個別評估會談，探討該案主參與團體的適配性並澄清相關議題
  2. （B）與該位案主在個別諮商中討論其參與團體的適配性並澄清相關議題
  3. （C）進行團體前的說明會，了解所有成員參與團體的適配性並澄清相關議題
  4. （D）考量雙重關係對案主會造成負向效應，將之列為不予錄取的名單

答案：（A）

詳解與考點

考點為雙重關係與團體前評估倫理。同時是個案又是團員會涉及雙重關係，正解 A 主張先做團體前個別評估會談，評估適配性並澄清議題，兼顧篩選與知後同意，故正確。B 在原個別諮商中討論易混淆關係界線；D 一律拒收過度僵化，皆為陷阱，C 範圍過廣未針對個別情況。

第 23 題

關於領導者須告知成員的心理傷害風險，下列何者最不適切？
  1. （A）成員可能經歷到非建設性的面質
  2. （B）建議成員要有危機意識並採取預防措施
  3. （C）告知成員在參與團體後，家人可能無法接受他的改變
  4. （D）預告參與團體可能會讓現在的生活更規律與正常

答案：（D）

詳解與考點

考點為知後同意中的心理風險告知。領導者應誠實預告可能的負向風險（如面質、家人不適應、需有危機意識）。D 預告「生活更規律正常」是正向期待而非風險告知，與題幹「風險」不符，故最不適切。陷阱在誤把正向承諾當成風險說明。

第 24 題

關於團體諮商倫理的保密議題，下列敘述何者最為正確？
  1. （A）錄影或錄音可能會干擾團體過程與成員的自然參與，因此最好密錄，小心不要被成員發現
  2. （B）在團體前與團體初期提醒成員，他們在團體中所說的有可能會被其他成員洩露出去，因此要慎重考慮自己要或不要揭露那些訊息，以免受傷害
  3. （C）帶領兒童青少年團體時，最好與家長建立合作關係，將兒童青少年在團體中所發生的事、說的話都讓家長知悉，並且幫助家長瞭解要如何幫助他們的孩子
  4. （D）在團體前面談以及團體初期，領導者最好重複地提醒成員關於保密的重要性，並討論為何需要保密、以及具體的保密策略與作法，尋求團體共識

答案：（D）

詳解與考點

考點為團體保密倫理。保密無法絕對保證，領導者應反覆提醒、討論理由並建立具體策略與共識，D 完整呈現此原則，故最正確。A 密錄違反知後同意；C 把兒少所言全告知家長破壞保密；B 雖提醒洩密風險但語氣消極，相較 D 不夠周延。

第 25 題

根據Corey等人（2014）的看法，針對18歲以下的未成年者進行團體時，最好取得家長合作。下列作法何者最不適當？
  1. （A）向家長表達雙方合作，協助孩子的態度
  2. （B）請家長口頭同意讓他們的孩子參與團體
  3. （C）教導家長如何和自己的孩子討論，參與團體的狀況，同時不去追問其他團體成員的隱私
  4. （D）提供團體說明書，包括團體目標、主題和活動等資訊給家長

答案：（B）

詳解與考點

考點為未成年團體與家長合作（Corey 等人）。應與家長合作、教導溝通、提供書面說明，但同意須為正式書面同意而非僅口頭。B 僅取得口頭同意，保障不足，故最不適當。陷阱在口頭與書面同意的效力差異。

第 26 題

關於團體普同感（universality）的敘述，下列何者最不適當？
  1. （A）成員感受到自己並不是最可憐、最特別的人
  2. （B）看到或聽到有很多人跟自己有類似的遭遇，可以更有共鳴
  3. （C）是一種同仇敵愾的感受，讓成員更有力量對抗非我同類的人
  4. （D）普同感可以帶出其他如宣洩、凝聚力的療效因子，使成員獲益更多

答案：（C）

詳解與考點

考點為 Yalom 療效因子之普同感（universality）。普同感指成員發現自己並不孤單、別人也有類似遭遇，從而產生共鳴並引發宣洩、凝聚力。C 將其曲解為「同仇敵愾、對抗他類」，方向錯誤，故最不適當。陷阱在把連結感誤讀成排他敵意。

第 27 題

關於團體效能評估的概念，下列敘述何者錯誤？
  1. （A）Luft的周哈里窗覺察模式認為在盲目區、隱藏區和未知區的成員耗能較大
  2. （B）內在效標評量是測量成員內在心理反應與行為變化的變項
  3. （C）成員出席率與流失率是檢視團體成效的標準指標之一
  4. （D）團體評估應該包含歷程性與總結性的評估

答案：（B）

詳解與考點

本題為「何者錯誤」，官方答案為 (B)。(B) 錯在把「內在效標評量」說成同時測量「內在心理反應」與「行為變化」兩者。內在效標（internal criteria）著重成員主觀、內在的心理反應與感受（如滿意度、自我覺察、情緒體驗等成員自陳的內在變項）；可觀察的外顯行為變化屬於外在效標（external criteria）的範疇，兩者應加以區辨，故 (B) 敘述錯誤、為正解。(A) 正確：Luft 與 Ingham 的周哈里窗（Johari Window）中，盲目區、隱藏區與未知區涉及未被覺察或未被揭露的訊息，成員需耗費心理能量維持這些區域，覺察與自我揭露增加（開放區擴大）則較省能。(C) 正確：出席率與流失率（drop-out rate）確實是檢視團體運作與成效的常用客觀指標之一。(D) 正確：完整的團體評估應兼含歷程性（formative，過程中持續評估）與總結性（summative，結束時評估成果）兩種評估。

第 28 題

應用理性情緒行為治療（REBT）於團體諮商時，下列何者是第一件要做的事情？
  1. （A）教導成員REBT理論
  2. （B）澄清成員困擾的特定情境
  3. （C）澄清成員的主要感受
  4. （D）澄清成員的負面自我內言

答案：（A）

詳解與考點

考點為理性情緒行為治療（REBT）團體流程。REBT 為教導性取向，通常先向成員教導 ABC 理論架構，使其理解非理性信念如何運作，再進入個別困擾處理，故 A 為第一步。陷阱是誤以為應先澄清情境或感受，那是後續步驟。

第 29 題

關於團體諮商理論與技術的配對，下列何者正確？
  1. （A）家庭作業（homework）—個人中心取向團體
  2. （B）未來投射（future projection）—心理劇團體
  3. （C）外化對話（externalization conversations）—認知行為取向團體
  4. （D）權力分析（power analysis）—敘事治療取向團體

答案：（B）

詳解與考點

考點為理論與技術配對。未來投射（future projection）為心理劇（psychodrama）常用技術，B 正確。陷阱：家庭作業屬認知行為而非個人中心；外化對話與權力分析分別屬敘事治療與女性主義治療，皆配對錯誤。

第 30 題

應用焦點解決短期治療進行團體諮商時，下列原則何者錯誤？
  1. （A）聚焦在正向的應對行為
  2. （B）聚焦在對問題的洞察
  3. （C）幫助成員找到更簡單的解決方式
  4. （D）鼓勵成員漸次放輕鬆地進入解決方案

答案：（B）

詳解與考點

考點為焦點解決短期治療（SFBT）原則。SFBT 聚焦正向應對、例外與解決方案，而非問題本身的洞察，故 B「聚焦對問題的洞察」與其去問題化精神相反，為錯誤敘述。陷阱在把重視洞察的傳統取向套到 SFBT。

第 31 題

關於完形治療團體的領導敘述，下列何者最不適當？
  1. （A）可以在團體的情境中進行個別治療
  2. （B）應用各種豐富且行動導向的實驗，以創造體驗的歷程
  3. （C）會挑戰或面質成員，以引導成員體驗他們自身的不一致
  4. （D）在體驗之前，先引導成員探索自己在認知上是否有新的想法

答案：（D）

詳解與考點

考點為完形治療團體領導。完形強調「此時此地」的體驗與實驗，先做後覺、由體驗帶出覺察，而非先在認知上想清楚再體驗。D 主張體驗前先探索認知新想法，與完形重經驗的精神相反，故最不適當。陷阱是把認知取向流程誤植到完形。

第 32 題

在心理動力取向的人際團體中，下列何者是成員較少機會經歷到的經驗？
  1. （A）從團體互動中重新經歷與過去家庭的相似經驗
  2. （B）有系統學習以「我訊息」表達個人感受或需求
  3. （C）透過與領導者及成員的互動，重新認識真實或想像中的自己或他人
  4. （D）從團體互動中，檢核自己的情感轉移，學習接納及表達過去可能排斥的情感

答案：（B）

詳解與考點

考點為心理動力人際團體的經驗類型。動力取向重移情、重現早期關係與接納被排斥情感，這些屬其特色。B「系統學習用我訊息表達」是溝通技巧訓練，屬人際技巧或行為取向，動力團體較少著墨，故為較少經歷的經驗。陷阱在混淆技巧訓練與動力歷程。

第 33 題

關於領導兒童團體的注意事項，下列何者錯誤？
  1. （A）運用領導者取向模式
  2. （B）運用多感官取向的團體形式
  3. （C）讓團體焦點維持在某一主題
  4. （D）利用團體進行個別諮商工作

答案：（D）

詳解與考點

考點為兒童團體領導。兒童團體宜採領導者較主動的取向、多感官形式並維持主題聚焦。D「利用團體進行個別諮商」混淆團體與個別工作的焦點，不利團體歷程，故錯誤。陷阱是把成人團體中偶見的個別工作誤用於兒童團體。

第 34 題

大地震後，舉辦倖存災民的諮商團體，下列敘述何者最為正確？
  1. （A）鼓勵他們說出來，因為不說出來，壓抑在心裡，會產生更大更多的問題
  2. （B）災民需要的是居住安全、飲食衛生及衣物提供，心理協助的需求沒有那麼迫切需要
  3. （C）領導者也是這場災難的災民，他最能感同身受，是適當的領導者
  4. （D）失落悲傷與心理創傷的議題和活動是該團體的重點

答案：（D）

詳解與考點

考點為災後創傷團體的重點。地震倖存者團體核心應放在失落悲傷與心理創傷的處理，D 正確。陷阱 A：強迫宣洩、要人「一定說出來」可能造成二次傷害，並非適切；B 否定心理需求、C 領導者本身為災民欠缺客觀均不當。

第 35 題

關於在大學中帶領男、女同志的支持性團體，下列敘述何者最不適當？
  1. （A）團體主軸可聚焦在成員面對歧視時的困擾及因應
  2. （B）團體可兼具心理教育導向及發展和諮商導向
  3. （C）男、女同志面對的議題不同，不適合將他們放在同一個團體
  4. （D）團體適合採取女性主義治療的理論取向

答案：（C）

詳解與考點

考點為同志支持團體。團體可聚焦歧視因應、兼具心理教育與發展諮商導向，並可採女性主義取向。C 主張男女同志議題不同故不宜同團，過度區隔且否定共同經驗，最不適當。陷阱在以議題差異為由切割，忽略支持團體的共通性。

第 36 題

領導者即將在大學帶領外籍學生的支持團體，帶領團體前的準備，下列何者最有幫助？
  1. （A）多出國以瞭解各國的文化差異
  2. （B）培養謙卑及尊重，而非批判或嘲諷的態度，面對不同文化族群
  3. （C）參加多元文化學術研討會，拓展自己對多元文化的生活體驗
  4. （D）儘速學習成為文化簡約的諮商心理師

答案：（B）

詳解與考點

考點為多元文化諮商準備。帶領外籍學生團體最關鍵的是文化謙卑（cultural humility）與尊重的態度，故 B 最有幫助。陷阱 D「文化簡約」方向相反；A、C 雖有助益但屬外圍經驗累積，不及內在態度根本。

第 37 題

親子遊戲治療團體是一套獨特的親職訓練方案，是以團體的形式訓練父母親成為孩子的治療代理人，下列敘述何者最不適當？
  1. （A）以兒童中心遊戲治療（child-centered play therapy）的原則與技巧為主要課程內容
  2. （B）首要目標是要讓父母有能力矯正或改變孩子的行為問題
  3. （C）參加團體的父母學員每週要在家中跟孩子進行一對一的遊戲單元，並將此過程回到團體中討論
  4. （D）若父母親可以有效學習到上課教授的原則與技巧，其對孩子的影響力遠勝於治療師

答案：（B）

詳解與考點

考點為親子遊戲治療（filial therapy）。其以兒童中心遊戲治療原則訓練父母成為治療代理人，首要目標是增進親子關係與父母的同理回應能力，而非矯正改變孩子行為。B 把目標窄化為矯正行為，最不適當。陷阱在把行為矯正當成首要目的。

第 38 題

關於注意力缺陷過動障礙症或對立反抗障礙症的兒童團體，領導者的介入原則，下列敘述何者最不適當？
  1. （A）領導者對於成員頻繁出現的干擾行為需加以包容
  2. （B）領導者可由調整成員的座位讓團體順利進行
  3. （C）成員出現可以專注傾聽其他成員說話約10分鐘時，領導者應給予公開鼓勵
  4. （D）領導者應溫和而堅定的面對成員間的對立或敵意

答案：（A）

詳解與考點

考點為 ADHD 與對立反抗兒童團體的介入。領導者宜溫和堅定、調整座位、適時公開鼓勵專注行為。A 主張對頻繁干擾行為一味包容，缺乏必要的結構與界線設定，最不適當。陷阱是把接納誤解為放任不設限。

第 39 題

關於特殊群體的團體治療，下列敘述何者最不正確？
  1. （A）失落哀傷團體常聚焦於罪惡感、孤單等議題
  2. （B）長期酒癮團體的領導者常需處理行動化的議題
  3. （C）失婚復原團體不會再討論如何面對前配偶、孩子適應等議題
  4. （D）酗酒者成年子女團體的領導者必須很熟悉成員的被遺棄感

答案：（C）

詳解與考點

考點為特殊群體團體。失落哀傷聚焦罪惡與孤單、酒癮處理行動化、酗酒者成年子女處理被遺棄感，皆屬通說。C 稱失婚復原團體「不會再討論前配偶、孩子適應」與實務相反，這正是常見議題，故最不正確。陷阱在誤判該團體的核心議題範圍。

第 40 題

下列何者不是帶領老人團體諮商時，領導者特別應具有的特質或能力？
  1. （A）對老化與死亡主題的熟悉度
  2. （B）熟悉社會福利政策與補助
  3. （C）活力
  4. （D）耐性

答案：（B）

詳解與考點

考點為老人團體領導者特質。帶領老人團體須熟悉老化與死亡、具活力與耐性。熟悉社會福利政策補助雖有助益，但非領導者「特別應具有」的核心諮商特質，故 B 為非。陷阱在把外部資源知識誤當成必備領導特質。
