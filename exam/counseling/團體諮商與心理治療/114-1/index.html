第 1 題

有關酗酒者匿名團體過程的陳述，下列何者最適當？
  1. （A）這種團體因為同質性高，所以可以感同身受的幫助到每一個成員
  2. （B）這種團體是一種積極、創造性、多感官與理論導向的治療方式
  3. （C）此種領導模式通常是以影響治療（impact therapy）為理論基礎
  4. （D）這種團體通常沒有常置的專業團體領導者，但能運用特定步驟完成團體流程

答案：（D）

詳解與考點

正解：「酗酒者匿名團體」——判準是匿名戒酒團體屬自助團體，依特定共同程序運作，而非由常置專業治療師主導。D 指出通常沒有常置專業團體領導者，仍可運用特定步驟完成團體流程，最適當，故選 D。

A：同質性可增加理解機會，卻不能保證感同身受並幫助每一位成員，故不選。

B：匿名戒酒團體不是積極、創造性、多感官且理論導向的治療方式，故不選。

C：其領導模式非以影響治療為理論基礎，故不選。

本題考點：匿名戒酒與自助團體——判準是以成員互助及特定步驟運作，通常沒有常置專業領導者；同質性有助支持，但不保證每位成員皆獲相同效益。

第 2 題

關於在日照中心帶領開放式團體（open groups）的敘述，下列何者最合適？
  1. （A）當新成員進入團體時，不需再次說明團體規則，他們從和舊成員的互動中自然就會理解
  2. （B）由於成員時常進出，很難產生團體凝聚力，故領導者不需催化其凝聚力
  3. （C）因為是開放式團體，成員連續或無理由缺席是被允許的
  4. （D）領導者可能需要主動組織團體，拜訪某些成員，以及支持成員參與

答案：（D）

詳解與考點

正解：日照中心的「開放式團體」與成員時常進出——流動性高時，領導者反而須更主動維持參與及團體運作。D 所述主動組織、拜訪成員與支持參與最合適，故選 D。

A：新成員加入時仍應重新說明團體規則，不能僅期待其從互動中自然理解，故不選。

B：開放式團體雖較難凝聚，領導者仍需催化凝聚力，故不選。

C：開放式是指可有新成員進出，不代表可無理由連續缺席，故不選。

本題考點：開放式團體帶領——判準是因成員流動而加強規則說明、凝聚力與出席支持；「開放」不等於放任規則或缺席。

第 3 題

下列那一項敘述屬於諮商團體（counseling group）的特性？
  1. （A）團體主要的工作是修通過去經驗及對阻抗的處理
  2. （B）參與團體的人通常主要是想減輕特定的心理症狀或困擾
  3. （C）著重於協助團體成員在認知、態度或行為技巧上的學習和發展
  4. （D）團體著重於意識層面的覺察與問題解決的策略

答案：（D）

詳解與考點

正解：「諮商團體」——判準是其主要處理意識層面的覺察與問題解決策略，服務發展性及預防性議題。D 符合諮商團體特性，故選 D。

A：修通過去經驗與處理阻抗，較偏向心理治療團體的深度工作，故不選。

B：以減輕特定心理症狀或困擾為主要目標，較偏向治療團體，故不選。

C：著重認知、態度或行為技巧的學習和發展，較偏心理教育或輔導團體，故不選。

本題考點：團體類型分辨——判準是諮商團體著重覺察及問題解決；心理治療團體較處理過去經驗、阻抗與症狀；心理教育團體較著重知識與技能學習。

第 4 題

下列那一種溝通技巧最能促進諮商團體成員之間的開放對話和信任？
  1. （A）鼓勵成員分享個人故事和經歷，以促進共同理解和支持
  2. （B）打斷成員發言，糾正任何誤解或不準確之處
  3. （C）示範並引導對話，讓所有成員都聚焦在團體主題上
  4. （D）提醒成員遵守專注聆聽他人發言的團體規範

答案：（A）

詳解與考點

正解：「最能促進開放對話和信任」——判準是能否直接催化自我揭露、共同理解與相互支持。A 鼓勵成員分享個人故事和經歷，最能建立此種互動，故選 A。

B：打斷並糾正成員發言帶有評價與糾錯意味，易降低安全感、抑制開放，故不選。

C：示範與引導對話、協助聚焦主題有助團體結構和安全，但對自我揭露與共同理解的直接促進不及 A，故不選。

D：提醒專注聆聽有助尊重與規範維持，同樣是正向作法，但較間接促進開放對話和信任，故不選。

本題考點：團體溝通技巧——判準是以自我揭露、同理理解與支持直接建立信任；聚焦和聆聽規範可維持結構，但不是最直接催化開放對話的方法。

第 5 題

下列關於催化團體歷程的方法，何者不適當？
  1. （A）領導者應多運用聚焦技術，以利團體在早期能很快進入工作階段
  2. （B）領導者應協助成員學習開放地表達他們對於團體的擔心與期望
  3. （C）領導者應鼓勵成員們直接相互對話，創造溝通的機會
  4. （D）領導者應鼓勵成員公開地表達矛盾與衝突，克服溝通障礙

答案：（A）

詳解與考點

正解：「早期很快進入工作階段」——團體初期的首要任務是建立安全、信任與參與規範，不能以快速深化取代循序發展。A 過早大量運用聚焦技術，意圖跳過初期歷程而立即工作，容易使成員尚未具備安全感便被推向深入探索，故為不適當選項。

B：協助成員開放表達對團體的擔心與期望，能讓領導者及成員共同處理初期焦慮，促進信任建立，故適當。

C：鼓勵成員直接相互對話，可減少成員只對領導者說話的依賴，創造真實溝通，故適當。

D：在具有足夠安全感時鼓勵公開表達矛盾與衝突，有助於辨識及克服溝通障礙，故適當。最強誘答是 A 的「很快進入工作階段」看似有效率，錯在團體階段任務不能省略。

本題考點：團體初期的催化原則——判準是先建立安全、信任與成員參與，再逐步深化工作；促進相互對話與表達擔心有助初期歷程，催促成員過早進入工作則可能揠苗助長。

第 6 題

當一個團體的凝聚力過高，可能會出現下列那種現象？
  1. （A）提升成員的獨立思考能力
  2. （B）促進更深層次的個人探索
  3. （C）不易有個人情感與想法的表達
  4. （D）增加團體內不滿的氛圍與壓力

答案：（C）

詳解與考點

正解：「凝聚力過高」——凝聚力能支持團體，但超過適當程度時會形成從眾壓力，判準是成員能否保有表達異議與個別感受的空間。C 所述不易表達個人情感與想法，正是成員為維持一致而壓抑差異的風險，故選 C。

A：獨立思考需要容納不同觀點；過高凝聚力反而可能以從眾壓力限制獨立思考，故非答案。

B：深層個人探索需有安全且可表達差異的氣氛；若同質壓力過高，成員可能自我審查，故非答案。

D：高凝聚力未必增加不滿與壓力，其主要風險是表面和諧下的異議壓抑，故非答案。最強誘答是把凝聚力一律視為好事；關鍵在題幹加了「過高」。

本題考點：團體凝聚力的雙面性——判準是凝聚力是否仍容許個別性與異議；適度凝聚力支持參與，過高則容易產生從眾、沉默與團體迷思式的壓抑。

第 7 題

下列關於領導者在工作階段教導成員進行有效回饋之原則，何者較不適當？
  1. （A）回饋聚焦在團體此時此刻發生的行為，會特別有效
  2. （B）委婉修飾的回饋比直接清楚的回饋，會更有幫助
  3. （C）表達自己是如何被對方的行為所影響，而不是給建議
  4. （D）及時且不具評價性的回饋，容易增加被回饋者反思的機會

答案：（B）

詳解與考點

正解：「有效回饋」與「較不適當」——工作階段的回饋要具體、直接、聚焦行為與此時此地，並以自己的感受陳述而非評價對方。B 主張委婉修飾比直接清楚更有幫助，會使重點含混、降低成員理解與反思的機會，故為不適當選項。

A：聚焦團體此時此刻發生的行為，能讓回饋有具體可觀察的依據，故適當。

C：說明自己如何受對方行為影響，是以「我」訊息回饋而非替對方下指導，故適當。

D：及時且不具評價性的回饋較易被接收，也能增加被回饋者反思的機會，故適當。最強誘答是 B 的「委婉」看似體貼，錯在體貼不等於模糊，回饋仍須清楚具體。

本題考點：團體有效回饋——判準是回饋須直接、具體、及時且不評價，聚焦此時此地行為與自身受影響的感受；含混修飾或直接給建議，均會削弱回饋功能。

第 8 題

在處理團體中的信任議題時，關於領導者的作為下列何者最適切？
  1. （A）嚴格保密每個成員的發言內容
  2. （B）強調成員之間必須互相信任
  3. （C）使用團體公約來約束成員行為
  4. （D）鼓勵成員對信任問題進行公開討論

答案：（D）

詳解與考點

正解：「處理團體中的信任議題」與「最適切」——信任不是以要求或規範直接製造，而是透過成員覺察、表達並共同處理關係經驗逐步形成。D 鼓勵成員公開討論信任問題，能把議題帶進團體歷程工作，最直接促進真實信任，故選 D。

A：保護成員發言的保密性是團體安全基礎，但保密本身不能取代對信任困難的歷程性處理，故非最適切。

B：要求成員「必須」互相信任是以命令代替關係建立，可能引發反感或表面順從，故非最適切。

C：團體公約可建立行為規範與安全感，但僅靠約束不足以處理成員實際的信任疑慮，故非最適切。最強誘答是 A 與 C 都是必要基礎；分辨關鍵在本題問的是直接處理信任議題的作為。

本題考點：團體信任的建立——判準是把成員對信任的感受帶入公開、可共同探索的歷程；保密與團體公約提供安全框架，卻不能以規定或要求取代信任關係的形成。

第 9 題

關於領導者在團體最後一次聚會的發言，下列那一個句子最不適合？
  1. （A）有哪一位想要給其他成員回饋？
  2. （B）有沒有你自己或其他任何人所說的話，對你而言特別重要？
  3. （C）你在團體中一直都很靜默，可以告訴我們你在團體中的感覺嗎？
  4. （D）這個團體的經驗對你有何意義？

答案：（C）

詳解與考點

正解：「最後一次聚會」與「最不適合」——結束階段的任務是回顧、統整、道別與將學習帶離團體，不宜在時間不足時開啟無法處理的新深層議題。C 在最後一次聚會追問靜默成員的團體感覺，可能引出尚待探索的新素材，故最不適合。

A：邀請成員給彼此回饋，有助於整理關係經驗與道別，故非答案。

B：請成員辨識自己或他人說過而特別重要的話，屬回顧與統整，故非答案。

D：詢問團體經驗的意義，能協助成員整合收穫並思考應用，故非答案。最強誘答是 C 看似關心沉默成員，錯在時機已是結束階段，不宜深掘新議題。

本題考點：團體結束階段的領導任務——判準是介入是否促進回顧、統整、意義建構與道別；若可能開啟需要長期探索的新素材，便不適合放在最後一次聚會。

第 10 題

關於帶領諮商團體前的說明會及訪談，下列敘述何者錯誤？
  1. （A）透過團體前的個別訪談可以幫助成員進入準備狀態
  2. （B）根據相關研究，團體前的訪談或說明可能妨礙團體的療效
  3. （C）團體前的說明會同時亦具有篩選成員的作用
  4. （D）團體前的訪談有助於了解成員的人際歷史

答案：（B）

詳解與考點

正解：「團體前的說明會及訪談」與負向問法「何者錯誤」——團體前準備的功能在於增進準備度、評估適配性與降低不確定感。B 說明訪談或說明可能妨礙團體療效，與其協助成員準備、提升投入及降低流失的功能相反，故為應選項。

A：個別訪談可協助成員理解團體性質、表達期待與顧慮，進入準備狀態，敘述正確，故非答案。

C：說明會可讓領導者了解成員需求與適配性，也具有篩選成員的作用，敘述正確，故非答案。

D：團體前訪談有助了解成員的人際歷史與目前困擾，以作帶領規劃，敘述正確，故非答案。

本題考點：團體前訪談與說明會——判準是是否有助於成員準備、適配篩選與了解人際背景；這些程序是帶領前的預防性工作，不是妨礙團體療效的因素。

第 11 題

對於團體領導技巧的運用，下列敘述何者錯誤？
  1. （A）非結構團體進行較無法預測，需更有效運用技巧
  2. （B）隨團體進展運用深化技巧，例如活化此時此地、角色扮演
  3. （C）團體前期領導者使用連結、自我表露、解釋技巧較多
  4. （D）接受督導或協同領導團體可增進技巧的運用

答案：（C）

詳解與考點

正解：「團體前期」與「解釋技巧較多」——領導技巧須配合團體發展階段，前期先建立安全與關係，深化性解釋則要待成員較能承受及運用時再增加。C 把解釋列為前期較常使用的技巧，錯置了技巧的時機，故為應選項。

A：非結構團體的互動走向較難預測，更需領導者敏銳且有效地運用技巧，敘述正確，故非答案。

B：隨團體進展，活化此時此地與角色扮演等深化技巧可協助工作，敘述正確，故非答案。

D：接受督導或協同帶領能取得回饋與觀察，增進領導技巧的運用，敘述正確，故非答案。最強誘答是 C 同時列出連結與自我表露等前期可用技巧；錯誤只在把較深的解釋也概括成前期較多。

本題考點：團體領導技巧與階段配適——判準是前期優先建立安全、連結與參與，中後期才逐步增加此時此地活化、角色扮演與解釋等深化介入。

第 12 題

對於團體領導者開放（openness）的特質，下列敘述何者錯誤？
  1. （A）是指領導者表達自己如何受到成員的影響
  2. （B）領導者本身的開放能促使成員更加開放
  3. （C）領導者的自我揭露越多，顯示開放度越大，對團體越有益
  4. （D）領導者的開放是一種真誠的表現

答案：（C）

詳解與考點

正解：「開放」與負向問法「何者錯誤」——領導者的開放是真誠且有目的地表達自己受到成員影響，不等同於不加節制地自我揭露。C 認為自我揭露越多就越有益，忽略揭露必須符合團體需要、時機與專業界線，故為應選項。

A：表達自己如何受到成員影響，是領導者開放的一種具體表現，敘述正確，故非答案。

B：領導者以適切方式開放自己，可示範真誠互動並促進成員開放，敘述正確，故非答案。

D：開放建立在真誠而非技巧性表演，敘述正確，故非答案。最強誘答是把「更開放」理解成「揭露更多」；關鍵在揭露的適切性，而非數量。

本題考點：團體領導者的開放與自我揭露——判準是揭露是否真誠、適時、有目的且服務於成員與團體；適度開放可示範真實，過度揭露則可能轉移焦點或破壞界線。

詳解與考點

本題考點：兒童團體初期的安全與自主——判準是先降低受壓成員的威脅感，讓其保有分享時機與程度的選擇；過早詮釋、要求指認他人或採絕對化承諾，都不利於安全參與。

第 17 題

C：若次團體目標與主團體一致，可能支持成員連結並提升凝聚力，敘述正確，故非答案。最強誘答是 D 似乎遵守保密原則；錯在把保密誤用為替破壞性次團體維持秘密。

本題考點：次團體的辨識與處理——判準是次團體是否與主團體目標一致，以及是否形成沉默共謀；可處理其在團體內的影響，但不應承諾掩護破壞信任的秘密結盟。

第 20 題

  2. （B）團體衝突會干擾團體的進行，是團體發展歷程的危機並非轉機
  3. （C）領導者處理團體衝突時，需考量歷程導向並以多面向兼顧的方式因應

詳解與考點

正解：「面對成員衝突」與「何者正確」——衝突是團體歷程中的關係訊息，領導者不能只壓制或只採單一策略，而要依團體發展、成員互動與安全程度多面向處理。C 所述以歷程導向並兼顧多面向因應，符合衝突處遇原則，故選 C。

  3. （C）你老是給別人意見，我希望你能將焦點放在自己身上
  4. （D）聽你這樣說，我覺得很難過

第 27 題

依據Yalom的觀點，關於聯合治療（conjoint therapy）與混合治療（combined therapy）的敘述，下列何者最正確？①特殊個案如人格問題、嚴重創傷，常需要採取聯合治療或混合治療②不論聯合治療或混合治療，皆以團體治療為主要模式，個別治療為補充模式③混合治療的模式，若要有輕重緩急之分，是以個別治療先於團體治療④不論是聯合治療或混合治療，皆有助於降低團體的流失率⑤聯合治療比起混合治療更需要處理在個別治療與團體治療所延伸的界線議題
  1. （A）①②④
  2. （B）①③④
  3. （C）②③⑤
  4. （D）③④⑤

答案：（B）

詳解與考點

正解：「聯合治療」與「混合治療」的模式區分，需逐一判斷①至⑤。①特殊個案如人格問題或嚴重創傷，常需採聯合或混合治療；③混合治療若有先後輕重，為個別治療先於團體治療；④兩種安排皆有助降低團體流失率，故正確組合為①③④，選 B。

  2. （B）邀請甲多分享一點炒股秘訣，以協助甲與其他成員的互動
  3. （C）鼓勵成員表達當甲說這些事情時，自己的真實感受與想法
  4. （D）反映甲僅陳述外在世界的經驗，邀請其分享對團體的信任與安全感

答案：（B）

詳解與考點

正解：「最不可能」與個人中心學派對此時此地關係的重視。甲在沉默時轉談團體外成就，可能迴避與成員互動；邀請甲分享炒股祕訣會順著外在話題，反而強化迴避，最不符合個人中心領導者的回應，故選 B。

A：仔細觀察甲說話時其他成員的表情，暫不介入，可保留對團體歷程的敏感度，並非個人中心取向不可能採取的作法。

C：鼓勵成員表達甲說這些事情時的真實感受與想法，能帶回此時此地的人際關係，符合以真實和同理促進互動的精神。

D：反映甲多談外在世界，並邀請其分享對團體的信任與安全感，能尊重其經驗又溫和探索關係，故可能採用。

本題考點：個人中心團體帶領——判準是回應成員當下的感受、關係與安全感，而非以技巧性話題轉移掩蓋互動；「促進互動」不等於順著成員的迴避內容延伸。

第 33 題

Flowers（1999）主張，團體第一次聚會前，先請成員在小卡片寫下來參加團體想要處理的問題，以利於首次聚會，減少過長沉默的窘境。這是何種理論取向最可能的作法？
  1. （A）認知行為治療
  2. （B）敘事治療
  3. （C）個人中心治療
  4. （D）完形治療

答案：（A）

詳解與考點

正解：「聚會前寫卡片」「要處理的問題」與「減少沉默」；這種預先設定議題、降低不確定性的高度結構化安排，符合認知行為治療的目標導向團體工作，故選 A。

B：敘事治療重視成員對問題的敘說、外化與另類故事，雖可使用書寫，題述以預設問題處理與控制沉默為目的，非其典型作法。

C：個人中心治療重視成員自然浮現的經驗與關係，領導者通常不以事前卡片明確設定處理議題作為主要架構。

D：完形治療強調此時此地覺察與經驗實驗，較不以事前結構化暖身來安排團體內容。

本題考點：認知行為團體的結構化——判準是預先設定問題、目標或作業，以明確流程促進參與與改變；看到「事前安排、目標導向、減少沉默」時，可與重歷程的取向區分。

第 34 題

下列關於規劃和設計伴侶諮商團體的敘述，何者最適當？
  1. （A）篩選面談應個別進行了解其需求，避免因雙方一起會談造成個人無法充分表達的問題
  2. （B）可以設計活動幫助成員檢視其妨礙親密的心理遊戲以及探索影響愛情價值觀的童年經驗
  3. （C）最好不要超過六對伴侶，才有足夠時間讓成員分享
  4. （D）若伴侶其中一方不願意承諾為彼此關係而努力，可鼓勵其參與團體來展現對伴侶的重視

答案：（B）

詳解與考點

正解：伴侶團體的工作目標是檢視互動模式與親密關係的形成脈絡。設計活動協助成員檢視妨礙親密的心理遊戲，並探索影響愛情價值觀的童年經驗，能直接服務此目標，故選 B。

A：篩選面談可蒐集個別資訊，但伴侶諮商團體也須評估兩人的互動與共同參與狀況；一概要求個別進行，理由又絕對化，故非最適當。

C：團體人數應依方案目標、領導資源及可讓成員有效參與的程度規劃，不能僅以「最好不超過六對」作為通則。

D：若其中一方不願承諾為關係努力，鼓勵其入團表現重視看似正向，但投入團體需要基本的自願與工作意願，硬拉入團反而不利團體工作，故不適當。

本題考點：伴侶諮商團體規劃——判準是篩選同時評估個別安全、兩人互動與參與動機，團體活動則聚焦親密互動模式與其發展脈絡；不能把缺乏承諾當成可由強制參與解決的問題。

第 35 題

諮商心理師在某大學帶領實體人際關係團體，在進行到第三次的時候，成員A表示因為假期返家來不及回到學校，但又表達想參加的意願，想用視訊的方式參加。下列領導者的做法何者最適切？
  1. （A）徵詢每一位成員的想法與意見，採多數決，決定A是否以線上參與
  2. （B）肯定A成員的積極參與，但考量到網路的保密性，請A下次聚會再參與
  3. （C）請成員A全程需開設鏡頭與麥克風，且需發言與參與活動
  4. （D）修改團體的方案，搭配目標，以線上能同步進行的活動為優先

答案：（B）

詳解與考點

正解：既有「實體人際關係團體」於第三次臨時改為「視訊參與」；此時首要判準是團體保密與既有安全結構。肯定 A 的參與意願，但因網路環境的保密性難以掌控，請其下次實體聚會再參與最為穩妥，故選 B。

A：是否採線上參與不只是成員偏好問題，還涉及保密、媒介安全與團體契約；不能以多數決將這些專業責任交由成員決定。

C：要求 A 全程開鏡頭、麥克風並發言，雖想維持參與，卻無法處理其周遭是否有人旁聽、空間是否私密等保密風險。

D：修改方案配合線上同步活動看似照顧參與，但臨時改變實體團體的媒介與活動結構，仍忽略線上保密及其他成員的安全感。

本題考點：團體諮商的媒介與保密倫理——判準是變更參與媒介前，須先確保私密空間、資訊安全、團體知後同意與既有結構；保密責任不能由多數決取代。

第 36 題

關於親密關係暴力倖存者的團體，領導者於團體前需蒐集與評估相關資訊以有效規劃團體，下列描述何者錯誤？①確認倖存者其伴侶或其他家庭成員對倖存者的期待或角色②蒐集倖存者曾歷經的暴力樣態與親密關係互動史③評估倖存者過去、現在與未來的風險程度④了解倖存者的支持系統，如人際、家庭、社政、法政等資源
  1. （A）①③
  2. （B）②③④
  3. （C）僅②④
  4. （D）僅③④

答案：（A）

詳解與考點

正解：「何者錯誤」及親密關係暴力倖存者團體的賦權與安全原則。官方答案為 A；惟風險評估可依既往與當前危險因子推估未來再受暴風險，並非精確預測。依本題的前置蒐集範圍，①將伴侶或家庭成員對倖存者的期待或角色置為評估焦點，不以倖存者自身需求與安全為中心；③的「過去、現在與未來」也應理解為風險推估而非確定未來，故題目列①③為錯誤敘述。

B：本組合含②③④。②蒐集暴力樣態與親密關係互動史、④了解人際、家庭、社政與法政支持系統，都是必要資訊；但本題將③列為錯誤，故不正確。

C：本組合僅含②④，兩者皆是規劃團體前應蒐集的資料，未包含本題列為錯誤的①與③，故非答案。

D：本組合含③但漏列本題同樣列為錯誤的①，故不正確。

本題考點：親密關係暴力倖存者團體的前置評估——判準是以倖存者自身需求、安全、暴力樣態、互動史與支持資源為中心；風險推估須依既往與當前危險指標，不能等同於確定預測。

第 37 題

下列那種作法較不適合運用在兒童團體？
  1. （A）運用多重感官的媒材，維持兒童的專注力
  2. （B）進行深層的個人議題探索，催化團體效力
  3. （C）切斷成員的漫談，讓其他成員有機會分享
  4. （D）將話題帶回到原來討論的主題，以維持團體進行的方向

答案：（B）

詳解與考點

正解：「較不適合運用在兒童團體」；兒童的認知、情緒表達與專注發展仍在成熟，帶領宜具體、活動化並保持可承載的深度。進行深層個人議題探索容易超出兒童的團體承載與發展需求，故選 B。

A：多重感官媒材能增加參與感並維持兒童專注，符合兒童團體活動化與具體化的原則。

C：適時切斷漫談可讓不同成員獲得分享機會，並維持團體節奏，作法本身適當。

D：將話題帶回原先主題有助維持團體方向與安全結構，亦適合兒童團體。

本題考點：兒童團體帶領——判準是使用具體、多感官且結構清楚的活動，兼顧注意力與分享機會；成人取向的深層探索不可直接套用於兒童團體。

第 38 題

關於帶領HIV/AIDS諮商團體的主要焦點，下列何者正確？
  1. （A）治療性焦點與教育性的內容同等重要
  2. （B）治療性焦點比教育性的內容重要
  3. （C）教育性的內容比治療性焦點重要
  4. （D）AIDS患者與HIV感染者處理的焦點不同

答案：（A）

詳解與考點

正解：HIV/AIDS 諮商團體的「主要焦點」；此類團體既需處理情緒支持、失落與因應等治療性工作，也需提供疾病知識與防治等教育內容，兩者同等重要，故選 A。

B：治療性焦點固然重要，但若貶低教育內容，會忽略成員對疾病知識與防治資訊的需求。

C：教育內容亦不可取代情緒支持與因應工作；把教育性置於治療性之上，違反團體整合性的設計。

D：AIDS 患者與 HIV 感染者的處境可能不同，但團體的主要焦點同樣須整合治療性與教育性內容，不能據此把兩者的處理焦點二分。

本題考點：HIV/AIDS 諮商團體——判準是同時整合治療性支持與教育性資訊，而非比較兩者高低；疾病相關團體的知識提供與情緒工作須互相配合。

第 39 題

Corey等人（2014）建議領導者在進行哀傷失落團體前，要能自我檢視與覺察，下列描述何者最不適當？
  1. （A）領導者宜先完全解決曾經遭遇的失落議題，以免造成在團體中情緒的崩潰
  2. （B）領導者個人對於失落哀傷的害怕，可能干擾其對團體相似議題的處理
  3. （C）領導者決定如何面對生命中不可逃避的存在議題，將影響其與個案工作和成長
  4. （D）哀傷、失落經驗易觸動個人最深層的恐懼，領導者若未能覺察自己的經驗，將嚴重影響此議題的處理

答案：（A）

詳解與考點

正解：「最不適當」與哀傷失落團體領導者的自我覺察。領導者確須覺察自身失落經驗及其可能觸發的反應，但不必先把所有失落「完全解決」才能帶團體；A 把覺察誤作零殘留的要求，故最不適當。

B：領導者對失落與哀傷的害怕，可能干擾其處理團體中的相似議題，這正是需要自我覺察的理由，故非答案。

C：領導者如何面對生命中不可逃避的存在議題，會影響其與個案工作和成長，此敘述正確，故非答案。

D：哀傷與失落容易觸動深層恐懼；若領導者未覺察自己的經驗，確可能嚴重影響處理品質，故非答案。

本題考點：哀傷失落團體的領導者自我覺察——判準是能辨識自身恐懼、未竟哀傷與可能反應，並以督導或支持維持專業功能；覺察不等於要求生命經驗完全沒有殘留。

第 40 題

關於非行少年家長的強制親職教育團體，下列敘述何者最不適當？
  1. （A）採用小團體方式進行，較能幫助家長深入討論其個別的需要和困難
  2. （B）團體進行前領導者應該先對家長進行面談與篩選，以提升家長的參與意願
  3. （C）觀護人較了解非行少年家長之特性，由他們帶領此類團體會比諮商心理師更具成效
  4. （D）領導者除了具備相關學經歷之外，最好也熟悉婚姻經營與子女教養議題

答案：（C）

詳解與考點

正解：「強制親職教育團體」與「最不適當」；即使觀護人熟悉非行少年家長的特性，帶領團體仍需要諮商與團體催化專業，不能推論由觀護人帶領必然比諮商心理師更具成效。C 缺乏根據，故為應選項。

A：採小團體能讓家長較有機會討論個別需要與困難，符合親職教育可兼顧支持與討論的目的，故非答案。

B：團體前面談與篩選可了解家長狀況、說明團體安排並促進參與準備，雖屬強制教育，仍有其必要性，故非答案。

D：領導者除相關學經歷外，熟悉婚姻經營與子女教養議題，有助處理家長的實際困難，故非答案。

本題考點：強制親職教育團體的帶領專業——判準是族群熟悉度可提供脈絡資訊，但不等於團體領導與諮商催化能力；帶領者須兼具相關知能、團體技術與親職家庭議題理解。
