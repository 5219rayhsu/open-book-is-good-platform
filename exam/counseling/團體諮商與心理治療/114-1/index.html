第 1 題

有關酗酒者匿名團體過程的陳述，下列何者最適當？
  1. （A）這種團體因為同質性高，所以可以感同身受的幫助到每一個成員
  2. （B）這種團體是一種積極、創造性、多感官與理論導向的治療方式
  3. （C）此種領導模式通常是以影響治療（impact therapy）為理論基礎
  4. （D）這種團體通常沒有常置的專業團體領導者，但能運用特定步驟完成團體流程

答案：（D）

詳解與考點

考點為自助/匿名戒酒(AA)團體的性質。正解 D：AA 等匿名團體通常沒有常置專業領導者，而是依十二步驟等特定流程運作。它非「理論導向治療」、非以影響治療為基礎，也不必然能幫到每個成員(故A、B、C皆不適當)。陷阱是 A 過度推論同質性即能幫到每位成員。

第 2 題

關於在日照中心帶領開放式團體（open groups）的敘述，下列何者最合適？
  1. （A）當新成員進入團體時，不需再次說明團體規則，他們從和舊成員的互動中自然就會理解
  2. （B）由於成員時常進出，很難產生團體凝聚力，故領導者不需催化其凝聚力
  3. （C）因為是開放式團體，成員連續或無理由缺席是被允許的
  4. （D）領導者可能需要主動組織團體，拜訪某些成員，以及支持成員參與

答案：（D）

詳解與考點

考點為開放式團體(open group)的帶領。正解 D：成員流動性高，領導者需更主動組織、聯繫成員、支持參與以維持運作。新成員仍須重申規則(故A錯)、凝聚力雖難仍須催化(故B錯)、不應允許無故缺席(故C錯)。陷阱是誤以為開放式團體就放任成員自然理解規則與出席。

第 3 題

下列那一項敘述屬於諮商團體（counseling group）的特性？
  1. （A）團體主要的工作是修通過去經驗及對阻抗的處理
  2. （B）參與團體的人通常主要是想減輕特定的心理症狀或困擾
  3. （C）著重於協助團體成員在認知、態度或行為技巧上的學習和發展
  4. （D）團體著重於意識層面的覺察與問題解決的策略

答案：（D）

詳解與考點

考點為諮商團體(counseling group)的特性。正解 D：諮商團體著重意識層面的覺察與問題解決策略，處理發展性、預防性議題。修通過去與處理阻抗偏治療團體(A)、減輕特定症狀偏治療(B)。C「認知態度行為學習」較偏心理教育/輔導團體。陷阱是與心理治療團體的深度潛意識工作混淆。

第 4 題

下列那一種溝通技巧最能促進諮商團體成員之間的開放對話和信任？
  1. （A）鼓勵成員分享個人故事和經歷，以促進共同理解和支持
  2. （B）打斷成員發言，糾正任何誤解或不準確之處
  3. （C）示範並引導對話，讓所有成員都聚焦在團體主題上
  4. （D）提醒成員遵守專注聆聽他人發言的團體規範

答案：（A）

詳解與考點

本題問哪種溝通技巧「最能」促進團體成員間的開放對話與信任，官方答案為 (A)。(A) 鼓勵成員分享個人故事與經歷，能促進相互理解、自我揭露與支持，最直接催化開放與信任的氛圍，故為最佳。其餘相對較弱或有風險：(B) 打斷成員發言、糾正誤解，帶評價與糾錯意味，易使成員感到不安全、抑制開放，最不利信任；(C) 示範並引導對話、讓成員聚焦主題，雖有助於建立結構與安全，且本身是適當的領導作為，但對「自我揭露與共同理解」的直接促進不如 (A)；(D) 提醒遵守專注聆聽規範，有助於營造尊重的環境，同樣是正向作為，但較屬規範維持，催化開放對話的直接性不及 (A)，故本題選 (A)。

第 5 題

下列關於催化團體歷程的方法，何者不適當？
  1. （A）領導者應多運用聚焦技術，以利團體在早期能很快進入工作階段
  2. （B）領導者應協助成員學習開放地表達他們對於團體的擔心與期望
  3. （C）領導者應鼓勵成員們直接相互對話，創造溝通的機會
  4. （D）領導者應鼓勵成員公開地表達矛盾與衝突，克服溝通障礙

答案：（A）

詳解與考點

考點為催化團體歷程的方法。正解 A 不適當：過早大量用聚焦技術想「很快進入工作階段」會跳過信任與安全建立，反而揠苗助長。應協助成員表達擔心期望、鼓勵相互對話、公開表達衝突(B、C、D皆適當)。陷阱是把「快速進工作期」當好事，忽略階段須循序。

第 6 題

當一個團體的凝聚力過高，可能會出現下列那種現象？
  1. （A）提升成員的獨立思考能力
  2. （B）促進更深層次的個人探索
  3. （C）不易有個人情感與想法的表達
  4. （D）增加團體內不滿的氛圍與壓力

答案：（C）

詳解與考點

考點為團體凝聚力過高的負面效應。正解 C：凝聚力過高易形成同質壓力與從眾，使成員不易表達個人不同的情感與想法(類似團體迷思)。它不會提升獨立思考或深化探索(A、B為正向反向描述)。陷阱是把凝聚力一律當好處，忽略「過高」會壓抑異議與個別性。

第 7 題

下列關於領導者在工作階段教導成員進行有效回饋之原則，何者較不適當？
  1. （A）回饋聚焦在團體此時此刻發生的行為，會特別有效
  2. （B）委婉修飾的回饋比直接清楚的回饋，會更有幫助
  3. （C）表達自己是如何被對方的行為所影響，而不是給建議
  4. （D）及時且不具評價性的回饋，容易增加被回饋者反思的機會

答案：（B）

詳解與考點

考點為工作階段有效回饋的原則。正解 B 不適當：回饋應直接、清楚、具體，「委婉修飾」反而模糊重點、降低效果。聚焦此時此刻(A)、表達自己被影響而非給建議(C)、及時且非評價性(D)皆為良好回饋原則。陷阱是誤把「委婉」當更有幫助，但清晰直接才有效。

第 8 題

在處理團體中的信任議題時，關於領導者的作為下列何者最適切？
  1. （A）嚴格保密每個成員的發言內容
  2. （B）強調成員之間必須互相信任
  3. （C）使用團體公約來約束成員行為
  4. （D）鼓勵成員對信任問題進行公開討論

答案：（D）

詳解與考點

本題問處理團體信任議題時領導者「最適切」的作為，官方答案為 (D)。(D) 鼓勵成員針對信任問題進行公開討論，能讓信任議題在團體歷程中被覺察、表達與共同處理，最直接催化真實的信任建立，故最適切。其餘並非最佳：(A) 嚴格保密成員發言是必要的安全基礎，但保密本身屬前提條件，無法取代對信任議題的歷程性公開討論；(B) 「強調成員必須互相信任」是用要求或命令來促成信任，信任無法靠規定產生，效果有限甚至引發反效果；(C) 使用團體公約約束行為同樣是建立安全與規範的基礎工具，但僅是基礎，不足以直接催化深層信任。保密與公約皆為安全基礎、並非無用，只是相較之下 (D) 的公開歷程討論最能真正處理信任議題，故選 (D)。

第 9 題

關於領導者在團體最後一次聚會的發言，下列那一個句子最不適合？
  1. （A）有哪一位想要給其他成員回饋？
  2. （B）有沒有你自己或其他任何人所說的話，對你而言特別重要？
  3. （C）你在團體中一直都很靜默，可以告訴我們你在團體中的感覺嗎？
  4. （D）這個團體的經驗對你有何意義？

答案：（C）

詳解與考點

考點為團體結束階段的領導發言。正解 C 最不適合：在最後一次聚會才質問靜默成員「告訴我們你的感覺」屬開啟新議題，結束階段不宜再深掘無法處理的新素材。其餘 A、B、D 皆屬統整、回顧、賦予意義的結束導向問句。陷阱是把探索靜默誤當好的結束介入。

第 10 題

關於帶領諮商團體前的說明會及訪談，下列敘述何者錯誤？
  1. （A）透過團體前的個別訪談可以幫助成員進入準備狀態
  2. （B）根據相關研究，團體前的訪談或說明可能妨礙團體的療效
  3. （C）團體前的說明會同時亦具有篩選成員的作用
  4. （D）團體前的訪談有助於了解成員的人際歷史

答案：（B）

詳解與考點

考點為團體前說明會與訪談的功能。正解 B 錯：研究支持團體前訪談或說明能提升療效、降低流失，並非「妨礙療效」。它有助成員準備(A)、篩選成員(C)、了解人際歷史(D)。陷阱是 B 把團體前準備說成負面，事實與研究相反，團體前準備有益療效。

第 11 題

對於團體領導技巧的運用，下列敘述何者錯誤？
  1. （A）非結構團體進行較無法預測，需更有效運用技巧
  2. （B）隨團體進展運用深化技巧，例如活化此時此地、角色扮演
  3. （C）團體前期領導者使用連結、自我表露、解釋技巧較多
  4. （D）接受督導或協同領導團體可增進技巧的運用

答案：（C）

詳解與考點

考點為團體不同階段的領導技巧運用。正解 C 錯：團體前期重在建立關係與安全，連結、自我表露適用，但「解釋」屬較深的技巧，多用於中後期工作階段而非前期較多。A、B、D 皆正確。陷阱是把「解釋」誤列為前期常用，實則深化技術應隨團體成熟才增加。

第 12 題

對於團體領導者開放（openness）的特質，下列敘述何者錯誤？
  1. （A）是指領導者表達自己如何受到成員的影響
  2. （B）領導者本身的開放能促使成員更加開放
  3. （C）領導者的自我揭露越多，顯示開放度越大，對團體越有益
  4. （D）領導者的開放是一種真誠的表現

答案：（C）

詳解與考點

考點為領導者開放(openness)特質。正解 C 錯：開放不等於自我揭露越多越好；揭露需適切、有目的，過度揭露反而不利團體。開放指表達自己如何受成員影響(A)、能促成員開放(B)、是真誠表現(D)皆正確。陷阱是把「揭露越多越好」當成開放，忽略適度原則。

第 13 題

兒童團體初期，領導者發現小華受其他成員施壓要求做分享，小華表現猶豫和沉默，領導者最適切的回應為何？
  1. （A）我覺得你保持沉默是因為對參與團體很抗拒和不信任大家
  2. （B）你感受到團體中誰給你壓力了嗎？要不要說說看你的感受或是壓力
  3. （C）要你現在做分享似乎不太容易，在團體中你可以自行決定何時做分享
  4. （D）你在團體中可以完全不說話，別人也不可以勉強你

答案：（C）

詳解與考點

考點為兒童團體初期對沉默/受壓成員的回應。正解 C：尊重小華的步調，明確告知他可自行決定何時分享，最能保護其自主與安全。A 過早詮釋抗拒不信任、B 引導指認施壓者可能加深對立、D「完全不說話」過度極端。陷阱是 A 妄加詮釋，初期不宜貼抗拒標籤。

第 14 題

關於線上團體諮商，下列敘述何者錯誤？
  1. （A）領導者權力較低，不容易掌握成員參與
  2. （B）線上團體的倫理議題有較高的挑戰性
  3. （C）容易低估成員問題的嚴重性
  4. （D）團體規範難以促進團體的運作

答案：（D）

詳解與考點

考點為線上團體諮商的特性。正解 D 錯：線上團體的團體規範仍可促進運作，並非「難以促進運作」。其領導掌控較難(A)、倫理挑戰較高(B)、易低估問題嚴重性(C)皆為正確的線上限制。陷阱是把規範功能誤判為失效，但規範在線上仍是維持團體的重要工具。

第 15 題

當領導者懷疑自己可能成為某位成員的投射認同對象時，下列那一項處遇最不適當？
  1. （A）嘗試與被投射性認同所引發的感覺共處一段時間
  2. （B）等適當時機，向該成員解釋此潛意識幻想的本質、動機、脈絡與防衛的功能
  3. （C）辨識出投射性認同裡實際與幻想的成分，直接面質幻想成分有助於卸除其防衛
  4. （D）尋求督導者的協助，在確認其懷疑為真時，提升自己處理此投射性認同的能力

答案：（C）

詳解與考點

考點為投射性認同(projective identification)的處遇。正解 C 最不適當：「直接面質幻想成分」過於急切、易引發防衛，並非卸除防衛的好方法。較適切的是與感覺共處(A)、適當時機解釋其本質與功能(B)、尋求督導(D)。陷阱是把「直接面質」當有效，但對潛意識防衛宜緩、宜詮釋而非直接面質。

第 16 題

小美與小芬共同帶領一個諮商團體，第三次聚會由小美擔任主要領導者，小芬為協同領導者。下列那一項協同帶領團體的行為最適當？
  1. （A）小美做了歷程評論，小芬覺得小美少說了一個環節，習慣性地在她之後補充自己的評論
  2. （B）成員小志提到他的人際問題，小美聚焦在小志身上，小芬會關注其他成員
  3. （C）進行繞圈活動時小芬領頭分享，小美對團體說明小芬分享的重點，小芬接著說明這些分享主要來自於那些觀察，之後小美邀請其他成員接續分享
  4. （D）小美看到成員小凱快睡著了，詢問小凱是否狀況不佳。小芬發現正在討論的主題被打斷後，因此接著詢問：「大家想要討論原來的主題或是先關心小凱狀況？」

答案：（B）

詳解與考點

考點為協同領導(co-leader)的適當分工。正解 B：主領導聚焦於小志時，協同領導關注其他成員的反應與狀態，分工互補最恰當。A 習慣性補充易爭主導、C 過度交錯說明顯混亂、D 兩人各自打斷顯不協調。陷阱是誤選看似積極補充的A，但好的協同是分工而非互相搶話。

第 17 題

關於次團體的敘述，下列何者最不適當？
  1. （A）只要主團體的目標沒有被放棄，任何團體外的接觸都可能有其價值
  2. （B）次團體本身不會破壞團體，而是伴隨次團體的沉默共謀破壞了團體
  3. （C）若次團體的目標與主團體的目標一致，次團體可能將提升團體的凝聚力
  4. （D）當成員要求對其在次團體中的資訊保密時，領導者可承諾保密

答案：（D）

詳解與考點

考點為次團體(subgroup)的處理。正解 D 最不適當：領導者不應對成員在次團體中的資訊「承諾保密」，因團體外的秘密結盟與隱瞞會破壞團體。A、B、C 皆為對次團體較持平的正確看法(關鍵在沉默共謀而非次團體本身)。陷阱是把保密原則誤用到次團體秘密，反而助長破壞性結盟。

第 18 題

團體的沉默對於領導者來說，一方面充滿挑戰，另一方面也提供領導者豐富的團體訊息，領導者需要考量多元面向，再決定如何介入，以下那些思考面向較為適切？①考量此時團體的沉默對於團體的進展具有助益性或破壞性②領導者的強勢風格是團體沉默的主要原因③領導者邀請團體停下來討論剛剛的沉默是發生了什麼事④調整領導者的指導語與催化能力，讓成員都能夠清楚明瞭⑤團體的沉默與成員的逃避或退縮行為沒有關聯，大多是領導者的因素占大多數
  1. （A）①②③
  2. （B）②③④
  3. （C）①③④
  4. （D）①③⑤

答案：（C）

詳解與考點

考點為團體沉默的多元思考面向。正解 C①③④：須考量沉默對團體的助益或破壞性(①)、邀請團體討論沉默(③)、調整指導語與催化(④)。②⑤把沉默成因「歸咎於領導者」過於絕對，忽略成員逃避退縮等多元因素。陷阱是②⑤的單一歸因，沉默成因應多面向看待。

第 19 題

說話常滔滔不絕的阿國又佔據團體大部分時間，部分成員開始出現不耐煩的反應、有的成員減少與阿國的目光對視、有的成員開始放空，有幾位成員開始頻繁交頭接耳，領導者發現團體歷程出現停滯狀態。領導者採取下列那項介入較無法發揮效能？
  1. （A）兼顧阿國的特殊需求與團體狀況、團體任務等面向，可採取設限與積極規約介入
  2. （B）考量阿國的表達需求而衍生的成員人際反應，適切處理成員間的人際互動關係和團體次系統的狀態
  3. （C）從團體歷程發展的角度切入，促進成員覺察與調整自身所展現的人際互動模式
  4. （D）顧及阿國感受，於團體結束後以個別方式詢問他對於剛才團體人際互動模式的觀察與發現

答案：（D）

詳解與考點

考點為處理獨佔(壟斷)成員與停滯歷程的介入。正解 D 較無法發揮效能：團體歷程中的人際議題宜在團體「當下」處理，會後私下個別詢問無法即時運用此時此地動力。A 設限、B 處理人際互動、C 促進成員覺察互動模式皆能在團體內發揮效能。陷阱是把會後私談當作妥善處理。

第 20 題

面對成員在團體中出現的衝突，下列敘述何者正確？
  1. （A）團體中期衝突的產生，和成員對領導者不切實際的期待感到失望有關
  2. （B）團體衝突會干擾團體的進行，是團體發展歷程的危機並非轉機
  3. （C）領導者處理團體衝突時，需考量歷程導向並以多面向兼顧的方式因應
  4. （D）當成員選擇克制且重視人際和諧，才有助於團體凝聚力的產生

答案：（C）

詳解與考點

考點為團體衝突的觀點。正解 C：處理衝突須採歷程導向、多面向兼顧的方式因應。中期衝突主因常是對領導者期待落空(A有部分道理但非最完整)、衝突常是轉機非僅危機(故B錯)、一味追求和諧反不利真正凝聚(故D錯)。陷阱是把衝突一律視為干擾與危機。

第 21 題

社區婦女成長團體的首次聚會，好幾位成員姍姍來遲。在訂定團體規範時，領導者特別聚焦於準時出席的討論，所有成員皆同意。第二次團體仍有三位成員遲到。下列領導者的作法，何者最不適當？
  1. （A）告訴成員開始時間已經到了，不再等待遲到的成員，開始進行團體活動
  2. （B）當遲到的成員出現時，領導者隨即暫停團體，請該成員坐下並詢問其遲到的緣由
  3. （C）當遲到的成員來團體後，領導者可趁活動空檔，告知遲到的成員剛才團體的過程
  4. （D）領導者在團體結束前，再次討論團體規範，並詢問成員有無改善遲到的好方法

答案：（B）

詳解與考點

考點為團體規範與遲到處理。正解 B 最不適當：遲到者一進來就暫停團體、當眾要其說明遲到緣由，是公開羞辱、打斷歷程的處理。準時開始不等候(A)、利用空檔補述(C)、結束前再討論規範(D)皆較適切。陷阱是把當眾質問當「執行規範」，實則傷害成員與團體。

第 22 題

小明被導師轉介參加學校的諮商團體，第一次聚會時，他對領導者說：「我在這裡很無聊，我希望您可以做些什麼來讓團體變得更有趣。」下列領導者的回答，何者最適當？
  1. （A）活動還沒有開始，你會無聊，這是正常的
  2. （B）多告訴我一點你想要我怎麼做
  3. （C）你老是給別人意見，我希望你能將焦點放在自己身上
  4. （D）聽你這樣說，我覺得很難過

答案：（B）

詳解與考點

考點為面對成員挑戰/要求時的領導回應。正解 B：「多告訴我一點你想要我怎麼做」以好奇、開放邀請成員具體化需求並承擔自身角色，最具催化性。A 否定其感受、C 反擊指責、D 自我中心回應皆不當。陷阱是 C 反過來要求成員聚焦自己，看似專業卻防衛且傷關係。

第 23 題

諮商心理師帶領大學生團體時，A成員的導師來信詢問A成員的狀況，並告知已取得學生同意，可詢問諮商心理師其參加團體的情形。此時諮商心理師應如何處理最適當？
  1. （A）直接告訴導師，A成員參與團體的情形，並請導師協助留意學生在班上的情形
  2. （B）了解導師的需求及目的後，決定要告訴導師多少內容
  3. （C）與學校的督導或主任討論後，再決定是否告知導師A成員的參與情形
  4. （D）與A成員討論資訊是否揭露，再決定是否告知導師或告知的範圍

答案：（D）

詳解與考點

考點為團體保密與第三方(導師)詢問的倫理。正解 D：即使導師聲稱已取得學生同意，仍應先與A成員本人核對是否揭露及揭露範圍，再決定告知與否。直接告知(A)、自行決定多少(B)、僅與督導討論(C)皆未把當事人意願放首位。陷阱是輕信第三方轉述的同意。

第 24 題

下列那些情況，領導者適合使用切斷（cutting off）技巧？①成員的意見與團體目標牴觸②領導者決定轉移團體的焦點③團體中有成員心不在焉④成員在漫談，領導者希望該成員可以澄清問題
  1. （A）①②④
  2. （B）②③④
  3. （C）①③④
  4. （D）①②③

答案：（A）

詳解與考點

考點為切斷(cutting off)技巧的適用時機。正解 A①②④：當成員意見牴觸團體目標(①)、領導者欲轉移焦點(②)、成員漫談需澄清(④)時適合切斷。③「成員心不在焉」屬連結/引入技巧的時機而非切斷。陷阱是把切斷誤用在分心成員身上，切斷主要針對發言過多或離題者。

第 25 題

下列針對各團體發展階段的特徵描述，何者最適當？
  1. （A）在初始階段，成員相識，互相了解，建立信任，會多試探領導者
  2. （B）在工作階段，成員開始試探性的自我揭露，面對衝突能主動協調
  3. （C）在轉換階段，團體會有信任與否的議題產生，人際互動有更多的連結
  4. （D）在結束階段，成員對自己的改變有統整性的描述，彼此會避免衝突和不一致

答案：（C）

詳解與考點

考點為團體發展各階段特徵。正解 C：轉換(過渡)階段確會出現信任與否的議題、抗拒與焦慮，並逐漸增加人際連結。A 將「試探領導者」放初始尚可但敘述偏弱、B 把試探性自我揭露放工作階段時序不符、D 結束階段不應只是避免衝突。陷阱在各階段特徵的時序錯置。

第 26 題

下列那一項治療因素，最有助於團體成員個人生命意義感的提升？
  1. （A）希望感
  2. （B）團體凝聚力
  3. （C）普同感
  4. （D）利他主義

答案：（D）

詳解與考點

考點為Yalom團體治療因素中與生命意義感最相關者。正解 D 利他主義(altruism)：透過幫助他人、感到自己對他人有價值，最能提升個人生命意義感。希望感、凝聚力、普同感各有功能但與「意義感」連結較弱。陷阱是誤選凝聚力或普同感，但提升意義感最直接的是利他的付出體驗。

第 27 題

依據Yalom的觀點，關於聯合治療（conjoint therapy）與混合治療（combined therapy）的敘述，下列何者最正確？①特殊個案如人格問題、嚴重創傷，常需要採取聯合治療或混合治療②不論聯合治療或混合治療，皆以團體治療為主要模式，個別治療為補充模式③混合治療的模式，若要有輕重緩急之分，是以個別治療先於團體治療④不論是聯合治療或混合治療，皆有助於降低團體的流失率⑤聯合治療比起混合治療更需要處理在個別治療與團體治療所延伸的界線議題
  1. （A）①②④
  2. （B）①③④
  3. （C）②③⑤
  4. （D）③④⑤

答案：（B）

詳解與考點

考點為Yalom的聯合治療與混合治療。正解 B①③④：特殊個案常需聯合/混合(①)、混合治療若有先後是個別先於團體(③)、兩者皆有助降低流失率(④)。②「皆以團體為主、個別為補充」與⑤的界線敘述不正確。陷阱是②把個別治療一律當補充模式，忽略不同模式的主從不同。

第 28 題

關於阿德勒學派在學校團體諮商的概念與應用的敘述，下列何者最適當？
  1. （A）阿德勒學派重視意識、目標與動機，涵蓋內容廣泛，宜採用長期團體進行
  2. （B）社會興趣的概念對學校團體諮商不太有意義，增進兒童與青少年的自尊更為重要
  3. （C）認為在團體中成員的不禮貌行為，可能是在追求某些錯誤目標，如追求權力或尋求注意
  4. （D）藉由在團體中重新檢視他人的態度、信念與價值，使其在關注自我與他人尊重間獲得平衡

答案：（C）

詳解與考點

考點為阿德勒學派在學校團體的應用。正解 C：阿德勒重視行為背後的目的，認為不禮貌行為可能在追求錯誤目標(如尋求權力、注意、報復、無能)。A 不宜長期、B 否定社會興趣、D 偏其他取向皆不當。陷阱是 B 貶低社會興趣，但社會興趣正是阿德勒學派核心。

第 29 題

在團體諮商理論中強調理解成員的主觀世界，並尋找可為成員帶來改變的現有資源，是下列何種取向？
  1. （A）心理動力
  2. （B）經驗與關係
  3. （C）認知行為
  4. （D）後現代

答案：（D）

詳解與考點

考點為強調主觀世界並尋找既有資源帶來改變的取向。正解 D 後現代：焦點解決、敘事等後現代取向重視成員主觀經驗，並挖掘其既有資源與例外、優勢促成改變。心理動力、經驗關係、認知行為的核心假設不同。陷阱是與經驗/關係取向混淆，但「尋找現有資源促改變」是後現代(尤其焦點解決)標誌。

第 30 題

人本主義取向和認知行為取向在團體諮商工作中都是廣泛使用的理論，以下敘述何者錯誤？
  1. （A）兩者都致力於幫助成員促進個人的成長和改變
  2. （B）兩者都強調成員之間的互動是團體重要的部分
  3. （C）人本主義取向的領導者扮演「導師」和「教導者」的角色；認知行為取向的領導者則扮演「陪伴者」和「促進者」的角色
  4. （D）人本主義取向認為團體動力的核心是成員之間的關係與情感；認知行為取向則視團體動力為達成治療目標的工具，藉由互動來促成改變

答案：（C）

詳解與考點

考點為人本取向與認知行為取向的比較。正解 C 錯：角色描述顛倒。認知行為取向的領導者較像「導師/教導者」(主動、結構化)，人本取向領導者較像「陪伴者/促進者」(以關係為主)。A、B、D 描述兩者共通與差異皆正確。陷阱是把兩取向的領導角色對調。

第 31 題

針對某團體成員甲表達出對於另一成員乙莫名的敵意時，領導者邀請甲說說乙給他的感覺像是他所熟悉的那個人。這是那一理論取向的領導者較常使用的探索技巧？
  1. （A）認知行為治療
  2. （B）心理動力取向
  3. （C）人本存在取向
  4. （D）後現代取向

答案：（B）

詳解與考點

考點為團體領導者的理論取向與技巧。將成員對另一人的「莫名敵意」連結到過去熟悉的人，正是心理動力取向的移情（transference）概念，故選 B。陷阱在認知行為治療（A）聚焦當下的想法與行為，不會探索成員把舊關係投射到新對象的潛意識歷程。

第 32 題

在團體內，成員甲幾乎沒有回應過其他成員的談話內容，但在團體沉默時就開始談論他在團體外的成就，例如：「這個星期股票又賺了多少錢。」下列何者是個人中心學派的領導者，最不可能的反應？
  1. （A）仔細觀察甲說話時，其他成員的表情，但不做任何介入
  2. （B）邀請甲多分享一點炒股秘訣，以協助甲與其他成員的互動
  3. （C）鼓勵成員表達當甲說這些事情時，自己的真實感受與想法
  4. （D）反映甲僅陳述外在世界的經驗，邀請其分享對團體的信任與安全感

答案：（B）

詳解與考點

考點為個人中心學派領導者的態度。該學派重真誠、同理與此時此地的關係，故會反映成員只談外在、邀請其分享團體內感受（C、D、A），B 鼓勵成員多談炒股秘訣等於強化其逃避團體互動，最不可能，故選 B。陷阱是把「促進互動」誤當成順著話題，反而偏離歷程。

第 33 題

Flowers（1999）主張，團體第一次聚會前，先請成員在小卡片寫下來參加團體想要處理的問題，以利於首次聚會，減少過長沉默的窘境。這是何種理論取向最可能的作法？
  1. （A）認知行為治療
  2. （B）敘事治療
  3. （C）個人中心治療
  4. （D）完形治療

答案：（A）

詳解與考點

考點為各學派團體前的結構化作法。聚會前先寫卡片、設定要處理的問題以減少沉默，屬高度結構與目標導向，符合認知行為治療，故選 A。陷阱在敘事、個人中心與完形（B、C、D）較重歷程與當下經驗，不會用此種預先結構化的暖身設計。

第 34 題

下列關於規劃和設計伴侶諮商團體的敘述，何者最適當？
  1. （A）篩選面談應個別進行了解其需求，避免因雙方一起會談造成個人無法充分表達的問題
  2. （B）可以設計活動幫助成員檢視其妨礙親密的心理遊戲以及探索影響愛情價值觀的童年經驗
  3. （C）最好不要超過六對伴侶，才有足夠時間讓成員分享
  4. （D）若伴侶其中一方不願意承諾為彼此關係而努力，可鼓勵其參與團體來展現對伴侶的重視

答案：（B）

詳解與考點

考點為伴侶諮商團體的規劃原則。B 設計活動檢視妨礙親密的心理遊戲、探索童年經驗，符合伴侶團體的工作目標，故正確。陷阱在 D：若一方不願承諾關係，硬拉其入團反而無效且不倫理，是常見誤選；A、C 的篩選與人數敘述也過於絕對。

第 35 題

諮商心理師在某大學帶領實體人際關係團體，在進行到第三次的時候，成員A表示因為假期返家來不及回到學校，但又表達想參加的意願，想用視訊的方式參加。下列領導者的做法何者最適切？
  1. （A）徵詢每一位成員的想法與意見，採多數決，決定A是否以線上參與
  2. （B）肯定A成員的積極參與，但考量到網路的保密性，請A下次聚會再參與
  3. （C）請成員A全程需開設鏡頭與麥克風，且需發言與參與活動
  4. （D）修改團體的方案，搭配目標，以線上能同步進行的活動為優先

答案：（B）

詳解與考點

考點為團體保密與媒介倫理。實體人際團體臨時改視訊，網路保密性難掌控，肯定成員但請下次再參與最為穩妥，故選 B。陷阱在 A 採多數決，把保密與成員權益交付表決並不適當；C、D 強行配合線上也忽略了既有團體的安全結構。

第 36 題

關於親密關係暴力倖存者的團體，領導者於團體前需蒐集與評估相關資訊以有效規劃團體，下列描述何者錯誤？①確認倖存者其伴侶或其他家庭成員對倖存者的期待或角色②蒐集倖存者曾歷經的暴力樣態與親密關係互動史③評估倖存者過去、現在與未來的風險程度④了解倖存者的支持系統，如人際、家庭、社政、法政等資源
  1. （A）①③
  2. （B）②③④
  3. （C）僅②④
  4. （D）僅③④

答案：（A）

詳解與考點

本題問「何者錯誤」，須選出規劃倖存者團體前不當的評估敘述，官方答案 A（①③）正確。①錯：在親密關係暴力脈絡中，以加害者（伴侶）或家庭成員「對倖存者的期待或角色」為評估焦點，等於把倖存者放回被定義、被要求順從的位置，違背賦權（empowerment）與以倖存者安全為核心的原則；領導者該評估的是倖存者自身的需求與安全，而非加害方的期待，故為錯誤敘述。③錯：風險評估只能根據過去與當前的危險指標（如暴力史、致命危險因子、當下處境）進行，「未來」的風險本質上無法被準確評估或預測，宣稱可評估「未來風險程度」在方法學上不成立，故為錯誤敘述。相對地，②（蒐集暴力樣態與親密關係互動史）與④（了解人際、家庭、社政、法政等支持系統資源）都是規劃倖存者團體前正確且必要的評估內容。因此錯誤項為①③，答案為 A。

第 37 題

下列那種作法較不適合運用在兒童團體？
  1. （A）運用多重感官的媒材，維持兒童的專注力
  2. （B）進行深層的個人議題探索，催化團體效力
  3. （C）切斷成員的漫談，讓其他成員有機會分享
  4. （D）將話題帶回到原來討論的主題，以維持團體進行的方向

答案：（B）

詳解與考點

考點為兒童團體的帶領原則。兒童認知與專注有限，宜用多感官媒材、適時切斷漫談與聚焦主題（A、C、D），B 進行深層個人議題探索超出兒童發展與團體承載，最不適合，故選 B。陷阱是把成人取向的深度自我探索套用到兒童團體。

第 38 題

關於帶領HIV/AIDS諮商團體的主要焦點，下列何者正確？
  1. （A）治療性焦點與教育性的內容同等重要
  2. （B）治療性焦點比教育性的內容重要
  3. （C）教育性的內容比治療性焦點重要
  4. （D）AIDS患者與HIV感染者處理的焦點不同

答案：（A）

詳解與考點

考點為 HIV/AIDS 諮商團體的焦點。此類團體既要情緒支持與因應（治療性），也要疾病知識與防治（教育性），兩者同等重要，故選 A。陷阱在 B、C 把兩者分高下，D 則錯誤區分感染者與患者的處理焦點，皆不符團體整合性的設計理念。

第 39 題

Corey等人（2014）建議領導者在進行哀傷失落團體前，要能自我檢視與覺察，下列描述何者最不適當？
  1. （A）領導者宜先完全解決曾經遭遇的失落議題，以免造成在團體中情緒的崩潰
  2. （B）領導者個人對於失落哀傷的害怕，可能干擾其對團體相似議題的處理
  3. （C）領導者決定如何面對生命中不可逃避的存在議題，將影響其與個案工作和成長
  4. （D）哀傷、失落經驗易觸動個人最深層的恐懼，領導者若未能覺察自己的經驗，將嚴重影響此議題的處理

答案：（A）

詳解與考點

考點為哀傷失落團體領導者的自我覺察。領導者需覺察自身失落經驗、面對存在議題（B、C、D 正確），A 要求「完全解決」自身失落才能帶團體並不切實際，重點是覺察而非全然解決，故最不適當選 A。陷阱是把「覺察」誤解為「必須先療癒到零殘留」。

第 40 題

關於非行少年家長的強制親職教育團體，下列敘述何者最不適當？
  1. （A）採用小團體方式進行，較能幫助家長深入討論其個別的需要和困難
  2. （B）團體進行前領導者應該先對家長進行面談與篩選，以提升家長的參與意願
  3. （C）觀護人較了解非行少年家長之特性，由他們帶領此類團體會比諮商心理師更具成效
  4. （D）領導者除了具備相關學經歷之外，最好也熟悉婚姻經營與子女教養議題

答案：（C）

詳解與考點

考點為強制親職教育團體的帶領者專業。C 主張觀護人帶領比諮商心理師更有成效並無根據，團體催化仍需專業諮商能力，故最不適當選 C。陷阱在以「熟悉個案族群」誤等於「具備團體領導專業」，忽略了帶領技巧與專業訓練的必要性。
