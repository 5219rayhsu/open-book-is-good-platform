第 1 題

利用團體為成員進行深度、個別性的治療工作時，下列何者最不適當？
  1. （A）領導者必須擁有良好的個別諮商技巧
  2. （B）治療應由領導者主導，其他成員提供分享和領悟
  3. （C）成員分享出現強烈情緒時，領導者應立即協助深入處理
  4. （D）當次團體的焦點可停留在某成員身上較長時間，以深入其議題

答案：（C）

詳解與考點

正解：「深度、個別性的治療工作」與「最不適當」——強烈情緒出現時，判準不是立刻深掘，而是先衡量安全、團體承載力與該成員的準備度。（C）把協助深入處理說成一律「立即」進行，忽略時機與危機處遇，故為應選項。

A：領導者若要在團體內進行個別深度工作，須具備良好的個別諮商技巧，才能兼顧焦點成員與全體團體歷程，故非答案。

B：深度個別工作需要領導者維持結構與焦點，其他成員仍可透過分享與領悟參與；此非指領導者獨占團體，而是維持處遇秩序，故非答案。

D：當團體同意且時機適切時，焦點可在某一成員身上停留較久，以深化議題並連結其他成員的共鳴，故非答案。

本題考點：團體中的個別深度工作——判準是「先評估安全、準備度與團體承載力，再決定是否深化」；情緒強烈是需要調節與評估的訊號，不是立即深入處理的指令。

第 2 題

相較於心理教育團體，下列關於團體諮商的敘述，何者最為正確？
  1. （A）團體的焦點通常是由成員所決定
  2. （B）成員通常缺乏某一特定領域的相關資訊
  3. （C）團體聚焦於成員的認知探索與學習
  4. （D）運用團體動力原理與過程預設工作目標

答案：（A）

詳解與考點

正解：「相較於心理教育團體」——判準是團體焦點由預先設計的知識與目標主導，還是由成員當下需求與互動歷程形成。團體諮商較開放，焦點通常由成員帶入的經驗與此時此地互動決定，故選 A。

B：成員缺乏某特定領域資訊，是心理教育團體常見的招募與設計基礎，故非答案。

C：聚焦認知探索與學習較符合心理教育團體以知識、技能與理解為主要任務的特徵，故非答案。

D：預設工作目標並運用團體動力達成之，較接近心理教育團體的結構化安排；它看起來也使用團體動力，最易混淆，但關鍵在目標是否先被設定，故非答案。

本題考點：團體諮商與心理教育團體的區辨——判準是「成員需求共同形成焦點」為團體諮商；「特定知識、技能與預設目標」為心理教育團體。

第 3 題

諮商心理師公會全國聯合會在大地震過後，邀請當地諮商心理師於收容所內進行每週一次2小時的聚會，協助災民彼此激勵分享感受，這是那一類團體？
  1. （A）討論團體
  2. （B）諮商與治療團體
  3. （C）教育團體
  4. （D）支持性團體

答案：（D）

詳解與考點

正解：「大地震後的收容所」、「彼此激勵」與「分享感受」——此情境的核心是危機後的情緒支持與相互扶持，而非深層人格改變。這類每週聚會屬支持性團體，故選 D。

A：討論團體以交換意見、分析議題或形成決策為主，未必以成員的情緒支持為主要任務，故非答案。

B：諮商與治療團體較著重深層議題處理、行為改變或人格成長；本題在災後收容情境優先提供支持，故非答案。

C：教育團體主要傳遞知識與技能，例如疾病或因應資訊；題幹強調彼此激勵與感受分享，故非答案。

本題考點：團體類型辨識——判準是「以情緒支持、相互扶持與降低孤立感為首要目的」即支持性團體；若主要傳遞資訊才是教育團體，若著重深層改變才偏向諮商與治療團體。

第 4 題

關於成員互動過程對於團體進展的敘述，下列何者最正確？
  1. （A）領導者應壓抑成員對於彼此敵意的表達
  2. （B）因為團體的溝通不能中斷，成員間的衝突要包容且被鼓勵
  3. （C）成員間互相不在意時，才會冒險說出對彼此的負向感受
  4. （D）衝突會降低成員的自我坦露，領導者宜保護成員使其朝向建設性的團體工作階段

答案：（D）

詳解與考點

正解：「成員互動過程」與「團體進展」——衝突既可能暴露關係議題，也可能暫時降低安全感與自我坦露；判準是領導者能否將它引向建設性工作。（D）兼顧保護成員與引導團體進入建設性階段，故選 D。

A：壓抑敵意的表達會讓重要的關係資料轉入檯面下，無助於學習以安全方式處理衝突，故非答案。

B：衝突不可因「溝通不能中斷」便一概鼓勵；缺乏界限的衝突可能傷害成員，故非答案。

C：成員願意表達負向感受通常需要關係中的在意與足夠安全感，不是互不在意才敢冒險，故非答案。

本題考點：團體衝突的領導——判準是「不壓抑、不放任，並以安全界限將衝突轉為可理解、可學習的互動」；衝突本身不是目標，建設性處理才是。

第 5 題

關於團體動力現象的敘述，下列何者錯誤？
  1. （A）次團體的發生不可能被禁止，但也不應該被鼓勵
  2. （B）癌症成員的團體外接觸是團體過程中的重要部分
  3. （C）在次團體中，瀰漫於團體中的「沉默的共謀」才是破壞團體的主因
  4. （D）當成員以秘密結盟的方式滿足個人需求，代表團體任務的達成高於成員附帶的滿足

答案：（D）

詳解與考點

正解：「秘密結盟」與「何者錯誤」——秘密結盟若是為滿足個人需求，代表隱藏的附帶滿足正在侵蝕公開團體任務，而不是團體任務優先。（D）將兩者關係顛倒，故為應選項。

A：次團體的形成難以完全禁止，但領導者也不宜鼓勵其排他結盟；應將其對團體的影響帶回公開歷程處理，故非答案。

B：癌症成員的團體外接觸可延伸支持網絡，是團體過程中具意義的部分，故非答案。

C：次團體中未被說出的沉默共謀會讓衝突與需求無法公開工作，往往比可見的結盟更具破壞性，故非答案。

本題考點：次團體與秘密結盟——判準是「是否使成員把需求公開帶入團體工作」；秘密結盟以私下滿足取代公開處理，表示附帶滿足凌駕團體任務。

第 6 題

成人女性飲食疾患治療團體的主要目標，下列何者最不適當？
  1. （A）對於異常進食習性的自我揭露
  2. （B）學習必要的營養及控制體重的知識
  3. （C）瞭解自尊、自我控制、身體意象與飲食的關係
  4. （D）找出成員的各種人際困難與議題

答案：（B）

詳解與考點

正解：「成人女性飲食疾患治療團體」與「最不適當」——治療目標應促進對飲食行為、身體意象與人際議題的理解，而非再把注意力集中於體重控制。（B）雖含營養知識，卻以「控制體重」為重心，可能強化既有體重執著，且較偏心理教育，故為應選項。

A：在安全團體中自我揭露異常進食習性，有助於減少羞恥與孤立，並使行為模式可被理解與工作，故非答案。

C：探索自尊、自我控制、身體意象與飲食的關係，可觸及飲食疾患的心理機制，故非答案。

D：辨識人際困難與議題可了解症狀在關係中的功能，亦是治療團體合宜的工作方向，故非答案。

本題考點：飲食疾患治療團體目標——判準是「促進覺察、關係理解與較健康的因應」；單純傳授控制體重的內容易失焦，並可能加重對體重的過度關注。

第 7 題

關於如何避免團體成員流失問題的敘述，下列何者正確？
  1. （A）領導者在團體開始前都不要讓成員知道團體內容，好讓成員驚喜而繼續參與團體
  2. （B）當成員不積極參與活動時，不該將成員請出去或轉介其他團體，而是要調整活動以留住他
  3. （C）領導者為了吸引成員留在團體，不管目標為何，都要設計活潑生動的活動，以留住成員
  4. （D）領導者被成員告知要退出團體時，可適時鼓勵成員回到團體中一起討論、處理

答案：（D）

詳解與考點

正解：「避免團體成員流失」——成員提出退出時，判準不是設法留人，而是尊重其選擇並邀請其把退出感受帶回團體檢視。（D）適時鼓勵成員回到團體共同討論、處理，能增加知後選擇與修通機會，故選 D。

A：團體開始前應清楚說明性質、目標與進行方式，以取得知後同意；隱瞞內容製造驚喜是操弄，故非答案。

B：成員不積極參與時，領導者需評估其需求、適配性與是否需轉介，不能為留人而無原則調整活動，故非答案。

C：活動設計應服務團體目標與成員需求，而不是不論目標只求活潑生動，故非答案。

本題考點：預防成員流失的倫理處遇——判準是「提供清楚資訊、檢視適配性並公開處理退出意圖」；留在團體不是唯一目的，尊重自主與合宜轉介同樣重要。

第 8 題

下列那一項處遇最不適合在團體最後一次聚會時進行？
  1. （A）增強所有成員於團體中學習到的部分
  2. （B）邀請所有成員分享生命中成功的經驗
  3. （C）邀請所有成員分享希望感並給予彼此鼓勵
  4. （D）鼓勵所有成員處理團體過程中未完成的事務

答案：（B）

詳解與考點

正解：「團體最後一次聚會」與「最不適合」——結束階段的判準是整合學習、處理分離與未竟事務、連結未來，而非展開與收尾任務無直接關係的新主題。（B）邀請分享生命中成功經驗雖正向，卻不是結束階段的核心處遇，故為應選項。

A：增強成員在團體中學到的部分，有助於統整收穫並遷移到團體外，故非答案。

C：分享希望感並給予彼此鼓勵，能協助成員面對結束與維持支持，故非答案。

D：處理團體中的未完成事務，可讓關係與情緒獲得較完整的收束，故非答案。

本題考點：團體結束階段任務——判準是「統整學習、處理未竟事務、面對分離並規劃延續」；一般性的成功經驗分享可在其他時段進行，卻不如收尾任務優先。

第 9 題

在團體初期，成員甲是個積極發言投入團體的人，但他常以貶抑和輕視的評論來回應乙成員的自我揭露，而誘發乙成員的憤怒，讓整個團體出現火藥味。領導者下列何種介入最不恰當？
  1. （A）保護乙成員，並反映其所觀察到的互動行為及情感給甲、乙雙方
  2. （B）邀請其他成員來回饋其所觀察到的雙方行為
  3. （C）使用面質的技術來指出成員甲行為中的不一致現象
  4. （D）反映成員乙所體驗到的情緒感受

答案：（C）

詳解與考點

正解：「團體初期」與甲以貶抑評論引發乙憤怒——初期的首要任務是建立安全與信任；面質雖可促進覺察，卻需有足夠關係基礎。（C）立即指出甲的不一致，容易引發防衛並加劇衝突，故為應選項。

A：保護乙並反映甲、乙互動行為與情感，能先恢復安全並讓雙方看見正在發生的歷程，故非答案。

B：邀請其他成員回饋所觀察到的互動，可在領導者維持安全界限下擴大團體覺察，故非答案。

D：反映乙所體驗到的情緒感受，能確認其受衝擊經驗並降低被忽略感，故非答案。

本題考點：團體初期的衝突介入——判準是「先保護安全、反映互動與情緒，再依信任程度決定是否面質」；面質方向可能正確，錯在初期時機過早。

第 10 題

下列何者最不可能是團體轉換階段中成員焦慮的原因？
  1. （A）擔心自己若在團體中哭了，不知會發生什麼事
  2. （B）想知道團體其他成員是否真的不會傷害自己
  3. （C）想知道現實生活中是否有人會像團體裡的成員一樣關心自己
  4. （D）擔心自己說了不該說的話，被領導者認為自己是個難搞的人

答案：（C）

詳解與考點

正解：「轉換階段」與「最不可能」——此階段的焦慮多圍繞安全、信任、被評價與自我揭露的後果。（C）關心現實生活是否有人像團體成員般關心自己，較接近工作後期或結束時對支持關係的反思，不是轉換階段典型焦慮，故為應選項。

A：擔心在團體哭泣後會發生什麼事，反映自我揭露與脆弱是否安全的焦慮，故非答案。

B：想確認其他成員是否真的不會傷害自己，正是轉換階段測試信任與安全感的表現，故非答案。

D：害怕被領導者視為難搞的人，涉及被評價與被接納的不安，故非答案。

本題考點：團體轉換階段——判準是「成員正在測試安全、信任與表露自我的風險」；對團體支持能否延伸至現實生活的思考，較常出現在關係已深化或接近結束時。

第 11 題

領導者在諮商團體人際互動回饋的層次中，成員間給予他人忠告與建議的行為，最常出現在那一個階段？
  1. （A）開始階段
  2. （B）轉換階段
  3. （C）工作階段
  4. （D）結束階段

答案：（B）

詳解與考點

正解：「給予他人忠告與建議」——這是較表淺、以替他人解決問題為主的人際回饋，常出現在信任尚未深化的轉換階段。成員此時一面想互助、一面仍迴避直接表露自身情感與關係感受，故選 B。

A：開始階段以定向、建立規範與初步安全感為主，成員尚在認識彼此，忠告與建議並非最典型的回饋型態，故非答案。

C：工作階段較能進行此時此地的深入回饋，重點是感受、互動與關係影響，不只停留於給建議，故非答案。

D：結束階段著重統整、告別與將學習帶回生活，並非忠告最常出現的時段，故非答案。

本題考點：團體階段與人際回饋層次——判準是「建議多是尚未深入關係的表淺互助」；轉換階段常見，工作階段則更能回饋此時此地的情感與互動。

第 12 題

領導者小雅帶領一個由高中男生所組成的諮商團體，在第二次聚會時，有兩三位成員不斷提到上學期領導者小可姐姐多麼的好，而小可剛好是小雅的同學。關於小雅的回應或處理，下列何者最適切？
  1. （A）這是屬於團體外的事件，請不要談論團體外的人或事
  2. （B）聽起來你們很喜歡上學期的團體及領導者，我和小可是不同的
  3. （C）你們分享了上學期參與團體的正向經驗，還有負向的感受嗎？

  2. （B）由於法定要求，成員沒有選擇的權利，必須揭露其犯行，故所有成員都有保密義務
  3. （C）雖然領導者無法讓成員自由決定參加與否，但仍需盡力降低因參與而產生的恐懼及抗拒心理
  4. （D）即使是強制治療，領導者不宜假設所有成員皆無意願改變，仍需建立對成員合宜的治療目標

詳解與考點

第 40 題

關於兒童團體之敘述，下列何者錯誤？
  1. （A）領導者需於團體中主動引導兒童發展正向的人際互動關係
  2. （B）除了強烈缺乏信任感的兒童外，一般而言兒童比成人更快度過轉換階段進入工作階段
  3. （C）當兒童在團體中抱怨父母時，領導者先與他們站在同一邊對抗父母，兒童可因此獲得與其他大人相處時不同的經驗
  4. （D）即使是早已預定好的團體結束時間，對某些兒童而言，結束的時間點仍是不成熟或有傷害的，宜謹慎處理

答案：（C）

詳解與考點

正解：「兒童抱怨父母」卻要求領導者「站在同一邊對抗父母」；兒童團體領導應承接情緒並維持專業中立，而非形成對抗性聯盟。C 會強化兒童與父母的對立，也使領導者捲入家庭衝突，違反適切的團體帶領原則，故為應選項。

A：領導者主動促進兒童的正向人際互動，能協助成員在安全情境中練習關係技巧，敘述正確，故非答案。

B：兒童團體通常較成人更快通過轉換階段並進入工作階段，但強烈缺乏信任感者例外，敘述符合兒童團體的發展特性，故非答案。

D：團體結束即使早有約定，仍可能對部分兒童造成失落或傷害，領導者應審慎處理終止歷程，敘述正確，故非答案。

本題考點：兒童團體帶領的專業角色——判準是領導者是否在同理兒童情緒的同時維持中立與安全界線；促進正向互動、依團體發展調整帶領及審慎處理終止均屬適切作法，結盟對抗家長則會使團體捲入家庭衝突。
