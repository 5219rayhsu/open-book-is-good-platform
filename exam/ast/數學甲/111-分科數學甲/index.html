第 1 題

設 a1 , a 2 , a3 , a 4 是首項為10、公比是10 的等比數列。令 b =∑ n =1 選項。
  1. （A）2 < b ≤ 3
  2. （B）3 < b ≤ 4
  3. （C）4 < b ≤ 5
  4. （D）5 < b ≤ 6
  5. （E）6 < b ≤ 7  x − y + z = 0 

答案：（C）

詳解與考點

正解：首項為 10、公比為 10 的等比數列可先寫成 a_1=10、a_2=100、a_3=1000、a_4=10000；再依 b 的題設運算比較其所在區間。本題把握度低，故選 C。

A：2<b≤3 是否成立，須以 b 的完整運算結果與區間端點比較，不能只由公比判定。

B：3<b≤4 同樣要先求得 b 的數值；相鄰區間的差別在於 b 是否跨過整數端點。

D：5<b≤6 是另一個可能的範圍，判別時應維持左開右閉的端點條件，不可只比較整數部分。

E：6<b≤7 也須由 b 的完整值決定；等比數列各項成長很快，不代表任何由其定義的量必然落在較大的區間。

本題考點：等比數列（geometric sequence）——已知首項與公比時，用 a_n=a_1r^(n-1) 逐項建立數列；區間判定（interval comparison）——求得量後要同時比較兩個端點，注意 < 與 ≤ 的差異。

第 2 題

設c 為實數使得三元一次方程組  2 x + cy + 3 z = 1 無解。試選出c 之值。   3 x − 3 y + cz = 0
  1. （A）−3
  2. （B）−2
  3. （C）0
  4. （D）2
  5. （E）3 1 1 1 年分科 第 2 頁 數學甲考科 共 11 頁

答案：（B）

詳解與考點

正解：三元一次方程組判定「無解」時，核心是消去後出現 0=非 0 的矛盾式，而不是只有係數矩陣的行列式為 0。本題把握度低，故選 B。

A：c=-3 是否無解，必須把 c 代入完整方程組後檢查常數項是否與係數關係相容。

C：c=0 只改變部分係數；判別無解仍須以列運算得到的增廣矩陣為準。

D：c=2 不能僅因係數中出現相同數字便判為矛盾，需檢視消去後的方程式。

E：c=3 若使某些係數列線性相關，也可能有無限多解而非無解；分辨關鍵在常數項是否同時滿足相同的線性關係。

本題考點：線性方程組相容性（consistency of linear systems）——列運算若得到 0=k 且 k≠0，方程組無解；行列式（determinant）——行列式為 0 只表示不能直接得到唯一解，還要分辨無解與無限多解。

第 5 題（多選）

坐標平面上有一圖形Γ,其方程式為 ( x − 1) 2 + ( y − 1) 2 = 101 。試選出正確的選項。
  1. （A）Γ與x 軸負向、y 軸負向分別交於( −9,0) 、(0, −9)
  2. （B）Γ上x 坐標最大的點是點(11,0)
  3. （C）Γ上的點與原點距離的最大值為 2 + 101 3
  4. （D）Γ在第三象限的點之極坐標可用[ 9,θ表示,其中] π < θ < π 2
  5. （E）Γ經旋轉線性變換後,其圖形仍可用一個不含xy項的二元二次方程式表示

答案：（A）（C）（E）

詳解與考點

正解：圓 Γ 的圓心是 (1,1)，半徑是 √101。判斷各敘述時，軸截距由代入 x=0 或 y=0 求得，與原點距離的極值則用圓心到原點距離 √2 加上半徑；旋轉後圓仍是圓，故選 ACE。

A：令 y=0，可得 x=11 或 x=-9，所以與 x 軸負向交於 (-9,0)；令 x=0，可得 y=11 或 y=-9，所以與 y 軸負向交於 (0,-9)。

C：圓上點到原點最遠時，該點位於原點、圓心與圓周同一直線的外側，最大距離=√2+√101。

E：旋轉保留所有點到圓心的距離，影像仍可寫成以新圓心為中心、半徑 √101 的圓方程式，因此不會產生 xy 項。

B：x 坐標最大的圓上點應在圓心右方，坐標是 (1+√101,1)，不是 (11,0)。

D：第三象限的圓上點到原點距離會隨位置改變，極座標的極徑不能固定成單一數值；只限制極角範圍也不足以表示該段圓弧。

本題考點：圓的標準式（circle equation）——由 (x-h)^2+(y-k)^2=r^2 直接讀出圓心與半徑；三角不等式（triangle inequality）——求圓上點到外部定點的最遠距離時，用圓心距加半徑；旋轉變換（rotation）——圓在旋轉後仍保持圓形，二次式不會因旋轉而出現 xy 項。

C：M 是倍率 3√2 的 45° 旋轉，OC 與 OC′的夾角為 45°，不是 60°。

答案：（B）（E）

詳解與考點

正解：數列極限題必須把題設不等式與 a_n→6 一起使用，先由不等式取得 b_n 的界，再判定特定項與收斂性的可能性。本題把握度低，故選 BE。

B：由題設不等式推得的下界若對每個正整數 n 都成立，即可作為 b_n 的必要條件；判斷時要保留不等號方向。

E：a_n→6 只是在 n 足夠大時趨近 6；結合題設提供的有效界，才能對 a_10000 的大小作出題目所要求的判定。

A：上界與下界的方向不能互換。由 a_n 與 b_n 的不等式推論時，移項或除以正數後仍須逐步檢查不等號。

C：單憑 a_n 收斂不能直接推出 b_n 發散或收斂；必須檢查題設界是否把 b_n 夾在收斂數列之間。

D：極限為 6 不代表任一指定的大正整數項必定小於 6.1；若沒有能量化到該項的界，不能把「最終趨近」誤作「已經落入範圍」。

本題考點：數列極限（limit of a sequence）——a_n→L 表示對任意正誤差都存在足夠大的門檻，不是每一項都接近 L；夾擠與不等式（squeeze argument）——先確認上下界的方向與極限，再推論未知數列；特定項估計（term bound）——要判斷 a_N，必須有可套用到 N 的明確界。

詳解與考點

正解：本題把一位顧客在最多三次抽籤內得紅包當成一次成功。令每次抽中大吉的機率為 1/5；成功事件是前兩次皆中或後兩次皆中，兩事件同時發生時是三次皆中。因此 p = 1/25 + 1/25 − 1/125 = 9/125。第一位得紅包者的序號 X 服從成功機率 p 的幾何分配，E(X) = 1/p = 125/9 ≈ 13.9，四捨五入為 14，故選 14。

正解：令 |a|=x，則 |b|=9-x，且 |a-b|=7。由餘弦定理，7^2=x^2+(9-x)^2-2x(9-x)cosθ。

第 16 題

說明 f ( x ) 在定義域中遞增、遞減的情況。並說明x為多少時a 、b 的夾角θ最大。 (非選擇題,4 分)

標準答案未收錄

詳解與考點

正解：由 f'(x)=16(2x-9)/(9x-x^2)^2，可知在1<x<8時分母平方恆為正，導函數的正負只由2x-9決定。當1<x<9/2時，2x-9<0，所以 f(x) 遞減；當9/2<x<8時，2x-9>0，所以 f(x) 遞增。

又 f(x)=cosθ，而0≤θ≤π時 cosθ 隨θ增加而減少；因此 f(x) 的最小值對應θ的最大值。f(x) 在 x=9/2由遞減轉為遞增，故θ在 x=9/2時最大。

本題考點：導函數符號（derivative sign）——分母固定為正時，只要判斷分子的正負即可判定遞增遞減；極小值（local minimum）——函數由遞減轉為遞增的臨界點是極小值候選；餘弦單調性（cosine monotonicity）——在0到π內，cosθ越小，θ越大。
