第 1 題

下列何者不會影響藥品的比旋光度（specific rotation）？
  1. （A）溫度
  2. （B）溶劑
  3. （C）燈源波⻑
  4. （D）貯液管⻑度

答案：（D）

詳解與考點

正解：比旋光度以 [α]λT = α/(l·c) 表示，已把觀測旋光角 α 依貯液管長度 l 與濃度 c 校正。改變 l 會改變觀測旋光角，卻不改變校正後的比旋光度，故選 D。

A：溫度會改變分子的構形、分子間作用與溶液折射行為，因此會影響比旋光度。

B：溶劑改變溶質的溶劑化狀態，可能改變旋光表現，故（B）會影響比旋光度。

C：旋光物質具有 optical rotatory dispersion，不同燈源波長下的旋光度可不同，故（C）也會影響結果。

本題考點：比旋光度（specific rotation）——以 [α]λT 將光徑與濃度標準化後再比較物質旋光性；光學旋光色散（optical rotatory dispersion）——判讀旋光數值時必須同時固定溫度、溶劑與波長。

第 2 題

維⽣素A之含量測定中，應避免接觸者不包含下列何項？
  1. （A）光
  2. （B）⽔
  3. （C）空氣
  4. （D）氧化劑

答案：（B）

詳解與考點

正解：維生素 A 的共軛多烯結構容易受光與氧化破壞；含水並非其含量測定中必須特別避免接觸的主要因素，因此（B）不包含在題目所問的避免事項內，故選 B。

A：光會促進維生素 A 的光異構化與光氧化，故（A）確實應避免。

C：空氣中的氧可氧化共軛多烯鏈，使有效成分含量下降，故（C）正確。

D：氧化劑會直接加速維生素 A 的氧化分解，故（D）也屬應避免接觸者。

本題考點：共軛多烯安定性（conjugated polyene stability）——含長共軛雙鍵的脂溶性維生素應優先防光與防氧化；藥品含量測定前處理（assay sample handling）——依主降解途徑選擇避光、隔氧或避氧化劑措施，不把所有接觸物一概列為關鍵風險。

第 3 題

欲定量葡萄糖注射液的葡萄糖，下列何者最適當？
  1. （A）氣相層析法
  2. （B）旋光度測定法
  3. （C）紫外光光譜法
  4. （D）原⼦吸收光譜測定法

答案：（B）

詳解與考點

正解：葡萄糖具手性且有穩定的旋光性，注射液可直接以旋光度與濃度的關係定量，不需先衍生化，故（B）最適當，故選 B。

A：葡萄糖不易揮發，使用氣相層析通常須先衍生化，作為直接定量法不如旋光度測定合適。

C：葡萄糖缺乏強而專一的紫外光吸收發色團，故（C）的靈敏度與選擇性不適合作為首選。

D：原子吸收光譜法測定的是金屬元素，不是有機分子葡萄糖，故（D）不適用。

本題考點：旋光度定量（polarimetry）——對具有已知比旋光度且樣品基質單純的光學活性物質，可由旋光角直接換算濃度；分析方法選擇（analytical method selection）——先看待測物是否揮發、是否具 UV 發色團或是否為元素，再選擇相應技術。

第 4 題

下列液相層析－質譜（LC-MS）分析的離⼦化法中，何者最適⽤於蛋⽩質的測定？
  1. （A）粒⼦束（particle beam）
  2. （B）熱噴灑（thermospray）
  3. （C）⾼速原⼦撞擊（FAB）
  4. （D）電灑法（ESI）

答案：（D）

詳解與考點

正解：完整蛋白質分子量大且極性高，電灑法（ESI）可由溶液形成多重帶電離子，使其 m/z 落在質譜可量測範圍，並能直接與 LC 串聯，故選 D。

A：粒子束法較適合分子量較小的分析物，對完整蛋白質並非首選離子化方式。

B：熱噴灑法主要用於較小且具熱穩定性的極性分析物，難以兼顧大型蛋白質的溫和離子化。

C：FAB 雖屬軟性離子化法，但常依賴基質且不如 ESI 適合 LC-MS 對完整蛋白質的直接分析。

本題考點：電灑游離（electrospray ionization, ESI）——分析蛋白質與胜肽時，優先選能產生多重帶電離子的溫和游離法；質荷比（mass-to-charge ratio, m/z）——多重帶電會降低大型分子的表觀 m/z，使質譜儀得以偵測。

第 5 題

下列藥物性質的測定中，何者不是紫外光光譜法的應⽤項⽬？
  1. （A）pKa測定
  2. （B）溶離速率測定
  3. （C）含⽔量測定
  4. （D）油⽔分配係數測定

答案：（C）

詳解與考點

正解：紫外光光譜法量的是物質對特定波長的吸收，含水量本身沒有可據以直接定量的專一 UV 吸收，通常以 Karl Fischer 法等方法測定，故選 C。

A：具發色團的酸鹼物質可量測不同 pH 下的吸收變化，據以求得 pKa，故（A）是 UV 光譜法的應用。

B：溶離試驗可定時取樣，以 UV 吸光值換算已溶出藥物濃度，故（B）正確。

D：若藥物具有 UV 吸收，可量測油相與水相濃度以求油水分配係數，故（D）亦可應用 UV 光譜法。

本題考點：紫外可見光譜定量（UV-Vis spectrophotometry）——待測物須有可量測且可歸屬的吸收訊號，才能以吸光值換算濃度；水分測定（water determination）——判斷含水量時優先選擇針對水反應或質量損失的技術，不以 UV 吸收取代。

第 6 題

下列何種芳香環類藥物可在鹼性環境（0.1 N NaOH）下產⽣增⾊效應（hyperchromic effect）？
  1. （A）ibuprofen
  2. （B）amphetamine
  3. （C）ephedrine
  4. （D）phenylephrine

答案：（D）

詳解與考點

正解：phenylephrine 的芳香環帶有酚性羥基，在 0.1 N NaOH 中可形成 phenoxide；電子效應改變芳香發色團的吸收，使吸收強度增加，這就是 hyperchromic effect，故選 D。

A：ibuprofen 雖含羧酸，但其羧基與芳香環間隔飽和碳，鹼化後不會形成與芳香環共軛的 phenoxide，故不符本題機轉。

B：amphetamine 的芳香環不具酚性羥基，鹼化主要改變胺基質子化狀態，不能產生題目所述的酚鹽增色效應。

C：ephedrine 的羥基是脂肪族醇羥基而非酚性羥基，故（C）不會以形成 phenoxide 的方式增色。

本題考點：增色效應（hyperchromic effect）——吸收強度上升時，先找是否有酸鹼化後可改變共軛或電子分布的發色團；酚鹽形成（phenoxide formation）——芳香酚在鹼性下去質子化後，常比中性酚呈現不同且較強的 UV 吸收。

第 7 題

下列各C－X（X非C）鍵結於紅外光光譜中之吸收強度由強⾄弱之排列為何？①C－O ②C－N ③C－C－ H ④C－Cl
  1. （A）③④②①
  2. （B）②①④③
  3. （C）④②①③
  4. （D）①④②③

答案：（D）

詳解與考點

正解：紅外光吸收強度取決於振動時偶極矩改變的大小。C-O 鍵的偶極矩改變最大，其後依序為 C-Cl、C-N、C-H，因此強至弱為 C-O > C-Cl > C-N > C-H，對應（D），故選 D。

A：將最弱的 C-H 排在最前，並把最強的 C-O 排在最後，與偶極矩改變的判準相反。

B：把 C-N 排在 C-O 之前；兩者相比，C-O 振動造成的偶極矩改變較大，故此順序不對。

C：雖把 C-H 排在最後，卻未將 C-O 列為最強吸收，故（C）仍不正確。

本題考點：IR 吸收強度（infrared absorption intensity）——比較鍵伸縮振動時，看偶極矩改變而非只看鍵是否存在；鍵極性（bond polarity）——異核原子間電負度差與振動偶極矩改變越顯著，吸收帶通常越強。

第 8 題

在波⻑248 nm下，hydrocortisone sodium phosphate之比吸光值A（1%, 1 cm）為333，在此波⻑下測得 hydrocortisone sodium phosphate樣品溶液之吸光值為0.666，則該溶液之濃度為何？
  1. （A）0.002 mg/1000 mL
  2. （B）0.002 mg/100 mL
  3. （C）0.002 g/1000 mL
  4. （D）0.002 g/100 mL

答案：（D）

詳解與考點

正解：題目給的是比吸光值 A（1%, 1 cm），故以 A = A（1%, 1 cm）× c 計算，其中 c 以 % w/v 表示且光徑為 1 cm。先算 c = 0.666 / 333 = 0.002%。再換算 0.002% w/v = 0.002 g/100 mL，因此為（D），故選 D。

A：0.002 mg/1000 mL 同時把質量單位與體積基準都誤讀，遠低於計算所得濃度。

B：0.002 mg/100 mL 的體積基準正確，但把 0.002 g 誤作 0.002 mg，少了 1,000 倍。

C：0.002 g/1000 mL 的質量正確，但把 % w/v 的每 100 mL 誤換成每 1000 mL，濃度少了 10 倍。

本題考點：比吸光值（specific absorbance）——A（1%, 1 cm）代表 1% w/v 溶液、1 cm 光徑的吸光值，計算時濃度單位須維持 % w/v；單位換算（unit conversion）——把百分濃度改寫成質量／體積前，先固定 1% = 1 g/100 mL。

第 9 題

以⽑細管電泳法分析光學異構物pilocarpine和isopilocarpine時，下列何種背景電解質溶液可以提供最好的分離 效果？
  1. （A）0.1 M phosphate buffer
  2. （B）0.1 M phosphate buffer containing 0.05 M SDS
  3. （C）0.1 M phosphate buffer containing 0.01 M β-cyclodextrin
  4. （D）0.1 M phosphate buffer containing 10% MeOH

答案：（C）

詳解與考點

正解：pilocarpine 與 isopilocarpine 為光學異構物，在非手性背景電解質中通常沒有足夠的遷移率差。β-cyclodextrin 可與兩者形成穩定度不同的包合複合體，提供手性辨識並分開遷移率，故選 C。

A：單用 phosphate buffer 沒有手性選擇劑，無法有效區分兩個光學異構物。

B：SDS 可形成微胞並改變疏水性選擇，但 SDS 本身不提供本題所需的手性辨識，故（B）不是最佳選項。

D：MeOH 可改變溶液性質與電滲流，卻不會建立異構物間的手性作用差異，故分離效果不如（C）。

本題考點：手性毛細管電泳（chiral capillary electrophoresis）——分離對映或光學異構物時，背景電解質須加入手性選擇劑；環糊精包合（cyclodextrin inclusion complexation）——不同立體異構物與 β-cyclodextrin 的包合穩定度不同，會轉化為可量測的遷移率差。

第 10 題

下列何種氣相層析檢測器須配備放射性物質？
  1. （A）electron capture detector
  2. （B）flame ionization detector
  3. （C）thermal conductivity detector
  4. （D）nitrogen phosphorus detector

答案：（A）

詳解與考點

正解：electron capture detector 以放射性 β 射線源產生背景電流，具捕捉電子能力的分析物會使電流下降，因此須配備放射性物質，故選 A。

B：flame ionization detector 以氫焰將有機物離子化後量測電流，訊號來自火焰，不需放射性物質。

C：thermal conductivity detector 比較載氣與流出物的導熱度，依熱導差異偵測，故（C）不使用放射源。

D：nitrogen phosphorus detector 利用鹼金屬珠與火焰增強含氮、含磷化合物訊號，並非以放射線偵測。

本題考點：電子捕獲偵測器（electron capture detector, ECD）——看到捕獲電子與背景電流下降時，連結其放射性電子源；氣相層析偵測器選擇（GC detector selection）——依分析物的電負性、可燃性或導熱差異選擇偵測器，不把所有 GC 偵測器都視為同一原理。

第 11 題

下列何種溶劑組合最適合⽤於去除hydrocortisone軟膏之基質？
  1. （A）water－chloroform
  2. （B）water－n-butanol
  3. （C）acetonitrile－hexane
  4. （D）MeOH－hexane

答案：（D）

詳解與考點

正解：hydrocortisone 具有多個羥基與羰基，軟膏基質則多為脂溶性成分。MeOH 可萃取較極性的 hydrocortisone，hexane 可溶解並帶走非極性基質，兩者能有效分離待測物與基質，故選 D。

A：chloroform 會同時溶解軟膏基質與 hydrocortisone，兩者一起進入有機相而分不開，water 對 hydrocortisone 的萃取能力又有限，因此 water-chloroform 不如（D）適合兼顧待測物回收與脂性基質去除。

B：軟膏基質多為凡士林等碳氫化合物，在 water 與 n-butanol 中皆不溶，這組溶劑根本帶不走基質，無法達成去除軟膏基質的目的。

C：acetonitrile 與 hexane 雖可分相、看似與 MeOH-hexane 同型，但 hydrocortisone 這類多羥基 steroid 在 acetonitrile 中的溶解度明顯低於 MeOH，回收率不足，故非最佳組合。

本題考點：液液萃取（liquid-liquid extraction）——去除製劑基質時，利用待測物與基質在極性上的差異分配；軟膏前處理（ointment sample preparation）——脂性基質宜以非極性溶劑處理，待測的較極性類固醇則以適當極性醇類萃取。

第 12 題

下列何種滴定法最適合作為chlorpromazine（MW= 318；pKa= 9.3；SolH2O= 2.55 mg/L）的定量分析法？
  1. （A）非⽔滴定法
  2. （B）沉澱滴定法
  3. （C）酸滴定法
  4. （D）鹼滴定法

答案：（A）

詳解與考點

正解：chlorpromazine 是弱有機鹼，pKa 為 9.3，而游離鹼在水中的溶解度僅 2.55 mg/L。非水酸性溶媒可先使其溶解，再以過氯酸進行酸鹼滴定並得到清楚終點，故選 A。

B：沉澱滴定法須依賴待測物與試劑形成可定量的難溶鹽，本題的弱鹼與低水溶性並不支持此方法。

C：水相酸滴定雖可中和鹼性官能基，但游離 chlorpromazine 的低水溶性會妨礙均一反應與終點判定。

D：鹼滴定法適用於可釋放質子的酸性待測物；chlorpromazine 的主要官能基表現為鹼性，方向不符。

本題考點：非水滴定（nonaqueous titration）——弱有機鹼若水溶性不足，可在適當非水酸性溶媒中溶解後以強酸滴定；酸鹼滴定溶媒效應（solvent effect）——方法選擇須同時考慮待測物酸鹼性與溶解度，不能只看 pKa。

第 13 題

有關卡爾費雪（Karl Fischer）⽔分測定法中，其試劑不包含下列何者？
  1. （A）碘化鉀
  2. （B）⼆氧化硫
  3. （C）吡啶
  4. （D）甲醇

答案：（A）

詳解與考點

正解：經典 Karl Fischer 水分測定試劑的關鍵成分為碘、二氧化硫、吡啶與甲醇；（A）碘化鉀不是其中的試劑成分，故選 A。

B：二氧化硫參與 Karl Fischer 反應，是經典試劑的必要成分之一，故（B）正確。

C：吡啶在經典配方中作為有機鹼，故（C）不是本題要找的選項。

D：甲醇提供反應所需的醇性介質，亦為經典 Karl Fischer 試劑成分，故（D）正確。

本題考點：卡爾費雪水分測定（Karl Fischer titration）——辨認經典試劑時，掌握碘、二氧化硫、有機鹼與醇性溶媒四類組成；水分專一反應（water-specific reaction）——含水量分析選擇會與水化學計量反應的試劑系統，而非一般的鹽類試劑。

第 14 題

在非⽔溶液滴定時，下列何者為標定過氯酸的常⽤試劑？
  1. （A）NaOH
  2. （B）C6H4(CO2K)CO2H
  3. （C）KOH
  4. （D）CH3ONa

答案：（B）

詳解與考點

正解：非水滴定中常以鄰苯二甲酸氫鉀作為過氯酸標定用基準物質；其化學式為 C6H4(CO2K)CO2H，對應（B），故選 B。

A：NaOH 易吸收水分與二氧化碳，並非本題非水過氯酸標定的常用基準物質。

C：KOH 同樣具吸濕性與吸收二氧化碳的問題，難作為穩定的標定基準。

D：CH3ONa 是非水鹼滴定可用的強鹼試劑，並非用來標定過氯酸的常用酸式基準物質。

本題考點：非水酸滴定標定（nonaqueous acidimetry standardization）——標定過氯酸時，選擇穩定、可精確秤量且能定量反應的酸式基準物質；基準物質（primary standard）——避免使用吸濕或易吸收二氧化碳的強鹼作為需要高準確度的標定基準。

第 15 題

詳解與考點

正解：Kieselguhr G-liquid paraffin 為非極性固定相時，較疏水的脂肪酸在固定相中停留較久，Rf 較小。硬脂酸為飽和的 C18 脂肪酸，在列出的脂肪酸中與液體石蠟的非極性作用最強，移動最少，故選 C。

B：棕櫚酸只有 C16 碳鏈，非極性碳鏈較短，與固定相的分配作用小於硬脂酸。

D：亞麻酸含三個雙鍵，不飽和度最高，和硬脂酸相比較不易強烈分配到液體石蠟固定相，Rf 不會最小。

本題考點：薄層層析的 Rf（thin-layer chromatography Rf）——固定相保留越強，分析物前進越少，Rf 越小；反相分配層析（reversed-phase partition chromatography）——非極性固定相下，比較脂肪酸時先看碳鏈長度與不飽和度造成的疏水性差異。

第 37 題

將⽔溶液中的弱酸性物質以有機溶劑充分萃取時，應調整⽔溶液的酸鹼值（pH），該pH值與此酸性物質之 pKa關係為何？

  2. （B）＝pKa＋2
  3. （C）＝pKa＋1
  4. （D）＝pKa

答案：（A）

詳解與考點

正解：弱酸要萃入有機層，應使其以不帶電的 HA 形式為主。由 pH = pKa + log([A-]/[HA])，若 pH = pKa - 2，則 [A-]/[HA] = 0.01，HA 約占 99%，最有利於進入有機溶劑，故選 A。

B：pH = pKa + 2 時，[A-]/[HA] = 100，弱酸幾乎都以帶電的 A- 形式留在水層。

C：pH = pKa + 1 時，[A-]/[HA] = 10，帶電型態已占多數，無法達到充分萃取弱酸的條件。

D：pH = pKa 時，[A-] 與 [HA] 比例為 1，只有約一半為中性型態，萃取不如 pKa - 2 有利。

本題考點：Henderson–Hasselbalch equation——弱酸的水有機萃取先算 [A-]/[HA]，pH 比 pKa 低 2 時可使中性 HA 占絕大多數；酸鹼萃取（acid–base extraction）——要把弱酸移至有機層就提高未離子化比例，弱鹼則採相反的 pH 調整方向。

  2. （B）降低分析時的溫度
  3. （C）降低分析物在動相中的擴散係數
  4. （D）降低靜相粒⼦的⼤⼩

答案：（D）

詳解與考點

正解：液相層析管效率以理論板數高、板高 H 小為目標。降低靜相粒子大小可減少流路不均並縮短分析物在粒子內外的傳質距離，降低 Van Deemter 式中的渦流與傳質項，因此提升管柱效率，故選 D。

A：降低分析物在靜相中的擴散係數會使其較慢達到分配平衡，增加靜相傳質阻力，不利於效率。

B：降低分析溫度通常會提高流動相黏度並降低擴散與傳質速率，不能作為一般提升效率的方法。

C：降低動相擴散係數雖可能減少縱向擴散項，卻會增加動相傳質阻力；它只是改變最佳流速的權衡，不能普遍提高管柱效率。

第 40 題

  1. （A）7
  2. （B）8
  3. （C）9
  4. （D）10

答案：（C）

詳解與考點

正解：承上題的 0.1 M HCl 與 0.1 M NaOH 可分別視為未解離型與去質子化型的吸收端點，吸光度為 0.4 與 1.5。pH 8 時，去質子化型分率 = (0.5 - 0.4) / (1.5 - 0.4) = 0.1 / 1.1 = 1/11，故去質子化型與未解離型之比 = (1/11) / (10/11) = 0.1。代入 Henderson-Hasselbalch 式：pH = pKa + log([A-]/[HA])，8 = pKa + log 0.1 = pKa - 1，因此 pKa = 9，故選 C。

本題考點：麥角生物鹼溶解性（ergot alkaloid solubility）——帶有胜肽型側鏈的 ergopeptine 類，如 ergotamine，判為非水溶性；簡單麥角酸醯胺（simple lysergic acid amides）——ergometrine 與 ergonovine 類應和 ergotamine 分開記憶。

第 72 題

下列有關吳茱萸之基原科別、學名及⽣藥名之配對，何者正確？
  1. （A）Sterculiaceae－Sterculia lychnophora－Sterculiae Semen
  2. （B）Solanaceae－Lycium chinensis－Lycii Radicis Cortex
  3. （C）Rutaceae－Evodia rutaecarpa－Evodiae Fructus
  4. （D）Magnoliaceae－Magnolia biondii－Magnoliae Flos

答案：（C）

詳解與考點

正解：依題目採用的生藥學命名，吳茱萸的基原為 Rutaceae 的 Evodia rutaecarpa，生藥名為 Evodiae Fructus；（C）三者配對完整正確，故選 C。

A：Sterculia lychnophora 所對應的是胖大海相關生藥，不是吳茱萸；科別與學名即使自成配對，也未能滿足題目所問藥材。

B：Lycium chinensis 屬 Solanaceae，其根皮為地骨皮相關生藥，與吳茱萸的果實來源不同。

D：Magnolia biondii 屬 Magnoliaceae，對應辛夷類花藥材，不是吳茱萸。

本題考點：吳茱萸（Evodiae Fructus）——題幹採用 Evodia rutaecarpa 時，應同時連結 Rutaceae 與果實生藥名；基原、科別與生藥名配對（source-family-drug-name matching）——三項必須同時一致，只有學名或科別局部正確仍不能作答。

第 73 題

下列有關tropane alkaloid之敘述，何者正確？
  1. （A）具三環結構之化合物
  2. （B）由吡咯啶（pyrrolidine）與2分⼦⼄酸縮合⽽成
  3. （C）主要分布於唇形科植物
  4. （D）其⽣合成前驅物（precursor）為⿃胺酸（ornithine）

答案：（D）

詳解與考點

正解：tropane alkaloid 的生合成從鳥胺酸（ornithine）出發，經由相關胺基與 pyrrolidine 中間體形成 tropane 骨架；（D）正確，故選 D。

A：tropane 的基本母核為雙環性 8-azabicyclo 結構，不是三環結構。環數是辨識 tropane 與其他複雜生物鹼的重要線索。

B：生合成雖會經過 pyrrolidine 型中間體並納入乙酸來源的碳單位，卻不是游離 pyrrolidine 與 2 分子 acetate 直接縮合而成；起始前驅物仍應判為 ornithine。

C：tropane alkaloids 主要分布於茄科（Solanaceae），如 Datura 與 Atropa，並非以唇形科為主要來源。

本題考點：莨菪烷生物鹼生合成（tropane alkaloid biosynthesis）——問前驅物時由 ornithine 判定，不把中間體當成起始原料；莨菪烷骨架（tropane skeleton）——基本母核為雙環性含氮結構，並常與 Solanaceae 藥材相連。

正解：calabar bean 的植物基原為 Physostigma venenosum，是 physostigmine 的來源；（B）正確，故選 B。

第 75 題

下列何者為isoquinoline類⽣物鹼？
  1. （A）quinidine
  2. （B）reserpine
  3. （C）morphine
  4. （D）caffeine

答案：（C）

詳解與考點

正解：morphine 屬 phenanthrene 型 isoquinoline alkaloid；（C）因此符合 isoquinoline 類生物鹼，故選 C。

A：quinidine 為 quinoline alkaloid，雖然名稱與 isoquinoline 只差一個前綴，母核分類並不相同。

B：reserpine 為 indole alkaloid，和 morphine 的 isoquinoline 生合成與骨架分類不同。

D：caffeine 為 purine alkaloid，屬黃嘌呤衍生物，不屬 isoquinoline 類。

本題考點：異喹啉生物鹼（isoquinoline alkaloids）——見到 morphine 時，可由其 phenanthrene 型 isoquinoline 骨架判定；生物鹼母核（alkaloid parent skeleton）——quinoline、indole、purine 與 isoquinoline 必須依環系結構分辨，不能依名稱相似度推論。

第 76 題

  1. （A）arecoline
  2. （B）yohimbine
  3. （C）colchicine
  4. （D）codeine

答案：（C）

詳解與考點

正解：colchicine 的氮原子位於 acetamido 側鏈，不是環狀骨架的一部分；（C）符合氮原子不在環上的條件，故選 C。

A：arecoline 的氮原子位於含氮雜環中，因此不符合題幹所問的環外氮。

B：yohimbine 為含氮環系的 indole alkaloid，氮原子屬於環狀結構的一部分。

D：codeine 為 morphinan 型生物鹼，其胺基氮位於環系內，與 colchicine 的環外 acetamido 氮不同。

本題考點：秋水仙鹼結構（colchicine structure）——看到 acetamido 側鏈上的氮而非雜環氮時，可判為 colchicine 的特徵；原生物鹼（protoalkaloids）——氮原子不併入環狀骨架是區別此類型與典型雜環生物鹼的操作線索。

第 78 題

Spearmint oil中主要含下列何種成分？
  1. （A）d-citronellol
  2. （B）l-citronellol
  3. （C）d-carvone
  4. （D）l-carvone

答案：（D）

詳解與考點

正解：Spearmint oil 的主要特徵成分為 l-carvone；（D）同時符合成分名稱與旋光異構配置，故選 D。

A：d-citronellol 為單萜醇，並非 Spearmint oil 的主要成分；本題不能只因同為揮發油單萜就視為相同來源。

B：l-citronellol 的鏡像異構配置雖不同，母體仍是 citronellol，不是 spearmint 的主成分 carvone。

第 79 題

清熱解毒藥中，含 forsythiaside 成分者為何？

  2. （B）板藍根
  3. （C）⾦銀花
  4. （D）連翹

答案：（D）

詳解與考點

正解：連翹是清熱解毒藥中含 forsythiaside 的來源藥材；此成分可作為連翹的辨識線索，故選 D。

A：敗醬草雖同屬清熱解毒用途的藥材，但其鑑別成分不是 forsythiaside，不能依相同功效推定為來源。

第 80 題

下列敘述，何項錯誤？
  1. （A）毒扁豆為豆科植物，產於⻄非
  2. （B）毒扁豆鹼可⽤於散瞳
  3. （C）⾺錢⼦種⼦為盤狀
  4. （D）reserpine為蛇根⽊之重要成分

答案：（B）

詳解與考點

正解：毒扁豆鹼（physostigmine）抑制 acetylcholinesterase，會增強副交感神經作用，使瞳孔括約肌收縮而造成縮瞳；（B）寫成可用於散瞳，作用方向相反，故選 B。

A：毒扁豆（Physostigma venenosum）為豆科植物，原產於西非，敘述正確，故非答案。

C：馬錢子為馬錢科植物的乾燥種子，外形呈扁平盤狀，敘述正確，故非答案。

D：reserpine 是蛇根木（Rauwolfia serpentina）的重要生物鹼成分，敘述正確，故非答案。

本題考點：膽鹼酯酶抑制劑（acetylcholinesterase inhibitor）——判斷眼部作用時，acetylcholine 增加會導向縮瞳，不是散瞳；毒扁豆鹼（physostigmine）——將其與抗 muscarinic 藥物區分，前者增強副交感作用，後者才會造成散瞳。
